# 人类紧急求生与健康指南

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 📖 项目简介

这是一本全面的紧急求生与健康指南手册,旨在为人们在面对各种紧急情况、疾病伤害、自然灾难以及野外生存挑战时提供实用的指导和帮助。

**⚠️ 重要声明**:本手册提供的信息仅供参考和教育目的。在实际紧急情况下,请务必优先寻求专业医疗人员的帮助。本手册不能替代专业医疗建议、诊断或治疗。

## 📚 内容目录

### [一、日常疾病和伤害应对手册](docs/01-日常疾病和伤害/README.md)

提供常见疾病和伤害的识别、预防和应急处理方法。

- **常见疾病**: 感冒、发烧、腹泻、食物中毒等
- **外伤处理**: 割伤、擦伤、烫伤、烧伤、冻伤等
- **骨骼损伤**: 骨折、脱臼、扭伤等
- **异物处理**: 眼睛、耳朵、鼻子、喉咙进异物
- **急性症状**: 过敏反应、中暑、失温等
- **心脑血管与突发病症**: 中风、心梗、低血糖、癫痫发作、哮喘发作
- **居家与交通意外**: 一氧化碳中毒、车祸现场处理
- **慢性病用药储备**: 突然停药的风险、长期处方、胰岛素储存、用药信息卡
- **口腔问题**: 牙痛、牙脓肿危险信号、牙齿撞掉、拔牙后出血
- **心理健康**: 危机后的正常反应、心理急救、自杀风险、哀伤、儿童心理

### [二、灾难应对手册](docs/02-灾难应对/README.md)

针对各类自然灾害和人为灾难的预防、应对和自救措施。

- **地质灾害**: 地震、泥石流、山体滑坡、火山喷发
- **气象灾害**: 台风、暴风雪、洪水、干旱、龙卷风
- **海洋灾害**: 海啸、风暴潮
- **火灾**: 建筑火灾、森林火灾
- **人为灾难**: 战乱、化学泄漏、核辐射

### [三、野外生存指南](docs/03-野外生存/README.md)

在各种极端环境下的生存技能和策略。

- **荒岛求生**: 水源获取、食物采集、庇护所建造、求救信号
- **森林求生**: 方向辨别、野外食物、危险动植物识别
- **沙漠求生**: 水源寻找、防晒避暑、沙漠导航
- **雪地/极地求生**: 保暖技巧、防止冻伤、雪地庇护所
- **山地求生**: 高原反应应对、岩石庇护、山地导航
- **末日求生**: 长期生存策略、资源储备、社区建设

### [四、动植物培育指南](docs/04-动植物培育/README.md)

常见可食用和有用动植物的培育方法。

- **蔬菜种植**: 快速生长蔬菜、根茎类、叶菜类
- **粮食作物**: 水稻、小麦、玉米、土豆、红薯(最高产)、大豆、高粱
- **果树培育**: 常见果树的种植和养护
- **药用植物**: 常见药用植物的识别和种植
- **家禽养殖**: 鸡、鸭、鹅的饲养
- **家畜养殖**: 猪、羊、兔的饲养
- **水产养殖**: 鱼类、虾类的养殖方法

### [五、冶金技术](docs/05-冶金技术/README.md)

末日情况下从零开始的金属冶炼和工具制作。

> ⚠️ **仅限文明崩溃、工业体系瓦解等极端情况。** 高温作业、有毒烟气、熔融金属遇水爆炸,非紧急情况请勿尝试。

- **基础冶金知识**: 炉子建造、燃料选择、温度控制
- **铁的冶炼**: 铁矿识别、炼铁技术、生铁到钢的转化
- **铜的冶炼**: 铜矿处理、青铜制作
- **简易工具锻造**: 刀、斧、锄、镰刀、钉子的制作
- **金属加工技术**: 锻造、铸造、淬火、退火

### [六、制药技术](docs/06-制药技术/README.md)

文明崩溃、无法获得商业药品时的应对。**重点是提前储备和可行的替代方案,而不是自制。**

> ⚠️ **在有现代医疗可及的情况下,绝不要自制药物。** 本章同时说明哪些药物确实无法自制,以免误信偏方。

- **基础制药知识**: 安全须知、提取方法、保存技术
- **消毒剂制备**: 酒精蒸馏、碘酒配制(最可行、最有用的一类)
- **抗生素**: 为什么不能自制、如何储备、天然抗菌物(蜂蜜等)
- **解热镇痛药**: 柳树皮煎剂;为何无法自制阿司匹林和扑热息痛
- **中药制剂**: 常用中药的炮制和提取

### [七、日常生活技能](docs/07-日常生活技能/README.md)

长期生活中最基础、却最容易被忽视的技能。

- **食物加工与保存**: 晒干、盐腌、发酵、烟熏、窖藏、罐藏;高风险食品(米酵菌酸、肉毒、黄曲霉)
- **营养与营养缺乏病**: 坏血病、脚气病、糙皮病等的识别与预防
- **卫生设施**: 应急厕所、旱厕、洗手点、粪便利用、垃圾处理
- **制皂**: 皂荚无患子、草木灰碱水制皂
- **长期住所**: 选址、防潮、土坯与夯土墙、木结构、抗震、保温、火炕炉灶与烟囱

## 📖 推荐阅读顺序

### 初学者
1. 先阅读[基础急救知识](docs/01-日常疾病和伤害/00-基础急救知识.md)
2. 了解[常见疾病](docs/01-日常疾病和伤害/01-常见疾病.md)
3. 学习[外伤处理](docs/01-日常疾病和伤害/02-外伤处理.md)

### 进阶学习
1. 掌握[灾难应对](docs/02-灾难应对/README.md)基本原则
2. 学习[野外生存](docs/03-野外生存/README.md)基础技能
3. 了解[动植物培育](docs/04-动植物培育/README.md)基础知识
4. 学习[日常生活技能](docs/07-日常生活技能/README.md): 食物保存、营养、卫生

### 末日准备
1. **提前储备**: 药品、伤口处理物资、种子、工具(见[制药技术-储备建议](docs/06-制药技术/02-抗生素制备.md#六储备建议))
2. 学习[冶金技术](docs/05-冶金技术/README.md)制作基本工具
3. 了解[制药技术](docs/06-制药技术/README.md)中可行的部分(消毒剂、中药、天然抗菌物)
4. 建立长期生存知识体系
