## 割伤与擦伤

### 伤口分类

**轻微伤口**:
- 浅表,出血少
- 边缘整齐
- 长度<2 cm
- 可自行处理

**需就医的伤口**:
- 深度超过0.5 cm
- 长度>2 cm
- 出血严重不止
- 边缘不整齐
- 脏污严重
- 特殊部位(面部、关节、手掌)

还要补充几种外表看着不大、但必须就医的情况:

| 情况 | 为什么要就医 |
|------|------|
| 伤口张开,能看见黄色颗粒状脂肪、红色肌肉或白色的筋、骨头 | 已经深达皮下,通常需要缝合 |
| 手指、手掌伤后某个手指伸不直、弯不了,或指尖麻木 | 可能切断了肌腱或神经,要尽早手术修复 |
| 按压10分钟仍止不住血,或血是一股一股往外喷 | 可能伤到动脉 |
| 刀、玻璃等扎进胸部、腹部、颈部 | 可能伤及内脏和大血管,即使伤口很小 |
| 伤口里有玻璃碴、木屑、泥沙洗不出来 | 异物留在里面会反复感染 |
| 被动物或人咬伤 | 感染和狂犬病风险,见本章[咬伤](#咬伤) |
| 伤者患糖尿病、正在服用抗凝药或免疫力低下 | 容易出血不止或感染 |

#### 哪些伤口需要缝合,什么时候缝

```
一般需要缝合(或医用胶水、皮肤钉)的伤口:
- 伤口张开,两侧皮肤不能自然合拢
- 长度超过约1-2 cm 且有一定深度
- 位于面部、嘴唇、眼睑(影响外观和功能)
- 位于关节处,一活动伤口就裂开

时间窗:
- 最好在受伤后6-8小时内缝合
- 面部、头皮血运好,可以放宽到24小时左右
- 超过时间或很脏的伤口,医生可能先清洗、换药几天后再缝(延期缝合),
  这不是耽误,而是为了不把细菌封在里面

小而干净、边缘整齐的切口(如菜刀切到指腹):
✓ 止血、冲洗后,可用免缝胶带(蝶形胶布)把两侧皮肤拉拢贴住
✓ 胶带横跨伤口,间隔约3-5 mm 贴几条,让伤口自然对齐即可,不要拉得过紧
❌ 咬伤、脏伤口、刺伤不要用胶带封闭,要保持引流

❌ 不要自己用针线缝合伤口: 缝合前需要彻底清创和局部麻醉,
   在家缝合常把细菌封在伤口里,引起深部感染
```

### 处理步骤

#### 1. 止血

```
轻微出血:
1. 清水冲洗
2. 干净纱布按压5-10分钟
3. 抬高伤处(高于心脏)

严重出血:
1. 立即按压止血
2. 持续按压至少10分钟
3. 必要时使用止血点
4. 呼叫急救
```

止血的要领:

```
✓ 用整块纱布或干净布叠成厚垫,用手掌直接压在出血点上,用力压
✓ 按压期间不要掀开看(每掀开一次,刚形成的血凝块就被扯掉)
✓ 血渗透了,在上面再加一层继续压,不要撤掉第一层
✓ 没有纱布: 干净毛巾、T恤、卫生巾都可以;实在没有就直接用手压
✓ 小伤口渗血是正常的,止住后再清洗;大出血先止血,清洗交给医院

⚠️ 四肢大出血压不住、危及生命时才用止血带,要记录时间
⚠️ 服用阿司匹林、氯吡格雷、华法林等药物的人,出血时间会延长,
   按压时间加倍;仍止不住要就医
```

止血带用法见[基础急救知识-止血带](00-基础急救知识.md#4-止血带最后手段)。

#### 2. 清洁伤口

```
步骤:
1. 洗手(或戴医用手套)
2. 流动清水冲洗伤口至少5分钟
3. 去除明显污物
4. 温和肥皂水清洁周围皮肤
5. 再次清水冲洗

注意:
❌ 不要用酒精直接冲洗伤口(疼痛且损伤组织)
❌ 不要用棉花直接接触伤口(纤维残留)
✓ 可用碘伏消毒
```

**冲洗是预防伤口感染最重要的一步**,比涂什么药都重要。细菌和泥沙要靠水流的量和冲力带走:

```
用多少水:
- 小擦伤、小切口: 至少冲5分钟,或用0.5-1 L 水
- 较大、较脏的伤口: 用数升水,冲到看不见泥沙、伤口发白干净为止
- 动物咬伤: 至少冲15分钟(见本章"咬伤")

用什么水:
✓ 能直接喝的自来水、瓶装水、烧开后放凉的水都可以,效果和生理盐水差不多
✓ 自制生理盐水: 1 L 凉开水加9 g 食盐(约2平茶匙)
❌ 不要用没有处理过的河水、塘水、井水直接冲伤口

怎样冲出力度:
- 伤口放在水龙头下,水流开到中等,不要猛冲到组织翻起
- 没有自来水: 用不带针头的注射器(20-50 mL)挤压冲洗;
  或在干净塑料袋、矿泉水瓶盖上扎一个小孔,装水后挤压,形成细水柱
- 边冲边用干净纱布轻轻擦掉附着的污物

去除嵌入的沙粒、碎屑:
✓ 用煮沸或酒精擦过的镊子夹出
✓ 夹不出、数量多 → 就医,医生会麻醉后清理
```

生理盐水的配制见[消毒剂制备-生理盐水](../06-制药技术/01-消毒剂制备.md#72-配制),野外没有干净水时的处理见[野外伤病处置与转运-伤口](../03-野外生存/11-野外伤病处置与转运.md#伤口)。

#### 3. 消毒

```
推荐消毒剂:
- 碘伏(首选):从伤口中心向外涂抹
- 双氧水:清除污垢,有气泡是正常现象
- 75%酒精:仅用于周围皮肤,避免直接接触伤口
```

```
✓ 碘伏刺激小,可以直接涂在伤口上;涂一次即可,不必天天反复涂厚厚一层
⚠️ 双氧水(3%)只在伤口很脏时用一次帮助带出污物,随后要用清水冲净;
   它也会损伤新生组织,不要每天用,不要用于深伤口和已经开始长肉的伤口
⚠️ 碘过敏、甲状腺疾病患者、孕妇和新生儿避免大面积长期使用碘伏
❌ 不要涂紫药水、红药水(汞溴红)、牙膏、草木灰、香灰、烟丝、白糖
   (有的有毒,有的带菌,有的让伤口结硬痂、掩盖感染)
```

#### 4. 包扎

```
小伤口:
- 创可贴(每天更换)
- 保持干燥

大伤口:
1. 无菌纱布覆盖
2. 医用胶带固定
3. 每1-2天更换
4. 观察感染迹象
```

```
包扎的要点:
✓ 敷料要比伤口每边大出约2 cm
✓ 伤口很容易粘纱布时,先薄涂一层凡士林或抗菌软膏,
  或用不粘伤口的敷料(油纱、凡士林纱布)
✓ 绷带缠在四肢上,松紧以能塞进一根手指为准;
  包完检查手指脚趾: 发白、发紫、发凉、麻木 → 太紧,松开重包
✓ 创可贴不要一贴好几天: 闷湿的皮肤发白起皱,反而容易感染
```

### 换药步骤

```
1. 洗手
2. 轻轻揭开旧敷料(先用温水浸湿)
3. 检查伤口
4. 清水轻轻冲洗
5. 重新消毒
6. 覆盖新的无菌纱布
7. 固定
```

#### 多久换一次

| 情况 | 换药频率 |
|------|------|
| 干净的小伤口,敷料干燥 | 每天1次;伤口闭合后(通常2-3天)可以不再覆盖 |
| 渗液多、敷料湿透 | 湿了就换,可能一天2-3次 |
| 敷料被水打湿或弄脏 | 立即换 |
| 已经感染、有脓 | 每天1-2次,同时尽快就医 |
| 缝合的伤口 | 按医生交代;一般24-48小时内保持干燥,之后可以短时间淋浴,洗完擦干换药 |

换药时要看什么:

```
每次换药都检查:
- 伤口周围的红肿范围: 比上次大还是小?(可以用笔在红肿边缘画线对比)
- 渗出物: 淡红色或淡黄色清亮液体是正常的;浑浊、黄绿色、有臭味是感染
- 疼痛: 一天比一天轻是正常的;一天比一天重是警告

敷料粘住了:
✓ 用凉开水或生理盐水浸湿几分钟,等它软了再慢慢揭
❌ 不要干着硬撕,会撕掉新长的组织,又重新出血
```

#### 没有现成敷料时

```
✓ 干净的纯棉布(旧床单、T恤)剪成块,煮沸10分钟,晾干或用热熨斗烫干后使用
✓ 用干净塑料袋或纸包好存放,用的时候只捏边角
✓ 卫生巾、新的尿不湿可以临时当吸水敷料(贴伤口的一面是干净的)
✓ 胶带不够时,用布条或绷带绕肢体一圈固定
❌ 不要用棉花、纸巾直接盖伤口(纤维会粘在伤口里)
❌ 用过的敷料不要重复使用,带血带脓的敷料装袋处理或烧掉
```

### 擦伤特殊处理

**"脏擦伤"**(如摔倒在地):
```
1. 细致清洗非常重要!
2. 用软毛刷轻刷去除嵌入的沙土
3. 如无法清除干净,必须就医
4. 防止"外伤性文身"和感染
```

```
擦伤的护理:
✓ 擦伤面积大但浅,冲洗干净后可薄涂凡士林,覆盖不粘伤口的敷料,
  保持湿润的伤口比晾干结硬痂愈合快、疤痕小
✓ 刷洗很痛,可以先在伤口上淋冷水几分钟再刷;儿童可能需要到医院处理
⚠️ 面部大面积擦伤、沙土嵌入多 → 就医,24小时内清理干净才不会留下"黑色文身"
```

### 伤口愈合阶段

**正常愈合**:
- 第1-2天:轻微肿胀,轻微疼痛
- 第3-7天:结痂,瘙痒
- 第7-14天:痂皮脱落,新皮肤生成

**注意**:
- 不要撕痂(会留疤)
- 保持适度湿润(促进愈合)
- 避免阳光直射

```
影响愈合的因素:
- 年老、糖尿病、吸烟、营养不良(蛋白质和维生素C不足)、长期用激素
  → 愈合慢,感染风险高,更要勤观察
- 伤口反复受力: 关节处的伤口要减少活动,必要时用夹板

伤口愈合后:
✓ 新皮肤6个月内容易晒黑,出门遮挡或涂防晒,可以减轻色素沉着
✓ 疤痕发红、发痒、隆起是常见现象,多在半年到一年内逐渐变平变淡
```

### ⚠️ 感染迹象(立即就医)

- 红肿扩大
- 疼痛加剧
- 发热、发烫
- 黄色或绿色脓液
- 红线从伤口向外延伸
- 发烧

感染一般在受伤后1-3天出现。下表帮助区分正常反应和感染:

| | 正常愈合 | 感染 |
|------|------|------|
| 红肿 | 伤口边缘一窄圈(约几毫米)淡红,逐日消退 | 红肿超过约1-2 cm,一天比一天大 |
| 疼痛 | 逐日减轻 | 第2-3天起反而加重,跳着痛 |
| 渗出物 | 少量清亮或淡红色液体 | 浑浊、黄绿色脓液,有臭味 |
| 皮温 | 和周围差不多 | 摸着明显发烫 |
| 全身 | 无 | 发热、发冷、乏力 |

```
感染后的处理:
1. 尽快就医: 伤口感染通常需要医生开抗生素,有脓肿需要切开引流
2. 等待就医期间: 每天换药,脏的敷料及时换掉,抬高受伤的肢体
3. 用笔在红肿边缘画线、写上时间,几小时后对比,
   扩散快(几小时内明显变大)要当急症处理
❌ 不要自己挤脓,会把细菌挤进更深的组织
❌ 不要用家里剩的抗生素自己吃(种类、剂量不对,还会掩盖病情)
```

#### 全身感染的危险信号(立即拨打120)

```
伤口感染的同时出现以下任何一项,可能已发展为全身感染(脓毒症):
- 高热(≥39°C)或体温反而低于36°C,伴寒战
- 心跳快(成人静息时>100次/分)、呼吸急促
- 神志不清、反应迟钝、极度虚弱
- 尿量明显减少
- 皮肤发花、手脚冰凉

伤口出现以下情况,可能是严重的深部感染,同样立即就医:
- 疼痛剧烈,和伤口看起来的严重程度不相称
- 伤口周围皮肤变成紫黑色、起血疱
- 按压伤口周围有像捏雪一样的"咯吱"感(皮下有气体),渗液恶臭
```

### 破伤风预防

**高风险伤口**:
- 脏污伤口
- 深刺伤
- 动物咬伤
- 泥土污染
- 超过6小时未处理

**破伤风疫苗**:
```
已完成全程免疫(≥3剂):
- 清洁小伤口: 距上次接种>10年,加强1剂疫苗
- 污染/高风险伤口: 距上次接种>5年,加强1剂疫苗
- 一般不需要免疫球蛋白

未接种、接种史不明或少于3剂:
- 清洁小伤口: 接种疫苗(并完成全程)
- 污染/高风险伤口: 接种疫苗 + 注射破伤风免疫球蛋白(或抗毒素)
```

破伤风是破伤风梭菌在缺氧的伤口里繁殖、产生毒素引起的,一旦发病死亡率很高,但**完全可以靠疫苗预防**。高风险伤口还包括烧伤、冻伤、开放性骨折、伤口有坏死组织或异物,以及在农田、畜圈、建筑工地受的伤。

#### 怎样判断自己打过几针

```
- 国内儿童计划免疫中的百白破疫苗(3月龄起共4剂,6岁再打1剂白破)含破伤风成分,
  按时打完的人算完成全程免疫,但通常已经过了10年以上
- 大多数成年人说不清自己的接种情况 → 按"接种史不明"处理
- 当过兵、做过破伤风全程接种的人,带上接种记录给医生看
- 每次接种后保存好接种凭证,写在家庭健康记录里

时间:
✓ 越早越好,最好在受伤后24小时内
✓ 超过24小时甚至几天,只要没有发病,仍然应该去打
⚠️ 破伤风抗毒素(TAT)是马血清制品,需要做皮试;免疫球蛋白不需要。由医生选择
```

#### 破伤风的早期症状

```
潜伏期多为3-21天,伤口越靠近头部、潜伏期越短,病情越重
早期信号:
- 张口困难、咀嚼肌发紧("牙关紧闭")
- 面部肌肉僵硬,像在苦笑
- 脖子、后背发硬
- 之后出现全身肌肉阵发性抽搐,声音、光线、触碰都会诱发
⚠️ 受伤后几天到几周内出现张嘴困难、脖子发硬 → 立即就医,告诉医生受过伤
   (伤口可能早已愈合,甚至想不起来)
```

## 烫伤与烧伤

```
⚠️ 先确保安全再救人:
- 衣服着火: "停、躺、滚" —— 停止奔跑,躺倒,用手护住脸来回打滚;
  旁人用厚毯子、外套从头往脚方向覆盖压灭,不要用化纤织物
- 电烧伤先断电,化学烧伤先防止自己接触到化学品
- 火场里的伤员要先移到空气新鲜处,注意有没有吸入烟雾
```

火场逃生见[火灾](../02-灾难应对/04-火灾.md),儿童烫伤的预防见[儿童安全-防烧烫伤](14-儿童安全.md#防烧烫伤)。

### 烧伤程度分类

#### 一度烧伤(浅表)
- **症状**: 皮肤发红、疼痛、无水疱
- **影响**: 仅表皮层
- **愈合**: 3-5天,不留疤
- **例子**: 轻微日晒伤

#### 二度烧伤(中度)
- **浅二度**:
  - 红肿、剧痛、大水疱
  - 基底红润湿润
  - 1-2周愈合,可能轻微疤痕
- **深二度**:
  - 基底苍白或红白相间
  - 疼痛较轻(神经受损)
  - 3-4周愈合,可能明显疤痕

#### 三度烧伤(重度)
- **症状**: 皮肤焦黑或蜡白、无痛(神经完全破坏)
- **影响**: 全层皮肤及皮下组织
- **愈合**: 需植皮,疤痕明显
- **必须就医**: 这是严重烧伤

```
现场判断深度的小技巧:
- 用干净的棉签或手指轻按伤处再松开:
  很快变红(毛细血管回流快)、很痛 → 多为浅度
  颜色不变、感觉迟钝或没有感觉 → 可能是深二度或三度
- 烧伤后头24-48小时深度会"加深",当时看着是浅二度的,
  第二天可能变成深二度 → 宁可往严重了估计
- 开水、热油烫伤多为浅度;火焰、热金属、电、化学品烧伤常常更深
```

### 烧伤面积评估

**手掌法则**:
- 伤者自己的手掌(包括手指)≈1%体表面积

**严重烧伤**(立即就医):
- 成人: 二度烧伤>10%体表面积
- 儿童: 二度烧伤>5%体表面积
- 任何三度烧伤
- 面部、手、脚、生殖器、关节部位烧伤

```
怎样用手掌法:
- 用的是伤者的手,不是救助者的手(孩子的手小,孩子的1%也小)
- 五指并拢,整个手掌加手指的面积约为1%
- 一度烧伤(只发红)不计入面积
- 零散的小块烧伤,逐块估算后加起来
```

#### 大面积烧伤用九分法估算

面积较大时用手掌一块块比太慢,可以按身体部位估算(国内常用的"中国新九分法"):

| 部位 | 成人占体表面积 |
|------|------|
| 头颈(头发区、面部、颈部各3%) | 9% |
| 双上肢(双上臂7%、双前臂6%、双手5%) | 18%(2个9%) |
| 躯干(前面13%、后面13%、会阴1%) | 27%(3个9%) |
| 双下肢(双臀5%、双大腿21%、双小腿13%、双足7%) | 46%(5个9%加1%) |

```
儿童头大腿短,要修正(12岁以下):
- 头颈 = 9% + (12 - 年龄)%
- 双下肢 = 46% - (12 - 年龄)%
例: 2岁儿童,头颈约19%,双下肢约36%
→ 同样是头面部烫伤,孩子烧伤的面积比例比成人大得多
```

#### 呼吸道烧伤(比面积更危险)

```
在密闭空间着火、吸入热气或浓烟,即使皮肤烧伤不重,也可能烧伤呼吸道,
几小时内喉咙肿胀,堵住气道。出现以下任何一项立即拨打120:
- 面部、口鼻周围烧伤,鼻毛烧焦
- 口腔、喉咙发红起疱,痰里有黑色炭末
- 声音嘶哑、咳嗽、呼吸有"呼噜""咝咝"声、呼吸困难
- 吞咽困难、流口水
⚠️ 现在呼吸正常也要去医院观察,肿胀可能在几小时后才出现
```

火场还常合并一氧化碳中毒,见[居家与交通意外-一氧化碳中毒](07-居家与交通意外.md#一氧化碳中毒)。

### 紧急处理:"冲、脱、泡、盖、送"

#### 1. 冲 - 冷水冲洗

```
时间: 至少15-20分钟
水温: 15-25°C(自来水即可)
方法: 轻柔流动冷水冲洗

作用:
✓ 降低局部温度
✓ 减轻疼痛
✓ 减少组织进一步损伤

禁忌:
❌ 不要用冰块直接敷(可能冻伤)
❌ 大面积烧伤不要长时间冷水浸泡(防失温)
❌ 不要用酱油、牙膏等涂抹
```

```
补充要点:
✓ 越早越好,但烧伤后3小时内开始冲,仍然有效 —— 来晚了也要冲
✓ 冲足时间: 很多人冲一两分钟不痛了就停,停下后热量还在往深处走
✓ 没有自来水: 用干净的凉水连续浇,或浸在盆里,水变温了就换;
  也可用湿毛巾冷敷,每1-2分钟换一次
✓ 冲的是烧伤处,身体其他部位要盖上衣服、毯子保暖

⚠️ 婴幼儿、老人、烧伤面积超过约10%的人特别容易失温:
   只冲烧伤部位,注意观察;出现发抖、嘴唇发紫、皮肤发凉就停止冲水,马上保暖
⚠️ 冲水的同时让旁人拨打120,不要为了冲满时间而推迟送医,
   可以在等车、去医院路上继续冷敷
```

#### 2. 脱 - 小心脱掉衣物

```
✓ 在冷水中小心剪开衣物
✓ 轻轻脱除
✓ 如衣物粘连,不要强行撕脱
✓ 保留粘连部分,就医处理
✓ 去除戒指、手表等(防肿胀后嵌顿)
```

```
✓ 热水、热汤浸湿的衣服会持续烫伤,要尽快脱掉;套头衫用剪刀剪开,
  不要从头上往下拽(会擦破面部水疱)
✓ 尿不湿被热水浸湿也要立即取下
✓ 戒指、手镯、鞋子要在肿起来之前取下,肿起来以后只能剪断
```

#### 3. 泡 - 继续冷水浸泡

```
时间: 10-30分钟
或直到疼痛明显减轻

注意:
- 面积大时不要过久(防失温)
- 保持水温
```

#### 4. 盖 - 覆盖保护

```
用料:
✓ 干净湿润的纱布或布料
✓ 保鲜膜(轻轻覆盖,不要缠绕)

禁止:
❌ 涂抹任何药膏、油脂、酱油、牙膏
❌ 刺破水疱
❌ 涂抹有色物质(影响医生判断)
```

```
✓ 保鲜膜要撕掉最外面的一两圈(可能不干净),顺着肢体轻轻铺上,
  不要绕肢体一圈圈缠紧 —— 烧伤后肢体会肿,缠紧会勒住血液循环
✓ 手部烧伤可以套一个干净塑料袋,手指之间不要相互贴着
✓ 面部烧伤不要覆盖口鼻,保持呼吸通畅
✓ 盖好后注意保暖,大面积烧伤的人体温丢失很快
```

#### 5. 送 - 尽快就医

```
需就医情况:
- 二度烧伤面积较大
- 三度烧伤
- 面部、手、脚、生殖器、关节烧伤
- 儿童或老人烧伤
- 化学或电烧伤
```

```
还要加上:
- 有吸入烟雾、呼吸道烧伤的迹象(见上文)
- 环绕肢体或躯干一圈的烧伤(肿胀会勒紧,影响血液循环或呼吸)
- 孕妇,或有糖尿病、心脏病等慢性病的人
- 怀疑虐待儿童、老人造成的烫伤
- 小烧伤在家处理2-3天后出现感染迹象,或2周还没有愈合

送医途中:
✓ 让伤员平躺,注意保暖
✓ 大面积烧伤的人会口渴,在拨打120、等待救援时间较长(超过1小时)时,
  神志清醒、能吞咽、不呕吐的成人可以少量多次喝口服补液盐或淡盐水;
  不要大量喝白开水,也不要喝酒
✓ 能联系上医院时,先说明烧伤面积、部位、原因,便于准备
```

口服补液盐的配制见[常见疾病-腹泻](01-常见疾病.md#腹泻)。

### 小面积轻度烫伤家庭处理

**条件**: 一度或小面积浅二度(直径<2 cm)

**处理**:
```
1. 充分冷水冲洗/浸泡
2. 清洁干燥后涂抹:
   - 凡士林或芦荟胶(保湿、减轻疼痛)
   - 有破皮或感染风险时可用抗菌软膏
   - 磺胺嘧啶银需遵医嘱:不用于面部,孕妇和2个月以下婴儿禁用
3. 覆盖无菌纱布(可选)
4. 每天换药1-2次
```

```
✓ 疼痛明显时可以服用对乙酰氨基酚或布洛芬,按说明书剂量
✓ 一度烧伤和晒伤: 冷敷、涂保湿霜即可,多喝水;发痒脱皮时不要抓
✓ 愈合后的新皮肤半年内避免暴晒
⚠️ 婴幼儿的烫伤,哪怕面积不大,也建议给医生看一次
```

**水疱处理**:
```
小水疱(<5 mm):
- 不要刺破
- 自然吸收

大水疱(>5 mm):
- 建议就医处理
- 如必须自行处理:
  1. 消毒水疱及周围
  2. 无菌针头刺破边缘
  3. 轻压排出液体
  4. 保留水疱皮(保护作用)
  5. 消毒后覆盖
```

```
水疱破了怎么办:
✓ 用凉开水或生理盐水轻轻冲洗
✓ 能贴回去的疱皮尽量贴回去,当作天然敷料
✓ 薄涂凡士林,覆盖不粘伤口的敷料,每天换药
❌ 不要撕掉疱皮,不要涂紫药水等有色药
```

### 特殊烧伤

#### 化学烧伤

```
立即处理:
1. 迅速脱去污染衣物
2. 大量清水持续冲洗30分钟以上
3. 不要试图中和化学物质
4. 立即就医,带上化学品信息

注意:
- 生石灰:先刷去,再冲水
- 浓硫酸:先用干布吸,再冲水
```

```
补充要点:
✓ 救助者先戴手套(没有就套塑料袋),不要直接碰化学品
✓ 浓硫酸: 用干布迅速沾去表面的酸,只花几秒钟,不要来回擦,
  随即大量冲水;冲水量要足,水少反而会放热加重烧伤
✓ 碱(生石灰、烧碱、水泥浆)比酸渗得更深,外表看着不重也要冲足时间,
  能冲1小时更好;冲到皮肤摸着不再滑腻为止
✓ 冲洗时让水流向远离身体其他部位和眼睛的方向,污染的水不要流到健康皮肤上
✓ 带上化学品的包装或标签去医院;不知道是什么,把容器一起带上

⚠️ 以下化学品烧伤要立即就医,不能只靠冲水:
- 氢氟酸(玻璃蚀刻液、除锈剂、部分清洗剂): 刚接触时可能不痛,
  几小时后出现剧痛,可伤及深部组织和骨头,并引起全身中毒
- 苯酚(石炭酸)、大面积的强酸强碱烧伤
❌ 不要用醋去"中和"碱,不要用小苏打去"中和"酸 —— 中和反应放热,
   会加重烧伤,还耽误冲水
```

化学品溅入眼睛见[异物处理-化学品入眼](04-异物处理.md#化学品入眼紧急),化学品泄漏现场的防护见[人为灾难-化学品泄漏](../02-灾难应对/05-人为灾难.md#化学品泄漏)。

#### 电烧伤

```
1. 切断电源(不要直接触碰伤者)
2. 检查心跳呼吸
3. 必要时CPR
4. 所有电烧伤都应就医(内部损伤可能严重)
```

```
✓ 电流有"入口"和"出口",两处都要找、都要处理,通常在手和脚
✓ 皮肤上只有很小的焦痕,里面的肌肉、血管、神经可能已经大片损伤
✓ 电击后可能出现心律失常,即使当时感觉正常也要去医院做心电图
```

触电现场的断电和救护见[急性症状-电击伤](05-急性症状.md#电击伤)。

### 预防感染

```
✓ 保持伤口清洁
✓ 定期换药
✓ 观察感染迹象
✓ 避免抓挠
✓ 充足营养(蛋白质、维生素C)
```

```
烧伤后感染的信号:
- 伤口周围红肿扩大,疼痛又加重
- 渗出液变浑浊、黄绿色、有臭味
- 原本是浅度的伤口颜色变暗、变深
- 发热、精神差,儿童烦躁或嗜睡
→ 尽快就医。烧伤面积越大,感染越危险
✓ 大面积烧伤的人需要比平时多得多的蛋白质和热量,多吃蛋、肉、豆制品
```

### ❌ 常见错误做法

- 涂抹牙膏、酱油、醋、酒精
- 涂抹油脂、香油
- 使用冰块直接敷
- 撒盐、糖等
- 涂抹有色药物

这些做法可能:
- 加重损伤
- 增加感染风险
- 影响医生判断
- 增加疤痕

| 常见做法 | 为什么不对 |
|------|------|
| 涂牙膏"清凉" | 清凉感是薄荷造成的错觉,牙膏封住热量,不降温,还带菌、难清洗 |
| 抹酱油、醋 | 刺激创面,颜色干扰医生判断深度,增加感染 |
| 抹香油、猪油、獾油 | 油会封住热量,让烧伤向深处发展;清理时要刮掉,很痛 |
| 敷冰块、冰水泡很久 | 局部冻伤,加重组织坏死;大面积时导致失温 |
| 涂草木灰、锅底灰、黄土 | 带菌,容易感染,包括破伤风 |
| 自己长期用含药烧伤膏 | 不必要,还可能延误就医;轻度烫伤用凡士林、芦荟胶即可 |

## 冻伤

```
冻伤是局部组织冻结造成的损伤,常发生在气温低于0°C、刮风、衣物潮湿的环境;
饮酒、疲劳、饥饿、吸烟、糖尿病、鞋袜过紧都会增加风险。
冻伤和失温常常同时发生: 先处理失温(全身),再处理冻伤(局部)。
```

全身失温的识别与处理见[急性症状-失温症](05-急性症状.md#失温症),野外失温见[涉水山洪与野外失温](../03-野外生存/08-涉水山洪与野外失温.md#不只是冬天-野外失温),雪地环境的冻伤预防见[雪地极地求生-冻伤](../03-野外生存/04-雪地极地求生.md#冻伤)。

### 冻伤程度

**一度**: 皮肤红肿、刺痛
**二度**: 水疱形成
**三度**: 组织坏死,变黑
**四度**: 深达骨骼

刚冻上时各度看起来都差不多(苍白、发硬、麻木),**真正的深度要复温后1-2天甚至更久才能看清**:

| 分度 | 复温后的表现 | 预后 |
|------|------|------|
| 冻僵前期(冻伤前兆) | 皮肤发白、麻木,复温后完全恢复,不起疱 | 不留损伤 |
| 一度 | 红肿、刺痛、发痒 | 约1周恢复,可能脱皮 |
| 二度 | 24小时内起清亮水疱,周围红肿 | 2-3周愈合,一般不留明显损伤 |
| 三度 | 起血疱(暗红色液体),皮肤发紫发黑 | 皮肤和皮下组织坏死,需就医 |
| 四度 | 皮肤青紫、发黑、干硬,没有感觉,不起疱 | 深达肌肉骨骼,可能需要截除坏死部分 |

```
冻伤前兆最常见、最该抓住:
- 耳朵、鼻尖、脸颊、手指出现发白的斑块,摸着发凉,感觉麻木
- 同伴之间互相看脸,发现白斑就马上处理
- 处理: 用自己的手捂、把手指夹在腋下、对着手指哈气,几分钟后恢复颜色
  (这时还没有冻结,温暖即可,不要搓)
```

### 易受冻部位

- 手指、脚趾
- 鼻子、耳朵
- 脸颊

### 复温处理

#### 轻度冻伤(一度)

```
1. 转移到温暖环境
2. 脱去湿冷衣物
3. 温水浸泡复温:
   - 水温: 37-39°C(温热,不烫手)
   - 时间: 15-30分钟
   - 直到皮肤恢复红润、柔软
4. 轻轻拍干
5. 保暖

禁止:
❌ 热水烫
❌ 火烤
❌ 摩擦搓揉
❌ 冻伤后行走(脚部冻伤)
```

```
没有温度计时怎样控制水温:
- 救助者用手肘或手腕内侧试,感觉"温热、能一直放在里面"即可
- 冻伤的部位已经没有感觉,不能让伤者自己试水温,否则很容易烫伤
- 水会被冻伤部位冷却,要不断加热水保持温度;加热水时先把伤肢拿出来

❌ 不要用雪搓(这是错误的老方法,会加重冻伤)
❌ 不要靠近火堆、暖气片、热水袋直接烤 —— 麻木的皮肤感觉不到烫
```

#### 严重冻伤(二度及以上)

```
能在短时间内送医:
1. 保持冻伤部位不动,包裹保暖
2. 立即就医,由医院复温

无法及时就医(野外、偏远地区):
1. 只要能保证复温后不会再次冻上,就应尽快复温
   - 37-39°C温水浸泡,直到皮肤变软、恢复颜色(通常30分钟左右)
   - 复温过程很痛,可服止痛药
2. 复温后用干燥纱布包扎,手指脚趾之间垫纱布
3. 不要刺破水疱
4. 抬高受伤部位,减轻肿胀

⚠️ 如果复温后可能再次冻上,宁可保持冻结状态,到达安全地点再复温
   (反复冻融造成的损伤比持续冻结更严重)
```

```
复温后的护理:
✓ 止痛可用布洛芬(还有一定抗炎作用),按说明书剂量
✓ 每天检查;保持干燥清洁,宽松包扎
✓ 脚部冻伤复温后尽量不走路,必须走时用担架或背
✓ 发黑坏死的部分不要自己剪掉,坏死和存活组织的分界要几周才清楚,交给医生
✓ 戒烟戒酒(会让血管收缩)
⚠️ 冻伤伤口同样有破伤风风险,见本章"破伤风预防"
```

### 预防

```
✓ 多层穿衣
✓ 保持干燥
✓ 覆盖暴露部位
✓ 避免紧身衣物
✓ 定期活动肢体
✓ 避免酒精和吸烟
```

```
补充:
✓ 戴连指手套比分指手套暖和;带一双备用的干袜子和手套
✓ 鞋子要留出能活动脚趾的空间,穿两层袜子时鞋要相应放大
✓ 不要在零下的环境里徒手接触金属、汽油(汽油挥发会迅速带走热量,造成冻伤)
✓ 吃饱、喝够热水;感到麻木时立即停下处理,不要"再坚持一会儿"
```

### 冻疮与浸渍足(不是冻伤)

这两种都是**没有冻结**的冷损伤,比冻伤常见得多:

| | 冻疮 | 浸渍足("战壕足") |
|------|------|------|
| 原因 | 反复处于0-10°C的湿冷环境(南方冬天室内不供暖时常见) | 脚长时间(超过十几个小时)泡在冷湿的鞋袜里,如洪水、雨季、湿靴子 |
| 表现 | 手指、脚趾、耳廓出现紫红色肿块,遇热发痒、灼痛,可起疱溃烂 | 脚发白、发皱、肿胀、麻木,回暖后变红、剧痛,严重时坏死 |
| 处理 | 保暖保干,不要用火烤或热水烫;不要抓破;溃烂时按伤口护理 | 换干袜子,晾干双脚,抬高,缓慢回暖;不要按摩;起疱、发黑要就医 |
| 预防 | 手脚保暖,戴手套,勤换湿袜子;平时适当活动促进血液循环 | 每天至少晾干脚、换干袜子一次;长时间涉水后尽快擦干 |

洪水中的防护见[洪水](../02-灾难应对/02-气象灾害.md#洪水)。

## 咬伤

### 动物咬伤

#### 即时处理

```
1. 冲洗(重要!):
   - 立即用流动清水冲洗15分钟以上
   - 肥皂水交替冲洗
   - 深度冲洗伤口
2. 消毒:
   - 碘伏或75%酒精
3. 覆盖无菌纱布
4. 尽快就医
```

```
冲洗的具体做法(按国内狂犬病暴露处置的要求):
1. 用肥皂水(或其他弱碱性清洁剂)和有一定压力的流动清水,
   交替冲洗所有咬伤、抓伤处,至少15分钟
2. 伤口深的,把伤口稍微撑开,让水流冲到深处;
   有条件可用注射器或冲洗器往伤口里注水冲洗
3. 冲完用生理盐水或清水把肥皂冲净
4. 用碘伏涂擦伤口(碘伏能灭活狂犬病毒),酒精只用于周围皮肤
5. 不包扎得太紧,覆盖干净敷料后尽快去狂犬病暴露处置门诊

⚠️ 冲洗做得好,能大大降低狂犬病和细菌感染的风险,
   但不能代替打疫苗。冲洗后一样要去打针
⚠️ 伤口小、出血少也要冲 —— 狂犬病毒不需要大伤口
❌ 不要挤压伤口"把毒挤出来",不要用嘴吸,不要涂辣椒、草药、烟灰
```

#### 狂犬病预防(关键!)

**高风险动物**: 狗、猫、蝙蝠、狐狸、狼等

**所有哺乳动物咬伤、抓伤都应评估狂犬病风险!**
(鼠、兔等啮齿类和兔形目动物传播风险极低,一般无需接种,但仍建议咨询医生)

**疫苗接种**:
```
时间: 越早越好,24小时内最佳
程序: 通常5针
  - 0天(当天)
  - 3天
  - 7天
  - 14天
  - 28天

严重咬伤: 需注射狂犬病免疫球蛋白
```

**何时必须接种**:
- 被犬、猫、蝙蝠及其他野生食肉动物咬伤、抓伤(皮肤破损)
- 皮肤破损被动物舔
- 粘膜被动物体液污染

狂犬病一旦发病,死亡率几乎是100%,没有有效治疗;但**暴露后及时规范处置,几乎都能预防**。潜伏期通常1-3个月,短的不到1周,长的超过1年,所以**被咬后哪怕过了几天、几周,只要还没发病,都要立即去打疫苗**。

#### 暴露分级

国内按接触方式把狂犬病暴露分为三级,决定怎样处理:

| 分级 | 接触方式 | 处置 |
|------|------|------|
| Ⅰ级 | 接触或喂养动物;完好的皮肤被舔;完好的皮肤接触动物的分泌物 | 清洗接触部位,不需要打针 |
| Ⅱ级 | 裸露的皮肤被轻咬(有压痕、无出血);无出血的轻微抓伤、擦伤 | 冲洗处理伤口 + 接种疫苗 |
| Ⅲ级 | 咬伤、抓伤穿透皮肤(出血);破损的皮肤被舔;口、眼等黏膜被唾液污染;与蝙蝠有接触 | 冲洗处理伤口 + 接种疫苗 + 注射被动免疫制剂(狂犬病免疫球蛋白或抗血清) |

```
补充说明:
- 判断不了是Ⅱ级还是Ⅲ级时,按Ⅲ级处理
- 免疫功能严重低下的人(如正在化疗、长期用大剂量激素),Ⅱ级也按Ⅲ级处理
- 头面部、手部、外生殖器等神经丰富的部位被咬,风险更高,要格外抓紧
- 被动免疫制剂要尽早注射,最迟在第一针疫苗后7天内;它要浸润注射到伤口周围
- 蝙蝠的牙很小,咬伤可能看不出来;在屋里醒来发现蝙蝠,或孩子独自和蝙蝠在一起,
  按Ⅲ级暴露就医

疫苗的另一种程序(四针法): 当天2针(左右上臂各1针)、第7天1针、第21天1针。
采用哪种由接种门诊决定,一旦开始要按同一程序按时打完。
```

#### 以前打过疫苗又被咬

```
- 完成全程接种后3个月内再次暴露: 一般不需要再打
- 超过3个月: 在当天和第3天各打1针,一般不需要免疫球蛋白
- 以前没有打完全程,或记不清: 按从未接种处理,重新开始
→ 以上为一般原则,具体以狂犬病暴露处置门诊的判断为准;保存好每一次的接种记录
```

```
常见误区:
❌ "自家狗打过疫苗,就不用打" —— 动物的疫苗接种不一定有效,仍要按暴露分级处理
❌ "先观察狗10天,狗没事再打" —— 不要为了观察推迟打针;
   可以先开始接种,同时观察动物,是否提前停止由医生决定
❌ "孕妇、婴儿不能打狂犬疫苗" —— 狂犬病是致死性疾病,
   孕妇、哺乳期妇女、婴幼儿、老人、慢性病人都要照常接种,没有禁忌
❌ "超过24小时打就没用了" —— 只要没发病,任何时候发现暴露都要立即接种
✓ 疫苗某一针晚了几天,不需要重新开始,尽快补上,后面的按原间隔顺延
```

#### 伤口处理原则

```
❌ 不要缝合(除非特殊部位且咬伤浅表)
✓ 保持开放引流
✓ 密切观察感染
✓ 可能需要抗生素
```

```
- 动物口腔里细菌多,猫咬伤尤其容易感染(猫牙细长,伤口深),
  手部的猫狗咬伤感染率很高,一般需要医生评估是否用抗生素
- 面部伤口影响外观,医生在彻底清洗、注射免疫球蛋白后可能会缝合
- 咬伤后24-72小时内出现红肿热痛加重、流脓、发热 → 立即复诊
- 动物咬伤同样要评估破伤风,见本章"破伤风预防"
- 大型犬、野猪咬伤可能有深部撕裂、骨折,先按出血和骨折处理
```

野外遇到狗、猴子、野猪时的预防见[马蜂蜱虫与危险动物-野猪、狗、猴子等](../03-野外生存/10-马蜂蜱虫与危险动物.md#野猪狗猴子等),家养动物的人畜共患病防范见[家畜养殖](../04-动植物培育/06-家畜养殖.md)。

### 人咬伤

**特点**: 感染风险高(口腔细菌多)

**处理**:
```
1. 彻底冲洗
2. 消毒
3. 必须就医
4. 预防性抗生素
5. 乙肝、艾滋病暴露评估
```

```
特别注意"拳头伤": 打架时拳头打到对方牙齿,
指关节处只有一个小口子,但牙齿可能刺穿到关节里,
感染后会破坏关节 → 指关节上的小伤口如果是这样造成的,一定要就医并说明原因

儿童之间咬伤多数较浅,冲洗消毒即可;咬破出血的仍建议就医评估。
```

### 蛇咬伤

#### 识别毒蛇

⚠️ **无法确定是否有毒时,一律按毒蛇咬伤处理!**

靠外形判断并不可靠:
- "三角形头部"不是可靠标准: 银环蛇、金环蛇、眼镜蛇等剧毒蛇头部呈椭圆形
- 咬痕可参考: 1-2个深牙痕提示毒蛇,一排细小浅齿痕多为无毒蛇,但不能据此排除中毒

**中国常见毒蛇按毒性分类**(影响现场处理方式):
- **神经毒**: 银环蛇、金环蛇、海蛇 —— 局部症状轻,但可在数小时内出现眼睑下垂、吞咽和呼吸困难
- **血液/细胞毒**: 五步蛇(尖吻蝮)、蝮蛇、竹叶青、烙铁头 —— 局部剧烈肿痛、出血、组织坏死
- **混合毒**: 眼镜蛇、眼镜王蛇

```
中毒的表现(出现任何一项都说明已经中毒,要争分夺秒):
- 局部: 伤口持续流血不止、迅速肿胀并向上蔓延、剧痛、起血疱、皮肤发黑
- 神经毒: 眼皮抬不起来、看东西重影、说话含糊、流口水、吞咽困难、
  四肢无力,最后呼吸困难 —— 局部可能只是有点麻,不痛不肿,最容易被忽视
- 血液毒: 牙龈出血、鼻出血、血尿、皮下大片瘀斑、呕血
- 全身: 恶心呕吐、头晕、出冷汗、心慌

⚠️ 被咬后暂时没有症状不代表没中毒,神经毒症状可能几小时后才出现,
   被咬后都要到医院观察(通常至少24小时)
```

#### 紧急处理

```
✓ 做:
1. 立即远离蛇
2. 保持冷静,减少活动
3. 移除饰物(防肿胀)
4. 伤肢制动,保持与心脏大致同一水平
5. 记住蛇的特征(拍照,但不要抓蛇)
6. 立即就医

❌ 不要:
- 切开伤口
- 吸吮毒液
- 冰敷
- 喝酒
- 奔跑
- 使用止血带(除非极端情况)
```

**固定**:
```
如果是四肢:
1. 用夹板固定肢体,减少活动
2. 移除戒指、手表等,防止肿胀后嵌顿

加压包扎(压力固定法):
✓ 仅适用于确认或高度怀疑为神经毒蛇(银环蛇、金环蛇等)
  - 用宽弹性绷带从手指/脚趾开始,覆盖伤口,向上缠绕整个肢体
  - 松紧度类似扭伤包扎,能插入一指
❌ 血液/细胞毒蛇(五步蛇、蝮蛇、竹叶青等)或蛇种不明且局部肿痛明显时不要加压包扎
  - 会把毒液局限在局部,加重组织坏死
```

#### 送医途中怎么做

```
1. 拨打120,说明是毒蛇咬伤,问清哪家医院有抗蛇毒血清
   (抗蛇毒血清是唯一的特效治疗,要送到有血清、能抢救的医院,而不是最近的诊所)
2. 记下被咬的时间
3. 用笔在肿胀的边缘画线、写上时间,每15-30分钟画一次,医生可以据此判断进展
4. 伤者尽量不要自己走: 用担架、背、车送;必须走时慢慢走
5. 让伤者侧卧或平卧,出现呕吐时侧卧防止呛入气道
6. 神经毒蛇咬伤的人如果呼吸越来越弱、停止,立即开始人工呼吸/CPR,
   并坚持到医院 —— 呼吸肌麻痹是可以靠呼吸支持度过的
7. 可以服用对乙酰氨基酚止痛;不要用阿司匹林(增加出血)
```

#### 错误做法为什么危险

| 错误做法 | 后果 |
|------|------|
| 刀割"十字"放血 | 毒液几秒钟内已进入组织,割不出来;反而加重出血(血液毒会让血不凝)、感染,割伤神经肌腱 |
| 用嘴吸 | 吸不出多少毒液,口腔有伤口的人自己也会中毒,还污染伤口 |
| 用绳子、皮筋紧紧扎住 | 阻断血流,血液毒、细胞毒蛇咬伤会导致肢体坏死甚至截肢;松开时毒液集中涌入 |
| 冰敷、冰水泡 | 加重局部组织损伤 |
| 喝酒"活血""解毒" | 加快吸收,加重出血 |
| 敷草药、等"蛇医" | 耽误抗蛇毒血清的最佳时间 |
| 追打蛇、带着活蛇去医院 | 再次被咬;刚打死的蛇头仍可能咬人。拍照即可 |

野外防蛇的方法见[马蜂蜱虫与危险动物-蛇](../03-野外生存/10-马蜂蜱虫与危险动物.md#蛇)。

### 昆虫叮咬

#### 一般处理

```
1. 移除蜇刺(蜜蜂):
   - 用卡片刮除
   - 不要捏取(会挤出更多毒液)
2. 清水清洗
3. 冰敷15-20分钟(减轻肿胀)
4. 抗组胺药膏
5. 口服抗过敏药(如瘙痒严重)
```

```
✓ 蜜蜂蜇针上带着毒囊,越早刮掉,注入的毒液越少;只有蜜蜂会留下蜇针,
  马蜂(胡蜂)不留针,但可以反复蜇,毒性也更强
✓ 冰敷时用毛巾包住冰袋,不要直接贴皮肤
✓ 口服抗过敏药可选氯雷他定、西替利嗪等,按说明书;儿童用儿童剂型
✓ 外用炉甘石洗剂可以止痒;痒得厉害可短期用弱效的激素药膏(按说明书,不用于破溃处)
✓ 取下被蜇的手上的戒指、手镯
❌ 不要抓破 —— 叮咬处抓破后很容易继发细菌感染(脓疱疮)
```

马蜂蜇伤(群蜂蜇伤可致肾衰竭)的处理见[马蜂蜱虫与危险动物-被蜇后](../03-野外生存/10-马蜂蜱虫与危险动物.md#被蜇后),叮咬抓破后的皮肤感染见[皮肤病与寄生虫-脓疱疮与皮肤细菌感染](16-皮肤病与寄生虫.md#脓疱疮与皮肤细菌感染)。

#### 其他常见叮咬和接触

| 种类 | 表现 | 处理要点 |
|------|------|------|
| 蚊子 | 红色风团,瘙痒;幼儿可能肿成一大片 | 冷敷、炉甘石洗剂;防蚊比处理重要(蚊子传播疟疾、登革热、乙脑) |
| 蜱虫 | 叮在皮肤上不掉,多在腋下、腰、头皮、腹股沟 | 用镊子贴近皮肤夹住蜱虫头部,垂直匀速往外拔;不要用烟头烫、抹油;之后观察约1个月,出现发热、皮疹就医 |
| 隐翅虫 | 拍死在皮肤上后出现线条状红肿、水疱、灼痛 | 发现虫子在身上,吹走或用纸拿走,不要拍;接触后立即用肥皂水冲洗 |
| 毛毛虫(刺毛) | 接触处刺痛、成片红疹 | 用胶带粘掉皮肤上的毒毛,再用肥皂水冲洗;不要揉 |
| 蜈蚣 | 两个小伤口,剧烈疼痛、红肿 | 肥皂水冲洗,冷敷,止痛;儿童、出现全身症状就医 |
| 蝎子 | 局部剧痛、麻木 | 冲洗、冷敷;儿童被蜇或出现流口水、肌肉抽动、呼吸困难,立即就医 |
| 蜘蛛 | 多数只是局部红肿 | 冲洗、冷敷;伤口中心变紫变黑、扩大,或出现肌肉痉挛、腹痛,就医 |
| 水蛭(蚂蟥) | 吸在皮肤上,掉后伤口流血较久 | 不要硬拔,轻拍或用盐、烟油让它自己脱落;按压止血 |

```
需要就医的叮咬:
- 口腔、喉咙内被蜇(肿胀可能堵住气道)
- 一次被蜇很多处(蜂蜇10处以上)
- 局部肿胀在24小时后仍持续扩大,或出现红线、发热(感染)
- 出现任何过敏性休克的表现(见下)
```

蜱虫和旱蚂蟥的详细处理见[马蜂蜱虫与危险动物-发现蜱虫叮在身上](../03-野外生存/10-马蜂蜱虫与危险动物.md#发现蜱虫叮在身上)和[旱蚂蟥](../03-野外生存/10-马蜂蜱虫与危险动物.md#旱蚂蟥)。

#### 过敏反应监测

**轻度**: 局部肿胀、瘙痒
**中度**: 大面积肿胀

**严重(过敏性休克)**:
⚠️ 立即就医:
- 呼吸困难
- 喉咙肿胀
- 全身荨麻疹
- 头晕、低血压
- 心跳加快

**处理**: 立即使用肾上腺素笔(如有)+ 呼叫急救

```
- 过敏性休克多在被蜇后几分钟到半小时内发生,来得越快越危险
- 被蜇的地方肿到超过约10 cm、整条胳膊或腿都肿,但没有全身症状,
  属于"大的局部反应",通常不危险,冷敷、抗过敏药即可,但要观察有无全身症状
- 曾经对蜂蜇严重过敏的人,再次被蜇反应可能更重,
  应随身携带医生开的肾上腺素笔,并让同伴知道怎么用
- 等待急救时: 呼吸困难的人坐起;头晕、脸色苍白的人平躺抬高双腿;
  意识丧失、没有呼吸 → 立即CPR
```

过敏性休克的详细处理见[急性症状-过敏反应](05-急性症状.md#过敏反应)。

## 刺伤

### 浅表刺伤

**小刺(木刺、玻璃碎片)**:

```
1. 清洁:
   - 肥皂水洗手和周围皮肤
2. 去除:
   - 用镊子(先消毒)
   - 顺着刺入方向拔出
   - 如看不见,用针轻轻挑开皮肤
3. 消毒伤口
4. 观察感染迹象
```

```
取刺的技巧:
✓ 光线要好,可用放大镜;镊子和针用酒精擦过或在火上烧一下再晾凉
✓ 夹住刺露在外面的末端,按它扎进去的角度拔,不要斜着拉,以免断在里面
✓ 很多细小的仙人掌刺、玻璃纤维: 用胶带贴上再撕下,反复几次
✓ 取出后挤出一两滴血,冲洗后涂碘伏
⚠️ 断在里面的木刺一般会在几天内被身体推出来或化脓排出;
   出现明显红肿化脓要就医
```

**无法取出**:
- 就医处理
- 不要强行挖出(可能推得更深)

### 深刺伤

**特点**:
- 伤口小,深度深
- 出血少
- 感染和破伤风风险高

**⚠️ 不要拔出插入物**:
```
如果有物体刺入体内:
1. 不要拔出!
2. 固定异物
3. 包扎周围
4. 立即就医
```

```
为什么不能拔: 刺入物可能正压着破裂的血管,拔出后会大出血;
拔的过程中还会造成二次损伤

怎样固定:
1. 在刺入物两侧各放一卷纱布或叠起来的布,把它夹住
2. 用绷带缠绕固定这两卷布(不要压在刺入物上)
3. 刺入物太长时,不要锯断或折断(震动会加重损伤),由消防或医院处理
4. 让伤员保持不动,刺在胸腹部的取半坐位或平躺,不要给吃喝
```

**就医处理**:
```
1. 清洗消毒
2. 检查伤口深度
3. 可能需要X光(查异物残留)
4. 抗生素
5. 破伤风预防
```

```
踩到钉子:
✓ 拔出钉子(这类浅表、小的刺入物可以拔),挤出少量血,
  反复冲洗,碘伏消毒,覆盖
✓ 评估破伤风接种情况(见本章"破伤风预防")
⚠️ 钉子穿透鞋底扎进脚底: 容易把鞋里的细菌带进深处,
   几天后脚底红肿、疼痛加重,走路痛 → 就医
⚠️ 刺伤后几天内出现局部红肿加剧、发热,要考虑深部感染
```

### 高风险刺伤

立即就医:
- 被生锈金属刺伤
- 被脏污物品刺伤
- 动物骨刺、牙齿
- 刺入关节、眼睛等特殊部位
- 无法完全取出异物

```
还包括:
- 被别人用过的注射器针头扎伤 —— 冲洗后立即就医(24小时内,越早越好),
  评估乙肝、丙肝、艾滋病暴露,医生可能需要做暴露后预防用药
- 高压注射伤(高压油枪、喷漆枪): 皮肤上只有针眼大小的口子,
  但油漆、机油已经被打进深部组织,要紧急手术处理
- 鱼刺、鱼鳍刺伤后剧痛或红肿扩大(海鱼、海水中的细菌感染可能很重)
```

## 挫伤与淤血

### 症状

- 疼痛
- 肿胀
- 淤青(皮下出血)
- 功能受限

挫伤是钝器撞击造成的皮下组织、肌肉损伤,皮肤没有破。大多数挫伤在家处理即可,但要先排除骨折和内脏损伤(见下文"需要警惕的挫伤")。扭伤和骨折的处理见[骨骼损伤](03-骨骼损伤.md)。

### RICE原则

#### R - Rest(休息)
```
- 避免使用受伤部位
- 前48小时尤其重要
```

#### I - Ice(冰敷)
```
时间: 受伤后48小时内
频率: 每2-3小时一次
时长: 每次15-20分钟
方法:
  - 冰袋用毛巾包裹
  - 不要直接接触皮肤
  - 可用冰冻蔬菜袋替代
作用:
  - 减轻肿胀
  - 减少疼痛
  - 减少内出血
```

```
没有冰: 用井水、自来水浸湿的毛巾敷,温了就换;或把伤处泡在凉水里
⚠️ 糖尿病、雷诺病等血液循环差、感觉迟钝的人,冰敷时间缩短,勤检查皮肤
⚠️ 婴幼儿冰敷每次不超过10分钟
```

#### C - Compression(加压包扎)
```
方法:
  - 弹性绷带包扎
  - 松紧适中(不影响血液循环)
  - 检查: 手指/脚趾是否温暖、颜色正常
作用:
  - 减少肿胀
  - 支撑保护
```

#### E - Elevation(抬高)
```
位置: 高于心脏水平
时间: 尽可能多的时间
尤其: 休息和睡觉时
作用:
  - 减少肿胀
  - 促进静脉回流
```

### 48小时后护理

**热敷**:
```
时间: 受伤48小时后
方法:
  - 温热湿毛巾
  - 热水袋(用毛巾包裹)
  - 温水浸泡
时长: 每次15-20分钟
作用:
  - 促进血液循环
  - 加速淤血吸收
  - 放松肌肉
```

```
✓ 热敷前确认肿胀已经不再加重;48小时后仍在继续肿,先不要热敷,要考虑就医
✓ 热敷的温度以皮肤感到温暖舒适为准,约40-45°C,防止烫伤(老人、糖尿病人尤其注意)
```

**轻柔活动**:
```
- 轻微拉伸
- 逐渐恢复活动
- 不要过度
```

### 药物治疗

**外用**:
- 跌打损伤药膏
- 消肿止痛凝胶
- 活血化瘀药物

**口服**:
- 布洛芬(抗炎止痛)
- 对乙酰氨基酚(止痛)

```
✓ 外用药只涂在皮肤完好处,破皮的地方不要涂
✓ 含双氯芬酸等成分的凝胶局部止痛效果较好,按说明书使用
⚠️ 有胃溃疡、肾病、哮喘对阿司匹林过敏、孕晚期的人不要自行服用布洛芬,
   改用对乙酰氨基酚或咨询医生
⚠️ 两种止痛药都不要超过说明书的最大剂量;对乙酰氨基酚注意感冒药里也含有,避免重复
⚠️ 孕妇不要自行使用"活血化瘀"类药物
```

### 淤血消散

**正常过程**:
- 初期: 红色
- 1-2天: 青紫色
- 3-5天: 绿色
- 5-7天: 黄褐色
- 1-2周: 完全消退

**加速消散**:
- 热敷(48小时后)
- 按摩(轻柔)
- 活血化瘀药

```
✓ 按摩只在48小时后、肿胀消退后轻轻做,早期按摩会加重出血
✓ 淤青顺着重力往下"流"是正常的(如小腿挫伤后淤青出现在脚踝)
⚠️ 淤青处出现越来越大、按着有波动感的肿块(血肿),或几周后仍是硬块,要就医
```

### 需要警惕的挫伤

| 部位或表现 | 可能的问题 | 怎么做 |
|------|------|------|
| 头部撞击后头痛加重、反复呕吐、嗜睡、说话不清、一侧手脚无力、两侧瞳孔不等大 | 颅内出血 | 立即拨打120;受伤后24小时内要有人陪着观察 |
| 胸部撞击后呼吸痛、气短 | 肋骨骨折、气胸 | 就医,见[骨骼损伤-肋骨骨折](03-骨骼损伤.md#肋骨骨折) |
| 腹部、腰部撞击后腹痛加重、腹部变硬、血尿,或出现面色苍白、心跳快 | 肝脾肾等内脏破裂,内出血 | 立即拨打120,不要吃喝 |
| 小腿、前臂挫伤后越来越肿胀发硬,疼痛剧烈、止痛药无效,活动手指脚趾时剧痛,手脚发麻 | 骨筋膜室综合征(肌肉在紧绷的筋膜内肿胀,压迫血管神经) | 立即就医,几小时内处理不及时可能导致肌肉坏死;松开所有包扎,不要抬得过高 |
| 没有明显撞击就出现大片淤青,或伴牙龈、鼻出血 | 凝血问题、血液病,或抗凝药过量 | 就医 |
| 老人、正在吃抗凝药的人头部撞伤 | 迟发颅内出血 | 即使当时没事也要就医 |
| 儿童身上反复出现不同时期、部位不寻常(背部、耳朵、臀部)的淤青 | 需警惕虐待 | 就医,必要时报警 |

### ⚠️ 就医指征

立即就医如果:
- 疼痛剧烈
- 肿胀严重
- 无法活动或负重
- 变形
- 麻木或刺痛
- 淤血异常扩大
- 伴随开放性伤口

## 📝 总结要点

### 伤口处理"五步法"

1. **止血**: 压迫止血
2. **清洗**: 流动清水冲洗
3. **消毒**: 碘伏(酒精只用于伤口周围皮肤)
4. **包扎**: 无菌纱布覆盖
5. **观察**: 注意感染迹象

```
记住这几个数字:
1. 伤口冲洗: 至少5分钟;动物咬伤用肥皂水和清水交替冲洗至少15分钟
2. 按压止血: 至少10分钟,中途不要掀开
3. 烧伤冷水冲: 至少15-20分钟,3小时内开始都有用
4. 化学烧伤冲水: 30分钟以上,碱更久
5. 冻伤复温: 37-39°C温水,复温后不能再冻上
6. 手掌法: 伤者自己的手掌连手指≈1%体表面积
7. 破伤风加强针: 干净小伤口距上次>10年,脏伤口距上次>5年
8. 缝合时间窗: 最好6-8小时内
```

### 何时必须就医

- 伤口深、大、脏
- 出血不止
- 特殊部位受伤
- 动物咬伤
- 感染迹象
- 异物无法取出
- 疼痛剧烈
- 功能受限

### 家庭急救包

**外伤用品**:
- 各种尺寸创可贴
- 无菌纱布
- 医用胶带
- 弹性绷带
- 三角巾
- 医用手套
- 剪刀、镊子
- 碘伏、酒精
- 凡士林或芦荟胶(轻度烫伤;不建议常备含药烧伤膏自行使用)
- 抗菌软膏
- 免缝胶带、不粘伤口的敷料(凡士林纱布)
- 一次性注射器(20-50 mL,不带针头,用于冲洗伤口)
- 生理盐水
- 炉甘石洗剂、口服抗过敏药
- 记号笔(画红肿边界、记录时间)

```
定期检查(每半年一次):
✓ 碘伏、药膏有没有过期
✓ 无菌纱布包装有没有破损受潮
✓ 补齐用掉的东西
✓ 家庭成员的破伤风、狂犬病疫苗接种记录放在急救包里
```
