## 一氧化碳中毒

一氧化碳无色无味,人在不知不觉中中毒,睡眠中尤其危险。每年冬季都有大量因取暖、洗澡导致的死亡。

### 常见来源

```
- 室内烧炭取暖、煤炉(尤其门窗紧闭时)
- 燃气热水器安装在浴室内或排烟不畅
  - 直排式燃气热水器国家已禁止使用,如仍在用应更换为强排式或电热水器
- 在车库、地下室里发动汽车
- 门窗紧闭的车内长时间开空调怠速(尤其排气管被雪堵住时)
- 室内使用发电机、燃气烤炉、炭火锅
- 火灾烟雾
```

### 识别

**症状**:
- 轻度: 头痛、头晕、恶心、乏力、心慌
- 中度: 意识模糊、呕吐、站立不稳
- 重度: 昏迷、抽搐、呼吸心跳停止

**⚠️ 高度怀疑一氧化碳中毒的线索**:
- 同一空间里**多人同时**出现头痛头晕
- 宠物也出现异常
- 离开这个房间后症状减轻,回来又加重
- 症状在使用炉子、热水器、取暖设备时出现

⚠️ 常说的"皮肤樱桃红色"并不可靠,多数患者看不到,不能据此排除中毒。

### 救助

```
1. 先保护自己
   - 深吸一口气后屏住呼吸再进入,动作要快
   - ⚠️ 湿毛巾捂口鼻对一氧化碳无效(只能挡烟尘颗粒)
   - 浓度很高或现场有明火、烟雾 → 不要进入,等待消防

2. 迅速打开门窗通风

3. 切断来源
   - 关闭燃气阀门、熄灭炉火
   - 炭盆、煤炉能搬动的搬到室外
   - ⚠️ 如果同时闻到燃气味: 不要开关电灯电器、不要在室内打电话(见下方链接)

4. 把患者转移到室外空气新鲜处

5. 拨打120,说明"一氧化碳中毒"
   - 便于送往有高压氧舱的医院

6. 患者处理:
   - 清醒者: 安静休息,保暖,不要走动
   - 意识不清但有呼吸 → 侧卧位(防呕吐物误吸)
   - 无反应、无正常呼吸 → 立即CPR
```

闻到燃气味时的处理见[燃气泄漏](../02-灾难应对/04-火灾.md#燃气泄漏);CPR步骤见[心肺复苏](00-基础急救知识.md#心肺复苏cpr)。

### ⚠️ 清醒了也必须就医

- 一氧化碳中毒后可能出现**迟发性脑病**: 看似恢复后数天到一两个月,出现记忆力减退、反应迟钝、走路不稳、性格改变,严重时生活不能自理
- 高压氧治疗是一氧化碳中毒的重要治疗手段,应遵医嘱完成疗程,不要中途中断
- 孕妇中毒对胎儿影响更大,即使症状轻也要就医

### 预防

```
✓ 安装一氧化碳报警器
  - ⚠️ 燃气报警器和一氧化碳报警器不是同一种东西!
    燃气报警器检测的是天然气、液化气泄漏,检测不到一氧化碳
  - 安装在卧室附近和使用燃气、炉具的房间
✓ 燃气热水器不要装在浴室内,使用强排式
✓ 不在密闭室内烧炭取暖、吃炭火锅
✓ 煤炉要装烟囱,定期检查是否堵塞、漏气
✓ 不在车库内发动汽车
✓ 车内休息不要长时间开空调怠速,下雪时清理排气管周围积雪
✓ 发电机只在室外使用,远离门窗
```

火炕、炉灶和烟囱的检查维护见[长期住所-火炕与炉灶](../07-日常生活技能/05-长期住所.md#火炕与炉灶)。

## 车祸现场处理

### 第一步: 防止二次事故

很多车祸伤亡发生在事故之后: 停在路上的人和车被后方车辆撞上。

```
1. 开启危险报警闪光灯(双闪)
2. 熄火,拉手刹
3. 车上人员下车,转移到安全位置:
   - 高速公路: 迅速转移到右侧路肩或应急车道外的护栏外
   - 不要站在车后方,不要在车道上停留
4. 设置警告标志(三角警示牌):
   - 普通道路: 车后50-100 m
   - 高速公路: 来车方向150 m以外
   - 夜间同时开启示廓灯、后位灯
   - 放置时面向来车方向行走,注意后方来车
5. 有反光背心就穿上
```

### 第二步: 报警

```
- 122: 交通事故
- 120: 有人受伤
- 119: 车辆起火、有人被困车内
- 高速公路上说明行驶方向和路边的公里桩号,便于定位
```

### 第三步: 处理伤员

**先判断现场是否安全**: 有无起火、漏油、来车风险。

```
✓ 意识清醒者: 让其保持不动,不要自行下车或站起
✓ 尽量不要把伤员从车内拖出
  - 可能有颈椎、脊柱损伤,移动不当可致瘫痪
  - 例外: 车辆起火、有爆炸风险、无法进行CPR,必须移出时
    → 尽量保持头、颈、躯干在一条直线上
✓ 大出血 → 直接压迫止血(见下方链接)
✓ 无反应、无正常呼吸 → CPR(需先将伤员平放在硬地面上)
✓ 保暖,安慰,持续观察
✓ 不要给伤员喝水、进食
```

止血见[止血方法](00-基础急救知识.md#止血方法),搬运脊柱损伤伤员见[搬运伤员](00-基础急救知识.md#搬运伤员)。

**摩托车、电动车骑手的头盔**:
```
❌ 一般不要摘头盔(可能加重颈椎损伤)
✓ 例外: 无法呼吸需要开放气道、呕吐需要清理、需要CPR
  → 两人配合: 一人固定头颈,另一人沿头部轴线慢慢摘下
```

### 车辆起火

```
- 燃油车冒烟、起火初期: 有车载灭火器可对准火源根部扑救,扑不灭立即远离
- 电动汽车电池起火:
  - 不要试图扑灭(电池火极难扑灭,会反复复燃,并释放有毒气体)
  - 所有人立即撤离到30 m以外的上风方向
  - 拨打119,说明是电动汽车
```

### 轻微事故

- 无人员伤亡、车辆能移动的轻微事故: 拍照固定现场后,尽快将车移到不妨碍交通的地方再协商处理
- 不要在车道上争执(这是二次事故的高发场景)

### 车载应急物品

```
- [ ] 三角警示牌(法规要求随车配备)
- [ ] 反光背心
- [ ] 灭火器
- [ ] 急救包
- [ ] 安全锤(破窗器)
- [ ] 手电筒
```

更完整的车载应急包见[灾难应对-车载应急包](../02-灾难应对/README.md#车载应急包)。

## 📝 总结要点

### 一氧化碳中毒

```
1. 多人同时头痛头晕 → 先想到一氧化碳
2. 屏气快进快出,开窗、关气源、移出患者
3. 湿毛巾挡不住一氧化碳
4. 清醒了也要就医(迟发性脑病)
5. 装一氧化碳报警器(燃气报警器测不到)
```

### 车祸现场

```
1. 双闪、熄火、人员撤到护栏外
2. 警示牌: 普通道路50-100 m,高速150 m以外
3. 报警: 122 / 120 / 119
4. 不随意拖出伤员,不随意摘头盔
5. 电动车电池起火: 撤离,不要扑救
```
