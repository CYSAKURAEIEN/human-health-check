## 感冒

### 症状识别

**普通感冒**:
- 鼻塞、流鼻涕
- 打喷嚏
- 喉咙轻微疼痛
- 轻微咳嗽
- 一般不发烧或低烧(<38°C)

**流感**:
- 突然高烧(>38.5°C)
- 全身肌肉酸痛
- 严重乏力
- 头痛
- 干咳

**怎样区分**:

| | 普通感冒 | 流感 |
|------|----------|------|
| 起病 | 慢,一两天内逐渐加重 | 急,几小时内就很难受 |
| 主要症状 | 鼻子和喉咙 | 全身: 高烧、肌肉酸痛、乏力 |
| 病程 | 一般7-10天自愈 | 发烧3-5天,乏力可持续1-2周 |
| 并发症 | 少 | 肺炎、心肌炎等,高危人群可能致命 |
| 传染期 | 症状最重的前几天 | 发病前1天到发病后约1周 |

```
判断要点:
- 感冒和流感都是病毒感染,大多数靠自身免疫在1-2周内好转
- 治疗的目标是"让人舒服地扛过去"和"及早发现并发症",不是把病"治好"
- 流鼻涕从清水样变成黄绿色,是病程的正常变化,不等于细菌感染
```

### 家庭护理

#### 1. 休息和补水
```
✓ 充足睡眠(每天8小时以上)
✓ 多喝温水(每天2-3 L)
✓ 温热饮品(蜂蜜柠檬水、姜茶)
✓ 避免脱水

怎么判断水喝够了:
- 尿液淡黄色、白天每3-4小时排尿一次 → 够了
- 尿少、颜色深黄 → 喝得不够
- 有心衰、肾病需要限水的人,按医生规定的量喝,不要盲目多喝

休息:
- 发烧期间卧床或在家休息,不上班上学(既是休养,也避免传染别人)
- 退烧24小时以上、精神好转后再恢复正常活动
- 发烧时不要硬撑着去跑步、打球(病毒感染期间剧烈运动可能诱发心肌炎)
```

#### 2. 缓解症状
- **鼻塞**:
  - 热水蒸汽熏蒸(10-15分钟)
    - 做法: 一盆刚离火的热水放在桌上,脸距水面约30 cm,头上盖毛巾,闭眼吸蒸汽
    - ⚠️ 儿童不要用热水盆熏蒸(打翻烫伤很常见),改为带孩子在洗澡时的浴室里待一会儿
  - 生理盐水鼻喷雾
    - 也可以用0.9%盐水(1 L凉开水+9 g盐)滴鼻或冲洗,冲洗用水必须煮沸后放凉,不能用生水;配法见[消毒剂制备-生理盐水](../06-制药技术/01-消毒剂制备.md#七生理盐水)
    - 婴儿鼻塞影响吃奶时: 每侧鼻孔滴1-2滴盐水,等一两分钟后用吸鼻器轻轻吸出
  - 提高枕头高度睡觉

- **喉咙痛**:
  - 温盐水漱口(半茶匙盐+温水)
    - 半平茶匙盐(约3 g)溶于一杯(约250 mL)温水,含漱后吐掉,每天数次
    - 适合能学会漱口不吞咽的大孩子和成人
  - 蜂蜜(1岁以上)
  - 润喉糖(3岁以下儿童不要给硬糖,有呛噎风险)

- **咳嗽**:
  - 蜂蜜(睡前一勺)
  - 保持空气湿润
  - 避免刺激性气味
  - 详见本章[咳嗽](#咳嗽)

#### 3. 药物治疗(非必需)
- 退烧止痛: 对乙酰氨基酚、布洛芬(剂量见本章[发烧](#发烧))
- 减充血剂: 缓解鼻塞
  - 口服伪麻黄碱(很多复方感冒药里含有): 高血压、心脏病、甲亢、青光眼、前列腺增生者慎用
  - 鼻用喷剂(羟甲唑啉、赛洛唑啉等): 连续使用不超过7天,否则停药后鼻塞反而更重
- **注意**: 抗生素对病毒性感冒无效

```
复方感冒药的用法陷阱:
⚠️ 很多"感冒药""感冒冲剂"里已经含有对乙酰氨基酚(看成分表上的"对乙酰氨基酚""扑热息痛")
   → 再另外吃退烧药,会造成对乙酰氨基酚过量,严重时肝衰竭
⚠️ 同时只用一种复方感冒药,不要两种感冒药一起吃
⚠️ 含"氯苯那敏""苯海拉明"的感冒药会让人犯困: 服药后不要开车、操作机器、登高
⚠️ 6岁以下儿童不要自行使用复方感冒药和止咳药(效果不确定,过量风险高),
   症状处理以盐水滴鼻、多喝水、退烧药为主
```

### 儿童、老人和孕妇感冒时

```
婴幼儿:
- 鼻塞会影响吃奶和睡眠: 喂奶前先清理鼻腔,少量多次喂
- 观察重点不是体温,而是: 吃奶量、尿量、精神、呼吸
- 3个月以下婴儿发烧 → 直接就医(见本章"发烧")
- 呼吸急促、吸气时胸口凹陷、口唇发紫 → 立即就医(见本章"咳嗽"中的呼吸频率判断)

老人:
- 感冒后容易继发肺炎,而且肺炎症状常不典型: 可能不发烧、不怎么咳嗽,
  只表现为没精神、不想吃饭、突然糊涂、走路不稳或跌倒
- 原有心脏病、慢阻肺、糖尿病的人,感冒常诱发原病加重 → 留意气喘、腿肿、血糖波动

孕妇:
- 发烧(≥38°C)要联系医生;退烧首选对乙酰氨基酚,不要自行用布洛芬、阿司匹林
- 不要自行吃复方感冒药、中成药,先问医生或药师
- 孕妇是流感重症高危人群,出现高烧、气短要尽早就医

流感高危人群(5岁以下尤其2岁以下儿童、65岁以上老人、孕妇、慢性病患者、肥胖者):
- 确诊或怀疑流感,发病48小时内就医: 医生可能开抗病毒药(处方药),越早用效果越好
```

### 预防措施

```
✓ 勤洗手(20秒以上)
✓ 避免触摸脸部
✓ 保持社交距离
✓ 佩戴口罩(人群密集处)
✓ 增强免疫力(均衡饮食、适度运动)
✓ 接种流感疫苗
```

洗手方法见[卫生设施-怎么洗](../07-日常生活技能/03-卫生设施.md#怎么洗);家里有人患呼吸道传染病时的隔离和消毒见[传染病家庭防控](15-传染病家庭防控.md#呼吸道传染病)。

### ⚠️ 就医指征

立即就医如果出现:
- 高烧持续3天以上
- 呼吸困难
- 胸痛
- 严重头痛或颈部僵硬
- 持续呕吐
- 意识混乱
- 症状突然恶化

也应尽快就医:
- 症状好转后又再次发烧、咳嗽加重(可能继发细菌感染,如肺炎、中耳炎、鼻窦炎)
- 感冒超过10天仍不见好转
- 儿童耳朵痛、抓耳朵、耳朵流脓
- 属于上述流感高危人群,出现流感样症状

## 发烧

### 体温标准

**各部位正常体温**:

| 测量部位 | 正常范围 | 说明 |
|----------|----------|------|
| 腋下 | 36.0-37.0°C | 国内最常用 |
| 口腔 | 36.3-37.2°C | 比腋温高约0.2-0.5°C |
| 肛门 | 36.5-37.7°C | 比腋温高约0.5°C,最接近核心体温 |
| 耳温 | 与肛温接近 | 受测量手法影响大,读数差异较大 |

**发热分级**(以腋温/口温计):

| 低热 | 中度发热 | 高热 | 超高热 |
|------|----------|------|--------|
| 37.3-38.0°C | 38.1-39.0°C | 39.1-41.0°C | >41°C |

```
要点:
- 体温一天中有波动,下午到傍晚比清晨高约0.5°C,饭后、运动后、哭闹后也会偏高
- 发烧本身是身体对抗感染的反应,一般的发热不会"烧坏脑子"
- 真正危险的是引起发烧的病(脑膜炎、肺炎、败血症等),
  所以看人的精神状态,比看体温数字更重要
- 中暑的高体温和发烧机制不同,退烧药无效,要立即物理降温(见急性症状-中暑)
```

中暑的处理见[急性症状-中暑](05-急性症状.md#中暑)。

### 怎样正确测体温

```
电子体温计(推荐,家中首选):
1. 腋下擦干汗水
2. 探头放在腋窝正中,手臂夹紧贴住胸前
3. 等到"嘀"声后再多夹一会儿读数更稳定
4. 刚喝过热水、刚洗澡、刚运动或哭闹后,先休息30分钟再测

水银体温计:
1. 测前甩到35°C以下
2. 腋下夹5-10分钟
3. 读数时横拿,转动到能看见水银柱
4. ⚠️ 打碎后: 开窗通风,人和宠物离开房间;用硬纸片把汞珠拢到一起,
   用湿纸巾或胶带粘起来装进密封瓶;不要用扫帚、吸尘器(会把汞扬散);
   小孩咬碎体温计、吞入汞或玻璃碴 → 就医

婴儿(3个月以下最好测肛温):
1. 电子体温计探头涂一点凡士林
2. 婴儿仰卧抬起双腿(像换尿布),或趴在大人腿上
3. 探头轻轻插入肛门约1-2 cm,不要硬推,扶住体温计直到读数完成
4. 肛温≥38.0°C 即为发烧

额温枪、耳温枪:
- 读数快,适合筛查,但受环境温度和手法影响大
- 额温枪读数高或可疑时,用腋温或肛温复核

没有体温计时:
- 手摸额头只能粗略判断,不可靠
- 可以参考: 寒战、皮肤发烫发红、呼吸和心跳明显变快、精神变差
- 一旦能借到体温计,尽快复测并记录
```

### 何时需要退烧

**成人**:
- 体温≥38.5°C,且感到不适
- 有基础疾病者,体温≥38°C

**儿童**:
- 3个月以下: 任何发烧都应就医
- 3-6个月: 体温≥38.5°C
- 6个月以上: 体温≥39°C或明显不适

```
理解"何时退烧":
- 退烧的目的是让人舒服一些、能喝水、能睡觉,不是把体温压回正常
- 用药后体温降1-1.5°C、人舒服了就算有效,不必非降到37°C
- 退烧药不能预防高热惊厥;孩子睡得安稳时,不必专门叫醒吃退烧药
- 3-6个月婴儿只能用对乙酰氨基酚(布洛芬用于6个月以上),而且最好先问过医生
```

### 退烧方法

#### 1. 物理降温

**温水擦浴**:
```
1. 水温: 32-34°C(略低于体温)
2. 擦拭部位: 颈部、腋下、腹股沟、四肢
3. 时间: 15-20分钟
4. 禁止: 酒精擦浴(可能导致中毒)

注意:
- 温水擦浴只能辅助,降温作用短暂,不能代替退烧药
- 孩子正在寒战、发抖,或擦浴时哭闹、不舒服 → 停止,寒战时擦浴反而让体温继续上升
- ❌ 不要用冷水、冰水擦浴,不要把冰块直接贴在皮肤上
- 退热贴作用很有限,小婴儿不要用(可能滑落遮住口鼻)
```

**环境调节**:
- 室温保持在22-24°C
- 减少衣物和被子
  - 寒战时可以盖一条薄毯,寒战停止、开始发热出汗后就减掉
  - ❌ 不要"捂汗"——婴幼儿被捂得太严可能体温急剧升高、脱水甚至危及生命
- 保持通风
  - 风扇、空调不要直吹病人

**补充水分**:
- 每小时喝200-300 mL水
- 可以喝: 水、果汁、清汤
- 避免: 含咖啡因饮料
- 婴儿: 继续母乳或配方奶,增加喂奶次数;6个月以下纯母乳喂养的婴儿一般不需要额外喂水
- 出汗多、同时腹泻呕吐时,改喝口服补液盐(见本章[腹泻](#腹泻))

#### 2. 药物退烧

**对乙酰氨基酚(扑热息痛)**
- 成人剂量: 500-1000 mg,每4-6小时一次
- 儿童剂量: 10-15 mg/kg体重,每4-6小时一次
- 最大剂量: 成人每天4000 mg
- 儿童: 24小时内不超过4次;3个月以上可用
- 国内非处方药说明书一般按每次500 mg、24小时内不超过4次(每天2000 mg)写,自行用药时按说明书;更高的量须遵医嘱
- 长期饮酒、肝病、营养不良或体重<50 kg的成人,每天总量要更低,先问医生
- 过量会造成严重肝损伤,早期可能没有任何症状(见[中毒-药物过量与误服](12-中毒.md#药物过量与误服))

**布洛芬**
- 成人剂量: 200-400 mg,每4-6小时一次
- 儿童剂量: 5-10 mg/kg体重,每6-8小时一次
- 最大剂量: 成人每天1200 mg(非处方)
- 儿童: 24小时内不超过4次;6个月以上可用
- 以下情况不要自行使用: 胃溃疡或胃出血史、肾病、严重脱水(腹泻呕吐、几乎不排尿时会伤肾)、对阿司匹林或布洛芬过敏、服抗凝药、孕妇(尤其孕20周以后)
- 部分哮喘患者用后会诱发哮喘发作
- 儿童出水痘时,退烧用对乙酰氨基酚,不用布洛芬

**用药注意**:
- ❌ 不要同时使用两种退烧药
- ❌ 18岁以下不要使用阿司匹林
- ✓ 饭后服用减少胃部不适

```
其他注意:
- ❌ 也不推荐两种退烧药"交替"使用: 容易算错次数和总量
- ❌ 18岁以下禁用阿司匹林: 儿童病毒感染(流感、水痘)时用阿司匹林,
  可能引起瑞氏综合征(急性脑病和肝损害,死亡率高);
  有些复方药和"感冒冲剂"里含阿司匹林(乙酰水杨酸),要看成分表
- ✓ 每次用药都记下时间和剂量,多人照顾孩子时尤其要记,防止重复喂药
- ✓ 吃药后约30-60分钟起效;一次用药后体温没降到正常,
  不要提前加喂,等够间隔时间
- ✓ 安乃近等药物不良反应严重,不要自行给儿童使用
- ✓ 所有药物锁好、放在儿童拿不到的地方(甜味儿童药容易被偷吃)
```

### 退烧药剂量速查

按**体重**而不是年龄算儿童剂量。下表是每次剂量范围(按上面的mg/kg原则换算),实际以所用药品说明书为准:

| 体重 | 对乙酰氨基酚 每次(10-15 mg/kg) | 布洛芬 每次(5-10 mg/kg) |
|------|------|------|
| 5 kg | 50-75 mg | 不用(6个月以下) |
| 8 kg | 80-120 mg | 40-80 mg |
| 10 kg | 100-150 mg | 50-100 mg |
| 15 kg | 150-225 mg | 75-150 mg |
| 20 kg | 200-300 mg | 100-200 mg |
| 30 kg | 300-450 mg | 150-300 mg |
| 间隔 | ≥4小时,24小时内≤4次 | ≥6小时,24小时内≤4次 |

```
把"毫克(mg)"换算成"毫升(mL)"——最容易出错的一步:
1. 看药瓶上的浓度,例如"每5 mL含布洛芬100 mg" → 每1 mL含20 mg
2. 每次毫升数 = 每次毫克数 ÷ 每毫升含的毫克数
   例: 孩子10 kg,布洛芬取每次100 mg → 100 ÷ 20 = 5 mL
3. ⚠️ 同一种药,"滴剂"和"混悬液"浓度可能相差一倍以上,
   换了包装一定重新算,不要沿用上一瓶的毫升数
4. 用药品自带的量杯、量管或滴管,不要用家里的汤匙(大小不一)
5. 体重≥40 kg或12岁以上: 一般可按成人小剂量,以说明书为准
```

### 发烧的护理

#### 监测记录
```
记录内容:
- 测量时间
- 体温数值
- 伴随症状
- 用药情况
- 饮水量

另外记:
- 尿量(次数、颜色)——判断有没有脱水
- 精神状态(能玩、能交流 → 好;嗜睡、叫不醒、烦躁不安 → 差)
- 吃奶或进食量

测量频率: 发热期间每4小时左右一次;服退烧药后30-60分钟复测一次
夜里孩子睡得安稳,不需要专门叫醒测体温
就医时带上这份记录,医生判断会准确得多
```

#### 饮食建议
- **宜**: 清淡易消化食物
  - 稀粥、面条
  - 新鲜水果
  - 蔬菜汤
- **忌**:
  - 油腻食物
  - 辛辣刺激
  - 生冷食物
- 发烧时胃口差是正常的,一两天吃得少问题不大,**喝够水比吃饱更重要**;不要强迫进食

### 发烧护理的常见误区

```
❌ "捂一身汗就好了" → 婴幼儿可能被捂到体温急升、脱水、抽搐
❌ 用酒精、冰水擦身 → 酒精可经皮肤吸收中毒,冰水引起寒战反而升温
❌ 一发烧就要求打针输液、吃抗生素 → 大多数发烧是病毒感染,抗生素无效;
   滥用抗生素会产生耐药,真正需要时就不管用了
❌ 体温没降到正常就提前加喂、加量 → 药物过量
❌ 两种退烧药交替或叠加 → 容易算错总量
❌ 只盯着体温数字 → 精神好、能喝水的39°C,比蔫蔫的38°C让人放心
```

### 不同人群的发烧就医标准

| 人群 | 什么情况立即就医(急诊) | 什么情况当天或尽快就医 |
|------|------|------|
| 3个月以下婴儿 | 任何发烧(肛温≥38.0°C);或体温过低(<36°C)、吃奶差、嗜睡 | — |
| 3-6个月 | 精神差、嗜睡、呼吸急促、不吃奶、抽搐 | 体温≥39°C;任何发烧持续超过24小时 |
| 6个月-5岁 | 嗜睡叫不醒、呼吸费力、不褪色皮疹、抽搐、前囟鼓起、6小时以上无尿 | 发烧超过3天;发烧伴耳朵痛、尿痛、频繁呕吐 |
| 大龄儿童和成人 | 体温≥40°C;伴颈部僵硬、剧烈头痛、意识改变、抽搐、呼吸困难、胸痛 | 发烧超过3天;好转后再次发烧 |
| 老人(65岁以上) | 意识改变、呼吸急促、血压低、尿少 | 体温比平时高1°C以上,或虽不高但突然没精神、不吃饭、跌倒 |
| 孕妇 | 发烧伴腹痛、阴道出血或流液、胎动减少 | 任何≥38°C的发烧,都联系产科医生 |
| 免疫力低下者(化疗、长期用激素、器官移植后) | 任何≥38°C的发烧 | — |

```
补充说明:
- 老人的体温反应弱,严重感染时可能只有37.5°C左右甚至不发烧,
  所以老人"不对劲"本身就是就医理由
- 孕妇高烧对胎儿也有影响,不要硬扛,退烧首选对乙酰氨基酚
- 儿童发烧时抽搐(高热惊厥): 首次发生必须就医
```

高热惊厥的现场处理见[心脑血管与突发病症-儿童高热惊厥](06-心脑血管与突发病症.md#儿童高热惊厥);孕期其他危险信号见[紧急分娩与新生儿护理-孕期危险信号](11-紧急分娩与新生儿护理.md#孕期危险信号);新生儿的危险信号见[紧急分娩与新生儿护理-新生儿最初几天](11-紧急分娩与新生儿护理.md#新生儿最初几天)。

### ⚠️ 紧急就医

以下情况立即就医:
- 婴儿(<3个月)任何发烧
- 体温≥40°C
- 发烧伴随:
  - 剧烈头痛
  - 颈部僵硬
  - 意识改变
  - 抽搐
  - 呼吸困难
  - 胸痛
  - 严重腹痛
  - 皮疹(尤其是不褪色的)
  - 持续呕吐
- 发烧超过3天无改善

```
"玻璃杯测试"——判断皮疹是否褪色:
1. 拿一个透明玻璃杯,杯壁用力压在皮疹上
2. 透过玻璃看: 压下去皮疹消失变白 → 褪色
3. 压着仍然看得清红点或紫斑 → 不褪色 → 可能是流行性脑脊髓膜炎或败血症
   → 立即拨打120,不要等其他症状出现(这类病可以在几小时内危及生命)
```

## 腹泻

### 腹泻分类

**急性腹泻** (持续<2周)
- 感染性: 细菌、病毒、寄生虫
- 非感染性: 食物不耐受、药物反应

**慢性腹泻** (持续>4周)
- 需就医检查原因

```
- 大多数急性腹泻是病毒(诺如病毒、轮状病毒)或细菌引起,几天内自愈
- 腹泻真正的危险是脱水和失盐,尤其是婴幼儿和老人
- 所以家庭处理的核心只有一件事: 及时、足量地补液
- 停水、洪水、人员聚集时腹泻容易成片暴发,传染病的防控见传染病家庭防控
```

霍乱、痢疾等腹泻类传染病的防控见[传染病家庭防控-腹泻类传染病](15-传染病家庭防控.md#腹泻类传染病)。

### 症状评估

**轻度**:
- 每天3-5次稀便
- 无脱水症状
- 能正常饮食

**中度**:
- 每天6-10次
- 轻度脱水
- 腹痛

**重度**:
- 每天>10次
- 明显脱水
- 发烧、血便

```
次数之外还要观察:
- 大便性状: 水样(多为病毒或产毒素细菌)/ 带黏液脓血(多为侵袭性细菌,如痢疾)
- 大量米泔水样大便、很快虚脱 → 警惕霍乱
- 黑色柏油样大便 → 可能是上消化道出血(吃铁剂、铋剂、动物血也会变黑,但不会黏稠发亮)
- 是否同时呕吐: 又吐又泻的人脱水快得多
```

### 脱水症状识别

**轻度脱水**:
- 口渴
- 尿量减少,颜色深
- 轻微头晕

**中度脱水**:
- 口干舌燥
- 皮肤弹性差
- 眼窝凹陷
- 尿量明显减少

**重度脱水**(立即就医):
- 极度口渴或不渴
- 无尿或极少
- 皮肤干燥
- 意识模糊
- 脉搏快而弱

**儿童脱水程度判断表**(参照WHO腹泻处理标准):

| 观察项目 | 无明显脱水 | 有些脱水(轻-中度) | 重度脱水 |
|------|------|------|------|
| 精神状态 | 正常、能玩 | 烦躁、易激惹 | 嗜睡、软弱无力、叫不醒 |
| 眼窝 | 正常 | 凹陷 | 明显凹陷 |
| 哭时眼泪 | 有 | 少 | 没有 |
| 口舌 | 湿润 | 干 | 很干 |
| 喝水 | 正常 | 口渴,急着喝 | 喝得很少或不能喝 |
| 捏起腹部皮肤再松开 | 立即回平 | 回平慢 | 很慢(超过2秒) |
| 尿量 | 正常 | 减少、颜色深 | 很少或6小时以上没尿 |
| 婴儿前囟(头顶软处) | 平 | 稍凹陷 | 明显凹陷 |
| **怎么办** | 在家补液(方案A) | 4小时内按体重补液(方案B),最好到医院 | **立即送医静脉补液** |

```
怎样做皮肤弹性试验:
1. 在肚脐和腹部侧面之间,用拇指和食指把皮肤纵向捏起1-2秒
2. 松手,看皮肤褶皱恢复平整要多久
3. 严重营养不良的孩子和老人皮肤本来就松弛,这一项不准,要结合其他项判断

成人和老人:
- 老人口渴感迟钝,"不渴"不代表不缺水
- 站起来时头晕眼黑、心跳快 → 已经有明显脱水
- 8小时以上不排尿、尿色像浓茶 → 需要就医
```

### 家庭治疗

#### 1. 补液(最重要!)

**口服补液盐(ORS)**:
```
首选: 药店购买的口服补液盐III(ORS III,WHO低渗配方)
- 按说明书用规定量的水冲配,不要随意加浓

WHO低渗配方(1 L水):
- 氯化钠: 2.6 g
- 无水葡萄糖: 13.5 g
- 氯化钾: 1.5 g
- 柠檬酸钠: 2.9 g

家庭应急自配(无ORS时,非WHO标准配方,不含钾):
- 1 L凉开水
- 食盐: 半平茶匙(约3 g)
- 白糖: 6平茶匙(约25 g)
- 可同时吃香蕉等补钾
- 盐不能多放(过咸会加重脱水)

用法:
- 少量多次饮用
- 成人: 每次腹泻后200-400 mL
- 儿童: 每次50-100 mL
- 室温或微温饮用
```

```
配制细节:
1. "平茶匙"= 一平勺、用筷子刮平,不是堆尖的一勺;一平茶匙约5 mL
2. 1 L大约是两瓶500 mL矿泉水瓶的量
3. 配好后尝一下: 咸味不应超过眼泪的咸度;太咸就加水稀释
4. 没有白糖时,可以用1 L稀米汤(米煮烂后滤出的汤,放凉)代替糖水,盐量不变
5. 冲好的补液盐在室温下24小时内喝完,剩下的倒掉重配
6. ❌ 不要用运动饮料、碳酸饮料、纯果汁代替: 糖太多,会加重腹泻

儿童按年龄的补液量(无明显脱水时,方案A):
- 2岁以下: 每次稀便后 50-100 mL
- 2-10岁: 每次稀便后 100-200 mL
- 10岁以上和成人: 每次稀便后 200-400 mL,想喝多少喝多少
- 同时照常喝水、喂奶

有些脱水时(方案A不够,方案B):
- 4小时内喂完: 75 mL × 体重(kg)
  例: 10 kg的孩子,4小时内约750 mL,平均每1-2分钟一小勺
- 4小时后重新对照脱水判断表评估: 好转 → 回到方案A;没好转或加重 → 立即送医

喂法:
- 婴幼儿用小勺或杯子,每1-2分钟喂一勺(约5 mL),不要让孩子一次大口猛喝
- 喂后呕吐: 停10分钟,再更慢地继续喂;大多数呕吐的孩子仍能吸收大部分补液
- 补液到尿量恢复、尿色变淡、精神好转,就说明补够了
```

关于盐的摄入和"盐不能多放"的道理,见[制盐](../07-日常生活技能/15-制盐.md)。

**其他补液**:
- 清汤
- 米汤
- 稀释的果汁
- 椰子水
- 这些只适合没有脱水、只需预防脱水的轻症;已经有脱水表现时,一定要用口服补液盐

#### 2. 饮食调整

**BRAT饮食** (初期)
- **B**ananas: 香蕉
- **R**ice: 白米饭/粥
- **A**pplesauce: 苹果泥
- **T**oast: 烤面包

```
注意: BRAT饮食只适合刚开始一两天胃口差时作为过渡,不要长期只吃这几样——
营养太少,反而影响肠道恢复。目前的主流建议是:
✓ 腹泻期间不要禁食,补液后尽快恢复与年龄相应的正常饮食
✓ 母乳喂养的婴儿继续喂母乳,而且多喂
✓ 配方奶喂养的婴儿继续按平时浓度冲奶,不要冲稀
✓ 少量多餐,每天5-6顿
✓ 腹泻停止后的1-2周,每天比平时多吃一顿,补回营养(尤其儿童)
```

**逐渐添加**:
- 煮熟的胡萝卜
- 蒸土豆
- 鸡肉(去皮)
- 酸奶(含益生菌)

**避免**:
- ❌ 油腻食物
- ❌ 辛辣食物
- ❌ 高纤维食物
- ❌ 乳制品(乳糖不耐受期)
- ❌ 咖啡因
- ❌ 酒精
- ❌ 含糖饮料、果汁(糖分会把水"拉"进肠道,加重腹泻)

#### 3. 药物治疗

**止泻药**(仅成人,医生建议下使用):
- 洛哌丁胺(Imodium)
- **禁用于**:
  - 血性腹泻
  - 高烧
  - 儿童(无医嘱)
- 原因: 感染性腹泻是身体在排出病原体,强行止泻可能让细菌和毒素留在肠道里加重病情

**蒙脱石散**:
- 吸附性止泻药,不被吸收,儿童也常用,按说明书和体重/年龄服用
- 与其他药物间隔1-2小时服用(会吸附其他药)
- 只能减轻症状,**不能代替补液**

**益生菌**:
- 有助于恢复肠道菌群
- 建议持续服用1-2周
- 活菌制剂用温水(不超过40°C)送服;如同时用抗生素,间隔2小时以上

**锌补充剂**(儿童):
- 可缩短腹泻持续时间
- WHO推荐用法: 6个月以下每天10 mg,6个月以上每天20 mg,连用10-14天(按所用锌制剂说明书换算)

```
❌ 不要自行给腹泻的人吃抗生素:
- 大多数腹泻是病毒引起,抗生素无效,还会破坏肠道正常菌群
- 只有痢疾样(脓血便伴高烧)、霍乱等情况才需要抗生素,应由医生判断
```

### 婴幼儿、老人和孕妇腹泻

```
婴幼儿(脱水最快,最需要警惕):
- 6个月以下婴儿腹泻,尽早就医
- 继续母乳,在两次喂奶之间喂口服补液盐
- 注意尿布: 6小时以上尿布是干的 → 立即就医
- 护理后彻底洗手: 轮状病毒、诺如病毒传染性极强
- 尿布区皮肤: 每次便后温水洗净、擦干,涂一层凡士林或氧化锌软膏防红屁股

老人:
- 口渴感差,脱水往往发现得晚;每次腹泻后主动提醒、帮助喝补液盐
- 服用降压药(尤其利尿剂)、降糖药的老人,腹泻呕吐吃不下饭时,
  血压过低、低血糖的风险增加 → 联系医生是否需要暂时调整药量,不要自行停药
- 长期卧床、便秘的老人突然出现"腹泻",可能是粪便嵌塞后的漏便(见本章"便秘")

孕妇:
- 轻症同样以口服补液盐为主
- 不要自行服用止泻药和抗生素,先问医生
- 腹泻伴腹痛规律发紧、阴道出血或流液 → 立即就医
```

### 预防措施

```
✓ 勤洗手(尤其是饭前便后)
✓ 食物煮熟煮透
✓ 饮用安全水源
✓ 妥善保存食物
✓ 避免生冷食物
✓ 注意食物卫生
✓ 餐具清洁消毒
```

饮用水的消毒见[水源工程与供水](../07-日常生活技能/10-水源工程与供水.md);厕所和粪便管理见[卫生设施](../07-日常生活技能/03-卫生设施.md)。

### ⚠️ 就医指征

立即就医如果:
- 严重脱水症状
- 血便或黑便
- 高烧(>39°C)
- 剧烈腹痛
- 持续呕吐无法补液
- 腹泻超过3天无改善
- 婴幼儿腹泻
- 近期旅行史(可能寄生虫感染)
- 免疫力低下者

```
按年龄补充:
- 6个月以下婴儿: 腹泻就要就医;出现有些脱水的表现 → 立即就医
- 婴幼儿: 6小时以上无尿、叫不醒、喝不进去、前囟凹陷 → 立即送医
- 老人: 站立时头晕、意识变差、尿极少 → 立即就医
- 孕妇: 不能进食进水超过12小时,或伴腹痛出血 → 立即就医
- 大量米泔水样腹泻,或同一家庭、集体多人同时发病 → 立即就医并报告疾控
```

## 呕吐

### 常见原因

- 肠胃炎(病毒或细菌)
- 食物中毒
- 晕动病
- 妊娠
- 药物副作用
- 过度饮酒

### 呕吐背后可能的急症

多数呕吐是肠胃炎,一两天就好。但呕吐也可能是严重疾病的表现,先排除下面这些情况:

| 呕吐的同时有… | 可能是 | 怎么办 |
|------|------|------|
| 头部受伤后呕吐 | 颅内出血 | 立即就医 |
| 剧烈头痛、颈部僵硬、发烧,呕吐呈喷射状 | 脑膜炎、颅内压升高 | 立即就医 |
| 胸闷胸痛、出冷汗(老人、糖尿病患者可能只有上腹不适和呕吐) | 心梗 | 立即拨打120 |
| 腹痛从肚脐周围转移到右下腹,按压更痛 | 阑尾炎 | 尽快就医,不要吃止痛药掩盖症状 |
| 腹胀、不排气不排便,吐出绿色或粪臭味的东西 | 肠梗阻 | 立即就医,禁食禁水 |
| 婴儿吐出绿色(胆汁样)的东西 | 肠扭转、肠梗阻 | 立即就医 |
| 2周到3个月的婴儿,每次喂奶后喷射状呕吐,吐后又饿 | 幽门狭窄 | 尽快就医 |
| 糖尿病患者呕吐、口渴、呼吸深快、有烂苹果味 | 糖尿病酮症酸中毒 | 立即就医 |
| 家中多人同时头痛、头晕、恶心呕吐 | 一氧化碳中毒 | 立即开窗、离开房间,拨打120 |
| 剧烈头痛、一侧肢体无力、口角歪斜 | 中风 | 立即拨打120 |
| 男孩突然阴囊疼痛伴呕吐 | 睾丸扭转 | 立即就医(超过6小时可能保不住睾丸) |

相关章节: [心梗与胸痛](06-心脑血管与突发病症.md#心梗与胸痛)、[中风](06-心脑血管与突发病症.md#中风)、[一氧化碳中毒](07-居家与交通意外.md#一氧化碳中毒)、[中毒](12-中毒.md)。

### 即时处理

#### 呕吐时
```
1. 坐起或侧卧(防止呛咳)
2. 准备容器
3. 漱口清洁
4. 深呼吸

补充:
- 意识不清、醉酒、婴幼儿、卧床老人呕吐时,一定让他侧卧,头稍低,
  吐完用手指裹纱布清理口中残留物,防止呕吐物吸入气管
- 不要让躺着的人仰面呕吐
- 呕吐物、被污染的地面衣物按传染性物品处理(诺如病毒很容易传给全家)
```

呕吐物的消毒方法见[传染病家庭防控-家用消毒液的配制](15-传染病家庭防控.md#家用消毒液的配制)。

#### 呕吐后
```
1. 先禁食1-2小时
2. 小口喝水测试
3. 如不再吐,逐渐增加液体
4. 休息

说明:
- "禁食"是不吃固体食物,让胃休息;婴幼儿不要停太久,30-60分钟后就开始少量喂补液盐
- 母乳喂养的婴儿: 可以继续喂,但每次喂的时间缩短、次数增加
```

### 补液方案

**第一阶段**(呕吐后0-4小时):
```
- 每5-10分钟一小口水(5-10 mL)
- 可以含冰块
- 可喝: 清水、口服补液盐
- 避免: 果汁、牛奶、饮料

注意:
- 反复呕吐的人失去的是水和盐,只喝清水会稀释血液里的盐分,
  呕吐多时以口服补液盐为主(配法见本章"腹泻")
- 小婴儿不要含冰块(有呛噎风险),用小勺喂补液盐
```

**第二阶段**(4-8小时,如无呕吐):
```
- 逐渐增加饮水量
- 每15分钟30-60 mL
- 可添加: 清汤、米汤
```

**第三阶段**(8小时后,如耐受):
```
- 开始进食
- 从流食开始: 稀粥、面汤
- 逐渐过渡到固体食物

判断是否顺利:
✓ 喝下去不再吐、开始排尿、精神好转 → 按步骤推进
✗ 每次一喝就吐、6-8小时没有排尿 → 不要在家硬撑,就医
```

### 饮食恢复

**可以吃**:
- 清淡的碳水化合物
  - 白米粥
  - 面条
  - 苏打饼干
  - 烤面包
- 香蕉
- 煮熟的土豆

**避免**(至少24-48小时):
- 油腻食物
- 辛辣食物
- 乳制品
- 酸性食物
- 咖啡因
- 酒精

### 药物治疗

**成人止吐药**(医生建议下):
- 甲氧氯普胺(胃复安)
- 多潘立酮(吗丁啉)
- 两者都可能有心脏、神经方面的副作用,不要超量、不要长期用;有心脏病的人先问医生

**儿童**:
- 不建议自行用药
- 应咨询医生

**晕车药**:
- 茶苯海明(乘晕宁)
- 出行前30分钟服用
- 会犯困,服药后不能开车;儿童按说明书减量

```
不用药预防晕车晕船:
✓ 坐在颠簸最小的位置: 汽车前排、船的中部、飞机机翼附近
✓ 眼睛看远处地平线,不要看书、看手机
✓ 打开车窗,保持空气流通
✓ 出发前吃少量清淡食物,不空腹也不吃太饱
✓ 生姜(含姜片、喝姜茶)对部分人有帮助
```

### 婴幼儿呕吐

```
- 婴儿吐奶(喂奶后少量奶从嘴角流出)是常见的,只要体重正常增长、精神好,一般不用处理
- 真正需要关注的是: 用力的、大量的、反复的呕吐
- 少量多次补液比"一次喂饱"重要: 每1-2分钟一小勺(约5 mL)
- 呕吐后让孩子侧卧或竖抱,不要马上平躺
- 呕吐伴腹泻、发烧时,对照本章"腹泻"中的脱水判断表观察

立即就医:
⚠️ 吐出绿色或黄绿色的东西、吐血或咖啡色物
⚠️ 婴儿8小时以上没有排尿,或大孩子12小时没有排尿
⚠️ 嗜睡、叫不醒、前囟鼓起或明显凹陷
⚠️ 剧烈哭闹、腹胀、阵发性哭闹伴果酱样大便(可能是肠套叠)
⚠️ 头部受伤后呕吐
⚠️ 怀疑吃了药物、电池、磁铁、清洁剂等
```

误吞电池、磁铁等见[异物处理-误吞异物](04-异物处理.md#误吞异物);误服药物或清洁剂见[中毒](12-中毒.md)。

### ⚠️ 就医指征

立即就医如果:
- 持续呕吐>24小时
- 无法保持任何液体
- 呕吐物含血或呈咖啡色
- 严重腹痛
- 脱水症状严重
- 剧烈头痛或颈部僵硬
- 意识改变
- 婴儿>8小时未排尿

也要尽快就医:
- 孕妇呕吐严重、吃什么吐什么、体重下降、尿少(妊娠剧吐)
- 糖尿病患者或长期服药的人因呕吐无法正常吃药
- 老人呕吐后出现精神差、糊涂

## 食物中毒

### 症状

通常在进食后数小时到几天内出现(多数在1-72小时内;金黄色葡萄球菌等毒素型最快可在1-6小时内发病,详见下方"不同病原体特点"):
- 恶心、呕吐
- 腹泻(可能带血)
- 腹痛、痉挛
- 发烧
- 头痛、乏力

```
线索:
- 一起吃了同一样东西的人先后发病 → 很可能是食物中毒
- 发病早(几小时内)、以呕吐为主 → 多为食物里已经产生的毒素
- 发病晚(一两天后)、以腹泻发烧为主 → 多为细菌在肠道里繁殖
- 出现视物模糊、眼皮下垂、说话吞咽困难、肢体无力 → 警惕肉毒中毒,立即就医
```

### 处理步骤

#### 1. 停止进食可疑食物
```
- 保留剩余食物样本(供检测)
- 记录: 食物种类、进食时间、症状出现时间

补充:
- 剩余食物、呕吐物用干净的袋子或容器装好封口,冷藏保存,带去医院或交给疾控
- 通知一起吃饭的其他人,让他们注意观察
- 记下一起吃的人有几个、谁发病了、谁没发病——有助于判断是哪样食物
```

#### 2. 补液
```
- 每15分钟喝少量液体
- 口服补液盐首选
- 避免咖啡因和酒精

补液量和方法同本章"腹泻""呕吐"
```

#### 3. 休息
```
- 卧床休息
- 避免剧烈活动
```

#### 4. 逐渐恢复饮食
```
- 症状缓解后开始进食
- 从清淡食物开始
```

```
❌ 不要做:
❌ 不要自行抠喉咙、灌盐水催吐(已经吐泻的人身体正在自己排出;催吐可能导致呛咳和误吸)
❌ 有发烧或血便时,不要自行吃止泻药
❌ 不要自行吃抗生素
❌ 不要喝"解毒"偏方(绿豆汤、醋、生鸡蛋等)代替就医
```

### 不同病原体特点

| 病原体 | 潜伏期 | 典型症状 | 常见来源 |
|--------|--------|----------|----------|
| 金黄色葡萄球菌 | 1-6小时 | 剧烈呕吐 | 熟食、糕点 |
| 蜡样芽孢杆菌 | 0.5-6小时(呕吐型) | 呕吐 | 室温放久的剩米饭、炒饭 |
| 副溶血性弧菌 | 2-48小时 | 腹痛、水样便 | 生的或未煮透的海鲜 |
| 沙门氏菌 | 6-72小时 | 腹泻、发烧 | 蛋、禽肉 |
| 大肠杆菌 | 1-8天 | 血性腹泻 | 生肉、未消毒奶 |
| 诺如病毒 | 12-48小时 | 呕吐、腹泻 | 贝类、污染水 |
| 肉毒杆菌 | 12-36小时 | 神经症状 | 罐头食品 |

```
说明:
- 金黄色葡萄球菌、蜡样芽孢杆菌产生的毒素耐热,食物重新加热也破坏不了
  → 关键是熟食不要在室温久放,而不是"吃前再热一下就安全"
- 肉毒中毒、米酵菌酸中毒致死率高,也没有可靠的家庭处理办法,
  怀疑时立即就医
- 儿童或老人的血性腹泻之后出现尿少、脸色苍白、浮肿 → 可能是溶血尿毒综合征,立即就医
```

### 集体发病和特殊食物中毒

```
多人同时发病:
1. 有人严重(意识改变、神经症状、严重脱水) → 立即拨打120
2. 其他人逐个评估脱水程度,轻症在家补液观察
3. 保留食物样本,向当地疾控或卫生院报告
4. 共用的厨具、餐具彻底清洗并煮沸消毒

非细菌性的食物中毒(发病常常很快,也更凶险):
- 毒蘑菇: 有的吃后6小时以上才发病,先吐泻后"好转",几天后肝衰竭
  → 吃了不认识的蘑菇,不管有没有症状,同吃的人都要就医
- 发芽或变绿的土豆: 龙葵素中毒,口舌发麻、恶心呕吐
- 没炒熟的四季豆(豆角): 进食后数小时恶心呕吐,一定要炒到完全变色、没有生豆味
- 亚硝酸盐(误当食盐、未腌透的咸菜): 嘴唇和指甲发紫、头晕、呼吸困难 → 立即就医
- 发酵变质的米面制品、泡发过久的木耳银耳: 米酵菌酸 → 立即就医
- 河豚、有毒贝类: 口唇四肢麻木 → 立即就医
```

相关章节: [食物加工与保存-高风险食品与食物中毒](../07-日常生活技能/01-食物加工与保存.md#高风险食品与食物中毒)、[中毒-其他中毒](12-中毒.md#其他中毒)、[传染病家庭防控-腹泻类传染病](15-传染病家庭防控.md#腹泻类传染病)。

### 预防措施

#### 采购
```
✓ 检查保质期
✓ 包装完整
✓ 冷藏食品温度适当
✓ 胀袋、胀罐、漏气的包装食品不买不吃
```

#### 储存
```
✓ 冰箱温度: ≤4°C
✓ 冷冻: ≤-18°C
✓ 生熟分开
✓ 密封保存
✓ 冰箱里生肉放下层、熟食放上层,防止生肉汁滴到熟食上
✓ 冷冻肉在冰箱冷藏室里解冻,不在室温下放一整天
```

#### 烹饪
```
✓ 煮熟煮透
✓ 肉类中心温度≥75°C
✓ 避免交叉污染
✓ 切菜板生熟分开
✓ 没有温度计时: 肉切开中心不再是粉红色、肉汁清亮;禽肉骨头附近不带血;蛋黄凝固
✓ 处理生肉、生蛋后洗手,再碰其他食物
```

#### 进食
```
✓ 热食热吃(>60°C)
✓ 冷食冷吃(<5°C)
✓ 食物在室温下不超过2小时
✓ 天气炎热(30°C以上)时,室温下不超过1小时
✓ 剩饭剩菜吃前彻底加热到滚烫;放了一夜在室温下的熟食,宁可丢掉
✓ 拿不准的食物: "有怀疑,就丢掉"
```

没有冰箱时的食物保存方法见[食物加工与保存](../07-日常生活技能/01-食物加工与保存.md)。

### ⚠️ 紧急就医

以下情况立即就医:
- 血性腹泻
- 高烧(>39°C)
- 严重脱水
- 持续呕吐>24小时
- 神经症状(视力模糊、肌肉无力、说话困难)
- 症状持续>3天
- 孕妇、儿童、老人、免疫力低下者
- 怀疑毒蘑菇、亚硝酸盐、米酵菌酸、河豚等中毒(即使暂时没有症状)

```
孕妇特别注意:
- 李斯特菌(冷藏熟肉、未消毒奶和软奶酪、冷藏烟熏海鲜)可以引起流产、早产,
  孕妇症状可能只像轻微感冒或发烧 → 孕期吃过可疑食物后发烧,要告诉医生
- 孕期避免: 生的或半生的肉、蛋、海鲜,未经巴氏消毒的奶
```

## 便秘

### 定义

以下任一情况:
- 每周排便<3次
- 大便干硬
- 排便困难,需用力
- 排便不尽感

```
说明: 排便次数因人而异,每天3次到每3天1次都可能是正常的。
关键是大便是否干硬、排便是否费力,而不是次数本身。
```

### 常见原因

- 饮食纤维不足
- 饮水少
- 缺乏运动
- 忽视便意
- 药物副作用
  - 常见: 含可待因等阿片类的止痛药和止咳药、铁剂、钙片、部分降压药、抗抑郁药、止泻药
- 生活习惯改变
- 压力

### 家庭治疗

#### 1. 增加纤维摄入

**目标**: 每天25-35 g纤维

**高纤维食物**:
- 蔬菜: 西兰花、胡萝卜、菠菜
- 水果: 苹果、梨、浆果、西梅
- 全谷物: 燕麦、糙米、全麦面包
- 豆类: 扁豆、黑豆、鹰嘴豆
- 坚果和种子

**注意**: 逐渐增加纤维,避免腹胀

```
怎么做到:
- 每天至少500 g蔬菜(深色叶菜占一半)、200-350 g水果
- 主食里掺一部分粗粮: 小米、玉米面、燕麦、杂豆
- 西梅、火龙果、猕猴桃对很多人有效
- 每1-2周增加一点,给肠道适应时间
- 加纤维的同时必须多喝水,否则纤维反而会让大便更干
```

#### 2. 充足饮水

```
- 成人: 每天2-3 L水
- 早晨空腹喝温水
- 多喝: 水、温水、果汁
- 心衰、肾病需要限水的人,饮水量听医生的
```

#### 3. 规律运动

```
- 每天至少30分钟
- 散步、慢跑、游泳
- 腹部按摩(顺时针)

腹部按摩做法:
1. 平躺屈膝,放松腹部
2. 手掌放在肚脐周围,以肚脐为中心顺时针(从右下腹→右上→左上→左下)打圈按揉
3. 力度以腹部微微下陷、不痛为准,每次5-10分钟,每天1-2次
4. 饭后1小时内不做;有腹部手术史、腹痛原因不明时不做
```

#### 4. 建立规律

```
- 固定时间如厕(如早餐后)
- 不要忽视便意
- 不要久坐马桶(不超过10分钟)
- 放松,不要过度用力
- 早餐后15-30分钟肠道蠕动最强,这时去厕所最容易成功
- 如厕时不玩手机、不看书
```

#### 5. 姿势优化

```
- 使用脚凳(蹲姿更自然)
- 身体前倾
- 膝盖高于臀部
- 脚凳高度约15-20 cm,双脚踩上去,手肘放在膝盖上
- ⚠️ 高血压、心脏病患者排便时不要憋气猛用力(可能诱发心梗、中风),
  大便干硬时提前用药软化
```

### 儿童、孕妇和老人的便秘

```
婴儿:
- 纯母乳喂养的婴儿,几天到一周才排一次软便,只要大便软、吃奶好、体重增长正常,就不是便秘
- 配方奶喂养: 严格按说明比例冲奶,冲得太浓容易便秘
- 添加辅食后便秘: 多给蔬菜泥、水果泥(梨、西梅),6个月以上可以喝少量水
- 婴儿不要自行使用泻药;顺时针揉肚子、做"蹬自行车"动作有帮助
- 新生儿出生后48小时内没排过胎便、腹胀、呕吐 → 立即就医

儿童:
- 常见原因是憋便(怕痛、玩得忘了、不愿在外面上厕所)→ 憋得越久大便越干越痛,形成恶性循环
- 每天饭后固定坐便5-10分钟,脚下放凳子,完成后表扬,不责骂
- 内裤上经常有少量稀便污渍,可能是长期便秘后的漏便,不是"拉肚子",要就医
- 儿童用泻药先问医生(乳果糖、聚乙二醇在医生指导下儿童也可用)

孕妇:
- 孕期激素和子宫压迫,便秘很常见
- 先用饮食、饮水、运动调整;需要用药时,乳果糖和膨胀性泻药相对安全,先问医生
- 不要自行用番泻叶、芦荟、大黄等刺激性泻药(可能引起宫缩)
- 补铁药容易引起便秘,不要因此自行停药,和医生商量

老人:
- 活动少、喝水少、吃药多,便秘最常见
- 长期卧床老人要警惕粪便嵌塞: 好几天没有排便,然后不断漏出少量稀便,
  伴腹胀、食欲差、烦躁,甚至意识混乱 → 需要医护人员处理
- 每天记录排便情况,超过3天没有排便就开始处理,不要等到嵌塞
```

卧床老人的日常护理见[老人照护-其他日常护理](13-老人照护.md#其他日常护理)。

### 药物治疗(短期使用)

**膨胀性泻药**(首选):
- 车前草、甲基纤维素
- 增加大便体积
- 需大量饮水

**渗透性泻药**:
- 乳果糖、聚乙二醇
- 软化大便
- 一般需要1-2天起效,不要因为当天没效果就加量

**刺激性泻药**(谨慎使用):
- 番泻叶、比沙可啶
- 仅短期、偶尔使用
- 可能产生依赖

**润滑剂**:
- 开塞露(甘油)
- 用于紧急缓解

```
开塞露的用法:
1. 剪开封口,挤出一点药液润滑开口处(剪口要修平,防止划伤)
2. 侧卧,轻轻把细管全部插入肛门(儿童用儿童装,插入浅一些)
3. 把药液全部挤入,拔出时继续捏扁,防止药液吸回
4. 尽量忍5-10分钟再排便,效果更好
5. 偶尔用;长期依赖会使肠道反应变差

❌ 不要长期自行吃"排毒""清肠"类产品,很多含有刺激性泻药成分
```

### ⚠️ 就医指征

立即就医如果:
- 突然便秘伴剧烈腹痛
- 便血或黑便
- 不明原因的体重下降
- 便秘与腹泻交替
- 便秘持续>2周无改善
- 伴随呕吐
- 腹部明显肿胀

```
另外:
- 腹胀、腹痛、呕吐、完全不排气 → 可能是肠梗阻,立即就医
- 40岁以上排便习惯近期改变(变细、次数改变)、伴贫血或乏力 → 尽快就医检查,排除肠道肿瘤
- 排便时肛门剧痛、便后滴血 → 可能是肛裂或痔疮,也应就医确认
```

## 头痛

### 头痛类型

#### 1. 紧张性头痛(最常见)

**症状**:
- 双侧头部紧缩感
- 像被绷带勒紧
- 轻到中度疼痛
- 持续30分钟到数天

**诱因**:
- 压力、焦虑
- 姿势不良
- 眼睛疲劳
- 睡眠不足

#### 2. 偏头痛

**症状**:
- 单侧搏动性疼痛
- 中到重度
- 恶心、呕吐
- 畏光、畏声
- 可能有先兆(视觉异常)
- 持续4-72小时

**诱因**:
- 特定食物(奶酪、巧克力、酒精)
- 荷尔蒙变化
- 睡眠不规律
- 强光、强烈气味

#### 3. 丛集性头痛

**症状**:
- 单侧眼部及周围剧痛
- 流泪、鼻塞
- 持续15分钟到3小时
- 可能每天发作多次

```
其他常见的头痛原因(处理原因比吃止痛药更有效):
- 发烧、感冒、鼻窦炎
- 缺水、饿过头(低血糖)
- 突然停喝咖啡、浓茶
- 高血压(血压很高时可出现头痛、头晕,应量血压)
- 饮酒后
- 一氧化碳中毒(取暖、烧炭、燃气热水器的房间里多人同时头痛)
```

### 家庭处理

#### 即时缓解

**紧张性头痛**:
```
1. 休息,闭眼
2. 热敷颈部和肩膀(20分钟)
3. 轻柔按摩太阳穴
4. 放松练习、深呼吸

补充:
- 热敷用40-50°C的热毛巾或热水袋外包毛巾,不要直接贴皮肤,防止烫伤
- 慢慢转动、伸展脖子和肩膀,每个方向保持10-15秒
- 喝一杯水,吃点东西
```

**偏头痛**:
```
1. 安静、黑暗的房间
2. 冷敷前额(15-20分钟)
3. 平躺休息
4. 避免光线和噪音

补充:
- 冷敷用毛巾包着冰袋或冷水瓶,不要直接贴冰
- 一感觉到先兆或头痛刚开始就用药,越早效果越好
- 能睡着的话,睡一觉常常就缓解了
```

#### 药物治疗

**轻到中度头痛**:
- 对乙酰氨基酚: 500-1000 mg
- 布洛芬: 200-400 mg
- 阿司匹林: 500-1000 mg(成人)

**注意**:
- 在头痛早期服用效果更好
- 不要频繁使用(可能导致药物过量性头痛)
- 每月使用不超过10-15天

```
具体说明:
- 每日最大量、禁忌和间隔时间同本章"发烧"中的退烧药
- 阿司匹林: 18岁以下禁用;有胃溃疡、出血倾向、服抗凝药者不要用;孕期不要自行使用
- 儿童头痛: 用对乙酰氨基酚或布洛芬,按体重计算剂量(见本章"发烧"剂量速查)
- 药物过量性头痛: 单一止痛药每月用药超过15天,或复方止痛药(含咖啡因等)
  每月超过10天,头痛会变得更频繁 → 需要医生帮助逐步停药
- 记录每月吃了几天止痛药
```

#### 非药物方法

```
✓ 保持水分充足
✓ 规律进食
✓ 充足睡眠(7-9小时)
✓ 减少屏幕时间
✓ 改善姿势
✓ 管理压力
✓ 规律运动
```

### 预防措施

#### 识别和避免诱因

**常见诱因记录表**:
```
- 日期时间
- 头痛类型和强度
- 持续时间
- 诱因(食物、活动、压力等)
- 治疗方法和效果

强度可以用0-10分记录: 0 = 不痛,10 = 能想象到的最痛
连续记录1-2个月,常能找到自己的规律;看医生时带上记录
女性可同时记下月经日期(部分偏头痛与月经周期有关)
```

#### 生活方式调整

```
✓ 规律作息
✓ 均衡饮食
✓ 适度运动
✓ 压力管理
✓ 限制咖啡因
✓ 戒烟限酒
```

长期压力、焦虑、失眠的应对见[心理健康](10-心理健康.md#长期压力下照顾好自己)。

### 特殊人群的头痛警示

```
儿童:
- 头痛伴发烧、呕吐、颈部僵硬、皮疹 → 可能是脑膜炎,立即就医
- 头痛越来越频繁,早晨起床时最痛并伴呕吐,或伴走路不稳、视力变化 → 尽快就医
- 头部撞伤后头痛加重、反复呕吐、嗜睡 → 立即就医

孕妇:
- 孕20周以后出现剧烈头痛、视物模糊、眼前闪光、上腹痛、脸和手突然浮肿
  → 可能是子痫前期,立即就医
- 孕期头痛用药首选对乙酰氨基酚,不要自行吃布洛芬、阿司匹林
- 产后1-2周内出现剧烈头痛,也要就医

老人:
- 50岁以后首次出现的头痛,都应就医查原因
- 跌倒或撞头后几天到几周内逐渐出现头痛、嗜睡、性格改变、走路不稳
  → 可能是慢性硬膜下血肿(服抗凝药、阿司匹林的老人尤其要警惕),就医
- 一侧太阳穴痛、梳头时头皮痛、咀嚼时下巴痛、视力模糊 → 可能是颞动脉炎,尽快就医(可致失明)
- 高血压患者突然剧烈头痛,先测血压,并按下方"雷击"信号判断是否急诊

家里多人同时头痛、头晕、恶心(尤其在用炉子、炭火、燃气取暖或洗澡的房间)
→ 先开窗、把人转移到室外,再拨打120
```

相关章节: [中风](06-心脑血管与突发病症.md#中风)、[一氧化碳中毒](07-居家与交通意外.md#一氧化碳中毒)、[孕期危险信号](11-紧急分娩与新生儿护理.md#孕期危险信号)、[老人跌倒后怎么办](13-老人照护.md#老人跌倒后怎么办)。

### ⚠️ 紧急就医("雷击"信号)

立即就医如果头痛伴随:
- 突发最剧烈头痛("一生中最严重")
- 发烧、颈部僵硬
- 意识改变、混乱
- 视力突然改变
- 说话困难
- 行走困难、失去平衡
- 面部、手臂或腿部麻木/无力
- 头部受伤后的头痛
- 头痛逐渐加重
- 50岁后首次出现严重头痛

```
"雷击样头痛": 几秒到1分钟内达到最剧烈的程度,像头被重重打了一下
→ 可能是蛛网膜下腔出血(脑血管破裂),即使后来缓解了,也必须立即拨打120
→ 等待时让病人平躺、保持安静,不要给吃喝,不要自行服阿司匹林
```

## 咳嗽

### 咳嗽类型

**按持续时间**:
- 急性: <3周(通常感冒)
- 亚急性: 3-8周(感染后)
- 慢性: >8周(需查明原因)

**按性质**:
- 干咳: 无痰
- 湿咳: 有痰

```
咳嗽是身体清理气道的保护反射。有痰的咳嗽不要强行压住,
要帮助把痰咳出来;只有严重影响睡眠的干咳才考虑镇咳药。
感冒后的咳嗽常常要持续2-3周才完全消失,这是正常的。
```

### 常见原因

- 病毒感染(感冒、流感)
- 细菌感染
- 过敏
- 哮喘
- 胃食管反流
- 药物副作用
  - 部分降压药(如卡托普利等"普利"类)会引起持续干咳,不要自行停药,和医生商量换药
- 吸烟

### 家庭治疗

#### 1. 缓解咳嗽

**蜂蜜**(1岁以上):
```
- 睡前1-2茶匙
- 可与温水或茶混合
- 有镇咳和抗菌作用
- ⚠️ 1岁以下婴儿禁止吃蜂蜜(可能含肉毒杆菌芽孢,引起婴儿肉毒中毒)
- 1-5岁: 每次约半茶匙到1茶匙
```

**蒸汽吸入**:
```
- 热水蒸汽(小心烫伤)
- 热水澡
- 加湿器
- 保持室内湿度40-50%
- 加湿器每天换水、每周清洗,否则容易滋生细菌霉菌
- 儿童不要用热水盆熏蒸,改为浴室蒸汽
```

**温热饮品**:
- 蜂蜜柠檬水
- 姜茶
- 鸡汤

**抬高头部**:
- 睡觉时多垫一个枕头
- 减少夜间咳嗽
- 1岁以下婴儿不要垫枕头,仰卧睡在硬床面上(防窒息)

#### 2. 化痰

**多喝水**:
- 稀释痰液
- 每天2-3 L

**拍背排痰**(适用于儿童):
```
1. 俯卧或侧卧
2. 掌心成杯状
3. 从下往上轻拍背部
4. 持续3-5分钟
5. 鼓励咳出痰液

要点:
- 手指并拢、掌心空出,拍上去是"噗噗"的空响声,不是"啪啪"声
- 避开脊柱和腰部以下(肾脏位置)
- 在饭前或饭后1-2小时进行,避免引起呕吐
- 也适用于卧床老人: 每2小时翻身一次,翻身时拍背
```

卧床老人防呛咳和肺部感染见[老人照护-安全喂食,防止呛咳](13-老人照护.md#安全喂食防止呛咳)。

#### 3. 药物

**止咳药**(干咳):
- 右美沙芬
- **注意**: 不建议给6岁以下儿童
- 含可待因的止咳药: 12岁以下禁用;成人也不要长期用(会成瘾、便秘)
- 有痰时不用镇咳药,否则痰排不出去

**祛痰药**(湿咳):
- 愈创甘油醚
- 氨溴索、乙酰半胱氨酸

**不建议**:
- 抗生素(病毒性咳嗽无效)
- 除非医生确诊细菌感染

```
⚠️ 止咳药、感冒药常是复方的,注意成分不要重复,
   尤其不要和含相同成分的感冒药同时吃(见本章"感冒")
```

#### 4. 避免刺激

```
❌ 吸烟和二手烟
❌ 强烈气味(香水、清洁剂)
❌ 冷空气(外出戴口罩)
❌ 剧烈运动(急性期)
❌ 室内烧煤、烧柴的烟(炉灶要有烟囱通到室外)
```

### 不同痰液的意义

| 痰液颜色 | 可能原因 | 处理 |
|----------|----------|------|
| 清白色 | 病毒感染、过敏 | 观察 |
| 黄绿色 | 病毒或细菌感染都可能(颜色来自白细胞) | 单凭颜色不需要抗生素;伴高烧不退、好转后又加重、气短 → 就医 |
| 棕色 | 吸烟、旧血 | 戒烟、就医 |
| 粉红泡沫 | 心脏/肺问题 | 立即就医 |
| 血丝/血块 | 多种原因 | 就医检查 |

### 儿童咳嗽和呼吸急促的判断

孩子咳嗽时,最重要的是看**呼吸**。让孩子安静(最好睡着)时,掀开衣服看胸腹起伏,数满1分钟:

| 年龄 | 呼吸急促的标准(每分钟) |
|------|------|
| 2个月以下 | ≥60次 |
| 2-12个月 | ≥50次 |
| 1-5岁 | ≥40次 |

```
立即就医的信号:
⚠️ 呼吸急促(达到上表标准)
⚠️ 吸气时胸骨下方、肋骨之间向里凹陷(胸凹陷)
⚠️ 鼻翼扇动、呼吸时发出呻吟声
⚠️ 嘴唇、舌头发紫或发青
⚠️ 不能吃奶、不能喝水,或吃什么吐什么
⚠️ 嗜睡、叫不醒、抽搐

几种特殊的咳嗽:
- 犬吠样咳嗽(像狗叫、"空空"声)、声音嘶哑、吸气时有尖锐的喉鸣,多在夜间突然发作
  → 多为急性喉炎(哮吼)。让孩子保持安静、竖抱安抚(哭闹会加重),
    带到凉爽的空气中可能缓解;安静时也有喉鸣、呼吸费力、口唇发紫 → 立即拨打120
- 一阵阵连续咳十几声、咳完深吸气时有"鸡鸣"样回声、咳后呕吐
  → 可能是百日咳。小婴儿可能不咳,只表现为憋气、脸发紫、呼吸暂停,非常危险 → 立即就医
- 孩子吃东西(花生、瓜子、果冻)或玩小物件时突然剧烈呛咳、之后一直咳或喘
  → 警惕气道异物,即使后来咳嗽减轻也要就医
- 反复喘息、夜里或运动后咳嗽 → 可能是哮喘,就医确诊
```

气道异物的急救见[异物处理-喉咙异物/气道梗阻](04-异物处理.md#喉咙异物气道梗阻);哮喘发作见[哮喘急性发作](06-心脑血管与突发病症.md#哮喘急性发作)。

```
老人和慢性病患者:
- 老人的肺炎可能只表现为精神差、食欲下降、呼吸变快,而不明显发烧或咳嗽
- 吃饭喝水时容易呛咳的老人,反复发烧咳嗽 → 警惕吸入性肺炎
- 慢阻肺、心衰患者咳嗽加重、气喘、痰量增多、腿肿 → 尽早就医
- 家中有指夹式血氧仪时: 安静状态下读数低于94%,或比平时明显下降 → 就医
```

### 预防措施

```
✓ 勤洗手
✓ 避免接触感染者
✓ 戒烟
✓ 接种疫苗(流感、肺炎)
✓ 避免过敏原
✓ 保持室内清洁
✓ 儿童按时接种百白破等国家免疫规划疫苗
```

疫苗接种见[传染病家庭防控-疫苗](15-传染病家庭防控.md#疫苗)。

### ⚠️ 就医指征

立即就医如果:
- 咳血
- 呼吸困难、喘息
- 胸痛
- 高烧持续
- 咳嗽>3周无改善
- 痰液颜色变化(粉红泡沫、带血;或黄绿色伴高烧不退、气短)
- 伴随体重下降
- 夜间盗汗
- 婴儿咳嗽伴呼吸急促

```
- 咳嗽、咳痰超过2周,伴低热、夜间出汗、消瘦 → 尽早排查肺结核(见传染病家庭防控)
- 3个月以下婴儿的任何咳嗽都应就医
```

肺结核见[传染病家庭防控-呼吸道传染病](15-传染病家庭防控.md#呼吸道传染病)。

## 📝 总结要点

### 何时自我护理

大多数轻微疾病可以在家处理:
- 症状轻微
- 逐渐好转
- 能正常饮食和休息
- 无危险信号

### 何时就医

出现以下情况应就医:
- 症状严重或持续
- 症状突然恶化
- 出现危险信号
- 婴幼儿、老人、孕妇
- 免疫力低下者

```
本章最重要的几条:
1. 看人的精神状态,比看体温数字更重要
2. 3个月以下婴儿任何发烧、体温≥40°C → 立即就医
3. 腹泻呕吐的核心是补液: 口服补液盐,少量多次;婴儿6小时无尿要就医
4. 儿童用药按体重算剂量,看清药液浓度,用自带量具
5. 18岁以下不用阿司匹林;不要同时或交替用两种退烧药;复方感冒药里可能已含退烧药
6. 感冒、大多数腹泻和咳嗽是病毒引起,抗生素无效
7. 头痛"雷击样"、呕吐伴头外伤、发烧伴不褪色皮疹 → 立即拨打120
8. 老人病重时症状可能不典型: "不对劲"本身就是就医理由
```

### 家庭常备药

**基础药物**:
- 退烧止痛药
- 止泻药
- 口服补液盐
- 抗过敏药
- 益生菌
- 外用消毒药

**定期检查**:
- 查看有效期
- 补充用完的药品
- 妥善保存

```
建议的具体清单(按家庭成员调整):
- [ ] 对乙酰氨基酚(成人片剂;有孩子时备儿童混悬液或滴剂)
- [ ] 布洛芬(成人片剂;有6个月以上孩子时备儿童混悬液)
- [ ] 口服补液盐III(按人数多备几包;也记住自配方法)
- [ ] 蒙脱石散
- [ ] 抗过敏药(氯雷他定或西替利嗪)
- [ ] 生理盐水或鼻腔冲洗盐
- [ ] 开塞露
- [ ] 电子体温计(备用电池)
- [ ] 儿童用药的量杯、量管
- [ ] 家庭成员的用药信息卡(过敏史、长期用药)

保存:
✓ 原包装保存,保留说明书(没有说明书就无法核对剂量)
✓ 阴凉干燥处,锁好或放高处,儿童拿不到
✓ 混悬液开封后的保存期限按说明书,通常比未开封短得多
✓ 每半年检查一次有效期;变色、变味、结块的药丢弃
```
