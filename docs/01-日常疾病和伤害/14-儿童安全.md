## 为什么要专门讲预防

手册其他章节讲的大多是"出了事怎么办"。但对孩子来说,很多意外一旦发生就来不及了: 溺水几分钟就会造成不可逆的伤害,从窗户坠落往往是致命的。

**意外伤害是儿童死亡的重要原因,而其中大部分是可以预防的。** 靠的不是事后急救,而是事前把环境变安全、把危险的东西收起来、看护时不分心。

```
三条总原则:
1. 看护: 年龄越小,越要在伸手可及的范围内,看护时不玩手机
2. 环境: 把家里变成"即使一时没看住,孩子也不容易出事"的地方
3. 教育: 随着年龄增长,教孩子认识危险、学会求助
```

## 防溺水

**溺水是我国1-14岁儿童意外伤害死亡的第一位原因。**

### 幼儿(主要在家里和家附近)

幼儿溺水常常发生在大人"离开一下"的时候,而且**几厘米深的水就能淹死一个幼儿**。

```
✓ 洗澡时大人始终在旁边,不要留孩子一个人在浴盆里,哪怕一分钟
✓ 用完的浴盆、水桶、水盆立即倒空
✓ 水缸、水井、蓄水池加盖,盖子要孩子掀不开
✓ 马桶盖盖好
✓ 家附近有池塘、水渠、鱼塘时,加装围栏,不让幼儿单独在门外玩
```

### 学龄儿童和青少年(主要在野外水域)

农村儿童溺水死亡率明显高于城市,多数发生在暑假、在没有安全设施的江河、池塘、水库。

```
教孩子"六不":
✓ 不私自下水游泳
✓ 不擅自与他人结伴游泳
✓ 不在没有家长或老师带领的情况下游泳
✓ 不到没有安全设施、没有救援人员的水域游泳
✓ 不到不熟悉的水域游泳
✓ 不熟悉水性的不擅自下水施救

✓ 学会游泳(但会游泳不等于不会溺水)
✓ 看到同伴落水: 大声呼救、拨打110/120、找竹竿绳子递过去,不要手拉手下水救人
```

### 真实的溺水看起来不像溺水

```
溺水的人往往:
- 没有呼喊、没有挥手(张口呼吸都来不及)
- 头在水面上下起伏,身体直立,像在水里"爬梯子"
- 几十秒内就沉下去

所以"听到喊救命再去救"是来不及的,水边必须一直盯着孩子。
```

溺水的急救见[急性症状-溺水](05-急性症状.md#溺水)。

## 防坠落

```
窗户和阳台:
✓ 窗户安装限位器(只能打开约10厘米)或防护栏
✓ 窗户和阳台下面不放椅子、床、沙发、箱子等孩子能爬上去的东西
✓ 阳台护栏的间隙不能让孩子钻过去,不能有横杆让孩子攀爬
✓ 纱窗挡不住孩子,不能当作防护
❌ 不要把孩子单独留在家里,哪怕"一会儿就回来"

家里:
✓ 楼梯上下装安全门
✓ 婴儿换尿布、放在床上时,一只手始终扶着
✓ 婴儿床护栏升起
✓ 高大家具(书柜、衣柜、电视柜)固定在墙上,防止孩子攀爬时倾倒
```

## 防误服误吞

### 收好危险的东西

```
锁起来或放在高处,孩子拿不到:
- 所有药品(包括维生素、铁剂、大人的降压药降糖药)
- 清洁剂、洗衣液(尤其是颜色鲜艳的洗衣凝珠)、消毒液
- 农药、鼠药、杀虫剂
- 酒、烟、电子烟油
- 化妆品、指甲油、洗甲水

❌ 不要用饮料瓶装清洁剂、农药、汽油
❌ 不要在孩子面前吃药,不要说"药是糖"
```

### 特别危险的小东西

```
- 纽扣电池(遥控器、玩具、手表里): 吞下后2小时内就能烧穿食道
- 小磁铁(磁力玩具): 吞下两个以上可在肠道内相互吸引,导致肠穿孔
- 硬币、小零件、气球碎片
```

纽扣电池和磁铁误吞的处理见[误吞异物](04-异物处理.md#误吞异物);误服药物和化学品见[中毒](12-中毒.md)。

## 防窒息

### 食物

3岁以下儿童(有些食物到4-5岁)吞咽能力还不成熟,以下食物容易卡住气道:

```
- 整颗的坚果、花生、瓜子
- 整颗的葡萄、小番茄、樱桃(切成小块再给)
- 果冻(尤其是吸食的果冻)
- 硬糖、口香糖
- 爆米花
- 大块的肉、香肠(切成小条)

✓ 吃东西时坐着,不要边跑边吃、边笑边吃
✓ 大人在旁边看着
```

海姆立克急救法见[异物处理-喉咙异物/气道梗阻](04-异物处理.md#喉咙异物气道梗阻),家长一定要学会。

### 婴儿安全睡眠

```
✓ 仰卧睡(不要趴着睡、侧着睡)
✓ 睡在硬而平的床垫上
✓ 婴儿床里不放枕头、被子、毛绒玩具、防撞围栏
  (可用睡袋代替被子)
✓ 和父母同一个房间,但睡在自己的婴儿床里
✓ 不要包裹得太厚太热
❌ 不要和喝过酒、吃过安眠药、非常疲惫的大人同睡一张床
❌ 不要让婴儿睡在沙发上
```

### 其他

```
✓ 窗帘绳、百叶窗拉绳收起来,剪短或绑高(会缠绕孩子脖子)
✓ 塑料袋、保鲜膜放在孩子拿不到的地方
✓ 不给婴幼儿戴项链、绳子挂的奶嘴链过长
✓ 废弃的冰箱、柜子、汽车后备箱要关好锁好(孩子钻进去会窒息)
```

## 防烧烫伤

```
厨房:
✓ 做饭时孩子不进厨房
✓ 锅柄朝里,不要伸出灶台边
✓ 热水壶、热汤、热饭放在桌子中间,不用桌布(孩子拉扯桌布会把热汤拉下来)

热水:
✓ 洗澡先放冷水,再放热水,用手肘试水温(温热不烫即可)
✓ 抱着孩子时不要喝热饮、端热汤
✓ 热水器温度不要设得太高

其他:
✓ 打火机、火柴收好
✓ 取暖器、电暖器加防护罩,远离床和窗帘
✓ 插座装保护盖
```

烧烫伤的处理见[外伤处理-烫伤与烧伤](02-外伤处理.md#烫伤与烧伤)。

## 乘车安全

```
✓ 使用适合年龄和体重的儿童安全座椅
  - 《未成年人保护法》要求监护人采取配备儿童安全座椅等措施
  - 婴儿使用反向(面朝车尾)安装的座椅,时间越长越安全
✓ 不满12周岁的孩子不坐副驾驶(多地法规明确规定)
✓ 不要大人抱着孩子坐车(急刹车时根本抱不住)
✓ 开车门前看后方来车,孩子从靠路边的一侧下车

❌ 绝不能把孩子单独留在车里,哪怕几分钟
   - 夏天停在阳光下的车内温度可在很短时间内升到致命高温
   - 下车前回头检查后座
```

## 防走失

```
✓ 在人多的地方(商场、景区、车站)始终牵着或在视线内
✓ 教孩子记住: 自己的名字、父母的名字和电话、家庭住址
✓ 年纪小的孩子在衣服里缝或放一张写有家长电话的卡片
✓ 约定: 走散了就站在原地不动,或找穿制服的工作人员、警察、带孩子的妈妈求助
✓ 教孩子: 不跟陌生人走,不吃陌生人给的东西,有人强行拉扯时大声喊"我不认识你"
✓ 出门前拍一张孩子当天穿着的照片

发现孩子走失:
⚠️ 立即拨打110报警,不需要等24小时!
- 同时通知现场工作人员(商场、景区可广播、封闭出口)
- 提供照片和当天的穿着
```

## 其他

```
触电:
✓ 插座装保护盖或使用安全插座
✓ 电线收好,不要让孩子玩电线和充电器
→ 触电急救见电击伤

动物:
✓ 不让幼儿单独和狗相处,即使是家里的狗
✓ 教孩子不要逗弄、追赶陌生的狗和猫
→ 被咬伤后的处理和狂犬病预防见外伤处理-咬伤

骑车、玩耍:
✓ 骑自行车、滑板车、轮滑时戴头盔
✓ 不在马路边、停车场玩耍
```

## 📝 儿童安全要点

```
1. 看护时在伸手可及的范围内,不玩手机
2. 溺水: 浴盆水桶倒空,水缸加盖,野外水域"六不",同伴落水不手拉手下水救
3. 窗户装限位器或护栏,窗下不放可攀爬的家具,不把孩子单独留在家
4. 药品、清洁剂、农药锁好,不装饮料瓶;纽扣电池和磁铁收好
5. 3岁以下不吃整颗坚果、果冻、整颗葡萄;婴儿仰卧睡在自己的床上
6. 热汤热水远离桌边,洗澡先放冷水
7. 用儿童安全座椅,绝不把孩子留在车里
8. 走失立即报110,不用等24小时
9. 家长学会海姆立克急救法和儿童CPR
```
