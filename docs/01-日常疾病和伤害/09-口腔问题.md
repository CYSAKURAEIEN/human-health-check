## 为什么口腔问题不能拖

牙痛常被当成小事,但**牙齿感染可以扩散到面部、颈部,压迫气道,甚至引起全身感染(脓毒症)**。在无法及时看牙医的情况下(灾后、偏远地区、长期断供),一颗烂牙可能发展成危及生命的问题。

```
口腔问题的三条底线:
1. 面部肿胀扩散、吞咽或呼吸困难 → 急症,立即就医
2. 恒牙撞掉 → 越快放回牙槽越好,最好15分钟内
3. 预防比治疗容易得多: 每天刷牙、少吃甜食
```

## 牙痛

### 常见原因

| 原因 | 特点 |
|------|------|
| 龋齿(蛀牙) | 遇冷热酸甜刺痛,能看到黑洞 |
| 牙髓炎 | 剧烈跳痛、夜间加重,冷热刺激后疼痛持续不消 |
| 牙周炎 | 牙龈红肿出血、牙齿松动、咬东西痛 |
| 智齿冠周炎 | 最后面的牙肿痛,张嘴受限 |
| 牙齿裂纹 | 咬到某个位置时突然刺痛 |

⚠️ **牙痛也可能是心梗的表现**(尤其是下牙、下颌痛,伴胸闷、出汗、气短),见[心梗与胸痛](06-心脑血管与突发病症.md#心梗与胸痛)。

### 临时止痛(在能看牙医之前)

```
✓ 口服止痛药: 布洛芬或对乙酰氨基酚,按说明书服用(常用剂量见下方链接)
✓ 温盐水漱口: 一杯温开水加半茶匙盐,含漱30秒,每天数次
✓ 有肿胀时,在脸颊外侧冷敷15-20分钟(隔着毛巾)
✓ 清除嵌塞的食物: 用牙线或牙签轻轻剔除
✓ 丁香油(如有): 棉签蘸极少量,轻点在痛牙上,不要大面积涂抹牙龈
✓ 避免过冷、过热、过甜的食物,用另一侧咀嚼
✓ 睡觉时头部垫高
```

止痛药的常用剂量和注意事项见[常见疾病-发烧](01-常见疾病.md#发烧)中的"药物退烧"部分。

### ❌ 不要做

```
❌ 不要把阿司匹林或任何药片放在痛牙旁边的牙龈上
   - 不会止牙痛,反而会在几小时内造成牙龈化学性烧伤和溃烂
❌ 不要用热敷敷肿起来的脸(可能促使感染扩散)
❌ 不要往牙洞里塞烟丝、花椒、大蒜、白酒浸泡的棉花等
   - 大蒜直接接触黏膜会造成化学性烧伤
❌ 不要以为吃了消炎药就好了
   - 抗生素只能暂时控制感染扩散,不能治好烂牙;
     根本解决需要补牙、根管治疗或拔牙
```

生蒜造成烧伤的说明见[抗生素制备-大蒜](../06-制药技术/02-抗生素制备.md#32-大蒜以食用为主)。

## 牙脓肿与危险信号

### 识别牙脓肿

- 持续剧烈跳痛
- 牙龈上鼓起脓包,按压可能流出脓液、有臭味
- 牙齿一碰就痛,感觉"变高了"
- 脸颊或下颌肿胀
- 可能发热

### ⚠️ 立即拨打120或去急诊

```
出现以下任何一项,是可能危及生命的急症:

- 面部或颈部肿胀迅速扩大,或越过脸的中线
- 舌头下方、下巴底下肿胀,舌头被抬高
- 吞咽困难、口水咽不下去而流出来
- 说话含糊、像嘴里含着东西
- 呼吸困难、呼吸时有异常声音
- 张口困难越来越严重
- 高热、寒战、精神差
- 眼睛周围肿胀(上牙感染扩散)
```

牙齿感染扩散到口底和颈部(称为路德维希咽峡炎)可以在数小时内压迫气道,必须在医院处理。

### 一般牙脓肿

没有上述危险信号时:
```
✓ 尽快看牙医(切开引流、根管治疗或拔牙才能根治)
✓ 等待期间: 温盐水漱口、口服止痛药、冷敷
✓ 无法及时就医时,医生可能会开抗生素控制感染
❌ 不要自己用针挑破或挤压脓包(可能把感染推向深处)
```

抗生素的储备见[抗生素制备-储备建议](../06-制药技术/02-抗生素制备.md#六储备建议)。

## 牙齿外伤

### 恒牙被撞掉(完整脱落)

**时间是关键: 最好15分钟内放回牙槽,牙齿在口外干放超过60分钟,保住的希望就很小了。**

```
1. 找到牙齿
2. 只捏牙冠(露在嘴里的白色部分),不要碰牙根
3. 如果有泥土:
   - 用牛奶或生理盐水轻轻冲一下(几秒钟)
   - ⚠️ 不要用自来水冲洗,不要用刷子刷,不要用纸巾擦牙根
4. 尽快放回原来的牙槽:
   - 确认方向正确(和旁边的牙对比)
   - 用手指轻轻按回去
   - 咬住一块干净纱布或手帕固定
5. 立即去看牙医或口腔急诊

如果无法放回:
- 把牙齿泡在牛奶或生理盐水里带去医院
- 成人也可以把牙齿含在脸颊内侧(用唾液保存;不要吞下)
- ❌ 不要泡在清水里,不要用纸包着干放
```

### ⚠️ 乳牙(儿童换牙前的牙)撞掉不要放回去

- 放回去可能伤到下面正在发育的恒牙牙胚
- 止血,带孩子看牙医检查
- 判断不了是乳牙还是恒牙时,带着牙齿去看牙医

### 牙齿折断、松动

```
牙齿折断:
- 找到断下的碎片,同样泡在牛奶或生理盐水中带去医院(有时可以粘回去)
- 温水漱口,冷敷减轻肿胀
- 尽快看牙医

牙齿松动或移位:
- 不要用手去摇或掰
- 吃软食,用另一侧咀嚼
- 尽快看牙医固定
```

### 同时注意

- 口腔外伤可能伴有下颌骨折、头部外伤,见[骨骼损伤](03-骨骼损伤.md)
- 被泥土污染的口腔伤口,注意破伤风预防,见[外伤处理-破伤风预防](02-外伤处理.md#破伤风预防)

## 拔牙后出血

```
正常: 拔牙后24小时内唾液中带少量血丝

止血:
1. 把干净纱布叠成小块,放在拔牙处,用力咬住30-45分钟
2. 仍渗血: 换新纱布再咬,或咬一个泡湿后挤干的红茶包(茶叶中的鞣酸有助止血)
3. 头部垫高休息

24小时内:
❌ 不要反复吐口水、不要用吸管、不要吸烟
   (负压会把伤口里的血凝块吸掉,导致"干槽症",剧烈疼痛)
❌ 不要用力漱口
❌ 不要用舌头舔伤口

⚠️ 咬纱布1小时后仍大量出血、血流不止,尽快就医
   (服用抗凝药、抗血小板药的人尤其要注意)
```

## 其他常见问题

### 牙龈出血

- 最常见原因是牙龈炎: 认真刷牙、用牙线,1-2周内通常好转
- **长期缺乏新鲜蔬果时,牙龈肿胀出血可能是坏血病的早期表现**,见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md)
- 伴皮肤瘀斑、流鼻血不止等其他出血,或正在服用抗凝药 → 就医

### 口腔溃疡

- 多数1-2周自愈
- 温盐水漱口,避免辛辣刺激
- ⚠️ **超过2周不愈合的溃疡、白斑、红斑或肿块,一定要就医排除口腔癌**

### 补牙材料脱落

- 保持清洁,避免用这一侧咀嚼硬物和甜食
- 药店有临时补牙材料可以暂时填补
- 尽快看牙医

### 假牙

- 假牙磨伤牙龈: 暂停佩戴,温盐水漱口,溃疡好了再戴
- 夜间取下,清洗后泡在清水中
- 意识不清、需要CPR的人要先取出活动假牙(防止堵塞气道)

## 没有牙膏牙刷时的口腔卫生

**清洁牙齿最关键的是机械清除牙菌斑(刷、擦),牙膏只是辅助。** 没有牙膏,认真刷牙也有效果。

```
没有牙膏:
✓ 清水刷牙,刷够2分钟
✓ 少量食盐或小苏打蘸着刷(不要太用力,以免磨损牙齿)

没有牙刷:
✓ 干净纱布或布条缠在手指上擦牙
✓ 咀嚼刷: 取柳树枝或其他无毒树枝,剥皮后把一端咬成刷毛状,用来刷牙
  (传统做法,只用确认无毒的树种)

✓ 牙线: 没有牙线可以用干净细线代替
✓ 饭后用清水漱口
```

### 预防最重要

```
✓ 每天早晚刷牙,每次2分钟
✓ 少吃甜食、少喝含糖饮料,尤其是睡前
✓ 定期检查,小洞早补(小洞补起来简单,拖成牙髓炎、脓肿就麻烦了)
✓ 儿童: 长出第一颗牙就开始清洁;睡前不要含着奶瓶入睡
✓ 运动时戴护齿(对抗性运动)
```

### 储备建议

```
- [ ] 牙刷(每人多支,约3个月换一支)
- [ ] 含氟牙膏
- [ ] 牙线
- [ ] 临时补牙材料
- [ ] 丁香油(小瓶)
- [ ] 止痛药(布洛芬、对乙酰氨基酚)
- [ ] 无菌纱布
```

## 📝 口腔问题要点

```
1. 面部颈部肿胀扩散、吞咽或呼吸困难 → 急症,立即就医
2. 恒牙撞掉: 捏牙冠、不碰牙根、不用清水冲,15分钟内放回或泡牛奶送医
3. 乳牙撞掉不要放回
4. 不要把阿司匹林放在牙龈上(会烧伤)
5. 消炎药不能治好烂牙,根本解决要靠牙医
6. 口腔溃疡超过2周不愈合要就医
7. 每天刷牙、少吃糖,是最省事的办法
```
