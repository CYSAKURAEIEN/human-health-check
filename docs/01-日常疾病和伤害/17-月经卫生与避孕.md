## 月经用品

灾后、长期断供时,月经用品是女性实际面临的大问题,却常常被应急物资清单忽略。

| 用品 | 特点 | 使用要点 |
|------|------|----------|
| 一次性卫生巾 | 最方便;用完即丢 | 一般每4-6小时更换一次,量多时更勤 |
| 卫生棉条 | 体积小,便于携带 | 按说明书时间更换,不要留置过久(见下方中毒性休克) |
| 月经杯 | 硅胶制成,可反复使用多年,不依赖供应 | 每次清空后清水冲洗;每个经期结束煮沸消毒;按说明书时间清空 |
| 布卫生巾 | 可自制、可反复使用 | 见下节 |
| 月经内裤 | 可反复使用 | 按说明书清洗 |

**长期储备的角度**: 月经杯和布卫生巾不依赖持续供应,适合长期储备。月经杯需要先在平时试用、熟悉。

## 自制可重复使用的布卫生巾

### 材料

```
✓ 吸水层: 纯棉布(旧棉T恤、毛巾布、法兰绒),多层叠用
✓ 外层(贴皮肤): 柔软的纯棉布
✓ 防漏层(可选): 防水布、旧雨衣布、干净的塑料布(放在最底层)
❌ 不要用化纤布作吸水层(不吸水),不要用旧报纸、草木灰、沙土等
```

### 做法

```
1. 剪出卫生巾形状(约长20-25 cm、中间宽约6-7 cm),两侧带护翼
2. 吸水层叠4-6层棉布,剪成稍小的长条
3. 按"外层棉布 + 吸水层 + 防漏层"叠好,沿四周缝合
4. 护翼末端缝上按扣或用别针,绕过内裤固定

最简单的做法: 把几层棉布或毛巾折成长条,垫在内裤上
```

缝纫针法见[纺织、缝补与鞣皮-缝补](../07-日常生活技能/07-纺织缝补与鞣皮.md#缝补)。

### 清洗和保存(最关键)

```
1. 换下后先用冷水浸泡、冲洗(热水会让血渍固定)
2. 用肥皂搓洗干净
3. 清水漂净
4. 在阳光下彻底晒干(阳光能杀灭部分细菌,也能去除潮气)
   - 不要因为不好意思而晾在阴暗处,潮湿会滋生细菌和霉菌,引起感染
   - 可以在上面盖一块薄布遮挡
5. 完全干透后,放在干净干燥的袋子里保存
6. 有条件时定期煮沸

✓ 每人至少准备5-8片,轮换使用
✓ 出现发霉、无法洗净、变薄破损时更换
```

## 月经期的健康问题

### 经期卫生

```
✓ 勤换卫生用品
✓ 每天用清水清洗外阴(从前往后),不需要用洗液冲洗阴道内部
✓ 换卫生用品前后洗手
✓ 有条件时勤换内裤,阳光下晒干
```

### ⚠️ 中毒性休克综合征

一种少见但危险的情况,和卫生棉条、月经杯留置时间过长有关。

```
使用卫生棉条或月经杯期间,突然出现:
- 高热
- 类似重感冒的全身酸痛、头痛
- 呕吐、腹泻
- 头晕、站立时眼前发黑(血压低)
- 晒伤样的皮疹

→ 立即取出棉条或月经杯,立即就医(拨打120)
```

预防: 按说明书时间更换,不要过夜留置棉条;选择能满足需要的最低吸收量。

### 需要就医的情况

```
- 出血量非常大: 连续几个小时每小时就要换一片卫生巾,或有大血块
- 月经期超过7天,或两次月经间隔很短
- 痛经剧烈,吃止痛药也不缓解
- 经期以外出血,或绝经后又出血
- 头晕、乏力、面色苍白(可能贫血,见营养与营养缺乏病)

⚠️ 月经推迟,同时出现下腹剧痛、阴道出血、头晕甚至晕倒
   → 可能是宫外孕破裂,危及生命,立即拨打120
```

相关章节: [营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md)。

痛经可以热敷下腹、适当休息,止痛药使用见[常见疾病-发烧](01-常见疾病.md#发烧)中的药物部分。

## 避孕

在长期缺医少药的情况下,一次计划外的怀孕、一次没有医生在场的分娩,都可能危及母婴生命(见[紧急分娩与新生儿护理](11-紧急分娩与新生儿护理.md))。避孕是保护女性健康的重要部分。

### 常见方法比较

| 方法 | 可靠性 | 特点 |
|------|--------|------|
| 避孕套 | 正确使用时较可靠 | **唯一同时能预防性病的方法**;容易获得和储备 |
| 宫内节育器(上环) | 很可靠 | 一次放置可用多年,适合长期;需医生放置和取出 |
| 皮下埋植 | 很可靠 | 一次放置可用数年;需医生操作 |
| 口服避孕药 | 按时服用时很可靠 | 需每天服用,依赖持续供应;需医生评估是否适合 |
| 哺乳期闭经避孕 | 条件全部满足时较可靠 | 见下方,条件严格 |
| 安全期、体外射精 | **不可靠** | 失败率高,不建议作为主要方法 |

### 避孕套

```
✓ 每次性生活全程使用
✓ 检查有效期,包装破损的不用
✓ 储存在阴凉干燥处,避免高温(不要长期放在钱包、车里)
✓ 只用水性润滑剂
  ❌ 凡士林、婴儿油、食用油等油性物质会使乳胶避孕套破损
✓ 一个只用一次
```

国家基本公共卫生服务向育龄人群免费提供避孕药具,可向社区卫生服务中心、乡镇卫生院咨询领取。

### 哺乳期闭经避孕

产后纯母乳喂养在一定条件下有避孕作用,但**以下三个条件必须同时满足**:

```
1. 产后还没有来月经
2. 纯母乳喂养或几乎全部母乳喂养
   (白天两次喂奶间隔不超过4小时,夜间不超过6小时,不加其他食物)
3. 宝宝不满6个月

任何一个条件不满足 → 立即改用其他避孕方法
```

### 长期生存情境下的考虑

- 宫内节育器、皮下埋植一次放置可以管很多年,不依赖持续供应,如有长期规划,可在医疗条件正常时与医生商量
- 避孕套是最容易储备的方法,注意储存条件和有效期
- 口服避孕药依赖持续供应,断药后避孕作用很快消失

## 紧急避孕

```
适用: 没有采取避孕措施,或避孕失败(避孕套破裂、滑脱)

✓ 紧急避孕药在性生活后72小时内服用,越早越有效
✓ 药店可以买到,按说明书服用
✓ 服药后如果下次月经推迟一周以上,要检查是否怀孕

⚠️ 紧急避孕药只是补救措施,不能代替常规避孕,不要反复使用
⚠️ 服药后出现严重下腹痛,及时就医
```

## 储备建议

```
月经用品:
- [ ] 一次性卫生巾(按每人每月计算,至少几个月的量)
- [ ] 月经杯(平时先试用熟悉)
- [ ] 布卫生巾,或制作布卫生巾的纯棉布、按扣
- [ ] 内裤(多备几条)
- [ ] 肥皂(清洗布卫生巾)

避孕:
- [ ] 避孕套(注意有效期和储存条件)
- [ ] 紧急避孕药(注意有效期)
- [ ] 正在使用口服避孕药的,与医生商量储备

其他:
- [ ] 止痛药(痛经)
- [ ] 补铁食物或补铁剂(月经量多的女性)
```

⚠️ 灾后安置点、集体住宿时,为女性提供可以私下更换和清洗月经用品的地方、可以晾晒的空间和夜间照明,这对女性的健康和安全都很重要。

## 📝 月经卫生与避孕要点

```
1. 月经杯和布卫生巾不依赖供应,适合长期储备
2. 布卫生巾: 纯棉多层;先冷水泡再肥皂洗,阳光下彻底晒干
3. 用棉条或月经杯时突然高热、皮疹、头晕 → 立即取出并就医
4. 月经推迟 + 下腹剧痛 + 出血 → 可能宫外孕,立即120
5. 避孕套是唯一同时预防性病的方法,不用油性润滑剂
6. 安全期、体外射精不可靠
7. 紧急避孕药72小时内服用,越早越好,不能代替常规避孕
```
