## 为什么要重视

在集中安置点、宿舍、长期缺水少洗澡的环境里,疥疮、头虱、皮肤感染传播很快。

它们本身大多不危及生命,但:
- 剧烈瘙痒影响睡眠和精神
- 抓破的皮肤容易继发细菌感染,严重时可发展成蜂窝织炎甚至全身感染
- 一人得病常常全家、全宿舍传染

⚠️ **皮肤感染的危险信号(立即就医)**: 红肿范围迅速扩大、皮肤发烫剧痛、出现红线向上蔓延、发热寒战、皮肤发黑或起血疱。

## 疥疮

由疥螨(一种肉眼几乎看不见的小虫)钻进皮肤引起,通过长时间的皮肤接触(同睡一张床、照顾病人)传播。

### 识别

```
- 剧烈瘙痒,夜间尤其严重
- 小红疙瘩、小水疱,有时能看到弯弯曲曲的细线(疥螨的隧道)
- 好发部位: 手指缝、手腕、肘窝、腋下、腰部、肚脐周围、
  臀部、外生殖器、女性乳房周围
- 婴幼儿可长在头面部、手掌脚掌
- 家里或同住的人也痒
```

### 处理

```
✓ 就医确诊,按医嘱或说明书使用抗疥疮药物(外用药膏为主)
  - 药膏要涂满脖子以下全身皮肤(婴幼儿按医嘱包括头面部),不只涂痒的地方
  - 按规定时间保留后再洗掉,通常需要隔一段时间再治疗一次
✓ **同住的家人、密切接触的人要同时治疗**,即使没有症状
  (否则会反复互相传染)

衣物和床上用品(治疗当天处理):
✓ 用热水洗涤(50-60°C以上),在阳光下晒干或用烘干机高温烘干
✓ 不能洗的东西(毛绒玩具、厚被子、鞋): 装进塑料袋扎紧,存放至少3天
  (疥螨离开人体2-3天后就会死亡)
✓ 地面、沙发吸尘或擦拭

⚠️ 治疗后瘙痒可能还会持续2-4周,这是正常的过敏反应,不一定是没治好
   超过4周仍有新皮疹,复诊
❌ 不要用开水烫皮肤、用盐搓、用强碱肥皂反复洗(会伤皮肤,不能杀虫)
```

## 头虱

### 识别

```
- 头皮发痒,尤其是耳后和后颈
- 头发里能看到小虫(芝麻大小,灰褐色,爬得很快)
- 发根附近粘着白色或黄褐色的小卵(虮子),不像头皮屑那样能轻易弹掉
- 儿童多见,通过头碰头、共用梳子帽子传播
```

### 处理

```
湿梳法(不用药,适合所有人):
1. 洗头后抹上护发素,头发保持湿润
2. 用密齿篦子(专用的虱子梳)从发根梳到发梢,一缕一缕梳
3. 每梳一下,把梳子在白纸巾上擦一下,检查有没有虫
4. 每隔3-4天梳一次,连续2周以上,直到连续几次都梳不到活虱

✓ 也可在药店购买灭虱药,按说明书使用,通常需间隔7-10天再用一次
✓ 家里其他人都要检查,有虱子的同时处理
✓ 近2天用过的帽子、枕套、毛巾、梳子:
  - 热水洗或烫
  - 不能洗的装塑料袋扎紧,存放2周
✓ 剪短头发能让处理更容易

❌ 不要用汽油、煤油、杀虫剂涂头发(有中毒和着火的危险)
```

## 臭虫

```
识别:
- 夜间被咬,早上发现身上有成排或成串的红疙瘩,很痒
- 床垫缝、床板缝、墙缝里能看到扁平的红褐色小虫、黑色的小点(粪便)、蜕下的皮
- 不传播疾病,但严重影响睡眠

处理:
✓ 床单被套用热水洗,高温烘干或暴晒
✓ 床垫、床架的缝隙用开水烫或用吸尘器反复吸
✓ 床脚放在装水的盘子里,防止臭虫爬上床
✓ 严重时请专业消杀
✓ 从外面带回的旧家具、行李先检查

被咬后: 冷敷止痒,不要抓破;止痒药膏或口服抗过敏药
```

## 癣(真菌感染)

| 部位 | 俗称 | 表现 |
|------|------|------|
| 脚 | 脚气、香港脚 | 脚趾缝发白、脱皮、发痒、起水疱 |
| 身体 | 体癣、钱癣 | 圆形或环形的红斑,边缘清楚,有鳞屑,中间颜色较淡 |
| 腹股沟 | 股癣 | 大腿根部红斑、瘙痒 |
| 头皮 | 头癣 | 儿童多见,头皮有片状脱发、断发、鳞屑 |
| 指甲 | 灰指甲 | 指甲增厚、变色、变脆 |

```
处理:
✓ 保持患处干燥、通风(真菌喜欢潮湿闷热)
✓ 药店有抗真菌药膏,按说明书坚持涂,症状消失后再继续涂1-2周
  (过早停药容易复发)
✓ 头癣、灰指甲往往需要口服药,要就医
✓ 不和别人共用毛巾、拖鞋、袜子、梳子
✓ 鞋袜勤换勤晒

❌ 不要用激素药膏(如含"松"字的药膏)涂癣,会让癣扩散
❌ 不要用醋泡、用热水烫
```

## 脓疱疮与皮肤细菌感染

### 脓疱疮(俗称"黄水疮")

```
- 儿童多见,夏季多发
- 口鼻周围、四肢出现水疱、脓疱,破了以后结成蜂蜜色的痂
- 传染性强,通过手抓传播到别处和别人

处理:
✓ 就医,通常需要抗菌药膏,范围大时需口服药
✓ 剪短指甲,避免抓挠
✓ 用肥皂水清洗患处,轻轻去痂
✓ 毛巾、衣物单独使用和清洗
✓ 痊愈前不要去托儿所、学校
```

### 毛囊炎、疖子

- 小的可以热敷,保持清洁
- ❌ 不要用手挤,尤其是鼻子和上唇周围("危险三角区",挤压可能把感染带到颅内)
- 反复发作、范围扩大、发热 → 就医

蜂窝织炎等严重感染的处理见[抗生素制备-天然抗菌物质](../06-制药技术/02-抗生素制备.md#三天然抗菌物质)中的危险征象。

## 痱子、湿疹与尿布疹

```
痱子:
- 炎热出汗多时出现的密集小红疹、小水疱
- 处理: 降温、减少出汗、穿宽松透气的衣服、温水洗澡后擦干
- 婴儿不要包裹太厚

湿疹:
- 皮肤干燥、发红、瘙痒、脱屑,反复发作
- 处理: 用温水洗澡(不要太烫),少用肥皂,洗后立即涂保湿霜
- 严重时就医

尿布疹:
- 婴儿尿布区域发红
- 处理: 勤换尿布,每次用温水清洗后擦干,让屁股多晾一会儿,涂护臀膏
- 出现脓疱、范围扩大、边缘有小红点(可能是真菌感染) → 就医
```

---

## 预防

```
✓ 有条件时定期洗澡、换衣服;缺水时至少用湿毛巾擦洗腋下、腹股沟、脚
✓ 不共用毛巾、梳子、帽子、衣物、拖鞋
✓ 被褥、衣物经常在阳光下晾晒
✓ 剪短指甲,保持清洁
✓ 安置点、宿舍: 床铺之间保持距离;新来的人如有瘙痒、皮疹,尽早检查
✓ 保持皮肤干燥,尤其是脚和皮肤褶皱处
```

传染病的一般防控见[传染病家庭防控](15-传染病家庭防控.md)。

---

## 📝 皮肤病与寄生虫要点

```
1. 疥疮: 夜间剧痒、手指缝等处皮疹;全家同时治疗;
   衣物热水洗,不能洗的装袋扎紧放3天
2. 头虱: 湿梳法;衣物热水洗,不能洗的装袋放2周;不用汽油煤油
3. 臭虫: 热水洗床品,烫或吸缝隙
4. 癣: 保持干燥,抗真菌药膏坚持涂,不用激素药膏
5. 脓疱疮传染性强,要就医,痊愈前不去学校
6. 不挤"危险三角区"的疖子
7. 红肿迅速扩大、红线蔓延、发热 → 立即就医
```
