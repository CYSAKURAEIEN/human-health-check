## 传染病是怎么传播的

| 途径 | 常见疾病 | 防护重点 |
|------|----------|----------|
| 飞沫、空气 | 流感、新冠、肺结核、麻疹、水痘 | 戴口罩、通风、保持距离 |
| 接触(手、物品) | 诺如病毒、手足口病、红眼病 | 洗手、消毒常摸的物品表面 |
| 粪口(脏水、脏手、苍蝇) | 霍乱、痢疾、伤寒、甲肝、诺如病毒 | 洗手、喝开水、吃熟食、管好粪便 |
| 血液、体液 | 乙肝、艾滋病 | 不共用剃须刀牙刷、处理伤口戴手套 |
| 蚊虫 | 疟疾、登革热、乙脑 | 防蚊、清除积水 |

**洗手**是阻断多数传染病最简单有效的方法,方法见[卫生设施-洗手点](../07-日常生活技能/03-卫生设施.md#洗手点)。

## 家里有人得了传染病

### 居家隔离

```
病人:
✓ 尽量住单独的房间,房门关上,开窗通风
✓ 没有单独房间时: 保持1 m以上距离,用帘子隔开,分床睡
✓ 和家人接触时戴口罩
✓ 用自己的毛巾、餐具、水杯
✓ 有条件时使用单独的卫生间;共用时用后消毒

照顾的人:
✓ 尽量固定一个人照顾(最好不是老人、孕妇、慢性病患者)
✓ 进病人房间戴口罩;接触病人的分泌物、呕吐物、粪便时戴手套
✓ 离开房间、摘手套后立即洗手
✓ 自己出现发热等症状,及时就医并告诉医生接触史

家里:
✓ 每天多次开窗通风(每次至少30分钟)
✓ 每天消毒常摸的地方: 门把手、开关、水龙头、马桶按钮、桌面、手机
✓ 病人的衣物、床单单独洗,能用热水的用热水
✓ 病人用过的纸巾、口罩装袋扎紧后丢弃
```

### 什么时候要就医

```
- 高热不退、精神很差
- 呼吸急促、胸闷、嘴唇发紫
- 剧烈呕吐腹泻、出现脱水(尿少、口干、眼窝凹陷)
- 意识改变、抽搐、颈部僵硬
- 皮疹伴发热(尤其是按压不褪色的出血点)
- 婴幼儿、老人、孕妇、有慢性病的人病情加重
```

发热的分级和就医标准见[常见疾病-发烧](01-常见疾病.md#发烧)。

⚠️ 甲类、乙类等法定传染病(如霍乱、肺结核、麻疹)确诊后,按医疗机构和疾控部门的要求隔离和治疗。

## 家用消毒液的配制

### 84消毒液(含氯消毒剂)

以下比例按**有效氯含量约5%**的84消毒液计算。不同品牌浓度不同,**先看瓶子上标的有效氯含量**,浓度不同时按比例调整。

| 用途 | 有效氯浓度 | 84消毒液 : 水 | 举例 |
|------|-----------|---------------|------|
| 日常物体表面、餐具、衣物 | 约500 mg/L | 1 : 100 | 10 mL原液 + 1 L水 |
| 病人用过的物品、有污染的地面、马桶 | 约1000 mg/L | 1 : 50 | 20 mL原液 + 1 L水 |
| 呕吐物、粪便等污染物 | 5000-10000 mg/L | 约1 : 10 到 1 : 5 | 100-200 mL原液 + 1 L水 |

```
使用方法:
✓ 用凉水或常温水稀释(热水会让有效成分分解,还会释放更多刺激性气体)
✓ 现配现用,配好的稀释液当天用完
✓ 擦拭或浸泡后作用约30分钟,再用清水擦净或冲净
  (金属物品、餐具、衣物消毒后要用清水冲洗干净)
✓ 戴手套,开窗通风

处理呕吐物、粪便:
1. 戴手套、口罩
2. 用纸巾、抹布等一次性吸水材料蘸取高浓度消毒液,完全覆盖住污染物
3. 作用30分钟后,小心清除,装袋扎紧丢弃
4. 再用1:50的消毒液擦拭消毒污染过的地面和周围
5. 摘手套,洗手

⚠️ 安全:
❌ 绝不能和洁厕灵等酸性清洁剂混用(产生氯气,见中毒-清洁剂中毒)
❌ 不要用于皮肤、伤口
❌ 不要用饮料瓶装稀释液;贴上标签,放在儿童拿不到的地方
⚠️ 对金属有腐蚀性,对衣物有漂白作用(深色衣物会褪色)
```

相关章节: [中毒-清洁剂中毒](12-中毒.md#清洁剂中毒)。

### 其他消毒方法

| 方法 | 用法 | 注意 |
|------|------|------|
| 煮沸 | 餐具、毛巾、奶瓶等耐热物品,水开后煮15分钟以上 | 简单可靠,停电断供时首选 |
| 75%酒精 | 擦拭手、小件物品、手机 | 易燃,不能大面积喷洒;**对诺如病毒效果差** |
| 日晒 | 被褥、衣物在强烈阳光下暴晒数小时 | 只能辅助,不能代替消毒 |

酒精的自制和浓度见[消毒剂制备](../06-制药技术/01-消毒剂制备.md)。

## 腹泻类传染病

诺如病毒、霍乱、痢疾、伤寒、甲肝等通过粪口传播,在停水、洪水后、人员聚集的安置点特别容易暴发。

```
预防:
✓ 只喝煮沸的水或安全的瓶装水
✓ 食物煮熟煮透,生熟分开,剩饭菜彻底加热
✓ 饭前便后洗手(用肥皂和流动水)
✓ 管好粪便,厕所远离水源(见卫生设施)
✓ 消灭苍蝇
✓ 病人不要给别人做饭

有人腹泻、呕吐时:
✓ 及时补液,首选口服补液盐(见常见疾病-腹泻)
✓ 呕吐物、粪便按上方方法用高浓度消毒液处理
✓ 病人的餐具煮沸消毒
✓ 病人症状消失后至少2-3天内仍有传染性,仍要注意洗手、不做饭

⚠️ 大量水样腹泻(像淘米水)、短时间内迅速脱水 → 可能是霍乱,立即就医并报告
⚠️ 同一家庭、同一集体多人同时腹泻 → 报告当地疾控或卫生院
```

相关章节: [卫生设施](../07-日常生活技能/03-卫生设施.md)、[常见疾病-腹泻](01-常见疾病.md#腹泻)。

## 呼吸道传染病

```
✓ 咳嗽、打喷嚏时用纸巾或肘部遮挡,纸巾扔进垃圾桶后洗手
✓ 有症状时戴口罩,少去人多的地方
✓ 室内经常开窗通风
✓ 流感季节,老人、儿童、慢性病患者尽量避免去人多密闭的场所

⚠️ 肺结核:
- 咳嗽、咳痰超过2周,或痰中带血,伴低热、夜间出汗、消瘦
  → 尽早到医院或结核病防治机构检查
- 肺结核可以治愈,但必须按医嘱完成全部疗程(通常半年以上),
  中途停药容易产生耐药
- 国家对肺结核患者有免费检查和治疗的政策,可向当地结核病防治机构咨询
```

---

## 疫苗

```
✓ 儿童按时完成国家免疫规划疫苗(免费)
✓ 老人、慢性病患者每年接种流感疫苗(有条件时)
✓ 被动物咬伤后接种狂犬病疫苗(见外伤处理-咬伤)
✓ 受伤后按需接种破伤风疫苗(见外伤处理-破伤风预防)
✓ 保存好疫苗接种记录(灾后搬迁时也要带上)
```

相关章节: [外伤处理-咬伤](02-外伤处理.md#咬伤)、[外伤处理-破伤风预防](02-外伤处理.md#破伤风预防)。

## 📝 传染病家庭防控要点

```
1. 勤洗手是最有效的方法
2. 病人单独房间、戴口罩、分开餐具毛巾;固定一人照顾
3. 每天开窗通风,消毒常摸的地方
4. 84消毒液(有效氯5%): 日常1:100,有污染1:50,呕吐物粪便约1:10到1:5
5. 84消毒液用凉水配、现配现用、不和洁厕灵混用
6. 酒精对诺如病毒效果差,煮沸是最可靠的消毒方法
7. 喝开水、吃熟食、管好粪便、消灭苍蝇
8. 咳嗽超过2周去查结核
```
