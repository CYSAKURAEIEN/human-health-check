## 中风

中风(脑卒中)分两类: 血管堵塞(缺血性,约占八成)和血管破裂(出血性)。两者在现场无法区分,只能靠医院的CT判断。

### 识别: "中风120"口诀

```
1 - 看一张脸: 让患者微笑,一侧嘴角下垂、脸不对称?
2 - 查两只手臂: 让患者闭眼、双臂平举10秒,一侧无力下垂?
0 - 聆(零)听语言: 让患者重复一句简单的话,吐字不清、说不出、听不懂?

出现任何一项 → 立即拨打120
```

**其他常见表现**:
- 突发一侧肢体麻木
- 突发一只眼或双眼看不清、看东西重影
- 突发行走不稳、眩晕
- 突发剧烈头痛(出血性中风常见)

⚠️ **症状可能在几分钟后自行消失(短暂性脑缺血发作),这同样是急症!** 这类发作之后短期内发生真正中风的风险很高,也要立即就医。

### 为什么分秒必争

- 缺血性中风的静脉溶栓,一般需在**发病4.5小时内**进行
- 越早治疗,脑组织损伤越少,后遗症越轻
- 拨打120而不是自己开车: 急救车可提前通知医院卒中中心准备,并能直接送往有溶栓条件的医院

### 等待救护车时

```
✓ 记下发病时间(或最后一次看到患者正常的时间)
  - 这是医生决定能否溶栓的关键信息!
  - 早上醒来才发现的,以前一晚入睡时间计
✓ 让患者躺下,头和肩部稍垫高
✓ 呕吐或意识不清 → 侧卧位(防误吸)
✓ 松开衣领、腰带
✓ 准备好患者的用药清单
```

### ❌ 不要做

```
❌ 不要给阿司匹林或任何药物
   - 现场无法区分缺血性还是出血性
   - 出血性中风服用阿司匹林会加重出血
❌ 不要喂水、喂食
   - 中风常伴吞咽困难,易呛入气管
❌ 不要掐人中、扎手指放血、针刺"十宣"
   - 没有治疗作用,只会耽误时间
❌ 不要等"看看会不会好转"
❌ 不要自行开车送医(除非确实无法叫到救护车)
```

## 心梗与胸痛

### 识别心梗

**典型症状**:
- 胸口正中压榨感、紧缩感、沉重感(像被大石压住)
- 持续超过几分钟,休息不缓解
- 可向左臂、下巴、颈部、后背放射
- 伴大汗、恶心、气短、头晕、濒死感

**⚠️ 不典型症状**(女性、老人、糖尿病患者常见):
- 只有上腹痛(易误认为胃病)
- 只有气短、乏力
- 只有牙痛、下颌痛、肩背痛
- 疼痛很轻甚至没有

**有心脏病史、高血压、糖尿病、吸烟的人,出现上述任何不明原因的不适,都要按心梗对待。**

### 立即处理

```
1. 立即停止一切活动
   - 不要走动、不要自己走去医院或爬楼梯
2. 坐下或半卧位(靠着休息)
3. 拨打120,说明"疑似心梗"
4. 松开衣领、腰带
5. 考虑嚼服阿司匹林(见下方条件)
6. 有AED时准备好;一旦倒地无反应、无正常呼吸 → 立即CPR
```

### 阿司匹林: 何时可以用

**做法**:
- 嚼碎后吞服(比整片吞服吸收快)
- 剂量: 300 mg(不确定时可先电话询问120调度员)
- 普通片优于肠溶片;只有肠溶片时同样嚼碎

**以下情况不要用**:
```
❌ 对阿司匹林过敏(或服用后哮喘发作)
❌ 正在出血,或有活动性胃溃疡、出血性疾病
❌ 怀疑主动脉夹层: 突发撕裂样剧痛,向后背放射
❌ 同时有中风表现(口角歪斜、肢体无力、言语不清)
❌ 孕妇
❌ 18岁以下
```

### 硝酸甘油

```
✓ 仅限医生已为该患者开具的情况下使用
✓ 舌下含服,不要吞服
❌ 血压低、头晕眼前发黑时不要用
❌ 24-48小时内服用过治疗勃起功能障碍药物(如西地那非)的不要用
   - 两者合用可致血压骤降
❌ 不要用别人的硝酸甘油
```

### 其他危险的胸痛

| 类型 | 特点 | 处理 |
|------|------|------|
| 主动脉夹层 | 突发撕裂样剧痛,向后背放射 | 120,**不要给阿司匹林** |
| 肺栓塞 | 突发气短、胸痛,常在久坐久卧后、单侧腿肿 | 120 |
| 气胸 | 突发一侧胸痛、气短,瘦高年轻人或胸部外伤后 | 120 |

**原则: 突发、剧烈或伴气短大汗的胸痛,一律按急症处理,不要自行判断"是胃病"。**

## 低血糖

主要发生在使用胰岛素或降糖药的糖尿病患者身上。血糖低于3.9mmol/L即为低血糖。

### 识别

**早期**:
- 心慌、手抖、出汗
- 强烈饥饿感
- 面色苍白
- 烦躁、焦虑

**加重**:
- 意识模糊、反应迟钝
- 说话含糊、行为异常(**常被误认为醉酒或中风**)
- 抽搐、昏迷

⚠️ **糖尿病患者出现异常行为或意识改变,先想到低血糖。** 无法判断是高血糖还是低血糖时,按低血糖处理更安全: 补一次糖对高血糖影响不大,而低血糖不处理会很快危及生命。

### 处理: 能吞咽时

**"15-15"原则**:
```
1. 吃15-20 g快速升糖的食物:
   - 葡萄糖片 3-4片
   - 果汁或含糖饮料 150 mL左右(⚠️ 不能是无糖/零度饮料)
   - 白糖或蜂蜜 1汤匙
   - 糖果 几颗(硬糖,非巧克力)
2. 等15分钟
3. 有血糖仪就复测;仍低于3.9或症状未缓解 → 重复第1步
4. 缓解后吃一份含淀粉的食物(面包、饼干、米饭)
   - 防止再次降低

注意:
- 巧克力、牛奶、坚果含脂肪,升糖慢,不适合急救
- 服用长效胰岛素或磺脲类降糖药者,低血糖可反复出现,应就医观察
```

### 处理: 意识不清、不能吞咽时

```
❌ 不要往嘴里喂任何东西(易呛入气管窒息)
1. 拨打120
2. 侧卧位(恢复体位)
3. 有胰高血糖素注射笔/鼻喷剂、且受过使用培训的,按说明使用
4. 持续观察呼吸,无呼吸 → CPR
```

## 癫痫发作

### 识别

全身发作的典型表现:
- 突然倒地、意识丧失
- 全身僵直,随后四肢节律性抽动
- 可能口吐白沫、咬破舌头、尿失禁
- 大多数在1-2分钟内自行停止
- 停止后常有一段时间意识模糊、困倦

### 发作时

```
✓ 记下开始时间(判断是否需要叫救护车的关键)
✓ 移开周围的硬物、尖锐物
✓ 在头下垫衣物等软物
✓ 松开衣领
✓ 抽动停止后,翻成侧卧位(恢复体位)
✓ 陪在身边,直到完全清醒
```

### ❌ 不要做

```
❌ 不要往嘴里塞任何东西(筷子、勺子、毛巾、手指)
   - 舌头不会被"吞下去"
   - 塞东西反而会弄断牙齿、造成窒息,救助者手指也会被咬伤
❌ 不要强行按住肢体(可致骨折、脱臼)
❌ 不要掐人中
❌ 完全清醒前不要喂水、喂药
```

### ⚠️ 立即拨打120

- 抽搐超过5分钟
- 一次发作后未清醒又再次发作
- 第一次发作
- 发作后呼吸不恢复正常,或长时间不清醒
- 发作中受伤
- 在水中发作
- 孕妇、糖尿病患者

### 儿童高热惊厥

- 多见于6个月至5岁儿童,发烧时出现
- 处理同上,同时松开衣物降温
- 多数短暂、预后良好,但**首次发生必须就医**,排除脑膜炎等严重疾病
- 发烧的护理见[常见疾病-发烧](01-常见疾病.md#发烧)

## 哮喘急性发作

### 识别

- 喘息(呼气时有哨音)、胸闷
- 呼吸困难,呼气费力
- 咳嗽

**⚠️ 危险信号**(立即拨打120):
- 说话无法说完一句话
- 嘴唇、指甲发紫
- 极度疲惫、意识模糊
- 喘息声反而减弱("沉默肺",气流已极少,非常危险)

### 处理

```
1. 让患者坐直(不要躺下),身体略前倾,保持冷静
2. 松开衣领
3. 使用患者自己的缓解型吸入剂(通常为蓝色,如沙丁胺醇):
   - 每30-60秒吸1喷
   - 最多10喷
   - 有储雾罐时配合使用,效果更好
4. 10喷后无好转或任何时候加重 → 拨打120
5. 等救护车超过10分钟仍无好转 → 重复第3步
```

**即使用药后缓解,当天也要就医复查。**

⚠️ 没有吸入剂时,没有有效的家庭替代方法: 让患者坐直、保持冷静,立即拨打120。

如果是过敏引起的(接触过敏原后突发喘憋,伴皮疹、面部肿胀),按[过敏性休克](05-急性症状.md#过敏反应)处理。

## 📝 总结要点

### 这几种情况的共同点

```
- 都是突发的
- 都和时间赛跑
- 都有流传很广的错误做法(塞东西、掐人中、放血、乱喂药)
```

### 一张表记住

| 情况 | 关键识别 | 第一反应 | 最常见的错误 |
|------|----------|----------|--------------|
| 中风 | 脸歪、手臂无力、说话不清 | 120,记下发病时间 | 给阿司匹林、喂水、放血 |
| 心梗 | 胸口压榨痛,大汗 | 停止活动,120,条件允许嚼服阿司匹林 | 自己走去医院、当成胃病 |
| 低血糖 | 糖尿病患者心慌出汗、行为异常 | 能吞咽就补糖 | 当成醉酒,或给昏迷者喂糖水 |
| 癫痫 | 倒地抽搐 | 护头、计时、侧卧 | 往嘴里塞东西 |
| 哮喘 | 喘息、说话困难 | 坐直,用吸入剂 | 让患者躺下 |

### 预防

- 高血压、糖尿病、心脏病患者按时服药,定期复查
- 糖尿病患者随身带糖和病情卡
- 哮喘患者随身带缓解型吸入剂
- 家人学会识别以上症状,并参加CPR培训
