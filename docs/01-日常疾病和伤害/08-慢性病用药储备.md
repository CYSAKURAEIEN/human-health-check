## 为什么要提前储备

地震、洪水、台风、封路、长期停电,都可能让人几天到几周无法去医院或药房。对于需要每天吃药的慢性病患者,**断药本身就可能是一场急症**。

历次大灾后,医疗队面对的大量病人不是外伤,而是高血压、糖尿病、哮喘等慢性病因断药而急性加重。

```
储备的三个目标:
1. 手头随时保有足够的药(至少能撑到下一次取药,再加一段缓冲)
2. 任何一位医生拿到你的信息,都能接着给你开药(用药信息卡)
3. 能在家监测病情(血压计、血糖仪)
```

⚠️ **本章不提供任何药物的剂量或调整方案。** 所有用药请遵医嘱;储备的数量、断药时怎么办,都应提前和自己的医生商量。

## 突然停药最危险的几类药

不同的药,断了以后的风险差别很大。以下几类**突然停用可能危及生命**,储备时要优先保证:

| 药物类别 | 常见用途 | 突然停用的风险 |
|----------|----------|----------------|
| **胰岛素** | 1型糖尿病、部分2型糖尿病 | 1型糖尿病患者断胰岛素,可在1-2天内发生酮症酸中毒,不及时救治会致命 |
| **抗癫痫药** | 癫痫 | 发作频繁,甚至出现持续不停的抽搐(癫痫持续状态) |
| **糖皮质激素**(长期口服,如泼尼松) | 风湿免疫病、哮喘、肾病、肾上腺功能不全等 | 长期服用后自身肾上腺功能被抑制,突然停用可致肾上腺危象: 低血压、休克 |
| **β受体阻滞剂**(如美托洛尔) | 高血压、冠心病、心衰、心律失常 | 心率反跳性加快、血压升高,可诱发心绞痛、心梗 |
| **可乐定** | 高血压 | 停药后1-2天内血压反跳性急剧升高 |
| **抗血小板药**(放了心脏支架后) | 冠心病支架术后 | 支架内形成血栓,导致心梗 |
| **抗凝药**(如华法林及新型口服抗凝药) | 房颤、静脉血栓、机械心脏瓣膜 | 血栓、中风 |
| **镇静催眠药、抗焦虑药**(如苯二氮䓬类) | 失眠、焦虑 | 长期服用后突然停用可出现严重戒断反应,甚至抽搐 |
| **抗精神病药、抗抑郁药** | 精神疾病 | 病情复发;部分抗抑郁药停用后出现头晕、情绪波动等停药反应 |
| **抗病毒药**(如艾滋病抗病毒治疗) | HIV感染 | 病毒反弹,产生耐药 |
| **抗排异药** | 器官移植术后 | 排异反应 |

**其他常见慢性病用药**(断药风险相对较慢,但同样重要):
- 一般降压药: 血压逐渐升高,增加中风、心梗风险
- 口服降糖药: 血糖逐渐升高
- 甲状腺素(甲减): 数周后症状逐渐加重;甲亢用药停用后易复发
- 哮喘控制药(吸入激素): 发作增多,见[哮喘急性发作](06-心脑血管与突发病症.md#哮喘急性发作)

**家里有人用上表中的药,就把这类药列为储备的第一优先。**

## 怎样合法地多备一些药

### 长期处方

国家卫健委《长期处方管理规范(试行)》规定:
- 适用于诊断明确、用药方案稳定、病情控制平稳的慢性病患者
- 处方量一般在4周内,有条件的地区可根据慢性病特点延长,**最长不超过12周**
- 胰岛素可以开长期处方

```
做法:
✓ 复诊时主动问医生: "我的情况能不能开长期处方?"
✓ 告诉医生你的实际顾虑(如居住偏远、交通不便、家中有老人需照顾)
✓ 了解当地医保对长期处方的报销规定
```

⚠️ **以下药品不能开长期处方**: 麻醉药品,第一、二类精神药品(多数安眠药、抗焦虑药属于此类),医疗用毒性药品,大部分抗菌药物,静脉用药等。

这类药恰恰有不少突然停用会出问题(见上表),**更需要提前和医生商量**: 万一一段时间无法取药,应该怎样处理。

### 建立缓冲

```
原理: 在药还没吃完时就提前续方取药,让手头始终多出一段时间的量

1. 每次复诊时,都在药还剩约1-2周时就去
2. 新取的药放后面,先吃旧的(先进先出)
3. 逐渐积累,让手头常备量达到1-3个月
4. 每次取药核对有效期

❌ 不要通过非法渠道购买处方药(来源不明、可能是假药)
❌ 不要囤积远超需要的量(药会过期,也占用公共资源)
```

### 分散存放

- 家中主储备(按[储存条件](../06-制药技术/02-抗生素制备.md#64-储存条件)保存)
- 随身包里: 3-7天的量
- 应急包里: 至少1周的量(见[灾难应对-家庭应急包](../02-灾难应对/README.md#-家庭应急包))
- 外出、旅行时多带几天

## 胰岛素等需要冷藏的药

### 胰岛素储存

| 状态 | 储存条件 | 期限 |
|------|----------|------|
| 未开封 | 冰箱冷藏 2-8°C | 到包装上的有效期 |
| 已开封(正在使用) | 室温,不超过30°C,避光 | 一般28天(不同产品有差异,以说明书为准),到期丢弃 |
| 任何状态 | ❌ **绝不能冷冻** | 冻过的胰岛素即使化开也不能再用 |

```
⚠️ 不要放在冰箱冷冻室附近或贴着冰箱后壁(容易结冰)
⚠️ 不要放在阳光直射处、车里、暖气旁
⚠️ 外观异常一律不用: 本应清澈的变浑浊,有颗粒、结块、变色
```

### 停电时

```
✓ 已开封的笔芯本来就在室温保存,短期停电影响不大
✓ 未开封的储备: 优先保持阴凉
  - 尽量少开冰箱门,冰箱可保持低温数小时
  - 放在家中最凉快的地方(地下室、北面房间)
  - 用凉水浸湿毛巾包裹容器,利用蒸发降温
  - 简易蒸发冷却罐: 大陶罐里套小陶罐,两罐之间填湿沙并保持湿润,
    胰岛素放在内罐中,罐口盖湿布,放在阴凉通风处
✓ 有条件时准备胰岛素专用冷藏包(遇水降温型或带冰袋型)

❌ 不要把胰岛素直接贴着冰块或冰袋(会冻坏)
```

### 1型糖尿病患者的储备要更充足

- 胰岛素是1型糖尿病患者的生命线,断药1-2天即可危及生命
- 同时储备: 针头、血糖仪试纸、采血针、酮体试纸
- 储备低血糖急救用品(葡萄糖片等,见[低血糖](06-心脑血管与突发病症.md#低血糖))
- 与医生提前商量: 如果胰岛素不足,应如何处理

### 其他需要冷藏或特殊储存的药

部分生物制剂、注射剂、滴眼液需要冷藏或开封后很快过期,储备困难。**请咨询医生是否有更易储存的替代方案。**

## 用药信息卡

灾难中可能见不到自己的医生,也可能药盒丢失。一张写清楚的卡片,能让任何医生迅速接着给你开药。

```
用药信息卡(每位慢性病患者一张):

姓名:                 出生日期:
血型:                 体重:
诊断: (如"2型糖尿病""高血压""癫痫")

正在使用的药物(每种一行):
- 药名(写通用名,不只写商品名):
  剂量:     每天几次:     开始时间:
- ...

过敏史: (药物、食物)
重要病史: (如心脏支架、器官移植、长期服用激素)
主治医生/医院/电话:
紧急联系人/电话:

更新日期:
```

```
✓ 写通用名(如"二甲双胍"),不同厂家的商品名各地可能不一样
✓ 复印或拍照,一份随身、一份放应急包、一份发给家人
✓ 每次换药都更新
✓ 保留最近的病历、处方、检查报告(拍照存手机)
```

## 监测工具

在无法就医的时期,能在家判断病情是否失控,非常关键。

```
- [ ] 血压计(电子上臂式,备用电池)
- [ ] 血糖仪 + 足量试纸 + 采血针(试纸有有效期,注意轮换)
- [ ] 体温计
- [ ] 体重秤(心衰患者体重短期内增加提示水肿加重)
- [ ] 记录本: 每天记录血压、血糖等,就医时带给医生
```

**需要定期化验调整剂量的药**(如华法林需要定期查凝血指标): 断了化验同样危险,提前和医生商量长时间无法化验时怎么办。

## 药快用完时

```
✓ 尽早想办法,不要等到最后一片
  - 灾后临时医疗点、救援医疗队、附近任何医院和药房
  - 带上用药信息卡和药盒
✓ 告诉医生你最近一次服药的时间和剩余量
✓ 优先保证上表中"突然停药最危险"的那几类药

❌ 不要自行减量、隔天吃来"拉长"使用时间,除非医生明确告诉你可以这样做
   (有些药可以,有些药减量和停药一样危险)
❌ 不要吃别人的药,即使"症状一样""药名差不多"
❌ 不要因为"感觉好了"就停药
```

## 📝 慢性病用药储备要点

```
1. 先找出家里"突然停药最危险"的药: 胰岛素、抗癫痫药、长期激素、
   β受体阻滞剂、支架后抗血小板药、抗凝药、镇静催眠药等
2. 和医生商量长期处方(最长12周),提前续方积累1-3个月缓冲
3. 胰岛素冷藏不冷冻,开封后室温不超过30°C,约28天
4. 每位患者一张用药信息卡,写通用名,多处存放
5. 备好血压计、血糖仪
6. 断药前尽早就医,不要自行减量,不要吃别人的药
```
