## 眼睛异物

### 常见异物

- 灰尘、沙子
- 睫毛
- 小虫
- 木屑、金属碎片

### 症状

- 刺痛、异物感
- 流泪
- 发红
- 眨眼频繁
- 视力模糊

**怎样判断严重程度**:

| 情况 | 多半是 | 怎么办 |
|------|--------|--------|
| 风吹进沙子,眨眼流泪后好转 | 浅表异物 | 按下面方法冲洗 |
| 异物感一直不消,但看不见东西 | 异物藏在上眼皮内侧,或角膜被划伤 | 冲洗;仍不好转当天就医 |
| 打磨、敲击金属或劈柴时有东西"打"进眼里 | 高速飞溅物,可能嵌入或刺穿眼球 | **不要自己取**,遮盖后立即就医 |
| 眼球表面能看到黑点、锈点 | 嵌入角膜的金属屑 | 不要自己挑,就医 |
| 眼睛变形、流出透明胶冻样液体、瞳孔变形 | 眼球破裂 | 按下面"眼球被刺伤"处理,立即送医 |

### 处理方法

#### 浅表异物(灰尘、睫毛)

```
1. 洗手
2. 不要揉眼!
   (揉眼会让沙粒在角膜上来回划,把小问题变成角膜擦伤)
3. 先让眼睛自己排出:
   - 闭眼1-2分钟,让眼泪积聚,再轻轻眨眼
   - 多数灰尘、睫毛会随眼泪流到内眼角,用干净的湿纸巾一角蘸走
4. 冲洗:
   - 用清水持续冲洗眼睛,冲到异物感消失(一般几分钟)
   - 头偏向患眼一侧,从内眼角向外眼角冲(免得冲进另一只眼)
   - 用杯子、干净的瓶子慢慢倒,或在水龙头下用细水流
   - 或将脸浸入一盆清水中,睁眼眨动
   - 戴隐形眼镜的,先取出眼镜再冲
5. 拉动眼皮:
   - 向下看,捏住上眼皮睫毛,轻轻拉起盖住下眼皮
   - 让下睫毛刷掉上眼皮内的异物
6. 如能看见异物:
   - 用湿润的棉签轻轻粘除
   - 仅限于眼白部分
   - 翻下眼皮(向上看,轻拉下眼皮)看看下方有没有

做对了的标志: 异物感消失,视力正常,1-2小时内红和流泪明显减轻。
异物取出后仍持续疼痛、怕光、流泪 → 可能角膜被划伤了,需要就医。
```

用什么水冲: 自来水、凉开水、瓶装水都可以;生理盐水更舒服但不是必需。没有干净水时,用能找到的最干净的水,别因为找水耽误。

#### ❌ 禁止

```
- 揉眼睛
- 用干棉签或硬物接触眼球
- 试图取出嵌入的异物
- 触碰角膜(黑眼球)
- 用舌头舔眼睛(口腔细菌会引起感染)
- 自行使用含激素的眼药水
```

#### 金属屑、木屑等高速飞溅物

```
打磨、切割、锤击金属,劈柴、除草时飞进眼里的碎片,
速度很快,可能嵌入角膜甚至穿进眼球里面,表面看伤口很小。

1. 不要揉、不要冲压力大的水、不要自己挑
2. 用干净纱布或布轻轻盖住
3. 当天就医(铁屑嵌入几小时后会生锈,形成锈环)
4. 告诉医生当时在做什么(敲击金属时要查有没有碎片进入眼内)

预防: 打磨、錾切、锤击、劈柴时戴护目镜。
```

打磨和机械加工的安全防护见[钳工与机械加工](../05-冶金技术/09-钳工与机械加工.md)。

#### 眼球被刺伤或扎入异物

```
⚠️ 这是眼科急症,目标是保住眼球,不是在现场把东西取出来

1. 让伤者躺平或半躺,保持安静,不要低头、不要用力
2. 不要拔出扎在眼上的东西,不要冲洗,不要按压眼球
3. 保护:
   - 用纸杯、剪开的塑料瓶底罩住伤眼,杯沿贴在眼眶骨上,用胶布固定
   - 杯子不能碰到眼球和异物
   - 另一只眼也盖上(两眼是一起转动的,盖住好眼能减少伤眼转动)
4. 不要吃喝(可能需要手术麻醉)
5. 拨打120或立即送医院眼科
```

### ⚠️ 立即就医

- 异物嵌入眼球
- 金属或木头碎片
- 化学物质溅入(先冲洗15-20分钟,再就医)
- 眼球受撞击
- 疼痛剧烈
- 视力明显下降
- 无法取出异物
- 取出后仍不适

### 化学品入眼(紧急!)

```
立即处理:
1. 立即冲洗! 不要延误!
   (找什么都没有冲水重要;先冲,再打电话、再找容器)
2. 流动清水冲洗至少15-20分钟
3. 翻开眼睑冲洗
4. 持续冲洗,同时拨打急救电话
5. 带上化学品容器或标签
6. 就医

注意:
- 酸碱伤害都严重
- 时间就是视力!
- 越早冲洗越好
```

**怎样冲洗才有效**:

```
1. 让伤者躺下或侧头,伤眼在下方(脏水不会流进好眼)
2. 用两根手指把上下眼皮撑开——伤者会因为疼痛死死闭眼,
   必须帮他撑开,否则水根本进不了眼里
3. 水流从内眼角冲向外眼角,水流要大、压力要小
   (水龙头开小,或用水壶、瓶子不停地倒)
4. 冲洗时让伤者上下左右转动眼球,冲到眼皮下的角落
5. 戴隐形眼镜的: 冲几分钟后取出镜片,再继续冲
6. 两只眼都溅到时,两只眼都冲
7. 冲满时间后,仍有疼痛就继续冲;送医路上能冲就继续冲
```

| 化学品 | 举例 | 特点 |
|--------|------|------|
| 碱 | 石灰、水泥、管道疏通剂、烧碱、草木灰水、碱水 | **比酸更危险**: 会不断向深处渗透,刚开始不太疼也可能很严重,冲洗时间宜更长 |
| 酸 | 洁厕灵、电池液、硫酸 | 很疼,但多数伤害较表浅;强酸同样可能致盲 |
| 其他刺激物 | 84消毒液、洗洁精、辣椒、汽油 | 冲洗后多数好转;仍疼痛、视物模糊就就医 |

#### 石灰、水泥等粉末入眼

```
生石灰遇水剧烈放热:
1. 先用干净的干布、棉签把眼周和眼皮上的干粉轻轻刷掉
2. 再用大量清水冲洗(同上,至少15-20分钟)
3. 一定要就医——石灰烧伤最初常被低估
```

```
❌ 不要用醋、牛奶、苏打水等"中和"(中和反应放热,而且耽误冲洗)
❌ 不要先找药水,不要只冲一两分钟
❌ 冲洗后不要包扎压迫眼睛
```

农药、清洁剂中毒的全身处理见[中毒](12-中毒.md#中毒的通用处理原则)。

## 耳朵异物

### 常见异物

- 小虫
- 小珠子、玩具零件(儿童)
- 棉花、纸团
- 食物
- 豆子、种子(儿童)
- 纽扣电池(儿童,危险)

### 症状

- 耳痛
- 听力下降
- 耳鸣
- 不适感
- 分泌物(虫子活动)

活虫在耳朵里爬动、扑打时会有很响的声音和剧痛,人会非常惊慌——先让他安静坐下,这不是会危及生命的情况。幼儿可能说不清,只是反复抓耳朵、哭闹,或者一侧耳朵流出有臭味的分泌物。

### 处理方法

#### 活虫入耳

```
0. 可以先试: 在暗处用手电筒照耳道口,有的虫子会循光爬出来
1. 倾斜头部(患耳向上)
2. 滴入:
   - 温植物油(橄榄油、婴儿油)
   - 或温水
   - 数滴即可
   - 温度接近体温: 滴一滴在手腕内侧试,不烫不凉
     (太凉或太热的液体进入耳道会引起剧烈眩晕、呕吐)
   - 成人把耳廓向后上方拉,儿童向后下方拉,耳道变直,油更容易流进去
3. 虫子会浮出或死亡
4. 倾斜头部(患耳向下)让其流出
5. 如未流出,就医取出
   (死虫留在耳道里也要取,否则会引起感染)

⚠️ 以下情况不要往耳里滴任何液体:
- 耳朵流血、流脓,或刚受过外伤、爆炸冲击
- 以前有鼓膜穿孔、做过鼓膜置管
- 耳内是纽扣电池或豆类
```

#### 可见异物

```
如果能看到且靠近外耳:
1. 倾斜头部(患耳向下)
2. 轻拍对侧头部
3. 可能掉出

或:
- 用镊子(非常小心!)
- 仅限于能完全看到的异物
- 在外耳道口部位
- 只夹软的、有边角能夹住的东西(纸团、棉花)
- 圆而光滑的东西(珠子、豆子)不要夹,一夹就往里滑
- 孩子不配合、乱动时不要尝试
```

#### 豆类、种子等会吸水膨胀的异物

```
- 绝对不要滴水、滴油
  (豆子吸水后膨胀,会卡得更紧、更疼,更难取)
- 头偏向患侧,轻拍对侧,掉不出来就去医院耳鼻喉科
- 不算急症,但应在1-2天内取出
```

### ❌ 禁止

```
- 用棉签或硬物掏耳
- 掏得更深(可能推得更深)
- 冲洗(除非是活虫)
- 盲目使用镊子
- 自行处理深部异物
```

外耳道很窄,深处就是鼓膜,用发夹、火柴棍等硬物去够,很容易把异物推到鼓膜上,或者戳破鼓膜。

### ⚠️ 立即就医

- 异物在耳道深处
- 电池(会腐蚀,紧急!)
- 尖锐物体
- 耳痛剧烈
- 流血
- 听力明显下降
- 自行取不出
- 眩晕、走路不稳、面部歪斜(可能伤到内耳或神经)

## 鼻子异物

### 常见(儿童多见)

- 小玩具、珠子
- 食物
- 纸团、棉花
- 小电池(危险!)

### 症状

- 单侧鼻塞
- 鼻涕(可能有臭味、血丝)
- 呼吸困难
- 鼻痛

孩子往鼻子里塞东西后常常不敢说。**只有一侧鼻孔**长期流脓臭鼻涕、带血丝,或者有一股说不清来源的口臭,要想到鼻腔异物,让医生检查。

### 处理方法

#### 可见异物

```
方法1: 擤鼻子
1. 压住健侧鼻孔
2. 轻轻从患侧擤鼻子
3. 不要太用力
   (适合大一点、会擤鼻涕的孩子和成人;
    先用嘴吸一口气,闭嘴,再从患侧鼻孔用力呼出)

方法2: 亲吻法(儿童)
1. 压住健侧鼻孔
2. 家长对孩子嘴巴快速吹气
3. 气流可能将异物冲出
   具体: 孩子躺平或坐在家长腿上,
   家长用嘴完全包住孩子的嘴,
   像吹气球一样短促地吹一口气(不要连续长吹)。
   孩子会本能地闭上会厌,气流只能从鼻子走,把异物推出来。
   可试2-3次,不行就去医院。
   事先告诉孩子"像亲亲一样",能减少孩子挣扎。

方法3: 镊子(仅外部可见)
- 非常小心
- 仅限于鼻孔口
- 圆而光滑的东西不要夹
```

#### 纽扣电池和磁铁入鼻

```
- 纽扣电池在潮湿的鼻腔里放电,几小时内就能腐蚀穿鼻中隔
- 有人把两块小磁铁分别放在鼻中隔两侧当"鼻环",
  会夹坏中间的组织
- 不要滴水、滴油,不要等,立即去急诊
```

### ❌ 禁止

```
- 用硬物捅
- 试图钩出(可能推深)
- 让孩子用力吸鼻子
- 盲目使用镊子
```

用力吸鼻子可能把异物吸到后鼻孔,再掉进喉咙、气管——这样就从小问题变成了气道梗阻。处理时让孩子**用嘴呼吸**。

### ⚠️ 立即就医

- 电池(立即!会腐蚀)
- 磁铁(尤其是两个)
- 尖锐物体
- 无法取出
- 呼吸困难
- 大量出血

鼻出血的压迫止血方法见[基础急救知识-鼻出血](00-基础急救知识.md#鼻出血)。

## 喉咙异物/气道梗阻

气道完全堵住后,人几分钟内就会失去意识,不到10分钟就可能出现脑损伤和死亡,**救护车通常来不及**。所以必须由身边的人立即动手。每个家庭至少要有一个人学会本节的方法,最好参加一次红十字会的急救培训,在模拟人上练过。

### 严重程度判断

最常见的场景: 吃饭时(尤其是边吃边说笑、喝了酒、老人假牙松动)、儿童玩小东西或吃坚果果冻时,突然停下、表情惊恐。**先问一句: "你被噎住了吗?"**

#### 部分梗阻(轻度)
**症状**:
- 能咳嗽
- 能说话或哭
- 能呼吸(虽困难)

**处理**:
```
✓ 鼓励用力咳嗽
✓ 不要拍背或干预
✓ 持续观察
✓ 准备急救

如转为完全梗阻,立即急救!
```

为什么不干预: 有力的咳嗽是排出异物最有效的办法,比任何外力都强。这时拍背、灌水、用手去抠,反而可能让异物松动后卡得更深,把部分梗阻变成完全梗阻。陪在他身边,别让他一个人走开(很多人会躲进厕所,然后在里面倒下)。

如果咳了几分钟仍咳不出、一直有异物感,或者老人、儿童反复呛咳,也要尽快就医。

#### 完全梗阻(重度)
**症状**:
- 不能咳嗽
- 不能说话或哭
- 不能呼吸
- 双手抓喉咙(窒息信号)
- 脸色发紫

**处理**: 立即急救!

| 表现 | 部分梗阻 | 完全梗阻(或已转为严重) |
|------|----------|------------------------|
| 咳嗽 | 有力、响亮 | 没有,或咳嗽无声、越来越弱 |
| 说话/哭 | 能 | 不能,只能点头摇头 |
| 呼吸 | 能,可能有喘鸣 | 没有气流,或吸气时发出尖细的高音 |
| 脸色 | 通红 | 发紫、发灰 |
| 意识 | 清醒 | 很快变得迷糊,倒下 |

⚠️ 咳嗽**变弱、变得无声**,或者吸气时出现高调的"嘶——"声,要按完全梗阻处理,不要等到脸发紫。

### 急救方法

```
基本流程(成人和1岁以上儿童):

清醒、完全梗阻 → 让别人拨打120 → 拍背5次 → 腹部冲击5次 → 交替重复
                                                   ↓
                                         异物排出 → 仍要就医检查
                                                   ↓
                                         失去意识 → 放平,立即开始CPR
```

先拍背还是直接冲击: 欧洲复苏委员会(ERC)和美国心脏协会(AHA 2025年版)推荐先拍背5次、再腹部冲击5次交替进行;国内很多培训直接教腹部冲击(海姆立克法)。**两种都是正确的,关键是立刻动手,不要犹豫。** 只学会一种的,就用你会的那种。

#### 成人和1岁以上儿童: 海姆立克急救法

**拍背(可先做)**:

```
1. 站在伤者侧后方
2. 一只手托住他的胸部,让他上身前倾、头低于胸部
   (异物被拍松后会往嘴里掉,而不是往里掉)
3. 另一只手的掌根用力拍击两肩胛骨之间
4. 拍5次,每次拍完看一下异物有没有出来
5. 5次拍不出 → 改做腹部冲击5次
```

**伤者站立或坐位**:

```
1. 站在伤者背后
2. 双臂环抱腰部
3. 一手握拳,拳头拇指侧放在:
   - 肚脐上方
   - 肋骨下缘
4. 另一手握住拳头
5. 快速向内上方冲击
6. 重复直到:
   - 异物排出,或
   - 伤者昏迷

力度:
- 快速、有力
- 向内上方
- 每次独立的冲击

细节:
- 拳头位置: 肚脐上方约两横指,剑突(胸骨最下端的尖)以下
  不要压在剑突或肋骨上(容易造成骨折和内脏损伤)
- 让伤者身体稍前倾,救护者一只脚插在伤者两脚之间站稳,
  伤者一旦失去意识可以顺势让他滑到地上,而不是直挺挺摔倒
- 每一下都是一次独立的、像要把人提起来的"J"形猛拉,
  不是连续揉压;每次冲击都要有把异物冲出来的意图
- 伤者坐在椅子上、轮椅上: 从椅背后方抱住同样操作
- 儿童(1-8岁左右): 救护者跪下或蹲下,和孩子同高,力度相应减小
```

**伤者昏迷**:

```
1. 平躺
2. 开始CPR(胸外按压)
3. 每次准备人工呼吸前:
   - 检查口腔
   - 如看到异物,取出
   - 不要盲目掏
4. 持续CPR直到急救到达

细节:
- 托住他慢慢放到硬地面上,大声呼救,
  让旁人拨打120、找AED(手机开免提放在旁边)
- 不需要先摸脉搏,直接从胸外按压开始
  (按压时胸腔内压力升高,本身就可能把异物推出来)
- 按压位置、深度、频率与普通CPR相同,30次按压:2次人工呼吸
- 只有看得见、能夹出来的异物才用手指取;
  看不见就不要伸手指进去掏(会把异物推得更深)
- 吹气吹不进(胸部不起伏)时,不要反复试,继续按压
```

CPR的完整步骤见[基础急救知识-心肺复苏](00-基础急救知识.md#心肺复苏cpr)。

**孕妇或肥胖者**:

```
胸部冲击:
1. 双臂环抱胸部
2. 拳头放在胸骨中部
3. 向后快速冲击

细节:
- 适用于: 孕中晚期(肚子明显隆起)、
  腰围太粗双臂抱不过来的人
- 救护者双臂从伤者腋下穿过,环抱胸部
- 拳头放在胸骨下半段(两乳头连线中点,与CPR按压位置相同),
  避开剑突和肋骨
- 另一手握住拳头,向正后方(朝自己)快速冲击,每次独立
- 孕妇失去意识后同样立即开始CPR,并告诉急救人员是孕妇
```

**自救**(独自一人):

```
方法1: 腹部冲击
1. 拳头放在腹部
2. 另一手握住
3. 向内上方快速冲击

方法2: 椅背法
1. 俯身在椅背上
2. 腹部抵住椅背顶端
3. 快速向下压

细节:
- 先拨打120;说不出话时不要挂断,可以敲击话筒、发出声音,尽量打开门或走到有人的地方(不能指望接线员一定能定位到你)
  或者冲到有人的地方、敲门、拍桌子引起注意
- 拳头位置同上: 肚脐上方、肋骨下缘
- 椅背法也可以用桌子边缘、台阶扶手、灶台边缘等
  坚固、不会移动、高度齐腰的硬边;不要用会滑动的椅子
- 每一下都要猛、要快,反复做直到异物出来
- 自救成功后也要就医检查
```

#### 1岁以下婴儿

**拍背法 + 胸部冲击法**:

```
1. 拍背:
   - 将婴儿面朝下放在前臂上
   - 头低于身体
   - 支撑头颈
   - 用手掌根拍背(两肩胛骨之间)
   - 5次,用力

2. 翻转婴儿:
   - 面朝上
   - 头仍低于身体

3. 胸部冲击:
   - 一只手的掌根放在胸骨中部(两乳头连线下方)
   - 快速向下压(深度约4 cm)
   - 5次

4. 重复拍背和胸部冲击
   - 直到异物排出
   - 或婴儿昏迷

如昏迷:
- 开始婴儿CPR
- 检查口腔异物
- 呼叫急救
```

**手法细节**:

```
姿势:
- 救护者坐下或单膝跪下,把托着婴儿的前臂搁在大腿上,这样不会累也不会摔
- 拍背时用手托住婴儿下巴两侧(拇指和其他手指分开捏住下颌骨),
  不要掐住或压住喉咙的软组织

拍背力度:
- 用掌根,在两肩胛骨之间向前下方(朝头的方向)拍
- 要用力,是能把东西震出来的力度,不是哄睡时的轻拍

翻身:
- 另一只手托住婴儿后脑和背部,把婴儿"夹"在两只前臂之间整体翻过来,
  不要让头颈晃动

胸部冲击:
- 用一只手的掌根放在两乳头连线正下方的胸骨上
  (旧教材的两指法往往压不到足够深度,新版指南改为掌根)
- 每次压下约胸廓厚度的1/3(约4 cm),比CPR按压更慢、更有力,
  每次之间让胸廓完全回弹
- 每轮做完看一眼嘴里,能看到异物才用小指勾出

求救:
- 有旁人: 一开始就让他拨打120
- 只有自己: 手机开免提拨打120,边打边做
```

**婴儿部分梗阻**: 能哭出声、能咳嗽的,让他自己咳,保持他头低一点的姿势观察,不要拍背、不要倒提、不要用手抠。哭声变弱、咳嗽无声、嘴唇发紫,立即按上面的方法处理。

婴儿CPR与成人的区别见[儿童和婴儿CPR区别](00-基础急救知识.md#儿童和婴儿cpr区别)。

#### ❌ 禁止(婴儿)

```
- 不要用海姆立克法(会伤内脏)
- 不要头朝上拍背(异物可能更深)
- 不要盲目掏喉咙
- 不要倒提双脚摇晃(会伤颈椎,也不比正确拍背有效)
- 不要喂水、喂奶"冲下去"
```

#### 急救成功之后

```
异物排出、恢复呼吸后,仍要就医检查,尤其是:
- 做过腹部冲击或胸部冲击(可能造成内脏、肋骨损伤)
- 仍持续咳嗽、喘鸣、声音嘶哑、吞咽疼痛
- 怀疑还有一部分异物没出来
- 婴儿、孕妇、老人

⚠️ 支气管异物: 孩子吃花生、瓜子时呛咳一阵后"好了",
   之后却反复咳嗽、喘息、发烧、"肺炎老不好"——
   可能有一小块异物掉进了支气管。
   只要有过明确的呛咳史,就要告诉医生。
```

### 预防

```
✓ 细嚼慢咽
✓ 小口进食
✓ 不要边吃边说笑
✓ 儿童:
  - 避免坚果(3岁以下)
  - 切小块
  - 远离小玩具
  - 监督进食
✓ 老人:
  - 假牙固定好
  - 食物煮软
✓ 饮酒时、吃大块肉时尤其要小口慢吃
✓ 吞咽困难的人(中风后、卧床老人):
  - 坐直进食,吃完再坐30分钟
  - 液体可加米糊、藕粉调稠,比清水更不容易呛
  - 不吃年糕、汤圆、果冻等黏而滑的食物
```

儿童防窒息的具体食物清单见[儿童安全-防窒息](14-儿童安全.md#防窒息);卧床老人的喂食方法见[老人照护-安全喂食](13-老人照护.md#安全喂食防止呛咳)。

## 误吞异物

### 常见误吞物

- 硬币
- 纽扣电池(危险!)
- 磁铁(尤其多个)
- 鱼刺、骨头
- 图钉、针
- 玩具零件
- 遇水膨胀的彩色珠子(水宝宝、海绵玩具,危险)
- 假牙、牙签、枣核(多见于老人)

### 症状

- 可能无症状
- 吞咽困难或疼痛
- 流口水
- 胸痛或腹痛
- 呕吐
- 拒绝进食

**异物卡在哪里**: 吞下的东西最容易卡在食管(胸骨后方)。卡在食管时典型表现是**流口水、咽不下口水、吃东西就吐、胸骨后疼痛**,幼儿表现为突然拒食、哭闹、流口水——这时必须当天就医取出。一旦过了食管进入胃,多数小而圆钝的东西能随大便自然排出。

如果同时有咳嗽、喘鸣、呼吸困难,说明可能进了气道,按[气道梗阻](#喉咙异物气道梗阻)处理。

### 处理

#### 一般异物(硬币、小圆物)

```
如果:
✓ 能说话
✓ 能呼吸
✓ 不痛或轻微不适

处理:
1. 保持冷静
2. 不要催吐
3. 不要喝水或进食
4. 联系医生咨询
5. 观察大便(多数在1周内排出)

就医如果:
- 持续疼痛
- 吞咽困难
- 呕吐
- 腹痛
- 1周左右仍未排出(视物体大小)

说明:
- 不催吐: 呕吐时异物可能从胃里返回,卡在食管或掉进气道
- 暂不进食: 如果需要做胃镜取出,空腹更安全;医生确认可以后再吃
- 儿童吞了硬币,通常需要拍X光片确认位置
  (硬币和纽扣电池在X光片上看起来很像,要医生分辨)
- 观察大便: 每次大便放在容器里,用筷子或在水里冲开检查,
  直到找到异物;平常饮食即可,不需要吃泻药或"韭菜"
```

**分不清吞的是什么**: 孩子身边少了一个硬币大小的圆片、遥控器后盖打开了、玩具里的电池不见了——**一律按纽扣电池处理**,立即就医。

#### 危险异物(立即就医!)

**纽扣电池**:
```
极度危险!
- 2小时内可造成严重化学烧伤
- 立即急诊!
- 不要等待
- 不要催吐
- 除蜂蜜外不要进食
- 1岁以上、吞入12小时内:在去医院路上可每10分钟喂10 mL(2茶匙)蜂蜜,最多6次
  (在电池表面形成保护层,减轻烧伤;1岁以下婴儿不能吃蜂蜜)
- 带上电池包装或相同电池

为什么这么危险:
- 电池卡在湿润的食管里会持续放电,在电池负极一侧产生强碱
- 碱会一层层腐蚀食管壁,可能烧穿到气管或主动脉,
  有的在取出后几天甚至几周才大出血
- 孩子开始时可能毫无症状,不能"等等看"
- 直径约2 cm的锂电池(如CR2032)最危险
- 没电的"旧电池"也有危险
```

**磁铁(两个或多个)**:
```
极度危险!
- 可能在肠道内互相吸引
- 导致肠穿孔
- 立即就医!

说明:
- 两块磁铁隔着两段肠壁吸在一起,夹住的肠壁会坏死、穿孔
- 一块磁铁加一个铁质物品(硬币、铁珠、发卡)也有同样危险
- 最危险的是强力磁铁小球、磁力积木里的小磁块
- 不确定吞了几块时,按多块处理
```

**尖锐物体**:
```
危险!
- 鱼刺、骨头、针、图钉
- 可能刺穿消化道
- 立即就医
- 不要吞食物(企图推下)
- 不要催吐
```

**长或大的物体、遇水膨胀的东西**:
```
- 长于约5 cm(幼儿约3 cm)或直径超过约2 cm的东西,
  往往过不了胃的出口,需要医生取出
- 水宝宝、吸水海绵玩具在肠道里会膨胀几倍,造成肠梗阻,
  X光片上看不到,吞了就要就医
- 装毒品的小包、含铅的物品(铅坠、某些旧油漆碎片)也要立即就医
```

#### 鱼刺卡喉

```
❌ 错误方法(不要用!):
- 吞饭团、馒头(可能刺更深)
- 喝醋(无效)
- 用手抠

✓ 正确方法:
1. 停止进食
2. 如能看到鱼刺,用镊子小心取出
3. 如在喉咙深处:
   - 不要自行处理
   - 立即就医
4. 医生会:
   - 喉镜检查
   - 取出鱼刺

危险信号:
- 剧烈疼痛
- 呼吸困难
- 吞咽困难
- 流口水
- 呕血
```

| 偏方 | 为什么不行 |
|------|------------|
| 吞饭团、馒头、韭菜 | 可能把鱼刺硬压进喉咙或食管壁,刺得更深;卡在食管的鱼刺、鸡骨可能刺穿食管,引起纵隔感染,甚至刺破主动脉 |
| 喝醋 | 一口醋在喉咙里只停留一两秒,根本软化不了鱼刺;大量喝醋还会灼伤口腔和食管黏膜 |
| 用手抠、用筷子捅 | 看不清,容易把刺推深、划伤咽部,还会引起呕吐 |
| 用力咳、干呕 | 偶尔有用,但用力过猛会使刺扎得更牢 |

**怎样自己看**:

```
1. 在光线好的地方(或用手电筒),张大嘴,发"啊——"的长音
2. 用干净的勺子柄轻轻压住舌头前2/3(不要压太靠后,会引起恶心)
3. 鱼刺最常卡在扁桃体(喉咙两侧的肉球)和舌根
4. 看得清楚、刺的一端露在外面: 用消过毒的长镊子夹住,顺着扎入的方向拔出
5. 看不见、够不着,或者夹了一两次没成功 → 停手,去医院耳鼻喉科
   (医生用间接喉镜或内镜,几分钟就能取出)
```

⚠️ 鱼刺掉下去后,喉咙被划伤处也会有一段时间的异物感,和刺还在里面不好分辨。**异物感持续不消、吞咽时疼痛加重、疼痛位置在胸骨后方**,都要当天就医,不要拖几天"看看能不能自己消化掉"。鸡骨、鸭骨、枣核比鱼刺更硬更大,卡住后更要尽快就医。

### ⚠️ 立即就医

- 纽扣电池
- 多个磁铁
- 尖锐物体
- 较大物体
- 呼吸困难
- 剧烈疼痛
- 吞咽困难
- 呕吐(尤其是血)
- 流口水
- 发烧
- 腹痛
- 大便发黑或带血
- 腹胀、不排气不排便

### 预防(儿童)

```
✓ 小物品远离儿童
✓ 检查玩具(无小零件)
✓ 纽扣电池妥善保管
✓ 硬币、磁铁收好
✓ 监督进食
✓ 食物切小块
✓ 去除鱼刺、骨头
✓ 遥控器、电子秤等电池仓用胶带封住或用螺丝固定
✓ 用过的旧电池也立即收走,不要随手放在桌上
✓ 不要把针、图钉、硬币含在嘴里(大人做样子,孩子会模仿)
```

更多儿童防误吞内容见[儿童安全-特别危险的小东西](14-儿童安全.md#特别危险的小东西)。

## 皮肤异物、鱼钩与扎入物

### 皮肤小刺

```
木刺、竹刺、仙人掌刺、玻璃碴:
1. 肥皂水洗净
2. 能看见一端露在外面: 用消毒过的镊子夹住,顺着扎入的角度拔出
3. 全部埋在皮下: 用消毒过的针轻轻挑开表皮,露出一端再夹
   (针和镊子用火烧一下或用75%酒精擦过)
4. 先用温水泡10分钟左右,皮肤软化后更容易取
5. 很细的毛刺、玻璃纤维、仙人掌细刺:
   用宽胶带贴上压紧,再快速撕下,能粘出一大片
6. 取出后洗净,贴创可贴,观察几天

取不出、刺得很深、在指甲下面、在关节处 → 就医
几天后红肿热痛加重、化脓 → 有残留或感染,就医
```

详细处理见[外伤处理-浅表刺伤](02-外伤处理.md#浅表刺伤)。

### 鱼钩扎入

鱼钩的钩尖后面有倒刺,扎进去以后**直接往回拔会撕裂一大块肉**,而且很疼。

```
只扎进钩尖、倒刺还在皮外:
- 顺着进去的方向退出即可

倒刺已经扎进皮肤(推出剪断法):
1. 先剪断鱼线,如果是多钩(三本钩),先把其他钩尖剪掉或包住
2. 洗净,可以先冰敷几分钟减轻疼痛
3. 顺着钩子的弧度,把钩尖继续向前推,直到钩尖和倒刺从皮肤另一处穿出
4. 用钳子(钢丝钳、斜口钳)把露出的倒刺连钩尖一起剪掉
   (剪的时候用手或布挡住,防止碎片崩到眼睛)
5. 沿原路把剩下的钩身退出来
6. 洗净伤口、消毒、包扎

这只适用于: 钩子扎在手指、手掌、手臂、腿等肉厚的地方,
钩尖已经在皮下很浅处能摸到。
```

```
❌ 以下情况不要自己取,固定好鱼钩去医院:
- 扎在眼睛、眼皮、脸部、耳朵、生殖器
- 扎在关节、肌腱、明显的血管附近
- 扎得很深,摸不到钩尖
- 伤者是不配合的小孩

固定方法: 剪断鱼线,在鱼钩周围垫几层纱布或布卷,用胶布固定,
         不让它随动作晃动。
```

### 扎入身体的大型异物

钢筋、树枝、刀、玻璃片、木桩等扎进身体后,异物本身往往堵住了被刺破的血管。**拔出来可能立即引起大出血**,还会造成二次损伤。

```
1. 拨打120
2. 不要拔出,不要摇晃
3. 固定: 用卷起的毛巾、衣物在异物周围垫一圈,把异物"夹"住,
   再用绷带或布条绕着垫子包扎固定(不要压在异物上)
4. 止血: 在异物两侧的伤口边缘按压,不要直接压异物
5. 让伤者保持不动;扎在胸、腹部的,不要吃喝
6. 异物太长无法搬运时(如钢筋),不要自己切割,
   等消防和急救人员用工具处理
7. 观察休克征象: 面色苍白、出冷汗、脉搏快弱、烦躁或迷糊

唯一的例外: 异物堵住口鼻导致无法呼吸,或者妨碍做CPR时,才考虑取出。
```

详细处理见[外伤处理-深刺伤](02-外伤处理.md#深刺伤);休克的处理见[基础急救知识-休克处理](00-基础急救知识.md#休克处理)。

### 破伤风

任何扎入皮肤的异物(尤其是生锈的、沾了泥土粪便的,以及鱼钩、木刺、钉子扎的深伤口)都有破伤风风险。是否需要打破伤风针,见[外伤处理-破伤风预防](02-外伤处理.md#破伤风预防)。

## 📝 总结要点

### 异物处理原则

```
✓ 保持冷静
✓ 评估严重程度
✓ 简单、安全的方法优先
✓ 不要盲目操作
✓ 及时就医

❌ 不要:
- 盲目掏取
- 用硬物捅
- 将异物推深
- 延误就医(危险异物)
- 拔出扎进眼睛或身体的大型异物
```

### 危险异物(立即就医)

- 纽扣电池
- 多个磁铁
- 尖锐物体
- 化学品入眼
- 完全气道梗阻
- 扎入眼睛或身体的异物
- 遇水膨胀的珠子

### 掌握的急救技能

- 海姆立克急救法
- 婴儿拍背法
- 眼睛冲洗
- 基础异物取出

```
1. 噎住: 能咳就让他咳;不能咳、不能说 → 拍背5次 + 腹部冲击5次交替
2. 孕妇和抱不住腰的人改用胸部冲击;1岁以下婴儿用拍背 + 掌根胸部冲击
3. 失去意识 → 放平,立即CPR,人工呼吸前看口腔
4. 化学品入眼 → 先冲! 撑开眼皮冲至少15-20分钟,石灰先刷再冲
5. 纽扣电池、多个磁铁、尖锐物 → 立即急诊;1岁以上吞电池可喂蜂蜜
6. 鱼刺卡喉 → 不吞饭团、不喝醋,看得见才夹,看不见去耳鼻喉科
7. 耳朵里的活虫滴温油;豆子不能沾水;鼻子里的东西让孩子用嘴呼吸
8. 扎进身体和眼睛的东西不要拔,固定好送医
```

### 预防最重要

- 儿童监护
- 安全存放小物品
- 细嚼慢咽
- 食物安全处理
- 打磨、劈柴戴护目镜
