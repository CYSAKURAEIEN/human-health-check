## 中毒的通用处理原则

### 立即做

```
1. 先保护自己
   - 现场有异味、有人接连倒下 → 可能是有毒气体,不要贸然进入
   - 接触农药、化学品时戴手套

2. 让中毒者脱离毒物
   - 吸入: 转移到空气新鲜处
   - 皮肤沾染: 脱去污染的衣物,用大量清水冲洗皮肤和头发
   - 眼睛: 用流动清水冲洗15-20分钟
   - 口服: 吐出嘴里剩余的东西,清水漱口(不要咽下)

3. 拨打120,说清楚:
   - 吃了(或接触了)什么、大概多少、什么时间
   - 中毒者的年龄、大概体重、现在的情况

4. 把毒物的瓶子、包装、剩余的药片、呕吐物带去医院
   (医生需要知道具体是什么才能对症解毒)

5. 观察:
   - 意识不清但有呼吸 → 侧卧位(恢复体位),防止呕吐物堵住气道
   - 无反应、无正常呼吸 → 立即CPR
```

眼睛沾染的处理见[异物处理-化学品入眼](04-异物处理.md#化学品入眼紧急)。

### ❌ 不要做

```
❌ 不要催吐
   - 抠喉咙、灌盐水、灌肥皂水催吐都不推荐
   - 催吐并不能有效清除胃里的毒物
   - 腐蚀性物质(强酸、强碱、清洁剂)吐出来会再次烧伤食道和口腔
   - 意识不清时呕吐容易吸入肺里,造成严重的肺损伤
❌ 不要灌醋、牛奶、生鸡蛋、绿豆汤等"解毒"偏方,除非医生或120明确让你这样做
❌ 不要给意识不清的人喂任何东西
❌ 不要因为中毒者"现在看起来没事"就不去医院
   - 很多毒物(百草枯、对乙酰氨基酚、某些鼠药)要几小时到几天后才出现严重症状,
     等到出现症状时往往已经错过最佳治疗时机
```

⚠️ 中国大陆暂无全国统一的中毒咨询热线,遇到中毒直接拨打120。

## 农药和鼠药中毒

农村地区中毒的常见原因,包括误服(农药装在饮料瓶里被当成饮料)、喷药时防护不当,以及自杀。

### 有机磷农药(敌敌畏、乐果、敌百虫等)

```
识别:
- 大量出汗、流口水、流泪、流鼻涕
- 瞳孔缩小(针尖样)
- 恶心、呕吐、腹痛、腹泻
- 肌肉跳动、抽搐
- 呼吸困难、胸闷
- 呼气或身上有大蒜样气味
- 严重时昏迷、呼吸停止

处理:
1. 救助者戴手套(有机磷可经皮肤吸收,救助者也可能中毒)
2. 立即脱去被污染的衣物、鞋袜,装袋隔离
3. 用肥皂水和大量清水反复冲洗皮肤、头发、指甲缝
4. 拨打120,说明是有机磷农药中毒(医院有特效解毒药,越早越好)
5. 把农药瓶带去医院
6. 呼吸停止时CPR(有条件时用面罩或隔离膜,避免救助者接触到口中的农药)
```

### 百草枯

```
⚠️ 剧毒,没有特效解毒药,误服一口就可能致命

- 国内已于2016年起停止百草枯水剂的销售,但仍有残存和非法流通,中毒事件仍时有发生
- 早期可能只有口腔、咽喉烧灼痛,看起来"不严重"
- 几天内逐渐出现肝肾损伤和不可逆的肺纤维化

处理:
- 无论喝了多少、有没有症状,立即拨打120送医
- 皮肤沾染: 立即脱衣,用肥皂水和清水彻底冲洗
- 告诉医生是百草枯,带上瓶子
```

### 鼠药

| 类型 | 特点 | 处理 |
|------|------|------|
| 抗凝血类(如溴敌隆、大隆) | 现在最常见。误服后**几天后**才出现出血: 牙龈出血、皮下瘀斑、血尿、黑便 | 即使当时没有任何症状,也要立即就医;医院有特效药 |
| 毒鼠强等(国家早已禁用) | 剧毒,很快出现抽搐 | 立即120 |

儿童误吃了鼠药颗粒,即使只有一两粒,也要带着包装立即就医。

### 喷洒农药时的防护

```
✓ 穿长袖长裤、戴手套、口罩、帽子,最好戴护目镜
✓ 站在上风方向喷洒,不要逆风
✓ 喷药时不吃东西、不喝水、不吸烟
✓ 喷完立即换衣服、洗澡,衣物单独清洗
✓ 出现头晕、恶心、出汗多、视物模糊 → 立即停止,离开现场,冲洗,就医
✓ 孕妇、哺乳期妇女、儿童、老人不要参与喷药
```

## 药物过量与误服

### 儿童误服

儿童误服最常见的是家里的药片、清洁剂、化妆品、纽扣电池。

```
1. 立即从孩子嘴里拿出剩下的东西
2. 弄清楚吃了什么、可能吃了多少(数一下药瓶里还剩多少)
3. 拨打120,或带着药瓶、包装立即去医院
4. 不要催吐
5. 不要等到出现症状再去

⚠️ 下面这些即使只吃了一点也很危险,必须立即就医:
- 纽扣电池、磁铁(见误吞异物)
- 降糖药、降压药、心脏病药
- 抗抑郁药、安眠药
- 含铁的补剂
- 大人的止痛药(对乙酰氨基酚等)
- 农药、鼠药、清洁剂
```

相关章节: [误吞异物](04-异物处理.md#误吞异物)。

### 成人药物过量

```
- 安眠药、镇静药: 嗜睡、意识不清、呼吸变慢变浅 → 120,侧卧,观察呼吸
- 降糖药、胰岛素: 低血糖表现(见低血糖)
- 对乙酰氨基酚(扑热息痛,很多感冒药里都含有):
  ⚠️ 过量后最初1-2天可能没有明显症状,但肝损伤在悄悄发生
  → 怀疑过量就要立即就医(有特效解毒药,但要在早期用)
  → 同时吃几种感冒药容易无意中过量,看清成分
```

相关章节: [低血糖](06-心脑血管与突发病症.md#低血糖)。

如果药物过量可能是有意的,在处理身体问题的同时,也要关注心理状况,见[心理健康-自杀风险](10-心理健康.md#自杀风险-识别与应对)。

## 酒精中毒

### 危险信号

```
出现以下任何一项,立即拨打120:
- 叫不醒,或只能短暂叫醒
- 失去意识时还在呕吐
- 呼吸慢(每分钟少于8次)或不规则,呼吸停顿
- 抽搐
- 皮肤湿冷、苍白或发青
- 体温低
```

### 处理

```
✓ 不要让醉酒的人单独躺着"睡一觉就好"
  - 酒精还在继续吸收,情况可能在停止喝酒后继续恶化
  - 最常见的死因是昏睡中呕吐、把呕吐物吸进气道窒息
✓ 侧卧位(恢复体位),保持呼吸道通畅
✓ 有人一直陪着,定时观察呼吸
✓ 保暖(醉酒的人容易失温,冬季醉倒在户外非常危险)
✓ 能坐起来、清醒时可以少量喝水

❌ 不要催吐
❌ 不要喝咖啡、浓茶"解酒"(不能加快酒精代谢,反而增加心脏负担)
❌ 不要冲冷水澡(可能导致失温、跌倒)
❌ 不要让他自己走路、骑车、开车
```

### ⚠️ 假酒(甲醇)中毒

- 喝了来路不明的散装酒、自酿酒后,数小时到一天后出现**视物模糊、看东西像蒙了一层雪**、剧烈头痛、恶心、呼吸困难
- 这是甲醇中毒,可导致失明和死亡,**必须立即就医**
- 同喝一批酒的人都要去医院检查
- 自制酒精中的甲醇见[消毒剂制备-蒸馏提纯](../06-制药技术/01-消毒剂制备.md#13-蒸馏提纯)

## 清洁剂中毒

### ⚠️ 不同清洁剂不能混用

```
❌ 84消毒液(含氯漂白剂) + 洁厕灵(含酸)
   → 产生氯气,刺激眼睛和呼吸道,严重时可致命
❌ 84消毒液 + 含氨的清洁剂
   → 产生有毒气体
❌ 不同的管道疏通剂混用
   → 剧烈反应、喷溅

原则: 一次只用一种清洁剂;用前看标签;打扫卫生间时开窗通风
```

### 吸入了有毒气体

```
1. 立即离开现场,到空气新鲜处
2. 打开门窗通风(屏住呼吸快进快出)
3. 出现咳嗽不止、胸闷、气短、呼吸困难 → 120
4. 即使症状缓解,也可能在数小时后加重,症状明显的要就医观察
```

### 误服清洁剂、消毒液

```
1. 不要催吐
2. 清水漱口,吐掉
3. 立即拨打120,带上瓶子
4. 出现吞咽困难、流口水、胸痛、呕血 → 说明有腐蚀伤,更要尽快送医
```

## 预防中毒

```
储存:
✓ 药品、农药、鼠药、清洁剂放在儿童够不着的地方,最好上锁
✓ 农药、清洁剂保留在原包装中
❌ 绝不用饮料瓶、矿泉水瓶装农药、汽油、清洁剂(最常见的误服原因)
✓ 农药和食物、饲料分开存放
✓ 农药空瓶不要用来装其他东西,按规定回收或处理

用药:
✓ 看清药名和剂量,不同的感冒药可能含相同成分
✓ 不要在孩子面前吃药,不要说"药是糖"
✓ 过期药、不用的药及时处理

其他:
✓ 不喝来路不明的散装酒
✓ 清洁剂不混用,用时通风
✓ 鼠药放在儿童和宠物接触不到的地方,并做好标记
```

---

## 📝 中毒要点

```
1. 拨打120,带上瓶子、包装、剩余的药
2. 不要催吐,不要灌偏方
3. 皮肤沾染: 脱衣,肥皂水和清水冲洗;救助者戴手套
4. 意识不清侧卧,无呼吸CPR
5. 百草枯、对乙酰氨基酚、抗凝血鼠药: 没症状也要立即就医
6. 醉酒的人不能单独"睡一觉",侧卧并有人看着
7. 84消毒液和洁厕灵绝不混用
8. 农药、清洁剂绝不装饮料瓶
```
