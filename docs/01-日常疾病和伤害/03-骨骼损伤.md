## 骨折

### 骨折类型

**闭合性骨折**: 皮肤完整,骨折未穿出
**开放性骨折**: 骨折端刺穿皮肤,严重!

开放性骨折不一定能看到骨头: 骨折处附近有伤口,哪怕只是一个小口子在渗血,都要按开放性骨折处理(骨头可能刺出后又缩了回去)。开放性骨折容易感染骨头(骨髓炎),出血也更多,必须当天送医。

其他几种要知道的类型:

| 类型 | 特点 | 常见于 |
|------|------|--------|
| 青枝骨折 | 骨头像青树枝一样弯折、一侧裂开,没有完全断开;畸形可能不明显 | 儿童 |
| 骺板(生长板)损伤 | 骨头末端靠近关节的软骨受伤,处理不好会影响骨头长长 | 儿童,关节附近受伤 |
| 压缩性骨折 | 椎骨被压扁,只有腰背痛,容易被当成"闪了腰" | 老人(骨质疏松)、高处坠落臀部着地 |
| 应力骨折(疲劳骨折) | 没有明显外伤,长期反复负重造成细小裂纹;越走越痛,休息减轻 | 长途行军、负重走路,常在足背、小腿 |
| 粉碎性骨折 | 骨头碎成多块 | 高处坠落、车祸、重物砸伤 |

### 症状识别

明确征象:
- 畸形(异常角度或形状)
- 异常活动(不该动的地方能动)
- 骨擦音或骨擦感

可能征象:
- 剧烈疼痛
- 肿胀
- 淤血
- 功能丧失(无法活动)
- 压痛

```
怎样检查(动作要轻,检查是为了判断,不是为了"确认"):
1. 先问: 怎么受的伤?哪里痛?听到"咔"的一声吗?
2. 看: 和对侧比较,有没有变形、缩短、旋转、肿胀、伤口
3. 摸: 用一个手指沿着骨头轻轻按,
   骨头上某一点特别痛(骨性压痛)→ 高度怀疑骨折
4. 查远端: 手指或脚趾的颜色、温度、感觉、能不能动(见下文检查血液循环)

❌ 不要为了"听骨擦音"去来回活动伤处
❌ 不要让伤员"走两步试试"(下肢)
❌ 不要用力拉、扭、按压变形的部位
```

#### 骨折、脱臼、扭伤怎么区分

| | 骨折 | 脱臼 | 扭伤 |
|---|------|------|------|
| 部位 | 骨头中段或关节附近 | 关节处 | 关节处(韧带) |
| 变形 | 骨头中段成角、缩短 | 关节形状明显改变(如肩部变"方"、手指关节错位) | 一般没有,只有肿胀 |
| 压痛点 | 压在骨头上最痛 | 关节周围 | 压在关节旁的软组织(韧带)上最痛 |
| 活动 | 不能用,可能有异常活动 | 关节"卡住",几乎不能动 | 能动但痛,轻度的还能走 |
| 处理 | 固定、就医 | 原位固定、就医,不要自己复位 | 轻中度可以在家处理(见扭伤) |

关节附近的骨折和脱臼常常同时发生,扭伤和小骨折也很难靠肉眼区分。**区分不了时,一律按骨折处理**: 固定、就医拍X光。

### 紧急处理原则

#### 1. 评估情况

```
首先检查:
✓ 伤者意识状态
✓ 呼吸和心跳
✓ 严重出血
✓ 其他危及生命的伤

然后处理骨折
```

骨折本身很少马上致命,但受伤的方式(坠落、车祸、重物砸伤)往往同时造成头部、胸部、腹部的伤。不要被变形的手脚吸引全部注意力,先按[生命体征评估](00-基础急救知识.md#生命体征评估)查一遍。大腿、骨盆骨折和多处骨折会大量内出血,注意[休克征象](00-基础急救知识.md#休克征象识别)。

#### 2. 不要移动!

```
❌ 禁止:
- 试图复位骨折
- 不必要的移动
- 让伤者站立或行走

✓ 除非:
- 现场有危险
- 必须移动才能获救
```

```
必须移动时:
1. 先固定,再移动(来不及固定的,至少用手托住伤处上下方)
2. 移动时伤处上下的关节一起托住,整体平移,不要拖拽伤肢
3. 怀疑脊柱损伤: 头、颈、躯干保持一条直线,多人同时平移
4. 移到安全地方就停下,不要为了"舒服"反复挪动
```

搬运方法见[基础急救知识-搬运伤员](00-基础急救知识.md#搬运伤员)。

#### 3. 止血(开放性骨折)

```
⚠️ 开放性骨折:
1. 不要推回突出的骨头
2. 无菌纱布覆盖伤口
3. 压迫止血(小心,不要压在骨折处)
4. 立即呼叫急救
```

```
开放性骨折详细步骤:
1. 戴手套或用塑料袋隔开手
2. 露出伤口: 剪开衣物,不要硬脱
3. 有大块明显污物(泥块、草)可以轻轻拿掉;
   ❌ 不要把手指伸进伤口,不要往伤口里倒药粉、草木灰、酒
   等待时间很长(数小时以上)时,可以用大量干净的饮用水冲掉表面泥沙
4. 用干净纱布或布覆盖整个伤口
5. 止血: 在骨头突出处的周围加压,或在伤口上方(靠近心脏一侧)压住
   - 可以在骨头断端周围用卷起的纱布围成一圈"甜甜圈",再包扎,
     使压力落在周围而不是骨头上
6. 出血止不住、呈喷射状,危及生命时,按大出血处理,必要时用止血带
7. 按"原位"固定,夹板避开伤口
8. 记下受伤时间、有无破伤风疫苗接种史,告诉医生

⚠️ 开放性骨折需要在医院彻底清创并尽早用抗生素,
   拖得越久感染风险越高,不能在家处理
```

止血带见[基础急救知识-止血带](00-基础急救知识.md#4-止血带最后手段);破伤风见[外伤处理-破伤风预防](02-外伤处理.md#破伤风预防)。

#### 4. 固定

**目的**:
- 减轻疼痛
- 防止进一步损伤
- 减少出血
- 防止闭合骨折变为开放骨折

**原则**:
```
1. 原位固定(保持受伤时的位置)
2. 固定上下两个关节
3. 松紧适度
4. 检查远端血液循环
```

```
具体做法:
1. 固定前先检查一次远端(手指/脚趾)的颜色、温度、感觉、活动,记下来
2. 摘掉伤侧的戒指、手镯、手表,脱掉鞋袜(脚踝、足部伤除外,见下文)
   → 肿起来以后就摘不下来,会像止血带一样勒住
3. 一人用双手托住骨折处上下方,保持不动;另一人放夹板
4. 夹板长度: 超过骨折处上下两个关节
   (前臂骨折 → 夹板从肘到手掌;小腿骨折 → 从大腿到脚)
   关节附近的骨折或脱臼 → 固定该关节上下两段骨头
5. 衬垫: 夹板和皮肤之间垫上毛巾、衣物、棉花,
   骨头突出处(手腕、肘、膝、踝两侧)和身体的凹处(腰下、膝下)多垫
6. 绑扎: 至少在骨折处上方、下方各绑一道;
   结打在夹板一侧,不打在伤处;绑带宽3-5 cm,不用细绳、铁丝
7. 松紧: 绑带下能伸进一根手指为宜
8. 固定后再检查远端,和固定前比较
9. 没有脊柱、骨盆伤时,把固定好的手臂或腿垫高,减轻肿胀

✓ 做对了: 伤员感觉疼痛减轻,手指脚趾颜色温度和固定前一样
⚠️ 变坏了: 手指脚趾变白、变紫、发凉、麻木,或疼痛越来越重
   → 先松开重绑;松开后仍不好转 → 紧急送医(见下文危险信号)
```

"原位固定"的意思是不要为了好绑把伤肢掰直。只有在伤肢变形严重、无法放进任何夹板,或远端没有脉搏、而又长时间(数小时以上)无法得到救治时,才可能需要由受过训练的人调整,这里不展开;没受过训练的人按原样固定、尽快送医。

### 就地取材做夹板

手边没有专业夹板时,很多东西都能用:

| 材料 | 适合 | 注意 |
|------|------|------|
| 木板、木条、扫把柄、树枝 | 四肢 | 削掉毛刺,外面包布 |
| 厚纸板、纸箱板 | 前臂、手腕、小腿 | 折成"U"形托住肢体更结实;沾水后会变软 |
| 卷紧的杂志、报纸 | 前臂、手腕 | 绕肢体卷一圈,用胶带或布条固定 |
| 枕头、叠起的毯子 | 脚踝、足部 | 包住脚踝两侧和脚底,绑紧("枕头夹板") |
| 雨伞、登山杖、防潮垫 | 四肢 | 防潮垫卷起包住肢体,很好用 |
| 伤员自己的身体 | 手臂贴躯干、伤腿绑健腿、伤指绑邻指 | 中间一定要垫软物 |
| 三角巾、围巾、撕成条的床单、皮带 | 绑扎、悬吊 | 宽3-5 cm,太细会勒伤 |

没有三角巾时,可以把上衣下摆向上翻起包住手臂,用别针别在胸前,当作悬臂带。野外的更多做法见[野外伤病处置与转运-就地取材固定](../03-野外生存/11-野外伤病处置与转运.md#就地取材固定)。

### 各部位固定方法

#### 上臂骨折

```
1. 三角巾或宽布条制作悬臂带
2. 前臂屈曲90°
3. 悬挂于胸前
4. 另一布条绕过胸部固定上臂
```

```
补充:
- 有夹板时,在上臂外侧放一块从肩到肘的夹板,再按上面的方法悬吊固定
- 上臂和胸壁之间垫一层衣物
- 如果肘部无法弯曲(或一弯就剧痛),不要硬弯:
  让手臂伸直贴在身体一侧,用长夹板从腋下到手指固定,再整条手臂绑在躯干上
- 检查: 手腕能不能向上翘起
  (上臂骨折容易伤到桡神经,出现"垂腕"——手腕抬不起来,要告诉医生)
- 老人摔倒时肩部着地,常是靠近肩膀的上臂骨折,同样用悬臂带固定
```

#### 前臂或手腕骨折

```
1. 夹板: 从肘部到手掌
2. 两侧放置硬物:
   - 木板、硬纸板
   - 杂志、报纸卷
3. 布条绑扎(避开骨折处)
4. 三角巾悬吊
```

```
补充:
- 让伤员用好手托住伤臂,找最舒服的姿势,通常是肘弯曲、拇指朝上
- 夹板放在掌侧(手心一侧),手心里握一卷绷带或袜子团,
  手指保持自然弯曲(功能位),手指尖露在外面以便检查
- 悬吊时手比肘略高,减轻肿胀
- 老人向前摔倒时手掌撑地,最容易摔断手腕(桡骨远端),
  手腕像"餐叉"一样变形
- 摔倒手撑地后,手腕拇指根部(伸拇指时出现的小凹窝处)压痛:
  可能是舟骨骨折,早期X光常看不出,容易漏诊,不愈合会留下长期疼痛
  → 按骨折固定,就医时专门告诉医生
```

#### 手指骨折

```
1. 立刻摘掉这只手上的戒指(涂肥皂水、抬高手后再慢慢转下来)
2. 伙伴固定: 把伤指和旁边一根手指用胶布绑在一起,
   中间垫一层纱布(防止出汗磨破皮),关节处不缠胶布
3. 或用压舌板、冰棒棍、硬纸条做小夹板,从指尖到手掌
4. 抬高手,冰敷
5. 就医: 手指明显歪斜、旋转(握拳时手指交叉),
   指甲下大片淤血,有伤口,或指尖一节不能伸直(锤状指)

❌ 不要自己把歪了的手指拉直
```

#### 大腿骨折

```
1. 长夹板: 从腋下到脚跟
2. 短夹板: 从腹股沟到脚跟
3. 两侧固定
4. 多处绑扎:
   - 胸部、腰部、大腿、膝盖、小腿、脚踝
5. 不要移动伤者
6. 等待专业救援
```

```
补充:
- 大腿骨(股骨)是人体最粗的骨头,断了说明受力很大;
  大腿里可以出血1-1.5 L,伤员很快会出现休克 → 拨打120,保暖,监测
- 没有长夹板时: 两腿之间(膝、踝之间)垫上衣物,
  把伤腿和健腿绑在一起(大腿、膝上、小腿、脚踝各一道,
  脚踝处用"8"字绑法把两只脚绑在一起)
- 绑扎时从身体下面的空隙(腰下、膝下、踝上)穿过绑带,不要抬起伤腿
- 专业人员使用的牵引夹板需要训练,不要自制

⚠️ 老人跌倒后髋部(大腿根)疼痛、不能站立,
   伤腿变短、脚尖向外歪 → 髋部骨折,不要扶起,
   两腿之间垫软物、绑在一起,保暖,拨打120
```

老人跌倒的判断见[老人照护-老人跌倒后怎么办](13-老人照护.md#老人跌倒后怎么办)。

#### 小腿骨折

```
1. 夹板: 从大腿到脚跟
2. 包含膝关节和踝关节
3. 可用:
   - 木板
   - 雨伞
   - 健侧腿(绑在一起)
```

```
补充:
- 夹板放在腿的内外两侧,上端到大腿中部,下端超过脚跟
- 膝下、踝两侧垫软物;脚保持和小腿成直角,脚底可以加一块垫板托住
- 小腿前面(胫骨)皮下几乎没有肌肉,最容易变成开放性骨折,搬动要特别轻
- 小腿骨折是骨筋膜室综合征最常见的部位,固定后要反复检查(见下文危险信号)
```

#### 膝部和踝部、足部骨折

```
膝部(包括膝盖骨/髌骨骨折):
1. 不要强行伸直或弯曲,按受伤时的角度固定
2. 腿是直的: 一块长夹板放在腿后面,从臀下到脚跟,膝下、踝下垫软物
3. 腿是弯的: 在膝下垫卷起的毯子保持角度,两侧用短夹板固定大腿和小腿

踝部、足部:
1. 枕头夹板: 把枕头或叠起的毯子从脚跟下面向两侧包住脚踝,
   用3-4道布条绑紧,脚趾露出以便检查
2. 已经穿着鞋、鞋子不太紧时,可以不脱(脱鞋可能加重损伤,鞋本身也有固定作用);
   但要能看到或摸到脚趾,肿胀加重、鞋勒脚时要剪开
3. 抬高,冰敷
```

崴脚后能不能走、要不要按骨折处理,判断方法见[野外伤病处置与转运-崴脚: 还能不能走](../03-野外生存/11-野外伤病处置与转运.md#崴脚-还能不能走)。

#### 锁骨骨折

```
1. 三角巾悬吊患侧上肢(首选)
2. 或8字绷带固定双肩
3. 坐位
```

```
补充:
- 现场处理时,用三角巾把伤侧手臂悬吊在胸前、
  再用一条宽布带把手臂绑在躯干上,通常就足够了,也最舒服
- 伤员常常自己用好手托着伤侧手肘,肩膀向前耷拉,这是正常的保护姿势
- 8字绷带要在腋下垫好软物,不能太紧,
  手臂发麻、发凉、变色时立即松开;不会绑时不要勉强
- 锁骨下方有大血管和肺尖: 出现呼吸困难、伤处迅速鼓起、手臂发凉 → 立即拨打120
- 儿童摔倒肩部着地很常见,绝大多数愈合良好
```

#### 肋骨骨折

```
⚠️ 注意气胸、血胸!

禁止:
❌ 用布条、绷带缠紧整个胸部"固定肋骨"
   (现在的急救指南不建议: 缠胸会限制呼吸,使痰咳不出来,增加肺炎风险)
```

```
处理:
1. 让伤员选择最舒服的姿势,通常是半坐位
2. 用三角巾把伤侧手臂悬吊在胸前,减少手臂牵拉胸壁
3. 咳嗽、深呼吸时,让伤员抱住一个枕头或叠起的衣服按在伤处,减轻疼痛
4. 不要刻意"浅呼吸": 疼痛允许时,每小时做几次深呼吸和咳嗽,防止肺炎
   (止痛药在这里很有帮助,让伤员能正常呼吸)
5. 就医拍片,排除气胸、血胸和内脏损伤

立即拨打120:
- 呼吸越来越困难、急促,嘴唇发紫
- 一侧胸部不随呼吸起伏,或一块胸壁吸气时反而塌陷(连枷胸)
- 咳血
- 胸部有伤口且随呼吸有"嘶嘶"漏气声 → 用手或不透气的塑料片盖住伤口
- 下部肋骨骨折伴腹痛(可能伤及肝、脾)
- 老人多根肋骨骨折(即使开始呼吸还好,也容易在几天后出现肺炎和呼吸衰竭)
```

#### 骨盆骨折

```
怎样怀疑:
- 高处坠落、车祸、重物挤压后,髋部、腹股沟、下腰部疼痛
- 不能站立,两腿不等长,会阴部肿胀淤血,排尿有血
- 伴有面色苍白、出冷汗、脉快 → 骨盆内大出血,可以出血数升

处理:
1. 拨打120,说明"怀疑骨盆骨折"
2. ❌ 不要挤压、摇晃骨盆去"检查"(会加重出血)
3. 让伤员平躺,不要翻身、不要让他坐起或站立,不要抬高下肢
4. 两膝之间、两踝之间垫上衣物,把膝和踝绑在一起,
   膝下垫一卷毯子,让腿保持微屈
5. 保暖,按休克处理,不喂水喂食
6. 只有在120调度员指导下,或受过训练、等待时间很长时,
   才用折叠的床单在髋部两侧最突出的骨头(大转子)水平环绕骨盆、适度收紧
```

#### 下颌骨折

```
- 咬合对不上、张口困难、牙齿松动、口内出血
- 让伤员坐着、身体前倾,便于血液和口水流出,保持呼吸通畅
- 可让伤员用手托住下颌;不要用绷带把嘴紧紧绑死(呕吐时会窒息)
- 常合并头部受伤,注意意识变化,尽快就医
```

口腔损伤见[口腔问题](09-口腔问题.md)。

#### 脊柱骨折(极其危险!)

```
⚠️ 症状:
- 背部剧痛
- 活动受限
- 可能麻木、无力
- 可能大小便失禁

处理:
1. 绝对不要移动!
2. 保持头-颈-背一直线
3. 等待专业救援
4. 硬板担架搬运(至少4人)

除非:
- 现场有生命危险(火灾等)
```

```
什么时候要怀疑脊柱损伤(即使伤员说"没事"):
- 高处坠落(超过自身身高,或从楼梯滚落)
- 车祸、摩托车事故、被车撞
- 跳水撞到池底,或头部受到重击
- 头部受伤后意识不清
- 老人轻微跌倒后背痛(骨质疏松,可能压缩性骨折)

处理要点:
- 让清醒的伤员不要动,不要让他"转转脖子试试"
- 有呕吐或意识不清、呼吸受影响时,呼吸优先:
  几个人一起把伤员像一根木头一样整体翻成侧卧("轴线翻身"),头颈不扭转
- 保暖(躺在地上不动的人很快变冷),身下尽量垫上东西
- 不确定时,一律按有脊柱损伤处理
```

多人搬运见[基础急救知识-多人搬运](00-基础急救知识.md#3-多人搬运脊柱损伤);车祸现场见[居家与交通意外-车祸现场处理](07-居家与交通意外.md#车祸现场处理)。

#### 颈椎骨折

```
最危险!可能导致瘫痪或死亡!

固定:
1. 双手固定头部两侧
2. 保持头-颈-身体在一直线
3. 不要屈曲、伸展、旋转
4. 等待专业救援
5. 专业颈托固定
```

```
补充:
- 救护者跪在伤员头顶后方,双手手掌贴住伤员头部两侧(耳朵处),
  手肘撑在地上或自己膝盖上,这样能坚持较长时间;累了要换人时,
  另一人先接手固定好,原来的人再松手
- 伤员头部歪着且一动就痛、或有阻力时,不要硬扶正,按原来的位置固定
- 没有颈托时,可以在头两侧各放一卷衣服或毯子卡住头部
- 摩托车头盔一般不要摘,见车祸现场处理
```

### 检查血液循环

固定后必须检查:

```
每15分钟检查一次:

1. 皮肤颜色:
   ✓ 正常: 粉红
   ⚠️ 苍白或青紫: 可能太紧

2. 温度:
   ✓ 正常: 温暖
   ⚠️ 冰冷: 血液循环差

3. 脉搏:
   ✓ 能触及
   ⚠️ 触及不到: 太紧

4. 感觉:
   ✓ 正常
   ⚠️ 麻木或刺痛: 可能压迫神经

5. 活动:
   ✓ 能活动手指/脚趾
   ⚠️ 无法活动: 检查固定

如发现异常: 稍微松开固定
```

```
补充:
- 和健侧比较最直观
- 毛细血管充盈: 按压指甲2秒,松开后颜色应在2秒内恢复粉红
- 脉搏位置: 手腕拇指一侧(桡动脉);脚背中间或内踝后方
- 皮肤颜色深的人看指甲和手掌
- 松开固定后仍然苍白、冰凉、无脉 → 紧急送医,这是在和时间赛跑
- 去医院的路上和到达后,仍要继续检查
```

### 冰敷

```
✓ 减轻肿胀和疼痛
- 冰袋用布包裹
- 放在骨折部位周围
- 每次15-20分钟
- 每小时一次
❌ 不要直接接触皮肤
```

```
补充:
- 可以隔着夹板外的衣物冰敷,不要为了冰敷拆开固定
- 没有冰: 冷水浸湿的毛巾(变温了就换)、冷冻的蔬菜袋、装冷水的塑料袋
- 婴幼儿、老人、糖尿病或手脚感觉迟钝的人皮肤容易冻伤,时间缩短到10分钟左右,勤看皮肤
- 开放性骨折的伤口上不冰敷
```

### 止痛

```
- 固定好、抬高、冰敷,本身就是最有效的止痛
- 常用非处方药: 对乙酰氨基酚、布洛芬,按说明书剂量服用
- 布洛芬类(非甾体抗炎药): 胃溃疡、肾病、哮喘对其敏感、孕晚期的人不要用;
  对骨折愈合可能有轻微影响,短期使用一般问题不大,长期使用前问医生
- 可能需要手术的伤员(大腿、骨盆、开放性骨折等)不要吃东西喝水,也先不要吃药
- 不要用酒止痛
```

剂量参考见[常见疾病-药物退烧](01-常见疾病.md#2-药物退烧)。

### 致命和致残的危险信号

骨折后多数情况是"疼但不急",但下面几种情况要按急症处理:

#### 骨筋膜室综合征

```
是什么:
小腿、前臂的肌肉被坚韧的筋膜包在一个个"隔间"里,
骨折或挤压后肌肉肿胀、出血,隔间里压力越来越高,压住血管和神经,
几个小时内肌肉和神经就会坏死,可能导致截肢

常见于: 小腿骨折、前臂骨折、长时间被压住的手脚、石膏或夹板太紧

最早、最重要的信号:
- 疼痛和看到的伤不相称,止痛药、固定都不管用,越来越痛
- 被动地轻轻拉直伤者的手指或脚趾时,剧痛
- 肢体肿胀发硬、皮肤发亮紧绷
晚期才出现: 麻木、无力、苍白、摸不到脉搏
(等到摸不到脉搏才处理就太晚了)

处理:
1. 立即松开所有绷带、夹板绑带,剪开石膏外的包扎
2. 把伤肢放在和心脏同一高度(不要再抬高,也不要放低)
3. 不要冰敷
4. 立即送医,告诉医生"怀疑骨筋膜室综合征"
```

#### 骨盆、大腿骨折大出血

骨盆骨折出血可以达到数升,大腿骨折1-1.5 L,伤口外面却看不到血。受伤后出现面色苍白、出冷汗、脉搏快而弱、烦躁或反应迟钝,就是失血性休克。处理: 拨打120,原地不动,固定(见上文骨盆骨折、大腿骨折),保暖,平躺,不抬高下肢。

#### 脊柱损伤

伤后手脚麻木、无力、不能动,大小便失禁,呼吸费力(高位颈髓损伤)。按上文脊柱骨折、颈椎骨折的方法处理,原地等待专业救援。

#### 挤压伤

```
地震、塌方中手脚被重物压住较长时间(超过1小时左右)后,
突然解除压迫,坏死肌肉释放的物质可能引起心律失常和肾衰竭(挤压综合征)
✓ 尽量等专业救援人员到场再搬开重物,他们会先给伤员补液
✓ 现场必须自行救出时: 搬开后让伤员平躺,保暖,
  清醒能吞咽的可以小口喝水,尽快送医,告诉医生被压了多长时间
```

地震被困的应对见[地质灾害-被困时](../02-灾难应对/01-地质灾害.md#被困时)。

#### 骨折后发热、伤口流脓

开放性骨折或手术后几天到几周内出现发热、伤处红肿热痛加重、流脓,可能是骨头感染,要尽快就医。

### 儿童、老人和孕妇

```
儿童:
- 骨头软,常是青枝骨折,畸形不明显,孩子可能只是"不肯用这只手"、"走路一瘸一拐"
- 关节附近受伤可能伤到生长板 → 关节处肿痛的孩子都要拍片
- 牵拉肘: 大人拉着幼儿的手提起或猛拽后,孩子哭闹、手臂垂着不肯动
  → 是桡骨头半脱位,医生很容易复位,但需先排除骨折,不要自己掰
- 孩子反复骨折、骨折和所说的受伤经过对不上,要考虑是否受到虐待
- 儿童愈合快,一般比成人快很多

老人:
- 骨质疏松,轻微跌倒就可能骨折,常见于手腕、髋部、肩部、脊柱
- 痛感可能不明显,"摔了一下能走"也可能有骨折,疼痛持续要拍片
- 髋部骨折后长期卧床,容易发生肺炎、压疮、血栓,尽早就医手术很重要

孕妇:
- 跌倒或车祸后即使只是轻伤,也要就医检查胎儿情况
- 平躺时子宫压迫大血管,孕晚期伤员(无脊柱伤时)尽量左侧卧,
  或在右侧腰下垫高,让身体向左倾斜
- 止痛药先问医生,孕晚期不要用布洛芬
```

儿童防坠落见[儿童安全-防坠落](14-儿童安全.md#防坠落);老人跌倒预防和卧床护理见[老人照护](13-老人照护.md)。

### 骨折愈合与康复

成人骨折大致愈合时间(指骨头连接、能开始逐渐负重,完全恢复力量和功能还需要更长时间):

| 部位 | 大致愈合时间 |
|------|------|
| 手指、脚趾 | 3-5周 |
| 锁骨 | 6-10周 |
| 肋骨 | 约6周 |
| 前臂、手腕 | 6-8周 |
| 上臂 | 6-10周 |
| 舟骨(手腕) | 10-12周,常更长 |
| 小腿(胫骨) | 3-6个月 |
| 大腿(股骨) | 3-4个月以上 |
| 脊柱压缩性骨折 | 约3个月 |

儿童往往只需成人的一半左右时间;老人、吸烟、糖尿病、营养不良、开放性骨折、骨折处反复活动,愈合都会变慢。

```
康复阶段:
1. 固定期间:
   - 没有被固定的关节要每天活动
     (如前臂打石膏时,手指、肩膀照常活动;小腿固定时,脚趾和髋部活动)
   - 被固定的肢体做"肌肉绷紧-放松"练习(肌肉用力但关节不动),减少肌肉萎缩
   - 夹板固定的: 每天检查皮肤有没有压红、磨破;
     肿胀消退后夹板会变松,要重新衬垫、绑紧
   - 长期卧床的: 预防压疮、多做深呼吸,防止肺炎和血栓
2. 拆除固定后:
   - 关节会僵硬、肌肉会变细,这是正常的
   - 先恢复活动范围,再练力量,再逐步负重;
     下肢从拄拐部分负重开始,按医生指导逐步过渡到完全负重
   - 练习时可以有轻微酸痛,疼痛明显加重、肿胀加重就要减量
3. 饮食: 足够的蛋白质(豆类、蛋、肉、鱼)、钙(奶、豆制品、带骨小鱼)、
   维生素D(晒太阳),戒烟

⚠️ 需要复诊:
- 骨折处长期(超过预计时间)仍有疼痛、异常活动 → 可能不愈合
- 肢体逐渐弯曲、变短 → 可能畸形愈合
- 小腿、大腿突然肿胀疼痛,或突然胸痛、气短 → 可能是血栓,立即就医
```

长期储备粮条件下怎样保证蛋白质和维生素,见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md)。

```
无法得到医疗救治时(偏远地区、灾后长期断联):
- 仍然是固定 + 等待愈合: 固定时间至少按上表,
  下肢骨折在固定期间不要负重,用拐杖
- 夹板要更认真地衬垫,每天检查皮肤和远端血运
- 开放性骨折: 每天换敷料,观察感染迹象;
  这种情况风险极高,仍要想尽办法联系医疗人员
- 不要自己尝试"正骨"、拉直已经愈合了一段时间的畸形
```

### ⚠️ 立即就医

所有骨折都应就医!

特别紧急:
- 开放性骨折
- 大量出血
- 严重变形
- 远端麻木、苍白、无脉
- 脊柱或颈椎损伤
- 头部、胸部、骨盆骨折

还包括: 大腿骨折、髋部骨折、疼痛越来越重且固定不能缓解(骨筋膜室综合征)、出现休克征象、呼吸困难。

## 脱臼

### 定义

关节骨端脱离正常位置

脱臼时关节周围的韧带、关节囊一定已经撕裂,还经常同时有骨折,或压迫附近的血管和神经。所以脱臼不是"把骨头推回去就好了"的小伤。

### 常见部位

- 肩关节(最常见)
- 肘关节
- 手指
- 髋关节
- 膝盖骨(髌骨)
- 下颌

### 症状

- 关节变形
- 剧烈疼痛
- 肿胀
- 活动受限或无法活动
- 可能伴随麻木

各部位的典型表现:

| 部位 | 典型表现 |
|------|------|
| 肩关节 | 肩膀外侧的圆形轮廓消失,变"方";伤员用好手托着伤侧手臂,手臂稍离开身体,不能贴近胸前 |
| 肘关节 | 多见于手撑地摔倒,肘后方明显突出,肘部固定在半屈位 |
| 手指 | 关节处明显错位、成角,常见于球类运动 |
| 髋关节 | 车祸时膝盖撞到仪表盘最常见;伤腿缩短、向内旋转,膝关节微屈 |
| 髌骨 | 膝盖骨滑到膝关节外侧,膝盖弯着伸不直 |
| 下颌 | 打哈欠、大笑后嘴张着合不上,说话不清,流口水 |

### 处理原则

```
❌ 绝对禁止:
- 自行复位(除非受过专业训练)
- 强行活动

✓ 正确做法:
1. 保持原位
2. 固定关节
3. 冰敷
4. 尽快就医
```

```
补充:
1. 让伤员自己找到最不痛的姿势,按这个姿势固定(这就是"保持原位")
2. 固定前后检查远端的颜色、温度、感觉、脉搏
   - 肩关节脱臼: 检查肩外侧一小块皮肤的感觉(腋神经)和手指的感觉
   - 远端发凉、苍白、无脉 → 血管受压,紧急送医
3. 冰敷,每次15-20分钟
4. 不要吃东西喝水(医生可能需要在麻醉或镇静下复位)
5. 越早复位越容易: 时间拖得越长,肌肉痉挛越重,复位越难,
   所以"尽快就医"是真的尽快,不要等到第二天
```

### 固定方法

**肩关节脱臼**:
```
1. 在腋下垫软垫(如毛巾卷)
2. 前臂悬吊于胸前
3. 宽布条固定上臂于躯干
```

```
补充:
- 伤侧手臂常常不能贴到胸前,不要硬压;
  在手臂和胸壁之间塞入足够厚的枕头或卷起的衣物填满空隙,再悬吊固定
- 伤员坐着去医院,通常比躺着舒服
```

**肘关节脱臼**:
```
1. 保持原位(不要强行弯曲或伸直)
2. 软垫支撑
3. 三角巾悬吊或夹板固定
```

**手指脱臼**:
```
1. 夹板固定在原位
2. 冰敷
3. 就医
```

手指脱臼同样要先摘掉戒指。拇指根部的脱臼和伴有伤口的手指脱臼更容易出问题,一定要就医。

**髋关节脱臼**:
```
⚠️ 急症: 股骨头的血供可能被切断,拖延数小时后可能坏死
1. 拨打120,不要移动伤员
2. 按受伤时的姿势,用枕头、毯子在腿下和两侧垫实,防止晃动
3. 常合并骨折和其他重伤,按大腿骨折和休克处理
```

**髌骨脱位**:
```
1. 膝盖保持在伤员最舒服的角度,膝下垫毯子卷
2. 不要强行伸直(有时伸直时膝盖骨会自己滑回去,这不用怕,但不要人为去推)
3. 固定膝部,就医检查有没有骨折和软骨损伤
```

**下颌脱位**:
```
1. 用手或宽布托住下颌,不要用绷带把头和下巴绑紧(会妨碍呕吐时清理口腔)
2. 尽快就医,医生通常可以很快复位
```

已经自己复位了(比如反复脱臼的肩膀自己滑回去了)也要固定、就医,检查有没有骨折和神经损伤。

### 复位

⚠️ 仅由医生操作!

**例外**: 在野外偏远地区,无法及时就医,且:
- 远离医疗点数小时以上
- 受过专业训练
- 肩关节脱臼且有经验

```
为什么不让没受过训练的人复位:
- 看起来像脱臼的,可能是关节附近的骨折,或骨折合并脱臼,
  强行复位会使骨折移位、刺破皮肤
- 用错方法、用力过猛,可能拉伤腋窝、肘部的神经和血管,造成永久瘫痪或缺血
- 髋关节、肘关节脱位复位需要很大力量,常需麻醉,现场基本不可能做好

上面的"例外"也只针对肩关节、手指等少数部位,
而且以受过野外急救或医学培训为前提;
本书不提供复位手法,没受过训练的人不要照着视频或文字尝试

完全无法得到医疗救治时,没有受过训练的人:
- 把关节按伤员最舒服的姿势固定好,止痛,冰敷
- 想尽办法转运或联系医疗人员(哪怕需要几天)
- 关节自己滑回去了(伤员突然感到"咯噔"一声、疼痛明显减轻、形状恢复),
  照样固定2-3周,然后逐渐活动
```

野外转运的判断见[野外伤病处置与转运-原地等待还是自行撤出](../03-野外生存/11-野外伤病处置与转运.md#原地等待还是自行撤出)。

### 脱臼 vs 骨折

有时难以区分,处理相同:
- 固定
- 冰敷
- 就医

脱臼复位后,关节一般需要固定2-3周(肩关节初次脱臼的年轻人,复发率很高,需要遵医嘱固定和康复训练)。固定期间和拆除后的锻炼原则与骨折康复相同。

## 扭伤

扭伤是关节周围的韧带(连接骨头和骨头的坚韧纤维)被拉长或撕裂。最常见的是脚踝外侧向内崴("崴脚"),其次是手腕、膝盖、手指。

### 分级

**I度(轻度)**:
- 轻微疼痛和肿胀
- 韧带拉伸,无撕裂
- 能行走

**II度(中度)**:
- 明显疼痛和肿胀
- 韧带部分撕裂
- 关节不稳
- 行走困难

**III度(重度)**:
- 剧烈疼痛(后可能减轻)
- 严重肿胀和淤血
- 韧带完全断裂
- 关节明显不稳
- 无法承重

III度扭伤的疼痛反而可能没有II度重(韧带完全断了,没有东西被牵拉),不要因为"不太痛"就判断为轻伤,关节松动、站不稳才是关键。

### 扭伤 vs 骨折

难以区分时,按骨折处理!

**考虑骨折如果**:
- 剧烈疼痛
- 严重变形
- 无法活动
- 骨性压痛

```
脚踝扭伤后,以下任何一条 → 按可能骨折处理,固定,去拍X光:
- 受伤后当时和检查时都不能用伤脚走4步(哪怕一瘸一拐)
- 按压脚踝内侧或外侧突起骨头(踝骨)的后缘和最下端,剧痛
  (从下端往上约6 cm的范围内)
- 按压脚外侧中段的骨性突起(第五跖骨基底)或足内侧中部,剧痛

膝关节扭伤后:
- 很快(几小时内)明显肿起来 → 关节内出血,可能韧带断裂或骨折
- 膝盖"卡住"伸不直、或走路时"打软腿" → 就医
```

### RICE处理(I-II度)

RICE 指休息、冰敷、加压、抬高,用于受伤后最初2-3天,目的是控制肿胀和疼痛。

#### R - Rest(休息)

```
- 避免使用受伤关节
- 前48-72小时尤其重要
- 使用拐杖(下肢扭伤)
```

```
补充:
- 休息不等于完全不动: 不引起明显疼痛的轻微活动(如活动脚趾)从第一天就可以做
- 下肢: 疼得不能正常走时用拐杖,伤脚可以轻轻着地,随疼痛减轻逐步多用力
- 没有拐杖: 结实的长木棍、扫把(顶端缠布垫在腋下或手握),拐杖拿在健侧手
```

#### I - Ice(冰敷)

```
前48小时:
- 每2-3小时一次
- 每次15-20分钟
- 冰袋用毛巾包裹

作用:
- 减轻肿胀
- 减少疼痛
- 减少内出血
```

```
补充:
- 越早开始越好
- 没有冰: 冷冻蔬菜袋、冷水浸湿的毛巾、把脚泡在凉的自来水或溪水里
- 皮肤先感到冷、再刺痛、再发麻 → 发麻时就停,不要超过20分钟
- 糖尿病、雷诺病(手指遇冷发白)、感觉迟钝的人,以及婴幼儿和老人,缩短时间
- 不要冰敷着睡觉
```

#### C - Compression(加压包扎)

```
方法:
- 弹性绷带(8字包扎)
- 从远端向近端
- 松紧适中

检查:
- 每小时检查血液循环
- 脚趾/手指温暖、颜色正常
- 如肿胀加重,松开重新包扎
```

```
脚踝"8"字包扎具体做法:
1. 脚保持和小腿成直角
2. 从脚趾根部开始,在脚掌上绕两圈固定绷带头
3. 斜着从脚背绕到脚踝后方,再从另一侧斜着回到脚背,
   形成"8"字,每圈压住上一圈的一半到三分之二
4. 一直包到小腿下段(踝上约10-15 cm),脚趾露在外面
5. 远端稍紧、近端稍松,不要在某一处特别紧
6. 睡觉时如果已经把腿抬高,可以把绷带稍微松开

✗ 不要用不透气的胶带一圈一圈缠紧
✗ 不要因为"包得越紧越消肿"而勒得发紫
```

#### E - Elevation(抬高)

```
- 高于心脏水平
- 尽可能多的时间
- 休息和睡觉时
```

脚踝扭伤时,躺下在小腿下垫两三个枕头,让脚踝高过心脏;坐着把脚搭在椅子上只能算"抬起",高度不够,消肿效果差。

### 48-72小时后

**热敷**:
```
- 促进血液循环
- 加速愈合
- 温热毛巾或热水袋
- 每次15-20分钟
```

热敷在肿胀不再增加、局部不再发热后开始;如果热敷后肿痛加重,说明太早了,改回冰敷。热水袋用毛巾包好,不要烫伤。

**轻柔活动**:
```
- 逐渐恢复活动范围
- 拉伸运动
- 不要疼痛
```

```
什么时候开始活动、怎么练(以脚踝为例):
现在的主流做法是"早活动、适度负重",比长时间完全制动恢复得更好更快

1. 受伤后1-3天(肿胀不再加重时)开始:
   - 坐着用脚尖在空中"写"0-9的数字,或画圈,每次几分钟,每天数次
   - 能忍受的情况下开始用伤脚负重走路(可借助拐杖或护踝)
2. 判断标准:
   - 练习时和练习后有轻微酸胀,第二天没有更重 → 合适
   - 疼痛明显加重、第二天更肿 → 减量,退回前一步
3. II度扭伤走路时最好穿高帮鞋或戴护踝,起保护作用
```

**加强锻炼**:
```
- 1-2周后(视恢复情况)
- 力量训练
- 平衡训练
- 预防再次扭伤
```

```
具体练习:
- 力量: 踮脚尖(提踵)10-15次×3组;用弹力带或毛巾绕住脚掌,
  向四个方向用力对抗
- 平衡: 伤脚单脚站立,从扶着墙开始,能坚持30秒后改为闭眼或站在软垫上
- 能恢复运动的标准: 伤脚单脚跳、快跑、急转都不痛,两侧力量和平衡差不多

⚠️ 很多人"不痛了就不练",结果反复崴脚(慢性踝关节不稳)
   平衡训练坚持到伤后至少6周
```

### 药物

**口服**:
- 布洛芬(抗炎止痛)
- 对乙酰氨基酚(止痛)

**外用**:
- 消肿止痛喷雾
- 跌打损伤膏

按说明书剂量使用。外用药不要涂在破损的皮肤上;含"活血化瘀"成分的药(如红花油一类)通常建议受伤48小时、肿胀稳定后再用,孕妇慎用含麝香等成分的药膏,具体看说明书。布洛芬的禁忌见上文骨折一节的止痛。

### 恢复时间

- **I度**: 1-2周
- **II度**: 3-6周
- **III度**: 数月,可能需手术

韧带的强度在疼痛消失以后还要几个月才能完全恢复,这期间最容易再次扭伤。

### 预防再次扭伤

```
✓ 完全康复后再恢复运动
✓ 充分热身
✓ 使用护具(护踝、护腕)
✓ 力量和平衡训练
✓ 选择合适的鞋
✓ 注意地面情况
```

### ⚠️ 就医指征

立即就医如果:
- III度扭伤
- 无法承重或行走
- 严重变形
- 麻木或刺痛
- 关节明显不稳
- 肿胀严重
- 自行处理3天无改善

还包括: 符合上文"按可能骨折处理"的任何一条;儿童关节处扭伤后持续疼痛(可能是生长板损伤);同一个关节反复扭伤。

## 📝 总结要点

### 骨骼损伤ABC

**A - Assessment(评估)**
- 评估伤情
- 检查生命体征
- 判断骨折、脱臼或扭伤

**B - Be still(制动)**
- 不要移动
- 原位固定
- 保护受伤部位

**C - Call for help(寻求帮助)**
- 严重伤及时就医
- 脊柱伤等待专业救援

### 记住

```
✓ 严重伤不要移动
✓ 固定上下关节
✓ 检查血液循环
✓ 冰敷减轻肿胀
✓ 及时就医

❌ 不要复位
❌ 不要推回骨头
❌ 不要活动受伤部位
```

```
✓ 先救命,再处理骨折: 呼吸、大出血、休克优先
✓ 固定前摘掉戒指、手镯
✓ 夹板要垫好,绑带避开伤处,能伸进一根手指
✓ 疼痛越来越重、固定也不缓解 → 想到骨筋膜室综合征
✓ 骨盆、大腿骨折会大量内出血 → 原地不动,防休克,拨打120
✓ 肋骨骨折不要缠紧胸部,要能深呼吸和咳嗽
✓ 扭伤早期RICE,1-3天后在不加重疼痛的范围内早活动
✓ 区分不了骨折还是扭伤 → 按骨折处理
```

### 何时立即就医

- 所有骨折
- 严重脱臼
- III度扭伤
- 脊柱或颈椎伤
- 变形明显
- 疼痛剧烈
- 麻木或血循环差
