## 现场评估与呼救

### 第一步: 先看现场安全

救人之前先花几秒钟看一圈,**救援者自己受伤,伤员就少了一个帮手,多了一个伤员**。

| 现场危险 | 先做什么 |
|----------|----------|
| 马路上 | 打开双闪,在来车方向放三角警示牌(高速公路约150 m 外),穿反光背心;不要站在车流中 |
| 触电 | 先断电(拉闸、拔插头),或用干燥木棍挑开电线;断电前不要碰伤员。见[电击伤](05-急性症状.md#电击伤) |
| 燃气味、烟、火 | 不开关电器、不打电话,先开窗或撤离,到安全处再打电话 |
| 密闭空间(地窖、沼气池、粪池、井) | 不要贸然下去,先通风、呼叫专业救援;连续多人下去施救而死亡的事故很常见 |
| 水中 | 优先"叫、伸、抛",不会救生的人不要下水。见[溺水](05-急性症状.md#溺水) |
| 不明有毒物质 | 远离、站在上风方向,不用嘴对嘴吹气 |
| 血液、体液 | 有手套戴手套,没有可用塑料袋套手;事后洗手 |

### 第二步: 判断伤员情况

```
1. 拍双肩、对两耳大声呼唤:"你怎么了?能听见吗?"
   (婴儿: 拍脚底)
2. 同时看胸腹部有没有起伏,观察5-10秒
3. 快速扫一眼有没有大量出血(衣服大片浸湿、地上有血泊)

  无反应 + 没有呼吸或只有濒死喘息 → 立即呼救,开始CPR
  无反应 + 有正常呼吸           → 呼救,摆成复苏体位,持续观察
  有大出血                     → 呼救,立即止血
  清醒                         → 问清哪里不舒服、发生了什么
```

**濒死喘息**: 像叹气、抽泣一样,很慢、不规律、嘴巴一张一合,常见于心脏骤停后的最初几分钟。**这不是正常呼吸**,按没有呼吸处理。

### 第三步: 呼救

```
1. 大声喊人:"快来人啊!这里有人晕倒了!"
2. 指定具体的人做具体的事(不要说"谁去打电话",没人会动):
   "穿红衣服的大哥,请你打120!"
   "你去拿AED!"(商场、地铁站、机场等常见)
3. 只有自己一个人时:
   - 有手机: 打120,开免提放在旁边,边按压边听调度员指导
   - 没有手机、伤员是成人: 先离开去打电话、拿AED,再回来做CPR
   - 没有手机、伤员是儿童或婴儿,或溺水者: 先做约2分钟CPR,再去求救
     (这些人多半是缺氧导致的心脏骤停,先给氧更重要)
```

### 打120时说清楚什么

**最重要的是地址**: 电话断了、伤员情况说不清都可以补救,地址说错救护车就找不到人。

```
1. 详细地址: 区、街道、小区名、楼号、单元、楼层、门牌号
   - 在路上: 路名 + 最近的路口、门店、公交站、路边桩号
   - 在野外: 手机地图上的坐标,或明显地标
2. 发生了什么: "一个50岁左右的男人突然倒地,叫不醒,没有呼吸"
3. 几个人受伤,目前情况: 有没有意识、有没有呼吸、有没有大出血
4. 已经做了什么: "我们已经在做心肺复苏"
5. 你的电话号码,保持畅通
6. 回答调度员的问题,等对方说可以挂再挂
```

接完电话后:

- 派人到小区门口、路口接救护车,打开楼道门、电梯
- 把伤员的病历、正在吃的药收拢,一起交给急救人员
- 记下发病时间、做了哪些处理(如止血带时间)

其他紧急电话见[主目录-紧急电话](../../README.md)。无法通话时可发短信报警12110。

## 生命体征评估

生命体征(意识、呼吸、脉搏、皮肤、体温、血压)告诉你伤员**现在**有多危险,以及**情况在变好还是变坏**。单次数值不如连续记录有意义: 每5-15分钟测一次,写下时间和数值,交给医生。

### ABC原则

在任何急救情况下,首先检查:

> ⚠️ 如果伤者**无反应且没有正常呼吸**,不要逐项检查,立即呼救并开始心肺复苏。现行指南的复苏顺序是**C-A-B(先按压)**,见下文。

此外,**有危及生命的四肢大出血时,先止血**(30秒内就可能流失致命的血量),再查气道和呼吸。

#### A - Airway (气道)
- **检查**: 气道是否通畅
  - 能说话、能哭 → 气道通畅
  - 打鼾样、咕噜咕噜的声音 → 舌根后坠或有分泌物/呕吐物堵塞
  - 不能说话、不能咳嗽、双手掐住脖子 → 可能是异物完全堵塞,见[喉咙异物/气道梗阻](04-异物处理.md#喉咙异物气道梗阻)
- **处理**:
  - 清除口腔异物(只取看得见的,不要盲目用手指掏)
  - 将头部后仰,下巴抬起(方法见[气道与复苏体位](#气道与复苏体位))
  - 侧卧位防止呕吐物堵塞

#### B - Breathing (呼吸)
- **检查**: 是否有呼吸
  - 看:胸部起伏
  - 听:呼吸声音
  - 感:脸颊感受气流
- **正常**: 成人12-20次/分钟
- **数法**: 看胸部或腹部一起一伏算1次,数30秒乘以2;不要告诉对方你在数(人一注意就会改变呼吸)
- **危险信号**: 成人超过30次/分或低于10次/分;说话说不成句;嘴唇发紫;呼吸时用力耸肩、肋间凹陷

#### C - Circulation (循环)
- **检查**: 脉搏和出血
  - 颈动脉:喉结旁2-3 cm
  - 桡动脉:手腕拇指侧
- **正常**: 成人60-100次/分钟
- **数法**: 用食指和中指(不要用拇指,拇指自己有脉搏)轻按,数30秒乘以2;脉搏不规则时数满60秒,同时留意强弱是否一致
- **意义**: 摸得到手腕的脉搏,说明血压还不算太低;手腕摸不到、只在颈部摸得到,说明情况严重
- **毛细血管再充盈**: 按压指甲床5秒后松开,正常2秒内恢复粉红;超过2秒提示循环不好(寒冷时会不准)
- 非专业人员摸颈动脉判断心脏骤停很容易出错,**不要因为找脉搏耽误CPR**

### 意识水平评估(AVPU)

- **A - Alert**: 清醒,能正常对话
- **V - Voice**: 对声音有反应
- **P - Pain**: 仅对疼痛刺激有反应
- **U - Unresponsive**: 完全无反应

**怎么用**:
- 清醒的人还要问"你叫什么?现在在哪里?今天几号?",答不对说明意识已经受影响
- 疼痛刺激: 用力捏肩膀上方的肌肉,或用笔杆压指甲床,看有没有皱眉、躲闪
- 只要低于A(需要叫才醒或叫不醒),都应拨打120;从A向V、P、U变化,说明情况在恶化,要告诉急救人员
- 意识差但有正常呼吸的人,摆成复苏体位,防止舌根后坠和呕吐物误吸

### 生命体征正常范围

| 年龄 | 呼吸(次/分) | 心率(次/分) | 备注 |
|------|--------------|--------------|------|
| 新生儿-1岁 | 30-60 | 100-160 | 婴儿数呼吸看腹部起伏 |
| 1-3岁 | 24-40 | 90-150 | |
| 3-6岁 | 22-34 | 80-140 | |
| 6-12岁 | 18-30 | 70-120 | |
| 12岁以上和成人 | 12-20 | 60-100 | 运动员静息心率可低至50左右 |

儿童的数值各指南略有出入,上表为大致范围;哭闹、发热时会明显升高,应在安静时测。

| 项目 | 成人正常 | 需要警惕 |
|------|----------|----------|
| 体温(腋下) | 36.0-37.0°C | 高于37.3°C为发热;低于35°C为失温 |
| 血压(上臂) | 收缩压90-139 mmHg,舒张压60-89 mmHg | 收缩压低于90 mmHg且有头晕、湿冷 → 休克可能;高于180/110 mmHg → 就医 |
| 血氧(指夹式血氧仪) | 95%-100% | 低于94%需就医,低于90%为急症(手冷、涂指甲油时读数不准) |
| 皮肤 | 温暖、干燥、颜色正常 | 苍白湿冷(休克)、发紫(缺氧)、潮红灼热(中暑、发热) |

体温的测量方法和发热分级见[常见疾病-发烧](01-常见疾病.md#发烧),失温见[失温症](05-急性症状.md#失温症)。

### 从头到脚检查

确认没有危及生命的问题后,对清醒或稳定的伤员做一次全身检查,找出被忽视的伤:

```
1. 问: 哪里疼?发生了什么?有什么病?在吃什么药?对什么过敏?
       上一次吃饭是什么时候?
2. 从头到脚看、摸,每处两侧对比:
   头颈 → 胸 → 腹 → 骨盆 → 双腿 → 双臂 → 背部(能翻动时)
3. 看: 出血、肿胀、变形、伤口、瞳孔两侧是否一样大
   摸: 压痛、骨擦感、皮肤温度
4. 疑似脊柱损伤的人,检查时不要转动头颈和身体
5. 记录检查结果和时间
```

## 气道与复苏体位

### 开放气道: 仰头抬颏法

意识不清的人仰卧时,舌根会后坠堵住喉咙。这是昏迷者窒息最常见的原因。

```
1. 伤员仰卧
2. 一只手放在前额,手掌向后下方压,使头后仰
3. 另一只手的食指和中指放在下巴骨头(下颌骨)上,向上抬起
   - 不要压下巴下面的软组织,会把舌头顶向喉咙
4. 成人: 头后仰到下颌角和耳垂的连线与地面垂直
   儿童: 后仰幅度小一些
   婴儿: 头保持"嗅物位"(像在闻东西),不要过度后仰,
         可在肩下垫一块折叠的毛巾
```

**疑似颈椎损伤**: 专业人员用"托下颌法"(双手托住下颌角向上提,头不后仰)。但如果托下颌打不开气道,**呼吸比颈椎更重要**,仍要仰头抬颏。

### 复苏体位(侧卧位)

**适用**: 无反应但有正常呼吸的人(醉酒、癫痫发作后、低血糖昏迷、中毒等)。**不适用**: 没有正常呼吸(要做CPR)。

```
1. 跪在伤员一侧,取下眼镜、口袋里的硬物
2. 把靠近你的手臂向上摆成直角,手心朝上
3. 把远侧手臂拉过胸前,手背贴在靠近你这侧的脸颊上,用手按住
4. 另一只手抓住远侧腿的膝盖下方,把膝盖拉起,脚掌踩地
5. 拉住膝盖把伤员朝你这侧翻过来,成侧卧
6. 上面那条腿的髋和膝都弯成直角,防止翻成趴着
7. 头稍后仰,嘴朝下,让呕吐物和口水能流出来
8. 盖上衣物保暖,每分钟检查一次呼吸
9. 侧卧超过30分钟时,换到另一侧,防止压伤下面的手臂
```

- 孕妇(肚子已明显隆起)优先**左侧卧**,减少子宫压迫大血管
- 婴儿: 抱在你的手臂上,脸朝下、头略低于身体,托住下巴和头
- 疑似脊柱损伤又必须侧卧时(如在呕吐、只有你一个人要离开求援): 多人配合,保持头颈躯干一条线整体翻转
- 呼吸一旦变得不正常或停止 → 立即翻回仰卧,开始CPR

## 心肺复苏(CPR)

心脏骤停后,大脑缺血4-6分钟就开始出现不可逆的损伤,每延迟1分钟,存活率下降约7%-10%。救护车在城市里通常也要10分钟以上才能到,**这段时间只能靠现场的人**。高质量的胸外按压能维持脑和心脏最基本的血流,为除颤和专业救治争取时间。

### 何时进行CPR
- 无反应
- 无呼吸或仅有濒死喘息
- 非专业人员不需要检查脉搏(容易误判,延误抢救),满足以上两条即开始按压

刚倒地时可能有几秒钟的抽搐,容易被误认为癫痫,**抽完后不呼吸,就是心脏骤停**。

不用担心"对方其实心跳还在,按压会伤到他": 对没有心脏骤停的人按压,造成严重伤害的情况很少;而该按不按,几乎必死。

### 成人CPR步骤

#### 1. 确认安全和呼救
```
1. 确保现场安全
2. 轻拍肩膀:"你还好吗?"
3. 如无反应,立即呼救
4. 拨打120急救电话
```

同时让人去拿AED。把伤员仰卧放在**硬的平面**上(地面最好;床垫太软,按压力量会被吸收,应移到地上)。

#### 2. 胸外按压
- **位置**: 胸骨中下1/3,两乳头连线中点
- **深度**: 5-6 cm
- **频率**: 100-120次/分钟
- **手法**:
  ```
  1. 跪在伤者旁边
  2. 一手掌根放在胸骨上
  3. 另一手掌根叠放在上面
  4. 手臂伸直,垂直向下按压
  5. 每次按压后完全放松,但手不离开
  ```

**要领**:
- 解开或剪开上衣,手直接放在胸部皮肤上,才能找准位置
- 两手手指交叉翘起,只用掌根着力,手指不压肋骨
- 肩膀在伤员胸部正上方,以髋关节为轴,用上半身的重量往下压,不是用手臂的力气
- 节奏: 按"一、二、三……"大声数,大约每秒2次
- **尽量不中断**: 换人、做人工呼吸、AED分析时,中断都不要超过10秒
- 两人以上时每2分钟(约5轮30:2)换一个人按,换人在5秒内完成;按压者自己往往察觉不到已经累得按浅了

**按对了的样子**: 每次能看到胸部明显下陷,松开时完全弹回;有人在旁边数节奏和次数。

**肋骨骨折**: 老人按压时常听到"咔"的一声,这是肋骨或软骨断了。**不要停**,检查手的位置没有偏,继续按。骨折可以治,心跳停了不能。

#### 3. 人工呼吸(如果会做)
- 每30次按压后,进行2次人工呼吸
- 每次吹气1秒,看到胸部隆起即可
- 如果不会或不愿意,只做胸外按压也可以

**做法**:
```
1. 仰头抬颏打开气道
2. 放在前额的手捏住伤员鼻子
3. 正常吸一口气(不要深吸),嘴完全包住伤员的嘴
4. 吹气约1秒,同时用眼角看胸部是否隆起
5. 松开嘴和鼻子,让气体呼出,再吹第2口
6. 两次吹气总共不超过10秒,然后马上恢复按压
```

- 胸部不起来: 重新调整头部位置再试;还不行就不再纠缠,继续按压(下次吹气前看一眼口腔有没有异物)
- 吹气过猛过多会把气吹进胃里,引起呕吐
- 有CPR面罩或隔离膜时使用;中毒(尤其是农药、氰化物)者不要直接嘴对嘴
- 伤员呕吐时: 把头和身体一起侧过来,清理口腔后翻回继续

#### 只按压不吹气(只按压CPR)

- **适用**: 没受过培训、不会或不愿意做人工呼吸的人;成人突然倒地的心脏骤停
- 做法: 按上面的位置、深度、频率**连续按压**,不停顿,直到AED到达或急救人员接手
- 成人突发心脏骤停的最初几分钟,血液里还有氧气,单纯按压的效果和标准CPR接近
- **儿童、婴儿、溺水、窒息、中毒导致的心脏骤停**,本来就是缺氧引起的,人工呼吸更重要;会做的话一定要做。见[溺水-上岸后处理](05-急性症状.md#2-上岸后处理)

#### 4. 持续CPR
- 按照30:2的比例持续
- 直到:
  - 急救人员到达
  - 伤者恢复呼吸和脉搏
  - 你已精疲力竭无法继续

**怎样判断恢复了**: 非专业人员不必摸脉搏,看到伤员**开始动、睁眼、咳嗽、出现正常呼吸**,就可以停下来,摆成复苏体位,密切观察;一旦再次没有正常呼吸,立即重新按压。

**其他可以停止的情况**:
- 现场出现新的危险(起火、塌方、来车),救援者必须撤离
- 有明确的死亡征象: 身体已经冰冷僵硬、出现尸斑,或有头部离断等不可能存活的伤
- 在完全没有专业救援可等的环境里(偏远地区、灾后),持续高质量CPR约30分钟以上,伤员始终没有任何生命迹象,复苏成功的可能已极低,停止是可以接受的决定。**低体温和冷水溺水者例外**,应坚持更久,见[失温症](05-急性症状.md#失温症)

### 孕妇、老人和特殊情况

- **孕妇**: 按压位置和方法与成人相同。肚子明显隆起(约孕5个月以上)时,另一人站在伤员左侧,用双手把子宫向伤员的左侧推,减轻子宫压迫大血管。同时告诉120是孕妇
- **老人**: 骨质疏松,更容易骨折,但按压深度不能因此减少
- **戴活动假牙**: 做人工呼吸前取出松动的假牙,见[口腔问题](09-口腔问题.md)
- **在床上或车内**: 尽量移到地面;实在不能移,在背下垫硬木板
- 中毒、触电、溺水、窒息、过敏导致的心脏骤停,CPR方法相同,同时注意救援者自身安全

### 儿童和婴儿CPR区别

| 项目 | 成人 | 儿童(1岁至青春期) | 婴儿(<1岁) |
|------|------|-------------|------------|
| 按压深度 | 5-6 cm | 约5 cm(胸廓厚度的1/3) | 约4 cm(胸廓厚度的1/3) |
| 按压方式 | 双手 | 单手或双手 | 双手环抱、两拇指按压<br>或单手掌根 |
| 按压位置 | 胸骨中下1/3 | 胸骨中下1/3 | 两乳头连线下方 |
| 按压频率 | 100-120次/分 | 100-120次/分 | 100-120次/分 |
| 按压呼吸比 | 30:2 | 30:2(单人)<br>15:2(双人) | 30:2(单人)<br>15:2(双人) |
| 吹气方式 | 口对口 | 口对口 | 口同时包住婴儿的口和鼻 |
| 吹气量 | 胸部隆起即可 | 胸部隆起即可 | 只用脸颊里的一小口气,胸部微微隆起即可 |
| 只有一人、没有手机时 | 先求救,再CPR | 先CPR约2分钟,再求救 | 先CPR约2分钟,再求救 |

**判断婴儿有无反应**: 拍打脚底、大声呼唤,不要摇晃。

**婴儿按压**:
```
1. 婴儿仰卧在硬的平面上(桌面、地面)
2. 首选: 双手环抱婴儿胸部,两拇指并排放在两乳头连线中点正下方的胸骨上按压,
   其余手指托住背部
3. 手小、或一个人既要按压又要吹气时: 用一只手的掌根按在同一位置
   (旧教材的"两指按压"往往按不到足够深度,新版指南已不再推荐)
4. 不要按在胸骨最下端的剑突上(容易伤到肝脏)
5. 婴儿非常小时可以把婴儿托在前臂上按压,但要保持头颈平直
```

- 青春期(出现乳房发育、喉结、腋毛)以后,按成人处理
- 新生儿刚出生不哭不呼吸的处理见[紧急分娩与新生儿护理](11-紧急分娩与新生儿护理.md#宝宝不哭不呼吸)
- 儿童心脏骤停多由窒息、溺水、严重感染等缺氧引起,**人工呼吸比成人更重要**
- 家长学会儿童CPR和异物梗阻急救,见[儿童安全](14-儿童安全.md)和[喉咙异物/气道梗阻](04-异物处理.md#喉咙异物气道梗阻)

### 自动体外除颤器(AED)使用

如果现场有AED设备:

```
1. 打开AED电源
2. 按照语音提示操作
3. 撕开衣服,擦干胸部
4. 贴上电极片(按图示位置)
5. 确保无人触碰伤者
6. 按下"分析"按钮
7. 如提示需要除颤,按下"电击"按钮
8. 立即继续CPR
```

**AED是什么**: 很多心脏骤停是心脏发生了"室颤"(心肌乱颤、不泵血),只有电击能让它恢复正常节律。AED会自动分析心律,**只在需要时才允许电击**,不会误电正常人,外行也能用。越早电击越好,倒地3-5分钟内除颤,存活率可大幅提高。

**常见位置**: 机场、地铁站、火车站、商场、体育馆、学校、写字楼大堂,标志通常是绿色或红色的心形加闪电图案。拨打120时调度员也可能告诉你附近哪里有。

**电极片怎么贴**:
```
成人(前-侧位,电极片上都有图示):
- 一片贴右胸上方: 右锁骨下方、胸骨右侧
- 一片贴左胸侧下方: 左乳头外侧、腋下下方约一掌宽处
```

**要点**:
- AED到达后**一边按压一边贴片**,不要停下按压去等
- 胸毛很浓密贴不牢时,用力压紧;有剃刀时快速刮掉
- 避开皮肤上的药物贴片(撕掉擦净)和锁骨下鼓起的起搏器
- 伤员躺在水里或雪里时,先拖到相对干燥处,擦干胸部;躺在金属地面上一般也可以用
- 分析和电击时大声说"大家都离开!",确认没有人碰到伤员
- 很多AED会自动分析,不需要按"分析"键;部分全自动机型会直接放电,听提示即可
- 电击后不要检查脉搏,**立即按压2分钟**,AED会自动再次分析
- 提示"不建议电击"时,同样立即继续CPR
- 电极片贴上后不要撕下,即使伤员已恢复呼吸,直到急救人员接手

**儿童和婴儿**:
- 8岁以下或体重不到25 kg的儿童,有儿童电极片或儿童模式(钥匙/开关)时使用
- 没有儿童电极片时**可以用成人电极片**;两片在胸前会相互接触时,改为一片贴胸前正中、一片贴背部两肩胛骨之间
- 婴儿也可以使用AED,首选带儿童模式的机型

### CPR常见错误

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 花很长时间找脉搏、听心跳 | 延误按压 | 无反应+无正常呼吸,10秒内开始按压 |
| 把濒死喘息当成有呼吸 | 错过抢救时机 | 慢、不规律、像叹气 → 按无呼吸处理 |
| 在床上、沙发上按压 | 按压无效 | 移到地上 |
| 按压太浅、太慢 | 没有足够血流 | 至少5 cm,至少100次/分,用上半身重量 |
| 手位置偏到肋骨或肚子上 | 骨折、内脏损伤、按压无效 | 胸骨下半段,掌根着力 |
| 每次按完不完全放松 | 心脏无法充盈 | 让胸部完全弹回,手不离开 |
| 频繁中断 | 每次停顿血压就归零,需重新按起来 | 中断不超过10秒 |
| 怕伤到人不敢按 | 伤员几乎必死 | 立即开始,按错也比不按好 |

## 止血方法

成年人全身约有5 L 血液,短时间内失去约1 L(相当于一个大号矿泉水瓶的2/3),就会出现休克;**四肢大动脉破裂可在几分钟内致死**,必须马上止血,不能等救护车。

### 判断出血的严重程度

| 类型 | 表现 | 处理 |
|------|------|------|
| 毛细血管出血 | 渗血,量少 | 清洁、压迫几分钟、包扎,见[外伤处理-割伤与擦伤](02-外伤处理.md#割伤与擦伤) |
| 静脉出血 | 暗红色,持续涌出 | 直接压迫、加压包扎 |
| 动脉出血 | 鲜红色,随心跳喷射 | 立即用力直接压迫,不止时用止血带,同时拨打120 |
| **危及生命的出血** | 血流不止、喷射、地上积成血泊、衣服迅速浸透、肢体离断,或伤员已出现休克 | 立即全力止血,拨打120 |

处理血液时尽量戴手套,或用塑料袋、保鲜膜隔开手,防止乙肝、艾滋病等经血液传播的疾病。

### 1. 直接压迫止血(首选)

**适用**: 大部分出血

**方法**:
```
1. 用干净纱布或布料直接压在伤口上
2. 持续用力按压至少10分钟
3. 不要频繁抬起查看
4. 如血液浸透,再加一层纱布继续按压
5. 用绷带固定
```

**要领**:
- **力度要大**: 用手掌根或双手叠压,把伤口压向下面的骨头;大出血时可以用膝盖压
- 没有纱布时用干净的毛巾、衣服、卫生巾(吸水性好),都没有时直接用手压
- 不要拿掉已浸透的纱布(会把刚形成的血凝块一起带掉),在上面加
- 伤口很深(如大腿根、腋窝、颈部的深伤口,止血带用不上的部位): 把纱布或布条**塞进伤口深处,一直塞满**,再在上面用力压至少3分钟(填塞止血),然后持续压迫,立即送医
- 伤口里有插入的异物(刀、钢筋、木棍): **不要拔出**,在异物两侧压迫,用卷起的布垫在异物周围把它固定住再包扎

**加压包扎**: 压迫止住血之后,用绷带缠紧,代替手的压力:
```
1. 纱布垫(或折叠的布)盖在伤口上,厚一些
2. 绷带从远离心脏的一端开始,一圈压住上一圈的一半,
   用力缠紧,经过伤口时多缠几圈
3. 在伤口外打结固定
4. 检查: 包扎处以下的手指、脚趾应保持温暖、颜色正常、能感觉到触碰;
   发紫、发凉、麻木 → 缠太紧了,稍微放松重缠
5. 血又从绷带渗出 → 在外面再加纱布、再缠一层,并重新用手压
```

**判断止住了**: 绷带外面不再有新的血渗出、扩大。可以用笔在血迹边缘画一圈,几分钟后看是否扩大。

### 2. 抬高伤肢

**配合使用**:
- 将受伤肢体抬高至高于心脏
- 有助于减少出血
- 同时继续直接压迫

现行急救指南认为抬高的作用有限,**不能代替直接压迫**。疑似骨折、抬高会引起剧痛,或会耽误压迫时,不要抬高。

### 3. 压迫止血点

**适用**: 四肢大出血且直接压迫无效

**主要止血点**:
- **上臂**: 肱动脉(上臂内侧)
- **大腿**: 股动脉(腹股沟中点)

**方法**: 用拇指或手掌压迫动脉搏动点

> 现行国际急救指南已不再推荐把压迫止血点作为常规方法: 位置难找准,效果不确定,还会分散压迫伤口的人手。只在**等待止血带、又一时无法直接压迫**时临时使用,不要因此放松对伤口本身的压迫。

### 4. 止血带(最后手段)

⚠️ **仅在以下情况使用**:
- 肢体严重出血威胁生命
- 其他止血方法无效
- 肢体已部分离断

这里的"最后手段"是指: 一般出血不需要也不应该用止血带。但对于**四肢危及生命的大出血**(喷射状出血、压迫后仍血流不止、肢体离断,或现场伤员多、你必须腾出手去救别人),应**尽早**上止血带,不要犹豫到伤员休克。止血带只能用在**手臂和大腿**,不能用于头、颈、躯干。

**使用方法**:
```
1. 在伤口上方5-7 cm处(近心端)
2. 使用宽布条(至少5 cm宽)
3. 紧紧缠绕2-3圈
4. 记录使用时间
5. 不要覆盖止血带
6. 不要松开,等待医疗救援
7. 最长不超过2小时
```

**要点**:
- 不要绑在关节(肘、膝)上;伤口位置不清时,绑在伤肢尽量高的位置(上臂或大腿根部)
- **必须绑到出血停止**: 绑得不够紧,只压住静脉、压不住动脉,出血反而会更多。正确绑好后伤肢远端会摸不到脉搏
- 会非常疼,这是正常的,告诉伤员原因,不要因为疼就松开
- 一根绑上后仍出血 → 在第一根上方紧挨着再绑一根
- 时间写在止血带上、伤员额头上或胶布上,如"止血带 14:35";并告诉120和接手的医生
- "最长不超过2小时"是指要尽量在2小时内送达医院处理,**不是到时间自己松开**。救援者自行松开可能导致大出血或有害物质突然回流,必须由医生决定

**用布条自制止血带(绞棒法)**:
```
1. 宽布条(三角巾、领带、撕开的衣服,至少5 cm宽)在伤口上方绕肢体两圈
2. 打一个半结
3. 在结上放一根短而结实的棍子(笔、筷子、扳手、树枝)
4. 再打一个结把棍子系住
5. 转动棍子绞紧,直到出血停止
6. 用另一根布条或胶带把棍子固定住,防止松开
7. 记录时间
```

有条件时,家庭和车载急救包里可以备一条商品旋压式止血带,事先看说明书在自己腿上练习过。

**禁止**:
- ❌ 使用铁丝、绳索等细线
- ❌ 用于躯干部位
- ❌ 反复松开和收紧

### 特殊部位出血

#### 鼻出血
```
1. 坐位,头略前倾
2. 捏紧鼻翼10分钟
3. 冷敷额头和鼻梁
4. 不要仰头(会导致血液流入喉咙)
```

- 捏的位置是**鼻子柔软的部分**(鼻翼),不是鼻梁骨;用嘴呼吸,把流到嘴里的血吐出来
- 10分钟内不要松手查看;没止住再捏10分钟
- 止住后24小时内不要用力擤鼻、挖鼻、做剧烈运动
- **就医**: 捏压20分钟以上仍不止;出血量大或从两侧鼻孔、嘴里大量涌出;头部受伤后流鼻血或流清水样液体;正在服用抗凝药(如华法林)或阿司匹林;反复出血;伴高血压头痛

#### 内出血征象
- 皮肤苍白、湿冷
- 脉搏快而弱
- 呼吸急促
- 腹部肿胀或僵硬
- 吐血或便血

**处理**: 立即就医,保持平卧,不要进食

内出血看不见,只能靠受伤经过和休克表现来推断。以下情况都要**按内出血对待,拨打120**:
- 高处坠落、车祸、被重物砸压、腹部或胸部受到猛烈撞击,即使当时看起来"没事"
- 咳出鲜红色带泡沫的血(肺)、吐出咖啡渣样物(胃)、黑色柏油样大便(消化道)
- 骨盆或大腿骨骨折(一处就能内出血1 L以上),见[骨骼损伤](03-骨骼损伤.md)
- 育龄女性突发下腹剧痛伴晕厥(可能是宫外孕破裂)

等待时按[休克处理](#休克处理),记录每次测的脉搏和意识;脉搏越来越快、意识越来越差,要告诉120情况在恶化。

## 休克处理

休克是**全身的器官得不到足够的血液和氧气**。它不是一种病,而是大出血、严重过敏、严重感染、心脏病发作等的共同结局。早期休克经过处理可以逆转;发展到后期,即使到医院也很难救回。

### 休克征象识别

- 皮肤苍白、湿冷
- 脉搏快而弱(>100次/分)
- 呼吸急促浅表
- 烦躁不安或淡漠
- 意识模糊
- 口渴

**早期和晚期**:

| 阶段 | 表现 | 意味着 |
|------|------|--------|
| 早期 | 烦躁、焦虑、口渴;皮肤苍白发凉;心率偏快;血压可能还正常 | 身体还在代偿,**这是最好的抢救时机** |
| 加重 | 脉搏又快又弱,手腕摸不清;呼吸快;出冷汗;尿少;反应变慢 | 已失代偿,情况危急 |
| 晚期 | 意识模糊、叫不醒;嘴唇发紫;心率反而变慢 | 随时可能心脏骤停 |

- **血压正常不代表没有休克**: 年轻人能靠加快心跳维持血压,直到突然崩溃
- 老人、服用降压药(如β受体阻滞剂)的人,心率可能不会明显加快,容易被低估
- 儿童代偿能力强,表现出来时往往已经很重
- 毛细血管再充盈超过2秒(按压指甲后恢复慢)是有用的早期信号

### 休克的处理

```
1. 让伤者平躺
2. 抬高下肢20-30 cm(疑似下肢、骨盆、脊柱损伤时不要抬高)
3. 保持体温(盖毯子)
4. 不要给食物或水
5. 如出现呕吐或意识不清,改为侧卧(恢复体位),防止误吸
6. 持续监测生命体征
7. 立即呼叫急救
```

**补充说明**:
- 排在第一位的是**处理原因**: 有大出血先止血,过敏有肾上腺素笔先用
- 抬高下肢: 在脚下垫背包、被子、椅子;抬高后出现呼吸困难或疼痛加重,就放下来
- 胸痛、呼吸困难的人(可能是心脏原因)不要平躺抬腿,让他取最舒服的半坐位
- 保暖: **身下垫隔离物**比身上盖更重要(地面带走的热量很多);但不要用热水袋直接加热皮肤
- 不要喝水: 很可能需要手术麻醉,而且休克者容易呕吐误吸。口渴可以用湿布润嘴唇。在等不到救援的长时间野外情况,见[野外伤病处置与转运](../03-野外生存/11-野外伤病处置与转运.md#等待救援时照顾伤员)
- 不要让伤员站起来、走动、自己去厕所,可能突然晕倒
- 陪伴、安慰、少说"好多血"之类的话,情绪激动会加重休克
- 每5分钟记录一次意识、呼吸和脉搏

### 不同类型休克

| 类型 | 原因 | 特点 |
|------|------|------|
| 失血性休克 | 大量出血 | 先止血 |
| 感染性休克 | 严重感染 | 保暖 |
| 心源性休克 | 心脏问题 | 半坐位 |
| 过敏性休克 | 严重过敏 | 立即用肾上腺素 |
| 神经性休克 | 脊髓损伤 | 绝对平卧 |

各类型的补充:

- **失血性**: 包括看不见的内出血和严重腹泻呕吐、大面积烧伤导致的体液丢失(低血容量)。皮肤苍白湿冷是典型表现
- **感染性**: 发热或体温过低、寒战,伴意识改变、呼吸快、皮肤花斑;老人可能只表现为精神差、糊涂。常见于肺炎、尿路感染、伤口感染、产后感染,需尽快送医用抗生素
- **心源性**: 常伴胸痛、胸闷、呼吸困难,见[心梗与胸痛](06-心脑血管与突发病症.md#心梗与胸痛)
- **过敏性**: 接触过敏原后几分钟内出现皮疹、嘴唇喉咙肿胀、喘憋、血压下降。患者自备肾上腺素自动注射笔的,立即帮他注射大腿外侧,同时拨打120,见[过敏反应](05-急性症状.md#过敏反应)
- **神经性**: 脊髓损伤后血管失去控制,特点是血压低但**皮肤可能温暖干燥**、心率不快甚至偏慢,同时有四肢瘫软、麻木。保持脊柱不动,见下文搬运

## 搬运伤员

**原则: 能不搬就不搬,能等救护车就等救护车**。不当搬运会加重骨折、出血,甚至让脊柱损伤者瘫痪。只有现场有危险、或确实必须移动才能救命时才搬。在山区、野外长距离转运见[野外伤病处置与转运-搬运伤员](../03-野外生存/11-野外伤病处置与转运.md#搬运伤员)。

### 何时不能搬运

⚠️ **以下情况不要移动伤者**:
- 疑似颈椎或脊柱损伤
- 除非:
  - 现场有危险(火灾、爆炸等)
  - 必须移动才能进行急救
  - 等待专业救援

**怎样判断可能有脊柱损伤**:
```
受伤经过(满足任何一条都要怀疑):
- 从高于自己身高的地方坠落,或从楼梯滚落
- 车祸(尤其是翻车、被甩出、行人被撞、摩托车事故)
- 跳水撞到池底、浅水
- 头部受到重击、头面部有伤
- 被重物砸中后背或头部
- 老人跌倒时头部着地

身体表现:
- 颈部或背部正中疼痛、压痛
- 手脚麻木、刺痛、无力、不能动
- 意识不清(无法说出哪里疼的人,按有脊柱损伤对待)
- 大小便失禁
```

**等待救援时手法固定头部**:
```
1. 跪在伤员头顶后方,双手放在头的两侧,手指沿着下颌
2. 保持头在当前位置不动,让鼻尖、下巴、肚脐在一条线上
3. 不要用力牵拉,不要垫枕头
4. 告诉伤员"不要动,不要点头摇头,用说的回答我"
5. 一直固定到急救人员接手;累了要换人时先交代清楚再换手
```

疑似脊柱骨折的更多表现见[骨骼损伤-脊柱骨折](03-骨骼损伤.md#脊柱骨折极其危险)。车祸中的伤员和摩托车头盔的处理见[居家与交通意外](07-居家与交通意外.md)。

### 安全搬运原则

1. **评估**: 先评估伤情
2. **准备**: 足够的人手和器材
3. **固定**: 先固定受伤部位
4. **保护**: 保护头颈和脊柱
5. **平稳**: 动作轻柔平稳

再补充几点:
- **由固定头部的人统一喊口令**:"准备——起!",所有人同时动作
- 救援者用腿的力量,**弯膝不弯腰**,背挺直,搬不动就再叫人,不要逞强
- 先止血、固定骨折,再搬运
- 搬运途中持续观察呼吸和意识,随时准备停下处理
- 担架上: 一般脚在前、头在后,后面的人能观察伤员脸色;上楼梯、上坡时头在前

### 紧急拖拽(现场有危险时)

起火、有毒气体、可能塌方、车辆有爆炸风险时,来不及等待,一个人也必须把伤员拖到安全处:

```
衣领拖拽法:
1. 站在伤员头顶后方
2. 双手抓住伤员衣领(或肩部衣服),用前臂夹住头部两侧
3. 沿身体的纵轴(头脚方向)向后拖,不要往侧面拉

腋下拖拽法:
1. 从伤员背后双手穿过腋下,抓住伤员交叉在胸前的前臂
2. 向后拖

毯子拖拽法:
1. 把毯子铺在伤员身边,整体翻转伤员到毯子上
2. 拉起头侧的毯子,沿纵轴拖

浓烟中: 尽量低姿,拖到安全处后立即检查呼吸
```

沿身体纵轴拖动能最大限度减少脊柱扭曲,所以即使怀疑脊柱损伤,紧急时也用这个方向。

### 搬运方法

#### 1. 单人搬运

**扶行法** (伤者能行走)
```
1. 站在伤者一侧
2. 一手扶腰,一手握住伤者手臂
3. 让伤者手臂搭在你肩上
```

站在伤者受伤的一侧(如左脚崴伤就站在左侧),帮他分担体重。

**抱持法** (伤者较轻)
```
1. 一手托背部
2. 一手托腿弯处
3. 将伤者抱起
```

适合儿童或体重轻的人,短距离使用。

**背负法** (伤者无法行走但意识清醒)
```
1. 蹲在伤者前方
2. 让伤者趴在背上
3. 双手托住臀部
4. 伤者手臂绕过肩膀
```

不适用于胸部、腹部受伤者(背负时胸腹受压),也不适用于上肢骨折、无法抓住你的人。

#### 2. 双人搬运

**椅托式**
```
1. 两人面对面,握住对方手腕形成"座椅"
2. 伤者坐在"座椅"上
3. 手臂搭在救援者肩上
4. 同时起立行走
```

**双人抬举法**
```
1. 一人托头颈和背部
2. 另一人托臀部和腿部
3. 同时发令起立
4. 步调一致
```

以上方法都**不能用于疑似脊柱损伤者**。

#### 3. 多人搬运(脊柱损伤)

**平板搬运法**
```
1. 至少3-4人
2. 使用硬板担架
3. 保持头-颈-躯干在一条直线
4. 同时翻转,同时抬起
5. 固定头部和身体
```

**轴线翻身(把伤员翻到硬板上)**:
```
1. 一人专门跪在头顶固定头颈,由他喊口令
2. 其余2-3人跪在伤员同一侧,分别扶住肩和腰、臀和大腿、小腿
3. 硬板放在伤员另一侧(或由第5人准备)
4. "准备——翻!": 所有人同时把伤员向自己这侧翻成侧身,
   头、肩、腰、腿像一根木头一样整体转动
5. 把硬板贴着伤员背部放好
6. "准备——放!": 同时把伤员放回平躺在板上
7. 头两侧用卷起的衣服、毛巾或沙袋塞紧,
   用布带在额头、胸、髋、膝分别把伤员绑在板上
```

硬板可以用门板、木板、长桌面代替,长度要超过伤员身高。

### 简易担架制作

**材料**: 两根结实木棍 + 毯子/衣服

**方法1**: 毯子担架
```
1. 毯子铺平
2. 两根棍子平行放置,间距约50 cm
3. 将毯子两侧向内折,包住棍子
4. 伤者平躺在中间
```

**方法2**: 衣服担架
```
1. 两根棍子穿过多件扣好的外套袖子
2. 外套开口朝下
3. 形成简易担架
```

- 棍子长约2-2.5 m,足够结实(竹竿、拖把杆、铁管);先让一个健康的人躺上去试一试能否承重
- 软担架**不能用于脊柱损伤者**,要用硬板
- 伤员要用布带绑好,防止上下坡时滑落

## 📝 关键要点总结

### 记住"四不要"

1. ❌ 不要随意搬动脊柱损伤者
2. ❌ 不要给昏迷者喂食喂水
3. ❌ 不要拔出插入体内的异物
4. ❌ 不要在能力之外勉强救援

### 记住"五优先"

1. ✅ 先保护自己安全
2. ✅ 先呼叫专业救援
3. ✅ 先处理危及生命的情况
4. ✅ 先止血再固定
5. ✅ 先抢救后搬运

### 生命救援顺序

```
1. 确保现场安全
2. 评估意识和呼吸
3. 呼叫急救(120)
4. 控制大出血
5. 处理休克
6. 固定骨折
7. 包扎伤口
8. 保暖和监护
```

无反应、无正常呼吸时,第2步之后直接开始CPR;四肢喷射性大出血,先止血再查呼吸。

### 一张卡片记住关键数字

| 项目 | 数值 |
|------|------|
| 成人按压深度 / 频率 | 5-6 cm / 100-120次/分 |
| 按压呼吸比 | 30:2(儿童婴儿双人施救时15:2) |
| 按压中断 | 不超过10秒 |
| 换人按压 | 每2分钟 |
| 直接压迫止血 | 至少10分钟 |
| 止血带位置 | 伤口上方5-7 cm,不绑在关节上 |
| 成人正常呼吸 / 心率 | 12-20次/分 / 60-100次/分 |
| 毛细血管再充盈 | 2秒内 |

## 🎓 培训建议

- 参加正规的急救培训课程(如红十字会急救证书)
- 定期复习和练习CPR技能
- 熟悉AED的使用
- 准备家庭急救包并定期检查
- 学会识别紧急情况

具体做法:
- 急救技能不练就会忘,建议每1-2年复训一次;CPR的力度和节奏必须在模型上练,看书学不会
- 留意自己单位、小区、常去的地铁站和商场里AED放在哪里
- 家里有心脏病、癫痫、严重过敏、糖尿病患者的,全家人都应该学会相应的急救方法
- 家庭急救包清单见[外伤处理-家庭急救包](02-外伤处理.md#家庭急救包)
- 在家里显眼处(如冰箱门)贴上: 家庭详细地址、家人的病史和用药、过敏史,打120时照着念
