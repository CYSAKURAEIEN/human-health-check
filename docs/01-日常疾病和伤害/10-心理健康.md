## 经历危机后的正常反应

地震、火灾、车祸、亲人离世、长期灾难之后,绝大多数人都会出现一些心理和身体上的反应。**这些是正常人对不正常事件的正常反应,不是软弱,也不是"疯了"。**

```
常见反应:

情绪: 害怕、焦虑、悲伤、愤怒、内疚("为什么活下来的是我")、麻木
思维: 反复想起当时的画面、注意力不集中、记忆力变差
身体: 失眠、做噩梦、容易受惊、心慌、头痛、胃口差、疲惫
行为: 回避与事件有关的地方和话题、容易发脾气、与人疏远
```

**大多数人在几周内会逐渐好转**,尤其是在有安全感、基本生活有保障、有家人朋友陪伴的情况下。

⚠️ 如果这些反应**持续超过1个月**、或严重到无法正常生活,需要寻求专业帮助,见[何时需要专业帮助](#何时需要专业帮助)。

## 心理急救: 怎样帮助身边的人

不需要是心理医生,任何人都可以提供心理急救。世界卫生组织推荐的心理急救可以概括为三个字: **看、听、联结**。

### 看: 先确保安全和基本需要

```
✓ 现场是否安全?先离开危险环境
✓ 有没有人受伤需要急救?
✓ 谁最需要帮助?
  - 明显惊慌失措、呆坐不动、不说话的人
  - 儿童、老人、孕妇、残障人士
  - 与家人失散的人
✓ 满足基本需要: 水、食物、保暖、休息的地方
```

### 听: 陪伴和倾听

```
✓ 介绍自己,问对方是否需要帮助
✓ 陪在旁边,保持冷静
✓ 让对方按自己的意愿说,愿意说多少就听多少
✓ 认可对方的感受: "发生了这种事,感到害怕是很正常的"
✓ 给出准确的信息(不知道的就说不知道)
✓ 帮对方解决眼前的具体问题(找家人、找住处、领物资)
```

### 联结: 帮助对方和支持资源连起来

```
✓ 帮助联系家人、朋友
✓ 告诉对方哪里可以获得帮助(救助点、医疗点、12356热线)
✓ 鼓励对方恢复日常作息、和身边的人在一起
```

### ❌ 不要做

```
❌ 不要强迫对方讲述经历的细节
   - 不要让人反复回忆当时的情景("你详细说说当时发生了什么")
   - 世界卫生组织不推荐这种做法,它不能帮助恢复,有时反而有害
❌ 不要说这些话:
   - "我完全理解你的感受"(你其实不能)
   - "至少你还活着""还好不是更糟"
   - "别哭了""要坚强""想开点"
   - "一切都会好起来的"(不确定的承诺)
❌ 不要评判对方的反应或做法
❌ 不要替对方做决定
❌ 不要做自己做不到的承诺
```

## 自杀风险: 识别与应对

### 警示信号

```
说的话:
- 说想死、想消失、"活着没意思"
- 说自己是别人的负担
- 说感到绝望、看不到出路

做的事:
- 把心爱的东西送人、交代后事、写遗书
- 打听或准备伤害自己的方法
- 和亲友告别
- 饮酒或用药明显增多
- 与人隔绝,不再参加以前喜欢的活动

情绪:
- 长期抑郁后突然变得平静("想通了")——可能已经下定决心,需高度警惕
```

**高风险人群**: 刚失去亲人、家园或生计的人;有抑郁症等精神疾病的人;以前尝试过自杀的人;长期酗酒的人;刚经历重大打击的老人。

### 怎样应对

**1. 直接问**

```
"你最近是不是想过不想活了?"
"你有没有想过要伤害自己?"

研究表明,直接询问自杀的想法不会让人产生这个念头,
反而让对方感到被理解,更愿意说出来。
```

**2. 认真听,不评判**

```
✓ 让对方说,不打断
✓ 表达关心: "我很担心你""谢谢你愿意告诉我"
❌ 不要说教: "你怎么能这么想""想想你的家人"
❌ 不要和对方争论"值不值得"
❌ 不要答应替对方保密
```

**3. 保证安全**

```
✓ 如果对方有明确计划,或已经准备好方法 → 不要让他独处
✓ 移走或锁好可能用来伤害自己的东西(大量药物、农药等)
✓ 立即求助:
  - 情况紧急 → 拨打120或110
  - 否则 → 陪对方拨打12356心理援助热线,或陪同去医院精神科、心理科
```

**4. 持续关心**

```
✓ 之后的几天、几周,继续联系、陪伴
✓ 帮助对方联系家人和专业支持
```

⚠️ **农药是农村地区重要的自杀方式**。家中的农药、鼠药要锁好或放在不易拿到的地方,这对防止冲动性的自我伤害非常有效。

### 如果是你自己有这样的想法

```
✓ 告诉一个你信任的人
✓ 拨打12356,或去医院
✓ 让自己远离可能伤害自己的东西
✓ 这些想法往往会随着处境和时间改变,很多人后来都庆幸自己当时求助了
```

## 哀伤

失去亲人、家园、熟悉的生活之后,哀伤是自然的。

```
正常的哀伤:
- 悲伤、哭泣、思念,反复想起逝者
- 内疚("如果我当时……")、愤怒
- 失眠、食欲差
- 有时会好一些,有时又会突然很难过(尤其是节日、纪念日)
- 没有固定的时间表,每个人不一样

怎样陪伴哀伤中的人:
✓ 陪着,听对方讲逝者的事
✓ 提供实际帮助(做饭、照顾孩子、处理后事)
✓ 允许对方以自己的方式哀悼(包括按习俗进行的仪式)
✓ 在之后的几个月里也记得去看看对方
❌ 不要催促"该走出来了"
❌ 不要说"他去了更好的地方""节哀顺变"就结束对话
```

⚠️ 如果半年到一年后仍然完全无法正常生活、整天沉浸在悲痛中,或出现自杀的念头,需要专业帮助。

## 儿童的心理照顾

儿童对灾难和丧失的反应与成人不同,也常常说不出来。

### 常见反应

| 年龄 | 可能的表现 |
|------|------------|
| 学龄前 | 黏人、怕和大人分开、尿床、吸手指等"倒退"行为、怕黑、在游戏中反复重演事件 |
| 学龄 | 害怕、做噩梦、注意力差、成绩下降、肚子痛头痛、发脾气、反复问同样的问题 |
| 青少年 | 回避、孤僻、易怒、冒险行为、饮酒、觉得"不会有未来" |

### 怎样帮助孩子

```
✓ 尽量让孩子和家人在一起,不要分开
✓ 恢复日常作息: 按时吃饭、睡觉,尽快复课或有固定的学习时间
✓ 用孩子听得懂的话,诚实地说明发生了什么(不要编造,也不要讲太多可怕的细节)
✓ 告诉孩子: 发生这件事不是你的错;你现在是安全的;大人会照顾你
✓ 允许孩子哭、提问、通过画画和游戏表达
✓ 多抱抱、多陪伴
✓ 减少孩子接触反复播放的灾难画面和新闻
✓ 大人先照顾好自己的情绪(孩子会从大人那里感受到安全或恐慌)

❌ 不要因为倒退行为(尿床、黏人)责骂孩子
❌ 不要对孩子隐瞒亲人的死亡(用简单、真实的话告诉他)
```

## 长期压力下照顾好自己

在长期灾后重建、物资短缺、照顾病人的情况下,照顾者自己也会耗竭。

```
✓ 保持规律作息: 固定时间起床、吃饭、睡觉
✓ 尽量保证睡眠
✓ 每天有一些身体活动(散步、做操、劳动)
✓ 和人保持联系: 聊天、一起做事、互相帮助
✓ 限制看灾难新闻和刷手机的时间
✓ 找一些能让自己平静的事: 做家务、种菜、看书、宗教活动
✓ 慢呼吸放松: 用鼻子慢慢吸气约4秒,再用嘴慢慢呼气约6秒,重复几分钟
✓ 照顾他人的人要轮换休息,不要一个人扛
✓ 允许自己难过,也允许自己有开心的时候

❌ 避免用酒精、烟、安眠药来"解决"情绪(灾后饮酒问题常明显增加)
```

## 何时需要专业帮助

```
出现以下情况,应尽快寻求专业帮助(拨打12356,或去医院精神科、心理科):

- 有自杀或伤害他人的想法(紧急情况拨打120/110)
- 危机过去1个月以上,仍然:
  - 反复做噩梦、闪回,像又经历了一遍
  - 极力回避任何相关的事,严重影响生活
  - 一直处于高度紧张、易惊、无法入睡
- 持续两周以上情绪低落、对什么都没兴趣、觉得自己没有价值
- 无法照顾自己或孩子,无法工作
- 酗酒或滥用药物
- 出现听到不存在的声音、坚信不符合事实的想法、言行明显异常
```

⚠️ **正在服用精神科药物的人,不要自行突然停药**。灾难中断药会导致病情复发,见[慢性病用药储备](08-慢性病用药储备.md)。

## 📝 心理健康要点

```
1. 危机后出现害怕、失眠、噩梦等反应是正常的,多数几周内好转
2. 帮助他人: 看(安全和需要)、听(陪伴不强迫)、联结(家人和资源)
3. 不要强迫人讲述经历细节
4. 担心有人想自杀: 直接问,认真听,不让他独处,移走危险物品,求助
5. 心理援助热线: 12356;紧急情况: 120/110
6. 孩子: 和家人在一起、恢复作息、诚实说明、少看灾难画面
7. 照顾者也要照顾好自己
8. 超过1个月仍严重影响生活,寻求专业帮助
```
