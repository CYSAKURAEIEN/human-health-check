## 预防跌倒

跌倒是老年人受伤和因伤死亡的最主要原因之一。一次髋部骨折可能让老人从此卧床,而**大多数跌倒是可以预防的**。

### 家里的布置

```
地面:
✓ 去掉门槛或做成斜坡;清除地上的电线、杂物、小地毯
✓ 卫生间、厨房铺防滑垫,地面有水及时擦干
✓ 常用的东西放在不用弯腰、不用踩凳子就能拿到的地方

照明:
✓ 走廊、卫生间、床边装夜灯(夜里起夜最容易摔)
✓ 床边伸手就能打开的灯
✓ 楼梯上下都有开关

扶手:
✓ 卫生间马桶旁、淋浴处装扶手
✓ 楼梯两侧装扶手
✓ 洗澡用防滑的洗澡椅

家具:
✓ 床和椅子的高度适中,坐下时膝盖约成直角,站起来不费力
✓ 不用带轮子会滑动的椅子
```

### 老人自己

```
✓ 穿合脚、防滑、包住脚跟的鞋;不穿拖鞋上下楼梯
✓ 起身慢: 躺→坐30秒→站30秒→再走
  (起得太快容易头晕,尤其是吃降压药的老人)
✓ 夜里起夜先开灯,坐一会儿再起身
✓ 视力下降及时配眼镜、治疗白内障
✓ 需要时使用拐杖、助行器,不要因为"不好看"而拒绝
✓ 坚持适度运动,锻炼腿部力量和平衡(散步、太极、站立踮脚等)
✓ 出门避开雨雪天气、湿滑路面
```

### 容易导致跌倒的药物

安眠药、镇静药、抗焦虑药、部分降压药、降糖药、利尿药等,都可能引起头晕、反应变慢、起身时血压下降。

**老人跌倒过,或经常头晕,要请医生评估正在吃的药。** 不要自行停药。

## 老人跌倒后怎么办

### 不要急着扶起来

```
1. 先问清楚:
   - 哪里痛?能不能动?
   - 头有没有撞到?
   - 跌倒前有没有头晕、胸闷、心慌、一侧手脚无力?

2. 以下情况不要扶起,保持原位,拨打120:
   - 剧烈疼痛,尤其是髋部(大腿根部)、腰背、颈部
   - 一条腿明显变短、脚尖向外歪(髋部骨折的典型表现)
   - 不能动,或手脚麻木无力
   - 头部受撞,或出现意识不清、呕吐
   - 口角歪斜、说话不清(可能是中风导致跌倒,见中风)
   - 胸痛、呼吸困难(可能是心脏问题导致跌倒)

3. 等待时: 用毯子保暖,在头下垫软物,不要喂水和食物
```

相关章节: [中风](06-心脑血管与突发病症.md#中风)。

### 没有明显受伤时,帮助慢慢起来

```
1. 让老人先侧身躺,休息一会儿
2. 慢慢翻成跪姿(双手双膝着地)
3. 在一把结实的椅子旁,扶着椅子,先一只脚踩地成半跪
4. 借力慢慢站起,转身坐到椅子上
5. 坐着休息,观察有无疼痛、头晕
6. 救助者在旁边保护,不要硬拉硬拽老人的胳膊
```

### ⚠️ 跌倒后也要警惕

- **服用抗凝药(如华法林)的老人,头部即使轻微碰撞也要就医**: 可能在数小时到数天后出现颅内出血(头痛加重、嗜睡、意识改变)
- 跌倒后长时间躺在地上起不来(独居老人常见),可能出现脱水、失温、压疮,要尽快就医
- 独居老人: 和家人约定每天固定时间联系;有条件时佩戴可以一键呼救的设备

骨折的固定见[骨骼损伤](03-骨骼损伤.md)。

## 长期卧床的家庭护理

### 预防压疮(褥疮)

身体长时间压在同一位置,皮肤和下面的组织缺血坏死,就会形成压疮。一旦形成,愈合很慢,严重时可引起全身感染。

```
✓ 定时翻身: 至少每2小时一次,白天黑夜都要翻
  - 平躺 → 左侧卧 → 平躺 → 右侧卧,轮换
  - 侧卧时背后垫枕头,身体倾斜约30°(不要正侧卧压在髋骨上)
  - 翻身时抬起身体,不要拖拽(摩擦会损伤皮肤)
✓ 骨头突出的部位最容易长压疮,每天检查:
  - 骶尾部(屁股后面)、髋部、脚后跟、脚踝、肩胛骨、后脑勺、耳朵
✓ 用枕头、软垫把脚后跟架空,两腿之间夹软枕
✓ 保持皮肤干燥清洁: 大小便后及时清洗擦干,床单平整无褶皱、无碎屑
✓ 有条件时使用防压疮气垫床
✓ 吃够蛋白质和水(营养差的人更容易长压疮)

⚠️ 发现皮肤发红,按压后不褪色 → 已经是早期压疮
   这个部位不要再受压,增加翻身次数
⚠️ 皮肤破溃、发黑、流脓、有臭味 → 就医
❌ 不要按摩已经发红的部位(会加重损伤)
```

### 安全喂食,防止呛咳

卧床老人吞咽能力常常下降,食物呛进气管会引起吸入性肺炎,这是卧床老人死亡的常见原因。

```
✓ 吃饭时尽量坐直(床头摇高到最高,或扶坐起来,背后垫稳)
✓ 吃完后保持坐姿约30分钟,不要马上躺下
✓ 小口慢喂,一口咽下再喂下一口
✓ 食物做软、做成糊状;稀水最容易呛,可以适当增稠
✓ 吃饭时不要说话、不要看电视分心
✓ 意识不清、昏昏欲睡时不要喂

⚠️ 吃饭时经常咳嗽、吃完后声音像含着水、反复发烧
   → 可能经常发生呛咳,请医生评估吞咽功能
```

### 其他日常护理

```
口腔: 每天刷牙或用纱布蘸水擦洗口腔(口腔不洁也会引起肺炎);
     假牙每天取下清洗
排泄: 定时提醒排尿;多喝水、吃蔬菜、适当腹部按摩预防便秘;
     失禁时及时更换、清洗,用护臀膏保护皮肤
关节: 每天帮助活动手脚各个关节几次,防止关节僵硬变形
呼吸: 定时拍背(手掌弓成杯状,从下往上轻拍),鼓励咳痰
     (方法见常见疾病-咳嗽)
情绪: 多陪伴说话,让老人尽量参与能做的事
```

相关章节: [常见疾病-咳嗽](01-常见疾病.md#咳嗽)。

## 认知障碍与走失

### 早期识别

```
需要注意的变化:
- 记性明显变差,尤其是刚发生的事(反复问同一个问题)
- 在熟悉的地方迷路
- 不会做以前熟练的事(做饭、算账)
- 性格改变、多疑、易怒
- 判断力下降(容易被骗)

出现这些变化,请医生检查: 一部分原因(如甲状腺问题、维生素缺乏、药物副作用)是可以治疗的。
```

### 预防走失

```
✓ 给老人戴写有姓名、家人电话的手环、胸卡,或在衣服里缝上联系方式
✓ 衣服口袋里放一张联系卡
✓ 保存老人近期的全身照片和正面照片
✓ 有条件时佩戴定位手表或手环
✓ 家门加装不易打开的门锁或开门提醒
✓ 告诉邻居、小区保安,请大家帮忙留意
✓ 外出时尽量有人陪同
```

### 发现走失

```
⚠️ 立即拨打110报警,不需要等24小时!
   走失后的最初几个小时是找回的关键

同时:
- 提供照片、穿着、体貌特征、可能去的地方
- 先在附近寻找: 老人常去的地方、以前的住处、单位、熟悉的路线
- 通知亲友、邻居、社区
```

## 用药安全

老人常同时吃好几种药,容易漏吃、多吃、吃错。

```
✓ 用分格药盒按每天、每顿分好
✓ 列一张用药清单(药名、剂量、时间),贴在显眼处,看病时带上
✓ 换医生、看不同科室时,告诉医生正在吃的所有药(包括中药、保健品)
✓ 不要自行加药、停药、换药
✓ 视力、记性不好的老人,由家人帮助管理药物
```

慢性病药物的储备见[慢性病用药储备](08-慢性病用药储备.md)。

## 极端天气

老人对冷热的感觉变迟钝,体温调节能力变差,在高温和严寒中都更容易出事。

```
高温:
✓ 主动定时喝水(不要等口渴)
✓ 室内开窗通风、用风扇或空调,不要因为省电而硬扛
✓ 避开中午外出
✓ 每天去看看独居老人
→ 中暑的识别与处理见中暑

寒冷:
✓ 室内保暖,夜间加盖被子
✓ 取暖注意一氧化碳中毒,见一氧化碳中毒
✓ 冬季雨雪天减少外出(防跌倒)
→ 失温见失温症
```

相关章节: [中暑](05-急性症状.md#中暑)、[一氧化碳中毒](07-居家与交通意外.md#一氧化碳中毒)、[失温症](05-急性症状.md#失温症)。

## 照顾好照护者

长期照顾卧床或认知障碍的老人非常辛苦,照护者自己也容易累垮、抑郁。

```
✓ 家人轮流照顾,不要一个人扛
✓ 了解社区、街道提供的居家养老服务、喘息服务
✓ 保证自己的睡眠和吃饭
✓ 允许自己有情绪,找人倾诉
✓ 感到撑不下去时,寻求帮助(可拨打12356心理援助热线)
```

更多见[心理健康-长期压力下照顾好自己](10-心理健康.md#长期压力下照顾好自己)。

## 📝 老人照护要点

```
1. 防跌倒: 防滑、扶手、夜灯、合脚的鞋、起身慢、评估药物
2. 跌倒后: 髋部剧痛、腿变短外旋、头部撞击、中风表现 → 不要扶起,打120
3. 吃抗凝药的老人头部碰撞,没症状也要就医
4. 卧床: 至少每2小时翻身,检查骨突部位,保持干燥
5. 喂食坐直,饭后坐30分钟,小口慢喂
6. 认知障碍: 戴联系手环、留照片;走失立即报110,不用等24小时
7. 用分格药盒管理药物
8. 照护者也要照顾好自己
```
