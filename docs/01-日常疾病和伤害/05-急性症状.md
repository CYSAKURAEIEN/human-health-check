## 过敏反应

过敏是免疫系统对本来无害的东西(花生、蜂毒、青霉素等)反应过度。多数过敏只是皮肤痒、起疹子,但少数人会在几分钟内发展为**过敏性休克**: 喉咙肿到无法呼吸、血压骤降。食物引起的严重过敏通常在接触后30分钟内发作,蜂蜇和注射药物可能只需几分钟,死亡多发生在发作后1小时之内。所以判断要快,用药要早。

### 严重程度

#### 轻度过敏
- 皮肤瘙痒、红疹
- 轻微肿胀
- 流鼻涕、打喷嚏
- 眼睛发痒

#### 中度过敏
- 大面积皮疹、荨麻疹
- 明显肿胀
- 腹痛、恶心、腹泻
- 轻度呼吸困难

#### 重度过敏 - 过敏性休克(危及生命!)
⚠️ **立即拨打120!**

**症状**:
- 呼吸困难、喘息
- 喉咙肿胀,吞咽困难
- 严重气促
- 血压下降
- 脉搏快而弱
- 头晕、意识模糊
- 皮肤苍白或发青
- 全身荨麻疹

#### 怎样判断是过敏性休克

不需要等所有症状都出现。**接触可能的过敏原(吃了某种食物、被蜂蜇、用了某种药)后几分钟到几小时内**,出现下面任何一组情况,就按过敏性休克处理:

| 情况 | 具体表现 |
|------|----------|
| 皮肤症状 + 呼吸问题 | 荨麻疹、嘴唇或眼皮肿,同时出现喘息、胸闷、声音嘶哑、喉咙发紧 |
| 皮肤症状 + 循环问题 | 皮疹的同时出现头晕、站不稳、面色苍白、晕倒、大小便失禁 |
| 皮肤症状 + 严重胃肠症状 | 皮疹的同时出现剧烈腹痛、反复呕吐 |
| 已知对某物严重过敏,接触后 | 只要出现呼吸困难或头晕晕倒,即使没有皮疹 |

```
⚠️ 要点:
- 约十分之一到五分之一的过敏性休克没有皮疹,不能因为"没起疹子"就排除
- 喉咙发紧、声音变哑、说话困难,是喉头水肿的信号,最危险
- 犹豫不决时,按过敏性休克处理(肾上腺素对不需要的人危害很小,
  延误使用的危害可能是致命的)
```

#### 儿童和婴儿的表现

```
婴幼儿说不清自己的感受,要留意:
- 突然哭闹不止、烦躁,或者反常地安静、发软、嗜睡
- 抓挠嘴巴、耳朵、喉咙
- 声音嘶哑、咳嗽、喘鸣
- 吃完新食物后反复呕吐
- 面色苍白、口唇发青
婴儿第一次吃花生、鸡蛋、海鲜等常见过敏食物时,
在家中、白天、大人在旁时少量尝试,吃后观察约2小时。
```

### 处理方法

#### 轻度过敏

```
1. 脱离过敏原
   - 停止吃可疑食物,漱口
   - 接触引起的(如植物、化妆品): 用清水和肥皂冲洗皮肤10分钟以上
   - 停用可疑药物,保留药盒(就医时给医生看)
   - 蜂蜇: 尽快刮掉皮肤上的毒刺(用指甲、卡片刮,速度比方法更重要)

2. 口服抗组胺药:
   - 氯雷他定
   - 西替利嗪
   (成人常规用量一般为每天1次、每次10 mg;儿童按体重和年龄,
    剂量以说明书为准;服后可能犯困,西替利嗪更明显,服药后不要开车)

3. 冷敷皮疹处
   - 毛巾包住冰袋或用冷水浸湿的毛巾,每次10-15分钟
   - 瘙痒处可外涂炉甘石洗剂
   - 不要抓挠,不要用热水烫洗(会更痒)

4. 观察症状变化
   - 接触过敏原后至少观察2小时,不要让患者独处
   - 出现任何呼吸、头晕症状,立即按过敏性休克处理
```

⚠️ 抗组胺药只能缓解皮肤瘙痒和皮疹,**不能阻止过敏性休克,也不能治疗过敏性休克**。已经出现呼吸困难或头晕时,不要等着抗组胺药"起效"。

#### 中度过敏的处理

```
1. 按上面轻度过敏的方法处理
2. 尽快就医(当天去医院或诊所),路上有人陪同
3. 让患者坐着或躺着,不要独自走动
4. 如有喘息、声音嘶哑,或肿胀蔓延到嘴唇、舌头、眼周
   → 已经可能是过敏性休克,立即拨打120,按下面处理
5. 有哮喘的人出现喘息,可以用自己的缓解型吸入剂,
   但不能因此推迟用肾上腺素和拨打120
```

#### 过敏性休克(紧急!)

```
立即处理:

1. 拨打120
   (如果患者带着肾上腺素笔,先注射,再打电话;
    旁边有人时,一人注射,另一人同时打电话)

2. 使用肾上腺素自动注射器(如有):
   - 如EpiPen等(中国大陆目前较难买到,高危人群需提前就医咨询)
   - 注射大腿外侧
   - 按住数秒(多数产品约3秒,不同品牌不同,以说明书为准)
   - 可重复(5-15分钟后)
   - 记下注射时间,告诉急救人员

3. 让患者平躺:
   - 抬高下肢
   - 如呕吐,侧卧位
   - 如呼吸困难,半坐位
   - 孕妇: 向左侧卧(避免子宫压迫大血管)

4. 检查呼吸和脉搏:
   - 如无,开始CPR

5. 保暖

6. 不要让其突然站立或走动(可导致血压骤降、心脏骤停);
   呼吸困难者可保持半坐位

7. 不要给食物或饮料

8. 持续监测直到急救到达
```

**为什么体位这么重要**: 过敏性休克时血管扩张、血压很低,突然站起或坐起,血液一下子流到下半身,心脏可能"抽空"而停跳。即使用了肾上腺素后感觉好了,也要一直躺着,由担架抬上救护车。

**用了肾上腺素也必须去医院**: 肾上腺素的作用只能维持约10-20分钟;少数患者在症状消退后数小时(多数在12小时内)会再次发作,称为"双相反应"。所以用药后无论多好,都要到医院观察,观察多长时间由医生决定。

#### 肾上腺素自动注射笔怎么用

肾上腺素是过敏性休克唯一的一线急救药,注射越早效果越好。自动注射笔是给非专业人员设计的,患者本人、家人、老师都可以用。不同品牌外观不同,**平时就要按说明书或训练笔练习**。以常见的笔式产品为例:

```
1. 握住笔身中部,拳头握紧,拇指不要放在任何一端
   (认清哪一端是针头端,通常标有颜色或箭头)
2. 拔掉安全帽(安全帽在针头的另一端)
3. 针头端对准大腿外侧中部(大腿前外侧肌肉最厚的地方)
   - 可以隔着裤子注射,不用脱衣服
   - 不要注射到臀部、手、脚,不要注射到静脉
4. 用力垂直压向大腿,直到听到"咔嗒"声
5. 保持按压数秒(以说明书为准),然后拔出
6. 轻揉注射部位约10秒
7. 记下时间。用过的笔交给急救人员

给小孩注射: 大人先把孩子的腿固定住,防止乱动造成针头划伤。

5-15分钟后症状没有好转或又加重:
→ 用第二支,注射另一侧大腿
```

| 规格 | 一般适用 |
|------|----------|
| 0.15 mg(儿童型) | 体重约15-30 kg的儿童 |
| 0.3 mg(成人型) | 体重约30 kg以上 |

具体用哪种规格、带几支,由医生根据体重和病史开具,不要自己判断。笔里的药液变色、混浊或过期,要及时更换;存放在室温下,不要放在车里暴晒或冰箱冷冻。

#### 没有肾上腺素笔时

```
1. 立即拨打120,说清楚"疑似严重过敏、呼吸困难",
   并说出地点和可疑的过敏原
2. 按上面第3-8步摆体位、保暖、监测
3. 有哮喘的人可用自己的缓解型吸入剂缓解喘息
4. 意识丧失、没有呼吸 → 立即CPR
5. 抗组胺药、激素药片起效需要较长时间,不能代替肾上腺素,
   不要因为"已经吃了药"就不打120、不去医院
```

心肺复苏方法见[基础急救知识-心肺复苏](00-基础急救知识.md#心肺复苏cpr);哮喘发作的处理见[哮喘急性发作](06-心脑血管与突发病症.md#哮喘急性发作)。

### 常见过敏原

- **食物**: 花生、坚果、海鲜、鸡蛋、牛奶、大豆、小麦
- **药物**: 青霉素、阿司匹林、某些疫苗
- **昆虫**: 蜜蜂、黄蜂、火蚁
- **乳胶**
- **其他**: 花粉、尘螨、动物皮屑

```
几个容易忽视的地方:
- 食物过敏原常藏在加工食品里: 酱料、糕点、"植物蛋白"、坚果油
- 对某种抗生素过敏,同类药物可能也过敏(如青霉素类),看病时要主动说
- 一次蜂蜇只是局部大片肿胀的人,下次也可能出现全身反应
- 部分人只在"吃了过敏食物 + 运动"或"+ 饮酒、服止痛药"时才发作
- 过敏性休克之后要去医院查清过敏原,否则下次可能更严重
```

昆虫叮咬后的局部处理见[外伤处理-昆虫叮咬](02-外伤处理.md#昆虫叮咬)。

### 预防

```
✓ 识别自己的过敏原
✓ 随身携带:
  - 过敏卡片(说明过敏原)
  - 肾上腺素自动注射器(严重过敏史者)
  - 抗组胺药
✓ 告知他人自己的过敏情况
✓ 外出就餐询问食材
✓ 检查药物成分
```

**过敏卡片写什么**: 姓名、过敏原、曾经发生过的最严重反应、随身药品放在哪里和怎么用、紧急联系人电话。中英文各一份,出国时更方便。

**有过敏性休克病史的人**:
- 就医做过敏原检测,请医生写一份书面的"过敏急救计划",家里、学校、单位各放一份
- 有处方时随身带2支肾上腺素笔(一支可能失败或需要第二剂),注意有效期
- 家人、同事、孩子的老师都要知道笔放在哪里、怎样使用
- 吃药、打针、做检查(如造影)之前,主动告诉医生过敏史

## 中暑

中暑是身体产热和吸热超过散热能力、体温调节失控造成的一组疾病,从轻到重分为热痉挛、热衰竭和热射病。前两种及时休息、降温、补液就能恢复;**热射病是急症,死亡率很高**,决定生死的是**最初半小时内能否把体温降下来**。

### 热相关疾病分级

先看最关键的区别: **意识是否改变**。

| | 热痉挛 | 热衰竭 | 热射病 |
|---|---|---|---|
| 意识 | 清醒 | 清醒(可能烦躁、头晕) | **意识改变**: 胡言乱语、行为异常、抽搐、昏迷 |
| 体温 | 正常或略高 | 一般<40°C | 一般≥40°C |
| 皮肤 | 出汗 | 大量出汗,湿冷 | 灼热;可能干燥,也可能仍在出汗 |
| 处理 | 休息、补电解质 | 阴凉处、降温、补液 | **立即拨打120 + 现场快速降温** |
| 严重性 | 轻 | 中,可发展为热射病 | 危及生命 |

```
⚠️ 判断时注意:
- 在高温中出现任何意识异常(说话含糊、答非所问、走路不稳、反常地烦躁),
  都先按热射病处理,不要等量体温
- 跑步、训练、高温劳动引起的热射病,患者常常仍在大量出汗,
  "不出汗"不是诊断热射病的必要条件
- 家用体温计测腋下、额头的温度,往往比身体内部的温度低很多,
  量出来不到40°C不能排除热射病
```

#### 1. 热痉挛
**症状**: 肌肉疼痛性痉挛(腿、手臂、腹部)

**处理**:
```
1. 转移到阴凉处
2. 休息
3. 补充电解质液
   - 运动饮料
   - 口服补液盐
4. 轻轻拉伸痉挛肌肉
```

热痉挛多发生在大量出汗后只喝白开水的人身上(盐分丢失)。

```
补充说明:
- 没有补液盐时,可按"常见疾病"一章的家庭应急配方自配(1 L水加约3 g盐),
  或喝淡盐水、吃点咸的食物
- 小腿抽筋: 伸直腿,把脚尖往自己身体方向扳,保持到缓解
- 当天不要再回到高温下干重活或剧烈运动
- 休息1小时后仍不缓解,或伴有恶心、乏力,按热衰竭处理
- 有心脏病、低盐饮食的人,出现热痉挛要就医
```

补液盐的配制见[常见疾病-补液](01-常见疾病.md#1-补液最重要)。

#### 2. 热衰竭
**症状**:
- 大量出汗
- 皮肤湿冷
- 脉搏快而弱
- 恶心、呕吐
- 头晕、乏力
- 体温轻度升高(<40°C)

**处理**:
```
1. 转移到阴凉处
2. 平躺,抬高下肢
3. 脱去多余衣物
4. 冷敷:
   - 湿毛巾擦身
   - 冰袋放腋下、腹股沟、颈部
5. 补液:
   - 小口频饮
   - 电解质液
6. 如30分钟未改善,就医
```

```
具体做法:
- 阴凉处: 树荫、有空调的室内或车内;没有时用衣服、雨布遮出一片阴凉
- 抬腿: 腿下垫背包或衣服,抬高约20-30 cm
- 降温: 用凉水把皮肤打湿,再用扇子、风扇吹风(蒸发散热比单纯冷敷快)
- 补液: 清醒、不呕吐时喝凉的(不要冰镇)补液盐或运动饮料,
  每隔几分钟喝几口,1小时内大约喝0.5-1 L;
  不要一口气灌下大量水,不要喝酒、浓茶、咖啡
- 呕吐、喝不进水: 需要医院静脉补液,尽快就医

出现以下任何一种,立即拨打120,按热射病处理:
- 意识改变(糊涂、答非所问、烦躁、嗜睡)
- 体温≥40°C
- 抽搐
- 处理后症状反而加重
```

热衰竭好转后,当天不要再回到高温环境中劳动或运动,接下来一两天也要减量。

#### 3. 热射病/中暑(危及生命!)
⚠️ **紧急情况!立即拨打120!**

**症状**:
- 体温≥40°C
- **皮肤干燥、灼热**(可能不出汗)
- 意识改变(混乱、躁动、昏迷)
- 癫痫发作
- 呼吸急促
- 心跳快
- 头痛剧烈

(注意: 上面"皮肤干燥"多见于高温天气里的老人;剧烈运动引起的热射病常常皮肤湿热、仍在出汗。最可靠的判断是**高温环境 + 意识改变**。)

**两种类型**:
- **经典型**: 多见于热浪期间的老人、婴幼儿、慢性病人,在闷热的房间里待了一两天后逐渐出现,常被家人误以为"老糊涂了""睡着了"
- **劳力型**: 多见于健康的年轻人(军训、长跑比赛、高温下体力劳动),可在一两个小时内发生

**处理**:

```
紧急处理:

1. 立即拨打120

2. 快速降温(最重要!):

   冰水浸泡法(最有效):
   - 冰水浴
   - 持续到体温降至38.5°C

   或蒸发降温法:
   - 脱去衣物
   - 全身喷洒凉水
   - 用风扇吹风

   同时:
   - 冰袋敷在:
     * 颈部两侧
     * 腋下
     * 腹股沟

3. 侧卧位(防呕吐)

4. 不要给食物或水(可能昏迷)

5. 监测体温
   - 目标: 降至38.5°C
   - 防止过度降温

6. 检查呼吸和脉搏
   - 必要时CPR

7. 持续降温直到急救到达
```

### 降温方法详解

原则是**先降温,边降温边等待救护车**,不要为了"赶紧送医院"而放弃现场降温: 体温在40°C以上持续的时间越长,脑、肝、肾等器官的损伤越重。下面的方法按效果从高到低排列,有什么条件用什么:

| 方法 | 怎么做 | 效果 |
|------|--------|------|
| 冷水浸泡 | 把身体浸入冷水,只露出头和颈 | 最快,首选 |
| 防水布包裹浸泡 | 用雨布、塑料布、浴帘兜住患者四边,倒入冷水和冰 | 接近浸泡,户外可用 |
| 冰水毛巾轮换 | 冰水浸透的毛巾或床单盖满全身,每2-3分钟换一次 | 中等 |
| 喷水 + 吹风 | 脱去衣物,不断喷洒凉水,同时用风扇或扇子吹 | 中等,空气干燥时较好 |
| 只敷冰袋 | 颈部、腋下、腹股沟放冰袋 | 单独使用太慢,只作辅助 |

#### 冷水浸泡怎么做

```
1. 浴缸、大盆、充气水池、水桶都可以;
   水越冷越好(加冰),没有冰时自来水、河水、池塘水也比不浸强
2. 脱去多余衣物,让患者半躺进水里,水浸到颈部
3. 必须有人一直托住头部和腋下,让口鼻保持在水面以上
4. 不断搅动水(让身体周围的热水散开)
5. 什么时候停:
   - 有直肠体温计时: 降到约38.5°C就出水(继续泡会降得过低)
   - 没有可靠体温计时: 浸泡约15-20分钟,或患者意识明显好转、
     开始发抖时出水
6. 出水后擦干,在阴凉处继续观察,体温或意识又变差时再降温
```

⚠️ 浸泡时必须有人看着、托着,昏迷的人可能滑入水中。

#### 降温时不要做

```
❌ 不要给退烧药(对乙酰氨基酚、布洛芬等)
   - 中暑的高温不是"发烧",退烧药无效,还可能加重肝肾损伤
❌ 不要用酒精擦身(会经皮肤吸收,儿童尤其危险)
❌ 意识不清、抽搐的人不要喂水喂药(会呛入气管)
❌ 不要用厚被子"捂汗"
❌ 不要因为体温降下来、人醒了就不去医院
```

**抽搐时**: 移开周围的硬物,不要按住肢体,不要往嘴里塞东西;抽搐停止后放成侧卧位。见[癫痫发作](06-心脑血管与突发病症.md#癫痫发作)。

**所有热射病都必须住院**: 即使降温后清醒了,也可能已经发生肾损伤、肌肉溶解(尿液呈浓茶色或可乐色)、凝血异常,需要医院检查和治疗。

### 高风险人群

- 婴幼儿、老人
- 慢性病患者
- 过度肥胖
- 某些药物使用者
- 剧烈运动者
- 首次暴露于高温

```
为什么风险高:
- 婴幼儿: 体温调节能力差,不会表达;
  ⚠️ 绝对不要把孩子单独留在车里,哪怕"几分钟"——
  阳光下停放的车内温度在十几分钟内就能升高十几到二十多度
- 老人: 口渴感迟钝,出汗少,常常舍不得开空调,独居者出事没人发现
- 慢性病: 心脏病、糖尿病、肾病、精神疾病患者
- 药物: 利尿剂、某些降压药(如β受体阻滞剂)、抗精神病药、
  部分抗抑郁药、抗组胺药等会影响出汗或补水,不要自行停药,
  热浪来临前问问医生
- 正在发烧、腹泻(已经缺水)、饮酒的人
- 孕妇
- 户外劳动者、军训和运动员
```

老人高温天的照顾见[老人照护-极端天气](13-老人照护.md#极端天气)。

### 预防

```
✓ 避免高温时段户外活动(10:00-16:00)
✓ 穿轻便、浅色、透气衣物
✓ 戴帽子、墨镜
✓ 充分补水:
  - 运动前、中、后
  - 每15-20分钟喝水
  - 不要等口渴
✓ 逐渐适应高温(1-2周)
✓ 注意身体信号
✓ 高温天避免剧烈运动
```

**补水的量**:
- 在高温中劳动或运动时,每15-20分钟喝约150-250 mL(一两大口到一小杯)
- 每小时喝水一般不要超过1-1.5 L;长时间大量出汗时,只喝白水而不补盐会引起低钠血症(头痛、恶心、意识模糊),应同时喝运动饮料、淡盐水,或吃些咸的食物
- 看尿色: 淡黄色说明水够;深黄色、尿量少说明缺水

**怎样逐渐适应高温**: 刚到炎热地区或天气突然变热时,第一天只做平常约一半的高温工作量或运动量,之后每天逐渐增加,1-2周后身体出汗能力提高,才能恢复正常强度。离开高温环境一两周后,适应能力会逐渐消失。

**热浪期间在家**:
- 白天关窗、拉上窗帘遮阳,晚上凉快时开窗通风
- 有空调就开,26°C左右即可;没有空调时,每天到商场、图书馆等凉爽的公共场所待几个小时
- 气温很高时风扇单独使用效果有限,配合打湿皮肤或冲凉水澡效果更好
- 每天至少一次看望或电话问候独居老人
- 高温下干活: 安排在早晚,每干一段时间就到阴凉处休息,结伴干活、互相观察

沙漠等极端炎热环境见[沙漠求生](../03-野外生存/03-沙漠求生.md#中暑)。

## 失温症

### 定义
核心体温<35°C

"核心体温"是身体内部(心脏、大脑周围)的温度,手脚冰凉不等于失温。家用体温计在低温时测量不准,野外通常也没有条件量体温,所以**主要根据发抖和意识状态判断**(见下面的表格)。

失温不只发生在冬天和雪地: 气温十几度时,只要**被雨或汗打湿 + 大风 + 疲劳饥饿**,同样会发生;落入冷水后更快。居家的老人在室温过低、不开暖气的房间里,也可能在几天内慢慢失温。

### 严重程度

#### 轻度(32-35°C)
**症状**:
- 剧烈寒战
- 手指不灵活
- 轻度意识混乱
- 呼吸和心跳稍快

#### 中度(28-32°C)
**症状**:
- 寒战减弱或停止
- 肌肉僵硬
- 反应迟钝
- 嗜睡
- 呼吸心跳变慢

#### 重度(<28°C)
**症状**:
- 无意识
- 脉搏微弱
- 呼吸浅慢
- 瞳孔放大
- 可能看似死亡

#### 没有体温计时怎样分级

| 表现 | 大致程度 | 处理重点 |
|------|----------|----------|
| 清醒,一直发抖,手指笨拙 | 轻度 | 避风、换干衣、包裹、热甜饮、吃东西 |
| 意识模糊或嗜睡,发抖减弱或停止 | 中度 | 拨打120,轻柔平移,包裹 + 躯干加温,不喂食 |
| 叫不醒,但还有呼吸 | 重度 | 同上,侧卧防误吸,持续观察呼吸 |
| 没有呼吸(检查长达1分钟) | 心脏骤停 | 立即CPR,持续到急救接手 |

```
⚠️ 两个容易误判的信号:
- 发抖停止了,人却更迷糊 → 不是好转,而是加重(身体已经没有力气发抖)
- "反常脱衣": 严重失温的人可能觉得热,把衣服脱掉
⚠️ 失温的人自己往往意识不到,同伴要互相观察:
   拉不上拉链、系不上鞋带、说话含糊、走路踉跄、跟不上队伍,都是早期信号
```

#### 婴儿和老人的失温

```
婴儿:
- 不一定发抖;表现为皮肤摸起来冰凉、发红,异常安静、软弱无力、不肯吃奶
- 处理: 脱去湿衣物,和大人皮肤贴皮肤抱在怀里,外面用毯子包住,头上戴帽子,
  尽快就医

老人:
- 寒战往往不明显,表现为反应慢、说话含糊、动作迟缓,容易被当成"糊涂了"
- 常见于室温过低、独居、行动不便、营养差、患有甲状腺功能减退或服用镇静药的人
- 冬季室内温度最好保持在18°C以上;对体弱老人要每天查看
- 发现时室温很低、老人反应迟钝 → 拨打120,按中重度处理
```

### 处理方法

#### 轻度失温

```
1. 转移到温暖干燥处

2. 脱去湿冷衣物

3. 保暖:
   - 干燥衣物、毯子
   - 睡袋
   - 保温毯(金属箔)

4. 温暖饮料:
   - 温热的甜饮料
   - 不要酒精!
   - 不要咖啡因

5. 温暖食物:
   - 高能量食物
   - 巧克力、糖果

6. 温和复温:
   - 温暖的房间
   - 多层覆盖
   - 体温传递(皮肤接触)

7. 活动:
   - 轻度活动
   - 不要剧烈运动
```

```
具体做法:
- 避风避雨: 野外没有房子时,躲到大石头后、树林里,或者用雨布搭起遮挡
- 隔绝地面: 坐或躺在背包、防潮垫、树枝上,地面带走的热量往往比空气多
- 没有干衣服可换时,在湿衣服外面套上防风防雨的外套,再包裹
- 包裹要从头到脚,戴上帽子,把脖子围起来
- 热水袋或装热水的水壶用衣服包好,放在胸口、腋下、腹股沟(不要直接贴皮肤,防烫伤)
- 热甜饮: 温热的糖水、红糖姜水、热巧克力,能自己端稳杯子、吞咽正常才给
- 发抖是身体在产热,是好事;发抖消耗大量能量,所以要不断吃东西补充"燃料"

怎样算好转: 发抖逐渐减轻、说话清楚、手指灵活、能自己穿衣服。
好转后也要休息、继续保暖至少几个小时,不要马上继续赶路。
处理后仍越来越迷糊、发抖停止 → 按中重度处理。
```

野外失温的识别和预防见[涉水、山洪与野外失温](../03-野外生存/08-涉水山洪与野外失温.md#不只是冬天-野外失温)。

#### 中重度失温(紧急!)

```
⚠️ 立即拨打120

处理:
1. 轻柔操作(避免触发心律失常)

2. 水平移动(不要站立)

3. 保暖:
   - 干燥衣物
   - 毯子包裹
   - 保护头颈

4. 不要:
   ❌ 直接加热(热水、火、暖气)
   ❌ 按摩四肢
   ❌ 给食物或饮料
   ❌ 让其走动

5. 检查呼吸和脉搏:
   - 检查时间长达1分钟(可能很微弱)
   - 如无,开始CPR
   - CPR持续到急救人员接手(在医院复温之前不要轻易放弃)

6. 等待专业救援
```

```
"包裹"的具体做法(由内到外):
1. 湿衣服能剪开就剪开脱掉,动作要轻;无法脱时保留,外面加一层塑料布或保温毯
2. 身下垫防潮垫、毯子,隔绝地面
3. 躯干贴放用布包好的热水袋或暖宝宝(胸口、背部、腋下),不要放在手脚上
4. 用睡袋、毯子从头到脚包起来,只露出脸
5. 最外面包一层塑料布、雨衣或保温毯(防风、防潮)

这里"不要直接加热"指的是: 不要泡热水澡、不要靠近火堆烘烤、不要用电热毯或暖气直吹,
不要把热源直接贴在皮肤上。用布包好、放在躯干上的热源是可以的,也是需要的。
```

**为什么动作要轻**: 体温很低时心脏非常"敏感",粗暴地搬动、搓揉、让患者坐起或走路,都可能诱发致命的心律失常(室颤)。

**CPR与AED**: 严重失温的人心跳可能慢到摸不出来,所以检查要长达1分钟。确认没有呼吸就开始CPR,有AED就按语音提示使用。低温对大脑有一定保护作用,失温导致心脏骤停的人,即使经过长时间心肺复苏,复温后仍有可能完全恢复。医学界的说法是: **"没有复温之前,不能宣布死亡"**。

心肺复苏方法见[基础急救知识-心肺复苏](00-基础急救知识.md#心肺复苏cpr)。

### 特殊注意

```
⚠️ 复温后体温续降("afterdrop"):
- 四肢复温时,冷血回流心脏
- 可能导致核心体温进一步下降
- 危险!

因此:
- 仅温暖躯干核心
- 不要按摩四肢
- 专业复温很重要
```

```
⚠️ 从冷水中救上来的人: 平着抬出水面
- 在冷水里泡久的人,水的压力帮助维持着血压
- 竖直拉出水面、让其自己爬上岸或站起来,血压可能骤降,导致突然晕倒甚至心脏骤停
- 能做到时,两个人一个托肩背、一个托腿,水平地抬上岸,上岸后保持平躺
```

**同时有冻伤时**: 先处理失温(保命),再处理冻伤。手脚冻伤的温水复温(37-39°C)要等全身情况稳定、确定不会再次冻上之后再做,见[外伤处理-冻伤](02-外伤处理.md#冻伤)。

### 预防

```
✓ 多层穿衣(3层系统):
  1. 内层:排汗
  2. 中层:保暖
  3. 外层:防风防水
✓ 保持干燥
✓ 保护头部(头颈暴露时散热很多,要戴帽子、围围巾)
✓ 充足食物和水
✓ 避免酒精和吸烟
✓ 识别早期症状
✓ 携带应急装备
```

```
补充:
✓ 内层不要穿棉质衣服(湿了不干、不保暖),穿速干或羊毛的
✓ 热了提前减衣服(少出汗),停下休息时马上加衣服
✓ 无论天气预报多好,上山都带保暖层和雨衣
✓ 不要喝酒"暖身": 酒精让皮肤血管扩张,感觉暖了,实际散热更快
✓ 天气突变、同伴出现早期失温信号时,及时下撤或就地避险,不要硬撑
✓ 应急装备: 保温毯、帽子手套、备用干袜子、高热量食物、能装热水的水壶
```

寒冷环境的穿衣和庇护所见[雪地极地求生-保暖](../03-野外生存/04-雪地极地求生.md#保暖-最关键)。

## 电击伤

电流穿过人体时,会扰乱心脏和呼吸(可导致室颤、呼吸停止),并在电流经过的路径上造成深部烧伤。**皮肤上的伤口常常很小,内部的损伤却可能很重**。另外,触电后常会被弹开或从高处摔下,造成骨折和颅脑损伤。

### 紧急处理

#### 1. 确保安全

```
⚠️ 首要原则:保护自己!

如果伤者仍接触电源:
1. 不要直接触碰!
2. 切断电源:
   - 关闭总闸
   - 拔掉插头
3. 如无法切断:
   - 用干燥非导电物品移开电源
   - 木棍、塑料、厚报纸
   - 站在干燥绝缘物上
4. 高压电:
   - 不要靠近!
   - 等待专业人员
```

#### 低压电和高压电的区别

| | 低压电 | 高压电 |
|---|---|---|
| 常见场所 | 家用插座和电器(220 V)、工厂动力电(380 V) | 电线杆上的架空线、变电站、配电箱(箱式变压器)、电气化铁路接触网 |
| 能不能自己施救 | 断电后可以;无法断电时可用干燥绝缘物挑开 | **不能**。木棍、橡胶手套都挡不住,靠近就可能被击中 |
| 救援者怎么做 | 关总闸、拔插头,然后救人 | 远离,打电话让电力部门断电,确认断电后才能接近 |
| 伤情特点 | 可能"粘住"甩不开;心律失常风险 | 深部大面积烧伤、肢体损伤、常被弹飞摔伤 |

```
低压电施救的细节:
- 拔插头时握住插头本身,不要拽电线;自己的手和脚必须干燥
- 不知道总闸在哪里时,先拔插头;漏电的电器不确定时,关总闸更可靠
- 挑开电线或推开伤者: 用干燥的木棍、扫帚柄、塑料椅子,
  自己站在干燥的木板、橡胶垫、一叠厚书或报纸上
- 不要用金属物品、潮湿的东西,不要徒手去拉伤者的身体
- 伤者泡在带电的积水、浴缸、泳池里: 先断电,断电前不要下水

高压电和断落的电线:
- 不要靠近断落在地上的电线和触电者,至少保持10 m以上的距离,并阻止他人靠近
- 电线落地处周围的地面带电("跨步电压"),走近时两脚之间的电压差可以致命
- 如果已经在附近,脚下感到发麻:
  双脚并拢,小步蹦跳或脚贴着地面小碎步挪开,不要大步跑
- 拨打电力抢修电话95598和120、110,说清地点,等电力部门确认断电
- 汽车撞上电线杆、电线压在车上: 待在车里不要下车;
  如必须下车(车起火),双脚并拢跳出去,落地时身体不要同时碰到车和地面,
  然后并脚蹦跳离开
```

家里的漏电保护和用电安全见[家庭用电安全](../07-日常生活技能/08-家庭用电安全.md)。

#### 2. 检查伤者

```
1. 评估意识

2. 检查呼吸和脉搏

3. 如无呼吸/脉搏:
   - 立即CPR
   - 拨打120
   - 持续CPR直到急救到达

4. 如有呼吸:
   - 侧卧位
   - 监测生命体征
```

```
补充:
- 电源已切断后,伤者身上不带电,可以放心触碰
- 触电最常见的死因是心脏骤停(室颤),及时CPR + 尽快用AED,救活的机会很大;
  AED可以正常使用,电击伤者不是禁忌
- 从高处摔下或被弹开的人: 可能有颈椎、脊柱损伤,尽量不要扭动头颈;
  但没有呼吸时,CPR优先
- 清醒的人: 让其躺下休息,不要马上起身走动,检查全身有无烧伤、骨折
```

#### 3. 处理烧伤

```
电击常导致烧伤:
1. 冷水冲洗烧伤处
2. 无菌纱布覆盖
3. 不要涂抹任何东西
```

```
补充:
- 电流进出身体的地方各有一个伤口(常见于手和脚),都要找到并处理
- 冷水冲洗方法与普通烧伤相同(15-20分钟);大面积时注意保暖,防止失温
- 取下戒指、手表、手镯(肿胀后会勒住)
- 伤口看起来只是一个焦黑的小点,下面的肌肉、血管、神经可能已经严重受损
- 伤肢肿胀、剧痛、发紫或发麻,或者尿液变成茶色,说明深部损伤严重,需要急诊处理
```

烧伤的处理方法见[外伤处理-烫伤与烧伤](02-外伤处理.md#烫伤与烧伤)。

#### 4. 就医

```
所有电击伤都应就医!

即使看似轻微:
- 可能有内部损伤
- 心律可能延迟异常
- 需心电图监测
```

```
以下情况必须拨打120,由救护车送医:
- 高压电击伤、雷击
- 曾经失去意识,或做过CPR
- 胸痛、心慌、心跳不齐、呼吸困难
- 有明显烧伤,尤其是电流进出口伤口
- 电流可能经过胸部(如一只手到另一只手、手到脚)
- 肌肉剧痛、肢体肿胀、尿色变深
- 孕妇(即使自己没有症状,也要检查胎儿)

其他看似没事的人,也要尽快到医院做心电图,观察多长时间由医生决定。
在等待和去医院的路上,不要让伤者独处。
```

### 特殊类型

#### 雷击

```
处理:
1. 可以立即触碰伤者(不会带电)
2. 呼叫急救
3. CPR(如需要)
4. 处理烧伤
5. 保暖
6. 就医

特点:
- 常导致心脏骤停
- 积极CPR至关重要
- 看似死亡可能被救活
```

```
补充:
- 雷暴还没过去时,先把伤者转移到相对安全的地方(建筑物内、车内)再抢救,
  避免救援者也被击中("雷电不会两次击中同一地方"是错误的)
- 雷击常让呼吸停止的时间比心跳停止更长: 心跳恢复了但还没有自主呼吸时,
  要继续人工呼吸,否则心脏会因为缺氧再次停跳
- 多人同时被雷击时,先救没有呼吸、看起来"已经死了"的人;
  能动、能喊叫的人通常能活下来,可以稍后处理
  (这和一般的多人伤员顺序相反)
- 雷击者皮肤上可能出现树枝状、羽毛状的红色花纹,几小时到一两天后消退;
  还可能出现暂时性的手脚瘫软、发凉发紫、耳聋、视物模糊
- 雷击伤者都要就医(检查心脏、眼睛、耳朵和神经系统)
```

雷雨天怎样避险见[气象灾害-雷电](../02-灾难应对/02-气象灾害.md#雷电)。

#### 儿童咬电线

```
小孩把通电的电线、插头放进嘴里咬,会烧伤嘴角和嘴唇:
- 按电击伤处理: 先断电,检查呼吸,带孩子就医(检查心脏和口腔)
- 嘴角烧伤后约1-2周,结痂脱落时嘴唇的动脉可能突然大量出血
  → 出血时用干净纱布或手指捏住嘴角(拇指和食指一里一外),持续压迫,
     同时拨打120或立即去医院
```

### 预防

```
✓ 电器安全:
  - 插座保护盖(有儿童时)
  - 湿手不碰电器
  - 检查电线损坏
  - 漏电保护器
✓ 雷雨天:
  - 室内躲避
  - 远离窗户、金属
  - 不要打电话(有线)
  - 不要洗澡
  - 户外:蹲低,双脚并拢(只是无处躲避时的最后手段,只能略微降低风险;
    听到雷声就应尽早进入坚固建筑或封闭汽车内)
✓ 专业电工处理电气问题
```

```
补充:
✓ 漏电保护器每月按一次"试验"按钮检查,跳闸后先找原因,不要短接或拆掉
✓ 浴室里不用插线板,热水器、吹风机远离水
✓ 不在高压线下放风筝、钓鱼(碳纤维鱼竿导电),不爬电线杆和变压器
✓ 发现断落的电线不要靠近,立即报告电力部门
✓ 洪水、积水后先确认断电,再进屋、再处理电器
```

## 溺水

溺水的人往往**没有呼喊、没有挥手**,几十秒内就会沉下去;从开始缺氧到大脑出现不可逆损伤只有几分钟。溺水导致的心脏骤停是**缺氧**引起的,所以急救的重点是**尽快给氧(人工呼吸)**,这和普通的心脏骤停不同。

### 紧急处理

#### 1. 水中救援

```
⚠️ 安全第一!

优先顺序:
1. 伸:用杆、树枝伸向溺水者
2. 抛:抛救生圈、绳索
3. 划:用船靠近
4. 游:最后选择(需训练)

注意:
- 不会游泳者不要下水!
- 溺水者可能拉你下水
- 背后接近较安全
```

```
具体做法:
- 先喊: 大声呼救,让旁人拨打110/120,让溺水者朝你的方向漂
- 伸: 趴在岸上或蹲低,重心放低,另一只手抓住固定物,
  用竹竿、树枝、衣服结成的长条、皮带递过去;
  对方抓住后慢慢往回拉,感到自己被往水里拽时,立即松手
- 抛: 能漂浮的东西都可以——救生圈、装了少量水的空塑料桶(加一点水抛得更准)、
  空饮料瓶、篮球、泡沫板、背包;最好系上绳子,抛到对方前方、顺水流的一侧
- 不要手拉手结成"人链"下水,不要多人一起下水
- 必须游过去时(受过训练、无法用其他办法): 带上漂浮物,
  在几米外停下,先把漂浮物推给对方,从背后接近;
  被对方抱住时,深吸一口气往水下沉,对方会本能地松手
- 冰面落水: 不要直接走上冰面,趴着用长杆、梯子、绳子施救
- 跳水后受伤(浅水区头朝下扎下去): 可能有颈椎骨折,
  救上岸时尽量让头、颈、身体保持一条直线;但没有呼吸时,CPR优先
```

自己落水、落入急流或冷水的自救方法见[涉水、山洪与野外失温-落入急流](../03-野外生存/08-涉水山洪与野外失温.md#落入急流)、[落入冷水](../03-野外生存/08-涉水山洪与野外失温.md#落入冷水)。

#### 2. 上岸后处理

```
立即评估:

1. 拨打120

2. 检查反应和呼吸:
   - 观察10秒

3. 如无反应、无呼吸或仅濒死喘息:
   ⚠️ 立即开始CPR!

   - 不要先控水!
   - 溺水是缺氧导致的心脏骤停,先开放气道,给予5次人工呼吸
   - 然后按30次按压:2次人工呼吸持续CPR
   - 不会或无法人工呼吸时,至少持续胸外按压
   - 持续直到:
     * 恢复呼吸
     * 急救到达
     * 精疲力竭

4. 如有呼吸:
   - 侧卧位(恢复体位)
   - 保暖
   - 监测呼吸
   - 可能会呕吐水

5. 保暖:
   - 脱去湿衣
   - 干毛巾擦干
   - 毯子包裹
   - 防止失温
```

```
人工呼吸的要点:
- 开放气道: 一手按额头,一手抬下巴,让头后仰
- 捏住鼻子,嘴包住对方的嘴,吹气约1秒,看到胸部隆起即可;不要用力猛吹
- 吹不进去: 重新调整头的位置再试;口中有明显异物时用手指取出,
  不要花时间去"倒水"
- 口鼻冒出泡沫是正常现象,不要反复去擦,继续CPR
- 有AED时: 把胸部擦干后贴电极片,按语音提示操作

在水里: 受过训练的救援者在浅水区就可以开始人工呼吸;
深水里无法做胸外按压,要尽快把人带上岸

其他:
- 冷水中救上来的人,尽量平着抬上岸(见失温症-特殊注意)
- 只有一个人时: 先做约2分钟(约5个循环)CPR再打电话;
  有手机时开免提,边做边打
```

心肺复苏的完整方法见[基础急救知识-心肺复苏](00-基础急救知识.md#心肺复苏cpr)。

#### 婴儿和儿童溺水

```
- 同样先给5次人工呼吸,然后按30:2进行CPR
  (两名受过训练的施救者可用15:2)
- 婴儿: 嘴同时包住婴儿的口和鼻吹气,吹气量小,看到胸部轻微隆起即可;
  用两根手指在两乳头连线下方按压,深度约4 cm
- 儿童: 单手或双手按压,深度约5 cm
- 小孩在浴盆、水桶里溺水往往只需要很浅的水和很短的时间,
  救出后即使已经哭出声,也要去医院检查
```

不同年龄的按压深度和比例见[儿童和婴儿CPR区别](00-基础急救知识.md#儿童和婴儿cpr区别)。

### ❌ 常见错误

```
- 先控水再CPR(错!)
  * 延误CPR
  * 浪费黄金时间
  * 可能导致呕吐、误吸

正确:
- 不控水,先5次人工呼吸,再开始CPR
- 如在CPR时呕吐,侧转头部清除,继续CPR
```

```
其他常见错误:
- 把人倒挂、扛在肩上颠着跑、按压肚子"倒水"
  → 吸进肺里的水通常很少,而且很快被吸收,倒不出来;
     倒出来的多是胃里的水,反而可能被吸进气管
- 用腹部冲击法(海姆立克法)"排水" → 只用于异物卡喉,不用于溺水
- 只做胸外按压、不做人工呼吸(会做而不做) → 溺水的根本问题是缺氧
- 救上来后看人醒了就回家,不去医院
- 给刚救上来的人喝酒"暖身子"
- 没有受过训练的人下水救人,结果自己也溺水
```

### 溺水后迟发性呼吸症状

> 俗称"干性溺水""二次溺水",这两个说法已被WHO和国际救生联合会弃用。溺水后呼吸症状通常在8小时内出现,无症状的人不会在数天后突然"溺水"。

⚠️ **即使救起,也要就医观察!**

**症状**(数小时内可能出现):
- 持续咳嗽
- 呼吸困难
- 乏力、嗜睡
- 行为异常
- 呕吐

**原因**:
- 吸入少量水刺激肺部
- 肺水肿

**处理**:
- 溺水后观察至少8小时
- 如出现症状,立即就医

```
必须立即去医院的情况:
- 在水里失去过意识、做过CPR或人工呼吸
- 上岸后持续咳嗽、呼吸急促、胸痛、嘴唇发紫
- 精神差、嗜睡、烦躁、说话不清
- 婴幼儿、老人、有心肺疾病的人

在家观察时(上岸后完全正常、只是呛了几口水):
- 8小时内有人一直陪着,包括晚上睡觉时
- 留意咳嗽是否越来越重、呼吸是否变快变费力、精神是否变差
- 出现任何上述症状,立即就医
```

### 预防

```
✓ 永远不要单独游泳
✓ 儿童必须有成人监护
✓ 学会游泳
✓ 穿救生衣(船上、水上活动)
✓ 了解水域情况
✓ 不要高估自己能力
✓ 避免酒后游泳
✓ 疲劳时不要游泳
✓ 家中泳池:
  - 围栏
  - 监护
  - 移除玩具(防儿童独自下水)
```

```
补充:
✓ 儿童溺水多发生在家里和家附近: 浴盆、水桶、水缸、鱼塘、
  水井要加盖或随手倒空,孩子在水里或水边时,大人伸手可及、不看手机
✓ 不去没有救生员的野外水域游泳(水库、河流、池塘、采石坑),
  这些地方水下地形复杂、水温低、有暗流和水草
✓ 不在水边打闹,不在冰面上玩耍
✓ 天然水域突然腿抽筋: 不要慌,深吸一口气仰浮,把抽筋的腿伸直、
  脚尖往回扳,同时呼救
✓ 游泳前热身;饱餐、饥饿、剧烈运动后不要马上下水
```

儿童防溺水的详细做法见[儿童安全-防溺水](14-儿童安全.md#防溺水)。

## 📝 总结要点

### 急性症状识别

记住危及生命的症状:
- 呼吸困难
- 意识改变
- 休克征象
- 体温异常
- 心跳异常

### 处理原则

1. **安全第一** - 保护自己
2. **评估紧急程度** - ABC原则
3. **呼叫帮助** - 拨打120
4. **提供急救** - 在能力范围内
5. **持续监测** - 直到专业救援

### 五种情况的第一步

| 情况 | 第一步 | 最关键的一件事 | 最常见的错误 |
|------|--------|----------------|--------------|
| 过敏性休克 | 用肾上腺素笔 + 拨打120 | 平躺抬腿,不要站起来 | 只吃抗过敏药等着好转 |
| 热射病 | 拨打120 + 立即降温 | 冷水浸泡,先降温 | 只敷几个冰袋就急着送医 |
| 中重度失温 | 拨打120,轻柔平移 | 包裹 + 躯干加温 | 搓手脚、泡热水、让其走路 |
| 电击伤 | 先断电,再碰人 | 没有呼吸立即CPR,所有人都要就医 | 徒手拉人,靠近高压电线 |
| 溺水 | 岸上施救,不下水 | 先5次人工呼吸,再CPR | 控水、倒挂 |

### 必须掌握的技能

- CPR
- 过敏性休克识别和处理
- 中暑快速降温
- 失温复温原则
- 电击安全救援
- 溺水CPR

### 预防意识

- 识别风险
- 采取预防措施
- 准备应急装备
- 学习急救技能

心脑血管急症(中风、心梗、低血糖、癫痫、哮喘)见[心脑血管与突发病症](06-心脑血管与突发病症.md);各类中毒见[中毒](12-中毒.md);一氧化碳中毒见[居家与交通意外-一氧化碳中毒](07-居家与交通意外.md#一氧化碳中毒)。
