## 本章的定位

```
⚠️ 分娩应当在医院、由专业人员处理。

本章只用于: 来不及到医院、救护车还没到时的紧急情况。
- 绝大多数分娩是自然顺利的,接生者的主要任务是"不添乱"
- 少数情况会迅速危及母亲或婴儿的生命,这时最重要的是尽早呼叫专业帮助

任何时候都应该先拨打120。
调度员会在电话中一步步指导你,把手机开免提放在旁边。
```

**提前准备(孕晚期)**:
- 了解到最近的产科医院的路线和时间
- 准备好待产包(证件、产检资料、母婴用品)
- 偏远地区、交通不便或灾害多发季节,临近预产期提前到医院附近
- 孕期按时产检;产检时问清楚自己是否有高危因素(胎位不正、前置胎盘、多胎等)

## 孕期危险信号

孕期出现以下任何一项,**立即去医院或拨打120**,不要等到"开始生":

```
- 阴道出血
- 剧烈头痛、看东西模糊或眼前闪光、脸和手突然肿胀(可能是子痫前期)
- 抽搐
- 剧烈腹痛,或腹部持续发硬不放松
- 发热
- 胎动明显减少或消失
- 破水(阴道流出液体):
  - 不足37周
  - 或流出的液体是绿色、褐色、有臭味
  - 或破水后能摸到、看到阴道口有脐带(见下方脐带脱垂)
- 不足37周出现规律宫缩
```

## 判断: 来得及送医吗

### 临产的表现

- 规律宫缩: 肚子一阵阵发紧发痛,间隔越来越短,疼痛越来越强
- 见红: 阴道流出带血丝的黏液
- 破水

### 快要生了的表现

```
- 宫缩每隔2-3分钟一次,每次持续约1分钟
- 产妇有强烈的、控制不住的"想大便""想用力"的感觉
- 产妇说"孩子要出来了"
- 阴道口能看到胎儿的头(头顶露出)

出现这些表现,特别是已经能看到胎头时,往往已经来不及送医:
→ 不要再上车赶路(在车上分娩更危险)
→ 原地准备接生,同时拨打120
```

**经产妇**(以前生过孩子的)通常产程快得多,要更早出发去医院。

## 必须立即呼叫专业帮助的情况

以下情况普通人难以处理,**立即拨打120,按调度员指导做**:

| 情况 | 识别 | 等待时的做法 |
|------|------|--------------|
| **脐带脱垂** | 胎儿出来前,脐带先从阴道口露出 | 让产妇双膝跪地、胸部贴近地面(膝胸卧位),臀部抬高;❌ 不要把脐带往回推,不要捏压;用温暖湿润的干净布轻轻盖住露出的脐带 |
| **臀位**(屁股或脚先出来) | 先露出的不是头 | 让产妇不要过早用力;❌ 不要拉拽胎儿的腿或身体;按调度员指导 |
| **手臂先出来** | 先露出一只手 | ❌ 不要拉;不能自然分娩,必须尽快送医 |
| **头出来后肩膀卡住** | 胎头娩出后缩回去,身体出不来 | 让产妇仰卧,双腿尽量向胸部抱紧;或改为双手双膝着地的姿势;❌ 不要用力拉拽胎头 |
| **大出血** | 分娩前或分娩后出血不止 | 见下方产后出血 |
| **产妇抽搐** | 分娩前后出现抽搐 | 侧卧,防止受伤和误吸,见[癫痫发作](06-心脑血管与突发病症.md#癫痫发作)的处理 |
| **早产** | 不足37周 | 新生儿要特别注意保暖 |
| **双胞胎或多胞胎** | 第一个出生后仍有宫缩、肚子仍大 | 准备迎接第二个,同时通知120 |

## 来不及送医时的接生

### 准备

```
1. 拨打120,开免提
2. 洗手(肥皂和流水),有手套就戴上
3. 准备:
   - 干净的毛巾、床单、衣物(至少3-4条,给宝宝擦干和保暖)
   - 一块干净的布或塑料布垫在产妇身下
   - 一个盆或塑料袋(接胎盘)
   - 如需处理脐带: 两根干净的布条或鞋带,一把剪刀或刀片
     (煮沸10分钟以上消毒,或用火烧过冷却后再用)
4. 房间保暖(新生儿非常容易失温)
5. 产妇选择自己舒服的姿势: 半卧位(背后垫高)最常用,也可侧卧
```

### 分娩过程

```
1. 让产妇在宫缩时顺着感觉用力,宫缩间隙休息
2. 胎头露出后:
   - 用手掌轻轻托在胎头上,不要按压,也不要往外拉
   - 让胎头慢慢出来(太快容易造成产妇撕裂)
   - 胎头最宽的部分出来时,让产妇改为短促的哈气,不要再使劲
3. 胎头出来后:
   - 检查脖子上有没有绕着脐带
     - 松的: 用手指轻轻勾起,从头上绕过去
     - 很紧拉不开: 不要剪,让胎儿随身体一起娩出
   - 胎头会自然转向一侧
4. 下一次宫缩时,肩膀和身体会随之娩出
   - 双手托住宝宝(新生儿身上滑,小心不要掉落)
   - ❌ 不要拉拽宝宝
5. 记下出生时间
```

### ❌ 接生时不要做

```
❌ 不要让产妇夹紧双腿、或用任何方法阻止胎儿出来
❌ 不要拉拽胎儿的头、身体、四肢
❌ 不要拉脐带
❌ 不要把手伸进产道
❌ 不要按压产妇的肚子往下推
```

## 新生儿的黄金一分钟

**出生后1分钟内,宝宝应该已经在自主呼吸,否则就要开始帮助呼吸。**

### 所有宝宝

```
1. 把宝宝放在母亲胸腹部,皮肤贴着皮肤
2. 立即用干毛巾擦干全身,尤其是头和背部
   - 擦干既能保暖,也能刺激宝宝呼吸
3. 换掉湿毛巾,用干的毛巾包住宝宝,盖住头部(头部散热很多)
4. 观察: 是否哭、是否在呼吸、皮肤颜色、手脚是否有活动
```

正常: 宝宝哭出声、呼吸规则、肤色逐渐变红润,四肢活动。手脚稍发紫在最初几分钟是正常的。

### 宝宝不哭、不呼吸

```
1. 继续用力擦干背部,轻弹脚底(刺激呼吸)
2. 嘴和鼻子里有明显的黏液: 用干净的布擦掉
3. 擦干和刺激后仍不呼吸,或只有偶尔的喘息:
   → 立即告诉120调度员,按指导做
   → 开始人工呼吸:
     - 宝宝平躺在平坦处,头部保持在正中位置(不要过度后仰)
     - 用你的嘴同时包住宝宝的口和鼻
     - 轻轻吹气,吹的量只是你口腔里的一小口气,看到胸部轻微起伏即可
     - 大约每秒吹一次(每分钟40-60次)
     - 每隔一会儿看看宝宝是否开始自己呼吸
4. 需要人工呼吸时,先处理脐带(见下方),以便把宝宝放到平坦的地方
5. 持续进行,直到宝宝开始自主呼吸或急救人员到达
```

新生儿心肺复苏的完整方法见[基础急救知识-儿童和婴儿CPR区别](00-基础急救知识.md#儿童和婴儿cpr区别),请按120调度员的指导操作。

## 脐带的处理

### 不急着剪

```
✓ 宝宝正常呼吸时,至少等1分钟(世界卫生组织的建议)再夹脐带
  - 这段时间胎盘里的血会继续流向宝宝,对宝宝有益
✓ 救护车很快就到时,不需要自己剪脐带
  - 宝宝放在母亲胸前,保持脐带不被拉扯即可
  - 胎盘娩出后,可以连同胎盘一起包好,和母婴一起送医
```

### 必须剪断时

需要剪断的情况: 宝宝需要人工呼吸;或预计很长时间(如1小时以上)得不到专业帮助。

```
1. 等脐带停止搏动(用手指轻捏能感到搏动,停止后脐带会变得瘪白)
   - 宝宝需要人工呼吸时不必等待
2. 用干净的布条或鞋带(煮过或用开水烫过)扎两道:
   - 第一道: 离宝宝肚脐约10 cm(约四指宽)
   - 第二道: 再往胎盘方向约5 cm
   - 每道都打结扎紧(不要用细线,细线可能勒断脐带)
3. 用消毒过的剪刀或刀片,在两道结之间剪断
4. 检查宝宝这一侧的断端有没有渗血,渗血就在靠近宝宝处再扎一道

⚠️ 剪刀、刀片必须消毒(煮沸10分钟以上)
   用不干净的工具断脐,是新生儿破伤风的主要原因,死亡率很高
❌ 不要在脐带断端上涂抹任何东西: 草木灰、泥土、香灰、牛粪、
   牙膏、各种偏方粉末(都可能导致感染和破伤风)
```

## 胎盘与产后出血

### 胎盘娩出

```
- 胎盘通常在宝宝出生后几分钟到30分钟左右娩出
- 产妇可能再次感到宫缩,有想用力的感觉
- 让胎盘自然娩出,用盆或塑料袋接住
- 保留胎盘,随母婴一起送医(医生需要检查胎盘是否完整)

❌ 绝对不要拉脐带帮胎盘出来
   (可能拉断脐带、造成子宫内翻和致命的大出血)
```

### ⚠️ 产后出血: 最主要的产妇死亡原因之一

```
分娩后出现一定量的出血是正常的。
异常: 出血不止,很快浸透多条毛巾或垫子;
     或产妇出现面色苍白、出冷汗、心慌、头晕、意识模糊(休克表现)

处理:
1. 立即告诉120调度员
2. 立即让宝宝吃奶(或刺激乳头)
   - 吸吮能促使子宫收缩,减少出血
3. 按摩子宫:
   - 胎盘娩出后,在产妇肚脐下方能摸到一个圆圆的、像柚子大小的硬块,
     这就是子宫
   - 如果摸起来软软的,用手掌在上面画圈按摩,直到它变硬
   - 会比较痛,告诉产妇这是必要的
   - 子宫变硬后,每隔一段时间再检查,变软就再按摩
4. 产妇平躺,抬高双腿,保暖(同休克处理)
5. 外阴撕裂处出血: 用干净的布垫用力压住
6. ❌ 不要往阴道里塞任何东西
```

休克的识别与处理见[基础急救知识-休克处理](00-基础急救知识.md#休克处理)。

## 产后的母亲

### 最初几小时

```
✓ 保暖,喝温水或温热的甜饮料
✓ 让母婴皮肤贴着皮肤,尽早开始喂奶(出生后1小时内)
✓ 每隔一段时间检查出血情况和子宫硬度
✓ 鼓励小便(膀胱过满会影响子宫收缩)
✓ 即使一切顺利,也要尽快送母婴到医院检查
```

### 产后几周的危险信号(立即就医)

```
- 阴道出血突然增多,或出血量不减反增
- 发热、寒战
- 阴道分泌物有臭味
- 剧烈头痛、看东西模糊、抽搐(产后也可能发生子痫)
- 胸痛、呼吸困难
- 一侧小腿肿痛、发红(可能是血栓)
- 乳房红肿热痛伴发热
- 持续情绪低落、焦虑,或有伤害自己、伤害孩子的想法(可拨打12356)
```

产后情绪问题和自杀风险的识别见[心理健康](10-心理健康.md)。

## 新生儿最初几天

### 保暖

- 新生儿,尤其是早产儿和低体重儿,非常容易失温
- 母亲怀抱、皮肤贴皮肤是最好的保暖方式
- 戴帽子,多包一层,但不要包得过紧过厚而捂出汗
- 不要洗澡太早(至少等24小时以后),洗澡时房间要暖和,动作要快

### 喂养

```
✓ 出生后1小时内开始母乳喂养
✓ 初乳(最初几天量少、颜色偏黄的乳汁)非常宝贵,一定要喂,不要挤掉
✓ 宝宝想吃就喂(按需喂养),每天通常8-12次
✓ 6个月内纯母乳喂养,不需要喂水
❌ 不要喂糖水、米汤、蜂蜜(1岁以下禁止蜂蜜)等代替母乳
```

营养方面见[营养与营养缺乏病-特殊人群](../07-日常生活技能/02-营养与营养缺乏病.md#特殊人群)。

### 脐带护理

```
✓ 保持脐带残端清洁、干燥,暴露在空气中(尿布折在脐带下方)
✓ 被尿液、粪便弄脏时,用干净的水清洗后擦干
✓ 一般1-2周自然脱落,不要用手去拉
❌ 不要涂抹任何偏方物质

⚠️ 脐周发红扩散、流脓、有臭味、渗血 → 就医
```

### ⚠️ 新生儿危险信号(立即就医)

世界卫生组织列出的新生儿危险信号,出现任何一项都要立即就医:

```
- 不吃奶,或吃奶明显减少
- 抽搐
- 呼吸快(安静时每分钟60次以上)
- 吸气时胸部明显凹陷
- 不怎么动,或只有在刺激时才动
- 发热(体温37.5°C以上)
- 体温低(35.5°C以下)
- 出生24小时内就出现皮肤发黄,或任何时候手心脚心发黄
```

另外: 嘴唇持续发紫、反复呕吐(尤其是绿色呕吐物)、脐带周围严重感染,也要立即就医。

### 其他

- 新生儿出生后在医院一般会注射维生素K(预防出血)和接种疫苗,院外出生的要尽快补上
- 母亲孕期如未接种破伤风疫苗,院外分娩后要告诉医生

## 📝 要点

```
1. 先打120,开免提按调度员指导做
2. 能看到胎头时不要再赶路,原地接生
3. 托住不拉拽;不夹腿、不推肚子、不拉脐带、不伸手进产道
4. 宝宝出生: 放在母亲胸前,立即擦干、保暖、包住头
5. 黄金一分钟: 擦干刺激后仍不呼吸,立即人工呼吸
6. 脐带: 正常时至少等1分钟;救护车快到就不用剪;
   剪时用消毒工具、扎两道、断端不涂任何东西
7. 胎盘自然娩出,不拉脐带,带去医院
8. 产后出血: 立即喂奶、按摩子宫、平躺保暖、呼救
9. 新生儿保暖、尽早吃初乳;出现危险信号立即就医
```
