# 焊接与连接

> **会打造零件,还要会把零件连在一起——锅要补、车要修、农具断了要接、铁皮要拼成桶。连接技术决定了能造出多大、多复杂的东西**

## ⚠️ 安全第一

- 👁️ **电弧光会严重伤害眼睛**: 不戴焊接面罩看电弧,几小时后会出现剧烈眼痛、流泪、怕光(电光性眼炎);旁观的人同样会受伤
- ☀️ 电弧的紫外线会像严重晒伤一样灼伤裸露的皮肤
- ⚡ 电焊机有触电危险,潮湿环境中尤其危险
- ☠️ 焊接镀锌件、涂漆件、镀镉件会产生有毒烟气;铅焊料有毒
- 🔥 焊接火花能飞出好几米,引燃附近的木屑、草、衣物
- 💥 **绝不焊接或切割装过燃料、油、化学品的容器**(即使看起来已经空了),残留蒸气会爆炸

---

## 一、连接方法比较

| 方法 | 难度 | 强度 | 需要的条件 | 适合 |
|------|------|------|-----------|------|
| 螺栓连接 | ⭐ | 好 | 钻孔、螺栓螺母 | 需要拆卸的地方 |
| 铆接 | ⭐⭐ | 好 | 钻孔或冲孔、铆钉 | 铁皮、板材、农具、不需要拆的结构 |
| 锡焊(软钎焊) | ⭐⭐ | 低 | 焊料、焊剂、烙铁 | 铁皮器具防漏、导线、电子元件 |
| 铜焊(硬钎焊) | ⭐⭐⭐ | 较好 | 黄铜或银焊料、硼砂、强火 | 钢、铜、黄铜零件,修补铸铁 |
| 锻焊 | ⭐⭐⭐⭐ | 很好 | 锻炉、高温、熟练技术 | 熟铁和低碳钢,接长、包钢刃 |
| 电弧焊 | ⭐⭐⭐ | 很好 | 电焊机和电力、焊条、面罩 | 钢结构、修理 |

```
选择原则:
- 要能拆 → 螺栓
- 没有电、没有焊机 → 铆接、锻焊、钎焊
- 要防水不漏、受力不大 → 锡焊
- 有电焊机和电力 → 电弧焊最快最强
```

## 二、铆接

不需要电,也不需要很高的温度,是电焊普及以前连接钢板最主要的方法(铁桥、锅炉、船都是铆起来的)。

### 2.1 尺寸经验

```
铆钉直径: 薄板约为板厚的1.5-2倍
铆钉中心距: 至少为铆钉直径的3倍
铆钉到板边的距离: 至少为铆钉直径的2倍
铆钉长度: 两层板的总厚度 + 约1.5倍铆钉直径(用来打成另一个铆钉头)
```

### 2.2 冷铆(小铆钉、铁皮、铜、铝)

```
1. 两块板夹紧,一起钻孔(孔径比铆钉稍大一点)
2. 插入铆钉,钉头一侧垫在砧子或铁块上
3. 用锤子先把露出的钉杆打粗(镦粗),再打成圆头
4. 铆好后两块板之间应紧密贴合,不晃动
```

### 2.3 热铆(大铆钉、钢结构)

```
1. 把铆钉加热到亮红色
2. 迅速插入孔中,背面顶住,正面锤打成头
3. 铆钉冷却收缩,把两块板拉得非常紧
→ 比冷铆结实得多,适合受力大的地方
```

### 2.4 铁皮的咬口

```
不用铆钉、不用焊接,把两块铁皮的边折弯互相钩住再压平(咬口)
→ 做铁皮桶、烟囱管、水槽的常用方法;再用锡焊封缝即可防漏
```

## 三、锻焊

把两块铁加热到接近熔化的白热状态,锤打在一起,结合成一整块。传统铁匠最核心的技术之一: 接长、包钢刃(见[简易工具锻造-嵌钢刃](03-简易工具锻造.md#112-嵌钢刃))、折叠锻打都靠它。

### 3.1 适用的材料

```
✓ 熟铁、低碳钢: 最容易锻焊
△ 中碳钢、高碳钢: 可以,但焊接温度要低一些,容易烧坏
✗ 铸铁: 不能锻焊(不能锻打)
✗ 不锈钢、镀锌件: 很难或不能
```

### 3.2 步骤

```
1. 准备接口
   - 把两个要焊接的端头各锻成斜面(像削铅笔那样的斜坡,叫"斜接口")
   - 端头先镦粗一点,弥补焊接时被锤薄的部分
   - 斜面稍微鼓起(中间略凸),锤合时从中间向外挤出氧化皮

2. 清洁和焊剂
   - 打掉氧化皮
   - 加热到亮红色时撒上焊剂: 硼砂最好;没有硼砂可以用干净的细石英砂
   - 焊剂熔化后包住接口,防止继续氧化,并溶解氧化皮

3. 加热到焊接温度
   - 两块料一起加热,接口朝下,埋在火的中心
   - 颜色: 亮黄到白色,表面像出汗一样发亮,开始冒出零星火花
   - 火花大量迸射 → 已经过烧,钢在燃烧,要退出来
   - 低碳钢约1250-1300°C

4. 锤合
   - 迅速取出,轻轻敲掉表面杂物,把两个斜面对齐叠上
   - 先轻锤让它们粘住,再从中间向外重锤
   - 动作要快: 几秒钟后温度下降就焊不上了

5. 再次加热、锤打,让焊缝完全结合,修整成型

检验: 冷却后在焊缝处弯曲,焊缝不裂开才算成功
```

```
常见失败:
- 温度不够 → 粘不上,一敲就分开
- 接口有氧化皮或炉渣 → 焊缝有夹渣,一弯就裂
- 火里有硫(用煤时)→ 铁变脆,焊不好
- 动作太慢
```

## 四、锡焊(软钎焊)

用熔点低的焊料(锡或锡铅合金)把金属粘在一起,金属本身不熔化。强度不高,但能**密封不漏**,也能**导电**。

### 4.1 材料

```
焊料:
- 锡铅焊料(如锡63%、铅37%): 约183°C熔化,最好用
  ⚠️ 含铅,不要用于盛食物、饮水的器具
- 无铅焊料(锡加少量铜): 约227°C熔化,可用于食品器具
- 纯锡: 232°C

焊剂(去除氧化膜,让焊料能"润湿"金属):
- 松香: 用于导线、电子元件,无腐蚀
- 焊锡膏
- 氯化锌溶液("熟盐酸"): 把锌片放入稀盐酸,直到不再冒泡
  → 用于铁皮、铜皮,效果好,但有腐蚀性,焊完必须用水洗净
  ⚠️ 制作时产生氢气,远离明火,在室外进行

烙铁:
- 电烙铁
- 没有电时: 一块较大的紫铜块装上铁柄,在火中加热后使用(传统烙铁)
```

### 4.2 步骤

```
1. 清洁: 用砂纸、锉刀把焊接处打磨到露出金属光泽,去除油污
2. 涂焊剂
3. 先"上锡": 分别在两个焊接面上镀一层焊料
4. 合在一起加热,让焊料熔化流进缝隙
5. 关键: 加热工件,让工件把焊料熔化;不要只是把焊料滴在冷的工件上
   (那样焊料只是"粘"在表面,一碰就掉)
6. 冷却前不要移动
7. 用了腐蚀性焊剂的,用水洗净

铁皮的缝: 先咬口或搭接,再锡焊密封,不要只靠焊料承受力量
```

### 4.3 导线连接

```
1. 剥去绝缘皮,刮亮铜线
2. 把两根线互相缠绕拧紧(先保证机械连接牢固)
3. 涂松香,焊上锡
4. 用绝缘胶布或热缩管包好
```

## 五、铜焊(硬钎焊)

用熔点较高的黄铜或银焊料,比锡焊结实得多,可以连接钢、铜、黄铜,也能修补铸铁件的裂纹。

```
焊料:
- 黄铜(铜锌合金): 约900°C熔化,便宜(可用回收的黄铜丝、黄铜片)
- 银焊料: 约600-800°C熔化,流动性好,接头漂亮,但贵
焊剂: 硼砂(用少量水调成糊)

步骤:
1. 清洁、打磨接口,接口之间的缝隙要小而均匀(零点几毫米)
2. 涂硼砂糊
3. 把工件整体加热到亮红色(锻炉、强火或喷灯)
4. 把焊料靠在接缝上,工件的热量把焊料熔化,焊料会被"吸"进缝隙
5. 自然冷却,敲掉玻璃状的硼砂残渣

⚠️ 黄铜过热时会冒出白色锌烟,不要吸入
⚠️ 铜焊的温度高于钢的回火温度,淬过火的工具铜焊后会变软,需要重新热处理
```

## 六、电弧焊

用电在焊条和工件之间产生电弧,温度高达数千摄氏度,把焊条和工件局部熔化,冷却后融为一体。只要有电焊机(回收)和电力,就是最快、最结实的连接方法。

### 6.1 设备和防护

```
设备:
- 电焊机(交流或直流,从废旧物资中回收)
- 焊钳、地线夹、电缆
- 焊条: 普通低碳钢焊条(如 J422 / E4303),保存在干燥处
- 敲渣锤、钢丝刷

防护(缺一不可):
- [ ] 焊接面罩,滤光镜遮光号约10-12(⚠️ 普通墨镜绝对不行)
- [ ] 皮手套、长袖厚棉衣(化纤衣服遇火花会熔化粘在皮肤上)
- [ ] 皮鞋
- [ ] 周围拉上遮挡,防止旁人看到电弧
- [ ] 通风;不在密闭空间焊接
- [ ] 手边准备灭火的沙或水,焊完后检查周围30分钟有无阴燃
```

### 6.2 焊接电流

```
普通低碳钢焊条的常用电流(以焊条包装上的推荐值为准):
  2.5 mm 焊条: 约50-80 A
  3.2 mm 焊条: 约90-130 A
  4.0 mm 焊条: 约140-200 A
  薄板、立焊、仰焊取下限,厚板平焊取上限
电流太小 → 起弧困难、粘条、焊不透
电流太大 → 飞溅多、咬边、烧穿薄板
```

### 6.3 操作要点

```
1. 清理: 焊接处打磨干净,去除锈、油漆、镀锌层
2. 接好地线夹,尽量靠近焊接处
3. 引弧: 戴好面罩,焊条在工件上轻轻划擦(像划火柴),电弧产生后提起
4. 弧长: 保持焊条末端到工件的距离约等于焊条直径
5. 运条: 匀速前进,焊条略向前进方向倾斜
6. 收尾: 填满弧坑后再提起
7. 敲去焊渣,检查焊缝
8. 多层焊: 每焊一层都要清净焊渣再焊下一层

点焊固定: 正式焊接前,先在接缝几处点焊固定,防止变形错位
厚板(约6 mm以上): 接口要先磨出坡口(V形),才能焊透
```

### 6.4 没有电焊机时

```
有人用3个汽车蓄电池串联(约36 V)应急焊接。
⚠️ 只能作为最后手段: 电流无法调节,电池会严重发热,
   并可能因放出的氢气而爆炸;电池要远离电弧和火花,接线要牢固
```

蓄电池的安全见[电气工程与电子学-电池和储能](../09-进阶科学与工程/02-电气工程与电子学.md#七电池和储能)。

## 七、气焊和气割(了解)

```
用乙炔(或其他可燃气)和氧气混合燃烧,火焰温度约3000°C以上,
可以焊接、加热,配合割炬还能切割钢板

⚠️ 这需要专业的气瓶、减压阀、回火防止器;
   气瓶受热、碰撞、漏气都可能爆炸,乙炔与空气混合极易爆炸
   → 只在有完好专业设备并经过培训的情况下使用,不要自制
```

## 八、检查焊接质量

```
外观: 焊缝均匀饱满,没有裂纹、气孔、咬边(焊缝边缘被烧出的沟)、未焊透
锤击: 用锤子敲打焊缝附近,听声音、看是否开裂
弯曲试验: 用同样的材料、同样的方法焊一块试片,夹在台钳上弯曲,
  焊缝处不开裂才说明焊得好
⚠️ 承重、受压的重要部件(吊钩、车轴、压力容器)不要依赖自己没有把握的焊缝
```

## 九、检查清单

### 焊接前

- [ ] 工件是否装过燃料、油或化学品?是 → 不焊
- [ ] 镀锌、油漆、油污是否已清除?
- [ ] 周围3-5 m内有无易燃物?
- [ ] 防护用品是否齐全(电焊: 面罩、皮手套、长袖、皮鞋)?
- [ ] 旁人是否已经远离或有遮挡?

### 焊接后

- [ ] 工件冷却前不要用手触摸
- [ ] 检查周围有无火星阴燃
- [ ] 焊缝是否经过检查
