# 钳工与机械加工

> **锻和铸只能做出"毛坯",要让零件真正能装配、能转动、能互换,靠的是锯、锉、钻、攻丝和车削——这是把铁块变成机器的最后一步**

## ⚠️ 安全第一

- ⚙️ **转动的机器会卷入手套、袖口、长发、项链**: 操作钻床、车床、砂轮时不戴手套,扎紧袖口,长发盘起
- 👁️ 切屑、砂轮碎片会飞溅伤眼: 戴护目镜
- 💥 砂轮转速很高,有裂纹的砂轮会爆裂: 使用前检查,站在砂轮侧面启动
- 🩸 金属切屑和毛刺锋利,不要用手抹切屑,用刷子或钩子清理
- 🔧 车床卡盘扳手用完立即取下,否则开机时会飞出
- ⚠️ 小工件钻孔时不要用手拿着,要用台钳或夹具固定,否则钻头卡住时工件会跟着转

---

## 一、钳工台和台钳

```
钳工台: 结实、沉重、不晃动的木台或钢台
台钳: 固定在台边;钳口高度约在操作者的肘部高度
  → 太高太低都会让锉削不平、容易疲劳

✓ 夹持已经加工好的表面时,钳口垫上铜皮、铝皮或硬木,防止夹伤
✓ 工件伸出钳口的部分尽量短,减少振动
```

---

## 二、划线和测量

### 2.1 工具

```
- 钢直尺、卷尺
- 角尺(检查直角)
- 划针: 淬硬磨尖的钢针,在金属上划出细线
- 样冲: 在线上或孔的中心打出小坑(钻孔前定位)
- 圆规(划规): 划圆、等分
- 游标卡尺: 测量外径、内径、深度,精度可达0.02 mm
- 平板: 一块平整的铸铁板或厚玻璃板,作为测量和划线的基准

划线前在工件表面涂一层白灰水、粉笔或蓝色颜料,线条更清楚
```

### 2.2 游标卡尺的读法

```
1. 先读主尺: 游标零线左边的主尺刻度(整毫米)
2. 再读游标: 找游标上哪一条刻线和主尺刻线对得最齐,读出它的数(×0.02 mm)
3. 两者相加
例: 主尺读到 23 mm,游标第 17 条线对齐 → 23 + 17 × 0.02 = 23.34 mm
```

度量基准的建立见[度量衡与科学方法](../08-基础科学知识/00-度量衡与科学方法.md)。

## 三、锯削

```
✓ 锯条的齿尖朝前(推的方向切削)
✓ 锯条要拉紧,不要扭曲
✓ 薄材料用细齿锯条,至少有2-3个齿同时在材料上(否则会崩齿)
✓ 用整根锯条的长度来回锯,速度约每分钟40-60次,不要太快
✓ 推时加压,拉回时不加压
✓ 快锯断时减轻压力,用手托住要掉的部分
✓ 锯钢时可以加一点机油;锯铸铁、黄铜干锯
```

---

## 四、锉削

### 4.1 锉刀的选择

```
按齿的粗细: 粗锉(去除多)→ 中锉 → 细锉、油光锉(修光)
按形状: 扁锉(平面)、方锉(方孔)、圆锉(圆孔、内圆角)、
  半圆锉(大的内圆弧)、三角锉(锐角、修锯齿)
```

### 4.2 方法

```
✓ 锉刀只在向前推时切削,拉回时轻轻提起或不加压
✓ 两手配合: 前手压锉尖,后手推锉柄,保持锉刀水平前进
  (锉削不平的最常见原因是锉刀在推的过程中上下晃动)
✓ 交叉锉: 换着方向锉,容易看出哪里高、哪里低
✓ 顺向锉(推锉): 最后修光时,锉刀横握,沿工件长度方向推拉
✓ 检查平面: 用角尺或直尺的刃口贴在工件上,对着光看缝隙

✓ 锉屑塞住锉齿时,用钢丝刷(锉刀刷)顺着齿纹刷干净
✗ 不要在锉刀上抹油(会打滑),不要用手摸锉过的表面(手上的油会让锉刀打滑)
✗ 新锉刀先锉铜、铝等软材料,再锉钢;不要锉淬过火的钢(会磨损锉刀)
```

## 五、钻孔

### 5.1 步骤

```
1. 划线,在孔的中心打样冲眼(钻头才不会滑走)
2. 工件夹紧在台钳或钻床工作台上
3. 大孔先钻一个小的导向孔,再用大钻头扩孔
4. 钻钢时加机油或肥皂水冷却润滑;钻铸铁、黄铜干钻
5. 快钻透时减小压力(钻头容易突然卡住)
6. 钻深孔时经常退出排屑

转速: 钻头越粗,转速越低;材料越硬,转速越低
```

### 5.2 没有电钻时

```
- 手摇钻、胸压钻(从废旧物资中回收)
- 弓钻: 用弓弦缠住钻杆来回拉动,适合小孔、软材料
- 冲孔: 薄铁板可以加热后用冲子在砧子的孔上冲出孔
```

### 5.3 磨钻头

```
麻花钻的钻尖角约118°,两条切削刃要等长、对称
- 刃口后面要磨出一点后角(约8-12°),让切削刃能切入
- 两刃不对称时,钻出的孔会偏大、钻头偏摆
```

## 六、攻丝和套丝

### 6.1 内螺纹(攻丝)

```
底孔直径 ≈ 螺纹公称直径 - 螺距
  M6 × 1: 底孔约5 mm
  M8 × 1.25: 底孔约6.8 mm
  M10 × 1.5: 底孔约8.5 mm
  M12 × 1.75: 底孔约10.2 mm

步骤:
1. 钻好底孔,孔口倒一个小角
2. 丝锥垂直对准孔,用铰杠(丝锥扳手)转动
3. 每向前转半圈,倒转约四分之一圈,把切屑折断
4. 钢件加机油;盲孔要经常退出清屑
5. 成套丝锥按头锥、二锥(三锥)的顺序使用
⚠️ 丝锥很脆,转不动时不要硬扳,否则会断在孔里,很难取出
```

### 6.2 外螺纹(套丝)

```
- 圆杆直径略小于螺纹公称直径(约小0.1-0.2 mm),端头倒角
- 板牙放正,用板牙架转动,同样每转半圈倒转一点
```

### 6.3 统一螺纹标准

```
✓ 社区内统一使用几种规格的螺纹(例如回收的公制丝锥板牙对应的规格)
✓ 丝锥、板牙极其宝贵,自己制造需要淬火的工具钢和精确的分度,尽量回收保存
```

螺纹标准化的意义见[工程力学与材料-螺纹和紧固件](../09-进阶科学与工程/01-工程力学与材料.md#116-螺纹和紧固件)。

## 七、刮研: 得到高精度的平面

```
锉削能得到"比较平"的平面;要得到机床导轨、滑动面那样高精度的平面,用刮研:

1. 准备一块标准平板(比工件更平的基准)
   → 没有现成的平板时,用三块板轮流对研(三平板互研法,见技术重建路线图)
2. 在平板上薄薄涂一层显示剂(红丹油、普鲁士蓝,或烟灰调油)
3. 工件放在平板上来回推研几下,拿开
4. 工件上沾到颜色的点就是高点
5. 用刮刀(淬硬磨利的扁钢片)刮掉这些高点
6. 重复,直到接触点又多又均匀
```

精密加工的自举方法见[技术重建路线图-精密加工](../09-进阶科学与工程/00-技术重建路线图.md#32-精密加工-机器的母机)。

## 八、磨削

```
天然磨石: 砂岩做成的大轮子,下部浸在水槽里,转动着磨刀具和工件
回收的砂轮:
- 使用前做"敲击检查": 用木槌轻敲砂轮,声音清脆说明完好;声音沙哑可能有裂纹,不要用
- 必须装防护罩
- 启动时站在砂轮侧面,不要正对砂轮
- 工件托架和砂轮之间的间隙不超过约3 mm,防止工件卡进去
- 磨淬过火的刀具时经常蘸水冷却,发蓝发黑说明退火了(变软)
```

磨刀方法见[木工与工具维护-磨刀](../07-日常生活技能/09-木工与工具维护.md#磨刀)。

## 九、车床

车床被称为"机床之母": 能车出圆柱、圆孔、端面、螺纹,用一台车床可以做出另一台更好的车床。

### 9.1 主要部件

```
主轴箱(床头): 带动工件旋转,装卡盘或顶尖
尾座: 用顶尖顶住长工件的另一端,或装钻头钻孔
刀架和溜板: 夹持车刀,沿导轨纵向、横向移动
丝杠: 带动溜板按精确的速度前进 → 车螺纹
床身导轨: 整台车床的精度基准
```

### 9.2 切削速度和转速

```
主轴转速(转/分)= 1000 × 切削速度(m/min)÷ (π × 工件直径(mm))

高速钢车刀的切削速度(大致):
  低碳钢: 约20-30 m/min
  铸铁: 约15-25 m/min
  黄铜、铝: 更快
例: 车直径50 mm的低碳钢,取25 m/min
  转速 = 1000 × 25 ÷ (3.14 × 50) ≈ 160 转/分

工件越粗,转速越低;车刀发红、冒蓝烟 → 太快了
```

### 9.3 车刀

```
- 材料: 高速钢(从回收的车刀、钻头、锯条中得到)或硬质合金刀片
- 前角: 车钢约10-15°,车黄铜接近0°
- 后角: 约6-8°,让刀刃以下的部分不和工件摩擦
- 刀尖对准工件的中心高度
```

### 9.4 没有现成车床时: 弹性杆车床

```
历史上最简单的车床,可以车木头和较软的金属:
- 两个支架上装两个顶尖,夹住工件
- 一根绳子在工件上绕一圈,上端系在头顶一根有弹性的长木杆上,下端系在脚踏板上
- 踩下踏板,工件转动,车刀切削;松开,木杆把绳子拉回,工件反转(这时退刀)
- 车刀架在一根横木上,用手把握
→ 只能断续切削,但做轴、把手、轮子、木碗足够
```

### 9.5 安全

```
✓ 工件夹牢,开机前取下卡盘扳手
✓ 不戴手套,不用手摸转动的工件,不用手清理切屑
✓ 长切屑会缠绕,用钩子清理
✓ 戴护目镜
```

## 十、精度和互换

```
公差: 零件尺寸允许的误差范围,如轴的直径 20 mm,允许 ±0.05 mm
配合: 轴和孔之间要"松"(能转动)、"紧"(压进去不动)还是"过渡"
量规: 做一对标准的"通规"和"止规",能通过通规、通不过止规的零件就合格
  → 不用每次都测量具体尺寸,检验又快又可靠

互换性: 按统一的标准和量规加工,不同人、不同时间做的零件能互相替换
  → 机器坏了只需换零件,这是大规模生产的基础
```
