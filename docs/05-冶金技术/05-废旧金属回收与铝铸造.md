# 废旧金属回收与铝铸造

> **文明崩溃后的几十年里,最大的"矿山"是废墟: 一辆报废汽车里的钢、铝、铜,比一个小炼铁炉几个月炼出的还多,质量也好得多**

## ⚠️ 安全第一

**拆解和熔化废旧金属有很多看不见的危险!**

- 💥 密封的容器、气瓶、减震器、灭火器受热会爆炸——**绝不把密封件放进火里**
- 💥 潮湿的废料、工具放进熔融金属会引起水蒸气爆炸,金属液四溅
- ☠️ 镀锌件(白色镀层的铁皮、水管、螺丝)受热放出锌烟,引起"金属烟热"(发烧、寒战、全身酸痛)
- ☠️ 铅、镉(金黄色镀层)及其烟尘有毒;旧刹车片可能含石棉
- 🔥 镁合金(某些轮毂、发动机罩)屑末和熔液会剧烈燃烧,**遇水更猛烈**,不能用水扑灭
- ⚡ 电容、蓄电池、锂电池拆解时可能放电、漏酸、起火

**必须在室外通风处操作,站在上风方向,穿戴防护用品。**

## 一、为什么先回收,再冶炼

| 来源 | 难度 | 质量 | 说明 |
|------|------|------|------|
| 现成的钢铁件直接改锻 | ⭐ | 很好 | 汽车板簧、锉刀、钢轨,成分稳定,远好于土法炼的铁 |
| 废铝熔化重铸 | ⭐⭐ | 好 | 熔点只有约660°C,木炭炉加鼓风就能熔化 |
| 废铜、黄铜熔铸 | ⭐⭐⭐ | 好 | 需要约1100-1200°C |
| 废铁熔化铸造 | ⭐⭐⭐⭐ | 一般 | 需要约1300-1400°C和焦炭,见[铸造进阶](07-铸造进阶.md) |
| 从矿石冶炼 | ⭐⭐⭐⭐⭐ | 难以保证 | 见[铁的冶炼](01-铁的冶炼.md)、[铜的冶炼](02-铜的冶炼.md) |

```
优先顺序:
1. 能直接用的,直接用(螺栓、链条、轴承、弹簧、管子)
2. 能改锻的,改锻(板簧 → 刀,钢轨 → 砧子)
3. 熔点低的,熔化重铸(铝、铅、锡、锌)
4. 最后才是从矿石冶炼
```

## 二、识别金属

### 2.1 简单判断

| 方法 | 结果 | 说明 |
|------|------|------|
| 磁铁 | 吸得很牢 | 钢、铁、铸铁(以及部分不锈钢) |
| 磁铁 | 不吸 | 铝、铜、黄铜、铅、锌、大部分不锈钢 |
| 颜色 | 红色 | 铜 |
| 颜色 | 金黄色 | 黄铜(铜 + 锌) |
| 颜色 | 暗金、褐色 | 青铜(铜 + 锡) |
| 掂重量 | 很轻 | 铝(密度约2.7 g/cm³)或更轻的镁(约1.7 g/cm³) |
| 掂重量 | 很重、软,指甲能划出痕 | 铅(约11.3 g/cm³) |
| 锉刀 | 锉不动、打滑 | 淬过火的钢(硬) |
| 锉刀 | 容易锉 | 低碳钢、熟铁、铸铁、有色金属 |
| 敲击 | 声音清脆 | 钢 |
| 敲击 | 声音发闷 | 铸铁、铅 |

### 2.2 火花鉴别(砂轮或粗锉打磨)

```
低碳钢(钢筋、铁皮): 火花流线长、黄白色,分叉很少
中碳钢(轴、齿轮): 流线较长,分叉明显增多
高碳钢(锉刀、弹簧): 流线较短,分叉多而密,像一簇簇小星星
铸铁: 流线短,暗红到橙色,末端有少量小分叉
不锈钢: 流线较短,橙黄色,分叉少
铝、铜、黄铜、铅: 几乎没有火花

→ 火花越多越"开花",含碳越高,越适合做刀具和工具
→ 拿一块已知的钢(如锉刀、钢筋)对比着看,判断更准确
```

### 2.3 镁和铝的区分

```
镁比铝更轻(同样大小,约为铝重量的三分之二)
用锉刀锉下一点碎屑,放在不燃的石头上点火:
  镁屑会发出耀眼的白光剧烈燃烧(⚠️ 不要直视,只用极少量)
  铝屑不容易点着
⚠️ 不确定是不是镁合金的零件,不要和铝一起熔化
```

## 三、废墟中的好材料

### 3.1 钢铁

| 来源 | 大致材质 | 适合做 |
|------|---------|--------|
| 汽车板簧、螺旋弹簧 | 弹簧钢(如60Si2Mn,含碳约0.6%) | 刀、斧、凿、撬棍、弹簧 |
| 锉刀 | 碳素工具钢(如T12,含碳约1.2%) | 小刀、刻刀、凿子(先退火再锻) |
| 滚动轴承的内外圈、滚珠 | 轴承钢(如GCr15,含碳约1%,含铬) | 冲子、小刀、钻头 |
| 钢轨 | 含碳约0.7%的钢 | 截一段作砧子,质量非常好 |
| 汽车半轴、传动轴 | 中碳合金钢 | 锤头、撬棍、重型工具 |
| 钢筋 | 低碳钢,成分不稳定 | 钉子、钩子、链条、不需要淬火的东西 |
| 汽车车身、铁皮 | 低碳钢板 | 铁皮器具、罩子、炉子 |
| 钢丝绳、钢丝 | 高碳钢丝 | 绳索、弹簧、捆扎 |
| 刹车盘、刹车鼓、发动机缸体 | 灰铸铁 | 重新熔化铸造(见铸造进阶);不能锻打 |

```
✓ 已知是好钢的料(板簧、锉刀、轴承)单独分类存放,做重要的工具
✓ 来源不明的钢,先截一小段做淬火试验: 加热到樱桃红淬水,
  用锉刀试,锉不动 → 含碳量高,可做刀具;能锉动 → 低碳钢
```

淬火方法见[金属加工技术](04-金属加工技术.md)。

### 3.2 有色金属

| 金属 | 来源 | 熔点 | 用途 |
|------|------|------|------|
| 铝 | 铝合金门窗型材、汽车轮毂、发动机活塞和缸盖、炊具、易拉罐 | 约660°C | 铸造锅具、零件、模具 |
| 铜 | 电线电缆、电动机和变压器的线圈、水管 | 1085°C | 导线(最好直接保留成线)、铸造 |
| 黄铜 | 水龙头、阀门、管件、弹壳 | 约900-940°C | 铸造阀门、轴套、零件 |
| 铅 | 蓄电池极板、车轮平衡块、旧水管、电缆护套 | 327°C | 配重、焊料、防辐射屏蔽 |
| 锡 | 焊锡、锡器 | 232°C | 焊料、和铜配成青铜 |
| 锌 | 镀锌层、压铸件(部分门把手、龙头) | 约420°C | 和铜配成黄铜 |

```
⚠️ 铜线不要直接烧掉绝缘皮: 塑料燃烧产生有毒烟气(含氯化氢、二噁英)
   → 用刀剥,或者剪开外皮抽出;粗电缆可以纵向剖开
✓ 能保持成线的铜线尽量保留,不要熔化 —— 自己拉铜丝非常困难,
  而发电机、电动机、电报都需要铜线
✓ 易拉罐的铝很薄,表面氧化物多、有涂层,熔化后损失大(可能只剩一半左右);
  优先熔化厚的铸铝件(轮毂、活塞、缸盖)
```

### 3.3 其他有用的东西

```
- 齿轮、链条、轴承、轴、螺栓螺母: 尽量直接使用
- 电动机、发电机: 见电气工程与电子学
- 磁铁: 扬声器、电动机、硬盘
- 弹簧: 门弹簧、床垫弹簧、汽车弹簧
- 锯条、钻头、丝锥、板牙: 非常宝贵,自己很难做
```

可回收的电气设备见[电气工程与电子学-现实可行的小型发电](../09-进阶科学与工程/02-电气工程与电子学.md#33-现实可行的小型发电)。

## 四、拆解与预处理

```
1. 分类: 按钢、铸铁、铝、铜、黄铜、铅、其他分开堆放
2. 去除非金属: 塑料、橡胶、油漆、油污、绝缘皮
3. 去除镀锌层: 镀锌铁皮、镀锌管在锻打或焊接前,
   用砂轮打磨掉,或用醋泡一两天让锌层溶解(在通风处)
4. 去除油污: 油在熔化时冒浓烟、起火;用火在室外烧掉,或用碱水洗
5. 切小: 熔化前切成能放进坩埚的小块
6. 干燥: 所有要放进熔融金属里的料必须彻底干燥(先放在炉边烘烤)

⚠️ 拆解时绝不加热或切割:
- 气瓶、灭火器、喷雾罐、打火机
- 汽车减震器、气弹簧(内有高压气体和油)
- 密封的管子、空心件(里面可能有水或气)
- 油箱(残留汽油蒸气会爆炸)
```

## 五、铝的熔化与铸造

铝是废墟中最容易熔铸的金属: 熔点低,一个小坩埚炉就能熔化,适合铸造锅、勺、零件、模具。

### 5.1 设备

```
坩埚炉(简易):
- 外壳: 铁桶或厚铁皮桶
- 内衬: 耐火材料,厚约5-8 cm(耐火黏土加熟料,见铁的冶炼-耐火材料配制)
- 底部侧面开一个进风口,斜着朝向炉膛切线方向,让火焰在坩埚周围旋转
- 盖子: 留一个出气口
- 燃料: 木炭或焦炭
- 鼓风: 皮囊、风箱、手摇鼓风机,或者回收的电吹风、鼓风机

坩埚:
- 铝可以用钢制坩埚: 一段厚壁钢管,一端焊上(或锻接)钢板做底
- 坩埚要有可靠的夹持方式: 配套的坩埚钳,或在坩埚两侧焊耳,用浇注叉抬起
- 坩埚钳和浇注叉事先空着试一遍,确认夹得牢、拿得稳
```

耐火材料的配制见[铁的冶炼-耐火材料配制](01-铁的冶炼.md#22-耐火材料配制);坩埚炉的详细做法见[铸造进阶-熔炉和坩埚](07-铸造进阶.md#二熔炉和坩埚)。

### 5.2 熔化步骤

```
1. 坩埚放进炉中,先空烧预热到发红,烤干水分
2. 放入少量干燥的铝块
3. 铝块熔化后,再逐块加入预热过的铝料(不要一次塞满)
4. 浇注温度约700-750°C
   (没有温度计时: 铝全部熔化、搅动时流动性很好后,再稍加热一会儿即可浇注;
    不要一直烧到坩埚发亮,温度太高会让铝吸入更多气体,铸件多气孔)
5. 用预热过的铁勺撇去表面的浮渣(氧化物和杂质)
6. 不要过度搅拌(会带入气体和氧化物)
7. 尽快浇注
```

### 5.3 模具

```
砂模: 最常用,见铜的冶炼-砂模铸造和铸造进阶-型砂与造型
金属模(钢、铸铁): 可以反复使用,适合简单形状的锭、块
  - 使用前必须预热(约200°C以上),彻底去除水分
  - 内表面用蜡烛或松枝熏一层烟灰,便于脱模
⚠️ 绝不使用潮湿的模具,也不要在水泥地面上浇注
  (水泥里的水分受热会使地面爆裂飞溅)
  → 在一层干沙上操作和浇注
```

### 5.4 铸件的处理

```
- 冷却后取出,锯掉浇口
- 锉、刮、打磨
- 铝铸件可以钻孔、锉削、车削,但比钢软,不耐磨
- 做炊具: 优先用回收的铸铝件和炊具熔化(成分较纯);
  来源不明的铝合金(可能含铅、镉等)不要做炊具
```

## 六、其他低熔点金属

### 6.1 铅

```
熔点327°C,在普通火上就能熔化,适合铸造配重、子弹形状的坠子、焊料

⚠️ 铅中毒是慢性的、不可逆的:
- 只在室外熔化,站在上风方向
- 温度不要过高(冒烟说明太热了),铅蒸气和铅烟毒性大
- 孕妇、儿童不要接触,不要在附近
- 操作后用肥皂洗手洗脸,换下的衣服单独洗
- 熔铅用的锅、勺、模具专用,绝不再用于食物
- 不要用铅做盛食物、饮水的容器

蓄电池极板: 不建议自己回收
  → 电池里有硫酸,极板上的铅膏是铅的化合物粉末,极易吸入
```

### 6.2 锡和锌

```
锡: 熔点232°C,无毒,用于焊料、配青铜;
  罐头盒是镀了极薄一层锡的钢板,不是锡的来源
锌: 熔点约420°C,沸点约907°C;熔化时温度过高会冒白色锌烟
  → 只在室外、小心控温,避免吸入
```

## 七、检查清单

### 熔化前

- [ ] 在室外、远离易燃物,地面铺干沙
- [ ] 坩埚、钳子、浇注叉、撇渣勺都已预热烘干
- [ ] 所有原料干燥,没有密封件、没有镀锌件、没有不明合金
- [ ] 模具干燥、预热,放在干沙上
- [ ] 穿戴: 皮手套、护目镜或面罩、皮围裙、皮鞋(不穿化纤衣服和凉鞋)
- [ ] 准备一桶干沙,用来覆盖洒出的金属(⚠️ 不能用水)
- [ ] 事先计划好浇注的路线,中间没有障碍物,旁人远离

### 浇注时

- [ ] 双手稳握,动作连贯,不中断
- [ ] 洒出的金属等它冷却再处理,不要用手或脚去碰
