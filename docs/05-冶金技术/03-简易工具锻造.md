# 简易工具锻造

> **末日最需要的工具 - 从零开始打造生存装备**

## 🔨 引言

**有了金属,还需要加工成工具才有用!**

本章节教你如何用熟铁、钢或青铜锻造最基本、最必需的工具。这些工具将成为你重建文明的基础。

**工具优先级:**
1. **锤子** - 制作其他工具的工具
2. **刀和斧** - 基本生存工具
3. **锄、镐** - 农业和采矿
4. **钉子** - 建造必需

**材料从哪里来:** 文明崩溃后最现实的原料不是自己炼的铁,而是废墟里的钢: 汽车板簧、锉刀、钢轨、半轴、钢筋。哪种料适合打哪种工具,见[废旧金属回收与铝铸造-钢铁](05-废旧金属回收与铝铸造.md#31-钢铁);自己冶炼熟铁见[铁的冶炼](01-铁的冶炼.md)。

**熟铁和钢的区别决定了怎么打:**
- **熟铁、低碳钢**(钢筋、铁皮): 软、好打、好锻焊,但**淬不硬** → 刀身、斧身、钉子、链条、锄板
- **中碳、高碳钢**(半轴、板簧、锉刀): 能淬硬,但锻打温度范围窄,烧过头会坏、温度低会裂 → 锤头、镐、刃口、凿子、冲子
- **生铁、铸铁**: **不能锻打**,一锤就碎,只能铸造

---

## ⚠️ 安全第一

- ☠️ **一氧化碳**: 木炭、煤炉在屋里或封闭棚子里会让人头痛、昏迷甚至死亡。锻炉必须在通风好的半敞开棚下,见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)
- 🔥 **"不发红"不等于"不烫"**: 铁冷到看不出红色时仍有几百摄氏度。砧子周围、地上的铁一律当它是烫的,用钳子夹,不用手捡
- 👁️ **戴护目镜**: 锤打时氧化皮会崩飞;錾子、冲子的头打成"蘑菇头"后,卷边会碎裂飞出,伤眼最常见
- 👕 穿棉、麻、皮质衣服和围裙,不穿化纤(遇火星熔化粘在皮肤上);穿包住脚面的鞋;扎好长发
- 🛢️ **淬火油会着火**: 用带盖的金属桶装油,工件要一次全部浸没;油着火时盖上盖子或撒沙,**绝不泼水**
- ☠️ 镀锌件(白色镀层的铁皮、水管、螺丝)加热会冒白烟,吸入引起"金属烟热";锻打前先去掉镀锌层(见[废旧金属回收与铝铸造-拆解与预处理](05-废旧金属回收与铝铸造.md#四拆解与预处理))。不锻打铅、镀镉件和来源不明的涂层件
- 🔨 两人打大锤时,事先约定口令;掌钳的人不能站在大锤挥动的方向上
- 🔇 长期锻打会伤听力,用棉花或软木塞堵耳

烫伤的处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤);冶金作业的通用防护见[基础冶金知识-安全防护](00-基础冶金知识.md#六安全防护)。

## 一、锻造基础知识

### 1.1 什么是锻造?

**锻造 = 加热金属 + 锤打成型**

**原理:**
- 金属加热后变软
- 锤打可改变形状
- 冷却后保持新形状
- 反复锤打使金属更致密、更强

锻打把炉渣挤出、把粗晶粒打碎,所以锻件比铸件韧得多: 受冲击的刀、斧、凿、钉要锻,形状复杂、不受猛烈冲击的锅、犁铧才铸造(见[铸造进阶](07-铸造进阶.md))。锻打只改变形状,算料时按成品重量多备约1/5,弥补氧化皮和料头。

### 1.2 锻造温度

| 温度 | 颜色 | 状态 | 适用 |
|------|------|------|------|
| 暗红(约500-600°C) | 暗红色勉强可见 | 太硬 | 不适合锻造,只能做轻微校直 |
| 深红(约700°C) | 深红色 | 较硬 | 熟铁、低碳钢的停锻温度: 打到这个颜色就回炉 |
| 樱桃红(约800-900°C) | 樱桃红 | 可锻 | **淬火温度**(约800°C);高碳钢锻打的下限;最后的精修整形 |
| 橙红(约1000-1100°C) | 橙红色 | **最好锻** | 熟铁、低碳钢拔长、镦粗的主要温度;高碳钢不要超过这个颜色 |
| 黄色(约1200°C) | 黄色 | 很软 | 熟铁、低碳钢的重锻、开坯;高碳钢会烧坏 |
| 亮黄到白(约1250-1300°C) | 发亮,表面像出汗,冒零星火花 | 锻焊温度 | 只在锻焊时用;火花大量迸射 = 已经过烧 |

**关键:**
- **熟铁、低碳钢在橙红到黄色时最好锻,打到深红就回炉**
- **高碳钢(板簧、锉刀)只在樱桃红到橙红之间锻,温度范围窄,要勤回炉**
- 温度不够: 打不动,工具易裂
- 温度过高: 金属烧损,性能下降
- **不发红时绝不重锤**: 低碳钢在约200-400°C(表面出现蓝色氧化色时)特别脆,这时锤打最容易打出暗裂

**看火色:** 在棚下阴凉处看(阳光下同样温度显得暗,容易烧过头);尖端、薄边热得快,要看最厚的部位是否热透。

### 1.3 必备工具

#### 最小工具集:

**1. 锻造炉:**
```
简易锻造炉:
- 比冶炼炉小得多
- 内径: 20 cm
- 深度: 15 cm
- 炉膛装木炭
- 侧面鼓风口
- 可用耐火砖临时砌
```

锻炉的结构、燃料、火的管理和各种风箱的做法见[鼓风设备与锻炉](08-鼓风设备与锻炉.md#五锻炉)。

**2. 砧(铁砧):**
```
理想: 大块熟铁或钢(50-100 kg)
替代:
  - 大石块(花岗岩、玄武岩)
  - 铁轨段
  - 大铁块
要求: 平整、坚硬、稳固
```

砧子的安装高度和废墟中的砧子材料见[鼓风设备与锻炉-砧子](08-鼓风设备与锻炉.md#54-砧子)。

- 砧子越重越好,锤下去砧子"不动",力气才用在工件上
- 砧面一条边磨成圆角(半径约5 mm)用来弯曲、拉槽,另一条边保持直角;旁边固定一根粗圆钢当"砧角",弯环、弯钩用
- 石砧容易崩裂,切断、冲孔时要垫一块软铁板

**3. 锤子:**
```
初期: 石锤、铁锤头绑木柄
后期: 自己锻造专用锤
重量: 0.5-2 kg
```

- 单人主锤约1-1.5 kg,初学者从1 kg左右开始;两人配合时帮手抡3-5 kg的大锤,师傅用小锤指点("小锤点哪,大锤打哪")
- 圆头锤(一面平一面球形)用来拔长、打凹面

**4. 钳子:**
```
用途: 夹持烫的工件
初期: 两根木棍+铁丝绑
后期: 锻造铁钳
```

- **钳口必须和工件的粗细、形状吻合**,否则锤一震工件就会飞出去伤人;方条、圆条、扁条各配一把。用铁环套住两根钳把,可以把钳口锁紧

**5. 凿子、冲子:**
```
用途: 开孔、切断
制作: 淬火硬化的铁棍
```

- 要用钢做,熟铁的淬不硬。**热錾、热冲**用在红热工件上,粗短、勤蘸水即可;**冷錾**切冷铁,必须淬火回火(做法见下)
- 另做一根锥度更缓的"冲杆",把冲好的孔扩大、修正形状

**辅助用品:** 淬火水桶(放在炉边伸手可及)、带盖的金属油桶、磁铁(判断淬火温度)、钢丝刷、磨石和砂纸(看回火色)、卡钳或铁丝样板、石笔、灭火沙。

#### 自制第一把铁钳:

```
材料: 两段约12-16 mm见方的熟铁或钢条,各长约40 cm,两半做得一模一样
1. 端头约5 cm打扁做钳口;紧挨着的一段打扁成关节,扁的方向与钳口转90°
2. 其余拔长成钳把,长约30 cm;关节中心冲孔(约8 mm)
3. 两半交叉,插入烧红的铆钉铆合,趁热反复开合防止卡死
4. 把要夹的料放进钳口,加热钳口锤打,使它贴合这种料
检查: 夹住工件用锤敲,工件不晃、不转、不滑出
```

铆接的要点见[焊接与连接-铆接](06-焊接与连接.md#二铆接)。

#### 錾子和冲子的做法:

```
材料: 高碳钢(板簧、旧锉刀需先退火)或中碳钢圆条,直径约16-20 mm,长约15-20 cm

1. 锻形: 一端拔成锥形或扁楔形(錾刃),另一端(锤击端)打出约2 mm的倒角
2. 正火: 加热到樱桃红,放在空气中自然冷却,重复2-3次(消除锻造应力)
3. 磨刃: 冷錾刃口夹角约60°(切铁),木工凿约25-30°
4. 淬火: 只把刃口一端约2-3 cm加热到樱桃红,浸入水中约1 cm,
   上下小幅晃动,刃口发黑后整个取出
5. 回火: 把刃口磨亮,靠上部的余热让颜色往刃口走,
   冷錾到紫色、木工凿到褐色时整体浸水
6. 锤击端不淬火,保持软;打成"蘑菇头"后立即磨掉卷边,
   否则卷边会碎裂飞出伤眼
```

### 1.4 基本锻打技巧

#### 握锤和站位

```
站位: 侧对砧子,握钳一侧的脚稍在前;砧面约在垂手时的指关节高度
握锤: 握在锤柄后部,不要攥死,让锤头自己的重量落下去
下锤: 锤面平着落下,落点在砧子正上方
      (锤面歪斜会留下月牙形锤印;打在悬空部分会打弯、震手)
每一火: 工件埋在火中心偏上(风口正前方氧化严重),翻动热透
        → 出火刷掉松散氧化皮 → 先重锤成型,变暗改轻锤
        → 降到深红就回炉。小件一火只能打20-40秒
        一火只做一件事: 这一火拔长,下一火再弯
```

**1. 平锤:**
- 垂直下锤
- 用于展平、延伸
- 修整表面时用轻而密的锤,把锤印打平

**2. 斜锤:**
- 倾斜击打
- 用于塑形、收拢
- 例如打出刃口斜面、把方条的棱收成八角

**3. 折叠锻打:**
- 对折金属
- 反复锤打
- 增加层次,提升强度
- 实际用途主要是**把块炼铁里的炉渣挤出去、让成分均匀**;层次本身并不神奇。熟铁折叠3-6次就够了,折得太多反而把碳烧掉、把料烧没。做法见[11.1](#111-折叠锻打百炼钢)

**4. 镦粗:**
- 垂直锤打端部
- 使金属增厚

```
用途: 钉帽、锻焊前加厚接头、锤头和镐的开眼部位

1. 只加热要镦粗的那一段(约为直径的2-3倍长),
   加热后可以把其余部分在水里蘸一下,让它保持硬
   → 只有热的一段被打粗,不会整根变粗
2. 工件竖立在砧面上,热端朝上(或朝下用砧子"撞"),锤子垂直打端面
3. 每打几锤就检查: 一开始弯了,立即在砧子上扶直再继续
   (弯着继续打会折叠出一道裂缝,叫"折叠",以后会从这里断)
4. 被镦的一段长度不要超过直径的约3倍,超过了必然打弯,要分几火来
```

**5. 拔长:**
- 持续锤打
- 使金属延伸、变薄

```
用途: 把粗料打成细长的条、刀身、尖

方条拔长:
1. 每一锤后把工件翻转90°,两个面轮流打,保持截面方正
   (只打一个方向会变成菱形截面,越打越歪,而且容易从中间开裂)
2. 工件压在砧子的圆角边上锤打,或用锤边打出一道道横槽,
   再把槽打平 → 金属只往长的方向走,比在平面上打快很多
3. 从料的根部往端头一段一段打,锤印前后搭接

拔成圆条: 方 → 打掉四个棱成八角 → 打成十六角 → 边转边轻锤成圆
拔尖: 方形打尖,最后再修圆;尖端薄、热得快,要先拿出火,
      避免烧坏
```

**6. 弯曲:**

```
1. 只加热要弯的那一段(弯哪里热哪里)
2. 在砧角或圆钢上弯圆弧;在砧子直角边上弯直角
   没有砧角时: 在木墩上钉两根粗铁桩,工件插在中间扳弯(弯曲叉)
3. 弯的外侧会被拉薄,角越尖越薄
   → 要弯出又方又结实的直角,先在拐角处镦粗一点,再弯
4. 弯好后放在平砧面上轻锤修平,检查是否在一个平面上
```

**7. 冲孔:**

```
用途: 锤眼、斧眼、钳子关节、铆钉孔

1. 先在工件上画好位置,用冲子轻轻冲出一个浅印,检查位置正确
2. 加热到橙红到黄色(要比一般锻打更热,冲孔才省力)
3. 冲子对准浅印,用力锤下,冲到工件厚度的约2/3深
   - 每打几锤把冲子拔出来蘸水,否则冲子会被烤软
   - 孔里撒一小撮木炭粉,冲子不易卡死
4. 翻过来,背面能看到一个颜色较暗的斑(那里被冲子挤得最近)
5. 从背面对准暗斑冲下,把中间剩下的一小块"料芯"冲掉:
   工件垫在砧子的孔上、或一个铁环上,料芯从下面落出
6. 再加热,用锥度更缓的冲杆把孔扩大、修正成需要的形状
   (例如锤眼、斧眼的椭圆形)

❌ 只从一面冲到底: 孔会歪,背面撕出毛边
❌ 冲孔的部位太窄: 孔两侧的"墙"会被挤裂。孔周围留的料至少要和孔径一样宽,
   需要时先把那里镦粗
```

**8. 切断:**

```
热切(料粗、红热时):
1. 工件下面垫一块软铁板或铜板,不要直接切在砧面上(会崩坏錾刃和砧面)
2. 热錾立在切口上,锤打,切进约一半深
3. 翻过来从另一面对准切口切
4. 剩下薄薄一层时,把切口放在砧子边上,轻锤掰断

冷切(细料、薄板):
- 用冷錾在冷料上錾出一圈深槽,再放在砧边掰断
- 戴护目镜: 切断的料头会飞出去,前方不要站人
- 有钢锯时,细料直接锯更省事(见钳工与机械加工)
```

锯削、锉削见[钳工与机械加工](09-钳工与机械加工.md#三锯削)。

**9. 锻焊:**

把两块熟铁或低碳钢加热到亮黄到白色、撒上硼砂(或细石英砂)当焊剂,迅速叠在一起锤打,结合成一块。接长、做铁环链条、包钢刃都靠它。完整步骤、温度判断和常见失败见[焊接与连接-锻焊](06-焊接与连接.md#三锻焊),这里只强调几点:

- 接口先镦粗、再打成斜面(斜接口),焊合后才不会比别处细
- 两块料要**同时**到焊接温度,动作要快,出火到第一锤不超过两三秒
- 第一锤要轻(先粘住),然后从中间往外加重
- 用煤做燃料时含硫,铁会变脆,锻焊很难成功;锻焊最好用木炭或焦炭

### 1.5 热处理: 火色与回火色

工具钢(中碳、高碳钢)锻好以后要**淬火**变硬,再**回火**消除脆性。原理和完整操作见[金属加工技术](04-金属加工技术.md),本章各工具用的颜色统一如下:

**淬火:**
```
1. 先正火: 锻好的工件加热到樱桃红,放在空气中(不要放在湿地上、
   风口上)自然冷却。重复2-3次 → 消除锻造应力,淬火时不容易裂
2. 淬火前先粗磨: 刃口留约1 mm厚,不要磨到锋利
   (太薄的刃淬火时最容易开裂、变形)
3. 加热到樱桃红(约800°C),热透
   简便判断: 拿磁铁去碰,钢加热到吸不住磁铁时,
   再稍微多加热一会儿,就是合适的淬火温度
4. 刃口先入水(或油),直上直下,前后搅动(不要左右摆动,会弯)
5. 冷到不发红后取出,立即回火(放着不管,有时会自己裂开)

水淬: 硬,但容易开裂,适合形状简单的錾子、冲子
油淬(植物油、动物油): 慢一些,不易裂,适合薄刃的刀、镰
温水(约30-60°C): 介于两者之间
```

**回火色**(把淬火件磨出光亮面后,慢慢加热时表面出现的颜色):

| 颜色 | 约温度 | 本章用于 |
|------|--------|---------|
| 浅黄 | 220°C | 剃刀、刻刀等极硬的小刃 |
| 金黄 | 240°C | 菜刀、小刀、刨刀 |
| 褐色 | 260°C | 斧头、木工凿、镰刀 |
| 紫色 | 280°C | 冷錾、锤面、剪刀 |
| 深蓝 | 300°C | 镐尖、锄刃、弹簧、钳子等要耐冲击的 |

```
回火要领:
- 刃口最薄,热得最快 → 从刀背或工件厚的一侧加热,
  让颜色慢慢"走"到刃口;或把工件放在一块烧红的铁板上
- 颜色到了立即浸水或浸油,停止回火
- 颜色一下子跑过头(变灰)→ 回火过度,硬度不够,只能重新淬火再回火
```

各种工具的回火温度表和局部淬火方法见[金属加工技术-回火操作](04-金属加工技术.md#32-回火操作)、[金属加工技术-选择性淬火](04-金属加工技术.md#24-选择性淬火局部淬火)。

**熟铁、低碳钢不能淬硬**,淬火没有用;要硬的刃口,只能包钢(见[11.2](#112-嵌钢刃))或渗碳(见[11.3](#113-表面硬化))。

## 二、锤子锻造

**为什么先做锤子?**
- 锤子是"制作工具的工具"
- 有了好锤子,其他工具更好做

### 2.1 锤头锻造

**材料:**
- 熟铁块: 1 kg
- 或钢块: 0.8 kg(更好)

最合适的料是一段中碳钢圆料: 汽车半轴、传动轴、大螺栓截一段。直径约40 mm的钢料,约10-12 cm长就是约1 kg的锤头料。熟铁锤头软,锤面会越用越凹,只能临时用。

**步骤:**

**1. 加热:**
- 铁块加热至樱桃红
- 钢料热透到橙红再开始重锤;每一火只打到深红就回炉

**2. 初步成型:**
```
圆柱形铁块
   ↓ 锤打一端
楔形(一端粗一端细)
   ↓ 锤打中部
中间收腰(安装柄的地方)
   ↓ 整形
锤头雏形
```

实用顺序: 圆料先打成方料、端面打正 → 画出锤眼位置 → **先开眼,再把两端成型**(开眼时挤歪的形状可以在后面修正)。

**3. 开眼(装柄的孔):**
```
方法A: 热冲法
  - 加热至橙红到黄色
  - 用尖凿从两面对冲
  - 打穿

方法B: 钻孔法
  - 锻造完成后
  - 用钻头钻孔(费时)
```

锤眼做成约15 mm × 30 mm的椭圆(1 kg锤头),冲杆从两面各打进一些,让孔两头稍呈喇叭口: 楔子胀开柄头后卡在里面不会脱出。冲杆留在孔里,把鼓出的两侧打平。

冲孔的通用方法见[1.4](#14-基本锻打技巧)第7项;钻孔见[钳工与机械加工-钻孔](09-钳工与机械加工.md#五钻孔)。

**4. 整形:**
- 锤击面: 平整光滑
- 楔面: 略弧形
- 锤面四周打一圈小倒角、中间略鼓,锤印不会有棱边

**5. 淬火(如果是钢):**
- 加热至樱桃红
- 快速放入水中
- 表面硬化

- 只淬两端,锤眼一带保持软: 整个加热到樱桃红,夹住锤眼,两个锤面轮流浸水约2 cm、上下晃动,两端都不发红后再整个浸入

**6. 回火:**
- 重新加热,看回火色(见[1.5](#15-热处理-火色与回火色))
- 减少脆性
- 锤面回火到**紫色**(约280°C): 把锤面磨亮,把一根烧红的粗铁条插进锤眼,热量从中间往两端走,锤面颜色经过浅黄、金黄、褐,变紫时立即浸水。锤眼一带被烧得更热、更韧,不会从眼处裂开

### 2.2 安装柄

**木柄制作:**
```
材料: 硬木(橡木、榆木、槐木)
长度: 30-40 cm
粗细: 握持舒适,前细后粗

安装:
1. 木柄插入锤头孔
2. 打入木楔或铁楔(从顶部)
3. 楔子胀开,卡紧
```

木料干透、木纹顺直、无疤节;**锤头有任何松动就停用修理**,飞出的锤头会伤人。完整步骤见[木工与工具维护-换工具柄](../07-日常生活技能/09-木工与工具维护.md#换工具柄斧锤锄)。

## 三、刀具锻造

### 3.1 简易菜刀

**材料:**
- 熟铁: 500 g(做刀身)
- 钢: 50 g(做刃口,如有)

有一段汽车板簧时,整块打一把刀最省事(不用锻焊);熟铁加钢片适合钢很少的时候。

**步骤:**

**1. 拔长:**
- 铁块加热
- 反复锤打拉长成条
- 目标尺寸: 长20 cm,宽8 cm,厚5 mm
- 一端留约10 cm拔细做"刀根"(装柄用),与刀身之间打出台阶,防止手往前滑

**2. 成型刀身:**
```
锤打边缘,使其变薄
形成刀刃
   ___
  /   \  ← 刀刃(薄)
 |     | ← 刀身
 |_____| ← 刀背(厚,保持强度)
```

从刀背往刃口逐渐打薄: 刀背约3-5 mm,刃口约1-1.5 mm。刃口一侧被打长,刀会向刀背方向弯 → 事先把料向反方向弯一点,或打完在砧上从刀背侧敲直。最后一火在樱桃红轻锤修平。

**3. 包钢(如果有钢):**
```
方法:
  - 刃口位置焊接钢片
  - 加热至接近熔化
  - 锤打使铁和钢结合
  - 形成"软铁背,钢刃口"
  - 传统中国菜刀、斧头"夹钢"就是这个原理
```

包钢要在成型之前做,见[11.2 嵌钢刃](#112-嵌钢刃)和[焊接与连接-锻焊](06-焊接与连接.md#三锻焊)。

**4. 磨刃:**
- 在磨石上研磨
- 形成锋利刃口
- **淬火前只粗磨**: 磨平锤印、修出刃口斜面,刃口留约1 mm厚;最后的开刃留到回火以后

**5. 淬火(如果刃口是钢):**
- 刃口加热至樱桃红
- 只有刃口部分浸水淬火
- 刀背不淬(保持韧性)

- 先正火2-3次;刃口均匀加热到樱桃红(磁铁吸不住再稍热),刃口朝下垂直浸入油(或水)约1-2 cm,沿刃口方向前后移动,不发红后整把浸入;锉刀打滑才算淬硬

**6. 回火:**
- 刃口回火到金黄色(约240°C)
- 减少脆性
- 刀身磨出光亮带,刀背贴在烧红的铁板上,颜色走到刃口变金黄时浸水

**7. 安装柄:**
- 木柄或包布

- 插柄: 刀根打成尖锥,硬木柄(长约12 cm)钻一个较细的孔,刀身用湿布包住(保护回火),刀根烧热后"烫"进孔里,柄前端套铁箍防裂
- 夹柄: 刀根打成扁片,两侧夹木片,用2-3个铆钉铆紧

**8. 最后开刃:** 回火后在磨石上开刃(刃口斜面约15-20°),不要把刃口磨热。磨法见[木工与工具维护-磨刀](../07-日常生活技能/09-木工与工具维护.md#磨刀)。

### 3.2 砍刀/匕首

**类似菜刀,但:**
- 更厚重(砍刀)
- 或更薄更尖(匕首)
- 单刃,刀背留厚
- 全钢最佳(如有)

本书只讲作为工具用的刀:
- **柴刀**(砍枝、劈竹、开路): 刀身长约25-30 cm,刀背厚约5-6 mm,重心靠前;回火到褐色(约260°C),比菜刀韧;刃口斜面约20-25°
- **尖头小刀**(宰杀、剥皮、削木): 刀身长约10-15 cm,刀背厚约3 mm,用板簧或旧锉刀打(锉刀先退火、磨掉锉齿再锻,否则锉齿会被锤成裂纹);回火到金黄色;刀根处打出台阶,防止手滑到刃上

## 四、斧头锻造

### 4.1 斧头结构

```
[侧视图]
       刃口
        ↓
    ___/  ← 斧头刃
   /
  |  ○  ← 安柄孔
  |
   \___  ← 斧头背(锤击用)
```

**关键:** 重心在刃口侧,砍伐有力

砍伐斧刃薄、吃木深(约1-1.5 kg);劈柴斧斧身厚、楔形钝(约1.5-2.5 kg)。斧背不要去砸铁楔、钢件,斧眼一带会被砸裂。

### 4.2 锻造步骤

**材料:**
- 熟铁: 1-1.5 kg
- 钢片(做刃口,如有): 约100 g,厚约5 mm、宽约4 cm

**步骤:**

**1. 对折锻打:**
```
长铁条
  ↓ 对折
双层
  ↓ 锤打焊合
一端开口(安柄孔)
  ↓ 整形
斧头雏形
```

```
包眼法(熟铁加钢刃):
1. 熟铁扁条约50 mm宽、12 mm厚、30 cm长,中间一段稍打薄
2. 加热,围着一根斧眼形状的铁芯对折
3. 两条"腿"的末端之间夹入钢片,露出约5 mm
4. 撒硼砂,加热到焊接温度,从斧眼一侧一路焊到刃口
5. 焊合后整体打成斧形,刃口由钢片构成
```

锻焊要领见[焊接与连接-锻焊](06-焊接与连接.md#三锻焊)。有一整块中碳钢(如半轴)时,也可以在后部两面对冲出斧眼、前部拔长展宽成斧身,不用锻焊。

**2. 开刃:**
- 锤打刃口使其变薄
- 形成斜面
- 刃口略呈外弧,两角打圆一点,不易崩角

**3. 开孔:**
- 对折处自然形成孔
- 或热冲、钻孔
- 斧眼上下两端略成喇叭口,楔子胀开后不会掉

**4. 淬火回火(如是钢):**
- 刃口淬火硬化
- 回火减脆

- 正火后只把刃口约3 cm加热到樱桃红,浸水约2 cm,前后晃动;磨亮侧面,让余热把颜色带到刃口,**刃口到褐色(约260°C)时**浸水

**5. 磨刃:**
- 磨石研磨
- 刃口角度20-30°
- 劈柴斧取大,砍伐斧取小;两面磨得一样,砍下去才不歪

**6. 安装斧柄:**
- 木柄长60-80 cm
- 前细后粗
- 楔子固定
- 从柄尾看过去,刃口要对准柄的中线

## 五、农具锻造

农具大多用熟铁或低碳钢做身,刃口包钢或渗碳。农具要锄进夹着石头的泥土,**韧比硬重要**: 刃口宁可软一点、钝了再磨,也不要硬到一碰石头就崩。

### 5.1 锄头

**结构:**
```
[俯视图]
┌─────┐
│     │ ← 锄板(宽15 cm,长20 cm)
│  ║  │ ← 安柄套筒
└─────┘
```

**锻造:**
1. 铁块锤打成薄板
2. 一端卷成套筒(装柄)
3. 板面略弧形
4. 磨锋利边缘

**用途:** 翻土、除草

**详细做法:**

```
1. 锄板: 熟铁或低碳钢打成约3-5 mm厚,刃口一侧打薄到约2 mm,
   靠柄一侧留厚
2. 装柄: 板后端留一条舌头,围着锥形铁芯卷成锥形套筒;
   或另打锄颈,一端锻焊或铆在锄板背面,另一端冲出锄眼
3. 锄板与柄约成60-70°,按使用者身高在锄颈处热弯调整
4. 刃口锻焊一条钢,或渗碳(见11.3);淬火后回火到深蓝(约300°C)
5. 只磨上面一面,刃口斜面约30°
修锄: 刃磨短后加热拔长打薄,再淬火回火,一把锄可以修很多年
```

### 5.2 镐(十字镐)

**结构:**
```
  ╱╲  ← 尖头(破硬土、岩石)
 ╱  ╲
═════ ← 安柄孔
 ╲  ╱
  ╲╱  ← 凿形(可选)
```

**锻造:**
1. 铁块中部开孔(安柄)
2. 两端锤打拔尖
3. 淬火增硬(如是钢)

**用途:** 挖掘、采矿、破冰

**详细做法:**

```
材料: 中碳钢(如半轴),约2-3 kg
1. 中间一段先镦粗,冲眼后孔两侧才有足够的"肉"
2. 两面对冲出镐眼,用冲杆修形
3. 一端拔成四棱尖,另一端打扁成宽约5 cm的凿形(或也拔尖),两臂略向下弯
4. 正火;两端分别加热到樱桃红、浸水约3 cm淬火;
   回火到紫色到深蓝(约280-300°C),镐要砸石头,太硬会崩尖
5. 柄长约80-90 cm,镐眼上大下小,柄从上往下穿,越用越紧
镐尖秃了: 重新加热拔尖再淬火回火,不要一直磨
```

### 5.3 镰刀

**结构:**
```
   ___
  /   ← 弧形刃口
 /
/
║ ← 柄
```

**锻造:**
1. 长铁条锤打成弯月形
2. 内侧磨成刃口
3. 一端锻造成安柄套筒

**用途:** 收割、割草

**详细做法:**

```
材料: 薄板簧等高碳钢片,或熟铁加钢刃
1. 拔长成约3 mm厚、3-4 cm宽、30-40 cm长的扁条
2. 把刃口一边打薄到约1 mm: 这一侧伸长,扁条自然弯成镰刀的弧形
3. 柄端打成柄脚,穿过木柄后把露出的尖弯回钉进木柄;或卷成套筒
4. 正火,刃口加热到樱桃红后油淬(薄件水淬易裂、易变形)
5. 回火到褐色(约260°C);只磨一面,刃口要薄
锯齿镰(割麦、稻): 淬火前用錾子沿刃口斜着錾出细齿,钝了重新錾
```

## 六、钉子和紧固件

### 6.1 铁钉锻造

**为什么重要?**
- 建筑、家具必需
- 用量巨大
- 简单但关键

钉子用熟铁或低碳钢(钢筋)打,不需要淬火 — 硬钉子钉进木头时会脆断。

**步骤:**

**1. 准备铁条:**
- 粗细: 小钉用约4-5 mm见方的条,大钉约6-10 mm见方
- 长度: 比成品钉长5 cm

- 批量做时直接在一根长条的端头打,做完一根切下一根,长条当把手,不用钳子

**2. 拔尖:**
- 加热一端至樱桃红
- 锤打成尖
- 打成四棱锥形,尖不要太细: 方而略钝的钉尖切断木纤维,不易劈裂木头

**3. 做钉帽:**
```
方法A: 直接镦粗
  - 另一端加热
  - 垂直锤打,增厚成钉帽

方法B: 使用钉模
  - 铁板上钻小孔
  - 尖端插入孔
  - 露出的端部锤打成帽
```

```
钉模: 厚约10 mm的钢板上冲一个比钉身略大的孔,孔往下稍变粗,
      架在砧子的孔上或两块砖之间;不同粗细的钉子各做一个
1. 钉身拔好后,在离端头约1.5倍钉粗处,在砧边錾出一圈切口
2. 插进钉模,在切口处掰断,端头留在钉模上方
3. 趁热先垂直重锤两三下,再斜着从四个方向各打一锤,成"玫瑰头"
4. 从下面敲出钉子。全程一火完成
```

**4. 切断:**
- 凿子切断

**5. 冷却:**
- 水冷

**效率:**
- 熟练后: 2-5分钟/根
- 一天可做100-200根!

**做铆钉:** 与钉子相同,但不拔尖,钉身两端平;长度按"两层板总厚 + 约1.5倍铆钉直径"截取(见[焊接与连接-尺寸经验](06-焊接与连接.md#21-尺寸经验))。

### 6.2 铁环、链条

**铁环(扣环):**
1. 铁条绕圆柱(木棍)成螺旋
2. 切断成单个环
3. 每个环锻接闭合

**链条:**
- 环环相扣
- 用于吊挂、牵引

**详细做法:**

```
材料: 熟铁或低碳钢圆条,常用直径8-10 mm
1. 下料: 用铁丝绕一个同样大小的环量出长度,再加约1倍料粗
   (锻焊时的重叠和损耗);试好后同一种链条都按这个长度
2. 两端镦粗,打成方向相反的斜接口
3. 在砧角上弯成U形,穿进上一个环,弯合使两个斜口叠在一起
4. 撒焊剂,加热到焊接温度,在砧角上锤合,修成椭圆
检验: 焊缝有缝线、凹陷、黑色夹渣 → 剪掉重做;
      挂约为使用重量2倍的重物试拉,人不站在下面
⚠️ 自制链条不吊人、不在人头顶上方吊重物;强度等于最差的那个环
```

不用锻焊的连接(铆合、冷弯钩环)见[板材与线材-线材的用途](11-板材与线材.md#45-线材的用途)。

## 七、容器类

### 7.1 铁锅

**方法:** 铸造或锻造

**铸造法(简单):**
- 熔化铁(或用生铁)
- 倒入锅形模具
- 冷却成型
- 铁水需要很高的炉温和合适的型砂,实际上并不简单,见[铸造进阶](07-铸造进阶.md)

**锻造法(费力):**
1. 大铁板
2. 加热后用圆头锤反复击打
3. 形成凹形
4. 边缘向外卷

锤揲的步骤见[板材与线材-锤揲](11-板材与线材.md#25-锤揲-把平板打成碗和盆)。铁板加热锤打,冷了变硬就再加热,一圈一圈从外往里打,厚约1.5-2 mm的低碳钢板最合适。

**用途:** 煮饭、烧水

```
⚠️ 不要用镀锌铁皮做锅: 加热会放出锌烟,酸性食物还会溶出锌
新做的铁锅: 抹一层薄植物油,小火烧到冒烟,重复几次形成防锈的油膜
```

### 7.2 铁桶

**锻造:**
1. 铁板围成圆筒
2. 边缘锤接或铆接
3. 焊接底部

- 铁皮桶的接缝和桶底最常用"咬口"(两边折弯互相钩住再压平),再用锡焊封缝防漏,见[焊接与连接-铁皮的咬口](06-焊接与连接.md#24-铁皮的咬口)
- 桶口卷进一根铁丝,桶才不会被提扁
- 提梁用铁条打成,两端弯钩挂在铆在桶上的耳朵里

**用途:** 运水、储物

## 八、质量检验

### 8.1 刀具检验

**1. 锋利度:**
```
测试: 削纸、削木
合格: 轻松削过
不合格: 重新磨刃
```

**2. 韧性:**
```
测试: 砍木头,观察刃口
合格: 不崩口、不卷刃
不合格: 重新回火或重做
```

```
怎样判断问题出在哪里:
- 崩口(刃口掉下小缺口)→ 太硬太脆: 回火温度不够,再回火到更深一级的颜色
- 卷刃(刃口被压歪、翻卷)→ 太软: 没淬硬或回火过度,要重新淬火、回火
- 刀身弯了不回弹 → 刀身没淬火或是熟铁(刀身软是正常的,只要刃口硬)
```

**3. 硬度(钢刀):**
```
测试: 锉刀刻划
合格: 锉刀打滑(硬度够)
不合格: 能刻动(重新淬火)
```

注意: 锉刀测试要在**淬火后、回火前**做。回火后的刃口锉刀能稍微锉动一点是正常的。

### 8.2 工具检验

**锤子:**
- 锤头牢固不脱落
- 击打不崩裂
- 重心合适
- 锤面打在铁上不留凹痕(太软);锤面边缘没有掉渣(太硬)

**钉子:**
- 钉入木头不弯曲
- 钉帽不脱落
- 敲弯后再扳直一次不断(熟铁钉不应该脆)

**斧头、锄头:**
- 斧眼、锄眼处没有裂纹(用放大镜或细看有没有发丝一样的线)
- 砍硬木疤节、锄进带石子的土,刃口不崩

**锻焊件(链条、接长的条料):**
- 焊缝处弯曲不开裂
- 断开处看断面: 灰色、细密 = 好;有黑色夹渣、能看到两层没长在一起 = 没焊好

## 九、常见问题

**常见失败速查:**

| 现象 | 最常见的原因 | 怎么办 |
|------|-------------|--------|
| 锤打时开裂 | 温度太低(冷锻);高碳钢烧过头 | 见Q1 |
| 一锤下去碎成渣 | 料是铸铁、生铁 | 不能锻,改作铸造原料 |
| 表面起皮、层层剥落 | 熟铁里夹渣多,层间没焊牢 | 加热到焊接温度重新锤合、折叠 |
| 工件冒大量火花、表面像泡沫 | 过烧,钢在燃烧 | 切掉烧坏的部分,不能再用来做刃 |
| 截面打成菱形、越打越歪 | 拔长时没有每锤翻转90° | 在砧边从对角方向把它打回方形 |
| 镦粗时打出折叠纹 | 镦弯了没扶直就继续打 | 把折叠处切掉;下次只热一短段 |
| 冲孔冲歪、背面撕裂 | 只从一面冲到底 | 两面对冲,冲杆修正 |
| 淬火后开裂 | 刃口太薄、温度太高、水淬太猛、没正火 | 见Q6 |
| 淬火后不硬 | 料是熟铁或低碳钢;温度不够 | 见Q2 |
| 淬火后弯了 | 斜着入水、左右摆动、两边厚薄不均 | 趁回火时(还热)轻轻扳直;下次直上直下 |
| 锻焊焊不上 | 温度不够、有氧化皮、动作太慢、燃料含硫 | 见[焊接与连接-锻焊](06-焊接与连接.md#三锻焊) |

### Q1: 锻造时金属开裂怎么办?

**原因:**
- 温度过低(冷锻)
- 杂质太多
- 锤击过猛

**解决:**
- 重新加热
- 裂纹处对齐,加热至将熔,锤打焊合
- 使用优质材料

**补充:**
- 熟铁、低碳钢的细小表面裂纹可以这样焊合;**高碳钢(板簧、锉刀)的裂纹焊不好**,裂纹处要切掉或改做不重要的东西
- 裂在边上的,常常是边角先冷下来又挨了重锤: 打薄的边、尖端要先修整,在它还红的时候
- 锉刀、板簧锻打前先退火,并且始终不要超过橙红色

### Q2: 刀具不够硬,容易变钝?

**原因:**
- 材料是熟铁(不是钢)
- 淬火温度不对
- 未淬火

**解决:**
- 使用钢材
- 或对熟铁进行渗碳(变成钢)
- 正确淬火

**怎样知道是不是钢:** 截一小段,加热到樱桃红淬水,用锉刀试: 锉不动是钢,能锉动是熟铁或低碳钢。也可以看砂轮火花(见[废旧金属回收与铝铸造-火花鉴别](05-废旧金属回收与铝铸造.md#22-火花鉴别砂轮或粗锉打磨))。

### Q3: 淬火后工具太脆,一砸就断?

**原因:**
- 淬火过度
- 未回火

**解决:**
- 必须回火!
- 淬火后重新加热,按工具用途回火到金黄、褐、紫或深蓝色(见[1.5](#15-热处理-火色与回火色))
- 空冷

**另外:** 淬火前过热(加热到橙红、黄色才淬)会让钢的晶粒长粗,断面发亮、粗颗粒状,回火也救不回来。这时要先正火2-3次细化晶粒,再在樱桃红重新淬火。

### Q4: 工具表面坑坑洼洼?

**正常!**
- 手工锻造品都这样
- 不影响使用
- 想要光滑: 反复锤打+打磨

**减少麻坑:** 每次出火先刷掉或敲掉松散的氧化皮再锤;砧面和锤面保持干净;最后一火在樱桃红用轻锤修整;刷一点水在砧面上再锤,水汽会把氧化皮炸飞(锤声会突然很响,戴好护目镜)。

### Q5: 一把刀要打多久?

**时间:**
- 新手: 6-10小时
- 熟练: 2-4小时
- 大师级: 1小时内

### Q6: 淬火时"叮"的一声裂了?

**原因:**
- 刃口打得太薄、厚薄差别太大
- 加热温度太高,或局部过热
- 没有正火,锻造应力还在
- 料里原来就有暗裂(冷锻、镦粗折叠留下的)
- 用了冷水或盐水淬高碳钢、复杂形状的工件

**预防:** 按[1.5](#15-热处理-火色与回火色)的顺序做: 正火、刃口留厚、磁铁判断温度、薄刃用油淬、淬完立即回火。

**已经裂了:** 高碳钢工件的淬火裂纹基本无法修复。小裂口可以把裂的部分磨掉,做成小一号的工具;大裂纹只能回炉改做别的。修复的尝试见[金属加工技术-实战案例](04-金属加工技术.md#十实战案例)。

## 十、工具保养

### 10.1 防锈

**方法:**
1. 涂油(动物油、植物油、矿物油)
2. 干燥保存
3. 定期擦拭
4. 包油纸或布

农具每季用完洗净、晾干、上油。发蓝/发黑(表面形成致密的黑色氧化膜)能大大减少生锈,见[金属加工技术-发蓝发黑](04-金属加工技术.md#72-发蓝发黑防锈)

### 10.2 刃口维护

**定期磨刀:**
- 粗磨: 砂轮石、粗磨刀石
- 精磨: 细磨刀石
- 磨刀角度保持一致

**钝了立即磨:**
- 不要等到严重钝化
- 越钝越难磨

**不要把刃口磨热:** 砂轮磨出黄、蓝色,说明那一段回火被破坏、变软了。砂轮要轻压、勤蘸水,只用来修形,开刃用磨石。

**该回炉而不是再磨:** 刃口崩出大缺口(约2 mm以上)、锄刃和镐尖磨短 → 重新锻打,再淬火回火;刃口怎么磨都卷、不锋利 → 硬度没了,重新热处理。

磨刀的手法和磨石保养见[木工与工具维护-磨刀](../07-日常生活技能/09-木工与工具维护.md#磨刀);砂轮的使用和安全见[钳工与机械加工-磨削](09-钳工与机械加工.md#八磨削)。

### 10.3 柄的维护

**木柄:**
- 定期涂油防干裂
- 松动及时楔紧
- 断裂立即更换

不要把松动的工具泡水"胀紧",干后会更松。换柄见[木工与工具维护-换工具柄](../07-日常生活技能/09-木工与工具维护.md#换工具柄斧锤锄),日常保养见[木工与工具维护-工具保养](../07-日常生活技能/09-木工与工具维护.md#工具保养)

## 十一、高级技巧

### 11.1 折叠锻打(百炼钢)

**方法:**
```
1. 铁块拔长
2. 对折
3. 加热锤打焊合
4. 再拔长、对折
5. 实用上重复3-6次就够

结果:
  - 炉渣被挤出,成分变均匀
  - 更致密
  - 强度、韧性提高(主要是因为渣少了)
  - 用不同含碳量的料叠在一起折叠,磨光后会出现花纹
```

每次对折前在贴合面撒焊剂。每次焊合都烧掉一层料和一部分碳,折叠十几次以后料少一大截,高碳钢也变成了低碳钢。

### 11.2 嵌钢刃

**方法:**
- 软铁做身
- 钢做刃
- 锻接结合
- 优点: 省钢,性能好

**三种做法:**

```
贴钢: 钢片贴在熟铁刀身的一面刃口上锻焊(单面贴钢)
      → 最简单;适合菜刀、刨刀、凿子(磨的那一面是钢)

夹钢: 钢片夹在两层熟铁之间(三明治),刃口露出钢
      → 两面都是软铁护着钢,不易断;斧头、菜刀常用

嵌钢: 在熟铁刃口处用热錾劈开一道槽(深约1-2 cm),
      把打成楔形的钢条插进槽里,再焊合
      → 刃口全是钢;斧头、锄头常用
```

```
嵌钢的步骤(斧头或厚刀):
1. 熟铁身先打成形,刃口一边留厚
2. 刃口加热到黄色,用热錾沿中线劈开一道槽
3. 钢条打成和槽相配的楔形,撒硼砂后敲进槽里
4. 加热到焊接温度(对钢偏高,不要在火里久留),
   先轻锤合口,再从槽底往刃口锤实;再加热一两次锤实焊缝
5. 打薄刃口、成形;正火、淬火、回火同全钢工具
检查: 刃口侧面用醋擦一擦,钢和铁颜色深浅不同,
      能看出钢的范围;焊缝中间不应有黑线
```

锻焊的通用要领见[焊接与连接-锻焊](06-焊接与连接.md#三锻焊)。

### 11.3 表面硬化

**渗碳硬化:**
- 已在炼钢章节介绍
- 表面硬,内部韧

没有钢时,把熟铁做的锄刃、犁铧、钉模等埋在木炭粉里密封加热几个到十几个小时,表面变成一层钢,再淬火回火。渗碳层只有约0.3-2 mm,磨掉就软了,要少磨。方法见[金属加工技术-渗碳技术](04-金属加工技术.md#六渗碳技术)和[铁的冶炼-渗碳法](01-铁的冶炼.md#52-方法-渗碳法)

**几项本章没有展开的工具:**

- **剪刀**: 两片刃口按刀的方法做(贴钢或全钢),回火到紫色,用铆钉铆合,两片刃口要略微向内弯,剪合时才能贴紧

## 十三、检查清单

- [ ] 锻炉在通风的半敞开棚下,周围无易燃物,灭火沙和水、带盖的油桶准备好
- [ ] 护目镜、棉麻或皮围裙、包脚的鞋;两人配合时已约定口令
- [ ] 钳口与料吻合;锤头不松;錾子、冲子没有蘑菇头
- [ ] 料已分清(熟铁/低碳钢、中碳钢、高碳钢),铸铁不上砧,镀锌层已去除
- [ ] 熟铁打到深红、高碳钢打到樱桃红就回炉;不发红时不重锤
- [ ] 淬火前正火、刃口留厚;淬完立即回火,回火色按工具用途选择
- [ ] 锉刀试硬度,试砍检查韧性;开刃时不把刃口磨热
- [ ] 收工时炉火熄灭或封好火种,工具上油归位
