# 铜的冶炼

> **新手首选 - 最容易成功的金属冶炼**

## ⚠️ 安全第一

**炼铜比炼铁容易,但危险一样不少:**

- ☠️ **一氧化碳**: 木炭炉在缺氧燃烧时大量产生,无色无味,只在室外开阔处作业
- 💥 **熔融的铜遇水爆炸**: 潮湿的坩埚、模具、工具、地面,接触铜水都会引起蒸汽爆炸
- ☠️ **二氧化硫**: 焙烧辉铜矿、黄铜矿等硫化矿时大量放出,刺激呼吸道,损害庄稼
- ☠️☠️ **砷**: 很多铜矿伴生砷(毒砂、黝铜矿等),加热时冒出白烟、带大蒜味,剧毒且在体内蓄积 —— **发现含砷立即停止,不要使用这种矿石**
- ☠️ **锌烟和铅**: 熔化黄铜冒白色锌烟(金属烟热);旧铜料中可能含铅
- 🔥 **烫伤**: 坩埚在1200°C左右,铜水溅到脚上会造成极严重的烧伤

**能从废墟中回收铜和铜合金,就先回收(见[废旧金属回收与铝铸造](05-废旧金属回收与铝铸造.md)),从矿石冶炼是最后的选择。** 防护装备见[基础冶金知识-必备防护装备](00-基础冶金知识.md#61-必备防护装备)。

---

## ✅ 为什么从铜开始?

**铜是冶金入门的最佳选择:**

| 对比项 | 铜 | 铁 |
|--------|----|----|
| 熔点 | 1085°C | 纯铁1538°C(生铁约1150°C) |
| 炉温要求 | 1200°C | 块炼1100-1300°C,出铁水1300-1400°C |
| 设备难度 | ⭐⭐ 简单 | ⭐⭐⭐⭐ 困难 |
| 成功率(初次) | 60-70% | 20-30% |
| 冶炼时间 | 3-5小时 | 8-24小时 |
| 识别难度 | ⭐ 非常简单(绿色) | ⭐⭐⭐ 较难 |

**优势:**
- ✓ 温度要求低,普通木炭炉+鼓风即可
- ✓ 冶炼时间短
- ✓ 铜矿易识别(颜色鲜艳)
- ✓ 可铸造成各种形状
- ✓ 不易锈蚀
- ✓ 可制成青铜(更硬、更耐用)

**局限(心里要有数):**
- ✗ 铜矿远不如铁矿普遍,多数地方找不到可用的铜矿
- ✗ 纯铜很软,做刃具要靠加锡成青铜或冷锻硬化,仍不如钢
- ✗ 硫化铜矿(最常见的原生铜矿)冶炼又慢又毒,初学者只适合碳酸盐类的氧化矿

## 一、铜矿石识别

### 1.1 孔雀石 Cu₂(OH)₂CO₃ ⭐推荐

**最易识别和冶炼的铜矿!**

**外观:**
- 颜色: **鲜艳的绿色**(孔雀羽毛色)
- 花纹: 同心圆或条带状
- 光泽: 丝绢光泽或玻璃光泽
- 硬度: 3.5-4(小刀可刻动)
- 比重: 约4,比一般岩石(约2.7)明显重

**识别要点:**
```
绿色石头不一定是孔雀石 —— 绿泥石、蛇纹石、绿帘石、绿色的
苔藓和地衣都可能骗人。做三个简单检验:

1. 条痕: 在没上釉的白瓷片(碗底、瓷砖背面)上用力划
   → 孔雀石: 淡绿色条痕
   → 绿泥石、蛇纹石等: 白色或几乎无色
2. 遇酸: 刮下一点粉末,滴几滴醋(越浓越好)或稀盐酸
   → 孔雀石: 冒细小气泡(碳酸盐)
3. 火焰: 把少量粉末撒进火焰
   → 含铜: 火焰带绿色或蓝绿色

三项都符合 → 基本可以确定是含铜的碳酸盐矿,可以冶炼
```

鉴定方法的通用说明见[地质矿物与土壤-鉴定方法](../08-基础科学知识/06-地质矿物与土壤.md#21-鉴定方法)。

**特性:**
- 含铜量: 55-60%
- 易分解(加热到300°C就开始分解释放CO₂)
- **最适合新手!**

**分布:**
- 铜矿床氧化带
- 岩石裂隙
- 常与蓝铜矿共生

```
在野外:
- 孔雀石常是岩石表面、裂缝里的一层绿色薄壳,纯净的大块很少
- 绿色、蓝色锈斑出现的地方,往深处可能有硫化铜矿
- 古代矿坑、带"铜"字的地名、老矿渣堆(黑色玻璃状、很重的渣块)都是线索
```

找矿线索见[地质矿物与土壤-金属矿床的常见线索](../08-基础科学知识/06-地质矿物与土壤.md#32-金属矿床的常见线索)。

### 1.2 蓝铜矿 Cu₃(OH)₂(CO₃)₂

**外观:**
- 颜色: **深蓝色、天蓝色**
- 光泽: 玻璃光泽
- 形态: 晶体或块状
- 条痕: 浅蓝色;遇酸同样冒泡

**特性:**
- 含铜量: 55%
- 易碎
- 常与孔雀石共生(绿蓝相间很漂亮)
- 冶炼方法与孔雀石完全相同,可以混在一起炼

### 1.3 辉铜矿 Cu₂S

**外观:**
- 颜色: 铅灰色,新鲜面带金属光泽
- 特征: 软,小刀可刻出铜的光泽
- 比重: 很重(5.5-5.8)
- 表面常氧化出一层绿色、蓝色的铜锈

**特性:**
- 含铜量: **79%**(最高!)
- 硫化物,需先焙烧去硫
- 加热时放出刺鼻的二氧化硫(像划火柴的呛味)

### 1.4 黄铜矿 CuFeS₂

**外观:**
- 颜色: 黄铜色(似黄金但更硬)
- 光泽: 强金属光泽
- 硬度: 3.5-4
- 表面常有蓝、紫、红色的彩虹状氧化膜

**识别:**
- 比黄金硬(黄金很软)
- 绿黑色条痕

| 矿物 | 颜色 | 小刀刻划 | 条痕 | 其他 |
|------|------|---------|------|------|
| 黄铜矿 | 深黄铜色,常带彩色锈膜 | 能刻动 | 绿黑色 | 敲碎成不规则块 |
| 黄铁矿("愚人金") | 浅黄铜色 | 刻不动(硬度6-6.5) | 黑色或绿黑色 | 常是立方体;用钢敲击冒火星 |
| 自然金 | 金黄色,不锈 | 很软,可压扁 | 金黄色 | 极重,能锤成薄片 |

**特性:**
- 含铜量: 34%
- 含铁,冶炼时铁成渣
- ⚠️ 冶炼要反复焙烧和熔炼多次(见流程C),**不适合初学者**

### 1.5 自然铜 Cu(纯铜)

**极罕见!**
- 纯红色金属
- 可直接使用,无需冶炼
- 如果找到,你太幸运了!

```
自然铜常见于某些玄武岩、铜矿氧化带中,表面多被绿色铜锈覆盖。
- 刮开表面露出红色金属,很软,锤打能延展而不碎
- 可以直接冷锻成小件(锥、针、片),打硬了就退火(见Q5)
- 量大时放进坩埚熔化后浇铸
```

### 1.6 矿石鉴定速查与危险矿石

| 矿石 | 外观 | 条痕 | 遇酸 | 含铜 | 冶炼难度 | 推荐 |
|------|------|------|------|------|---------|------|
| 孔雀石 | 鲜绿 | 淡绿 | 冒泡 | 55-60% | ⭐⭐ | ✓✓ |
| 蓝铜矿 | 深蓝 | 浅蓝 | 冒泡 | 55% | ⭐⭐ | ✓✓ |
| 辉铜矿 | 铅灰、金属光泽 | 暗灰 | 不冒泡 | 79% | ⭐⭐⭐⭐(需焙烧)☠️ | △ |
| 黄铜矿 | 黄铜色 | 绿黑 | 不冒泡 | 34% | ⭐⭐⭐⭐⭐ ☠️ | ✗ 初学者 |
| 自然铜 | 红色金属 | 铜红、有光泽 | 不冒泡 | 约100% | ⭐ | ✓✓✓ |

**这些矿石不要用:**

```
☠️☠️ 含砷矿石(最危险):
  - 毒砂(砷黄铁矿): 银白到钢灰色,金属光泽,敲击时有大蒜味
  - 黝铜矿、砷黝铜矿: 钢灰到铁黑色,常和黄铜矿、方铅矿在一起
  - 雄黄(橙红色)、雌黄(柠檬黄色): 常伴生在矿脉中
  判断: 敲击、摩擦或加热时闻到大蒜味,或冒出白烟 → 含砷
  → 立即停止,远离烟气,不要再用这处矿石

☠️ 方铅矿: 铅灰色、很重、常呈立方体 → 炼出的铜含铅,铅烟有毒
```

铅和砷的危害见[化学-重金属](../08-基础科学知识/03-化学.md#93-重金属),本章[七、安全提示](#七安全提示)。

### 1.7 采集与手选富集

```
1. 采集: 用锤子、钢钎沿绿色矿化的部分敲取,不要挖深坑、不要进入无支护的老矿洞
   (老矿洞会塌方,洞底可能积聚二氧化碳和其他有害气体)
2. 手选: 把矿石敲成核桃大小,在阳光下把绿色、蓝色的部分挑出来,
   白色的石英、灰色的岩石尽量剔除
   → 脉石越少,炉渣越少,铜珠越不容易被渣包住
3. 淘洗: 再粉碎到黄豆大小,在水里摇晃淘洗,轻的泥土和岩屑冲走
4. 晾干: 矿石必须彻底干燥后才能入炉

判断: 手选后的矿石大部分是绿色、蓝色 → 合格
      一半以上是白色、灰色岩石 → 继续挑,否则大概率炼不出成块的铜
```

淘洗方法见[基础冶金知识-矿石富集](00-基础冶金知识.md#54-矿石富集)。

## 二、简易炼铜

### 2.0 三条路线怎么选

| 路线 | 适合矿石 | 设备 | 时间 | 难度 | 危险 |
|------|---------|------|------|------|------|
| A 坩埚熔炼 | 手选过的孔雀石、蓝铜矿 | 小炉 + 坩埚 | 3-5小时 | ⭐⭐ | ☠️(CO、烫伤) |
| B 竖炉还原熔炼 | 量较大的氧化铜矿 | 小竖炉 | 3-5小时(含预热更久) | ⭐⭐⭐ | ☠️ |
| C 焙烧 + 熔炼 | 辉铜矿、黄铜矿等硫化矿 | 焙烧场 + 竖炉 | 数天 | ⭐⭐⭐⭐⭐ | ☠️☠️(二氧化硫,可能含砷) |

```
第一次: 只用路线A,原料1-2 kg手选孔雀石
成功一次后: 再考虑路线B扩大产量
路线C: 只有在确实没有氧化矿和废铜时才考虑
```

### 2.1 设备准备

**简易炼铜炉:**
- 比炼铁炉小、简单得多!
- 内径: 20-30 cm
- 高度: 40-60 cm
- 壁厚: 10-15 cm
- 材料: 普通黏土即可(耐火黏土更好)

```
建炉要点:
1. 选干燥、地势稍高的地方,地面铺一层干沙
2. 黏土掺切碎的干草和粗沙(防裂),一圈圈垒起,或在地上挖坑后用泥抹内壁
3. 在离炉底约5-10 cm处开一个风口,插入陶管或黏土管(风嘴),
   风嘴略向下倾斜,对准坩埚下部
4. 阴干几天,再用小火烘烤半天以上,烘到不再冒水汽
5. 鼓风: 皮囊、风箱或回收的鼓风机;两个风箱轮流鼓,风才不断

判断炉子合格: 鼓风后木炭层亮黄色,丢进一小段铜线能熔化(>1085°C)
```

耐火泥配方见[铁的冶炼-耐火材料配制](01-铁的冶炼.md#22-耐火材料配制);风箱做法见[鼓风设备与锻炉](08-鼓风设备与锻炉.md#三各种风箱的做法);看火色判断温度见[基础冶金知识-判断温度](00-基础冶金知识.md#41-判断温度)。

**坩埚(熔铜容器):**
```
可选方案:
1. 购买石墨坩埚(理想)
2. 耐火黏土自制
3. 厚铁罐(临时)
   ⚠️ 只能短时间应急: 在铜的熔化温度下铁会严重氧化,很快烧穿,
      铁还会混进铜里 → 不推荐,有黏土石墨坩埚或自制黏土坩埚就不要用
```

**自制黏土坩埚:**
1. 耐火黏土捏成碗状
2. 壁厚2-3 cm
3. 容量500 mL-1 L
4. 慢慢烘干、烧硬
5. 可重复使用

```
补充:
- 耐火黏土里掺约一半熟料(粉碎的旧耐火砖、瓷片),烧时不易开裂
- 阴干至少一两周,先小火烘几小时,再逐渐升温烧透
- 熔化干净的铜料,一个好坩埚能用很多次;
  直接炼矿的坩埚会被炉渣侵蚀,往往只能用一到几次
- 每次使用前检查: 有裂纹就不用;用前预热,不要冷坩埚直接进旺火
```

坩埚和坩埚钳的详细做法见[铸造进阶-坩埚](07-铸造进阶.md#22-坩埚)。

### 2.2 炼铜流程A: 直接熔炼法(适合孔雀石、蓝铜矿)

**材料(首次):**
- 孔雀石: 2 kg
- 木炭: 3 kg
- 坩埚: 1个

**步骤:**

**1. 矿石预处理:**
```
粉碎 → 黄豆至花生大小
焙烧(可选):
  - 在空气中加热至红热
  - 持续1-2小时
  - 反应: Cu₂(OH)₂CO₃ → CuO + H₂O + CO₂
  - 目的: 去水、去CO₂,减少杂质
  - 判断: 绿色变成黑色,再加热也不再冒气 → 焙烧完成
```

**2. 装炉:**
```
炉底: 铺木炭(10 cm)
放入坩埚
坩埚周围填满木炭
坩埚内装矿石(装七分满)

⚠️ 坩埚里不能只放矿石: 氧化铜要靠碳和一氧化碳才能还原成铜
   → 矿石和木炭粉按体积约2:1拌匀后装入,上面再盖一层约2 cm厚的木炭粉
   → 只放矿石的话,最后得到的只是熔化的黑色氧化铜和渣,没有铜
```

**3. 点火:**
- 从底部点燃木炭
- 开始鼓风
- 先小风让坩埚慢慢升温(约半小时),再加大风量,避免坩埚急热炸裂

**4. 加热(2-4小时):**
```
温度变化:
约300-400°C → 矿石分解冒气,由绿变黑(氧化铜)
约800°C以上 → 一氧化碳和木炭开始把氧化铜还原成铜(固态的海绵状铜)
1085°C → 铜开始熔化,小铜珠汇集
约1150-1200°C → 完全熔化成铜水,沉到坩埚底部

判断:
- 坩埚发亮(黄色)
- 用铁棍探入,无固体感
- 坩埚口的火焰带绿色,说明里面已有铜在高温下
- 随时补充炉膛里的木炭,坩埚四周的木炭不能烧空

常见错误:
✗ 鼓风断断续续 → 温度忽高忽低,铜珠分散在渣里不汇集
✗ 炉膛木炭不足 → 坩埚上半部温度不够
✗ 中途往坩埚里加湿的矿石或木炭 → 喷溅
```

**5. 扒渣:**
```
铜水表面会浮一层渣(氧化物、杂质)
用长勺或铁棍撇去
撇下的渣放在干沙上,冷后敲碎,里面常夹着小铜珠,挑出来下次再熔
```

**6. 浇铸:**
```
准备模具:
  - 沙模(在沙子上刻槽)
  - 石模(在石板上刻凹槽)
  - 铁模(耐久)

倒铜:
  - 用长柄钳夹坩埚
  - 慢慢倒入模具
  - 注意不要带入渣

⚠️ 模具必须彻底干燥并预热;在干沙地上浇注,不要在水泥地、湿地上浇
⚠️ 浇注时人站在侧面,脸不要正对模具口
```

**7. 冷却:**
- 自然冷却10-20分钟
- 铜锭呈红色金属光泽
- 冷到不发红后再用钳子取出;**不要用手试温度,也不要往热铜锭上泼水取快**

**产量:**
- 2 kg孔雀石 → 理论上最多约1.1 kg铜(孔雀石含铜约57%)
- 手选干净的孔雀石,实际约0.6-0.9 kg;混有较多岩石的矿石少得多

```
失败了怎么判断原因:
坩埚里只有黑色粉末        → 温度不够,或没有拌入木炭
得到一团渣,里面夹很多小铜珠 → 温度不够或渣太黏 → 捣碎渣块,拣出铜珠,再熔一次
坩埚开裂、铜水漏光        → 坩埚没烘干或急热 → 炉底的铜冷后扒出来可回收
铜锭发黑、多孔、很脆      → 吸气或氧化,见常见问题Q2
```

### 2.3 炼铜流程B: 还原熔炼法(适合氧化铜矿)

**原理:** 用木炭还原氧化铜
```
2CuO + C → 2Cu + CO₂↑
```

**与铁冶炼类似,但简单得多:**

1. 矿石和木炭混合(1:1)
2. 装入炉中,分层或混装
3. 鼓风加热
4. 3-5小时后,铜在炉底聚集
5. 打开出口,流出铜水
6. 浇铸成锭

**适用:** 氧化铜矿石(黑色或褐色)

```
操作细节:
1. 先装满木炭预热炉子约1小时,把炉壁烧透
2. 从炉顶分批加料: 一层木炭、一层矿石(或混合料),每次加料不要太多,
   保持炉内木炭始终满着
3. 持续鼓风;炉渣在炉内熔化,可以从侧面的渣口放出
4. 脉石(白色石英)多时,渣会很黏,铜珠出不来:
   可以加少量赤铁矿或褐铁矿粉、少量石灰石作助熔剂,让渣变稀
5. 小炉子往往不出铜水: 停炉冷却后拆开炉底,取出一块"炉底铜饼",
   打碎粘在上面的渣即可
6. 这样炼出的是含渣、含铁的粗铜(黑铜),要再精炼(见2.5)

判断: 放出的渣稀、像熔化的黑色玻璃 → 正常
      渣稠、拉丝不流 → 温度不够或需要助熔剂
```

炉内温度和鼓风的控制见[基础冶金知识-温度控制](00-基础冶金知识.md#四温度控制)。

### 2.4 炼铜流程C: 硫化铜矿处理

**针对:** 辉铜矿、黄铜矿等硫化物

**两步法:**

**第一步: 焙烧(去硫):**
```
1. 矿石粉碎
2. 露天堆放或浅坑
3. 点燃,让其缓慢燃烧
4. 反应:
   2Cu₂S + 3O₂ → 2Cu₂O + 2SO₂↑
   (硫变成刺鼻呛人的SO₂逸出)
5. 持续6-12小时
6. 产物: 氧化铜(黑色)
```

```
细节:
- 矿石要和木柴、木炭交替堆放才能烧起来;硫化矿本身燃烧后也会放热
- 温度保持暗红即可,太热矿石会熔结成块,里面的硫烧不出去
- 中途翻动,让空气进入
- 判断: 翻开后不再冒出刺鼻的烟,矿石变成暗红褐色到黑色的疏松物 → 焙烧完成
- 黄铜矿往往要焙烧两三次

⚠️ 焙烧场: 远离住处和水源,距离居住区500 m以上,
   放在居住区和农田的下风处(二氧化硫会让附近的庄稼叶子发黄枯死)
⚠️ 作业的人站在上风处,不要弯腰凑近闻;烟里如果有大蒜味或白色烟雾 → 含砷,停止
```

**第二步: 还原熔炼:**
- 用流程B处理焙烧后的氧化铜

```
黄铜矿为什么特别难(了解):
- 黄铜矿含铁,一次焙烧很难把硫去干净
- 熔炼后先得到的不是铜,而是"冰铜"(铜和铁的硫化物熔在一起的暗色块)
- 冰铜还要再粉碎、再焙烧、再熔炼,往往反复好几轮,铁逐渐进入渣中,
  最后才得到粗铜
→ 历史上这是需要整个矿场协作、持续数周的工作,小团体不要把它当作首选
```

二氧化硫的防护见本章[七、安全提示](#七安全提示)。

### 2.5 粗铜的精炼

炉B、炉C炼出的粗铜常含铁、硫和氧,发黑、发脆,需要精炼:

```
1. 粗铜敲碎,放进坩埚熔化
2. 熔化后鼓风对着铜水表面吹一段时间(氧化精炼):
   铁、硫等杂质先被氧化,浮到表面成渣 → 反复撇渣
3. 撇净后,铜里会溶有较多的氧(变脆),要脱氧:
   - 表面盖一层木炭粉
   - 用一根新砍的湿木棍(生木)插进铜水搅动 ——
     木头受热放出的气体和碳会夺走铜里的氧("插木还原")
   ⚠️ 插木时铜水会剧烈翻腾冒泡,人站远,用长木棍,动作要慢
4. 取一小勺浇成薄片,冷后弯折:
   能反复弯折、断口细密呈粉红色 → 合格
   一弯就断、断口粗糙发暗 → 继续精炼
5. 合格后浇铸成锭
```

## 三、青铜制作

### 3.1 什么是青铜?

**青铜 = 铜 + 锡合金**

**配比:**
- 标准青铜: 90% Cu + 10% Sn
- 硬青铜(工具): 88% Cu + 12% Sn
- 软青铜(装饰): 92% Cu + 8% Sn

**为什么要青铜?**
- 纯铜太软,做工具易变形
- 加锡后硬度大幅提升
- 熔点降低(更易铸造): 含锡10%的青铜约1000°C熔化
- 流动性好(铸造复杂形状)

**硬度对比:**
| 材料 | 硬度(HB) | 说明 |
|------|----------|------|
| 纯铜 | 40-50 | 软,易弯曲 |
| 青铜(10%锡) | 100-120 | 硬度提升2-3倍! |
| 熟铁 | 80-100 | 青铜更硬! |
| 钢 | 200+ | 钢最硬 |

表中为大致数值;青铜刃口经过冷锻还能明显变硬,但仍远不如淬火钢。

**含锡量和用途:**

| 含锡 | 性质 | 适合 |
|------|------|------|
| 约5-8% | 较软、韧,能冷锻 | 片、线、钉、针 |
| 约10-12% | 硬而不太脆 | 斧、锄、刀等工具 |
| 约15%以上 | 越来越脆,只能铸不能锻 | 不适合工具 |
| 约20%以上 | 很脆,但敲击声音洪亮、能磨亮 | 钟、铃、镜 |

```
简易检验: 浇一条约5 mm厚的小样条,冷后用锤子弯折
- 能弯一些再断,断口细密 → 含锡合适
- 一敲就碎,断口灰白发亮、颗粒粗 → 锡太多,补加铜重熔
- 很容易弯、不硬 → 锡太少
```

### 3.2 锡的获取

**锡矿石: 锡石 SnO₂**

**识别:**
- 颜色: 黑色、褐色、暗红色
- 光泽: 强金属光泽或金刚光泽
- 比重: **非常重**(约6.8-7.0,远重于一般岩石的约2.7)
- 硬度: 6-7(很硬)

**分布:**
- 花岗岩地区
- 砂矿(河流沙中)

**炼锡:**
```
锡石 + 木炭 → 强鼓风加热至约1000°C以上 → 锡被还原并熔化流出

注意: 金属锡的熔点虽然只有232°C,但把锡石还原成锡需要
约1000°C以上的温度和大量木炭(强还原气氛),必须鼓风,普通火堆不行。
炉渣中常夹着锡,需要再炼一次。
```

详细方法见[其他金属-锡](./10-其他金属.md#二锡)。

```
从废墟中找锡(比炼锡容易得多):
- 焊锡丝、焊锡条: 旧的多为锡铅合金(约含铅37%),
  ⚠️ 含铅的锡做成青铜会带铅 → 不要用来做饮食器具
- 标有"无铅"的焊锡: 主要是锡,少量铜、银,可以直接配青铜
- 旧锡器: 常含铅,同样不要用来做饮食器具
- 镀锡铁皮(罐头盒)上的锡层很薄,回收不划算
```

### 3.3 青铜熔炼

**材料:**
- 纯铜: 900 g
- 锡: 100 g
- 木炭: 2 kg

**步骤:**

1. **熔化铜:**
   - 坩埚中放铜
   - 加热至1100°C熔化
   - 铜水表面盖一层木炭粉,减少氧化

2. **加入锡:**
   - 铜熔化后,加入锡块
   - 锡瞬间熔化(熔点太低)
   - 用铁棍搅拌均匀
   - 锡块事先放在炉边烤干、预热;用钳子把锡块压到铜水里面,不要只丢在表面(锡在表面会被大量氧化)
   - 锡在熔炼中会烧损一点,可多加约1-2%(约10-20 g)

3. **扒渣:**
   - 撇去表面浮渣

4. **浇铸:**
   - 倒入模具
   - 青铜流动性极好,能铸造精细形状
   - 加锡后不要久放,尽快浇注;浇注温度约1100-1200°C(亮橙黄色)

5. **冷却:**
   - 自然冷却
   - 青铜略带黄色

**成品特性:**
- 颜色: 新铸、磨亮后为金黄到橙黄色;"青"是长期氧化后表面铜锈的颜色
- 硬度: 比纯铜高得多
- 韧性: 不易折断
- 耐腐蚀: 数千年不锈(青铜文物!)

```
常见问题:
✗ 铸件表面有很多小孔 → 铜水吸气,或模具潮湿 → 盖木炭粉、模具彻底烘干
✗ 成分不均,有的地方发白发脆 → 加锡后没搅匀
✗ 锡大量变成灰白色渣 → 锡丢在表面被氧化,应压入铜水中
```

浇注系统、砂型和铸造缺陷见[铸造进阶-熔炼与浇注](07-铸造进阶.md#六熔炼与浇注)和[铸造进阶-铸造缺陷和原因](07-铸造进阶.md#八铸造缺陷和原因)。

### 3.4 黄铜制作(替代方案)

**黄铜 = 铜 + 锌**
- 配比: 70% Cu + 30% Zn
- 颜色: 金黄色(像金子!)
- 硬度: 中等,不如青铜

**问题:** 锌熔点419°C,但沸点907°C
- 炼铜温度(1100°C)下,锌会汽化!

**古代方法(固态渗锌):**
1. 铜片+炉甘石(ZnCO₃)粉末混合
2. 密封加热至900°C
3. 锌蒸汽渗入铜中
4. 形成黄铜表面

```
补充:
- 坩埚里放铜屑或薄铜片、炉甘石粉和木炭粉,用泥封严坩埚口
- 加热到约900-1000°C,保持数小时;锌被木炭还原成蒸气,渗进铜里
- 最后升温让黄铜熔化,倒出
- 封口漏气时会冒出白色的氧化锌烟 → 人离开,不要吸入
```

锌的来源和难点见[其他金属-锌的现实做法](10-其他金属.md#42-现实做法)。

**现代方法:**
- 回收黄铜制品重熔(简单!)
- 废弃的铜管、阀门、装饰品等

```
重熔黄铜的注意事项:
- 熔化后尽快浇注,温度不要过高,否则冒白烟(锌烟)、锌烧损
- 吸入锌烟几小时后会发烧、寒战、全身酸痛("金属烟热"),
  一般一两天好转;出现呼吸困难、胸痛或症状不退,要就医
- 水龙头、阀门等"易切削黄铜"常含1-3%的铅 → 不要用来做饮食器具
```

## 四、铸造技术

本节只讲炼铜现场最常用的几种简易铸法;砂箱造型、浇注系统、冒口、铸造缺陷等见[铸造进阶](07-铸造进阶.md)。

### 4.1 砂模铸造(最简单)

**材料:**
- 细沙(河沙)
- 黏土粉(少量,5-10%)
- 水(微量,调至湿润)

```
湿度判断: 抓一把捏紧,能成团、手上不沾水,掰开断面整齐 → 合适
          捏不成团 → 太干;手上湿、有水印 → 太湿(浇注时会产生大量蒸汽,可能喷溅)
```

型砂的配制和砂箱造型见[铸造进阶-型砂与造型](07-铸造进阶.md#四型砂与造型)。

**制作模型:**
```
方法1: 直接刻槽
  - 在平整的湿沙上刻出形状
  - 适合: 简单形状(锭、片、环)

方法2: 压模
  - 用木头/石头雕刻原型
  - 压入沙中留下印模
  - 取出原型
  - 倒入金属

方法3: 双面模
  - 制作上下两半沙模
  - 留出浇注口
  - 合模后浇注
  - 适合: 复杂形状(斧头、刀)
```

**浇注步骤:**
1. 沙模压实(防塌陷)
2. 挖出浇注通道
3. 预热模具(避免冷裂)
4. 快速倒入铜水
5. 等待冷却5-10分钟
6. 扒开沙子取出铸件
7. 去除毛刺、打磨

```
补充:
- 第3步"预热"对砂模来说主要是晾干、用炭火烤干型腔表面
- 用细铁丝在型腔周围扎几个通气孔,让蒸汽和空气排出
- 一次浇满,中途不要停;浇到浇口冒出铜水为止
```

浇口和冒口的设计见[铸造进阶-浇注系统](07-铸造进阶.md#五浇注系统)。

### 4.2 失蜡法(精密铸造)

**适用:** 复杂形状、艺术品

**流程:**
```
1. 雕刻蜡模(蜂蜡或动物脂肪)
2. 包裹黏土形成外壳
3. 留出浇注口和排气孔
4. 烘烤:
   - 蜡熔化流出
   - 黏土烧硬成陶
5. 倒入铜水填充空腔
6. 冷却后打碎外壳
7. 得到精细铸件
```

```
各步要点:
1. 蜡料: 蜂蜡加少量松香更硬、不易变形;纯动物油脂太软,只适合很简单的形状
   蜡模壁厚不要小于约3 mm,太薄铜水流不满
2. 浇口、排气孔也用蜡条做好,粘在蜡模上,一起包进泥里
3. 包泥分两层:
   - 第一层: 很细的泥浆(细泥加水调成稀糊),刷或浸几遍,复制出细节
   - 第二层: 粗泥掺切碎的干草或粗沙,包成约1-2 cm厚的外壳
4. 阴干几天,彻底干透
5. 浇口朝下慢慢加热,让蜡流出(可以收集再用),
   再升温到暗红烧几个小时,把残蜡烧尽、泥壳烧成陶
6. 趁外壳还热时浇注(热壳让铜水流得更远),外壳埋在干沙里防止胀裂

判断外壳合格: 烧后敲击声音清脆,摇动时里面没有残渣声
```

**优点:** 可铸造极复杂的形状
**缺点:** 模具只能用一次

### 4.3 石模铸造(耐用)

**方法:**
- 在软石(皂石、砂岩)上雕刻模具
- 可重复使用数十次
- 适合: 箭头、刀片、钉子等小件

```
做法:
1. 选两块质地细密、没有裂纹的软石,磨平接合面
2. 在一块或两块上刻出型腔和浇口,刻好后合起来,
   在侧面刻几道对位线,或做两个榫和孔,保证每次对准
3. 浇注前: 型腔熏一层烟灰(脱模),整体用炭火烘热,把石头里的水分赶出去
4. 合模用铁丝或绳捆紧,浇口朝上立在干沙里浇注

⚠️ 不要用河里的卵石或刚从水里捞出的石头: 内部含水,遇高温会炸裂
⚠️ 砂岩受热容易开裂剥落,皂石最好;也可以用烧过的陶范代替
```

## 五、实用铜制品

### 5.1 工具类

**1. 铜斧、铜锄(青铜):**
- 虽不如铁,但胜过石器
- 不易锈蚀
- 适合农耕

**2. 铜刀(青铜):**
- 砍伐、切割
- 需要经常磨砺(不如钢)

**3. 铜箭头(青铜):**
- 锋利、穿透力强
- 铸造简单

**4. 铜针、铜钩:**
- 缝纫、捕鱼
- 不生锈

```
让青铜工具更耐用:
- 铸出毛坯后,用锤子在冷态下反复锤打刃口(冷锻硬化),再磨出刃
- 刃口崩了、卷了,可以重新锤打修整,用旧了还能回炉重铸 —— 铜不会浪费
- 有了钢铁之后,铜更适合做不生锈、要导电或要导热的东西
```

工具的锻打和刃口修整见[简易工具锻造](03-简易工具锻造.md)。

### 5.2 容器类

**1. 铜锅、铜盆:**
- 导热快
- 耐用
- 注意: 不能装强酸性食物(产生铜绿有毒)
- 传统铜锅内壁镀一层锡,隔开食物和铜;锡层磨穿露出红色铜后要重新镀锡

**2. 铜桶、铜杯:**
- 储水
- 天然抑菌(铜离子有杀菌作用)
- ⚠️ 这种抑菌作用慢而不可靠,不能代替煮沸或其他饮水消毒

**其他重要用途:**
- 铜线: 导电性仅次于银,发电机、电动机、电报都离不开(废墟里的铜线尽量保留成线,见[废旧金属回收与铝铸造](05-废旧金属回收与铝铸造.md))
- 铜板、铜管: 蒸馏器、热交换器、屋面(铜板和拉线见[板材与线材](11-板材与线材.md))

### 5.3 装饰和货币

**铜镜:**
- 抛光后可当镜子

**铜钱:**
- 可作为货币(古代钱币多为铜)

**铜铃、铜饰:**
- 装饰品

## 六、常见问题

### Q1: 找不到锡,能做青铜吗?

**A: 有替代方案**

**方案1: 铜-砷合金**
- 用含砷的矿石代替锡
- 硬度也会提升
- ⚠️ 砷有剧毒!需极度小心

```
☠️☠️ 本书不推荐这个方案:
- 历史上最早的"青铜"很多是砷铜,但炼砷铜时,砷以白烟(三氧化二砷,
  即砒霜)的形式大量挥发,冶炼的人长期吸入,损害神经、皮肤,致癌
- 砷在体内蓄积,中毒往往在多年后才显现,无法逆转
- 没有可靠的方法在土法条件下控制含砷量和防护烟气
→ 不要刻意使用含砷矿石;优先方案2、方案3
```

**方案2: 用纯铜**
- 虽然软,但也能用
- 冷锻(反复锤打)可增加硬度

**方案3: 回收废铜**
- 电线(纯铜)
- 黄铜制品(含锌)
- 青铜制品(古董可能含锡)

### Q2: 炼出的铜很脆,是什么原因?

**A: 可能含氧过高**

**解决:**
- 熔化时在表面撒一层木炭粉(隔绝空气)
- 搅拌时用木棍(木炭化后脱氧)

| 原因 | 表现 | 解决 |
|------|------|------|
| 含氧过高 | 断口暗红、粗糙 | 盖木炭粉,插木还原(见[粗铜的精炼](#25-粗铜的精炼)) |
| 含硫(焙烧不彻底) | 铸件多气孔,有硫的气味 | 矿石焙烧彻底;粗铜氧化精炼 |
| 含铁、铅等杂质 | 发硬发脆,颜色不正 | 原料手选;氧化精炼撇渣 |
| 青铜含锡太多 | 灰白色、一敲就碎 | 补加铜重熔(见[3.1](#31-什么是青铜)) |
| 冷锻过度 | 锤打后出现裂纹 | 锤一阵就退火一次(见Q5) |

### Q3: 铜器有毒吗?

**A: 纯铜无毒,但要注意:**

✓ 安全使用:
- 铜锅煮饭、烧水
- 铜杯饮水

✗ 避免:
- 长期装酸性食物(醋、果汁)→ 产生铜绿(有毒)
- 如有绿锈,彻底清洗后再用
- 饭菜不要在铜器里过夜存放

### Q4: 一次能炼多少铜?

**A:**
- 小坩埚(500 mL): 0.5-1 kg
- 中坩埚(2 L): 2-4 kg
- 大坩埚(5 L): 5-10 kg

```
说明:
- 上面是用矿石在坩埚里冶炼时,每炉大致能得到的铜
- 如果熔化的是废铜料,同样的坩埚能装得多: 铜水密度约8.9 g/mL,
  500 mL坩埚装七分满就有约3 kg铜水 → 坩埚和钳子要能承受这个重量
- 大坩埚装满铜水很重,必须两人用浇注叉抬,事先空手演练
```

### Q5: 铜可以锻造吗?

**A: 可以,但要注意:**

**冷锻:**
- 纯铜可冷锻(常温锤打)
- 会越打越硬(加工硬化)
- 但也越来越脆

**热锻:**
- 加热至500-600°C(暗红)
- 锤打成型
- 退火(加热后慢冷)恢复韧性

```
补充:
- 纯铜主要靠"冷锻 + 退火"反复交替来成型: 锤一阵,摸到变硬、开始出现
  细小裂纹之前,就加热到暗红(约500-600°C)退火,再接着锤
- 铜和钢不同: 退火后放在空气中冷或直接浸水冷都可以,淬水不会让铜变硬,
  还能让表面的氧化皮脱落
- 大件纯铜也可在深红到樱桃红(约700-900°C)热锻
- 青铜(约10%锡)以铸造为主,只适合冷锻刃口;含锡越高越不能锻
```

钢的退火、淬火见[金属加工技术](04-金属加工技术.md);拉铜丝、压铜板见[板材与线材](11-板材与线材.md)。

## 七、安全提示

### 铜毒(相对较轻,但仍需注意):

**急性中毒:**
- 症状: 恶心、呕吐、腹痛
- 原因: 误食大量铜盐
- 处理: **不要催吐**,不要自行灌牛奶等"解毒"偏方;漱口后立即拨打120或送医,带上误食物的样品

```
- 最常见的是误服硫酸铜(胆矾,蓝色晶体,用于配波尔多液等农药),
  毒性远比铜器上的铜绿大 → 装在有标签的容器里,放在儿童拿不到的地方
- 呕吐物呈蓝绿色、腹痛剧烈、尿少、皮肤眼睛发黄 → 病情严重,尽快送医
```

中毒的通用处理见[中毒-中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则)。

**预防:**
- 作业后洗手
- 不用破损、氧化的铜器装食物
- 定期清洗铜器

### 硫化铜矿焙烧:

**产生SO₂(有毒!):**
- 刺鼻、呛人的刺激性气体(像划火柴的气味),不是臭鸡蛋味
- 必须上风向
- 距离居住区500 m以上

```
- 吸入后: 咳嗽、喉咙和胸口发紧、喘息、眼睛刺痛流泪
- 哮喘病人、儿童、老人、孕妇尤其危险,让他们远离焙烧场下风方向
- 处理: 立即离开烟区到上风处的新鲜空气中;眼睛用大量清水冲洗;
  咳嗽、胸闷不缓解,或出现呼吸困难 → 立即送医
- 湿布捂口鼻只能稍微减轻刺激,不能当作防护 → 靠距离和风向
- 焙烧场下风处的庄稼、蔬菜会受损;不要在水源上游焙烧
```

有毒气体的一般知识见[化学-有毒气体](../08-基础科学知识/03-化学.md#92-有毒气体)。

### 砷: 最需要警惕的伴生毒物

```
☠️☠️ 很多硫化铜矿含砷;焙烧和熔炼时,砷以白烟的形式放出,
    在烟道、炉口等较冷的地方凝结成白色粉末(三氧化二砷,即砒霜)

识别信号:
- 敲击、加热矿石时有大蒜味
- 焙烧或熔炼时冒白烟,炉口附近积了一层白霜状粉末

一旦发现:
1. 停止作业,所有人撤到上风处
2. 不要清扫或触摸白色粉末,不要让儿童和牲畜靠近,不要让雨水把它冲进水源
3. 这批矿石、炉渣和产出的铜都不要用于饮食器具
4. 此后放弃这处矿石

慢性中毒的表现(长期接触): 手脚麻木刺痛、皮肤变黑或出现斑点、
手掌脚掌皮肤增厚、乏力 → 停止接触并就医
```

### 其他危险

```
☠️ 一氧化碳: 头痛、头晕、恶心是早期信号 → 立即离开炉边到新鲜空气中;
   多人作业互相照看,炉子附近不要睡觉
💥 熔融金属遇水: 坩埚、模具、工具、地面必须干燥;雨天不作业
☠️ 锌烟、铅烟: 熔化黄铜、旧焊锡时冒白烟 → 不要凑近;孕妇和儿童远离
🔥 烫伤: 立即用流动冷水冲15-20分钟;大面积、深度烧伤送医
```

一氧化碳和烫伤的处理见[基础冶金知识-中毒预防](00-基础冶金知识.md#63-中毒预防)和[基础冶金知识-烧伤处理](00-基础冶金知识.md#64-烧伤处理)。

## 八、检查清单

### 首次炼铜准备:
- [ ] 识别并采集孔雀石或蓝铜矿(最简单)
- [ ] 条痕、遇酸检验确认是铜矿,没有大蒜味(不含砷)
- [ ] 粉碎矿石
- [ ] 手选去掉大部分白色、灰色岩石,晾干
- [ ] 制作或准备坩埚
- [ ] 坩埚检查无裂纹,已烧透
- [ ] 建好小型炉子并烘干
- [ ] 准备木炭5 kg
- [ ] 制作沙模
- [ ] 防护装备齐全
- [ ] 地面铺干沙,10 m内无可燃物,备好灭火沙
- [ ] 至少两人在场

### 冶炼中:
- [ ] 持续鼓风
- [ ] 温度达到橙黄色(约1200°C)
- [ ] 铜完全熔化
- [ ] 扒去浮渣
- [ ] 随时补充木炭,坩埚四周不能烧空
- [ ] 有人头痛、头晕 → 立即离开炉边

### 浇铸前:
- [ ] 模具预热
- [ ] 模具干燥
- [ ] 安全距离
- [ ] 坩埚钳空手试夹、试倒过一遍
- [ ] 多余铜水的去处(干沙坑或干燥铁模)已准备好

### 冶炼后:
- [ ] 炉渣冷后敲碎,拣回铜珠
- [ ] 熄灭炉火,确认无余烬
- [ ] 洗手、洗脸后再饮食
- [ ] 记录: 矿石用量、木炭用量、时间、产铜量,下次对照改进
