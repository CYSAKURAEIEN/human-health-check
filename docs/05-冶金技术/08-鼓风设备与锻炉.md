# 鼓风设备与锻炉

> **火的温度不是由燃料决定的,而是由风决定的。木炭明火只有七八百摄氏度,鼓风之后就能熔铜炼铁——风箱是冶金的心脏**

## ⚠️ 安全第一

- ☠️ **一氧化碳**: 炉子在棚子、屋里工作时,一氧化碳会积聚,使人头痛、昏迷甚至死亡 → 必须通风,最好在半敞开的棚下
- 🔥 鼓风会让火星和炭粒飞出很远,周围清除易燃物,准备灭火的沙和水
- 🔥 鼓风管(风嘴)靠近火的一端温度极高,铁管会很快烧坏;风管附近不要放手
- ⚙️ 水力、机械带动的鼓风设备有转动部件,会卷入衣服和手

一氧化碳中毒见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

## 一、为什么鼓风这么重要

```
燃料燃烧的快慢取决于能得到多少氧气
- 木炭在空气中自然燃烧: 约700-800°C,不够熔铜
- 持续鼓风: 约1200-1400°C,能炼铜、炼铁
- 强鼓风 + 保温好的炉子: 约1300-1400°C以上,能炼出铁水

炉温上不去,十有八九是风不够:
- 风量太小
- 风不连续(一停一停)
- 风没有吹到燃料最多、最集中的地方
- 风管漏气
```

炉温的判断见[基础冶金知识-温度控制](00-基础冶金知识.md#四温度控制)。

## 二、鼓风设备比较

| 设备 | 难度 | 风量 | 是否连续 | 说明 |
|------|------|------|---------|------|
| 吹管(人用嘴吹) | ⭐ | 很小 | 否 | 只够熔化极少量的金属、焊接小件 |
| 皮囊 | ⭐⭐ | 中 | 两个轮流时接近连续 | 最古老的鼓风方法 |
| 盆式风箱 | ⭐⭐ | 中 | 两个轮流时接近连续 | 陶盆或木盆蒙皮,做法简单 |
| 木扇 | ⭐⭐ | 中到大 | 两个轮流 | 我国传统,木板开合鼓风 |
| 双作用活塞风箱 | ⭐⭐⭐ | 大 | **连续** | 我国传统风箱,推拉都出风,最实用 |
| 水力鼓风(水排) | ⭐⭐⭐⭐ | 大 | 连续 | 不用人力,可以长时间工作 |
| 离心鼓风机 | ⭐(回收)| 大 | 连续 | 回收的电动鼓风机、汽车暖风电机 |

## 三、各种风箱的做法

### 3.1 皮囊

```
材料: 一整张羊皮(或其他兽皮),尽量完整
1. 剥皮时从颈部和四肢少开口,把皮剥成一个袋子
2. 一条腿的开口处绑上一根管子(木管、竹管、陶管),作为出风口
3. 颈部(或背部)的开口两侧各钉一根木条,手握木条可以张开或合拢
4. 其他开口全部扎紧缝牢

使用:
- 张开口子向上提 → 皮囊吸满空气
- 合拢口子(手捏紧木条)向下压 → 空气从管子挤出
- 两个皮囊轮流操作,风几乎不断
```

### 3.2 盆式风箱

```
1. 两个陶盆或木盆(直径约30-40 cm),盆底侧面开孔接出风管
2. 盆口蒙上软皮或厚布,四周扎紧,不漏气
3. 蒙皮中央系一根竖直的木棍(或绳子)作拉手
4. 蒙皮上开一个小孔作进气口(拉起时用手指按住,或做一个简单的皮瓣)

使用: 提起拉手吸气,压下出风;两盆轮流,双手各控制一个
```

### 3.3 双作用活塞风箱(最推荐)

我国传统的木风箱,推和拉都能出风,风连续均匀,一个人就能长时间操作。

```
构造(侧视示意):

  进气阀           进气阀
   ↓                 ↓
 ┌─┬─────────────────┬─┐
 │ │    活 塞  ═══════════ 拉杆 ←→ 操作者
 └─┴─────────────────┴─┘
   └──→ 侧面的风道 ──┘
             ↓
        出气阀 → 风嘴

1. 箱体: 长方形木箱,长约60-100 cm,内截面约25 × 30 cm,内壁刨平刨光
2. 活塞: 一块和箱体内截面一样大的木板,四周钉上一圈软皮、毛毡或鸡毛(羽毛向外),
   既能滑动又不漏气
3. 拉杆: 穿过箱体一端的孔,连在活塞中心
4. 进气阀: 箱体两端的端板上各开一个方孔,孔的内侧钉一块能向里摆动的皮瓣或木板
   → 活塞离开这一端时,板被吸开进气;活塞压向这一端时,板被压紧关闭
5. 风道: 沿箱体侧面(或底部)做一条通道,两端分别通到箱体两端的内部
6. 出气阀: 风道中间通向风嘴的出口处,装一块能左右摆动的小板(或两个单向皮瓣),
   哪一侧来风,它就被推向另一侧,挡住回流

工作:
- 推拉杆: 活塞前方的空气被压缩,经风道从风嘴吹出;活塞后方吸入新鲜空气
- 拉回来: 反过来,另一侧的空气吹出
→ 每个行程都出风,风是连续的

要点:
✓ 活塞四周的密封最关键: 太紧推不动,太松漏风
✓ 箱体和风道不能漏气: 接缝处用胶或泥封严
✓ 拉杆处的孔加一个皮套减少漏气
```

### 3.4 水力鼓风(水排)

```
东汉时期(公元1世纪)我国就用水力推动风箱冶铁,称为"水排"

原理:
水轮(立式或卧式)转动 → 曲柄连杆把旋转运动变成往复运动 → 推拉风箱
→ 只要有流水,可以昼夜不停地鼓风,节省大量人力

要点:
- 需要有一定落差和流量的水流(功率估算见物理-水力)
- 风箱和水轮之间的连杆要结实,速度要合适
- 炉子就要建在水边,注意洪水季节
```

水力功率的估算见[物理-水力: 水车和水磨](../08-基础科学知识/02-物理.md#33-水力-水车和水磨)。

### 3.5 回收的电动鼓风机

```
- 汽车暖风(空调)鼓风电机: 12 V,可以用蓄电池或小型太阳能系统带动
- 各种离心风机、抽油烟机的风机、吹风机(只用冷风挡)
- 在进风口处装一块可以调节开口大小的挡板来控制风量

⚠️ 塑料外壳的风机离炉子要远,用金属管把风引到风嘴
⚠️ 电动风机突然停电时,炉子里的热气可能沿风管倒流 → 风管和风嘴不要用塑料
```

## 四、风嘴和风管

```
风嘴(风口): 风进入炉子的那一段,直接面对高温
- 用耐火黏土烧制的陶管最好(耐高温、不烧坏)
- 铁管会很快被烧穿,只能用在离火较远的地方
- 内径约2-3 cm(小锻炉)到5 cm以上(大炉)

位置:
- 炉子: 风口在炉子下部,稍微向下倾斜,对准炉膛中心
- 锻炉: 风口在火床的侧面或底部,对准放工件的位置下方

防倒流:
传统的皮囊、盆式风箱,风管口和风嘴之间留一点间隙(不接死),
  吸气时不会把炉里的热气吸回风箱里
```

## 五、锻炉

### 5.1 锻炉的结构

```
                烟罩(可选)
                   │
       ┌───────────────────────┐
       │   火床(砖石平台)        │
       │      ┌─────┐           │← 高度约70-80 cm
       │      │火盆 │← 风口      │  (站着干活舒适的高度)
       │      └─────┘           │
       └───────────────────────┘

火盆: 火床中央的凹坑,直径约20-30 cm,深约15 cm
风口: 侧吹(从侧面进风,最简单)或底吹(从火盆底部进风)
底吹的火盆底部要有可以打开的灰渣口,方便清理炉渣
旁边放: 淬火水槽、燃料堆、工具架
```

简易锻炉的尺寸见[简易工具锻造-必备工具](03-简易工具锻造.md#13-必备工具)。

### 5.2 燃料

```
木炭:
✓ 干净,几乎不含硫,锻焊效果好
✗ 烧得快,体积大,需要的量多

煤:
✓ 热值高,火力集中
✗ 含硫会让铁变脆,锻焊困难;烧结成的炉渣要经常清理
→ 最好先烧成焦炭再用(焦炭也是熔化铸铁所需的燃料)

燃料块的大小: 核桃大小,均匀
```

### 5.3 火的管理

```
✓ 火要深: 工件埋在火的中间,上下都有燃料
  - 风口附近是氧化区(氧气多),工件放在这里表面会严重起氧化皮
  - 往上一点是还原区(温度最高、氧气少),是加热工件的最佳位置
✓ 保持火床干净: 定期清除炉渣(炉渣会堵住风口)
✓ 不用时减少鼓风,用湿的燃料在外圈围住火,保存火种
✓ 加热时经常翻转工件,受热均匀
✓ 不要让工件在火里"过烧"(冒出大量火花说明钢在燃烧)
```

### 5.4 砧子

```
✓ 理想的砧子: 大块钢砧,重量是最重的锤子的几十倍
✓ 一段钢轨: 竖着立起来(截面朝上)用,比平放的反弹好得多
✓ 大的钢块、大型机械上拆下的厚钢件
✓ 坚硬的大石块(初期)
安装: 牢牢固定在粗木墩或砖台上,砧面高度约在操作者垂手时的指关节高度
```

砧子和锤、钳等工具见[简易工具锻造](03-简易工具锻造.md);废墟中的砧子材料见[废旧金属回收与铝铸造-钢铁](05-废旧金属回收与铝铸造.md#31-钢铁)。

## 六、炉子的保温和节能

```
✓ 炉壁加厚、炉衬用耐火材料,外层再包一层保温材料(草泥、灰土)
✓ 炉口加盖,减少热量散失
✓ 利用排出的热烟气预热鼓进去的空气(让风管经过炉子外壁或烟道)
  → 热风能明显提高炉温、节省燃料(历史上热风炉是炼铁的重大改进)
✓ 一炉多用: 同一炉火先熔化、再锻打、再回火
✓ 下雨天停止作业,潮湿的炉衬和燃料都会让温度上不去
```

## 七、检查清单

- [ ] 炉子在通风良好的地方,周围无易燃物
- [ ] 风箱、风管不漏气,阀门开合灵活
- [ ] 风嘴完好,没有烧穿
- [ ] 燃料干燥,大小均匀
- [ ] 淬火水槽、灭火沙准备好
- [ ] 两人配合时,约定好鼓风和取料的口令
