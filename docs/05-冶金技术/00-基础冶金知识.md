# 基础冶金知识

> **冶金入门 - 从零开始掌握金属冶炼的基础**

## ⚠️ 安全第一

**冶金是高危作业!在开始之前必须了解:**

- 🔥 工作温度可达1300°C以上
- ☠️ 一氧化碳中毒风险(无色无味剧毒)
- 💥 熔融金属遇水会爆炸性飞溅
- 🌡️ 高温引起的严重烧伤
- 🏭 重金属污染
- ☠️ 金属烟尘: 加热镀锌件、熔炼黄铜冒出的白烟会引起"金属烟热";焙烧硫化矿放出刺鼻的二氧化硫,有的矿石还会放出含砷的白烟
- ☠️ **铅、汞不要碰**: 不熔铅、不用汞提金,孕妇和儿童远离一切冶炼现场

**必须在室外、通风良好、远离居住区的地方进行!**

```
本章的定位:
- 讲所有冶炼共用的基础: 原理、炉子、木炭、看火判断温度、认矿、安全
- 具体冶炼铁、铜的步骤在后面的章节
- 文明崩溃后的最初几十年,废墟里的钢铁、铜、铝远比土法冶炼来得快、质量好,
  应当先回收、改锻、重熔;从矿石冶炼是回收材料用完以后的长远之计
```

废旧金属的回收见[废旧金属回收与铝铸造](05-废旧金属回收与铝铸造.md);鼓风设备的详细做法见[鼓风设备与锻炉](08-鼓风设备与锻炉.md)。

## 一、冶金基本原理

### 1.1 什么是冶金?

**简单说:** 从矿石中提取金属的过程。

**化学原理:**
```
金属氧化物 + 碳(还原剂) → 金属 + 二氧化碳
例: Fe₂O₃ + 3C → 2Fe + 3CO↑
```

```
炉子里实际发生的事:
1. 鼓进去的空气和木炭燃烧: C + O₂ → CO₂,放出大量热
2. CO₂ 向上穿过灼热的木炭层,被还原成一氧化碳: CO₂ + C → 2CO
3. 一氧化碳上升,从矿石里夺走氧: Fe₂O₃ + 3CO → 2Fe + 3CO₂
4. 矿石里的泥沙等杂质和助熔剂结合,熔成炉渣流走,金属留下

→ 真正的还原剂主要是一氧化碳,炉内必须是"炭多氧少"的状态
→ 这也是为什么炉口、出渣口周围一氧化碳浓度很高
```

**两类矿石的处理不同:**
- 氧化矿(磁铁矿、赤铁矿、褐铁矿、孔雀石、锡石): 直接和木炭一起冶炼
- 硫化矿(黄铜矿、辉铜矿、方铅矿、黄铁矿): 要先在空气中焙烧,把硫烧掉变成氧化物,再冶炼(见[5.4 矿石富集](#54-矿石富集))

化学反应的基础知识见[化学](../08-基础科学知识/03-化学.md)。

### 1.2 关键要素

| 要素 | 作用 | 说明 |
|------|------|------|
| **矿石** | 原料 | 含金属的天然矿物 |
| **燃料** | 提供热量 | 木炭、焦炭 |
| **还原剂** | 夺取氧气 | 通常是碳(木炭) |
| **助熔剂** | 降低熔点 | 石灰石、石英 |
| **鼓风** | 提高温度 | 增加氧气供应 |

**助熔剂怎样选:**
- 矿石里泥沙(石英)多 → 加石灰石或贝壳,两者结合成容易熔化的炉渣
- 矿石里石灰质多 → 加石英砂
- 块炼铁时矿石本身的铁和石英会结合成炉渣(会损失一部分铁),新手可以先不加助熔剂,看炉渣流动情况再调整
- 用量凭经验摸索,每次记录配比和出渣情况

**炉渣的作用:** 把杂质带走,同时盖在金属上面,防止金属重新被氧化。炉渣流动性好(像稀糖浆,能从出渣口流出)说明温度和配比合适;炉渣黏稠、堵在炉里,说明温度不够或助熔剂不对。

### 1.3 温度需求

| 金属 | 熔点 | 所需炉温 | 难度 |
|------|------|----------|------|
| 铜 | 1085°C | 1200°C | ⭐⭐ 简单 |
| 金 | 1064°C | 1200°C | ⭐⭐ 简单 |
| 银 | 962°C | 1100°C | ⭐⭐ 简单 |
| 铁(块炼法) | 不熔化 | 1100-1300°C | ⭐⭐⭐ 较难 |
| 铁(液态生铁) | 约1150°C(含碳4%) | 1300-1400°C | ⭐⭐⭐⭐ 困难 |
| 锡(熔化金属锡) | 232°C | 300°C | ⭐ 非常简单 |
| 锡(从锡石冶炼) | 232°C | 约1000°C以上 | ⭐⭐⭐ 需要鼓风和强还原 |

**关键:**
- 木炭明火: ~700-800°C (不够)
- 木炭+鼓风: 1200-1400°C (可炼铜)
- 木炭+强鼓风+耐火材料: 1300-1400°C (可炼出液态生铁)

> 纯铁熔点1538°C,但炼铁不需要达到这个温度:块炼法让铁在固态下被还原成海绵铁;生铁因含碳约4%,熔点降到1150°C左右。

**"所需炉温"比熔点高的原因:** 金属要整体化透、炉渣要能流动、浇注时还会降温,所以炉温一般要比熔点高出100-200°C。铅、锌、铝等其他金属的熔点和浇注温度见[铸造进阶-常用金属的熔点和浇注温度](07-铸造进阶.md#11-常用金属的熔点和浇注温度)。

## 二、冶炼炉的建造

### 2.1 简易黏土炉(初级)

**适用于:** 铜、锡、铅等低熔点金属

> ⚠️ 铅有毒,本书不建议自行冶炼或熔化铅,原因见[其他金属-铅](10-其他金属.md#三铅)。

#### 材料清单:
- 黏土: 50-100 kg
- 沙子: 20 kg(混入黏土增强)
- 稻草/干草: 1-2 kg(防开裂)
- 石块: 若干(砌炉底)

**哪种土合用:** 湿时黏手、能搓成筷子粗细的泥条弯成圈不断的土就可以;沙子太多搓不成条,太黏的纯黏土干燥时容易裂,要多掺沙。怎样找黏土见[陶瓷玻璃与造纸-什么样的土能做陶](../07-日常生活技能/11-陶瓷玻璃与造纸.md#什么样的土能做陶)。

#### 建造步骤:

**第1步: 选址**
- 平整地面,清除可燃物
- 上风向10 m内无建筑
- 靠近水源(安全)

```
选址补充:
✓ 地势稍高、排水好的砂土地;不在低洼积水处、不在水泥地上
  (地下潮气和水泥里的水受热会让炉底、地面爆裂)
✓ 搭一个高一些、四面通风的棚子挡雨,棚顶离炉口至少2 m,不能用茅草
✓ 水源是用来灭火和冲洗烧伤的: 水桶放在几米外固定位置,
  绝不放在炉前、出渣口、浇注区附近
✓ 远离干草堆、柴垛、林地边缘,常年主风向的下风方向不要有住房
```

**第2步: 打地基**
```
[俯视图]
○ = 通风口
═ = 石块

   正面
   ║
 ╔═══╗
 ║ ○ ║← 通风口(直径10 cm)
 ╚═══╝
 ┌───┐
 │地基│← 石块垫高30 cm
 └───┘
```

- 用石块垫高30-50 cm(防潮)
- 留一个通风口

**第3步: 配制耐火黏土**
```
配方:
- 黏土: 70%
- 细沙: 25%
- 切碎的稻草: 5%
- 水: 适量,调至可塑状
```

**搅拌:** 反复踩踏、揉捏30分钟

```
怎样判断泥调好了:
✓ 抓一把捏成团,不粘手,掰开断面均匀、没有干粉疙瘩和气泡
✓ 搓成拇指粗的泥条弯成U形,外侧只有细纹,不断开
✗ 一捏就流 → 水太多,摊开晾一会儿
✗ 弯折就断 → 太干或沙太多,加水或加黏土
✓ 调好后盖上湿布或塑料布放一夜,第二天再揉一遍更均匀
```

**第4步: 砌炉墙**
- 墙厚: 10-15 cm
- 内径: 30-40 cm
- 高度: 50-60 cm
- 炉底: 倾斜便于倒渣

```
砌法:
1. 在地基上用泥条一圈圈往上盘筑,每圈约5 cm高,
   上下两圈之间用手指抹压结合,不能只是叠在上面
2. 每砌高约15 cm停一停,让下部稍微变硬再继续,否则会被压塌
3. 也可以用一个木桶、编筐或捆紧的草把作内模,砌好后抽出或烧掉
4. 风口: 在离炉底约10-15 cm处留孔,略向下倾斜对准炉膛中心
5. 出渣口/出铜口: 在炉底最低处留一个小孔,冶炼时用泥塞堵住
6. 内壁抹光,外壁可以留得粗糙一些
```

**第5步: 晾干(关键!)**
- 阴干3-5天(避免阳光直晒开裂)
- 小火慢慢烘烤2-3天
- 第一天: 小火30分钟,停火,重复3次
- 第二天: 小火2小时
- 第三天: 中火4小时

```
为什么要这么慢: 炉壁里的水分急速变成蒸汽会把炉壁胀裂,甚至崩出碎块
怎样判断干透了:
✓ 颜色由深变浅,整体均匀,没有深色湿斑
✓ 手摸不发凉,敲击声音发脆而不发闷
✗ 烘烤时炉壁冒出大量水汽、外壁出现湿印 → 还没干,继续小火
下雨天、空气潮湿时要多晾几天
```

**第6步: 高温定型**
- 大火烧烤6-8小时
- 黏土会变硬、略微收缩
- 出现裂缝用黏土糊补

```
补裂缝: 细裂缝(约2 mm以下)可以不管;宽裂缝在炉子冷却后,把缝刮宽、刷湿,
  用同样配比的泥压实填满,再小火烘干
每次冶炼前都要检查: 炉壁变薄、出现贯通裂缝时要修补或重砌
```

#### 鼓风装置

**简易风箱(必需!):**

```
[侧视图]

活动板 ↓
┌─────┐
│     │  皮革/布料
│  □  │  ←空气
└──║──┘
   ║← 竹筒/木管
   ↓
  炉子
```

**制作:**
1. 木框: 40×30×15 cm
2. 顶部蒙皮革或厚帆布
3. 底部开口连接竹筒
4. 竹筒插入炉子通风口
5. 手动或脚踩压缩空气

```
⚠️ 注意:
- 竹筒、木管不能直接伸进炉里,会被烧坏: 炉壁里要嵌一段耐火黏土烧成的陶管(风嘴),
  竹筒只接到风嘴外端
- 风箱要有进气活门(一块皮革盖住进气孔,压下时盖住、抬起时打开),
  否则一压一松会把炉里的热气吸回风箱
- 单个风箱送风是一阵一阵的,炉温会忽高忽低;两个风箱轮流压最简单
```

**高级版:**
- 双腔风箱(一压一松都送风)
- 连续鼓风,效率高

皮囊、盆式风箱、双作用活塞风箱、水力鼓风的做法和风嘴尺寸见[鼓风设备与锻炉](08-鼓风设备与锻炉.md#三各种风箱的做法)。

### 2.2 高温炉(炼铁用)

**材料:**
- 耐火砖或耐火黏土(普通黏土不够)
- 耐火黏土配方:
  - 铝矾土(或高岭土): 60%
  - 石英砂: 30%
  - 黏土: 10%

**结构改进:**
- 更厚的炉壁(20-30 cm)
- 更高的炉身(100-150 cm)
- 预热进风(利用废气加热鼓风)
- 多层装料

**炉型:**
```
[剖面图]
   ╔═══╗← 投料口
   ║   ║
   ║   ║← 炉腰(最宽处)
   ║   ║
   ╚═══╝
    ║║← 炉腹(收窄)
    ║║
   ╔═╗
   ║○║← 风口
   ╚═╝
   ╔═╗← 出铁口
```

```
为什么要更高、更厚:
- 炉身越高,上升的热气和一氧化碳在穿过料柱时把热量和还原能力
  交给矿石的时间越长 → 省炭、还原更充分
- 炉壁越厚,散热越少;普通黏土在1300°C左右会软化、和炉渣粘在一起烧穿
- 新手不必一开始就建大炉: 先用高约1 m的小竖炉练习,
  摸清鼓风、装料、出渣的节奏
```

竖炉的具体尺寸、两种耐火泥配方和建炉日程见[铁的冶炼-简易竖炉](01-铁的冶炼.md#21-简易竖炉推荐)和[铁的冶炼-耐火材料配制](01-铁的冶炼.md#22-耐火材料配制);耐火砖和坩埚的烧制见[陶瓷玻璃与造纸-坩埚和耐火砖](../07-日常生活技能/11-陶瓷玻璃与造纸.md#坩埚和耐火砖)。

## 三、燃料制作

### 3.1 木炭的重要性

**为什么必须用木炭?**
- ✗ 木柴: 含水分、杂质,温度低(仅700°C)
- ✓ 木炭: 主要成分是碳(约80-90%),鼓风时燃烧温度高(1200-1400°C)
- ✓ 木炭无烟,一氧化碳浓度更稳定

**还有两点:**
- 木炭几乎不含硫、磷,炼出的铁不容易发脆;煤含硫,直接用会让铁变脆(见[Q4](#q4-可以用煤代替木炭吗))
- 木炭多孔、块头稳定,在炉里不会像木柴一样冒焰、塌陷,料柱能保持透气

### 3.2 木炭制作(闷烧法)

**原理:** 隔绝空气加热木材,挥发物逸出,剩余碳。

```
⚠️ 烧炭的安全:
- 炭窑冒出的烟含大量一氧化碳和焦油,站在上风方向,不要把头凑到烟口
- 绝不钻进还没完全冷透的窑坑里
- 刚出窑的炭可能有暗火,会复燃甚至自燃
- 不在室内、帐篷里用烧炭的方法取暖
```

**木材准备:**
- 硬木(栎、栗、榆、槐等)出的炭硬实耐烧,适合冶炼;松、杨、柳的炭较轻较软,可用于锻炉和日常
- 木材要晾干: 砍下后劈开、架空晾放几个月以上,湿柴出炭少、耗时长
- 去掉腐朽部分,粗细尽量一致;太粗的劈开

怎样晾柴、一片林地能产多少柴见[薪柴与林地管理-柴要干](../04-动植物培育/09-薪柴与林地管理.md#柴要干)。

#### 土窑法(大量生产)

**步骤:**

**1. 挖坑:**
- 直径2-3 m
- 深度1-1.5 m
- 坑底中心挖烟道

**2. 装柴:**
- 木材竖立摆放(直径5-15 cm)
- 中心留空隙作烟囱
- 装满后顶部覆盖小树枝

```
装柴要点:
- 尽量装紧,粗的放中间、细的放外圈(中间温度高,外圈烧得慢)
- 柴与柴之间的缝用短柴头塞满,空隙大的地方会烧成灰
- 中心的空隙里放干草、细柴作引火
```

**3. 封土:**
- 覆盖10-20 cm厚的湿土
- 留顶部和底部通气孔
- 不能完全封死

```
先在柴堆上铺一层干草或树叶,再盖土,土不会漏进柴缝;
封土要拍实,没有裂缝。闷烧时土层开裂冒烟,要立即用湿土补上 ——
漏进空气的地方会把炭烧成灰
```

**4. 点火:**
- 从顶部点燃
- 火势稳定后逐渐缩小顶部通气孔

**5. 闷烧:**
- 持续3-7天
- 观察烟色:
  - 白烟(水蒸气) → 初期
  - 黄烟(木焦油) → 中期
  - 青烟(接近完成)
  - 透明热气(完成)

```
闷烧期间:
- 要有人日夜轮班看守,主要是巡查封土有没有塌陷、开裂冒火
- 白烟又浓又湿(用冷的东西挡一下会结水珠)说明还在烘干木材,不要急
- 烟变黄、有刺鼻的焦油味,是木材正在炭化
- 某一侧烟色先变青,说明那一侧快烧好了,把那一侧的底部通气孔先封上
- 一下子冒出火苗 → 有地方漏气,马上封堵
```

**6. 熄火:**
- 完全封死所有通气孔
- 等待冷却2-3天
- 扒开取炭

```
取炭:
- 从一侧开一个口,用手背在口外感觉温度,仍然烫手就重新封上再等
- 取出的炭摊开放在空地上,旁边备好水和沙,观察至少24小时没有复燃,
  再装袋、入库
- 烧得半生的"炭头"(断面发褐、还有木纹)挑出来,下一窑再烧
```

**产量:**
- 1 t木材 → 200-300 kg木炭
- 优质硬木(如栎木)出炭率更高

#### 简易铁桶法(小量生产)

**步骤:**
1. 准备大铁桶,盖上开小孔(排气)
2. 装满木材块
3. 倒扣在火堆上加热
4. 小孔冒烟时点燃(燃烧可燃气体)
5. 烟变清后撤火,等待冷却
6. 取出木炭

**时间:** 4-8小时

```
要点:
- 木块切成长短一致、拳头大小,装紧
- 第4步小孔冒出的烟能被点着、形成小火苗,说明木材正在炭化,
  这些可燃气体顺便给桶加热,能省柴
- 火苗变小、熄灭,不再冒烟 → 炭化结束
- 撤火后用土把桶边缘埋住隔绝空气,完全冷却前不要打开,否则炭会烧起来
- 不要用装过油漆、农药、化学品的桶;旧桶先在室外烧一遍去掉残留
```

**常见问题:**

| 现象 | 原因 | 办法 |
|------|------|------|
| 出炭很少,大部分成了灰 | 封土漏气或通气孔开太大 | 封土拍实,随时补裂缝 |
| 炭里夹着很多没烧透的木头 | 木材太湿、太粗,或闷烧时间不够 | 晾干、劈细,延长闷烧 |
| 炭发软、一捏就碎 | 软木,或闷烧温度太高、太快 | 选硬木,通气孔开小些 |
| 出窑后炭堆冒烟起火 | 没冷透就取出 | 多等几天,出窑后摊开观察 |

### 3.3 木炭质量检验

**优质木炭:**
- ✓ 黑色有金属光泽
- ✓ 敲击声音清脆
- ✓ 断面纹路清晰
- ✓ 燃烧时无烟或少烟

**劣质木炭:**
- ✗ 褐色或未完全炭化
- ✗ 多灰分
- ✗ 易碎

```
储存:
- 放在干燥、通风、有顶棚的地方,离住房和柴堆远一些,防雨防潮
  (受潮的炭在炉里会降温、爆裂)
- 大堆的炭有自燃的可能,不要堆得太高太实,定期检查有没有发热
- 冶炼前筛一遍: 碎末和粉会堵住炉内通道,筛下的碎炭用于锻炉或日常
```

## 四、温度控制

### 4.1 判断温度

**无温度计情况下:**

| 温度 | 金属颜色 | 说明 |
|------|----------|------|
| 500°C | 暗红色 | 刚可见红 |
| 700°C | 深红色 | - |
| 约800°C | 樱桃红 | 淬火温度(780-850°C) |
| 约900°C | 鲜红(亮樱桃红) | 锻造温度 |
| 1100°C | 橙红色 | 铜熔化、块炼铁 |
| 1300°C | 黄色 | 生铁熔化出铁水 |
| 1500°C | 亮黄色 | 接近纯铁熔点(土法很难达到) |
| 1700°C | 白色 | 极高温 |

**辅助方法:**
- 投入小块铜: 融化表示>1085°C
- 投入铁钉: 融化表示>1538°C

```
看火色的要领:
- 光线影响很大: 阳光下颜色看起来偏暗(会把温度估低,容易烧过头),
  阴天、傍晚或在棚子阴影里看最准;每次尽量在同样的光线下看
- 看的是炉内炭火和金属本身的颜色,不是炉口窜出的火焰
- 不同人眼睛有差别: 同一个人长期判断,并和有经验的人对照
- 能用小块纯金属核对时(锡232°C、铝约660°C、铜1085°C),
  就用它校准自己的眼睛
- 保护眼睛: 从风口或观察孔看炉内时,时间要短;长时间看1300°C以上的炉火
  要隔一片深色玻璃(电焊面罩的镜片最好),不要贴近风口(会喷火)
```

```
不用眼睛的辅助判断:
- 炉渣: 能顺畅流出 → 温度够;又黏又稠、堵在出渣口 → 温度偏低
- 炉口: 火焰从暗红、冒烟变成稳定的蓝色、黄白色短火苗,说明炉内燃烧旺
- 风口: 风口内能看到的炭火颜色最亮,也最能代表炉内最高温度
```

更多金属熔点固定点和自制温度计见[计量基准的重建-高温的固定点](../08-基础科学知识/09-计量基准的重建.md#52-高温的固定点-金属的熔点);锻造和热处理时看钢的颜色见[金属加工技术-温度判断](04-金属加工技术.md#13-温度判断无温度计)。

### 4.2 提高温度的方法

**1. 加强鼓风**
- 持续、稳定的鼓风
- 双风箱轮流工作

```
- 鼓风要均匀,不能时快时慢;累了换人,不要停
- 风量不是越大越好: 风太大,木炭烧得太快,炉内变成"氧多炭少",
  已经还原出的金属会重新被氧化,一氧化碳也不够 → 炼铁时尤其要注意
- 风口被炉渣堵住时,用一根铁棒从风口外捅通
```

**2. 优化燃料**
- 使用优质硬木炭
- 木炭块大小适中(核桃大小)

```
太大的炭块之间空隙大,热量散失;太碎的炭和粉末会堵塞通道、风吹不进去;
炭一定要干燥
```

**3. 炉体保温**
- 加厚炉壁
- 炉顶部分封闭(减少热损失)

```
- 炉子外面可以再糊一层掺稻草的泥,或在外侧堆土、垒石,减少散热
- 雨天、大风天炉温很难上去,而且有危险,不要开炉
```

**4. 预热进料**
- 利用废气预热空气

```
最简单的做法是让风管从炉身外侧绕过一段,进风先被炉壁的余热加热;
炉身高的炉子,矿石和木炭从上往下走时已被上升的热气预热,本身就省炭
```

**5. 燃料与矿石的比例**
- 炼铁: 木炭:矿石 ≈ 1:1(重量)
- 炼铜: 木炭:矿石 ≈ 1:2

```
这是每一批装料时的比例,不是总消耗: 预热炉子、维持炉温还要另外烧掉不少木炭,
整个过程的木炭消耗见Q3
```

**温度上不去时的排查:**

| 现象 | 可能原因 | 办法 |
|------|---------|------|
| 炉温一直只有暗红到樱桃红 | 风量不够,或风箱漏气 | 检查风箱皮革、接口,换人或加一个风箱 |
| 炉壁外面摸起来很烫、冒水汽 | 炉壁太薄或没干透 | 加厚保温层,下次彻底烘干 |
| 风口附近火很旺,上面很暗 | 炭块太碎,料柱不透气 | 筛掉碎炭,用核桃大小的炭 |
| 温度忽高忽低 | 单个风箱间断送风 | 两个风箱轮流,或改用双作用风箱 |
| 风口发黑、风吹不进 | 炉渣或熔化的金属堵住风口 | 用铁棒捅通;风口位置偏低时下次抬高 |

炉温和风量的关系、各种风箱的风量比较见[鼓风设备与锻炉](08-鼓风设备与锻炉.md)。

## 五、矿石识别与采集

> 矿物鉴定的一般方法(条痕、硬度、比重)和到哪里找矿的线索,见[地质、矿物与土壤](../08-基础科学知识/06-地质矿物与土壤.md#32-金属矿床的常见线索)。这里只讲冶炼用的矿石。

### 5.1 铁矿石

#### 磁铁矿 Fe₃O₄
- **外观:** 黑色、有金属光泽
- **特征:** 有磁性(关键!)
- **含铁:** 60-70%
- **识别:** 用磁铁吸附
- **分布:** 山区、河床

#### 赤铁矿 Fe₂O₃
- **外观:** 红褐色
- **特征:** 粉末状时呈红色
- **含铁:** 50-60%
- **识别:** 在白瓷板上划红色条痕
- **分布:** 沉积岩地区

#### 褐铁矿 FeO(OH)
- **外观:** 黄褐色至褐色
- **特征:** 土状、块状
- **含铁:** 40-50%
- **识别:** 较轻、易碎
- **分布:** 风化带、沼泽

```
判断一块铁矿值不值得采:
- 掂一掂: 同样大小,铁矿明显比普通石头沉
- 河床里的黑色沉沙常有磁铁矿砂,用磁铁在沙里拖一拖就能收集
- 表面一层锈色,里面是普通石头的,含铁不高,不值得背回去
- 黄铁矿(金黄色、立方体)虽然含铁,但含硫太多,炼出的铁很脆,不作首选
```

简易鉴定流程和首次采集量见[铁的冶炼-简易鉴定流程](01-铁的冶炼.md#12-简易鉴定流程)。

### 5.2 铜矿石

#### 孔雀石 Cu₂(OH)₂CO₃
- **外观:** 鲜艳的绿色
- **特征:** 条带状花纹
- **含铜:** 55-60%
- **识别:** 颜色特殊,易辨认
- **最易冶炼的铜矿!**

#### 辉铜矿 Cu₂S
- **外观:** 铅灰色、金属光泽
- **特征:** 较重、柔软
- **含铜:** 79%
- **识别:** 刀刻有铜的光泽

#### 黄铜矿 CuFeS₂
- **外观:** 黄铜色
- **特征:** 金属光泽
- **含铜:** 34%
- **识别:** 颜色似黄金但更硬

```
- 岩石表面的绿色、蓝色锈斑(孔雀石、蓝铜矿)往往是下面有铜矿的信号
- 辉铜矿、黄铜矿是硫化矿,冶炼前必须先焙烧(见5.4)
- 有的铜矿伴生砷: 焙烧时冒白烟、闻到大蒜一样的气味 → 有砷,立即远离下风方向,
  这种矿石不要用
```

蓝铜矿、自然铜和各种铜矿的冶炼方法见[铜的冶炼](02-铜的冶炼.md)。

### 5.3 其他有用矿石

#### 锡石 SnO₂
- **外观:** 黑色或棕色,光泽强
- **用途:** 制作青铜(铜+锡)
- **熔点低:** 232°C,但从锡石还原出锡需要约1000°C以上和鼓风(见[其他金属-锡](./10-其他金属.md#二锡))

#### 方铅矿 PbS
- **外观:** 铅灰色、金属光泽强
- **特征:** 很重、立方体晶体
- **用途:** 铅制品、合金
- **警告:** 铅有毒!

```
☠️ 方铅矿: 认识它是为了避开它
- 焙烧和冶炼方铅矿会放出铅烟和二氧化硫,铅中毒是慢性的,
  早期没有明显感觉,却会损害儿童智力、造成贫血和神经损伤
- 本书不建议冶炼铅;确实需要铅时,从旧蓄电池极板、铅管等回收,并做好防护
- 不要用铅做饮食器具、水管,也不要用含铅的釉
```

铅、锌、金、银的情况见[其他金属](10-其他金属.md);汞的危险见[其他金属-汞](10-其他金属.md#七汞-只需知道它的危险)。

### 5.4 矿石富集

**原矿石通常含杂质多,需要富集:**

#### 重力选矿(淘洗法)
```
1. 粉碎矿石(拳头大小)
2. 放入水槽中
3. 摇晃淘洗
4. 轻的杂质浮起或流走
5. 重的金属矿石沉底
```

**适用:** 密度大的矿石(铁、铜、锡)

```
做法补充:
- 淘洗前要把拳头大小的块再敲碎到黄豆、花生大小,太大的块淘不出差别
- 用一个浅木盘或斜放的木槽,上端慢慢加水,一边晃一边让水把轻的泥沙冲下去
- 沉在底部、颜色深、掂着沉的部分留下;冲下去的部分可以再淘一遍
- 淘洗后的矿要晒干或烘干再进炉,湿矿进炉会降温、甚至引起炸裂
```

#### 磁选(仅限磁铁矿)
```
1. 粉碎矿石
2. 用强磁铁吸附
3. 分离出磁性的磁铁矿
```

```
磁铁外面包一层塑料袋或布,吸满后把袋子从磁铁上翻下来,矿粉就掉下来了;
废旧扬声器、电机里能拆出强磁铁
```

#### 焙烧(去硫)
```
某些硫化矿(如黄铁矿FeS₂):
1. 露天堆放
2. 点火焙烧
3. 硫变成SO₂逸出
4. 残留物为氧化铁(可冶炼)
```

```
⚠️ 焙烧的安全:
- 二氧化硫刺激眼睛和呼吸道,浓了会让人窒息,还会熏死下风方向的庄稼和树
- 焙烧场选在空旷处,离住房、田地、水源远一些;人始终站在上风方向
- 闻到大蒜味、看到大量白烟(可能含砷) → 停止,远离
- 焙烧要彻底: 把矿石翻动几次,烧到不再冒刺鼻的烟、颜色变成红褐色为止;
  没烧透的硫留在金属里,铁会发脆,铜会冒泡
- 褐铁矿、含水多的矿石焙烧也有好处: 去掉水分,矿石变疏松,更容易还原
```

### 5.5 矿石粉碎

**为什么要粉碎?**
- 增大反应面积
- 提高冶炼效率
- 便于与燃料混合

**方法:**
1. **石臼捣碎** - 人力
2. **石锤敲碎** - 人力
3. **石磨碾碎** - 畜力
4. **水力碾磨** - 利用水流

**粒度:**
- 炼铁: 花生到核桃大小
- 炼铜: 黄豆到花生大小
- 越小越好,但粉末太细会影响透气

```
- 先焙烧再粉碎更省力: 焙烧过的矿石变脆,容易敲碎
- 敲矿石时戴护目镜(碎石片会飞进眼睛),戴口罩或湿布捂住口鼻,减少吸入粉尘
- 敲出的细粉不要扔: 可以和少量黏土加水捏成鸡蛋大小的团,晒干后进炉
```

### 5.6 采集安全

```
⚠️ 采矿的风险往往比冶炼更隐蔽:
- 不要进入废弃矿洞、坑道: 可能塌方、积水,底部常积聚缺氧或有毒的气体,
  进去的人倒下、下去救的人接着倒下,是常见的群死事故
- 在露头、陡坡上采矿,注意头顶落石和脚下松动的石块;
  雨后、解冻期不要在陡坡下作业
- 挖坑采矿时坑壁要放坡,不要掏挖成"倒悬"的坑壁;
  深度超过人的胸口时,坑壁要支撑或改为分级台阶
- 有人在坑下作业时,坑边要有人看守,不在坑边堆放石块
- 戴手套、护目镜;敲击时周围的人退后
```

地质灾害的征兆见[地质灾害](../02-灾难应对/01-地质灾害.md)。

## 六、安全防护

### 6.1 必备防护装备

| 装备 | 用途 | 简易替代 |
|------|------|----------|
| **厚皮手套** | 防高温 | 多层干燥厚棉布包手(不能用湿布,湿布遇热产生蒸汽,反而烫伤) |
| **护目镜** | 防飞溅 | 透明塑料片+绳子(只能挡碎屑,遇高温会软化,浇注时尽量用玻璃镜片) |
| **口罩** | 防粉尘 | 多层湿布 |
| **厚围裙** | 防烧伤 | 湿皮革 |
| **长柄钳** | 夹持高温物 | 木棍+铁丝 |
| **长柄勺** | 舀熔融金属 | 耐火黏土做碗+长木柄 |
| **高帮皮鞋** | 防金属液溅到脚上 | 厚皮革裹脚,裤腿盖住鞋面(不要把裤腿塞进鞋里) |
| **深色观察镜** | 看炉火时保护眼睛 | 电焊面罩镜片,或熏黑的玻璃片 |

```
- 湿布口罩只能挡粉尘,挡不住一氧化碳,也挡不住金属烟
- 衣物要用棉、毛、皮革: 化纤遇高温会熔化,粘在皮肤上造成更深的烧伤
- 长柄工具的柄至少1 m,夹持和浇注时身体侧对坩埚,不要正对
```

### 6.2 作业安全规则

#### 环境安全
- [ ] 10 m内无可燃物
- [ ] 上风向无人居住
- [ ] 准备灭火沙和水
- [ ] 夜间作业有照明和守夜人
- [ ] 浇注区地面铺一层干沙,不在水泥地、潮湿地面上浇注
- [ ] 儿童、牲畜在安全距离以外,用绳子或篱笆隔开

#### 操作安全
- [ ] 所有工具完全干燥(湿气会爆炸!)
- [ ] 绝不在下雨天作业
- [ ] 熔融金属倒入预热的模具
- [ ] 远离风口观察
- [ ] 加入炉内、坩埚内的料(废料、矿石、助熔剂)都要预先烘干
- [ ] 密封的容器、管子、气瓶绝不放进火里(会爆炸)

#### 个人安全
- [ ] 穿长袖长裤,扎紧袖口
- [ ] 头发扎起或戴帽
- [ ] 不穿易燃材料(化纤)
- [ ] 保持清醒,禁止饮酒
- [ ] 多喝水、轮流休息,炉边高温作业容易中暑
- [ ] 现场有急救用品(干净的布、水桶)和熟悉急救的人

中暑的处理见[急性症状](../01-日常疾病和伤害/05-急性症状.md)。

### 6.3 中毒预防

**一氧化碳中毒(头号杀手!)**

**来源:** 不完全燃烧产生CO

**症状:**
- 轻度: 头痛、头晕、恶心
- 中度: 意识模糊、乏力
- 重度: 昏迷、死亡

```
⚠️ 高度怀疑一氧化碳中毒的线索:
- 在炉边、炭窑边干活的几个人同时头痛、头晕、恶心
- 离开炉子一会儿症状减轻,回来又加重
- 把头痛当作"累了""热的",继续干活,是最危险的
```

**预防:**
- ✓ 必须在室外或开阔处
- ✓ 多人作业,互相监督
- ✓ 感觉不适立即离开
- ✓ 炉子附近不要躺卧

```
预防补充:
- 一氧化碳在炉口、出渣口和下风方向最浓,不要在那里停留、休息
- 冶炼棚四面通风,不要为挡风把棚子围死
- 不要把余火未尽的炉子、炭盆、刚出窑的炭搬进屋里
- 有条件就在作业区放一个一氧化碳报警器
```

**急救:**
1. 立即转移到新鲜空气处
2. 平躺、保暖
3. 清醒者安静休息,不要走动,也不要让他继续回去干活
4. 昏迷者侧卧,防窒息
5. 呼吸停止立即CPR

```
- 救人时先保护自己: 屏住气快进快出;湿毛巾挡不住一氧化碳
- 能联系上时立即拨打120,说明"一氧化碳中毒",便于送往有高压氧的医院
- 清醒了也要尽快就医: 一氧化碳中毒可能在看似恢复后几天到一两个月,
  出现记忆力下降、反应迟钝、走路不稳(迟发性脑病)
- 孕妇中毒即使症状轻也要就医
```

完整的识别和救助步骤见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒);心肺复苏见[基础急救知识-心肺复苏](../01-日常疾病和伤害/00-基础急救知识.md#心肺复苏cpr)。

**重金属中毒**

**高危金属:** 铅、汞、砷

**预防:**
- 作业后彻底洗手
- 不在作业区饮食
- 怀孕妇女和儿童禁止接触

```
- 铅: 不熔铅、不冶炼方铅矿;铅中毒早期只有乏力、腹痛、便秘、贫血,容易被忽视
- 汞: 不用汞提金,不加热任何含汞的东西;汞蒸气无色无味,
  加热时吸入会严重损伤肺、肾和神经
- 砷: 焙烧时冒出有大蒜味的白烟要立即远离;含砷的矿石不用
- 作业服和平时的衣服分开存放、分开洗,不要穿着作业服回家抱孩子
- 炉渣、焙烧残渣不要倒进水源、田里,集中埋在远离水源的地方
```

**金属烟热**

```
加热镀锌铁皮、熔炼黄铜时冒出白色的锌烟,吸入后几小时
出现发冷、发热、全身酸痛、咳嗽,像得了感冒
- 处理: 离开现场,休息、多喝水,一般一两天内好转
- 出现呼吸困难、高热不退、症状加重 → 立即就医
- 预防: 镀锌件加热前先去掉镀层,在上风方向操作,黄铜不要过热
```

汞和铅的详细说明见[其他金属-汞](10-其他金属.md#七汞-只需知道它的危险)和[其他金属-铅](10-其他金属.md#三铅)。

### 6.4 烧伤处理

**轻度烧伤(发红、起泡):**
1. 立即冷水冲洗15-20分钟
2. 不要弄破水泡
3. 涂烧伤膏或芦荟汁
4. 无菌纱布包扎

```
- "冲"最重要,冲足时间,不痛了也要冲够;烧伤后3小时内开始冲仍然有效
- 戒指、手镯等在肿起来之前取下
- 不涂酱油、牙膏、草木灰、油脂
- 水疱直径超过约2 cm、在手脚关节面部、出现红肿化脓发热 → 就医
```

**重度烧伤(皮肤焦黑):**
1. 用大量清水冲洗
2. 剪开衣物(不要撕拉)
3. 清洁敷料覆盖
4. 立即就医
5. 少量多次喝口服补液盐或淡盐水(神志清醒、能吞咽、不呕吐的成人,在等待救援时间较长时),不要大量喝白开水

```
- 立即拨打120;冲水的同时让旁人呼救,不要为冲满时间推迟送医
- 大面积烧伤只冲烧伤部位,其他部位盖上保暖;
  出现发抖、嘴唇发紫就停止冲水(防失温)
- 粘在皮肤上的衣物不要撕,剪开周围留下粘连部分
- 不涂任何药膏,用干净湿润的布或保鲜膜轻轻覆盖,不要缠紧
```

**熔融金属飞溅:**
- 绝不能立即用水!
- 先扑灭衣物上的火
- 用干净布料包裹
- 就医处理

```
理解"不能用水":
- 指的是绝不往熔融金属、坩埚、炉子里或金属液洒落的地方泼水 ——
  水碰到金属液瞬间变成蒸汽,会把金属液炸得四处飞溅,伤到更多人
- 人身上: 先离开金属液洒落的地方,衣服着火"停、躺、滚"扑灭
  (或用厚毯子、沙土盖灭);溅到身上的小金属滴几秒内就会凝固
- 离开危险区后,对烧伤部位按上面的方法用流动的凉水冲洗15-20分钟
- 已经凝固、粘在皮肤上的金属不要硬抠,冷却后用干净布覆盖,留给医生处理
- 金属溅入眼睛: 不要揉,立即就医
```

烧伤的深度判断、面积估算和"冲、脱、泡、盖、送"的完整步骤见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤)。

## 七、常见问题

### Q1: 完全新手要多久才能成功冶炼?

**A:**
- 铜: 1-2周准备,成功率60%
- 铁: 1-2个月准备,初次成功率20-30%
- 建议从铜开始,积累经验

```
推荐的练习顺序:
1. 烧一窑木炭,做一个风箱
2. 用小坩埚熔化回收的铝、锡,练习看火色、浇注(温度低、风险小)
3. 熔化废铜、用孔雀石炼铜
4. 建竖炉,块炼铁
每一次都记录: 木炭用量、鼓风时间、炉温颜色、出渣情况、结果
```

### Q2: 一次能产多少金属?

**A:**
- 小型炉(1次): 0.5-2 kg
- 中型炉(1次): 2-10 kg
- 大型炉(1次): 10-50 kg

### Q3: 木炭消耗量有多大?

**A:**
- 炼1 kg铁(块炼法): 通常需要几 kg 到十几 kg 木炭,新手的损耗更大
- 炼1 kg铜(氧化铜矿): 需要几 kg 木炭
- 制1 kg木炭: 需要约3-5 kg木材(土窑得率低时更多)

**结论:** 需要大量木材!可持续性是关键。林地需要多大、怎样轮伐见[薪柴与林地管理](../04-动植物培育/09-薪柴与林地管理.md)。

### Q4: 可以用煤代替木炭吗?

**A:**
- 可以,但煤含硫,产品质量差
- 需要先炼成焦炭(类似木炭制法)
- 优点是热值更高

```
- 生煤直接进炉: 受热会软化粘结、冒浓烟,把料柱堵死,硫进入铁里让铁发脆
- 炼焦和烧炭一样要隔绝空气闷烧,但冒出的煤焦油烟和一氧化碳更多,
  要远离住处,人在上风方向
- 焦炭适合化铁、铸造和锻炉;从矿石炼铁,木炭仍然更容易得到好铁
```

煤到哪里找见[地质、矿物与土壤-建筑和日用材料](../08-基础科学知识/06-地质矿物与土壤.md#31-建筑和日用材料)。

### Q5: 找不到矿石怎么办?

**A:**
- 回收废弃金属制品
- 旧汽车、机械(大量钢铁)
- 废弃电器(铜线)
- 旧建筑钢筋
- 重新熔化、锻造即可

```
⚠️ 回收件的危险: 密封容器、气瓶、减震器、灭火器受热会爆炸;
镀锌件放出锌烟;旧刹车片可能含石棉;蓄电池含铅和酸
```

识别金属、拆解和熔铸的方法见[废旧金属回收与铝铸造](05-废旧金属回收与铝铸造.md)。

### Q6: 一个人能完成冶炼吗?

**A:**
- 理论可以,但强度很大
- 建议至少2-3人:
  - 1人鼓风
  - 1人加料
  - 1人监控和安全
- 冶炼是社区性工作

```
一次炼铁要连续鼓风好几个小时,再加上烧炭、采矿、粉碎,
实际需要的人手远多于炉前这几个人;鼓风的人要轮换,
安全员不要同时干别的活,专门盯着人的状态和火情
```

## 八、检查清单

### 开工前检查

- [ ] 炉子完全干燥,无裂缝
- [ ] 燃料充足(准备量的2倍)
- [ ] 鼓风装置工作正常
- [ ] 所有工具齐备且干燥
- [ ] 防护装备穿戴完毕
- [ ] 灭火设施就位
- [ ] 风向检查(下风向无人)
- [ ] 天气晴朗,无雨
- [ ] 矿石、助熔剂、木炭都已烘干、筛好
- [ ] 分工明确: 谁鼓风、谁加料、谁负责安全
- [ ] 知道最近的救治地点,有人会急救

### 作业中监控

- [ ] 每15分钟检查炉温
- [ ] 鼓风稳定持续
- [ ] 观察烟色变化
- [ ] 人员状态正常(无头晕等)
- [ ] 燃料及时补充
- [ ] 风口、出渣口没有堵塞
- [ ] 炉壁外侧没有发红、冒火的地方(快烧穿的征兆,出现就停风降温)
- [ ] 鼓风的人按时轮换、喝水

### 结束后处理

- [ ] 熄火后至少等待12小时
- [ ] 余烬完全熄灭
- [ ] 残渣妥善处理(可能含有毒物质)
- [ ] 工具清洁归位
- [ ] 记录本次经验(温度、配比、结果)
- [ ] 洗手、换下作业服
- [ ] 检查炉子损坏情况,记下要修补的地方
