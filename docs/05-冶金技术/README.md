# 冶金技术

> **末日情况下从零开始的金属冶炼和工具制作**

## ⚠️ 重要警告

**冶金作业具有极高危险性!**

- 🔥 高温作业,易导致严重烧伤
- ☠️ 金属蒸汽有毒,需良好通风
- 💥 熔融金属遇水会爆炸
- ⚡ 需要专业防护装备
- 🏭 环境污染严重,需远离水源和居住区

**在非紧急情况下,请勿尝试!本指南仅供文明崩溃、工业体系瓦解等极端情况使用。**

### [01-铁的冶炼](./01-铁的冶炼.md)

从铁矿石到可用铁器的完整流程。

**核心内容:**
- 🪨 铁矿石的识别(磁铁矿、赤铁矿、褐铁矿)
- 🔥 炼铁基本原理(还原反应)
- ⚒️ 从矿石到生铁
- 🛠️ 从生铁到熟铁/锻铁
- ⚡ 炼钢技术(渗碳法)

**关键要点:**
- 铁矿石 + 木炭 → 海绵铁(块炼法,约1200°C)或生铁(约1300-1400°C出铁水)
- 生铁含碳高(脆),需精炼成熟铁
- 熟铁渗碳 → 钢

**时间成本:**
- 建炉: 3-7天
- 一次炼铁: 8-12小时
- 产量: 1-5 kg铁/次

### [02-铜的冶炼](./02-铜的冶炼.md)

铜和青铜的冶炼方法。

**核心内容:**
- 🟢 铜矿石识别(孔雀石、辉铜矿)
- 🔥 铜的冶炼(熔点1085°C,比铁容易)
- 🛡️ 青铜的制作(铜+锡)
- 🔨 黄铜的制作(铜+锌)
- 📿 简易铸造技术

**关键要点:**
- 氧化铜矿(孔雀石、蓝铜矿)是最容易炼的;硫化矿难度大、焙烧放出二氧化硫
- ☠️ 含砷矿石(毒砂、雄黄等)不要用,冶炼时砷烟剧毒
- 优先回收废铜重熔,比从矿石冶炼容易得多
- 青铜(90%铜+10%锡)硬度高,用于工具、容器、轴套

**优势:**
- ✓ 熔点低,普通炉子即可
- ✓ 易于铸造成型
- ✓ 耐腐蚀

末日最需要的基础工具制作。

**核心内容:**

2. 刀和斧(基本生存工具)
3. 锄和镐(农业和采矿)
4. 钉子(建筑必需)

### [04-金属加工技术](./04-金属加工技术.md)

提高金属性能的处理方法。

**核心内容:**
- 🌡️ 热处理技术
  - 淬火(快速冷却增硬)
  - 回火(减少脆性)
  - 退火(软化便于加工)
  - 正火(细化晶粒)
- 🛡️ 表面处理(防锈、渗碳)

**关键要点:**
- 淬火: 加热至红色后急速水冷
- 回火: 淬火后再加热至约220-300°C,按工具看回火色(菜刀金黄、斧镰褐色、锤面紫色)
- 正确的热处理能显著提高硬度并保持韧性;处理不当则开裂或过脆

### [05-废旧金属回收与铝铸造](./05-废旧金属回收与铝铸造.md)

文明崩溃后最现实的金属来源: 废墟。

**核心内容:**
- 🧲 金属识别(磁铁、颜色、重量、锉刀、火花鉴别)
- 🚗 废墟中的好钢: 汽车板簧、锉刀、轴承、钢轨分别适合做什么
- 🔌 有色金属的来源;铜线尽量保留成线
- ⚠️ 拆解的危险: 密封件、镀锌件、镁合金、电池
- 🫕 铝的熔化与铸造;铅、锡、锌

**关键要点:**
- 先直接用,再改锻,再熔铸,最后才从矿石冶炼
- 铝熔点约660°C,是最容易熔铸的金属
- 镀锌件受热放出锌烟;密封件受热会爆炸

把零件连接成更大、更复杂的东西。

**核心内容:**

### [07-铸造进阶](./07-铸造进阶.md)

铸出锅、轮子、齿轮毛坯、阀门等复杂形状。

**核心内容:**
- 🌡️ 常用金属的浇注温度和收缩率
- 🏭 坩埚炉、坩埚(钢、黏土石墨、自制黏土)、冲天炉原理

## 🎯 学习路线

### 第一阶段:准备(1-2周)
1. 学习基础知识
2. 建造冶炼炉
3. 制作木炭
4. 识别和采集矿石

### 第二阶段:回收与初级冶炼(1-2个月)
1. 回收废旧金属,学会识别和分类
2. 用回收的铝练习熔化和砂型铸造
3. 尝试铜的冶炼(较简单)
4. 用回收的钢料练习锻打和铆接

### 第三阶段:高级冶炼(3-6个月)
1. 掌握铁的冶炼
2. 学习锻造技术
3. 制作铁制工具
4. 掌握热处理

### 第四阶段:精通(6个月+)
1. 炼钢技术
2. 焊接、铸造进阶、钳工与机械加工
3. 板材与线材(铁皮器具、铜线)
4. 复杂工具制作与大规模生产

## ⚠️ 关键安全提示

### 🔥 火灾预防
- 远离易燃物至少10 m
- 准备灭火沙和水
- 风向下游不可有建筑
- 夜间作业需要守夜人

### 💧 防爆炸
- **绝对禁止熔融金属接触水!**
- 工具必须完全干燥
- 下雨天停止作业
- 铸模需预热去湿

### ☠️ 防中毒
- 必须在室外或通风良好处
- 避免吸入金属蒸汽
- 铅、汞等重金属极毒,慎用
- 作业后清洗手部

### 🩹 烧伤处理
- 立即冷水冲洗15-20分钟(不要用冰)
- 不要挑破水泡
- 不要涂抹油脂、酱油、牙膏等
- 覆盖干净湿纱布,严重烧伤立即就医
- 详见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤)

## 💡 新手建议

### ✅ 推荐起步
1. **先从铜开始**: 熔点低、易操作、成功率高
2. **收集废旧金属**: 比炼矿容易,可练习锻造和熔铸(见[废旧金属回收与铝铸造](./05-废旧金属回收与铝铸造.md))
3. **从简单工具开始**: 钉子、刀片等
4. **建立团队**: 冶金是高强度劳动,需要分工

### ❌ 常见错误
- ✗ 第一次就尝试炼出铁水(太难,容易放弃;新手应先用块炼法)
- ✗ 炉子通风不足(温度上不去)
- ✗ 淬火时工件过热(开裂)
- ✗ 单人作业(危险且效率低)

### 💰 资源优先级
1. **木炭** - 最重要,大量消耗
2. **黏土** - 建炉必需
3. **矿石** - 根据难度选择铜或铁
4. **水源** - 冷却和安全

## 📖 术语表

- **生铁**: 含碳2-4%,硬但脆,不能锻造
- **熟铁**: 含碳<0.2%,软但韧,易锻造
- **钢**: 含碳0.2-2%,既硬又韧
- **还原**: 氧化物去氧得到金属
- **渣**: 冶炼产生的废弃物
- **淬火**: 高温后急冷,增加硬度
- **回火**: 淬火后回温,减少脆性
- **渗碳**: 在表面增加碳含量
- **锻造**: 加热后锤打成型
- **铸造**: 熔化后倒模成型
