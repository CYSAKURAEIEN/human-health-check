# 其他金属: 锡、铅、锌、金、银

> **铁和铜撑起了工具和机器,但青铜需要锡、黄铜需要锌、焊接需要锡和铅,电子和精密器件离不开金和银——这些"小金属"各有不可替代的用途,也各有危险**

## ⚠️ 安全第一

**这几种金属中,铅、锌的冶炼和银的提取都伴随着大量有毒烟气。**

- ☠️ **铅**: 铅烟、铅尘会在体内蓄积,损害神经、血液、肾脏,对儿童和孕妇危害尤其大,而且不可逆
- ☠️ 硫化物矿石(方铅矿、闪锌矿)焙烧放出二氧化硫,刺激呼吸道,损害周围庄稼
- ☠️ 锌蒸气、锌烟引起金属烟热
- ☠️ **绝不使用汞(水银)提金**: 汞蒸气剧毒,污染水源和土壤,危害几代人
- ✓ 所有冶炼在远离住处、水源、农田的下风处进行;孕妇和儿童远离

**优先从废墟中回收这些金属(见[废旧金属回收与铝铸造](05-废旧金属回收与铝铸造.md)),从矿石冶炼是最后的选择。**

## 一、概览

| 金属 | 主要矿石 | 熔点 | 冶炼难度 | 毒性 | 主要用途 |
|------|---------|------|---------|------|---------|
| 锡 | 锡石 SnO₂ | 232°C | ⭐⭐⭐ | 低 | 青铜、焊料、镀锡铁皮、锡器 |
| 铅 | 方铅矿 PbS | 327°C | ⭐⭐⭐ | ☠️☠️☠️ | 焊料、配重、防辐射屏蔽、蓄电池 |
| 锌 | 闪锌矿 ZnS、菱锌矿 ZnCO₃ | 约420°C | ⭐⭐⭐⭐⭐ | ☠️ | 黄铜、镀锌防锈、电池 |
| 金 | 自然金(砂金、岩金) | 1064°C | ⭐⭐(淘金) | 无 | 不腐蚀的电触点、交换价值 |
| 银 | 自然银;与铅共生 | 962°C | ⭐⭐⭐⭐ | 提取时☠️☠️ | 银焊料、电触点、镜子 |

## 二、锡

### 2.1 锡石的识别

```
- 颜色: 黑色、褐色,有时暗红
- 光泽: 强,像金属或金刚石
- 很重: 密度约7,比一般岩石(约2.7)重得多
- 很硬: 小刀划不动
- 产地: 花岗岩地区,常富集在河流的砂砾中(砂锡)
  → 和淘金一样,用淘洗的方法把重的锡石富集出来
```

### 2.2 冶炼

```
锡石 + 木炭 → 锡 + 二氧化碳(SnO₂ + 2CO → Sn + 2CO₂)

⚠️ 虽然金属锡的熔点只有232°C,但把锡石还原成锡需要约1000°C以上的温度
   和很强的还原气氛(大量木炭、鼓风)
   → 需要鼓风炉,普通火堆不行

步骤:
1. 淘洗、富集锡石,捣碎成小颗粒
2. 和木炭粉混合,放进坩埚或小竖炉,上面盖一层木炭
3. 强鼓风加热到约1000°C以上
4. 还原出的锡熔化,沉到底部
5. 炉渣中常常还夹着锡,可以捣碎后再炼一次

精炼(熔析法):
  把粗锡放在倾斜的炉底上缓慢加热,温度稍高于232°C,
  纯锡先熔化流出,熔点较高的杂质留下
```

鼓风设备见[鼓风设备与锻炉](08-鼓风设备与锻炉.md)。

### 2.3 用途

```
- 青铜: 铜 + 约10%锡(见铜的冶炼-青铜制作)
- 焊料: 锡焊(见焊接与连接)
- 镀锡铁皮(马口铁): 薄铁皮镀上锡,不生锈,可做罐头盒、水壶(见板材与线材)
- 锡器: 锡加少量铜或锑,做成碗、壶、烛台
  ⚠️ 不要加铅;旧锡器常含铅,不要用来装酒、醋等酸性饮食
- 锡在约13°C以下长期存放可能逐渐变成灰色粉末("锡疫"),
  寒冷地区的锡锭、锡器存放在较温暖的地方
```

## 三、铅

### 3.1 方铅矿

```
- 铅灰色,金属光泽很强
- 很重(密度约7.5),常呈立方体晶体,敲碎后也是小立方块
- 常和银、锌矿伴生
```

### 3.2 冶炼(原理)

```
1. 焙烧: 在空气中加热,硫化铅变成氧化铅,放出二氧化硫
   2PbS + 3O₂ → 2PbO + 2SO₂
2. 还原: 氧化铅和木炭一起加热,还原出铅
   PbO + C → Pb + CO

☠️ 整个过程产生大量铅烟、铅尘和二氧化硫,对人和周围环境危害极大
   → 除非确有必要,不要从矿石炼铅;优先回收废铅
```

### 3.3 用途和防护

```
用途:
- 配重、渔网坠子
- 焊料
- 防辐射屏蔽(厚铅板挡γ射线)
- 铅酸蓄电池(见电气工程与电子学)

防护:
✓ 熔铅只在室外,温度不要过高(冒烟就是太热)
✓ 操作后洗手洗脸,工作服单独洗
✓ 专用工具,绝不用于食物
✗ 不用铅做饮水管、盛水盛食物的容器,不用铅皮屋顶收集饮用雨水
✗ 孕妇、儿童远离
```

铅中毒的预防见[化学-重金属](../08-基础科学知识/03-化学.md#93-重金属)。

## 四、锌

### 4.1 为什么锌很难炼

```
锌的沸点只有约907°C,而把锌矿还原成锌需要约1000°C以上
→ 锌一被还原出来就变成蒸气,在炉子里和空气接触又被氧化,随烟跑掉
→ 必须在密闭的容器里还原,再让锌蒸气在冷凝处凝结成液体或固体

我国明代宋应星的《天工开物》记载了"升炼倭铅"(炼锌):
  把炉甘石(菱锌矿)装进泥罐,封严,罐和罐之间堆满煤饼,
  加热后锌蒸气在罐上部较冷的地方凝结成锌
```

### 4.2 现实做法

```
- 锌主要从废墟中获得: 镀锌层、锌合金压铸件、旧电池的锌筒
- 做黄铜不一定需要金属锌: 历史上的"渗锌法"是把铜和炉甘石、木炭一起
  封在坩埚里加热,锌蒸气直接渗进铜里形成黄铜(见铜的冶炼-黄铜制作)
- 熔化锌时注意通风,避免吸入锌烟
```

### 4.3 用途

```
- 黄铜(铜 + 锌)
- 镀锌: 钢铁件浸入熔化的锌中,表面形成锌层防锈
  (锌比铁活泼,先被腐蚀,保护了铁,见化学进阶-腐蚀和防护)
- 牺牲阳极: 锌块连在船体、水管上防腐
- 锌锰干电池的负极
```

## 五、金

### 5.1 淘金

金几乎不和其他元素化合,以金属状态存在于自然界,而且极重(密度约19.3),可以用水把它和砂石分开。

```
在哪里找:
- 河流的弯道内侧、大石头的下游、河床的基岩缝隙里(重的东西在这里沉积)
- 有石英脉的山区下游

淘金盘:
1. 一个浅的、底部较平的盘子(铁盘、木盘、塑料盘)
2. 装入河沙,浸入水中,用手搅散,去掉大石块
3. 在水中左右摇晃、转动盘子,让重的东西沉到底部
4. 稍微倾斜盘子,用水把上层的轻砂慢慢冲出去
5. 重复,最后盘底剩下黑砂(磁铁矿、锡石等重矿物)和金粒
6. 金粒呈金黄色,不像黄铁矿("愚人金")那样有棱角、易碎

溜槽: 一条倾斜的长木槽,底部钉横条(格条)或铺粗毛毡,
  从上端倒入沙石和水,重的金粒被格条挡住,轻的沙子被冲走
  → 效率比淘金盘高得多
```

### 5.2 不要用汞

```
❌ 用汞(水银)和金粒混合成"汞齐",再加热蒸发汞来得到金,
   是很多地方土法采金的做法,但汞蒸气剧毒,会造成严重的神经损害,
   还会长期污染河流和鱼类
→ 只用重力法(淘洗、溜槽)分选
```

### 5.3 用途

```
- 熔点1064°C,可以熔化铸成金块(见基础冶金知识)
- 不生锈、不腐蚀,导电性好 → 电触点
- 延展性极好,可以打成极薄的金箔
- 在重建初期,金的实际用处远不如铁和铜;
  它的价值主要在于交换,而这取决于社会是否承认
```

## 六、银

### 6.1 来源

```
- 自然银(较少见)
- 和方铅矿共生: 很多铅矿中含有少量银,历史上大部分银是从铅中提取的
- 废墟: 银器、银饰、电子元件中的银触点、银焊料
```

### 6.2 灰吹法(原理)

```
把含银的铅放在用骨灰(或草木灰)做成的浅盘(灰皿)里,鼓风加热熔化:
- 铅被氧化成氧化铅,被多孔的灰皿吸收,或者被吹走
- 银不被氧化,最后留下一颗银珠
→ 也可以用来检验和提纯金、银

☠️ 这个过程中产生大量铅烟,极其危险;只作原理了解
```

### 6.3 用途

```
- 导电性最好的金属: 电触点、开关
- 银焊料(见焊接与连接-铜焊)
- 镜子的反光层
- 银器
⚠️ 银离子有一定抑菌作用,但不要饮用"胶体银",它不能治病,
   长期服用会让皮肤永久变成灰蓝色
```

## 七、汞: 只需知道它的危险

```
汞(水银)存在于旧体温计、血压计、荧光灯管、老式开关中
- 常温下是液体,会挥发出看不见的有毒蒸气
- 打碎后: 开窗通风,用硬纸片收集汞珠装进密封瓶,不要用吸尘器吸、不要用扫帚扫
- 不要加热含汞的东西
- 不要用汞做任何冶炼和提纯
```

## 八、检查清单

- [ ] 优先考虑从废墟中回收,而不是从矿石冶炼
- [ ] 冶炼地点远离住处、水源、农田,在下风处
- [ ] 有铅、锌、硫化物矿石时: 室外、控制温度、防护口罩、事后清洗
- [ ] 孕妇和儿童远离
- [ ] 铅、汞绝不接触食物和饮水
- [ ] 淘金只用重力法,不用汞
