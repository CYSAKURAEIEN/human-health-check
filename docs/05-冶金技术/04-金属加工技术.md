# 金属加工技术

> **从合格到卓越 - 热处理与精加工技术**

## 📖 引言

**同样的铁,处理不同,性能天差地别!**

本章教你如何通过热处理、表面处理等技术,让金属制品性能提升数倍。掌握这些技术,你的工具将远超粗制滥造的产品。

**核心技术:**
- 🔥 淬火 - 硬化
- 🌡️ 回火 - 韧化
- ♨️ 退火 - 软化
- 🔄 正火 - 均质化
- 🛡️ 渗碳 - 表面硬化

本章只讲热处理和表面处理。锻打成形见[简易工具锻造](03-简易工具锻造.md),锉、钻、磨见[钳工与机械加工](09-钳工与机械加工.md),铜、铝等有色金属的退火见[板材与线材-退火](11-板材与线材.md#一退火-冷加工的关键),为什么淬火会变硬(相变原理)见[工程力学与材料-钢的热处理原理](../09-进阶科学与工程/01-工程力学与材料.md#103-钢的热处理原理)。

## ⚠️ 安全第一

- 🔥 **淬火油着火**: 红热工件入油,油面会冒火。油要装在带盖的金属桶里,旁边放盖子和干沙;着火时盖上盖子闷灭,**绝对不能泼水**
- 🔥 **烫伤和蒸汽**: 淬火时水会猛烈沸腾、喷出蒸汽和热水;穿长袖、皮围裙、皮手套,脸不要正对淬火桶。看起来已经"不红"的铁仍有几百度,一律用钳子夹
- ☠️ **一氧化碳**: 渗碳箱、木炭炉在屋里会积聚一氧化碳;在通风的棚下操作,开渗碳箱时会窜出火苗,人站在侧面
- 👁️ **磨削火花**: 砂轮磨削、火花试验必须戴护目镜,站在砂轮侧面
- ☠️ **不要用**: 熔融的铅浴、氰化物盐浴(工厂的"液体渗碳""盐浴"会用到,剧毒)、硝酸盐浴(遇木炭、油会燃烧爆炸)、石棉制品

烧烫伤处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤),一氧化碳中毒见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

## 一、热处理基础

### 1.1 什么是热处理?

**热处理 = 加热 + 保温 + 冷却**

**目的:** 改变金属内部结构,获得需要的性能

**关键要素:**
- 加热温度
- 保温时间
- 冷却速度

### 1.2 钢的相变(简化理解)

```
常温: 铁素体(软) + 渗碳体(硬)
  ↓ 加热到临界温度(约727°C)
高温: 奥氏体(可塑)
  ↓
  ├→ 快速冷却(淬火)
  │   → 马氏体(极硬、脆)
  │
  ├→ 慢速冷却(退火)
  │   → 铁素体+珠光体(软、韧)
  │
  └→ 中速冷却(正火)
      → 铁素体+珠光体(细化,强度好)
```

**关键:**
- **冷却速度决定性能!**
- 快冷 → 硬
- 慢冷 → 软

### 1.3 温度判断(无温度计)

判断温度有两套颜色,不要混淆:

- **火色**: 钢在500°C以上自己发光的颜色,用于淬火、正火、退火、锻造
- **回火色**: 打磨光亮的钢面在200-350°C时表面氧化膜的颜色(钢本身不发光),只用于回火

**火色表(在阴暗处观察):**

| 温度(约) | 火色 | 用途 |
|------|------|------|
| 500-550°C | 暗红(在暗处刚可见) | 太低,什么都不适合 |
| 650-700°C | 深红 | 去应力退火 |
| 约770°C | 暗樱桃红,**磁铁刚好吸不住** | 淬火温度的下限 |
| 780-850°C | 樱桃红 | **淬火、正火、退火温度** |
| 850-950°C | 鲜红(亮樱桃红) | 锻造、渗碳 |
| 1000-1100°C | 橙黄 | 锻造上限,钢件开始过热 |
| 1200°C以上 | 黄白、冒火星 | 过烧,钢被烧坏 |

**回火色表(操作详见[三、回火技术](#三回火技术)):**

| 温度(约) | 回火色 | 典型工具 |
|------|------|------|
| 200-220°C | 浅黄(稻草色) | 锉刀、刮刀、剃刀 |
| 230-240°C | 金黄 | 菜刀、刨刀、钻头 |
| 250-260°C | 褐色 | 凿子、冲子 |
| 270-280°C | 紫色 | 斧头、剪刀 |
| 290-300°C | 深蓝 | 锯条、螺丝刀 |
| 310-350°C | 浅蓝-灰 | 弹簧 |

```
看火色的要点:
1. 在阴暗处或背光处看。阳光下颜色显得偏暗,
   人会不自觉地把钢烧得过热
2. 每次在同一个地方、同样的光线下看,才能积累经验
3. 用磁铁核对: 钢在约770°C以上失去磁性。
   用一块磁铁(可绑在铁丝上)碰工件,刚好吸不住时,
   再加热片刻(颜色再亮一点)就是淬火温度
4. 磁铁只对钢有用;铜、铝本来就不吸磁铁
5. 不同人对颜色的感觉不同,表中温度只是大约值,
   要用试片淬火、锉刀试硬来校正自己的眼睛
```

**记忆口诀:**
- 淬火: 樱桃红入水
- 回火: 稻草黄空冷

## 二、淬火技术

### 2.1 什么是淬火?

**淬火 = 加热至红色 + 快速冷却(水或油)**

**目的:** 硬化金属表面

**适用:** 钢(不适用纯铁或熟铁!)

### 2.2 淬火操作

**步骤:**

**1. 加热:**
```
加热至淬火温度:
- 碳钢: 780-850°C(樱桃红至鲜红)
- 颜色判断: 暗室中观察更准确
- 磁铁核对: 刚好吸不住后再稍加热

加热要点:
✓ 慢慢、均匀地加热,薄刃不要先烧红而厚背还暗着;
  可以把刃口移到火的外缘,让厚的部分先热
✓ 工件不要直接压在风口正前方(那里温度最高、氧气最多)
✗ 不要在火里久泡: 高温停留越久,表面的碳被烧掉越多(脱碳),
  淬完表层是软的,要磨掉0.2-0.5 mm才露出硬钢
✗ 不要烧到鲜红以上: 晶粒变粗,淬后又脆又易裂
```

**2. 保温:**
```
保持红热状态:
- 小件: 30秒-2分钟
- 大件: 5-10分钟
- 目的: 均匀透热
```

**3. 快速冷却:**
```
方法A: 水淬(最快)
  - 直上直下插入水中
  - 快速搅动(均匀冷却)
  - 冷却至不发红

方法B: 油淬(较慢)
  - 冷却速度慢,不易开裂
  - 用于复杂形状、大件

方法C: 分级淬火
  - 先入热水/温油(200-300°C)
  - 停留片刻
  - 再入冷水
  - 减少开裂风险

淬火液的量和温度:
- 至少是工件重量的10倍以上;淬一把菜刀约需10 L水或4-5 L油,
  容器要深,能让整个工件竖直没入
- 水: 用常温水(约20°C),不要用刚打来的冰水;
  加5-10%食盐成盐水,冷却更快、更均匀(盐能减少工件表面的蒸汽膜),
  但也更易裂,只用于形状简单的件
- 油: 先用一块烧红的废铁把油预热到约50°C(手指能短暂伸入的程度),
  冷油反而淬不硬也更易裂

入液动作:
1. 用钳子夹牢厚的一端,刃口朝下,竖直、快速、整个没入
2. 在液中沿刃口方向上下抽动(像切东西那样),不要左右甩;
   左右甩会让两面冷却不同,刀身弯曲
3. 水淬约3-5秒后看到不再剧烈沸腾、不再发红,
   薄件可以提起;厚件继续在液中直到冷却到约100°C以下
4. 淬到手勉强能握住(约50-80°C)就取出,立即回火;
   不要让它冷透后放置过夜(内应力会让它自己开裂)
```

**4. 检查:**
```
淬火成功的特征:
- 表面呈青灰色
- 硬度极高(锉刀打滑)
- 敲击声音清脆

淬火失败的特征:
- 新锉刀能咬进去 → 没淬硬(温度不够、冷得太慢或不是钢)
- 表层能锉动,锉掉一层后打滑 → 表面脱碳,磨掉即可
- 有发丝样细纹(洒水后擦干,裂纹处会渗出水线) → 淬裂,
  受力工具不能再用
```

锉刀试硬的详细方法见[8.1 硬度测试](#81-硬度测试)。

### 2.3 淬火液选择

| 淬火液 | 冷却速度 | 优点 | 缺点 | 用途 |
|--------|----------|------|------|------|
| **冷水** | 极快 | 简单易得,硬度高 | 易开裂 | 简单形状,小件 |
| **盐水** | 最快 | 硬度最高 | 最易裂 | 特殊需求 |
| **温水(30-60°C)** | 快 | 比冷水裂少 | 需加热水 | 中等件 |
| **机油/植物油** | 慢 | 不易裂 | 冒烟、着火风险 | 复杂形状 |
| **动物脂肪** | 慢 | 古代常用 | 臭味 | 替代油 |

```
按钢料选淬火液(回收钢料的来源见废旧金属回收一章):
- 含碳约0.4-0.6%的中碳钢(汽车半轴、部分农具): 水或盐水
- 含碳约0.6-0.8%(钢轨、普通板簧): 先试油,淬不硬再用水
- 含碳1%以上的高碳钢、合金钢(锉刀、轴承、弹簧钢):
  用油;这类钢入水很容易开裂
- 低碳钢、钢筋、熟铁(含碳<0.2%): 怎么淬都不硬,要先渗碳

不知道是什么钢: 截一小段试片,先油淬,锉刀试硬;
锉得动再用水淬一次试。试片敲断看断口(见8.1)
✓ 用过的废机油也能用,但烟大、有毒,在户外通风处操作
✗ 不要用汽油、柴油、酒精等低闪点液体,一碰红铁就会着火
```

回收钢料的种类和用途见[废旧金属回收与铝铸造](05-废旧金属回收与铝铸造.md)。

### 2.4 选择性淬火(局部淬火)

**为什么?**
- 刀刃需要硬(锋利)
- 刀背需要韧(不断)

**方法:**

**方法A: 遮蔽淬火**
```
1. 涂泥在不想淬火的部分(刀背)
2. 厚度5-10 mm
3. 整体加热
4. 入水淬火
5. 泥保护的部分冷却慢,不淬硬
```

**方法B: 局部加热**
```
1. 只加热刃口部分至红热
2. 刀背保持暗色
3. 入水,刃口先入
4. 只有刃口淬硬
```

**方法C: 涂水淬火**
```
1. 整体加热
2. 用湿布快速擦拭刃口
3. 刃口快速冷却淬硬
4. 刀背缓慢冷却保持韧性
```

### 2.5 淬火常见问题

**问题1: 淬火后开裂**

**原因:**
- 冷却过快
- 温度过高
- 有内应力或裂纹

**预防:**
- 使用油淬代替水淬
- 温度准确控制
- 原材料质量好

**问题2: 淬不硬**

**原因:**
- 材料不是钢(是熟铁)
- 温度不够
- 冷却太慢

**解决:**
- 确认是钢材
- 提高温度至樱桃红
- 快速冷却

**问题3: 淬火后变形**

**原因:**
- 冷却不均匀
- 形状不对称

**解决:**
- 直上直下,不斜入
- 快速搅动
- 使用夹具固定

## 三、回火技术

### 3.1 为什么必须回火?

**淬火后的钢:**
- ✓ 硬度极高
- ✗ 脆性极大
- ✗ 一摔就碎!

**回火目的:**
- 减少脆性
- 保留适当硬度
- 获得硬韧兼备的状态

**原则: 淬火必回火!否则工具易碎!**

### 3.2 回火操作

**步骤:**

**1. 清理表面:**
- 用砂纸或磨石打磨淬火件
- 去除氧化皮
- 露出光亮金属面(重要!观察颜色)

**2. 加热:**
```
方法A: 炉火回火
  - 小火加热
  - 观察表面颜色变化

方法B: 明火回火
  - 木炭或煤气火焰
  - 不断移动,均匀加热

方法C: 热板/热砂回火(均匀,推荐小件)
  - 一块厚铁板或一盘干沙放在火上烧热
  - 工件光亮面朝上放在上面,不断翻动
  - 颜色变化慢,容易控制
  - ✗ 不要用熔融铅浴(铅蒸气和铅尘有毒)

方法D: 走色回火(刀、凿等长条工具)
  - 用一根烧红的粗铁棒或火焰只加热刀背/凿子尾部
  - 热量向刃口传,颜色像波纹一样从背部"走"向刃口:
    黄 → 褐 → 紫 → 蓝依次前进
  - 刃口出现目标颜色时,立即把刃口蘸水止住
    (此时背部已到蓝色,更韧;刃口硬)
  - 颜色走得太快就移开热源,让它慢下来

方法E: 炉灶/烤箱回火(最准,适合批量)
  - 家用烤箱或用砖砌的小烘炉,放一支能测到300°C的温度计
  - 200-230°C,保温1小时,取出空冷,再重复1次
  - 时间够长,里外一致,比看颜色更可靠
```

**3. 观察颜色(关键!):**
```
淬火件表面会出现氧化色:

浅黄(220°C) → 剃刀、手术刀
金黄(240°C) → 菜刀、刨刀
褐色(260°C) → 斧头、凿子
紫色(280°C) → 剪刀
深蓝(300°C) → 锯条、弹簧
```

**4. 冷却:**
- 到达目标颜色后立即离开热源
- 一般空冷或油冷
- 走色法为了止住颜色可以蘸水;回火温度远低于淬火温度,
  这时入水不会再淬硬,只是停止回火
- 颜色过头(要黄变成了蓝): 只能重新淬火再回火,不能"回退"

### 3.3 不同工具的回火温度

| 工具 | 回火温度 | 回火颜色 | 性能要求 |
|------|----------|----------|----------|
| 锉刀、锯条 | 200-220°C | 浅黄 | 极硬,微脆 |
| 刀具、凿子 | 220-240°C | 金黄 | 硬,一定韧性 |
| 斧头、剪刀 | 240-270°C | 褐-紫 | 硬韧兼备 |
| 弹簧、钳子 | 300-350°C | 深蓝-灰 | 极韧,硬度适中 |

```
回火时间和次数:
- 看颜色回火: 颜色到了就停,时间短,只回火了表层附近,
  厚件(超过10 mm)颜色到了里面可能还没到温度 → 慢慢加热,
  到色后在热沙中再放10-15分钟,或回火2次
- 烤箱回火: 每25 mm厚保温约1小时,至少1小时,做2次
- 回火色只在打磨光亮的新鲜表面上准确;油污、氧化皮会让颜色失真

回火后的判断:
✓ 锉刀刚好开始能在刃口轻微咬住(比淬火后略软)
✓ 刃口砍硬木、削骨头不崩、不卷 → 合适
✗ 崩口、缺齿 → 回火不够,升高一档颜色再回火
✗ 卷刃、很快变钝 → 回火过头,重新淬火再回火
✓ 不同部位要求不同(刃硬、背韧),用走色法一次完成
```

## 四、退火技术

### 4.1 什么是退火?

**退火 = 加热 + 极慢冷却**

**目的:**
- 软化金属
- 消除内应力
- 便于加工

### 4.2 退火操作

**步骤:**

**1. 加热:**
- 加热至700-800°C(深红至樱桃红)
- 保温30分钟-2小时

**2. 慢冷:**
```
方法A: 炉冷
  - 熄火后留在炉中
  - 随炉自然冷却
  - 12-24小时

方法B: 埋灰/沙中
  - 取出后埋入干灰/干沙
  - 保温慢冷

方法C: 石棉布包裹
  - 隔热保温
```

**3. 冷却到常温:**
- 完全冷却需24小时+

### 4.3 退火用途

**1. 锻前退火:**
- 金属太硬,难锻造
- 退火软化,便于加工

**2. 去应力退火:**
- 焊接、加工后有内应力
- 退火消除,防变形开裂

**3. 纠正淬火失误:**
- 淬火不满意
- 退火重来

## 五、正火技术

### 5.1 什么是正火?

**正火 = 加热 + 空冷**

**与退火区别:**
- 退火: 慢冷(炉冷)
- 正火: 空冷(自然冷却)

**目的:**
- 细化晶粒
- 均匀组织
- 提高强度和韧性

### 5.2 正火操作

**步骤:**

1. **加热:** 780-850°C(樱桃红)
2. **保温:** 10-30分钟
3. **出炉空冷:** 放在空气中自然冷却

**用途:**
- 锻造后正火(改善组织)
- 粗加工后正火(便于精加工)

## 六、渗碳技术

### 6.1 什么是渗碳?

**渗碳 = 让低碳铁吸收碳,表面变成钢**

**原理:**
- 高温下,碳原子渗入铁表面
- 表面含碳量提高
- 形成"软心硬壳"结构

**优势:**
- 省钢材(内部用熟铁)
- 性能优(外硬内韧)
- 古代宝剑常用!

### 6.2 固体渗碳(实用)

**材料:**
```
渗碳剂配方:
- 木炭粉: 70-80%
- 草木灰: 15-20%
- 食盐: 5-10%

混合均匀,备用
```

**步骤:**

**1. 准备:**
- 熟铁工件打磨光滑
- 准备密封铁盒或陶罐

**2. 装填:**
```
[剖面图]
┌────────────┐
│  渗碳剂(3 cm)  │← 顶部
├────────────┤
│  ┌──────┐  │
│  │ 工件 │  │← 周围填满渗碳剂
│  └──────┘  │
├────────────┤
│  渗碳剂(3 cm)  │← 底部
└────────────┘
用黏土密封
```

**3. 加热:**
```
温度: 900-950°C(鲜红)
时间:
  - 薄件(刀片2-3 mm): 4-6小时
  - 中件(斧头5 mm): 8-12小时
  - 厚件(10 mm): 16-24小时

保持温度稳定!
```

**4. 冷却:**
- 随炉慢冷
- 或取出空冷

**5. 检验:**
- 表面应呈暗灰色
- 可见渗碳层

**6. 淬火:**
- 重新加热至樱桃红
- 淬火硬化渗碳层

**7. 回火:**
- 回火降低脆性

### 6.3 液体渗碳(快速)

**方法:**
```
1. 工件加热至樱桃红
2. 快速插入木炭粉
3. 表面粘附木炭
4. 再加热
5. 碳渗入表面
6. 重复5-10次
```

**优点:** 快(1-2小时)
**缺点:** 渗层浅(0.1-0.3 mm)

### 6.4 渗碳深度

| 时间 | 温度 | 渗碳深度 |
|------|------|----------|
| 4小时 | 900°C | 0.3-0.5 mm |
| 8小时 | 900°C | 0.5-1 mm |
| 16小时 | 900°C | 1-1.5 mm |
| 24小时 | 900°C | 1.5-2 mm |

**够用深度:** 0.5-1 mm(刀具)

## 七、其他表面处理

### 7.1 氮化(可选)

**原理:** 渗入氮,形成极硬氮化层

**简易方法:**
```
1. 工件埋入尿素或硝酸盐
2. 加热至500-550°C
3. 保温12-24小时
4. 形成氮化层

硬度: 比渗碳还高!
```

### 7.2 发蓝/发黑(防锈)

**原理:** 形成致密氧化膜

**方法:**
```
1. 工件表面除锈、除油
2. 加热至300-350°C(深蓝色)
3. 立即浸入油中
4. 表面形成蓝黑色氧化膜

或:
1. 浸入碱性氧化液(配方复杂)
2. 加热至135-155°C
3. 30-90分钟
4. 表面发黑
```

**效果:** 防锈,美观

### 7.3 镀层(高级)

**镀锡:**
- 熔融锡浸渍
- 防锈(马口铁)

**镀铜:**
- 电镀或化学镀
- 防锈,导电

## 八、质量控制

### 8.1 硬度测试

**方法A: 锉刀测试**
```
用锉刀在工件上推:
- 锉刀打滑,发出"咝咝"声 → 硬度高✓
- 能锉动 → 硬度不够✗
```

**方法B: 刮削测试**
```
用刀尖刮:
- 刮不动或微痕 → 硬✓
- 轻易刮出槽 → 软✗
```

**方法C: 火花测试(高级)**
```
在砂轮上打磨观察火花:
- 生铁: 火花短,爆裂
- 熟铁: 火花长,分叉少
- 钢: 火花中等,分叉多
- 淬火钢: 火花细密,明亮
```

### 8.2 韧性测试

**弯曲测试:**
```
刀刃向外弯曲:
- 90°不断裂 → 韧性好✓
- <45°断裂 → 脆,需回火✗
```

**跌落测试:**
```
从1 m高跌落到水泥地:
- 完好 → 韧性好✓
- 崩口/断裂 → 脆✗
```

## 九、故障排除

### 问题1: 淬火后太脆,一用就崩口

**原因:** 未回火或回火不足

**解决:**
- 重新回火至250-280°C
- 观察颜色变化

### 问题2: 刀具不锋利,容易钝

**原因:**
- 淬火温度不够
- 冷却太慢

**解决:**
- 重新淬火
- 温度至樱桃红
- 快速水冷

### 问题3: 渗碳不均匀

**原因:**
- 渗碳剂填装不实
- 温度不稳定

**解决:**
- 渗碳剂压实
- 保持恒温

### 问题4: 工件变形严重

**原因:**
- 冷却不均匀
- 工件形状不对称

**解决:**
- 使用夹具
- 垂直入水
- 或改用油淬

```
4. 锤打焊合
5. 重新磨光
6. 再淬火(这次用油)
7. 回火

成功率: 70%
```
