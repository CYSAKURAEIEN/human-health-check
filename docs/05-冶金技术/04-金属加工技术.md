# 金属加工技术

> **从合格到卓越 - 热处理与精加工技术**

## 📖 引言

**同样的铁,处理不同,性能天差地别!**

本章教你如何通过热处理、表面处理等技术,让金属制品性能提升数倍。掌握这些技术,你的工具将远超粗制滥造的产品。

**核心技术:**
- 🔥 淬火 - 硬化
- 🌡️ 回火 - 韧化
- ♨️ 退火 - 软化
- 🔄 正火 - 均质化
- 🛡️ 渗碳 - 表面硬化

本章只讲热处理和表面处理。锻打成形见[简易工具锻造](03-简易工具锻造.md),锉、钻、磨见[钳工与机械加工](09-钳工与机械加工.md),铜、铝等有色金属的退火见[板材与线材-退火](11-板材与线材.md#一退火-冷加工的关键),为什么淬火会变硬(相变原理)见[工程力学与材料-钢的热处理原理](../09-进阶科学与工程/01-工程力学与材料.md#103-钢的热处理原理)。

## ⚠️ 安全第一

- 🔥 **淬火油着火**: 红热工件入油,油面会冒火。油要装在带盖的金属桶里,旁边放盖子和干沙;着火时盖上盖子闷灭,**绝对不能泼水**
- 🔥 **烫伤和蒸汽**: 淬火时水会猛烈沸腾、喷出蒸汽和热水;穿长袖、皮围裙、皮手套,脸不要正对淬火桶。看起来已经"不红"的铁仍有几百度,一律用钳子夹
- ☠️ **一氧化碳**: 渗碳箱、木炭炉在屋里会积聚一氧化碳;在通风的棚下操作,开渗碳箱时会窜出火苗,人站在侧面
- 👁️ **磨削火花**: 砂轮磨削、火花试验必须戴护目镜,站在砂轮侧面
- ☠️ **镀锌件**(白色镀层的铁丝、水管、螺丝)不要直接加热淬火,锌烟会引起金属烟热;先用醋浸泡一两天溶掉镀层,或在户外上风处磨掉
- ☠️ **不要用**: 熔融的铅浴、氰化物盐浴(工厂的"液体渗碳""盐浴"会用到,剧毒)、硝酸盐浴(遇木炭、油会燃烧爆炸)、石棉制品

烧烫伤处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤),一氧化碳中毒见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

## 一、热处理基础

### 1.1 什么是热处理?

**热处理 = 加热 + 保温 + 冷却**

**目的:** 改变金属内部结构,获得需要的性能

**关键要素:**
- 加热温度
- 保温时间
- 冷却速度

### 1.2 钢的相变(简化理解)

```
常温: 铁素体(软) + 渗碳体(硬)
  ↓ 加热到临界温度(约727°C)
高温: 奥氏体(可塑)
  ↓
  ├→ 快速冷却(淬火)
  │   → 马氏体(极硬、脆)
  │
  ├→ 慢速冷却(退火)
  │   → 铁素体+珠光体(软、韧)
  │
  └→ 中速冷却(正火)
      → 铁素体+珠光体(细化,强度好)
```

**关键:**
- **冷却速度决定性能!**
- 快冷 → 硬
- 慢冷 → 软

### 1.3 温度判断(无温度计)

判断温度有两套颜色,不要混淆:

- **火色**: 钢在500°C以上自己发光的颜色,用于淬火、正火、退火、锻造
- **回火色**: 打磨光亮的钢面在200-350°C时表面氧化膜的颜色(钢本身不发光),只用于回火

**火色表(在阴暗处观察):**

| 温度(约) | 火色 | 用途 |
|------|------|------|
| 500-550°C | 暗红(在暗处刚可见) | 太低,什么都不适合 |
| 650-700°C | 深红 | 去应力退火 |
| 约770°C | 暗樱桃红,**磁铁刚好吸不住** | 淬火温度的下限 |
| 780-850°C | 樱桃红 | **淬火、正火、退火温度** |
| 850-950°C | 鲜红(亮樱桃红) | 锻造、渗碳 |
| 1000-1100°C | 橙黄 | 锻造上限,钢件开始过热 |
| 1200°C以上 | 黄白、冒火星 | 过烧,钢被烧坏 |

**回火色表(操作详见[三、回火技术](#三回火技术)):**

| 温度(约) | 回火色 | 典型工具 |
|------|------|------|
| 200-220°C | 浅黄(稻草色) | 锉刀、刮刀、剃刀 |
| 230-240°C | 金黄 | 菜刀、刨刀、钻头 |
| 250-260°C | 褐色 | 斧头、凿子 |
| 270-280°C | 紫色 | 剪刀、冲子 |
| 290-300°C | 深蓝 | 锯条、螺丝刀 |
| 310-350°C | 浅蓝-灰 | 弹簧 |

```
看火色的要点:
1. 在阴暗处或背光处看。阳光下颜色显得偏暗,
   人会不自觉地把钢烧得过热
2. 每次在同一个地方、同样的光线下看,才能积累经验
3. 用磁铁核对: 钢在约770°C以上失去磁性。
   用一块磁铁(可绑在铁丝上)碰工件,刚好吸不住时,
   再加热片刻(颜色再亮一点)就是淬火温度
4. 磁铁只对钢有用;铜、铝本来就不吸磁铁
5. 不同人对颜色的感觉不同,表中温度只是大约值,
   要用试片淬火、锉刀试硬来校正自己的眼睛
```

**记忆口诀:**
- 淬火: 樱桃红入水
- 回火: 稻草黄空冷

## 二、淬火技术

### 2.1 什么是淬火?

**淬火 = 加热至红色 + 快速冷却(水或油)**

**目的:** 硬化金属表面

**适用:** 钢(不适用纯铁或熟铁!)

### 2.2 淬火操作

**步骤:**

**1. 加热:**
```
加热至淬火温度:
- 碳钢: 780-850°C(樱桃红至鲜红)
- 颜色判断: 暗室中观察更准确
- 磁铁核对: 刚好吸不住后再稍加热

加热要点:
✓ 慢慢、均匀地加热,薄刃不要先烧红而厚背还暗着;
  可以把刃口移到火的外缘,让厚的部分先热
✓ 工件不要直接压在风口正前方(那里温度最高、氧气最多)
✗ 不要在火里久泡: 高温停留越久,表面的碳被烧掉越多(脱碳),
  淬完表层是软的,要磨掉0.2-0.5 mm才露出硬钢
✗ 不要烧到鲜红以上: 晶粒变粗,淬后又脆又易裂
```

**2. 保温:**
```
保持红热状态:
- 小件: 30秒-2分钟
- 大件: 5-10分钟
- 目的: 均匀透热
```

**3. 快速冷却:**
```
方法A: 水淬(最快)
  - 直上直下插入水中
  - 快速搅动(均匀冷却)
  - 冷却至不发红

方法B: 油淬(较慢)
  - 冷却速度慢,不易开裂
  - 用于复杂形状、大件

方法C: 分级淬火
  - 先入热水/温油(200-300°C)
  - 停留片刻
  - 再入冷水
  - 减少开裂风险

淬火液的量和温度:
- 至少是工件重量的10倍以上;淬一把菜刀约需10 L水或4-5 L油,
  容器要深,能让整个工件竖直没入
- 水: 用常温水(约20°C),不要用刚打来的冰水;
  加5-10%食盐成盐水,冷却更快、更均匀(盐能减少工件表面的蒸汽膜),
  但也更易裂,只用于形状简单的件
- 油: 先用一块烧红的废铁把油预热到约50°C(手指能短暂伸入的程度),
  冷油黏稠,冷却反而慢,容易淬不硬

入液动作:
1. 用钳子夹牢厚的一端,刃口朝下,竖直、快速、整个没入
2. 在液中沿刃口方向上下抽动(像切东西那样),不要左右甩;
   左右甩会让两面冷却不同,刀身弯曲
3. 水淬约3-5秒后看到不再剧烈沸腾、不再发红,
   薄件可以提起;厚件继续在液中直到冷却到约100°C以下
4. 淬到手勉强能握住(约50-80°C)就取出,立即回火;
   不要让它冷透后放置过夜(内应力会让它自己开裂)
```

**4. 检查:**
```
淬火成功的特征:
- 表面呈青灰色
- 硬度极高(锉刀打滑)
- 敲击声音清脆

淬火失败的特征:
- 新锉刀能咬进去 → 没淬硬(温度不够、冷得太慢或不是钢)
- 表层能锉动,锉掉一层后打滑 → 表面脱碳,磨掉即可
- 有发丝样细纹(洒水后擦干,裂纹处会渗出水线) → 淬裂,
  受力工具不能再用
```

锉刀试硬的详细方法见[8.1 硬度测试](#81-硬度测试)。

### 2.3 淬火液选择

| 淬火液 | 冷却速度 | 优点 | 缺点 | 用途 |
|--------|----------|------|------|------|
| **冷水** | 极快 | 简单易得,硬度高 | 易开裂 | 简单形状,小件 |
| **盐水** | 最快 | 硬度最高 | 最易裂 | 特殊需求 |
| **温水(30-60°C)** | 快 | 比冷水裂少 | 需加热水 | 中等件 |
| **机油/植物油** | 慢 | 不易裂 | 冒烟、着火风险 | 复杂形状 |
| **动物脂肪** | 慢 | 古代常用 | 臭味 | 替代油 |

```
按钢料选淬火液(回收钢料的来源见废旧金属回收一章):
- 含碳约0.4-0.6%的中碳钢(汽车半轴、部分农具): 水或盐水
- 含碳约0.6-0.8%(钢轨、普通板簧): 先试油,淬不硬再用水
- 含碳1%以上的高碳钢、合金钢(锉刀、轴承、弹簧钢):
  用油;这类钢入水很容易开裂
- 低碳钢、钢筋、熟铁(含碳<0.2%): 怎么淬都不硬,要先渗碳

不知道是什么钢: 截一小段试片,先油淬,锉刀试硬;
锉得动再用水淬一次试。试片敲断看断口(见8.1)
✓ 用过的废机油也能用,但烟大、有毒,在户外通风处操作
✗ 不要用汽油、柴油、酒精等低闪点液体,一碰红铁就会着火
```

回收钢料的种类和用途见[废旧金属回收与铝铸造](05-废旧金属回收与铝铸造.md)。

### 2.4 选择性淬火(局部淬火)

**为什么?**
- 刀刃需要硬(锋利)
- 刀背需要韧(不断)

**方法:**

**方法A: 遮蔽淬火**
```
1. 涂泥在不想淬火的部分(刀背)
2. 厚度5-10 mm
3. 整体加热
4. 入水淬火
5. 泥保护的部分冷却慢,不淬硬
```

**方法B: 局部加热**
```
1. 只加热刃口部分至红热
2. 刀背保持暗色
3. 入水,刃口先入
4. 只有刃口淬硬
```

**方法C: 涂水淬火**
```
1. 整体加热
2. 用湿布快速擦拭刃口
3. 刃口快速冷却淬硬
4. 刀背缓慢冷却保持韧性
```

### 2.5 淬火常见问题

**问题1: 淬火后开裂**

**原因:**
- 冷却过快
- 温度过高
- 有内应力或裂纹

**预防:**
- 使用油淬代替水淬
- 温度准确控制
- 原材料质量好

**问题2: 淬不硬**

**原因:**
- 材料不是钢(是熟铁)
- 温度不够
- 冷却太慢

**解决:**
- 确认是钢材
- 提高温度至樱桃红
- 快速冷却

**问题3: 淬火后变形**

**原因:**
- 冷却不均匀
- 形状不对称

**解决:**
- 直上直下,不斜入
- 快速搅动
- 使用夹具固定

## 三、回火技术

### 3.1 为什么必须回火?

**淬火后的钢:**
- ✓ 硬度极高
- ✗ 脆性极大
- ✗ 一摔就碎!

**回火目的:**
- 减少脆性
- 保留适当硬度
- 获得硬韧兼备的状态

**原则: 淬火必回火!否则工具易碎!**

### 3.2 回火操作

**步骤:**

**1. 清理表面:**
- 用砂纸或磨石打磨淬火件
- 去除氧化皮
- 露出光亮金属面(重要!观察颜色)

**2. 加热:**
```
方法A: 炉火回火
  - 小火加热
  - 观察表面颜色变化

方法B: 明火回火
  - 木炭或煤气火焰
  - 不断移动,均匀加热

方法C: 热板/热砂回火(均匀,推荐小件)
  - 一块厚铁板或一盘干沙放在火上烧热
  - 工件光亮面朝上放在上面,不断翻动
  - 颜色变化慢,容易控制
  - ✗ 不要用熔融铅浴(铅蒸气和铅尘有毒)

方法D: 走色回火(刀、凿等长条工具)
  - 用一根烧红的粗铁棒或火焰只加热刀背/凿子尾部
  - 热量向刃口传,颜色像波纹一样从背部"走"向刃口:
    黄 → 褐 → 紫 → 蓝依次前进
  - 刃口出现目标颜色时,立即把刃口蘸水止住
    (此时背部已到蓝色,更韧;刃口硬)
  - 颜色走得太快就移开热源,让它慢下来

方法E: 炉灶/烤箱回火(最准,适合批量)
  - 家用烤箱或用砖砌的小烘炉,放一支能测到300°C的温度计
  - 200-230°C,保温1小时,取出空冷,再重复1次
  - 时间够长,里外一致,比看颜色更可靠
```

**3. 观察颜色(关键!):**
```
淬火件表面会出现氧化色:

浅黄(220°C) → 剃刀、手术刀
金黄(240°C) → 菜刀、刨刀
褐色(260°C) → 斧头、凿子
紫色(280°C) → 剪刀
深蓝(300°C) → 锯条、弹簧
```

**4. 冷却:**
- 到达目标颜色后立即离开热源
- 一般空冷或油冷
- 走色法为了止住颜色可以蘸水;回火温度远低于淬火温度,
  这时入水不会再淬硬,只是停止回火
- 颜色过头(要黄变成了蓝): 只能重新淬火再回火,不能"回退"

### 3.3 不同工具的回火温度

| 工具 | 回火温度 | 回火颜色 | 性能要求 |
|------|----------|----------|----------|
| 锉刀、刮刀、剃刀 | 200-220°C | 浅黄 | 极硬,微脆 |
| 刀具、凿子 | 220-240°C | 金黄 | 硬,一定韧性 |
| 斧头、剪刀 | 240-270°C | 褐-紫 | 硬韧兼备 |
| 锯条、螺丝刀 | 290-300°C | 深蓝 | 韧,能弯曲回弹 |
| 弹簧、钳子 | 300-350°C | 深蓝-灰 | 极韧,硬度适中 |

```
回火时间和次数:
- 看颜色回火: 颜色到了就停,时间短,只回火了表层附近,
  厚件(超过10 mm)颜色到了里面可能还没到温度 → 慢慢加热,
  到色后在热沙中再放10-15分钟,或回火2次
- 烤箱回火: 每25 mm厚保温约1小时,至少1小时,做2次
- 回火色只在打磨光亮的新鲜表面上准确;油污、氧化皮会让颜色失真

回火后的判断:
✓ 锉刀刚好开始能在刃口轻微咬住(比淬火后略软)
✓ 刃口砍硬木、削骨头不崩、不卷 → 合适
✗ 崩口、缺齿 → 回火不够,升高一档颜色再回火
✗ 卷刃、很快变钝 → 回火过头,重新淬火再回火
✓ 不同部位要求不同(刃硬、背韧),用走色法一次完成
```

## 四、退火技术

### 4.1 什么是退火?

**退火 = 加热 + 极慢冷却**

**目的:**
- 软化金属
- 消除内应力
- 便于加工

### 4.2 退火操作

**步骤:**

**1. 加热:**
- 加热至700-800°C(深红至樱桃红)
- 保温30分钟-2小时
- 完全软化(为了锉、钻、锯)要烧到樱桃红、磁铁吸不住为止
- 保温时间按厚度: 每10 mm厚约15-20分钟,薄件烧透即可

**2. 慢冷:**
```
方法A: 炉冷
  - 熄火后留在炉中
  - 随炉自然冷却
  - 12-24小时

方法B: 埋灰/沙中
  - 取出后埋入干灰/干沙
  - 保温慢冷

方法C: 保温材料包裹
  - 草木灰、干燥的炉渣、蛭石、珍珠岩都可以
  - 灰要事先烘干,并预热(放在炉边);冷湿的灰会让工件冷得太快
  - 埋深至少10 cm,上面盖住
  - ✗ 不要用旧石棉布、石棉板(石棉纤维吸入致癌)

判断冷却够慢: 埋进去1小时后扒开看,应该还是热得不能碰;
如果已经能用手拿,说明冷得太快,软化不充分
```

**3. 冷却到常温:**
- 完全冷却需24小时+

### 4.3 退火用途

**1. 锻前退火:**
- 金属太硬,难锻造
- 退火软化,便于加工

**2. 去应力退火:**
- 焊接、加工后有内应力
- 退火消除,防变形开裂

**3. 纠正淬火失误:**
- 淬火不满意
- 退火重来

**4. 回收钢料的再加工:**
- 锉刀、轴承、板簧原本都是淬硬的,直接锯、钻、锻都很难
- 先退火再加工,做好后重新淬火、回火

```
各种退火的温度(碳钢):
- 完全退火(彻底变软): 樱桃红(约780-850°C),炉冷或埋灰
- 去应力退火(焊接、冷弯、重锻后): 深红以下(约550-650°C),
  保温后空冷或埋灰,不会改变硬度,只消除应力防变形开裂
- 冷锻中途的退火: 红热后埋灰即可

判断退火成功:
✓ 新锉刀能轻松咬进,锉屑成卷
✓ 钢锯能锯动,钻头能钻进
✗ 锉起来仍打滑 → 温度不够或冷得太快,再做一次

铜、黄铜、铝的退火方法和钢完全不同(铜可以直接浸水),
不要套用本节,见板材与线材一章
```

有色金属退火见[板材与线材-退火](11-板材与线材.md#一退火-冷加工的关键);焊接后的处理见[焊接与连接](06-焊接与连接.md)。

## 五、正火技术

### 5.1 什么是正火?

**正火 = 加热 + 空冷**

**与退火区别:**
- 退火: 慢冷(炉冷)
- 正火: 空冷(自然冷却)

**目的:**
- 细化晶粒
- 均匀组织
- 提高强度和韧性

### 5.2 正火操作

**步骤:**

1. **加热:** 780-850°C(樱桃红)
2. **保温:** 10-30分钟
3. **出炉空冷:** 放在空气中自然冷却

**用途:**
- 锻造后正火(改善组织)
- 粗加工后正火(便于精加工)

```
铁匠常用的"三次正火"(锻成形后、淬火前):
1. 第一次: 加热到鲜红(约850-900°C),出炉放在干燥处空冷到不发红
2. 第二次: 加热到樱桃红(约800°C),空冷到不发红
3. 第三次: 加热到刚好失去磁性(约770°C),空冷
   温度一次比一次低,晶粒一次比一次细

空冷的要求:
✓ 放在干燥的砖、铁板上或挂起来,周围空气自然流动
✗ 不要放在潮湿的地面、水泥地上,也不要对着风吹(冷得太快、不均匀)
✗ 薄件不要平放在冷铁砧上(一面冷得快,会弯)

什么时候做正火:
✓ 锻打时温度忽高忽低、反复加热过多次,组织粗大
✓ 淬火前,让淬火更均匀、不易开裂变形
✓ 不知道钢料以前经过什么处理(回收料)
✓ 断口发亮、颗粒粗大(过热的标志) → 正火可以挽救
```

断口的看法见[8.1 硬度测试](#81-硬度测试)。

## 六、渗碳技术

### 6.1 什么是渗碳?

**渗碳 = 让低碳铁吸收碳,表面变成钢**

**原理:**
- 高温下,碳原子渗入铁表面
- 表面含碳量提高
- 形成"软心硬壳"结构

**优势:**
- 省钢材(内部用熟铁)
- 性能优(外硬内韧)
- 古代宝剑常用!

### 6.2 固体渗碳(实用)

**材料:**
```
渗碳剂配方:
- 木炭粉: 70-80%
- 草木灰: 15-20%
- 食盐: 5-10%

混合均匀,备用
```

**步骤:**

**1. 准备:**
- 熟铁工件打磨光滑
- 准备密封铁盒或陶罐

```
准备要点:
- 工件先锻成最终形状、除净氧化皮和锈(渗碳后不宜再大量锻打)
- 渗碳剂: 木炭砸成米粒到黄豆大小(太细不透气、太粗接触差),
  与草木灰、盐拌匀;木炭要干
- 容器: 铁皮盒、厚铁管两端封堵或耐火陶罐;
  工件之间、工件与盒壁之间至少留2-3 cm,填满压实
- 不需要渗碳的部位(如装柄的孔)可以涂一层黏土泥隔开
- 同时放入1-2根同材料的小试条(约8 mm粗),一端露在易取的位置,
  用来判断渗碳深度,不必破坏工件
```

**2. 装填:**
```
[剖面图]
┌────────────┐
│  渗碳剂(3 cm)  │← 顶部
├────────────┤
│  ┌──────┐  │
│  │ 工件 │  │← 周围填满渗碳剂
│  └──────┘  │
├────────────┤
│  渗碳剂(3 cm)  │← 底部
└────────────┘
用黏土密封
```

**3. 加热:**
```
温度: 900-950°C(鲜红)
时间:
  - 薄件(刀片2-3 mm): 4-6小时
  - 中件(斧头5 mm): 8-12小时
  - 厚件(10 mm): 16-24小时

保持温度稳定!

计时和控温:
- 从整个箱子烧到鲜红(箱子中心也透红)时才开始计时;
  大箱子烧透要1-2小时
- 箱子埋在木炭炉中,小风慢烧,保持鲜红,不要烧到橙黄
  (温度过高会让工件晶粒粗大,甚至局部熔化)
- 中途可以抽出一根试条淬水、敲断,看硬壳的厚度,够了就停
- 开箱时会窜出一氧化碳火苗,站在侧面,户外操作
```

**4. 冷却:**
- 随炉慢冷
- 或取出空冷

**5. 检验:**
- 表面应呈暗灰色
- 可见渗碳层

**6. 淬火:**
- 重新加热至樱桃红
- 淬火硬化渗碳层
- 渗碳时长时间高温使晶粒变粗,淬火前最好先正火1-2次;
  淬火温度取低一些(刚失去磁性再稍热),表层的高碳钢用水淬容易裂,
  薄件可以用盐水或温水,复杂件用油

**7. 回火:**
- 回火降低脆性

### 6.3 液体渗碳(快速)

**方法:**
```
1. 工件加热至樱桃红
2. 快速插入木炭粉
3. 表面粘附木炭
4. 再加热
5. 碳渗入表面
6. 重复5-10次
```

**优点:** 快(1-2小时)
**缺点:** 渗层浅(0.1-0.3 mm)

```
说明: 这种做法实际是"反复粘炭的简易表面渗碳",
渗层很薄,只适合小件(钉子做的锥子、小刀刃口);
磨一次刃就可能磨穿,不适合需要反复磨的刀具。

工厂里真正的"液体渗碳"用熔融的氰化物盐浴,剧毒,
吸入或溅到伤口都可能致命,绝对不要尝试。
```

### 6.4 渗碳深度

| 时间 | 温度 | 渗碳深度 |
|------|------|----------|
| 4小时 | 900°C | 0.3-0.5 mm |
| 8小时 | 900°C | 0.5-1 mm |
| 16小时 | 900°C | 1-1.5 mm |
| 24小时 | 900°C | 1.5-2 mm |

**够用深度:** 0.5-1 mm(刀具)

```
表中是固体渗碳的大约值,实际受温度、渗碳剂和密封好坏影响很大,
以试条为准:
1. 试条随工件一起淬火
2. 在试条上用锉刀刻一道口,夹在台钳上敲断
3. 断口: 外圈一层颗粒细、颜色灰白的就是渗碳淬硬层,
   中心颗粒较粗、较亮、能弯的是没渗到的熟铁
4. 量外圈厚度。刀具0.5-1 mm,农具锄、镐1-1.5 mm

刀具的渗碳层不能太薄: 磨刃时会把刃口的硬层磨掉,
露出软铁 → 刃口很快变钝。需要反复磨的刀,
最好用整块钢或"夹钢"(熟铁夹一片钢刃)
```

夹钢、嵌钢刃的锻法见[简易工具锻造-嵌钢刃](03-简易工具锻造.md#112-嵌钢刃)。

## 七、其他表面处理

### 7.1 氮化(可选)

**原理:** 渗入氮,形成极硬氮化层

```
了解即可,不推荐土法尝试:
- 工厂的氮化要用氨气在密封炉中长时间保温,或用含氰的盐浴,
  需要专门设备,盐浴剧毒
- 流传的"埋在尿素或硝酸盐里加热"的做法不可靠且危险:
  尿素受热分解出氨气和有毒产物;硝酸盐是强氧化剂,
  遇到木炭、油脂、木屑会剧烈燃烧甚至爆炸
- 对小社区来说,渗碳 + 淬火 + 回火已经能满足绝大多数工具的需要
```

### 7.2 发蓝/发黑(防锈)

**原理:** 形成致密氧化膜

**方法:**
```
1. 工件表面除锈、除油
2. 加热至300-350°C(深蓝色)
3. 立即浸入油中
4. 表面形成蓝黑色氧化膜

或:
1. 浸入碱性氧化液(配方复杂)
2. 加热至135-155°C
3. 30-90分钟
4. 表面发黑
```

**效果:** 防锈,美观

```
实用的做法是"油烤发黑"(和开铁锅、养铸铁锅是一个道理):
1. 工件打磨光亮,用热碱水或草木灰水洗净油污,之后不要用手摸
2. 加热到抹上的油会立刻冒烟(约250-350°C)
3. 薄薄涂一层植物油(亚麻籽油、桐油、菜籽油)或蜂蜡,
   油冒烟碳化,形成黑色硬膜
4. 擦掉多余的油,再加热、再涂,重复3-5次,颜色越来越黑越均匀
5. 冷却后再擦一层油

⚠️ 已经淬火回火的刀具不要整体这样烤: 加热到300°C以上,
   刃口会被回火变软。只用在不需要高硬度的部位
   (刀柄铁箍、铰链、钉子、锅、农具的非刃部分),
   或者先发黑再淬火回火
⚠️ "碱性氧化液发黑"要用接近沸腾的浓碱液,溅到眼睛会致盲,
   不建议土法操作
✓ 发黑膜很薄,单靠它防锈不够,必须经常上油,
  它的作用是让油附着得更好
```

### 7.3 镀层(高级)

**镀锡:**
- 熔融锡浸渍
- 防锈(马口铁)

**镀铜:**
- 电镀或化学镀
- 防锈,导电

```
各种镀层的实际效果:
- 镀锡: 适合铁皮、炊具、饮水器具;锡层破损后,
  铁反而锈得更快(铁比锡活泼),要保持完整
  做法见板材与线材一章;饮食器具只用纯锡,不用含铅焊锡
- 热镀锌: 铁件浸入熔化的锌,锌层破损后锌先被腐蚀,
  仍能保护铁,适合室外铁件、铁丝、水桶;
  ☠️ 锌熔化时冒白烟(氧化锌),吸入会引起"金属烟热"
  (发热、寒战、咳嗽,类似感冒),必须在户外上风处操作
- 把铁件放进硫酸铜溶液会"自己镀上一层铜",
  但铜层疏松、附着差,铜比铁不活泼,有破损处铁反而锈得更快,
  只能做装饰或识别标记,不能防锈
- 真正的电镀需要稳定的直流电源和配好的镀液,属于电化学工业
```

镀锡铁皮的做法见[板材与线材-镀锡铁皮](11-板材与线材.md#三镀锡铁皮马口铁),镀锌的原理见[其他金属-锌](10-其他金属.md#四锌)和[化学进阶-腐蚀和防护](../09-进阶科学与工程/05-化学进阶.md#54-腐蚀和防护)。

### 7.4 涂层与日常防锈

| 方法 | 做法 | 防锈时间(约) | 适用 |
|------|------|------|------|
| 薄油 | 擦净后抹一层植物油、机油、动物油 | 室内几周到几个月 | 常用工具 |
| 黄油/牛油厚涂 | 涂厚一层,包油纸或布 | 1年以上 | 长期封存的工具、备件 |
| 蜂蜡 | 工件微热,擦上蜂蜡,擦匀 | 几个月 | 刀具、小件、木柄铁件 |
| 熟桐油/亚麻籽油 | 薄涂,晾干形成硬膜,涂2-3遍 | 1年左右 | 不常摩擦的部位、农具 |
| 沥青/松焦油 | 加热熔化后刷上 | 多年 | 埋地、泡水的铁件(桩脚、铁箍) |
| 油漆 | 先除锈,刷底漆再刷面漆 | 多年 | 大件、门窗、铁皮屋顶 |

```
防锈的关键是"干燥 + 隔绝空气":
✓ 用完先擦干水、汗、泥土,再上油。汗和盐是最快的锈蚀源
✓ 存放处远离海风、厕所、牲口圈(氨气、盐雾加速生锈)
✓ 封存的工具和木炭、生石灰一起放在密闭箱里吸潮
  (生石灰吸水后发热膨胀,装在布袋里,箱子不要装满)
✓ 已经起了浮锈: 用砂纸、钢丝刷或醋浸泡后刷掉,洗净擦干,立即上油
✗ 不要用含盐的油(如腌肉的油)、含水的动物油,会越涂越锈
✗ 刃口不要涂油漆、沥青,刀具用油或蜡
✗ 食用器具(锅、刀)只用食用油,不用机油、沥青
```

工具日常保养见[简易工具锻造-防锈](03-简易工具锻造.md#101-防锈)和[木工与工具维护-工具保养](../07-日常生活技能/09-木工与工具维护.md#工具保养)。

## 八、质量控制

### 8.1 硬度测试

**方法A: 锉刀测试**
```
用锉刀在工件上推:
- 锉刀打滑,发出"咝咝"声 → 硬度高✓
- 能锉动 → 硬度不够✗
```

锉刀试硬的做法:
```
1. 用一把锋利的新锉刀(或专门留作试硬的旧锉刀,不要用它干活),
   用锉刀的一个角或边
2. 选不重要的位置: 刀根、刀背靠刃处、凿子侧面;
   先磨掉表面的氧化皮和脱碳层,露出光亮金属
3. 只用很轻的力,推一下就停,不要来回锉(会损伤刃口和锉刀)
4. 同时在一块已知硬度的料上试(如一段旧锉刀、一块退火钢),对比手感
```

| 锉刀手感 | 大致状态 | 说明 |
|------|------|------|
| 完全打滑、像在玻璃上滑,咝咝声 | 淬火后未回火(最硬) | 锉刀、刮刀要求的硬度 |
| 打滑,略有阻滞感 | 淬火后低温回火(浅黄-金黄) | 刀具、钻头合适 |
| 能轻微咬住,留下浅亮痕 | 回火到紫-蓝 | 斧、凿、锯条、弹簧合适 |
| 咬进去,有锉屑 | 没淬硬,或回火过头 | 刀具不合格 |
| 很容易锉,锉屑成卷 | 退火状态或低碳钢、熟铁 | 便于加工 |

```
✓ 锉刀试硬只看表层;渗碳件锉不动只说明表面硬,
  渗层厚度要看试条断口
✗ 不要拿锉刀去试比它硬的东西(淬火后未回火的高碳钢),
  试完锉刀那一处就废了;试一下就停
```

**方法B: 刮削测试**
```
用刀尖刮:
- 刮不动或微痕 → 硬✓
- 轻易刮出槽 → 软✗
```

**方法C: 火花测试(高级)**
```
在砂轮上打磨观察火花:
- 生铁: 火花短、暗红到橙色,末端少量小分叉
- 熟铁: 火花长,分叉少
- 钢: 火花中等,分叉多
- 淬火钢: 火花细密,明亮
```

火花试验的详细判断:
```
准备:
- 砂轮(手摇或电动均可),装防护罩,戴护目镜,站在砂轮侧面
- 在阴暗处做,背景暗,火花看得清楚
- 准备已知钢种的"标样": 旧锉刀(高碳)、钢轨或板簧(中高碳)、
  钢筋或铁丝(低碳)、铸铁锅碎片(铸铁),每次和标样比较
- 每次用同样的压力、同样的位置把工件压在砂轮上,火花水平射出

看什么:
1. 火花流线的长短和颜色
2. 流线上"爆花"(像小烟花一样炸开的分叉)的多少
3. 分叉是一次分叉,还是分叉上再分叉(二次、三次爆花)
```

| 材料 | 流线 | 爆花 | 颜色 |
|------|------|------|------|
| 熟铁、低碳钢(<0.2%碳) | 长而直、粗 | 很少,偶见单个小分叉 | 草黄色 |
| 中碳钢(约0.4-0.6%) | 中长 | 较多,有二次分叉 | 黄色,较亮 |
| 高碳钢(约0.8%以上,锉刀、轴承) | 短而密 | 很多、很密,多次分叉,像一簇簇烟花 | 亮白黄色 |
| 铸铁、生铁 | 短而细,数量少 | 小而少,末端带细碎小花 | 暗红-橙色 |
| 部分合金钢(如含钨、铬) | 流线发暗、偏红 | 爆花减少 | 暗红,末端可能有箭头状 |

```
判断原则:
✓ 含碳越多,爆花越多、越密、分叉越多
✓ 只用来比较"哪块料碳多、哪块碳少",不能精确测含碳量
✓ 淬火与否对火花影响不大,判断硬度还是要靠锉刀
✗ 不要用来测铜、铝、不锈钢:
  铜铝几乎没有火花,而且会糊住砂轮
```

**方法D: 断口检查(试片)**
```
1. 截一小段同料试片(或渗碳试条),和工件一起淬火
2. 在一侧用锉刀或砂轮刻一道口,夹在台钳上,用锤子敲断
   (戴护目镜,碎片会飞出)
3. 看断口:
   - 颗粒极细、灰白色、像细瓷或天鹅绒 → 温度正确,淬透 ✓
   - 颗粒粗大、闪闪发亮、像白糖 → 淬火温度过高(过热) ✗
     → 正火后重新淬火,温度降低
   - 一敲就弯、不断 → 没淬硬(不是钢,或温度不够)
   - 外圈细、中心粗 → 渗碳件正常,或者大件没有淬透
```

用砂轮的安全要点见[钳工与机械加工-磨削](09-钳工与机械加工.md#八磨削)。

### 8.2 韧性测试

**弯曲测试:**
```
刀刃向外弯曲:
- 90°不断裂 → 韧性好✓
- <45°断裂 → 脆,需回火✗
```

**跌落测试:**
```
从1 m高跌落到水泥地:
- 完好 → 韧性好✓
- 崩口/断裂 → 脆✗
```

```
⚠️ 弯曲、跌落都是破坏性试验,第一次处理某种钢料时,
   用同料、同炉处理的试片来做,不要拿刚做好的成品冒险
✓ 一把合格的刀: 轻轻弯曲后能弹回原形;砍硬木、削骨头后
  刃口不崩不卷;仍能被磨刀石磨利(太硬的磨不动)
✓ 斧、凿、锤要承受敲击: 用它砍劈、敲击十几次后检查刃口和锤击面,
  不崩、不卷、锤击面不起"蘑菇头"
✓ 弹簧: 压到工作位置几十次后,松开能回到原来的长度
```

## 九、故障排除

### 问题1: 淬火后太脆,一用就崩口

**原因:** 未回火或回火不足

**解决:**
- 重新回火至250-280°C
- 观察颜色变化

### 问题2: 刀具不锋利,容易钝

**原因:**
- 淬火温度不够
- 冷却太慢

**解决:**
- 重新淬火
- 温度至樱桃红
- 快速水冷

### 问题3: 渗碳不均匀

**原因:**
- 渗碳剂填装不实
- 温度不稳定

**解决:**
- 渗碳剂压实
- 保持恒温

### 问题4: 工件变形严重

**原因:**
- 冷却不均匀
- 工件形状不对称

**解决:**
- 使用夹具
- 垂直入水
- 或改用油淬

## 十、实战案例

### 案例1: 制作一把高品质菜刀

**步骤:**
```
1. 材料: 熟铁500 g
2. 锻造成刀形
3. 渗碳: 刃口部位,8小时
4. 淬火: 樱桃红,水淬(刃口先入)
5. 回火: 240°C(金黄色)
6. 磨刃
7. 安装柄

结果: 外硬内韧,锋利耐用!
```

### 案例2: 修复淬裂的工具

**问题:** 凿子淬火开裂

**修复:**
```
1. 退火(软化)
2. 加热至鲜红
3. 裂纹对齐
4. 锤打焊合
5. 重新磨光
6. 再淬火(这次用油)
7. 回火

成功率: 不高
```

```
说明: 淬裂的裂纹内表面已经氧化,锻焊很难真正焊合,
看起来合上了,里面往往仍有夹灰,受力时会从原处再裂。
✓ 裂纹在边角、不受力处: 磨掉或截掉裂的部分,改做小一号的工具
✓ 裂纹贯穿或在受力处(凿子的刃根、锤头的孔边): 不要修,
  退火后改锻成别的东西(冲子、钉子、小刀)
✗ 锤子、斧头、凿子等受敲击的工具,修过的裂纹可能在使用时崩飞,
  不要冒险继续使用
```
