# 板材与线材

> **水桶、烟囱、锅盖要铁皮,篱笆、弹簧、钉子要铁丝,发电机、电报要铜线——把金属变成薄板和细线,是从"打工具"走向"做器具、做机器"的一步**

## ⚠️ 安全第一

- 🩸 金属板的边缘和线头非常锋利: 戴皮手套,剪下的边角料及时收拾
- 💥 拉丝时线材突然断裂会猛烈回弹: 人不要站在线的延长线上,拉丝用绞盘时周围不站人
- ☠️ 镀锡、镀锌用的焊剂和酸有腐蚀性,熔融的锡、锌会烫伤;加热镀锌件会放出锌烟
- 🔥 退火时工件很烫,看起来不红也可能有几百摄氏度

---

## 一、退火: 冷加工的关键

```
金属在冷态下锤打、弯折、拉伸,会越来越硬、越来越脆(加工硬化),
继续加工就会开裂、断掉。这时要退火,让它恢复柔软:

铜、黄铜: 加热到暗红色,可以放在空气中冷却,也可以直接浸水冷却
  (铜和钢不同,急冷不会变硬,反而方便快速去掉氧化皮)
铁、低碳钢: 加热到红热,在炉灰中或空气中慢慢冷却
铝: 加热温度低得多(约300-400°C),不能烧红(会熔化);
  一个土办法: 先在铝表面涂一层肥皂或画上记号笔,加热到肥皂发黑、记号消失即可

✓ 原则: 加工几次 → 退火 → 再加工几次 → 再退火
✓ 退火后表面的氧化皮可以用稀酸或醋浸泡后刷掉(酸洗)
```

加工硬化的原理见[工程力学与材料-金属为什么能锻打](../09-进阶科学与工程/01-工程力学与材料.md#101-金属为什么能锻打)。

## 二、板材

### 2.1 获得金属板

```
最现实: 从废墟中回收
- 汽车车身、家电外壳(低碳钢板)
- 铁皮屋顶、铁皮桶(常有镀锌层)
- 铝板、铝型材、铜板

锻打成板:
- 把铁条或铁块加热,用锤子反复向四周锤展,逐渐变薄变宽
- 很费力,而且难以做到厚薄均匀,只适合小块的、较厚的板

轧制:
- 两根淬硬的钢辊,用齿轮连在一起反向转动,金属从中间挤过去就被压薄
- 每次只压薄一点,逐渐调小两辊的间距;冷轧的铜、铝要多次退火
- 可以用回收的轴、齿轮、轴承自制小型手摇轧辊
```

### 2.2 剪切和弯折

```
剪切: 铁皮剪(手剪)剪薄板;厚板用錾子在砧子边上凿断,或者锯断
弯折:
- 把板夹在两块直的硬木或角钢之间,用木槌沿着边沿敲弯 → 直的折边
- 在圆钢、圆木或砧子的尖角上敲打 → 弯成圆筒、弧面
- 用木槌、皮锤敲打铁皮,不容易留下锤痕
卷边: 板的边缘卷一道,既加强又不割手
```

### 2.3 展开: 先在平板上画出形状

```
圆筒(水桶身、烟囱管):
  展开是一个长方形,长 = π × 直径(再加上接缝的咬口余量),宽 = 高度

圆锥(漏斗、桶底稍大的桶身):
  母线长 L = √(r² + h²)  (r 是底面半径,h 是锥的高度)
  展开是一个扇形,半径 = L,扇形的圆心角 = 360° × r ÷ L

例: 做一个口径20 cm(r = 10 cm)、高12 cm的漏斗(圆锥部分)
  L = √(10² + 12²) ≈ 15.6 cm
  圆心角 = 360° × 10 ÷ 15.6 ≈ 231°
  → 在铁皮上以15.6 cm为半径画圆,剪下231°的扇形,卷起来接缝即可
```

数学基础见[数学-几何](../08-基础科学知识/01-数学.md#四几何)。

### 2.4 接缝

```
- 咬口: 两块板的边缘折弯互相钩住、压平(见焊接与连接-铁皮的咬口)
- 铆接: 受力较大的地方
- 锡焊: 咬口或搭接后再用锡封缝,防止漏水
```

接缝的做法见[焊接与连接](06-焊接与连接.md)。

### 2.5 锤揲: 把平板打成碗和盆

```
1. 把退过火的圆形铜板或铁板放在一个凹坑(木墩上挖的坑或沙袋)上
2. 用圆头锤从外圈向中心一圈一圈锤打,板逐渐凹下去
3. 变硬后退火,再继续
4. 最后放在圆头的铁砧上,从里面向外轻轻锤平表面(平锤)
→ 铜盆、铜壶、铁锅都可以这样做;铜最容易,其次是低碳钢
```

## 三、镀锡铁皮(马口铁)

铁皮镀上一层锡后不易生锈,可以做水壶、饭盒、灯罩,也便于锡焊。

```
1. 清洁: 用砂子、砂纸把铁皮打磨光亮,或浸在稀酸(醋也可以)里去锈去氧化皮,
   清水洗净
2. 涂焊剂: 氯化锌溶液(见焊接与连接-锡焊)
3. 浸锡: 把锡在铁锅里熔化(稍高于232°C),表面撒一点松香或盖一层油,
   把铁皮浸入,停留片刻,取出
4. 用麻布或软布趁热擦匀多余的锡
5. 用清水洗掉残留的焊剂

小件也可以: 加热铁件,涂焊剂,把锡条压在表面熔化,用布擦匀
⚠️ 用于饮食器具的,只用纯锡,不用含铅的焊锡
```

锡的来源见[其他金属-锡](10-其他金属.md#二锡)。

## 四、线材

### 4.1 拉丝的原理

```
把一根金属条的一端削尖,穿过一个比它略小的孔,从另一侧用力拉出来,
它就变细变长了。用一系列由大到小的孔反复拉,就能得到需要的细线。

每次拉拔,截面积大约减小10-20%(太多会拉断)
拉几次后线材变硬,要退火再继续
```

### 4.2 拉丝板

```
材料: 高碳钢(回收的锉刀、板簧最合适),厚约1-2 cm

制作:
1. 先把钢板退火变软
2. 钻一排由大到小的孔
3. 每个孔从背面扩成锥形(入口大、出口小),出口处的直径就是这一档线的直径
   相邻两个孔的直径差不要太大(截面积减小约10-20%,
   即直径减小约5-10%)
4. 用锥形的锉、磨棒把孔壁修光滑
5. 淬火、回火,让孔壁足够硬、耐磨

孔壁越光滑,拉出的线越光洁,越不容易断
```

热处理见[金属加工技术](04-金属加工技术.md)。

### 4.3 拉丝步骤

```
1. 准备线坯: 锻出或剪出一根粗细均匀的圆条,退火
2. 把一端锉尖或锤尖,能从孔的入口穿过去
3. 涂润滑剂: 肥皂、蜡、牛羊油
4. 拉丝板固定在台钳或结实的木桩上
5. 用钳子夹住穿出的尖端,用力拉出;粗线用绞盘或杠杆拉
6. 换下一个更小的孔,重复
7. 拉了几次后线材变硬、发脆,退火后再继续
8. 铁丝退火后会起氧化皮,先酸洗去掉再拉

铜丝最容易拉,铝丝次之,铁丝最难
```

### 4.4 电线

```
发电机、电动机、电报、电灯都需要铜线:
✓ 尽量保留回收的铜线(带绝缘的漆包线极其宝贵),不要熔化
✓ 自己拉的铜线要绝缘:
  - 用棉线或丝线紧密缠绕,再浸漆或浸蜡(历史上的做法)
  - 裸线架空时,用陶瓷或干燥的木头作绝缘子
✓ 导线粗细按电流选择(见电气工程与电子学-导线和保护)
```

导线的选择见[电气工程与电子学-导线和保护](../09-进阶科学与工程/02-电气工程与电子学.md#62-导线和保护)。

### 4.5 线材的用途

```
- 铁丝: 捆扎、篱笆、铁丝网、钉子、铆钉坯
- 弹簧: 用弹簧钢丝绕在圆棒上,绕好后淬火、回火
- 铜线: 导线、线圈
- 编织: 筛网、过滤网、篮子
- 链条: 铁丝弯成环,锻焊或铆合(见简易工具锻造-铁环、链条)
```

链条的做法见[简易工具锻造-铁环、链条](03-简易工具锻造.md#62-铁环链条)。

## 五、管材

```
- 最现实: 回收水管、钢管、铜管
- 卷管: 把铁皮或铜皮卷成管,接缝用铜焊或锻焊封住
- 钻孔: 短而粗的管子可以在实心棒上钻孔得到
- 弯管: 管内灌满干沙、两端堵住,加热后再弯,管子不容易瘪
```

## 六、检查清单

- [ ] 加工前退火,加工中变硬了及时退火
- [ ] 戴皮手套处理板材和线头
- [ ] 拉丝时人不站在线材的延长线上
- [ ] 镀锡用纯锡,焊剂残留洗净
- [ ] 回收的铜线、漆包线单独保存,不随意熔化
