# 铸造进阶

> **锻打只能做简单的形状,铸造却能一次做出锅、轮子、齿轮毛坯、阀门、机床床身——形状再复杂,只要能做出模型,就能铸出来**

## ⚠️ 安全第一

**铸造最大的危险是熔融金属遇水爆炸,往往发生在人们以为"已经够干了"的时候。**

- 💥 潮湿的型砂、模具、坩埚、工具、地面,接触金属液都会引起蒸汽爆炸,金属液四溅
- 💥 **绝不在水泥地面上浇注**: 水泥里的水分受热会让地面爆裂;要在一层厚厚的干沙上操作
- 🔥 金属液洒在脚上会造成极严重的烧伤: 穿高帮皮鞋,裤腿盖住鞋面(不要把裤腿塞进鞋里)
- 🔥 化纤衣服遇高温会熔化粘在皮肤上: 穿棉、毛、皮革
- ☠️ 熔炼黄铜时温度过高会冒白色锌烟(金属烟热);熔铅有毒
- ⚠️ 坩埚钳夹不牢、坩埚破裂,是最常见的事故原因: 每次使用前检查

## 一、铸造基础

### 1.1 常用金属的熔点和浇注温度

| 金属 | 熔点 | 大致浇注温度 | 收缩率(约) | 难度 |
|------|------|-------------|-----------|------|
| 锡 | 232°C | 约300°C | 很小 | ⭐ |
| 铅 | 327°C | 约350-400°C | 约1% | ⭐(有毒☠️) |
| 锌 | 约420°C | 约450-480°C | 约1% | ⭐⭐ |
| 铝 | 约660°C | 约700-750°C | 约1.3% | ⭐⭐ |
| 黄铜 | 约900-940°C | 约1000-1100°C | 约1.5-2% | ⭐⭐⭐ |
| 青铜(10%锡) | 约1000°C | 约1100-1200°C | 约1.5% | ⭐⭐⭐ |
| 铜 | 1085°C | 约1150-1200°C | 约2% | ⭐⭐⭐ |
| 灰铸铁 | 约1150-1200°C | 约1300-1400°C | 约1% | ⭐⭐⭐⭐ |
| 钢 | 约1450-1530°C | 约1550-1650°C | 约2% | ⭐⭐⭐⭐⭐(土法基本做不到) |

```
收缩率: 金属从液态冷却到室温后缩小的比例
→ 模型要按收缩率做得比成品大一点
  例: 铸铝件要求长100 mm,模型做成约101.3 mm
```

### 1.2 铸造的基本流程

```
1. 做模型(木头、蜡、泡沫、旧零件)
2. 用模型在型砂里做出型腔(造型),需要空心的地方放砂芯
3. 做浇注系统(浇口、冒口、通气孔)
4. 熔化金属
5. 浇注
6. 冷却后打开砂型,取出铸件
7. 切掉浇口冒口,清理打磨,必要时热处理
```

## 二、熔炉和坩埚

### 2.1 坩埚炉

```
结构:
- 外壳: 铁桶或砖砌
- 内衬: 耐火材料,厚约5-8 cm
- 炉膛直径: 比坩埚大约10 cm(四周各留约5 cm,让火焰绕着坩埚流动)
- 进风口: 在炉膛底部侧面,沿切线方向进风,让火焰旋转着包住坩埚
- 炉底: 垫一块耐火砖作坩埚座,让坩埚高出进风口
- 盖子: 耐火材料做的盖,中间开出气口(可从这里观察和加料)
- 燃料: 木炭(熔铝、铜),焦炭(熔铜、铸铁更好)
- 鼓风: 风箱、皮囊、手摇或电动鼓风机

温度不够时: 加强鼓风、加盖保温、燃料块大小均匀(核桃到鸡蛋大小)、
  炉衬加厚
```

耐火材料的配制见[铁的冶炼-耐火材料配制](01-铁的冶炼.md#22-耐火材料配制);鼓风和炉温控制见[基础冶金知识-温度控制](00-基础冶金知识.md#四温度控制)。

### 2.2 坩埚

| 坩埚 | 适合熔化 | 说明 |
|------|---------|------|
| 钢坩埚(厚壁钢管加底) | 铝、锌、铅、锡 | 简单耐用;不适合铜和铜合金(高温下钢严重氧化,铁也会混进铜里) |
| 黏土石墨坩埚 | 铜、黄铜、青铜、铝 | 最好用;尽量从废旧物资中回收 |
| 自制黏土坩埚 | 铜、青铜 | 耐火黏土 + 熟料(粉碎的旧耐火砖、瓷片),各约一半 |

```
自制黏土坩埚:
1. 耐火黏土和熟料混合,加少量水揉成泥,揉透排出气泡
2. 捏成厚壁的杯形(壁厚约1-2 cm,底更厚),口沿做一个小流嘴
3. 阴干至少一两周,彻底干透
4. 慢慢加热烧成(先小火烘几个小时,再逐渐升温到烧透)
5. 每次使用前预热,检查有无裂纹;有裂纹的坩埚绝不使用

坩埚钳和浇注叉:
- 形状要和坩埚贴合,夹住后不能转动、不能滑脱
- 浇注叉(两人抬的长柄铁环)适合较大的坩埚
- 用之前空着试一遍: 夹起、移动、倾倒
```

### 2.3 化铁炉(冲天炉,了解)

```
熔化铸铁需要约1300-1400°C,一般要用冲天炉:
- 竖立的筒形炉,内衬耐火材料
- 从顶部按层加入: 焦炭、铁料、少量石灰石(造渣),一层一层交替
- 从底部风口强力鼓风
- 铁水从底部出铁口流出
需要: 焦炭、强鼓风、较大的规模和几个人的配合
→ 先掌握铝和铜的铸造,再考虑铸铁
```

## 三、模型

```
材料: 木头(最常用)、蜡、石膏、硬泡沫塑料、旧零件(直接拿来翻砂)

要点:
✓ 收缩余量: 按金属的收缩率放大(见1.1)
✓ 拔模斜度: 垂直的侧面做出约1-3°的斜度,模型才能从砂里取出来而不带坏砂型
✓ 加工余量: 以后要车削、锉平的面,多留几毫米
✓ 圆角: 内角做成圆角,避免铸件在尖角处开裂
✓ 壁厚尽量均匀: 厚薄悬殊处冷却快慢不同,容易缩孔、开裂
✓ 模型表面光滑,刷漆或打蜡,便于起模
✓ 复杂的模型做成两半(分模),沿分型面分开
```

## 四、型砂与造型

### 4.1 湿型砂

```
配方(大致):
- 干净的细砂(河砂或石英砂,过筛)
- 黏土约5-10%(作粘结剂)
- 水约3-5%

检验(手捏法):
- 抓一把用力捏紧,松开后砂团保持手指的形状,表面光滑 → 合适
- 捏不成团、一松就散 → 黏土或水不够
- 粘手、有水渍 → 水太多(⚠️ 水多是最危险的,浇注时易爆)
- 捏成的砂团掰开时断口整齐,不散不粘 → 很好

✓ 用过的型砂可以过筛、重新加水混合后反复使用
✓ 贴近模型的一层用更细的"面砂",铸件表面更光洁
```

### 4.2 砂箱造型(两箱造型)

```
砂箱: 两个没有底和盖的木框或铁框(上箱、下箱),能准确对位(用销子或做记号)

步骤:
1. 下箱放在平板上,模型的一半放在中间(平面朝下)
2. 撒一层分型粉(干细砂、滑石粉或木炭粉),防止粘模
3. 填入型砂,分层用木槌捣实(边角处要捣紧,但不要捣得过死,否则不透气)
4. 刮平,翻转过来
5. 放上模型的另一半(分模时)和上箱,撒分型粉
6. 插上浇口棒和冒口棒,填砂捣实,刮平
7. 用细铁丝在型砂上扎一些通气孔(不要扎到模型上)
8. 抽出浇口棒、冒口棒,分开上下箱,小心取出模型
9. 修补损坏的地方,开出连接浇口和型腔的通道
10. 吹去散砂,合箱,上面压上重物或夹紧(防止浇注时金属液把上箱顶起来)
```

### 4.3 砂芯

```
铸件需要空心(如管子、带孔的轮毂)时,在型腔中放入砂芯
- 砂芯用砂加粘结剂做成(粘结剂: 糖浆、面粉糊、亚麻籽油等),
  放在芯盒里成型,烘干变硬
- 模型上要做出"芯头",在砂型里留下放砂芯的座
- 砂芯要能透气: 中间扎通气孔
```

### 4.4 其他铸型

| 方法 | 说明 | 适合 |
|------|------|------|
| 地坑造型 | 直接在地上的砂坑里造型 | 大而简单的铸件 |
| 失蜡法 | 见[铜的冶炼-失蜡法](02-铜的冶炼.md#42-失蜡法精密铸造) | 精细复杂的小件 |
| 消失模 | 用泡沫塑料(回收的包装泡沫)做模型,埋在干砂中直接浇注,泡沫被金属液烧掉 | 铝、铜;不用起模;⚠️ 产生烟气,室外操作 |
| 金属型 | 钢或铸铁做的模具,可反复使用 | 铝、锌、铅、锡的锭和简单零件;使用前预热、熏烟灰 |
| 石模 | 见[铜的冶炼-石模铸造](02-铜的冶炼.md#43-石模铸造耐用) | 小件 |

## 五、浇注系统

```
          浇口杯(漏斗)
              │
           直浇道(上粗下细)
              │
          ┌───┴────────┐
        横浇道        冒口(在铸件最厚的地方上方)
          │              │
        内浇口 ─→  型腔(铸件)

浇口杯和直浇道: 让金属液平稳流入,直浇道上粗下细,底部做一个小坑缓冲
横浇道和内浇口: 把金属液引到型腔,从侧面、较低的位置平稳进入,不要直冲砂型
冒口: 比铸件更粗的金属储存柱,铸件冷却收缩时由冒口补充金属液
  → 放在铸件最厚、最后凝固的部位
  → 冒口要比它补缩的部位粗,最后凝固
通气孔: 让型腔里的空气和型砂产生的气体排出
```

## 六、熔炼与浇注

### 6.1 熔炼

```
✓ 坩埚、工具预热烘干,原料干燥(见废旧金属回收与铝铸造)
✓ 先放少量料,熔化后再逐块加入预热过的料
✓ 铝: 熔化后撇渣,不要过热,不要过度搅拌
✓ 铜和青铜: 表面盖一层木炭粉,减少氧化;铜完全熔化后再加入锡
  (配比和步骤见铜的冶炼-青铜熔炼)
✓ 黄铜: 加锌时温度不要过高,减少锌烧损和锌烟
✓ 浇注前撇去表面浮渣
```

青铜熔炼见[铜的冶炼-青铜熔炼](02-铜的冶炼.md#33-青铜熔炼)。

### 6.2 浇注

```
1. 砂型放在干沙地上,上箱压好重物
2. 两人配合时,事先约定口令和动作
3. 坩埚口尽量靠近浇口杯
4. 浇注要连续、快而稳,让浇口杯一直保持满的状态,中途不能停
5. 浇到冒口出现金属液为止
6. 剩余的金属液倒入准备好的干燥铁模或沙坑中,不要乱倒
7. 等待凝固: 小件约十几分钟,大件更久;铸铁件要冷却到暗色后再打箱
```

### 6.3 打箱和清理

```
- 冷却后打开砂箱,敲掉型砂
- 用锯或錾子切掉浇口、冒口
- 锉、磨去毛刺和粘砂
- 铸铁件: 慢慢冷却或退火可以降低硬度,便于加工
```

## 七、铸铁

铸铁便宜、耐磨、减震、能铸出复杂形状,是锅、炉子、管件、机床床身、齿轮的重要材料。

```
灰铸铁: 含碳约3%左右、含硅较多,冷却较慢时碳以片状石墨析出
  → 断口灰色,能切削加工,耐磨减震;但脆,不能锻打
白口铸铁: 冷却太快或含硅太少时形成
  → 断口白亮,极硬极脆,几乎无法加工
  → 薄壁处、贴近冷模具的表面容易变成白口

要得到可以加工的灰铸铁:
✓ 壁不要太薄,铸型不要太冷
✓ 回收的灰铸铁件(刹车鼓、刹车盘、缸体、旧铁锅)重熔,成分比较合适

⚠️ 铸铁件不能淬火当刀具用,也不能锻打
⚠️ 铸铁锅、铁炉受到急冷急热(烧红后泼冷水)会开裂
```

## 八、铸造缺陷和原因

| 缺陷 | 表现 | 常见原因 | 改进 |
|------|------|---------|------|
| 气孔 | 铸件内部或表面有圆滑的孔洞 | 型砂太湿、不透气;金属过热吸气 | 少加水、多扎通气孔、控制温度 |
| 缩孔 | 厚大部位内部有不规则的空洞 | 没有冒口或冒口太小 | 在厚处加冒口,让壁厚更均匀 |
| 浇不足、冷隔 | 铸件缺一块,或有没融合的缝 | 金属液温度太低、浇得太慢、壁太薄 | 提高浇注温度,浇得快而连续 |
| 砂眼、夹砂 | 铸件里夹着砂粒 | 型砂捣得不实、浇注冲坏砂型、散砂没清干净 | 捣实、内浇口方向避开砂壁、合箱前吹净 |
| 错箱 | 上下两半错开 | 合箱没对准 | 用定位销或对位记号 |
| 粘砂 | 铸件表面粘着一层砂 | 温度太高、砂太粗 | 用细面砂、刷涂料(石墨粉、滑石粉调水) |
| 裂纹 | 铸件开裂 | 壁厚不均、尖角、冷却受阻 | 圆角、壁厚均匀、及时打箱松砂 |

## 九、检查清单

### 浇注前

- [ ] 砂型干湿合适,通气孔已扎好,上箱压紧
- [ ] 浇注场地是干沙地,不是水泥地
- [ ] 坩埚无裂纹,坩埚钳试夹过
- [ ] 所有工具、加入的料都已预热烘干
- [ ] 防护: 面罩、皮手套、皮围裙、高帮皮鞋、棉质衣服
- [ ] 准备干沙应对洒出(⚠️ 不能用水)
- [ ] 浇注路线畅通,旁人远离

### 浇注后

- [ ] 剩余金属液已妥善处理
- [ ] 铸件充分冷却后再打箱
- [ ] 记录: 金属、温度判断、型砂情况、结果和缺陷,下次改进
