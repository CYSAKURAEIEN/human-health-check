# 铁的冶炼

> **文明的脊梁 - 从零开始掌握炼铁技术**

## ⚠️ 警告

**炼铁是冶金中最困难的技术!**

- 🔥 块炼法需1100-1300°C;要炼出铁水需1300-1400°C
- ⏱️ 单次冶炼需8-24小时持续作业
- 💪 体力消耗巨大(持续鼓风)
- ☠️ 一氧化碳浓度极高
- 💥 操作不当可能爆炸

**初次尝试失败率70%+,需要充分准备和多次尝试!**

```
⚠️ 开工前必须明白的几件事:

☠️ 一氧化碳: 炉子本身就是一台一氧化碳发生器(铁就是靠它还原出来的)
   - 炉口、出渣口冒出的蓝色火苗就是一氧化碳在燃烧
   - 无色无味,头痛、头晕、恶心、犯困是早期信号
   - 只在露天或三面敞开的棚下作业;不要在下风处、低洼处休息;
     夜里守炉的人不能在炉边睡觉

💥 水 + 高温 = 爆炸: 铁水、炉渣碰到潮湿的沙、工具、地面或雨水,
   水瞬间变成蒸汽,会把上千度的金属崩得到处都是 → 一切接触物先烤干

🔥 烫伤: 炉渣、铁块冷却到暗红甚至看起来发黑时仍有数百摄氏度
   → 一律用钳子,不用手摸;穿棉、麻、皮衣物,不穿化纤

👁️ 眼睛: 长时间盯着风口、炉膛的强光会伤眼(红外线),飞溅火星会烫伤眼睛
   → 戴护目镜;观察风口用深色玻璃,只看几秒

🚫 不炼来路不明的矿石和废料: 方铅矿、朱砂(含汞)、雄黄(含砷)、
   镀锌铁皮、涂漆或带塑料的废件,加热时放出有毒烟气
```

一氧化碳中毒的处理见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒);烧烫伤的处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤);防护装备和作业规则见[基础冶金知识-安全防护](00-基础冶金知识.md#六安全防护)。

## 一、铁矿石识别与采集

### 1.1 三大主要铁矿石

#### ① 磁铁矿 Fe₃O₄

**外观特征:**
- 颜色: 黑色、铁黑色
- 光泽: 金属光泽或半金属光泽
- 硬度: 5.5-6.5(小刀刻不动)
- 比重: 5.0-5.2(很重!)

**独特识别方法:**
```
最简单: 有磁性!
- 用磁铁吸附: 强烈吸引
- 或用指南针靠近: 指针偏转

没有磁铁时:
- 回收的喇叭、电机、硬盘里都有强磁铁
- 一根钢针在磁铁上同方向摩擦几十次,也能吸起细小的磁铁矿砂
- 条痕为黑色(和赤铁矿的红色条痕区分)
```

**优点:**
- ✓ 含铁量最高(60-70%)
- ✓ 易识别(磁性)
- ✓ 冶炼效率高

**分布:**
- 火成岩地区
- 接触变质带
- 河流黑砂中

**河滩黑砂的采集:**
```
1. 找河湾内侧、急流后面的缓水处,沙层里常有一条条黑色细砂
2. 用盆或簸箕像淘金一样淘洗,轻的石英砂被冲走,黑砂留下
3. 磁铁装进塑料袋里去吸黑砂,吸满后把袋子翻过来,黑砂就掉下来
   (直接吸会粘在磁铁上很难取下)
4. 反复吸2-3次,得到的就是比较纯的磁铁矿砂

⚠️ 有的黑砂含钛很多(钛铁矿),炉渣会变得很黏、难排出
   → 试炼一小炉,渣特别稠、出铁特别少,就换别处的矿
```

#### ② 赤铁矿 Fe₂O₃

**外观特征:**
- 颜色: 红褐色、钢灰色、黑色
- 光泽: 金属光泽(致密块状)或暗淡(土状)
- 条痕: **红色**(关键识别!)
- 硬度: 5.5-6.5

**识别方法:**
```
关键: 条痕颜色!
1. 在未上釉的白瓷板上摩擦
2. 留下樱桃红色或铁锈色条痕
3. 即使矿石本身是黑色,条痕也是红色

没有白瓷板时: 碗底、盘底一圈没上釉的粗瓷,或碎瓷片的断面都可以
```

**优点:**
- ✓ 含铁量高(50-60%)
- ✓ 分布广泛
- ✓ 易于粉碎

**分布:**
- 沉积岩地区
- 风化壳
- 红土层

#### ③ 褐铁矿 FeO(OH)·nH₂O

**外观特征:**
- 颜色: 褐色、黄褐色、黑褐色
- 光泽: 暗淡、土状
- 形态: 钟乳状、土状、致密块状
- 比重: 3.6-4.0(相对较轻)

**识别方法:**
```
特征:
- 黄褐色条痕
- 较轻,用手能感觉出
- 多孔,像土块
```

**缺点:**
- ✗ 含铁量较低(40-50%)
- ✗ 含水,冶炼时需烘干
- ✗ 多杂质

**优点:**
- ✓ 分布广,表层即有
- ✓ 易采集
- ✓ 新手入门选择

**分布:**
- 沼泽地
- 湖泊底部
- 古老风化壳

**沼铁矿(褐铁矿的一种)的线索:**
```
- 沼泽、湿地的水面上有一层像油膜一样的彩虹色薄膜
  (用棍子一戳会碎成小片的是铁的薄膜;油膜则会重新合拢)
- 溪沟底部、草根周围有橙红色的絮状沉淀
- 往下挖二三十厘米,能挖出褐色、多孔、像炉渣一样的硬块
→ 这就是古代北欧等地大量使用的炼铁原料

⚠️ 沼铁矿常含磷较多,炼出的铁冷的时候发脆(见 Q8)
```

### 1.2 简易鉴定流程

```
发现可疑矿石
     ↓
┌────┴────┐
│ 用磁铁测试 │
└────┬────┘
     │
  有磁性?
     │
 是 ↓          否 ↓
磁铁矿!      在白瓷板划痕
              ↓
          红色条痕?
              │
          是  ↓    否 ↓
         赤铁矿!  褐色条痕?
                     │
                 是  ↓
                褐铁矿!
```

**容易认错的石头:**

| 看起来像 | 怎样区分 | 能不能炼铁 |
|----------|----------|-----------|
| 黄铁矿(金黄色,俗称"愚人金") | 条痕黑绿色,敲碎或加热有硫磺臭味 | 不宜直接用,硫会让铁"红脆"(见 Q8) |
| 黑色玄武岩、页岩 | 拿在手里不压手,条痕灰白或无 | 不能 |
| 红色砂岩、红土 | 轻,条痕浅红,一捏就散,多是砂和黏土 | 含铁太少,炼不出 |
| 锰矿(黑色,常见树枝状花纹) | 条痕黑色,无磁性 | 少量混入无害,但不是铁矿 |
| 古代炉渣 | 表面有流淌、气泡的痕迹,断口像玻璃 | 有的含铁不少,但新手先别用 |

**判断"重不重"的简便方法:**
```
同样大小的石头,手掂: 磁铁矿、致密赤铁矿明显比普通石头重
  (普通岩石比重约2.6-2.8,好的铁矿约5)
更准一点: 一杆秤 + 一桶水
  1. 称出矿石在空气中的质量 A
  2. 用细绳吊着矿石浸没在水中再称,得到 B
  3. 比重 ≈ A ÷ (A - B)
  → 比重 4 以上的通常值得一炼;3 以下的多半杂质太多
```

更多矿物鉴定方法见[地质矿物与土壤-认识矿物](../08-基础科学知识/06-地质矿物与土壤.md#二认识矿物)。

### 1.3 采集要点

**优选矿点:**
- 矿石露出地表
- 矿层厚度>30 cm
- 含铁量高(颜色深、密度大)
- 距离居住地3-10 km(太近污染,太远运输累)

**采集工具:**
- 铁镐或尖锄(挖掘)
- 铁锤(敲碎)
- 簸箕或背篓(运输)
- 布袋(装碎矿石)

**采集量(首次):**
- 目标产铁: 2 kg
- 需要矿石:
  - 磁铁矿: 5-7 kg
  - 赤铁矿: 6-9 kg
  - 褐铁矿: 8-12 kg

```
为什么要这么多矿石?
- 好的磁铁矿含铁也只有六七成,还有石英、黏土等脉石
- 土法冶炼时,相当一部分铁和脉石结合成炉渣(铁橄榄石)流走,
  能变成金属铁的往往只有矿石含铁量的一半甚至更少
- 第一炉通常就是试验: 宁可多采一些,也不要炼到一半没料

采集安全:
⚠️ 不挖陡坎、悬崖底部的矿,不掏空坡脚(塌方会把人埋住)
⚠️ 废弃矿洞不要进(塌方、积水、缺氧和有毒气体)
⚠️ 雨后的土坡和沟壁先观察,有裂缝、落石不要挖
```

### 1.4 矿石处理

#### 步骤1: 粉碎
```
块状矿石 → 核桃大小
工具: 石锤、铁锤
时间: 1-2小时

大小的讲究:
- 通常打到核桃大小(约2-3 cm)
- 炉子内径只有二三十厘米的小炉,矿石最好再小一些:
  豌豆到花生大小(约0.5-1.5 cm),还原得更透
- 不要打成粉: 粉末堵塞炉料之间的缝隙,风吹不进去,
  还会被风吹出炉口
- 打碎后用筛子(或编得较稀的竹筐)筛掉粉末,粉末可以和少量
  黏土捏成小团晒干后再用

⚠️ 敲矿石时戴护目镜,碎屑会崩进眼睛;干燥的矿粉戴湿布口罩
```

#### 步骤2: 焙烧(去水、去硫)
```
针对: 褐铁矿、含硫矿石
方法:
1. 平铺在耐火砖/石板上
2. 堆木柴点燃加热
3. 焙烧2-4小时
4. 目的: 蒸发水分,氧化硫

怎样判断焙烧好了:
✓ 褐黄色的褐铁矿烧成红褐色到黑红色
✓ 矿石变得酥脆,一敲就碎(焙烧后再粉碎更省力)
✓ 不再冒白汽;含硫矿石不再有刺鼻的硫磺味

⚠️ 焙烧含硫矿石会放出二氧化硫(刺鼻、伤呼吸道)
   → 人站在上风处,远离住房、牲畜圈和菜地
⚠️ 焙烧过的矿石要放凉、存放在干燥处,下炉前不能再淋湿
```

#### 步骤3: 淘洗富集(可选)
```
1. 将碎矿石放入水槽
2. 加水摇晃
3. 轻的泥土流走
4. 重的铁矿石沉底
5. 可提升含铁量5-10%

淘洗后的矿石必须彻底晒干或烤干再入炉
```

淘洗和磁选的做法见[基础冶金知识-矿石富集](00-基础冶金知识.md#54-矿石富集)。

### 1.5 矿石的试炼

```
大规模采矿、建大炉之前,先用小炉试一下矿:
1. 取约1 kg粉碎好的矿石,在锻炉或小坩埚炉里和木炭一起烧
   (矿石和木炭交替铺,鼓风烧1-2小时)
2. 冷却后扒开: 看有没有灰色、能被磁铁吸起、锤打会变形的小铁粒
3. 有 → 这个矿点值得开采;
   全是玻璃状的渣、没有铁粒 → 矿太贫,或含钛、杂质太多,换矿点

记录每次试炼的: 矿点位置、矿石种类、处理方式、木炭用量、结果
→ 炼铁的经验大部分来自这样的记录
```

## 二、炼铁炉建造

### 2.1 简易竖炉(推荐)

**规格:**
- 高度: 120-150 cm
- 内径:
  - 炉缸(风口以下,出铁口所在): 20 cm
  - 炉腹(风口以上,向下收窄): 25 cm
  - 炉腰(最宽): 40 cm
  - 炉顶(装料口): 30 cm
- 壁厚: 20-30 cm

**剖面图:**
```
     [俯视顶部]
      ┌─────┐
      │ 30 cm│ ← 装料口
      └─────┘

     [剖面侧视]
      ╔═══╗ ← 装料口(30 cm)
      ║   ║
      ║   ║ ← 炉身(120 cm)
     ╔╝   ╚╗
    ╔╝     ╚╗ ← 炉腰(最宽40 cm)
    ║   ●   ║ ← 风口(25 cm高度)
    ╚╗  ↑  ╔╝
     ╚╗   ╔╝ ← 炉腹(收窄到25 cm)
      ║   ║
      ╚═══╝ ← 炉缸、炉底
       \_/
      出铁口
```

**关键尺寸解释:**
- **炉腰**: 最宽处,矿石和燃料充分反应区
- **炉腹**: 向下收窄,炉料熔化后体积缩小,收窄能让炉料始终贴紧、继续下沉
- **风口**: 鼓风进入位置,距炉底20-30 cm

```
各部位的叫法(本章采用通行的高炉术语):
炉喉(装料口)→ 炉身 → 炉腰(最宽)→ 炉腹(收窄)→ 炉缸(风口以下)

块炼法用的炉子可以更简单:
- 直筒形,内径25-35 cm,高100-150 cm
- 不需要很高的炉身和收窄的炉腹
- 风口以下留出15-20 cm的空间,让海绵铁块在这里长大

炉子不要太大: 内径越大,需要的风量增加越快(大致和截面积成正比),
  人力风箱带不动时,炉温反而上不去
```

**风口和出渣口:**
```
风口:
- 墙上预留的孔(直径8-12 cm)里插一根耐火黏土烧成的风管,
  风管内径约2-3 cm
- 风管稍向下倾斜(约15-25°),伸进炉内几厘米,
  对准炉膛中心偏下的位置
- 风管和风箱之间不要接死,留一点缝隙,防止热气倒吸进风箱

出渣口 / 出铁口:
- 位置在炉底前方,平时用一团湿黏土塞住
- 炉前挖一个比出口低的浅坑,铺干沙,用来接渣、接铁

炉前场地:
- 炉子周围3 m内清除干草、木屑;炉前留出能后退的空地
- 头顶搭一个高一些的防雨棚,四面敞开通风
- 风箱放在风口的侧后方,鼓风的人不正对出渣口
```

风箱的种类、做法和风管的详细要求见[鼓风设备与锻炉](08-鼓风设备与锻炉.md)。

### 2.2 耐火材料配制

**普通黏土不行!必须用耐火材料!**

#### 耐火黏土配方A(推荐):
```
成分:
- 铝矾土(或高岭土): 50%
- 石英砂: 30%
- 耐火黏土: 15%
- 碎耐火砖(如有): 5%
- 水: 适量
```

**铝矾土/高岭土在哪找?**
- 瓷土矿区
- 白色/灰白色土层
- 摸起来细腻,吸水性强

#### 耐火黏土配方B(简易):
```
成分:
- 黄黏土: 40%
- 砂子: 30%
- 碎砖/陶片(粉碎到米粒大小): 25%
- 切碎的干草、稻壳或干马粪: 5%(防止开裂;烧掉后留下细孔,更隔热)

⚠️ 不要往炉衬里加食盐、生石灰、草木灰:
   它们是助熔剂,会让黏土在高温下变软、熔化,反而降低耐火度
```

**制作:**
1. 混合干料
2. 加水调至可塑
3. 反复践踏、揉捏30分钟
4. 静置24小时"腐化"(更均匀)

**怎样判断耐火泥合格:**
```
可塑性: 搓成手指粗的泥条,弯成圆圈不断、只有细小裂纹 → 合适
   一弯就断 → 砂太多,加黏土;粘手、表面发亮 → 黏土太多,加砂和熟料

收缩试验: 做一块10 cm长的泥条,阴干后量一量
   收缩超过1 cm(10%)→ 干燥时容易开裂,多加砂和熟料

耐火试验(最可靠):
   做几块小泥饼,放进锻炉最热的地方鼓风烧1小时
   ✓ 形状不变、只是变硬变色 → 可用
   ✗ 发亮起釉、变软塌陷、起泡 → 耐火度不够,换更白、更细的黏土

黄黏土配方B只适合炉子外层和炉身上部;
  风口附近和炉缸这些最热的部位,尽量用配方A或白色黏土加大量熟料
```

耐火材料的原理见[工程力学与材料-陶瓷和耐火材料](../09-进阶科学与工程/01-工程力学与材料.md#105-陶瓷和耐火材料);找白色黏土见[陶瓷玻璃与造纸](../07-日常生活技能/11-陶瓷玻璃与造纸.md)。

### 2.3 建炉步骤

**第1天: 砌筑**
1. 选址: 空旷、通风、远离建筑
2. 地基: 石块垫高50 cm,防潮
3. 内模: 用木桶或草编筐作模型
4. 外墙: 一边砌黏土,一边抽出内模
5. 风口: 预留直径8-12 cm的孔

```
砌筑的细节:
- 选址避开低洼积水处和地下水位高的地方(炉底受潮会出事故)
- 地基石块上先铺一层干沙和碎陶片,再夯一层耐火泥作炉底
- 泥要一层一层往上加,每层10-15 cm,用拳头和木槌捶实,
  和下一层之间先刮毛、洒一点泥浆再接,防止分层
- 草编筐内模可以不抽出,烘炉时自己烧掉
- 炉壁可以分两层: 内层耐火泥约10 cm,外层用普通草泥、石块加厚保温
- 炉子外面可以箍几道铁丝或藤条,减少开裂后炸开的危险
```

**第2-7天: 干燥**
- 自然阴干5天(重要!)
- 不可阳光暴晒
- 下雨需遮盖

```
为什么要阴干: 外面干得快、里面还湿,收缩不均就开裂
- 头两天用湿草帘盖住,让它慢慢干
- 炉膛里可以挂一盏油灯或放一小盆炭火,从里面微微烘
- 用手指按炉壁,按不出印、颜色变浅且均匀 → 表面干了
  (内部仍要靠烘炉排出水分)
```

**第8-10天: 烘炉**
- 第1天: 小火烘烤2小时,停火,重复3次
- 第2天: 中火烘烤4小时
- 第3天: 大火烘烤6小时
- 看到炉壁微微发红即可

```
烘炉时炉壁冒出大量白汽是正常的,说明水分在排出
- 小火阶段用柴火或少量木炭,不鼓风
- 升温太快 → 内部水分变成蒸汽,会把炉壁炸开一块
- 摸外壁: 从冰凉变成烫手且干燥、不再冒汽 → 基本烘透
```

**第11天: 检查**
- 检查有无裂缝
- 裂缝<2 mm: 不管
- 裂缝>2 mm: 用耐火泥填补
- 风口畅通

```
补裂缝: 先把裂缝刮宽、刷湿,塞进耐火泥压实,再小火烘干
⚠️ 贯穿炉壁、能透光的裂缝,或炉缸部位的裂缝要拆掉重砌那一段
   → 冶炼时铁水和炉渣可能从这里漏出来
```

## 三、炼铁实战

### 3.0 两条路线: 块炼法 vs 生铁法

| 对比项 | 块炼法(推荐新手) | 生铁法(本章3.1-3.3) |
|--------|------------------|---------------------|
| 炉温 | 1100-1300°C | 1300-1400°C |
| 铁的状态 | 不熔化,得到海绵状铁块 | 熔化成铁水流出 |
| 产物 | 含碳低,接近熟铁,可直接锻打 | 生铁,很脆,需再炒炼成熟铁 |
| 难度 | 较低 | 较高(鼓风要求高) |

**块炼法要点:**
- 使用同样的竖炉、矿石和木炭,鼓风强度可以低一些
- 炉温保持在橙红到黄色(约1200°C),铁不会熔化
- 冶炼结束后从炉底扒出夹杂炉渣的海绵铁块
- 趁红热反复锻打,挤出炉渣、压实成块,即得熟铁
- 古代早期炼铁(包括中国春秋时期以前)主要采用此法

```
炉子里在发生什么(简化):
1. 风口附近: 木炭燃烧 C + O₂ → CO₂,放出大量热
2. 往上一点: 炽热的木炭把 CO₂ 变成一氧化碳 CO₂ + C → 2CO
3. 炉身中部: 一氧化碳从矿石中夺走氧
   Fe₂O₃ + 3CO → 2Fe + 3CO₂
   铁在固态下被还原出来,像海绵一样多孔
4. 脉石(石英等)和一部分氧化铁结合成炉渣,熔化后往下流
5. 块炼法: 海绵铁颗粒在风口下方粘结成一块"铁坨"(铁块中夹着渣)
   生铁法: 炉温更高、铁在炉中停留更久,吸收大量碳后熔点降到
           约1150°C,变成铁水流到炉底

→ 所以木炭既是燃料,又是还原剂;风小了温度不够,
  风太猛、木炭太少则炉内氧气过多,已还原的铁又被烧回成氧化铁
```

化学原理见[化学](../08-基础科学知识/03-化学.md)。

**以下3.1-3.3为生铁法流程。**

### 3.1 材料准备

**单次冶炼(目标: 2 kg铁):**

| 材料 | 用量 | 备注 |
|------|------|------|
| 铁矿石 | 6-10 kg | 已粉碎 |
| 木炭 | 6-10 kg | 优质硬木炭 |
| 石灰石 | 0.5 kg | 助熔剂,降低熔点 |
| 备用木炭 | 5 kg | 以防万一 |

```
木炭:
- 用硬木(栎、青冈、槐等)烧的木炭最好,敲起来声音清脆
- 敲成2-3 cm的小块,筛掉碎末(碎末堵塞透气)
- 必须干燥: 淋过雨的木炭烤干再用
- 预热和最后保温也要烧掉不少木炭,
  加上备用量,一炉总用量常是产铁量的好几倍

石灰石:
- 敲成指头大小;用醋或酸菜水滴上去会冒泡的白色、灰色石头
- 作用: 和矿石里的石英结合成容易流动的炉渣,让铁和渣分开
- 块炼法可以少加或不加: 矿石里的氧化铁本身就和石英结成渣
  (代价是一部分铁进了渣里)
```

木炭的烧制和质量检验见[基础冶金知识-燃料制作](00-基础冶金知识.md#三燃料制作)。

**其他准备:**
- 水(2桶): 灭火、冷却
- 长柄钳: 夹持
- 长柄铁勺: 舀渣
- 沙土(1堆): 应急灭火
- 铁桶: 接铁水

```
还应准备:
- 防护: 皮手套、护目镜、皮或厚帆布围裙、包住脚面的鞋、帽子
- 一根长约1.5 m的铁钎(捅出渣口、探炉底)
- 一把木槌和几块平整的大石或铁砧(块炼法锻合铁坨用)
- 湿黏土团若干(堵出渣口、补漏)
- 照明(冶炼常常拖到夜里)
- 记录本: 每批加料的时间、数量和现象
- 饮水和食物: 鼓风的人出汗很多,每1-2小时喝一次水,
  适量加盐,防止中暑和抽筋
```

### 3.2 操作流程

#### 阶段1: 预热炉子(1-2小时)

```
1. 炉底铺木炭(10 cm厚)
2. 点火
3. 开始鼓风
4. 温度升至600-700°C(暗红色)

预热的要点:
- 先在炉底点着一小堆干柴,再加木炭,先自然通风烧旺
- 然后轻鼓风,逐渐加木炭到半炉高
- 炉壁里残留的水分在这一阶段排出,外壁会冒汽
- 预热不够就加矿石,炉子"冷",矿石下来会把火压灭
```

**鼓风节奏:**
- 1人: 每5秒鼓1次
- 2人轮换: 持续鼓风

```
鼓风的要领:
- 均匀比猛烈更重要: 一阵猛一阵停,炉温上下波动,还原不稳定
- 每人连续鼓风20-30分钟就换人,换人时不要停风
  (双风箱或双作用活塞风箱可以做到连续不断)
- 听声音: 风口"呼呼"均匀;突然变成闷响、风箱发硬,
  可能是风口被渣堵住,要用铁钎从风口捅通
- 看风口: 透过风管能看到炉内亮黄色 → 正常;
  变暗红 → 风口前结了渣或缺木炭
```

风量不足时怎样改进风箱见[鼓风设备与锻炉](08-鼓风设备与锻炉.md)。

#### 阶段2: 装料(分批进行)

**装料顺序(循环):**
```
第1批:
1. 加木炭(1层,3-5 cm厚)
2. 加矿石(1层,3-5 cm厚)
3. 加少量石灰石(1小把)
4. 继续鼓风5分钟

重复装料8-10批,装满炉身
```

**关键要点:**
- 木炭和矿石交替
- 木炭略多于矿石
- 不要一次装满(窒息)
- 边装料边鼓风

```
更细的做法:
- 头两三批矿石少放(约正常量的一半),让炉子先适应
- 以后按"炉料下降多少就补多少"的节奏加,一般每10-20分钟一批
- 矿石均匀撒在木炭层中间,不要全堆在一侧贴着炉壁
- 加料时人站在炉口侧面,别把脸凑到炉口上方
  (炉口冒出的是一氧化碳和热气,常有蓝色火苗)
```

#### 阶段3: 冶炼反应(6-10小时)

**持续鼓风!**
- 风力要稳定
- 不能停止(温度会骤降)
- 人员轮换

**温度管理:**
```
目标温度: 1300-1400°C
颜色判断: 黄色到亮黄色

温度不足:
- 加大鼓风
- 增加木炭

温度过高(罕见):
- 减少鼓风
- 停止加料

块炼法: 炉温保持橙红到黄色(约1200°C)即可,不要追求更高
```

温度和颜色的对照表见[基础冶金知识-判断温度](00-基础冶金知识.md#41-判断温度)。

**现象观察:**

| 时间 | 现象 | 说明 |
|------|------|------|
| 1-2小时 | 浓烟,刺鼻 | 矿石加热,挥发杂质 |
| 3-4小时 | 烟少,炉内明亮 | 进入还原阶段 |
| 5-6小时 | 偶尔火星飞出 | 铁开始熔化 |
| 7-8小时 | 炉底发亮 | 铁水聚集 |

**排渣(每1-2小时一次):**
```
炉渣在炉底越积越多,会把风口淹没,必须定时放出来
1. 估计渣快到风口高度时(风口发暗、鼓风变闷),准备放渣
2. 人站在出渣口侧面,用铁钎捅开出渣口的黏土塞
3. 黑红色、像糖稀一样的炉渣流进炉前的沙坑
4. 渣流变慢、开始冒出亮黄色火焰时,用湿黏土团重新堵上

判断炉况:
✓ 渣流动顺畅,冷后黑色、断口玻璃状、比较重 → 正常
✗ 渣很稠流不出来 → 炉温低,或矿里钛、黏土多;加大鼓风、加石灰石
✗ 渣里夹着许多亮晶晶的铁珠 → 铁随渣流失,出渣过早或炉温不稳

⚠️ 刚流出的渣面上很快结一层黑壳,下面仍是液体,不要踩、不要用手碰
```

**补料:**
- 炉料下降时,继续添加
- 保持炉腰以上充满
- 木炭消耗快,及时补充

**一氧化碳的防范(全程):**
```
- 所有人站在上风处;风向变了,人跟着换位置
- 加料、看炉口的人做完就退开,不要在炉口上方停留
- 每个人都留意自己和同伴: 头痛、头晕、恶心、乏力、犯困、反应变慢
  → 立即离开到上风处的新鲜空气中,换人顶替
- 两人以上同时出现症状、有人意识模糊或昏倒 → 当作一氧化碳中毒,
  先把人移到新鲜空气处,有条件马上就医
- 夜间守炉至少两人,互相叫醒对方说话
```

#### 阶段4: 出铁(关键!)

**判断完成:**
- 炉底出铁口发亮
- 用铁棍探入,有液态感觉
- 时间已达8小时+

**出铁步骤:**
```
1. 准备接铁容器(干燥!)
   - 地面挖坑铺沙
   - 或用耐火砖砌槽

2. 打开出铁口
   - 用铁棍捅开堵塞的黏土
   - 铁水会流出

3. 分离铁和渣
   - 铁水(重)在底部
   - 渣(轻)浮在上面
   - 用铁板或木板挡住渣

4. 铸锭或铸块
   - 倒入沙模
   - 或直接倒在沙地上成薄饼状(便于后续加工)
```

**⚠️ 安全警告:**
- 铁水温度1200-1400°C,极度危险!
- 保持2 m安全距离
- 绝对不能接触水!
- 准备好灭火沙

```
出铁前再确认一遍:
- 沙坑、沙模、挡渣板、铁钎提前在火边烤至少20分钟,摸上去烫手、干燥
- 地面没有积水;天要下雨就推迟出铁,先保温
- 无关的人(尤其是孩子)退到5 m以外
- 捅出铁口的人戴护目镜、手套,站在侧面,捅开后立即后撤

如果有人被铁水或炉渣溅到:
1. 衣服着火: 立即躺倒打滚或用厚毯子压灭,不要奔跑
2. 已经凝固在皮肤上的金属不要硬撕,连同周围冲凉水
3. 用清洁的凉水冲洗烫伤处15-20分钟
4. 用干净的布松松盖住,不涂牙膏、酱油、草木灰
5. 面积大于伤者一个手掌、伤到脸、手、脚、关节或眼睛 → 尽快送医
```

烧伤的程度判断和处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤)。

#### 阶段5: 冷却(2-4小时)

```
铁块在模具中:
- 自然冷却
- 不要浇水(会炸裂)
- 等待变成暗红色后可移动

炉子:
- 停止鼓风
- 让炉火自然熄灭
- 等待12小时后清理

⚠️ "看起来不红了"不等于凉了: 暗处看不见红光的铁仍可能有400-500°C
   → 用一滴水试(离远一点): 滋滋作响立即蒸发,就还很烫
⚠️ 熄火后的炉内仍在产生一氧化碳,不要把头伸进炉口
⚠️ 炉渣、残炭堆在远离柴草的沙地上,第二天确认完全熄灭
```

### 3.3 首次成果

**你得到的是: 生铁**

**生铁的特性:**
- 含碳量: 2-4%
- 硬度: 很硬
- 脆性: 很脆,一砸就碎
- 颜色: 灰白色(铸铁)或白色(白口铁)
- **不能锻造!**

**能做什么?**
- ✓ 铸造成型(熔化后倒模)
- ✓ 制作铁锅、犁铧(耐磨损)
- ✗ 不能锻打成刀、斧(会碎)

**需要进一步精炼成熟铁或钢!**

```
怎样判断这一炉炼出了什么:
- 冷后敲断看断口:
  灰色、颗粒粗 → 灰口铸铁(还能锉动、能铸造)
  白亮、闪光、极硬 → 白口铁(适合拿去炒成熟铁)
- 烧红后锤一下: 碎成几块 → 生铁;能压扁 → 熟铁或低碳钢
- 一部分是海绵状、夹着渣的块 → 炉温不够,其实是块炼铁(见3.4)
```

生铁的铸造见[铸造进阶-铸铁](07-铸造进阶.md#七铸铁)。

### 3.4 块炼法的出炉与锻合

块炼法得到的是一团夹着炉渣、木炭的海绵铁("铁坨"),要趁热把它锻合成致密的熟铁。这是块炼法最费力、也最容易失败的一步。

```
1. 出炉
   - 最后一批矿石加完后,继续鼓风30-60分钟,让上面的矿石也还原完
   - 停止加料,拆开炉前的出铁口(块炼炉常把这一段砌成可拆的)
   - 用长钳和铁钎把炉底那团最重、发亮的铁坨撬出来
   - 用木槌把铁坨表面松散的渣和木炭敲掉

2. 初锻(最关键,要快)
   - 趁铁坨还是黄色到橙色时,先用木槌或很轻的铁锤轻轻拍
   - 开始用力过猛,海绵铁会碎成好几块
   - 拍打中会挤出发亮的液态渣,渣点四溅 → 戴护目镜、围裙
   - 颜色降到暗红就停,回炉加热

3. 反复加热锻打
   - 放进锻炉或冶炼炉上部加热到黄色,再锻,每次逐渐加大力度
   - 把铁坨压成厚块,再切开、对折、锻合
   - 通常要来回十几次,直到断面基本看不到渣和孔洞

4. 检验
   - 锻合好的铁块敲起来声音清亮,不是"噗噗"的闷声
   - 烧红后能弯折、不沿渣线裂开 → 合格

损耗: 锻合中会去掉大量渣并有氧化损失,
  最后得到的熟铁常常只有铁坨质量的一半左右
```

锻打的基本手法见[简易工具锻造](03-简易工具锻造.md)。

## 四、从生铁到熟铁

### 4.1 原理

```
生铁(含碳2-4%)
    → 去碳
      → 熟铁(含碳<0.2%)
```

**目的:** 去除碳,增加韧性,便于锻造

```
为什么搅拌能去碳:
- 铁水里的碳和空气中的氧结合,变成一氧化碳、二氧化碳跑掉
- 碳越来越少,铁的熔点越来越高(纯铁约1538°C),
  炉温不变的情况下,铁水就会逐渐变稠、凝固成团
- 所以"由稀变稠"本身就是去碳成功的标志

代价: 一部分铁也被氧化成铁渣,所以越炒越少(见 Q6)
```

### 4.2 方法A: 炒钢法(推荐)

**设备:**
- 浅盘状炉子(炒锅状)
- 鼓风装置

```
炒炉的做法:
- 地上挖一个直径约40-50 cm、深约20-25 cm的浅坑,
  内壁抹耐火泥并烘干
- 侧面开一个风口,稍向下对准坑的中部
- 小炉每次炒1-3 kg生铁比较好控制
```

**步骤:**

**1. 装炉:**
- 炉底铺木炭
- 点火鼓风至高温

**2. 化生铁:**
- 将生铁块放入炉中
- 鼓风加热至熔化
- 温度: 1300-1400°C

```
- 生铁先打成鸡蛋大小的碎块,化得快
- 碎块放在木炭上面、正对风口的位置
- 白口铁比灰口铁更适合炒: 含硅少,去碳快
```

**3. 搅拌(关键!):**
```
用长铁棍不断搅动铁水:
- 目的: 让铁水充分接触空气
- 反应: C + O₂ → CO₂ (碳被氧化烧掉)
- 时间: 持续30-60分钟
- 现象:
  * 火花四溅
  * 逐渐变稠(碳少,熔点升高)

搅拌的人:
- 铁棍至少1.5 m长,前端可以弯一个小钩
- 戴护目镜、手套,站在侧面,不正对风口
- 铁棍头部会被烧掉、粘铁,准备两三根轮换
```

**4. 观察变化:**
```
铁水 → 铁浆(半固态) → 铁坨(固态团块)

火花的变化也能判断进度:
- 开始: 铁水表面火花多、爆得响(碳多)
- 后来: 火花越来越少
- 铁团揉在一起、像面团一样能被铁棍挑起 → 可以出炉
```

**5. 取出锻打:**
- 用钳子夹出铁坨(趁热!)
- 放在砧上快速锤打
- 目的:
  * 打出残渣
  * 压实铁块
  * 整形

**6. 反复加热锻打:**
- 加热至橙红色
- 锤打
- 重复3-5次

**成品: 熟铁(锻铁)**
- 含碳<0.2%
- 软,韧性好
- 可以锻造成各种形状
- 不易折断

```
炒钢的火候:
- 搅得早停、炉温偏低时,铁团里还残留较多碳 → 得到的是钢而不是熟铁
- 我国汉代的"炒钢"正是利用这一点: 有经验的工匠控制火候,
  直接炒出含碳适中的钢
- 新手先炒到熟铁(结果更稳定),需要钢时再按第五节渗碳
```

### 4.3 方法B: 吹炼法

**原理:** 在熔融生铁中吹入空气,氧化碳

**设备:**
- 坩埚(耐火黏土制)
- 耐火黏土烧成的风管或铁管(铁管会被烧掉一截,属于消耗品)

**步骤:**
1. 坩埚中熔化生铁
2. 插入风管,深入铁水
3. 风管接风箱鼓风(绝不能用嘴吹)
4. 碳被氧化,铁水翻腾
5. 持续20-40分钟
6. 倒出锻打

**缺点:** 危险,容易飞溅

```
⚠️ 为什么本书不推荐新手用吹炼法:
- 吹入的空气在铁水中剧烈反应,铁水会翻腾、喷溅出坩埚
- 小坩埚里的铁水散热快,碳一减少就凝固,常常卡住风管
- 竹管等含水的材料插入铁水会引起蒸汽爆炸 → 绝对不可用
- 坩埚在高温下被铁水和氧化铁侵蚀,可能突然破裂

如果要尝试: 只用很少量(几百 g),坩埚放在沙坑里,
  人在侧面用长柄操作,周围5 m内不留人
```

### 4.4 熟铁检验

**方法:**
```
1. 锻打测试:
   - 加热至红色
   - 锤打能延展成薄片
   - 不开裂 → 熟铁✓
   - 碎裂 → 生铁,需继续精炼

2. 弯曲测试:
   - 常温下弯曲铁条
   - 能弯90°不断裂 → 熟铁✓
   - 折断 → 生铁

3. 火花测试:
   - 在砂轮上打磨
   - 熟铁: 火花长、黄白色,分叉很少
   - 生铁: 火花短、暗红到橙色,末端只有少量小分叉
   - 钢: 介于两者之间,含碳越高分叉越多、越密
   - 拿一块已知的钢筋、锉刀对比着看更准
```

```
熟铁的另一个特征: 纤维状断口
- 把熟铁条锯开一个口,在台钳上反复弯折至断
- 断口呈木头一样的纤维状(夹渣被锻成一丝一丝)→ 典型的熟铁
- 断口呈细小亮晶粒 → 含碳较多,可能已经是钢
```

各种金属火花的详细对照见[废旧金属回收与铝铸造-火花鉴别](05-废旧金属回收与铝铸造.md#22-火花鉴别砂轮或粗锉打磨)。

## 五、炼钢技术

### 5.1 什么是钢?

**钢 = 含碳0.2-2%的铁**

- 比生铁含碳少(不脆)
- 比熟铁含碳多(更硬)
- **既硬又韧,制刀最佳!**

| 种类 | 含碳量(大致) | 特点 | 适合做 |
|------|---------------|------|--------|
| 熟铁 | <0.2% | 软、韧,不能淬硬 | 钉子、铁丝、链环、铰链、箍 |
| 低碳钢 | 约0.2-0.3% | 韧性好,淬火变硬不明显 | 一般铁件、铁板 |
| 中碳钢 | 约0.3-0.6% | 强度和韧性兼顾 | 斧、锤、锄、轴 |
| 高碳钢 | 约0.6-1.5% | 淬火后很硬,较脆 | 刀、凿、锉、弹簧 |

```
钢最大的价值在于能淬火: 加热到约780-850°C后急冷,硬度大增
  → 熟铁怎么淬都不硬,这就是为什么熟铁要渗碳成钢才能做刃口
```

钢的组织和热处理原理见[工程力学与材料-铁和钢](../09-进阶科学与工程/01-工程力学与材料.md#102-铁和钢-碳决定一切)。

### 5.2 方法: 渗碳法

**原理:** 让熟铁吸收碳

#### 固体渗碳法(简单)

**材料:**
- 熟铁块
- 木炭粉
- 密封容器(铁盒或陶罐)

**步骤:**

**1. 准备渗碳剂:**
```
木炭粉: 80%
草木灰: 10%
食盐: 10%
(混合均匀)

- 木炭粉用硬木炭碾碎,粗细像小米到绿豆
- 草木灰起促进作用,让渗碳更快
- 渗碳剂用过一次后效果变差,下次掺入一半新料
```

**2. 装填:**
```
铁盒/陶罐内:
底部铺渗碳剂(3 cm)
  ↓
放入熟铁块
  ↓
周围填满渗碳剂
  ↓
顶部覆盖渗碳剂(3 cm)
  ↓
密封(用黏土糊严)

- 工件之间、工件和罐壁之间至少隔2 cm渗碳剂
- 同时放一根同样材料的小铁条作"试样",方便检查
- 黏土封口留一个筷子粗的小孔,让气体能排出,防止胀裂
```

**3. 加热:**
- 将密封容器放入炉火中
- 加热至900-1000°C(橙红色)
- 保温4-12小时
  - 薄件(刀片): 4-6小时
  - 厚件(斧头): 8-12小时

```
保温时的注意:
- 罐子烧透需要时间: 从整个罐子都发出均匀的橙红色时开始计时
- 炉温不要忽高忽低;每隔一段时间添木炭、转动罐子,让各面受热均匀
- 小孔冒出的蓝色火苗是一氧化碳在燃烧,属于正常现象
  (同样意味着周围有一氧化碳,人站在上风处)
```

**4. 冷却:**
- 随炉慢冷
- 或取出空冷

**5. 检查:**
- 打开容器
- 铁表面应呈灰黑色
- 硬度明显增加

```
最可靠的检查: 用试样
1. 取出试样,加热到樱桃红(约800°C),投入水中淬火
2. 用锉刀锉: 锉刀打滑 → 表面已渗碳成钢 ✓
   能轻松锉动 → 渗碳不足,延长时间重来
3. 把试样敲断看断口: 外圈是细密发亮的一层(钢),
   中间是较粗的灰色(熟铁),外圈的厚度就是渗碳深度
```

**成品: 钢!**
- 表面渗碳深度: 约0.3-1.5 mm(随保温时间增加)
- 外硬内韧(最佳状态!)

```
渗碳后的工件还要淬火、回火才真正变硬又不易崩:
- 淬火: 加热到约780-850°C(樱桃红至鲜红),投入水或油中
- 回火: 淬火后再加热到较低温度,去掉脆性
- 渗碳层很薄: 磨刃口时不要磨穿,否则露出里面的熟铁就不硬了
```

渗碳深度与时间的对照、淬火回火的具体操作见[金属加工技术](04-金属加工技术.md)。

#### 液体渗碳法(快速)

**步骤:**
1. 熟铁加热至1000°C(橙黄色)
2. 迅速插入木炭粉中
3. 表面吸收碳
4. 再加热、再插入
5. 重复5-10次
6. 淬火(快速冷却)

**优点:** 快
**缺点:** 渗碳深度浅

```
- 这种做法渗入的碳很少,渗层只有约0.1-0.3 mm,
  只适合不常磨的小件(钉子、小凿子)做表面硬化
- 工厂里真正的"液体渗碳"是把工件泡在含氰化物的熔融盐浴里,
  氰化物剧毒 → 不要尝试
```

### 5.3 其他得到钢的途径

```
1. 炒钢时控制火候(见4.2): 不炒到底,得到含碳适中的钢
2. 夹钢、贴钢: 熟铁做刀身,只在刃口夹一条或贴一片钢,
   锻合在一起 → 省钢,刀身韧、刃口硬,是古代农具和刀具的常用做法
3. 利用废钢: 锉刀、弹簧、钢板弹簧、轴承本身就是高碳钢,
   回收来锻打成刃口,比自己渗碳省事得多
```

夹钢的做法见[简易工具锻造-高级技巧](03-简易工具锻造.md#十一高级技巧);废钢的挑选见[废旧金属回收与铝铸造](05-废旧金属回收与铝铸造.md)。

## 六、常见问题与故障

### Q1: 炉温上不去,一直不到1300°C?

**原因:**
- ✗ 鼓风不足
- ✗ 炉壁太薄,散热快
- ✗ 炉顶开口太大
- ✗ 木炭质量差

**解决:**
- ✓ 加强持续鼓风
- ✓ 加厚炉壁或外围再砌一层
- ✓ 炉顶部分封闭
- ✓ 更换木炭

```
逐项排查:
- 风管和风箱接口漏气: 用手在接口处感觉有没有风往外冒
- 风口位置太高或太浅: 风没吹到炉缸中心,只吹到炉壁
- 木炭块太碎、太湿: 透气差,热量都用来蒸发水
- 炉膛太大: 同样的风箱,炉子越大温度越低 → 先缩小炉子
- 矿石一次加得太多: 冷料压住了火
```

### Q2: 冶炼8小时,没有铁水出来?

**可能原因:**
1. **温度不够**
   - 检查炉内颜色,应为黄白色
   - 增强鼓风

2. **还原不充分**
   - 木炭与矿石比例不对
   - 增加木炭用量

3. **铁成海绵状,未熔化**
   - 正常现象!这就是块炼法的产物(见3.0)
   - 取出炉料,挑出海绵铁块
   - 反复加热锻打,压实成块,得到可直接使用的熟铁

4. **铁都进了炉渣**
   - 渣黑而重、流得很稀,但几乎没有铁 → 矿石里石英多、炉温又不稳,
     氧化铁和石英结成了渣
   - 多加石灰石,矿石淘洗得更干净,炉内保持木炭充足

### Q3: 出铁时爆炸飞溅?

**原因:** 水气!
- 出铁口潮湿
- 接铁容器不干燥
- 地面有积水

**预防:**
- 所有接触铁水的部分彻底烘干
- 提前用火烤20分钟

```
还有两个容易忽视的水源:
- 堵出渣口、出铁口的湿黏土: 用前捏成团在炉边烤到半干
- 生锈、潮湿的铁工具: 锈里含水,伸进铁水前先在火上烤热

一旦发生飞溅: 所有人立即后撤,不要去抢救铁水;
  先检查有没有人被烫伤、衣服着火
```

### Q4: 得到的铁质量很差,杂质多?

**原因:**
- 矿石品位低
- 炉渣混入

**改进:**
- 矿石淘洗富集
- 添加足够石灰石(助熔剂)
- 出铁时仔细分离渣

### Q5: 一次只能得到几百 g铁,太少?

**正常!**
- 小型炉单次产量: 0.5-3 kg
- 中型炉: 5-10 kg
- 大型炉(需多人): 20-50 kg

**提高产量:**
- 扩大炉子
- 提高装料量
- 多建几座炉,同时作业

```
扩大规模前先算一下木炭: 炉子大一倍,木炭、鼓风的人力都要跟着翻倍
  → 先把小炉的出铁率稳定下来(每炉都有铁),再考虑扩大
```

### Q6: 生铁精炼成熟铁时,铁块越炒越少?

**正常现象!**
- 碳被氧化烧掉
- 部分铁被氧化成铁渣
- 损失率: 10-30%
- 这就是为什么要多炼铁

### Q7: 风口被堵、炉子烧穿或出口冻住?

```
风口被渣堵住(风箱发硬、风口发暗):
- 用铁钎从风管口往里捅,把风口前的渣打碎
- 经常堵 → 出渣不及时,或风口位置太低

炉壁烧穿(外壁出现亮红色斑点,甚至有渣渗出):
- 人立即离开那一侧,停止鼓风
- 从外面用湿黏土加干土厚厚糊住,降低风量继续;
  漏得多就只能停炉,放凉后拆修

出渣口、出铁口冻住(捅不开或流出一点就凝固):
- 炉缸温度太低 → 先加木炭、加大鼓风半小时再试
- 出口太小 → 用铁钎扩大;下一炉把出口做大、做低
```

### Q8: 炼出的铁一锻就裂?

| 现象 | 可能原因 | 怎么办 |
|------|----------|--------|
| 烧红锻打时开裂,冷了反而不太裂("红脆") | 硫多(矿石含黄铁矿、用了煤) | 矿石充分焙烧;只用木炭,不用未经炼焦的煤 |
| 常温下一敲就断,断口亮晶晶("冷脆") | 磷多(沼铁矿常见) | 换矿;或只用来做不受冲击的东西(钉子、铁箍) |
| 沿着一条条黑线裂开 | 夹渣没锻出来 | 加热到更高温度(黄色)再锻,多折叠锻合几次 |
| 越锻越碎,像饼干 | 其实是生铁或白口铁 | 先按第四节炒成熟铁 |
| 锻打时表面起皮、掉渣、越打越小 | 加热太久,氧化严重 | 加热时埋在木炭里、风不要直吹工件,到温度就锻 |

## 七、时间与资源评估

### 单次炼铁完整流程:

| 阶段 | 时间 | 人力 |
|------|------|------|
| 建炉 | 7-10天 | 2-3人 |
| 采矿 | 1-2天 | 2人 |
| 制木炭 | 5-7天 | 1-2人 |
| 预处理矿石 | 1天 | 1人 |
| 冶炼 | 10-14小时 | 2-3人(轮换) |
| 冷却 | 12小时 | 无需看管 |
| **总计** | **约3周** | **2-3人团队** |

```
炉子能用很多次: 第二炉起,只需修补炉衬1-2天,
  整个周期主要取决于木炭和矿石的准备
```

### 资源消耗(单次):

| 资源 | 用量 | 获取难度 |
|------|------|----------|
| 木材(制木炭用) | 50-80 kg | ⭐⭐ |
| 黏土 | 100 kg | ⭐ |
| 铁矿石 | 6-12 kg | ⭐⭐⭐ |
| 石灰石 | 1 kg | ⭐⭐ |

### 产出:
- 生铁: 1-3 kg
- 精炼后熟铁: 0.7-2 kg

```
木材是真正的瓶颈:
- 烧1 kg木炭约需3-5 kg木材(简陋土窑更多)
- 炼1 kg铁通常需要几 kg 到十几 kg 木炭,新手的损耗更大
- 炼铁之外,锻打、渗碳、热处理还要不断烧木炭
→ 一个想长期炼铁的社区,必须先规划好轮伐的薪炭林
```

木炭的烧制见[基础冶金知识-木炭制作](00-基础冶金知识.md#32-木炭制作闷烧法);林地需要多大、怎样轮伐见[薪柴与林地管理](../04-动植物培育/09-薪柴与林地管理.md)。

**结论: 炼铁是资源和时间密集型工作,需要团队协作和充分准备!**

## 八、进阶技巧

### 8.1 提高产量

**多炉并行:**
- 建3-5座炉
- 轮流作业
- 持续产出

**连续作业:**
- 一炉出铁后,立即清理
- 检修2-3小时
- 开始下一炉

```
⚠️ 连续作业最大的风险是疲劳: 人累了就会犯错(碰到铁水、忘记防水)
   → 排好班,每班不超过一个白天或一个夜晚,下班的人离开炉区休息
```

### 8.2 提高质量

**矿石精选:**
- 只用磁铁矿或优质赤铁矿
- 充分淘洗

**温度控制:**
- 训练固定鼓风人员
- 保持稳定节奏

**合理配料:**
- 木炭:矿石:石灰石 = 2:2:0.2

```
怎样找到适合自己矿石的配比:
- 每炉只改变一个条件(例如只多加一些木炭),其余不变
- 记录: 矿石和木炭的质量、加料批数、鼓风时长、出渣情况、产铁质量
- 产铁/矿石的比值越来越高、渣里铁珠越来越少 → 方向对了
- 三五炉之后,就能得到适合本地矿石的配方
```

### 8.3 废铁利用

**末日情况下,废铁可能比矿石更易得:**
- 旧汽车(大量钢材)
- 建筑钢筋
- 机械零件
- 铁轨、铁丝

**处理:**
- 分类(去除铜、铝、塑料)
- 重新熔化
- 铸造或锻造
- **比从矿石炼铁容易10倍!**

```
⚠️ 废铁加热前去掉油漆、塑料、橡胶和镀层:
   - 镀锌铁皮(白色、有花纹的铁皮、水管)加热会放出氧化锌烟,
     吸入后发冷发热、像得了重感冒("金属烟热")
   - 含铅的焊锡、铅皮、蓄电池零件不要放进炉里
   - 油箱、气瓶、密闭的管子、罐头里可能有残留燃料或气体,
     加热会爆炸 → 先确认开口、清空
⚠️ 熔化钢需要的温度比生铁高得多,土法炉通常只能锻打废钢,
   不能把它熔化
```

识别和分类废旧金属、哪些废料是好钢,见[废旧金属回收与铝铸造](./05-废旧金属回收与铝铸造.md)。

## 九、检查清单

### 冶炼前:
- [ ] 炉子完全干燥,无裂缝
- [ ] 鼓风装置运行流畅
- [ ] 木炭充足(准备量×1.5)
- [ ] 矿石已粉碎、处理
- [ ] 石灰石准备好
- [ ] 出铁口、接铁容器干燥
- [ ] 灭火沙、水准备好
- [ ] 人员分工明确
- [ ] 天气晴朗
- [ ] 防护装备齐全(手套、护目镜、围裙、包脚的鞋)
- [ ] 炉区3 m内无柴草,孩子和牲畜远离
- [ ] 每个人知道一氧化碳中毒的症状和处理办法

### 冶炼中:
- [ ] 鼓风持续、稳定
- [ ] 温度达到黄白色
- [ ] 及时补充木炭
- [ ] 人员轮换,防疲劳
- [ ] 监测一氧化碳中毒迹象
- [ ] 定时排渣,风口畅通
- [ ] 记录每批加料的时间和数量
- [ ] 鼓风的人按时喝水

### 出铁时:
- [ ] 确认铁水聚集
- [ ] 接铁容器已预热
- [ ] 人员后退至安全距离
- [ ] 准备分离渣
- [ ] 地面无积水,不在下雨时出铁

### 结束后:
- [ ] 炉渣、残炭堆在沙地上,确认熄灭
- [ ] 不把头伸进还在冒气的炉口
- [ ] 检查炉衬损坏情况,记下需要修补的地方
- [ ] 产出的铁称重,写进记录本
