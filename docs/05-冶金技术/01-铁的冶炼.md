# 铁的冶炼

> **文明的脊梁 - 从零开始掌握炼铁技术**

## ⚠️ 警告

**炼铁是冶金中最困难的技术!**

- 🔥 块炼法需1100-1300°C;要炼出铁水需1300-1400°C
- ⏱️ 单次冶炼需8-24小时持续作业
- 💪 体力消耗巨大(持续鼓风)
- ☠️ 一氧化碳浓度极高
- 💥 操作不当可能爆炸

**初次尝试失败率70%+,需要充分准备和多次尝试!**

```
☠️ 一氧化碳: 铁就是靠它还原出来的,炉口的蓝色火苗就是它在燃烧
   → 只在露天或四面敞开的棚下作业;人站上风处;守夜不能在炉边睡觉
💥 铁水、炉渣碰到潮湿的沙、工具、地面或雨水会爆炸性飞溅
   → 一切接触物先烤干
🔥 炉渣、铁块发暗甚至发黑时仍有数百摄氏度 → 一律用钳子
👁️ 戴护目镜;盯风口、炉膛的强光只看几秒
🚫 不炼含铅、汞、砷的矿石,不烧镀锌、涂漆、带塑料的废件(有毒烟气)
```

一氧化碳中毒见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒);烧烫伤见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤);防护装备见[基础冶金知识-安全防护](00-基础冶金知识.md#六安全防护)。

## 一、铁矿石识别与采集

### 1.1 三大主要铁矿石

#### ① 磁铁矿 Fe₃O₄

**外观特征:**
- 颜色: 黑色、铁黑色
- 光泽: 金属光泽或半金属光泽
- 硬度: 5.5-6.5(小刀刻不动)
- 比重: 5.0-5.2(很重!)

**独特识别方法:**
```
最简单: 有磁性!
- 用磁铁吸附: 强烈吸引
- 或用指南针靠近: 指针偏转
- 条痕黑色(和赤铁矿的红色条痕区分)
- 磁铁可从旧喇叭、电机、硬盘里拆
```

**优点:**
- ✓ 含铁量最高(60-70%)
- ✓ 易识别(磁性)
- ✓ 冶炼效率高

**分布:**
- 火成岩地区
- 接触变质带
- 河流黑砂中

```
河滩黑砂: 在河湾内侧的缓水处淘洗,再用装在塑料袋里的磁铁去吸
  (翻转袋子黑砂就掉下来),反复2-3次
⚠️ 有的黑砂含钛多,炉渣会很黏、出铁很少 → 先试炼(见1.5)
```

#### ② 赤铁矿 Fe₂O₃

**外观特征:**
- 颜色: 红褐色、钢灰色、黑色
- 光泽: 金属光泽(致密块状)或暗淡(土状)
- 条痕: **红色**(关键识别!)
- 硬度: 5.5-6.5

**识别方法:**
```
关键: 条痕颜色!
1. 在未上釉的白瓷板上摩擦
2. 留下樱桃红色或铁锈色条痕
3. 即使矿石本身是黑色,条痕也是红色

没有白瓷板: 用碗底没上釉的一圈,或碎瓷片的断面
```

**优点:**
- ✓ 含铁量高(50-60%)
- ✓ 分布广泛
- ✓ 易于粉碎

**分布:**
- 沉积岩地区
- 风化壳
- 红土层

#### ③ 褐铁矿 FeO(OH)·nH₂O

**外观特征:**
- 颜色: 褐色、黄褐色、黑褐色
- 光泽: 暗淡、土状
- 形态: 钟乳状、土状、致密块状
- 比重: 3.6-4.0(相对较轻)

**识别方法:**
```
特征:
- 黄褐色条痕
- 较轻,用手能感觉出
- 多孔,像土块
```

**缺点:**
- ✗ 含铁量较低(40-50%)
- ✗ 含水,冶炼时需烘干
- ✗ 多杂质

**优点:**
- ✓ 分布广,表层即有
- ✓ 易采集
- ✓ 新手入门选择

**分布:**
- 沼泽地
- 湖泊底部
- 古老风化壳

```
沼铁矿的线索: 湿地水面有一戳就碎成小片的彩虹色薄膜(油膜会重新合拢),
  沟底有橙红色絮状沉淀,往下挖20-30 cm有褐色多孔的硬块
⚠️ 沼铁矿常含磷,炼出的铁容易"冷脆"(见 Q8)
```

### 1.2 简易鉴定流程

```
发现可疑矿石
     ↓
┌────┴────┐
│ 用磁铁测试 │
└────┬────┘
     │
  有磁性?
     │
 是 ↓          否 ↓
磁铁矿!      在白瓷板划痕
              ↓
          红色条痕?
              │
          是  ↓    否 ↓
         赤铁矿!  褐色条痕?
                     │
                 是  ↓
                褐铁矿!
```

**容易认错的石头:**

| 看起来像 | 怎样区分 | 能不能用 |
|----------|----------|---------|
| 黄铁矿(金黄色,"愚人金") | 条痕黑绿色,敲碎或加热有硫磺味 | 不宜,硫使铁"红脆"(见 Q8) |
| 黑色玄武岩、页岩 | 掂着不压手,条痕灰白 | 不能 |
| 红色砂岩、红土 | 轻,一捏就散 | 含铁太少 |

更多鉴定方法见[地质矿物与土壤-认识矿物](../08-基础科学知识/06-地质矿物与土壤.md#二认识矿物)。

### 1.3 采集要点

**优选矿点:**
- 矿石露出地表
- 矿层厚度>30 cm
- 含铁量高(颜色深、密度大)
- 距离居住地3-10 km(太近污染,太远运输累)

**采集工具:**
- 铁镐或尖锄(挖掘)
- 铁锤(敲碎)
- 簸箕或背篓(运输)
- 布袋(装碎矿石)

**采集量(首次):**
- 目标产铁: 2 kg
- 需要矿石:
  - 磁铁矿: 5-7 kg
  - 赤铁矿: 6-9 kg
  - 褐铁矿: 8-12 kg

```
为什么要这么多: 土法冶炼时相当一部分铁和脉石结成炉渣流走,
  能变成金属铁的往往只有矿石含铁量的一半甚至更少

⚠️ 不挖陡坎底部、不掏空坡脚;不进废弃矿洞(塌方、缺氧、有毒气体)
```

### 1.4 矿石处理

#### 步骤1: 粉碎
```
块状矿石 → 核桃大小
工具: 石锤、铁锤
时间: 1-2小时

- 内径20-30 cm的小炉,打到豌豆到花生大小(约0.5-1.5 cm)更好
- 不要打成粉: 粉末堵塞透气,还会被风吹出炉口 → 筛掉
- 敲矿时戴护目镜
```

#### 步骤2: 焙烧(去水、去硫)
```
针对: 褐铁矿、含硫矿石
方法:
1. 平铺在耐火砖/石板上
2. 堆木柴点燃加热
3. 焙烧2-4小时
4. 目的: 蒸发水分,氧化硫

焙烧好了: 颜色变成红褐到黑红、一敲就碎、不再冒白汽和硫磺味
⚠️ 含硫矿石放出二氧化硫,人站上风处,远离住房、畜圈和菜地
⚠️ 焙烧后的矿石保持干燥,下炉前不能再淋湿
```

#### 步骤3: 淘洗富集(可选)
```
1. 将碎矿石放入水槽
2. 加水摇晃
3. 轻的泥土流走
4. 重的铁矿石沉底
5. 可提升含铁量5-10%

淘洗后的矿石必须晒干或烤干再入炉
```

淘洗和磁选见[基础冶金知识-矿石富集](00-基础冶金知识.md#54-矿石富集)。

### 1.5 矿石的试炼

```
建大炉之前先试矿:
1. 约1 kg碎矿石和木炭交替铺在锻炉里,鼓风烧1-2小时
2. 冷后扒开: 有灰色、能被磁铁吸起、锤打会变形的小铁粒 → 值得开采
   全是玻璃状的渣 → 矿太贫或杂质太多,换矿点
3. 记下矿点、处理方式、木炭用量和结果
```

## 二、炼铁炉建造

### 2.1 简易竖炉(推荐)

**规格:**
- 高度: 120-150 cm
- 内径:
  - 炉缸(风口以下,出铁口所在): 20 cm
  - 炉腹(风口以上,向下收窄): 25 cm
  - 炉腰(最宽): 40 cm
  - 炉顶(装料口): 30 cm
- 壁厚: 20-30 cm

**剖面图:**
```
     [俯视顶部]
      ┌─────┐
      │ 30 cm│ ← 装料口
      └─────┘

     [剖面侧视]
      ╔═══╗ ← 装料口(30 cm)
      ║   ║
      ║   ║ ← 炉身(120 cm)
     ╔╝   ╚╗
    ╔╝     ╚╗ ← 炉腰(最宽40 cm)
    ║   ●   ║ ← 风口(25 cm高度)
    ╚╗  ↑  ╔╝
     ╚╗   ╔╝ ← 炉腹(收窄到25 cm)
      ║   ║
      ╚═══╝ ← 炉缸、炉底
       \_/
      出铁口
```

**关键尺寸解释:**
- **炉腰**: 最宽处,矿石和燃料充分反应区
- **炉腹**: 向下收窄,炉料熔化后体积缩小,收窄让炉料始终贴紧下沉
- **风口**: 鼓风进入位置,距炉底20-30 cm

```
块炼法的炉子可以更简单: 直筒形,内径25-35 cm,高100-150 cm,
  风口以下留15-20 cm让海绵铁块长大
炉子不要贪大: 内径越大需要的风量越多,风箱带不动时炉温反而上不去

风口: 墙上8-12 cm的孔里插一根耐火黏土风管(内径约2-3 cm),
  稍向下倾斜,伸进炉内3-5 cm;风管和风箱之间留缝,防热气倒吸
出渣口/出铁口: 在炉底前方,平时用湿黏土塞住;炉前挖低一些的沙坑接渣
场地: 炉周3 m内无柴草;防雨棚要高、四面敞开;鼓风的人不正对出渣口
```

风箱和风管的做法见[鼓风设备与锻炉](08-鼓风设备与锻炉.md)。

### 2.2 耐火材料配制

**普通黏土不行!必须用耐火材料!**

#### 耐火黏土配方A(推荐):
```
成分:
- 铝矾土(或高岭土): 50%
- 石英砂: 30%
- 耐火黏土: 15%
- 碎耐火砖(如有): 5%
- 水: 适量
```

**铝矾土/高岭土在哪找?**
- 瓷土矿区
- 白色/灰白色土层
- 摸起来细腻,吸水性强

#### 耐火黏土配方B(简易):
```
成分:
- 黄黏土: 40%
- 砂子: 30%
- 碎砖/陶片(打到米粒大小): 25%
- 切碎的干草或稻壳: 5%(防开裂,烧掉后留下细孔,更隔热)

⚠️ 不要加食盐、生石灰、草木灰: 它们是助熔剂,会让炉衬在高温下软化熔化
配方B只用于外层和炉身上部;风口附近和炉缸用配方A
```

**制作:**
1. 混合干料
2. 加水调至可塑
3. 反复践踏、揉捏30分钟
4. 静置24小时"腐化"(更均匀)

```
合格判断:
- 搓成手指粗的泥条弯成圈,不断 → 可塑性合适
  一弯就断 → 加黏土;粘手发亮 → 加砂和熟料
- 小泥饼放进锻炉最热处鼓风烧1小时:
  ✓ 不变形,只变硬变色 → 可用
  ✗ 发亮起釉、变软、起泡 → 耐火度不够,换更白的黏土
```

耐火材料原理见[工程力学与材料-陶瓷和耐火材料](../09-进阶科学与工程/01-工程力学与材料.md#105-陶瓷和耐火材料)。

### 2.3 建炉步骤

**第1天: 砌筑**
1. 选址: 空旷、通风、远离建筑
2. 地基: 石块垫高50 cm,防潮
3. 内模: 用木桶或草编筐作模型
4. 外墙: 一边砌黏土,一边抽出内模
5. 风口: 预留直径8-12 cm的孔

```
- 避开低洼和地下水位高的地方(炉底受潮会出事故)
- 每层加泥10-15 cm,捶实;接上一层前先刮毛、刷泥浆,防止分层
- 草编筐内模可以不抽出,烘炉时烧掉
- 内层耐火泥约10 cm,外层用普通草泥、石块加厚保温
```

**第2-7天: 干燥**
- 自然阴干5天(重要!)
- 不可阳光暴晒
- 下雨需遮盖

```
外干内湿、收缩不均就会开裂 → 头两天盖湿草帘让它慢慢干
```

**第8-10天: 烘炉**
- 第1天: 小火烘烤2小时,停火,重复3次
- 第2天: 中火烘烤4小时
- 第3天: 大火烘烤6小时
- 看到炉壁微微发红即可

```
冒白汽是正常的;升温太快,内部水分变蒸汽会把炉壁炸开一块
外壁从冰凉变成烫手、干燥、不再冒汽 → 基本烘透
```

**第11天: 检查**
- 检查有无裂缝
- 裂缝<2 mm: 不管
- 裂缝>2 mm: 用耐火泥填补
- 风口畅通

```
⚠️ 贯穿炉壁、能透光的裂缝,或炉缸部位的裂缝,拆掉那一段重砌
   → 否则冶炼时铁水、炉渣会从这里漏出
```

## 三、炼铁实战

### 3.0 两条路线: 块炼法 vs 生铁法

| 对比项 | 块炼法(推荐新手) | 生铁法(本章3.1-3.3) |
|--------|------------------|---------------------|
| 炉温 | 1100-1300°C | 1300-1400°C |
| 铁的状态 | 不熔化,得到海绵状铁块 | 熔化成铁水流出 |
| 产物 | 含碳低,接近熟铁,可直接锻打 | 生铁,很脆,需再炒炼成熟铁 |
| 难度 | 较低 | 较高(鼓风要求高) |

**块炼法要点:**
- 使用同样的竖炉、矿石和木炭,鼓风强度可以低一些
- 炉温保持在橙红到黄色(约1200°C),铁不会熔化
- 冶炼结束后从炉底扒出夹杂炉渣的海绵铁块
- 趁红热反复锻打,挤出炉渣、压实成块,即得熟铁(见3.4)
- 古代早期炼铁(包括中国春秋时期以前)主要采用此法

```
炉内: 木炭燃烧生成 CO,CO 夺走矿石里的氧(Fe₂O₃ + 3CO → 2Fe + 3CO₂)
生铁法的铁再吸收碳,熔点降到约1150°C,化成铁水
风太猛、木炭太少 → 已还原的铁又被烧回氧化铁
```

**以下3.1-3.3为生铁法流程。**

### 3.1 材料准备

**单次冶炼(目标: 2 kg铁):**

| 材料 | 用量 | 备注 |
|------|------|------|
| 铁矿石 | 6-10 kg | 已粉碎 |
| 木炭 | 6-10 kg | 优质硬木炭 |
| 石灰石 | 0.5 kg | 助熔剂,降低熔点 |
| 备用木炭 | 5 kg | 以防万一 |

```
木炭: 硬木炭敲成2-3 cm,筛掉碎末,必须干燥
石灰石: 敲成指头大小(滴醋冒泡的白色、灰色石头),
  和矿石中的石英结成易流动的渣;块炼法可少加或不加
```

木炭的烧制和质量检验见[基础冶金知识-燃料制作](00-基础冶金知识.md#三燃料制作)。

**其他准备:**
- 水(2桶): 灭火、冷却
- 长柄钳: 夹持
- 长柄铁勺: 舀渣
- 沙土(1堆): 应急灭火
- 铁桶: 接铁水
- 防护: 皮手套、护目镜、厚围裙、包脚面的鞋
- 约1.5 m长的铁钎(捅出渣口、风口)、湿黏土团(堵口、补漏)
- 照明、记录本、饮水(鼓风的人每1-2小时喝水,适量加盐)

### 3.2 操作流程

#### 阶段1: 预热炉子(1-2小时)

```
1. 炉底铺木炭(10 cm厚)
2. 点火
3. 开始鼓风
4. 温度升至600-700°C(暗红色)

先用干柴引燃,再加木炭到半炉高;预热不够就加矿石,会把火压灭
```

**鼓风节奏:**
- 1人: 每5秒鼓1次
- 2人轮换: 持续鼓风

```
- 均匀比猛烈更重要,一阵猛一阵停炉温就上下波动
- 每人鼓20-30分钟换人,换人时不停风
- 风箱突然发硬、风口发暗 → 风口被渣堵住,用铁钎从风管口捅通
```

风量不够时怎样改进见[鼓风设备与锻炉](08-鼓风设备与锻炉.md)。

#### 阶段2: 装料(分批进行)

**装料顺序(循环):**
```
第1批:
1. 加木炭(1层,3-5 cm厚)
2. 加矿石(1层,3-5 cm厚)
3. 加少量石灰石(1小把)
4. 继续鼓风5分钟

重复装料8-10批,装满炉身
```

**关键要点:**
- 木炭和矿石交替
- 木炭略多于矿石
- 不要一次装满(窒息)
- 边装料边鼓风
- 头两三批矿石减半,之后炉料降多少补多少
- 加料时站在炉口侧面,不要把脸凑到炉口上方

#### 阶段3: 冶炼反应(6-10小时)

**持续鼓风!**
- 风力要稳定
- 不能停止(温度会骤降)
- 人员轮换

**温度管理:**
```
目标温度: 1300-1400°C
颜色判断: 黄色到亮黄色

温度不足:
- 加大鼓风
- 增加木炭

温度过高(罕见):
- 减少鼓风
- 停止加料
```

颜色和温度的对照见[基础冶金知识-判断温度](00-基础冶金知识.md#41-判断温度)。

**现象观察:**

| 时间 | 现象 | 说明 |
|------|------|------|
| 1-2小时 | 浓烟,刺鼻 | 矿石加热,挥发杂质 |
| 3-4小时 | 烟少,炉内明亮 | 进入还原阶段 |
| 5-6小时 | 偶尔火星飞出 | 铁开始熔化 |
| 7-8小时 | 炉底发亮 | 铁水聚集 |

**排渣(约每1-2小时):**
```
渣积到风口高度会淹没风口(风口发暗、鼓风变闷)
1. 人站侧面,用铁钎捅开出渣口
2. 黑红色、像糖稀的渣流进沙坑
3. 开始冒亮黄色火焰时,用湿黏土团堵上

✓ 渣流畅,冷后黑色、断口像玻璃 → 正常
✗ 渣稠流不出 → 炉温低或矿里杂质多;加大鼓风、加石灰石
✗ 渣里夹许多亮铁珠 → 出渣过早或炉温不稳
⚠️ 渣面结了黑壳,下面仍是液体,不要踩
```

**补料:**
- 炉料下降时,继续添加
- 保持炉腰以上充满
- 木炭消耗快,及时补充

**一氧化碳(全程留意):**
```
- 风向变了人跟着换位置;看完炉口就退开
- 头痛、头晕、恶心、犯困、反应变慢 → 立即到上风处换人
- 两人以上同时不适、有人意识模糊 → 按一氧化碳中毒处理,
  移到新鲜空气处,尽快就医
```

#### 阶段4: 出铁(关键!)

**判断完成:**
- 炉底出铁口发亮
- 用铁棍探入,有液态感觉
- 时间已达8小时+

**出铁步骤:**
```
1. 准备接铁容器(干燥!)
   - 地面挖坑铺沙
   - 或用耐火砖砌槽

2. 打开出铁口
   - 用铁棍捅开堵塞的黏土
   - 铁水会流出

3. 分离铁和渣
   - 铁水(重)在底部
   - 渣(轻)浮在上面
   - 用铁板或木板挡住渣

4. 铸锭或铸块
   - 倒入沙模
   - 或直接倒在沙地上成薄饼状(便于后续加工)
```

**⚠️ 安全警告:**
- 铁水温度1200-1400°C,极度危险!
- 保持2 m安全距离
- 绝对不能接触水!
- 准备好灭火沙
- 沙模、挡渣板、铁钎、堵口用的黏土都先在火边烤干
- 要下雨就推迟出铁,先保温;孩子和无关的人退到5 m外

```
被铁水或炉渣溅到:
1. 衣服着火: 躺倒打滚或用厚毯子压灭,不要跑
2. 粘在皮肤上已凝固的金属不要硬撕
3. 凉水冲洗15-20分钟,干净布松松盖住,不涂牙膏、酱油、草木灰
4. 面积超过伤者一个手掌,或伤在脸、手、脚、关节、眼睛 → 尽快送医
```

烧伤的程度判断和处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤)。

#### 阶段5: 冷却(2-4小时)

```
铁块在模具中:
- 自然冷却
- 不要浇水(会炸裂)
- 等待变成暗红色后可移动

炉子:
- 停止鼓风
- 让炉火自然熄灭
- 等待12小时后清理

⚠️ 不红了不等于凉了: 离远一点滴一滴水,滋滋作响就还很烫
⚠️ 熄火后炉内仍产生一氧化碳,不要把头伸进炉口
⚠️ 炉渣、残炭堆在沙地上,第二天确认完全熄灭
```

### 3.3 首次成果

**你得到的是: 生铁**

**生铁的特性:**
- 含碳量: 2-4%
- 硬度: 很硬
- 脆性: 很脆,一砸就碎
- 颜色: 灰白色(铸铁)或白色(白口铁)
- **不能锻造!**

**能做什么?**
- ✓ 铸造成型(熔化后倒模)
- ✓ 制作铁锅、犁铧(耐磨损)
- ✗ 不能锻打成刀、斧(会碎)

**需要进一步精炼成熟铁或钢!**

```
看这一炉炼出了什么:
- 断口灰色、颗粒粗 → 灰口铸铁(能锉动,适合铸造)
- 断口白亮、极硬 → 白口铁(适合炒成熟铁)
- 烧红能锤扁 → 熟铁或低碳钢
- 海绵状夹渣的块 → 炉温不够,其实是块炼铁(按3.4处理)
```

生铁的铸造见[铸造进阶-铸铁](07-铸造进阶.md#七铸铁)。

### 3.4 块炼法的出炉与锻合

```
海绵铁块("铁坨")夹着渣和木炭,要趁热锻成致密的熟铁,这一步最容易失败

1. 出炉: 最后一批料加完再鼓风30-60分钟,停料,拆开炉前出口,
   用长钳、铁钎撬出炉底最重的铁坨,敲掉表面松渣
2. 初锻(要快): 趁黄色到橙色时先用木槌或轻锤轻拍,
   一开始用力过猛,海绵铁会碎成几块;挤出的液态渣会四溅
3. 颜色降到暗红就回炉,加热到黄色再锻,逐步加大力度,
   压成厚块后切开、对折、锻合,往往要来回十几次
4. 合格: 敲起来声音清亮、断面基本无渣孔,烧红能弯不沿渣线裂开

损耗: 最后的熟铁常只有铁坨质量的一半左右
```

锻打手法见[简易工具锻造](03-简易工具锻造.md)。

## 四、从生铁到熟铁

### 4.1 原理

```
生铁(含碳2-4%)
    → 去碳
      → 熟铁(含碳<0.2%)
```

**目的:** 去除碳,增加韧性,便于锻造

```
碳和空气中的氧结合跑掉 → 碳越少熔点越高(纯铁约1538°C)
→ 炉温不变,铁水就会变稠、结成团: "由稀变稠"本身就是去碳的标志
```

### 4.2 方法A: 炒钢法(推荐)

**设备:**
- 浅盘状炉子(炒锅状)
- 鼓风装置
- 做法: 地上挖直径约40-50 cm、深约20-25 cm的浅坑,抹耐火泥烘干,侧面开风口;每次炒1-3 kg

**步骤:**

**1. 装炉:**
- 炉底铺木炭
- 点火鼓风至高温

**2. 化生铁:**
- 将生铁块放入炉中
- 鼓风加热至熔化
- 温度: 1300-1400°C
- 生铁先打成鸡蛋大小,放在正对风口的木炭上;白口铁比灰口铁好炒

**3. 搅拌(关键!):**
```
用长铁棍不断搅动铁水:
- 目的: 让铁水充分接触空气
- 反应: C + O₂ → CO₂ (碳被氧化烧掉)
- 时间: 持续30-60分钟
- 现象:
  * 火花四溅
  * 逐渐变稠(碳少,熔点升高)

铁棍至少1.5 m长,备两三根轮换;搅拌的人戴护目镜、站侧面
```

**4. 观察变化:**
```
铁水 → 铁浆(半固态) → 铁坨(固态团块)

火花由多而响变得越来越少;铁团像面团一样能挑起 → 可以出炉
```

**5. 取出锻打:**
- 用钳子夹出铁坨(趁热!)
- 放在砧上快速锤打
- 目的:
  * 打出残渣
  * 压实铁块
  * 整形

**6. 反复加热锻打:**
- 加热至橙红色
- 锤打
- 重复3-5次

**成品: 熟铁(锻铁)**
- 含碳<0.2%
- 软,韧性好
- 可以锻造成各种形状
- 不易折断

> 不炒到底就停,铁里会留下较多碳,直接得到钢——汉代"炒钢"即如此,但火候难控制。新手先炒到熟铁,需要钢再按第五节渗碳。

### 4.3 方法B: 吹炼法

**原理:** 在熔融生铁中吹入空气,氧化碳

**设备:**
- 坩埚(耐火黏土制)
- 耐火黏土风管或铁管(铁管会被烧掉一截)

**步骤:**
1. 坩埚中熔化生铁
2. 插入风管,深入铁水
3. 风管接风箱鼓风(绝不能用嘴吹)
4. 碳被氧化,铁水翻腾
5. 持续20-40分钟
6. 倒出锻打

**缺点:** 危险,容易飞溅

```
⚠️ 不推荐新手:
- 铁水剧烈翻腾,会喷出坩埚;坩埚可能被侵蚀破裂
- 竹管等含水材料插进铁水会引起蒸汽爆炸 → 绝对不用
- 要试只用几百 g,坩埚放沙坑里,长柄操作,5 m内不留人
```

### 4.4 熟铁检验

**方法:**
```
1. 锻打测试:
   - 加热至红色
   - 锤打能延展成薄片
   - 不开裂 → 熟铁✓
   - 碎裂 → 生铁,需继续精炼

2. 弯曲测试:
   - 常温下弯曲铁条
   - 能弯90°不断裂 → 熟铁✓
   - 折断 → 生铁

3. 火花测试:
   - 在砂轮上打磨
   - 熟铁: 火花长、黄白色,分叉很少
   - 生铁: 火花短、暗红到橙色,末端只有少量小分叉
   - 钢: 含碳越高,分叉越多越密
   - 拿已知的钢筋、锉刀对比着看更准

```

火花对照见[废旧金属回收与铝铸造-火花鉴别](05-废旧金属回收与铝铸造.md#22-火花鉴别砂轮或粗锉打磨)。

## 五、炼钢技术

### 5.1 什么是钢?

**钢 = 含碳0.2-2%的铁**

- 比生铁含碳少(不脆)
- 比熟铁含碳多(更硬)
- **既硬又韧,制刀最佳!**

| 种类 | 含碳量(大致) | 特点 | 适合做 |
|------|---------------|------|--------|
| 熟铁 | <0.2% | 软、韧,不能淬硬 | 钉子、铁丝、链环、铁箍 |
| 中碳钢 | 约0.3-0.6% | 强度和韧性兼顾 | 斧、锤、锄 |
| 高碳钢 | 约0.6-1.5% | 淬火后很硬,较脆 | 刀、凿、锉、弹簧 |

钢能淬火变硬(加热到约780-850°C后急冷),熟铁不能——所以刃口要用钢。原理见[工程力学与材料-铁和钢](../09-进阶科学与工程/01-工程力学与材料.md#102-铁和钢-碳决定一切)。

### 5.2 方法: 渗碳法

**原理:** 让熟铁吸收碳

#### 固体渗碳法(简单)

**材料:**
- 熟铁块
- 木炭粉
- 密封容器(铁盒或陶罐)

**步骤:**

**1. 准备渗碳剂:**
```
木炭粉: 80%
草木灰: 10%
食盐: 10%
(混合均匀)

木炭粉粗细像小米到绿豆;用过一次后掺一半新料
```

**2. 装填:**
```
铁盒/陶罐内:
底部铺渗碳剂(3 cm)
  ↓
放入熟铁块
  ↓
周围填满渗碳剂
  ↓
顶部覆盖渗碳剂(3 cm)
  ↓
密封(用黏土糊严)

- 工件之间、工件和罐壁之间至少隔2 cm
- 同时放一根同材料的小铁条作试样
- 封口留一个筷子粗的小孔排气,防止胀裂
```

**3. 加热:**
- 将密封容器放入炉火中
- 加热至900-1000°C(橙红色)
- 保温4-12小时
  - 薄件(刀片): 4-6小时
  - 厚件(斧头): 8-12小时
- 从整个罐子均匀橙红时开始计时;小孔冒蓝色火苗是一氧化碳,人站上风处

**4. 冷却:**
- 随炉慢冷
- 或取出空冷

**5. 检查:**
- 打开容器
- 铁表面应呈灰黑色
- 硬度明显增加
- 最可靠: 试样烧到樱桃红淬水,锉刀打滑 → 已成钢;能锉动 → 时间不够

**成品: 钢!**
- 表面渗碳深度: 约0.3-1.5 mm(随保温时间增加)
- 外硬内韧(最佳状态!)
- 之后还要淬火、回火;渗层薄,磨刃口不要磨穿

渗碳深度与时间的对照、淬火回火操作见[金属加工技术](04-金属加工技术.md)。

#### 液体渗碳法(快速)

**步骤:**
1. 熟铁加热至1000°C(橙黄色)
2. 迅速插入木炭粉中
3. 表面吸收碳
4. 再加热、再插入
5. 重复5-10次
6. 淬火(快速冷却)

**优点:** 快
**缺点:** 渗碳深度浅(约0.1-0.3 mm),只适合小件表面硬化

> 工厂里的"液体渗碳"用的是含氰化物的盐浴,剧毒,不要尝试。

### 5.3 其他得到钢的途径

```
1. 炒钢时不炒到底(见4.2)
2. 夹钢、贴钢: 熟铁做刀身,刃口夹一条钢锻合,省钢又韧
3. 回收废钢: 锉刀、弹簧、钢板弹簧本身就是高碳钢,比自己渗碳省事
```

夹钢见[简易工具锻造-高级技巧](03-简易工具锻造.md#十一高级技巧)。

## 六、常见问题与故障

### Q1: 炉温上不去,一直不到1300°C?

**原因:**
- ✗ 鼓风不足
- ✗ 炉壁太薄,散热快
- ✗ 炉顶开口太大
- ✗ 木炭质量差

**解决:**
- ✓ 加强持续鼓风
- ✓ 加厚炉壁或外围再砌一层
- ✓ 炉顶部分封闭
- ✓ 更换木炭
- ✓ 查风管接口漏气、风口太高或太浅、炉膛太大、一次加矿太多

### Q2: 冶炼8小时,没有铁水出来?

**可能原因:**
1. **温度不够**
   - 检查炉内颜色,应为黄白色
   - 增强鼓风

2. **还原不充分**
   - 木炭与矿石比例不对
   - 增加木炭用量

3. **铁成海绵状,未熔化**
   - 正常现象!这就是块炼法的产物(见3.0)
   - 取出炉料,挑出海绵铁块
   - 反复加热锻打,压实成块,得到可直接使用的熟铁

4. **铁都进了炉渣**
   - 渣黑重、流得稀,却几乎没铁 → 矿里石英多、炉温不稳
   - 多加石灰石、淘洗矿石、保持木炭充足

### Q3: 出铁时爆炸飞溅?

**原因:** 水气!
- 出铁口潮湿
- 接铁容器不干燥
- 地面有积水
- 堵口的湿黏土、生锈潮湿的铁工具

**预防:**
- 所有接触铁水的部分彻底烘干
- 提前用火烤20分钟
- 一旦飞溅,所有人后撤,不要抢救铁水,先查有没有人烫伤

### Q4: 得到的铁质量很差,杂质多?

**原因:**
- 矿石品位低
- 炉渣混入

**改进:**
- 矿石淘洗富集
- 添加足够石灰石(助熔剂)
- 出铁时仔细分离渣

### Q5: 一次只能得到几百 g铁,太少?

**正常!**
- 小型炉单次产量: 0.5-3 kg
- 中型炉: 5-10 kg
- 大型炉(需多人): 20-50 kg

**提高产量:**
- 扩大炉子
- 提高装料量
- 多建几座炉,同时作业
- 先让小炉每炉都稳定出铁,再扩大(木炭和人力要跟着翻倍)

### Q6: 生铁精炼成熟铁时,铁块越炒越少?

**正常现象!**
- 碳被氧化烧掉
- 部分铁被氧化成铁渣
- 损失率: 10-30%
- 这就是为什么要多炼铁

### Q7: 风口被堵、炉子烧穿或出口冻住?

| 情况 | 表现 | 处理 |
|------|------|------|
| 风口被渣堵 | 风箱发硬、风口发暗 | 铁钎从风管口捅碎;常堵说明出渣不及时 |
| 炉壁烧穿 | 外壁出现亮红斑,甚至渗渣 | 人离开那一侧,减风,外面糊厚泥;漏得多就停炉 |
| 出口冻住 | 捅不开,或流一点就凝固 | 加木炭、加大鼓风半小时再试;下一炉出口做大做低 |

### Q8: 炼出的铁一锻就裂?

| 现象 | 可能原因 | 怎么办 |
|------|----------|--------|
| 烧红锻打时开裂("红脆") | 硫多(黄铁矿、用了煤) | 矿石充分焙烧;只用木炭 |
| 常温一敲就断,断口亮晶晶("冷脆") | 磷多(沼铁矿常见) | 换矿,或只做不受冲击的东西 |
| 沿一条条黑线裂开 | 夹渣没锻出 | 加热到黄色再锻,多折叠锻合 |
| 越锻越碎 | 其实是生铁 | 先按第四节炒成熟铁 |
| 表面起皮、越打越小 | 加热太久,氧化严重 | 埋在木炭里加热,到温就锻 |

## 七、时间与资源评估

### 单次炼铁完整流程:

| 阶段 | 时间 | 人力 |
|------|------|------|
| 建炉 | 7-10天 | 2-3人 |
| 采矿 | 1-2天 | 2人 |
| 制木炭 | 5-7天 | 1-2人 |
| 预处理矿石 | 1天 | 1人 |
| 冶炼 | 10-14小时 | 2-3人(轮换) |
| 冷却 | 12小时 | 无需看管 |
| **总计** | **约3周** | **2-3人团队** |

炉子能用很多次,第二炉起通常只需修补炉衬1-2天。

### 资源消耗(单次):

| 资源 | 用量 | 获取难度 |
|------|------|----------|
| 木材(制木炭用) | 50-80 kg | ⭐⭐ |
| 黏土 | 100 kg | ⭐ |
| 铁矿石 | 6-12 kg | ⭐⭐⭐ |
| 石灰石 | 1 kg | ⭐⭐ |

### 产出:
- 生铁: 1-3 kg
- 精炼后熟铁: 0.7-2 kg

```
木材是真正的瓶颈: 烧1 kg木炭约需3-5 kg木材,
  炼1 kg铁通常需要几 kg 到十几 kg 木炭,锻打和热处理还要另算
→ 长期炼铁必须先规划轮伐的薪炭林
```

林地需要多大、怎样轮伐见[薪柴与林地管理](../04-动植物培育/09-薪柴与林地管理.md)。

**结论: 炼铁是资源和时间密集型工作,需要团队协作和充分准备!**

## 八、进阶技巧

### 8.1 提高产量

**多炉并行:**
- 建3-5座炉
- 轮流作业
- 持续产出

**连续作业:**
- 一炉出铁后,立即清理
- 检修2-3小时
- 开始下一炉
- ⚠️ 排好班,人累了最容易碰到铁水、忘记防水

### 8.2 提高质量

**矿石精选:**
- 只用磁铁矿或优质赤铁矿
- 充分淘洗

**温度控制:**
- 训练固定鼓风人员
- 保持稳定节奏

**合理配料:**
- 木炭:矿石:石灰石 = 2:2:0.2
- 每炉只改一个条件并记录(矿石、木炭质量,鼓风时长,渣况,产铁);三五炉后就能找到适合本地矿石的配比

### 8.3 废铁利用

**末日情况下,废铁可能比矿石更易得:**
- 旧汽车(大量钢材)
- 建筑钢筋
- 机械零件
- 铁轨、铁丝

**处理:**
- 分类(去除铜、铝、塑料)
- 重新熔化
- 铸造或锻造
- **比从矿石炼铁容易10倍!**

```
⚠️ 加热前去掉油漆、塑料、橡胶;镀锌件加热放出氧化锌烟,
   吸入后发冷发热("金属烟热");含铅件不进炉
⚠️ 油箱、气瓶、密闭管子可能残留燃料或气体,加热会爆炸 → 先开口清空
⚠️ 熔化钢比熔化生铁难得多,土法炉通常只能锻打废钢
```

识别和分类废旧金属、哪些废料是好钢,见[废旧金属回收与铝铸造](./05-废旧金属回收与铝铸造.md)。

## 九、检查清单

### 冶炼前:
- [ ] 炉子完全干燥,无裂缝
- [ ] 鼓风装置运行流畅
- [ ] 木炭充足(准备量×1.5)
- [ ] 矿石已粉碎、处理
- [ ] 石灰石准备好
- [ ] 出铁口、接铁容器干燥
- [ ] 灭火沙、水准备好
- [ ] 人员分工明确
- [ ] 天气晴朗
- [ ] 防护装备齐全,炉周3 m内无柴草
- [ ] 每个人知道一氧化碳中毒的症状

### 冶炼中:
- [ ] 鼓风持续、稳定
- [ ] 温度达到黄白色
- [ ] 及时补充木炭
- [ ] 人员轮换,防疲劳
- [ ] 监测一氧化碳中毒迹象
- [ ] 定时排渣,风口畅通

### 出铁时:
- [ ] 确认铁水聚集
- [ ] 接铁容器已预热
- [ ] 人员后退至安全距离
- [ ] 准备分离渣

### 结束后:
- [ ] 炉渣、残炭确认熄灭
- [ ] 检查炉衬,记下要修补处
- [ ] 产铁称重并记录
