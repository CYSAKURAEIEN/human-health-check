# 计量基准的重建

> **"加热到200°C""电压220 V""每千克体重10 mg"——如果没有人还知道1 m有多长、1 kg有多重,这本书里成千上万个数字就全都失去了意义。本章讲怎样只靠自然界和废墟中的东西,把单位重新找回来**

## ⚠️ 本章的定位

[度量衡与科学方法](00-度量衡与科学方法.md#二重建长度质量体积时间)讲了重建单位的基本思路,本章系统地讲:

- 每个基本单位从哪里来、最可靠的重建方法、能达到多大的精度
- 书中用到的其他单位(N、J、W、Pa、V、A……)是怎样由基本单位推出来的、实际有多大、怎样标定
- 废墟中现成的、尺寸统一的参照物
- 怎样制作和保存标准,怎样读懂古书里的单位

```
⚠️ 先读这几条:
- 重建出的单位一定有误差: 本章给出的是"大约能做到多准",
  用于配药等关系人命的场合时,要按最不利的误差留出余量
- 废墟中保存完好的量具(卷尺、钢尺、电子秤、温度计、万用表)比任何重建方法都准,
  先找、先保护好,用它们来校准自制的标准
- 一个社区内部最重要的不是"和古代的米一样长",而是"所有人用的是同一个米"
```

## 一、单位之间的关系

```
基本单位(其他单位都由它们推出):
  长度 m     质量 kg     时间 s     温度 K(°C)
  电流 A     物质的量 mol    (发光强度 cd,本书不用)

导出单位(由基本单位组合而成):
  面积 m²、体积 m³ → 由长度
  速度 m/s → 由长度和时间
  力 N = kg·m/s²
  能量 J = N·m
  功率 W = J/s
  压强 Pa = N/m²
  电压 V = W/A
  电阻 Ω = V/A

所以: 只要把 m、kg、s、°C、A 这几个找回来,其余的都能算出来
```

### 重建的顺序

```
1. 秒(s): 来自天空,地球自转一圈的时间是不变的
2. 米(m): 用秒和单摆得到;或者用地球的大小得到
3. 千克(kg): 用米做出1 L的容器,装满水
4. 摄氏度(°C): 冰和沸水
5. 安培(A): 用秒和千克,通过电解铜得到
6. 其余单位: 由上面几个推出
```

## 二、秒: 从星星得到

### 2.1 恒星日比太阳日更稳定

```
太阳日: 太阳连续两次经过正南方(正午)的时间间隔
  - 一年平均是24 h = 86400 s,但每天的长度不一样,
    一年中会有几十秒的变化 → 一天天地用太阳校钟,误差较大
恒星日: 同一颗恒星连续两次经过正南方(或同一个方向)的时间间隔
  - 每天都一样: 约23 h 56 min 4 s = 86164 s
  - 比太阳日短约4分钟,所以同一颗星每天晚上提前约4分钟出现在同一个位置
```

### 2.2 观测恒星经过

```
1. 立一根竖直的细杆(用铅垂线校准),在它正北(或正南)方几米外再立一根
   → 两根杆连成一条正南北的线(定南北的方法见天文导航进阶)
2. 夜里眼睛靠近一根杆,看一颗亮星什么时候被另一根杆挡住
   → 记下这一刻
3. 第二天晚上,同一颗星再次被挡住的时刻,和前一晚相隔正好一个恒星日(86164 s)

更简单的做法: 一个固定的观测位置,看一颗星什么时候消失在一座房子的屋脊、
  一根固定的杆子后面(视线不变就可以,不一定是南北方向)
```

正南北方向的确定见[天文导航进阶-精确定方向](../09-进阶科学与工程/09-天文导航进阶.md#二精确定方向)。

### 2.3 用恒星日校准摆

```
单摆的周期 T = 2π√(L/g),只和摆长L有关(摆动幅度小时)

方法一(有一台能走的钟,哪怕不准):
1. 一颗星第一次被挡住时,记下钟的读数
2. 第二晚同一颗星被挡住时,再读一次
3. 钟走过的时间应该是23 h 56 min 4 s;多走了说明钟快,少走了说明钟慢
4. 调整摆长: 时间误差的比例 × 2 = 摆长要改变的比例
   例: 钟一个恒星日快了86 s(快了0.1%) → 摆长加长0.2%
   (钟快 → 摆太短 → 加长;钟慢 → 摆太长 → 缩短)
5. 反复几个晚上,直到误差满意为止

方法二(没有钟): 几个人轮流数摆动的次数,每数满100次拨一颗算珠,
  从星星被挡住数到第二晚再被挡住,应该是86164次(秒摆)
  → 很辛苦,但可行;也可以只做一次,得到一个准的摆,以后照着它复制

✓ 摆动幅度要小(偏离竖直不超过约5°),幅度大了周期会变长
✓ 摆锤用小而重的金属球,悬线细而不易伸长
✓ 秒摆: 从一边摆到另一边正好1秒(完整周期2秒)
```

单摆原理见[物理-圆周运动和单摆](02-物理.md#15-圆周运动和单摆)。

### 2.4 能做到多准

```
- 认真观测恒星经过,一次误差约几秒;连续观测多天取平均,可以把一天的误差降到1秒左右
  → 相对误差约十万分之一,对日常和工程完全够用
- 有了准确的秒,摆钟、水钟、沙漏都可以照着它校准
```

## 三、米: 两条独立的路

### 3.1 用秒摆(推荐)

```
秒摆(从一边摆到另一边正好1 s)的摆长 L = g ÷ π²
g(重力加速度)随纬度略有不同,所以秒摆的长度也略有不同:
```

| 纬度 | 秒摆长度 | 我国大致地区 |
|------|---------|-------------|
| 20° | 0.9916 m | 海南、广东南部 |
| 30° | 0.9923 m | 长江流域 |
| 40° | 0.9931 m | 华北 |
| 50° | 0.9940 m | 东北北部 |

```
做法:
1. 用校准好的秒(见第二节)把一个摆调成秒摆
2. 量出悬挂点到摆锤中心的距离
3. 按所在纬度查上表: 例如在北纬40°,这段长度是0.9931 m
   → 在它上面标出0.9931 m的位置,再按比例加长到1 m
   (1 ÷ 0.9931 ≈ 1.0069,即再加长约6.9 mm)
4. 把它刻在一根金属尺或硬木尺上,作为"标准米"

精度: 约千分之一(1 mm左右),主要来自量摆长(摆锤中心不容易找准)
纬度测量方法见天文导航进阶-测纬度
```

纬度的测量见[天文导航进阶-测纬度](../09-进阶科学与工程/09-天文导航进阶.md#三测纬度)。

### 3.2 用地球的大小(核对用)

```
米最初就是这样定义的: 从北极到赤道的距离定为10000 km
→ 纬度每差1°,南北方向的距离约111 km(1′约1852 m,就是1海里)

做法:
1. 在南北方向上相距较远的两地,分别精确测出纬度
2. 用测量的方法(三角测量、测绳)量出两地之间的南北距离
3. 1° ≈ 111 km → 反推出米的长度

精度: 取决于纬度测得有多准、两地相距多远
  - 例: 纬度测准到0.05°,两地相差5°(约555 km) → 误差约1%
→ 不如秒摆准,但它完全不依赖时间,可以用来核对秒摆的结果有没有大错
```

三角测量见[测量与制图-三角测量](08-测量与制图.md#三三角测量)。

### 3.3 废墟中的长度标准(最现实)

见第六节的参照物表。只要找到一把完好的钢卷尺或钢直尺,就比上面两种方法都准。

## 四、千克: 用水

```
1 L = 边长10 cm(0.1 m)的立方体的容积
1 L纯水的质量 ≈ 1 kg

做法:
1. 用标准米做一个内边长正好10 cm的方盒(金属或硬木,内壁涂蜡防渗)
   或者做一个容器,量出内径和深度,算出容积
2. 装满干净的水(烧开过、放凉的雨水或蒸馏水最好),水面刮平
3. 用等臂天平,把一块金属或石头调整到和这盒水一样重(减去空盒的重量)
   → 这就是标准1 kg
```

### 4.1 影响精度的因素

| 因素 | 影响有多大 | 怎样减小 |
|------|-----------|---------|
| 容器尺寸 | **每边误差1%,体积误差就是3%** | 边长尽量量准;容器做大一些(如10 L),相对误差更小 |
| 水温 | 4°C时1 L水 ≈ 1.000 kg;20°C时约0.998 kg;30°C时约0.996 kg | 记下水温,按左边修正 |
| 水质 | 海水约1.025 kg/L;泥水更重 | 用干净的淡水 |
| 天平两臂不等长 | 可能差百分之几 | 用交换称量法(见下) |

```
交换称量法(消除天平两臂不等长的误差):
1. 物体放左盘,砝码放右盘,称出 m₁
2. 物体放右盘,砝码放左盘,称出 m₂
3. 真实质量 ≈ (m₁ + m₂) ÷ 2
```

### 4.2 再分成小砝码

```
有了1 kg,用天平反复对分:
- 两块金属在天平上互相平衡,而且两块加起来和1 kg平衡 → 各是500 g
- 依此类推做出200 g、100 g、50 g、10 g、5 g、1 g
- 克以下的小砝码: 用细铜丝,称出一段长的质量,按长度截取

✓ 一套砝码: 1、2、2、5、10、20、20、50、100、200、200、500 g,可以组合出任何整克数
```

### 4.3 能做到多准

```
- 认真做: 千分之几
- 配药需要毫克级的精度,自制砝码和天平很难做到
  → 药物剂量见制药技术部分的警告,尽量用保存下来的药品原包装和剂量
```

## 五、温度: 固定点

### 5.1 0°C和100°C

```
0°C(冰点):
- 碎冰和水混合,不断搅拌,温度计读数不再变化时就是0°C
- 冰和水都要干净;盐水的冰点低于0°C

100°C(沸点):
- 纯水在1个标准大气压(101.325 kPa)下沸腾的温度
- 海拔越高沸点越低: 大约每升高300 m降低1°C
  → 海拔1500 m的地方,水约95°C就沸腾
- 温度计泡放在沸水上方的蒸汽中(而不是插在水底),读数更稳定
```

### 5.2 高温的固定点: 金属的熔点

冶炼、制陶、热处理需要判断几百到上千摄氏度,可以用纯金属的熔点作为标准:

| 金属 | 熔点 |
|------|------|
| 锡 | 232°C |
| 铅 | 327°C |
| 锌 | 约420°C |
| 铝 | 约660°C |
| 银 | 962°C |
| 金 | 1064°C |
| 铜 | 1085°C |

```
用法: 在炉中放一小块纯金属,看它是否熔化 → 判断炉温有没有达到这个温度
⚠️ 必须是纯金属: 焊锡、黄铜、铝合金的熔点和纯金属不同
⚠️ 铅有毒,只作为判断用,不要随意熔化
```

看火色判断温度见[基础冶金知识-判断温度](../05-冶金技术/00-基础冶金知识.md#41-判断温度)。

### 5.3 自制温度计

```
1. 细玻璃管下端连一个小玻璃泡,装入染色的酒精
2. 放进冰水中,标出液面 → 0°C
3. 放进沸水的蒸汽中,标出液面 → 100°C(按海拔修正)
4. 两点之间等分100格
⚠️ 不用水银: 打破后的汞蒸气有毒
```

### 5.4 开尔文

```
K = °C + 273.15
绝对零度(0 K = -273.15°C)是理论上最低的温度
气体的压强和体积与K成正比(见物理-热学)
```

## 六、废墟中的现成参照物

很多工业产品的尺寸、质量是按国家标准统一生产的,找到它们就找到了现成的标准。

### 6.1 长度

| 物品 | 尺寸 | 说明 |
|------|------|------|
| 钢卷尺、钢直尺、游标卡尺 | 刻度 | **最准,第一优先**;注意检查有没有被拉伸、折弯 |
| A4纸 | 210 mm × 297 mm | 很多打印纸、书本用纸都是这个规格;A3是A4的两倍 |

| 1元硬币 | 旧版直径25 mm;2019年版22.25 mm | 先看清是哪一版 |
| 标准黏土砖 | 240 mm × 115 mm × 53 mm | 烧制有收缩误差,多块平均 |
| 地砖 | 常见600 mm × 600 mm、800 mm × 800 mm | 尺寸印在包装上 |
| 钢筋 | 直径常见6、8、10、12、16、20 mm…… | 带肋钢筋的直径常轧在表面上 |

| 物品 | 数值 | 说明 |

| 物品 | 数值 | 说明 |
|------|------|------|

### 6.4 用身体估算

```
每个人都不一样,先用标准尺量一次自己的,记住:
- 一拃(张开手掌,拇指尖到中指尖): 成人约18-22 cm
- 一指宽: 约1.5-2 cm
- 两臂平伸的宽度 ≈ 身高
- 一步: 约0.6-0.8 m(步测前先校准,见度量衡与科学方法)
- 一捧水: 约几百毫升,误差很大

只能用于估算,不能用于配药和工程
```

## 七、导出单位: 实际有多大、怎样标定

### 7.1 力学和热学

| 单位 | 定义 | 实际有多大 | 怎样标定 |
|------|------|-----------|---------|
| N(牛顿) | 1 kg × 1 m/s² | 约100 g物体受到的重力(一个小苹果) | 1 kg的物体重约9.8 N |
| J(焦耳) | 1 N × 1 m | 把1 kg的东西举高约10 cm | 由N和m算出 |
| W(瓦特) | 1 J/s | 一个人长时间干活约75-100 W | 由J和s算出 |
| hp(马力) | 约735 W | 一匹马长时间做功的能力 | — |
| Pa(帕斯卡) | 1 N/m² | 非常小: 一张纸平放在桌上产生的压强约1 Pa | 1 m水柱约9.8 kPa |
| atm(大气压) | 约101 kPa | 约10.3 m水柱、760 mm汞柱 | 用水柱或汞柱气压计测量 |
| cal(卡) | 约4.18 J | 让1 g水升高1°C的热量 | 加热已知质量的水,测温度升高 |
| kcal(千卡) | 约4.18 kJ | 让1 kg水升高1°C;食物热量常用这个单位 | 同上 |
| kWh(千瓦时) | 3600000 J | 把1 t的东西举高约367 m;俗称"1度电" | 由W和h算出 |
| Hz(赫兹) | 每秒1次 | 秒摆来回一次(完整周期)是0.5 Hz | 数每秒振动几次 |

大气压的测量见[物理-压强与流体](02-物理.md#四压强与流体);热量的计算见[物理-热学](02-物理.md#五热学)。

### 7.2 电学

电学单位不能直接从米、千克、秒"看出来",要借助化学和热学的方法标定。

```
安培(A): 电解铜(最可靠)
原理: 通过的电量和析出的金属质量成正比(法拉第定律)
  1 A的电流通过1小时,在阴极上析出约1.186 g铜
做法:
1. 两块铜片插在硫酸铜溶液里,接上电源和要校准的电流表(串联)
2. 阴极铜片先洗净、烘干、称重
3. 保持电流稳定,通电一段时间(如1小时)
4. 取出阴极,轻轻冲洗、烘干,再称重,算出增加了多少克
5. 电流(A) = 析出铜的质量(g) ÷ 1.186 ÷ 通电时间(h)
   例: 2小时析出2.20 g → 电流 = 2.20 ÷ 1.186 ÷ 2 ≈ 0.93 A
6. 和电流表读数比较,得出修正值
精度: 认真做约百分之一
⚠️ 硫酸铜有毒,不要误食,溅到眼睛立即冲洗
```

```
伏特(V): 两种方法
方法一: 丹尼尔电池(锌-铜电池)
- 锌片插在硫酸锌溶液中,铜片插在硫酸铜溶液中,
  两种溶液用一个未上釉的素烧陶罐隔开(离子能通过,溶液不混合)
- 两极之间的电压约1.10 V(用高内阻的电压表在不取电流时测量)
- 精度: 百分之几,和溶液浓度、温度有关

方法二: 电热法(更基本)
- 用校准好的电流表,让电流I通过一段浸在水里的电阻丝
- 测出水的质量m、温度升高ΔT、通电时间t
- 功率 P = m × 4.18 × ΔT ÷ t(m单位g,ΔT单位°C,t单位s,P单位W)
- 电压 V = P ÷ I
- 容器要保温,时间不要太长,减少散热损失
```

```
欧姆(Ω): 由伏特和安培算出,R = V ÷ I
另一个方便的标准: 铜导线
- 20°C时,截面积1 mm²、长1 m的纯铜线,电阻约0.0172 Ω
- 截面积1 mm²的铜线约58 m长时,电阻约1 Ω
- 回收的电线铜很纯,适合做电阻标准;温度每升高10°C,电阻约增加4%
```

原电池和法拉第定律见[化学进阶-电化学](../09-进阶科学与工程/05-化学进阶.md#五电化学);导线电阻见[物理-导线的电阻](02-物理.md#74-导线的电阻);电表的制作见[电气工程与电子学-电气测量](../09-进阶科学与工程/02-电气工程与电子学.md#九电气测量);素烧陶罐见[陶瓷、玻璃与造纸](../07-日常生活技能/11-陶瓷玻璃与造纸.md)。

### 7.3 化学和原子

```
mol(摩尔): 1 mol物质的质量(g)等于它的相对分子质量
  例: 1 mol碳 = 12 g,1 mol水 = 18 g,1 mol食盐(NaCl)= 58.5 g
  → 有了千克和元素周期表上的原子量,就有了mol
  0°C、1个标准大气压下,1 mol任何气体的体积约22.4 L

eV(电子伏): 原子尺度的能量单位,约1.6 × 10⁻¹⁹ J,只用于理论计算
```

原子量见[元素周期表](05-元素周期表.md)。

### 7.4 做不出来的单位

```
放射性和辐射剂量(Bq、Sv、mSv):
- 需要专门的探测器和标准放射源,没有现代工业无法重新标定
- 保存下来的辐射剂量仪只能相信它原来的校准
- 自制的验电器(金属箔片)能看出"有没有、多不多",但给不出Sv的数值
→ 遇到核辐射,按核灾难章节的原则(远离、屏蔽、减少时间)行动,不要依赖自制仪器的数值

其他精密量(如药物的毫克、微克级剂量): 自制的天平很难做到,
  尽量依靠保存下来的原包装药品和说明书
```

核灾难的防护见[人为灾难](../02-灾难应对/05-人为灾难.md)、[末日求生-核灾难](../03-野外生存/06-末日求生.md#核灾难)。

## 八、制作和保存标准

### 8.1 逐级复制

```
原器(最高标准):
- 一根标准米尺、一个标准千克砝码
- 用不生锈、不易变形的材料: 黄铜、青铜、不锈钢;石头砝码也可以(不会生锈)
- 平时锁起来,不用来干活,只用来校准下一级

工作标准(每个村、每个作坊一套):
- 照着原器复制,定期(如每年)拿回来和原器比较

日常量具(尺子、秤、量杯):
- 照着工作标准制作,经常校准
```

### 8.2 注意事项

```
长度:
- 尺子上刻两条很细的线,两线之间的距离就是1 m(比用尺子的两端更准,端面会磨损)
- 金属热胀冷缩: 黄铜尺温度每变化10°C,1 m会变化约0.2 mm
  → 规定在一个固定的温度(如20°C)下比较
质量:
- 不用手直接拿砝码(汗会腐蚀),用布或夹子
- 防潮、防锈、防磕碰;掉落过的砝码要重新核对
- 铁砝码会生锈变重,不适合做原器
比较方法:
- 长度: 两把尺子并排放,用放大镜对齐刻线
- 质量: 等臂天平,用交换称量法

✓ 原器做两到三份,分开保存在不同地方(防火、防丢失)
✓ 把原器的制作方法、日期、比较的结果写成文字记录,和原器放在一起
✓ 社区的所有交易、工程、配药都使用同一套标准
```

统一量具和交易见[记账、交易与社会分工-交易](../07-日常生活技能/13-记账交易与社会分工.md#交易)。

## 九、读懂古书和旧文献中的单位

历代的尺、斤、升差别很大,读古书、古方时不能按今天的市制来理解。下表是大致的数值(各朝代内部也有变化,学界也有不同说法):

| 时代 | 1尺 | 1斤 | 1升 |
|------|-----|-----|-----|
| 秦汉 | 约23 cm | 约250 g | 约200 mL |
| 隋唐 | 约30 cm | 约600-680 g | 约600 mL |
| 宋元 | 约31 cm | 约600-640 g | 约600-900 mL |
| 明清 | 约32 cm | 约597 g | 约1 L |
| 1959年以后的市制 | 1/3 m | 500 g | 1 L |

```
- 1959年以前,1斤 = 16两;之后改为1斤 = 10两
  → 旧书里的"半斤八两"就是这个来历
- 中医古方: 不同朝代的"一两"差别很大(汉代约15.6 g,明清约37 g);
  现代中医通常按1钱 ≈ 3 g、1两 ≈ 30 g折算,但汉代方剂的折算有争议
  ⚠️ 古方剂量不能直接照搬,见中药制剂
- 英制单位: 见度量衡与科学方法-市制和英制
```

市制和英制的换算见[度量衡与科学方法-市制和英制](00-度量衡与科学方法.md#32-市制和英制);中药剂量见[中药制剂](../06-制药技术/04-中药制剂.md)。

## 十、检查清单

- [ ] 找到并保护好废墟中的钢卷尺、钢直尺、电子秤、温度计、万用表
