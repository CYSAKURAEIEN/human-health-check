# 测量与制图

> **修水渠要知道哪边高、高多少,分土地要知道面积和边界,找回一个地方要有地图——测量是把"大概"变成"确切"的本事**

## ⚠️ 本章的定位

[度量衡与科学方法](00-度量衡与科学方法.md#四没有仪器时的测量)讲了画直角、找水平、测高度这些单项的方法。本章把它们连起来,讲怎样测出远处一点的位置(三角测量)、怎样测出两地的高差(水准测量)、怎样画出一张地图,以及怎样丈量土地、记录边界。

```
⚠️ 安全和注意:
- 野外测量至少两人同行,注意脚下的陡坎、水边和交通
- 不要为了测量去攀爬危险的高处或下到深沟里
- 边界涉及利益: 丈量土地时请有关各方都在场,结果当场确认、签字
```

需要的数学: [比例尺](01-数学.md#23-比例尺)、[勾股定理和面积](01-数学.md#四几何)、[三角函数](01-数学.md#五三角函数)。

## 一、测量工具

### 1.1 量距离

```
测绳: 一根不易伸缩的绳子(麻绳先浸湿拉伸再晾干,减少伸缩),每1 m做一个记号,
  每5 m、10 m做明显的记号
  → 用回收的卷尺先校准测绳;没有卷尺时用重建的米(见度量衡与科学方法)
测链: 铁丝做成的链节,比绳子更不容易伸缩,历史上的测量多用测链
步测: 先在已知距离上校准自己的步长,误差约百分之几,适合粗略测量

✓ 量距离时拉直、拉平,坡地上分段水平地量(测绳一端抬起,用铅垂线对点)
✓ 往返各量一次,取平均值
```

### 1.2 定直线: 标杆

```
标杆: 约2 m长的直木杆,下端削尖,涂上红白相间的颜色(便于远处看清)
定直线:
1. 在起点A和终点B各立一根标杆
2. 一人站在A后面看向B,另一人拿着第三根标杆在中间移动,
   直到三根标杆重叠成一根 → 这一点就在AB直线上
3. 依次插下去,就能在地上标出一条长直线
铅垂线: 让标杆竖直
```

### 1.3 量角度

```
罗盘(指南针): 测方位角(从正北顺时针量起的角度,0°-360°)
  ⚠️ 指南针指的是磁北,和真北有偏差(磁偏角),附近有铁器、电线会受干扰

自制测角仪:
1. 把量角器(或自己在木板上画的刻度盘)固定在一块水平的木板上,
   木板装在一根插在地里的木桩上
2. 在刻度盘的中心装一根能转动的瞄准尺: 两端各竖一根细钉或带细缝的小板,
   从一端的缝看过去对准另一端的钉,就是视线方向
3. 先对准一个目标读刻度,再转到另一个目标读刻度,两数之差就是两目标间的水平夹角
4. 用找水平的方法(见1.4)把木板调平

测高度角(仰角): 用象限仪——四分之一圆的刻度板,挂一根铅垂线
  (见天文导航进阶-测角仪器)
```

磁偏角见[天文导航进阶-磁偏角](../09-进阶科学与工程/09-天文导航进阶.md#24-磁偏角);象限仪见[天文导航进阶-测角仪器](../09-进阶科学与工程/09-天文导航进阶.md#五测角仪器)。

### 1.4 找水平

```
连通管: 透明软管灌满水,两端水面等高(精度高,适合短距离)
水平尺: 三角形木架加铅垂线(见度量衡与科学方法-找水平)

A字架(修梯田、开等高垄最实用):
1. 用三根木条钉成一个大"A"字形: 两条腿约2 m长,两脚之间约2 m,中间钉一根横档
2. 从顶点挂一根铅垂线
3. 校准: 把A字架两脚放在地上,在横档上标出铅垂线的位置;
   原地把A字架掉转180°(两脚交换位置),再标一次;
   两个记号的正中间就是"水平点"
4. 使用: 一只脚固定,另一只脚在坡上上下移动,直到铅垂线对准水平点
   → 两只脚就在同一高度上;一步一步往前走,连起来就是一条等高线
```

## 二、距离和高度的间接测量

### 2.1 测不能直接到达的距离

```
相似三角形和全等三角形的方法(测河宽、测树高)见度量衡与科学方法

用三角函数(需要测角仪):
- 测河宽: 在岸上沿河量一段基线AB,在A点测出对岸目标C与AB的夹角,
  在B点使∠ABC = 90°(站在正对C的位置)
  → 河宽 BC = AB × tan(∠A)
  例: AB = 50 m,∠A = 40°,tan 40° ≈ 0.839 → BC ≈ 42 m
```

测河宽、树高的基本方法见[度量衡与科学方法-测高度和宽度](00-度量衡与科学方法.md#43-测高度和宽度)。

### 2.2 测高度

```
测仰角法:
- 站在离物体水平距离为d的地方,用象限仪测出物体顶端的仰角θ
- 高度 = d × tan θ + 眼睛离地的高度
例: d = 30 m,θ = 35°,tan 35° ≈ 0.700,眼高1.5 m
  高度 ≈ 30 × 0.700 + 1.5 = 22.5 m
```

## 三、三角测量

### 3.1 原理

```
只要知道三角形一条边的长度和两个角,就能算出另外两条边
→ 先精确地量一条"基线",然后只测角度,就能求出远处各点的位置
  (测角比量长距离容易得多,也准得多)

正弦定理: a / sin A = b / sin B = c / sin C
```

### 3.2 步骤

```
1. 在平坦的地方选一条基线AB,精确地量出长度(往返量几次取平均)
2. 在A点测出目标C与基线的夹角∠A,在B点测出∠B
3. ∠C = 180° - ∠A - ∠B
4. 用正弦定理算出 AC 和 BC

例: AB = 100 m,∠A = 60°,∠B = 70°
  ∠C = 180° - 60° - 70° = 50°
  AC = AB × sin B ÷ sin C = 100 × 0.940 ÷ 0.766 ≈ 122.7 m
  BC = AB × sin A ÷ sin C = 100 × 0.866 ÷ 0.766 ≈ 113.1 m
  C到基线的垂直距离 = AC × sin A ≈ 122.7 × 0.866 ≈ 106.3 m

✓ 三角形最好接近等边: 某个角太小(小于约20°),一点测角误差就会让结果差很多
✓ 再以AC或BC为新的基线,继续测下一个点 → 三角网,可以覆盖很大的范围
```

### 3.3 不用计算: 平板仪交会法

```
1. 一块平整的木板钉上白纸,装在三脚架上调平
2. 在A点: 在纸上点出a(代表A),用一把带瞄准的直尺,从a向各个目标瞄准,
   沿尺边画出方向线
3. 量出AB的距离,按比例尺在纸上的AB方向线上定出b
4. 把平板搬到B点,对齐方向(让纸上的ba对准地面上的A),
   再从b向各个目标瞄准、画线
5. 两次方向线的交点,就是各个目标在图上的位置
→ 边测边画,直接得到一张地图
```

## 四、水准测量

修水渠、排水沟、引水管道,必须知道沿途各点的高差: 水只能往低处流,高差估计错了,渠就修不成。

### 4.1 原理

```
1. 在A、B两点各竖一根有刻度的标尺(水准尺,每1 cm一格的木杆)
2. 在两点中间放一台能看出水平视线的仪器(水准仪)
3. 先看A尺,读出水平视线落在尺上的读数(后视读数)
4. 再看B尺,读出读数(前视读数)
5. B比A高出 = 后视读数 - 前视读数
   (结果为负数,说明B比A低)

✓ 仪器放在两尺的正中间,能抵消仪器本身不完全水平带来的误差
```

### 4.2 简易水准仪

```
- 连通管法: 一根长的透明软管灌满水,一端贴在A尺上、一端贴在B尺上,
  分别读出两端水面在尺上的读数,两读数之差就是高差
  (两人操作,距离受管长限制,精度很高)
- 瞄准管: 一根直管(或带两个瞄准孔的木条)固定在水平尺上,
  调到水平后沿管看出去,就是一条水平视线
- 有回收的激光水平仪、水准仪更好
```

### 4.3 长距离: 逐站推进

```
距离远时,一站一站地测,把每一站的高差加起来

例: 从A测到B,中间设一个转点1
  第一站: A尺读数1.52 m,转点1尺读数0.87 m → 高差 = +0.65 m
  第二站: 转点1尺读数1.20 m,B尺读数1.65 m → 高差 = -0.45 m
  A到B总高差 = 0.65 - 0.45 = +0.20 m → B比A高0.20 m

检查: 从B再测回A,高差应该大小相等、符号相反;差得太多就要重测
✓ 记录表: 站号、后视读数、前视读数、高差、累计高差
```

### 4.4 给水渠放坡

```
坡度 = 高差 ÷ 水平距离
- 土渠: 约1/1000左右水就能流动(每100 m降低约0.1 m)
- 坡度太小: 水流慢、容易淤积;坡度太大: 水流冲刷渠底和渠岸
- 排水沟、污水沟要更陡一些,防止淤积

放坡步骤:
1. 从水源处开始,确定渠底的起点高程
2. 每隔一段距离(如20 m)打一根木桩
3. 用水准测量算出每根木桩处的渠底应该在什么高度(比上一根低0.02 m,即1/1000)
4. 在木桩上标出渠底的位置,按记号挖
5. 放水试流,找出积水和冲刷的地方修整
```

引水的做法见[水源工程与供水-输水和提水](../07-日常生活技能/10-水源工程与供水.md#输水和提水)。

## 五、绘制地图

### 5.1 地图的要素

```
每张地图都要有:
✓ 比例尺: 例如1:10000表示图上1 cm代表实际100 m
✓ 指北方向: 标明是真北还是磁北
✓ 图例: 各种符号代表什么(水井、道路、房屋、田地、河流)
✓ 绘制日期和绘制人
✓ 等高线(需要表示地形时)
```

比例尺换算见[数学-比例尺](01-数学.md#23-比例尺);读地图和等高线见[户外出行准备与求救-看懂地图和等高线](../03-野外生存/07-户外出行准备与求救.md#看懂地图和等高线)。

### 5.2 导线测量: 沿一条路线测绘

```
沿一条路线(道路、河流、田地边界)一段一段地测:
1. 在路线的每个转折点设一个点(插标杆): 1、2、3……
2. 在每一点用罗盘测出到下一点的方位角,用测绳量出距离
3. 记录: 起点 → 终点、方位角、距离
4. 在纸上按比例尺,从起点按方位角和距离一段段画出来

闭合导线: 绕一圈回到起点
- 画出来的终点应该和起点重合;不重合的距离就是"闭合误差"
- 误差小时,把它按各段距离的比例分摊到各点上修正;误差太大就要重测
```

### 5.3 测绘一个区域

```
1. 先用三角测量或导线测量建立一个"骨架"(几个位置准确的控制点)
2. 再从控制点出发,测量周围的房屋、水井、道路、田块
   (量距离加方位角,或者用平板仪交会)
3. 地形: 用水准测量测出一批点的高程,在图上标出,
   把高程相同的点用平滑的曲线连起来,就是等高线
4. 在野外画草图,回来后整理成正式的图,多抄几份保存
```

### 5.4 用坐标记录位置

```
在地图上画方格网,每个点用(东, 北)两个数表示位置:
- 选一个固定的原点(一块大石头、一口井)
- 向东量多少米是x,向北量多少米是y
- 一个点距原点的距离 = √(x² + y²)

由方位角α和距离d,求下一点的坐标:
  x₂ = x₁ + d × sin α
  y₂ = y₁ + d × cos α
例: 从(0, 0)出发,方位角30°,距离100 m
  x = 100 × sin 30° = 50 m,y = 100 × cos 30° ≈ 86.6 m

经纬度: 用天文方法测出(见天文导航进阶)
```

测纬度和经度见[天文导航进阶-测纬度](../09-进阶科学与工程/09-天文导航进阶.md#三测纬度);坐标的数学见[数学-坐标](01-数学.md#61-坐标)。

## 六、土地丈量与边界

### 6.1 计算面积

```
规则形状: 见数学-面积公式
  长方形 = 长 × 宽;三角形 = 底 × 高 ÷ 2;梯形 = (上底 + 下底) × 高 ÷ 2

不规则地块: 分成几个三角形,分别算面积再加起来
  只量三条边时用海伦公式:
  s = (a + b + c) ÷ 2
  面积 = √[s × (s - a) × (s - b) × (s - c)]
  例: 三边为30 m、40 m、50 m → s = 60 → 面积 = √(60 × 30 × 20 × 10) = 600 m²

有各角点的坐标时(坐标法):
  按顺序列出各点(x₁, y₁)、(x₂, y₂)……(xₙ, yₙ),再回到第一点
  面积 = |Σ(xᵢ × yᵢ₊₁ - xᵢ₊₁ × yᵢ)| ÷ 2
  例: (0, 0)、(40, 0)、(50, 30)、(10, 40)
    0×0 - 40×0 = 0
    40×30 - 50×0 = 1200
    50×40 - 10×30 = 1700
    10×0 - 0×40 = 0
    面积 = (0 + 1200 + 1700 + 0) ÷ 2 = 1450 m²

单位: 1 ha = 10000 m²
坡地: 量的是水平距离还是沿坡的距离要说清楚,约定统一的方法
```

面积公式见[数学-面积公式](01-数学.md#44-面积公式)。

### 6.2 标记边界

```
✓ 在地块的每个拐角埋设界桩: 石头、大块的砖、刻了记号的木桩(木桩会腐烂,
  最好用石头);在界桩下面埋一些木炭或碎瓷片作为暗记,即使界桩被移动也能找到
✓ 利用不会移动的自然标志: 大石头、河岸、山脊
✓ 种植作为边界的树或灌木
```

### 6.3 记录边界

```
地块档案(每块地一页):
- 地块编号、名称、位置
- 四至: 东、南、西、北分别和谁的地或什么地物相邻
- 各边的长度、各拐角的方位角(或坐标)
- 面积
- 草图(标出界桩)
- 丈量日期、丈量人、相邻各方的签字

✓ 一式多份,分别保存
✓ 有争议时,先找界桩和档案,而不是凭记忆
```

社区档案见[记账、交易与社会分工-社区档案](../07-日常生活技能/13-记账交易与社会分工.md#社区档案)。

## 七、测量用在哪里

| 用途 | 用到的方法 |
|------|-----------|
| 盖房放线 | 3-4-5直角、找水平、定直线 |
| 修梯田、等高种植 | A字架定等高线 |
| 修水渠、排水沟、引水管道 | 水准测量、放坡 |
| 分地、记录边界 | 面积计算、界桩、地块档案 |
| 画本地地图 | 导线测量、三角测量、平板仪 |
| 找回某个地点(水源、仓库、矿点) | 坐标、方位角和距离 |
| 测量桥梁跨度、河宽 | 三角函数 |

梯田和等高种植见[地质、矿物与土壤-保护土壤](06-地质矿物与土壤.md#55-保护土壤);盖房放线见[长期住所](../07-日常生活技能/05-长期住所.md)。
