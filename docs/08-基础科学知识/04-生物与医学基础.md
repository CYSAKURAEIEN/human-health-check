# 生物与医学基础

> **人类平均寿命翻倍,主要不是靠高深的医术,而是靠几个简单的认识: 病是由看不见的微生物引起的、要洗手、要喝干净的水、要接种疫苗**

## ⚠️ 本章的定位

本章讲的是**原理**: 为什么会生病、为什么洗手和煮沸有用、为什么疫苗和抗生素有效、为什么要选种留种。具体的疾病处理和急救操作见[急救与家庭健康](../01-日常疾病和伤害/README.md)部分,药物的使用见[制药技术](../06-制药技术/README.md)部分。

```
对人类寿命影响最大的几个认识(按影响大小大致排序):
1. 很多病由微生物引起,会传染 → 洗手、消毒、隔离
2. 粪便污染饮用水会传播疾病 → 干净的水、厕所远离水源
3. 疫苗可以预防传染病 → 天花被消灭,很多儿童传染病大幅减少
4. 某些病是缺乏营养引起的 → 坏血病、脚气病可以靠饮食预防
5. 抗生素能治疗细菌感染 → 但会产生耐药,不能滥用

这些认识大多在近两三百年才确立,而且在确立之前,人类花了几千年时间相信错误的解释
(如"瘴气""体液不平衡")。
```

## 一、细胞和微生物

### 1.1 细胞

```
一切生物都由细胞构成,细胞只能由原有的细胞分裂产生
- 人体约有几十万亿个细胞
- 细菌是单个细胞
- 细胞太小,肉眼看不见,要用显微镜

显微镜: 两个凸透镜组合(见物理-透镜)
  17世纪列文虎克用自制的单透镜显微镜第一次看到了细菌
```

### 1.2 引起疾病的微生物和寄生虫

| 类型 | 大小 | 例子 | 能否用抗生素治疗 |
|------|------|------|----------------|
| 细菌 | 约千分之一毫米,普通光学显微镜能看到 | 结核、霍乱、伤寒、破伤风、伤口化脓 | 能 |
| 病毒 | 比细菌小得多,普通显微镜看不到 | 感冒、流感、麻疹、狂犬病、乙肝 | **不能** |
| 真菌 | 有的是单细胞(酵母),有的是丝状(霉菌) | 脚气、癣、鹅口疮 | 要用抗真菌药 |
| 寄生虫 | 从单细胞到几米长 | 疟疾、蛔虫、绦虫、疥螨、头虱 | 要用对应的驱虫药 |

```
⚠️ 绝大多数微生物是无害甚至有益的:
- 肠道细菌帮助消化、合成维生素
- 酵母发面酿酒,乳酸菌做酸菜酸奶
- 土壤微生物分解落叶粪便,让土地肥沃
```

## 二、病菌学说: 改变人类命运的认识

### 2.1 历史上的几个关键事件

```
1847年 洗手: 匈牙利医生塞麦尔维斯发现,医生解剖尸体后不洗手就去接生,
  产妇大量死于产褥热;要求用含氯的消毒液洗手后,产妇死亡率从10%以上
  降到约1-2%。当时很多医生不相信他

1854年 水井: 英国医生斯诺把伦敦霍乱病人的住址标在地图上,发现病例集中在
  一口公共水井周围;拆掉水泵的把手后,疫情得到控制
  → 证明霍乱通过被污染的水传播(而不是"瘴气")

1860年代 巴斯德: 用实验证明食物腐败和发酵是微生物引起的,
  微生物不会凭空产生;发明巴氏消毒法

1867年 李斯特: 在外科手术中用石炭酸消毒伤口和器械,手术后感染死亡率大幅下降

1880年代 科赫: 找到引起结核病、霍乱的细菌,
  建立了证明"某种细菌引起某种病"的方法
```

### 2.2 由此得出的做法

```
认识: 病菌从病人、粪便、脏水、脏手传到健康人身上
做法:
✓ 洗手: 饭前、便后、接触病人后、处理伤口前
✓ 只喝煮沸或消毒过的水
✓ 厕所远离水源,粪便不污染水和食物
✓ 伤口清洗消毒,器械煮沸
✓ 病人隔离,用过的东西消毒
✓ 食物煮熟,剩饭冷藏

这些做法都很简单,不需要任何高科技,但效果超过绝大多数药物。
```

具体做法见[传染病家庭防控](../01-日常疾病和伤害/15-传染病家庭防控.md)、[卫生设施](../07-日常生活技能/03-卫生设施.md)。

### 2.3 怎样杀灭和抑制微生物

| 方法 | 原理 | 效果和局限 |
|------|------|-----------|
| 煮沸 | 高温使微生物的蛋白质变性 | 能杀死绝大多数细菌和病毒;杀不死某些细菌的芽孢(如肉毒杆菌、破伤风杆菌) |
| 高压蒸汽(约121°C,15分钟以上) | 更高的温度 | 能杀死芽孢,是最可靠的灭菌方法 |
| 酒精(70-75%) | 使蛋白质变性 | 对多数细菌病毒有效;对诺如病毒、芽孢效果差 |
| 含氯消毒剂、碘 | 氧化破坏微生物 | 广谱有效;有腐蚀性 |
| 干燥 | 微生物需要水才能繁殖 | 晒干的食物能长期保存 |
| 高浓度盐、糖 | 把微生物体内的水"吸"出来 | 腌制、蜜饯 |
| 酸 | 大多数致病菌在酸性环境中不能繁殖 | 醋泡、酸菜 |
| 低温 | 冷藏减慢繁殖,冷冻停止繁殖,但不能杀死 | 解冻后又会繁殖 |
| 阳光(紫外线) | 破坏微生物的遗传物质 | 只能辅助 |

```
⚠️ 肉毒杆菌芽孢能耐受100°C,在密封、缺氧、低酸的罐头里会繁殖并产生毒素
   → 没有压力锅时不要自制蔬菜、肉类罐头
```

食物保存见[食物加工与保存](../07-日常生活技能/01-食物加工与保存.md);消毒灭菌的操作见[基础制药知识](../06-制药技术/00-基础制药知识.md)。

## 三、免疫和疫苗

### 3.1 免疫

```
人体有两道防线:
1. 天生的防线: 皮肤、黏膜、胃酸、白细胞、发烧
   → 皮肤破损(伤口、烧伤)后,这道防线就被打开了
2. 后天获得的免疫: 身体"记住"得过的病原体,
   下次遇到时能迅速消灭它
   → 很多传染病得过一次就不会再得(如麻疹、水痘)
```

### 3.2 疫苗

```
原理: 给身体看一个"假的"或"减弱的"病原体,让它提前记住,
  以后遇到真的病原体时能迅速消灭,自己却不用真的得病

历史:
- 人痘接种: 至迟在明代,我国已用天花病人的痘痂接种预防天花
  (有一定风险,少数接种者会发病)
- 1796年 琴纳: 发现得过牛痘的挤奶工不得天花,用牛痘接种,更安全
- 1980年: 世界卫生组织宣布天花被彻底消灭——
  人类第一次用疫苗消灭了一种传染病

群体免疫: 接种的人足够多时,病原体找不到足够的人传播,
  没法接种的人(婴儿、病人)也会受到保护
```

```
⚠️ 疫苗必须由正规机构生产、按规定冷藏运输、按程序接种
   自制"疫苗"极其危险,可能直接让人感染或发生严重反应
✓ 保存好全家的疫苗接种记录
✓ 被动物咬伤后接种狂犬病疫苗,受伤后按需接种破伤风疫苗
```

疫苗接种见[传染病家庭防控-疫苗](../01-日常疾病和伤害/15-传染病家庭防控.md#疫苗)。

## 四、抗生素和耐药

```
抗生素: 能杀死或抑制细菌的药物
  1928年弗莱明发现青霉素,1940年代开始大规模用于治疗,
  肺炎、伤口感染、产褥热等从致命变得可以治疗

⚠️ 抗生素对病毒无效: 感冒、流感大多是病毒引起的,吃抗生素没有用

耐药是怎么产生的(自然选择,见第六节):
- 用抗生素时,大部分细菌被杀死,少数天生不怕这种药的活了下来
- 活下来的细菌繁殖,下一代就都不怕这种药了
- 滥用、吃吃停停、剂量不足,都会加快耐药菌的产生

所以:
✓ 只在确实是细菌感染时使用,按医生要求的剂量和疗程用完
✓ 不要把抗生素当"消炎药"随便吃
✓ 预防感染(洗手、清洗伤口)比治疗更重要
```

为什么不能自制抗生素,以及天然抗菌物质的作用和局限,见[抗生素制备](../06-制药技术/02-抗生素制备.md)。

## 五、营养

### 5.1 营养素

```
三大能量来源:
- 糖类(淀粉): 每克约4千卡,主要来自粮食
- 脂肪: 每克约9千卡
- 蛋白质: 每克约4千卡,构成肌肉、血液、免疫物质;来自肉蛋奶、豆类

维生素和矿物质: 需要量很少,但缺了会生病
```

### 5.2 营养缺乏病的发现

| 疾病 | 缺什么 | 历史上的发现 | 预防 |
|------|--------|-------------|------|
| 坏血病(牙龈出血、伤口不愈) | 维生素C | 1747年林德在船上做对照试验: 吃柑橘的水手很快好转 | 新鲜蔬果、豆芽 |
| 脚气病(腿脚无力、水肿、心衰) | 维生素B1 | 吃精白米的人群多发,吃糙米的少 | 别把米碾得太白,杂粮 |
| 糙皮病(皮炎、腹泻、痴呆) | 烟酸 | 以玉米为主食又不用碱处理的地区多发 | 玉米用碱处理,吃豆类 |
| 甲状腺肿(大脖子病)、克汀病 | 碘 | 远离海洋的山区多发 | 碘盐 |
| 贫血 | 铁等 | | 肉、动物血、肝、豆类 |
| 夜盲症 | 维生素A | | 动物肝脏、深色蔬菜 |
| 佝偻病(骨骼变形) | 维生素D | 缺少日照的儿童多发 | 晒太阳 |

```
林德的坏血病试验是历史上最早的对照临床试验之一:
  把12个患坏血病的水手分成6组,每组用不同的方法治疗,
  只有吃柑橘的那组明显好转 → 对照实验的威力(见度量衡与科学方法)
```

实际的预防方法见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md)。

## 六、遗传和进化

### 6.1 遗传

```
子代会继承亲代的特征,遗传信息储存在细胞里的DNA中

孟德尔的豌豆实验(1860年代):
- 纯种高茎和纯种矮茎豌豆杂交,第一代全是高茎
- 第一代自交,第二代高茎和矮茎大约是 3 : 1
- 说明: 性状由成对的"遗传因子"(基因)控制,
  有显性和隐性之分,隐性性状可能隔代出现
```

### 6.2 选种育种

```
人类几千年来一直在用遗传规律,只是不知道原理:
✓ 每年从长得最好、最抗病的植株上留种
✓ 选最健壮、产量最高的牲畜配种
→ 一代一代积累,作物和牲畜越来越好

⚠️ 杂交种(F1代)不适合留种:
   杂交第一代整齐高产(杂种优势),但它的种子种下去,
   第二代会出现性状分离,产量和品质参差不齐
   → 长期自给自足,要储备和种植能留种的传统品种
```

留种方法见[粮食作物-种子保存](../04-动植物培育/02-粮食作物.md#种子保存)。

### 6.3 近亲繁殖的危害

```
近亲之间携带相同隐性致病基因的可能性大,
后代表现出隐性遗传病的几率显著升高
- 牲畜: 长期近亲配种会体弱、多病、繁殖力下降 → 定期引入外来种畜
- 人: 我国法律禁止直系血亲和三代以内旁系血亲结婚
```

### 6.4 进化和自然选择

```
- 同一种生物的个体之间有差异
- 这些差异有一部分能遗传
- 环境中能更好生存繁殖的个体留下更多后代
- 一代代积累,生物就会改变

能解释:
- 细菌对抗生素产生耐药
- 害虫对农药产生抗药性 → 轮换使用不同的农药,不要一种药一直用
- 作物和家畜的驯化(人工选择)
```

## 八、生态与农业生物学

### 8.1 物质循环

```
碳循环: 植物通过光合作用吸收二氧化碳 → 动物吃植物 →
  呼吸、分解、燃烧又把碳变回二氧化碳

氮循环: 空气中的氮气 → 豆科植物根瘤菌、闪电固定成植物能用的氮 →
  植物 → 动物 → 粪便、尸体被微生物分解 → 回到土壤
  → 这就是种豆能肥田、粪肥能肥田的原因
```

化学原理见[化学-氮肥和合成氨](03-化学.md#410-氮肥和合成氨)。

### 8.2 农业中的生物学

```
轮作: 同一块地年年种同一种作物,专门危害这种作物的病虫害会越积越多,
  土壤中它需要的养分会越来越少 → 不同作物轮流种,中间种豆科植物

授粉: 很多果树、瓜类需要蜜蜂等昆虫授粉才能结果
  → 保护蜜蜂,开花期不打农药;缺少昆虫时可以人工授粉

堆肥: 微生物分解有机物时放热,好的堆肥中心温度可以达到55°C以上,
  能杀死大部分病原体和杂草种子
  → 粪便必须充分堆沤或长时间储存后才能施用

食物链: 每往上一级,能量只能传递一小部分(大约十分之一)
  → 同样的土地,种粮食直接吃能养活的人,比种饲料养牲畜再吃肉要多得多
```

粪便利用见[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用)。

## 九、流行病学基础

研究疾病在人群中怎样分布和传播,是控制传染病的科学。

```
1. 记录病例: 谁、什么时间、在哪里、有什么症状
2. 找共同点: 病人都喝了同一口井的水?吃了同一顿饭?接触过同一个人?
   (斯诺的霍乱地图就是这样找到污染水源的)
3. 切断传播途径: 封闭污染的水源、隔离病人、消毒

几个概念:
- 潜伏期: 从感染到出现症状的时间
  → 接触过病人的人要观察到最长潜伏期结束
- 传染期: 病人能传染给别人的时间,有时在症状出现之前就开始了
- 每个病人平均传染给几个人:
  大于1 → 病例越来越多;小于1 → 疫情逐渐消退
  → 隔离、洗手、戴口罩、接种疫苗,都是为了把这个数降到1以下

隔离与检疫:
- 隔离: 把病人和健康人分开
- 检疫: 把可能被感染、但还没发病的人观察一段时间
  ("检疫"的英文一词来自意大利语的"四十天",
   中世纪威尼斯让来自疫区的船只在港外停泊四十天)
```

## 十、重大发现时间线

| 时间 | 发现 | 意义 |
|------|------|------|
| 1670年代 | 列文虎克用显微镜看到微生物 | 人类第一次看见细菌 |
| 至迟明代 | 我国用人痘接种预防天花 | 最早的免疫预防方法之一 |
| 1747年 | 林德用对照试验证明柑橘能治坏血病 | 对照临床试验的开端 |
| 1796年 | 琴纳用牛痘预防天花 | 疫苗的开端 |
| 1847年 | 塞麦尔维斯要求医生洗手 | 产妇死亡率大幅下降 |
| 1854年 | 斯诺证明霍乱通过水传播 | 流行病学的开端 |
| 1860年代 | 巴斯德证明微生物引起腐败和发酵 | 病菌学说确立 |
| 1866年 | 孟德尔发表豌豆杂交实验 | 遗传学的开端 |
| 1867年 | 李斯特用消毒法做外科手术 | 无菌手术的开端 |
| 1880年代 | 科赫发现结核杆菌、霍乱弧菌 | 证明特定细菌引起特定疾病 |
| 1928年 | 弗莱明发现青霉素 | 抗生素时代的开端 |
| 1953年 | 发现DNA的双螺旋结构 | 现代分子生物学的开端 |
| 1980年 | 天花被宣布消灭 | 人类第一次消灭一种传染病 |
