# 化学

> **烧石灰、炼铁、做肥皂、酿酒、消毒——理解物质怎样变化,就能把石头、草木灰、粮食变成需要的东西**

## ⚠️ 安全第一

**本章介绍化学原理,目的是理解生产生活中的化学变化,不是化学实验指导。** 很多化学品有腐蚀性、有毒或易燃:

- ☠️ 强酸、强碱会严重烧伤皮肤和眼睛,操作时戴手套和护目镜
- ☠️ 多种清洁剂混合会产生有毒气体(见第九节)
- ☠️ 铅、汞等重金属会在体内蓄积,造成慢性中毒
- 🔥 酒精蒸气、氢气、沼气遇明火会燃烧爆炸
- 🏭 有气体产生的操作必须在室外或通风良好的地方进行

具体的生产操作见冶金、制药、日常生活技能等部分的相关章节,那里有更详细的安全要求。

## 一、物质的组成

### 1.1 元素、化合物、混合物

```
元素: 不能用化学方法再分的基本物质(如铁、氧、碳),目前已知118种
化合物: 两种以上元素按固定比例结合(如水 H₂O、食盐 NaCl)
  → 性质和组成它的元素完全不同: 钠是遇水爆燃的金属,氯是有毒气体,
    结合成的食盐却可以吃
混合物: 几种物质混在一起,没有固定比例(如空气、海水、土壤)
  → 可以用物理方法分开(过滤、蒸发、蒸馏)
```

### 1.2 原子和分子

```
原子: 元素的最小单位,由原子核(质子、中子)和电子组成
  质子数决定是哪种元素(氢1个,碳6个,氧8个,铁26个)
分子: 几个原子结合在一起(水分子 H₂O = 2个氢原子 + 1个氧原子)
```

### 1.3 质量守恒

```
化学反应前后,物质的总质量不变,原子的种类和数目也不变
  → 原子不会凭空出现或消失,只是重新组合
  → 木头烧完只剩一点灰,是因为大部分变成二氧化碳和水蒸气跑到空气中了
  → 铁生锈后变重,是因为结合了空气中的氧和水
```

### 1.4 摩尔: 化学计算的单位

```
1摩尔 = 6.02 × 10²³ 个粒子(阿伏伽德罗常数)
1摩尔物质的质量(克)= 它的相对分子质量
  水 H₂O: 1×2 + 16 = 18 → 1摩尔水 = 18克
  二氧化碳 CO₂: 12 + 16×2 = 44 → 1摩尔 = 44克

用途: 按方程式计算需要多少原料、能得到多少产品
  (例子见第三节)
```

### 2.2 金属活动性顺序

```
钾 钙 钠 镁 铝 锌 铁 锡 铅 (氢) 铜 汞 银 铂 金
K  Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au
←── 越活泼                                越稳定 ──→

用途:
1. 越靠后的金属越容易从矿石中炼出来
   - 金、银在自然界中能找到纯金属;铜、锡、铅用木炭就能炼出
   - 铁需要更高的温度;铝、镁要用电解法,古代炼不出来
   → 这就是人类先进入青铜时代、再进入铁器时代的原因

2. 前面的金属能把后面的金属从它的盐溶液中置换出来
   - 铁放进硫酸铜溶液,表面会析出铜(古代"湿法炼铜")
   Fe + CuSO₄ → FeSO₄ + Cu

3. 排在氢前面的金属能和稀酸反应放出氢气;
   酸性食物(醋、果汁、腌菜)不要长期放在铁、锌、铝容器里

4. 两种不同的金属连在一起放在潮湿环境中,较活泼的那个会先被腐蚀
   → 镀锌铁皮: 锌先被腐蚀,保护了铁
   → 电池: 利用两种金属活泼程度的差别产生电压
```

冶炼的具体方法见[基础冶金知识](../05-冶金技术/00-基础冶金知识.md)。

## 三、化学方程式

### 3.1 写法和配平

```
反应物 → 生成物,两边每种原子的数目必须相等

例: 氢气燃烧
  H₂ + O₂ → H₂O(没配平: 左边2个氧,右边1个)
  2H₂ + O₂ → 2H₂O(配平: 左右都是4个氢、2个氧)

常见标记: ↑ 生成气体;↓ 生成沉淀;△ 加热;⇌ 可逆反应
```

### 3.2 用方程式计算

```
例: 烧100千克石灰石(碳酸钙),能得到多少生石灰?
  CaCO₃ → CaO + CO₂↑
  100      56     44   (相对分子质量: 40+12+48=100;40+16=56;12+32=44)
  → 100千克碳酸钙,理论上得到56千克生石灰,放出44千克二氧化碳
  (石灰石不纯、烧不透时实际得到的更少)
```

## 四、改变人类社会的重要反应

### 4.1 燃烧

```
完全燃烧(氧气充足):
  C + O₂ → CO₂
  CH₄ + 2O₂ → CO₂ + 2H₂O(沼气、天然气)

不完全燃烧(氧气不足):
  2C + O₂ → 2CO
  ⚠️ 一氧化碳无色无味、剧毒 → 室内烧炭、炉子通风不良会致命

燃烧三要素: 可燃物 + 氧气 + 达到着火点
  灭火就是去掉其中一个: 隔绝空气(盖住)、降温(浇水)、移走可燃物
```

一氧化碳中毒见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

### 4.2 冶炼: 从矿石到金属

```
金属在矿石中以氧化物等形式存在,冶炼就是用碳(木炭)把氧"抢"走:
  Fe₂O₃ + 3CO → 2Fe + 3CO₂(炼铁: 赤铁矿 + 一氧化碳)
  2CuO + C → 2Cu + CO₂(炼铜)

木炭先不完全燃烧生成一氧化碳,一氧化碳再还原矿石
加入石灰石作助熔剂,和矿石中的杂质(主要是二氧化硅)结合成炉渣
```

详见[铁的冶炼](../05-冶金技术/01-铁的冶炼.md)、[铜的冶炼](../05-冶金技术/02-铜的冶炼.md)。

### 4.3 生锈

```
铁 + 氧气 + 水 → 铁锈(主要是含水的氧化铁)
  只有氧气或只有水,铁都不容易生锈;盐会加快生锈

防锈: 隔绝空气和水
  - 涂油、刷漆
  - 镀锌、镀锡
  - 保持干燥
```

### 4.4 石灰的循环: 建筑的基础

```
1. 烧石灰(约900°C以上):
   CaCO₃ → CaO + CO₂↑
   石灰石 → 生石灰

2. 消化(加水):
   CaO + H₂O → Ca(OH)₂ + 大量热
   生石灰 → 熟石灰
   ⚠️ 放出大量热,可以把水烧开,会烧伤皮肤和眼睛

3. 硬化(在空气中慢慢吸收二氧化碳):
   Ca(OH)₂ + CO₂ → CaCO₃ + H₂O
   熟石灰 → 又变回坚硬的碳酸钙

用途: 石灰砂浆砌墙、刷墙(石灰水有一定杀菌作用)、改良酸性土壤、
  消毒(撒在病死动物尸体上)、制碱(见下)
```

### 4.5 碱和肥皂

```
草木灰中含有碳酸钾(K₂CO₃),用水浸泡得到碱水

加熟石灰可以得到更强的碱(苛化):
  K₂CO₃ + Ca(OH)₂ → 2KOH + CaCO₃↓

皂化(做肥皂):
  油脂 + 碱 → 肥皂 + 甘油
  肥皂分子一头亲水、一头亲油,能把油污"拉"进水里洗掉
```

具体做法见[制皂](../07-日常生活技能/04-制皂.md)。

### 4.6 发酵

```
酒精发酵(酵母,无氧):
  C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂↑
  葡萄糖 → 酒精 + 二氧化碳(发面时让面团膨胀的也是二氧化碳)

醋酸发酵(醋酸菌,需要氧气):
  C₂H₅OH + O₂ → CH₃COOH + H₂O
  酒精 → 醋酸(酒放久了变酸)

乳酸发酵(乳酸菌,无氧):
  葡萄糖 → 乳酸
  酸菜、泡菜、酸奶;酸性环境抑制其他细菌,使食物能保存
```

食物发酵见[食物加工与保存](../07-日常生活技能/01-食物加工与保存.md);酒精的蒸馏和消毒用途见[消毒剂制备](../06-制药技术/01-消毒剂制备.md)。

### 4.7 光合作用和呼吸作用

```
光合作用(植物,需要光):
  6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂
  二氧化碳 + 水 → 葡萄糖 + 氧气
  → 地球上几乎所有食物和氧气的来源

呼吸作用(所有生物):
  C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + 能量
  → 是光合作用的逆过程,释放能量供生命活动使用
  → 密闭的菜窖、粮仓里,粮食和蔬菜的呼吸会消耗氧气、积累二氧化碳,
    下窖前要先通风
```

### 4.8 氯消毒

```
次氯酸钠(84消毒液的有效成分): NaClO
漂白粉的有效成分: 次氯酸钙 Ca(ClO)₂

它们在水中产生次氯酸(HClO),能杀灭细菌和病毒
  → 饮用水消毒、物体表面消毒

⚠️ 和酸性物质(洁厕灵)混合会放出有毒的氯气
```

消毒液的配制见[传染病家庭防控-家用消毒液的配制](../01-日常疾病和伤害/15-传染病家庭防控.md#家用消毒液的配制)。

### 4.9 水泥和玻璃

```
水泥: 石灰石 + 黏土,磨细混合后在约1450°C烧成熟料,再磨成粉
  加水后发生水化反应,慢慢变硬,在水中也能硬化
  → 比石灰砂浆坚固耐水得多;需要很高的温度,土法很难做好

玻璃: 石英砂(SiO₂)+ 纯碱(Na₂CO₃)+ 石灰石,约1400-1500°C熔化
  Na₂CO₃ + SiO₂ → Na₂SiO₃ + CO₂↑
  → 用途: 容器、窗户、透镜(眼镜、放大镜、显微镜)
```

### 4.10 氮肥和合成氨

```
氮是植物生长最需要的元素。空气中78%是氮气,但植物不能直接利用

自然的固氮方式:
- 豆科植物(大豆、花生、苜蓿、紫云英)根上的根瘤菌能把空气中的氮固定下来
- 雷电
- 动物粪便、人的尿液中含有大量氮

合成氨(哈伯法,20世纪初):
  N₂ + 3H₂ ⇌ 2NH₃
  需要高温(约400-500°C)、高压(数百个大气压)和铁催化剂
  → 化肥让粮食产量大幅提高,今天世界上很大一部分人口依靠它养活
  → 需要大型工业设备,文明崩溃后短期内无法恢复;
    要靠豆科轮作、粪肥和尿液维持土地肥力
```

肥料的实际使用见[粮食作物](../04-动植物培育/02-粮食作物.md)、[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用)。

### 4.11 其他重要的基础化工

```
硫酸: 被称为"工业之母",用于制化肥、处理矿石、蓄电池等
  硫磺燃烧 → 二氧化硫 → 进一步氧化 → 三氧化硫 → 被吸收成硫酸

纯碱(碳酸钠): 制玻璃、肥皂、造纸
  历史上来自草木灰、海藻灰和天然碱湖,后来用食盐和石灰石工业化生产

电解: 用电流分解物质
  电解食盐水 → 烧碱(NaOH)+ 氯气 + 氢气
  ⚠️ 产生的氯气有毒、氢气易爆,只能在专业条件下进行
```

## 五、溶液与浓度

### 5.1 浓度的表示

```
质量分数 = 溶质质量 ÷ 溶液总质量 × 100%
  例: 9克盐溶在991克水里 → 0.9%的盐水(生理盐水的浓度)

体积分数 = 溶质体积 ÷ 溶液总体积 × 100%
  例: 75%酒精 = 每100毫升中有75毫升酒精

物质的量浓度 = 溶质的摩尔数 ÷ 溶液体积(升),单位 摩尔/升

百万分比(ppm,mg/L): 很稀的溶液
  例: 有效氯500毫克/升 = 0.05%
```

### 5.2 稀释

```
稀释前后溶质的量不变:
  浓度₁ × 体积₁ = 浓度₂ × 体积₂

例: 用95%酒精配75%酒精100毫升
  95% × V₁ = 75% × 100 → V₁ ≈ 79毫升,加水到100毫升
```

### 5.3 溶解度

```
一定温度下,100克水最多能溶解的溶质质量
  - 大多数固体: 温度越高溶解度越大(热水溶糖快、溶得多)
  - 食盐: 溶解度受温度影响很小(约36克)
  - 气体: 温度越高溶解度越小(水烧开会冒气泡;天热鱼塘缺氧)

饱和溶液: 不能再溶解更多溶质
重结晶提纯: 在热水中溶到饱和 → 过滤掉不溶的杂质 → 冷却后析出较纯的晶体
```

## 六、酸、碱、盐

### 6.1 pH

```
pH 0 ─────── 7 ─────── 14
   强酸     中性      强碱

  胃酸约1-2,醋约3,纯水7,肥皂水约9-10,石灰水约12,烧碱溶液约14

自制酸碱指示剂: 紫甘蓝(紫色卷心菜)切碎,用热水泡出紫色汁液
  遇酸变红或粉红,中性呈紫色,遇碱变蓝、绿,强碱变黄
```

### 6.2 常见的酸和碱

| 名称 | 化学式 | 俗称/来源 | 注意 |
|------|--------|----------|------|
| 盐酸 | HCl | 胃酸的成分;洁厕灵 | 腐蚀性 |
| 硫酸 | H₂SO₄ | 蓄电池液 | 浓硫酸腐蚀性极强,遇水剧烈放热 |
| 醋酸 | CH₃COOH | 醋 | 弱酸 |
| 碳酸 | H₂CO₃ | 二氧化碳溶于水(汽水) | 弱酸 |
| 氢氧化钠 | NaOH | 烧碱、火碱 | 强腐蚀性 |
| 氢氧化钾 | KOH | 草木灰水加石灰 | 强腐蚀性 |
| 氢氧化钙 | Ca(OH)₂ | 熟石灰 | 腐蚀性 |
| 碳酸钠 | Na₂CO₃ | 纯碱、苏打 | 水溶液呈碱性 |
| 碳酸氢钠 | NaHCO₃ | 小苏打 | 弱碱性,可食用 |

### 6.3 中和反应

```
酸 + 碱 → 盐 + 水
  HCl + NaOH → NaCl + H₂O

小苏打遇酸放出二氧化碳:
  NaHCO₃ + CH₃COOH → CH₃COONa + H₂O + CO₂↑
  → 发面(小苏打 + 酸性物质)、灭火器

⚠️ 酸碱溅到皮肤或眼睛上: 立即用大量清水冲洗至少15分钟,
   不要用另一种酸或碱去"中和"(会放热,加重烧伤)
```

化学烧伤的处理见[外伤处理-化学烧伤](../01-日常疾病和伤害/02-外伤处理.md#化学烧伤)。

### 6.4 稀释浓酸: 酸入水

```
⚠️ 稀释浓硫酸时,必须把酸沿着容器壁慢慢倒进水里,边倒边搅拌
❌ 绝不能把水倒进浓硫酸里: 水会瞬间沸腾,把酸溅出来
```

## 七、有机化学基础

### 7.1 碳的化合物

```
碳原子能和4个原子相连,还能连成长链和环 → 能形成种类极多的化合物
  一切生物体都主要由碳的化合物构成

常见的有机物:
- 甲烷 CH₄: 沼气、天然气的主要成分
- 乙醇 C₂H₅OH: 酒精
- 甲醇 CH₃OH: ⚠️ 剧毒,少量就能致盲致死;假酒中毒的原因
- 乙酸 CH₃COOH: 醋酸
```

甲醇中毒见[中毒](../01-日常疾病和伤害/12-中毒.md)中的假酒(甲醇)中毒一节。

### 7.2 酯化

```
酸 + 醇 → 酯 + 水
  醋酸 + 乙醇 → 乙酸乙酯(有香味,陈酒香味的来源之一)
油脂就是甘油和脂肪酸形成的酯
```

### 7.3 营养物质

```
糖类: 葡萄糖、蔗糖、淀粉(粮食)、纤维素(植物纤维、木头、棉花)
  人能消化淀粉,不能消化纤维素(牛羊可以,靠胃里的微生物)
油脂: 储存能量最多(每克约9千卡,糖和蛋白质每克约4千卡)
蛋白质: 由氨基酸组成,含氮
  加热、酒精、强酸强碱、重金属会使蛋白质"变性",失去活性
  → 煮熟食物、酒精消毒杀菌的原理
  → 重金属中毒的原因
```

营养需要见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md)。

## 八、分离与提纯

| 方法 | 原理 | 应用 |
|------|------|------|
| 过滤 | 不溶的颗粒被滤布、沙层挡住 | 净水、过滤碱水 |
| 沉淀 | 重的颗粒沉到底部 | 浑水静置;明矾净水 |
| 蒸发结晶 | 加热或晒干,溶剂跑掉,溶质留下 | 晒盐、熬盐 |
| 蒸馏 | 不同物质沸点不同,加热后先后变成蒸气再冷凝 | 提纯酒精、从海水制淡水 |
| 浸提(萃取) | 有效成分在某种液体里溶解得更多 | 泡药酒、用热水提取药材成分 |
| 重结晶 | 不同物质溶解度随温度变化不同 | 提纯盐类 |

```
明矾净水: 明矾在水中生成氢氧化铝絮状物,吸附水中的悬浮杂质一起沉下去
  → 只能让水变清,不能杀菌,还要煮沸或消毒
```

## 九、化学安全

### 9.1 危险的组合

```
❌ 含氯消毒剂(84、漂白粉)+ 酸性清洁剂(洁厕灵)→ 氯气
❌ 含氯消毒剂 + 氨水、尿液较多的环境 → 氯胺等有毒气体
❌ 不同的化学品不要混用,不知道成分的不要混合
```

### 9.2 有毒气体

```
一氧化碳(CO): 不完全燃烧产生,无色无味
硫化氢(H₂S): 臭鸡蛋味,粪坑、沼气池、下水道中积聚;浓度高时闻不到气味,
  很快致人死亡
二氧化碳(CO₂): 比空气重,积在地窖、枯井、沼气池底部,使人窒息
氯气(Cl₂): 黄绿色,刺激性气味

→ 进入地窖、枯井、沼气池、粪坑前先通风,不要贸然下去救人
```

沼气池的危险见[照明与能源-沼气](../07-日常生活技能/06-照明与能源.md#沼气)。

### 9.3 重金属

```
铅: 不要用铅制或含铅的容器、锡壶(旧锡器常含铅)盛放酒、醋、果汁等酸性饮食
  → 酸会溶出铅,长期造成慢性中毒(贫血、神经损害,儿童影响智力发育)
汞: 打碎水银温度计后,开窗通风,用硬纸片收集汞珠,装进密封瓶,
  不要用吸尘器吸,不要扫得到处都是
```

中毒的处理见[中毒](../01-日常疾病和伤害/12-中毒.md)。
