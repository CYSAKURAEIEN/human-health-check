# 地质、矿物与土壤

> **石灰从石灰石来,砖瓦从黏土来,铁从赤铁矿来,井水从含水层来,庄稼从土壤里长出来——认识脚下的岩石和土,才知道到哪里去找需要的东西**

## ⚠️ 本章的定位

本章讲认识岩石、矿物、地下水和土壤的基础知识,帮助在野外判断"这里可能有什么"。

```
⚠️ 安全:
- 采石、挖矿、挖井时,塌方是最大的危险: 坑壁要有坡度或支护,不要在陡坎下方挖掘
- 废弃矿井、坑道、深井底部可能缺氧或积聚有毒气体,绝不贸然进入
- 下雨后、解冻期的山坡容易滑坡,注意地质灾害的征兆
```

地质灾害见[地质灾害](../02-灾难应对/01-地质灾害.md);具体的金属矿石识别见[基础冶金知识-矿石识别与采集](../05-冶金技术/00-基础冶金知识.md#五矿石识别与采集)。

## 一、岩石的三大类

| 类别 | 怎样形成 | 常见岩石 | 特点 | 用途 |
|------|---------|---------|------|------|
| 岩浆岩(火成岩) | 地下的岩浆冷却凝固 | 花岗岩、玄武岩 | 坚硬,一般没有层理 | 建筑石材、磨盘、铺路;花岗岩地区常有锡、钨等矿,风化后形成砂土和黏土 |
| 沉积岩 | 泥沙、生物遗体一层层沉积压实 | 砂岩、页岩、石灰岩、砾岩、煤 | 常有明显的层理,可能含化石 | 石灰岩烧石灰、做水泥;砂岩做磨刀石和建材;页岩风化成黏土;煤 |
| 变质岩 | 原有岩石在高温高压下改变 | 大理岩、板岩、石英岩、片麻岩 | 致密,常有片状或条带状构造 | 大理岩可烧石灰、做石材;板岩可劈成薄片做屋瓦 |

```
野外判断:
- 有一层一层的条纹、可能有化石 → 沉积岩
- 颗粒大小均匀、有闪亮晶粒、没有层次 → 花岗岩等岩浆岩
- 黑色致密、有小气孔 → 玄武岩
- 能劈成很薄的平板 → 板岩、页岩
```

## 二、认识矿物

### 2.1 鉴定方法

```
硬度: 用已知硬度的东西去刻划
条痕: 在没有上釉的白瓷片(如碗底、瓷砖背面)上用力划,看留下粉末的颜色
  → 条痕颜色比矿物外表的颜色稳定得多
光泽: 金属光泽(像金属)、玻璃光泽、油脂光泽、土状光泽(暗淡)
比重: 掂在手里是否特别重
磁性: 用磁铁试
解理: 敲开后是否沿固定方向裂成平整的面
遇酸: 滴醋或稀盐酸,冒泡说明含碳酸盐(石灰石、大理石)
```

### 2.2 莫氏硬度

| 硬度 | 标准矿物 | 野外参照 |
|------|---------|---------|
| 1 | 滑石 | 指甲能轻松划出痕 |
| 2 | 石膏 | 指甲能划动(指甲约2.5) |
| 3 | 方解石 | 铜币能划动(铜币约3.5) |
| 4 | 萤石 | 小刀容易划动 |
| 5 | 磷灰石 | 小刀勉强能划动 |
| 6 | 正长石 | 能划动玻璃(玻璃、小刀约5.5) |
| 7 | 石英 | 能划动钢锉(钢锉约6.5) |
| 8 | 黄玉 | |
| 9 | 刚玉 | |
| 10 | 金刚石 | 最硬 |

```
用法: A 能划伤 B,说明 A 比 B 硬
  例: 一块矿物能在玻璃上划出痕,而小刀划不动它 → 硬度大于5.5,可能是石英
```

### 2.3 常见的有用矿物

| 矿物 | 外观 | 条痕 | 其他特征 | 用途 |
|------|------|------|---------|------|
| 石英 | 无色、白色,玻璃光泽 | 白色 | 硬度7,能划玻璃;断口像贝壳 | 玻璃原料、磨料 |
| 方解石 | 白色、无色 | 白色 | 硬度3,遇酸冒泡,敲开是斜方块 | 石灰石的主要成分 |
| 石膏 | 白色 | 白色 | 硬度2,指甲能划动 | 烧成熟石膏,做模具、固定骨折 |
| 磁铁矿 | 黑色 | 黑色 | 强磁性,很重 | 铁矿 |
| 赤铁矿 | 红褐到钢灰色 | **红褐色** | 较重 | 铁矿 |
| 褐铁矿 | 黄褐、锈色 | 黄褐色 | 常呈土状 | 铁矿;沼铁矿属于这一类 |
| 黄铁矿 | 金黄色,金属光泽,常为立方体 | **绿黑色** | 比金硬得多,敲击冒火星 | "愚人金";不是金矿 |
| 方铅矿 | 铅灰色,强金属光泽 | 灰黑色 | 很重,立方体 | 铅矿(☠️有毒) |
| 孔雀石 | 鲜绿色 | 淡绿色 | 遇酸冒泡 | 铜矿 |
| 锡石 | 黑、褐色,光泽强 | 白到浅褐色 | 很重,很硬 | 锡矿 |
| 高岭石(瓷土) | 白色土状 | 白色 | 细腻,湿了有可塑性 | 瓷器、耐火材料 |

```
⚠️ 金和黄铁矿的区别:
  金: 很软(小刀能刻出痕)、很重、条痕金黄、敲打会变形不会碎
  黄铁矿: 很硬、条痕绿黑、敲打会碎成小块
```

各种金属矿石见[铁的冶炼](../05-冶金技术/01-铁的冶炼.md)、[铜的冶炼](../05-冶金技术/02-铜的冶炼.md)、[其他金属](../05-冶金技术/10-其他金属.md)。

## 三、到哪里找有用的东西

### 3.1 建筑和日用材料

| 需要 | 去哪里找 | 判断 |
|------|---------|------|
| 石灰石 | 石灰岩山区(常有溶洞、石林、地下河) | 灰白色、滴醋冒泡 |
| 黏土 | 河流阶地、湖边、低洼地的细腻土层;页岩风化地带 | 湿时黏手、能搓成细条不断(见第五节) |
| 沙 | 河床、河滩、海滩 | 河沙较干净;海沙含盐,做建筑材料要洗 |
| 建筑石材 | 花岗岩、砂岩、石灰岩露头 | 选没有裂纹、风化不严重的 |
| 磨刀石 | 细砂岩、板岩 | 颗粒细而均匀 |
| 煤 | 沉积岩地区,常和页岩、砂岩成层出现 | 黑色,可燃 |
| 盐 | 海边、盐湖、盐井 | 晒盐、熬盐 |

### 3.2 金属矿床的常见线索

```
- 砂矿: 河流把山上风化下来的重矿物(金、锡石)冲到河床、河湾内侧、
  大石头背后沉积 → 淘洗河沙(见其他金属-淘金)
- 矿脉: 岩石裂缝中充填的石英脉,有时伴有金属硫化物 →
  注意石英脉附近有没有金属光泽的矿物、绿色或锈色的污染
- "铁帽": 地表一大片疏松的锈红、褐色岩石,是地下硫化物矿体氧化后留下的,
  下面可能有铜、铅、锌等矿
- 绿色、蓝色的锈斑: 可能有铜矿(孔雀石、蓝铜矿)
- 沼铁矿: 沼泽、湿地底部的褐色铁质沉积,古代重要的铁矿来源
- 地名: 很多带"铜""铁""银""锡""矾""硝"的地名,来自古代的矿产
```

## 四、地下水

### 4.1 地下水在哪里

```
雨水渗入地下,储存在岩石和土层的空隙、裂缝里
- 含水层: 能储水、透水的地层,如砂层、砾石层、有裂隙的岩石、有溶洞的石灰岩
- 隔水层: 不透水的地层,如黏土层、致密的页岩
- 地下水面: 土层被水完全浸透的上界,挖井要挖到它以下

容易找到地下水的地方:
✓ 山谷、山脚、河流附近的冲积平原(砂砾层厚)
✓ 有泉水、植物特别茂盛(芦苇、柳树等喜水植物)的地方
✓ 干河床下面(雨季有水的河道,地下常有潜流)
✓ 透水层和不透水层交界的地方,常有泉水流出

不容易找到的地方:
✗ 山顶、山脊
✗ 致密的岩石地区(要找裂缝带)
```

### 4.2 水质

```
- 石灰岩地区的地下水含钙镁多(硬水): 烧水结水垢,肥皂不起泡,但一般可以饮用
- 靠近海边的井水可能发咸;抽水过多会让海水倒灌
- 浅层地下水容易被厕所、粪坑、垃圾污染 → 井要远离污染源,在上坡方向
- 有的地区地下水含氟或砷过高,长期饮用会致病 → 当地若有这类地方病的历史,要特别注意
```

打井、取水和净水见[水源工程与供水](../07-日常生活技能/10-水源工程与供水.md)。

## 五、土壤

### 5.1 土壤的组成

```
矿物颗粒(约一半体积)+ 有机质(腐殖质)+ 水 + 空气 + 大量微生物

按颗粒大小:
- 砂粒: 粗,摸起来扎手,透水快,保水保肥差
- 粉粒: 中等,摸起来像面粉
- 黏粒: 极细,湿时黏、干时硬,保水保肥好但透气差

壤土: 三者比例适中,最适合种植
```

### 5.2 简单的土壤质地判断

```
搓条法:
1. 取一把湿润的土(加水揉到像橡皮泥)
2. 在手掌中搓成细条
- 搓不成条,一搓就散 → 砂土
- 能搓成条,但一弯就断 → 壤土
- 能搓成细长条,还能弯成圈不断 → 黏土

沉淀法(更准确):
1. 在透明瓶子里装约三分之一的土,加水到接近满,加一小撮盐或洗衣粉帮助分散
2. 用力摇匀,静置
3. 约1分钟后沉下的是砂,几个小时后沉下的是粉粒,一两天后才沉下的是黏粒
4. 量出各层的厚度,就知道大致比例
```

土坯和夯土的选土见[长期住所-选土](../07-日常生活技能/05-长期住所.md#选土)。

### 5.3 酸碱性

```
测试: 取土加水搅拌,用紫甘蓝汁或试纸测(见化学-pH)
  - 加醋冒泡 → 含石灰质,偏碱性
- 酸性土(我国南方的红壤、黄壤常见): 撒石灰或草木灰改良
- 碱性土、盐碱地(北方部分地区、海边): 灌水洗盐、修排水沟、增施有机肥、种耐盐作物
- 大多数作物喜欢接近中性的土壤
```

紫甘蓝指示剂见[化学-pH](../08-基础科学知识/03-化学.md#61-ph)。

改良酸性土的石灰用量见[石灰与建筑材料-农业和其他用途](../07-日常生活技能/16-石灰与建筑材料.md#农业和其他用途)。

### 5.4 土壤肥力

```
植物需要最多的营养: 氮、磷、钾
- 氮: 粪肥、尿液、豆科植物、绿肥
- 磷: 骨粉、草木灰、粪肥
- 钾: 草木灰
有机质: 堆肥、厩肥、秸秆还田 → 让土壤疏松、保水保肥、养活微生物

判断: 土色深、松软、有很多蚯蚓的土往往比较肥沃
```

肥料和堆肥见[粮食作物](../04-动植物培育/02-粮食作物.md)、[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用)。

### 5.5 保护土壤

```
表土(最上面十几到几十厘米)是几百上千年才形成的,一场暴雨就可能冲走
✓ 坡地修梯田、等高种植(沿着等高线开垄),不要顺坡开垄
✓ 地面尽量有植物或秸秆覆盖,不要长期裸露
✓ 陡坡不开垦,保留树林和草地
✓ 河岸、沟边种树固土
```

等高线见[户外出行准备与求救-看懂地图和等高线](../03-野外生存/07-户外出行准备与求救.md#看懂地图和等高线)。

## 六、读懂地形和地层

```
- 岩层倾斜的方向和角度,决定了地下水流动和矿层延伸的方向
- 河流的阶地(河边一级一级的平台)多是古代的河床,常有砂砾层和地下水,
  也是古人居住和耕种的地方
- 山坡上的醉汉林(树木东倒西歪)、裂缝、坡脚渗水 → 可能在缓慢滑动,不要在附近建房
- 冲沟口的扇形堆积(洪积扇) → 是山洪、泥石流经过的地方
```

滑坡、泥石流的征兆见[地质灾害](../02-灾难应对/01-地质灾害.md)。
