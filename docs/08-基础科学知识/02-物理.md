# 物理

> **杠杆、水车、蒸汽机、发电机——理解了物理规律,才能让自然的力量为人所用**

## ⚠️ 本章的定位

本章收录对人类生产生活影响最大的物理规律,重点放在**能直接用于生产和建造**的部分: 简单机械、水力、热、电。每个公式后面都说明它能用来做什么。

```
最优先掌握:
- 杠杆、滑轮、斜面(省力搬运和建造)
- 压强与大气压(水井、水泵、虹吸)
- 热量与保温(取暖、做饭、冶炼)

其次:
- 功和能量(水车、风车、畜力的计算)
- 电与磁(发电、电池、电动机)
- 天文(历法、定方向、测纬度)
```

公式中: m 质量(kg),g 重力加速度(约9.8 m/s²),v 速度(m/s),t 时间(s),F 力(N),单位见[度量衡与科学方法](00-度量衡与科学方法.md#三常用单位换算)。

## 一、运动与力

### 1.1 牛顿三定律

```
第一定律(惯性): 不受外力时,静止的保持静止,运动的保持匀速直线运动
  → 急刹车时人会往前冲;要系安全带

第二定律: F = m × a
  力 = 质量 × 加速度
  → 同样的力,推轻的东西加速快,推重的东西加速慢

第三定律: 作用力和反作用力大小相等、方向相反
  → 划船时桨向后推水,水向前推船;火箭向后喷气而前进
```

### 1.2 重力

```
重力 G = m × g,g ≈ 9.8 m/s²(粗算用10)
  1 kg的物体受到约9.8 N的重力

万有引力: F = G₀ × m₁ × m₂ ÷ r²(G₀ ≈ 6.67 × 10⁻¹¹)
  解释了物体下落、月亮绕地球转、潮汐
```

### 1.3 自由落体

```
速度 v = g × t
下落高度 h = ½ × g × t² ≈ 4.9 × t²

测井深、悬崖高度: 扔一块石头,数到听见落地的秒数
  2秒 → 约20 m;3秒 → 约44 m
  (较深时声音传上来也要时间,实际比算出的略浅)
```

### 1.4 摩擦力

```
f = μ × N
  μ: 摩擦系数(冰面很小,橡胶在干燥路面很大)
  N: 压在接触面上的力

增大摩擦: 粗糙表面、增加压力(防滑)
减小摩擦: 润滑(油、蜡、肥皂水)、用滚动代替滑动
  → 轮子和滚木: 滚动摩擦远小于滑动摩擦,
    在重物下面垫圆木滚动,搬运省力得多
```

### 1.5 圆周运动和单摆

```
圆周运动需要向心力: F = m × v² ÷ r
  → 转弯越急、速度越快,越容易翻车或甩出去

单摆周期: T = 2π × √(L ÷ g)
  只和摆长有关 → 摆钟计时的原理
  摆长约0.993 m时,单程正好1秒(随纬度略有不同,见度量衡章)
```

## 二、简单机械

**所有简单机械都遵循同一条规律: 省力就要费距离,省距离就要费力,做的功不会变少("省力不省功")。**

### 2.1 杠杆

```
动力 × 动力臂 = 阻力 × 阻力臂
  F₁ × L₁ = F₂ × L₂

例: 用2 m长的撬棍,支点离重物0.2 m,手离支点1.8 m
  手上用力 = 重物 × 0.2 ÷ 1.8 ≈ 重物的1/9

应用: 撬棍、剪刀、钳子、杆秤、天平、桔槔(打水)、独轮车
```

### 2.2 滑轮

```
定滑轮: 不省力,改变用力方向(向下拉把东西吊上去)
动滑轮: 省一半力,绳子要拉两倍长
滑轮组: 拉力 ≈ 重物重量 ÷ 承重的绳子段数
  (还要加上摩擦和滑轮自身的重量)

应用: 吊装房梁、从井里提水、装卸重物
```

### 2.3 斜面

```
沿光滑斜面推物体: 推力 = 重量 × 高度 ÷ 斜面长度
  斜面越长越缓,越省力

应用: 往车上装重物搭跳板、盘山路、楔子、斧头
```

### 2.4 轮轴和螺旋

```
轮轴: 力 × 轮半径 = 阻力 × 轴半径
  应用: 辘轳(井上打水)、绞盘、门把手、方向盘

螺旋: 绕在圆柱上的斜面
  应用: 螺丝、千斤顶、榨油机、压榨机
```

### 2.5 齿轮和传动

```
两个咬合的齿轮: 转速之比 = 齿数的反比
  小齿轮带大齿轮 → 转得慢但力量大
  大齿轮带小齿轮 → 转得快但力量小

应用: 水车、风车带动磨盘;自行车变速
```

## 三、功、能量和功率

### 3.1 功和功率

```
功 W = F × s(力 × 沿力方向移动的距离),单位 J(焦耳)
功率 P = W ÷ t,单位 W(瓦特)

参考:
- 一个成年人长时间持续劳动: 约75-100 W
- 1 hp(马力)≈ 735 W(一匹马持续工作的功率量级)
- 举起100 kg到1 m高: 约980 J
```

### 3.2 能量

```
动能 = ½ × m × v²
  速度加倍,动能变成4倍 → 车速快一点,撞击伤害大很多

重力势能 = m × g × h
  高处的水、举起的重锤储存着能量

能量守恒: 能量不会凭空产生或消失,只会从一种形式变成另一种形式
  → 不存在"永动机"
  → 任何机器的输出都小于输入(一部分变成热散失了),
    输出 ÷ 输入 = 效率
```

### 3.3 水力: 水车和水磨

```
水力功率(kW)≈ 9.8 × 流量(m³/s)× 落差(m)× 效率

例: 一条小溪每秒流过0.1 m³水,落差3 m
  理论功率 = 9.8 × 0.1 × 3 ≈ 2.9 kW
  水车的实际效率差别很大: 水从上方落进水斗的上射式约60%,
  水从下面冲过的下射式只有约20-30%
  → 按50%估算约1.5 kW,相当于十几个人持续劳动

提高功率: 加大落差(修水渠、筑堰引水),增加流量
```

### 3.4 动量

```
动量 p = m × v
动量守恒: 两个物体碰撞,碰撞前后总动量不变
  → 锤子重、速度快,钉钉子才有力
```

## 四、压强与流体

### 4.1 压强

```
压强 p = F ÷ S(力 ÷ 受力面积),单位 Pa(帕斯卡)
  同样的力,面积越小压强越大

应用:
- 刀磨锋利、钉子尖 → 面积小,压强大,容易切入
- 宽轮胎、雪鞋、铺木板过泥地 → 面积大,压强小,不易陷下去
- 地基要宽 → 分散房屋重量
```

### 4.2 液体压强

```
p = ρ × g × h
  ρ: 液体密度(水 1000 kg/m³)
  h: 深度

每下降10 m水深,压强增加约1 atm
  → 水坝下面要比上面厚
  → 水塔越高,水龙头出水压力越大(每高10 m约增加1 atm)
```

### 4.3 连通器

```
底部相连的几个容器,装同一种液体静止时,液面高度相同

应用: 水平管(找水平,见度量衡章)、茶壶、船闸、
  自来水系统(水塔要比用水点高)
```

### 4.4 大气压: 水泵和虹吸

```
1个标准大气压 ≈ 101 kPa ≈ 能支撑约10.3 m高的水柱

⚠️ 抽水机(吸水泵)最多只能把水"吸"上来约10 m
   实际上由于漏气和摩擦,一般只有7-8 m
   → 地下水位更深的井,要把泵放到井下面往上"推",或者用水桶提

虹吸:
1. 管子装满水,一端放进高处水池,另一端放到比水面更低的地方
2. 水会持续从高处流向低处,越过中间的高点
3. 管子最高点不能比水面高出约10 m
应用: 从水缸、水池里抽水;给田地引水
```

### 4.5 浮力: 阿基米德原理

```
浮力 = 物体排开的液体的重量
  F = ρ液 × g × V排

- 物体密度比水小 → 浮起(木头、冰、油)
- 物体密度比水大 → 下沉(铁块);但做成船形排开更多的水就能浮起
- 盐水密度比清水大 → 新鲜鸡蛋在清水中下沉,在浓盐水中浮起

测密度和体积:
- 不规则物体的体积: 放进装满水的容器,溢出的水的体积就是物体的体积
- 密度 = 质量 ÷ 体积
  → 可以检查金属是否掺假(纯金 19.3 g/cm³,铁 7.9,铜 8.9,铝 2.7)
```

筏的载重计算见[车船与道路-水上](../07-日常生活技能/18-车船与道路.md#水上-筏和船)。

### 4.6 流动的流体

```
流速越快的地方,压强越小(伯努利原理)
  → 风吹过屋顶,屋顶上方压强小,台风能把屋顶"掀"起来
  → 烟囱越高、风越大,抽力越强
```

## 五、热学

### 5.1 温度和热量

```
温度: 冷热的程度(°C)
热量: 传递的能量(J)

热量计算: Q = c × m × Δt
  c: 比热容(水约 4200 J/(kg·°C),是常见物质中最大的)
  Δt: 温度变化

例: 把1 kg水从20°C烧到100°C,需要 4200 × 1 × 80 = 336000 J

水的比热大 → 
- 升温降温都慢,海边、湖边气候温和
- 热水袋、暖水壶用水储存热量
- 用水冷却发动机、给发热的人降温
```

### 5.2 物态变化和潜热

```
熔化/凝固: 冰在0°C熔化,熔化1 kg冰吸热约334000 J
汽化: 1 kg100°C的水变成水蒸气,吸热约2260000 J
  (是把它从20°C烧到100°C所需热量的约7倍)

应用:
- 出汗、湿布降温: 水蒸发带走大量热量
- 被100°C蒸汽烫伤比被100°C的水烫伤更严重(蒸汽凝结放出大量热)
- 冰块冷藏食物: 熔化时吸热,温度保持在0°C
- 蒸馏: 利用沸点不同分离液体(酒精78°C,水100°C)
```

### 5.3 沸点和气压

```
气压越低,沸点越低;气压越高,沸点越高
- 高原上水不到100°C就沸腾,食物煮不熟 → 用高压锅
- 高压锅内水的沸点约120°C,煮得快,也能杀灭更多细菌
```

高海拔地区煮沸消毒饮用水的时间见[基础生存技能-水源获取与净化](../03-野外生存/00-基础生存技能.md#水源获取与净化)。

### 5.4 热的传递

```
传导: 通过接触传递(金属传热快;空气、羊毛、木头、稻草传热慢)
  → 保温材料都是"困住空气"的: 棉絮、羽绒、稻草、双层墙中间的空气层
对流: 液体和气体流动带走热量
  → 暖气放在下面,热空气上升;防风就是阻止对流散热
辐射: 不需要接触,通过"光"传递
  → 深色物体吸热多,浅色、光亮的表面反射多
  → 应急保温毯的铝箔反射人体的热辐射

燃料的热值(每 kg 完全燃烧放出的热量,约数):
  干木柴 约15 MJ;木炭 约30 MJ;煤 约20-30 MJ;
  汽油、柴油 约45 MJ;沼气(主要是甲烷)约20 MJ/m³
```

保温的实际做法见[长期住所-保温](../07-日常生活技能/05-长期住所.md#保温)。

### 5.5 热胀冷缩

```
大多数物质受热膨胀、遇冷收缩
  → 铁轨、桥梁、长水泥地面要留伸缩缝
  → 拧不开的金属瓶盖用热水烫一下

⚠️ 水是例外: 4°C时密度最大,结冰时体积膨胀约9%
  → 冬天水管、水缸会被冻裂;冰浮在水面上,水底的鱼能过冬
```

### 5.6 气体定律

```
理想气体状态方程: p × V = n × R × T
  T 是绝对温度: T(K)= t(°C)+ 273
  R ≈ 8.31

一定量的气体:
- 体积不变,温度越高,压强越大 → 密封罐头受热会爆裂,打火机不能放在太阳下
- 温度不变,压缩体积,压强增大 → 打气筒
```

### 5.7 热力学定律和热机

```
第一定律: 能量守恒(热也是一种能量)
第二定律: 热量自发地从高温物体传向低温物体,不会自发地反过来
  → 热机(蒸汽机、内燃机)不可能把热量全部变成功

热机最高效率 = 1 - T冷 ÷ T热(用开尔文温度)
  → 进气温度越高、排气温度越低,效率越高
  早期蒸汽机效率只有几个百分点,现代发电厂也只有约40%左右

蒸汽机的原理: 烧水产生高压蒸汽 → 推动活塞或叶轮 → 带动机器
```

## 六、波、声与光

### 6.1 波

```
波速 = 频率 × 波长 (v = f × λ)
  频率: 每秒振动多少次(Hz)
```

### 6.2 声音

```
声音需要介质传播,真空中不能传声
声速: 空气中约340 m/s,水中约1500 m/s,钢铁中约5000 m/s

应用:
- 雷电距离: 闪电后数秒到听到雷声,秒数 ÷ 3 ≈ 距离(km)
- 回声测距: 对着山崖喊,听到回声的时间 × 340 ÷ 2 = 距离
- 耳朵贴在铁轨上能更早听到远处的火车
```

### 6.3 光的反射和折射

```
光速: 约 3 × 10⁸ m/s

反射定律: 入射角 = 反射角
  → 镜子反光发信号;凹面镜汇聚阳光生火、做太阳灶

折射: 光从一种物质进入另一种物质时会改变方向
  n₁ × sin θ₁ = n₂ × sin θ₂
  (n 是折射率: 空气1,水约1.33,玻璃约1.5)
  → 水里的东西看起来比实际浅;用鱼叉叉鱼要往看到的位置下方叉
```

### 6.4 透镜

```
凸透镜(中间厚): 汇聚光线
  - 放大镜、老花镜(远视眼镜)
  - 聚焦阳光生火
凹透镜(中间薄): 发散光线
  - 近视眼镜

透镜公式: 1/f = 1/u + 1/v
  f: 焦距;u: 物体到透镜的距离;v: 成像到透镜的距离
  测焦距: 用凸透镜把太阳光聚成最小最亮的点,这一点到透镜的距离就是焦距

应用: 两个凸透镜组合可以做成望远镜和显微镜
  (显微镜让人类第一次看见细菌,是现代医学的起点)
```

### 6.5 色散

```
白光经过三棱镜(或水滴)会分成红橙黄绿蓝靛紫 → 彩虹
```

## 七、电与磁

### 7.1 基本量

| 量 | 符号 | 单位 | 类比(水管) |
|----|------|------|-----------|
| 电压 | U | 伏特 V | 水压 |
| 电流 | I | 安培 A | 水流量 |
| 电阻 | R | 欧姆 Ω | 水管的阻力 |
| 电功率 | P | 瓦特 W | |
| 电能 | E | 千瓦时 kWh(俗称"度") | |

### 7.2 欧姆定律和电功率

```
欧姆定律: U = I × R(电压 = 电流 × 电阻)

电功率: P = U × I = I² × R = U² ÷ R
电能: E = P × t
  1000 W的电器用1小时 = 1 kWh = 1度电

例: 220 V、1100 W的电热水壶,电流 = 1100 ÷ 220 = 5 A
```

### 7.3 串联和并联

```
串联(一条路): 电流处处相等,总电阻 = R₁ + R₂ + …
  一个灯坏了全都不亮

并联(多条路): 每条支路电压相等,1/R总 = 1/R₁ + 1/R₂ + …
  家里的电器都是并联的,互不影响
  ⚠️ 并联的电器越多,总电流越大 → 插线板超负荷发热
```

### 7.4 导线的电阻

```
R = ρ × L ÷ S
  ρ: 电阻率(铜约 1.7 × 10⁻⁸,铝约 2.8 × 10⁻⁸ Ω·m)
  L: 长度;S: 横截面积

→ 导线越长越细,电阻越大,发热越多、电压损失越大
→ 大功率电器要用粗导线
→ 远距离输电用高电压: 输送同样的功率,电压越高电流越小,
  线路上的损失(I² × R)越小
```

家庭用电的安全规则见[家庭用电安全](../07-日常生活技能/08-家庭用电安全.md)。

### 7.5 电池

```
原理: 两种活泼程度不同的金属浸在能导电的溶液里,就会产生电压

伏打电堆(最早的电池):
- 锌片、浸过盐水或醋的布片(或纸板)、铜片,依次叠放
- 每一组产生约1 V左右的电压,叠的组数越多电压越高
- 只能提供很小的电流

铅酸蓄电池(汽车电瓶): 每格约2 V,6格串联 = 12 V,可以反复充电
```

蓄电池的安全使用见[照明与能源-蓄电池安全](../07-日常生活技能/06-照明与能源.md#蓄电池安全)。

### 7.6 电生磁、磁生电

```
电流产生磁场(电生磁):
- 导线绕成线圈,中间放一根铁芯,通电就成了电磁铁
- 电动机: 通电线圈在磁场中受力转动 → 电能变成机械能

电磁感应(磁生电,法拉第发现):
- 磁铁在线圈里移动,或线圈在磁场中转动,线圈里就会产生电流
- 发电机: 用水力、风力、蒸汽、人力转动线圈(或磁铁)→ 机械能变成电能
- 转得越快、线圈匝数越多、磁铁越强,电压越高

变压器: U₁ ÷ U₂ = N₁ ÷ N₂(电压之比 = 线圈匝数之比)
  只能用于交流电
```

### 7.7 磁铁和指南针

```
- 磁铁有南北两极,同极相斥,异极相吸
- 地球本身是一个大磁铁,所以小磁针会指向南北
- 自制指南针: 用磁铁沿同一个方向摩擦缝衣针几十次,
  针就被磁化了;把针放在漂浮在水面的树叶上,它会转向南北
```

指南针的使用见[基础生存技能-导航与定向](../03-野外生存/00-基础生存技能.md#导航与定向)。

### 7.8 用电安全

```
⚠️ 我国规定的一般安全电压为36 V以下;家用220 V足以致命
⚠️ 人体潮湿时电阻大大降低,更容易触电
⚠️ 电流通过人体心脏最危险
```

## 八、原子与辐射

### 8.1 原子

```
一切物质由原子组成
原子 = 原子核(质子 + 中子)+ 核外电子
  质子数决定是什么元素(见化学章)
  质子数相同、中子数不同的叫同位素
```

### 8.2 放射性

```
有些原子核不稳定,会放出射线变成别的原子核:
  α射线: 一张纸就能挡住,但进入体内危害大
  β射线: 几 mm铝板能挡住
  γ射线: 穿透力强,需要厚铅板、厚混凝土、厚土层

半衰期: 一半原子核发生衰变所需的时间(计算见数学-指数衰减)

防护三原则:
- 时间: 减少停留时间
- 距离: 距离加倍,受到的照射约减少到1/4
- 屏蔽: 躲在厚墙、地下室里
```

核事故的应对见[人为灾难](../02-灾难应对/05-人为灾难.md)。

### 8.3 质能关系

```
E = m × c²
  极少的质量可以转化成巨大的能量 → 核能、太阳发光的原理
```

## 九、天文与地球

### 9.1 日和年

```
- 地球自转一周 = 一天(相对太阳24小时)
- 地球绕太阳公转一周 = 一年 ≈ 365.2422天
- 地轴倾斜约23.4° → 一年中太阳直射点在南北回归线之间移动 → 产生四季
  - 夏至: 北半球白天最长,正午太阳最高
  - 冬至: 北半球白天最短,正午太阳最低
  - 春分、秋分: 昼夜等长,太阳直射赤道
```

### 9.2 历法

```
阳历(公历)闰年规则:
- 能被4整除的年份是闰年(2月29天)
- 但能被100整除的不是闰年
- 能被400整除的又是闰年
  例: 2000年是闰年,1900年不是,2024年是

月亮: 月相变化周期(朔望月)约29.53天
  农历以月相定月,约每3年加一个闰月,和季节对齐

二十四节气: 太阳在一年中的位置每移动15°为一个节气,
  反映季节和农时,指导播种和收获
```

农时安排见[粮食作物](../04-动植物培育/02-粮食作物.md)。

### 9.3 测纬度和经度

```
纬度(在北半球):
- 北极星的仰角 ≈ 当地纬度
- 或: 春分、秋分正午时,太阳的仰角 = 90° - 当地纬度

经度:
- 地球每小时自转15°
- 当地正午时刻与某个参照地点的正午时刻每相差1小时,经度相差15°
- 需要一个准确记录参照地点时间的钟表
```

找北极星和用太阳辨方向见[基础生存技能-导航与定向](../03-野外生存/00-基础生存技能.md#导航与定向)。

### 9.4 潮汐

```
- 主要由月亮的引力引起,太阳也有影响
- 大多数海岸每天两次涨潮、两次落潮,每天推迟约50分钟
- 新月和满月前后潮差最大(大潮),上弦月和下弦月前后最小(小潮)
```
