# 元素周期表

> **118种元素排成一张表,性质却像日历一样周期性地重复——知道一种元素在表中的位置,就能推测它的大部分性质。这是化学中信息量最大的一张表**

## ⚠️ 本章的定位

本章收录完整的元素周期表和全部118种元素的基本数据,并说明怎样从周期表中读出规律。化学反应、溶液、酸碱等内容见[化学](03-化学.md),原子结构和化学键的进阶内容见[化学进阶](../09-进阶科学与工程/05-化学进阶.md)。

```
⚠️ 表中标注"剧毒""放射性"的元素,不要尝试制取或接触;
   本章只用于认识和查阅
```

## 一、周期表是什么

```
原子序数 = 原子核中的质子数 = 核外电子数(中性原子)
  → 原子序数决定了是哪种元素

把元素按原子序数从小到大排列,每当最外层电子的排布"重新开始"时换一行:
- 横行叫周期: 第几周期,原子就有几层电子(共7个周期)
- 竖列叫族: 同一族的元素最外层电子数相同(主族),化学性质相似(共18列)

主族元素(第1、2、13-18列): 族序数的个位数 = 最外层电子数
  例: 第1族最外层1个电子,第17族最外层7个电子
过渡金属(第3-12列): 性质变化比较平缓,大多是坚硬、能导电的金属
镧系、锕系: 本来分别在第6、7周期的第3列,因为太长,单独放在表的下方
```

## 四、怎样读周期表

### 4.1 从左到右(同一周期)

```
- 原子半径逐渐变小(核电荷增加,把电子吸得更紧)
- 金属性减弱,非金属性增强: 钠(很活泼的金属)→ 镁 → 铝 → 硅 → 磷 → 硫 → 氯(很活泼的非金属)
- 最高正化合价从 +1 逐渐升到 +7
- 最右边的稀有气体最外层电子已满,几乎不反应
```

### 4.2 从上到下(同一族)

```
- 原子半径逐渐变大(电子层增多)
- 金属越来越活泼: 锂 < 钠 < 钾 < 铷 < 铯
  → 锂放进水里缓慢冒泡,钠在水面上乱窜,钾立即燃烧
- 非金属越来越不活泼: 氟 > 氯 > 溴 > 碘
  → 氯气能把溴、碘从它们的盐中置换出来
```

### 4.3 常见化合价(主族)

| 族 | 最外层电子 | 常见化合价 | 例子 |
|----|-----------|-----------|------|
| 1 | 1 | +1 | NaCl、KOH |
| 2 | 2 | +2 | CaO、MgCl₂ |
| 13 | 3 | +3 | Al₂O₃ |
| 14 | 4 | +4、-4 | CO₂、SiO₂、CH₄ |
| 15 | 5 | -3、+3、+5 | NH₃、P₂O₅ |
| 16 | 6 | -2(以及+4、+6) | H₂O、SO₂、H₂SO₄ |
| 17 | 7 | -1(以及+1、+5、+7) | NaCl、NaClO |
| 18 | 8(氦为2) | 0 | 几乎不形成化合物 |

```
用化合价写化学式: 正负化合价的总和为零
  例: 铝 +3、氧 -2 → 2个铝(+6)和3个氧(-6)→ Al₂O₃
```

### 4.4 用位置推测性质: 例子

```
问: 铷(Rb)是什么样的?
答: 第1族、第5周期 → 碱金属,比钾更活泼
    → 很软、银白色、遇水剧烈反应甚至爆炸,要保存在煤油里,化合价+1

问: 硒(Se)可能有什么性质?
答: 第16族,在硫的下面 → 化学性质像硫,能形成 H₂Se、SeO₂,化合价 -2、+4、+6
```

金属活动性顺序见[化学-金属活动性顺序](03-化学.md#22-金属活动性顺序);周期表规律的物理解释见[现代物理-电子排布和元素周期表](../09-进阶科学与工程/06-现代物理.md#23-电子排布和元素周期表)。

## 五、中文元素名的造字规律

我国的元素名称大多是一个字,由"偏旁 + 读音"组成。看偏旁就能知道这种元素在常温下的状态:

| 偏旁 | 含义 | 例子 |
|------|------|------|
| 钅(金字旁) | 金属 | 钠、镁、铝、钾、钙、铁、铜、锌 |
| 气(气字头) | 常温下是气体 | 氢、氦、氮、氧、氟、氖、氯、氩、氪、氙、氡 |
| 氵(三点水)/ 水 | 常温下是液体 | 溴;汞(下面是"水") |
| 石(石字旁) | 常温下是固态非金属 | 硼、碳、硅、磷、硫、砷、硒、碲、碘 |

```
另一半通常表示读音:
- 很多是取外文名称第一个音节的发音: 钠(Natrium)、钾、钙、镁、锰……
  这套命名方法由清代化学家徐寿等人在19世纪70年代确立
- 金、银、铜、铁、锡、铅、汞、硫等是古代就已经认识的元素,保留了原来的名字
- 例外: "金"本身是金属,"汞"是液态金属
```

## 七、门捷列夫的预言: 周期表为什么是科学

```
1869年,俄国化学家门捷列夫把当时已知的63种元素按原子量排列,
发现性质周期性地重复。他做了两件大胆的事:

1. 留下空格: 在表中给"应该存在但还没发现"的元素留了位置
2. 预言性质: 根据空格周围元素的性质,预言了这些未知元素的性质

例如他预言的"类硅"(在硅的下方):
                 门捷列夫的预言(1871年)   实际发现的锗(1886年)
  相对原子质量        约72                   72.6
  密度               约5.5 g/cm³            5.35 g/cm³
  氧化物             XO₂,密度约4.7 g/cm³    GeO₂,密度4.7 g/cm³
  氯化物             液体,沸点低于100°C     GeCl₄,沸点约86°C

他预言的"类铝"(镓,1875年)和"类硼"(钪,1879年)也相继被发现,性质与预言相符

→ 一个好的理论不只是整理已知,还能预测未知,并且可以被检验
→ 即使从零开始,只要发现了这个规律,就能有方向地去寻找和认识新的物质
```

科学方法见[度量衡与科学方法-科学方法](00-度量衡与科学方法.md#一科学方法)。
