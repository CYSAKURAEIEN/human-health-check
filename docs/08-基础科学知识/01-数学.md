## 一、数与计数

### 1.1 位值制和零

```
十进制位值制: 同一个数字放在不同位置,代表不同的大小
  352 = 3×100 + 5×10 + 2×1

"0"的作用: 占位
  305 和 35 的区别全靠这个0

为什么重要: 有了位值制,任何大数都能用十个符号写出来,
  加减乘除可以按位竖式计算。罗马数字等非位值制的记数法很难做乘除法。
```

### 1.2 分数、小数、百分数

```
分数: 1/4 表示把一个整体分成4份取1份
  加减: 先通分 1/2 + 1/3 = 3/6 + 2/6 = 5/6
  乘法: 分子乘分子,分母乘分母 2/3 × 3/4 = 6/12 = 1/2
  除法: 乘以倒数 1/2 ÷ 1/4 = 1/2 × 4/1 = 2

小数: 0.25 = 25/100 = 1/4

百分数: 25% = 25/100 = 0.25
  "增加20%"= 原数 × 1.2
  "减少20%"= 原数 × 0.8
  ⚠️ 先涨20%再降20%,不回到原数: 100 × 1.2 × 0.8 = 96
```

### 1.3 负数

```
表示相反方向的量: 欠债、零下温度、海平面以下
  -3 + 5 = 2
  负负得正: (-2) × (-3) = 6
```

### 1.4 科学计数法

```
很大或很小的数写成 a × 10ⁿ(1 ≤ a < 10)
  光速 300000000 m/s = 3 × 10⁸ m/s
  0.000001 = 1 × 10⁻⁶

乘法: 前面相乘,指数相加 (2×10³) × (3×10⁴) = 6×10⁷
```

## 二、比和比例

比例是日常生产中用得最多的数学: 配料、配药、配消毒液、地图、按人口分配粮食。

### 2.1 比例

```
a : b = c : d  等价于  a × d = b × c

例: 1.5 kg米煮饭要加2.25 kg水,2.5 kg米要加多少水?
  1.5 : 2.25 = 2.5 : x
  x = 2.25 × 2.5 ÷ 1.5 = 3.75 kg
```

### 2.2 配比和稀释

```
"1:100"通常指 1份原液 + 100份水(也有资料指总量的1/100,看清说明)

稀释公式: 浓度₁ × 体积₁ = 浓度₂ × 体积₂
  例: 把5%的消毒液稀释成0.05%,要配1 L
  5% × V₁ = 0.05% × 1000 mL
  V₁ = 10 mL原液,加水到1 L
```

84消毒液的实际配制见[传染病家庭防控-家用消毒液的配制](../01-日常疾病和伤害/15-传染病家庭防控.md#家用消毒液的配制);浓度的化学计算见[化学-溶液与浓度](03-化学.md#五溶液与浓度)。

### 2.3 比例尺

```
地图比例尺 1:50000 表示图上1 cm = 实地50000 cm = 500 m
```

## 三、代数

用字母代表未知的数,把问题写成方程来求解。

### 3.1 一元一次方程

```
例: 一块长方形田地长比宽多20 m,周长200 m,长和宽各是多少?
  设宽为 x,长为 x + 20
  2 × (x + x + 20) = 200
  4x + 40 = 200
  x = 40(宽40 m,长60 m)

解法: 等式两边同时加、减、乘、除同一个数(除数不为0),等式不变
```

### 3.2 二元一次方程组

```
例: 鸡兔同笼,共35个头,94只脚
  x + y = 35
  2x + 4y = 94
  由第一式 x = 35 - y,代入第二式: 70 - 2y + 4y = 94 → y = 12, x = 23
  (鸡23只,兔12只)
```

### 3.3 一元二次方程

```
ax² + bx + c = 0 (a ≠ 0)

求根公式:
       -b ± √(b² - 4ac)
  x = ─────────────────
             2a

b² - 4ac > 0: 两个不同的根
b² - 4ac = 0: 一个根
b² - 4ac < 0: 没有实数根

例: x² - 5x + 6 = 0 → x = (5 ± √(25-24))/2 → x = 3 或 x = 2
```

### 3.4 常用乘法公式

```
(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
(a + b)(a - b) = a² - b²
```

## 四、几何

### 4.1 勾股定理

```
直角三角形中,两条直角边的平方和等于斜边的平方:
  a² + b² = c²

常用整数组合: 3-4-5、5-12-13、6-8-10、8-15-17

用途:
- 画直角(3-4-5绳,见度量衡章)
- 已知两边求第三边: 梯子长5 m,底部离墙3 m,能够到 √(25-9) = 4 m高
- 检查房屋地基是否方正: 量两条对角线,相等就是矩形
```

### 4.2 角度和三角形

```
- 一周角 = 360°,平角 = 180°,直角 = 90°
- 三角形内角和 = 180°
- 多边形内角和 = (边数 - 2) × 180°
- 相似三角形: 形状相同、大小不同,对应边成比例
  → 用影子测高、测河宽(见度量衡章)
```

### 4.3 圆和 π

```
π(圆周率)= 圆的周长 ÷ 直径 ≈ 3.14159
  祖冲之的近似值 355/113 ≈ 3.1415929,非常精确
  粗略计算用 3.14 或 22/7

周长 = 2πr = πd
面积 = πr²

自己测 π: 用绳子绕圆柱(水桶)一圈量周长,再量直径,相除
```

### 4.4 面积公式

| 图形 | 面积 | 备注 |
|------|------|------|
| 长方形 | 长 × 宽 | |
| 正方形 | 边长² | |
| 三角形 | 底 × 高 ÷ 2 | 高是顶点到底边的垂直距离 |
| 三角形(已知三边) | √(p(p-a)(p-b)(p-c)) | 海伦公式,p = (a+b+c)/2 |
| 平行四边形 | 底 × 高 | |
| 梯形 | (上底 + 下底) × 高 ÷ 2 | |
| 圆 | πr² | |
| 椭圆 | πab | a、b 是两个半轴长 |

```
不规则田地: 分成几个三角形,分别量三边用海伦公式算,再加起来
```

### 4.5 体积公式

| 立体 | 体积 | 表面积 |
|------|------|--------|
| 长方体 | 长 × 宽 × 高 | 2(长宽 + 长高 + 宽高) |
| 圆柱 | πr²h | 2πr² + 2πrh |
| 圆锥 | πr²h ÷ 3 | |
| 棱锥(金字塔形) | 底面积 × 高 ÷ 3 | |
| 球 | 4πr³ ÷ 3 | 4πr² |

```
用途:
- 粮仓、水池、水缸能装多少: 1 m³ = 1000 L
- 堆成圆锥形的粮食、沙土有多少: 量底面周长和高度,
  r = 周长 ÷ 2π,体积 = πr²h ÷ 3
- 木材体积、砖石用量

注意: 尺寸放大2倍,面积变成4倍,体积变成8倍
  (所以大锅比小锅散热慢,大动物比小动物耐寒)
```

## 五、三角函数

在直角三角形中,用角度和一条边就能算出其他边。用于测量、建筑、航海、天文。

### 5.1 定义

```
             斜边
           /|
         /  | 对边
       / θ  |
      ───────
        邻边

sin θ = 对边 / 斜边
cos θ = 邻边 / 斜边
tan θ = 对边 / 邻边

sin²θ + cos²θ = 1
```

### 5.2 特殊角

| 角度 | sin | cos | tan |
|------|-----|-----|-----|
| 0° | 0 | 1 | 0 |
| 30° | 0.5 | 0.866 | 0.577 |
| 45° | 0.707 | 0.707 | 1 |
| 60° | 0.866 | 0.5 | 1.732 |
| 90° | 1 | 0 | 不存在 |

### 5.3 用途

```
测高: 站在离树20 m处,仰望树顶的角度是30°,
  树高 ≈ 20 × tan30° + 眼睛高度 = 20 × 0.577 + 1.6 ≈ 13 m

坡度: 坡度 = 高度 ÷ 水平距离 = tan(坡角)
  1:3 的坡 ≈ 18.4°;45°的坡 = 1:1

正弦定理(任意三角形): a / sin A = b / sin B = c / sin C
余弦定理(任意三角形): c² = a² + b² - 2ab × cos C
  (C = 90°时就是勾股定理)
```

量角器可以用量角器纸样或半圆木板自制,每1°一格。

## 六、坐标和函数

### 6.1 坐标

```
在平面上画两条垂直的数轴(横轴 x,纵轴 y),
任何一点都可以用一对数 (x, y) 表示

用途: 画地图、画图表、把几何问题变成代数问题
```

### 6.2 正比例和直线

```
y = kx + b
  k: 斜率(每增加1,y增加多少)
  b: x = 0 时 y 的值

例: 每公顷施肥150 kg,另加基础用量5 kg → 总量(kg)= 150 × 面积(ha)+ 5
```

### 6.3 抛物线

```
y = ax² + bx + c 的图像是抛物线
  - 投出去的石块、喷出的水流的轨迹接近抛物线
  - 抛物面形状的镜子能把阳光汇聚到一点(太阳灶)
```

### 6.4 画图表

```
✓ 把记录的数据画成图: 横轴时间,纵轴产量/温度/病例数
✓ 趋势一眼就能看出来,比看一列数字容易发现规律
```

## 七、指数和对数

### 7.1 指数增长

```
每过一段时间,数量都乘以同一个倍数:
  N = N₀ × (1 + r)ⁿ

例子:
- 细菌每20分钟分裂一次,1个细菌8小时后变成 2²⁴ ≈ 1677万个
  (所以剩饭菜要冷藏,食物中毒的细菌繁殖极快)
- 人口增长、传染病早期的病例增长
- 复利: 借50 kg粮,每年利息10%,10年后要还 50 × 1.1¹⁰ ≈ 130 kg

"70法则": 每期增长 r%,大约 70 ÷ r 期翻一倍
  年增长7% → 约10年翻一倍
```

### 7.2 指数衰减和半衰期

```
每过一段时间都减少一半:
  N = N₀ × (1/2)^(t ÷ T),T 是半衰期

例: 碘-131半衰期约8天,80天后剩下 (1/2)¹⁰ ≈ 千分之一
```

核辐射的防护见[人为灾难](../02-灾难应对/05-人为灾难.md)。

### 7.3 对数

```
对数是指数的反运算: 如果 10³ = 1000,那么 lg 1000 = 3

性质(把乘除变成加减):
  log(a × b) = log a + log b
  log(a ÷ b) = log a - log b
  log(aⁿ) = n × log a

常用值: lg 2 ≈ 0.301,lg 3 ≈ 0.477,lg 10 = 1

自然对数 ln,以 e ≈ 2.71828 为底;换底公式 logₐ b = ln b ÷ ln a

历史意义: 在没有计算机的年代,天文学家和工程师用对数表、计算尺,
  把繁重的乘除法变成查表和加减法
```

## 八、微积分的基本思想

微积分是近代物理和工程的基础。这里只介绍思想和最基本的公式。

### 8.1 导数: 变化有多快

```
导数 = 瞬间的变化率
  - 位置对时间的导数 = 速度
  - 速度对时间的导数 = 加速度
  - 曲线某一点的导数 = 这一点切线的斜率

基本公式:
  (常数)' = 0
  (xⁿ)' = n × xⁿ⁻¹
  (eˣ)' = eˣ
  (ln x)' = 1/x
  (sin x)' = cos x
  (cos x)' = -sin x

用途: 求最大值和最小值(导数等于0的地方)
  例: 用一定长度的篱笆围出面积最大的长方形 → 正方形
```

### 8.2 积分: 累积了多少

```
积分 = 把很多很小的部分加起来
  - 速度对时间积分 = 走过的路程
  - 曲线下面的面积

基本公式: ∫ xⁿ dx = xⁿ⁺¹ ÷ (n+1) + C (n ≠ -1)

微积分基本定理: 积分和导数互为逆运算

近似计算(没有公式时): 把面积切成很多窄条,
  每条看作梯形,算出面积再加起来(梯形法)
```

## 九、概率与统计

决定一种药、一种种子、一种做法"是否真的有效",靠的是统计。

### 9.1 描述数据

```
平均数: 总和 ÷ 个数
中位数: 从小到大排列后中间的那个数(不受极端值影响)
  例: 5户人家存粮 50、60、65、75、1000 kg
  平均数 250 kg(被一户大户拉高),中位数 65 kg(更能代表一般人家)

标准差: 数据有多分散
  s = √[ Σ(每个数 - 平均数)² ÷ (个数 - 1) ]
```

### 9.2 正态分布

```
很多自然测量值(身高、产量、测量误差)呈"钟形"分布:
  - 约68%的数据落在 平均数 ± 1个标准差 内
  - 约95% 落在 ± 2个标准差 内
  - 约99.7% 落在 ± 3个标准差 内
```

### 9.3 概率

```
概率 = 有利结果数 ÷ 所有可能结果数(每种结果可能性相同时)

两件互不影响的事同时发生: 概率相乘
  两枚硬币都正面 = 1/2 × 1/2 = 1/4
两件不能同时发生的事,发生其中一件: 概率相加

期望值 = Σ(每种结果 × 它的概率)
  用来比较不同选择的平均收益
```

### 9.4 常见的错误

```
❌ 样本太少: 一个人吃了某种草药病好了,不能说明草药有效
❌ 相关不等于因果: 冰淇淋销量和溺水人数同时上升,原因是夏天
❌ 幸存者偏差: 只听到"用这个方法成功了"的人说话,失败的人没机会说话
❌ 没有对照组: 很多病不治也会好
```

对照实验的设计见[度量衡与科学方法-科学方法](00-度量衡与科学方法.md#一科学方法)。

## 十、实用算法

### 10.1 手算平方根(巴比伦法)

```
求 √a: 先随便猜一个数 x,然后反复计算
  新的 x = (x + a ÷ x) ÷ 2

例: √10,猜 x = 3
  (3 + 10/3) ÷ 2 = 3.1667
  (3.1667 + 10/3.1667) ÷ 2 = 3.1623
  已经非常接近真实值 3.16228
```

### 10.2 最大公约数(辗转相除法)

```
求 48 和 18 的最大公约数:
  48 ÷ 18 = 2 余 12
  18 ÷ 12 = 1 余 6
  12 ÷ 6 = 2 余 0 → 最大公约数是 6

用途: 约分、按比例分配
```

### 10.3 找质数(筛法)

```
1. 写出 2 到 100
2. 2 是质数,划掉所有 2 的倍数
3. 下一个没划掉的 3 是质数,划掉所有 3 的倍数
4. 重复,剩下的都是质数
```

### 10.4 二进制

```
只用 0 和 1 记数,逢二进一:
  1 = 1,2 = 10,3 = 11,4 = 100,13 = 1101(8+4+1)

意义: 开关、电路只有"通"和"断"两种状态,
  二进制是一切计算机的基础
```
