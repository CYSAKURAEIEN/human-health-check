# 基础科学知识

## 📋 目录概览

本部分收录对人类社会影响最大的数学、物理、化学、生物与医学知识: 公式、规律、性质,以及它们能用来做什么。目标是: **如果人类需要从头重建技术,手里有足够的理论基础**,不必从零摸索。

其他部分讲"怎么做"(怎样炼铁、怎样做肥皂、怎样建房),本部分讲"为什么"。理解了原理,遇到书上没写到的情况也能自己推断。

### 内容章节

1. [度量衡与科学方法](00-度量衡与科学方法.md) - 对照实验与记录、用秒摆和水重建米和千克、计时与温度、单位换算、没有仪器时的测量(3-4-5直角、水平、测高测距)
2. [数学](01-数学.md) - 位值制与分数、比例与稀释、方程、勾股定理与面积体积、三角函数、指数与对数、微积分思想、概率统计、实用算法
3. [物理](02-物理.md) - 牛顿定律、杠杆滑轮斜面、功与能量、水力、压强与大气压(水泵、虹吸、浮力)、热学、声与光、电与磁、原子与辐射、天文与历法
4. [化学](03-化学.md) - 元素与金属活动性、化学方程式计算、燃烧冶炼石灰发酵等重要反应、溶液浓度、酸碱盐、有机物基础、分离提纯、化学安全
5. [生物与医学基础](04-生物与医学基础.md) - 细胞与微生物、病菌学说与消毒灭菌原理、免疫与疫苗、抗生素与耐药、营养缺乏病、遗传与选种、人体基本知识、生态与农业生物学、流行病学基础、重大发现时间线

## 📖 学习建议

```
1. 先读度量衡与科学方法: 测量和验证是其余一切的基础
2. 数学先掌握前四节(计数、比例、方程、几何),够日常生产使用
3. 生物与医学基础建议通读: 洗手、净水、疫苗、营养这几条认识救人最多
4. 物理和化学按需要查阅: 建造看力学,取暖做饭看热学,
   发电看电磁学,冶炼、制皂、酿造看化学反应
5. 把公式用到实际问题上,在纸上算一遍,比背下来有用得多
```
