# 天气观测与预报

> **没有气象台的时候,天空、风和气压计就是天气预报。种地要看天,出行要看天,防灾更要看天**

## ⚠️ 本章的定位

本章讲不依赖气象部门、靠自己观察来判断未来一两天天气的方法,以及怎样长期记录本地的天气规律。

```
⚠️ 要清楚它的局限:
- 自己观察只能大致判断未来几小时到一两天的天气,准确度远不如专业预报
- 有官方预报和预警时,以官方为准(见灾难应对-灾难信息来源)
- 看到雷暴、山洪、台风等危险的征兆,宁可提前躲避
```

各类气象灾害的应对见[气象灾害](../02-灾难应对/02-气象灾害.md)。

## 一、天气是怎么形成的

```
太阳加热地面不均匀 → 空气受热上升、遇冷下沉 → 形成气压高低的差别
空气从高压流向低压 → 形成风
空气上升时膨胀冷却 → 水汽凝结成云 → 云滴长大到一定程度 → 下雨或下雪

所以:
- 低气压区: 空气上升,多云、多雨
- 高气压区: 空气下沉,多晴天、少云
- 冷空气和暖空气相遇的地方(锋面): 天气变化剧烈
```

## 二、看云识天气

### 2.1 主要的云

| 云 | 样子 | 高度 | 预示 |
|----|------|------|------|
| 积云 | 一朵朵白色棉花团,底部平 | 低 | 晴天里的"淡积云"是好天气;下午越长越高要警惕 |
| 积雨云 | 高耸像山或铁砧,底部乌黑 | 从低到很高 | 雷雨、大风、冰雹,有时伴有龙卷风 |
| 卷云 | 白色细丝、羽毛、钩子状 | 很高 | 卷云增多、变厚,天气可能在一两天内转坏 |
| 卷层云 | 白色薄幕,太阳、月亮周围出现"晕"(光圈) | 很高 | 常是下雨的前兆 |
| 高积云 | 一排排小云块,像鱼鳞 | 中 | 天气可能变化,常有风 |
| 高层云 | 灰白色幕,太阳像隔着毛玻璃 | 中 | 云继续加厚变低,不久会下雨 |
| 雨层云 | 灰暗、厚而低、看不到太阳 | 低 | 连续性的雨或雪 |
| 层云 | 灰色低云,像高处的雾 | 很低 | 毛毛雨或阴天 |
| 荚状云 | 像豆荚、透镜,静止不动 | 中 | 高空风很大;山区要警惕大风 |

### 2.2 典型的变天顺序

```
暖锋来临(天气逐渐转坏):
  卷云出现 → 卷层云,日月有晕 → 高层云,太阳像隔毛玻璃 →
  雨层云,开始下连续的雨(往往持续较久)
  → 从看到卷云增多到下雨,常在半天到一两天之间

冷锋过境(天气急变):
  西边或北边出现高耸的积雨云 → 风突然增大、转向,气温骤降 →
  短时间的阵雨、雷雨,有时冰雹 → 雨后迅速转晴,天空特别透亮,气温较低
```

### 2.3 雷暴的征兆

```
- 上午就出现积云,而且越长越高、顶部像花椰菜一样翻腾
- 午后天空迅速变暗,远处有雷声
- 风突然变凉、变大(雷暴前的"阵风锋")
→ 立即离开山顶、水边、开阔地,远离孤立的大树
```

雷电时的避险见[气象灾害-雷电](../02-灾难应对/02-气象灾害.md)。

## 三、气压和风

### 3.1 气压

```
气压下降 → 天气多半要变坏(多云、下雨、起风)
气压快速下降(几小时内明显下降) → 可能有强风暴、台风
气压上升 → 天气多半好转
气压稳定在较高水平 → 晴好天气可能持续

看的是变化趋势,不是一次读数
```

### 3.2 自制简易气压计

```
瓶子气压计:
1. 一个玻璃瓶装半瓶水,倒插进一个装水的盘子或宽口杯里(瓶口浸在水下,不碰底)
2. 瓶颈中的水位会随外面的气压变化: 气压降低,瓶里的水位下降;气压升高,水位上升
3. 在瓶上贴纸条,每天同一时间标记水位
⚠️ 温度变化也会影响水位,放在温度稳定的地方(室内背阴处),主要看变化趋势

有条件时: 回收的气压计、带气压功能的手表或手机(不需要信号)
```

### 3.3 风

```
风向: 风从哪个方向吹来,就叫什么风(北风 = 从北边吹来的风)
北半球的规律: 背对着风站立,低气压在你的左前方
  → 可以大致判断坏天气(低压)在哪个方向

风向转变:
- 风向逐渐由东南转向西北,风力增大 → 常是冷锋过境,降温
- 一直刮温暖潮湿的南风、东南风,气压下降 → 可能要下雨

山区和水边的局地风:
- 白天风从山谷吹向山顶(谷风),夜间从山顶吹向山谷(山风)
- 白天风从海(湖)吹向陆地,夜间反过来
```

### 3.4 风力等级

| 等级 | 名称 | 风速(m/s) | 陆地上的现象 |
|------|------|-----------|------------|
| 0 | 无风 | 0-0.2 | 烟直上 |
| 1 | 软风 | 0.3-1.5 | 烟能表示风向,风向标不动 |
| 2 | 轻风 | 1.6-3.3 | 人脸感觉有风,树叶微响 |
| 3 | 微风 | 3.4-5.4 | 树叶和细枝摇动不息,旗子展开 |
| 4 | 和风 | 5.5-7.9 | 吹起尘土和纸张,小树枝摇动 |
| 5 | 清劲风 | 8.0-10.7 | 有叶的小树摇摆,水面起小浪 |
| 6 | 强风 | 10.8-13.8 | 大树枝摇动,电线呼呼响,撑伞困难 |
| 7 | 疾风 | 13.9-17.1 | 全树摇动,迎风步行困难 |
| 8 | 大风 | 17.2-20.7 | 折断小树枝,人迎风前行阻力很大 |
| 9 | 烈风 | 20.8-24.4 | 房屋有小损(瓦片被掀起) |
| 10 | 狂风 | 24.5-28.4 | 树木可被吹倒,房屋损坏较重 |
| 11 | 暴风 | 28.5-32.6 | 大范围破坏 |
| 12 | 飓风(台风) | ≥32.7 | 摧毁力极大 |

## 四、其他征兆和谚语

我国民间积累了大量看天的经验,有的有科学道理,有的只在特定地区适用。

| 谚语 | 道理 | 可靠程度 |
|------|------|---------|
| 朝霞不出门,晚霞行千里 | 我国中纬度地区天气系统大多自西向东移动;早晨东边有霞说明西边云多、坏天气将到,傍晚西边有霞说明西边晴朗 | 较可靠(中纬度) |
| 日晕三更雨,月晕午时风 | 日晕、月晕来自卷层云,常是暖锋前的云 | 较可靠 |
| 天上钩钩云,地上雨淋淋 | 钩卷云增多,天气转坏 | 较可靠 |
| 鱼鳞天,不雨也风颠 | 高积云、卷积云预示天气变化 | 一般 |
| 燕子低飞要下雨 | 下雨前空气潮湿,昆虫飞得低,燕子追着捕食 | 一般 |
| 蚂蚁搬家早晚要下 | 蚂蚁对湿度敏感 | 一般 |
| 久晴大雾必阴,久雨大雾必晴 | 雾的成因不同 | 一般 |
| 早上露水重,白天多晴天 | 夜里晴朗无风,地面散热快才结露 | 较可靠 |

```
其他:
- 远处的声音(火车、钟声)听起来特别清楚、远山看起来特别近 → 空气潮湿,可能要下雨
- 水缸外壁"出汗"、盐罐返潮 → 空气湿度大
- 烟囱的烟贴地飘散 → 气压低,常是变天前
```

## 五、霜冻

霜冻对农作物危害很大,而且最常发生在看起来很"好"的天气里。

```
容易出现霜冻的情况:
- 春秋季节
- 晴朗无云的夜晚(地面向天空散热快)
- 无风或微风(冷空气沉在地面)
- 空气干燥
- 低洼地、山谷底部(冷空气往低处流)

防霜冻:
✓ 傍晚预感有霜冻时,用草帘、塑料布、旧布盖住幼苗和菜
✓ 浇一次水(湿土比干土放热慢)
✓ 在上风方向点燃湿草堆熏烟(⚠️ 注意防火)
✓ 种在坡地中部,不要种在冷空气聚集的低洼处
✓ 记录本地每年最后一次春霜和第一次秋霜的日期,安排播种和收获
```

## 六、自己做观测

### 6.1 简单的观测工具

```
雨量计: 一个直上直下、口径均匀的容器(如圆筒),放在开阔、没有遮挡的地方,
  口离地面约70 cm;雨后量水深(mm)就是降水量
  → 1 mm降水 = 每平方米1 L水
温度计: 挂在通风、背阴、离地约1.5 m的地方(最好放在白色、通风的百叶箱里),
  不要被太阳直晒
风向标: 一根能自由转动的杆,一头大一头小(大头像尾巴),小头指向风来的方向
气压计: 见3.2
```

降水量与收集雨水的计算见[水源工程与供水-收集雨水](../07-日常生活技能/10-水源工程与供水.md#收集雨水)。

### 6.2 天气日记

```
每天固定时间(如早上8点、下午2点、晚上8点)记录:
- 日期、时间
- 气温、气压(或水位)、风向、风力
- 云的种类和多少、天气现象(晴、雨、雪、雾、霜、雷)
- 降水量

坚持记录几年,就能总结出本地的规律:
- 雨季、旱季的大致时间
- 最后一次春霜、第一次秋霜
- 哪种云、哪种风之后通常会下雨
→ 这些规律比任何谚语都更适合本地
```

## 七、我国的气候概况

```
季风气候:
- 夏季: 东南季风、西南季风从海洋带来暖湿空气 → 多雨,雨热同期,利于农业
- 冬季: 西北季风从内陆带来寒冷干燥的空气 → 北方寒冷少雨
- 雨带每年大致从南向北推进: 华南前汛期 → 江淮梅雨 → 华北、东北雨季

主要灾害性天气:
- 台风: 夏秋季影响东南沿海
- 寒潮: 冬春季,气温骤降、大风
- 暴雨、洪涝: 夏季
- 干旱: 北方春旱较常见
```
