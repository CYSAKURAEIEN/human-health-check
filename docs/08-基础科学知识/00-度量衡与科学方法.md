# 度量衡与科学方法

> **一切科学和技术都从"能准确地测量"和"能可靠地验证"开始**

## ⚠️ 为什么从这里开始

数学、物理、化学的公式,只有在能**测量**的时候才有用: 不知道一米有多长、一公斤有多重,配不准药,炼不好铁,盖不直房子。

而科学方法决定了我们怎样知道一件事是"真的有效",还是"碰巧"或"以为有效"。历史上大量错误的疗法(放血、偏方)流传了上千年,就是因为没有对照和记录。

**这一章是本部分其余各章的基础。**

## 一、科学方法

### 1.1 基本步骤

```
1. 观察: 注意到一个现象
   例: 某块地的庄稼长得比别处好

2. 提出假设: 猜测原因,而且这个猜测必须能被检验
   例: 这块地以前堆过草木灰

3. 设计实验: 只改变一个因素,其他条件都相同
   例: 把一块地分成两半,一半撒草木灰,一半不撒,
       种同样的种子,浇同样的水

4. 记录结果: 用数字记录,不凭印象
   例: 每半块地收了多少斤

5. 得出结论,并重复验证
   例: 换一块地、换一年再做一次,结果一样才算数
```

### 1.2 对照实验: 最重要的一条

```
✓ 要有"对照组": 除了要测试的那一个因素,其他条件完全相同
✓ 一次只改变一个因素
   (同时换种子又换肥料,收成变好了也不知道是哪个的功劳)
✓ 样本要足够多: 一棵树、一个病人的结果说明不了问题
✓ 随机分组: 不要把好的地、身体好的人都分到一组

为什么重要:
- 很多病不治也会自己好,不对照就会以为是"药"的功劳
- 很多事情是巧合
```

### 1.3 记录

```
✓ 写下: 日期、做了什么、用了多少、条件(温度、天气)、结果
✓ 失败的结果也要记录(和成功的一样有价值)
✓ 记录要让别人看得懂、能照着重复
✓ 保存好,传下去

人类知识能够积累,靠的就是记录和传承。
```

## 二、重建长度、质量、体积、时间

在没有现成量具的情况下,可以利用自然界中稳定的东西重新建立标准。**最重要的是全社区使用同一个标准**,做出一把"标准尺"、一个"标准砝码",其他量具都照着它复制。

### 2.1 长度: 米

```
方法一: 秒摆
- 单摆的周期只和摆长有关(和摆锤轻重、摆动幅度小的时候无关)
- 摆长约0.994米的单摆,从一边摆到另一边正好1秒
- 做法: 细绳一端拴小重物,调整绳长,
  数它摆动60次(从一边到另一边算一次)是否正好1分钟
  → 摆长(悬挂点到重物中心)≈ 1米
- 需要先有可靠的计时(见下方"时间")

方法二: 保存下来的任何标准尺、卷尺
- 卷尺、钢尺、标准砖、A4纸(长297毫米、宽210毫米)、
  人民币硬币(1元硬币直径25毫米)都可以作为参照

1米 = 100厘米 = 1000毫米
1千米(公里) = 1000米
```

### 2.2 体积与质量: 升和千克

```
水是最好的标准:
- 1升 = 一个边长10厘米的立方体的容积
- 1升水的质量 ≈ 1千克(4°C时最准,常温下误差很小)
- 1毫升(1立方厘米)水 ≈ 1克

做标准砝码:
1. 做一个内边长10厘米的方盒(或用量过容积的容器)
2. 装满干净的水 → 这就是1千克
3. 用天平(等臂杠杆)把石块、金属块调整到和它一样重
4. 这块石头或金属就是"标准1千克"

天平: 一根木杆,正中间悬挂,两端挂秤盘
  两边平衡 → 两边质量相等(原理见物理-杠杆)
```

### 2.3 时间

```
一天:
- 太阳在正南方(北半球)时是"正午",影子最短
- 两次正午之间就是一天,分成24小时

日晷:
- 在平地上竖一根直杆,观察影子的方向和长度
- 影子最短时就是当地正午

摆钟:
- 摆长约1米的单摆每摆一次约1秒,可以用来细分时间

一年:
- 一年约365.2422天
- 冬至(北半球正午影子最长的一天)到下一个冬至就是一年
```

历法和用星星定方向见[物理-天文与地球](02-物理.md#九天文与地球)。

### 2.4 温度

```
摄氏度的两个固定点:
- 冰水混合物: 0°C
- 水在海平面沸腾: 100°C
  (海拔越高沸点越低,大约每升高300米降低1°C)

自制温度计: 细玻璃管装酒精或水银(水银有毒,慎用),
  在冰水和沸水中分别做记号,中间等分100格
```

## 四、没有仪器时的测量

### 4.1 画直角: 3-4-5 绳

```
1. 一根绳子上等距打13个结,分成12段
2. 拉成三角形,三边分别是3段、4段、5段
3. 3段和4段之间的角就是直角(90°)

用途: 盖房子放线、开垦方正的田地
原理: 勾股定理 3² + 4² = 5²(见数学-几何)
```

### 4.2 找水平

```
连通管(水平管):
- 一根透明软管灌满水(不能有气泡)
- 两端举起,两端的水面一定在同一高度
- 用来在两面墙上标出同样的高度

简易水平尺:
- 一个三角形木架,顶点挂一根铅垂线
- 底边中点做记号,铅垂线对准记号时,底边就是水平的

铅垂线: 绳子拴一个重物,自然下垂就是竖直方向
```

### 4.3 测高度和宽度

```
测树高、楼高(影子法):
1. 竖一根已知长度的杆子,量出它的影子长度
2. 同一时间量出树的影子长度
3. 树高 = 杆长 × (树影长 ÷ 杆影长)
原理: 相似三角形

测河宽:
1. 站在岸边A点,正对着河对岸的一个目标(如一棵树)
2. 沿着河岸(与A到目标的视线垂直)走到B点,插一根标杆,再继续沿同一方向走同样的距离到C点
3. 从C点转90度背离河岸走,直到D点看过去,标杆B和对岸的树在一条直线上
4. CD的长度 = 河宽
原理: 全等三角形
```

### 4.4 估算距离

```
步测:
- 先在已知距离(如100米)上走几次,数出自己的平均步数
- 之后数步数就能估算距离

雷电距离:
- 看到闪电后数秒,听到雷声为止
- 秒数 ÷ 3 ≈ 距离(公里)(声音每秒约传播340米)
```

雷电防护见[气象灾害-雷电](../02-灾难应对/02-气象灾害.md)。

## 五、误差与估算

```
✓ 任何测量都有误差: 多测几次,取平均值
✓ 记录时写清单位(只写"5"没有意义,是5米还是5厘米?)
✓ 有效数字: 尺子最小刻度是毫米,就不要写到0.01毫米
✓ 先估算再计算: 算出来的结果和估算差了十倍,多半是哪里算错了
✓ 配药、配消毒液、配制任何化学品时,单位和小数点错一位就是十倍的差别,
  必须复核
```
