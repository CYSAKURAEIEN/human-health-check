## 为什么种子断了农业就断了

粮食吃完了还能再种,种子没了就什么都种不出来。今天绝大多数农户每年买种子,一旦种子店、种子公司和物流停摆,**第一个种植季过后,手里的种子就决定了这个社区还能不能继续种地**。

```
⚠️ 先记住三件事:
1. 种子是"明年的粮食",再饿也不吃种子粮;单独存放、上锁、记账
2. 买来的商品种子常常拌了药(染成红、粉、蓝、绿等颜色):
   ☠️ 拌药种子含杀虫剂、杀菌剂,有的剧毒
   ✗ 不能吃,不能喂鸡鸭猪牛,不能和粮食混放,不放在孩子能拿到的地方
   ✓ 播种时戴手套,播完洗手;装过拌药种子的袋子、容器不再装食物
   ✓ 剩下的拌药种子照样能播种,但它结出的种子不再带药
3. 有条件时,现在就储备"常规品种"(能留种的品种)的种子
```

### 杂交种(F1)为什么不能留种

```
种子袋上写着"F1""杂交一代""××杂交种"的,就是杂交种
- 由两个不同的纯系亲本杂交得到,第一代整齐、高产、抗病(杂种优势)
- 它结的种子(F2)种下去,性状会分离: 高矮不齐、成熟期不一、产量明显下降,
  有的品质很差
- 杂交种子每年必须由制种单位重新配制,自家没法生产

所以:
✓ 储备和种植常规品种(也叫"常规种""农家种""传统品种""开放授粉品种")
✓ 常规品种年年留种,只要不和别的品种串粉,下一代和上一代基本一样
✓ 手里只有杂交种时: 照种照收,同时留种;连续几年挑选表现好的植株,
  慢慢可以选出一个稳定的新品种(见后文"选育"),但前几年产量会差一些
```

遗传和性状分离的原理见[生物与医学基础-遗传](../08-基础科学知识/04-生物与医学基础.md#61-遗传)和[选种育种](../08-基础科学知识/04-生物与医学基础.md#62-选种育种)。粮食作物留种的简要清单见[粮食作物-种子保存](02-粮食作物.md#种子保存)。

## 自花授粉与异花授粉

留种之前先弄清楚: 这种作物的花粉是自己给自己授粉,还是靠风、靠昆虫从别的植株传过来。

```
自花授粉: 花粉在花开之前或刚开时就落到同一朵花的柱头上
  → 很少和别的品种串粉,留种简单,留少量植株也不容易退化
异花授粉: 花粉要靠风或昆虫从别的植株、别的花传来
  → 附近有同一种作物的其他品种就会串粉,种子"变样"
  → 留种的植株太少会近交衰退(一代比一代弱),必须留足株数
常异花授粉: 以自花为主,但有相当比例靠昆虫串粉(如辣椒、茄子、蚕豆、高粱)
  → 按"中等难度"对待
```

| 类型 | 主要作物 | 传粉方式 | 留种难度 |
|------|----------|----------|----------|
| 自花授粉 | 水稻、小麦、大麦、大豆、豌豆、菜豆、番茄、生菜 | 自己授粉 | ⭐ 容易 |
| 常异花授粉 | 辣椒、茄子、蚕豆、高粱、棉花 | 自花为主,昆虫串粉 | ⭐⭐ 中等 |
| 异花授粉(风媒) | 玉米、菠菜、甜菜 | 风传花粉,能飘很远 | ⭐⭐⭐ 难 |
| 异花授粉(虫媒) | 黄瓜、南瓜、西瓜、甜瓜等瓜类;白菜、萝卜、甘蓝等十字花科;洋葱;胡萝卜 | 蜜蜂等昆虫 | ⭐⭐⭐ 难 |

```
哪些会互相串粉(同一个"种"之内才串):
- 白菜、小白菜、大白菜、芜菁(蔓菁)、菜心 → 互相串
- 甘蓝(包菜)、花椰菜、西兰花、芥蓝 → 互相串
- 萝卜和白菜 → 一般不串;萝卜和野萝卜 → 串
- 黄瓜只和黄瓜串,不和南瓜、西瓜串
- 西葫芦和部分南瓜(同一个种的)会串,不同种的南瓜之间一般不串;
  拿不准就当作会串
- 胡萝卜和野胡萝卜 → 串(野胡萝卜是常见杂草,开白色伞状花)
- 甜玉米、糯玉米、普通玉米 → 互相串
```

## 隔离、套袋和人工授粉

### 隔离距离

下表是家庭和社区留种时**常用的参考范围**,不是严格标准。地形、风向、树林和房屋遮挡、附近的蜂群数量都会影响结果;要求越纯,距离越大。

| 作物 | 参考隔离距离 | 说明 |
|------|--------------|------|
| 水稻、小麦、大豆、豌豆、菜豆、生菜 | 3-10 m | 不同品种隔开几行或种别的作物即可 |
| 番茄 | 3-15 m | 老品种中柱头伸出花外的,取上限 |
| 辣椒、茄子 | 50-200 m | 或套袋/罩网 |
| 黄瓜、瓜类、南瓜 | 400-800 m | 或人工授粉 |
| 白菜、萝卜等十字花科 | 500-1000 m | 或网罩 + 人工放蜂/授粉 |
| 洋葱、胡萝卜 | 500-1000 m | 胡萝卜还要拔除附近的野胡萝卜 |
| 菠菜 | 500-1000 m以上 | 风媒,花粉很轻 |
| 玉米 | 200-400 m以上 | 或花期错开约30天以上 |

```
没有足够距离时的办法:
1. 时间隔离: 两个品种错开播种,让开花期不重叠(玉米常用)
2. 一年只留一个品种: 同一种异花作物,今年留A品种,明年留B品种
   (种子能存好几年,轮流留种完全来得及)
3. 社区分工: 同一片地方,每户负责一种作物的一个品种
4. 套袋、网罩、人工授粉(下面)
```

### 套袋和人工授粉

```
套袋材料: 纸袋、纱布袋、细尼龙网袋;要透气,不能用塑料袋(闷热会烂花)

瓜类(南瓜、黄瓜)人工授粉:
1. 傍晚找第二天要开的花: 花瓣已经发黄、尖端快要张开
   雌花: 花下面带一个小瓜;雄花: 花下面只有细花柄
2. 用细绳或胶带把雌花和雄花的花瓣尖轻轻扎住,不让它们开放
3. 第二天上午(早晨露水干后),摘下雄花,撕去花瓣,
   把花药在雌花柱头上轻轻涂抹;最好用2-3朵不同植株的雄花
4. 授完粉马上把雌花花瓣再扎上或套袋
5. 在瓜柄上系一根有颜色的线做记号 → 只留这些瓜的种子

玉米人工授粉:
1. 雌穗吐丝之前,用纸袋套住雌穗(套袋前把苞叶尖剪掉一点也可以)
2. 雄穗开始散粉时,用大纸袋套住雄穗,第二天上午轻敲,收集花粉
3. 把几株的花粉混在一起,打开雌穗的袋子迅速撒在花丝上,立即重新套袋
4. 写好标签;袋子一直套到花丝变干变褐

十字花科、洋葱、胡萝卜:
- 整株罩细网(网眼能挡住蜜蜂),在网内用软毛笔每天在不同植株的花之间轻刷,
  或往网里放一些苍蝇、蜜蜂帮助授粉
```

### 最少留种株数

| 作物类型 | 最少株数 | 理想株数 |
|----------|----------|----------|
| 自花授粉(水稻、小麦、豆类、番茄、生菜) | 5-10株 | 20株以上 |
| 常异花(辣椒、茄子) | 10株 | 20株以上 |
| 瓜类、南瓜 | 5-6株 | 10-20株 |
| 十字花科、洋葱、胡萝卜、菠菜 | 20株 | 50株以上 |
| 玉米 | 100株 | 200株以上 |

```
为什么异花授粉作物要留这么多:
- 只从一两株留种,相当于让这个品种"近亲结婚"
- 几年下来植株变矮、变弱、产量下降、抗病力差,这叫近交衰退
- 玉米、十字花科、洋葱、胡萝卜对此最敏感;瓜类较不敏感
- 留种株数多,还能保住品种内部的多样性,遇到新病虫害时更可能有株能扛住
✓ 种子要从所有留种株上混合收取,不要只收其中最大的一两株
```

近亲繁殖的危害见[生物与医学基础-近亲繁殖的危害](../08-基础科学知识/04-生物与医学基础.md#63-近亲繁殖的危害)。

## 主要作物的留种要点

| 作物 | 授粉 | 什么时候收种 | 处理要点 | 最少株数 |
|------|------|--------------|----------|----------|
| 水稻 | 自花 | 穗子九成以上谷粒变黄、硬实 | 选穗大粒饱的单株,单收单脱,晒干 | 10-20 |
| 小麦 | 自花 | 完熟,籽粒变硬、指甲掐不动 | 同上;防雨淋防发芽 | 10-20 |
| 玉米 | 异花(风媒) | 苞叶干枯、籽粒基部出现黑层 | 带苞叶挂起晾干;只用果穗中段的籽粒 | 100+ |
| 大豆 | 自花 | 豆荚变褐、摇动有响声 | 及时收,晚了会炸荚;晒时防暴晒裂种 | 10-20 |
| 番茄 | 自花 | 果实完全熟透(比吃的还熟) | 发酵去胶(见下) | 5-10 |
| 黄瓜 | 异花(虫媒) | 瓜变黄褐、变软,比食用期晚约5周 | 挖出种子,发酵1-2天,洗净 | 5-6 |
| 南瓜 | 异花(虫媒) | 瓜皮坚硬、指甲掐不进,瓜柄干枯 | 收后放3-4周再取种;洗净晾干 | 5-6 |
| 辣椒 | 常异花 | 果实完全变红(或变成品种的成熟色) | 剖开刮下种子阴干;辣椒戴手套 | 10 |
| 白菜、萝卜 | 异花,二年生 | 第二年春天抽薹开花,角果变黄 | 越冬后栽种(见下) | 20+ |
| 洋葱 | 异花,二年生 | 第二年花球上的蒴果开裂、露出黑籽 | 剪下花球放纸袋中后熟 | 20+ |
| 胡萝卜 | 异花,二年生 | 第二年伞状花序变褐 | 分批剪下成熟的花序 | 20+ |
| 土豆 | 无性繁殖 | 茎叶枯黄,薯皮老化 | 留健康株的薯块做种薯 | — |
| 红薯 | 无性繁殖 | 霜前 | 种薯越冬,春天育苗剪藤 | — |

### 种子从湿果肉里取的作物(番茄、黄瓜)

```
番茄发酵去胶:
1. 挑选熟透、无病的果实,从多株上采
2. 切开,把种子连同周围的胶质挤进玻璃瓶或碗里,加少量清水
3. 放在室温下2-4天,每天搅一次;表面会长一层白霉,有酸臭味,这是正常的
4. 胶质分解后,种子沉底,空瘪种子和果肉浮起
5. 倒掉上面的漂浮物,加水再倒,重复几次,直到只剩干净的种子
6. 倒在细筛或布上滤干,摊在盘子、筛子上阴干(不要铺在纸巾上,会粘住)
7. 每天拨动几次,1-2周后完全干燥再装起来
→ 发酵能除去发芽抑制物质,还能杀死一部分附着在种子表面的病菌
⚠️ 不要发酵太久(超过约4天),种子可能在瓶里发芽

黄瓜: 留种瓜不摘,一直长到黄褐变软,方法同番茄,发酵1-2天即可
```

### 二年生作物: 白菜、萝卜、胡萝卜、洋葱

这些作物第一年长叶子、长根或长鳞茎,要经过冬天的低温,第二年春天才抽薹开花结籽。

```
1. 秋季收获时,挑选最符合品种特征的单株:
   根形端正、大小适中、不裂、不早抽薹、无病虫
   ✗ 不要选当年就提早抽薹开花的株(留了它的种,后代会更容易早抽薹)
2. 越冬:
   - 冬季不太冷的地方: 留在地里过冬,盖草保护
   - 寒冷地区: 挖出,萝卜、胡萝卜切去叶子(留2-3 cm叶柄),
     白菜去外层老叶,放在地窖里储存,温度约0-3°C,埋在湿沙中保湿;
     洋葱放在干燥通风处
3. 第二年早春栽回地里,株距加大(开花的植株很高大)
4. 开花期注意隔离(见上表)
5. 种荚、花序变黄变褐时分批收,或整株割下挂在通风处后熟,再敲打脱粒
⚠️ 萝卜、白菜的角果成熟后容易开裂,鸟也爱吃,要及时收
```

地窖储存的温度和湿度见[食物加工与保存-窖藏](../07-日常生活技能/01-食物加工与保存.md#窖藏)。

### 土豆和红薯: 用薯块繁殖

```
土豆种薯:
1. 生长季节在田里观察,给健壮、叶片平展、没有花叶和卷叶的植株插标记
2. 收获时单独挖这些植株,选30-60 g左右、无伤无病的薯块做种薯
3. 种薯和食用薯分开存放并标记,温度约2-4°C,避光
4. 播种前2-4周拿出来放在散射光下催芽,长出短而壮的绿芽
   ⚠️ 见光变绿的种薯不要吃
5. 大薯块切块,每块至少带1-2个芽眼,切后晾1-2天让切口干燥愈合再种;
   切刀切到病薯后要消毒(开水烫或酒精擦)

⚠️ 病毒积累(种薯退化):
- 土豆的病毒病随种薯一代代传下去,年年自家留种,几年后会越来越矮、
  叶子皱缩、产量大减
- 对策: 每年严格选健康株留种;病株连薯一起拔掉,不留种也不留在地里;
  在凉爽的高海拔地区或秋季留种(蚜虫少,传毒少);
  社区可以指定一块远离其他土豆地的"种薯田"

红薯种薯:
1. 霜前收获,选中等大小、无伤、无黑斑的薯块
2. 晾干表皮后储存在10-15°C,低于9°C易冻伤腐烂
3. 春天把种薯排在温床或苗床里,盖土保温保湿,长出藤蔓
4. 剪下20-30 cm长、带5-6个节的藤段插到地里
→ 温暖地区也可以把藤蔓插在室内或温暖处的盆里越冬
```

土豆和红薯的种植见[蔬菜种植-土豆](01-蔬菜种植.md#土豆)、[蔬菜种植-红薯](01-蔬菜种植.md#红薯)。

## 干燥、清选和储存

### 干燥

种子寿命最大的敌人是**潮湿和高温**。一条常用的经验法则: 种子含水量每降低1个百分点,或储存温度每降低5°C,储存寿命大约延长一倍(只在一定范围内适用)。

```
干燥方法:
✓ 摊薄放在筛子、竹匾、布上,放在通风阴凉处,每天翻动
✓ 粮食种子可以在早晚的阳光下晒
✗ 不要在正午烈日下的水泥地、铁皮、石板上暴晒小粒种子(温度可超过50°C,会烫死胚)
✗ 不要放在火炉、灶台上烘;人工加热时种子温度不超过约35°C

判断干没干(没有水分仪时):
1. 咬: 粮食和豆类种子用牙咬,咬不动、发出脆响 → 干了;咬下去有齿痕 → 还湿
2. 锤: 大粒种子(豆类、玉米)用锤子敲,碎裂 → 干了;压扁不碎 → 还湿
3. 折: 小粒种子用指甲压,碎裂 → 干了;变形 → 还湿
4. 盐测法(最可靠的土办法):
   - 在干燥的玻璃瓶里放一小把干的食盐(先在锅里炒干)
   - 放入一把种子,盖严,摇匀,放置约1天
   - 盐粒结块、粘在瓶壁上 → 种子还太湿,要继续晾
   - 盐粒松散 → 种子已经干燥到可以储存

参考含水量: 谷物种子约12%以下,豆类约12%以下,油料种子(大豆、花生、葵花籽)约8-9%以下
```

### 清选

```
1. 脱粒: 豆荚、角果装进布袋里踩、打;谷物用连枷或在桶边摔打
2. 风选: 在有风的地方或用扇子,把种子从高处慢慢倒到布上,
   轻的壳、碎屑被吹走
3. 筛选: 用不同孔径的筛子去掉大杂物和瘪小的种子
4. 水选: 番茄、瓜类种子放进水里,沉下去的饱满,浮起来的扔掉;
   水稻可以用盐水选种,浮起的空瘪粒去掉,选完立即用清水洗净
   ⚠️ 水选后必须重新彻底晾干再储存
5. 手选: 挑出病斑粒、虫蛀粒、变色粒、杂草种子
```

### 储存

```
✓ 干燥: 晾干后装进能密封的容器(玻璃瓶、带盖陶罐、金属罐、厚塑料瓶)
✓ 密封容器里放干燥剂: 炒干后冷却的米、干燥的草木灰、烘干的硅胶,
  用纸或布包好,和种子隔开
✓ 低温: 放在家里最凉、温度最稳定的地方(地窖、北面房间的地上);
  ✗ 不要靠近灶台、屋顶下面、向阳的墙
✓ 冷冻: 充分干燥的种子可以冷冻,储存寿命能延长很多;
  从冰箱取出后,等容器回到室温再打开,否则水汽会凝结在种子上
✓ 防虫:
  - 豆类、谷物最容易生虫;入库前可以冷冻几天杀死虫卵
  - 拌入干燥的草木灰,或混入晒干的花椒、艾叶
  - 密封容器本身能闷死大部分害虫
✓ 防鼠: 金属罐、陶罐或吊起来
✓ 标签: 每一个容器内外各放一张标签(外面的可能掉),写:
  作物、品种名、留种年份、产地/来源、留种株数、发芽率和测试日期
```

| 作物 | 一般储存条件下大致可用年限 |
|------|----------------------------|
| 洋葱、大葱、韭菜 | 1-2年 |
| 花生、大豆 | 1-3年 |
| 玉米、胡萝卜、辣椒、菠菜 | 2-3年 |
| 水稻、小麦、菜豆、豌豆 | 2-4年 |
| 生菜、白菜、萝卜 | 3-5年 |
| 番茄、茄子 | 4-6年 |
| 黄瓜、南瓜、西瓜等瓜类 | 5-6年 |

```
这里的年限指在干燥、阴凉条件下,发芽率仍然比较好的时间;
干燥后冷藏或冷冻可以长得多,潮湿闷热的屋里可能一年就大幅下降
→ 年限短的种子(洋葱、大葱等)最好每年都留
→ 所有种子都不要等到"快不行了"才种,应该在年限内轮换更新
```

粮食的干燥和防虫储存见[食物加工与保存-粮食和豆类](../07-日常生活技能/01-食物加工与保存.md#粮食和豆类)。

## 发芽率测试

存放了一段时间、换来的、或拿不准的种子,播种前2-3周先测发芽率,不要等播下去不出苗才发现。

```
湿纸巾法:
1. 随机数出100粒(种子少时可以用50粒,结果乘2)
2. 把纸巾、草纸或棉布打湿,拧到不滴水
3. 种子均匀摆在上面,互相不接触,卷起来或对折
4. 装进塑料袋或盖上盘子保湿,写上作物名和日期
5. 放在温暖处(大多数作物约20-25°C;
   瓜类、辣椒、茄子喜欢更暖,约25-30°C)
6. 每天检查,保持湿润但不积水;长出胚根的种子数一次,拣出来
7. 统计: 大多数作物7-10天;辣椒、茄子、胡萝卜、洋葱、菠菜要等14天左右

发芽率 = 发芽的种子数 ÷ 测试的种子数 × 100%
```

| 发芽率 | 判断 | 做法 |
|--------|------|------|
| 85%以上 | 好 | 正常播种 |
| 60-85% | 一般 | 按比例加大播种量 |
| 40-60% | 差 | 加大播种量,并尽快种一茬重新留种 |
| 40%以下 | 很差 | 尽量换种子;只有这批时,大量播种并全部用来繁殖新种子 |

```
调整播种量:
实际播种量 = 原定播种量 ÷ 发芽率

例: 原计划每穴播2粒,发芽率60% → 2 ÷ 0.6 ≈ 3.3,每穴播3-4粒
例: 原计划播种量 50 kg/ha,发芽率80% → 50 ÷ 0.8 ≈ 63 kg/ha

注意: 田间出苗率通常比纸巾上的发芽率低一些(土壤温度、湿度、虫害),
     重要的作物再多留一点余量
```

## 无性繁殖

用根、茎、叶、芽直接长成新植株,新植株和母株完全一样。果树、葡萄、土豆、红薯、大蒜、草莓等都靠它保持品种。

```
⚠️ 无性繁殖的风险: 母株带的病毒病会原样传给后代,
   所以只从健康、高产、多年表现好的母株上取材料
```

### 扦插

```
硬枝扦插(葡萄、无花果、石榴、桑、柳、杨):
1. 冬季落叶后到春季发芽前,剪取一年生、铅笔粗细的健壮枝条
2. 剪成约15-20 cm长,带3-4个芽;上端在芽上方约1 cm平剪,下端在芽下斜剪
   (这样上下不会插反)
3. 暂时不插的捆好埋在湿沙里,放在阴凉处
4. 春天插进疏松的土或沙里,只露出最上面1个芽,压实,浇透
5. 保持土壤湿润,遮阴,新根长出前不要拔出来看

嫩枝扦插(很多花木、部分果树、薄荷、番茄侧枝):
1. 生长季剪取半木质化的新梢,约10-15 cm,保留顶端2-3片叶
2. 插进湿润的沙或土,遮阴,罩上塑料袋或倒扣的瓶子保湿
3. 2-4周后轻拉有阻力 → 已生根

✓ 柳枝泡的水(新鲜柳枝切段浸泡一两天)常被用作土生根剂,有一定帮助
```

### 分株

```
适合: 韭菜、葱、大蒜、黄花菜、薄荷、草莓、芦荟、香蕉、竹子
1. 春季或秋季,把成丛的植株挖出
2. 用手或刀分成几丛,每丛都要带根和芽
3. 剪掉过长的根和部分叶子,马上栽种、浇水
草莓: 匍匐茎上长出的小苗生根后剪断,就是新苗
```

### 压条

```
普通压条(葡萄、黑莓、迎春等枝条柔软的):
1. 把靠近地面的枝条弯下,在要埋土的地方把树皮刮伤一小段
2. 埋入土中约10 cm深,用钩子或石块固定,枝梢露出地面
3. 保持湿润,生根后(通常几个月到第二年春天)从母株上剪断,移栽

高空压条(枝条不能弯到地面的果树、柑橘、荔枝):
1. 选1-2年生枝条,环剥一圈宽约1-2 cm的树皮,刮净
2. 用湿苔藓或湿土包住伤口,外面用塑料布裹紧,两头扎住
3. 一两个月后从塑料布里看到根,在下方剪断,栽进盆或地里
```

### 嫁接

把一个品种的枝或芽(接穗)接到另一株有根的植物(砧木)上。**成败的关键是让两者的形成层(树皮和木质部之间那层青绿色的薄层)对齐贴紧**。

```
基本要求:
- 亲缘相近才能接活: 苹果接苹果或海棠,梨接梨或杜梨,桃接桃或山桃/毛桃,
  柑橘接枳或其他柑橘,枣接酸枣;不同科的基本接不活
- 刀要非常锋利、干净;切面一刀削平,不能来回拉锯
- 动作要快,切面不要碰手、不要沾土、不要晾干
- 绑扎材料: 塑料薄膜条最好;没有时用浸湿的麻皮、树皮
- 伤口封闭: 蜡、蜂蜡和油脂的混合物,或湿黏土,防止失水

劈接(春季发芽前后,砧木较粗时):
1. 接穗: 冬季剪取健壮的一年生枝,埋在湿沙中低温保存,保持不发芽
2. 在离地面约5-10 cm处锯断砧木,削平断面
3. 用刀在断面中间向下劈一道约3-4 cm深的口
4. 接穗留2-3个芽,下端两侧各削一刀,削成约3 cm长的楔形,外侧略厚
5. 用刀撬开劈口,插入接穗,让接穗外侧的形成层与砧木一侧的形成层对齐
   (砧木粗时两边各插一根)
6. 抽出刀,用塑料条从下往上绑紧,断面和接穗顶端用蜡或泥封住
7. 砧木上冒出的芽要及时抹掉,不和接穗争养分
8. 接穗发芽长出新梢后,适时松绑,防止勒伤

芽接(T形芽接,夏末到初秋,树皮容易剥开时):
1. 在砧木离地约5-10 cm、光滑的一面,横切一刀,再从中间向下竖切一刀,成"T"形,
   深到木质部
2. 从接穗枝条上削下一个饱满的芽: 从芽下约1-1.5 cm处向上削,
   带一薄层木质,到芽上约1 cm处横切一刀取下,剪掉叶片、保留叶柄
3. 轻轻撬开T形口的树皮,把芽片从上往下插进去,上端与横切口对齐
4. 用塑料条从下往上绑紧,露出芽和叶柄
5. 约10-15天后检查: 碰一下叶柄就脱落、芽片仍然新鲜 → 成活;
   叶柄干枯不掉、芽片发黑 → 失败,可在旁边重接
6. 成活的芽当年不剪砧,第二年春天发芽前,在接芽上方约1 cm处剪掉砧木
```

果树的品种选择和定植见[果树培育](03-果树培育.md),磨刀见[木工与工具维护-磨刀](../07-日常生活技能/09-木工与工具维护.md#磨刀)。

### 储存块根、块茎、鳞茎

种用的薯块、鳞茎和食用的分开存放、单独标记,入窖前挑出有伤、有病斑的,储存期间每月翻检一次。各自的储存温度见[食物加工与保存-各类蔬菜的储存条件](../07-日常生活技能/01-食物加工与保存.md#各类蔬菜的储存条件)。

## 选育: 让品种一年比一年好

留种不只是"保存",每年选什么样的植株留种,就是在决定这个品种往哪个方向变。

```
选什么:
✓ 产量高、籽粒或果实饱满
✓ 抗病、抗虫,在病害流行的年份仍然健康
✓ 适应本地: 耐旱、耐寒、成熟期合适(赶在霜冻或雨季之前)
✓ 抗倒伏(粮食作物)、不早抽薹(叶菜、根菜)
✓ 好吃、好储存
✗ 不要只看果实大小: 要看整株,在田里看,不要等收回家再挑
✗ 不选种在特别肥沃的地头、粪堆边、孤立的空地上的株: 它们长得好可能只是条件好
```

### 两种基本方法

```
混合选择(简单,适合大多数情况):
1. 在田里(而不是在晒场)挑出一批符合要求的植株,做标记
2. 把它们的种子混在一起收,作为下一年的种子
3. 每年重复
→ 能保持并慢慢改良品种,保留多样性;异花授粉作物尤其适合

单株选择(更快,适合自花授粉作物或想选出新类型时):
1. 发现某一株特别突出(例如早熟一周、病害年份没有发病),单独收种
2. 第二年把它的种子单独种一小行(一株一行),和普通种子种在旁边对比
3. 只保留表现确实更好、而且整行整齐的株系,其余淘汰
4. 连续两三年仍然表现好,再扩大繁殖
→ 自花授粉作物一两年就能稳定;异花授粉作物要避免一直单株选,会近交衰退

去杂(每年都做):
在开花前和收获前各巡田一次,把明显不像本品种的植株(太高、太矮、
颜色不对、早抽薹、病株)拔掉,不让它开花授粉
```

### 记录本

```
每个品种一页,每年记:
- 品种名(自己起的名字也行,统一叫法)、来源(哪里换来的、谁给的)
- 留种年份、播种日期、种植地块
- 出苗、开花、成熟日期
- 表现: 产量、病虫害、耐旱耐寒、味道、储存性
- 留种株数、选择标准、发芽率
- 和哪些品种挨着种过(可能串粉)
→ 几年下来,哪个品种适合本地一目了然
```

记录的方法见[记账、交易与社会分工-社区档案](../07-日常生活技能/13-记账交易与社会分工.md#社区档案)。

### 防止混杂,保持多样性

```
防混杂:
✓ 不同品种分块种,中间留空当或种别的作物,地头插牌子
✓ 留种的先收,单收、单晒、单脱粒、单装袋;换品种时清扫晒场、工具、筛子、袋子
✓ 自生苗(去年掉在地里长出来的)不留种

多样性:
✗ 全社区只种一个"最好"的品种: 一场新病害、一次反常天气就可能全部绝收
✓ 每种主要作物至少保留2-3个品种(早熟和晚熟、耐旱和耐涝、高产和抗病)
✓ 主粮不只靠一种作物: 稻、麦、玉米、薯类、豆类搭配
✓ 少种的老品种也定期种一小块更新种子,不要让它在库里"老死"
```

## 社区种子库

个人的种子容易被老鼠、受潮、火灾一次毁掉;一个社区集中管理、分散保存,才能保证每年都有种可种。

```
组织方法:
1. 指定1-2个负责人(要细心、会记账),另有一人做副手,两人都懂全部流程
2. 登记: 每份种子编号,记录作物、品种、来源、年份、数量、发芽率、存放位置
3. 至少保存两份,放在不同的建筑里(防火、防水、防鼠)
4. 主粮种子保留至少够两季播种的量,防止一季绝收后无种可播
5. 每年测一次发芽率;发芽率明显下降或接近储存年限的,
   安排人种一茬,收新种子替换
6. 分配种植任务: 异花授粉作物同一片区域一年只种一个品种用于留种,
   不同的人家负责不同的作物和品种
7. 借种还种: 领走种子的人,收获后归还更多的种子(常见做法是借一还二),
   归还的种子要经过检查、晾干、测发芽率
8. 交换: 和附近社区交换品种,既增加多样性,也互为备份;
   换来的种子先小面积试种一年
9. 教学: 让年轻人参与留种全过程,不要只有一两个人会
```

库存管理的方法见[记账、交易与社会分工-库存管理](../07-日常生活技能/13-记账交易与社会分工.md#库存管理),教人手艺见[教育与知识传承-怎样教手艺](../07-日常生活技能/12-教育与知识传承.md#怎样教手艺)。

## 📝 留种与育种要点

```
1. 种子是明年的粮食,再饿也不吃种子粮;拌药种子有毒,不能吃、不能喂牲畜
2. 储备常规品种;杂交种(F1)的后代会分离,不适合直接留种
3. 先分清自花和异花授粉: 自花容易留,异花要隔离、套袋或人工授粉
4. 异花授粉作物要留足株数(玉米100株以上,十字花科、洋葱、胡萝卜20株以上)
5. 番茄、黄瓜发酵去胶;白菜、萝卜、胡萝卜、洋葱要越冬到第二年才结籽
6. 种子要充分干燥(盐测法),密封、低温、防虫防鼠,内外都贴标签
7. 播种前做发芽率测试,按"原定播种量 ÷ 发芽率"调整播种量
8. 土豆选健康株留种防病毒退化;果树靠嫁接、扦插、压条保持品种
9. 在田里选整株,每年去杂,做记录;每种作物保留多个品种
10. 社区种子库集中登记、分开存放、定期更新、借一还二
```
