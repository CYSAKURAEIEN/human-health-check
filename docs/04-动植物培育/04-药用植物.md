# 药用植物识别与种植指南

⚠️ **重要声明**:
- 本章节仅供教育参考
- 不能替代专业医疗诊断和治疗
- 使用前请咨询医生或中医师
- 错误使用可能有害
- 某些植物有毒,需专业指导

```
本章能做的:
✓ 认识、种植、采收、干燥储存几种常见而温和的药用植物
✓ 知道它们最容易和哪些有毒植物认错,怎样区分
✓ 知道哪些人不该用、和哪些西药同用要小心

本章不能做的:
❌ 不能用来给自己或家人"看病开方"
❌ 发热不退、剧烈疼痛、呼吸困难、便血、黄疸、孕期不适、
   婴幼儿生病等情况,任何草药都不能代替就医——先拨打120或去医院
```

药方、煎煮方法、炮制和配伍禁忌见[中药制剂](../06-制药技术/04-中药制剂.md),本章不重复;误食野菜和毒蘑菇见[毒蘑菇与野菜误食](../03-野外生存/09-毒蘑菇与野菜误食.md)。

**本章用量的读法**: 每种植物后面写的"常规用量",是《中华人民共和国药典》中该药材成人每日干品的常规范围,只用来提醒"不要超量",不是让读者自行用药。**具体用不用、用多少,按药典和中医师的指导**;儿童、老人、体弱者的用量更小,需要医生定。

## 常见易种药用植物

下面每种植物按同样的顺序写: 功效 → 识别(和容易混淆的有毒植物) → 种植 → 采收与干燥 → 用法 → 禁忌和用药提醒。

### 薄荷

**功效**: 疏风散热,清利头目,利咽,透疹

**识别**:
```
- 多年生草本
- 茎四棱
- 叶对生,卵形,有锯齿
- 揉搓有强烈薄荷香
- 夏季开淡紫色小花
```

**易混淆**: 留兰香(绿薄荷)、藿香、荆芥、紫苏都是茎四棱、叶对生、有香气的唇形科植物,彼此认错一般不会中毒,但功效不同。真正要防的是**把不认识的、没有薄荷香味的野草当成薄荷**——判断时一定要揉碎叶子闻,薄荷的清凉味非常明确。

**种植**:
```
✓ 极易种植!
✓ 分株或扦插
✓ 喜湿润
✓ 半阴或全日照
✓ 生长快,需控制(侵占性强)

具体做法:
- 春季(日均气温约10°C以上)挖一段带根的地下茎,剪成10-15 cm、
  带2-3个节的小段,平埋在5 cm深的土里,株行距约30 cm
- 扦插: 剪8-10 cm嫩枝,去掉下部叶片,插入湿土或清水,
  约1-2周生根
- 土要保持湿润但不积水;叶片发黄卷边多是缺水或积水烂根
- 控制蔓延: 种在花盆、无底旧桶里,或在四周埋入约30 cm深的挡板
- 每2-3年挖出来重新分栽一次,否则老根盘结、长势变差

常见问题:
- 锈病(叶背橙黄色小点): 剪掉病叶烧掉,改善通风,不要从上往下浇水
- 蚜虫: 用清水冲、手捏,或喷稀肥皂水
```

扦插和分株的通用做法见[留种与育种-扦插](08-留种与育种.md#扦插)、[分株](08-留种与育种.md#分株)。

**采收**:
```
采收:
- 生长期随时采叶
- 开花前采收药效最好
- 鲜用或晒干

具体:
- 一年可收割2次左右: 头茬在初夏现蕾前,二茬在秋季
- 晴天上午露水干后,在离地约10 cm处割下,留茬让它再发
- 干燥: 捆成小把倒挂在通风阴凉处阴干;
  薄荷靠挥发油起作用,暴晒或高温烘烤香气会散失,
  烘干时温度不超过约35-40°C
- 干好的标准: 叶片一搓就碎,茎一折就断
```

**用法**:
- 泡茶: 解暑、清咽
- 外用: 止痒(蚊虫叮咬)

```
- 泡茶: 干叶一小撮(约3 g)或鲜叶几片,开水冲泡,加盖焖几分钟
  常规用量: 3-6 g(按药典/中医师指导);入煎剂时"后下"
- 外用: 鲜叶揉出汁涂在蚊虫叮咬处,止痒
```

**禁忌和提醒**:
```
⚠️ 薄荷油、薄荷脑(清凉油、风油精的成分)不要涂在婴幼儿的
   口鼻附近,可能引起喉头痉挛、呼吸暂停
⚠️ 不要自制或口服薄荷精油、其他植物精油
- 胃食管反流(烧心)的人喝薄荷茶可能加重
- 体虚多汗者不宜常喝
- 哺乳期大量饮用可能减少乳汁
- 与西药: 作为茶饮少量饮用,一般没有明确的相互作用;
  长期服药者仍应告诉医生
```

### 金银花(忍冬)

**功效**: 清热解毒,疏散风热

**识别**:
```
- 多年生藤本
- 叶对生,卵形
- 花初开白色,后变黄色(金银相映)
- 花香浓郁
- 5-7月开花

补充:
- 半常绿缠绕藤本,幼枝和叶两面常有短柔毛
- 花冠细长,先端分成上下两片(唇形),雄蕊伸出花外
```

**⚠️ 致命易混: 钩吻(断肠草)**

钩吻同为藤本、开黄花,在华南地区常被误当金银花采摘泡茶,每年都有中毒死亡案例。钩吻中毒发作快,可迅速导致呼吸麻痹。

| 特征 | 金银花 | 钩吻(断肠草) |
|------|--------|---------------|
| 花形 | 唇形,细长管状,花瓣上下分裂 | 漏斗/喇叭形,5裂整齐 |
| 花的排列 | 两朵并生于叶腋 | 多朵聚成伞状花序 |
| 花色 | 先白后黄,同株黄白相间 | 只有黄色 |
| 叶片 | 被短柔毛 | 光滑无毛,有光泽 |
| 花期 | 5-7月 | 约5-11月(与金银花重叠,不能靠花期区分) |

**原则: 野外采集的"金银花"不能100%确认,就不要用。优先使用自家种植的。**

```
另外注意:
- 钩吻不开花的时候更难区分,没有花的藤条、叶子一律不采
- 钩吻的根、茎、叶、花全株有毒,不要用来泡药酒、炖汤
- 喝了自采的"金银花茶"后出现口舌发麻、头晕、视物模糊、
  眼睑下垂、四肢无力、呼吸困难 → 立即拨打120,
  带上剩下的花和叶给医生看
- 山银花(灰毡毛忍冬等)外形相近,无毒,
  但药典把它和金银花列为两种药材
```

中毒的处理见[误食有毒植物怎么办](#误食有毒植物怎么办)。

**种植**:
```
✓ 适应性强
✓ 扦插或分株
✓ 喜阳光
✓ 耐旱耐瘠
✓ 需搭架或地栽让其攀援

具体做法:
- 扦插: 春季或雨季,剪1-2年生健壮枝条20-30 cm(带3-4个节),
  斜插入土中约2/3,浇透水,保持湿润,约1个月生根
- 地栽株行距约1.5 m × 1.5 m;靠墙、篱笆或搭1.5 m左右的架子
- 修剪: 冬季剪去枯枝、过密枝,把主干控制在1 m左右,
  让它长成灌木状——花开在新枝上,修剪后开花更多、也好采
- 头一两年就能开少量花,3年后进入盛花期

常见问题:
- 蚜虫(新梢和花蕾上成团): 早发现,剪掉虫枝或冲洗
- 白粉病: 加强通风,剪除病叶
- 药园尽量不用农药;必须用时按标签,严格遵守安全间隔期,
  不用国家禁用的高毒农药
```

**采收**:
```
采收:
- 花蕾期采收(未开放)
- 早晨采收最佳
- 及时晒干或烘干

具体:
- 最佳时机: 花蕾由绿变白、上部膨大但还没开放时
  (已开放的花药效和品质都差)
- 一年可采2-4茬,每茬花期集中约1周,要每天采
- 采后当天摊在竹席、纸上晒,厚度约1 cm;
  晒的过程中尽量不要翻动、不要用手捏,否则花会变黑
- 阴雨天烘干: 先30-35°C烘几小时,再升到约50°C烘干
- 干好的标准: 手一握有响声,花蕾一捏就碎
```

**用法**:
- 泡茶: 清热解毒,预防感冒
- 煎服: 咽喉肿痛,热毒疮疡

```
- 泡茶: 干花约3-5朵到一小撮,开水冲泡
- 常规用量: 6-15 g(按药典/中医师指导)
- "预防感冒"没有可靠证据,预防呼吸道传染病主要靠
  通风、洗手、戴口罩、接种疫苗
```

**禁忌和提醒**:
```
- 性寒,脾胃虚寒、常腹泻的人不宜常喝
- 孕妇、哺乳期、婴幼儿: 先问医生
- 咽喉肿痛伴高热、吞咽困难、流口水,或疮疡红肿迅速扩大、
  发热——可能是严重感染,应就医,不要只靠金银花
- 与西药: 作为茶饮一般无明确相互作用;正在服药者告诉医生
```

### 菊花

**功效**: 疏风清热,平肝明目

**识别**:
```
- 多年生草本
- 叶互生,羽状分裂
- 秋季开花,颜色多样
- 气味芳香

补充:
- 药用菊花是头状花序,外圈舌状花白色或黄色,中间管状花黄色
- 野菊花: 花小(直径约1.5-2.5 cm)、黄色、味很苦,
  也是一味药材,但药性更苦寒,不能当普通菊花茶天天喝
```

**易混淆**: 花店、公园的观赏菊、盆栽菊多喷过农药,**不能采来泡茶**。菊科中有些植物(如千里光、菊三七)含有损伤肝脏的成分,野外采"黄花"泡茶前要100%确认,见[有毒植物(避免误用)](#有毒植物避免误用)。

**种植**:
```
✓ 容易种植
✓ 分株或扦插
✓ 喜阳光充足
✓ 排水良好
✓ 秋季开花

具体做法:
- 扦插: 4-5月剪嫩枝顶端8-10 cm,插入湿沙或疏松土中,
  遮阴保湿,约2-3周生根
- 分株: 春季把老株挖出,分成带根的小丛另栽
- 株行距约40 cm;怕积水,低洼地要起高垄
- 摘心: 苗高约20 cm时掐掉顶尖,以后再摘2-3次,
  分枝多、花多;7月下旬以后不再摘心,否则影响开花
- 同一块地连续种菊花,枯萎病、根腐病会越来越重,
  最好隔2-3年换地种

常见问题:
- 蚜虫: 冲洗、手捏、剪掉
- 叶片下部发黑枯死(叶斑病): 摘除病叶,避免株间过密
```

**采收**:
```
采收:
- 花盛开时采收
- 晒干或烘干

具体:
- 霜降前后,花瓣平展、约七八成开放时,晴天露水干后采
- 菊花直接晒容易散瓣、变色,传统做法是:
  把花放在蒸笼里蒸约3-5分钟(蒸到花瓣稍软即可),再摊开晒干
  或者阴干,或低温(约40-50°C)烘干
- 干好的标准: 花托一捏就碎,没有湿心
```

**用法**:
- 泡茶: 清肝明目,降火
- 药用多用杭白菊、贡菊

```
- 泡茶: 干花4-6朵,开水冲泡
- 常规用量: 5-10 g(按药典/中医师指导)
- "明目"不能代替眼科检查: 视力突然下降、眼痛、眼红伴头痛、
  看东西有黑影飘动或闪光 → 当天去医院
```

**禁忌和提醒**:
```
- 对菊科植物(菊花、艾草、蒲公英、豚草等)过敏的人不要用,
  可能出现皮疹、哮喘
- 性微寒,脾胃虚寒、常腹泻的人少喝
- 与西药: 茶饮量一般无明确相互作用
```

### 生姜

**功效**: 发汗解表,温中止呕,温肺止咳

**识别**:
```
- 多年生草本
- 地下根茎肥大,淡黄色
- 叶披针形,互生
- 独特辛辣味
```

**易混淆**: 生姜一般从菜场买种姜,不会认错。野外的"野姜"种类很多,不要采来吃或入药。

**种植**:
```
✓ 温暖湿润环境
✓ 种姜(根茎)种植
✓ 春季种植
✓ 充足水分
✓ 半阴环境

具体做法:
- 选种: 肥大、皮色光亮、无病斑、没受冻的老姜
- 催芽: 晒姜1-2天,然后在约20-25°C的地方(盖湿草或放在暖炕旁)
  放约20-30天,芽长到约1-1.5 cm
- 掰块: 掰成每块约50-75 g、带1-2个壮芽的姜块
- 下种: 地温稳定在约15°C以上时(多数地区4-5月),
  开沟深约10-15 cm,行距约50-60 cm、株距约20 cm,芽朝上平放,
  盖土约5 cm
- 用种量大: 约0.6-0.75 kg/m²(约6000-7500 kg/ha)
- 遮阴: 生姜怕强光,夏季用树枝、遮阳网搭棚,遮去约三到五成光
- 培土: 出苗后随着根茎长大,分2-3次把沟边的土培到根部,
  姜块才长得大、不发绿
- 土壤保持湿润,但积水会烂姜

常见问题:
- 姜瘟(细菌性病害,叶片发黄卷曲、根茎变褐腐烂、有臭味):
  一旦发生很难治;拔除病株连土带走深埋,
  同一块地3-4年内不再种姜,不用病姜作种
```

**采收**:
```
采收:
- 嫩姜: 夏季
- 老姜: 秋季霜前

储存:
- 老姜不要洗,带少量泥土放在地窖、沙堆里
- 适宜温度约12-15°C,湿度高;低于约10°C会冻伤,之后容易腐烂
- 入药用的"干姜"是老姜切片晒干或低温烘干的,
  和生姜的药性不同
```

地窖的建法见[食物加工与保存-窖藏](../07-日常生活技能/01-食物加工与保存.md#窖藏)。

**用法**:
- 煮水: 风寒感冒,恶心呕吐
- 泡茶: 姜枣茶(暖胃)
- 食用: 调味,温中

```
- 煮水: 切3-5片,加水煮约10分钟,趁热喝
- 常规用量: 3-10 g(按药典/中医师指导),约相当于几片
```

**禁忌和提醒**:
```
⚠️ 腐烂的生姜不要吃: 烂了的部分切掉也不保险,整块扔掉
- 阴虚火旺(口干、咽痛、便秘、怕热)的人不宜多吃
- 胃溃疡、胃炎的人空腹大量吃会刺激胃
- 呕吐不止、呕血、剧烈腹痛,或孕妇剧烈呕吐、吃喝不下
  → 就医,不要只靠姜水
- 与西药: 大量食用(远超调味量)可能增加出血倾向,
  服华法林等抗凝药、阿司匹林等抗血小板药的人不要大量吃,
  见下方"与西药同用的提醒"
```

### 大蒜

**功效**: 解毒消肿,杀虫,止痢

**识别**: 见[蔬菜种植-大蒜](01-蔬菜种植.md#大蒜)

**种植**: 秋季种植,初夏收获

具体的播种、管理、收获方法见[蔬菜种植-大蒜](01-蔬菜种植.md#大蒜)。收获后编辫子挂在通风处阴干,储存时保持干燥、凉爽。

**用法**:
- 食用: 抗菌,预防感冒
- 外用: 捣烂敷患处(消肿)

```
⚠️ 更正: 不要把生蒜泥敷在皮肤或伤口上
- 生蒜泥直接接触皮肤会造成化学性烧伤(起疱、溃烂),
  包扎覆盖后更重,儿童皮肤更容易受伤
- 民间用蒜泥"消炎""拔脓""治脚气""敷牙龈",是常见的致伤原因

正确用法: 以食用为主
- 捣碎后静置约10分钟再拌入食物,比整瓣煮熟保留更多活性成分
- 常规用量: 9-15 g(按药典/中医师指导),约相当于几瓣
- 空腹大量生吃会刺激胃,胃炎、胃溃疡患者减量
- "抗菌""预防感冒"作用有限,不能代替抗生素和就医
```

详细说明见[抗生素制备-大蒜](../06-制药技术/02-抗生素制备.md#32-大蒜以食用为主)。

**禁忌和提醒**:
```
- 大蒜有抗血小板作用,大量食用会延长出血时间:
  手术、拔牙前应减量;服抗凝药、抗血小板药的人不要大量吃
- 被蒜泥灼伤: 按烫伤处理,用流动的凉水冲洗至少15分钟,
  起大疱或面积大时就医
```

### 蒲公英

**功效**: 清热解毒,消肿散结,利尿通淋

**识别**:
```
- 多年生草本
- 叶基生,倒披针形,羽状裂
- 花黄色,头状花序
- 种子有白色冠毛(蒲公英伞)
- 折断有白色乳汁

补充:
- 每根花葶是中空的,顶上只开一朵花
- 苦苣菜、苦荬菜等长相相似,也有白色乳汁、开黄花,
  但茎上分枝、一根茎上开多朵花;它们多数也是传统野菜,一般无毒
```

**易混淆**: 蒲公英本身少有致命误认,但**采野菜时混进别的植物才是风险**,尤其是幼苗期。没开花时只凭叶子很难确认,第一次采最好等它开花、结出绒球后确认植株,再采这一片。野菜采食的原则见[毒蘑菇与野菜误食-采食野菜野果的原则](../03-野外生存/09-毒蘑菇与野菜误食.md#采食野菜野果的原则)。

**种植**:
```
✓ 野生常见
✓ 极易种植
✓ 种子繁殖
✓ 耐寒耐旱
✓ 适应性极强

具体做法:
- 春季或秋季播种,种子很小,撒在耙平的湿土表面,
  只盖约0.5 cm细土,保持湿润,约15-25°C时一周左右出苗
- 行距约25-30 cm,苗长出4-5片叶后间苗到株距约10-15 cm
- 也可以挖野生植株的根移栽
- 采叶时从离地约2 cm处割,留下根,会再长新叶
- 及时摘掉花,不让它满园子飞种
```

**采收**:
```
采收:
- 全草入药
- 春夏采收
- 鲜用或晒干

具体:
- 药用以春季开花前或刚开花时为好,连根挖出
- 抖去泥土,洗净后晒干;根粗的可以纵切成两半,干得快
- 采野生的: 远离公路、工厂、矿区、垃圾场和喷过除草剂的地方
```

**用法**:
- 嫩叶可食(凉拌、炒食)
- 煎服: 热毒疮疡,咽喉肿痛
- 泡茶: 清热利尿

```
- 嫩叶有苦味,焯水后凉拌或炒食
- 常规用量: 10-15 g(按药典/中医师指导)
- 乳房红肿热痛、发热(尤其是哺乳期)、皮肤疖肿迅速扩大
  → 可能是需要抗生素或切开引流的感染,应就医
```

**禁忌和提醒**:
```
- 对菊科植物过敏的人不要用
- 性寒,脾胃虚寒、腹泻的人不宜多用;用量大时可能腹泻
- 有利尿作用: 正在服利尿药、锂盐的人,或肾功能不好的人,
  不要自行大量服用,先问医生
```

### 鱼腥草(折耳根)

**功效**: 清热解毒,排脓消痈,利尿通淋

**识别**:
```
- 多年生草本
- 茎紫红色
- 叶心形,全缘
- 揉搓有鱼腥味
- 白色花穗
- 地下茎蔓延

补充:
- 那4片白色的像"花瓣"的其实是苞片,中间直立的穗才是花序
- 鱼腥味非常明显,是最可靠的识别点
```

**易混淆**: 鱼腥草喜欢生长在沟边、田埂、水湿地,**毒芹也长在同样的潮湿地方**。成片采挖时注意不要把别的植物一起拔回来,特别是叶子羽状分裂、开白色伞形小花、像芹菜的植物——一律不要。见[有毒植物(避免误用)](#有毒植物避免误用)。

**种植**:
```
✓ 喜湿润半阴
✓ 地下茎繁殖
✓ 生长旺盛(需控制蔓延)
✓ 耐寒

具体做法:
- 春季把白色的地下茎剪成带2-3个节、约10 cm的段,
  平放在约5 cm深的沟里,行距约25-30 cm
- 土壤保持湿润,半阴处长得最好;夏季强光下叶片发黄
- 地下茎会到处钻,最好种在挡板围起来的地块或大盆里
- 第二年起可以挖地下茎吃、割地上部分入药
```

**采收**:
```
采收:
- 全草或根茎
- 夏季采收
- 鲜用或晒干

具体:
- 入药: 夏季茎叶茂盛、开花时割取地上部分,晒干
- 当菜吃: 挖嫩的地下茎(折耳根),全年都可以
- 生吃前用清水反复洗净;长在污水沟、粪坑边的不要采
```

**用法**:
- 食用: 凉拌(嫩茎叶,根茎)
- 煎服: 肺热咳嗽,尿路感染

```
- 常规用量: 15-25 g(按药典/中医师指导);入煎剂时不宜久煎
- 咳嗽伴高热、胸痛、气促、咳脓痰或血痰,
  以及尿频尿痛伴发热、腰痛、尿血 → 就医,
  肺炎、肾盂肾炎需要抗生素
```

**禁忌和提醒**:
```
- 当作蔬菜按日常食用量吃,一般是安全的;不要长期大量当药吃
- 性微寒,脾胃虚寒的人少吃
- 孕妇、肾功能不好的人入药前先问医生
- 鱼腥草注射液曾出现严重过敏反应,这和日常食用不是一回事,
  但说明它的成分并非完全无害
```

### 艾草(艾蒿)

**功效**: 温经止血,散寒止痛

**识别**:
```
- 多年生草本
- 茎直立
- 叶互生,羽状深裂,背面有白色绒毛
- 强烈香气
- 夏季开小黄花

补充:
- 叶正面深绿、背面灰白,摸上去像毡,这是和多数蒿类区别的要点
- 野艾蒿、蒙古蒿等近缘种长相相似,香气也相近,常被一起当艾用
```

**易混淆**: 蒿属植物很多,大多无剧毒,但其中的豚草(叶也是羽状分裂、背面没有白色绒毛、香气弱)花粉是强过敏原。要入口的艾(做青团、煎水)只用自己确认过、背面有白绒毛、香气浓的植株。

**种植**:
```
✓ 适应性强
✓ 种子或分株
✓ 耐旱
✓ 喜阳光

具体做法:
- 最简单的是分株: 春季挖带根的地下茎,剪成10-15 cm的段,
  埋入约5-8 cm深,株行距约30-40 cm
- 种子很小,撒播后薄薄覆一层土,出苗慢、整齐度差
- 地下茎蔓延很快,种一次多年不用再种;要用挡板控制范围
- 怕积水,雨季注意排水
- 一年可以割2-3次
```

**采收**:
```
采收:
- 端午前后采收最佳
- 全草入药
- 晒干悬挂保存

具体:
- 端午前后枝叶茂盛、还没开花时,晴天割取
- 入药主要用叶: 捆成把,倒挂在通风阴凉处阴干,
  或短时间晒干;香气重的要避免暴晒
- 做艾绒用存放1-3年的陈艾: 干叶反复捶打、过筛去掉碎末和叶脉,
  留下的绒状物就是艾绒
```

**用法**:
- 艾灸: 温经通络
- 煮水泡脚: 散寒,助眠
- 驱蚊: 燃烧艾叶

```
- 煮水泡脚: 一把干艾叶(约20-30 g)加水煮约10分钟,
  兑凉水到约40°C以下再泡,先用手肘试温
- 内服: 常规用量3-9 g(按药典/中医师指导),
  内服必须在中医师指导下,不要自行大量煎服——艾叶含有的挥发油
  大量服用可损伤肝脏、引起抽搐
- 驱蚊: 熏艾时开窗通风,人和火保持距离,不要整夜在密闭房间里烧
```

**禁忌和提醒**:
```
⚠️ 艾灸、熏烧容易烫伤、起火: 艾条离皮肤保持一定距离,
   皮肤感觉迟钝的人(糖尿病、老人、瘫痪、醉酒、熟睡的人)、
   婴幼儿不要做艾灸;用后彻底熄灭,放进装水或沙的容器里
- 孕妇不要自行艾灸,尤其是腹部和腰骶部;内服必须问医生
- 哮喘、慢阻肺患者避免吸入艾烟
- 糖尿病患者泡脚: 水温不要超过约40°C,时间不要超过约15分钟,
  泡后检查脚有没有烫红、破皮
- 与西药: 服抗凝药的人内服艾叶前先问医生
```

烫伤的处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤)。

### 枸杞

**功效**: 滋补肝肾,益精明目

**识别**:
```
- 落叶灌木
- 枝条细长,有刺
- 叶披针形或卵状披针形
- 花紫色
- 果实红色浆果(枸杞子)

补充:
- 果实长椭圆形,长约1-2 cm,成串挂在枝上(每个叶腋1-几个)
- 枝条常弯曲下垂,叶腋处常有短刺
```

**易混淆**: 红色、黑色的小浆果很多,儿童最容易误食。龙葵(未熟的青果有毒,成熟后黑紫色)、马桑(果实先红后紫黑,剧毒)、南天竹等的果实都是一串一串的小浆果。**只采自己种的、或100%确认是枸杞树(有刺的灌木、长椭圆形红果)上的果实**,教孩子不要吃路边的果子。

**种植**:
```
✓ 耐旱耐瘠
✓ 种子、扦插或分株
✓ 喜阳光
✓ 适应性强

具体做法:
- 扦插最快: 春季萌芽前,剪1年生、粗约0.5-1 cm的枝条15-20 cm,
  斜插入土,露出1-2个芽,保持湿润,当年能长成苗
- 定植: 株距约1-1.5 m,行距约2 m;耐盐碱,但怕积水
- 修剪: 留一根主干约50-60 cm高,上面留3-5根主枝,
  形成伞状;每年冬季剪掉枯枝、病枝、过密枝和贴地枝
- 第二年开始结果,3-4年进入盛果期
- 施肥: 冬季在树冠外围挖沟埋入腐熟的厩肥,每株约5-10 kg

常见问题:
- 蚜虫、木虱: 新梢上成团,冲洗、剪除虫枝
- 瘿螨: 叶片上出现紫黑色小疙瘩,剪掉病叶烧毁
- 黑果病(果实变黑腐烂,雨季多): 及时摘除病果,改善通风
```

**采收**:
```
采收:
- 夏秋采收成熟果实
- 晒干或烘干

具体:
- 果实变成鲜红、发软、有光泽时采(约八九成熟)
- 早晨露水干后采,连果柄轻轻摘下,不要捏破
- 先在阴凉处摊开晾1-2天让表皮起皱,再移到太阳下晒;
  直接暴晒、晒时用手翻动,果实容易变黑
- 晒的时候摊薄,不要翻动;阴雨天低温烘干,约40-50°C起,
  逐渐升到约55-60°C
- 干好的标准: 果皮皱缩,一抓一把不粘手,不粘连成团
```

**用法**:
- 泡茶,煮粥,炖汤
- 滋补肝肾,明目

```
- 常规用量: 6-12 g(按药典/中医师指导),约一小把
- 当成食物适量吃,一般是安全的;不要因为"滋补"就大量吃
```

**禁忌和提醒**:
```
- 感冒发热、腹泻、腹胀的时候暂停
- 与西药: ⚠️ 枸杞(包括枸杞茶、枸杞汁)与华法林同用,
  有出现出血、凝血指标升高的报告;服华法林的人不要突然增加或
  长期大量吃枸杞,改变饮食前先告诉医生
- 糖尿病患者: 枸杞含糖,干品吃多了会升高血糖
- 储存时极易生虫、受潮发霉,见下方"采收与加工-储存"
```

### 甘草

**功效**: 补脾益气,清热解毒,调和诸药

**识别**:
```
- 多年生草本
- 根和根茎粗壮,淡黄色
- 羽状复叶
- 紫色蝶形花
- 豆科植物

补充:
- 根外皮红棕色或灰褐色,断面黄白色,嚼起来明显发甜
- 主要分布在西北、华北、东北的干旱草原和沙地
```

**种植**:
```
- 种子或根茎繁殖
- 耐旱耐盐碱
- 生长缓慢
- 3-4年后采收根部

注意:
- 种植有地区限制(保护植物)
- 购买合法种源

更正和补充:
- 受保护的是野生甘草: 甘草属的几种野生植物被列入
  国家重点保护野生植物名录,禁止私自采挖;
  人工种植是提倡的,但种子、种苗要从合法渠道获得

具体做法:
- 种子种皮坚硬、不透水,不处理很难发芽:
  播前用粗沙和种子一起搓磨,磨破种皮,再用温水浸泡一夜
- 要求土层深厚、疏松、排水好的沙壤土;黏重、积水的地方根会烂
- 春季或初夏播种,行距约30-40 cm,覆土约2-3 cm
- 头一两年苗弱,要勤除草
- 甘草是豆科植物,根上有根瘤,能固氮改土
```

土壤质地的判断见[地质矿物与土壤-简单的土壤质地判断](../08-基础科学知识/06-地质矿物与土壤.md#52-简单的土壤质地判断)。

**采收**: 种植3-4年后,秋季地上部分枯黄后或春季发芽前挖根。根扎得很深,要顺着根挖深沟,尽量挖全;去掉须根和芦头,晒到半干时捆成把,再晒干。

**用法**:
- 煎服: 补气,止咳,解毒
- 炙甘草: 炒制后功效增强

```
- 常规用量: 2-10 g(按药典/中医师指导)
- 甘草在复方中多是"配角",用量本来就小;
  不要单独、长期、大量煎服或嚼食
```

炙制方法见[中药制剂-炙制](../06-制药技术/04-中药制剂.md#炙制);甘草与甘遂、大戟、芫花、海藻的配伍禁忌见[中药制剂-十八反十九畏](../06-制药技术/04-中药制剂.md#61-十八反十九畏配伍禁忌)。

**禁忌和提醒**:
```
⚠️ 长期或大量服用甘草(包括甘草片、甘草含量高的零食、凉茶),
   会使身体留钠、排钾: 血压升高、浮肿、乏力、
   严重时低血钾引起肌肉无力、心律失常

不宜用或必须先问医生:
- 高血压、心力衰竭、肾病、低血钾的人
- 孕妇(大量食用与早产风险有关)

与西药同用要小心:
- 利尿药(如氢氯噻嗪、呋塞米)、糖皮质激素: 低血钾更严重
- 地高辛: 低血钾会增加地高辛中毒的风险
- 降压药: 甘草可能抵消降压效果
```

## 药用植物种植要点

### 选择原则

```
新手推荐(易种植):
1. 薄荷(极易)
2. 金银花(适应性强)
3. 菊花(普通)
4. 生姜、大蒜(蔬菜兼药用)
5. 蒲公英(野生,易采)

需经验:
- 甘草(生长慢)
- 黄芪、当归等(专业)

选择时还要考虑:
✓ 自己种比野外采安全: 种的植物来源清楚,不会和有毒植物混在一起
✓ 优先选"药食两用"、性质温和的: 薄荷、菊花、生姜、大蒜、
  蒲公英、鱼腥草、枸杞、马齿苋,它们本来就能当菜、当茶
✓ 不种、不留有毒的药用植物: 乌头、附子、半夏、天南星、
  商陆、曼陀罗等,家里有孩子时尤其不要
✓ 适合当地气候: 生姜怕冷,北方要晚种早收;
  甘草、枸杞耐旱,适合北方和西北
```

### 家庭药园配置

**小面积(10-20 m²)**:
```
- 薄荷: 1 m²
- 金银花: 攀援架
- 菊花: 2-3株
- 蒲公英: 散种
- 艾草: 2-3株
- 枸杞: 1-2株

+ 生姜、大蒜(蔬菜地)
```

```
布局建议:
- 选向阳、排水好、离厕所和畜圈远的地块
  (厕所、畜圈离水源至少30 m,药园也不要在它们下坡方向)
- 薄荷、鱼腥草、艾草地下茎乱窜,单独种在挡板围起来的角落或大盆里
- 金银花、枸杞是多年生灌木/藤本,放在北侧或边上,不挡矮的植物
- 菊花、蒲公英种在中间阳光充足处
- 每种植物插标签: 名称、种植日期——几年后容易记混
- 施肥用腐熟的堆肥、厩肥,每平方米约2-3 kg,翻入土中;
  不要用没有腐熟的粪便
```

粪肥的安全用法见[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用);土壤酸碱性见[地质矿物与土壤-酸碱性](../08-基础科学知识/06-地质矿物与土壤.md#53-酸碱性)。

### 采收与加工

**采收时间**:
```
- 全草类: 开花前或初花期
- 花类: 花蕾期或初开期
- 果实类: 成熟时
- 根茎类: 秋冬季(养分储存)

原则:
✓ 晴天采收
✓ 早晨露水干后
✓ 清洁无污染

补充:
✓ 叶类: 植物生长最旺、开花前,如薄荷、艾叶
✓ 种子类: 果实完全成熟、刚开始变干时,如车前子
✓ 雨后不要马上采,含水多,难干、易霉
✓ 每次只采一种,分开装、分开晾,贴上标签——
  几种混在一起晒,干了以后很难分清
✓ 野外采集: 远离公路、工厂、矿区、垃圾场、喷过农药除草剂的田边
```

**加工方法**:
```
晒干:
- 薄层摊开
- 通风阴凉处或阳光下
- 经常翻动
- 至干燥

烘干:
- 低温(<60°C)
- 保持药效

鲜用:
- 某些药材鲜用效果更好
- 如蒲公英、鱼腥草

补充:
- 先挑拣: 去掉泥土、杂草、枯叶、虫蛀和霉烂的部分
- 根类洗净后趁鲜切片(约2-4 mm厚),比整根干得快
- 芳香类(薄荷、艾叶、菊花): 阴干,或烘干时不超过约35-40°C,
  避免挥发油散失
- 花类(金银花): 晒时少翻动,翻动多了会变黑
- 浆果类(枸杞): 先阴凉处晾,再晒或低温烘,不要捏破
- 晒干时晚上收回屋内,防止夜露回潮
- 怎样算干透: 叶一搓就碎、茎一折就断、根的断面没有湿心、
  花一捏就碎;没干透就装起来,几天内就会发霉
```

阴雨天的低温干燥方法见[食物加工与保存-晒干与风干](../07-日常生活技能/01-食物加工与保存.md#晒干与风干);炒、炙、蒸等炮制方法见[中药制剂-中药炮制方法](../06-制药技术/04-中药制剂.md#二中药炮制方法)。

**储存**:
```
✓ 充分干燥
✓ 密封容器
✓ 阴凉干燥处
✓ 避光
✓ 防潮防虫
✓ 标签注明品种和日期

保质期:
- 一般1-2年
- 每年更新

具体做法:
- 容器: 带盖的陶罐、玻璃瓶、铁皮罐;没有的话用厚塑料袋扎紧口,
  外面再套一层
- 防潮: 传统的"石灰缸"——缸底放用布包好的生石灰吸潮,
  中间隔一层板放药材;生石灰遇水剧烈放热,包好放稳,
  不要让孩子接触,溅入眼睛先刷去再冲水
- 雨季前后、每1-2个月打开检查一次:
  回潮的拿出来复晒;发现小虫、虫粉,晒或挑出虫蛀部分
- 花叶类和芳香类(薄荷、菊花、金银花)放1年左右香气就明显变淡;
  根类可放更久
- 艾绒、陈艾例外,存放1-3年反而更好用
```

```
⚠️ 发霉的药材一律扔掉:
- 不要洗一洗、晒一晒、炒一炒再用——霉菌毒素(如黄曲霉毒素)
  耐高温,可严重损伤肝脏
- 判断: 表面有白色、绿色、黑色的毛状物或斑点,闻起来有霉味,
  掰开后里面结块、变色
```

黄曲霉毒素见[食物加工与保存-黄曲霉毒素](../07-日常生活技能/01-食物加工与保存.md#黄曲霉毒素)。

## 常见中草药识别(野生)

这一节的植物路边常见、比较温和,但仍然只在100%确认时采用;采集时远离污染地点。

### 车前草

```
识别:
- 叶基生,卵形,有明显平行脉
- 花穗直立,穗状花序
- 路边、田野常见

补充识别:
- 叶柄长,叶片从中心向四周平铺成莲座状
- 叶片上有5-7条从基部弧形伸到叶尖的粗脉,扯断叶柄能拉出白色细丝
- 种子很小,黑褐色,遇水发黏

功效:
- 利尿通淋,清热明目

采收:
- 全草,夏秋采收
- 种子(车前子): 夏秋果穗变黄褐色时剪下穗子,晒干搓出种子

用法:
- 车前草常规用量: 9-30 g;车前子: 9-15 g,入煎剂时要用布包起来煎
  (按药典/中医师指导)

禁忌和提醒:
- 有利尿作用,孕妇、肾功能不好的人、服利尿药的人先问医生
- 尿频尿痛伴发热、腰痛、尿血 → 就医
```

### 马齿苋

```
识别:
- 肉质草本
- 茎平卧,紫红色
- 叶倒卵形,肥厚
- 黄色小花

补充识别:
- 叶片像小勺子,掐断有透明黏液,没有白色乳汁
- 夏秋季在菜地、田边、墙脚大量生长

功效:
- 清热解毒,凉血止血

用法:
- 可食用(凉拌,炒食)
- 煎服

具体:
- 当野菜: 嫩茎叶洗净焯水后凉拌、炒、做馅,
  也可以焯水后晒干储存过冬
- 常规用量: 9-15 g(按药典/中医师指导)
```

```
⚠️ 易混淆: 地锦草、斑地锦、泽漆等大戟科植物也趴在地上、
   茎常带红色,但它们折断有白色乳汁,叶片薄、不肉质。
   有白色乳汁的不是马齿苋,不要采——大戟科植物的乳汁会刺激皮肤、
   误食引起剧烈呕吐腹泻

禁忌和提醒:
- 性寒,腹泻、脾胃虚寒的人少吃
- 孕妇不宜大量食用或入药
- 含草酸较多,有肾结石的人不要大量吃
- 腹泻伴高热、脓血便、严重脱水 → 就医,不要只靠马齿苋
```

腹泻的处理和补液见[传染病家庭防控-腹泻类传染病](../01-日常疾病和伤害/15-传染病家庭防控.md#腹泻类传染病)。

### 夏枯草

```
识别:
- 直立草本
- 叶对生,卵形或披针形
- 穗状花序,紫色
- 夏季花穗变褐色(夏枯)

补充识别:
- 茎四棱,常带紫红色,高约20-30 cm
- 花穗短而粗,像一个小棒槌,花一层层轮生

功效:
- 清肝火,散郁结

采收:
- 花穗,夏季采收
- 花穗大部分变成棕褐色时剪下,晒干

用法:
- 常规用量: 9-15 g(按药典/中医师指导)

禁忌和提醒:
- 性寒,脾胃虚弱的人慎用
- 脖子上、乳房里摸到肿块,不要自己用"散结"的草药,
  要去医院查清楚
- 有降血压作用的报道,服降压药的人先问医生
```

### 益母草

```
识别:
- 直立草本,茎方形
- 叶掌状深裂
- 粉红或淡紫色花,轮生
- 田野、路边

补充识别:
- 高约0.5-1 m;下部叶掌状3裂,上部叶越来越细,近条形
- 花一圈圈长在上部叶腋,花萼有刺尖,干后扎手

功效:
- 活血调经,利尿消肿

⚠️ 孕妇禁用(活血,可致流产)

采收:
- 全草,夏季采收
- 初夏茎叶茂盛、花还没开或刚开时割取,晒干

用法:
- 常规用量: 9-30 g(按药典/中医师指导)

禁忌和提醒:
- 孕妇禁用;月经量多、有出血倾向的人不要用
- 大量或长期服用有损伤肾脏的报道,肾功能不好的人不要用
- 服华法林、阿司匹林等抗凝、抗血小板药的人不要用,增加出血风险
- 产后出血多、发热、腹痛,或月经异常出血 → 就医
```

月经问题见[月经卫生与避孕](../01-日常疾病和伤害/17-月经卫生与避孕.md)。

## ⚠️ 安全警示

### 有毒植物(避免误用)

```
常见有毒植物:
❌ 曼陀罗: 全株有毒,剧毒
❌ 商陆: 根似人参,有毒
❌ 天南星: 块茎有毒,需炮制
❌ 半夏: 有毒,需炮制
❌ 附子: 剧毒,需严格炮制
❌ 马钱子: 剧毒
❌ 苍耳子: 有毒

原则:
✓ 不认识不采不用!
✓ 确认无误才使用
✓ 初学者避免有毒品种
```

下表是采草药、挖野菜时最常见的误认。中毒表现和发作时间见[毒蘑菇与野菜误食-容易认错的有毒植物](../03-野外生存/09-毒蘑菇与野菜误食.md#容易认错的有毒植物),这里只写怎样区分。

| 有毒植物 | 常被误当成 | 区分要点 |
|----------|-----------|----------|
| 钩吻(断肠草) | 金银花 | 见上方[金银花](#金银花忍冬)的对比表: 钩吻花是整齐的5裂小喇叭、多朵聚生、只有黄色,叶光滑无毛 |
| 毒芹 | 水芹、野芹菜 | 毒芹高大(可达1 m以上),根状茎粗、纵切开有一格一格的横隔空腔,伤口流出淡黄色汁液;**野生的伞形科(开白色伞状小花、叶像芹菜的)植物一律不采** |
| 商陆 | 人参、"土人参"、野萝卜 | 商陆是高约1-1.5 m的草本,茎常紫红色,一串串紫黑色浆果;根粗大肉质,横切面有一圈圈同心环纹。人参是矮小的五加科植物,掌状复叶。注意: 市场上叫"土人参"的东西可能是别的植物,也可能是商陆根 |
| 曼陀罗(洋金花) | 野菜、其他草药;种子混入豆类粮食 | 大型白色或淡紫色喇叭花(长约10-20 cm),果实是带刺的圆球,叶有难闻气味 |
| 乌头、草乌、附子 | 自采自制的药酒、炖汤材料 | 叶掌状深裂,花蓝紫色、形状像头盔;块根像小芋头。**乌头类煮久了也不能保证去毒,不要自制乌头药酒、附子炖肉** |
| 天南星、半夏、野芋(滴水观音) | 芋头、魔芋 | 生的块茎咬一口就口舌、喉咙剧烈麻木灼痛,可致喉头水肿。只吃自己种的、确认的芋头 |
| 菊三七(俗称"土三七") | 三七 | 三七是五加科、掌状复叶、红色小果;菊三七是菊科,叶羽状裂、开黄色或橙黄色头状花。**菊三七含吡咯里西啶生物碱,长期或大量服用可引起严重肝损伤(肝窦阻塞综合征),家里种来泡酒、炖汤的"土三七"多半是它** |
| 苍耳(幼苗和种子) | 野菜、豆芽 | 果实椭圆形、表面布满钩刺,常粘在衣服上;幼苗和种子毒性最大,可致急性肝衰竭 |
| 马兜铃科植物(关木通、广防己、青木香、马兜铃等) | 自采的"木通""防己"等草药 | 含马兜铃酸,可致肾衰竭和泌尿系统癌症,且损伤不可逆。**不要自己采用名称里有"木通""防己""马兜铃""青木香"的植物** |
| 雷公藤 | 自制治风湿的药酒 | 毒性极大,治疗剂量和中毒剂量非常接近,只能在医生监测下用 |
| 马桑、龙葵未熟果 | 野果、枸杞 | 见上方[枸杞](#枸杞)的易混淆说明 |

```
另外几条:
- 何首乌: 常被当成补药自种自服,有引起肝损伤的报告;
  长期服用要定期查肝功能,有肝病的人不用
- 马钱子、附子、半夏、天南星这类"需要炮制"的药材,
  家庭条件下无法可靠控制炮制质量和剂量,不要自己炮制使用
- 拍照识别软件、"老人说能吃"都不能作为确认依据
- 买药材去正规药店;一包药材里混进别的植物也会出事,
  打开后发现形状、气味不对,不要用
```

### 用药安全

```
✓ 咨询专业中医师
✓ 了解禁忌症
✓ 不过量使用
✓ 某些药材需炮制后使用
✓ 孕妇、儿童、老人慎用
✓ 观察不良反应
✓ 出现不适立即停用就医
```

**哪些人用任何草药前都要先问医生**:
```
- 孕妇、备孕和哺乳期妇女: 活血类(益母草、红花、桃仁等)、
  泻下类、有毒类禁用
- 婴幼儿和儿童: 用量要按体重减少,很多草药没有儿童安全数据;
  3岁以下不要自行使用;不要给婴儿喂草药水代替喂奶、补液
- 老人: 常同时吃多种药,肝肾功能减退,更容易出现相互作用和蓄积
- 肝病、肾病患者: 大多数草药要经肝脏代谢、肾脏排出;
  部分草药本身就可能损伤肝肾(见上表)
- 有过敏史的人: 尤其是对菊科植物过敏者
- 准备手术或拔牙的人: 提前停用活血类草药和大量的大蒜、生姜,
  并告诉医生自己吃过什么
```

孕期禁忌见[中药制剂-孕妇禁忌](../06-制药技术/04-中药制剂.md#62-孕妇禁忌),儿童用药见[中药制剂-儿童用药](../06-制药技术/04-中药制剂.md#63-儿童用药)。

**怎样安全地尝试一种草药茶**:
```
1. 先确认: 植物100%认得,部位对,干净无霉
2. 先少量: 第一次用常规用量的下限,只用一种,不要几种混在一起
3. 观察: 喝后几小时内出现皮疹、瘙痒、嘴唇肿、心慌、腹痛腹泻、
   头晕 → 停用;出现呼吸困难、喉咙发紧、嘴唇舌头肿 → 拨打120
4. 不长期连续喝: 一般连续几天到一两周,症状没有好转就停,去看病
5. 记录: 喝了什么、多少、哪天——就医时告诉医生
```

### 与西药同用的提醒

很多人以为"草药是天然的,和西药一起吃没关系",其实一些草药会让西药效果变强(出血、低血糖、低血压)或变弱。**长期服药的人(尤其是下表中的药),用任何草药、"养生茶"、药酒之前先问医生或药师**,并把草药写进自己的用药信息卡。

| 正在服用的西药 | 要小心的草药(本章涉及的) | 可能的后果 |
|---------------|---------------------|-----------|
| 华法林等抗凝药;阿司匹林、氯吡格雷等抗血小板药 | 枸杞、益母草、大量大蒜、大量生姜;本章以外还有当归、丹参、银杏、红花等 | 出血、凝血指标波动 |
| 利尿药(氢氯噻嗪、呋塞米等)、糖皮质激素 | 甘草 | 严重低血钾 |
| 地高辛 | 甘草 | 低血钾诱发地高辛中毒、心律失常 |
| 降压药 | 甘草(使血压升高);夏枯草等(可能叠加降压) | 血压控制不好,或血压过低、头晕 |
| 锂盐、利尿药 | 蒲公英、车前草等利尿草药 | 脱水、电解质紊乱、锂中毒 |
| 降糖药、胰岛素 | 各种宣称"降糖"的草药茶 | 低血糖(出汗、心慌、手抖、意识不清) |
| 抗癫痫药、免疫抑制剂(器官移植后)、抗心律失常药、抗肿瘤药 | 任何草药 | 这些药的有效剂量和中毒剂量很接近,草药可能改变它们的血药浓度 |

```
✓ 不要因为喝了草药就自行减少或停用西药——
  降压药、降糖药、抗凝药、抗癫痫药、激素突然停用都很危险
✓ 常见的建议是草药和西药间隔1-2小时服用,
  但这只能减少一部分在胃肠道里的相互影响,不能消除上表的风险
✓ 就医时主动说出所有在吃的草药、保健品、药酒
```

用药信息卡和不能突然停的药见[慢性病用药储备-用药信息卡](../01-日常疾病和伤害/08-慢性病用药储备.md#用药信息卡)、[突然停药最危险的几类药](../01-日常疾病和伤害/08-慢性病用药储备.md#突然停药最危险的几类药)。

### 误食有毒植物怎么办

```
1. 立即拨打120,或尽快去医院——不要等症状出现或加重
   (钩吻、乌头、毒芹可在几十分钟内导致呼吸、心跳骤停)
2. 一起吃过、喝过的人都要去医院,即使没有症状
3. 带上剩下的植物、药渣、药酒,或拍下照片,告诉医生
   什么时间吃的、吃了多少、什么时候开始不舒服
4. 病人昏迷、抽搐时侧卧,防止呕吐物堵住气道;
   没有呼吸、没有反应 → 开始心肺复苏

❌ 不要自己用偏方"解毒"(灌绿豆汤、甘草水、醋等)
❌ 不要自行催吐,尤其是病人意识不清或正在抽搐时;
   是否需要催吐按120或医生的指导
```

见[中毒-中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则)、[基础急救知识](../01-日常疾病和伤害/00-基础急救知识.md)。

### 采集伦理

```
✓ 不过度采集野生药材
✓ 保护植物资源
✓ 某些是保护植物(禁采)
✓ 了解当地法规
✓ 提倡人工种植

具体:
- 一片地里只采一部分(不超过约三分之一),留下母株和开花结籽的植株
- 挖根时选成熟大株,小的留着;挖后把土回填
- 野生甘草、野生人参、石斛、天麻等多种是国家重点保护植物,
  不要采挖和买卖野生来源的
- 自然保护区内禁止采集
- 能种的就自己种,采集一次野生种子或根苗,带回来繁殖
```
