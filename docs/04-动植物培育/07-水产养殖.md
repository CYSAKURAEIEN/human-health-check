# 水产养殖指南

## 水产养殖的价值

```
优点:
✓ 蛋白质丰富(鲜鱼肉约含蛋白质17-20%,可食部分约占鱼重的一半多)
✓ 充分利用水资源: 一口塘同时蓄水、养鱼、灌溉、消防
✓ 某些品种生长快(四大家鱼当年鱼种养到次年秋可达0.5-1.5 kg)
✓ 能"吃"掉别处的废料: 青草、菜叶、米糠、腐熟粪肥都能变成鱼肉
✓ 经济效益好

需求:
- 水源(池塘、水库、稻田、水箱)
- 一定技术
- 水质管理(养鱼失败,绝大多数是水出了问题,而不是鱼出了问题)
```

灾后自给的角度: 鱼塘不需要买饲料也能产鱼(靠青草、粪肥培养的浮游生物),但产量会比精养低得多;养鱼的同时塘泥是好肥料,塘水可浇菜。前提是水源可靠——饮用水优先,见[水源工程与供水](../07-日常生活技能/10-水源工程与供水.md)。

---

## 鱼类养殖

### 常见养殖鱼类

**四大家鱼**:
- 草鱼: 吃草,生长快;吃得多拉得多,粪便能肥水养鲢鳙
- 鲢鱼(白鲢): 滤食浮游植物(使水变绿的藻类),生活在上层
- 鳙鱼(花鲢): 滤食浮游动物,上层;鲢鳙不用喂饲料,是"吃水"的鱼
- 青鱼: 吃螺蛳、蚌等,底层;长得慢、需要大量螺蚬,家庭塘少养

**其他**:
- 鲫鱼: 适应性强,耐低氧,能自然繁殖
- 鲤鱼: 杂食,易养;会拱泥使水变浑,放少量即可
- 罗非鱼: 热带鱼,生长快;水温低于约15°C停止生长,低于约10°C会冻死,北方不能在室外越冬
- 黄颡鱼: 经济价值高,肉食性偏强,会吃小鱼苗

**选品种的原则**: 优先选本地常见、苗种容易买到或能自繁的品种;不要把外来物种(如罗非鱼、小龙虾、清道夫)放进河流湖泊。

### 池塘养鱼

#### 池塘条件

```
面积:
- 小型: 约700-2000 m²
- 中型: 约2000-6700 m²
- 大型: >6700 m²
- 家庭自给: 700-2000 m² 的塘最合适;太小水质变化快、容易缺氧,
  太大清塘、捕捞费力

水深:
- 1.5-3 m(成鱼塘常用2-2.5 m)
- 深浅结合更好
- 水太浅(<1 m): 夏天水温过高、冬天易冻透,水质不稳
- 太深(>3 m): 底层缺氧、光照不到,没有用处

水源:
✓ 充足(旱季也能补水)
✓ 清洁
✓ 无污染(上游无工厂、矿山排水,不接收农田药水)
✓ 进排水方便

底质:
- 淤泥10-20 cm(过厚需清淤)
- 或沙泥底
- 黏土、壤土保水好;沙土漏水,要在池底和池埂内侧铺约30 cm 黏土并夯实

形状:
- 长方形为好(长:宽约2-3:1,便于拉网)
- 东西向(受光好,风吹水面能增氧)
```

土壤质地的判断见[地质矿物与土壤-简单的土壤质地判断](../08-基础科学知识/06-地质矿物与土壤.md#52-简单的土壤质地判断)。

**池埂与进排水**:
```
池埂:
- 顶宽至少1.5-2 m(能走人、推车,不易垮)
- 内坡比约1:2-1:3(每升高1 m,水平伸出2-3 m);
  沙性土取缓坡。缓坡不易塌,落水的人和牲畜也容易爬上来
- 埂顶高出最高水位30-50 cm,防大雨漫塘跑鱼
- 修筑时分层(每层约20-30 cm)夯实;埂上种草护坡,不种深根大树(根会造成漏水)

进水口:
- 高于池水面,让水跌落进塘(顺便增氧)
- 装两道滤网(先粗后细,如40-60目尼龙网袋),挡住野杂鱼、鱼卵和敌害

排水口:
- 设在池底最低处,能把塘水排干(清塘、干塘捕鱼都需要)
- 简易做法: 埋一根竖管或插板闸门,拔管、抽板即可放水
- 出口外装拦鱼栅

溢水口:
- 在设计最高水位处开一个带拦鱼栅的溢水口,
  大雨时多余的水从这里流走,不会冲垮池埂
```

#### 池塘准备

**清塘消毒**:

为什么要清塘: 塘底淤泥里藏着病原菌、寄生虫卵和野杂鱼(黑鱼、鲶鱼会吃鱼种,野杂鱼抢食抢氧)。老塘不清,新放的鱼种往往大批死亡。

```
放鱼前15-20天:

1. 排干水(或只留5-10 cm)
2. 清除杂鱼、野杂鱼、敌害(黑鱼、蛇、水老鼠等)
3. 修整池埂,堵漏洞
4. 清除过多淤泥(留10-20 cm);挖出的塘泥是好肥料,可上菜地、果园
5. 有条件的冬季排干晒塘,让塘底晒到开裂,冻晒一冬病原少很多

消毒(任选一种):
- 生石灰干法清塘(留水5-10 cm): 约900-1125 kg/ha
  * 在池底挖几个小坑,把生石灰块放进坑里
  * 加水化开,趁热(还在冒泡)用长柄瓢泼洒全池,包括池坡
  * 第二天用耙子把石灰浆和淤泥翻拌一遍,效果更好
- 生石灰带水清塘(水深1 m): 约1875-2250 kg/ha
  (用量按水深折算: 水深0.5 m 约一半)
  * 在船上或岸边用桶化开后全池泼洒
- 漂白粉带水清塘(含有效氯约30%): 约20 g/m³ 水,
  即水深1 m 约200 kg/ha
  * 用木桶、陶缸加水溶解后全池泼洒,不要用金属容器
  * 药效快、毒性消失快,但对淤泥里的病原作用不如生石灰,也不能改良底质
- 没有石灰和漂白粉时: 茶籽饼(茶粕)捣碎浸泡一夜,连渣泼洒,
  水深1 m 约600-750 kg/ha;能毒死野杂鱼和螺,但杀菌效果差

等毒性消失再放鱼:
- 生石灰: 约7-10天;漂白粉: 约4-5天;茶粕: 约7天
- 放鱼前"试水": 用网箱或桶装几尾鱼放在塘里一天(24小时),
  鱼正常游动就可以放养
- 注水时进水口一定要装滤网,否则前面白清了
```

生石灰为什么好用: 遇水生成氢氧化钙,短时间内让水的 pH 升到11以上,杀死病原和野杂鱼;之后吸收二氧化碳变成碳酸钙,还能中和塘泥酸性、补充钙、让淤泥释放养分。

```
⚠️ 生石灰安全
- 遇水剧烈放热,能把水烧开、溅出灰浆,化石灰时人站远、偏开脸
- 戴护目镜、手套,穿长袖长裤;身边备一桶清水
- 溅到皮肤: 先刷去干粉,再用大量清水冲洗
- 溅入眼睛: 立即翻开眼皮用大量清水持续冲洗,尽快就医
- 儿童远离石灰堆和化灰坑
```

石灰的烧制、熟化和安全见[石灰与建筑材料](../07-日常生活技能/16-石灰与建筑材料.md#先说清楚-本章的定位)及[消石灰粉](../07-日常生活技能/16-石灰与建筑材料.md#消石灰粉撒地消毒改土用);化学烧伤见[外伤处理-化学烧伤](../01-日常疾病和伤害/02-外伤处理.md#化学烧伤)。

**施基肥**:
```
放鱼前7-10天(清塘毒性消失、注水50-80 cm 后):
- 有机肥(发酵鸡粪、猪粪、牛粪)3000-4500 kg/ha
  堆在池边浅水处或撒开,让养分慢慢溶出
- 也可用沼液、绿肥(嫩草、豆科植物割下沤在塘角)
- 目的: 培养浮游生物,鱼种下塘就有天然饵料(鱼苗开食)
- 水色呈黄绿色或茶褐色为好,透明度约25-30 cm 时放鱼
```

```
⚠️ 粪肥必须腐熟后才能下塘
- 生粪下塘会大量耗氧,还会带入病原
- 人粪尤其危险: 肝吸虫卵随人粪进入水中 → 被螺吃进 → 幼虫钻进鱼肉
  → 人吃生鱼、半生鱼而感染。不要在塘边建厕所、不要把新鲜人粪倒进塘里
```

粪便的储存期限见[卫生设施-粪便](../07-日常生活技能/03-卫生设施.md#粪便必须长时间储存),沼液见[照明与能源-沼渣沼液的利用](../07-日常生活技能/06-照明与能源.md#沼渣沼液的利用)。

#### 鱼种放养

**时间**: 春季(3-5月),水温10°C以上;南方也可在冬季(12月-次年2月)水温低、鱼不易受伤时放养,开春就能吃食。

**鱼种规格**: 当年孵出、长到约3 cm 的叫"夏花";养到秋冬、约10-15 cm 的叫"冬片"(大规格鱼种)。养食用鱼尽量放冬片,成活率高、当年就能长成。

**密度**(混养,每 ha 尾数,精养即每天投饲料的情况):

| 鱼种 | 主养草鱼 | 主养鲢鳙 | 规格参考 |
|------|----------|----------|----------|
| 草鱼 | 12000-15000 | 3000-4500 | 100-200 g/尾 |
| 鲢鱼 | 3000-4500 | 7500-12000 | 冬片 |
| 鳙鱼 | 750-1500 | 3000-4500 | 冬片 |
| 鲫鱼、鲤鱼 | 750-1500 | 1500-3000(合计"其他") | 冬片 |

```
注: 规格、密度根据条件调整
- 不买饲料、只喂青草和施粪肥的"粗养": 按上表的1/3-1/2放养,
  宁稀勿密。密度超过水的承载力,鱼长不大,还容易缺氧、发病
- 塘水交换条件差、没有增氧机的,也取低值
- 鲢:鳙 一般约3-5:1(鳙鱼吃浮游动物,数量少,放多了长不大)
- 传统经验"一草带三鲢": 草鱼吃草、排粪肥水,养出的浮游生物
  正好喂鲢鳙,不另花饲料
- 鲤鱼不宜多(拱泥搅浑水);黑鱼、鲶鱼等肉食鱼不要放进混养塘
```

**混养原理**:
- 充分利用水体各层次
- 鲢鳙: 上层(浮游生物)
- 草鱼: 中下层(草食)
- 青鱼、鲤鱼、鲫鱼: 底层(底栖生物、残饵)
- 互利互补: 草鱼的粪肥了水,鲢鳙吃掉藻类使水不至过肥,鲫鲤清理残饵

**投放方法**:
```
✓ 选健康鱼种: 体表光滑无伤、鳞片完整,游动活泼,逆水能力强;
  拿在手里有力挣扎;离水后鳃盖张合有力
✗ 体色发黑、离群独游、浮在水面、身上有白点或出血点的不要
✓ 规格整齐(同种鱼大小差不多,否则小的抢不到食)
✓ 同池鱼种一次放足
✓ 晴天上午投放(不在闷热、阴雨或大风天放)
✓ 鱼种消毒(3-5%食盐水浸泡5-10分钟,
  即每10 L 水加盐300-500 g;鱼出现侧翻就马上捞出)
✓ 水温适应(温差<5°C): 运鱼的袋子或桶先放在塘里漂15-30分钟,
  再慢慢往里掺塘水,最后让鱼自己游出去
✓ 放鱼的地点选在上风处、离岸稍远的深水处
```

#### 饲养管理

**投饲**:
```
草鱼:
- 青草、水草为主: 嫩旱草、黑麦草、苏丹草、苦草、菜叶、浮萍
- 或颗粒饲料
- 日投饲量(颗粒料): 鱼体重的3-5%(夏季),1-2%(春秋)
- 青草含水多,投喂量按鲜重约为塘里草鱼总重的20-40%(夏季高峰),
  以下次投喂前基本吃完为准;数量级上约30 kg 青草长1 kg 草鱼
- 设置食台: 用竹竿在水面围一个方框(如2 m × 2 m)投草,草不会漂散
- 草要新鲜、嫩;不喂打过农药的草、发热变黄的草

鲤鱼、鲫鱼:
- 颗粒饲料
- 或玉米、麸皮、豆饼等(玉米要粉碎、泡软或煮过)

鲢鳙:
- 主要靠浮游生物
- 施肥(有机肥)培养浮游生物
- 可补充豆浆、麸皮浆(泼洒在水面)

青鱼:
- 螺蛳、蚬、河蚌(压碎);鱼小时喂饼粕
```

**自制饲料**(鲤、鲫、草鱼通用,参考配比):
```
- 米糠或麸皮 约40-50%
- 豆饼、花生饼、菜籽饼 约25-35%(提供蛋白质)
- 玉米粉、碎米、薯粉 约10-20%(提供能量,兼作黏合剂)
- 动物蛋白(蚯蚓、蚕蛹、蝇蛆、小杂鱼煮熟剁碎) 约5-10%,有就加
- 加少量盐(约0.5%)

做法:
1. 原料粉碎、过筛,加水拌成团(手握成团、松手一碰即散)
2. 蒸或煮熟(淀粉熟化后黏合好,在水里不易散)
3. 搓成条或压成小颗粒,晒干或阴干;粒径约为鱼口径的一半
4. 当天做当天喂的可以湿喂,不能放过夜(发霉)

注意:
✗ 发霉的饼粕、粮食不能喂(黄曲霉毒素能伤肝致死)
✗ 棉籽饼、菜籽饼含毒素,各不超过饲料的约1/4,最好先浸泡或煮过
✗ 不要用活的福寿螺直接喂(外来物种,会逃逸繁殖、啃食水稻)
```

**投喂量按体重百分比估算**:
```
步骤:
1. 估计塘里鱼的总重 = 尾数 × 成活率 × 平均体重
   (每月用网抽捞20-30尾称一称,算平均体重)
2. 日投喂量 = 鱼总重 × 投饲率

水温与投饲率(颗粒料或自制干料):
| 水温      | 投饲率 | 每天次数 |
| <10°C    | 停喂或极少 | — |
| 10-15°C  | 约0.5-1% | 1次(中午) |
| 15-20°C  | 约1-2% | 1-2次 |
| 20-30°C  | 约3-5% | 2-3次 |
| >32°C    | 减半 | 早晚凉时 |

例: 塘里约1000尾草鱼,平均0.4 kg,共约400 kg;
    7月水温28°C,按4% → 每天约16 kg 干料,分上午、下午2次

判断:
- 颗粒料投下后约20-30分钟吃完为适量;剩料多就减量,
  吃完后鱼还在食台抢食就略加
- 阴雨、闷热、鱼浮头后、发病时减量或停喂
```

**投饲原则**:
```
✓ 定时(每天同一时间,如上午8-9时、下午3-4时)
✓ 定位(固定食台,便于观察鱼吃食和清理残饵)
✓ 定质(新鲜,不腐败)
✓ 定量(根据季节、天气、鱼情)

口诀: "四定"投饲
另外"三看": 看天气、看水色、看鱼的吃食和活动
```

**水质管理**(重要!):
```
"养鱼先养水"

水色:
✓ 黄绿色或茶褐色(好): 鲢鳙爱吃的硅藻、绿藻多
✓ 清澈见底: 水瘦,需施肥
✓ 浓绿、蓝绿: 水肥,易缺氧
✗ 水面有绿漆样或油漆状浮膜、有腥臭: 蓝藻"水华",
  夜间耗氧大、藻类死亡后可能产生毒素,需换水、停肥
✗ 黑褐色、发臭: 有机物过多,底泥腐败
✗ 突然变清、变白或水色发红: 藻类大量死亡,随时可能缺氧

好水的标准(老渔民说"肥、活、嫩、爽"):
- 肥: 浮游生物多,水有颜色
- 活: 水色早晚有变化(上午淡、下午浓),说明藻类在正常繁殖
- 嫩: 颜色鲜亮,不发暗发黑
- 爽: 透明度适中,水面没有浮沫、浮膜

透明度:
- 25-30 cm 为宜(<20 cm 太肥,>40 cm 太瘦)
- 测法: 在白色瓷盘(或刷白的木板,直径约20 cm)中心系绳,
  慢慢放入水中,刚好看不见时绳子入水的长度就是透明度

溶氧(溶解在水里的氧气):
- ≥5 mg/L: 理想
- 3-5 mg/L: 可以,但鱼吃食减少、长得慢
- <2 mg/L: 缺氧,鱼开始浮头
- <1 mg/L: 严重浮头,可能"泛塘"(全塘死鱼)
- 一天中: 下午光合作用最强,溶氧最高;黎明前最低

pH:
- 适宜约7-8.5,微碱性
- 晴天下午藻类吸收二氧化碳,pH 会升高;早上低,这是正常的
- 低于约6.5(酸性): 鱼生长差、易发病。每次泼洒生石灰
  约150-300 kg/ha(按水深1 m),化浆后全池泼洒,间隔15-20天
- 高于约9: 停施石灰,加注新水
- 测法: 试纸或自制紫甘蓝汁

调节:
✓ 定期加注新水(每7-10天,每次加高约10-20 cm;高温季节可更勤)
✓ 有条件使用增氧机
✓ 施肥(有机肥,培养浮游生物)
✓ 调节pH(生石灰)
✓ 清除水面浮草(不能太多;浮萍、水葫芦盖满水面会遮光缺氧)
✓ 每年清一次淤泥(淤泥过厚是耗氧大户)

巡塘:
✓ 每天早中晚各巡视一次;黎明前最重要(看有没有浮头)
✓ 观察水色、鱼活动、摄食
✓ 检查设施(池埂漏水、滤网破损、增氧机)
✓ 捞出死鱼、残饵、腐烂水草
✓ 记巡塘日记: 天气、水温、水色、投喂量、异常情况
```

酸碱性的测法见[地质矿物与土壤-酸碱性](../08-基础科学知识/06-地质矿物与土壤.md#53-酸碱性)。

**增氧机的用法**(有电时):
```
"晴天中午开,阴天清晨开,浮头早开,连绵阴雨半夜开"

- 晴天中午开1-2小时: 上层水溶氧过饱和,搅动后送到下层,
  预先给夜里"存氧";傍晚不要开(会把上层的氧搅散,反而促使浮头)
- 阴天下午以后不开中午那一次,改在后半夜到清晨开
- 有浮头迹象时立即开,开到太阳出来、鱼不再浮头为止
- 没有增氧机: 太阳能小水泵、手摇水车、人工划船拍水都能救急
```

```
⚠️ 用电安全
- 增氧机、水泵在水边用电,必须装漏电保护器,电线架空、不泡在水里
- 检修前先断电;雷雨天不要靠近
```

见[家庭用电安全-潮湿环境用电](../07-日常生活技能/08-家庭用电安全.md#潮湿环境用电)、[照明与能源-小型太阳能](../07-日常生活技能/06-照明与能源.md#小型太阳能)。

**浮头的识别与急救**:

浮头是鱼缺氧时浮到水面"吞空气"。轻度浮头不急着处理问题不大,但严重浮头几小时内就能让全塘鱼死光,是池塘养鱼最大的风险。

```
容易浮头的天气和征兆:
- 夏秋闷热、无风、气压低(暴雨前)
- 白天热、傍晚下雷阵雨: 表层冷水下沉,把底层缺氧的水翻上来
- 连续阴雨、光照不足,藻类不产氧
- 水太肥(浓绿)、透明度<20 cm,或水色突然变化
- 傍晚食台的饲料没吃完;鱼在下午就在水面游
```

| 程度 | 表现 | 处理 |
|------|------|------|
| 轻度 | 黎明前后鲢鳙在池中央浮头,稍受惊吓就下沉;太阳出来就消失 | 当天减料,当晚注意,准备好增氧设备 |
| 中度 | 鲢鳙、草鱼都在浮头,受惊后下沉又很快浮上来 | 立即增氧或冲注新水 |
| 重度 | 草鱼、青鱼、鲤鱼也浮头,鱼群靠到池边,受惊也不下沉,鱼体发黑 | 全力抢救,同时准备转塘 |
| 泛塘 | 鱼乱窜、侧翻、沉底死亡,先死的多是大鱼 | 能救多少救多少 |

```
急救步骤:
1. 立即开增氧机;或抽注新水:
   - 从上风处、水面加注,形成一股水流,浮头的鱼会聚到新水处
   - 新水要溶氧高: 井水、河水先经过一段跌水或喷洒再入塘
   - 不要从塘底抽水再打回去,会搅起淤泥更缺氧
2. 停止投喂,直到鱼恢复正常后1天
3. 不要拉网、不要在塘里走动惊鱼
4. 化学增氧剂(过氧化钙、过碳酸钠等)可应急,严格按包装说明的用量全池撒
5. 鱼不再浮头后,当天及随后几天加注新水、少喂;
   水太肥的换去1/4-1/3,停止施肥
6. 已经死的鱼尽快捞出,新鲜的可以当天吃或腌制;
   发臭、不明原因死的按病死动物处理
```

病死动物的处理见[卫生设施-病死动物处理](../07-日常生活技能/03-卫生设施.md#病死动物处理);看天气变化见[天气观测与预报-气压](../08-基础科学知识/07-天气观测与预报.md#31-气压)。

**施肥**:
```
目的: 培养浮游生物(鲢鳙食物)

方法:
- 有机肥(腐熟): 每次1500-2250 kg/ha
- 间隔10-15天
- 少量多次
- 看水施肥(水瘦多施,水肥少施)
- 施在向阳的浅水处,或装在竹筐、编织袋里吊在水中慢慢溶出

注意:
- 高温季节少施或不施(易缺氧)
- 阴雨天不施(没阳光藻类长不起来,有机物只会耗氧)
- 施肥选晴天上午
- 有机肥必须发酵腐熟!
- 施肥和泼洒生石灰间隔约7-10天(石灰会让肥中的氮跑掉)
```

**越冬管理**:
```
- 深水越冬(水深1.5-2 m以上)
- 保持冰下水位
- 冰面扫雪(雪会挡住阳光,冰下藻类停止产氧)
- 冰下充氧(打冰眼): 每约700 m² 打1-2个,面积约1 m²,
  打开后用稻草、草帘盖住防止重新冻实;
  靠近冰眼的鱼嘴张合急促、聚集,说明缺氧,要加注新水
- 减少投饲或停喂(水温低于约10°C鱼基本不吃)
- 南方不结冰地区: 冬季晴天中午水温回升时可少量投喂
```

```
⚠️ 冰面危险
- 不要让儿童到塘面上玩;大人打冰眼时腰系绳子,有人在岸上看护
- 冰厚至少约10 cm 才能承受一个成年人;靠近冰眼、进水口处冰更薄
```

落入冰窟的自救和救援见[雪地极地求生-冰面与落入冰窟](../03-野外生存/04-雪地极地求生.md#冰面与落入冰窟)。

#### 病害防治

```
预防为主:
✓ 清塘消毒
✓ 鱼种消毒
✓ 工具消毒(网具、桶用后晒干;各塘工具分开用)
✓ 食台定期消毒(每1-2周在食台周围泼洒生石灰浆或漂白粉液)
✓ 投喂新鲜饲料
✓ 水质管理良好
✓ 合理密养
✓ 发现病鱼及时隔离
✓ 拉网、运输时动作轻,少碰伤鱼体(伤口是水霉和细菌的入口)
✓ 发病季节(5-9月)每15-20天全池泼洒一次生石灰,
  约225-300 kg/ha(水深1 m)
```

**识别病鱼**: 离群独游、浮在水面或在池边打转、吃食明显减少、体色发黑、身上有白点、白毛、出血或溃烂、鳃发白或发紫。每天巡塘时注意,早发现早处理。

**常见病**:

| 病 | 表现 | 一般处理 |
|----|------|----------|
| 烂鳃病(细菌) | 鳃丝腐烂发白、带污泥,鳃盖内侧有时透明("开天窗") | 生石灰或漂白粉全池泼洒;按水产技术员建议用药 |
| 赤皮病(细菌) | 体表局部出血发红、鳞片脱落,多在拉网碰伤后 | 同上;避免碰伤 |
| 肠炎(细菌) | 肛门红肿,轻压腹部流出黄色黏液 | 停喂1天,改喂新鲜饲料;不喂发霉饲料 |
| 草鱼出血病(病毒) | 草鱼鳃盖、鳍基、肌肉出血,发病急、死亡多 | 无特效药;注射疫苗预防,发病后改善水质、减料 |
| 水霉病(真菌) | 伤口处长出白色棉絮状毛 | 3-5%食盐水浸洗病鱼;避免受伤 |
| 小瓜虫病(白点病) | 体表、鳍上布满小白点 | 水温升到25°C以上虫会自然减少;加注新水 |
| 车轮虫病 | 鱼苗、鱼种成群在池边狂游,"跑马" | 请教技术员用药 |
| 锚头鳋、鱼虱 | 肉眼可见虫体挂在体表,周围红肿 | 药物杀虫,全池泼洒;清塘可预防 |

```
"草鱼三病"(烂鳃、赤皮、肠炎)常同时发生,是草鱼最常见的病;
加上出血病,合称"四病"。

用药的一般原则:
✓ 先确诊再用药: 病鱼送当地水产技术推广站检查
✓ 按标签用量: 按全池水体积计算(面积 × 平均水深),不要估错
✓ 遵守休药期: 用药后到捕捞上市必须间隔足够的天数
✗ 不用国家禁用的药物(如孔雀石绿、氯霉素、硝基呋喃类、
  有机氯农药等),它们会残留在鱼肉里危害吃鱼的人
✗ 不要乱用农药杀虫(很多农药对鱼的毒性比对虫还大)
✗ 浮头、闷热、阴雨天不泼药;泼药后加强观察,有浮头立即加水

⚠️ 病害严重咨询水产技术员!
```

缺氧浮头的处理见上方"浮头的识别与急救"。

#### 收获

```
时间:
- 秋冬季,水温下降(鱼不易受伤,也便于保存)
- 或达到商品规格随时

方法:
- 拉网捕捞
- 干塘捕捞(排水后)
- 可捕大留小(轮捕轮放): 夏秋分批捕出大鱼,
  给留下的鱼腾出空间,再补放鱼种

捕捞注意:
✓ 捕前停食1-2天(鱼肠空,运输、暂养时死得少,鱼肉也更干净)
✓ 选凉爽的清晨捕;闷热天、鱼浮头时不拉网
✓ 拉网动作要稳,网在水中停留时间短,捕后马上补注新水
✓ 干塘捕鱼后顺便清淤、晒塘,为下一年做准备

产量:
- 一般管理: 4500-7500 kg/ha
- 精养高产: 12000-22500 kg/ha
- 不买饲料、只靠青草和粪肥的粗养: 约1500-3000 kg/ha(数量级)
```

**捕捞后的保鲜**:

鱼比肉坏得快得多: 常温(25°C以上)放几个小时就开始变质。

```
活鱼暂养:
- 捕来吃不完的放进网箱或清水池里暂养,不喂食可活几天到十几天
- 需要时现杀现吃,这是没有冰箱时最好的"保鲜"

杀后:
1. 立即敲头致死、放血(切断鳃),去鳞、去鳃、去内脏
2. 用清水冲净腹腔血污;放在阴凉通风处,当天吃完
3. 有冰时: 一层冰一层鱼,可保存约3-5天

判断新鲜:
✓ 鳃鲜红,眼球饱满透明,鳞片紧贴,肉按下去能弹回,只有腥味
✗ 鳃发灰发暗、眼球下陷浑浊、肉软有指压坑、有臭味 → 不要吃

吃不完的:
- 盐腌、晒干、烟熏(做咸鱼、鱼干、熏鱼)

⚠️ 鱼胆有毒: 草鱼、青鱼、鲢鳙等的鱼胆,生吞、泡酒吞服都能引起
   中毒(呕吐、腹泻、少尿、急性肾衰竭),严重可致死。
   民间"吞鱼胆明目、清热"的说法没有根据,杀鱼时摘除丢弃
⚠️ 淡水鱼必须彻底煮熟,不吃生鱼、醉鱼、半生鱼片(肝吸虫)
```

腌、晒、熏的具体做法见[食物加工与保存-盐腌](../07-日常生活技能/01-食物加工与保存.md#盐腌)、[晒干与风干](../07-日常生活技能/01-食物加工与保存.md#晒干与风干)、[烟熏](../07-日常生活技能/01-食物加工与保存.md#烟熏);吞服鱼胆后出现症状立即就医,中毒的通用处理见[中毒](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则)。

### 稻田养鱼

```
优点:
✓ 一水两用
✓ 鱼吃害虫、杂草
✓ 鱼粪肥田
✓ 稻谷+鱼双丰收

方法:
- 在稻田周围挖鱼沟(宽1 m,深0.5 m)
- 鱼坑(供鱼栖息): 在田角或进水口附近挖一个深约1 m 的坑
- 鱼沟、鱼坑总面积约占稻田的5-10%(太多会减少稻谷产量)
- 进排水口设栅栏
- 放养鱼种: 鲤鱼、鲫鱼、草鱼等
  (草鱼稍大会吃稻苗,以鲤鲫为主,草鱼少放或稻子长高后再放)
- 密度: 750-2250尾/ha
- 放鱼时间: 插秧后约7-10天,秧苗返青扎根后再放
  (太早鱼会拱倒、吃掉秧苗)

管理:
- 稻田正常管理
- 施农药时排水至鱼沟(保护鱼)
- 适当投饲(米糠、麸皮、草)
- 晒田: 慢慢排水,让鱼顺着水流进鱼沟鱼坑,
  沟坑内保持水深;晒田时间不宜过长
- 施肥以有机肥、基肥为主;追施化肥少量分次,
  不撒在鱼沟里;不用碳铵、氨水等(氨对鱼毒性大)
- 收稻前先排水把鱼集中到沟坑里捕捞,或转到池塘

效益:
- 每公顷产鱼300-750 kg
- 稻谷也增产!

适用条件:
- 水源稳定,能保持水层(鱼沟内水深不低于0.5 m)
- 田埂加高加固(防漏水、防逃)
- 最好有当地成熟模式和技术指导
  (如浙江青田稻鱼共生,2005年列入联合国粮农组织全球重要农业文化遗产;
   各地推广的稻渔综合种养)

常见失败原因:
- 没挖鱼沟、鱼坑,晒田或断水时鱼无处躲避
- 田埂漏水、进排水口栅栏不牢,鱼逃走
- 照常喷洒农药(尤其杀虫剂),导致死鱼
- 放养过密又不投饲,鱼长不大
- 防不住鸟、蛇、鼠等天敌
```

```
农药的一般原则(稻田养鱼时更要注意):
✓ 先用农业和物理办法: 灯光诱虫、人工拔除病株、鱼鸭吃虫吃草
✓ 必须用药时,选标签注明对鱼低毒的品种,按标签用量
✓ 喷雾时喷头朝上喷到稻叶上,不要直接喷进水里;
  下雨前不喷(药会冲进田水)
✓ 先排水到鱼沟、施药后过几天再灌水
✗ 不用国家禁用的高毒农药;有机磷、菊酯类大多对鱼毒性很大
```

水稻的水层和晒田见[粮食作物-水稻田间管理](02-粮食作物.md#田间管理);喷药防护和农药中毒见[中毒-农药和鼠药中毒](../01-日常疾病和伤害/12-中毒.md#农药和鼠药中毒)。

### 稻田养鸭(稻鸭共作)

鸭子在稻田里吃杂草、吃虫(稻飞虱、螟虫幼虫等),来回游动搅动田水、刺激稻株,鸭粪肥田。很多地方用它代替除草剂和大部分杀虫剂。

```
条件:
- 田块平整,能保持水层约5-10 cm
- 田边用尼龙网、竹篱围起来(高约60-80 cm),防鸭外逃、防黄鼠狼、狗
- 田角搭一个简易鸭棚(遮雨、晚上歇息、补饲)

品种:
- 体型小、灵活、善觅食的麻鸭类(如本地麻鸭、绍兴鸭)
- 不用体型大、行动慢的北京鸭、樱桃谷鸭(会压倒稻苗)

步骤:
1. 雏鸭先在棚里养约7-15天,适应后再下田(先在浅水里练几天)
2. 插秧后约7-14天、秧苗返青扎根后放鸭
3. 密度: 约150-300只/ha;每块围起的田约0.3-1 ha 一群
4. 早上放、傍晚可在棚边补喂少量稻谷、米糠(少喂,让它饿着去找虫找草)
5. 稻子抽穗前(开始灌浆)把鸭赶出稻田,否则会吃稻穗
6. 收回的鸭子育肥一段时间后宰杀,或转去养蛋

注意:
- 鸭会吃小鱼苗。稻鸭鱼同田时,鱼要放大规格鱼种,
  或先养鸭、收鸭后再放鱼
- 田里不能用对鸭有毒的农药、鼠药
- 鸭在稻田里的密度太高会把稻苗踩坏
```

鸭的育雏、品种和日常饲养见[家禽养殖-鸭的养殖](05-家禽养殖.md#鸭的养殖)。

### 水箱(桶)养鱼(小规模)

```
适合:
- 无大水面
- 家庭小规模
- 观赏+食用

容器:
- 大水箱、水族箱、大塑料桶(选食品级或不含异味的)
- 至少50-100 L水;想吃到鱼,最好用几百升的大桶或1000 L 吨桶
- 水深至少约40 cm;放在避开暴晒的地方或搭遮阳网

品种:
- 鲫鱼、鲤鱼(耐低氧)
- 罗非鱼(热带,需保温)
- 泥鳅(更耐低氧)

密度(按鱼的重量算,比按条数可靠):
- 不增氧、不过滤: 每100 L 水不超过约0.5 kg 鱼
- 有气泵增氧和过滤: 每1000 L 水约10-20 kg 鱼
- 新手取低值

管理:
✓ 增氧(气泵)
✓ 过滤(简易: 一个装海绵、砾石的桶,水泵抽水流过后回流)
✓ 定期换水(1/3,每周): 新水先晒1-2天(自来水去氯)、温度接近再加
✓ 投饲(颗粒料,少量): 每天1-2次,5分钟内吃完的量
✓ 防夏季高温、冬季低温
✓ 每天看: 鱼在水面张嘴 → 缺氧;水发臭、发白浑浊 → 喂多了,立即减料换水

产出有限,主要体验和观赏
```

### 简易鱼菜共生

鱼的排泄物里有氨,对鱼有毒;细菌把氨转化成硝酸盐,正好是菜的肥料;菜吸收养分后,干净的水流回鱼缸。用很少的水同时得到鱼和菜,比单纯水箱养鱼稳定得多。

```
最简单的结构(一个鱼缸 + 一个种植床):

鱼缸: 1000 L 吨桶或大水箱(切掉顶部),放鱼
种植床: 一个较浅的大槽(深约30 cm),放在鱼缸上方或旁边
  - 填洗净的砾石、陶粒或碎砖(粒径约1-2 cm,不含石灰石,
    否则 pH 会一直偏高)
  - 种植床的体积约为鱼缸体积的1-2倍
循环:
  - 小水泵把鱼缸水抽到种植床,水流过砾石后靠重力流回鱼缸
  - 种植床里装钟形虹吸或定时开关,让水"灌满-排空"交替,
    根系能透气
  - 没有电的时候: 每天人工用桶舀水浇种植床几次也能凑合

启动("养水",约3-6周):
1. 先放水开泵循环,放少量鱼(或只放几尾小鱼)
2. 少喂,让砾石上慢慢长出硝化细菌
3. 这段时间鱼最危险: 看到鱼浮头、不吃食就换掉1/3的水、少喂
4. 菜开始长绿、鱼正常吃食,说明系统稳定了,再逐步加鱼

比例(数量级):
- 鱼: 每1000 L 水不超过约20 kg
- 每平方米种植床每天投喂约40-50 g 饲料(种叶菜);
  种番茄、黄瓜等果菜需要更多养分,约50-80 g
- pH 保持约6.8-7.2(鱼、菜、细菌折中);太低时用少量草木灰水调

适合的菜: 生菜、小白菜、空心菜、芹菜、香草类最容易;
  番茄、黄瓜需要更大的种植床、更长的时间

常见问题:
- 新叶发黄、叶脉还绿: 缺铁,是鱼菜共生最常见的问题
- 鱼死、水臭: 鱼放太多或喂太多,先减料、换水
- 不能给菜喷农药(会毒死鱼);菜的虫害靠人工捕捉、防虫网
```

小型太阳能供电见[照明与能源-小型太阳能](../07-日常生活技能/06-照明与能源.md#小型太阳能);蔬菜的选择见[蔬菜种植](01-蔬菜种植.md)。

## 虾类养殖

### 小龙虾养殖

```
⚠️ 先看清
- 小龙虾(克氏原螯虾)是外来物种,善打洞,会掏空田埂、堤坝,
  破坏水稻和本地水生生物。只在已有养殖的地区、封闭的池塘稻田里养,
  不要带到新地区放生
- 食用必须彻底煮熟(可能携带肺吸虫等寄生虫),只吃来源清楚的
- 吃小龙虾后数小时到一天内出现肌肉酸痛、乏力、尿呈酱油色,
  可能是横纹肌溶解,立即就医
```

**池塘条件**:
```
- 面积: 约2000-3300 m²
- 水深: 1-1.5 m
- 进排水方便
- 防逃设施(围网): 塘边用光滑的塑料薄膜或钙塑板围一圈,
  高出地面约40-50 cm,下端埋入土中约20 cm,
  小龙虾爬不上光滑面;雨天最易逃逸
- 塘埂较宽、坡缓,经得起打洞
```

**放养**:
```
- 虾苗: 450-750 kg/ha
- 时间: 春季或秋季
  (秋季放亲虾,让它们在洞里抱卵过冬,次年春天自繁出苗)
- 提供隐蔽物(水草、瓦片、网片)
- 水草占水面约1/2-2/3: 伊乐藻、轮叶黑藻、水花生等
- 放苗前同样清塘消毒(生石灰,见上方池塘准备)
```

**管理**:
```
饲料:
- 杂食性
- 小鱼虾、螺蛳、水草、人工饲料
- 也吃煮熟的玉米、小麦、豆饼、南瓜、米糠
- 投喂量约为虾体重的3-5%,傍晚为主(小龙虾夜间活动觅食)

水质:
- 保持清新
- 适当种植水草(净化水质,提供饵料和隐蔽)
- 每15-20天少量泼洒生石灰(补钙,利于蜕壳)

注意:
- 小龙虾生长过程蜕壳
- 蜕壳时易受攻击,需隐蔽物
- 定期巡塘,防逃
- 小龙虾对很多杀虫剂极敏感,稻田、塘边不要用菊酯类等农药
```

**收获**:
```
- 地笼捕捞
- 可以边养边捕(捕大留小,虾长约9-10 cm 以上即可起捕)
- 4-10月为捕捞旺季
- 活虾在湿润、阴凉处(如湿麻袋覆盖)能存活1-2天,死虾很快变质,不要吃
```

### 青虾(河虾)养殖

```
类似小龙虾,但:
- 对水质要求更高(溶氧要足,不耐低氧,不像小龙虾能离水爬)
- 密度可稍高
- 价值更高
- 不打洞,对池埂没有破坏
- 能在池塘里自然繁殖,也常与鱼混养(放在以鲢鳙为主、不放肉食鱼的塘里)
```

## 螃蟹养殖

### 河蟹(大闸蟹)养殖

**池塘条件**:
```
- 水深: 1-1.5 m
- 底部硬质(防打洞)
- 防逃设施(光滑围板或网)
- 种植水草(伊乐藻等)
```

**放养**:
```
- 蟹苗(扣蟹): 7500-12000只/ha
- 时间: 春季
- 规格: 100-150只/kg
```

**管理**:
```
饲料:
- 杂食性
- 小鱼、螺蛳、玉米、南瓜、河蟹专用料

水质:
- 清新,溶氧充足
- 水草覆盖50-60%

蜕壳:
- 生长需多次蜕壳
- 蜕壳期营养补充
- 提供隐蔽场所

注意:
- 防逃(特别是大雨、闷热天气)
- 防盗
```

**收获**:
```
- 9-11月(秋季)成熟
- 地笼、网捕
- 鲜活上市,价值高
- 死蟹不吃(死后很快腐败,产生有害物质);蟹必须蒸熟煮透
```

河蟹对水质和技术要求高,投入大,不适合作为灾后自给的首选。

## 泥鳅养殖

**特点**:
```
✓ 适应性强
✓ 耐低氧: 能吞空气在肠道里呼吸,浅水、稻田、小坑都能活
✓ 杂食性
✓ 经济价值好
✓ 适合小水面、稻田
```

**养殖**:
```
池塘:
- 小型池塘、水泥池均可(几十到几百平方米)
- 水深30-50 cm
- 底部淤泥10-15 cm(泥鳅要钻泥;水泥池底铺泥)
- 池壁高出水面约30-40 cm,土池的池壁内侧铺网片、
  下端埋入土中约30 cm(泥鳅会钻洞逃走)

放养:
- 750-1500 kg/ha
- 苗种3-5 cm
- 放养前清塘消毒(生石灰,同鱼塘);苗种同样用食盐水消毒
- 水面放约1/5的水葫芦、水花生等,遮阴降温

饲喂:
- 杂食
- 米糠、麸皮、蚯蚓、小杂鱼、专用料
- 投喂量约为体重的3-5%,水温25-28°C 时吃得最多;
  傍晚投喂为主
- 水温低于约15°C 或高于约30°C 吃食减少,钻泥不出

管理:
- 水质保持(泥鳅频繁窜到水面吞气 → 水质变坏,换水)
- 防逃(泥鳅善钻): 下大雨时特别注意进排水口和池壁
- 夏季遮阳
- 防鸟、蛇、黄鳝(黄鳝吃泥鳅)

收获:
- 养殖4-6个月
- 规格达10-15 cm
- 地笼捕捞(放米糠、炒香的麸皮作饵)
- 冬季可排干水挖泥捕捉
```

**稻田养泥鳅**: 和稻田养鱼的田间工程相同(鱼沟、鱼坑、防逃),泥鳅在稻田里吃虫和有机碎屑,耐浅水、耐晒田时的短期缺水,比鲤鲫更适合稻田。放养量明显少于池塘精养,以不投喂或少投喂为主。

## 安全: 鱼塘边的溺水与下水作业

鱼塘、稻田鱼沟、水箱都是儿童溺水的高发地点。**农村儿童溺水多发生在家附近的池塘里。**

```
防儿童溺水:
✓ 住房、院子附近的鱼塘加装围栏(高约1.2 m 以上,幼儿翻不过去,
  门要能关严)
✓ 池埂内坡做缓坡,浅水边留一段平台,落水的人容易站住、爬上来
✓ 塘边立警示牌,放一根长竹竿、绳子或救生圈,固定位置、人人知道
✓ 水箱、吨桶、水缸、蓄水池加盖,盖子孩子掀不开
✓ 不让儿童单独到塘边玩、捞鱼、钓鱼;冬天不让上冰面
✓ 大人下塘拉网、干活不带幼儿;拉网时孩子在岸上也要有人专门看着
✓ 看到有人落水: 大声呼救,拨打110/120,递竹竿、绳子,
  不要不会水的人下水、不要手拉手下水救人

下水作业:
✓ 下塘拉网、清淤至少两人,一人在岸上
✓ 清淤后的塘底淤泥很深,人陷进去可能拔不出脚,踩稳木板再走
✓ 皮肤有伤口时不下水;下水穿胶靴、戴手套,干完活用清水洗净
✓ 南方血吸虫病流行区(有钉螺的地方)不赤脚下水,听从当地疾控的要求
✓ 洪水后、鼠多的稻田和水沟里长时间泡水,可能感染钩端螺旋体病:
  接触泥水后1-2周内突然高烧、全身肌肉酸痛(小腿尤其明显),应尽快就医
```

防溺水的完整内容见[儿童安全-防溺水](../01-日常疾病和伤害/14-儿童安全.md#防溺水),溺水急救见[急性症状-溺水](../01-日常疾病和伤害/05-急性症状.md#溺水),救落水者见[涉水山洪与野外失温-救落水的同伴](../03-野外生存/08-涉水山洪与野外失温.md#救落水的同伴)。

## 📝 水产养殖要点

### 新手推荐

```
容易上手:
1. 池塘混养(四大家鱼)
2. 稻田养鱼(一水两用)、稻田养鸭
3. 泥鳅(适应性强)

需经验:
- 河蟹(技术要求高,投入大)
- 小龙虾(管理要求高,外来物种,破坏田埂)

观赏体验:
- 水箱养鱼(少量)
- 鱼菜共生(有电或有人力循环时,鱼和菜都能收一点)
```

### 成功关键

```
✓ 水质管理!(最重要)
  - 溶氧充足(黎明前巡塘看浮头)
  - 水色适宜(黄绿、茶褐,透明度25-30 cm)
  - 定期换水或加新水

✓ 合理密度(不贪多;没有饲料就少放)

✓ 科学投饲
  - 定时定量(按鱼体重百分比算)
  - 新鲜饲料,不喂发霉的

✓ 病害预防
  - 清塘、鱼种消毒
  - 早发现早治疗

✓ 日常巡塘(勤观察)

✓ 学习技术(请教当地老渔民、水产站)
```

### 家庭水产配置(有约700-1300 m²池塘)

```
池塘混养:
- 草鱼为主,搭配鲢鳙、鲤鲫
- 或小龙虾+鱼混养

稻田(如有):
- 稻田养鱼或稻田养鸭

目标:
- 自家食用为主
- 剩余出售

预期:
- 约667 m²池塘产鱼300-500 kg
- 够一家人一年吃鱼
- 剩余可出售
- 不买饲料、只靠青草粪肥时,产量约为上述的1/3-1/2

物质循环:
- 塘边种草喂草鱼,菜叶、米糠喂鱼
- 腐熟的猪粪、鸡粪、沼液肥水养鲢鳙
- 每年清出的塘泥上菜地、果园
```

### 注意事项

```
✓ 水源:
  - 确保水源充足、清洁
  - 了解水权(不和饮用水、下游灌溉争水)

✓ 技术:
  - 学习基础知识
  - 请教有经验者
  - 小规模试验

✓ 投入:
  - 池塘改造
  - 鱼种
  - 饲料
  - 设备(增氧机等)

✓ 风险:
  - 病害
  - 缺氧泛塘(最常见的大损失)
  - 自然灾害(洪水漫塘跑鱼、干旱缺水)
  - 市场价格波动
  - 盗窃、天敌(鸟类、水獭、蛇等)

✓ 食用安全:
  - 淡水鱼虾必须煮熟
  - 生吃(如鱼生)易感染肝吸虫等寄生虫
  - 鱼胆不能吃
  - 病死、不明原因死亡的鱼不吃

✓ 环境:
  - 不过度投饲施肥(污染水质)
  - 合理用药(按标签、守休药期、不用禁用药)
  - 废水处理(塘水排放前不要带药;肥水可浇地)
  - 不把外来物种放进自然水体

✓ 人身安全:
  - 塘边围栏、救生竹竿,防儿童溺水
  - 增氧机、水泵装漏电保护器
  - 生石灰操作防烫伤、防溅眼
```

### 效益估算(约667 m²池塘混养)

```
投入:
- 清塘、池塘整理: 200元
- 鱼种: 1000-1500元
- 饲料: 2000-3000元
- 肥料、药物: 300-500元
- 电费、其他: 200-300元
总计: 3700-5500元

产出:
- 产量: 400 kg
- 价格: 平均15元/kg
- 收入: 6000元

净利润: 500-2300元

注:
- 新手第一年利润较低
- 经验增加后提高
- 自食用价值更高
- 配合其他种养效益更好
```
