# 粮食作物种植指南

## 主食作物重要性

```
粮食作物 = 生存基础
- 提供碳水化合物(能量)
- 可长期储存
- 单位面积产量高
- 自给自足核心
```

蔬菜能补充维生素,但几乎提供不了热量;一个成年人以粮食为主食时每天约需0.5 kg粮食(约2000 kcal以上),一年约180 kg。能不能挺过一个冬天,取决于秋天仓里有多少干粮。

**先看自己的条件,再选作物**:

| 作物 | 需要的条件 | 上手难度 | 从种到能吃 | 储存性 | 主要用途 |
|------|-----------|---------|-----------|--------|---------|
| 土豆 | 凉爽,怕高温和积水 | 易 | 约3-4个月 | 窖藏几个月,要避光 | 救急、主食 |
| 红薯 | 温暖,耐旱耐瘠,怕霜 | 易 | 约4-5个月 | 怕冷(低于约10°C会烂),晒干片可存 | 高产主食、叶蔓可吃 |
| 玉米 | 温暖,水肥要求较高 | 较易 | 约3-5个月 | 晒干可存1-2年 | 主食、饲料 |
| 大豆 | 适应性广,不耐连作 | 较易 | 约3-4个月 | 晒干可存1-2年 | 蛋白质、油 |
| 高粱 | 耐旱、耐瘠、耐盐碱 | 较易 | 约3-4个月 | 晒干可存 | 旱地保底、饲料、酿酒 |
| 水稻 | 要有稳定水源和保水田块 | 较难 | 约4-5个月 | 稻谷可存1-2年 | 南方主粮 |
| 小麦 | 温带,冬小麦要过冬 | 较难 | 冬小麦约8个月 | 可存1-2年 | 北方主粮 |

```
选作物的几条原则:
✓ 先问本地老农往年种什么、什么时候种 —— 本地品种和本地农时是几百年试出来的
✓ 不要只种一种: 一场病害、一次旱涝就可能绝收,至少搭配2-3种作物
✓ 救急先种生长快、不需要加工的(土豆、红薯),同时开始准备主粮
✓ 主粮要考虑加工: 稻谷要去壳,小麦要磨面,没有石磨和碾子时
  玉米、土豆、红薯更容易直接吃
```

土壤好坏的判断见[地质矿物与土壤-土壤肥力](../08-基础科学知识/06-地质矿物与土壤.md#54-土壤肥力),霜期与农时见[天气观测与预报-霜冻](../08-基础科学知识/07-天气观测与预报.md#五霜冻)和[物理-历法](../08-基础科学知识/02-物理.md#92-历法)(二十四节气)。

## 水稻

### 基本信息

```
类型: 主粮作物
周期: 120-150天
产量: 约7500 kg/ha(稻谷,出米率约70%)——良种、化肥、灌溉充足时
      只用农家肥、传统品种、手工管理时现实约3000-4500 kg/ha
适宜: 水源充足地区
```

水稻要求田块能蓄住水: 田面平整、田埂不漏、有水渠能灌能排。没有稳定水源的地方不要硬种水稻,改种玉米、红薯、高粱更稳妥。

### 品种选择

**按生育期**:
- 早稻: 90-120天
- 中稻: 120-150天
- 晚稻: 150-170天

**按种植方式**:
- 水稻(淹水种植)
- 旱稻(旱地种植,产量较低)

**新手推荐**: 本地适应品种

```
为什么一定要本地品种:
- 很多水稻品种对日照长短敏感(晚稻尤其明显),
  从南方拿到北方或反过来,可能迟迟不抽穗,或者在秋霜前来不及成熟
- 籼稻耐热,多在南方;粳稻耐寒,多在北方和高海拔地区
- 杂交稻产量高,但第二代性状分离,不能留种(见种子保存)
  → 灾后长期打算,要有能自己留种的常规稻
```

### 种植方法

#### 育苗移栽法(常用)

**1. 育秧(约30天)**:
```
时间: 清明前后(南方)
- 更准确的标准: 日平均气温稳定在12°C以上(籼稻)或10°C以上(粳稻)再播种
- 太早遇倒春寒会烂秧;晚稻、双季稻按本地农时推后

秧田准备:
- 平整、肥沃
- 浅水层(2-3 cm)
- 选背风向阳、排灌方便、离大田近的地块
- 秧田和大田面积比约1:8-1:10(插1000 m²大田,秧田约100-125 m²)
- 做成宽约1.2-1.5 m的秧畦,畦间留宽约25-30 cm的沟,方便走人和排水
- 畦面耙到泥烂而平,"上糊下松"

种子用量:
- 大田用种(常规稻): 约30-60 kg/ha,即每1000 m²大田约3-6 kg种子
- 秧田播种量: 约75-100 g/m²,撒均匀

选种和浸种:
1. 晒种1-2天(提高发芽势)
2. 选种: 种子倒进水里搅动,捞去浮起的瘪粒、杂物;
   盐水选种更彻底: 每10 L水溶约1.5 kg盐(粳稻;籼稻减到约1 kg),
   下沉的饱满种子捞出后用清水冲洗2-3遍
3. 浸种防病(可选): 熟石灰约1 kg兑100 L水,搅匀后取澄清液浸种,
   水面会结一层石灰膜,不要搅破,浸2-3天,
   对恶苗病、稻瘟病有一定预防作用;浸后清水洗净
   (⚠️ 石灰水伤皮肤和眼睛,戴手套)
4. 浸种到谷壳半透明、胚部发白膨大: 水温约15°C要3天左右,约25°C约2天

播种:
- 浸种催芽(2-3天)
- 播种密度适中
- 保持湿润
- 催芽: 浸好的种子沥干,堆在箩筐里盖湿麻袋保温,
  保持在约30-35°C,一天翻动几次、淋温水,约1天就"破胸露白"
- 芽长到约半粒谷长、根约一粒谷长就可以播,芽太长播时容易折断
- 堆内超过约40°C会"烧芽"(有酒味、芽发黄),要经常摸温度
- 播后用木板或手掌轻压,把种子压进泥面(塌谷),薄撒一层草木灰或细土

管理:
✓ 保持浅水
✓ 薄施肥料
✓ 防病虫
- 一叶一心以前: 畦面保持湿润、沟里有水,不要上水淹苗(缺氧烂芽)
- 二叶以后: 上浅水2-3 cm;寒潮夜里灌深水护苗,第二天回暖再排浅
- 二叶前后施一次"断奶肥": 腐熟稀粪水或稀释5-10倍的尿液
- 移栽前3-5天再薄施一次"送嫁肥",秧苗带肥下田返青快
- 有薄膜可以搭小拱棚保温,但晴天中午棚内超过约30°C要揭开通风,否则烧苗

壮秧的样子:
✓ 苗高约15-20 cm,叶色青绿,茎基部扁粗
✓ 白根多,带1-2个分蘖,没有病斑
✗ 细高、发黄、根发黑 → 秧田太密、缺肥或长期淹水
```

**2. 整田**:
```
- 犁田(翻耕)
- 耙平
- 做好田埂(保水)
- 灌水

要点:
- 翻耕深约15-20 cm,把基肥(腐熟农家肥)翻进土里
- 田面高低差最好不超过约3 cm: 高处露泥长草,低处积水淹苗
- 田埂拍实、修补鼠洞和蟹洞,不然水层保不住
- 进水口和出水口分开,一块田能单独灌、单独排
- 冬季绿肥(紫云英等)在插秧前约1-2周翻压沤烂
```

**3. 移栽**:
```
时间: 秧苗4-5叶时(秧龄约25-35天)

密度:
- 行距: 20-25 cm
- 株距: 15-20 cm
- 每穴2-3株
- 合计约每平方米20-33穴
- 肥田、分蘖力强的品种稀一些;瘦田、晚插、分蘖少的品种密一些

深度:
- 浅插(2-3 cm)
- 插秧时田里保持约3 cm浅水: 水太深秧苗漂起,无水看不清又伤手
- 插得太深分蘖晚而少;插得太浅容易漂秧

要点:
✓ 边起秧边栽
✓ 当天栽完
✓ 保持水层
- 起秧前一天秧田灌水泡软,连泥带根轻拔,不要扯断根
- 秧根要直插下去,不要窝成钩状(返青慢)
- 插后3-5天水层稍深(3-5 cm)护苗,防止烈日晒蔫
- 约一周后新叶转绿、长出白根 = 返青;缺穴的及时补上
```

#### 直播法(简单但产量略低)

```
- 整田后直接播种
- 省工省时
- 适合小面积
- 杂草控制难

做法:
- 用种量比移栽多: 常规稻约45-75 kg/ha(撒播取高值)
- 田面一定要平,播前排干明水,播后保持湿润不淹,
  出苗后2-3叶再上浅水
- 鸟和老鼠会吃种子: 播后用细土或草木灰盖种,有人看守
- 杂草和稻苗同时出土,要勤拔草或在稻苗站稳后用水层压草
```

### 田间管理

**水层管理**:
```
关键!

分蘖期(移栽后):
- 浅水(3-5 cm)
- 促进分蘖
- 浅水升温快,分蘖多;长期深灌分蘖少

分蘖末期:
- 排水晒田5-7天
- 控制无效分蘖,促进扎根

孕穗期:
- 深水(5-8 cm)

抽穗开花:
- 浅水
- 保持湿润
- 这一段最怕缺水,缺水会出现大量空瘪粒

成熟期:
- 干湿交替
- 收获前7-10天断水
- 断水太早籽粒不饱满;太晚田烂,收割困难
```

**晒田怎么掌握**:
```
什么时候晒:
- 每穴的茎数达到计划穗数的约八成时(例如每穴已有10-15根茎),
  一般在移栽后约25-30天
- 必须在幼穗开始分化(拔节)以前晒完

晒到什么程度:
✓ 田面出现细裂缝(像鸡爪),人踩下去不陷脚、有脚印
✓ 田面露出白根,叶色由浓绿褪淡,叶片挺起来
✗ 裂缝宽到能伸进手指 → 晒过头,扯断根系,要立即复水

轻重:
- 苗多、叶色浓绿、长势过旺 → 重晒,时间长些
- 苗少、叶色发黄、沙质田、漏水田 → 轻晒或只排水露田1-2天
- 晒后复水先灌浅水,不要一下灌深

抽穗开花时遇到异常天气:
- 低温(粳稻约20°C以下、籼稻约22°C以下)的冷风天 → 灌深水保温
- 高温(约35°C以上)→ 保持水层,有条件的日灌夜排降温
```

**施肥**:
```
基肥(整田时):
- 有机肥为主
- 腐熟农家肥
- 用量约15000-30000 kg/ha(每平方米约1.5-3 kg),整田时翻入土中
- 缺钾的田(老叶叶尖、叶缘发黄焦枯)加草木灰约75-150 g/m²
  (草木灰不要和粪尿混在一起堆放,会让氮变成氨气跑掉)

追肥:
- 分蘖肥(移栽后7-10天)
- 穗肥(孕穗期)
- 以氮肥为主,配合磷钾
- 用稀粪水或稀释5-10倍的尿液,浇在行间,施后保持浅水
- 穗肥在幼穗分化时(晒田复水后)施,叶色已经很浓绿的田少施或不施

原则:
- 前促(分蘖)
- 中控(防徒长)
- 后补(壮籽)

施氮过多的后果: 叶片披垂、茎秆软 → 倒伏;
稻瘟病、纹枯病、稻飞虱都明显加重;贪青晚熟
```

**病虫害防治**:
```
常见病害:
- 稻瘟病: 选抗病品种,避免偏施氮肥
- 纹枯病: 控制水层,不过密

常见虫害:
- 稻飞虱: 田间灯光诱杀
- 螟虫: 及时排除枯心苗

预防为主!
```

| 病虫 | 怎么认 | 怎么防 |
|------|--------|--------|
| 稻瘟病 | 叶上梭形病斑,中间灰白、边缘褐色;穗颈变黑褐,整穗发白不结实(穗颈瘟) | 抗病品种;种子消毒;不偏施氮肥;病稻草不要留到第二年 |
| 纹枯病 | 靠近水面的叶鞘上出现云纹状、边缘褐色的灰绿色大斑,逐渐向上蔓延 | 不要插得太密;适时晒田;不过量施氮 |
| 白叶枯病 | 叶尖、叶缘出现黄白色长条枯斑,台风暴雨后多发 | 抗病品种;病田的水不要串灌到别的田 |
| 恶苗病 | 秧苗细长、淡黄,比别的苗高出一截,后期枯死 | 浸种消毒;秧田里见到就拔除 |
| 稻飞虱 | 稻株基部聚集大量褐色或灰白色小虫,严重时成片发黄倒伏("虱烧") | 不过密、不偏施氮;灯光诱杀;保护蜘蛛、青蛙;稻田养鸭 |
| 螟虫(二化螟、三化螟) | 分蘖期心叶枯死(枯心);抽穗后整穗发白直立、一拔就断(白穗) | 拔除枯心株、白穗株带出田外;收割时稻桩留低;冬春翻耕灌水淹死越冬幼虫 |
| 稻纵卷叶螟 | 叶片被吐丝纵卷成筒,里面有绿色幼虫,叶上留白色条斑 | 保护天敌;少量时人工捏卷叶;灯光诱杀成虫 |

```
补充:
- 稻田养鸭: 移栽后约7-10天放入约半个月大的雏鸭,每公顷约150-300只,
  鸭子吃虫吃草、搅浑水抑草;抽穗前把鸭子赶出,否则会吃稻穗
- 稻田养鱼也能吃虫除草,用药前要先把鱼赶进鱼沟
- 抽穗灌浆后防麻雀: 稻草人、拉彩带、有人看守
- 不要用来路不明、标签不清的农药(见病虫害防治原则)
```

养鸭见[家禽养殖-鸭的养殖](05-家禽养殖.md#鸭的养殖),养鱼见[水产养殖-稻田养鱼](07-水产养殖.md#稻田养鱼)。

### 收获与储存

**收获**:
```
时间:
- 90%谷粒黄熟
- 早收损失大
- 迟收易落粒

方法:
- 割稻
- 脱粒
- 晾晒(水分<13%)

✓ 选连续几个晴天开镰,割下尽快脱粒,不要堆在田里捂着(会发热、发芽)
```

**储存**:
```
✓ 充分干燥
✓ 密封防潮
✓ 防鼠防虫
✓ 通风阴凉处
✓ 定期检查

糙米/稻谷可储存1-2年
- 以稻谷(带壳)形式储存最耐放,吃多少碾多少
- 糙米、白米碾出后容易变味生虫,一次不要碾太多
```

成熟度判断、脱粒和晒干见[粮油加工-收获](../07-日常生活技能/14-粮油加工.md#收获-什么时候割怎么割)和[干燥到安全水分](../07-日常生活技能/14-粮油加工.md#干燥到安全水分),去壳碾米见[稻谷-去壳和碾米](../07-日常生活技能/14-粮油加工.md#稻谷-去壳和碾米)。

## 小麦

### 基本信息

```
类型: 主粮作物
周期: 冬小麦约220-260天,春小麦约90-120天
产量: 约4500-6000 kg/ha——良种、化肥、灌溉条件下
      只用农家肥、传统品种、靠天时现实约1500-3000 kg/ha
适宜: 北方、温带
```

冬小麦秋天播种、第二年初夏收获,从播种到收获一般约220-260天(南方冬麦较短);春小麦约90-120天。

### 品种

**按种植季节**:
- 冬小麦: 秋播春收(主要,产量高)
- 春小麦: 春播秋收(高寒地区)

```
- 冬小麦必须经过一段低温(春化)才会抽穗: 冬性强的品种春天才播,只长叶不抽穗
- 冬小麦能在哪里种,看冬天能不能安全越冬: 冬季太冷、积雪少、风大的地区种春小麦
- 同样要用本地品种: 北方冬性强的品种拿到南方会晚熟,南方春性品种拿到北方会冻死
```

### 种植方法

**整地**:
```
- 深耕(20-25 cm)
- 耙细整平
- 施足基肥
- 基肥: 腐熟农家肥约15000-30000 kg/ha(每平方米约1.5-3 kg),耕地前撒匀
- 土块要细碎、上虚下实: 土块大、架空的地方种子落进缝里出不了苗,冬天还容易冻死
- 墒情: 抓一把土能握成团、落地即散最合适;太干先浇底墒水再播
```

**播种**:
```
时间:
- 冬小麦: 寒露至霜降(10月)
- 春小麦: 清明前后

冬小麦更准确的判断:
- 日平均气温降到约16-18°C(冬性品种)或14-16°C(半冬性品种)时播种
- 目标是入冬前长成"壮苗": 主茎5-6片叶、带3-5个分蘖
- 太早: 冬前长得太旺,冬天易冻死,病虫也重
- 太晚: 冬前苗太小(只有2-3片叶),抗冻差、分蘖少、产量低
- 大致农时(差别很大,以本地经验为准):
  华北北部约9月下旬,黄淮地区约10月上中旬,长江流域约10月下旬至11月上旬

春小麦: 土壤化冻约5-7 cm深、能耙地时就抢播("顶凌播种"),
        越早越好,晚播产量下降明显

方法:
- 条播(行距20-25 cm)
- 或撒播
- 条播出苗齐,行间方便锄草追肥,比撒播好

播量:
- 150-225 kg/ha
- 播期适宜、土壤好时取低值;晚播、土差、整地粗时取高值
- 晚于适宜播期,每晚一天大约每公顷多播约7.5 kg

深度:
- 3-5 cm
- 太深出苗慢、苗弱;太浅易干、易冻
- 播后轻轻镇压,让种子和湿土贴紧
```

**自己算播量**(种子来源不同、千粒重差别很大时):
```
播量(kg/ha) = 计划每平方米苗数 × 千粒重(g) ÷ (发芽率 × 出苗率) ÷ 100

例: 计划每平方米250株,千粒重40 g,发芽率90%,田间出苗率80%
    250 × 40 ÷ (0.9 × 0.8) ÷ 100 ≈ 139 kg/ha(每平方米约14 g)

- 千粒重: 数1000粒饱满种子称重
- 发芽率: 播前做发芽试验
- 一般适期播种每平方米约200-300株苗
```

发芽率测试见[留种与育种-发芽率测试](08-留种与育种.md#发芽率测试)。

### 田间管理

**冬前管理**(冬小麦):
```
✓ 及时浇灌(出苗水、越冬水)
✓ 中耕除草
✓ 镇压(防冻拔)
✓ 追施腊肥

具体:
- 出苗后查苗: 断垄超过约15 cm的地方及时补种
- 越冬水: 日平均气温降到约3-5°C、"夜冻昼消"时浇,
  当天要能渗下去;浇早了苗旺,浇晚了地面结冰
  土壤底墒足、苗弱的可以不浇
- 镇压: 土壤疏松、坷垃多的地,用石磙或木磙压一遍,
  压碎土块、弥合裂缝,防止冬季冷风钻进根部"吊根"冻死;
  地太湿时不压
- 腊肥: 入冬前后在麦垄间撒施腐熟农家肥或草木灰,既供肥又盖土保温
- 冬季不要让牲畜进麦田啃青、踩踏
```

**春季管理**:
```
✓ 返青水肥(早春)
✓ 拔节期追肥
✓ 防倒伏
✓ 病虫害防治

返青(早春气温回升、麦苗开始转绿生长):
- 先锄地(松土保墒、提高地温),不要急着浇水
- 弱苗、黄苗: 早施返青肥(稀粪水、稀释尿液)
- 旺苗(冬前长太高、叶色浓): 不施肥不浇水,镇压一遍"蹲苗",防后期倒伏

拔节(茎基部第一节伸出地面约1.5-2 cm,手捏能摸到硬节):
- 这是最重要的一次追肥浇水,决定穗大小
- 追肥后浇水,或趁雨前施
- 拔节后遇霜冻(倒春寒)预报,提前浇一次水能减轻冻害

防倒伏:
- 播量不过大,不偏施氮肥
- 旺苗拔节前镇压、控水
- 抽穗后遇大风雨前不要浇水
```

**灌溉**:
```
关键期:
- 出苗期
- 越冬前
- 返青期
- 拔节期
- 孕穗期
- 灌浆期

原则:
- 干旱时及时浇
- 雨季注意排水
- 水少时优先保拔节水和孕穗水
- 灌浆后期大风天不浇,防倒伏
- 南方冬麦"怕湿不怕旱": 开好畦沟、腰沟、围沟,雨后田里不积水
```

**病虫害**:
```
- 锈病: 选抗病品种
- 赤霉病: 扬花期喷药预防
- 蚜虫: 早防早治

识别:
- 锈病: 叶片上鲜黄色条状(条锈)或橙褐色散点(叶锈)的粉疱,
  手指一抹一层"锈粉";拔除自生麦苗、不过早播种能减轻
- 蚜虫: 穗上、叶背上密集的小绿虫,叶面有黏液;
  瓢虫、草蛉多时往往不用管;数量猛增、穗上爬满时才处理
- 黑穗病: 麦穗变成一包黑粉 → 拔除装袋带出田外烧掉,不要用这块田的麦子留种
```

### 赤霉病: 发霉的麦子不能吃

赤霉病是小麦最危险的病害,不只减产,病粒里含**脱氧雪腐镰刀菌烯醇(俗称呕吐毒素)**等真菌毒素,人吃了恶心、呕吐、腹泻,牲畜吃了拒食、呕吐、流产。毒素耐高温,蒸煮烘烤都去不掉。

```
什么时候发生:
- 扬花期(抽穗后约一周)遇到连续阴雨、潮湿温暖的天气,最容易大发生
- 长江中下游和黄淮麦区多发;前茬是玉米、田里玉米秸秆多的更重

怎么认:
- 穗上一个或几个小穗先变得枯白、像提前熟了一样
- 潮湿时小穗基部和颖壳缝里长出粉红色霉层
- 病粒干瘪、发白或带粉红色,比好麦粒轻

预防:
✓ 种抗病性较好的本地品种
✓ 播种前把田里的玉米秸秆、稻桩清理或深翻埋掉
✓ 开好排水沟,田里不积水
✓ 扬花初期如果天气预报有连阴雨,这是唯一有效的用药时机,
  按农药标签用药;发病后再喷基本无效

病麦的处理:
1. 病穗多的地块单收、单打,不要和好麦子混在一起
2. 风选、水选去掉轻的病粒(病粒轻,扬场时落得远,泡水时浮起)
3. 病粒多(大约超过几个百分点)、带粉红色的整批不作口粮,也不要喂猪和鸡
4. 绝不能用病麦留种
```

### 收获储存

**收获**:
```
时间:
- 蜡熟末期至完熟初期
- 90%籽粒变硬

方法:
- 割晒(割后晾晒再脱粒)
- 或联合收割

晾晒:
- 水分<12%

⚠️ 小麦熟后遇雨,麦粒会在穗上发芽(穗发芽),面粉变黏、做不成面食,
   而且很快发霉: 熟一块收一块,"龙口夺粮"
```

**储存**:
```
✓ 干燥通风
✓ 防虫防鼠
✓ 避光
✓ 可储存1-2年
```

收割、脱粒、晒干的判断见[粮油加工-收获](../07-日常生活技能/14-粮油加工.md#收获-什么时候割怎么割),磨面见[小麦-石磨磨面](../07-日常生活技能/14-粮油加工.md#小麦-石磨磨面)。

## 玉米

### 基本信息

```
类型: 主粮/饲料
周期: 100-150天
产量: 约7500-9000 kg/ha——良种(多为杂交种)、化肥条件下
      农家品种、只用农家肥时现实约2000-4500 kg/ha
适宜: 广泛,适应性强
```

### 品种

- 普通玉米
- 甜玉米(鲜食)
- 糯玉米
- 饲料玉米

```
- 现在市面上的玉米种子绝大多数是杂交种,当年产量高,但不能留种
  → 长期打算要找农家品种(常规品种、开放授粉品种)
- 甜玉米含糖高、淀粉少,晒干后皱缩,不耐储存,不适合当主粮
- 主粮玉米选硬粒型或马齿型,本地成熟期合适的品种
```

### 种植方法

**整地施肥**:
```
- 深耕
- 施足有机肥
- 做垄或平作
- 耕深约20 cm;基肥用腐熟农家肥约15000-30000 kg/ha
- 低洼、雨水多的地方做垄,排水好;干旱地区平作或沟种,保墒好
```

**播种**:
```
时间:
- 春播: 4-5月(地温稳定12°C以上)
- 夏播: 6月(麦后复种)
- 地温: 在5-10 cm深处测,早晨的读数连续几天达到要求才算稳定
- 夏玉米越早播越好,收麦后抢墒抢种;晚了秋霜前可能来不及成熟

方法:
- 穴播或条播
- 行距: 60 cm
- 株距: 28-37 cm
- 密度: 45000-60000株/ha
- 肥地、株型紧凑的品种取高值;瘦地、植株高大的农家品种取低值
- 也可用宽窄行(例如宽行80 cm、窄行40 cm交替),通风透光好,方便间作

深度:
- 一般4-6 cm
- 黏土、湿土浅些(约3-4 cm);沙土、干土深些(约6-7 cm)

每穴:
- 2-3粒
- 出苗后间苗留1株
- 用种量约30-45 kg/ha(视千粒重)
```

```
⚠️ 玉米靠风传粉,雄花(顶上的穗)的花粉落到雌穗的花丝上才能结粒
- 小面积种植要种成方块(至少4行以上),不要只种单独一长行,
  否则授粉不良,玉米棒上缺粒、秃尖
- 甜玉米、糯玉米和普通玉米要隔开种,相互串粉会改变籽粒性状
```

隔离距离见[留种与育种-隔离距离](08-留种与育种.md#隔离距离)。

### 田间管理

**苗期**:
```
✓ 间苗、定苗(3-4叶)
✓ 中耕除草
✓ 防治地下害虫(蛴螬、蝼蛄)

- 留壮苗、留匀苗,拔掉弱苗、病苗和过大过小的苗
- 缺苗处用旁边穴里多余的苗带土移栽,移后浇水
- 苗期适当干旱能"蹲苗",根扎得深(叶片中午稍卷、傍晚恢复即可)
- 地老虎在夜里咬断幼苗: 早晨在断苗附近扒开表土捉虫
- 蛴螬(白色弯曲肥虫)、蝼蛄咬根: 翻地时拣出喂鸡,施用的粪肥一定要腐熟
```

**拔节期**:
```
✓ 追肥(大喇叭口期)
✓ 培土(防倒伏)
✓ 除蘖(去分蘖)

- 培土: 结合中耕把土壅到茎基部约10 cm高,促发气生根,抗倒伏,也便于排灌
- 农家品种分蘖多时,把茎基部长出的侧枝掰掉
```

**抽雄开花期**:
```
✓ 充足水分
✓ 防治玉米螟
✓ 人工辅助授粉(小面积,提高结实率)

- 抽雄前后约一个月是需水最多的时候,这时干旱减产最重
- 人工授粉: 晴天上午露水干后,摇动植株或用纸袋收集花粉,
  撒到花丝上,隔2-3天再做一次
- 留种的植株不要去雄穗
```

**灌浆成熟期**:
```
✓ 保持水分
✓ 防早衰
✓ 防倒伏
```

**施肥**:
```
基肥: 有机肥为主
追肥:
- 苗肥: 3-4叶期
- 穗肥: 大喇叭口期(重要!)
- 粒肥: 抽雄后

重施穗肥!

怎么认大喇叭口期:
- 约11-12片叶展开,上部几片叶簇在一起、从上往下看像喇叭口
- 大约在抽雄前10-15天
- 这时雌穗正在分化,缺肥会穗小、粒少

施法:
- 在离植株约10-15 cm的地方开沟或挖穴,深约10 cm,施后盖土
  (撒在地面上氮会挥发损失,雨水也会冲走)
- 用腐熟粪肥、稀释的尿液或饼肥;施后浇水或趁雨前施
- 分配: 苗肥少量,穗肥占追肥的大部分,粒肥看长势,叶色发黄脱肥时才补

缺肥的样子:
- 缺氮: 下部老叶从叶尖沿中脉变黄,呈"V"字形
- 缺钾: 老叶叶缘发黄焦枯
- 缺磷: 苗期叶片暗绿发紫
```

### 玉米螟

玉米螟是玉米最主要的害虫,幼虫蛀食心叶、雄穗、茎秆和果穗,造成折茎、果穗被蛀,还会让穗腐病和霉菌毒素加重。

```
怎么认:
- 心叶期: 展开的叶片上有一排排整齐的小孔(虫在卷着的心叶里咬的)
- 抽雄后: 雄穗折断;茎秆上有蛀孔,孔外有锯末样虫粪
- 果穗: 穗顶被咬,里面有肉色幼虫和虫粪

防治(以农业和物理防治为主):
1. 处理秸秆: 幼虫在玉米秸秆、玉米芯里过冬,
   第二年春天化蛹前(本地成虫出现前)把秸秆粉碎还田、沤肥或当柴烧完
   → 这是最根本的办法,最好全村一起做
2. 灯光诱杀: 成虫发生期夜里在田边点灯,灯下放一盆水(水面滴少许油)
3. 保护和释放天敌: 赤眼蜂、瓢虫、草蛉;少用广谱杀虫药
4. 心叶末期(喇叭口期)虫多时,把生物农药(如白僵菌、苏云金杆菌)
   或按标签使用的颗粒剂撒进喇叭口里
5. 收获时剥下的虫蛀果穗单独处理,发霉的不要吃
```

```
其他常见问题:
- 大斑病、小斑病: 叶上长条形或椭圆形的灰褐色病斑,雨水多时重 → 抗病品种、轮作、清除病残体
- 黑粉病: 茎、穗上长出白色包膜的瘤,破裂后散出黑粉 → 在包膜破裂前摘除,带出田外
- 黏虫: 大量幼虫一夜之间把叶子啃光 → 早发现,人工捕捉,鸡鸭放田里吃
- 穗腐: 果穗上长粉红色、灰绿色或黄绿色的霉 → 这样的玉米不能吃、不能喂牲畜
```

### 收获储存

**收获**:
```
时间:
- 苞叶枯黄
- 籽粒变硬
- 乳线消失

方法:
- 掰穗
- 剥皮
- 晾晒

- 乳线: 籽粒背面黄白交界的那条线,从顶部向下移动,消失时(籽粒基部出现黑层)完全成熟
- 适当晚收几天(籽粒完全变硬后)产量更高,但雨水多的地方要防穗上发霉
```

**储存**:
```
玉米棒:
- 挂起通风晾干
- 水分<14%

玉米粒:
- 脱粒后晾晒
- 密封防潮防虫
- 可储存1-2年

☠️ 发霉、变色、发苦的玉米整批丢弃,不能吃也不能喂牲畜(黄曲霉毒素,加热去不掉)
```

脱粒和磨粉见[粮油加工-玉米](../07-日常生活技能/14-粮油加工.md#玉米)。**长期以玉米为主食要先用石灰水或草木灰碱水煮**,否则容易得糙皮病,见[营养与营养缺乏病-烟酸](../07-日常生活技能/02-营养与营养缺乏病.md#烟酸-吃玉米要用碱处理);霉变见[食物加工与保存-黄曲霉毒素](../07-日常生活技能/01-食物加工与保存.md#黄曲霉毒素)。

见[蔬菜种植-土豆](01-蔬菜种植.md#土豆)

```
周期: 90-120天
产量: 22500-30000 kg/ha
特点:
✓ 产量高
✓ 营养丰富
✓ 耐储存
✓ 可做主食

是重要的备荒作物!
```

```
产量说明: 上面是良好管理下的鲜薯产量;
         只用农家肥、自留种薯时现实约10000-20000 kg/ha
折算: 鲜土豆约含水80%,大约4.5 kg鲜土豆的热量相当于1 kg粮食
```

### 土豆大田要点

种植和收获的基本做法见蔬菜种植章节,这里只补充成片种植时的要点。

```
种薯:
- 用量约1500-2250 kg/ha(每平方米约150-225 g)
- 大薯切块,每块约25-40 g、带1-2个芽眼;小薯(约50 g以下)整薯播种最好
- 切块后拌干燥草木灰,摊在阴凉处晾1-2天让切口愈合,防止烂种
- 切到有黑圈、褐色环或腐烂的薯,把刀在开水或酒精里消毒后再切下一个
- 播前约2-3周把种薯摊在散射光下"晒芽",出短壮绿芽后播,出苗早而齐

密度:
- 行距约60-70 cm,株距约25-30 cm,每公顷约50000-65000穴
- 起垄种植,随苗长分2-3次培土,薯块不露出地面(见光变绿有毒)

时间:
- 春薯: 当地终霜前约2-4周、10 cm地温达到约7-8°C时播种,出苗时躲过晚霜
- 土豆喜凉,高温(白天超过约30°C)时块茎几乎不长,
  所以南方多种秋冬薯,北方和高海拔地区种春薯
```

```
⚠️ 晚疫病: 土豆最致命的病,1840年代爱尔兰大饥荒就是它造成的
怎么认: 叶片上出现水渍状的暗褐色病斑,潮湿时叶背有一圈白霉,
       阴雨天几天之内整片地的茎叶发黑倒伏,有腥臭味;薯块表皮下变褐腐烂
怎么防:
✓ 种无病种薯,不同时只种一个品种
✓ 培土厚一些,盖住薯块,病菌不容易随雨水渗到薯块
✓ 发现中心病株立即拔除,装袋带出田外深埋
✓ 茎叶大量发病时,割掉地上部带走,过1-2周再挖薯(薯皮老化,带菌少)
✓ 和茄子、番茄、辣椒(同为茄科)隔开种,不轮作在一起
✓ 至少隔3年才在同一块地再种土豆或其他茄科作物

退化: 自留种薯连种几年,植株矮小、叶片皱缩花叶,产量一年比一年低
→ 多是病毒病;留种选健壮无病株,最好从冷凉高海拔地区换种
```

种薯留种见[留种与育种-土豆和红薯](08-留种与育种.md#土豆和红薯-用薯块繁殖),窖藏见[食物加工与保存-窖藏](../07-日常生活技能/01-食物加工与保存.md#窖藏)。

## 红薯(甘薯)

见[蔬菜种植-红薯](01-蔬菜种植.md#红薯)

```
周期: 120-150天
产量: 30000-60000 kg/ha
特点:
✓ 超高产!
✓ 耐旱耐瘠
✓ 易种植
✓ 可鲜食、晒干储存
✓ 叶和蔓也可食用

是最高产的粮食作物!
```

```
产量说明: 上面是良好管理下的鲜薯产量;
         粗放种植现实约15000-30000 kg/ha
折算: 大约3.5 kg鲜红薯的热量相当于1 kg粮食,
      所以按单位面积产出的热量,红薯通常比谷物高
不足: 蛋白质很少,不能只吃红薯;鲜薯怕冷不耐久放
```

### 红薯大田要点

```
育苗:
- 每公顷大田约需种薯750-1500 kg育苗
- 苗床温度保持约25-30°C(可用温床、酿热床),出苗后降到约20-25°C炼苗
- 苗长到约20-25 cm、有5-7片叶时剪下,插入大田

栽插:
- 起垄: 垄距约70-90 cm,垄高约25-30 cm(土松才结大薯)
- 株距约20-30 cm,每公顷约45000-60000株
- 薯苗斜插或平插,入土3-4个节(每个节都可能结薯),叶片露出地面
- 阴天或傍晚栽,栽后浇水;地温约15°C以上才栽,怕霜

管理:
- 封垄前锄草1-2次
- 氮肥不要多: 多了只长藤叶不结薯
- 草木灰(钾)对红薯效果最好,约75-150 g/m²
- 收获: 当地初霜前,或日平均气温降到约15°C时;
  挖时轻拿轻放,破皮的先吃
```

```
⚠️ 黑斑病: 薯块上出现黑褐色、略凹陷的圆斑,切开病斑下的薯肉发黑发绿、味苦
- 病薯里有毒素(甘薯酮等),人吃了恶心呕吐,牛羊吃了会中毒致死
- 病薯不能吃,也不要喂牲畜,煮熟也不行;深埋或烧掉
- 防: 用无病种薯育苗;选苗时剪高一点(离床面约3 cm以上剪,不带病根);
     收获和入窖时不碰伤薯皮

储存:
- 入窖前在约30-35°C、湿润条件下放几天"愈伤",让伤口长好(没条件时至少晾几天)
- 窖温保持约10-15°C: 低于约9°C会冷害腐烂,高于约15°C会发芽
- 大量储存不现实时,切片晒成薯干、磨薯粉
```

育苗用的种薯越冬见[留种与育种-土豆和红薯](08-留种与育种.md#土豆和红薯-用薯块繁殖),薯块和其他蔬菜的储存温度见[食物加工与保存-各类蔬菜的储存条件](../07-日常生活技能/01-食物加工与保存.md#各类蔬菜的储存条件)。

## 大豆

### 基本信息

```
类型: 粮食/油料
周期: 100-120天
产量: 2250-3000 kg/ha——良好管理时;粗放种植现实约900-1500 kg/ha
特点:
- 蛋白质丰富
- 可榨油
- 豆科固氮(改良土壤)
```

大豆含约35-40%蛋白质、约20%油,是以粮食为主食时最重要的蛋白质来源。缺肉缺蛋的年头,每人每天吃几十克豆类,能明显减少蛋白质缺乏。

### 种植方法

**播种**:
```
时间: 5-6月(夏大豆)
- 春大豆(北方一年一熟): 5 cm地温稳定在约8-10°C以上,一般4月下旬至5月中旬
- 夏大豆: 麦收后抢墒早播,越早越好
- 大豆对日照长短敏感,不同纬度的品种不能随便换: 
  南方品种拿到北方会贪青晚熟,北方品种拿到南方会过早开花、植株矮小

方法:
- 条播或穴播
- 行距: 40-50 cm
- 株距: 15-20 cm
- 每穴2-3粒,出苗后留1-2株
- 每公顷约20万-30万株;春大豆、肥地、分枝多的品种稀些,夏大豆密些
- 用种量约60-90 kg/ha(视粒大小)

深度: 3-5 cm
- 大豆出苗时要把两片肥大的子叶顶出地面,顶土力弱
- 播深了、播后遇雨土面板结,都会出不了苗;黏土播浅些(约3 cm)
```

**管理**:
```
✓ 苗期中耕除草
✓ 开花结荚期追肥、浇水
✓ 根瘤菌固氮(少施氮肥)
✓ 防治病虫害

- 苗期中耕2-3次,封垄前完成
- 开花到鼓粒(豆粒长大)是需水最多的时期,干旱会大量落花落荚
- 开花期叶色发黄的,可少量追施草木灰和磷肥(如骨粉),氮肥只在明显脱肥时少量补
```

### 根瘤: 大豆为什么不需要多施氮

大豆根上的根瘤里住着根瘤菌,能把空气中的氮固定下来供大豆使用,一季大豆所需的氮大部分来自根瘤,收获后的根茬和落叶还能给下一季作物留下一些氮。

```
检查根瘤(出苗后约3-4周以后):
1. 用铲子连土挖出一株,在水里轻轻抖掉泥土(直接拔会把根瘤扯掉)
2. 主根和上部侧根上应有一粒粒米粒到黄豆大小的瘤
3. 切开: 里面粉红色或红色 → 正在固氮,好
         白色、灰绿色 → 不工作;没有根瘤 → 这块地缺少大豆根瘤菌

为什么不要多施氮:
- 土里氮多,大豆就"偷懒"少长根瘤,固氮能力下降
- 氮多还会让茎叶徒长、倒伏、落花落荚,产量反而低
- 只在瘦地播种时少量施一点起苗肥(如少量腐熟粪肥),帮助苗期过渡

第一次种大豆的生地(从没种过大豆的地):
- 从种过大豆、根瘤长得好的老田取表土,
  和种子拌在一起(土和种子约等量,用少量清水湿润),在阴凉处拌好立即播种
- 根瘤菌怕晒、怕干、怕石灰和草木灰直接接触,拌好后不要晒太阳

根瘤长得好的条件:
✓ 土壤不太酸(酸性土先施石灰改良)
✓ 有足够的磷、钾和钙,草木灰、骨粉有帮助
✓ 土壤通气,不长期积水
```

改良酸性土见[石灰与建筑材料-改良酸性土](../07-日常生活技能/16-石灰与建筑材料.md#改良酸性土),酸碱性测法见[地质矿物与土壤-酸碱性](../08-基础科学知识/06-地质矿物与土壤.md#53-酸碱性)。

```
病虫害和连作:
- 不要连作(重茬): 连种几年后胞囊线虫、根腐病积累,植株矮黄、产量大减
  → 至少隔2-3年再种大豆
- 豆荚螟、食心虫: 幼虫钻进豆荚吃豆粒 → 轮作、收获后翻耕、及时收获
- 蚜虫: 会传播病毒病 → 保护瓢虫,早期发现掐掉虫多的嫩梢
```

**收获**:
```
- 叶片脱落
- 豆荚变黄干燥
- 摇动有响声

晾晒后脱粒储存

- 大豆熟后不及时收会炸荚落粒: 在早晨有露水时收割,豆荚不容易炸开
- 晒干到水分约12%以下;豆类容易生豆象,晒干后密闭储存
- 鲜毛豆(豆荚饱满还是绿色时)可以提前采一部分当菜吃
```

```
⚠️ 大豆必须煮熟煮透才能吃: 生大豆、生豆浆含胰蛋白酶抑制物和皂素,
   会引起恶心、呕吐、腹泻;豆浆要防"假沸",沸腾后再煮几分钟
```

做豆腐和豆浆见[食物加工与保存-豆腐](../07-日常生活技能/01-食物加工与保存.md#豆腐),脱粒和豆类储存见[粮油加工-豆类](../07-日常生活技能/14-粮油加工.md#豆类),豆类在膳食中的作用见[营养与营养缺乏病-蛋白质](../07-日常生活技能/02-营养与营养缺乏病.md#蛋白质-豆类是最重要的植物蛋白)。

## 高粱

### 基本信息

```
周期: 90-130天
产量: 4500-6000 kg/ha——良好管理时;旱薄地粗放种植现实约1500-3000 kg/ha
特点:
✓ 耐旱耐瘠
✓ 适应性强
✓ 可食用、可酿酒、可饲料

为什么耐旱:
- 根系深而密,叶面有蜡质,蒸腾少
- 干旱时能暂停生长"休眠",下雨后恢复,玉米干旱时则会严重减产
- 对盐碱和短时间积水的耐受也比玉米强
→ 在玉米、小麦种不好的旱薄地、盐碱地,高粱是保底作物
```

### 种植

**播种**:
```
- 春夏均可
- 条播或穴播
- 行距50-60 cm
- 株距20-25 cm
- 深度3-5 cm

- 高粱比玉米更喜热: 5 cm地温稳定在约12°C以上再播,低温下种子容易烂
- 种子小,顶土力弱: 土要细碎,播后镇压,墒情差时可播深到约5 cm
- 用种量约10-20 kg/ha(条播),出苗后分次间苗
```

**管理**:
```
✓ 间苗定苗
✓ 中耕除草
✓ 追肥1-2次
✓ 防倒伏
✓ 防治蚜虫

- 3-4叶间苗,5-6叶定苗,每穴留1株
- 苗期生长慢,杂草容易压过幼苗,前期要勤锄
- 追肥: 拔节期一次为主,孕穗期视长势补一次
- 掰掉茎基部长出的分蘖(饲用高粱可保留)
- 高粱蚜: 叶背成片的浅黄色蚜虫,分泌的蜜露让叶面发亮、长黑霉
  → 保护瓢虫;早期掐掉有蚜的底叶带出田外
- 鸟害: 成熟期麻雀成群啄食,留种的穗子套纸袋或网袋;
  深色高粱(单宁多)鸟吃得少,浅色高粱鸟害重
- 黑穗病: 穗子变成一包黑粉 → 拔除烧掉,不留种
```

### 高粱的食用和饲用安全

```
☠️ 幼苗和再生苗有毒(喂牲畜要特别注意):
- 高粱的幼苗、割后重新长出的嫩芽、受旱或受霜打的茎叶,
  含较多氰苷,牛羊大量啃食后会氰化物中毒,很快死亡
- 不要在高粱地里放牧幼苗;饲用的要等植株长高(约60 cm以上)、
  或晒干、青贮后再喂;干旱、霜冻后几天内不要喂
- 成熟的高粱籽粒没有这个问题

单宁:
- 深色(红、褐)高粱含单宁多,味涩,影响蛋白质的消化吸收
- 碾去外皮、浸泡后再煮,能减少单宁;也常用来酿酒、做饲料
- 白色、浅色高粱口感好,适合做口粮,但鸟害重
```

脱壳和食用见[粮油加工-杂粮](../07-日常生活技能/14-粮油加工.md#杂粮)。

## 📝 粮食作物种植要点

### 新手推荐种植顺序

```
1. 土豆/红薯(简单高产,必种!)
2. 玉米(容易,产量稳定)
3. 大豆(改良土壤,蛋白质)
4. 水稻(有水源地区)
5. 小麦(需要经验)

为什么这样排:
- 土豆3-4个月就能挖,不用脱粒、去壳、磨粉,煮熟就能吃 → 最快填饱肚子
- 玉米对整地、灌溉的要求比稻麦低,籽粒晒干就能存
- 大豆补蛋白质,还能给下一季作物留下氮
- 水稻要修水田、育秧,小麦要过冬、要磨面,第一年没有经验容易失败
- 但第一年就要开始准备稻麦的田和种子: 薯类不耐久存、蛋白质少,不能长期只靠它
```

### 产量与面积估算

**产量的现实范围**(kg/ha,单位面积按公顷;1 ha = 10000 m²,1 kg/ha = 0.1 g/m²):

| 作物 | 良好管理(良种、化肥、灌溉) | 低投入(农家肥、自留种、手工) | 折算成能吃的粮食 |
|------|--------------------------|----------------------------|----------------|
| 水稻(稻谷) | 约7500 | 约3000-4500 | 出米率约65-70% |
| 小麦 | 约4500-6000 | 约1500-3000 | 出粉率约75-85% |
| 玉米 | 约7500-9000 | 约2000-4500 | 约90%(去芯脱粒后几乎全可吃) |
| 高粱 | 约4500-6000 | 约1500-3000 | 去皮后约80% |
| 大豆 | 约2250-3000 | 约900-1500 | 约100%(蛋白质来源) |
| 土豆(鲜薯) | 约22500-30000 | 约10000-20000 | 约4.5 kg鲜薯 ≈ 1 kg粮食 |
| 红薯(鲜薯) | 约30000-60000 | 约15000-30000 | 约3.5 kg鲜薯 ≈ 1 kg粮食 |

```
灾后头几年要按"低投入"这一列打算:
- 没有化肥、没有良种、灌溉不足,产量常常只有现代水平的一半或更少
- 新开荒的地、第一次种某种作物的人,第一年产量还会更低
- 一场旱涝、病虫害就可能减产一半以上
```

**由口粮反推面积**:
```
1. 算需要多少粮:
   每人每年约180 kg成品粮(每天约0.5 kg,以粮食为主食时)
   4口之家: 4 × 180 = 约720 kg(两个大人两个小孩略少,重体力劳动时更多)

2. 加上必要的余量:
   + 种子: 约5%(明年要播的种子不能吃)
   + 收获、晾晒、储存损失: 约10%
   + 歉收储备: 至少再加20-30%(一年歉收不至于挨饿)
   → 每年要收获约1000 kg"粮食当量"

3. 用低投入单产除:
   面积(ha) = 需要的粮食(kg) ÷ 单产(kg/ha)
   例: 全种玉米,低投入约3000 kg/ha,折粮约90%
       1000 ÷ (3000 × 0.9) ≈ 0.37 ha ≈ 3700 m²

4. 结论: 一家4口靠低投入种粮自给,大约需要0.3-0.5 ha(3000-5000 m²)粮田,
   另加蔬菜地;多种红薯、一年两熟的地方可以少一些
```

库存够吃多久的算法见[记账、交易与社会分工-算一算够用多久](../07-日常生活技能/13-记账交易与社会分工.md#算一算够用多久)。

### 自给自足配置(1家4口)

**面积约3000-5000 m²(0.3-0.5 ha)粮田,另加蔬菜地**:

**示例一: 北方旱地(一年一熟为主)**

| 作物 | 面积 | 按低投入单产估计 | 折合粮食 |
|------|------|----------------|---------|
| 小麦 | 1200 m² | 约2000 kg/ha → 约240 kg | 约200 kg面粉 |
| 玉米 | 1200 m² | 约3000 kg/ha → 约360 kg | 约320 kg |
| 土豆 | 800 m² | 约15000 kg/ha → 约1200 kg鲜薯 | 约270 kg |
| 高粱或谷子 | 500 m² | 约2000 kg/ha → 约100 kg | 约80 kg |
| 大豆 | 600 m² | 约1200 kg/ha → 约70 kg | 约70 kg(蛋白质) |
| **合计** | **约4300 m²** | | **约940 kg** |

**示例二: 南方水田区**

| 作物 | 面积 | 按低投入单产估计 | 折合粮食 |
|------|------|----------------|---------|
| 水稻(一季) | 1500 m² | 约3500 kg/ha → 约525 kg稻谷 | 约350 kg大米 |
| 红薯 | 800 m² | 约20000 kg/ha → 约1600 kg鲜薯 | 约450 kg |
| 玉米 | 600 m² | 约3000 kg/ha → 约180 kg | 约160 kg |
| 大豆 | 500 m² | 约1200 kg/ha → 约60 kg | 约60 kg(蛋白质) |
| **合计** | **约3400 m²** | | **约1020 kg** |

```
说明:
- 这些是粗略估计,本地条件差别很大;第一年宁可多种30-50%
- 一年两熟能少用地: 华北麦收后接种夏玉米,
  南方稻田冬季种小麦、油菜或绿肥,同一块地多收一季
- 薯类产量高但不耐久放(红薯怕冷、土豆会发芽),
  1000多kg鲜薯要有地窖,或切片晒干;口粮的主体仍应是能存一两年的谷物
- 留出轮作和种绿肥的地,不能年年把地种满同一种作物
- 劳动力: 0.3-0.5 ha粮田手工耕种,全家一年约需100-200个工作日(见时间投入)
- 鸡、猪等牲畜要吃粮,养殖的饲料要另外计算
```

### 轮作方案

```
3年轮作:
年1: 水稻/小麦
年2: 玉米/高粱
年3: 大豆/花生

或:
年1: 薯类
年2: 玉米
年3: 豆类

好处:
✓ 平衡土壤养分
✓ 减少病虫害
✓ 提高产量

常见搭配:
- 豆类之后种玉米、小麦等需氮多的作物,能利用豆茬留下的氮
- 土豆、番茄、茄子、辣椒同属茄科,不要前后接着种
- 小麦前茬避开玉米秸秆多的地(赤霉病病菌在玉米秸秆上过冬)
- 南方水旱轮作(稻—麦、稻—油菜): 淹水和干旱交替,能压低很多病虫和杂草
- 间作: 玉米行间种大豆(例如2行玉米、2-4行大豆交替),
  高矮搭配,大豆固氮,总产量往往比单种高
```

轮作的道理见[生物与医学基础-农业中的生物学](../08-基础科学知识/04-生物与医学基础.md#82-农业中的生物学)。

### 施肥与地力

粮食作物年年从地里拿走养分,只种不养,几年后产量就会越来越低。

```
有机肥(灾后主要靠它):
- 腐熟厩肥、堆肥: 基肥约15000-30000 kg/ha(每平方米约1.5-3 kg)
  一定要腐熟: 生粪会烧根、带病菌和虫卵,还招地下害虫
- 人尿: 稀释5-10倍后追肥,浇在土上不浇叶子;
  一个成年人一年的尿约含氮3-4 kg,够约300-400 m²粮田一季的大部分氮肥需要
- 人粪: 必须长时间储存或高温堆肥后才能用,用于粮食作物、施入土中
- 草木灰(钾): 约75-150 g/m²;碱性强,不要和粪尿、铵态氮肥混放,
  也不要直接接触根瘤菌拌过的种子
- 骨粉(磷): 骨头烧过或蒸煮后砸碎磨粉
- 秸秆: 不要全部烧掉,一部分堆沤或还田,补有机质

绿肥:
- 南方稻田冬季种紫云英,北方可种苕子、草木樨、苜蓿等豆科绿肥
- 盛花期翻压入土,约1-2周后再种下一季

看叶色判断缺什么:
- 叶色变淡黄,老叶先黄 → 缺氮
- 老叶叶尖、叶缘发黄焦枯 → 缺钾
- 苗期叶片暗绿带紫、长得慢 → 缺磷(低温时也常见)
- 酸性土(很多作物长不好、豆类根瘤少)→ 撒石灰改良
```

人粪尿安全利用见[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用),堆肥做法见[动植物培育-土壤改良](README.md#土壤改良),石灰改土见[石灰与建筑材料-改良酸性土](../07-日常生活技能/16-石灰与建筑材料.md#改良酸性土),氮肥的化学原理见[化学-氮肥和合成氨](../08-基础科学知识/03-化学.md#410-氮肥和合成氨),保持水土见[地质矿物与土壤-保护土壤](../08-基础科学知识/06-地质矿物与土壤.md#55-保护土壤)。

### 病虫害防治原则

```
先农业和物理防治,化学药剂最后:
1. 农业防治: 本地抗病品种、轮作、适期播种、合理密植、
   平衡施肥(不偏施氮肥)、清除病残体和秸秆、开沟排水
2. 物理防治: 灯光诱杀、人工捕捉、拔除病株、收获后翻耕晒垡
3. 生物防治: 保护青蛙、蜘蛛、瓢虫、鸟类;稻田养鸭养鱼;鸡鸭啄虫

不得不用农药时:
✓ 只用标签完整、认得清的农药,严格按标签上的作物、用量和方法
✓ 遵守标签上的"安全间隔期": 最后一次施药到收获必须隔够这些天
✓ 不使用国家已经禁用的高毒农药(如甲胺磷、对硫磷"1605"、六六六、滴滴涕等),
  也不用来路不明、没有标签的药
✓ 不在水井、水源旁配药和洗药械;空药瓶不能装食物和水,深埋处理
✓ 孕妇、哺乳期妇女、儿童、老人不参与配药和喷药
✓ 出现头晕、恶心、多汗、视物模糊 → 立即停止、离开现场、冲洗、拨打120就医
```

喷药防护和农药中毒急救见[中毒-喷洒农药时的防护](../01-日常疾病和伤害/12-中毒.md#喷洒农药时的防护)和[农药和鼠药中毒](../01-日常疾病和伤害/12-中毒.md#农药和鼠药中毒)。

### 种子保存

```
重要!必须留种!

选种:
✓ 选健壮植株
✓ 饱满籽粒
✓ 无病虫害

处理:
✓ 充分干燥
✓ 密封保存
✓ 低温阴凉
✓ 防虫防鼠

注意:
- 杂交种(F1)后代会分离,不适合留种
- 传统品种(传家宝)可留种
- 建议储备传统品种种子!
- 种子粮和口粮分开放,标明"种子",饿了也不能吃
- 至少多留一季的种子,防止播后遇灾需要补种
```

各种作物的留种方法、隔离距离、发芽率测试见[留种与育种](08-留种与育种.md);脱粒、扬场、碾米磨面见[粮油加工](../07-日常生活技能/14-粮油加工.md)。

### 储存要点

```
粮食长期储存:
✓ 充分干燥(水分<13%)
✓ 密封容器(防潮防虫)
✓ 阴凉通风处
✓ 避光
✓ 定期检查翻晒

各类粮食的安全水分:
- 稻谷 <13%,小麦 <12%,玉米 <14%,大豆约12%以下

延长储存:
- 真空或充氮包装
- 冷藏
- 混入干燥剂

注意:
- 糙米比白米更营养,但储存期短
- 全谷物营养更好,但需防虫
- 可分批储存,轮换使用
- 带壳稻谷、整粒麦子比米、面耐放: 吃多少加工多少
- 粮仓离地离墙,每月手插进粮堆检查有无发热、发潮、霉味
- ☠️ 发霉结块的粮食整批丢弃,不能吃,也不能喂牲畜
- ☠️ 不要自己用磷化铝熏蒸片熏粮(释放剧毒气体)
```

晒干的判断、密闭缺氧和低温防虫等具体做法见[粮油加工-干燥到安全水分](../07-日常生活技能/14-粮油加工.md#干燥到安全水分)和[储粮-防霉和防虫](../07-日常生活技能/14-粮油加工.md#储粮-防霉和防虫)。

### 时间投入

```
每1000 m²(0.1 ha)粮田(手工):
- 整地: 7-15天
- 播种/移栽: 3-7天
- 日常管理: 每周2-3小时
- 收获: 7-15天
- 加工: 5-10天

总计约30-45工作日/年

- 水稻(育秧、插秧、管水)最费工,玉米、高粱、薯类较省工
- 有耕牛时整地时间可以缩短到原来的几分之一
- 农忙集中在播种和收获季节,要全家甚至几家人换工一起干
- 一家4口0.3-0.5 ha粮田,全年约需100-200个工作日
```
