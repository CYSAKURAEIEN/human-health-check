# 家禽养殖指南

家禽是灾后最容易恢复的肉蛋来源: 鸡从出壳到开产只要5-6个月,不需要大面积草场,还能吃掉厨余和虫子、把粪便变成菜地的肥料。但家禽也是禽流感、沙门氏菌等疾病的来源,**养得好靠的是卫生和防疫,而不是多喂料**。

> 本章的兽药、疫苗内容只讲一般原则。用药、免疫程序请按产品说明书并咨询当地畜牧兽医站;出现成批死亡要上报,不要自己处理了事。

## 鸡的养殖

### 为什么养鸡?

```
优点:
✓ 鸡蛋(蛋白质)
✓ 鸡肉
✓ 鸡粪(肥料)
✓ 控制害虫
✓ 相对容易
✓ 占地小

投入:
- 初期: 鸡舍、围栏、设备
- 日常: 饲料、水、时间
```

**先算饲料账**: 一只产蛋鸡每天吃100-120 g料,一年约40 kg。养15只鸡一年要约600 kg饲料,相当于3个成年人一年的口粮(每人每天约0.5 kg粮食)。粮食紧张时,鸡群的规模要由**能找到多少厨余、青草、虫子和次等粮**决定,而不是由想吃多少蛋决定。

```
粗略估算:
- 土鸡年产蛋约120-180个,高产蛋鸡约250-300个(第一年)
- 每人每天想吃1个蛋,大约需要2-3只产蛋鸡
- 一只产蛋鸡每天排鲜粪约0.1 kg,一年约35 kg
```

### 品种选择

**蛋鸡**:
- 来航鸡: 高产蛋(280-300个/年)
- 褐壳蛋鸡: 适应性强

**肉鸡**:
- 白羽肉鸡: 生长快(45天出栏)
- 黄羽肉鸡: 肉质好

**蛋肉兼用**:
- 芦花鸡、三黄鸡: 综合性能好
- 土鸡: 抗病力强,适合散养

**新手推荐**: 本地土鸡品种

**怎样选**:

| 类型 | 优点 | 缺点 | 适合 |
|------|------|------|------|
| 商品蛋鸡(来航、褐壳) | 产蛋多,吃料省 | 多为杂交配套系,后代性状分离,基本不抱窝;对饲料质量要求高 | 有稳定饲料来源 |
| 白羽肉鸡 | 6-7周就能宰,料肉比低 | 必须吃高蛋白全价料;长大后腿病、猝死多,很难留作种鸡 | 短期快速出肉 |
| 黄羽肉鸡、土鸡 | 耐粗饲、会觅食、抗病、母鸡会抱窝 | 产蛋少,长得慢(3-5个月出栏) | **长期自给、自己繁殖** |

```
灾后/长期自给的选择原则:
✓ 首选本地土鸡或兼用品种: 能自己孵小鸡,不依赖孵化场和全价饲料
✓ 留一部分会抱窝的母鸡(土鸡、芦花鸡、狼山鸡等)做"活孵化器"
✓ 公母比例约1:8-12(只要蛋不要小鸡,可以不养公鸡,母鸡照样产蛋)
✓ 每年从不同来源换进公鸡,或保持几十只以上的群体,避免近亲繁殖
  (近亲繁殖会让孵化率下降、畸形增多,见下方链接)

选购小鸡/青年鸡:
✓ 精神活泼,叫声清脆,眼亮有神
✓ 脐部愈合好、干燥,肛门周围干净不糊粪
✓ 脚胫有光泽,站立稳
✓ 从有防疫记录的种鸡场买,问清楚打过哪些疫苗(马立克氏病疫苗一般在孵化场出壳当天注射)
❌ 不买精神萎靡、扎堆发抖、肛门糊白粪的
```

近亲繁殖见[生物与医学基础-近亲繁殖的危害](../08-基础科学知识/04-生物与医学基础.md#63-近亲繁殖的危害),选种思路见[留种与育种-选育](08-留种与育种.md#选育-让品种一年比一年好)。

### 鸡舍建设

**选址**:
```
✓ 地势高燥
✓ 通风向阳
✓ 排水良好
✓ 远离居住区(气味)
✓ 便于管理

补充:
✓ 离水井、水源至少30 m,并在水源的下坡方向(同厕所、畜圈)
✓ 坐北朝南,冬季背风(北方北墙少开窗)
✓ 远离野鸟聚集的水塘、湿地(野鸭等是禽流感的主要来源)
❌ 不建在低洼处、山沟口(积水、洪水、冷空气下沉)
```

**规格**:
```
面积:
- 平养: 6-8只/m²(鸡舍内)
- 散养: 每只需1-2 m²(室外活动区)

高度:
- 2-2.5 m

结构:
✓ 墙壁:砖、木板均可
✓ 地面:水泥或土(铺稻草)
✓ 屋顶:防雨
✓ 通风窗
✓ 门(防兽)

内部:
✓ 栖架(晚上栖息,30 cm高)
✓ 产蛋箱(每4-5只一个,30x30x30 cm)
✓ 饮水器
✓ 料槽
✓ 垫料(稻草、木屑)
```

**面积细算**:

| 项目 | 标准 | 说明 |
|------|------|------|
| 舍内面积 | 轻型蛋鸡6-8只/m²;土鸡、兼用鸡4-6只/m² | 白天能出运动场时可以按上限;整天关在舍内取下限 |
| 栖架长度 | 每只15-20 cm(大体型20-25 cm) | 冬天挤得紧些,夏天要宽松 |
| 料槽长度 | 每只约8-10 cm(两面采食时按一半) | 槽边与鸡背同高,减少扒料浪费 |
| 饮水 | 每只每天约0.2-0.3 L,热天加倍 | 约为吃料重量的2倍 |
| 产蛋箱 | 每4-5只一个 | 箱底离地40-60 cm,放在暗处 |

**栖架**:
```
✓ 用直径4-5 cm的圆木或棱角磨圆的方木(太细抓不稳,会压伤胸骨)
✓ 离地30-60 cm(大体型鸡放低,防跳下时伤腿);多根栖杆时阶梯排列,水平间距30-35 cm
✓ 所有栖杆在同一高度更好(鸡会争抢最高处,打架)
✓ 栖架下方设接粪板或粪坑,每周清理 — 鸡粪一大半是夜里排的
✓ 栖杆两端做成可拆的,方便刷洗、检查鸡螨(螨虫白天藏在栖杆缝里)
```

**产蛋箱**:
```
✓ 30x30x30 cm,前面有10 cm左右的挡板挡住垫草
✓ 内铺干净稻草、木屑,脏了就换(蛋壳沾粪是细菌进入蛋内的主要途径)
✓ 位置要暗、安静;放在栖架下方或比栖架低,免得鸡在里面过夜、拉粪
✓ 新开产的鸡可以在箱里放一个假蛋(石头、木蛋)引导,减少窝外蛋
```

**通风**:
```
原则: 换气充分,但鸡身高度不能有穿堂风

✓ 窗户和通风口总面积约占地面的1/10以上,夏天全开
✓ 屋檐下或屋脊处留排气口(热空气和氨气往上走),进风口在下方
✓ 冬天关下面的窗,只留上面的排气口
✓ 判断: 人进鸡舍闻到明显氨臭、眼睛发辣,说明氨气已经伤鸡的呼吸道,
  要加强通风、换垫料
✓ 垫料保持松散干燥(手抓一把,松开后能散开);结块潮湿是球虫病的温床
```

**防鼠、防黄鼠狼**:

黄鼠狼、猫、狐狸、蛇、鹰和老鼠是家禽最大的损失来源之一。黄鼠狼能钻过约3-4 cm的缝隙,一夜可能咬死多只鸡;老鼠偷料、偷蛋、咬小鸡,还传播沙门氏菌。

```
✓ 夜间必须关进封闭的鸡舍,天黑前点数、关门、上插销(黄鼠狼会扒开简单门钩)
✓ 舍内的窗、通风口钉孔径约1-1.5 cm的金属网(电焊网);
  普通六角铁丝网只能防鸡外逃,防不住黄鼠狼和老鼠
✓ 防打洞: 墙基向下埋网30-45 cm,或在墙外地面平铺50 cm宽的网再盖土
✓ 地面最好硬化(水泥、三合土),或在土地面下埋网
✓ 饲料存放在有盖的铁桶、缸里;晚上收走剩料,不在地上撒料过夜
✓ 鸡舍周围割净杂草、清除杂物堆(老鼠和蛇的藏身处)
✓ 运动场上方有鹰害时拉网,或留灌木、遮棚供鸡躲藏
⚠️ 用鼠药时放在鸡够不到的毒饵站里,及时捡走死鼠(鸡会吃毒饵和死老鼠)
```

**运动场**:
```
- 面积: 鸡舍2-3倍
- 围网(防逃、防兽)
- 遮阴(树、棚)

补充:
✓ 网高约1.8-2 m;轻型鸡会飞,可剪掉一侧翅膀的主翼羽(剪羽毛末端,不剪到血管)
✓ 留一块干燥松土或草木灰坑给鸡沙浴 — 这是鸡自己除虱除螨的办法
✓ 运动场分成2-3块轮换使用,让地面休养、长草,减少寄生虫卵积累
```

土地面硬化见[石灰与建筑材料-三合土和灰土](../07-日常生活技能/16-石灰与建筑材料.md#三合土和灰土),防鼠的一般做法见[卫生设施-消灭苍蝇和老鼠](../07-日常生活技能/03-卫生设施.md#消灭苍蝇和老鼠)。

### 育雏(0-6周)

**设备**:
```
- 育雏箱/笼
- 保温灯(冬季)
- 温度计

补充:
- 没有电: 用火炕、火墙,或热水瓶(灌热水用布包好)放在育雏箱一角,每隔几小时换热水
- 育雏箱四角用硬纸板围成弧形,防止雏鸡挤在死角压死
- 用母鸡带小鸡最省事: 抱窝母鸡自己负责保温,只需防兽、供料供水
```

**温度**:
```
关键!
- 第1周: 32-35°C
- 第2周: 29-32°C
- 第3周: 26-29°C
- 之后每周降2-3°C
- 至21°C(约6周)

判断:
- 温度合适:小鸡分散,活泼
- 太冷:扎堆,叫声
- 太热:远离热源,张嘴
```

```
补充:
✓ 温度计挂在雏鸡背部高度(离垫料约5 cm)、热源边缘处测,不是测屋顶
✓ 热源只占育雏区一侧,让雏鸡能在热和凉之间自己选
✓ 看鸡比看温度计更可靠: 夜里也要看一次,扎堆就是冷了
✓ 只挤向一侧(不是围着热源) → 那一侧有贼风,要挡住
✓ 降温要逐步,天气突变(寒潮)时暂缓降温
✓ 6周脱温前,先白天停热源、夜里保留,过渡几天
```

**密度**:

| 日龄 | 平养密度 |
|------|----------|
| 1-2周 | 30-40只/m² |
| 3-4周 | 20-25只/m² |
| 5-6周 | 10-15只/m² |

太挤会导致生长不齐、啄羽、球虫病暴发;随长随扩大育雏区。

**饲喂**:
```
0-6周:
- 雏鸡料(高蛋白)
- 随时供应
- 清洁饮水
- 每天清理

注意:
✓ 前3天温水(防应激)
✓ 逐渐过渡饲料
✓ 保持清洁
```

**先饮水,后开食**:
```
1. 雏鸡到家先休息片刻,先给水: 温水约20-25°C(与室温相近,不要烫)
   第一天水里可加约5%的白糖或红糖,帮助恢复体力
2. 不会喝的,轻轻把鸡嘴在水里点一下,其他鸡会跟着学
3. 大约2-3小时后、多数雏鸡喝过水再开食:
   把雏鸡料(或碾碎的玉米、小米,煮熟后晾到不粘手的碎蛋黄也可以)
   撒在报纸、浅盘上,让它们容易啄到
4. 头几天少喂勤添,每天6-8次;之后改用料槽

✓ 饮水器要浅,或在水盘里放干净的小石子 — 防止雏鸡掉进去淹死、湿身受凉
✓ 雏鸡料粗蛋白约19-21%;只喂碎米、玉米会因蛋白不足长不大、啄羽
✓ 判断吃饱: 开食后几小时摸嗉囊(颈下),多数鸡应是软而饱满的
```

**管理**:
```
✓ 观察精神状态
✓ 定期清洁
✓ 通风(但保温)
✓ 防挤压
✓ 疫苗接种(咨询兽医)

补充:
✓ 糊肛(肛门被干粪堵住)时用温水泡软,轻轻擦掉;多是温度不当或白痢
✓ 垫料潮湿处及时更换,饮水器下方垫高或放在网上
✓ 防猫、鼠、蛇 — 雏鸡最容易被叼走
✓ 出现啄羽、啄肛: 光线调暗(换红光)、降低密度、检查料中蛋白和盐,被啄伤的鸡挑出单养
```

### 成鸡饲养(6周后)

**饲料**:
```
商品饲料:
- 蛋鸡料(产蛋鸡)
- 肉鸡料(肉鸡)

自配饲料:
- 玉米(60-70%)
- 豆粕/饼(15-20%)
- 麸皮(5-10%)
- 贝壳粉/骨粉(3-5%,补钙)
- 盐(0.3%)
- 青饲料(菜叶、草,10-20%)

添加:
- 沙砾(助消化)
```

**配比原则**:

| 阶段 | 粗蛋白 | 钙 | 说明 |
|------|--------|----|------|
| 雏鸡(0-6周) | 19-21% | 约1% | 蛋白不足是长不大的首要原因 |
| 育成鸡(7-18周) | 15-16% | 约1% | 不要喂产蛋料: 钙太高伤肾 |
| 产蛋鸡 | 16-17% | 约3.5-4% | 上面的自配料钙不够,要另外补贝壳 |
| 肉鸡 | 前期21-23%,后期18-19% | 约1% | 白羽肉鸡对饲料要求最高 |

```
自配料的要点:
✓ 能量(玉米、碎米、高粱、薯干)约占六七成,蛋白料(豆饼、花生饼、鱼粉、
  虫子)约两成,其余是麸皮、矿物质
✓ 生黄豆不能直接喂(含抗营养因子,吃了长不好),要炒熟或煮熟;
  市售豆粕已经过加热处理
✓ 棉籽饼(含棉酚)、菜籽饼(含硫苷)有毒性,用量不超过5%,产蛋鸡最好不用
✓ 盐: 0.3%左右即可,多了会拉稀、中毒;有咸鱼、剩菜时不再另加盐
✓ 沙砾: 粒径约2-4 mm(雏鸡更细),单独放一槽,散养鸡一般自己能找到
✓ 换料要在一周内逐渐掺换,突然换料会减产、拉稀
❌ 不喂发霉的玉米、花生、饼粕 — 黄曲霉毒素对家禽(尤其雏鸭)毒性极强
```

**补钙(产蛋鸡最重要)**:
```
一个蛋壳约含2 g钙,产蛋鸡每天需要的钙远多于育成鸡。
✓ 开产前2周起,另放一槽贝壳碎粒(或石灰石碎粒),让鸡自由采食,
  鸡会按自己的需要吃
✓ 蛋壳回收: 洗净、在灶里烤干(或煮几分钟)后压碎再喂;
  一定要压碎到看不出蛋壳形状,否则鸡会学会啄食鸡蛋
✓ 骨头: 煮过、烧过后砸碎成骨粉,同时补钙和磷
❌ 蛋壳变薄、软壳蛋、破蛋增多 → 首先怀疑缺钙,其次是高温、老龄和疾病
```

**用厨余和虫子补充**:
```
厨余可以喂(约占日粮的三分之一以内,多了蛋白和能量不够):
✓ 菜叶、瓜果皮、剩饭、米糠、豆渣、酒糟(少量)
✓ 肉类剩菜要煮熟,少量喂
❌ 不喂: 发霉、发酸变质的食物;太咸的剩菜;发芽变绿的土豆皮;生的干豆类;
  牛油果;巧克力;生禽肉和禽类内脏(会在鸡群里传播疫病)

虫子(最好的蛋白补充):
✓ 散养鸡在运动场、果园、收割后的田里自己找虫、草籽
✓ 鸡跟在翻地、割草后面,能吃到大量虫子和虫卵
✓ 蚯蚓: 用烂菜叶、牛粪、湿秸秆堆一个蚯蚓床,保持湿润、遮阴,定期挖一部分喂
✓ 黄粉虫: 木箱里铺麸皮,放菜叶保湿,一两个月就能繁殖起来
✓ 黑水虻幼虫: 能吃厨余和粪便,老熟幼虫会自己爬出,适合规模稍大的家庭
✓ 夜里挂一盏灯引虫(灯下放一盆水或让鸡在下面),夏天能诱到不少飞虫
⚠️ 喂鸡的虫子不要来自刚打过农药的地块
```

**饲喂**:
```
- 定时定量
- 蛋鸡: 每天100-120 g
- 肉鸡: 自由采食
- 清洁饮水(随时)

补充:
✓ 散养鸡早上少喂(促使出去觅食),傍晚喂饱(引导回舍,也方便点数)
✓ 判断喂得够不够: 产蛋鸡体重稳定、羽毛光亮;产蛋突然下降、鸡变瘦就要加料
✓ 冬天多喂一些能量料(玉米),热天早晚凉快时喂
✓ 饮水器每天刷洗;断水比断料危害大得多,夏天断水半天就会大减产
```

**日常管理**:
```
每日:
✓ 观察鸡群(精神、食欲、粪便)
✓ 喂料、加水
✓ 捡蛋(2-3次)
✓ 清理粪便(或定期)

每周:
✓ 清洁饮水器、料槽
✓ 更换垫料(部分)
✓ 检查设备

定期:
✓ 全面清洁消毒
✓ 驱虫
✓ 疫苗
```

**看粪便判断健康**:

| 粪便 | 可能原因 |
|------|----------|
| 成形,褐色,顶端带少量白色尿酸盐 | 正常 |
| 偶尔的糊状褐色"盲肠粪" | 正常(大约每天一次) |
| 带血、橘红色或胡萝卜样 | 球虫病 |
| 黄绿色、稀 | 新城疫、禽流感等严重疫病(同时看精神和死亡) |
| 白色糊状,粘肛门(雏鸡) | 白痢 |
| 水样 | 喂太多青料、饮水或天气太热;也可能是疾病 |

**极端天气**:
```
热(30°C以上): 张嘴喘气、翅膀张开 → 遮阴、加强通风、给凉水、在凉快时喂料;
  屋顶加草帘或刷白灰反光
冷: 鸡冠、肉垂冻伤发黑 → 堵住贼风但保留上方通风;
  冬天鸡舍潮湿比寒冷更伤鸡;冠大的品种可在冠上抹凡士林或油脂
```

**健康检查**:
```
每月抓几只看看:
✓ 翻开肛门周围、翅膀下的羽毛: 有没有虱子、螨虫(细小红点或灰白小虫)
✓ 摸胸骨两侧: 肌肉饱满还是像刀背一样突出(太瘦)
✓ 看脚: 鳞片翘起、结痂(脚螨);脚底肿胀发炎(趾瘤,多因栖杆粗糙、地面太硬)
发现虱螨: 保证沙浴坑(干土加草木灰),栖架和缝隙用开水烫或石灰乳刷;
  严重时用兽用杀虫药,按标签用法和休药期
```

### 产蛋管理

**开产**:
- 5-6月龄开始产蛋
- 逐渐增加到高峰(8-10月龄)
- 高产期1年左右

```
判断一只母鸡是否在产蛋:
✓ 冠和肉垂红润、饱满、温暖
✓ 肛门大、湿润、呈椭圆形
✓ 两根耻骨(肛门下方两侧的骨头尖)之间能放进2-3指,耻骨末端与胸骨之间能放进3-4指
✗ 冠小发白发干、肛门小而干、耻骨间只能放进1指 → 不在产蛋(停产、换羽或该淘汰)
```

**促进产蛋**:
```
✓ 营养充足(蛋白、钙)
✓ 光照: 14-16小时/天
  - 自然光不足,补充人工光
  - 早晚开灯
✓ 安静环境
✓ 适宜温度(13-23°C)
✓ 充足饮水
```

**光照管理**:

光照时长是母鸡"判断季节"的信号: 白天变长就产蛋,变短就停产、换羽。所以不仅要够长,还要**稳定、只增不减**。

```
✓ 育成期(约18周龄前)不要延长光照,用自然光或固定的短光照,
  否则开产太早,蛋小、易脱肛
✓ 开产后逐步加光,每周延长15-30分钟,直到每天14-16小时,然后保持
✓ 补光放在早上(天亮前开灯),傍晚让天自然黑下来,鸡能自己上架;
  如果傍晚补光,关灯时要先调暗,或留一盏小灯,免得鸡在黑暗里找不到栖架
✓ 光不需要很亮: 能看清料槽和水的程度即可(大约每10 m²一盏小功率LED灯);
  太亮容易引起啄癖
❌ 产蛋期突然缩短光照(停电、忘了开灯持续多日) → 产蛋大幅下降,甚至诱发换羽
⚠️ 没有电时不强求补光,接受冬季减产;用煤油灯、蜡烛在鸡舍补光有火灾风险
```

**换羽**:
```
母鸡每年秋季自然换羽一次: 先头颈、后身体、最后翅膀,一般持续2-4个月,
换羽期间大多停产。这是正常现象,不是病。

✓ 换羽期提高饲料蛋白(多喂虫子、豆饼、鱼粉),羽毛主要由蛋白质构成
✓ 换羽期少抓鸡,新长的羽毛根部有血管,碰伤会出血
✓ 换羽又快又早(1-2个月完成)的母鸡通常是好鸡,换羽拖得很长的可考虑淘汰
❌ 不建议用断料、断水的方法"强制换羽": 伤鸡、死亡率高,而且不人道
✓ 除了秋季,应激(断水、断料、受惊、光照骤减)也会引起换羽和停产
```

**抱窝**:
```
土鸡、兼用鸡常会抱窝(就巢): 赖在产蛋箱里不出来、炸毛、咕咕叫、啄人,停止产蛋。
- 想孵小鸡: 这正是机会,见下方"孵化"
- 不想孵: 及早处理恢复产蛋更快 —
  把它移到底部通风的笼子(铁丝网底)或明亮凉爽处,单独喂料喂水,3-5天一般就醒抱
❌ 不要用浸冷水、饿饭等粗暴方法
```

**常见产蛋问题**:

| 问题 | 原因 | 处理 |
|------|------|------|
| 窝外蛋 | 产蛋箱不够、太亮、开产时没引导 | 加产蛋箱、放假蛋;开产期上午晚放出运动场 |
| 鸡吃蛋 | 破蛋诱发、缺钙缺蛋白、太挤、无聊 | 勤捡蛋、补钙补蛋白、蛋壳压碎再喂;顽固的淘汰 |
| 软壳、薄壳 | 缺钙、缺维生素D(长期不见阳光)、高温、老龄、疾病 | 补贝壳、多晒太阳、防暑 |
| 蛋内血斑、肉斑 | 偶发属正常;频繁时与受惊、维生素A不足有关 | 照蛋挑出;血斑蛋可以吃 |
| 脱肛 | 开产过早、蛋太大、太肥 | 隔离,清洗推回,严重的淘汰;控制育成期光照 |

**捡蛋**:
```
- 每天2-3次
- 及时捡(防啄破、弄脏)
- 保存: 钝端向上,阴凉处,10-15°C
```

```
补充:
✓ 蛋壳表面有一层天然保护膜。干净的蛋不要洗,沾粪的蛋用干布或砂纸擦掉
✓ 必须水洗时用比蛋温热的水(冷水会让蛋内收缩,把脏东西吸进壳内),洗后尽快吃掉
✓ 有裂纹的蛋当天煮熟吃,不要保存、不要生吃
✓ 新鲜度判断: 放入清水中,平躺沉底是新鲜蛋;一头翘起是放了一段时间;浮起来不要吃
✓ 长期保存可用石灰水浸泡(见下方链接)
⚠️ 鸡蛋可能带沙门氏菌: 儿童、孕妇、老人、病人不吃生蛋和溏心蛋;处理生蛋后洗手
```

石灰水存蛋见[石灰与建筑材料-其他用途](../07-日常生活技能/16-石灰与建筑材料.md#其他用途),食物中毒的识别见[常见疾病-食物中毒](../01-日常疾病和伤害/01-常见疾病.md#食物中毒)。

### 孵化

自己孵小鸡,鸡群才能不靠外人延续下去。种蛋来自有公鸡的鸡群。

**选种蛋**:
```
✓ 来自健康、产蛋好、无白痢的种鸡群;公母比例约1:8-12
✓ 蛋形正常,大小中等(鸡蛋约50-65 g),壳厚均匀、无裂纹、干净
✓ 保存不超过7天(越久孵化率越低),保存在约13-16°C的阴凉处,小头朝下
❌ 不用双黄蛋、畸形蛋、沙壳蛋、脏蛋、洗过的蛋
```

**母鸡抱窝孵化(最简单、成功率高)**:
```
1. 选抱性稳定的母鸡(连续抱窝2-3天不离窝的再给蛋)
2. 窝放在安静、半暗、防兽、离地的地方,铺干草;
   窝周围和母鸡身上先检查并处理虱螨(母鸡被咬得坐不住会弃窝)
3. 每只母鸡给10-15个蛋(以母鸡能完全盖住为准,大型母鸡多些,小型少些)
4. 种蛋用铅笔标记,每天检查,把其他母鸡后来下进窝里的蛋拿走(会孵化不同步)
5. 窝边放水和料;母鸡一般每天离窝一次吃喝排便约10-20分钟,不要赶它
6. 母鸡自己翻蛋、控温控湿,不需要人帮忙;天很干燥时可在窝下垫湿土
7. 第21天前后出壳;出壳后让母鸡带1-2天再出窝,给碎料和浅水
✓ 母鸡也能孵鸭蛋(约28天),中途可在蛋上洒一点温水
```

**简易孵化(无母鸡时)**:

| 参数 | 鸡 | 鸭 | 鹅 |
|------|----|----|----|
| 孵化期 | 21天 | 28天(番鸭约35天) | 约30-31天 |
| 温度(有风扇,箱内温度均匀) | 37.5-37.8°C | 37.5°C左右 | 37.3-37.5°C |
| 温度(无风扇,测蛋顶高度) | 38.3-38.9°C | 同左略低 | 同左略低 |
| 相对湿度(孵化期) | 50-55% | 55-60% | 55-60% |
| 相对湿度(出雏前3天) | 65-75% | 70-75% | 70-75% |
| 停止翻蛋 | 第18天 | 第25天 | 第27-28天 |

```
1. 箱体: 泡沫箱、木箱均可,内放热源(灯泡、热水袋/热水瓶、炕热)、
   温度计(放在蛋的高度)、一盘水(调湿度)
2. 先空箱运行1-2天,温度稳定后再放蛋
3. 翻蛋: 每天至少3次(最好5次,奇数次可避免每晚同一面朝下),每次转动约180°;
   蛋上一面画"×"一面画"○",翻后检查是否都翻到了
   翻蛋防止胚胎粘在壳膜上 — 不翻蛋是简易孵化失败的常见原因
4. 照蛋: 在暗处用手电从蛋的大头往里照
   - 第7天左右: 能看到蛛网状血管和黑点(胚胎) → 受精正常;
     清亮无物 → 无精蛋,取出;有血环 → 死胚,取出(放着会腐败甚至爆裂)
   - 第18天左右: 蛋内大部分黑暗,气室边缘清楚 → 正常
5. 停止翻蛋后提高湿度,出雏期间尽量不开箱(湿度一跑,小鸡容易粘在壳里)
6. 出壳: 啄壳到出壳一般要几小时到一天,不要急着帮剥;
   超过24小时还出不来、壳膜发干时,才小心剥开一小块,看到出血立即停止
7. 绒毛干了再移入育雏箱;出壳后约24-48小时内不吃不喝问题不大(靠体内卵黄)

鸭蛋、鹅蛋: 蛋大、脂肪多,孵化中后期自身发热多,
  从约第10-15天起每天晾蛋一次(开箱让蛋温降到手摸微温)并喷少许温水
```

```
常见失败原因:
- 温度偏高: 提前出壳、畸形、腹部大而肚脐愈合不好
- 温度偏低: 推迟出壳、雏鸡软弱
- 湿度太低: 雏鸡粘壳、出不来
- 湿度太高: 雏鸡大肚子、身上湿黏
- 温度短时(几小时)下降比短时升高危险小 — 停电时盖上被子保温,不要慌着开箱
```

### 疾病预防

**预防为主**:
```
✓ 清洁卫生
✓ 通风良好
✓ 密度适当
✓ 营养均衡
✓ 疫苗接种
✓ 定期消毒
✓ 隔离病鸡
✓ 观察异常
```

**生物安全: 不让病进门**:
```
✓ 新买的鸡单独隔离饲养至少2-4周,无异常再合群;隔离区离原鸡群越远越好
✓ 鸡、鸭、鹅最好分开饲养: 鸭、鹅感染禽流感可能不发病,却会把病毒传给鸡
✓ 料槽、水源加盖或放在舍内,不让野鸟、老鼠接触;不用野鸟常去的池塘水饮鸡
✓ 进鸡舍换专用鞋或踩消毒垫(石灰乳、草木灰水浸湿的草垫);
  不去别人的鸡场,去过家禽市场、病鸡场的人和工具不进自家鸡舍
✓ 肉鸡尽量"全进全出": 一批出栏后彻底清扫消毒,空舍1-2周再进下一批
✓ 每批、每次免疫和用药写进记录本
```

**清洁消毒**:
```
1. 先清: 清出全部粪便、垫料(拿去堆肥),刮净墙角、栖架、产蛋箱
2. 再洗: 用水刷洗;有条件用热碱水
3. 后消毒: 石灰乳(熟石灰1 kg加水4-9 L)刷墙面地面;
   或用含氯消毒液按说明书稀释喷洒;栖架缝隙可用开水烫
4. 晾干通风后再放鸡
⚠️ 先清扫再消毒 — 粪便厚厚一层时,任何消毒剂都难起作用
⚠️ 生石灰遇水剧烈放热,溅入眼睛先擦去粉末再大量清水冲洗
```

石灰乳的配制见[石灰与建筑材料-畜圈、厕所消毒](../07-日常生活技能/16-石灰与建筑材料.md#畜圈厕所消毒),含氯消毒液的配制和安全事项见[传染病家庭防控-家用消毒液的配制](../01-日常疾病和伤害/15-传染病家庭防控.md#家用消毒液的配制)。

**常见病**:
```
鸡瘟(新城疫):
- 疫苗预防!
- 症状: 精神差,呼吸困难,绿便,死亡率高

球虫病:
- 症状: 血便,消瘦
- 预防: 保持干燥,药物预防

白痢:
- 雏鸡常见
- 症状: 白色粪便
- 保温,抗菌药

⚠️ 疾病严重时咨询兽医!
```

| 疾病 | 主要表现 | 预防 | 发病后 |
|------|----------|------|--------|
| 新城疫(鸡瘟) | 各日龄都可发病;精神沉郁、呼吸困难、嗉囊积液、黄绿色稀粪;后期扭头、转圈、瘫痪;死亡率高 | 疫苗是唯一可靠办法,按程序反复免疫 | 无特效药;隔离、报告兽医站,对未发病鸡紧急免疫 |
| 禽流感(高致病性) | 突然大批死亡;头脸肿、冠和肉垂发紫、腿鳞出血;产蛋骤停 | 我国对高致病性禽流感实行强制免疫;防野鸟、鸡鸭分养 | **不得自行治疗或出售**,立即上报当地畜牧兽医部门,按要求扑杀和无害化处理 |
| 球虫病 | 多见于3-6周龄和潮湿季节;血便、闭眼缩颈、羽毛松乱、消瘦 | 垫料干燥、料槽水槽垫高防粪污;雏鸡料中加抗球虫药或接种球虫疫苗 | 抗球虫药按说明书用,同时更换全部湿垫料 |
| 鸡白痢 | 2-3周内雏鸡白色糊状粪、粘肛、怕冷扎堆;可经种蛋传给下一代 | 从无白痢种鸡群引种;育雏保温、勤消毒 | 保温;按兽医指导用抗菌药;耐过的鸡可能带菌,不留作种鸡 |
| 马立克氏病 | 2-5月龄起消瘦、一腿伸前一腿伸后(劈叉)、瘫痪、眼睛灰白 | 出壳当天注射疫苗(之后接种无效) | 无治疗价值,淘汰 |
| 传染性法氏囊病 | 3-6周龄多发;突然精神沉郁、白色水样稀粪、啄自己肛门 | 疫苗 | 无特效药;注意保温、供水 |
| 寄生虫(蛔虫、虱螨) | 消瘦、贫血、产蛋下降;粪中可见虫 | 运动场轮换、沙浴、清洁栖架 | 驱虫药按说明书和休药期 |

**免疫程序原则**:
```
✓ 免疫程序因地区流行病、鸡的来源和疫苗种类而不同,
  以当地畜牧兽医站推荐的为准;下面只是常见的大致思路:
  - 出壳当天: 马立克氏病(孵化场注射)
  - 约1-2周龄: 新城疫(弱毒苗,滴眼滴鼻)、传染性支气管炎
  - 约2-4周龄: 法氏囊病(饮水,常需两次);新城疫加强
  - 约2月龄和开产前: 新城疫(灭活苗注射)、禽流感(按国家强制免疫要求)
  - 产蛋期: 根据当地疫情每隔几个月加强新城疫
✓ 只给健康鸡接种;病鸡接种不但无效,还可能加重病情
✓ 疫苗按说明书冷藏避光运输保存;稀释后在规定时间内(通常1-2小时内)用完
✓ 饮水免疫前停水2-4小时让鸡口渴,用不含消毒剂的清洁水稀释
✓ 免疫前后几天不用消毒剂带鸡消毒,避免应激(抓鸡、转群、换料)
✓ 用剩的疫苗、空瓶煮沸或深埋,不要随手丢
✓ 没有疫苗的时期: 更要严格隔离、小群分散饲养、少从外面引进
```

**兽药使用的一般原则**:
```
✓ 先请兽医确诊再用药;不要见病就喂抗生素,也不要用人用的抗生素
✓ 严格按说明书剂量和疗程
✓ 遵守休药期: 用药期间及休药期内的蛋和肉不能吃、不能卖
✓ 不用国家禁用的兽药;预防性长期添加抗生素会养出耐药菌,最终害人
```

**隔离与报告**:
```
发现病鸡:
1. 立即挑出,放到远离鸡群的隔离笼(下风向),专人专用具照看
2. 观察全群: 精神、采食、饮水、粪便、产蛋、死亡数,每天记下来
3. 短期内多只死亡(例如一两天死了好几只),或出现头脸肿、冠发紫、大批绿便
   → 怀疑新城疫或禽流感,立即报告当地畜牧兽医部门,
   在此之前全群封闭,不卖、不送、不吃、不转移
4. 病死鸡不剖检、不吃、不喂狗猫、不扔进河里

病死禽处理(要点):
✓ 戴手套、口罩处理,装袋;深埋(坑深至少1.5 m,远离水源,撒生石灰再覆土)或焚烧
✓ 处理后彻底洗手,工具、鞋消毒;污染的垫料、粪便一起深埋或高温堆肥
```

病死动物处理的完整要求见[卫生设施-病死动物处理](../07-日常生活技能/03-卫生设施.md#病死动物处理);疫苗和抗生素耐药的原理见[生物与医学基础-免疫和疫苗](../08-基础科学知识/04-生物与医学基础.md#三免疫和疫苗)、[抗生素和耐药](../08-基础科学知识/04-生物与医学基础.md#四抗生素和耐药)。

**人畜共患病提醒**:

| 疾病 | 怎样传给人 | 预防 |
|------|-----------|------|
| 禽流感 | 接触病死禽、禽粪,宰杀病禽,去活禽市场 | 不徒手接触病死禽;不宰杀、不吃病死禽;接触后洗手 |
| 沙门氏菌病 | 生蛋、未熟禽肉,摸鸡(尤其小鸡)后不洗手 | 蛋和禽肉彻底煮熟;摸鸡后洗手;5岁以下儿童不亲吻、搂抱小鸡小鸭 |
| 弯曲菌肠炎 | 生禽肉汁污染砧板、熟食 | 生熟砧板分开;不洗生鸡(水花溅开污染厨房) |
| 鹦鹉热(衣原体) | 吸入病禽的干粪尘、羽毛尘 | 清理鸡舍前先洒水压尘,戴口罩 |

```
⚠️ 接触病死禽或禽类大批死亡的场所后,2周内出现发热、咳嗽、乏力、肌肉酸痛等症状:
   立即就医,并主动告诉医生禽类接触史 — 这对医生早诊断禽流感非常关键
✓ 孕妇、儿童、老人和免疫力低下的人尽量不做清粪、宰杀、处理病死禽的工作
✓ 清粪、清垫料时戴口罩、手套,结束后用肥皂流水洗手
```

洗手方法见[卫生设施-怎么洗](../07-日常生活技能/03-卫生设施.md#怎么洗),发热、呼吸道症状的家庭处理见[传染病家庭防控-呼吸道传染病](../01-日常疾病和伤害/15-传染病家庭防控.md#呼吸道传染病)。

### 淘汰与更新

```
淘汰:
- 产蛋1-2年后产量下降
- 淘汰老鸡,补充新鸡
- 淘汰病弱鸡

补充:
- 每年补充20-30%(保持产蛋)
- 或全进全出(肉鸡)
```

```
挑选淘汰对象(在秋季换羽前后最容易看出):
✗ 换羽早而拖拉、冠发白干缩、耻骨间距窄、长期不产蛋
✗ 慢性病、长期瘦弱、经常吃蛋或啄别的鸡
✓ 留种: 产蛋多、换羽快、体型端正、抗病、会带小鸡的母鸡,和健壮温顺的公鸡
✓ 新老鸡合群前先隔网相处几天,夜里放进去,减少打架
```

### 鸡粪利用

鸡粪是农家肥中养分最浓的一种(氮、磷含量高),但**新鲜鸡粪不能直接上地**: 会"烧"苗(发酵时发热、释放氨气),还可能带病原菌和寄生虫卵。

```
✓ 连同垫料(稻草、木屑)一起堆肥,垫料提供碳,正好平衡鸡粪的高氮
  大约鸡粪1份 : 秸秆、干叶、木屑2-3份
✓ 堆肥保持湿润(手捏成团、不滴水),定期翻堆;
  堆心发热(约55°C以上)数天能杀灭大部分病原菌,一般2-3个月以上才腐熟
✓ 腐熟标志: 颜色变深褐、没有臭味、手感松散像泥土
✓ 用量参考: 腐熟鸡粪作基肥约0.5-1.5 kg/m²,翻入土中;比猪牛粪用量少
✓ 鸡舍放在菜园旁边,或用可移动的"鸡车"(带轮子的小鸡笼)轮流放在空闲菜畦上,
  鸡吃草吃虫的同时把粪留在地里,过一段时间再种菜
❌ 不在生吃的蔬菜上追施鸡粪;病死禽的粪便、垫料要深埋或单独高温堆肥,不上菜地
```

堆肥方法见[动植物培育-土壤改良](README.md#土壤改良),粪肥使用的卫生原则见[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用)。

### 宰杀与卫生

以下适用于鸡、鸭、鹅。**只宰杀健康的禽**;病禽、死禽、死因不明的禽一律不宰不吃,按病死动物处理。

```
宰前:
✓ 停料8-12小时(嗉囊和肠道排空,宰杀时不易污染),照常给水
✓ 宰前观察: 精神、呼吸、粪便正常;正在用药或在休药期内的不宰

宰杀:
1. 快速、减少痛苦: 将禽倒挂(或头朝下放入锥形桶、长筒里),
   让它安静下来,用锋利的刀在下颌后方迅速切断颈部一侧的大血管
2. 放血2-3分钟,放尽血肉质好、保存久
3. 血如果要食用,接在干净容器里,当天煮熟
⚠️ 刀要磨快;犹豫和反复切割会让动物更痛苦,也容易伤到自己
⚠️ 禽流感流行期间或当地有疫情时,不在家宰杀活禽

烫毛和拔毛:
✓ 鸡: 约60-65°C的热水,浸烫约30-60秒,能轻松拔下翅膀大羽即可
✓ 鸭、鹅: 羽毛有油、绒毛密,水温略高(约65-70°C)、时间更长,
  烫前可先用冷水把羽毛泡透;细绒毛用小镊子或手指捏着慢慢拔净
✗ 水太烫、烫太久 → 皮被烫熟、一拔就破
✓ 鹅、鸭的绒毛洗净晒干,可以做被褥、衣物填充

开膛:
1. 在操作台上进行,不在地面上
2. 先摘除嗉囊,在肛门周围环切,小心掏出内脏,不要弄破肠道和胆囊
   (肠内容物污染肉是细菌污染的主要来源;胆汁会让肉发苦)
3. 检查内脏: 肝脏有白点、大片出血、肿大,腹腔有积液或异味 →
   整只不要吃,按病死动物处理
4. 肫(砂囊)剖开去掉内容物和角质膜,心、肝、肫可食
5. 用清洁的水冲洗,尽快冷却
```

```
卫生:
✓ 生禽肉专用砧板和刀,用完立即用热水、洗涤剂清洗;处理后肥皂洗手
✓ 没有冰箱时当天吃完,或马上用腌制、烟熏、晒干的方法保存
✓ 禽肉、禽蛋彻底煮熟: 肉中心温度≥75°C,切开不带血、肉汁清亮
✓ 羽毛、内脏、血污不随地丢弃: 内脏煮熟可喂狗猫(病禽的除外),
  其余深埋或堆肥,远离水源
❌ 不用生禽内脏喂鸡鸭(循环传播疫病)
```

肉的保存方法见[食物加工与保存-腊肉、咸肉](../07-日常生活技能/01-食物加工与保存.md#腊肉咸肉)、[烟熏](../07-日常生活技能/01-食物加工与保存.md#烟熏);烹饪和储存的卫生要求见[常见疾病-食物中毒](../01-日常疾病和伤害/01-常见疾病.md#食物中毒)。

## 鸭的养殖

### 特点

```
优点:
✓ 适应性强
✓ 抗病力强
✓ 产蛋多(270-300个/年,某些品种)
✓ 肉质好
✓ 喜水,可水旱结合

需求:
- 水源(水池或溪流,更好)
- 较大活动空间
```

```
与鸡的不同:
- 鸭不上栖架,睡在地上,所以垫料要更厚、更勤换
- 鸭吃食时要喝水把食物冲下去,料槽旁必须有水,饮水器要深到能浸没整个鸭嘴
  (鸭靠这样清洗鼻孔和眼睛)
- 鸭很少抱窝(番鸭除外),孵鸭蛋要靠母鸡、番鸭或孵化箱
- 鸭比鸡更怕黄曲霉毒素,发霉的饲料绝对不能喂
- 鸭可能带禽流感病毒而不发病,和鸡分开养
```

### 品种

- 蛋鸭: 绍兴鸭、金定鸭
- 肉鸭: 北京鸭、樱桃谷鸭
- 蛋肉兼用: 高邮鸭

```
补充:
- 番鸭(瘤头鸭): 叫声小、能飞、会抱窝孵蛋,耐粗饲,适合小规模自给;孵化期约35天
- 麻鸭类地方品种: 体小、善觅食,适合放牧和稻田养鸭
- 公母比例: 蛋鸭种群约1:15-20,肉用种鸭约1:5-8
```

### 鸭舍

```
类似鸡舍,但:
✓ 地面防水(鸭便湿)
✓ 略倾斜(排水)
✓ 运动场大些
✓ 水池(如可能)
```

```
细节:
✓ 舍内密度: 成鸭约4-6只/m²
✓ 饮水处设在舍的一端,下方用网格或砖垫高、通向排水沟,其余地面保持干燥
✓ 垫料厚铺(约10 cm以上),湿了及时换;鸭长期睡湿地会得腿病、胸部囊肿
✓ 产蛋窝: 在墙边地面用木板隔出一排窝(约40x40 cm),铺干草;不需要离地
✓ 同样要防黄鼠狼、狐狸,夜间关舍;鸭在夜里受惊会乱跑踩踏,舍内可留一盏小灯
✓ 水池: 水要能更换或流动,死水很快变臭、滋生病菌;水池周围铺石子或砖防泥泞
```

### 饲养

**育雏**:
```
- 保温(类似小鸡)
- 第1周: 29-32°C
- 逐周降温
- 饮水+雏鸭料
```

```
补充:
✓ 之后大约每周降2-3°C,天气温和时3-4周可脱温
✓ 先饮水、后开食;开食可用煮熟的碎米、碎玉米,或雏鸭料拌湿成不粘手的湿料
✓ 雏鸭需要较多的烟酸(维生素B3),只喂玉米容易腿软、站不起来;
  可加酵母、麸皮、豆饼,或按说明加禽用多维
✓ 没有母鸭带的雏鸭,绒毛防水性差: 头1-2周不要让它们游水,
  水深只要能浸没鸭嘴即可;防止弄湿全身后受凉、淹死
✓ 2周后可在晴暖天气短时间下浅水,上岸后让它们晒干理毛
✓ 雏鸭期常见鸭病毒性肝炎(突然大批死亡、死前头向后仰),要按当地兽医站建议免疫
```

**成鸭**:
```
饲料:
- 鸭料或自配(类似鸡料)
- 喜青饲料(菜叶、水草)
- 可放养觅食(虫、草、螺)

放牧:
- 早晚放牧(鸭喜凉爽)
- 水面放养(吃水草、螺、鱼虾)
- 减少饲料成本

产蛋:
- 多在夜间或清晨
- 产蛋箱
- 定时捡蛋
```

```
补充:
✓ 蛋鸭也要补钙: 贝壳碎粒单独放一槽,和鸡一样
✓ 鸭在下半夜到早晨产蛋,早上9点前不放出鸭舍,捡完蛋再放牧,否则蛋会下在野外和水里
✓ 稻田养鸭: 秧苗返青、分蘖后放入小鸭,鸭吃虫吃草、搅动泥水;抽穗后收回,避免吃稻穗
✓ 放牧前了解附近田地是否刚打过农药,打过药的田块和水面1-2周内不放鸭
✓ 鸭瘟(鸭病毒性肠炎): 流泪、头颈肿大("大头瘟")、绿色稀粪、大批死亡 —
  靠疫苗预防,发生时隔离、上报,方法同鸡的疫病
```

稻田养殖的配合见[水产养殖-稻田养鱼](07-水产养殖.md#稻田养鱼)。

## 鹅的养殖

### 特点

```
优点:
✓ 主要食草(成本低)
✓ 生长快
✓ 抗病力强
✓ 肉质好
✓ 羽绒价值高

需求:
- 草地
- 水源
- 空间大
```

```
补充:
✓ 鹅警觉性高,见生人、野兽会大声叫,可以兼作"看家鹅"
✓ 成鹅每天能吃约1-2 kg青草,有好草地时精料可以很少
✓ 鹅寿命长,种鹅可利用4-5年以上
⚠️ 公鹅繁殖期有攻击性,会啄人、扑打,小孩不要单独靠近
```

### 品种

- 狮头鹅、太湖鹅、四川白鹅等

```
补充:
- 大型(狮头鹅): 长得大,产蛋少(约25-35个/年)
- 中小型(太湖鹅、四川白鹅、豁眼鹅等): 产蛋较多(约60-100个/年),较适合自繁自养
- 公母比例约1:4-6
```

### 饲养

**育雏**(0-4周):
```
- 保温: 第1周28-30°C
- 雏鹅料+切碎青菜
- 比例: 料:青 = 1:2逐渐到1:4
```

```
补充:
✓ 第2周约25-27°C,之后逐周降低,天暖时2-3周可脱温
✓ 先饮水后开食;青菜切成细丝,只喂嫩叶
✓ 第1周不要在有露水的早晨或雨后放到草地上(绒毛打湿后受凉);
  约1周后在晴暖中午短时间放牧,逐渐延长
✓ 小鹅瘟: 3周龄内雏鹅最易感,死亡率很高;靠种鹅产蛋前免疫(雏鹅从母源得到抗体)
  或雏鹅出壳后按兽医站指导注射疫苗、抗血清预防
```

**育成**(4周后):
```
- 以放牧为主
- 食草(新鲜嫩草)
- 补充少量精料
- 水源(游水)

放牧:
- 上午、下午各一次
- 草地、水边
- 可快速育肥(70-90天,3-4 kg)
```

```
放牧细节:
✓ 鹅爱吃禾本科、豆科嫩草和菜叶;放牧草地要轮换,啃秃后休养长草
✓ 认识并避开有毒植物(如夹竹桃、曼陀罗、毒芹等)和刚喷过农药的地块
✓ 中午太热时赶回阴凉处;傍晚回舍后看嗉囊,不饱的补喂精料
✓ 育肥: 出栏前2-3周减少放牧、增加玉米、碎米等精料,肉更肥
```

**产蛋**:
```
- 8-10月龄开产
- 季节性产蛋(春季)
- 年产蛋40-80个
- 蛋大(150-200 g)
```

```
补充:
✓ 产蛋季前1个月加喂精料和贝壳,保证产蛋所需
✓ 产蛋窝设在舍内安静角落,铺干草;鹅蛋要及时收,避免被踩破
✓ 想孵小鹅: 部分地方品种母鹅会抱窝,也可由母鸡、番鸭或孵化箱孵化,约30-31天
✓ 鹅交配多在水中进行,有水面时种蛋受精率更高
```

## 📝 家禽养殖要点

```
选择:
- 新手: 鸡(容易)
- 有水源: 鸭、鹅
- 有草地: 鹅(成本低)

数量(家庭):
- 10-20只鸡(够吃蛋+偶尔吃肉)
- 或混养: 鸡+鸭+鹅

成功关键:
✓ 清洁卫生
✓ 适当密度
✓ 营养充足
✓ 防病疫苗
✓ 细心观察
✓ 及时处理问题

效益:
- 投入: 设施+饲料+时间
- 产出: 蛋+肉+肥料
- 约半年回本(养得好)
- 长期稳定收益

注意:
✓ 了解当地法规
✓ 防止扰民(气味、噪音)
✓ 人道养殖
✓ 食品安全
✓ 防范禽流感: 不徒手接触病死禽,病死禽深埋或交防疫部门处理,出现大量死亡立即上报
```

```
最容易出错的几件事:
❌ 鸡舍漏缝 → 黄鼠狼一夜咬死半群
❌ 育雏温度忽高忽低、夜里没人看 → 雏鸡扎堆压死
❌ 垫料潮湿 → 球虫病
❌ 产蛋鸡不单独补钙 → 软壳、破蛋、鸡吃蛋
❌ 产蛋期光照忽长忽短 → 停产
❌ 新鸡不隔离直接合群、鸡鸭混养 → 疫病传入
❌ 喂发霉饲料 → 黄曲霉毒素中毒
❌ 吃、卖病死禽 → 自己生病,疫病扩散
```
