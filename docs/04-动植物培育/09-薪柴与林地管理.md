## 为什么燃料是瓶颈

做饭、烧开水、取暖、烧陶烧砖、烧石灰、炼铁打铁,全都要烧东西。电网和燃气断了之后,绝大多数社区能依靠的燃料只有木柴。**粮食一年一熟,树却要长好几年到十几年;砍得比长得快,几年之内周围就无柴可烧。**

历史上这样的事反复发生:

```
- 很多古代文明的都城周围,森林在几代人之内被砍光,
  柴和木炭要从越来越远的地方运来,价格越来越高
- 烧炭炼铁、烧盐、烧陶的地区,往往最先把山砍秃
- 中国黄土高原、华北不少地区,历史上森林大量消失,
  农民只能烧秸秆、草根、牲畜粪,甚至把麦茬连根刨出来烧
- 山坡上的树被砍光后,表土被雨水冲走: 河水变浑、泥沙淤积、
  下游洪水加重、山上再也长不起树,也种不了庄稼
```

```
⚠️ 安全
- 伐木是事故率很高的劳动: 被倒下的树、断枝砸中,斧锯割伤,搬运压伤
- 林火一旦烧起来,人跑不过火
- 砍伐要量力而行,结伴作业,不单独进林子干活
- 柴堆、炭窑、烟囱都有火灾和一氧化碳风险
```

燃料作为技术重建的瓶颈见[技术重建路线图-燃料和能源](../09-进阶科学与工程/00-技术重建路线图.md#31-燃料和能源);水土流失与保护土壤见[地质、矿物与土壤-保护土壤](../08-基础科学知识/06-地质矿物与土壤.md#55-保护土壤)。

## 需要多少柴

### 生活用柴

下面是用传统柴灶生活时的大致范围(**估计值**,随气候、灶的好坏、家庭人数差别很大):

| 情况(一户4-5口人) | 一年用风干柴(大致) |
|------|------|
| 南方温暖地区,只做饭烧水 | 约2-3 t |
| 北方,做饭 + 火炕取暖(做饭的火同时烧炕) | 约4-6 t |
| 北方,做饭之外另烧敞口炉或火盆取暖 | 6-10 t 甚至更多 |
| 东北、高原等严寒地区 | 可能再多一半以上 |

```
粗略记法:
- 一个人只做饭: 每天约1.5-3 kg风干柴(敞口灶取上限,省柴灶取下限)
- 取暖的耗柴往往比做饭多得多,省柴最大的空间在取暖
- 一个约50人(十几户)的北方社区,一年生活用柴约50-80 t

体积换算(大致): 1 m³ 整齐码放的风干硬木柴约400-500 kg,软木约300-400 kg
```

### 木材的热值

| 燃料 | 热值(大致) | 说明 |
|------|------|------|
| 完全干燥的木材 | 约18-19 MJ/kg | 不同树种按质量算差别不大 |
| 风干柴(含水率15-20%) | 约15-16 MJ/kg | 实际能用到的好柴 |
| 半干柴(含水率约30%) | 约12-13 MJ/kg | |
| 刚砍的湿柴(含水率约50%) | 约8 MJ/kg 或更低 | 还要烧掉大量热去蒸发水 |
| 木炭 | 约29-30 MJ/kg | 无烟、火温高 |
| 秸秆、干粪饼 | 约12-15 MJ/kg | 体积大,烧得快 |

```
硬木(栎、槐、榆、枣等)和软木(杨、柳、松、杉)每 kg 发热差不多,
但硬木密度大: 同样一堆柴,硬木重得多、烧得久、出炭多
松木油脂多: 好引火,但烟和焦油多,烟囱要勤清理
```

热量和热值的概念见[物理-热学](../08-基础科学知识/02-物理.md#五热学)。

### 手工业用柴(数量级估计)

| 用途 | 大致耗用 | 说明 |
|------|------|------|
| 露天堆烧一批陶器 | 柴的质量约为陶器的1-3倍 | 热量大部分散失 |
| 简易窑烧陶 | 柴的质量约为陶器的0.5-2倍 | 窑越保温越省 |
| 烧砖 | 每1000块砖约0.5-1.5 t柴 | 土窑、简易窑取上限 |
| 烧石灰(约900°C) | 每 t 生石灰约0.5-1 t柴 | 立窑连续烧比较省 |
| 烧木炭 | 木炭得率按质量约15-25% | 1 t木材约得150-250 kg木炭 |
| 块炼铁 | 每 kg 熟铁几 kg 到十几 kg 木炭 | 折合木材几十 kg |

```
⚠️ 以上都是估计,只用来判断数量级:
- 木炭得率: 简陋土窑、湿柴、操作不熟练时只有十几%;
  硬木、窑好、控制得好时可到25-30%
- 炼铁: 冶金章给出的每 kg 铁约1-1.5 kg 木炭是条件好时的下限;
  加上矿石品位低、渣里损失和反复加热锻打,实际往往是铁的好几倍
- 结论: 一座小炼铁炉一年用的木材,可能比整个村子的生活用柴还多,
  必须先有成片的轮伐林,再谈炼铁
```

木炭的烧制方法见[基础冶金知识-木炭制作](../05-冶金技术/00-基础冶金知识.md#32-木炭制作闷烧法);烧窑见[陶瓷玻璃与造纸-烧制](../07-日常生活技能/11-陶瓷玻璃与造纸.md#烧制)。

## 柴要干

刚砍下的树,含水率(水的质量占湿柴总质量的比例)通常有40-60%。湿柴不但热值低,还难点、烟大,在烟囱里结焦油,容易引发烟囱火。**同样一车柴,晒干后烧出的有效热量能多出将近一倍。**

```
干燥步骤:
1. 砍倒后尽快截成段: 长度按灶膛定,一般30-50 cm
2. 劈开: 不劈开的圆木段,树皮包着,几年都干不透;
   直径超过约10 cm的都要劈开
3. 堆放风干: 至少半年,硬木、粗柴最好一年以上;
   冬季砍、来年冬天烧,是最省心的节奏
4. 先烧细柴和软木(干得快),硬木和粗柴留到第二年

判断干没干:
✓ 两块相敲声音清脆,不发闷
✓ 两端有放射状裂纹,颜色变灰
✓ 明显变轻
✓ 更准确: 挑几块做记号,定期称重,重量不再下降就是干了
✗ 劈开断面发潮、发凉,点燃时吱吱冒水、冒白烟
```

```
码柴垛:
1. 选通风、向阳、不积水的地方,离房屋墙壁有一段距离
2. 底部垫石块、砖或横放的木杆,离地10-15 cm,防潮、防腐
3. 两端用柴交叉码成"井"字形柴桩,或靠立木桩,防止倒塌
4. 柴段一层层平码,劈面朝下、树皮朝上(树皮像瓦片挡雨)
5. 两排柴垛之间留空隙,长边对着常刮的风向
6. 顶上盖树皮、木板、旧铁皮或草帘,四面不要包死
7. 垛高不超过约1.5 m,太高容易倒塌砸人

✗ 不要用塑料布把整个柴垛裹严: 水汽出不去,柴会发霉腐烂
⚠️ 柴垛里常藏蛇、蝎子、蜈蚣,取柴时戴手套,不要直接伸手进缝里
```

木柴储存的防火要求见[照明与能源-木柴](../07-日常生活技能/06-照明与能源.md#木柴);做家具和工具柄用的木材干燥更讲究,见[木工与工具维护-干燥](../07-日常生活技能/09-木工与工具维护.md#干燥)。

## 一片林地能产多少柴

一片林地每年能长出多少木材,决定了每年可以砍多少而不把林子砍光。**只砍新长出来的那一部分,林子就能永远用下去。**

| 林地类型 | 每公顷每年生长量(干材,大致) |
|------|------|
| 北方干旱、寒冷地区的天然次生林、灌木林 | 约1-3 t |
| 一般温带天然林 | 约2-5 t |
| 管理好的萌生林(栎、刺槐、杨柳等) | 约3-8 t |
| 南方水热条件好的速生林(桉、杨、竹等) | 10 t以上 |

```
⚠️ 这些数字随树种、气候、土壤、雨量差别很大,只能估数量级。
   最可靠的办法是自己记录: 一块地砍完称一称(或量堆放体积),
   记下这块地上次砍是哪年,几轮下来就知道本地的真实产量。

由需求反推林地面积:
  需要的林地(ha)= 每年用柴(t)÷ 每公顷每年生长量(t/ha)

例: 北方50人社区,生活用柴每年约60 t,
    萌生林每公顷每年按4 t计 → 需要约15 ha林地
    如果还要烧砖、烧石灰、烧炭炼铁,林地要再翻一番甚至更多

例: 南方一户人家只做饭,每年约2.5 t,
    速生林按每公顷每年10 t计 → 约0.25 ha就够
```

1 ha = 10000 m²,即100 m × 100 m。面积测量见[测量与制图](../08-基础科学知识/08-测量与制图.md)。

## 萌生林: 砍了还会再长

很多阔叶树砍断后,树桩会冒出一丛新枝,几年后又长成可以砍的柴。这种经营方法叫**萌生林**(矮林作业)。树根还活着,不用重新种,长得比新栽的树快得多,也能一直固住土。

### 哪些树能萌生

| 树种 | 萌生能力 | 适合地区 | 大致轮伐周期 |
|------|------|------|------|
| 柳、旱柳、杞柳 | 很强 | 全国,喜水湿 | 2-5年 |
| 杨树 | 强(也能从根部萌蘖) | 北方、中部 | 4-8年 |
| 刺槐(洋槐) | 很强,根部也萌蘖 | 北方、中部,耐旱耐瘠薄 | 4-8年 |
| 桉树 | 很强 | 华南、西南温暖地区 | 3-6年 |
| 栎类(麻栎、栓皮栎、蒙古栎等) | 强 | 全国山区 | 8-15年 |
| 板栗 | 强 | 南北都有 | 8-15年(当柴时) |
| 榆、槐、枫杨、桤木 | 较强 | 各地 | 5-12年 |
| 竹 | 地下茎每年发新竹 | 南方 | 每年砍3-5年生的老竹 |

```
✗ 大多数针叶树(松、杉、柏)砍断后树桩不会再发芽,只能重新种
  (杉木有一定萌生能力,但不如阔叶树可靠)
✓ 轮伐周期越短,柴越细,砍和搬越省力,但每次的量少;
  周期越长,柴越粗,可以兼做小木料、烧炭
```

### 怎么砍

```
砍伐季节:
✓ 冬季到早春发芽前的休眠期砍: 养分存在根里,来年萌条多而壮;
  冬天的木材含水少、干得快,农闲有人手
✗ 不要在生长季(春末到夏季)砍: 树桩萌条少,甚至死掉;
  夏末秋初砍,新萌条来不及木质化,冬天容易冻死

留桩和切口:
1. 留桩高度一般离地约5-15 cm,低一点萌条从根颈发出,更结实;
   有牲畜啃食风险的地方,也有人留到1-2 m高(头木作业),让新枝长在牲畜够不着的地方
2. 切口要平整、干净,向一侧斜(斜面),让雨水流走,不在桩顶积水腐烂
3. 不要把树桩劈裂、撕破树皮: 用锋利的斧头或锯,从外侧斜着砍
4. 砍后第一、二年,一个桩上会冒出很多萌条,
   选留3-5根健壮、分布均匀的,其余剪掉,让养分集中

分块轮流砍:
1. 把林地分成和轮伐周期年数相同的块数
   例: 周期8年 → 分8块,每年砍1块,第9年回到第1块
2. 在地图或本子上记下每一块的位置、面积、砍伐年份和产量
3. 每块地边界用石堆、刻痕或界桩标清楚
4. 刚砍过的块,头两三年禁止放牧(牲畜会啃光萌条)
5. 每块里可以留几棵大树不砍(留作木材、采种、鸟类和遮阴)
```

林地记录的方法见[记账交易与社会分工](../07-日常生活技能/13-记账交易与社会分工.md)。

## 植树造林

现有的树不够用,或者周围已经是荒山,就要种。**种树要比需要用柴提前好几年**,越早开始越好。

### 选地: 种在不宜耕种的地方

```
✓ 不适合种粮的陡坡、石坡、薄地
✓ 沟边、河岸、渠旁、塘边(树根固土护岸,柳、杨、枫杨、桤木最适合)
✓ 村子周围、道路两旁、田边地角
✓ 冬季的迎风面(兼作防风林)

✗ 不占用平整肥沃的好地(粮食更重要)
✗ 不在房屋旁边种高大的树(倒伏砸房、根系破坏墙基)
✗ 不在水井、泉眼正上方紧挨着种(落叶腐烂、根系破坏井壁)
```

### 速生薪炭树种

| 树种 | 优点 | 注意 |
|------|------|------|
| 刺槐 | 耐旱、耐瘠薄,根瘤能固氮肥地,木材硬、火力旺,花可养蜂 | 有刺;根蘖扩散快,不要种在耕地边 |
| 杨、柳 | 扦插就能活,长得极快 | 木材轻、不耐烧;柳要水湿 |
| 桉树 | 南方长得极快,萌生力强 | 只适合温暖地区,怕冻;耗水多,不种在水源边 |
| 栎类 | 柴质最好、出炭多,橡子可食(需脱涩) | 长得慢,育苗要几年 |
| 紫穗槐、柠条、沙棘(灌木) | 耐旱耐沙,固氮,能在很差的地上长 | 柴细,适合北方干旱地区 |
| 银合欢、木麻黄 | 华南速生,固氮 | 只适合热带亚热带 |

### 扦插(杨柳最简单)

```
1. 冬末春初、发芽前,从健壮的一两年生枝条上剪插条
2. 长约20-30 cm,粗约1-2 cm,上端平剪、下端斜剪,分清上下
3. 插入湿润的土中,露出地面只留1-2个芽(约插入2/3以上)
4. 插后踩实,浇透水,保持土壤湿润
5. 柳树也可以直接插粗枝(长1-2 m的"插干"),插进河岸湿土约0.5 m深
```

### 育苗和栽植

```
育苗:
- 栎类、板栗: 秋天捡饱满的种子,直接播或埋在湿沙里过冬,春天播;
  种子怕干,也怕被老鼠吃
- 刺槐、紫穗槐: 种皮坚硬,播前用约80°C的热水烫种,
  自然冷却浸泡1天,膨胀的种子先播,不胀的再烫一次
- 苗床整细,条播,覆土约种子直径的2-3倍,保持湿润
- 一年生苗高约30-100 cm时就可以出圃移栽

挖坑栽植:
1. 时间: 春季发芽前或秋季落叶后;南方雨季栽也可以
2. 坑: 约40-60 cm见方、深约40 cm;薄地、石坡挖大一些,换入好土
3. 薪炭林可以密植,株行距约1-2 m;坡地按等高线成排栽,
   挖成外高内低的"鱼鳞坑",接住雨水
4. 根系舒展放入坑中,填土到一半时轻轻向上提一下苗,再填满踩实
5. 浇一次透水,水渗下后再盖一层松土或草,减少蒸发

成活管理:
✓ 头一两年旱季浇水,周围的杂草割掉或压在树下当覆盖
✓ 防牲畜: 3-5年内不许放牧,必要时用荆棘、篱笆围住
✓ 第二年春天检查成活,死的及时补栽
✓ 不急着砍: 新栽的林子一般至少要3-5年,栎类更久,才进入第一次轮伐
```

育苗、嫁接等基础方法也可以参考[果树培育-定植](03-果树培育.md#定植);等高线见[户外出行准备与求救-看懂地图和等高线](../03-野外生存/07-户外出行准备与求救.md#看懂地图和等高线)。

## 保护森林

```
不能砍的地方:
✓ 陡坡(大约25°以上)不砍光,只能疏伐(间隔着砍一部分)
✓ 水源林: 泉眼、水井、取水溪流上游的林子不砍,至少保留一条宽林带
✓ 河岸、沟边的护岸林不砍光
✓ 村子上方挡山洪、挡落石、挡风沙的林子不砍

不"剃光头":
✓ 一次只砍一块,不把整面山一次砍光
✓ 大片地按块轮伐,砍过的块和没砍的块相间
✓ 每块留下一些母树、果树、大树
✓ 树枝、树叶的细碎部分可以留一部分在地里,养土、挡雨水冲刷
✗ 不连根刨树桩、不搂光地上的落叶(那是林地的肥料和护土层)

防火:
✓ 林地和村子、田地之间留出防火带: 宽约10-20 m,清除干草和灌木,
  可以种不易燃的作物或保持裸土
✓ 房屋周围约30 m内清除枯枝杂草,柴垛不靠着林子
✓ 秋冬干燥大风季节,林区严禁烧荒、烧田埂、烧垃圾
✓ 炭窑、砖窑、石灰窑建在空地上,周围清理干净,有人看守到完全熄灭
✓ 社区约定: 谁看到烟立刻报告,大家都要会扑救的基本方法

不放牧幼林:
✓ 新栽的林子和刚砍过的萌生林,3-5年内禁止放羊、放牛
  (羊最厉害,会啃光嫩枝和树皮)
✓ 放牧安排在成林、草地或专门的牧场
```

林火的预防、逃生和扑救见[火灾-森林火灾](../02-灾难应对/04-火灾.md#森林火灾)。

## 其他燃料

| 燃料 | 优点 | 缺点和注意 |
|------|------|------|
| 秸秆、玉米芯、豆秆 | 每年都有,不用等树长 | 火猛但烧得快,要不断添;全部烧掉会让土地越来越瘦 |
| 牲畜粪饼 | 草原、无林地区的传统燃料 | 晒干才能烧;烟大,室内要通风;粪也是肥料,烧多了地就缺肥 |
| 枯枝落叶、杂草、灌木 | 随手可得 | 量少、火不耐;不要搂光林地落叶 |
| 果壳、锯末、刨花 | 加工的副产品 | 锯末要压成块或用专门的炉子 |
| 沼气 | 用粪便和秸秆发酵,还得到肥料 | 有中毒、窒息和爆炸风险,严格遵守安全规则 |
| 煤 | 热值高,有的地方露出地表 | 含硫,烟有毒;室内烧一氧化碳风险更大;直接炼铁会让铁变脆 |

```
秸秆的原则: 一部分还田(直接翻埋或堆肥)、一部分喂牲畜,
            剩下的才当柴烧;不在地里露天焚烧

粪饼做法: 新鲜牛粪掺一些碎草,拍成饼贴在向阳的墙上或摊在地上晒干,
          干透后码在棚下;做完后洗手
```

沼气见[照明与能源-沼气](../07-日常生活技能/06-照明与能源.md#沼气);煤的找法见[地质、矿物与土壤-建筑和日用材料](../08-基础科学知识/06-地质矿物与土壤.md#31-建筑和日用材料);煤和木炭用于冶炼的区别见[基础冶金知识-常见问题](../05-冶金技术/00-基础冶金知识.md#七常见问题)。

## 省柴

省下的每一 kg 柴,就是林地少砍的一 kg。**改进炉灶和保温,往往比多种一片林更快见效。**

```
炉灶:
✓ 省柴灶: 灶膛小而深,锅底贴近火焰,有挡火圈,烟道拐弯,
  比敞口三石灶能省下相当一部分柴
✓ 一火多用: 做饭的火同时烧炕、烧热水(灶旁砌热水罐)
✓ 火炕: 做饭的余热在炕下多走一段再排出,北方最省柴的取暖方式
✓ 烧干柴,劈细一点,火旺而少烟
✓ 用多少烧多少,饭做好就撤火

做饭:
✓ 盖锅盖;豆子、粮食先浸泡
✓ 焖烧: 煮沸后把锅放进稻草筐或厚被褥里,靠余热焖熟
✓ 几家合用一个大灶、一个烤炉,比各家各烧一灶省

取暖:
✓ 先保温,再烧火: 厚墙、密封门窗缝、屋顶保温、挂厚门帘
✓ 全家集中在一个小房间取暖
✓ 多穿衣、厚被褥,比烧火取暖省得多

⚠️ 保温不能以堵死通风为代价: 烧火的房间必须留通风口,防一氧化碳中毒
```

更多节约能源的方法见[照明与能源-节约能源](../07-日常生活技能/06-照明与能源.md#节约能源);火炕和省柴灶的结构见[长期住所-火炕与炉灶](../07-日常生活技能/05-长期住所.md#火炕与炉灶);墙体和屋顶保温见[长期住所-保温](../07-日常生活技能/05-长期住所.md#保温)。

## 伐木安全

### 伐树

**伐树只适合有经验的人带着做。** 直径超过约20 cm的树,新手不要单独伐;倾斜、枯死、挂着断枝的树,更要请有经验的人判断。

```
伐前:
1. 看树: 往哪边歪、哪边枝叶重、有没有枯枝挂在上面("寡妇枝")、树干有没有腐朽空心
2. 看周围: 倒下的方向上没有人、房屋、电线,不会挂在别的树上
3. 清场: 树周围的灌木、藤蔓清掉
4. 定退路: 在预定倒向的斜后方约45°,两侧各清出一条退路
   ✗ 不要往正后方退(树干落地时根部可能向后弹跳)
5. 其他人站在离树至少两倍树高以外
6. 大风、下雨、下雪、天黑时不伐树

伐倒(原理):
1. 在要倒的一侧砍出一个缺口(楔形口),深约树干直径的1/4-1/3
2. 从对侧、比缺口底部稍高处锯或砍,向缺口方向推进
3. 中间留一条不砍断的"铰链"木,让树沿着它按预定方向倒下
   ✗ 不要把铰链砍断,否则树会失去控制
4. 树开始倾倒时,喊一声提醒,立刻沿退路离开,边退边看树冠

⚠️ 树倒下挂在别的树上(搭挂树)是最危险的情况之一:
   ✗ 不要爬上去、不要砍支撑它的那棵树、不要在它下面走动
   ✓ 用绳子、杠杆从侧面远处把它拉下来,或请有经验的人处理
```

### 斧头、锯子和搬运

```
✓ 斧头、锯子保持锋利,斧头柄楔紧不松动
✓ 劈柴时双脚分开站稳,木段放在宽大的劈柴墩上,
  斧子挥下的方向上不能有自己的脚和腿,周围清场,戴护目镜
✓ 在坡上砍伐和截段时,人站在上坡方向(滚下的木头会砸向下坡)
✓ 用锯时另一只手远离锯路;锯到最后木头会突然断开、下坠
✓ 抬重木头时多人同时起、同时放,喊口令;用腿发力,背保持挺直
✓ 搬运距离远时用板车、雪橇、滑道,不要硬扛
✓ 进林子带上急救包,结伴作业,告诉别人去哪片林子、什么时候回来

❌ 不要在疲劳、饮酒后砍树或使用油锯
❌ 不要单手抡斧头,不要拿斧背当锤子砸硬铁楔
```

斧头和工具使用安全见[木工与工具维护-安全](../07-日常生活技能/09-木工与工具维护.md#安全),换斧柄、磨斧头见同章[换工具柄](../07-日常生活技能/09-木工与工具维护.md#换工具柄斧锤锄)和[磨刀](../07-日常生活技能/09-木工与工具维护.md#磨刀);割伤、砸伤的处理见[外伤处理-割伤与擦伤](../01-日常疾病和伤害/02-外伤处理.md#割伤与擦伤)。

林区用火、发现林火后的扑救和逃生见[火灾-森林火灾](../02-灾难应对/04-火灾.md#森林火灾)。

## 林地的其他产出

管理好的林地不只是柴房:

| 产出 | 来源 | 说明 |
|------|------|------|
| 木材 | 轮伐时留下的大树、长周期的块 | 房梁、门窗、工具柄、家具 |
| 坚果 | 板栗、核桃、榛子、橡子 | 高能量食物,耐储存;橡子要反复浸泡去涩才能吃 |
| 蘑菇 | 栎类等阔叶树的段木上接种香菇、木耳 | 野生蘑菇不认识的一律不吃 |
| 药材 | 林下的金银花、天南星、黄精、灵芝等 | 认准才采,有毒植物多 |
| 蜂蜜 | 刺槐、枣、椴树、荆条等蜜源 | 林地边放蜂箱,同时帮果树授粉 |
| 编织材料 | 柳条、荆条、竹子 | 筐、篮、篱笆、席 |
| 饲料、肥料 | 刺槐叶、紫穗槐叶、落叶 | 嫩叶喂牲畜,落叶堆肥 |
| 草木灰 | 烧柴剩下的灰 | 钾肥;泡水得碱水,用来制皂 |

```
✓ 林地规划时,可以在边缘、沟边多种坚果树和蜜源树
✓ 木屑、细枝可以作为养菇的原料或堆肥
⚠️ 林下采集同样不要搂光、挖光,留下足够让它们继续繁殖
```

可食植物和有毒植物见[森林求生-食物](../03-野外生存/02-森林求生.md#食物);药材见[药用植物](04-药用植物.md);草木灰制碱见[制皂](../07-日常生活技能/04-制皂.md)。

## 📝 薪柴与林地管理要点

```
1. 燃料是长期生存和技术重建的瓶颈: 树长得慢,砍得比长得快就会无柴可烧
2. 先算账: 每户每年用柴约2-6 t(取暖地区更多),炼铁烧炭用柴更是惊人
3. 林地面积 = 每年用柴 ÷ 每公顷每年生长量,只砍新长出来的那部分
4. 柴要劈开、码垛、风干半年到一年以上,干柴的有效热量接近湿柴的两倍
5. 阔叶树萌生林: 冬季休眠期砍,留低桩、斜切口,分块轮流砍
6. 种树要提前几年: 杨柳扦插,刺槐、栎类育苗,种在坡地、沟边、河岸
7. 陡坡、水源林、护岸林不砍光;留防火带;幼林和刚砍过的林地禁牧
8. 改进炉灶、一火多用、先保温再烧火,比多种一片林见效更快
9. 伐树先定倒向和退路,结伴作业,搭挂树不硬处理
```
