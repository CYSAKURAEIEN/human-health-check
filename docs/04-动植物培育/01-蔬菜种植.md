## 播种期与发芽温度

种菜失败最常见的原因不是技术,而是**种错了时间**: 喜温的菜种早了被霜冻死,怕热的菜种晚了直接抽薹开花。我国南北气候差别很大,同一种菜的播种期能相差两三个月。

### 北方和南方怎么区分

本章说的"北方"以华北为例,"南方"以长江流域为例;其他地区按下表前后推移。下表的霜期是大致范围,**最可靠的是自己记录本地每年最后一次春霜和第一次秋霜的日期**(见[天气观测与预报-霜冻](../08-基础科学知识/07-天气观测与预报.md#五霜冻))。

| 地区 | 大致范围 | 春季晚霜 | 秋季初霜 | 种菜特点 |
|------|----------|----------|----------|----------|
| 东北、内蒙古、西北高寒区 | 黑吉辽、内蒙古、新疆北部、青藏高原 | 4月下-5月中 | 9月中下 | 一年基本只种一季;喜温菜要育苗 |
| 华北(本章"北方") | 京津冀、山东、河南、山西、陕西关中 | 4月上中 | 10月中下 | 春秋两季,冬季露地只能越冬耐寒菜 |
| 长江流域(本章"南方") | 江浙沪皖、两湖、江西、四川盆地 | 3月中下 | 11月中下 | 秋冬春都能种叶菜;盛夏高温暴雨缺菜 |
| 华南 | 广东、广西、海南、福建南部、云南南部 | 基本无霜 | — | 冬春是种菜黄金季节;夏季种耐热菜 |

按对温度的要求,蔬菜大致分四类:

```
耐寒菜: 菠菜、大蒜、大葱、韭菜、豌豆
  - 成株能耐零下几度的低温;菠菜、大蒜在华北加覆盖可以露地越冬
  - 土壤一化冻就能播种("顶凌播种")
半耐寒菜: 白菜、萝卜、胡萝卜、甘蓝、生菜、土豆
  - 最适15-20°C,能耐轻霜但怕严寒;怕高温(会抽薹、不包心、味苦)
  - 春季早播、秋季是主要季节
喜温菜: 番茄、辣椒、茄子、黄瓜、菜豆、豇豆
  - 一遇霜就冻死,低于10-12°C基本停止生长
  - 必须在晚霜过后、10 cm深处地温稳定在12-15°C以上才能露地播种或定植
耐热菜: 南瓜、豇豆、红薯、苋菜、空心菜、丝瓜
  - 夏季的主力,喜温菜里最耐热的一批
```

没有温度计时,参考当地传统农时和自己记录的晚霜日期,**喜温菜宁可晚播几天,也不要早播被霜打**。用前先测发芽率,见[留种与育种-发芽率测试](08-留种与育种.md#发芽率测试)。

### 发芽温度和播种深度

| 蔬菜 | 发芽适温 | 最低发芽温度 | 播种深度 | 出苗天数(d) |
|------|----------|--------------|----------|-------------|
| 生菜 | 15-20°C(超过25°C难出苗) | 约4°C | 0.3-0.5 cm | 3-7 |
| 小白菜、大白菜、甘蓝 | 20-25°C | 约4°C | 0.5-1 cm | 2-4 |
| 萝卜 | 20-25°C | 约4°C | 1.5-2 cm | 3-5 |
| 胡萝卜 | 20-25°C | 约4°C | 约1 cm | 10-15 |
| 菠菜 | 15-20°C(超过25°C出苗差) | 约2°C | 1.5-2 cm | 7-10 |
| 番茄 | 25-30°C | 约12°C | 0.5-1 cm | 5-10 |
| 辣椒、茄子 | 25-30°C | 约15°C | 0.5-1 cm | 7-14 |
| 黄瓜 | 25-30°C | 约12°C | 1.5-3 cm | 3-5 |
| 南瓜、西葫芦 | 25-30°C | 约13°C | 3-4 cm | 4-7 |
| 菜豆、豇豆 | 20-30°C | 约10-12°C | 3-4 cm | 5-8 |
| 豌豆 | 15-20°C | 约2-5°C | 3-5 cm | 7-14 |
| 大葱、韭菜 | 15-20°C | 约3-5°C | 0.5-1 cm | 7-14 |

```
经验规则:
- 播种深度约为种子直径的2-3倍;沙土稍深,黏土稍浅
- 小粒种子(生菜、胡萝卜、葱)覆土太厚是出苗差的头号原因
- 温度低于适温时出苗慢、容易烂种;茄果瓜类宁可在室内催芽育苗
- 表中数值为一般参考,不同品种有差别
```

## 菜园规划: 轮作、间作与连作障碍

### 菜园面积与布局

```
面积: 一家4口,鲜菜基本自给约需50-100 m²(见本部分README);
  如果还要种土豆、红薯、南瓜和冬储的白菜萝卜,另外再加地

选地:
✓ 每天直射阳光6小时以上(茄果瓜类最需要)
✓ 离水源近,浇水方便;但地势要高一点,雨后不积水
✓ 离住处近: 便于天天照看、防偷、防鸡鸭和野兽
✓ 远离大树(树根抢水肥、树荫挡光)
✓ 用篱笆围起来;散养的鸡一天就能把菜苗啄光

布局:
- 畦最好南北向,两侧受光均匀
- 高的(搭架的黄瓜、豆角、番茄)放在北边或西边,不要挡住矮菜
- 多年生的韭菜、香葱、药用植物固定在菜园一边,不参加轮作
- 留好步道,畦面不踩
- 画一张菜园图,每块畦编号,每年记录种了什么、什么时候种、收了多少、
  出了什么病——轮作和改进全靠这本账
```

### 轮作

同一块地连年种同一科的蔬菜,专门危害这一科的病菌、线虫和害虫会在土里越积越多。**关键是"科",不是"种"**: 番茄和土豆看起来完全不同,却同属茄科,病害(如晚疫病)相通。

| 科 | 常见蔬菜 | 同一块地隔几年再种这一科 |
|----|----------|--------------------------|
| 茄科 | 番茄、辣椒、茄子、土豆 | 3-4年;茄子黄萎病重的地5年以上 |
| 葫芦科(瓜类) | 黄瓜、南瓜、西葫芦、丝瓜、冬瓜、西瓜 | 黄瓜2-3年;西瓜5-7年 |
| 十字花科 | 白菜、小白菜、萝卜、甘蓝、芥菜、油菜 | 2-3年 |
| 豆科 | 豌豆、蚕豆、菜豆、豇豆、大豆 | 豌豆3-4年;其他2-3年 |
| 葱蒜类 | 葱、蒜、韭菜、洋葱 | 2-3年 |
| 伞形科 | 胡萝卜、芹菜、芫荽 | 2-3年 |
| 菊科 | 生菜、莴笋、茼蒿 | 1-2年 |
| 苋科 | 菠菜、苋菜、甜菜 | 1-2年 |
| 旋花科 | 红薯、空心菜 | 2-3年 |

```
排茬的原则:
✓ 豆科在前: 豆科根瘤固氮,下一茬种需氮多的叶菜、瓜类
✓ 深根和浅根交替: 萝卜、胡萝卜、番茄根深;葱、生菜、小白菜根浅
✓ 葱蒜之后种茄果、瓜类: 传统上认为葱蒜茬病害少
✓ 菜和粮食轮: 菜地隔几年种一季玉米、小麦,对土传病害效果最好
✓ 南方"水旱轮作": 菜和水稻轮种,淹水能杀死大量土传病菌和线虫
```

四年轮作计划见[本部分README-轮作计划](README.md#轮作计划4年),粮食作物的轮作见[粮食作物-轮作方案](02-粮食作物.md#轮作方案)。

### 间作套种

在同一块地上同时或交错种两种以上的菜,能多收一茬,也能减轻病虫害。

```
常用搭配:
- 高矮搭配: 搭架的黄瓜、豆角行间种生菜、小白菜;玉米和矮生豆类隔行种
- 快慢搭配: 番茄、茄子定植后,行间先撒一茬小白菜或樱桃萝卜,
  30-40天在茄果封行之前收完
- 喜光与耐阴: 盛夏在瓜豆架下面种生菜、芫荽,借架子遮阴
- 不同科搭配: 葱、蒜和其他菜间种,病虫害一般较少
- 套种: 前一茬收获前1-3周,在行间先播或栽下一茬,节省等地的时间

注意:
✗ 不要同科间作(病虫互相传)
✗ 不要太密: 通风差会让霜霉病、疫病更重
✓ 高秆作物顺南北行种,减少遮阴
```

### 连作障碍

连作障碍就是同一块地连续种同一类菜后出现的"越种越差"。

```
表现:
- 同样的管理,产量一年比一年低
- 苗长不起来,根发黑、发褐
- 枯萎病(黄瓜、西瓜)、青枯病(番茄、茄子,南方多)、黄萎病(茄子)年年发生
- 根上长满大大小小的瘤状疙瘩 → 根结线虫
原因:
- 土里专门危害这类作物的病菌、线虫越积越多(最主要)
- 根系分泌物对同类作物有抑制作用(自毒)
- 某些养分被一种作物长期偏吃
解决:
1. 轮作: 最根本,按上表的年限
2. 多施腐熟有机肥,让土里有益微生物多起来
3. 收获后彻底清园: 病株连根拔出,烧掉或深埋,不放进冷堆肥
4. 夏季晒土: 7-8月空闲时深翻、浇透水,盖透明薄膜,四周压严,
   闷晒3-4周,表层土温可升到50°C左右,能杀死相当部分病菌、线虫和草籽
5. 换用抗病品种;有经验时黄瓜可用南瓜作砧木嫁接(防枯萎病)
6. 根结线虫重的地: 轮作玉米、小麦等禾本科作物;种几茬万寿菊有一定抑制作用
```

## 整地做畦与小面积高产

土壤质地、酸碱性和肥力的判断见[地质矿物与土壤-土壤质地](../08-基础科学知识/06-地质矿物与土壤.md#52-简单的土壤质地判断)、[酸碱性](../08-基础科学知识/06-地质矿物与土壤.md#53-酸碱性)、[土壤肥力](../08-基础科学知识/06-地质矿物与土壤.md#54-土壤肥力)。酸性土撒石灰见[石灰与建筑材料-改良酸性土](../07-日常生活技能/16-石灰与建筑材料.md#改良酸性土)。

### 平畦、高畦和垄

```
翻地:
- 深度20-30 cm;根菜(萝卜、胡萝卜)和土豆要更深
- 什么时候能翻: 抓一把土握成团,从齐腰高处落地能散开 → 可以翻
  握不成团 → 太干,先浇水等一两天;落地成饼、粘手 → 太湿,翻了会结成硬块
- 翻时拣净石块、草根(尤其是茅草、香附子的根茎),土块打碎,基肥同时翻入

平畦(北方干旱少雨):
- 畦面与地面平,四周筑10-15 cm高的土埂,便于漫灌保水
- 宽1-1.5 m,长5-10 m;太长了浇水两头不匀

高畦(南方多雨、黏土、地下水位高):
- 畦面比沟底高15-25 cm,宽1-1.5 m,沟宽30-40 cm
- 畦沟、腰沟、围沟要一沟通一沟,最后通到排水沟,雨停后沟里不留水
- 辣椒、番茄、大白菜等怕涝的菜在南方必须用高畦

垄(土豆、红薯、萝卜、大白菜):
- 垄距60-90 cm,垄高15-30 cm
- 土层厚、疏松,块根块茎长得大;垄沟可以灌水和排水

畦宽的原则: 站在两边的步道上能伸手够到畦的中间,不用踩到畦面
```

### 深翻和覆盖

地少的时候,靠"深翻 + 多施肥 + 密植 + 一茬接一茬"在小面积上种出更多菜。

```
双层深翻(做一次管几年):
1. 在畦的一头挖一条宽约30 cm、深约25 cm(一锹深)的沟,土堆在一边
2. 用铁锹或镐把沟底再松一锹深(只松不翻,底土留在下面)
3. 沟底撒一层堆肥
4. 挖紧挨着的第二条沟,把表土翻到第一条沟里;如此往前推
5. 最后一条沟用第一条沟挖出的土填上
6. 畦面再铺约3-5 cm腐熟堆肥(约5-10 kg/m²),浅翻混匀
→ 根能扎到50 cm以上,同样面积可以比普通平畦种得更密
⚠️ 以后畦面不踩,否则又会压实

密植:
- 深翻过的畦,按本章株距的下限,以三角形(梅花形)错开种
- 标准: 植株长大后叶片刚好互相碰到、盖住地面(能遮住草、减少蒸发),不严重拥挤
- 前提是水肥跟得上;缺水缺肥时密植反而减产

一茬接一茬:
- 菜苗提前在苗床育好,前茬一收,当天整地施肥、马上定植
- 一块畦一年可以种3-4茬(如: 早春菠菜 → 番茄 → 秋萝卜/小白菜)

覆盖:
- 地温回升后,在行间铺5-10 cm稻草、麦秸、干草或落叶
- 好处: 保墒(少浇一半水)、压草、防雨水溅泥(减少病害)、烂了变成肥
- 早春不要太早盖(地温升不起来);用的草不要带草籽

立体种植:
- 篱笆、墙边、架子上种黄瓜、豆角、丝瓜、南瓜,占地少
- 盆、桶、木箱、泡沫箱也能种: 底部打排水孔;叶菜土深至少15-20 cm,
  茄果瓜类30-40 cm;容器里的土干得快,夏季每天浇
```

### 温床

北方春季育茄果类苗时,外面还冷,需要能自己发热的苗床。传统的"酿热温床"靠新鲜牲畜粪发酵放热。

```
做法:
1. 选背风向阳处,挖东西向的床坑: 宽1.2-1.5 m,深40-50 cm(北侧稍深),长按需要
2. 北侧用土墙、秸秆或草帘做一道风障
3. 填酿热物: 新鲜马粪、驴骡粪最好(发热快、温度高);牛粪发热慢,
   可以掺入30-50%铡碎的秸秆或落叶
   分2-3层填,每层踩实、浇水,湿度以手握有水渗出但不往下滴为准,总厚25-35 cm
4. 盖上薄膜或旧窗玻璃,3-5天后开始发热(手伸进去明显发热)
5. 在上面铺10-15 cm育苗土(或摆放营养钵),床土温度稳定在20-25°C后播种
6. 夜间盖草帘保温,白天揭开见光

判断和调整:
- 床温超过35°C: 掀开通风,或在床边插孔浇水降温
- 几天都不热: 粪太干、太湿或踩得太实,翻开重填
- 用完的酿热物已经半腐熟,是很好的堆肥原料

其他办法:
- 灶边、炕头、贴身口袋可以给种子催芽(不超过35°C)
- 火道温床(床下砌烟道烧火)要注意防火,烟道必须通到室外
```

### 简易拱棚和地膜

```
小拱棚:
- 材料: 竹片、劈开的竹竿、柳条、细钢筋;2-2.5 m长的弯成拱,两头插入土中20-30 cm
- 拱高0.5-1 m,宽1-2 m(罩住一畦),拱间距0.6-1 m
- 盖0.05-0.1 mm厚的农用薄膜,四周埋土压严,拱外再压绳或竹条防风掀
- 效果: 春季比露地提早约2-3周定植,秋季延后收获;能挡轻霜,挡不住严寒
- 管理:
  ✓ 晴天上午棚温上升很快,超过30°C就从背风一侧掀开膜通风
    ⚠️ 晴天中午密闭的棚里能超过40°C,几十分钟就能把苗烤死
  ✓ 下午三四点前关好,保住白天的热;冷夜在膜上再盖草帘
  ✓ 外面稳定转暖后,先白天揭、夜里盖,过一周左右再撤膜
- 没有薄膜: 草帘、旧玻璃窗、剪开的塑料袋拼接、剪掉底的透明塑料瓶罩单株

地膜覆盖:
- 起垄或做畦后浇透水,铺薄膜,四周压土,在膜上打孔播种或定植
- 能提高地温2-4°C,保墒,黑色膜还能压草
- ⚠️ 用完的旧膜要捡干净;残膜在土里几十年不烂,年年积累会伤土

风障和阳畦(北方传统):
- 风障: 在畦的北侧立1.5-2 m高的秸秆或芦苇墙,稍向南倾斜,挡北风、反射阳光
- 阳畦: 风障 + 北高南低的土框,白天盖玻璃或薄膜、夜里盖草帘;
  冬季可种耐寒菜,早春可以育苗
```

## 堆肥与粪肥

菜地要高产,靠的是年年大量施有机肥。**任何粪肥都必须充分腐熟后才能用**——生粪烧根、招地蛆,还会把寄生虫卵和病菌带到菜上。堆肥的基本配方见[本部分README-土壤改良](README.md#土壤改良),堆肥杀菌的原理见[生物与医学基础-农业中的生物学](../08-基础科学知识/04-生物与医学基础.md#82-农业中的生物学)。

### 堆肥怎么做

```
热堆(2-3个月):
- 体积至少约1 m×1 m×1 m,太小保不住热
- 绿料(菜叶、青草、新鲜畜粪)和棕料(干叶、秸秆、碎木屑)按体积约1:2-3分层堆
- 湿度像拧干的海绵: 用力捏有水渗出但不成流
- 3-5天内中心温度升到55-65°C(铁棍插入中心,拔出来烫手)
- 温度开始下降时翻堆,把外层翻到中间;共翻3-5次
冷堆(半年到一年): 不翻,慢慢腐熟,省力但杀不死草籽和病菌

腐熟的标志: 深褐色、有泥土气味、看不出原来的材料、翻开不再发热

✗ 不要放: 发病的植株(尤其晚疫病、枯萎病)、已结籽的杂草、肉骨油脂、
  猫狗粪、人粪(人粪必须单独按卫生要求处理)

用量: 作基肥约2-5 kg/m²;叶菜取低值,茄果瓜类取高值
```

### 畜禽粪和人粪尿

```
畜禽粪:
- 和秸秆一起堆沤,热堆2-3个月或冷堆半年以上再用
- 肥力大致: 鸡鸭粪 > 羊粪、兔粪 > 猪粪 > 牛粪
- 鸡粪最"热",用量减半(约1-2 kg/m²);猪、牛粪(厩肥)约2-5 kg/m²
- 病死畜禽的粪便、垫草不要用在菜地

人粪尿(严格按卫生设施一章的要求):
- 尿液: 加水稀释5-10倍,浇在土上不浇在叶上;叶菜收获前1个月停用
  → 生长期只有30-40天的快菜(小白菜、生菜),尿液只能在播种前作基肥
- 粪便: 气温在20°C以下的地区储存1.5-2年,更热的地区至少1年,
  到期后优先用于果树、粮食作物,施入土中并覆盖
✗ 绝对不要把新鲜粪便直接浇菜
✗ 人粪不要用于生吃的蔬菜(生菜、黄瓜、番茄等)
```

人粪尿的安全利用见[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用)。

### 草木灰和其他肥料

```
草木灰(主要补钾,也含钙):
- 适合土豆、红薯、萝卜、胡萝卜、瓜类、茄果类
- 基肥约100-200 g/m²,撒开后翻入土中;也可少量撒在行间作追肥
✗ 不要和人粪尿、畜禽粪、铵态氮肥混放混施(会放出氨气,氮白白跑掉)
✗ 呈碱性,盐碱地少用;要干燥保存,淋过雨的灰肥效大减

绿肥: 冬季空着的地种紫云英(南方)、苕子、箭筈豌豆等豆科绿肥,
  开花时翻压入土,2-3周后再种菜
沤肥水: 杂草、菜叶装进有盖的桶,加水沤2-3周,滤出的液体兑水后浇根作追肥
骨粉: 骨头烧过或煮透后捣碎,掺进堆肥,补磷
传统土肥: 塘泥(晒干后)、老墙土、炕土、草皮土
石灰: 只用于酸性土;和粪肥、氮肥要间隔1-2周
```

## 育苗与移栽

```
必须育苗: 番茄、辣椒、茄子(苗期长达两三个月)、甘蓝、大葱;红薯用薯块育苗
可育苗也可直播: 黄瓜、南瓜、生菜、大白菜、韭菜
只宜直播: 萝卜、胡萝卜(移栽伤主根会分叉)、菠菜、小白菜、豆类
```

育苗的好处: 苗期集中照顾、省种子、在温床里提前起步,而且大田可以先种一茬别的菜。

### 育苗土和播种

```
育苗土:
- 3年内没种过茄科、瓜类的园土6份 + 充分腐熟的堆肥或厩肥4份,过筛,
  可以掺少量草木灰
- 消毒: 夏秋在水泥地或薄膜上摊薄暴晒几天;量少时可上锅蒸约半小时
- 不用长过病的菜地土

容器: 营养钵、纸杯、竹筒、报纸卷成的筒,底部要有排水孔;
  也可以把湿的育苗土压实后切成8-10 cm的方块("切块育苗"),移栽时整块带走

播种:
1. 温汤浸种(茄果类): 种子放入约55°C热水中,不停搅拌15分钟
   (水温降了就兑热水,用温度计),能杀死种子表面的部分病菌
2. 再用常温水浸泡: 茄果类8-12小时,瓜类4-6小时
3. 催芽: 用湿布包好,放在25-30°C处(灶边、炕头、贴身口袋),
   每天用温水淘洗1次,大部分种子露白就播
4. 先把苗床或营养钵浇透,水渗下去后再撒种,盖过筛的细土
5. 盖薄膜或湿草帘保湿;一出苗立即揭开,否则几天就长成又细又高的"高脚苗"
```

### 苗期管理和炼苗

```
温度(茄果类): 出苗前25-30°C;出苗后白天20-25°C,夜间12-15°C
  - 夜温太高、光照不足 → 徒长(茎细长、叶色淡)
光照: 尽量多见光;苗朝一边歪就转动容器;室内窗台光照常常不够
浇水: 见干见湿,上午浇,不要傍晚浇
分苗: 2-3片真叶时移到营养钵,或在苗床里把苗距加大到8-10 cm,带土挖

猝倒病(最常见的死苗原因):
- 表现: 幼苗茎基部像被开水烫过一样变细、变软,突然成片倒伏
- 原因: 低温、过湿、不通风
- 处理: 立即拔除病苗,在周围撒干细土或草木灰吸湿,减少浇水,加强通风

壮苗: 茎粗、节间短、叶色深绿、根白而多、无病虫

炼苗: 定植前7-10天开始
- 逐渐降低温度、减少浇水
- 白天搬到室外背风半阴处,先放几小时,逐日延长、逐渐见全日照
- 最后几天夜里也放在外面(无霜时)
→ 没炼过的苗直接栽到外面,常被晒伤、冻伤、风吹折
```

### 移栽定植

```
1. 时间: 阴天,或晴天下午三四点以后;避开大风天和寒潮前夕
2. 前一天把苗浇透;挖苗时多带土,带土坨的苗缓苗快
3. 挖穴 → 放苗 → 填土 → 轻轻压实 → 浇"定根水"(每株约0.5-1 L)
4. 深度: 番茄可以深栽;辣椒、黄瓜与原土面平或略深;生菜、白菜不要埋住菜心
5. 缓苗: 3-5天内保持湿润,晴天中午用树枝、草帘遮阴;
   心叶开始长新叶 = 缓苗成功
6. 多育10-20%的备用苗,发现缺苗、死苗及时补栽
```

## 浇水、追肥与病虫害防治通则

各种菜的具体要求写在后面各节里,这里是共同的原则。浇水的基本原则也见[本部分README-水分管理](README.md#水分管理)。

### 浇水

```
什么时候浇: 手指插入土中约5 cm,感觉干了就浇;叶菜和瓜类要求勤一些
浇透: 每次让水渗到15-20 cm深的根层;每次只洒湿表面,根会长得很浅、更怕旱
用水量: 夏季生长旺盛期,每 m² 每周大约需要20-30 L(相当于20-30 mm降雨)
时间: 早晨最好;夏季避开中午(冷水浇热土伤根);冬春选晴天上午浇
方式: 沟灌或浇在根部;叶面长时间湿着最容易发霜霉病、疫病
雨季: 清沟排水,做到雨停沟里不积水;很多菜(辣椒、番茄、大白菜)淹几小时就烂根
节水:
- 覆盖秸秆
- 简易滴灌: 水桶底部扎小孔放在植株旁;或在株间埋一个不上釉的陶罐,
  罐口露出地面,装满水盖好,水慢慢从罐壁渗到周围的根
```

蓄水和引水见[水源工程与供水](../07-日常生活技能/10-水源工程与供水.md)。

### 追肥

```
原则: 基肥为主,追肥为辅;薄肥勤施;施在根旁,不施在叶上和根颈上

时机:
- 叶菜: 定苗后、生长最旺时
- 茄果、瓜类、豆类: 第一批果坐住以后开始,之后每采收1-2次追一次
- 根菜: 肉质根开始膨大时
- 葱蒜: 返青后、采薹后

方法:
- 液肥(腐熟稀粪水、沤肥水、稀释的尿液): 在离根约10 cm处开浅沟或挖穴,
  浇入后盖土
- 固体(腐熟堆肥、草木灰): 撒在行间,浅锄混入土中,再浇水
- 有化肥时: 尿素每次约10-15 g/m²,不要碰到根和叶,施后浇水

看叶片判断:
- 缺氮: 下部老叶先均匀变黄,整株瘦小
- 缺钾: 老叶叶缘发黄、焦枯
- 缺磷: 叶色暗绿发紫(低温时也会出现),长得慢
- 氮肥过多: 叶片浓绿肥大、只长秧不结果("疯秧")
- 肥太浓烧根: 施肥后叶片萎蔫、根发黑 → 立即大量浇水稀释
```

### 病虫害综合防治

**预防为主,先用农业和物理办法**,本部分README的[病虫害管理](README.md#-病虫害管理)有简要清单。

```
农业措施:
1. 轮作、清园: 收获后病残株连根拔净,带出菜园烧掉或深埋
2. 适期播种: 例如秋白菜不早播,避开高温和蚜虫高峰
3. 培育壮苗,不过密,保持通风
4. 选抗病品种;自己留种时只从健康植株上留

物理措施:
5. 防虫网: 40-60目,播种或定植后马上盖上,四周用土压严;
   夏秋种白菜、萝卜等十字花科几乎必备,能挡住菜青虫、小菜蛾、跳甲、蚜虫
6. 色板: 黄板诱蚜虫、粉虱,蓝板诱蓟马;在黄色或蓝色的板上涂机油或粘虫胶,
   插在比植株高约20 cm处
7. 手捉: 早晨和傍晚翻看叶背;捉到的虫丢进肥皂水里
8. 地下害虫(地老虎、蛴螬、蝼蛄): 发现苗被咬断,在附近扒开表土就能找到虫;
   用糖、醋加少量酒兑水装盆,夜里放在菜地诱杀成虫
9. 蜗牛、蛞蝓: 傍晚和雨后捉;畦边撒一圈干草木灰或石灰粉

生物措施:
10. 保护瓢虫、草蛉、蜘蛛、青蛙、鸟类;不乱喷药
11. 苏云金杆菌(Bt)制剂: 专杀菜青虫、小菜蛾等鳞翅目幼虫,对人畜安全,按说明使用
12. 菜地空闲时放鸡鸭进去啄虫吃草(种菜期间要隔开)
```

### 自制喷剂

```
通用要求: 先在几片叶子上试喷,1-2天没有药害(叶片发黄、焦斑)再大面积用;
  傍晚喷,对准叶背和虫体;隔3-5天再喷一次;采收前用清水冲洗

肥皂水: 普通肥皂或洗衣皂约10 g溶于1 L水,或洗洁精约5 mL兑1 L水
  → 杀蚜虫、粉虱、红蜘蛛(只对直接喷到的虫有效)
草木灰浸出液: 草木灰1份加水5-10份泡一昼夜,取上清液喷
  → 防蚜虫;也可趁早晨露水未干,把干草木灰直接撒在叶上
小苏打水: 小苏打约5 g兑1 L水,加几滴肥皂水 → 预防和减轻白粉病
辣椒水、大蒜水: 以驱避为主,做法见本部分README
```

### 农药的一般原则

```
- 只在农业、物理措施不够、损失严重时才用
- 严格按标签上写的作物、浓度、次数使用,不随意加大浓度
- 看清"安全间隔期"(最后一次用药到采收的天数),不到天数不采收
- 不用国家禁止使用的农药;标签上有"剧毒""高毒"字样或骷髅标志的,
  一律不用在蔬菜上
- 农药原包装锁好,远离食物、水源和儿童;空瓶不装食物和水
- 喷过药的菜地插牌提醒他人
- 喷药时出现头晕、恶心、多汗、视物模糊 → 立即停止,离开现场,脱衣冲洗,
  拨打120就医,带上农药瓶
```

喷药时的个人防护和农药中毒的急救见[中毒-喷洒农药时的防护](../01-日常疾病和伤害/12-中毒.md#喷洒农药时的防护)。

## 快速生长蔬菜(30-60天)

### 生菜

**周期**: 30-45天

```
种植:
- 时间: 春秋(避开盛夏)
  北方: 春季2月下-3月育苗,或3月下-4月直播;秋季8月播种
  南方: 9月-翌年3月都能种,秋冬是主季;华南冬季最好
- 发芽: 15-20°C最快;超过25°C种子休眠,很难出苗
  → 夏秋播种: 种子浸湿后用湿布包好,放在阴凉处(井边、地窖)一两天,露白再播
- 土壤: 疏松肥沃;基肥每 m² 施腐熟堆肥2-3 kg
- 播种: 撒播或条播,浅覆土(约0.3-0.5 cm);用种约0.3-0.5 g/m²,育苗移栽更省种
- 间距: 15-20 cm(散叶生菜);结球生菜25-30 cm
- 间苗: 1-2片真叶时第一次,4-5片真叶定苗;间下的小苗可以吃

管理:
✓ 保持湿润: 根浅,表土一干就要浇,小水勤浇
✓ 薄肥勤施: 用腐熟堆肥或沤肥水;生长期短,尿液只在播种前作基肥
✓ 部分遮阴(夏季)

病虫害:
- 霜霉病、软腐病: 不要浇得太多、行间保持通风,烂叶及时摘掉带出菜园
- 蚜虫: 肥皂水
- 抽薹(长出花茎、叶片变苦): 高温和长日照引起 → 避开盛夏,长足就收

收获:
- 外叶采收(持续生长): 长到8-10片叶后,每次从外面掰2-3片,留下菜心
- 或整株收获: 散叶生菜播后约40天;结球生菜在叶球紧实、手压有硬感时
- 生吃前充分清洗
```

### 小白菜/青菜

**周期**: 30-40天

```
种植:
- 适应性强,四季可种(北方冬季需要阳畦或拱棚)
  北方: 3月下-9月都能播,盛夏选耐热品种、加防虫网和遮阴
  南方: 几乎全年;7-8月用耐热品种
- 发芽: 20-25°C,2-4天出苗;耐寒,4-5°C也能慢慢发芽
- 撒播或条播: 覆土0.5-1 cm;撒播用种约1-1.5 g/m²
- 间距: 10-15 cm
- 间苗: 出苗后约7天间一次,3-4片真叶定苗;间下的嫩苗就是"鸡毛菜"

管理:
✓ 充足水分: 缺水时纤维多、发苦、容易抽薹
✓ 速效氮肥: 定苗后追1次腐熟沤肥水或稀粪水(人粪尿不用于这种快菜);
   有化肥时尿素约10 g/m²兑水浇
✓ 防虫(黄板、网罩): 播种后马上盖防虫网,四周压严,这是最有效的办法

病虫害:
- 蚜虫: 肥皂水喷洒
- 菜青虫: 手工捉、BT杀虫剂(苏云金杆菌,晴天傍晚喷效果好)
- 小菜蛾: 幼虫小,一碰就扭动、吐丝下垂 → 防虫网 + BT
- 黄条跳甲: 黑色小甲虫,一碰就跳,把叶子咬成密密的小孔,幼虫在土里吃根
  → 防虫网;不连作十字花科;前茬清园
- 软腐病(茎基部腐烂、发臭): 拔除病株,病穴撒石灰或草木灰

收获:
- 播后30-40天,株高15-20 cm,可分批间拔或整株收获
```

### 萝卜

**周期**: 30-60天(品种而异)

```
种植:
- 秋季最佳(秋萝卜个大、甜、耐储)
  北方: 7月下-8月中(立秋前后)
  南方: 长江流域8月下-9月;华南9-11月
  春季种小型萝卜(樱桃萝卜、四季萝卜),要选不易抽薹的春播品种
- 发芽: 20-25°C,3-5天出苗
- 直播(不移栽): 移栽伤主根,萝卜会分叉
- 播深1.5-2 cm;大萝卜穴播,每穴3-4粒;小萝卜条播
- 间距: 10-20 cm(中小型);大型秋冬萝卜株距25-30 cm、行距40-50 cm
- 土壤: 深厚疏松
  翻地25-30 cm以上,拣净石块;不要施未腐熟的粪(会分叉、招地蛆);黏土地起垄种

管理:
✓ 苗期保湿
✓ 间苗(保证间距): 1片真叶时第一次,2-3片第二次,5-6片定苗
✓ 膨大期充足水分: 根颈部表皮开裂("破肚")后需水最多;
   浇水要均匀,久旱后突然猛浇会裂根
✓ 磷钾肥: 基肥里加草木灰100-150 g/m²;破肚时追一次肥

病虫害:
- 蚜虫、黄条跳甲: 同小白菜
- 病毒病(叶片花叶、皱缩): 蚜虫传播 → 早防蚜虫;天气特别热的年份推迟几天播种
- 黑腐病、软腐病: 轮作,不积水

收获:
- 根据品种,30-60天;大型秋冬萝卜80-100天
- 标准: 肉质根充分膨大、根头部露出土面,叶色转淡、下部叶片开始发黄
- 及时收获(防空心): 拖得太久或后期缺水,萝卜变糠、空心
- 储存: 切去叶子,留顶部1-2 cm,埋在湿沙里,0-3°C
```

### 菠菜

**周期**: 40-50天

```
种植:
- 秋冬春(夏季抽薹): 菠菜遇日照变长、气温升高就开花
  北方: 秋播8月下-9月上,当年收;
    越冬菠菜9月中下旬播,入冬前长到4-6片叶,冬前浇一次"冻水"、
    盖一层碎草或粪土,来年早春最早上市;
    春播: 3月土一化冻就播
  南方: 9月-翌年2月分期播种
- 发芽: 15-20°C最好,超过25°C出苗差;种子外壳硬
  → 播前浸种12-24小时;秋播时浸后放阴凉处催芽,露白再播
- 撒播: 用种约4-6 g/m²;或条播,行距10-15 cm
- 浅覆土: 1.5-2 cm,保持湿润到出苗
- 菠菜怕酸: 酸性土上长不好、叶片发黄,先用石灰改土

管理:
✓ 保持湿润
✓ 氮肥为主: 3-4片叶后追1-2次
✓ 间苗: 株距5-10 cm

病虫害:
- 霜霉病(叶面黄斑,背面灰紫色霉层): 不要过密,雨后排水,病叶摘除
- 蚜虫: 肥皂水

收获:
- 10 cm高开始间拔
- 或整株收获: 株高20-30 cm;在花茎抽出之前收完
```

## 大白菜与甘蓝

这两种菜生长期较长,但产量高、耐储存,大白菜是北方冬季的当家菜。

### 大白菜

**周期**: 60-90天(早熟品种约60天)

```
种植:
- 播期要卡准,传统说法"头伏萝卜二伏菜"
  北方: 华北立秋前后(8月上中旬);东北7月中下旬
  南方: 长江流域8月下-9月;华南9-11月
  播得太早: 高温、蚜虫多,病毒病、软腐病重;播得太晚: 包心不实
- 发芽适温20-25°C,2-3天出苗
- 以直播为主: 起垄或做高畦,穴播每穴3-5粒,覆土约1 cm
- 株距40-55 cm,行距55-65 cm
- 基肥: 腐熟厩肥4-5 kg/m²

管理:
✓ 间苗3次,5-6片真叶定苗
✓ 叶片大量展开(莲座期)和开始包心时是需肥水高峰,各追一次肥;
   包心期保持地面湿润
✓ 收获前7-10天停水;北方降温前可用草绳把外叶拢起捆住,保护叶球

病虫害:
- 三大病害: 病毒病、霜霉病、软腐病
  → 不早播、早防蚜虫、轮作、高垄排水;软腐病株连土挖走,病穴撒石灰
- 菜青虫、小菜蛾、蚜虫: 同小白菜

收获:
- 叶球紧实,手按顶部有硬实感
- 北方在初霜后、气温降到-2°C以下的冰冻天气来临前收回
- 收后在地里晾晒2-3天,去掉烂叶,0-2°C窖藏或堆藏,定期翻倒
```

### 甘蓝(包菜)

**周期**: 定植后50-90天

```
种植:
- 适应性强,耐寒也较耐热,春秋两季
  北方: 春甘蓝1-2月温床育苗,3月下-4月上定植;秋甘蓝6-7月育苗
  南方: 以秋冬种植为主,7-10月育苗
- 育苗移栽: 播深约1 cm,6-8片叶时定植
- 株距35-50 cm,行距45-60 cm(早熟品种取小值)
- ⚠️ 春甘蓝先期抽薹: 幼苗长得过大(茎粗超过约0.6 cm)后再经历较长时间低温,
  会不包球直接抽薹开花 → 不要播得过早,育苗期间别让苗长得太大

管理:
✓ 莲座期和结球期追肥浇水
✓ 结球期大雨后排水;久旱后猛浇容易裂球

病虫害:
- 菜青虫、小菜蛾、蚜虫 → 防虫网、BT、手捉

收获:
- 叶球紧实时及时收;过熟会裂球
```

## 常见茄果类

### 番茄

**周期**: 育苗+100-120天

```
育苗:
- 早春室内育苗: 定植前50-60天播种
  北方露地: 2月中-3月上播种,晚霜后(约4月下-5月上)定植
  南方: 12月-翌年1月在保护地育苗,3月中下定植;秋番茄7月育苗
- 发芽适温25-30°C,低于12°C几乎不出;播深0.5-1 cm
- 播种后7-10天出芽(温度合适时5-7天)
- 2-3片真叶时分苗
- 4-5片真叶移栽(小苗缓苗快);传统的大苗在7-9片叶、第一穗花现蕾时定植

种植:
- 基肥: 腐熟厩肥或堆肥3-5 kg/m²,加草木灰150-200 g/m²
- 间距: 40-50 cm,行距60-70 cm;一畦种两行
- 深栽(促发根): 番茄茎上能长出不定根;徒长的高苗可以斜躺着栽,
  把茎埋到第一片真叶下方
- 插支架: 定植后一周内插好,"人"字架或单杆;用软绳"8"字形绑蔓,不要勒紧

管理:
✓ 充足阳光: 每天直射6小时以上
✓ 打侧枝(单干整枝): 每个叶腋长出的侧芽在5-7 cm长时掰掉
   (晴天上午掰,伤口干得快);留4-6穗果后,在最上面一穗果上方留2片叶摘心
✓ 开花期减少氮肥,增加磷钾肥: 第一穗果长到核桃大时开始追肥,之后每穗果追一次
✓ 均衡浇水(防裂果): 定植水、缓苗水之后适当控水("蹲苗"),
   第一穗果坐住后保持土壤均匀湿润;久旱后不要一次浇大水
✓ 下部老叶、病叶摘除,改善通风

病虫害:
- 晚疫病: 避免叶面积水
  识别: 叶片上水渍状暗绿至褐色斑块,潮湿时叶背有白霉;青果上褐色硬斑;
    阴雨凉爽时几天就能毁掉一片地
  → 浇根不浇叶,摘除下部叶片,病株拔除带出菜园;不和土豆相邻或接茬
- 早疫病: 下部叶片上有同心轮纹的褐斑 → 摘病叶,轮作
- 脐腐病: 果实顶端(脐部)黑褐色凹陷 → 不传染,是缺钙加上水分忽多忽少;
  均匀浇水,酸性土施石灰
- 病毒病: 叶片花叶、变细("蕨叶"),植株矮 → 防蚜虫、粉虱;整枝前洗手
- 蚜虫: 肥皂水
- 烟粉虱(小白飞虫): 黄板

收获:
- 果实开始转色(由绿变白、出现红晕)后即可采,放在室内会继续转红
- 霜前把青果全部采下,在室温下后熟,或做酱、腌制
```

番茄留种见[留种与育种-种子从湿果肉里取的作物](08-留种与育种.md#种子从湿果肉里取的作物番茄黄瓜)。

### 辣椒

**周期**: 育苗+90-120天

```
育苗:
- 早春育苗: 比番茄早约2周播种,苗龄70-90天
  北方: 1月下-2月中播种(需要温床),晚霜后定植
  南方: 11-12月或1月在保护地育苗,3-4月定植
- 温度: 25-30°C发芽(慢,7-14天);浸种后保湿催芽,露白再播
- 播深0.5-1 cm

种植:
- 间距: 30-40 cm,行距50-60 cm;北方常每穴栽2株
- 阳光充足
- 不宜栽得太深,与原土面平或略深

管理:
✓ 不耐涝(排水好): 积水几小时根就会坏;雨季清沟,南方用高畦
✓ 开花结果期增加肥水
✓ 采摘促进持续结果: 第一个果("门椒")早点摘
✓ 高温(超过32°C)会大量落花: 夏季浇水降温、适当遮阴、覆盖秸秆

病虫害:
- 疫病: 雨后茎基部变黑腐烂,整株突然萎蔫 → 高畦排水、轮作
- 炭疽病、日灼: 果实上凹陷斑或发白的晒伤斑 → 不要摘叶太多,让叶片遮住果实
- 病毒病: 防蚜虫
- 蚜虫、红蜘蛛、茶黄螨: 肥皂水,重点喷叶背

收获:
- 青椒: 果实充分长大、果皮有光泽、手捏发硬
- 红椒、干辣椒: 完全转红后采,晒干或成串挂干

品种:
- 甜椒、辣椒、朝天椒
```

### 茄子

**周期**: 育苗+100-120天

```
育苗:
- 春季育苗: 苗龄80-100天(茄果类中最长),北方需温床,1月下-2月上播种
- 发芽适温25-30°C,种皮厚、出苗慢;白天30°C、夜间20°C的变温催芽出得更快
- 播深0.5-1 cm

种植:
- 喜温暖: 怕冷,晚霜后、10 cm地温15°C以上才定植
- 间距: 50 cm,行距60-70 cm
- 深厚肥沃土壤: 基肥腐熟厩肥4-5 kg/m²

管理:
✓ 大肥大水: 第一个果("门茄")坐住后开始追肥浇水,每7-10天一次
✓ 整枝(去老叶): 门茄以下的侧芽全部抹掉;下部老叶、黄叶摘除,通风透光
✓ 支撑(防倒伏)

病虫害:
- 黄萎病(叶片从下往上、常常半边发黄萎蔫): 土传病害,连作越种越重
  → 与非茄科作物轮作3-4年以上
- 绵疫病(果实上水渍状斑,长出白色棉毛): 雨季多发 → 不让果实贴地,摘除病果
- 红蜘蛛、茶黄螨: 叶片发黄、果皮变粗变褐 → 叶背喷水、肥皂水
- 二十八星瓢虫(背上黑点多,啃叶成网状): 手捉,抖落到水盆里

收获:
- 看"茄眼"(萼片与果实相接处的一圈白色带): 白色带变窄、不明显时就该摘;
  果皮有光泽、手捏有弹性
- 摘晚了籽变硬、果肉发柴
```

## 瓜类

### 黄瓜

**周期**: 50-70天

```
种植:
- 春夏
  北方: 4月下-5月上直播(地温稳定在12°C以上),或3月下-4月育苗、晚霜后定植;
    秋黄瓜7月直播
  南方: 3-4月春播,7-8月秋播
- 直播或育苗移栽: 黄瓜根受伤后很难恢复,育苗必须用营养钵、带土坨移栽,
  苗龄约30天(3片真叶)
- 播深1.5-2 cm(直播2-3 cm),每穴2-3粒,出苗后留1株
- 发芽适温25-30°C,3-5天出苗
- 间距: 30-40 cm,行距60-70 cm
- 搭架或地爬: 搭架省地、通风、瓜条直;"人"字架高约2 m

管理:
✓ 保持土壤湿润: 根浅、叶大,最怕旱
✓ 开花结果期大肥水: 第一个瓜(根瓜)坐住后,每采收2-3次追一次肥
✓ 及时采收(促进持续结果): 根瓜要早摘,不让它和植株抢养分
✓ 整枝打杈: 主蔓结瓜的品种,把下部(约第5节以下)的侧枝摘掉;主蔓爬到架顶后摘心

病虫害:
- 霜霉病(叶面上被叶脉分隔成多角形的黄斑,背面黑灰色霉层): 湿度大时最重
  → 通风,浇根不浇叶,早上浇水不在傍晚浇
- 白粉病: 通风,喷小苏打水
- 枯萎病(白天萎蔫、早晚恢复,几天后整株死,茎基部纵裂): 土传病害
  → 轮作2-3年以上;有经验可用南瓜作砧木嫁接
- 蚜虫: 肥皂水
- 黄守瓜(橙黄色小甲虫,把叶片咬成圆圈,幼虫蛀根): 清晨露水未干时捕捉;根旁撒草木灰
- 苦瓜条: 缺水、低温、氮肥多时瓜会发苦;苦味成分(葫芦素)多时吃了会呕吐、腹泻,
  明显很苦的瓜不要吃

收获:
- 开花后8-12天,瓜条长到品种应有的大小、刺瘤明显、颜色鲜绿时摘
- 结瓜盛期每1-2天摘一次;老瓜留在藤上,植株就不再结新瓜
```

### 南瓜/西葫芦

**周期**: 60-100天

```
种植:
- 春夏播种: 晚霜后,地温15°C左右
  北方: 4月下-5月中;南方: 2月下-4月
- 直播: 每穴2-3粒,种子平放,播深3-4 cm;出苗后留1株
- 间距: 50-100 cm(占地大)
  爬地南瓜行距2-3 m、株距0.5-1 m;西葫芦(短蔓)株距50-60 cm、行距80-100 cm
- 挖穴施肥: 每穴放腐熟粪肥或堆肥3-5 kg,与土拌匀——种好南瓜的关键
- 南瓜可以种在地边、沟坡、篱笆下、肥坑旁,不占好地

管理:
✓ 耐旱,但开花结果期需水
✓ 粗放管理: 爬地南瓜每隔几节在蔓上压一把土,促生不定根、防大风翻蔓
✓ 人工授粉(提高坐果率): 早晨6-9点摘当天开的雄花,去掉花瓣,
   把花粉抹在雌花(花下带小瓜)的柱头上;阴雨天、昆虫少时尤其要做;
   没授上粉的小瓜几天后发黄脱落
✓ 蔓太多时保留主蔓和1-2条侧蔓;大果型品种每株留2-4个瓜

病虫害:
- 白粉病(叶面一层白粉): 小苏打水,去除重病叶
- 瓜实蝇(南方): 果实被产卵处流胶,内部腐烂生蛆 → 幼瓜套袋;烂瓜收集深埋
- 蚜虫、黄守瓜: 同黄瓜

收获:
- 西葫芦: 开花后7-10天,约0.25-0.5 kg时采嫩瓜
- 嫩南瓜随时可采
- 老南瓜: 果皮变硬、指甲掐不进,果柄木质化变黄褐色;
  霜前全部收回,采时留一段约5 cm的果柄

储存:
- 南瓜可长期储存(数月)
- 收后在温暖处放约10天让果皮更硬,然后放在10-15°C干燥通风处,不要堆压
- 是很好的储备食物;南瓜嫩梢(南瓜尖)和花也能吃
```

人工授粉和留种的细节见[留种与育种-套袋和人工授粉](08-留种与育种.md#套袋和人工授粉)。

## 根茎类

### 土豆

**周期**: 90-120天

```
种植:
- 春秋两季
  北方(华北): 春薯3月中-4月上(10 cm地温稳定在7-8°C以上);
    东北、西北一季作区4月下-5月上
  南方: 长江流域春薯1-2月(注意覆盖防冻),秋薯8月下-9月;
    华南、西南冬季种10-12月
- 种薯: 选无病、不烂、表皮光滑的薯块
  催芽: 播前2-3周放在15-20°C、有散射光的地方,
  芽长到1-2 cm、粗壮发绿时播种(暗处长出的白长芽易断)
- 种薯切块(带芽眼): 每块25-50 g,至少带1-2个芽眼;50 g以下的小薯整个播最好
  切到切面有褐色环或黑心的病薯 → 整个扔掉,刀在开水或75%酒精里消毒后再切
  切块拌上草木灰,晾1-2天让切口干燥再播,减少烂种
- 用种量: 约1.5-2.5 t/ha(每 m² 150-250 g)
- 沟栽,间距: 25-30 cm,行距60-70 cm
- 覆土10-15 cm: 先盖约8-10 cm,出苗后通过培土加厚

管理:
✓ 出苗后培土(2-3次): 苗高15-20 cm时第一次,封垄前最后一次,垄高培到20-30 cm;
   块茎露出土面会见光变绿
✓ 块茎膨大期充足水分: 开花前后需水最多;浇水不要漫过垄顶;收获前1-2周停水
✓ 花前追肥: 以钾肥(草木灰)为主;氮肥太多只长秧不结薯

病虫害:
- 晚疫病(最危险): 叶片边缘出现水渍状褐斑,潮湿时叶背有白霉,
  几天之内整片地变黑;块茎表面褐色凹陷,内部褐色腐烂
  (19世纪爱尔兰大饥荒就是这种病造成的)
  → 不和番茄相邻或接茬;培高垄,挡住病菌随雨水渗到块茎;
    茎叶发病严重时把地上部割掉带走,过约2周再挖,减少块茎染病
- 病毒病("退化"): 自己留的种薯一代比一代产量低,叶片皱缩、花叶
  → 选冷凉的高处地块留种,严格挑选健康植株;有条件用脱毒种薯
- 疮痂病(薯皮上粗糙的木栓斑): 碱性土和刚撒过石灰的地多发
  → 需要撒石灰改土时,安排在种其他作物的那一年
- 二十八星瓢虫: 手捉
- 地下害虫(蛴螬、地老虎、金针虫): 翻地时捡拾;不施生粪

收获:
- 茎叶枯黄时: 大部分叶片变黄枯萎
- 判断: 先挖一株,用拇指搓薯皮,搓不掉了才算老熟(嫩皮易破易烂)
- 选晴天挖,别用锄头碰伤薯块
- 挖出晾晒: 在阴凉通风处摊开晾几小时到一天,让表皮干燥;
  不要在烈日下长时间暴晒(会晒伤、变绿)
- 阴凉干燥处储存: 2-4°C,必须避光;伤薯、烂薯挑出来先吃

产量高,耐储存!

⚠️ 储存要避光: 发芽、表皮变绿的土豆含龙葵素,可引起中毒
- 少量发芽或变绿: 深挖去除芽眼和绿色部分
- 大面积发芽变绿: 整个丢弃
```

土豆的留种和实生种子见[留种与育种-土豆和红薯](08-留种与育种.md#土豆和红薯-用薯块繁殖),窖藏见[食物加工与保存-各类蔬菜的储存条件](../07-日常生活技能/01-食物加工与保存.md#各类蔬菜的储存条件)。

### 红薯

**周期**: 120-150天

```
种植:
- 育苗:春季,薯块催芽
  北方: 3月中下用温床育苗,5月上中旬栽插(晚霜后,地温15°C以上)
  南方: 2-3月育苗,4-5月栽春薯;6-7月麦收或油菜收后栽夏薯
  育苗步骤:
  1. 选无病斑、无冻伤、无破损的中等薯块(150-250 g)
  2. 有温度计时,在51-54°C温水中浸10分钟,防黑斑病(温度必须准)
  3. 头朝上斜排在温床上,薯块之间留一点空隙,盖土2-3 cm,浇透
  4. 前几天床温保持28-32°C(不超过35°C),出芽后降到22-25°C
- 剪藤扦插: 苗长20-25 cm、有5-7片叶时,在离床面3-5 cm处剪下
  (高剪的苗不带土,能少带黑斑病);一个苗床可以剪3-4茬
  苗不够时,先插到"采苗圃"里扩繁,长出的藤再剪
- 起垄: 垄距70-90 cm,垄高25-30 cm;疏松的垄里结薯多、薯形好
- 插法: 斜插或水平浅插,入土3-4个节,露出3-4片叶;阴天或傍晚栽,栽后浇透水
- 间距: 30-40 cm

管理:
✓ 前期少水(促扎根)
✓ 中期膨大充足水分
✓ 提蔓(轻轻提起藤蔓防止节上生根,不要翻藤伤叶)
✓ 少肥(氮肥少,防徒长): 基肥以堆肥和草木灰为主,红薯喜钾
✓ 缺苗及时补栽

病虫害:
- 黑斑病: 薯块上黑褐色圆形病斑,发苦
  → 选无病种薯、温汤浸种、高剪苗
  ⚠️ 有黑斑病斑、发苦的红薯不要吃,也不要喂牲畜(含毒素,牛吃了可中毒死亡)
- 茎线虫病(北方)、小象甲(南方): 轮作;收获时清除田里残留的薯块和薯藤

收获:
- 霜前收获: 气温降到15°C左右、茎叶还没受冻时收完;受过霜冻的薯很快腐烂
- 选晴天,挖时尽量不碰伤;在地里晾晒半天,让表皮干燥
- 可长期储存: 10-15°C,低于9°C会受冷害腐烂;入窖前挑出伤薯、病薯
- 嫩茎尖(红薯叶)是好蔬菜,夏季缺菜时可以多次掐尖吃
```

### 胡萝卜

**周期**: 70-120天

```
种植:
- 秋季最佳
  北方: 7月上中旬播种,10-11月收;春播3月下-4月,要选不易抽薹的品种
  南方: 8-9月播种,冬季陆续收
- 直播(不移栽)
- 种子带刺毛、吸水慢,出苗要10-15天: 播前搓掉刺毛,浸种12-24小时
- 撒播或条播: 条播行距15-20 cm;覆土约1 cm,盖一层草或遮阴保湿到出苗;
  用种约0.5-1 g/m²
- 间距: 5-10 cm(大型品种10-15 cm)
- 土壤: 深厚疏松
  翻25-30 cm以上,打碎土块、拣净石块;不施生粪(会分叉)

管理:
✓ 保持湿润(出苗前): 夏秋播种最常见的失败,就是出苗前表土被晒干
✓ 间苗: 1-2片真叶第一次,3-4片真叶定苗;同时除草(苗期长得慢,杂草容易压过它)
✓ 根开始膨大时追一次肥(草木灰 + 腐熟稀粪水)
✓ 后期控水(防裂根): 均匀浇水,不要久旱后大水猛浇
✓ 根的顶部露出土面变绿时,培土盖住

病虫害:
- 蚜虫: 肥皂水
- 根分叉: 土里有石块、硬土块、生粪,或移栽伤了主根
- 根蛆: 不施生粪

收获:
- 根据品种,70-120天
- 标准: 心叶变成淡绿、外叶稍发黄,根的肩部饱满
- 北方在严重冰冻前收完;南方可以留在地里随吃随挖
- 储存: 去叶,留顶部1-2 cm,埋在湿沙中,0-3°C
```

## 豆类

### 豇豆(豆角)

**周期**: 60-80天

```
种植:
- 春夏: 喜温怕冷,地温稳定在15°C以上再播
  北方: 4月下-6月;南方: 3-8月可分批播种
- 直播: 每穴3-4粒,播深3-4 cm,穴距25-30 cm,行距60-70 cm;出苗后留2-3株
  一般不必浸种(浸过的种子遇上低温湿土容易烂);土壤湿润但不过湿
- 搭架或矮生品种: 蔓生种抽蔓后插"人"字架,高2-2.5 m,引蔓上架

管理:
✓ 开花结荚期充足水肥: 开花前适当控水,防止只长叶不开花;
   第一批荚坐住后再追肥浇水
✓ 及时采收(嫩豆荚)
✓ 持续结荚长: 结荚后期再追一次肥,能"翻花"再结一茬

病虫害:
- 豆荚螟(豆野螟): 幼虫钻进花和嫩荚 → 早晨开花时检查,摘除被蛀的花和荚
- 蚜虫: 肥皂水、草木灰浸出液
- 锈病、煤霉病: 下部病叶摘除,不过密

收获:
- 开花后10-15天,荚条粗细均匀、豆粒刚开始鼓起、荚还没变松软时摘
- 每1-2天摘一次;捏住荚柄掰下,不要伤到同一花序上的其他花蕾
- 老荚里的豆粒可以晒干当干豆吃,或留种

⚠️ 豆角必须炒熟煮透,到失去生绿色、没有生豆味才能吃,否则会中毒

优点:
- 产量高
- 采收期长
- 豆科植物固氮(改良土壤)
```

未煮熟豆角中毒见[食物加工与保存-高风险食品与食物中毒](../07-日常生活技能/01-食物加工与保存.md#高风险食品与食物中毒)。

### 豌豆

**周期**: 90-120天

```
种植:
- 秋冬(耐寒): 南方10-11月秋播,幼苗越冬,来年4-5月收
- 北方冬季太冷,改为早春土壤一化冻(约3月上中旬)就播("顶凌播种"),
  6月收;播晚了遇上高温,结荚少
- 发芽: 2-5°C就能慢慢发芽,适温15-20°C
- 直播: 条播,行距30-50 cm(蔓生种60 cm以上),株距5-10 cm,播深3-5 cm
  用种约10 g/m²(按种子大小增减)
- 搭架: 蔓生种插1-1.5 m高的树枝或竹竿;矮生种不用架
- 豌豆最忌连作: 同一块地至少隔3-4年

管理:
✓ 苗期少肥水
✓ 开花结荚期增加
✓ 根瘤菌固氮: 在从没种过豌豆的地里第一次种时,
   从种过豌豆的老地里取一把土拌种,能带进根瘤菌

病虫害:
- 白粉病: 后期常见 → 适当早播,通风
- 潜叶蝇(叶片上弯弯曲曲的白色隧道): 摘除虫叶

收获:
- 嫩豆荚: 荚刚长足、豆粒还没鼓起(荷兰豆类)
- 青豆粒: 荚饱满、颜色鲜绿、还没发黄
- 成熟豆粒: 荚变黄干枯时收,晒干储存
- 嫩梢(豌豆苗、豌豆尖)也是好菜
```

### 菜豆(四季豆)

**周期**: 矮生种50-70天;蔓生种70-90天

```
种植:
- 比豇豆耐凉、不耐热(超过30°C大量落花)
  北方: 春播4月下-5月上,秋播7月;南方: 3月、8月
- 发芽适温20-25°C;种子大,怕又湿又冷,土太湿时不要浸种
- 直播: 每穴3-4粒,播深3-4 cm
  矮生种穴距约30 cm、行距40-50 cm;蔓生种同豇豆

管理:
✓ 蔓生种插架;开花前控水,开花结荚后保持湿润
✓ 及时采嫩荚

病虫害:
- 炭疽病、锈病: 轮作,摘病叶
- 蚜虫: 肥皂水

收获:
- 开花后约10-15天,荚充分长大、豆粒刚显出来时

⚠️ 和豆角一样,必须炒熟煮透再吃
```

## 葱蒜类

### 大葱/香葱

**周期**: 60-120天

```
种植:
- 四季可种(香葱);大葱一年一季
  大葱北方: 9月下秋播育苗越冬,或3月春播育苗;6月(芒种前后)定植,10-11月收
  南方: 香葱、分葱全年可种,夏季遮阴
- 育苗或分株
  育苗: 撒播,覆土0.5-1 cm,发芽适温15-20°C;葱籽寿命短,最好用上一年新收的种子
  分株: 香葱、分葱一丛掰成每份2-3株,剪去过长的根和叶尖后栽
- 间距: 5-10 cm(香葱)
  大葱沟栽: 沟距60-80 cm、沟深25-30 cm,株距4-6 cm,苗直立贴着沟壁栽

管理:
✓ 喜肥水
✓ 培土(大葱): 立秋后开始,每2-3周一次,共3-4次;先把沟填平,再培成垄;
   培土越高,葱白越长;不要埋住葱心(叶片分叉处)
✓ 多次采收: 香葱贴地留2-3 cm割,追肥后再长

病虫害:
- 葱蓟马(叶片上银白色细条斑): 蓝板;干旱时多发,适当浇水
- 葱蝇(地蛆,蛀食根和鳞茎): 不施生粪,轮作
- 紫斑病、霜霉病: 雨季排水

收获:
- 大葱: 霜降前后,叶片发黄、葱白充实时挖;晾几天后捆把,立放在背阴处或窖藏

优点:
- 易种
- 多次收获
- 驱虫(和其他菜间种有一定驱避作用,但不能代替其他防虫措施)
```

### 韭菜

**周期**: 多年生,种一次可收5-6年

```
种植:
- 播种: 春季3-4月或秋季,撒播育苗,覆土0.5-1 cm;出苗慢(10-15天),要一直保湿
- 定植: 苗高15-20 cm(播后约2-3个月)时,行距20-30 cm、穴距10-15 cm,每穴10-20株
- 分株: 老韭菜挖出一丛,掰开栽,最快最省事

管理:
✓ 定植当年不割或少割,让根长好
✓ 每次割后等2-3天伤口干了、新叶冒出来,再浇水追肥(马上浇易烂根)
✓ 韭菜的根茎每年向上长("跳根"),秋季或早春在上面培土1-2 cm
✓ 北方冬季地上部分枯死,根在土里越冬,早春最先发出来

病虫害:
- 韭蛆(根茎被蛀烂、叶片发黄萎蔫): 不施生粪;
  早春扒开根部土层晾晒几天,再覆细沙或细土
- 灰霉病: 通风,割后清除残叶

收获:
- 叶长20-30 cm时割,每20-30天一刀,割茬离地2-3 cm
- 一年割4-5刀;夏季韭菜粗老,可以不割,秋天收韭菜花
- 冬季可以遮光培育韭黄(见"冬季和缺菜季节")
```

韭菜、香葱的分株见[留种与育种-分株](08-留种与育种.md#分株)。

### 大蒜

**周期**: 180-210天

```
种植:
- 秋季(9-10月): 华北9月下-10月上;长江流域9-10月;华南10-11月
  东北、西北寒冷地区秋播会冻死 → 改为春播(土壤化冻后,3-4月)
  播得太早冬前长得太大易受冻,太晚根少不耐冻;冬前长到4-5片叶最好
- 选种: 选蒜头大、蒜瓣大而整齐的,只用大瓣;播前可用凉水浸泡一天
- 蒜瓣分开种植
- 间距: 10-15 cm(株距);行距约15-20 cm
- 尖端向上: 按入土中,覆土3-4 cm;太深出苗慢,太浅易被冻拔出土
- 用种量: 约250-350 g/m²(按蒜瓣大小)

管理:
✓ 越冬前浇水: 在土壤"夜冻日化"时浇"冻水";北方再盖一层碎草或地膜
✓ 春季返青追肥: 返青后浇水追肥一次
✓ 蒜薹采收后增肥(膨大)
✓ 抽薹前后需水多;挖蒜头前约1周停水

病虫害:
- 蒜蛆(根蛆): 生粪招来的 → 只用充分腐熟的肥
- 叶枯病、锈病: 轮作,不积水

收获:
- 蒜薹:春季
  薹的顶部(总苞)变白、薹茎弯成钩状时,在中午或下午(植株稍蔫、不易折断)抽出
- 蒜头:初夏
  抽薹后约20天,叶片大部分发黄、假茎变软时挖;
  挖出后用叶子盖住蒜头晾2-3天(防晒伤),编辫或扎把挂在通风处
- 青蒜(蒜苗): 密种、早收的嫩株
```

## 冬季和缺菜季节

```
一年中最缺菜的时候:
- 北方: 冬季到早春(12月-翌年4月);最难熬的是4-5月的"春淡":
  窖里的菜吃完了,新菜还没长起来
- 南方: 除了早春,还有7-9月高温暴雨,叶菜难长,叫"伏缺"

长期吃不到新鲜蔬菜会得坏血病(维生素C缺乏)
→ 提前安排: 秋季多种耐储菜、秋播越冬菜,冬季发豆芽
```

营养缺乏的识别和补充见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md)。

### 越冬种植

```
秋播越冬(第二年春天最早上市):
- 菠菜、大蒜、大葱、韭菜(根越冬);南方还有豌豆、蚕豆、油菜、菜薹、芥菜
- 北方用风障、阳畦、覆盖秸秆或地膜保护

早春抢种:
- 土壤一化冻就播菠菜、小白菜、生菜、小萝卜,上面盖小拱棚,能提早半个多月吃上

南方冬季:
- 是种菜的好季节: 白菜、萝卜、菜薹、芥菜、莴笋、甘蓝、豌豆苗

假植(北方传统):
- 晚秋还没长成的白菜、芹菜、菠菜,连根带土挖起,
  密排在阳畦或背风的浅沟里,培土、少量浇水,
  冬季慢慢长,随吃随取
```

### 储存与加工

```
秋季要有意识地多种耐储菜:
- 大白菜、萝卜、胡萝卜、土豆、红薯、南瓜、洋葱、大蒜
- 窖藏、腌制、晒干三条路一起走,不要只靠一种

腌菜、酸菜: 能吃一冬,但要腌够时间再吃,避免亚硝酸盐中毒
晒干菜: 豆角、萝卜条、白菜、茄子、南瓜条都可以晒干
```

窖藏见[食物加工与保存-窖藏](../07-日常生活技能/01-食物加工与保存.md#窖藏),腌菜见[泡菜、酸菜](../07-日常生活技能/01-食物加工与保存.md#泡菜酸菜)和[亚硝酸盐](../07-日常生活技能/01-食物加工与保存.md#-亚硝酸盐-腌菜要等够时间),晒干见[蔬菜和水果](../07-日常生活技能/01-食物加工与保存.md#蔬菜和水果)。

### 芽苗菜和豆芽

冬季屋里有一点温度,就能长出新鲜的菜,不需要土地。

```
豆芽(黄豆、绿豆): 3-5天就能吃,是冬季最可靠的维生素C来源,做法见营养章

豌豆苗:
1. 豌豆浸泡12-24小时
2. 平铺在底部有孔的浅盘里(铺一层湿布或薄土),盖湿布
3. 出芽后揭布,放在室内有光的窗边,每天淋水1-2次
4. 约10-15天,苗高10-15 cm时贴根剪下;有时还能再长一茬

萝卜苗、白菜苗: 撒在浅盘的湿土上,7-10天可吃

蒜苗: 蒜瓣一个挨一个立着摆在盆里的沙或土中,浇水,放在室内15-25°C处,
  2-3周长到约20 cm剪下,可以剪2-3茬

韭黄: 冬季在阳畦或屋里的韭菜根上扣瓦盆、盖黑色薄膜或厚草帘遮光,
  长出的嫩黄韭菜就是韭黄

⚠️ 发芽苗用的种子必须没有拌过药: 买来的商品种子常拌有杀虫杀菌剂
  (染成红、粉、蓝、绿色),不能用来发芽吃
⚠️ 发臭、发黏、长霉 → 整盘丢弃
```

豆芽的做法见[营养与营养缺乏病-豆芽](../07-日常生活技能/02-营养与营养缺乏病.md#维生素c-豆芽是最可靠的冬季来源),拌药种子的危险见[留种与育种-为什么种子断了农业就断了](08-留种与育种.md#为什么种子断了农业就断了)。

### 夏季伏缺

```
耐热菜(南方夏季的主力):
- 空心菜(蕹菜): 播种或扦插,喜水喜肥,割了又长,可割多次
- 苋菜: 撒播,30天左右可吃
- 豇豆、丝瓜、南瓜(连嫩梢一起吃)
- 红薯叶: 掐嫩茎尖,越掐分枝越多
- 木耳菜(落葵): 搭架,割嫩梢
小白菜、生菜: 用遮阳网或架下遮阴 + 防虫网,浇水降温
```

野菜可以补充缺菜季节,但必须100%确认,见[毒蘑菇与野菜误食-采食野菜野果的原则](../03-野外生存/09-毒蘑菇与野菜误食.md#采食野菜野果的原则)。

## 📝 蔬菜种植要点

```
新手推荐(易种高产):
1. 生菜、小白菜(快速)
2. 萝卜(简单)
3. 豆角(高产)
4. 葱(多次收获)
5. 番茄、辣椒(产量稳定)

轮作原则:
- 豆科→叶菜类→茄果类→根茎类→豆科
- 同一科(茄科: 番茄、辣椒、茄子、土豆)隔3-4年再种

四季安排:
- 春: 叶菜、茄果类育苗
- 夏: 瓜类、豆类
- 秋: 萝卜、白菜、秋豌豆、蒜
- 冬: 耐寒叶菜

关键技巧:
✓ 土壤肥沃疏松
✓ 薄肥勤施
✓ 适时浇水
✓ 病虫害预防
✓ 轮作倒茬
✓ 及时采收

最常见的失败:
✗ 播种期不对: 喜温菜被霜打,秋菜播晚了长不成,春季叶菜种晚了抽薹
✗ 小粒种子覆土太厚,或出苗前表土晒干
✗ 用生粪: 烧根、招地蛆、萝卜胡萝卜分叉
✗ 同一块地连年种同一科
✗ 雨季不排水: 辣椒、番茄、白菜烂根
✗ 只种夏菜,冬季和早春无菜可吃

安全:
⚠️ 粪肥必须腐熟;人粪不用于生吃的蔬菜
⚠️ 豆角、四季豆必须煮熟;发芽变绿的土豆、有黑斑的红薯、很苦的黄瓜不吃
⚠️ 农药按标签和安全间隔期使用,不用高毒农药
```
