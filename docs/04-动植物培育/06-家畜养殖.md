## 猪的养殖

### 为什么养猪?

```
优点:
✓ 生长快(5-6月出栏)
✓ 繁殖力强
✓ 肉产量高
✓ 杂食性(但不能喂泔水,见疾病防治)
✓ 猪粪是优质肥料

考虑:
- 投入较大(饲料、设施)
- 需要一定技术
- 气味较大
- 疫病风险(尤其非洲猪瘟,无疫苗)
```

**灾后视角**: 猪和人"抢粮食"——猪长1 kg肉要吃3 kg左右的粮食。粮食不宽裕时,猪只能少养,主要靠菜叶、薯藤、糠麸、豆渣这些人不吃的东西;羊、兔、牛吃草,不和人争粮,更适合粮食紧张的时候。

### 品种选择

**本地猪**:
- 适应性强,抗病力好
- 肉质好
- 生长较慢
- 耐粗饲: 能吃较多青粗饲料(糠麸、菜叶、薯藤),精料不足时比外来猪更扛得住
- 母猪性成熟早、母性好、产仔多(如太湖猪一窝常有十几头)

**外来猪** (如杜洛克、大白猪、长白猪):
- 生长快
- 瘦肉率高
- 饲料转化率高
- 但要求全价饲料和较好的猪舍,喂得粗就长不快,也更容易生病

**杂交猪**:
- 综合优势
- 新手推荐
- 杂交猪留作种猪,后代会性状分离、参差不齐;想长期自繁自养,最好保留本地母猪或纯种母猪(选育原理见[留种与育种](08-留种与育种.md))

### 猪舍建设

**选址**:
```
✓ 地势高燥
✓ 向阳背风
✓ 排水良好
✓ 远离居住区(200 m以上)
✓ 水源方便
✓ 离水井、水源至少30 m,并且在水源的下坡方向(防止粪水渗入)
✓ 下风向: 夏季主导风向的下游,气味不吹向住房
```

**猪舍结构**:
```
面积:
- 育肥猪: 1.5-2 m²/头
- 母猪: 3-4 m²/头

设计:
✓ 保温通风(冬暖夏凉)
✓ 干燥清洁
✓ 光线充足
✓ 坚固耐用

设施:
✓ 食槽(水泥或铁制)
✓ 水槽或自动饮水器
✓ 漏缝地板(利于清洁)
✓ 或水泥地面(有坡度排水)

分区:
- 睡卧区(干燥)
- 排粪区(易清理)
- 喂食区
```

**具体做法**:
```
地面和排水:
- 地面坡度约2%-3%(每米降2-3 cm),坡向排粪区和排水沟
- 睡卧区比排粪区略高,铺干草或木板,不要让猪睡在湿水泥地上
- 猪爱干净: 只要圈够大、分区明确,猪会固定在离食槽和睡处最远的角落排粪
  → 把排粪区设在低处、靠门、靠排水沟一侧,每天清理

墙和围栏:
- 围栏高约1 m(成年猪),要结实: 猪会拱、会撞,木栏的下沿要埋入地下或用石块压住
- 圈门向外开,方便清粪

通风和防潮:
- 冬天关窗保温,但屋顶或高处留通风口,让潮气和臭气散出去
- 进圈时眼睛刺痛、闻到很冲的氨味 = 通风不够,呼吸道病会多
- 墙上挂水珠、垫草发潮发霉 = 太湿,要加大通风、勤换垫草
- 防"贼风": 冬天墙缝、门缝的冷风直吹猪身最容易引起感冒腹泻,通风口要开在高处

防暑:
- 猪几乎不会出汗,气温超过约28-30°C就会热应激(张口喘、趴着不动、不吃)
- 遮阳棚、在圈里或运动场设泥水坑让猪打滚、往地面和猪身上洒凉水
- 夏天饮水一定要充足
```

### 仔猪选购

**选择健康仔猪**:
```
✓ 精神活泼
✓ 眼睛明亮
✓ 被毛光亮
✓ 食欲旺盛
✓ 粪便正常(不拉稀)
✓ 呼吸正常(无咳嗽)
✓ 体重适中(断奶时约7-10 kg)
✓ 有免疫记录

购买:
- 15-30 kg仔猪(断奶并保育后,更易养活)
- 本地信誉好的养殖场
- 查看防疫记录
```

```
❌ 不要买: 尾巴和屁股沾着稀粪的、毛长而乱且发暗的、
   弓背缩成一团的、皮肤有红斑紫斑的、咳嗽喘气的、走路跛的
❌ 不从发生过非洲猪瘟或其他疫病的地区引进猪,不买来路不明的便宜猪
✓ 新买的猪先单独关一个圈观察约30天,确认健康再和原有的猪合群(见防疫与免疫原则)
✓ 运回后先给少量清水,隔几个小时再少量喂料,第一周饲料逐渐过渡到自家的料
```

### 猪的饲料与喂量

**一头猪每天大致吃多少**(风干饲料,即粮食、糠麸、豆饼这类,不含青饲料的水分):

| 阶段 | 体重 | 每天饲料 | 每天饮水 |
|------|------|---------|---------|
| 保育仔猪 | 10-30 kg | 约0.5-1.5 kg | 约2-5 L |
| 生长猪 | 30-60 kg | 约1.5-2.2 kg | 约5-8 L |
| 育肥猪 | 60-110 kg | 约2.2-3 kg | 约8-12 L |
| 妊娠母猪 | — | 约2-2.5 kg(最后一个月约2.5-3 kg) | 约15-20 L |
| 哺乳母猪 | — | 约2 kg + 每头仔猪0.4-0.5 kg(常为5-7 kg) | 约25-40 L |
| 种公猪 | — | 约2.5-3 kg | 约15-20 L |

```
大致规律:
- 饮水量约为干饲料的2.5-3倍;天热、哺乳期更多
  → 饮水不足比少喂一顿料危害大得多: 吃得少、长得慢,严重时盐中毒
- 自由采食时,吃饱后槽里略有剩余为宜;每次喂完半小时后槽底还剩很多 = 喂多了或饲料不合口/猪病了

青粗饲料(人不吃的部分,能省不少粮):
- 菜叶、红薯藤、南瓜、萝卜、苜蓿、紫云英、野菜(不认识的不喂)
- 本地猪的日粮里,青饲料可以占到相当比例;外来猪和小猪消化不了太多粗纤维
- 青饲料要新鲜洗净,切碎;不要堆放发热(堆闷的菜叶会产生亚硝酸盐,猪吃了会中毒,
  表现为皮肤和黏膜发紫、呼吸困难、很快死亡)
- 糠麸、豆渣、酒糟(少量)、豆饼都是好饲料(来源见下方链接)
- 生大豆不能直接喂: 含抗营养因子,影响消化,要煮熟或炒熟

盐和矿物质:
- 盐: 饲料的约0.3-0.5%,拌匀;猪对盐敏感,用剩菜、咸菜喂猪或饮水不足时容易盐中毒
  (口渴、抽搐、转圈、死亡)
- 钙磷: 没有预混料时,用骨粉约1-2%(骨头烧透或煮透后砸碎磨粉)、贝壳粉或石灰石粉约1%
- 维生素: 青饲料充足一般不缺

❌ 霉变的玉米、花生饼、粮食不喂: 黄曲霉毒素会让猪肝坏死、母猪流产
❌ 不喂泔水和任何含肉的剩饭剩菜(非洲猪瘟,见疾病防治)
```

相关章节: 糠麸和豆饼的来源见[粮油加工](../07-日常生活技能/14-粮油加工.md);牲畜用盐见[制盐](../07-日常生活技能/15-制盐.md);霉变粮食见[食物加工与保存-黄曲霉毒素](../07-日常生活技能/01-食物加工与保存.md#黄曲霉毒素)。

### 饲养管理

#### 仔猪期(断奶-30 kg)

```
饲料:
- 仔猪料(高蛋白,易消化)
- 自由采食
- 清洁饮水

管理:
✓ 保温(18-22°C)
✓ 清洁干燥
✓ 防腹泻
✓ 分群饲养(10-15头/群)
✓ 去势(公猪,1月龄)
✓ 疫苗接种
```

```
补充说明:
- 刚断奶的一两周最容易拉稀: 饲料逐渐过渡,少喂多餐(每天4-5次),不要一次喂饱
- 保温判断看猪: 挤成一堆、发抖 = 冷;分散躺开、喘气 = 热;
  侧卧舒展、互相挨着但不挤压 = 合适
- 去势(阉割): 不作种用的公猪要去势,否则长大后肉有膻臊味;
  请有经验的人或兽医操作,器械和伤口消毒,术后保持圈舍干净干燥,观察几天有无化脓
- 合群: 不同窝的猪放到一起会打架,最好傍晚合群,合群时往猪身上洒同一种气味(如稀释的醋水)
```

#### 育肥期(30 kg-出栏)

```
饲料:
- 育肥猪料
- 或自配:
  * 玉米60-70%
  * 豆粕/豆饼15-20%
  * 麸皮5-10%
  * 预混料3-5%
  * 青饲料(菜叶、草)适量

饲喂:
- 每天2-3次
- 定时定量
- 先粗后精,先干后湿
- 充足清洁饮水

管理:
✓ 温度适宜(15-25°C)
✓ 通风良好(不要贼风)
✓ 干燥清洁(每天清理粪便)
✓ 适当运动(圈养注意)
✓ 保持安静
✓ 观察健康状况

饲料用量:
- 育肥期总耗料约300-350 kg
- 料重比: 约3:1(3 kg料长1 kg活重)
```

```
没有豆粕和预混料时(灾后常见):
- 蛋白质: 煮熟的大豆、豆饼、豆渣、蚕豆豌豆,苜蓿等豆科青草;
  鱼的下脚料要煮透(不要用任何猪肉制品)
- 矿物质: 骨粉、贝壳粉和盐,用量见上节
- 只喂玉米和糠: 猪会长膘不长个,长得慢,一头猪可能要养到一年
- 本地猪粗放饲养长到出栏常要8-12个月,这是正常的,不要为了催肥喂发霉的粮食

判断长得好不好:
- 每月称重(或用皮尺量胸围估重),生长期每天增重约0.5-0.8 kg算正常(本地猪粗养会少一些)
- 被毛有光泽、皮肤粉红、粪便成形不干不稀、吃完就睡 = 正常
- 毛长而乱、消瘦、拱墙吃土、互相咬尾巴 = 营养不足(缺盐、缺矿物质或蛋白质)或太挤
```

#### 出栏

```
时间:
- 5-6月龄
- 体重90-120 kg

判断:
- 体型丰满
- 背部平直
- 食欲开始下降(达到顶峰)

及时出栏(再养饲料转化率下降)
```

宰杀和肉品检查见[屠宰卫生与肉品检查](#屠宰卫生与肉品检查)。

### 母猪繁殖与接产

**选留和配种**:
```
选母猪:
- 来自产仔多、母性好的母猪的后代
- 奶头6对以上、排列均匀、没有瞎奶头(内陷不出奶的)
- 四肢结实、走路正常,外阴正常大小

初配年龄:
- 本地母猪约6-8月龄,外来/杂交母猪约8月龄、体重约120 kg以上
- 太早配种: 母猪自己还没长好,产仔少、以后体质差

发情识别(发情周期约21天,每次持续约2-3天):
- 外阴红肿,有黏液流出
- 不安、叫唤、食欲下降、爬跨其他猪
- 静立反应(最重要): 用手用力按压母猪腰背部,母猪站着不动、两耳竖起
  → 出现静立反应是配种的最佳时机

配种:
- 出现静立反应后约12-24小时配第一次,间隔约12小时再配一次,受胎率更高
- 没有公猪时,只能到附近有种公猪的人家配种(运猪注意防疫)
- 配种后约21天不再发情,基本可以认为怀上了;再次发情要补配
```

**妊娠期约114天**(俗称"三月三周三天")。

```
妊娠期管理:
- 前期不要喂得太肥: 过肥的母猪产仔少、难产多、压死仔猪多
- 最后一个月胎儿长得最快,加料(见饲料表)
- 避免惊吓、追赶、挤压、滑倒,不和其他猪打架
- 产前约1周把母猪赶进打扫消毒好的产房,让它熟悉环境
```

**产房和防压**:
```
- 产栏约2 m × 2.5 m,沿墙离地约20-25 cm、离墙约20-25 cm装一圈护仔栏杆(圆木或钢管)
  → 母猪躺下靠墙时,仔猪能从栏杆下躲开,不被压死(压死是仔猪死亡的主要原因之一)
- 一角用木板隔出仔猪保温区(只有仔猪能钻进去),铺干草,吊保温灯或放保温箱
- 温度: 母猪舒服约18-22°C,初生仔猪需要约30-34°C,所以要分开:
  母猪区凉一点,仔猪保温区热一点
```

**临产征兆和接产**:
```
临产征兆:
- 产前1-3天乳房膨大、发红
- 叼草做窝、起卧不安、频繁排尿
- 挤奶头能挤出奶: 前面的奶头能挤出 → 约1天内产;后面的奶头也能挤出 → 几个小时内产
- 阴门流出带血的羊水

接产准备:
- 干净的毛巾或软布、剪刀、细线(都煮过)、碘酒、保温箱/草窝、手电、记录本
- 接产人剪短指甲、洗手,戴一次性手套

接产步骤:
1. 母猪一般侧卧分娩,通常每隔约10-30分钟产一头,整窝约2-5小时
2. 仔猪出生后立即用干净布擦净口鼻黏液,再擦干全身(冬天尤其重要)
3. 脐带: 在离肚皮约4 cm处用线扎紧,在线外侧剪断,断端涂碘酒
   (脐带自己断了、不出血的,只涂碘酒即可)
4. 擦干后马上放到母猪奶头上吃初乳,弱小的放到前面的奶头(奶多)
5. 最后排出胎衣(胎盘),一般在最后一头仔猪产出后数小时内;
   胎衣排出后及时拿走,和死胎一起深埋,不要让母猪吃

假死仔猪(不呼吸但心还在跳):
- 清除口鼻黏液,倒提后腿轻拍胸部,或一手托头颈、一手托臀部做屈伸运动帮助呼吸

需要请有经验的人或兽医:
⚠️ 用力努责超过约30-60分钟仍不见仔猪产出
⚠️ 产出几头后停了很久(超过约1小时)且母猪还在用力或已经无力
⚠️ 阴门流出恶臭、发黑的液体,或母猪高热、不吃不喝
⚠️ 不要硬拉、不要用不干净的手和器械掏(会撕裂产道、感染)
```

**仔猪护理**:
```
✓ 初乳: 出生后尽快吃到,最初几个小时最重要;初乳里的抗体是仔猪唯一的免疫力
✓ 固定奶头: 头几天帮弱小仔猪固定吃前面的奶头,让整窝长得均匀
✓ 保温: 第1周约30-34°C,以后每周降约2°C;仔猪挤成一堆 = 太冷
✓ 补铁: 母猪奶里铁很少,圈养仔猪在3日龄左右要补铁(铁制剂按产品说明使用,或请兽医注射),
  否则约2-3周龄开始贫血(皮肤苍白、拉稀、长不大)
  → 没有铁制剂时: 每天往仔猪活动区放一铲干净的新鲜泥土(从没养过猪的地方挖的,
     深层土更干净),让仔猪拱食补铁
✓ 补料: 约7日龄开始在保温区放少量炒熟磨碎的粮食或仔猪料引诱采食
✓ 断奶: 一般约4-5周龄;家庭饲养可到6-8周龄,断奶时把母猪移走,仔猪留在原圈
✓ 母猪断奶后约3-7天再次发情,可以配下一胎
```

### 疾病防治

**预防为主**:
```
✓ 清洁卫生(每天清理)
✓ 消毒(定期,空栏消毒)
✓ 通风干燥
✓ 营养均衡
✓ 免疫接种(猪瘟、口蹄疫等)
✓ 驱虫(定期)
✓ 隔离病猪
✓ 观察异常(食欲、粪便、精神)
```

```
每天喂食时的观察(最省事的健康检查):
- 喂料时有没有猪不来抢食、离群独卧
- 粪便: 正常成形;拉稀、带血、粪球干硬像羊粪都不正常
- 呼吸: 安静时腹部起伏是否急促,有没有咳嗽
- 皮肤: 耳朵、腹下、四肢有没有红斑、紫斑
- 体温: 用兽用(或单独专用的)体温计测肛温,猪正常约38-39.5°C,超过40°C就是发热

驱虫:
- 猪蛔虫最常见: 仔猪进入育肥前驱一次,母猪产前约2周驱一次,种猪每年2-3次
- 驱虫药按体重和标签用量,驱虫后几天的粪便及时清走堆肥(里面有大量虫卵)

空栏消毒:
- 一批猪出栏后,清除全部粪便垫草 → 清水冲刷 → 用生石灰水(石灰乳)刷墙和地面
  → 空置晾干约1-2周再进新猪
- 生石灰遇水剧烈放热,溅入眼睛先刷去再大量冲水
```

石灰的安全使用见[石灰与建筑材料](../07-日常生活技能/16-石灰与建筑材料.md)。

**常见疾病**:
```
非洲猪瘟(最大威胁):
- 目前没有疫苗和特效药,死亡率接近100%
- 禁止用泔水(餐厨剩余物)喂猪: 国家明令禁止,也是主要传播途径
- 不从疫区购猪,外来人员和车辆进场前消毒
- 猪只突然高热、成批死亡,立即报告当地畜牧兽医部门

猪瘟:
- 疫苗预防!
- 高热、不食、便秘后腹泻、皮肤紫斑
- 发病立即隔离,报告兽医

腹泻:
- 仔猪常见
- 保暖,清洁饮水
- 抗菌药治疗
- 补液防脱水

呼吸道病:
- 咳嗽、气喘
- 通风,保温
- 及时治疗

⚠️ 严重疾病咨询兽医!
```

**非洲猪瘟: 更多要点**:
```
传播途径:
- 病猪、带毒猪肉和猪肉制品(香肠、腊肉、冻肉里的病毒能存活几个月)
- 泔水、剩饭剩菜里的猪肉
- 被污染的人、衣物、鞋、车辆、饲料、工具;蜱虫;野猪

表现:
- 高热(40-42°C)、不吃、扎堆、皮肤(耳、腹下、四肢)发红发紫
- 呕吐、便血、呼吸困难,往往几天内死亡;也可能先是一两头突然死亡

做到:
✓ 只喂自家的粮食、糠麸、青饲料;任何含肉的剩菜都不喂猪
✓ 进猪圈换专用的鞋和外衣;外人(尤其是其他养猪人、贩猪的人)不进猪圈
✓ 自家买来的猪肉、肉制品不要带进猪圈附近,切过生肉的手和刀不要碰猪食
✓ 防野猪接触家猪(围栏),防蜱虫
✓ 发现可疑: 立即把全部猪关在圈里、不出售、不宰杀、不转移,
  报告当地畜牧兽医部门;死猪不要剥皮、不吃、不扔进河里,
  按要求深埋或交给专门处理(见下方链接)
⚠️ 不要使用来路不明的所谓"非洲猪瘟疫苗"——没有获批的产品,
   非法疫苗反而可能造成新的毒株扩散

非洲猪瘟不传染人,但会让一个地区的猪几乎全部死光。
```

病死猪的处理见[卫生设施-病死动物处理](../07-日常生活技能/03-卫生设施.md#病死动物处理)。

```
其他:

口蹄疫:
- 猪、牛、羊都会得;嘴、舌、蹄冠、蹄叉起水疱,溃烂后跛行、流涎、不吃
- 传染极快,按国家要求免疫;发现可疑立即报告,不要自行处理和出售

仔猪腹泻的补液:
- 仔猪拉稀最怕脱水: 皮肤失去弹性、眼窝下陷、站不起来
- 继续让仔猪吃奶,另外给清洁温水或口服补液盐溶液自由饮用
- 黄色、白色稀粪多见于出生头几天到3周,常和受凉、圈湿、母猪奶头不洁有关
  → 保温、垫干草、母猪奶头和乳房擦洗干净,往往就能好转
- 成窝拉稀、带血、仔猪大批死亡,或伴有呕吐(可能是传染性胃肠炎、流行性腹泻)→ 请兽医

寄生虫:
- 蛔虫: 消瘦、长不大、咳嗽;驱虫(见上)
- 疥螨: 剧痒、蹭墙、皮肤结痂增厚,隔离并按标签用药,圈舍同时清理

猪链球菌病:
- 突然高热、关节肿、走路摇晃、转圈,或突然死亡
- 会传染人!处理病死猪时戴手套,手上有伤口时不要碰,病死猪绝对不吃(见人畜共患病)
```

## 羊的养殖

### 为什么养羊?

```
优点:
✓ 以草为主(成本低)
✓ 适应性强
✓ 抗病力强
✓ 繁殖力好
✓ 羊肉、羊毛、羊奶

适宜:
- 有草地、山地资源
- 粗放管理
- 小规模养殖
```

```
山羊和绵羊的区别:
- 山羊: 爱吃树叶、灌木嫩枝,能上陡坡,耐粗饲;产肉、奶、绒
  → 会啃树皮、毁幼林,放牧要远离新造林和果园
- 绵羊: 主要吃草,喜欢平缓草地,性情温顺合群;产毛、肉、奶
  → 怕湿热,低洼潮湿的地方容易得腐蹄病和寄生虫病
```

### 品种

**肉羊**:
- 波尔山羊、杜泊羊(引进)
- 小尾寒羊(本地,繁殖力强)

**奶羊**:
- 萨能奶山羊

**毛用羊**:
- 美利奴羊

**本地羊**:
- 适应性强,推荐

### 羊舍建设

```
选址:
✓ 地势高燥
✓ 向阳避风
✓ 靠近草场

羊舍:
面积: 1.5-2 m²/只(舍内)
高度: 2.5-3 m
地面: 干燥,略有坡度
通风: 良好
分区: 成羊、羔羊、产房

运动场:
- 舍外,面积2-3倍
- 设草架、饮水槽、遮阳棚
```

```
补充:
- 羊怕湿不怕冷: "羊卧干处",地面潮湿比冬天冷更伤羊(腐蹄病、寄生虫、肺炎)
- 防潮做法: 地面垫高夯实,铺干草或木条;或做离地约0.5-1 m的漏缝木条地板
  (木条宽约3-5 cm、缝约1.5-2 cm,羊粪能掉下去,蹄子卡不进去)
- 面积细分: 成年母羊约1.5-2 m²,带羔母羊约2-2.5 m²,种公羊约2-3 m²(单独圈),
  断奶羔羊约0.5-0.8 m²
- 草架: 让羊从栅栏缝里抽草吃,不把草踩在脚下(羊不吃踩脏的草,浪费很大)
- 防兽: 夜间关进有结实围栏和门的羊舍,狼、狗是羊的主要威胁
- 产房: 单独的小间,每只母羊约1.5 m × 1.5 m(俗称"母子栏"),
  冬天能挡风保暖,铺干净干草
```

### 羊的饲料与喂量

**一只羊每天大致吃多少**(以体重约50 kg的成年羊为例):

| 饲料 | 每天大约 | 说明 |
|------|---------|------|
| 鲜青草 | 5-7 kg | 放牧时自己采食;约为体重的10%-15% |
| 或干草 | 1.5-2 kg | 约为体重的3%-4% |
| 精料(维持期) | 不需要或0.1-0.2 kg | 草好时可以不喂 |
| 精料(妊娠后期、哺乳期) | 0.3-0.5 kg | 双羔母羊取上限 |
| 盐 | 5-10 g | 盐砖自由舔食或拌料 |
| 饮水 | 3-6 L | 哺乳期、天热、吃干草时更多 |

```
冬季储草:
- 北方舍饲期约4-5个月,每只羊要准备干草约200-300 kg(或相当量的秸秆+青贮)
- 干草: 草在开花初期割,晒到一折就断、不再有潮气才堆垛,下面垫高、上面盖顶防雨
  → 没晒干就堆的草会发热霉变,霉草喂羊会导致流产和中毒
- 秸秆(玉米秆、豆秸、花生秧): 铡短到约2-3 cm再喂,豆秸和花生秧营养比禾本科秸秆好

青贮(条件允许时):
- 青玉米秆等铡短到约1-2 cm,装进窖或塑料袋,层层踩实排出空气,完全密封
- 约40-60天后成熟,应有酸香味;发黑、发臭、长霉的不能喂

换料: 从放牧转舍饲、从青草转干草,用7-10天逐渐过渡,
      突然换料容易腹泻、胀气
```

### 饲养管理

**饲料**:
```
以草为主:
✓ 放牧(最佳,成本低)
✓ 干草(冬季)
✓ 青贮饲料
✓ 农作物秸秆

补充精料:
- 玉米、麸皮、豆粕
- 妊娠后期、哺乳期、羔羊补饲

矿物质:
- 食盐、骨粉
- 自由舔食盐砖
```

**饲喂**:
```
放牧:
- 早出晚归
- 夏季避开中午高温
- 冬季中午放牧
- 慢赶慢走
- 不食毒草、露水草(易胀气)

舍饲:
- 早晚各喂一次草
- 夜间加喂
- 先粗后精
- 少喂勤添
- 充足饮水
```

```
放牧的更多要点:
- 轮牧: 把草场分成几块轮流放,每块放几天就换,让草长回来(约3-6周后再回来);
  还能打断寄生虫的循环(虫卵随粪便落到草上,幼虫要一段时间才有传染性)
- 不要在低洼积水、有很多小螺蛳的地方放牧: 容易感染肝片吸虫
- 豆科牧草(苜蓿、三叶草)长得嫩、带露水或雨水时,先喂些干草再放,
  不要让饿羊猛吃 → 防瘤胃臌气
- 毒草: 认识当地常见毒草(如夹竹桃、杜鹃、蓖麻籽、萌芽的或霜打的高粱苗和玉米苗),
  新草场先观察;饥饿的羊最容易误食毒草
- 不让羊吃塑料袋、绳头: 积在胃里会堵塞
```

**繁殖**:
```
配种:
- 母羊8-10月龄
- 公羊1-1.5岁
- 自然交配或人工授精

妊娠:
- 150天(5个月)

产羔:
- 大多单羔,某些品种双羔、多羔
- 做好接产准备(产房、保温)

哺乳:
- 及早吃初乳(出生后2小时内)
- 母乳或代乳
- 2-3月龄断奶
```

```
发情识别:
- 绵羊发情周期约17天,山羊约21天;每次发情约1-2天
- 表现: 摇尾巴、外阴红肿有黏液、叫唤、食欲下降、主动接近公羊、接受爬跨
  (山羊表现明显,绵羊较不明显,常靠公羊来"试情")
- 初配看体重: 母羊体重达到成年体重的约70%再配,太小配种难产多

配种:
- 发情后约12-24小时内配种,隔约12小时复配一次
- 一只公羊自然交配可以负担约20-30只母羊(配种季节加喂精料)
- 种公羊几年就要换,不要用自己的女儿配种(近亲繁殖,后代体弱畸形)

配种季节安排:
- 尽量让羔羊在春季出生(早春),这时天气转暖、青草长出来,母羊奶多
- 妊娠约150天,倒推: 想早春3月产羔,就在前一年10月左右配种
```

**日常管理**:
```
✓ 定期清理羊舍
✓ 通风干燥
✓ 修蹄(定期)
✓ 剪毛(春季)
✓ 驱虫(春秋各一次)
✓ 疫苗(口蹄疫、羊痘等)
✓ 观察健康
```

### 羊的接产与羔羊护理

```
妊娠后期(最后6周):
- 胎儿长得最快,补精料(见饲料表)
- 饿着的双羔母羊容易得"妊娠毒血症": 精神沉郁、离群、站立不稳、磨牙、
  失明样乱撞,多在产前1-3周 → 预防靠喂够,一旦发生请兽医
- 避免拥挤、急赶、跳沟

临产征兆:
- 乳房胀大,能挤出初乳;外阴松弛肿大;腹部下沉,肷窝凹陷
- 离群、刨地、起卧不安、频频回头看腹部
- 有临产征兆的母羊赶进产房

正常分娩:
- 先露出水泡,接着是两只前蹄(蹄底朝下)和搭在前腿上的鼻子
  ——像跳水的姿势,这是正产
- 破水后一般约30分钟到1小时内产出;双羔的第二只常在约10-30分钟后
- 正产就不要插手,让母羊自己生

接产:
1. 羔羊产出后立即清除口鼻黏液;不呼吸时倒提后腿轻拍胸部、
   或用干草秆轻捅鼻孔刺激打喷嚏
2. 让母羊舔干羔羊(有利于母子相认);天冷时人帮着用干草或布擦干
3. 脐带一般自己扯断;断端涂碘酒;太长时在离肚皮约4-5 cm处扎线后剪断
4. 尽早帮羔羊找到奶头吃初乳,最好1小时内,最迟不超过2小时;
   第一天吃的初乳总量约为羔羊体重的10%-20%,分多次
5. 胎衣一般在产后几个小时内排出,拿走深埋;超过约12小时不下请兽医

需要帮助的情况(请有经验的人或兽医):
⚠️ 用力努责超过约30-60分钟不见羔羊
⚠️ 只露出一只前蹄、只露头不见前蹄、先露出尾巴或后蹄(胎位不正)
⚠️ 羔羊卡住、母羊已无力
帮助时: 剪指甲、洗手消毒、戴长手套、涂润滑(植物油或肥皂水),
       趁母羊努责时顺着产道向下后方轻拉;矫正胎位需要经验,不要蛮拉
⚠️ 接产时一定戴手套: 羊的胎衣、羊水可能带布鲁氏菌(见人畜共患病)
⚠️ 母羊流产(尤其是一群里接连流产): 胎儿和胎衣不要徒手碰,装袋深埋撒石灰,
   流产母羊隔离,报告兽医检测布鲁氏菌病

羔羊护理:
- 冻羔: 羔羊冰凉、站不起来 → 先温暖(放进约38-40°C温水里保住头部,或抱在怀里),
  回暖后擦干,再喂初乳;太弱吸不动的用奶瓶慢慢喂,不要灌进气管
- 母羊不认羔、奶不够: 把死羔的皮披在孤羔身上让另一只母羊认养,或人工喂奶
  (人工喂奶: 先喂初乳,之后用羊奶或牛奶,温热到约38°C,少量多次,奶具每次洗烫)
- 约7-10日龄开始让羔羊接触嫩草和少量精料,学吃草
- 2-3月龄断奶;断奶时把母羊移走,羔羊留在熟悉的圈里
- 不作种用的公羔: 由有经验的人在约1-2周龄去势,注意消毒和防破伤风
```

### 剪毛与修蹄

**剪毛**(绵羊,一般每年一次):
```
时间:
- 春末天气稳定转暖后(北方约4-6月),剪早了怕冻,剪晚了羊怕热、毛也会自己脱落
- 雨天、羊毛湿的时候不剪(湿毛储存会发霉);剪前约半天停喂,空腹好操作

做法:
1. 场地扫净铺垫布,一只羊剪完一只
2. 让羊坐着背靠人的腿(羊坐起来就不怎么挣扎),先剪腹部,再剪腿、
   然后从一侧剪到背部和另一侧
3. 剪刀贴着皮肤平推,留毛茬约0.5-1 cm,尽量一刀剪到底,不剪二茬(二茬毛短,没用)
4. 皱褶多的地方(颈部、腿后)把皮肤拉平再剪,防止剪破
5. 剪破的地方涂碘酒;伤口多的羊注意蝇蛆
6. 剪下的整张毛摊开,去掉粪块污毛,卷起装袋,放干燥处

之后:
- 剪毛后约1周内防雨淋、防受凉
- 剪毛后约2周可以药浴或驱除体外寄生虫(此时毛短,药效好)
- 一只本地绵羊每年产毛约1-3 kg,细毛羊更多

山羊绒: 春季用密齿梳子把底绒梳下来,不是剪
```

羊毛的清洗和纺线见[纺织、缝补与鞣皮-纺线](../07-日常生活技能/07-纺织缝补与鞣皮.md#纺线)。

**修蹄**:
```
为什么: 圈养、在软地上活动的羊,蹄壳会越长越长、向内卷,
       夹进泥粪 → 跛行、腐蹄病
多久: 舍饲羊约每2-3个月检查修一次;放牧在石子地上的羊磨损多,修得少

做法:
1. 雨后或用湿草地浸泡后蹄壳较软好修
2. 固定羊(坐姿或侧卧),抬起蹄子,先用小刀或签子清出蹄底泥粪
3. 用修蹄剪或锋利的刀削去长出的蹄壳边缘,把蹄底修平,和蹄冠线平行
4. 一点一点修,看到颜色变成粉红就停(再削会出血);出血时压迫止血,涂碘酒

腐蹄病:
- 蹄间红肿、发臭、流脓,跛行或跪着吃草
- 修去坏死的角质,清洗,隔离到干燥地方;
  用约5%-10%硫酸铜或硫酸锌溶液浸蹄(建一个浅槽让羊走过,每次站几分钟);
  严重的请兽医
- 根本还是羊舍和运动场干燥
```

### 疾病防治

```
预防:
✓ 清洁卫生
✓ 通风干燥
✓ 免疫接种
✓ 定期驱虫
✓ 营养均衡

常见病:
- 寄生虫病:定期驱虫
- 腹泻:清洁饮水,卫生管理
- 口蹄疫:疫苗预防
- 羊痘:疫苗,隔离病羊
```

```
健康检查:
- 健康羊: 合群、眼睛有神、反刍正常(吃完草后卧着嚼,每天几个小时)、粪便为成形的小粒
- 体温: 正常约38.5-40°C(山羊略高)
- 眼睑黏膜检查(判断寄生虫贫血): 翻开下眼睑,正常是粉红色;
  苍白甚至发白 = 严重贫血,多为捻转血矛线虫(胃里的吸血线虫),要立即驱虫
- 下巴下水肿("瓶颈"样)、消瘦: 也常见于严重寄生虫病

驱虫:
- 一般春秋各一次,放牧季虫多时可以加一次;按标签、按体重给药,驱虫后几天的粪便堆肥
- 同一种驱虫药长期反复用,虫会产生抗药性 → 不同类的药轮换使用,配合轮牧
- 体外寄生虫(虱、螨、蜱): 剪毛后药浴或按标签涂药

口蹄疫: 见猪的疾病防治,牛羊同样易感

羊痘:
- 体温升高,眼、鼻流分泌物,随后在少毛部位(眼周、嘴唇、乳房、腹下、
  尾根下)出现红斑 → 丘疹 → 水疱 → 结痂
- 传染性强,按免疫程序接种疫苗;发现病羊立即隔离,报告兽医,
  病羊用过的圈舍、用具彻底消毒;病死羊深埋
- 接触病羊的人手上偶尔会长痘疱("羊口疮"类似),处理病羊戴手套

小反刍兽疫("羊瘟"):
- 高热、口腔糜烂、流眼泪鼻涕、严重腹泻,山羊死亡率高
- 国家强制免疫病种;发现可疑立即报告,封锁、不要卖羊

梭菌病(羊快疫、肠毒血症等):
- 常常看不出症状就突然死亡,多发在换季、突然吃了大量精料或嫩草时
- 用多联梭菌疫苗预防;控制精料,换料逐渐过渡

瘤胃臌气(急症):
- 吃了大量带露水的豆科青草、霉变饲料后,左肷部(左侧肚子靠后的凹窝)
  迅速鼓起,敲起来像鼓,羊不安、张嘴呼吸,严重的很快窒息死亡
- 立即停喂;让羊站在前高后低的坡上,头朝上;
  在羊嘴里横衔一根木棍(两头用绳系在头后),促使它嗳气;
  轻按摩左腹部、牵着慢走
- 不见好转或很严重: 马上请兽医(穿刺放气要专业操作,位置不对会伤及内脏)
- 预防: 见放牧要点

吃粮过多(酸中毒):
- 羊偷吃大量粮食后,几小时到一天内不吃、腹泻、站不稳 → 请兽医
- 粮仓、饲料间门要关好

包虫病: 见人畜共患病(和狗有关,会传染人)
```

## 兔的养殖

### 为什么养兔?

```
优点:
✓ 繁殖力极强(1年数窝)
✓ 生长快(3-4月出栏)
✓ 占地小
✓ 投资少
✓ 饲料转化率高
✓ 以草食为主(成本低)
✓ 兔肉营养丰富
✓ 兔粪是优质肥料

非常适合小规模家庭养殖!
```

**灾后视角**: 兔子不和人争粮,房前屋后割的草就能养,一窝几只,两三个月就能吃,是家庭稳定吃上肉最快的办法。但兔肉很瘦,只吃兔肉而缺少脂肪和其他食物会营养不良("兔肉饥饿"),要和粮食、油脂一起吃(见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md))。

### 品种

**肉兔**:
- 新西兰兔、加利福尼亚兔、比利时兔
- 本地肉兔

**毛兔**:
- 安哥拉长毛兔

**皮兔**:
- 獭兔

### 兔舍建设

**笼养**(推荐):
```
兔笼规格:
- 成兔: 60×50×40 cm(长×宽×高)
- 母兔: 70×60×40 cm(需产仔箱)

材料:
- 木制或铁丝网笼
- 底网(防粪便积累)

放置:
- 室内或有遮蔽处
- 通风良好
- 避免阳光直射
- 离地30-50 cm
```

```
细节:
- 底网: 用竹片或镀锌铁丝网,竹片宽约2-2.5 cm、间隙约1-1.2 cm;
  缝太宽兔脚会卡住骨折,铁丝太细会磨出脚皮炎("脚皮炎"即脚底掉毛溃烂)
  → 在笼里放一块木板让兔子歇脚
- 木笼兔子会啃,木条外侧用铁皮或铁丝网包住
- 笼下设粪沟或接粪板,倾斜便于清扫;尿液有大量氨,粪尿要每天清
- 产仔箱: 约40 × 25 × 20 cm木箱,顶部开活盖,前面开一个离箱底约10 cm的出入口
  (防仔兔过早爬出),箱底钻几个小孔防潮
- 温度: 兔最适约15-25°C;超过约30°C容易中暑死亡,比冷更危险
  → 夏天遮阳、通风、地面洒水,笼里放一瓶冻过的水让兔靠着降温
- 防鼠、防猫狗、防蛇: 老鼠会咬死仔兔,也传病
```

**舍内散养或围栏**:
- 需要更大空间
- 清洁管理较难
- 地面散养兔子会打洞逃跑,也更容易得球虫病(兔吃到地上的粪);围栏底部要埋网,地面保持干燥

### 饲养管理

**饲料**:
```
主料:
✓ 青草、青菜(主食)
✓ 干草(常备,磨牙)
✓ 胡萝卜、白菜等

精料:
- 兔饲料(颗粒料)
- 或自配:玉米、麸皮、豆粕

禁忌:
❌ 带露水的草(易胀气)
❌ 腐烂变质饲料
❌ 突然换料(逐渐过渡)

注意:
- 宁干勿湿(干草为主,少喂水分大的)
- 但保证饮水

口诀: "兔吃百样草,看你找不找"
```

```
兔子爱吃的常见草和不能喂的:
✓ 好饲料: 禾本科野草、苜蓿、三叶草、蒲公英、车前草、苦荬菜、
  红薯藤、花生秧、桑叶、槐树叶、榆树叶,秋冬的干草和晒干的树叶
✓ 胡萝卜、红薯、南瓜等块根适量,作冬天的多汁饲料
❌ 有毒或有害: 夹竹桃、杜鹃、曼陀罗、毒芹、蓖麻叶、
   土豆的芽和绿皮、发芽的土豆、霜冻的菜叶、打过农药不久的草和菜
❌ 不认识的草不喂;路边、喷过除草剂的草不割

纤维很重要:
- 兔子靠盲肠消化纤维,干草、粗纤维不足会腹泻、胀肚;不能只喂精料和多汁菜叶

食粪(盲肠粪):
- 兔子每天清晨会从肛门直接吃掉一种软的、表面发亮的小粪团,这是正常的,
  里面有B族维生素和蛋白质,不要阻止
```

**饲喂**:
```
- 早晚各喂一次
- 夜间加喂(兔有夜食性)
- 定时定量
- 少喂勤添
- 清洁饮水(自动饮水器)

用量:
- 成兔: 每天鲜青草约300-500 g+精料约50-100 g
```

```
补充:
- 只喂草不喂精料时: 成兔每天约需鲜草0.5-1 kg(约为体重的15%-25%),
  外加干草自由采食;这样长得慢一些,但能养
- 妊娠后期和哺乳母兔需要多得多: 哺乳母兔可吃到平时的2倍以上,精料加到约150-200 g
- 饮水: 成兔每天约0.3-0.5 L,哺乳母兔约1 L;喂干草和颗粒料时一定要有水
  → 母兔产后缺水,可能吃掉仔兔
- 雨天割的湿草摊开晾干表面水分再喂
```

**繁殖**:
```
配种:
- 母兔5-6月龄
- 公兔6-7月龄

妊娠: 31天

产仔:
- 每窝6-10只
- 做好产仔箱(干草、兔毛保暖)
- 检查母兔是否哺乳

哺乳:
- 母乳30-40天
- 逐渐添加饲料
- 断奶后分笼

繁殖力:
- 年产5-6窝!
- 增殖非常快
```

```
发情识别:
- 兔没有固定发情周期,交配刺激才排卵(诱导排卵)
- 看外阴: 苍白干涩 = 未发情;粉红 = 刚开始;大红、湿润肿胀 = 最佳配种时机;
  紫黑 = 发情快过去了
  口诀: "粉红早,黑紫迟,大红正当时"
- 母兔不安、用下巴蹭笼、拱草、食欲下降

配种:
1. 把母兔放进公兔笼里(不要反过来: 公兔到陌生环境会先忙着闻味)
2. 正常情况几分钟内完成,公兔交配后会侧倒或后倒并叫一声
3. 交配后把母兔取出,轻轻提起后躯约十几秒,防止精液流出
4. 隔约6-8小时可以再配一次
- 一只公兔可以负担约8-10只母兔;每天配种不超过1-2次,连用2天休息1天
- 种兔不要近亲交配,隔几年从别处换公兔

妊娠检查:
- 配种后约10-12天,把母兔放在平面上,一手轻摸腹部后方两侧,
  能摸到一串花生米或葡萄大小、滑动有弹性的肉球 = 怀孕
- 动作要轻,不要用力捏(会流产);摸不到的再配
```

**日常管理**:
```
✓ 每天清理粪便
✓ 保持干燥清洁
✓ 通风(兔怕潮湿、闷热)
✓ 夏季防暑(遮阳、通风)
✓ 冬季保暖(防风,不需过高温度,兔耐寒)
✓ 观察粪便(正常为圆球状)
✓ 观察食欲、精神
```

```
补充:
- 抓兔: 一手抓住两耳后颈部的皮,另一手托住屁股;不要只提耳朵或后腿(会伤到兔)
- 磨牙: 兔牙一直在长,要经常有干草、树枝(柳、杨、果树枝)啃;
  门牙长得太长顶住嘴无法进食,要剪短(请有经验的人)
- 剪趾甲: 笼养兔趾甲过长会卷曲、挂伤,约2-3个月剪一次,避开里面的血线
- 毛兔: 安哥拉兔约每2-3个月剪(或拔)一次毛,剪毛后注意保暖
```

### 母兔产仔与仔兔护理

```
产前:
- 配种后约27-28天放进铺好干草的产仔箱
- 临产前1-2天母兔衔草做窝,并拔下自己胸腹部的毛铺窝 —— 正常现象
- 一定要有充足饮水
- 环境安静,产前产后几天不要让陌生人、狗猫靠近

产仔:
- 多在夜间或清晨,一般约半小时内产完
- 母兔自己会咬断脐带、吃掉胎衣、舔干仔兔,一般不需要帮忙
- 没有拔毛做窝的初产母兔,人帮着把它的腹毛轻拔一些铺进窝(同时露出奶头)

产后检查(第二天):
- 先把母兔引开(喂点青草),手上搓点窝里的草和毛(去掉人的气味)再查窝
- 拿出死仔、湿草、胎衣残留;数清仔兔数量
- 吃饱的仔兔: 肚子圆鼓、皮肤红润、安静成堆
- 没吃饱的仔兔: 肚子瘪、皮肤皱、乱爬、叫
  → 可能母兔缺奶或不愿喂;每天把母兔放进箱里喂一次(母兔一天只喂1-2次奶,
     每次几分钟,这是正常的)

寄养:
- 一窝太多(超过母兔奶头数,一般8个)或母兔缺奶,
  把多出的仔兔并到同期(相差1-2天内)产仔的另一窝,先在新窝里放一会儿沾上气味

仔兔成长:
- 约10-12天睁眼,约18-20天开始出窝吃草料
- 开始出窝时就放少量嫩草和精料让它们学吃
- 30-40天断奶: 最好先把母兔移走,仔兔留在原笼几天,再分笼(减少应激和腹泻)
- 断奶前后是兔一生中最容易死的阶段(球虫病、腹泻),饲料要干净,换料要慢

母兔吃仔、不喂仔:
- 常见原因: 缺水、缺盐/蛋白质、受惊吓、窝里有异味、初产母兔
- 对策: 保证饮水和饲料;安静;连续两窝都吃仔的母兔淘汰
```

### 疾病防治

```
预防:
✓ 清洁干燥!
✓ 通风
✓ 勤清粪
✓ 食具消毒
✓ 免疫接种
✓ 隔离病兔

常见病:
腹泻:
- 食物不洁、受凉、换料过快
- 停喂青料,喂干草,保温
- 口服抗菌药

球虫病:
- 幼兔常见,严重!
- 预防为主(药物,卫生)
- 症状:腹泻、消瘦、死亡

疥癣:
- 皮肤病,脱毛
- 隔离治疗,涂药

⚠️ 兔病来得快,重在预防!
```

```
补充:

兔瘟(兔出血症,最危险):
- 病毒病,往往没有征兆就突然死亡;有的抽搐、尖叫后死亡,鼻孔流出血性泡沫
- 一群兔可以在几天内大批死亡,多发于2月龄以上的兔
- 没有特效药,只能靠疫苗: 按疫苗说明,一般约35-40日龄首免,
  以后约每半年加强一次;引进种兔前问清免疫情况
- 发生兔瘟: 死兔深埋或焚烧,不吃不卖、不剥皮;笼具用火焰或消毒液彻底消毒,
  报告当地畜牧兽医部门
- 野兔、老鼠、苍蝇、人的鞋和衣物都能带入病毒 → 外人不进兔舍

球虫病:
- 断奶前后到3月龄最多发,腹泻、肚子胀大、消瘦,死亡率高
- 根本在于让兔子吃不到自己的粪: 笼底网粪能漏下去、每天清粪、
  饲料和饮水不被粪便污染、不在地面上喂草
- 断奶前后在饲料或饮水中按标签加抗球虫药预防,注意休药期

巴氏杆菌病(传染性鼻炎、肺炎):
- 打喷嚏、流鼻涕,兔用前爪擦鼻子(前爪内侧毛发黏结),严重时肺炎死亡
- 通风不良、氨味重时多发;病兔隔离,长期不好的淘汰

中暑:
- 天热时兔呼吸急促、耳朵发红发烫、趴着不动
- 移到阴凉通风处,耳朵上蘸凉水降温;预防比治疗重要(见兔舍细节)

胀肚(臌气):
- 吃了带露水的草、霉变或冻的饲料、大量豆类后,肚子胀大、不吃、磨牙
- 停喂多汁饲料,只给干草和水,轻揉腹部,让兔子活动

人能不能被传染:
- 兔的疥螨、皮肤真菌(癣)能传给人: 处理病兔戴手套,洗手
- 野兔可能携带兔热病,剥皮时注意,见人畜共患病
```

### 成本与效益

家庭养殖(10只母兔+2只公兔):

投入(首年):
- 种兔: 600-1000元
- 兔笼: 500-800元

## 牛、驴等役用牲畜

拉犁、拉车、推磨要靠大牲畜。它们的力气、挽具和干活时的照料见[车船与道路-畜力与挽具](../07-日常生活技能/18-车船与道路.md#畜力与挽具)和[车船与道路-牲畜的照料](../07-日常生活技能/18-车船与道路.md#牲畜的照料);这里讲日常的养。

```
先想清楚养不养:
- 一头牛一年要吃干草约3-4 t(或相当的青草、秸秆),还要圈舍和每天的照料
- 一户人家耕地少、没有草场,养一头大牲畜往往负担不起;
  几户合养一头、轮流使用,更划算
- 新手优先: 驴(好养、耐粗饲)或性情温顺的阉牛;马饲料要求高、较娇贵
```

### 牛的饲养要点

```
吃多少(以体重约400 kg的役用黄牛为例):
- 鲜青草约30-40 kg/天,或干草/秸秆约8-10 kg/天(约为体重的2%-2.5%)
- 干活的日子加精料约1-2 kg(玉米、豆饼、麸皮);农忙前2-3周就开始加,先把膘养起来
- 饮水约30-50 L/天,天热、干活时更多;水牛还需要泡水或泥浴降温
- 盐约30-60 g/天,盐砖自由舔食
- 秸秆铡短(约3-5 cm),最好和青草、少量精料混合;只喂干秸秆会越喂越瘦

注意:
- 牛是反刍动物: 吃完要卧下安静反刍,不要喂完马上使役
- 防胀气: 同羊,不要让饿牛猛吃带露水的豆科嫩草
- 饲草里不能有铁丝、钉子、碎铁片: 牛吃东西不细嚼,金属扎进胃壁会引起
  创伤性网胃炎(不吃、弓背、不愿下坡),甚至扎到心包致死
  → 铡草时注意捡出,草料堆放远离废铁
- 牛舍: 每头约4-6 m²,地面干燥防滑,铺垫草;
  拴系时绳子留够长度让牛能自如卧下起立
- 修蹄: 舍饲牛约每半年检查一次;蹄形异常、跛行要修
```

```
繁殖:
- 发情周期约21天,发情期很短(约半天到一天): 不安、哞叫、爬跨别的牛,
  被别的牛爬时站着不动是最可靠的标志,外阴流出透明黏液
- 配种时机: 俗话"早上发情下午配,下午发情第二天早上配"
- 母牛初配约15-18月龄、体重达到成年的约2/3
- 妊娠期: 黄牛约280天(约9个半月),水牛约310-330天
- 接产: 正产同羊(两前蹄加鼻子);破水后约2小时仍不见进展、胎位不正,请兽医
- 犊牛: 出生后1小时内吃上初乳,第一天总量约为体重的10%;
  脐带涂碘酒;犊牛舍保持干燥
- 母牛产后十几天开始可以轻活,哺乳期不要重役

役用:
- 牛约2-3岁开始调教,从拉空车、轻犁开始,逐渐加重
- 每天工作时间和休息见车船与道路的牲畜照料;夏天避开中午
- 不作种用的公牛去势后性情温顺,适合役用(请有经验的人或兽医操作)

⚠️ 安全: 公牛、带犊的母牛可能突然攻击;牛向后蹬踢,不要站在牛的正后方;
   牵牛用鼻环或笼头,不要把缰绳缠在手上
```

### 驴、马、骡的饲养要点

```
和牛最大的区别: 马属动物不反刍,胃小,一次不能吃太多;最怕"结症"(肠梗阻性腹痛)

吃多少(以体重约200 kg的驴为例):
- 干草或铡碎的秸秆约3-5 kg/天(约为体重的1.5%-2.5%),干活的日子加精料约0.5-1 kg
- 马按体重比例同样估算,但干重活时精料要多得多(马约2-4 kg)
- 饮水约15-30 L/天(驴),马约30-50 L/天
- 盐: 驴约20-30 g/天,马约30-60 g/天,盐砖自由舔食

怎么喂(老经验很有道理):
- "寸草铡三刀,无料也上膘": 草要铡得很短(约2-3 cm),驴马吃得多、消化好
- "马无夜草不肥": 少量多次,夜里加喂一次草,不要一顿喂饱
- 先喂草,后喂料;精料用水拌湿
- 干活回来先拴在阴凉处歇约半小时,汗干、喘匀了再饮水、再喂料
- 换饲料用约1-2周逐渐过渡

防结症(马、骡、驴最常见的急病):
- 原因: 突然换料、饲草太粗太长、饮水不足、吃了霉变或冰冻的饲料、累后马上喂饱
- 表现: 不吃、回头看肚子、刨地、起卧打滚、出汗、粪少或不排粪
- 处理: 立即停喂;牵着慢慢遛(防止翻滚扭伤肠子),请兽医;
  不要灌油灌药(灌进气管会致命),不要强迫重役
- 预防: 草铡短、喂匀、饮水足、霉草不喂

蹄: 约每1-2个月修一次;在硬路上干活的要钉掌(请有经验的掌工),见车船与道路
牙: 老驴老马的牙磨得尖锐不齐会吃不好、消瘦,需请有经验的人锉平

繁殖:
- 驴妊娠期约12个月(约360天),马约11个月(约340天);母驴、母马一般3岁左右配种
- 发情周期约21天,发情持续约5-7天,在发情的第2-3天开始配,隔1-2天再配
- 骡子是驴和马的杂交后代,几乎都不能生育,只能靠驴马杂交获得
```

**牲畜的人畜共患病**: 牛和羊一样能传布鲁氏菌病、炭疽,牛还能传结核病(喝生牛奶),见[人畜共患病](#人畜共患病)。马属动物的伤口、粪便和泥土里常有破伤风梭菌,照料牲畜的人受伤后注意[破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防)。

## 防疫与免疫原则

```
免疫(有疫苗时):
✓ 按当地畜牧兽医部门规定的免疫程序接种;口蹄疫、小反刍兽疫等是国家强制免疫病种,
  具体病种和时间以当地要求为准
✓ 疫苗冷藏保存(一般约2-8°C,按说明),不能冻(冻过的灭活苗失效),不能晒
✓ 只给健康的牲畜接种;病、瘦弱、临产的按说明推迟
✓ 一头(或至少一圈)换一个针头,针头和注射部位消毒,防止交叉感染
✓ 接种后观察约半小时(偶有过敏反应);记录日期、疫苗名称、批号
✓ 疫苗只能降低风险,不能代替卫生和隔离

没有疫苗时(灾后很可能):
- 生物安全就是唯一的防线,也是最便宜的防线:
✓ 新引进的牲畜单独隔离观察约30天,没问题再合群
✓ 不同种类分圈(如羊不要和牛混养在同一个小圈,猪远离其他牲畜)
✓ 外人不进圈舍;自家人进圈换专用鞋和衣服,或在门口设石灰池/消毒垫
✓ 防鼠、防蝇、防鸟、防野生动物接触(野猪→非洲猪瘟,野兔→兔瘟)
✓ 饲料、饮水干净;不同圈的工具不混用
✓ "全进全出": 一批出栏后空圈、清洗、石灰消毒、晾干再进下一批
✓ 发现病畜马上隔离,饲养员先喂健康的、最后喂病的,处理完换衣洗手

疫情报告:
⚠️ 短时间内多头发病或死亡、高热传染快、口蹄有水疱、突然死亡并从口鼻流血,
   都要立即报告当地畜牧兽医部门(乡镇兽医站)。
   这不是"惹麻烦": 及早扑灭能保住周围所有人家的牲畜。

兽药的一般原则:
- 抗菌药只对细菌有效,对病毒病(非洲猪瘟、口蹄疫、兔瘟)无效
- 按标签剂量和疗程,不要随意加量、不要几种乱混
- 遵守休药期: 用药后到屠宰、挤奶、收蛋之间要隔够标签规定的天数,期间的肉奶蛋不能吃
- 记录每次用药

病死畜处理: 深埋至少1.5 m、撒生石灰、远离水源;不吃、不卖、不扔进河里
```

病死畜的处理方法见[卫生设施-病死动物处理](../07-日常生活技能/03-卫生设施.md#病死动物处理)。

## 人畜共患病

养畜的人比别人更容易染上从牲畜传来的病。下面几种在我国农村最重要。**出现不明原因发热时,看病时一定告诉医生"我养羊/养猪/接触过病死牲畜"**,很多人因为没说而被长期误诊。

| 病 | 主要来源 | 怎么传给人 | 人的表现 | 关键预防 |
|----|---------|----------|---------|---------|
| 布鲁氏菌病(布病) | 羊、牛、猪(流产的最危险) | 接产、处理流产胎儿和胎衣时经皮肤伤口和黏膜;喝生奶;吸入污染尘土 | 反复发热(时高时低)、大量出汗、乏力、关节和腰痛、男性睾丸肿痛 | 接产戴手套;不喝生奶;流产物深埋 |
| 炭疽 | 病死的牛、羊、马等 | 剥皮、宰杀、吃病死畜肉;接触带芽孢的皮毛 | 皮肤上无痛的黑色焦痂样溃疡,周围肿;吃了病死肉可严重腹痛腹泻;吸入型极危险 | 病死畜不剥皮、不宰杀、不吃 |
| 猪链球菌病 | 病死猪 | 宰杀、处理病死猪时经手上伤口 | 高热、头痛、呕吐,可迅速发展为休克或脑膜炎 | 病死猪不宰不吃;处理时戴手套 |
| 包虫病 | 狗吃了羊、牛的病内脏后排出虫卵 | 人摸狗、吃被狗粪污染的食物和水 | 多年后在肝、肺长出囊肿 | 病内脏不喂狗;给狗驱虫;饭前洗手 |
| 绦虫病/囊虫病 | 猪、牛 | 吃没熟透的"米猪肉""米糁牛肉" | 肠里长绦虫;虫卵进入人体可在脑、肌肉形成囊虫,引起癫痫 | 肉煮熟煮透;厕所和猪圈分开 |
| 旋毛虫病 | 猪、野猪 | 吃生的或没熟透的猪肉 | 发热、肌肉剧痛、眼睑水肿 | 肉煮熟煮透,野猪肉尤其 |
| 狂犬病 | 狗、猫等 | 咬伤、抓伤 | 一旦发病几乎100%死亡 | 见[外伤处理-狂犬病预防](../01-日常疾病和伤害/02-外伤处理.md#狂犬病预防关键) |

**布鲁氏菌病的防护**:
```
✓ 接产、处理流产胎儿和胎衣、给母畜掏宫时戴手套(最好长臂手套)和口罩
✓ 手上有伤口时不接产,或包扎好再戴手套
✓ 流产胎儿、胎衣、垫草装袋深埋并撒生石灰,圈舍消毒;不要拿去喂狗
✓ 不喝生奶: 羊奶、牛奶一律煮沸后再喝,做奶酪、酸奶的奶也先煮
✓ 母畜不明原因流产(尤其是孕期后段、一群里接连流产),报告兽医检测
✓ 布病在人身上要长疗程用药才能治好,必须到医院诊治,不要自己乱吃药
```

**炭疽: 绝对不能碰的死畜**:
```
可疑的表现:
- 牛、羊、马突然死亡,死前高热、呼吸困难或什么症状都没有
- 尸体迅速膨胀,口、鼻、肛门流出黑红色、不凝固的血
- 尸体不僵硬或僵硬不全

做到:
❌ 绝不剥皮、不开膛、不放血、不吃、不卖
   (炭疽杆菌接触空气后形成芽孢,能在土壤里存活几十年;
    剥开尸体就等于把芽孢撒满地)
✓ 不要移动尸体,用塑料布盖住防苍蝇和狗,立即报告当地畜牧兽医部门,由专人处理
✓ 接触过可疑死畜、皮肤上出现无痛的黑色焦痂样疮时,马上就医,说明接触史
✓ 炭疽多发的地区,牲畜按当地要求接种疫苗
```

处理兽皮前务必读[纺织、缝补与鞣皮](../07-日常生活技能/07-纺织缝补与鞣皮.md#鞣皮)一节开头的安全须知: 只处理健康宰杀的牲畜的皮,病死、死因不明的一律不剥。

## 屠宰卫生与肉品检查

```
法律: 平时在我国,上市出售的猪、牛、羊等应经定点屠宰和检疫(有检疫证明);
     自家宰杀自食也要遵守当地规定。下面是没有检疫条件时的基本卫生常识,
     不能代替官方检疫。
```

**宰前**:
```
✓ 只宰健康的牲畜: 宰前一天观察,精神、食欲、呼吸、粪便正常,体温正常
❌ 病畜、病死畜、死因不明的牲畜、用药后还没过休药期的牲畜,不宰不吃
✓ 宰前约12-24小时停喂(照常给水): 胃肠空,开膛时不容易划破,肉也更干净
✓ 宰前让牲畜安静休息,不要追打(应激会让肉质变差、不耐存放)
```

**宰杀和开膛的卫生**:
```
1. 场地: 远离水源(至少30 m)、硬地面或铺垫,有清水;
   刀具、盆、挂钩事先洗净烫过
2. 宰杀要快、准,尽量减少牲畜痛苦;充分放血(放血不净的肉容易腐败)
3. 放完血后吊挂起来操作,不要在地上的泥土里剥皮开膛
4. 开膛时先把肛门周围割开扎紧,刀尖朝外、用手指护着往上划,
   不要划破胃肠和膀胱(粪便、胃内容物污染肉是最主要的污染来源);
   划破了就把污染的部分割掉,不要只用水冲
5. 内脏取出后放在单独的干净容器里,和胴体分开
6. 操作人戴手套,手上有伤口不参与;中途刀具污染了要换或烫洗
7. 结束后场地清洗,血水、废弃物深埋(不要倒进河沟),工具洗净晾干
```

**看内脏和肉(发现异常就别吃)**:
```
看什么:
- 脾脏: 是否显著肿大、发黑、切开流出黑色煤焦油样血
  → ⚠️ 这是炭疽的可疑信号: 立即停止操作,不要继续剖切,报告兽医
- 肝脏: 有没有白色的斑点、条纹,或大小不等的水泡样囊肿(包虫、肝片吸虫)
- 肺: 有没有大面积实变、化脓、结节(结核)
- 淋巴结(颈部、腹股沟等处的"肉疙瘩"): 是否肿大、出血、化脓
- 肌肉: 猪肉重点切开咬肌(腮帮子)、腰肌、心肌、膈肌,
  看有没有米粒大小、半透明的白色小泡(囊尾蚴,"米猪肉")
- 整体: 脂肪和皮下发黄(黄疸)、全身出血点、肉色发暗、有异味、脓肿很多

怎么办:
- 局部的小脓肿、个别寄生虫囊: 连同周围组织一起割掉深埋,其余彻底煮熟
- 米猪肉、多处异常、全身出血、黄疸、恶臭: 整头不吃,深埋
- 有病的内脏一律深埋,不要生喂狗(包虫病就是这样传开的)

旋毛虫肉眼看不出来 → 猪肉、野猪肉一律煮熟煮透(切开中心没有血色、肉汁清亮)
```

**宰后保存**:
```
- 宰后尽快把胴体挂在阴凉通风、防蝇的地方晾凉,不要趁热堆在一起
- 气温高时当天吃不完的要尽快腌、晒、熏制(见下方链接)
- 生熟分开: 切生肉的刀和案板不要直接切熟食
```

保存方法见[食物加工与保存-腊肉、咸肉](../07-日常生活技能/01-食物加工与保存.md#腊肉咸肉)和[食物加工与保存-肉干](../07-日常生活技能/01-食物加工与保存.md#肉干)。猪油的熬制见[粮油加工-熬炼动物油](../07-日常生活技能/14-粮油加工.md#熬炼动物油)。

## 粪污利用

牲畜粪便是种地最重要的肥料来源,但新鲜粪便里有寄生虫卵和病菌,直接用会烧苗、传病,**必须堆沤腐熟**。

```
大致产粪量(鲜粪,每天):
- 育肥猪约2-3 kg(加尿约5 kg以上)
- 羊约1-2 kg
- 兔约0.1-0.2 kg
- 牛约20-30 kg,驴约8-15 kg

堆肥做法:
1. 粪和垫草、秸秆、落叶混合(纯粪太湿太黏,不透气)
2. 堆成高约1-1.5 m的堆,湿度以手握成团、指缝见水但不滴为宜
3. 几天内堆内温度应升到约55°C以上(手伸进去烫手),保持几天能杀死大部分病菌、
   虫卵和草籽;约每1-2周翻堆一次,让外层翻到里面也被"烧"一遍
4. 堆上盖草或土防雨淋流失;堆肥场离水源至少30 m
5. 约1-3个月后(冬天更久),颜色变深褐、松散、没有臭味、有泥土气味,就是腐熟了

用法和用量:
- 作基肥: 腐熟粪肥约15-30 t/ha(约1.5-3 kg/m²),翻地时混入土中
- 生吃的蔬菜(生菜、黄瓜等)只用充分腐熟的粪肥,并在收获前较早施用
- 粪水、尿液也是好的速效肥,但要稀释、发酵后再用

其他用途:
- 猪粪、牛粪可以进沼气池,沼渣沼液作肥料;
  沼气池有窒息和爆炸危险,见下方链接
- 晒干的牛粪、驴粪饼可以当燃料
```

堆肥原理和施肥见[动植物培育-土壤改良](README.md#土壤改良);人粪尿和病原体存活时间见[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用);沼气的安全见[照明与能源-沼气](../07-日常生活技能/06-照明与能源.md#沼气);粪饼等燃料见[薪柴与林地管理-其他燃料](09-薪柴与林地管理.md#其他燃料)。

## 📝 家畜养殖要点

### 新手推荐

```
最适合:
1. 兔(繁殖快,投入小,管理相对简单)
2. 羊(有草地,粗放,耐病)

需经验:
- 猪(投入大,技术要求高,疫病风险)
```

### 选择建议

```
考虑因素:
✓ 资金(兔<羊<猪)
✓ 场地(兔占地小,猪羊需较大)
✓ 饲料来源(羊适合有草地,猪需购买饲料)
✓ 技术(兔羊粗放,猪精细)
✓ 目的(自食、出售、综合)
✓ 劳动力

家庭配置:
- 鸡10-20只(蛋肉)
- 兔10-20只(肉,高繁殖)
- 羊3-5只(有草地)

或:
- 鸡+猪1-2头(每年)
```

### 成功要素

```
✓ 清洁卫生(第一重要!)
✓ 科学饲喂(营养均衡,定时定量)
✓ 防疫驱虫(预防为主)
✓ 细心观察(早发现早治疗)
✓ 学习技术(书籍、有经验者)
✓ 记录管理(饲料、疫病、效益)
✓ 适度规模(别贪大,稳步发展)
```

```
记录本至少记: 每头(只)牲畜的来源和出生日期、配种日期和预产期、
产仔数和成活数、免疫和用药(含休药期)、驱虫日期、发病和死亡
→ 预产期: 猪 配种日+114天,羊 +150天,兔 +31天,黄牛 +280天,驴 +360天左右
```

### 注意事项

```
✓ 了解当地法规(养殖许可、环保)
✓ 防疫要求(动物防疫条件合格证)
✓ 环境保护(粪污处理)
✓ 邻里关系(气味、噪音控制)
✓ 人畜共患病防范(布病、狂犬病等)
✓ 人道养殖
✓ 市场风险(价格波动)
```

```
绝对不做:
❌ 用泔水、含肉剩菜喂猪
❌ 吃、卖、剥皮病死和死因不明的牲畜
❌ 徒手接产、处理流产胎儿
❌ 喝生奶
❌ 把病内脏生喂狗
❌ 牲畜成批死亡不报告
```
