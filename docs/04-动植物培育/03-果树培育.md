# 果树培育指南

## 果树种植的价值

```
优点:
✓ 维生素和营养
✓ 多年生(种一次收多年)
✓ 相对省工
✓ 经济价值高
✓ 美化环境

考虑:
- 需要耐心(2-5年结果)
- 占地较大
- 前期投入
- 需要一定技术
```

**灾后自给的角度**: 粮食一年一种,果树是"一次投入、几十年产出"。一棵管理好的成年苹果树或柿树每年能产50-150 kg果;枣、柿可以晒干,核桃、板栗是高热量、耐储存的"木本粮食"。缺点是从栽下到见效要3-5年,所以**越早种越好**,哪怕眼下粮食更紧,也值得在房前屋后、地边坡地先栽上几棵。

```
⚠️ 先想清楚:
- 选本地已经有人种、能结果的树种和品种,比引进"好品种"可靠得多
- 果树要占地几十年,不要种在以后要盖房、开渠、修路的地方
- 不要占用好的平地粮田;坡地、沟边、院落、地埂更适合果树
- 果树开花结果离不开蜜蜂等传粉昆虫,滥用农药会让果园"有花无果"
```

## 果树种植基础

### 选址

```
✓ 阳光充足(每天6小时以上)
✓ 排水良好(不积水)
✓ 土壤深厚肥沃
✓ 避风(或设风障)
✓ 水源方便

❌ 避免:
- 低洼易涝地
- 重粘土
- 地下水位过高
- 风口
```

**具体怎么看**:

```
1. 光照: 冬季中午看一看,地块大部分时间不被房屋、大树挡住
   - 光不足 → 枝条徒长、花芽少、果小不甜
2. 排水: 雨后半天地面仍有积水,或挖1 m深的坑第二天坑底渗出水
   → 不宜种,或起垄(垄高30-50 cm)后再种
   - 桃、樱桃、无花果最怕涝,积水2-3天就可能烂根死树
3. 土层: 有效土层最好1 m以上;下面是石头或硬土层,要挖大坑、换土
4. 酸碱性: 多数果树适合微酸到中性;板栗、柑橘喜微酸,
   枣、石榴、葡萄、无花果较耐盐碱
5. 冷空气: 山谷底部、洼地春天容易积冷空气发生晚霜,花被冻死
   → 选坡地中部(南坡、东南坡最好)
6. 风: 长期大风的地方,在上风方向种几行耐风树(杨、柳、榆、刺槐)做风障
```

土壤质地和酸碱性的判断见[地质矿物与土壤-简单的土壤质地判断](../08-基础科学知识/06-地质矿物与土壤.md#52-简单的土壤质地判断)和[酸碱性](../08-基础科学知识/06-地质矿物与土壤.md#53-酸碱性);酸性土用石灰改良见[石灰与建筑材料-改良酸性土](../07-日常生活技能/16-石灰与建筑材料.md#改良酸性土);晚霜规律见[天气观测与预报-霜冻](../08-基础科学知识/07-天气观测与预报.md#五霜冻)。

### 选种和砧木

果树几乎都用**嫁接苗**: 上面是品种(接穗),决定果子的样子和味道;下面是砧木,决定根系、耐寒耐旱耐涝能力和树的大小。

**选品种**:

```
✓ 最重要的标准: 在本地能正常越冬、正常结果
   - 问老农、看邻村的老树: 哪个品种年年结、不怎么生病
✓ 需冬季低温的果树(苹果、梨、桃、樱桃、杏)
   冬天要有足够天数处于约0-7°C,否则春天发芽开花不整齐、坐果差
   → 冬季温暖的南方种苹果、甜樱桃往往"光长树不结果"
✓ 不耐寒的果树(柑橘、无花果、石榴)在北方要选耐寒品种或采取防寒措施
✓ 早、中、晚熟品种搭配,延长采收期,也分散天气风险
✓ 需要授粉树的果树,至少选2个花期相同、能互相授粉的品种(见"授粉"一节)
✓ 灾后自给优先: 耐储存、能晒干的品种(晚熟苹果、晚熟梨、柿、枣、核桃、板栗)
```

**常见砧木**(亲缘相近才能接活):

| 果树 | 常用砧木 | 特点 |
|------|---------|------|
| 苹果 | 山定子、海棠(八棱海棠等) | 乔化,根深,寿命长,结果晚 |
| 苹果 | 矮化砧(M26、M9、SH系等) | 树小、结果早(2-3年)、需支架和较好水肥 |
| 梨 | 杜梨、豆梨 | 杜梨耐旱耐盐碱,豆梨适合南方湿热 |
| 桃 | 毛桃、山桃 | 毛桃耐湿适合南方,山桃耐旱耐寒适合北方 |
| 柑橘 | 枳(枸橘)、红橘 | 枳耐寒、抗病,但不耐盐碱 |
| 枣 | 酸枣 | 极耐旱瘠 |
| 柿 | 君迁子(黑枣)、野柿 | 君迁子耐寒耐旱,北方常用 |
| 核桃 | 本地实生核桃 | 野核桃、核桃楸也可 |

**选苗(买苗或从苗圃挑苗时)**:

```
✓ 合格苗:
- 嫁接口愈合良好,接口上方的品种部分粗壮
- 主根和侧根完整,须根多,根皮新鲜(刮一下是白色或黄白色、湿润)
- 干上芽饱满,皮色正常不皱缩
- 苹果、梨等一年生苗: 高约1 m以上,接口上方直径约1 cm以上

✗ 不要:
- 根被切得只剩一截、根发黑发霉
- 根上有瘤子(根癌病)
- 干上有流胶、腐烂斑、虫孔
- 皮皱缩、刮开发褐 → 已失水,难成活

起苗到栽植期间: 根系蘸泥浆或包湿草,不让风吹日晒;
不能马上栽的,挖沟斜放、用湿土埋住根和下半截干(假植)
```

嫁接、扦插、压条的操作步骤见[留种与育种-无性繁殖](08-留种与育种.md#无性繁殖),本章不重复。

### 定植

**时间**:
- 落叶果树:秋季落叶后至春季发芽前(休眠期)
- 常绿果树:春季(3-4月)

```
怎样选具体时间:
- 冬季不太冷的地区(冬季最低气温高于约-15°C): 秋栽好
  → 根系在冬前就开始恢复,来年发芽早、长势好
- 冬季严寒、多风干旱的北方: 春栽(土壤解冻后到发芽前)
  → 秋栽的苗冬天容易被冻死、抽干
  → 若一定要秋栽,栽后把苗弯倒埋土防寒,春天再扶起
- 常绿果树(柑橘等): 春梢萌发前,或南方雨季初期阴天栽,
  带土团栽、剪去部分叶片减少蒸发
```

**株行距**:
根据树种,一般:
- 大型果树(苹果、梨):4x5 m
- 中型(桃、李、杏、甜樱桃):3x4 m
- 小型(枣、石榴、无花果):2x3 m

| 果树 | 株距 × 行距 | 约每 ha 株数 | 说明 |
|------|------------|-------------|------|
| 苹果(乔化砧) | 4-5 m × 5-6 m | 330-500 | 树大、寿命长 |
| 苹果(矮化砧) | 1-1.5 m × 3.5-4 m | 1700-2800 | 需立支架,水肥要求高 |
| 梨 | 3-4 m × 4-5 m | 500-830 | |
| 桃、李、杏 | 3-4 m × 4-5 m | 500-830 | 开心形树冠展开大 |
| 甜樱桃 | 3-4 m × 4-5 m | 500-830 | |
| 柿 | 4-5 m × 5-6 m | 330-500 | |
| 核桃 | 5-6 m × 6-8 m | 210-330 | 早实品种可4 m × 5 m |
| 板栗 | 4-5 m × 5-6 m | 330-500 | |
| 柑橘 | 3 m × 4 m | 约830 | 柚类更大 |
| 枣 | 2-3 m × 3-4 m | 830-1700 | |
| 石榴、无花果 | 2-3 m × 3 m | 1100-1700 | |
| 葡萄(篱架) | 1-1.5 m × 2-2.5 m | 2700-5000 | |
| 葡萄(棚架) | 1-2 m × 4-6 m | 830-2500 | |

```
原则:
- 土薄、地瘦、坡地 → 树长不大,可适当密一些
- 土肥、水足 → 树长得大,要稀一些
- 宁稀勿密: 太密的果园几年后枝条交叉、通风透光差、病多果少,
  只能砍树,反而更费事
- 行向南北向为好,两侧受光均匀
- 高大的核桃、板栗、柿种在果园北侧或地边,不要挡住矮树的阳光
```

**定植坑**:
```
规格: 60-80 cm宽深

步骤:
1. 挖定植坑
2. 底部填有机肥+表土混合
3. 放入树苗(根系舒展)
4. 填土踩实
5. 浇透定根水
6. 树盘覆盖(保湿)

深度:
- 嫁接口露出地面5-10 cm
- "深栽不过嫁接口,浅栽不露根"
```

**逐步做法**:

```
1. 挖坑(最好提前1-2个月挖好,让底土风化):
   - 一般60-80 cm见方、60-80 cm深
   - 土层薄、底下是硬土或石块: 挖到约1 m见方、1 m深,捡出石块换好土
   - 密植园(矮化苹果、葡萄)可以挖通长的定植沟,宽深各约60-80 cm
   - 挖出的表土(上面30 cm左右的熟土)和底土(下面的生土)分开堆放

2. 施底肥、回填:
   - 每坑施腐熟的农家肥(厩肥、堆肥)约20-30 kg,
     可同时加骨粉或过磷酸钙约0.5-1 kg、草木灰约1 kg
   - 坑底先垫一层约20 cm厚的秸秆、杂草、落叶(粘土地尤其有用,改善通气)
   - 肥料和表土充分混匀,填入坑的中下部
   - 上面再填约15-20 cm厚的纯表土,让根不直接碰到肥料
   - 回填后浇一次透水让土沉实;来不及的话,填土时就高出地面约10-15 cm,
     预留下沉量
   ⚠️ 生粪、没腐熟的饼肥放进坑里会发酵发热、烧根,幼树成片死亡

3. 修根、浸根:
   - 剪掉断根、伤根、发霉的根,剪口要平
   - 过长的根适当剪短
   - 栽前把根泡在清水里半天到一天,或蘸泥浆(黄泥加水调成糊)

4. 放苗:
   - 在坑中间堆一个小土丘,把苗放在土丘上,根系向四周舒展开,不要盘在一起
   - 前后左右对齐成行(拉绳或目测标杆)
   - 嫁接口朝向迎风方向(接口处相对较脆,可减少风折)

5. 填土、提苗、踩实:
   - 先填表土,边填边把苗轻轻往上提一提、抖一抖,让土进入根缝
   - 分层踩实,但不要用力踩在根上
   - 最后填底土,在树周围做一个直径约1 m的圆形土埂(树盘),便于浇水

6. 浇透定根水:
   - 每株至少15-20 L,分两次浇,让水渗到根层
   - 水渗下后如果苗歪了、土沉了,及时扶正、补土
   - 第二天表土稍干后,在树盘上盖一层细土或覆盖物保墒

7. 定干: 栽后马上在离地一定高度处剪断主干,促使下部发出主枝
   - 苹果、梨: 约70-90 cm(矮化苹果按纺锤形管理,可不定干或轻剪)
   - 桃、李、杏: 约40-60 cm
   - 枣: 约60-80 cm
   - 剪口下20-30 cm范围内要有5-8个饱满芽
   - 剪口涂蜡或漆,防止失水
```

**栽植深度和嫁接口**:

```
✓ 栽后(土沉实后)的深度 ≈ 苗在苗圃时的深度
   → 看干上的土痕: 土痕附近颜色深浅交界的地方就是原来的地面
✓ 嫁接口必须露出地面约5-10 cm

为什么:
- 栽得太深: 根缺氧,长势弱,多年不旺;
  接口埋进土里,上面的品种部分会自己生根,
  矮化砧失去矮化作用,抗性砧木的作用也没了;接口还容易腐烂
- 栽得太浅: 根系露出,干旱、受冻,被风吹倒

判断栽得对不对:
- 一个月后苗没有明显下沉,接口仍在土面以上
- 树盘浇水后土面不再出现大裂缝
```

### 幼树管理

栽后头3年决定果园的成败。幼树死亡多半不是病,而是**缺水、被啃、被草压住**。

**成活期(栽后1-2个月)**:

```
1. 浇水: 无雨时每7-10天浇一次透水,每次每株约15-20 L
   - 粘土地宁可间隔长一点,浇水过勤会烂根
   - 用手指插入土中约5 cm: 湿润、能捏成团 → 不用浇;干散 → 浇
2. 覆盖: 树盘覆盖约10 cm厚的干草、秸秆或塑料膜,保湿、抑草、减少地温变化
   - 覆盖物离树干留出约5-10 cm空隙,紧贴树干容易招虫、霉烂
3. 支柱: 风大的地方或矮化苗,在旁边立一根木桩,用软布条"8"字形绑住,
   不要勒得太紧
4. 判断成活:
   ✓ 春栽后约3-4周芽开始膨大、绽出新叶 → 成活
   ✓ 用指甲轻刮树皮,下面是绿色、湿润 → 还活着,继续等
   ✗ 刮开是褐色、干的,枝条一折就断 → 已死,秋天或来年补栽
   ⚠️ 有时苗先发几片小叶又萎蔫(叫"假活"),是靠枝干里存的养分,
      根还没有长出来,这时更要保持土壤湿润,并在晴天中午适当遮阴
```

**头三年的管理**:

```
✓ 除草: 树盘(直径约1-1.5 m)内保持无草;杂草会抢水抢肥,还会把小苗"淹没"
✓ 追肥: 新梢长到约10-20 cm后开始,少量多次:
   - 每株每次稀释5-10倍的腐熟人尿或沼液约5-10 L,或腐熟鸡粪约1 kg
   - 在树盘外缘开浅沟施入,盖土后浇水
   - 立秋(约8月上旬)后不再施氮肥,让枝条成熟、利于过冬
✓ 防啃: 兔、羊、牛啃一圈树皮,树就死了
   - 用铁丝网、竹片、带刺的枝条围住树干,高约1 m
   - 羊群绝对不能放进幼龄果园
✓ 间作: 行间可以种矮秆作物(豆类、花生、红薯、蔬菜、绿肥),
   离树干至少1 m
   ✗ 不要间作玉米、高粱等高秆作物和爬蔓作物(遮光、缠树)
✓ 摘花: 栽后头1-2年开的花全部摘掉,先长树后结果
✓ 整形: 按选定树形轻剪、拉枝,不要重剪(重剪会推迟结果)
✓ 防寒: 北方头两三年冬季要培土、包干(见"冬季防冻与防霜")
```

## 常见果树

### 苹果

**品种**: 红富士、嘎拉、金帅等

**气候**: 温带,需要一定冬季冷量

**结果**: 嫁接苗一般3-4年开始结果(矮化砧2-3年,乔化实生砧4-6年);约第8-10年进入盛果期,管理好的乔化树盛果期可维持到30-40年

**种植要点**:
```
授粉:
- 大多需异花授粉
- 建议种2-3个品种
- 或嫁接不同品种

修剪:
- 冬季修剪(休眠期)
- 疏除过密枝、病虫枝
- 开心形或纺锤形

施肥:
- 基肥:秋季(有机肥)
- 追肥:春季萌芽、花后、果实膨大期

病虫害:
- 腐烂病:刮治病斑
- 蚜虫:早春喷药
- 红蜘蛛:生长季防治
```

**补充**:

```
- 适合年平均气温约8-14°C、冬季较冷的地区;红富士冬季耐寒性一般,
  极寒地区选寒富、金红等抗寒品种,或用山定子砧
- 大小年明显: 一年结很多、第二年几乎不结 → 必须疏花疏果(见"疏花疏果")
- 幼树枝条直立、只长不结 → 春季或秋季把主枝拉开到约70-90°(拉枝),
  能明显提早结果
- 腐烂病是北方苹果的头号病害: 树皮出现红褐色、水渍状、有酒糟味的病斑,
  手按发软;要在早春仔细检查,发现就刮(做法见"病虫害防治")
- 富士晚熟、耐储存,窖藏可存到第二年春天
```

**收获**: 9-11月(品种而异)

### 梨

**品种**: 雪花梨、鸭梨、砀山梨等

**气候**: 适应性强,较耐寒

**结果**: 3-5年,盛果期20-30年

**种植要点**:
```
特点:
- 需异花授粉(配置授粉树)
- 喜湿润

管理:
- 整形修剪(疏散分层形)
- 充足灌溉
- 疏花疏果(提高品质)

病虫害:
- 梨黑星病:清除落叶,喷药保护
- 梨木虱:早春防治
```

**补充**:

```
- 寿命长,管理好的老梨树能结果百年以上
- 鸭梨、雪花梨、砀山酥梨等大多不能自花结实,
  授粉组合要选花期相同的品种(问当地果农最可靠)
- 一个花序有5-8朵花,只留1-2个果,间距约20-25 cm
- 黑星病: 叶背、果面出现黑色霉斑,果实变形开裂;
  秋冬彻底清扫落叶、剪除病梢烧掉是最有效的预防
- 梨木虱: 若虫分泌黏液,叶片发黑(煤污);冬季刮老翘皮、清园,
  早春越冬成虫出蛰时防治
- 秋子梨、南果梨等小果型品种极耐寒,适合东北
```

### 桃

**品种**: 水蜜桃、油桃、黄桃等

**气候**: 喜温暖,较耐旱

**结果**: 2-3年(早),盛果期10-15年

**种植要点**:
```
特点:
- 结果早
- 寿命相对短
- 生长快

修剪:
- 重要!
- 夏季摘心、疏枝
- 冬季短截、回缩
- 开心形

施肥:
- 喜肥
- 生长季多次追肥

病虫害:
- 桃缩叶病:春季发芽前喷药
- 蚜虫、红蜘蛛:及时防治
- 桃蛀螟:果实套袋
```

**特别**:
- 需疏果(早期摘除部分幼果)
- 提高单果品质

**补充**:

```
- 桃树一般15-20年后衰老,要提前在别处育苗、分批更新
- 桃大多自花能结实,单独一个品种也能结果
  (少数无花粉品种需配授粉树,买苗时问清楚)
- 疏果标准: 长果枝留3-4个、中果枝留1-2个、短果枝留1个或不留,
  果间距约15-20 cm;在花后约2-4周、果子黄豆到花生米大时疏完
- 桃树伤口容易流胶: 大剪口要涂封;避免在严冬修剪;
  积水、施生粪、虫伤都会加重流胶
- 桃缩叶病: 春天新叶皱缩、变红肿厚,像"烫伤";
  关键是发芽前(芽开始膨大时)喷一次铜制剂或石硫合剂,发病后再喷效果差
- 忌重茬: 老桃园挖掉后原地再种桃,往往长不好,换地或换土
- 极怕涝: 低洼地必须起垄种植
```

### 葡萄

**品种**: 巨峰、夏黑、阳光玫瑰等

**气候**: 适应性强

**结果**: 2-3年,盛果期20-30年

**种植要点**:
```
架式:
- 篱架、棚架
- 需搭架支撑

繁殖:
- 扦插(易成活)
- 压条

修剪:
- 冬季重剪
- 夏季摘心、疏梢

管理:
✓ 疏花疏果
✓ 果穗套袋(防病虫、提高品质)
✓ 充足水肥(果实膨大期)
✓ 冬季埋土防寒(北方)

病虫害:
- 霜霉病:雨季注意防治
- 白粉病:通风,喷药
```

**补充**:

```
搭架:
- 篱架: 每隔约4-6 m立一根约2 m高的桩(木桩、水泥桩、竹竿),
  拉3-4道铁丝,最下一道离地约50-60 cm,往上每隔约40-50 cm一道
- 棚架: 院子里的葡萄架,架高约1.8-2 m,便于人在下面走动和遮阴

冬剪(最重要):
- 时间: 落叶后约2-3周到土壤封冻前(北方埋土前完成);
  南方不埋土的,在落叶后到伤流开始前一个月剪完
  ⚠️ 春季树液流动后剪,剪口会大量"流水"(伤流),削弱树势
- 选留: 每个结果母枝留2-3个芽(短梢)或5-8个芽(中长梢),
  按品种和架式选择;其余一年生枝从基部剪除
- 老蔓逐年更新,不让架面上长满老枝

夏季管理:
- 抹芽: 一个芽眼长出2-3个梢的,只留1个最壮的
- 定梢: 新梢间距约15-20 cm,多余的抹掉
- 摘心: 开花前在果穗上方留约5-8片叶摘心,提高坐果
- 一个结果枝一般只留1穗;大穗品种剪掉穗尖约1/5,把副穗去掉

霜霉病: 叶片正面出现黄色油浸状斑,背面长出白色霜状霉层,
雨水多时几天就能让叶子落光;做好排水、通风,雨季前开始保护,
传统用波尔多液(硫酸铜与石灰配制,配比按专业资料或说明)
```

扦插、压条步骤见[留种与育种-扦插](08-留种与育种.md#扦插)和[压条](08-留种与育种.md#压条);北方埋土防寒做法见本章"冬季防冻与防霜"。

**收获**: 7-10月(品种而异)

### 柑橘类(橘、橙、柚、柠檬)

**气候**: 亚热带,不耐寒

**结果**: 3-5年

**种植要点**:
```
特点:
- 常绿果树
- 喜温暖湿润
- 怕霜冻

管理:
✓ 保持水分
✓ 施有机肥
✓ 修剪(通风透光)
✓ 防寒(北方盆栽,冬季移入室内)

病虫害:
- 溃疡病:剪除病枝叶
- 红蜘蛛、蚜虫:及时防治
- 潜叶蛾:夏秋梢防治
```

**补充**:

```
耐寒性(大致,低于此温度会受冻):
- 柠檬、柚: 约-2~-3°C
- 甜橙: 约-5°C
- 温州蜜柑、椪柑: 约-7~-9°C
- 金柑、枳砧的宽皮橘: 较耐寒

水分:
- "保持水分"不是天天浇: 土壤干到约5-10 cm深时浇透一次
- 夏秋干旱季节约每7-10天一次;秋末适当控水,有利花芽分化和提高糖度
- 雨季排水,根部积水易烂根、黄叶

施肥: 一年三次左右——春芽前(促春梢和花)、
     稳果后(壮果)、采果前后(恢复树势、保叶过冬)

修剪: 春季萌芽前为主,剪除枯枝、病虫枝、交叉枝、徒长枝,
     树冠保持"外密内空不能太空",以通风透光为准

坐果: 多数柑橘自花能结实或不经授粉也能结果;
     沙田柚等少数品种需要配授粉树或人工授粉

⚠️ 黄龙病(最危险): 叶片出现不对称的黄绿斑驳,新梢叶脉黄化,
   果小、着色不正常(红鼻子果)
   → 无法治疗,发现后整株挖除烧毁,并防治传播它的柑橘木虱
   → 只从可靠来源引苗,不随便从病区带苗、带接穗
```

### 樱桃

**品种**: 甜樱桃、酸樱桃、中国樱桃

**气候**: 喜冷凉,怕热怕涝

**结果**: 3-4年(甜樱桃),2-3年(中国樱桃)

**种植要点**:
```
特点:
- "春果第一枝"(最早成熟)
- 对环境要求高
- 经济价值高

要求:
✓ 排水极好(忌涝!)
✓ 配置授粉树
✓ 防鸟害(网罩或驱鸟)

管理:
- 轻剪缓放(促早结果)
- 夏季摘心
```

**补充**:

```
- 甜樱桃大多自花不实,至少配2-3个花期相同、能互相授粉的品种
  (少数自花结实品种如拉宾斯可单独种,但配授粉树产量更高)
- 中国樱桃(小樱桃)自花结实,适应性强,适合房前屋后
- 果实成熟前遇雨容易裂果;灾后条件下可选中国樱桃和小果型品种
- 鸟害: 成熟前约2周罩网,网眼约2-3 cm;挂反光条、彩带只能管几天
- 伤口易流胶,修剪尽量在生长季(采果后)进行
```

### 枣

**品种**: 冬枣、金丝小枣、大枣等

**气候**: 耐干旱,适应性强

**结果**: 2-3年(嫁接苗)

**种植要点**:
```
特点:
✓ 极耐旱
✓ 耐瘠薄
✓ 管理粗放
✓ 适合干旱地区

管理:
- 开甲(环剥,提高坐果率)
- 花期喷水(提高坐果)
- 枣头摘心

病虫害:
- 枣步曲:早春防治
- 枣锈病:雨季注意
```

**收获**: 鲜食或晒干

**补充**:

```
- 枣树寿命可达百年以上;发芽晚(春天各种果树里几乎最晚),
  正好躲过晚霜,北方种植很稳
- 根蘖苗(树下根上冒出的小苗)可以挖出来作砧木或直接栽
- 花期遇干燥热风("焦花"),坐果很差: 盛花期傍晚向树冠喷清水,
  隔2-3天一次,共2-3次

开甲(环剥):
- 对象: 只做在长势旺、干径约10 cm以上的成年树上;弱树、幼树不做
- 时间: 盛花期,大约一半花开时
- 方法: 第一次在主干离地约20-30 cm处,环切两刀,
  宽约0.3-0.5 cm(树越弱越窄),剥掉中间这圈树皮,不伤木质部
  以后每年往上移约3-5 cm
- 判断: 约1个月内伤口应完全愈合;1个半月仍未愈合要用泥抹住、塑料包好
⚠️ 开甲过宽、年年在弱树上开,树会衰弱甚至死亡;没把握宁可不做

- 枣步曲(枣尺蠖): 早春在树干上绑一圈塑料布或涂黏虫胶,
  阻止无翅雌蛾上树产卵
- 枣疯病: 枝叶簇生成"扫帚状"、花变成叶 → 无法治疗,病枝或病株挖除烧掉
- 晒干: 成熟后(果皮全红)采收,摊在席上暴晒,每天翻动,
  夜间收起或盖住防露水,约7-15天至含水量足够低、手握不黏
```

晒干的一般要求见[食物加工与保存-蔬菜和水果](../07-日常生活技能/01-食物加工与保存.md#蔬菜和水果)。

### 石榴

**气候**: 喜温暖干燥

**结果**: 3-4年

**种植要点**:
```
特点:
- 耐旱
- 观赏和食用兼具

管理:
✓ 充足阳光
✓ 花期、幼果期充足水分
✓ 疏除部分花果
✓ 修剪(通风透光)
```

**补充**:

```
- 冬季约-12°C以下易冻伤,北方选耐寒品种,幼树冬季培土或包草
- 花有两种: 花瓶状、下部膨大的"完全花"能结果;
  钟状、下部细的"退化花"一般不结果 → 疏花时优先疏掉退化花
- 树基部和根部常冒出很多萌蘖,及时从基部剪除
- 成熟期遇雨易裂果: 成熟前保持土壤湿度稳定,不要久旱后猛灌
- 可扦插繁殖,一年生枝条成活率高
```

### 无花果

**气候**: 喜温暖,较耐寒

**结果**: 当年或次年

**种植要点**:
```
特点:
✓ 结果极早!
✓ 管理简单
✓ 病虫害少
✓ 扦插易成活

管理:
- 粗放管理
- 修剪(控制树形)
- 冬季防寒(寒冷地区)

新手友好!
```

**补充**:

```
- 常见品种不用授粉就能结果,单株也能结
- 地上部约-10~-12°C以下会冻死,但根还活着、春天能重新发枝;
  北方把枝条压倒埋土,或种在南墙根下
- 一年可结两批: 夏果(去年枝上)和秋果(当年新梢上)
- 果实成熟后很软、不耐放,吃不完的及时晒干或煮成果酱
- 枝叶的白色乳汁会刺激皮肤,有人接触后在阳光下起红斑、水疱,
  采摘修剪时戴手套、穿长袖
```

### 柿

**气候**: 适应性强,北至华北南部、南至华南都能种

**结果**: 嫁接苗3-5年,盛果期很长,寿命可达百年以上

```
- 砧木: 北方用君迁子(黑枣),南方用野柿
- 多数品种不授粉也能结果(单性结实);雄花少的地区,
  附近有雄花的柿树或野柿有助于减少落果
- 树形: 疏散分层形或自然开心形;以疏枝为主、少短截
  (柿的花芽在枝条顶端附近,短截会把花芽剪掉)
- 管理粗放,病虫较少;柿蒂虫会蛀果,虫果早落,随时捡拾烧掉;
  炭疽病使果面出现黑色凹陷斑,剪除病枝、清园
- 涩柿要脱涩才能吃: 和成熟的苹果、梨一起密封放几天;
  或在约40°C温水中浸泡约1天
- 柿饼: 去皮后晾晒、捏软,约3-4周,表面"上霜";
  柿饼和干枣都是很好的冬季热量来源
⚠️ 空腹大量吃柿子(尤其未熟透、带皮)可能在胃里形成结石,
   引起腹痛、呕吐,严重时要到医院处理;一次不要吃太多
```

### 核桃

**气候**: 温带,较耐寒,怕晚霜

**结果**: 实生树约8-10年;早实品种嫁接苗2-3年开始,约10年进入盛果期

```
- 雌雄同株但开花时间常错开,多品种混栽或附近有其他核桃树,坐果更好
- 树大根深,要留足空间;叶片和根会分泌抑制其他植物的物质,
  树下不宜种番茄、苹果等敏感作物
- 修剪时间: 采收后到落叶前,或春季展叶后
  ⚠️ 休眠期修剪伤流严重,伤口会大量流液,削弱树势
- 采收: 青皮开裂、少数果实自然脱落时采收;堆放几天后青皮变软易剥
  ⚠️ 青皮汁液会把手染黑、刺激皮肤,剥皮时戴手套
- 核桃举肢蛾(黑核桃): 果实变黑早落 → 捡拾落果深埋或烧掉
- 晒干至坚果仁一折就断,放在干燥通风处可存放一年左右
```

### 板栗

**气候**: 温带至亚热带,喜微酸性、排水好的沙质土;盐碱地和粘重土长不好

**结果**: 嫁接苗3-4年开始,约8-10年进入盛果期

```
- 自花结实率低,一定要2个以上品种混栽,或附近有其他栗树(风媒+虫媒)
- 实生栗树结果晚、品质参差,最好用嫁接苗,或在实生树上嫁接好品种
- 栗瘿蜂: 芽被害后长成虫瘿,不能抽枝开花;冬季剪除虫瘿枝
- 栗实象甲(蛀果): 采收后把栗子倒入清水,捞去漂浮的虫果、空果
- 采收: 等刺苞自然开裂、栗子落地后每天捡拾,不要用竿子打树
- 保存: 鲜栗怕干又怕热,晾干表面水分后与湿沙分层堆放在阴凉处;
  也可晒干或煮熟后晒成栗干
```

## 果树管理技术

### 整形修剪

**目的**:
- 控制树形和大小
- 通风透光
- 促进结果
- 更新复壮

**时期**:
- 冬季修剪:休眠期(落叶果树)
- 夏季修剪:生长季

```
冬剪:
- 落叶后到春季发芽前,避开最冷的时段(约-10°C以下时剪口易受冻),
  北方多在早春(2-3月)剪
- 以疏枝、短截、回缩为主,决定第二年树形和产量

夏剪(生长季):
- 抹芽: 发芽后抹掉位置不当、过密的芽(用手即可,伤口最小)
- 摘心: 新梢长到一定长度时掐掉顶端,促使分枝、充实
- 疏梢: 剪掉过密的新梢、徒长枝
- 拉枝: 把直立枝拉成水平或斜向(用绳子拴在地上的木桩上),
  一般在春季或秋季进行,固定约1-2个月后解开

特殊时间:
- 核桃: 采收后到落叶前,或展叶后(休眠期伤流严重)
- 葡萄: 落叶后到伤流开始前一个月
- 桃、杏、李、樱桃: 伤口易流胶,避免严冬修剪,可推迟到早春或采果后
- 柑橘(常绿): 春季萌芽前为主
```

**基本方法**:
```
短截:
- 剪短枝条
- 促发新枝

疏枝:
- 从基部剪除
- 减少枝量

回缩:
- 剪去多年生枝的一部分
- 更新复壮

缓放:
- 不剪
- 促进结果
```

**怎样下剪**:

```
1. 先看整体: 绕树一圈,决定要去掉哪几根大枝,先疏大枝、再剪小枝
   → "先大后小、先上后下、先里后外"
2. 疏什么: 枯枝、病虫枝、交叉枝、重叠枝、向内长的枝、
   直立的徒长枝、根部和主干上的萌蘖
3. 短截的剪口:
   - 剪在一个芽的上方约0.5-1 cm处,斜面向芽的背面
   - 剪口芽朝外(朝树冠外侧),新枝才会向外长、树冠开张
   ✗ 留桩太长: 枯死成"干橛子",病菌从这里侵入
   ✗ 贴芽太近: 芽会干死
4. 疏枝的剪口: 贴着枝条基部的"领圈"(微微隆起的一圈)剪平,
   不留桩,也不要削进主干
5. 锯大枝(直径约5 cm以上)用"三锯法",防止树皮撕裂:
   ① 在要锯处外侧约20-30 cm,从下往上锯约1/3深
   ② 在①的外侧几厘米处从上往下锯断,枝条掉下
   ③ 最后贴领圈锯掉剩下的短桩
6. 伤口: 直径约2 cm以上的剪口、锯口削平后,涂蜡、油漆、
   或黄泥加少量牛粪调的泥,防止干裂和病菌侵入
7. 工具消毒: 剪过腐烂病、枣疯病等病树后,用75%酒精擦刀刃,
   或用开水烫,再去剪健康树

剪多少:
- 幼树: 轻剪,多拉枝、少短截,尽快成形、早结果
- 盛果期: 每年适量更新,保持树冠内外都有光
- 老树: 分2-3年逐步回缩复壮,一次剪太多会冒出大量徒长枝
- 修剪后看树冠: 站在树下能看到"筛子眼"大小的光斑透下来,比较合适
```

**常见树形**:
- 开心形:中心空虚,通风好
- 疏散分层形:有中心干
- 纺锤形:密植园

```
自然开心形(桃、李、杏,也可用于苹果、梨、柿):
- 干高约40-60 cm
- 没有中心干,3个主枝分别朝三个方向(彼此约120°),
  主枝上下错开约10-20 cm,与地面夹角约40-60°
- 每个主枝上培养2-3个侧枝,侧枝上着生结果枝
- 做法: 定干后选3个方向好的新梢做主枝,其余摘心或疏除;
  第二、三年剪掉中央直立枝
- 树高控制在约2.5-3 m,方便采收

疏散分层形(主干形的一种;苹果乔化树、梨、柿、核桃、板栗):
- 有中心干,主枝分2-3层,共5-7个
  - 第一层3个,第二层2个,第三层1-2个
  - 层与层之间约80-100 cm,让光线透进内膛
- 树高约4-5 m,成形需4-6年
- 适合株行距大、寿命长的大树

纺锤形 / 细长主干形(矮化密植苹果、梨):
- 一根直立的中心干(必要时绑在支柱上),
  上面螺旋状分布10-20个较小的枝,枝条拉成约70-90°甚至下垂
- 下部枝稍长、上部枝短,整体像一个纺锤
- 树高约2.5-3.5 m;某个枝条太粗(超过中心干的一半)就从基部疏掉换新的
```

### 施肥

**原则**: "有机肥为主,化肥为辅"

**基肥**(秋季):
```
- 有机肥(腐熟)
- 在树冠投影外缘挖沟施入
- 量:每株20-50 kg(成年树)
```

```
时间: 果实采收后到落叶前(约9-10月)最好
- 这时地温还高,断根容易愈合并长出新根,肥料能被吸收储存,
  来年发芽、开花、坐果都靠这些储备
- 晚到冬季或春天再施,效果明显变差

用量(经验):
- 幼树: 每株约5-10 kg
- 成年树: 每株约20-50 kg;
  经验上"每产1 kg果施1-2 kg腐熟有机肥"
- 可同时加入骨粉、草木灰(补磷、钾)

施法:
1. 环状沟: 沿树冠外缘(根系吸收最活跃的地方)挖一圈沟,宽、深各约30-40 cm
2. 放射沟: 从离树干约1 m处向外挖4-6条沟,里浅外深
3. 条沟: 密植园在行间一侧挖沟,第二年换另一侧
- 每年轮换位置,逐步把整个根区改良一遍
- 肥土混匀后填入,施后浇水
⚠️ 必须腐熟: 生粪烧根、招地下害虫
```

粪尿的安全处理和腐熟时间见[卫生设施-粪便与尿液的利用](../07-日常生活技能/03-卫生设施.md#粪便与尿液的利用);氮磷钾的作用见[动植物培育-施肥](README.md#施肥)。

**追肥**(生长季):
```
关键期:
1. 萌芽前:氮肥为主
2. 花后:氮磷配合
3. 果实膨大期:氮磷钾
4. 采收后:恢复树势

方法:
- 沟施或穴施
- 或叶面喷肥
```

```
具体做法:
- 穴施: 在树冠外缘挖6-10个深约15-20 cm的穴,施入后盖土浇水
- 没有化肥时: 稀释5-10倍的腐熟人尿、沼液,或腐熟的鸡粪、饼肥
  - 成年树每次每株约20-30 L稀释尿液,或3-5 kg腐熟鸡粪
- 果实膨大期多补钾: 草木灰每株约1-2 kg,撒在树盘浅翻入土
  (草木灰不要和人粪尿、铵态氮肥混在一起放,会损失氮)
- 叶面喷肥: 尿素约0.3-0.5%、磷酸二氢钾约0.2-0.3%(按包装说明配),
  傍晚或阴天喷叶背,见效快,但只是补充
- 判断:
  ✓ 叶片浓绿、新梢长度适中(约30-50 cm)、果实正常膨大 → 合适
  ✗ 叶色淡黄、新梢短 → 肥不足(先排除积水烂根)
  ✗ 新梢疯长、叶大而薄、果少着色差 → 氮过多,减少氮肥
- 晚秋(约8月以后)控制氮肥,否则枝条不充实,冬季易冻
```

### 浇水

```
关键期:
✓ 萌芽前
✓ 花后
✓ 果实膨大期
✓ 采收后
✓ 封冻前

方法:
- 沟灌、穴灌
- 滴灌(节水)

排水:
- 雨季及时排水(防涝)
```

```
浇多少:
- 每次要浇透根系分布层(约40-60 cm深),
  成年树每株约100-200 L;浅浇勤浇会让根往上长、更怕旱
- 判断: 浇后1天,在树冠外缘挖土看,40 cm深处仍湿润、能捏成团 → 浇透了

注意:
- 花期一般不大水浇灌(降低地温、加重落花),旱得严重可少量浇
- 果实成熟前2-3周控水,果更甜、更耐储,
  但不要久旱后猛灌(容易裂果)
- 封冻水: 土壤将冻未冻时(北方约11月)浇一次透水,
  减少冬季抽条和冻害
- 节水: 树盘覆草约10-20 cm厚,能明显减少蒸发;
  缺水地区可在树冠外缘埋陶罐、带孔的桶,灌水慢慢渗出
- 排水: 果园四周和行间挖排水沟,雨后6-12小时内地面不应再有积水
```

水渠和蓄水见[水源工程与供水](../07-日常生活技能/10-水源工程与供水.md)。

### 疏花疏果

**目的**:
- 提高果实品质
- 防止大小年(隔年结果)
- 保持树势

**时期**:
- 疏花:花期
- 疏果:坐果后2-4周

**方法**:
```
- 疏除畸形、病虫果
- 疏除过密、弱小果
- 保留位置好的果

留果量:
- 根据树势、品种
- 叶果比:30-50:1(苹果)
```

```
为什么一定要疏: 一棵树的养分是有限的。果子留太多,
个个又小又酸,树被拖垮,还会用光来年花芽的养分 → 第二年几乎绝收(大小年)

先疏花还是先疏果:
- 花期没有晚霜、坐果稳定的地区: 疏花(更省养分)
- 常有晚霜或授粉条件差: 先不疏花,等坐果后再疏果,稳妥

各树种留果参考:
- 苹果: 每个花序留中心果1个,果间距约20-25 cm
- 梨: 每个花序留1-2个,果间距约20-25 cm
- 桃: 长果枝3-4个,中果枝1-2个,短果枝1个,果间距约15-20 cm
- 葡萄: 一个结果枝留1穗,大穗掐去穗尖,过密的果粒疏掉
- 柿、枣、核桃、板栗: 一般不专门疏果,靠修剪调节

做法:
1. 用疏果剪或指甲掐断果柄,不要往下拽(会拉伤果台和来年的芽)
2. 先疏病虫果、畸形果、小果,再按间距疏多余的
3. 留下的: 果形端正、果柄粗壮、着生在枝条下方或侧面的
4. 分两次疏: 第一次粗疏,1-2周后定果,自然落果多时可少疏

判断: 疏完后看起来"太可惜了",往往就是合适的程度
```

### 授粉

很多果树**自己的花粉不能让自己结果**,只种一个品种,再怎么开花也只结很少的果。

| 授粉需求 | 果树 |
|---------|------|
| 必须配授粉树 | 苹果大多数品种、梨大多数品种、甜樱桃大多数品种、板栗、沙田柚等 |
| 配授粉树结果更好 | 核桃、枣、李、杏、柿(部分品种) |
| 单独一个品种也能正常结果 | 桃(大多数)、葡萄、柑橘(大多数)、石榴、无花果(常见品种)、中国樱桃 |

```
配授粉树:
- 授粉品种和主栽品种要: 花期相同、能互相亲和、本身也是好品种
  → 最可靠的办法是问当地果农,或看本地老果园怎么搭配
- 比例: 每4-8棵主栽树配1棵授粉树;也可以2个品种隔行种
- 距离: 主栽树离授粉树最好在约20 m以内,不超过约50 m
- 只有一棵树的: 在树上高接一两根授粉品种的枝条,一棵树开两种花
  (嫁接方法见留种与育种-嫁接)

帮助传粉:
- 果园里或附近放蜂箱(约每0.5-1 ha放1箱),或保护野蜂
- 花期绝对不喷杀虫剂
- 花期遇阴雨低温、蜜蜂不出来时,人工授粉

人工授粉:
1. 采花: 在授粉品种上采含苞待放的"大气球"期花朵
2. 取花药: 两花对搓或用梳子刮下花药,摊在纸上,
   放在约20-25°C干燥处1-2天,花药裂开散出黄色花粉
3. 点授: 在主栽品种开花当天到第3天,用毛笔、带橡皮头的铅笔
   蘸花粉轻点在柱头上;每个花序点1-2朵(中心花)
   - 花粉少时可加入2-5倍的淀粉或滑石粉作填充
4. 花粉放在干燥阴凉处,几天内用完
```

人工授粉的一般原理见[留种与育种-套袋和人工授粉](08-留种与育种.md#套袋和人工授粉)。

### 病虫害防治

**预防为主**:
```
✓ 选抗病品种
✓ 合理修剪(通风透光)
✓ 清理落叶、病果(减少病源)
✓ 翻耕(消灭越冬虫源)
✓ 树干涂白(防冻、防虫)
```

```
一年中最省力、效果最大的几件事:
1. 冬季清园: 扫净落叶、捡净僵果烂果,剪掉病枝枯枝,集中烧掉或深埋
2. 冬季刮老翘皮: 很多害虫和病菌在粗糙的老树皮缝里过冬,
   用刮刀刮掉翘起的老皮(不伤到绿色的活皮),刮下的皮烧掉
3. 秋季绑草把: 9月在树干上绑一圈草把或瓦楞纸,
   害虫会钻进去越冬,冬季取下烧掉
4. 发芽前喷一次保护性药剂(传统用石硫合剂),杀死越冬病菌和虫卵
5. 生长季每周巡园一次,发现病叶病果马上摘除
```

**物理防治**:
- 糖醋液诱杀
- 黑光灯诱杀
- 套袋(果实)
- 粘虫板

```
- 糖醋液: 约糖1份、醋4份、酒1份、水16份,装在广口瓶或碗中,
  挂在树冠中下部,每周更换,诱杀食心虫、卷叶蛾等成虫
- 套袋: 苹果、梨在疏果后约2-4周、桃在疏果后套袋,
  能挡住食心虫、桃蛀螟和鸟,还减少药剂残留;
  报纸糊的纸袋也能用,下部要留透气排水孔
- 黄色粘虫板: 诱粘蚜虫、潜叶蛾等,每 ha约挂300-450块
- 天牛: 树干上看到新鲜的虫粪木屑(从孔里排出)时,
  用细铁丝顺着虫道钩出幼虫,或把浸了药的棉球塞进虫孔后用泥封住
- 鸟害: 罩网是唯一长期可靠的办法
```

**生物防治**:
- 保护利用天敌
- 生物农药

```
- 瓢虫、草蛉、食蚜蝇吃蚜虫;捕食螨吃红蜘蛛;
  寄生蜂寄生食心虫、卷叶蛾
- 果园行间留草或种绿肥(三叶草、苜蓿等),为天敌提供栖息地,
  比清耕光地更好
- 喜鹊、山雀等鸟吃大量害虫,可以挂鸟巢箱
- 鸡在果园里放养(树盘已高于鸡啄食的高度的成年果园),
  能吃掉落果中的虫和地面越冬的虫蛹,但要防止它们刨伤根系
```

**化学防治**:
- 关键期喷药
- 轮换用药(防抗性)
- 注意安全间隔期

```
一般原则:
- 只在确实需要时用;优先上面的农业、物理、生物方法
- 严格按标签上的作物、浓度、次数使用;不随意加大浓度
- 遵守安全间隔期: 最后一次喷药到采收之间的天数,标签上写明
- 不使用国家禁用的高毒农药;花期不喷杀虫剂(保护蜜蜂)
- 喷药戴口罩、手套、帽子,穿长衣长裤;站在上风处;喷药时不吃喝、不吸烟;
  喷后洗澡、换洗衣服;孕妇、哺乳期妇女、儿童、老人不参与喷药
- 农药存放在原包装里,锁好,远离水源、食物和儿童;不用饮料瓶分装
- 石硫合剂、波尔多液是传统的果园药剂,熬制和配比请按专业资料
⚠️ 喷药后出现头痛、恶心、多汗、流涎、视物模糊 → 立即离开现场,
   脱去污染衣物,用肥皂水和大量清水冲洗皮肤,拨打120,带上农药包装就医
```

喷药防护和农药中毒的急救见[中毒-农药和鼠药中毒](../01-日常疾病和伤害/12-中毒.md#农药和鼠药中毒)。

**主要病虫害识别**:

| 病虫害 | 主要危害 | 识别 | 主要防治 |
|-------|---------|------|---------|
| 腐烂病 | 苹果、梨 | 枝干树皮红褐色湿腐、有酒糟味,后期病斑上长小黑点 | 早春刮治: 刮到病斑外约1 cm健康皮,刮口涂药或封泥;刮下的皮烧掉;增强树势 |
| 轮纹病、炭疽病 | 苹果、梨、柿、葡萄 | 果面出现同心轮纹状或凹陷的褐色烂斑 | 套袋;清除病果;剪除病枝 |
| 黑星病 | 梨 | 叶背、果面黑色霉层,果实畸形龟裂 | 清扫落叶;剪除病梢 |
| 缩叶病 | 桃 | 春季新叶皱缩、发红、肿厚 | 发芽前喷保护剂;摘除病叶 |
| 流胶病 | 桃、杏、樱桃 | 枝干流出透明→琥珀色胶 | 排水、少伤口、伤口涂封;刮除胶块后涂药 |
| 霜霉病 | 葡萄 | 叶面黄色油斑,叶背白霜 | 排水通风;雨季前保护 |
| 白粉病 | 葡萄、苹果 | 叶、梢、果表面一层白粉 | 剪除病梢;通风 |
| 黄龙病 | 柑橘 | 叶片斑驳黄化,果小、着色不正常 | 无药可治,挖除病株;防治木虱 |
| 枣疯病 | 枣 | 枝叶簇生成丛 | 无药可治,去除病枝或病株 |
| 蚜虫 | 各种果树 | 新梢嫩叶背面成群,叶片卷曲 | 保护瓢虫;黄板;剪除被害嫩梢;严重时按标签用药 |
| 红蜘蛛(叶螨) | 苹果、梨、桃、柑橘 | 叶片出现密集的黄白小点,严重时变褐脱落,叶背有细丝 | 刮老翘皮、清园;保护捕食螨;干旱时喷清水 |
| 食心虫 | 苹果、梨、桃、枣 | 果面小虫孔,虫粪从孔里排出 | 套袋;糖醋液;捡拾虫果深埋 |
| 天牛 | 苹果、梨、桃、核桃、柑橘 | 枝干上有排粪孔和木屑 | 钩杀幼虫;捕捉成虫 |
| 潜叶蛾 | 柑橘 | 嫩叶上弯曲的银白色虫道 | 抹除零星夏秋梢,统一放梢 |

### 冬季防冻与防霜

```
一般防冻(北方落叶果树):
1. 秋季控氮、控水,让枝条充分成熟(枝条木质化、颜色变深)
2. 封冻前浇一次透水(封冻水)
3. 树干涂白: 晚秋(约10-11月)把主干和主枝基部涂白,
   高约1-1.2 m;白色反光,减少冬季白天晒热、夜间骤冷造成的树皮冻裂,
   也能杀死部分越冬虫卵
   参考配方: 生石灰约10份、食盐约1份、水约30-40份,
   加少量黏土或动物油增加附着
   ⚠️ 生石灰遇水剧烈放热、会沸腾飞溅: 戴手套和护目镜,
      先放水再慢慢加石灰;溅入眼睛先刷去颗粒再用大量清水冲洗,并就医
4. 幼树防寒(栽后头2-3年):
   - 树干基部培土堆,高约30 cm
   - 主干缠草绳、包稻草或旧布
   - 北方特冷地区: 1-2年生幼树弯倒埋土
   - 冬春干旱多风的地方,幼树枝条会"抽条"(失水干枯): 包裹或埋土是关键

葡萄埋土防寒(冬季最低气温常低于约-15°C的地区):
1. 冬剪后、土壤封冻前进行
2. 把枝蔓从架上解下,顺一个方向压倒在地面,捆在一起
3. 用行间的土(离根至少约1 m取土,别把根挖出来)覆盖,
   厚度约20-30 cm(越冷越厚,最冷处可约40-50 cm),宽约1-1.5 m
4. 次年春天土壤解冻、树液开始流动前后(山桃开花时)撤土上架
   - 撤土太早: 遭晚霜;太晚: 芽在土里萌发,一见光就伤

无花果、石榴: 方法与葡萄类似,把枝条压倒埋土或包裹;
在南墙根下种植可少受冻

柑橘(在边缘地区):
- 寒潮来前浇水、在树冠上盖草帘或塑料布,树盘覆草、根颈培土
- 雪后及时摇落枝上积雪,防止压断
- 冻后先不要急着剪,等春季发芽后看清枯死范围再剪
- 北方只能盆栽,冬季移到室内(约5-10°C、有光的地方)

春季防晚霜(花期一次霜冻可能导致当年绝收):
- 注意天气: 晴朗、无风、傍晚气温下降很快的夜晚最危险
- 霜前1-2天浇水,湿土放热多
- 熏烟: 在果园上风方向每隔约10-15 m堆一堆湿草、锯末,
  后半夜气温降到约1°C时点燃,保持冒浓烟到日出后约1小时
  ⚠️ 留人看守,远离房屋柴草,防火
- 小树用草帘、塑料布、旧布罩住

冻后判断: 花或幼果切开,中心变褐、变黑 → 已冻死;
仍是绿白色 → 还活着。冻害严重的年份,保住树、明年再来,
不要因为当年没果就放弃管理
```

晚霜的天气规律见[天气观测与预报-霜冻](../08-基础科学知识/07-天气观测与预报.md#五霜冻);生石灰的安全操作见[石灰与建筑材料-熟化与陈伏](../07-日常生活技能/16-石灰与建筑材料.md#熟化与陈伏)。

## 📝 果树种植要点

### 新手推荐

```
容易种植(适合新手):
1. 无花果(极易,结果快)
2. 枣(耐旱粗放)
3. 桃(结果早)
4. 葡萄(易管理)
5. 石榴(观赏食用)

需经验:
- 苹果、梨(需授粉、修剪技术)
- 樱桃(环境要求高)
- 柑橘(北方难越冬)
```

```
灾后自给优先考虑:
- 耐储存、能晒干: 枣、柿、核桃、板栗、晚熟苹果和梨
- 管理粗放、少用药: 枣、柿、核桃、板栗、无花果、石榴
- 见效快: 无花果、葡萄、桃(先吃上),同时种寿命长的树(长期收益)
```

### 家庭果园配置(约667 m²)

```
混合种植:
- 苹果/梨: 10-15株(主体)
- 桃/李: 5-8株
- 葡萄: 20-30株(篱架)
- 石榴/枣: 3-5株
- 草莓/覆盆子: 边缘空地

优点:
✓ 品种多样
✓ 延长采收期
✓ 互相授粉(某些)
✓ 降低风险
```

```
注意:
- 上面的株数需要矮化砧或小树冠管理才放得下;
  用乔化苹果、梨时按4 m × 5 m计,约667 m²的地只能种约30棵树,
  各类要相应减少
- 苹果、梨各至少种2个能互相授粉的品种
- 高大的核桃、柿种在地块北侧或边上,不遮挡其他树
```

### 省力管理要点

```
✓ 选择适应当地的品种
✓ 抗病虫品种
✓ 适当密度(不过密)
✓ 地面覆盖(保湿、抑草)
✓ 滴灌系统
✓ 矮化砧木(方便管理)
```

```
一年的工作日历(北方落叶果树,南方相应提前):
- 冬季(12-2月): 冬剪、刮老翘皮、清园、积肥;检查腐烂病
- 早春(3月): 发芽前喷保护剂;撤除葡萄防寒土;补栽
- 春季(4-5月): 防晚霜;花期授粉、放蜂;疏花疏果;追肥、浇水;抹芽
- 夏季(6-8月): 套袋;夏剪(摘心、疏梢);追肥;雨季排水、防病
- 秋季(9-11月): 采收;施基肥;绑草把;涂白;浇封冻水;葡萄埋土
```

### 采收与储存

**适时采收**:
- 过早:品质差
- 过晚:不耐储运

```
怎样判断成熟:
- 底色(果皮背阴面)由绿转黄绿、黄色
- 种子由白变褐
- 果柄轻轻一抬就和果台分离
- 尝几个: 酸甜适口、香味出来
- 储存用的果子比马上吃的早几天采(约八九成熟)

采收:
- 晴天露水干后采,雨天和中午高温时不采
- 用手托住果子,向上一抬或一转;不要硬拽,不要折断果枝
- 苹果、梨保留果柄;桃要连带少量果柄或贴果柄摘
- 轻拿轻放,筐里垫草或软布,堆放不超过4-5层
- 先采树冠外围和下部,再采内膛和上部
```

**储存**:
```
短期:
- 阴凉通风处
- 分层摆放

长期:
- 冷藏(适合的品种)
- 加工(果酱、果干、罐头)
```

```
- 能长期窖藏的: 晚熟苹果、梨(约0-3°C、湿度高的地窖,可存3-6个月)
- 不耐放的: 桃、樱桃、无花果、葡萄(几天到1-2周) → 及时加工
- 入窖前挑出有伤、有病斑的果,一个烂果会传染一窝
- 苹果释放的乙烯会催熟其他果蔬,和土豆、绿叶菜分开存放
- 储存期间每月翻检一次
```

地窖、晒干和果酱的做法见[食物加工与保存-窖藏](../07-日常生活技能/01-食物加工与保存.md#窖藏)、[晒干与风干](../07-日常生活技能/01-食物加工与保存.md#晒干与风干)和[果酱](../07-日常生活技能/01-食物加工与保存.md#果酱酸性沸水浴)。

### 繁殖方法

**嫁接**(常用):
```
优点:
✓ 保持优良性状
✓ 矮化控制
✓ 提早结果
✓ 适应性强(砧木)

方法:
- 枝接(春季)
- 芽接(夏季)

需学习技术!
```

**扦插**:
- 葡萄、无花果:易生根
- 其他需生根剂

**压条**:
- 葡萄等蔓性

**实生**(种子):
- 不能保持母本特性
- 结果晚
- 一般不推荐(除非培育砧木)

```
- 砧木苗: 秋季采集山定子、杜梨、毛桃、山桃、酸枣、君迁子等的成熟种子,
  湿沙层积过冬(种子与湿沙约1:3-5混匀,放在约0-5°C的地方),
  春天露白后播种,当年秋季或次年即可嫁接
- 老树换品种(高接换头): 品种不好的成年树,春季在主枝上锯断后劈接好品种,
  2-3年即可恢复结果,比重新栽树快得多
- 接穗、插条只从多年表现好、没有病毒病和枣疯病、黄龙病的健康母树上取
```

劈接、芽接的具体步骤见[留种与育种-无性繁殖](08-留种与育种.md#无性繁殖)。

### 要点汇总

```
1. 选本地能正常越冬、正常结果的树种和品种,用健康的嫁接苗
2. 选阳光充足、排水好的坡地;低洼积水和冷空气聚集处不种
3. 定植坑约60-80 cm,施腐熟底肥,肥土隔开;嫁接口露出地面5-10 cm
4. 宁稀勿密;苹果、梨、甜樱桃、板栗必须配授粉树
5. 头三年保水、除草、防啃,摘花先长树
6. 冬剪定骨架,夏剪去密枝;剪口平、不留桩,大伤口涂封
7. 秋施基肥为主,生长季少量多次追肥;晚秋控氮控水
8. 疏花疏果防大小年;冬季清园、刮皮、涂白,花期不喷杀虫剂
9. 北方注意防寒防晚霜;耐储存、可晒干的果子留作冬粮
```
