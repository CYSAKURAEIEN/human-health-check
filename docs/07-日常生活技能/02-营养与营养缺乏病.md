## 为什么储备粮会让人生病

大米、面粉、玉米能提供足够的热量,但**只靠它们,几个月后就会出现营养缺乏病**。历史上的饥荒、远洋航海、战争围困中,大量人员并非饿死,而是死于这些可以预防的疾病。

```
热量够 ≠ 营养够

只吃精白米 → 缺维生素B1 → 脚气病
只吃玉米   → 缺烟酸     → 糙皮病
缺新鲜蔬果 → 缺维生素C  → 坏血病
不吃碘盐   → 缺碘       → 甲状腺肿、儿童智力损害
```

**原则: 储备粮只解决"饿",还需要豆类、蔬菜(包括野菜、豆芽)、少量动物性食物来解决"病"。**

## 常见营养缺乏病

| 疾病 | 缺乏 | 多久出现 | 早期表现 | 预防食物 |
|------|------|----------|----------|----------|
| 坏血病 | 维生素C | 约1-3个月 | 乏力、牙龈肿胀出血、皮下出血点、伤口不愈合 | 新鲜蔬果、豆芽、松针茶、野菜 |
| 脚气病 | 维生素B1 | 数周到数月 | 下肢麻木无力、水肿、心慌气短 | 糙米、全麦、豆类、瘦猪肉 |
| 糙皮病 | 烟酸 | 数月 | 暴露部位对称性皮炎、腹泻、记忆减退 | 豆类、花生、肉、鱼;玉米用碱处理 |
| 夜盲症 | 维生素A | 数月 | 黄昏看不清,眼干,儿童易感染 | 深绿色和橙黄色蔬菜(胡萝卜、南瓜、菠菜)、动物肝脏、蛋黄 |
| 佝偻病/骨软化 | 维生素D、钙 | 数月(儿童) | 儿童骨骼弯曲、出牙晚;成人骨痛 | 晒太阳、鱼、蛋黄、豆制品、骨头汤(钙少,不能代替) |
| 甲状腺肿 | 碘 | 数月到数年 | 颈部肿大;孕期缺碘可致胎儿智力损害 | 碘盐、海带、紫菜 |
| 缺铁性贫血 | 铁 | 数月 | 面色苍白、乏力、心慌、指甲变薄 | 动物血、肝脏、红肉;豆类配合维生素C吸收更好 |
| 蛋白质-能量营养不良 | 蛋白质和热量 | 数周 | 消瘦、水肿(尤其儿童)、头发稀黄 | 豆类、蛋、鱼、肉、奶 |

⚠️ 出现上述症状,尤其是儿童和孕妇,在补充食物的同时应尽早就医。坏血病和脚气病在补充对应营养后通常恢复很快。

## 用身边的食物补充

### 维生素C: 豆芽是最可靠的冬季来源

干豆子几乎不含维生素C,但发芽后维生素C大量增加,而且不受季节限制。

```
发豆芽(黄豆、绿豆):
1. 豆子挑去坏豆,清水浸泡8-12小时
2. 放入底部有孔的容器(或纱布上),盖湿布避光
3. 每天淋水2-3次,保持湿润但不积水
4. 3-5天即可吃(绿豆芽约5-7厘米长)
5. 吃时炒或焯水,不要久煮(维生素C怕热)

⚠️ 发芽过程中发臭、发黏、长霉 → 丢弃
```

**其他来源**:
- 野菜: 荠菜、马齿苋、蒲公英嫩叶等(必须100%确认,见[药用植物](../04-动植物培育/04-药用植物.md))
- 松针茶: 新鲜松针切碎,热水(不要沸水久煮)浸泡。⚠️ 只用确认的松树;**红豆杉(紫杉)剧毒**,叶片扁平、外形相似,不能混淆;孕妇不要饮用松针茶
- 辣椒、白菜、萝卜、土豆也含一定量维生素C

**保护维生素C**: 蔬菜先洗后切、切后尽快烹调、急火快炒、少放碱。

### 维生素B1: 别把米碾得太白

```
✓ 糙米、少碾几遍的"半精米"比精白米好得多
✓ 淘米不要反复用力搓洗
✓ 搭配豆类、全麦、杂粮
❌ 煮粥加碱会破坏维生素B1
```

### 烟酸: 吃玉米要用碱处理

以玉米为主食的地区历史上曾大量流行糙皮病。玉米中的烟酸是结合形式,人体难以吸收。

```
传统方法: 用石灰水或草木灰水煮玉米粒
1. 玉米粒加水,加入少量熟石灰(或草木灰滤出的碱水)
2. 煮至玉米皮可以搓掉
3. 浸泡过夜,第二天反复冲洗干净,去皮
4. 再磨粉或煮食

作用: 释放结合的烟酸,同时改善口感
```

如果不做碱处理,就要同时吃足豆类、花生、肉、鱼。

### 碘

- 坚持吃碘盐(中国大陆食用盐普遍加碘)
- 沿海可食用海带、紫菜
- 储备时选碘盐,密封保存(碘受潮、受热、见光会流失)
- ⚠️ 甲状腺疾病患者遵医嘱;不要用碘伏、碘酒等外用碘制品代替碘盐

### 蛋白质: 豆类是最重要的植物蛋白

- 大豆及豆制品(豆腐、豆浆、豆芽),做法见[食物加工与保存-豆腐](01-食物加工与保存.md#豆腐)
- 谷物 + 豆类搭配(如米饭配豆腐、杂粮粥),蛋白质互补
- 鸡蛋是最容易获得的优质蛋白,见[家禽养殖](../04-动植物培育/05-家禽养殖.md)
- 昆虫也是蛋白质来源(必须煮熟),见[基础生存技能](../03-野外生存/00-基础生存技能.md)

## 特殊人群

### 孕妇和哺乳期妇女

```
✓ 叶酸: 孕前3个月到孕早期,预防胎儿神经管缺陷(储备叶酸片)
✓ 碘: 孕期需要量增加,坚持碘盐
✓ 铁: 动物血、肝、红肉
✓ 钙: 豆制品、奶、虾皮
✓ 比平时多吃一些,尤其是蛋白质
```

### 婴幼儿

```
✓ 6个月内: 母乳喂养是最安全的选择(不依赖净水和奶粉供应)
✓ 6个月起: 添加辅食,先加含铁的(如强化铁米粉、肉泥、蛋黄)
✓ 多晒太阳(维生素D)
❌ 1岁以下不吃蜂蜜(肉毒中毒风险)
❌ 不用米汤、糊糊长期代替奶(蛋白质严重不足)
```

### 老人

- 牙口不好容易吃得少、吃得单一,把食物做软做碎
- 注意蛋白质和钙
- 口渴感减弱,主动定时喝水

## 长期饥饿后恢复进食

⚠️ **严重饥饿、极度消瘦的人,突然大量进食可能致命**(再喂养综合征: 电解质紊乱,可致心力衰竭、抽搐)。

```
适用: 数天以上几乎未进食,或长期严重营养不良的人

做法:
1. 从少量、清淡、易消化的食物开始(稀粥、米汤、面汤)
2. 少量多餐,每次只吃一点
3. 数天内逐步增加食量
4. 可加少量盐
5. 有条件时尽快就医,在医生监护下恢复进食

观察: 出现心慌、气短、水肿、抽搐、意识改变 → 减量并立即就医
```

## 储备建议

在[末日求生-储备清单](../03-野外生存/06-末日求生.md#储备清单)的基础上,补充:

```
- [ ] 碘盐(密封保存)
- [ ] 多种干豆: 黄豆、绿豆(既是蛋白质,又能发豆芽补维生素C)
- [ ] 花生、芝麻(脂肪、烟酸)
- [ ] 糙米或杂粮(不要只存精白米)
- [ ] 复合维生素片(作为保险,注意有效期)
- [ ] 叶酸片(家中有备孕或孕期女性时)
- [ ] 蔬菜种子(传统品种,可留种)
```

---

## 📝 营养要点

```
1. 热量够 ≠ 营养够,储备粮之外要有豆类和蔬菜
2. 冬季缺菜时发豆芽,是最可靠的维生素C来源
3. 米不要碾太白;玉米为主食时要用碱处理或多吃豆类
4. 坚持碘盐
5. 孕妇、婴幼儿、老人优先保证营养
6. 长期饥饿后少量多餐,慢慢恢复
```
