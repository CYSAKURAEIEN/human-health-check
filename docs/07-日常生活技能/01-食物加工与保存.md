## 保存原理

食物变质是微生物(细菌、霉菌)繁殖和酶的作用造成的。所有保存方法都是让微生物无法繁殖:

| 方法 | 原理 | 适合 |
|------|------|------|
| 晒干、风干 | 去除水分 | 粮食、豆类、蔬菜、果干、肉干 |
| 盐腌 | 高盐让微生物脱水 | 咸菜、腊肉、咸鱼 |
| 发酵 | 有益菌产酸,抑制有害菌 | 泡菜、酸菜 |
| 烟熏 | 干燥 + 烟中物质抑菌 | 肉、鱼 |
| 低温窖藏 | 减慢微生物和呼吸作用 | 土豆、红薯、白菜、萝卜 |
| 罐藏 | 加热灭菌 + 密封 | 果酱、酸性蔬菜 |

**通用原则**:
```
✓ 原料新鲜、无腐烂
✓ 容器、工具洗净并烫过或晒干
✓ 少量多批,不要一次做太多(一坛坏了不至于全损失)
✓ 贴标签: 品名、日期
✓ 定期检查,发现霉变、异味、胀袋胀罐立即丢弃
❌ "切掉发霉部分继续吃"只适用于硬质奶酪等极少数食物;
   粮食、坚果、腌菜、酱类发霉要整批丢弃(霉菌毒素会扩散到看不见的地方)
```

## 晒干与风干

最简单、最安全的保存方法。

### 粮食和豆类

```
1. 收获后尽快晾晒,摊薄、勤翻
2. 晒到水分足够低:
   - 稻谷 <13%,小麦 <12%,玉米 <14%
   - 简易判断: 用牙咬发出清脆声音、不粘牙
3. 晾凉后再装袋(热装会返潮)
4. 储存: 密封、防潮、防鼠、阴凉处
```

粮食长期储存详见[粮食作物-储存要点](../04-动植物培育/02-粮食作物.md#储存要点)。

### 蔬菜和水果

```
适合: 豆角、萝卜条、茄子、辣椒、蘑菇(已确认可食的)、红枣、柿子、苹果片

方法:
1. 洗净、切成薄片或细条(越薄干得越快)
2. 可先用开水烫1-2分钟(保色、杀灭表面细菌、减少酶的作用)
3. 摊在竹匾或网上,阳光下晾晒,夜间收回防露水
4. 晒到完全干脆或干韧(视品种)
5. 密封保存

阴雨天: 放在灶台上方、火炕边或低温烘烤(<60°C)
```

### 肉干

```
1. 选瘦肉,去净肥肉(脂肪易酸败)
2. 顺纹切成薄条(约5 mm厚)
3. 先煮熟或用盐腌一夜
4. 在通风、有阳光、防蝇的地方晾晒,或低温烘烤
5. 干透(弯折会裂开)后密封保存

⚠️ 生肉直接晾晒风险较高,先煮熟或充分盐腌更安全
⚠️ 晾晒时必须防蝇(纱网罩)
```

## 盐腌

### 咸菜

```
1. 蔬菜(萝卜、芥菜、雪里蕻等)洗净晾干表面水分
2. 一层菜一层盐,压实
   - 用盐量约为菜重的10-15%(盐少易坏,盐多更耐存但更咸)
3. 上面压重石,让菜出水并没入盐水中
4. 密封,阴凉处保存
5. 腌制20天以上再吃(见下方亚硝酸盐说明)
```

### 腊肉、咸肉

```
1. 选新鲜猪肉,切成长条
2. 用盐(肉重的6-8%)反复揉搓,可加花椒、白酒
3. 装缸腌制5-7天,每天翻动一次
4. 取出挂在阴凉通风处风干,或烟熏
5. 冬季(气温低于10°C)制作最安全

⚠️ 气温高时制作易腐败;苍蝇多的季节必须防蝇
⚠️ 腌制品含盐高,高血压、肾病患者少吃
```

### ⚠️ 亚硝酸盐: 腌菜要等够时间

腌菜在腌制初期亚硝酸盐含量会升高,一般在第3-10天达到高峰,之后逐渐下降,**20天后**基本降到安全水平。

```
✓ 腌菜至少20天后再吃
✓ 腌制期间用盐要足、保持密封
❌ 不要吃"暴腌"几天的半生腌菜
❌ 不要吃已经腐烂、发黏的腌菜
```

亚硝酸盐中毒表现: 口唇、指甲青紫,头晕、心慌、呼吸困难。立即拨打120。

## 发酵

### 泡菜、酸菜

```
1. 容器: 泡菜坛(带水封口)或玻璃罐,洗净烫过
2. 盐水: 凉开水加盐,浓度约5-8%
   (约1 L水加50-80 g盐)
3. 蔬菜洗净晾干,放入坛中,盐水没过蔬菜
4. 加盖,坛沿水槽注水密封(隔绝空气)
5. 室温发酵,夏季约1周,冬季2-3周
6. 变酸、有清香味即可;至少20天后再吃更安全

日常管理:
- 取菜用干净无油的筷子
- 坛沿的水要常换、保持不干
- 表面长白膜(产膜酵母): 撇去,加少量盐或白酒;
  如长出黑、绿、粉色霉斑,或有腐臭味,整坛丢弃
```

### 其他发酵食品

- **醪糟(酒酿)**: 糯米蒸熟、拌酒曲、保温发酵2-3天。原料要新鲜,发酵过程如发黑、发臭、长杂色霉,整批丢弃
- **酱类(豆瓣酱、黄豆酱)**: 制作周期长,发霉和肉毒杆菌风险较高,新手不建议自制,见下方高风险食品

⚠️ **酵米面制品(酸汤子、臭碴子、吊浆粑等)不要自制!** 见下方[高风险食品与食物中毒](#高风险食品与食物中毒)。

## 烟熏

```
1. 肉或鱼先盐腌(同腊肉)
2. 搭简易熏棚: 上方挂肉,下方是小火堆或烟道引来的烟
3. 燃料: 硬木屑、果木、松枝(松枝烟味重)、茶叶、甘蔗渣
   ❌ 不要用油漆过的木材、刷过防腐剂的木料、塑料
4. 保持低温冷烟(手放在肉旁感觉温热即可,不要烤熟烤焦)
5. 熏数天到数周,至表面干硬、颜色深褐

食用: 烟熏制品吃前最好再蒸煮
⚠️ 熏制品含多环芳烃(致癌物),不宜长期大量食用
```

## 窖藏

适合秋冬收获的块根、块茎和耐储蔬菜。

### 地窖

```
选址: 地势高、不积水、背阴
深度: 2 m左右(冬季地下温度稳定在0-10°C)
通风: 留通气孔,保持空气流通
湿度: 较高湿度(防蔬菜失水萎缩)

⚠️ 进入密闭地窖前先打开通风,或用点燃的蜡烛试探:
   蔬菜呼吸会使地窖内二氧化碳积聚,蜡烛熄灭说明缺氧,不能下去
   每年都有下窖窒息死亡的事故
```

### 各类蔬菜的储存条件

| 蔬菜 | 温度 | 要点 |
|------|------|------|
| 土豆 | 2-4°C | **必须避光**(见光变绿产生龙葵素) |
| 红薯 | 10-15°C | 怕冷(低于9°C易冻伤腐烂),入窖前晾干表皮 |
| 白菜 | 0-2°C | 晾晒去外层老叶,码放并定期翻倒 |
| 萝卜、胡萝卜 | 0-3°C | 埋在湿沙中保湿 |
| 南瓜 | 10-15°C | 干燥通风,不要堆压 |
| 洋葱、大蒜 | 0-5°C | 干燥通风,悬挂 |

土豆发芽变绿的处理见[蔬菜种植-土豆](../04-动植物培育/01-蔬菜种植.md#土豆)。

## 罐藏

### 先分清酸性食物和低酸食物

这是罐藏最重要的安全知识:

```
酸性食物(pH ≤4.6): 大多数水果、果酱、加醋的泡菜、加柠檬汁的番茄
→ 可以用沸水浴罐藏

低酸食物(pH >4.6): 所有新鲜蔬菜、肉、禽、鱼、豆类
→ 只能用压力罐藏(需达到116°C以上)
→ 沸水浴(100°C)杀不死肉毒杆菌芽孢!
```

肉毒杆菌芽孢能耐受100°C,在密封、缺氧、低酸的罐子里会繁殖并产生肉毒毒素,这是家庭自制罐头最主要的中毒风险。

**没有压力锅或压力罐藏设备时: 不要自制蔬菜、肉类罐头。** 改用晒干、盐腌、发酵等方法保存。

### 果酱(酸性,沸水浴)

```
1. 玻璃瓶和盖子煮沸10分钟消毒
2. 水果加糖(约为果肉重量的50-100%)熬至浓稠
3. 趁热装瓶,留1 cm空隙,拧紧盖子
4. 瓶子放入沸水中,水面没过瓶盖,煮10-15分钟
5. 取出冷却,盖子中央凹陷说明密封成功
6. 开封后冷藏,尽快吃完
```

### 罐头变质的信号

```
❌ 以下任何一种,直接丢弃,不要尝:
- 盖子鼓起、胀罐
- 开罐时喷出液体或气体
- 有异味、发浑、起泡
- 罐身严重锈蚀、漏液
```

## 豆腐

黄豆是重要的蛋白质来源,做成豆腐更易消化。

```
1. 黄豆浸泡8-12小时(夏季短、冬季长)
2. 加水磨浆(豆:水 约1:6)
3. 用纱布过滤,分出豆浆和豆渣
4. 豆浆煮沸后,小火再煮5-10分钟
   ⚠️ 必须彻底煮熟: 生豆浆含皂素和胰蛋白酶抑制物,喝了会恶心、呕吐、腹泻
   注意"假沸": 豆浆加热到80°C左右会起泡沫,看似沸腾,其实没有熟
5. 降温至80-90°C,边搅边慢慢加入凝固剂:
   - 卤水(氯化镁,北豆腐)
   - 石膏(硫酸钙,南豆腐)
   - 白醋(应急用,口感偏酸)
6. 静置10-15分钟,出现豆花
7. 舀入铺好纱布的模具,压上重物1-2小时,成型

⚠️ 卤水是浓盐溶液,误饮可致严重中毒甚至死亡,必须标明并远离儿童
豆渣: 可炒食、做饼,或喂鸡喂猪、堆肥
```

## 高风险食品与食物中毒

⚠️ 以下几种中毒,**加热都不能可靠地解决问题**,要靠"不做、不吃、丢弃"来预防。

### 米酵菌酸: 最危险的一种

| 项目 | 说明 |
|------|------|
| 来源 | 椰毒假单胞菌污染发酵米面制品后产生 |
| 高危食品 | 酵米面制品(酸汤子、臭碴子、格格豆、吊浆粑、汤圆等);泡发过久的木耳、银耳;湿米粉、河粉 |
| 危险之处 | **煮沸、高压都不能破坏**;没有特效解毒药;病死率很高 |
| 预防 | **不制作、不食用酵米面类食品**;木耳银耳泡发时间不要过长,泡好尽快烹调;泡发后发黏、有异味的丢弃 |

### 肉毒中毒

| 项目 | 说明 |
|------|------|
| 高危食品 | 家庭自制低酸罐头;自制豆瓣酱、臭豆腐等发酵豆制品;真空包装的肉类、腌制不当的肉 |
| 表现 | 进食后数小时到数天: 视物模糊、重影,眼睑下垂,说话、吞咽困难,继而全身无力、呼吸困难 |
| 处理 | **立即拨打120**(有抗毒素,越早越好) |
| 预防 | 不做低酸罐头;发酵豆制品原料煮透;可疑食品食用前煮沸10分钟以上可破坏毒素;胀罐、胀袋一律丢弃 |

### 黄曲霉毒素

| 项目 | 说明 |
|------|------|
| 高危食品 | 霉变的花生、玉米、大米、坚果;发苦的花生、瓜子;霉变的自榨花生油 |
| 危险之处 | 强致癌物,高温烹调不能破坏 |
| 预防 | 粮食充分晒干储存;霉变、发苦的坚果和粮食**整批丢弃**,不要挑拣着吃;不要因为"可惜"喂给家禽家畜(会通过肉蛋奶转移) |

### 其他

- **亚硝酸盐**: 腌菜20天以上再吃(见上文);不要误把工业用盐当食盐
- **发芽、变绿的土豆**: 龙葵素,见[蔬菜种植-土豆](../04-动植物培育/01-蔬菜种植.md#土豆)
- **四季豆、豆角未煮熟**: 皂素中毒,必须炒熟煮透至失去生绿色
- **野生蘑菇**: 不认识的一律不吃,见[森林求生](../03-野外生存/02-森林求生.md)

食物中毒的一般处理见[常见疾病-食物中毒](../01-日常疾病和伤害/01-常见疾病.md#食物中毒)。

## 📝 食物保存要点

```
最安全、最推荐:
1. 晒干(粮食、豆类、蔬菜、肉干)
2. 窖藏(土豆、红薯、白菜、萝卜)
3. 盐腌(等够20天)

需要注意:
- 发酵: 保持密封,出现杂色霉斑整坛丢弃
- 烟熏: 不用有漆或防腐剂的木材

不要做:
❌ 没有压力锅时做蔬菜、肉类罐头
❌ 酵米面类食品
❌ 吃霉变、发苦的粮食坚果
```
