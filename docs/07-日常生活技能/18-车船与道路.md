## 先说清楚: 本章的定位

粮食要从田里运回来,柴要从山上运下来,砖、石灰、矿石要运到工地,产品要运到集市。没有了汽车和柏油路,**运输能力会直接决定一个社区能耕种多大范围、能和多远的邻居交换东西**。本章讲手工能做到的车、路、桥、船,目标是让同样的力气运更多的东西。

```
⚠️ 安全:
- 下坡是车辆事故最多的地方: 重车下坡要有刹车、拖木或用绳子从后面拉住,
  人绝不站在下坡方向的车前面
- 车停在坡上要用石块或木楔垫住车轮
- 牲畜会踢、会咬、会受惊狂奔: 不站在马、骡、驴的正后方,不在牲畜和墙之间被挤住
- 桥会塌: 新桥、旧桥、洪水后的桥都要先检验再过重车
- ☠️ 水上最大的危险是溺水: 穿救生衣或带浮具,不超载,洪水和大风天不行船
- 冷水能在几分钟内让人失去自救能力,即使是会游泳的人
```

最现实的路线: **先回收**。自行车、手推车、旧汽车上的车轮和轴承,比自己造容易得多;自己造是为了长期补充和维修。

## 先用现成的: 自行车、手推车和旧车

### 自行车: 最高效的人力交通

一个人骑自行车,消耗的力气只有步行同样距离的几分之一,速度却是步行的3-4倍。平路上空车骑行约15-20 km/h,一天走50-80 km并不难。**储备几辆结实的自行车和足够的备件,比储备汽油实际得多。**

```
载货改装:
✓ 后货架: 选钢制、焊在或螺栓固定在车架上的,载重约20-30 kg
✓ 前筐或前货架: 放轻物,太重会让车把难控制
✓ 挂兜(驮包): 挂在后货架两侧,重心低,比堆在货架顶上稳
✓ 拖车: 用两个旧自行车轮做一辆小拖车,挂在车座下或后轴上,
  可拖30-50 kg;下坡时注意拖车会推车
✓ 推着走: 车把上绑一根长木杆当推杆,人在旁边推,一辆自行车可以运100 kg以上
  (山路、烂路上常这样运货)

⚠️ 载重车刹车距离长得多: 提前减速,下长坡不时停下让刹车冷却
```

```
补胎(内胎扎破):
1. 拆下外胎一侧(用撬胎棒或勺柄,不要用螺丝刀,容易再扎破内胎)
2. 取出内胎,打气后放进水盆,冒气泡的地方就是漏点,做好记号
3. 摸一遍外胎内侧,把扎进去的刺、玻璃、铁丝找出来拔掉(否则装上又会破)
4. 漏点周围用砂纸打毛、擦干净
5. 涂一层薄胶,等到胶不粘手(约几分钟)再贴补片,用力压紧
6. 装回内胎时先打一点气,让它成形,避免被外胎夹住
7. 按外胎侧面印的气压打气

保养要点:
✓ 气压: 按外胎侧面的数值,常见约300-450 kPa;气不足最容易扎胎、伤轮圈
✓ 链条: 擦干净后上少量机油,外面多余的油擦掉(油多了粘泥沙,磨得更快)
✓ 刹车: 闸皮磨到纹路消失就换;刹车线生锈发涩要上油或换线
✓ 轴承(车轴、中轴、车头碗): 每年拆开清洗一次,重新填黄油
✓ 储备: 内胎、补胎胶和补片、外胎、链条、刹车皮、刹车线、辐条、打气筒
```

### 手推车、板车和旧车

```
✓ 手推车(建筑用独轮推车)、两轮板车、平板拖车: 尽量收集,轮子和轴承是最难自制的部分
✓ 旧汽车: 轮子(带轮毂和轴承)可以改做板车和畜力车;
  钢板弹簧、钢材、螺栓、轴承都是宝贵的材料
✓ 充气轮胎: 放在阴暗处,避开阳光和油;橡胶会随时间老化开裂
✓ 电动自行车、电动三轮车: 有太阳能板时可以继续充电使用,
  但电池寿命有限,坏了很难修

燃油会变质:
- 汽油: 一般储存3-6个月就开始变质,加燃油稳定剂可延长到约一年;
  变质的汽油会在油路和化油器里结胶,让发动机打不着
- 柴油: 保存时间长一些,但会吸水、长微生物、堵滤清器
→ 机动车只能作为过渡,不要把长期运输寄托在燃油上
```

汽油的储存规则见[照明与能源-汽油](06-照明与能源.md#汽油),太阳能充电见[照明与能源-小型太阳能](06-照明与能源.md#小型太阳能)。

## 人力搬运

```
人力负重的大致数值(健康成年人,长距离、能连续几天):
- 背负(背篓、背架、背包): 约20-30 kg,约为体重的1/3以下
- 扁担挑: 熟练的人约40-50 kg,两头平衡,换肩不停步
- 独轮车: 平路上约100-150 kg
- 两人抬: 每人约30-40 kg
每天行程: 负重走平路约20-30 km,山路少得多
⚠️ 体力差、老人、孩子、孕妇要大大减少;长期过载会伤腰和膝盖
```

```
省力的要点:
✓ 重物贴近身体、靠上背: 背篓、背架让重量落在背和腰胯上,而不是肩上
✓ 背带加宽加垫,腰带把一部分重量传到胯骨上
✓ 扁担选有弹性的竹木,走路的节奏和扁担上下的弹动配合,会轻松很多
✓ 搬起重物: 蹲下、背挺直、用腿起身,不要弯腰直接提
✓ 拄一根棍子,山路、下坡、过水时多一个支点
```

### 为什么独轮车省力

```
独轮车是一个杠杆: 轮子是支点,货物在中间,人在把手端用力
- 货物越靠近轮子,人承担的重量越少
- 中国传统独轮车(大轮子在车子正中,货物分放两侧):
  货物的重心几乎就在轮子正上方,人几乎只用扶着保持平衡、往前推
  → 一个人能推100 kg以上,在窄小的田埂、山路上也能走
- 常见的建筑推车(轮子在前端): 人要抬起相当一部分重量,
  装货时把重的放在靠轮子一侧
✓ 轮子越大,越容易越过石块和坑
✓ 加一根肩带挂在两个把手之间,用肩膀分担手的力量
```

杠杆的原理见[物理-杠杆](../08-基础科学知识/02-物理.md#21-杠杆)。

## 车轮与车轴

### 为什么轮子省力

拖着东西在地上走,要克服滑动摩擦;放在轮子上,只要克服滚动阻力和轴上的摩擦,小得多。**路面越硬越平,轮子的优势越大**;在烂泥和沙地里,轮子陷下去,优势就大打折扣。

| 方式 | 拉动需要的力(约为重量的) | 说明 |
|------|----------------------|------|
| 在土地上拖(滑动) | 30%-60% | 只适合短距离 |
| 雪橇在雪地、冰面上 | 5%-10% | 冬季运输很好用 |
| 车轮在软土、沙地 | 10%-30% | 宽轮胎陷得浅 |
| 车轮在碎石路 | 2%-5% | |
| 充气胎在硬路面 | 约1%-2% | |
| 铁轮在铁轨上 | 约0.2% | 所以铁路运量极大 |

```
例: 一辆连车带货500 kg的板车
- 在硬路面上: 约需拉力 500 × 0.02 ≈ 10 kg 的重量(约100 N),一个人轻松拉
- 在烂泥地里: 约需 500 × 0.2 = 100 kg 的重量(约1000 N),几个人也很吃力
→ 修好路,等于多养了几头牲畜
```

摩擦力的原理见[物理-摩擦力](../08-基础科学知识/02-物理.md#14-摩擦力)。

### 木轮

```
实心轮(最简单):
1. 用2-3块厚木板(约5-8 cm厚的硬木)并排拼起来
2. 两面各钉或用榫钉一根横档,把木板连成一体(横档的木纹和木板垂直)
3. 画圆锯成圆形,中心开轴孔,孔周围加厚或包铁皮
缺点: 重,容易沿木纹裂开

辐条轮(轻而结实,费工):
- 轮毂: 一段粗硬木(榆、槐、橡等),中间开轴孔,周围凿辐条的榫眼
- 辐条: 直纹硬木,一头插入轮毂,一头插入轮辋
- 轮辋: 几段弧形木块拼成一圈
- 铁箍: 把铁箍烧热(胀大)后套在木轮外面,浇水冷却收缩,把整个轮子箍紧
✓ 轮子直径越大越省力,过坑越容易;畜力车常用约1-1.5 m
✓ 木轮干燥后会松,旧时会把车泡在水里让木头胀紧
```

木材的选用和榫卯见[木工与工具维护-木材](09-木工与工具维护.md#木材)、[简单的榫卯: 直角榫](09-木工与工具维护.md#简单的榫卯-直角榫);铁箍的锻打见[金属加工技术](../05-冶金技术/04-金属加工技术.md)。

### 轴和轴套

```
木轴木孔(最简单): 硬木车轴在轮毂孔里转,磨损快,要常润滑
加轴套: 在轮毂孔里镶一个铁管或铁环,车轴相应部位包铁皮,
        铁磨铁比木磨木耐用得多
回收轴承: 汽车、摩托车、自行车、电动机里的滚珠轴承,摩擦最小,
          装进木轮毂时要做好轴承座,用油脂封住,不让泥沙进去

润滑:
✓ 动物油(牛羊油最耐用)、植物油、废机油
✓ 石墨粉(铅笔芯研碎)混进油脂里,耐压、不容易挤出去
✓ 每天出车前检查: 轴头发烫、吱吱响 → 缺油
✗ 不要让轴在没有油的情况下长时间转: 木轴会磨坏甚至发热冒烟
✓ 车轴两端加销子或挡圈,防止轮子脱出
```

轴承的原理见[工程力学与材料-轴和轴承](../09-进阶科学与工程/01-工程力学与材料.md#111-轴和轴承)。

### 双轮板车的平衡

```
两轮车的车轴是支点,货物的重心要在车轴上或稍微靠前:
- 重心稍靠前: 车把(车辕)上有一点向下的压力,人或牲畜容易控制,车不乱晃
- 重心太靠前: 拉车的人或牲畜要额外扛着很大的重量,很快就累
- 重心在车轴后面: 车把会向上翘,上坡时可能整车向后翻,
  套在牲畜身上的挽具会把牲畜往上吊
✓ 装好货先抬一下车把试试,手上只有约5-15 kg的压力为宜
✓ 上坡时货往前挪一点,下坡时往后挪一点
✓ 货物绑牢,防止路上移动改变重心
```

## 畜力与挽具

一头牲畜持续工作的功率,大约相当于5-10个人。但牲畜要饲料、草场、圈舍和照料,只有社区规模和饲料够了才划算。牛、驴、马、骡的饲养要点见[家畜养殖-牛、驴等役用牲畜](../04-动植物培育/06-家畜养殖.md#牛驴等役用牲畜),能找到有经验的人请教最好。

| 牲畜 | 持续拉力(约为体重的) | 速度 | 驮载 | 特点 |
|------|------------------|------|------|------|
| 牛 | 10%-15% | 慢,约2-3 km/h | 不常驮 | 力大、耐粗饲、性情稳,适合犁地、拉重车、短途 |
| 马 | 10%-15% | 快,约4-5 km/h | 约80-100 kg | 速度快,但饲料要求高(需精料),较娇贵 |
| 驴 | 约15% | 约3-4 km/h | 约40-60 kg | 体小、耐粗饲、耐旱、好养,适合小户 |
| 骡 | 10%-15% | 约4 km/h | 约80-120 kg | 马和驴的杂交,耐力强、少生病,不能繁殖 |

```
大致的数量级:
- 一头约500 kg的马或牛,能长时间保持约500-700 N的拉力(相当于提起50-70 kg的重物)
- 马的持续功率约370-750 W,一个成年人约75-100 W
- 牛车每天约15-20 km;马车在好路上每天约30-40 km
```

畜力的功率见[热力学与动力机械-畜力和人力](../09-进阶科学与工程/03-热力学与动力机械.md#83-畜力和人力)。

### 挽具: 让力气用得出来

**挽具不合适,牲畜再壮也拉不动。** 拉力要压在牲畜骨骼结实的部位(肩部、胸前),而不是勒在喉咙或软组织上。

```
牛: 牛轭(颈轭)
- 一根弯木架在牛的颈后、肩隆(脖子后面隆起的地方)前面,牛用肩往前推
- 单牛用的叫"牛轭",两头牛并排用一根横木的叫"双牛轭"
- 轭的弯度要合牛的颈形,接触面打磨光滑,下面用绳或木条兜住不脱落

马、骡、驴:
1. 颈带式(最原始,不要用): 带子绕在脖子上,马一用力,带子就往上滑、勒住气管
   → 马拉得越用力越喘不过气,只能拉很轻的车
2. 胸带式: 一条宽带横过马的胸前(气管下面),两侧接拉绳
   → 不勒气管,适合轻车和中等的车;做法简单
3. 颈圈式(套包): 一个填充了软料的硬圈,套在马的颈根部,紧贴肩膀,
   拉绳接在圈两侧,马用肩膀往前推
   → 力完全落在肩膀骨骼上,能把马的力气全部用出来,适合重车、犁地;
     历史上颈圈的普及让马能拉的重量大大增加

✓ 颈圈要按每匹马的大小做: 太大会磨伤肩,太小会压住气管和血管
  (套上后,喉咙和圈之间能平着伸进一只手为宜)
✓ 接触面用皮革包裹,内衬软料;每次用完擦干净
✓ 拉绳(套绳)两侧等长,高度让拉力方向从肩部斜向后下方
```

皮革的制作和保养见[纺织、缝补与鞣皮-让皮子更柔软、防水](07-纺织缝补与鞣皮.md#让皮子更柔软防水)。

### 牲畜的照料

```
✓ 蹄: 定期修蹄(马大约每1-2个月),在硬路和石子路上干活的马、骡要钉铁掌;
  每天收工检查蹄底有没有石子、钉子
✓ 休息: 每天工作一般不超过约6-8小时,中间歇口气、饮水;每周至少休息一天
✓ 饮水: 干活后先让它喘匀了再饮,不要满头大汗时猛饮冷水
✓ 不要过载: 驮载一般不超过体重的约20%-25%;车装得太重、坡太陡时宁可分两趟
✓ 每次卸套检查肩、背、胸有没有磨破(套伤、鞍伤),有伤要停用并处理,
  否则伤口越磨越深
✓ 饲料: 干重活的马需要加精料(谷物、豆类),只吃草会越干越瘦
❌ 不要打骂、惊吓牲畜: 受惊的牲畜会拖着车狂奔,非常危险
```

## 道路

**水是道路最大的敌人。** 土路在干的时候很结实,一旦泡了水就变成烂泥,车轮一压就是深沟。修路的大部分功夫都花在让水离开路面上。

### 选线

```
✓ 走高处、干处: 避开低洼地、沼泽、河滩(会淹水、泥泞)
✓ 避开滑坡、塌方、落石的山坡(坡上有裂缝、歪树、渗水的地方)
✓ 坡度不要太陡:
  - 畜力车道: 长坡最好不超过约5%(每走100 m升高5 m),
    短坡不超过约10%
  - 人行和驮运小路可以陡一些,但超过约15%-20%就要修台阶或之字形路
  - 爬坡太陡就绕: 用"之"字形盘山路把坡度放缓(斜面省力不省功)
✓ 尽量少过河,过河处选河道窄、两岸稳固、河床是石头的地方
✓ 放坡: 坡度 = 高差 ÷ 水平距离,用简易水准仪每隔20 m测一个桩
```

具体测法见[测量与制图-简易水准仪](../08-基础科学知识/08-测量与制图.md#42-简易水准仪)和[给水渠放坡](../08-基础科学知识/08-测量与制图.md#44-给水渠放坡);斜面原理见[物理-斜面](../08-基础科学知识/02-物理.md#23-斜面);滑坡的前兆见[地质灾害-山体滑坡](../02-灾难应对/01-地质灾害.md#山体滑坡)。

### 路拱和排水沟

```
路拱: 路面中间高、两边低,雨水向两侧流走
- 横坡约3%-5%(4 m宽的路,中间比边缘高约6-10 cm)
- 太平: 雨水积在路面;太陡: 车往一边溜,路边被冲坏

排水沟:
- 路的两侧各挖一条边沟,深约30-50 cm,沟底低于路基
- 沟底要有坡度,比引水渠陡,至少约0.5%,让水流走而不淤积
- 每隔一段把边沟的水引离道路(引到低处的自然沟谷),不要让水一路沿着路流
- 横穿道路的水: 埋涵管(陶管、石砌涵洞、旧水泥管、空心圆木)
- 坡路上: 斜着在路面上埋一道石条或木条(截水条),把路面上的水引到路边
```

### 碎石路面

```
做法(分层铺,每层压实):
1. 路基: 挖掉表层的草皮和腐殖土,把下面的土整平、夯实,做出路拱
2. 底层: 拳头大小的石块,厚约10-15 cm
3. 中层: 鸡蛋大小的碎石,厚约5-10 cm
4. 面层: 小碎石加石屑、粗砂,厚约3-5 cm
5. 每铺一层洒水、压实(石碾、夯、或让车辆来回碾压)

要点:
✓ 用敲碎的有棱角的石块,互相卡住;圆河卵石容易滚动,要掺碎石
✓ 路基干燥比路面厚更重要: 路基泡水,再厚的碎石也会陷下去
✓ 只有少量石料时: 先铺最泥泞、最低洼的几段
```

### 过水路面

小溪、季节性水沟,修桥不划算时,可以让路面直接从水里过去:

```
1. 选水浅、水流平缓、河床坚实的地方
2. 把过水的一段铺上大石块(或混凝土),两头做成缓坡,防止被水冲出坑
3. 下游一侧用大石块或木桩护住,防止路面被掏空
4. 两侧立标杆,刻上水深记号

⚠️ 水没过记号、水流湍急、水浑浊看不见路面时,人和车都不要过
⚠️ 车辆被水冲走大多发生在这种地方: 约30 cm深的急流就能把车推走
```

能不能涉水的判断见[涉水、山洪与野外失温-判断能不能过](../03-野外生存/08-涉水山洪与野外失温.md#判断能不能过)。

### 维护

```
✓ 每场大雨后巡路: 填坑、清理边沟和涵管里的泥沙和杂物
✓ 雨季前清一遍所有的沟和涵管
✓ 车辙出现就填平,不要让水沿着车辙流(车辙会越冲越深,变成沟)
✓ 砍掉路边伸进来的树枝和灌木,让路面通风晒干
✓ 路面泥泞时尽量不走重车,碾坏一次要修很久
```

## 桥

### 简单的过河方式

```
搭石(跳墩):
- 在浅而平缓的溪流里放一排大石块,间距约一步(约0.4-0.5 m)
- 选又大又平、放在河底不晃的石头,顶面高出常水位
✗ 湿滑、长青苔的石头很滑;涨水后不要走

独木桥:
- 一根粗直的树干横架在两岸,两端搁在稳固的石头或土台上,埋住或楔住防止滚动
- 顶面砍平一些,增加立足面
✓ 加一根扶手绳或扶手杆,能大大减少落水
```

### 简支梁木桥

**梁桥是最容易建的桥: 两岸各做一个桥台,上面搁几根木梁,梁上铺横板。**

```
要点:
- 跨度越大,需要的梁就越粗: 同样的荷载,跨度加倍,中间受的弯矩加倍(均匀荷载时变成4倍)
- 木梁"立着放"(高大于宽)比平放结实得多
- 圆木梁: 直径约30 cm的松木,跨度约5 m,两根并排,过一辆装满货的板车有余量
  (按允许应力约10 MPa估算;木头会腐朽、有节疤,实际要留足余量)
- 跨度超过约6-8 m: 中间加桥墩,或者改用桁架
- 桥台: 用石块砌或木框里填石头,深埋到坚实的土层,防止被洪水掏空
- 梁的两端搁在石头上,不要直接埋进土里(两端最先腐烂)
- 桥面横板之间留缝,让雨水漏下去;两侧加护栏
```

木梁的计算见[工程力学与材料-估算一根木梁能承受多少](../09-进阶科学与工程/01-工程力学与材料.md#53-估算一根木梁能承受多少),桁架见[三角形和桁架](../09-进阶科学与工程/01-工程力学与材料.md#六三角形和桁架),桥台的地基见[地基](../09-进阶科学与工程/01-工程力学与材料.md#九地基)。

### 石拱桥

```
原理: 拱把桥上的重量变成沿拱身的压力,传到两端;石头抗压很强,所以石拱桥能用几百年

建法(原理):
1. 先建两边厚重的桥台(拱脚),必须坐在坚实的地基或岩石上
2. 搭一个木拱架(拱胎),形状就是拱的内弧
3. 从两边拱脚同时往上砌楔形石块,两边一样高,保持对称
4. 最后放进中间的拱顶石,把拱"锁"住
5. 拱上的两肩填石填土,铺好桥面
6. 等灰浆硬化后,再慢慢、均匀地拆掉拱架

⚠️ 拱会向两侧推: 桥台不够厚重,拱脚会向外滑开,整座桥塌掉
⚠️ 没有经验时只建小跨度(几 m)的拱桥,拆拱架时人不要站在拱下
```

拱的受力见[工程力学与材料-拱](../09-进阶科学与工程/01-工程力学与材料.md#71-拱)。

### 索桥

```
原理: 绳索或钢缆只受拉,两端锚固,中间下垂,桥面挂在或铺在缆上
- 主缆: 两根以上的粗绳、钢丝绳(回收)
- 垂度约为跨度的1/10: 拉得越平,缆上的拉力越大
- 锚固: 两端锚在大树根部、巨石或深埋的横木上,要承受缆的全部拉力
- 两侧加扶手缆,扶手缆和桥面之间用绳子连成网,防止人掉下去
✓ 人走在上面会晃: 一次限过几个人,不要齐步走
✓ 植物纤维绳会腐烂、被虫咬: 定期检查,发现磨损、发霉就换
```

悬索的受力见[工程力学与材料-悬索和绳索](../09-进阶科学与工程/01-工程力学与材料.md#八悬索和绳索),绳结见[基础生存技能-绳结技能](../03-野外生存/00-基础生存技能.md#绳结技能)。

### ⚠️ 桥的检验和使用

```
新桥、久未使用的桥、洪水后的桥:
1. 先目测: 桥台有没有被掏空、倾斜;梁有没有裂缝、腐烂(用刀扎,能轻易扎进去就是烂了)
2. 慢慢加载试验: 在桥中间堆放比计划过桥的重量更重的石头或沙袋,
   观察梁往下弯了多少、有没有响声,卸掉后能不能弹回去
3. 先空车过,再半载,再满载
4. 一次只过一辆车、一头牲畜;人和牲畜不要挤在桥上

✓ 在桥头立牌子,写明限重
✓ 每年检查一次,洪水后立即检查

☠️ 洪水期不要过桥: 桥墩、桥台可能已经被掏空,表面看不出来;
   漂下来的树木会撞断桥。宁可等水退
```

山洪的征兆见[涉水、山洪与野外失温-山洪](../03-野外生存/08-涉水山洪与野外失温.md#山洪-溪谷里最大的危险)。

## 水上: 筏和船

**在水上运东西最省力。** 水把重量托住了,低速时阻力很小,一个人撑一条船能运的东西,在路上要好几头牲畜才拉得动。

```
⚠️ 水上安全(每次都要遵守):
✓ 每个人穿救生衣,没有时至少身边有能抱住的浮具(空桶、木块、泡沫块)
✓ 不超载: 船舷离水面要留足高度(小船至少约20-30 cm)
✓ 货物放低、放稳、绑牢,左右平衡;人在船上不要突然站起、挤到一边
☠️ 不在洪水期、大风、大雾、夜里行船
☠️ 远离水坝、拦水堰的下游(翻滚的回流会把人困住)、瀑布、急弯和倒木
✓ 冷水: 落入冷水先控制呼吸,抓紧最初的几分钟自救
✓ 出发前告诉岸上的人去哪里、什么时候回来
```

落入冷水的处理见[涉水、山洪与野外失温-落入冷水](../03-野外生存/08-涉水山洪与野外失温.md#落入冷水),救人见[救落水的同伴](../03-野外生存/08-涉水山洪与野外失温.md#救落水的同伴)和[急性症状-溺水](../01-日常疾病和伤害/05-急性症状.md#溺水)。

### 筏: 用浮力算载重

```
原理: 排开1 m³的水,能托起约1 t(淡水约1000 kg)
筏能载的货 = 浸入水中的体积 × 1000 kg/m³ − 筏自身的重量

例1: 木筏
  10根松木,每根长3 m、直径25 cm
  每根体积 ≈ 3.14 × 0.125² × 3 ≈ 0.15 m³,共约1.5 m³
  干松木约500 kg/m³: 自重约750 kg
  全部压入水中的浮力约1500 kg → 最多约750 kg
  实际只按一半用: 约350 kg(要留出筏面高出水面的余量)
  ⚠️ 木头泡久了会吸水变重,浮力越来越小

例2: 浮筒筏
  200 L的空油桶: 约200 kg浮力,减去桶重约20 kg
  20 L的塑料桶: 约20 kg浮力
  4个200 L油桶上面绑木框、铺木板: 最多约700 kg,安全载重约300 kg
  ✓ 桶口拧紧密封;桶之间、桶和木框之间绑牢

竹筏:
  粗竹(如毛竹)中空、轻,每根净浮力约20-30 kg
  ✓ 竹节不能破,破了会进水;两端削尖翘起,水阻小
  ✓ 用横木和藤、绳把竹子绑成一排,多层叠放增加浮力
```

浮力原理见[物理-浮力: 阿基米德原理](../08-基础科学知识/02-物理.md#45-浮力-阿基米德原理)。

### 独木舟

```
1. 选一根粗、直、没有大节疤的树干(软木容易挖,如松、杉、杨)
2. 顶面砍平,画出船舱的范围
3. 挖空: 用斧、凿一点点挖;或在表面烧炭再刮掉(反复烧、刮,不烧穿)
4. 船壁留约2-3 cm,船底稍厚一些
5. 两头削尖或做成圆弧,减小水阻

✗ 独木舟窄而圆,很容易翻: 在一侧(或两侧)用横杆连一根小浮木(舷外浮杆),
  稳定性大大提高
✓ 新挖的船慢慢阴干,防止开裂;不用时放在阴凉处,底朝上
```

### 木船的基本构造

```
- 龙骨: 船底正中一根纵向的粗木,是船的"脊梁"
- 肋骨: 从龙骨向两侧、向上弯起的一排弯木,决定船的形状
- 船板: 一块块钉在肋骨外面,形成船壳
- 隔舱板: 横向的木板把船舱隔成几格,一格漏水船也不会沉(中国传统做法)
- 填缝防水: 船板之间的缝塞进麻丝、旧棉絮,外面抹桐油石灰(桐油和石灰调成的油灰),
  干后很硬、防水;没有桐油可用松脂、沥青代替
✓ 新船或久放的船下水前先泡几天,木板吸水膨胀,缝就闭紧了
✓ 船底定期刮去附着物、补缝、上油
```

### 桨、舵、篙

```
桨: 两侧划的桨用桨架支在船舷上;单人短桨直接用手握着划
舵: 船尾一块可以转动的木板,转动它改变船的方向;小船也可以在船尾用一支长桨当舵
撑篙: 一根长竹竿,插到河底往后撑,船就往前走
  - 适合约3 m以内的浅水;水深了撑不到底,换桨
  - 撑篙时人沿着船舷从船头走向船尾,不要在船中间猛撑把船弄翻
顺流而下最省力;逆流时靠岸边水缓处走,或在岸上用绳子拉船(拉纤)
```

## 渡河

```
渡口选址:
✓ 河面宽、水流平缓、两岸有坚实平缓的上下船地方
✓ 上游没有急流、险滩;下游一段距离内没有瀑布、拦水堰
✓ 两岸修平台或台阶,方便牲畜和车上下

绳索导引的渡船(拉索渡):
1. 在两岸之间拉一根粗绳或钢缆,高出水面,两端牢牢锚住
2. 船通过绳环或滑轮挂在缆上(或船上的人手拉着缆走)
3. 把船头斜着对向上游,水流会把船推向对岸,不用划桨也能过河
4. 涨水时加大缆的高度或停渡,防止漂浮物挂住缆

☠️ 渡船超载是历史上最常见的翻船原因: 定好每船的人数和货物重量,写在渡口
☠️ 牲畜上船要拴好、蒙眼或有人牵住,受惊乱动会把船弄翻
❌ 不要把绳子系在人身上过河(人被冲倒后会被绳子按在水下)
✓ 船上常备救生衣、浮具、水瓢(舀水)
```

徒步涉水的方法见[涉水、山洪与野外失温-涉水过河](../03-野外生存/08-涉水山洪与野外失温.md#涉水过河)。

## 运输方式的比较

| 方式 | 每次运量 | 每天行程 | 适合 |
|------|---------|---------|------|
| 人背 | 约20-30 kg | 约20-25 km | 山路、小路、短途 |
| 扁担挑 | 约40-50 kg | 约20-30 km | 平路、田间 |
| 独轮车 | 约100-150 kg | 约20-30 km | 窄路、田埂 |
| 自行车(推行载货) | 约100 kg | 约30-40 km | 有路的地方 |
| 驴驮 | 约40-60 kg | 约20-30 km | 山路 |
| 骡、马驮 | 约80-120 kg | 约25-35 km | 山路、长途 |
| 牛车 | 约0.5-1 t | 约15-20 km | 重货、短途 |
| 马车(好路) | 约0.5-1 t | 约30-40 km | 平路、长途 |
| 小木船(2-3人) | 数吨 | 顺水数十 km | 沿河、湖 |

```
结论:
1. 同一个人的力气,水运 > 车运 > 驮运 > 背挑
   历史上常说一匹马在运河上拖船能运几十吨,在路上拉车只能运约1 t
2. 路的好坏比车的好坏更重要: 碎石路上一头牲畜能拉的货,是烂泥路上的几倍
3. 重而便宜的东西(粮食、石料、木材、柴炭)尽量走水路,或者就近生产、就近使用
4. 村子、仓库、作坊尽量选在河边或路边,能省下大量搬运的力气
```

功和功率的计算见[物理-功和功率](../08-基础科学知识/02-物理.md#31-功和功率)。

## 📝 车船与道路要点

```
1. 先回收: 自行车、手推车、旧车的轮子和轴承最难自制;汽油放3-6个月就会变质
2. 自行车是最高效的人力交通,储备内胎、补胎胶、链条、刹车皮
3. 独轮车把货物的重心放在轮子上方,人只扶着推;板车重心在轴上或稍靠前
4. 车轴勤加油(动物油加石墨),轴头发烫就是缺油
5. 牛用牛轭,马用胸带或颈圈;不用勒脖子的颈带,不过载,检查蹄和肩
6. 水是道路最大的敌人: 路拱、边沟、涵管;车道长坡不超过约5%
7. 梁桥最容易建;拱桥的桥台要厚重;新桥和洪水后的桥先加载试验
8. 排开1 m³水约托起1 t,筏只按一半载重用
9. 水上必须穿救生衣或带浮具,不超载,洪水、大风、大雾不行船
10. 水运最省力,重而便宜的东西尽量走水路
```
