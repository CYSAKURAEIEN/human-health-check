## 先说清楚: 本章的定位

种出粮食只是一半。从田里的稻穗、麦穗到锅里的米饭、馒头和炒菜的油,中间还有收割、脱粒、扬净、晒干、去壳、磨粉、榨油一整串工序。机器停摆以后,这些工序全要靠人力、畜力和水力,而且**收获季节一旦遇上连阴雨,晒不干的粮食几天就会发芽、霉烂**,一年的辛苦可能白费。

种植方法见[粮食作物](../04-动植物培育/02-粮食作物.md),晒干和储存的基本要求见[食物加工与保存-粮食和豆类](01-食物加工与保存.md#粮食和豆类)。本章讲收获以后到能下锅的加工过程。

```
⚠️ 安全:
- ☠️ 霉变的粮食、花生、玉米整批丢弃,不能吃、不能榨油、不能喂牲畜(黄曲霉毒素)
- ☠️ 棉籽油不经精炼不能吃;桐油、蓖麻油有毒,绝不能当食用油
- 面粉、糠麸粉尘飘在空气中遇明火会爆炸: 磨坊、粮仓里禁止明火
- 脱粒机、石碾、石磨、榨油机都会把手、衣袖、头发卷进去
- 牲畜拉磨、拉碾时,人不要站在它行走的圈内
- 熟石灰水(玉米碱处理用)会烧伤皮肤和眼睛
```

## 收获: 什么时候割、怎么割

### 看成熟度

| 作物 | 适合收割的时候 | 简易判断 |
|------|---------------|---------|
| 水稻 | 约90%谷粒黄熟 | 穗弯垂,谷粒用指甲掐不出白浆、能掐出硬痕 |
| 小麦 | 蜡熟末期到完熟初期 | 籽粒像蜡一样能用指甲掐断但不出浆;再晚就会落粒 |
| 玉米 | 苞叶枯黄,籽粒变硬 | 籽粒顶部的乳线消失,底部出现黑层 |
| 大豆 | 叶片脱落,豆荚变黄 | 摇动植株,豆粒在荚里哗哗响 |
| 高粱、谷子 | 穗下部籽粒变硬 | 籽粒有光泽,牙咬不出浆 |

```
用指甲掐籽粒,分三个阶段:
1. 乳熟: 一掐就出白浆 → 太早,割下会瘪粒、产量低
2. 蜡熟: 像蜡一样软,掐得动但没有浆 → 小麦开始收
3. 完熟: 硬,掐不动 → 稻谷适合收;小麦此时已开始落粒

✓ 宁早两三天,不要晚: 熟过头会落粒、倒伏、遇雨在穗上发芽
✓ 看天收割: 选连续几个晴天开镰,见天气观测
```

看天气见[天气观测与预报](../08-基础科学知识/07-天气观测与预报.md)。

### 收割和捆扎

```
1. 镰刀割: 左手握一把茎秆,右手镰刀贴近地面往怀里拉
   ⚠️ 镰刀永远往远离自己腿脚的方向用力;刀要磨快,钝刀更容易滑脱伤人
2. 留茬: 稻麦一般留茬约10-20 cm,秸秆另有用处(盖房、垫圈、造纸、燃料)
3. 割下的稻麦一小把一小把放在茬上晾一两天(田里干燥时)
4. 捆把: 抽一小绺秸秆当"草腰子",把一抱稻麦拦腰捆紧,穗都朝一头
5. 码垛: 穗朝里或朝上、茎朝外,码成尖顶垛,顶上盖草帘防雨
   → 不要堆成大堆久放: 湿稻麦捂在一起会发热、发芽、霉烂
```

磨镰刀见[木工与工具维护-磨刀](09-木工与工具维护.md#磨刀)。

## 脱粒

先准备**打谷场(场院)**: 选平整、向阳、通风的空地,除去草根,洒水后用石磙反复压实,干后地面坚硬光滑,粮食不会混进泥土。没有场院时铺大块篷布、竹席。

### 摔打(掼稻)

```
最简单,只要一个大木桶或木箱(稻桶、拌桶):
1. 桶的三面围上草席或布,挡住飞溅的谷粒
2. 双手握住一把稻的茎秆,高举后用力摔打在桶壁或桶内斜放的木架上
3. 每把摔三四下,翻过来再摔,谷粒落进桶里
✓ 适合稻谷(谷粒易落)和小把麦子
→ 一个熟练的人一天约脱几百 kg 稻谷;体力消耗很大,轮换着干
```

### 连枷

```
构造: 一根长柄(约1.5-2 m),顶端用横轴连一块可以转动的拍板
      (几根木条或竹条并排编成,约0.5-1 m长)
用法: 稻麦、豆荚平铺在场院上,双手挥柄,让拍板翻转过来拍打穗头
✓ 适合小麦、大豆、油菜籽、谷子等
⚠️ 几个人同时打时排成一排、节奏一致,彼此保持距离,防止拍板打到人
```

### 碾压

```
1. 把穗子在场院上摊成厚约20-30 cm的一圈
2. 牲畜(牛、驴、马)拉石磙沿圆圈来回碾压,人跟在后面用木杈翻动
3. 碾完一遍翻一遍,反复几遍,直到穗上没有籽粒
4. 挑走秸秆,剩下籽粒和碎壳,再扬场
✓ 适合小麦、谷子、高粱、豆类,效率比人力摔打高得多
⚠️ 牲畜要戴笼嘴(不然会边走边吃),人不要站在石磙前面
```

畜力的功率见[热力学与动力机械-畜力和人力](../09-进阶科学与工程/03-热力学与动力机械.md#83-畜力和人力)。

### 简易脚踏脱粒机

```
构造:
- 一个能转动的木滚筒(直径约40 cm,长约0.6-1 m),表面钉满弯成倒U形的粗铁丝(弓齿)
- 滚筒一端连曲柄和连杆,接到下方的脚踏板上
- 滚筒装在木架上,三面围挡

用法: 一人踩踏板让滚筒高速转动,双手握紧稻把,把穗头放到滚筒上翻动,
      弓齿把谷粒梳打下来
→ 效率约为摔打的2-3倍

⚠️ 双手只握茎秆根部,不要把手伸到滚筒附近;袖口扎紧,不戴围巾,长发盘起
⚠️ 先停稳滚筒再清理缠绕的稻草
```

曲柄、齿轮等传动原理见[物理-齿轮和传动](../08-基础科学知识/02-物理.md#25-齿轮和传动)。

## 扬场与风选

脱下来的粮食混着碎秸秆、谷壳、瘪粒和尘土,要借风把轻的吹走。

### 借风扬场

```
1. 等有稳定的微风(树叶不停摇动、细枝轻摆的程度),风太大会把好粒也吹走
2. 人侧对风站,用木锨铲起粮食,斜向上抛成一道弧线
3. 重的饱满籽粒落在近处,轻的瘪粒和碎壳落在稍远处,尘土和碎叶被吹走
4. 扫帚轻扫落在籽粒堆表面的碎壳(掠场)
5. 一般扬两三遍才干净
```

### 簸箕

```
少量粮食用簸箕: 双手端住两侧,上下颠动并稍向前送
→ 籽粒向簸箕里面集中,谷壳和碎屑被颠到前沿,轻轻一抖就出去了
✓ 碾米、舂米后去糠也用这个办法
```

### 风车(扇车)

没有风的日子,用手摇风车自己造风。

```
原理: 粮食从上方漏斗匀速落下,穿过一股侧向的风
      → 重粒几乎直落,轻粒被吹偏一点,壳和尘土被吹出去

构造:
1. 木箱,一端装一个手摇的风扇(4-6片木叶片装在轴上,外面有圆形风道)
2. 上方装漏斗,漏斗下口有可调节的闸板,控制落料速度
3. 箱底有两个出口: 靠近风扇的出口出饱满粮食,稍远的出口出瘪粒
4. 箱的另一端开口,壳和尘土从这里吹出

调节:
- 摇得快 → 风大,好粒也可能被吹走
- 摇得慢 → 风小,壳吹不干净
- 落料要细而匀,一下倒太多就吹不透
```

木箱和榫卯做法见[木工与工具维护](09-木工与工具维护.md)。

## 干燥到安全水分

刚收的稻麦含水约20-30%,霉菌和虫子都能活。要晒到安全水分才能入仓: **稻谷 <13%,小麦 <12%,玉米 <14%**,大豆约12%以下,花生、油菜籽等油料更低(约8-10%)。

### 晒粮

```
1. 早上露水干后再摊开,摊厚约3-5 cm,用木耙划出垄沟(增加受热面)
2. 每隔约1小时翻一遍
3. 傍晚趁粮食还温热时收拢成堆、盖好,防夜露返潮
   (但装袋入仓要等晾凉,热粮装袋会凝结水汽返潮)
4. 稻谷不要在烈日下一次晒得太急,也不要晒后马上泼水降温
   → 籽粒内外收缩不均会出现裂纹("爆腰"),碾米时碎成碎米
5. 一般连晒2-4个晴天

防雨:
✓ 场院边备好篷布、草帘和扫帚、木锨,天色一变全体收场
✓ 收拢成长条堆,顶部尖,盖布四周压石块,底下垫高防地面水
✓ 连阴雨时,把粮食摊薄在屋内、棚下,通风,勤翻;
  可以在室内架起竹席,下面用小火温烘(不能有明火直接接触,注意防火)
```

### 怎么判断晒干了

```
牙咬: 咬下去"咔"一声清脆断开,不粘牙、不变形 → 基本干了
      咬起来发软、发黏、能咬出牙印 → 还湿
手握: 抓一把用力攥紧再松开,籽粒立刻散开、沙沙响 → 干
      松开后成团或手心发潮 → 湿
摇响: 装进瓶子或竹筒摇,声音清脆 → 干;声音发闷 → 湿
盐瓶法(较可靠):
  1. 干燥的玻璃瓶装约3/4瓶粮食,加1-2勺干燥的细盐
  2. 盖紧摇1分钟,静置15分钟,再摇一下
  3. 盐粘在瓶壁上或结块 → 粮食太湿(水分大约超过14%),继续晒
     盐松散不粘 → 可以入仓
```

## 储粮: 防霉和防虫

容器、仓房和储存期限见[粮食作物-储存要点](../04-动植物培育/02-粮食作物.md#储存要点)。这里补充防霉防虫的具体办法。

```
防霉:
✓ 唯一可靠的办法是晒干: 霉菌在安全水分以下基本不长
✓ 粮仓离地、离墙,下面垫木板或石块,防地面返潮
✓ 每月检查: 手插进粮堆深处,感觉发热、发潮、有霉味 → 立即摊开翻晒
✓ 雨季后检查一次表层和靠墙的粮食

防虫:
1. 低温: 储粮害虫在约15°C以下基本不繁殖;北方冬季把粮食摊在室外冻几天,
   能冻死大部分虫卵,冻后放凉再收回
2. 密闭缺氧: 晒干的粮食装满能完全密封的缸、桶、厚塑料袋,封死
   → 虫子在里面呼吸,把氧气耗尽后死亡,一般几周
   ✓ 尽量装满,少留空气;不要中途反复打开
3. 草木灰: 豆类、小量种子拌入干燥的草木灰(盖过表面、填满粒间的空隙),
   或在缸里一层粮一层灰,阻止虫子爬行和产卵;吃之前淘洗干净
4. 晒: 已生虫的粮食摊在烈日下暴晒,虫子会爬出逃走,过筛
5. 花椒、干辣椒、艾叶包成小布包放在粮缸里,有一定驱虫作用

☠️ 不要自己用磷化铝("粮虫净"等熏蒸片)熏粮: 释放剧毒的磷化氢,每年都有家庭因此死亡
```

```
☠️ 霉变粮食的处理:
- 发霉、结块、变色、发苦的粮食、花生、玉米 → 整批丢弃
- 不要挑拣着吃,不要洗了再吃,不要喂鸡喂猪
- 黄曲霉毒素加热不能破坏,而且会通过肉蛋奶转移到人身上
```

黄曲霉毒素见[食物加工与保存-黄曲霉毒素](01-食物加工与保存.md#黄曲霉毒素),用库存估算吃多久见[记账、交易与社会分工-算一算够用多久](13-记账交易与社会分工.md#算一算够用多久)。

## 稻谷: 去壳和碾米

稻谷外面有一层硬谷壳(砻糠),人不能消化。去掉谷壳得到**糙米**,再把外面的糠层碾掉得到**白米(精米)**。

### 砻谷: 去壳

```
石臼舂米(最简单):
1. 石臼或硬木挖成的臼,里面放约1/3深的稻谷
2. 用木杵(一头粗圆)上下舂捣,谷粒互相摩擦,谷壳破开脱落
3. 舂一会儿倒出来用簸箕簸去谷壳,没破的再舂
✓ 脚踏碓: 一根长木杠,中间架在支架上,一头装杵头,
  人踩另一头再松开,杵头落下舂米 → 用腿比用手省力得多(杠杆原理)

土砻:
- 像一盘小磨,上下两扇,用竹篾编外壳、里面填压实的黄泥,
  磨面上嵌入竹片或硬木片做齿
- 稻谷从上扇中间的孔落下,转动上扇,谷粒在两扇之间被搓开外壳,
  但米粒不被磨碎(两扇间隙比磨面粉的石磨大)
- 出来的谷壳和糙米混在一起,用风车或簸箕分开
```

杠杆原理见[物理-杠杆](../08-基础科学知识/02-物理.md#21-杠杆)。

### 碾米和出米率

```
在石臼里继续舂糙米,或用石碾碾压,糙米之间互相摩擦,糠层被磨下来,簸出米糠

大致出率(按重量):
- 稻谷 → 糙米: 约78-80%
- 糙米 → 白米: 约88-92%(碾得越白,损失越多)
- 稻谷 → 白米: 约65-70%

米糠: 营养丰富,可以掺进粥饭、做饼,也是很好的饲料;
     容易酸败变哈,碾出来一两周内用掉
谷壳: 燃料、垫圈、和泥做土坯、堆肥
```

### 糙米和精米: 别碾得太白

稻米的维生素B1主要在糠层和胚芽里。碾得越白、淘洗越狠,丢掉的就越多。长期只吃精白米、缺少豆类杂粮的人群,历史上大批患**脚气病**(腿脚水肿麻木、心力衰竭),这不是"脚气"那种真菌感染。

```
✓ 吃糙米或只碾一两遍的半精米(米粒还带一点黄色)
✓ 搭配豆类、杂粮
✓ 好处之二: 少碾一遍,出米率更高,干活还更省力
✗ 糙米储存期比白米短(糠层里的油脂会酸败),现吃现碾
```

详见[营养与营养缺乏病-维生素B1](02-营养与营养缺乏病.md#维生素b1-别把米碾得太白)。

## 小麦: 石磨磨面

### 磨之前

```
1. 筛去土块、草籽,挑出石子
2. 簸净或用清水快速淘洗,摊开晾到表面干、内部还稍有潮气(润麦)
   → 麸皮稍有韧性,磨时成大片,容易筛出;不要泡湿,湿麦会糊磨
3. 黑色、变形的麦粒(麦角)和发霉的麦粒必须挑出
   ☠️ 麦角有毒,会引起四肢坏疽和抽搐;黑麦更常见
```

### 石磨的构造

```
- 上下两扇圆形石盘,常用硬而不易掉渣的石材(花岗岩、砂岩)
- 下扇(底扇)固定不动,中心有一根短轴(磨脐)
- 上扇(顶扇)套在轴上转动,上面开一两个进料孔(磨眼),侧面装推杆或拉杆
- 两扇相对的磨面都刻有磨齿:
  - 磨面分成若干区(常见6区或8区),每区刻一组平行的斜槽
  - 上下两扇的斜槽方向相反,转动时像剪刀一样交错
  - 中心部分稍凹(磨膛),麦粒先在这里破碎,然后被挤向外缘越磨越细
- 下扇外面有一圈磨盘(接面的台子),面粉从磨缝挤出落在上面

尺寸参考:
- 手推磨: 直径约40-60 cm,一人可推
- 畜力磨: 直径约80-100 cm,驴或牛拉
```

### 磨面和过筛

```
1. 往磨眼里放麦子,一次不要太多,让它自己慢慢流下去
2. 推磨: 匀速转动,手推磨约每分钟十几到二十几圈
3. 第一遍出来的是碎麦和粗粉,用细箩(细筛)筛出面粉
4. 留在筛上的粗渣再上磨,反复磨、反复筛,一般3-5遍
5. 最后剩下的片状物是麸皮

出粉率(按重量):
- 全麦粉(连麸一起磨细): 约95%以上
- 普通面粉: 约75-85%
- 白面(只要最白的头几遍粉): 约60-70%
→ 粮食紧张时多出粉,麸皮里有B族维生素和纤维,不要浪费

产量(大约): 手推磨每小时磨几 kg;驴拉磨每小时约十几 kg
  一家4口每天约需2 kg粮食(按每人约0.5 kg),手推磨约要1小时
```

### 磨齿的修凿(锻磨)

用一两个月以后,磨齿会变浅变平,磨得慢、面发热、出麸多,就要重新凿齿。

```
1. 卸下上扇(两三个人抬,或用撬棍和木楔一点点抬起,防止砸脚)
2. 扫净两扇磨面,用尺量看磨面是否还平,高处先磨平
3. 用钢錾子和锤子沿原有的斜槽一道一道凿深,保持槽的方向和角度不变
4. 槽的一边陡、一边缓;边缘锋利才能剪碎麦粒
5. 凿完扫净,先磨一点麸皮或碎粮把石屑带出来,这一批不吃

⚠️ 戴护目镜: 凿石时碎屑飞溅,伤眼最常见
⚠️ 长期凿石吸入石粉会得矽肺,打湿了再凿,戴口罩
```

錾子的锻打和淬火见[钳工与机械加工](../05-冶金技术/09-钳工与机械加工.md)。

### 畜力磨和水磨

```
畜力磨: 牲畜套在磨杆上绕圈走,给牲畜戴上眼罩(防止头晕、停下偷吃)
水磨: 水车带动磨盘
- 立式水轮 → 通过一对齿轮把水平轴的转动变成竖直轴的转动,带动上扇
- 卧式水轮(平轮): 水冲击装在竖轴下端的水平叶轮,竖轴直接带动上扇,
  结构最简单,适合山区落差较大的小溪
- 一个小水磨(约1-2 kW)相当于十几个人推磨,可以全村共用
```

水力功率估算见[物理-水力: 水车和水磨](../08-基础科学知识/02-物理.md#33-水力-水车和水磨)和[热力学与动力机械-水力](../09-进阶科学与工程/03-热力学与动力机械.md#81-水力),引水渠见[水源工程与供水-引水](10-水源工程与供水.md#引水)。

## 玉米

### 脱粒和磨粉

```
脱粒:
1. 带苞叶挂起或在通风处晾干玉米棒(水分<14%),籽粒变硬才好脱
2. 两个玉米棒互相搓,或用拇指顺着行推;量大时用木棒敲打装在麻袋里的玉米棒
3. 简易脱粒器: 木板上钻一个比玉米棒稍粗的孔,孔边钉一圈钉子头,
   把玉米棒用力从孔中旋转推过去
4. 玉米芯晒干是很好的燃料

磨粉: 石磨磨成玉米碴(粗)或玉米面(细),做法同小麦
- 玉米胚芽含油多,磨成粉后容易变哈,少磨勤磨
```

### ⚠️ 以玉米为主食: 先用碱水煮

玉米里的烟酸是结合形式,人体难以利用,而且玉米蛋白质缺少色氨酸(人体能用它合成一部分烟酸)。长期以玉米为主食、又少吃豆类肉蛋的人群,历史上大批患**糙皮病**: 晒太阳的地方皮肤发红脱皮、腹泻、精神异常,严重时死亡。

美洲原住民几千年吃玉米却很少得这种病,原因是他们**用石灰水煮玉米**: 碱让结合的烟酸释放出来,同时软化玉米皮,改善口感和营养。

```
石灰水煮玉米(约数):
1. 干玉米粒1 kg,清水约2-3 L,熟石灰约10-20 g(玉米重量的1-2%)
   没有熟石灰时用草木灰滤出的碱水
2. 先把熟石灰搅进水里,再下玉米,煮约30-60分钟,到玉米皮能用手指搓掉
3. 离火浸泡过夜
4. 倒掉碱水,反复搓洗冲净,去掉大部分玉米皮
5. 晾干后磨粉,或直接湿磨成面团做饼

⚠️ 熟石灰和碱水会烧伤皮肤和眼睛,溅入眼睛立即用大量清水冲洗
⚠️ 只用熟石灰(氢氧化钙),不要往水里直接加生石灰(剧烈放热、飞溅)
```

做法和背景见[营养与营养缺乏病-烟酸](02-营养与营养缺乏病.md#烟酸-吃玉米要用碱处理),石灰的烧制见[化学-石灰的循环](../08-基础科学知识/03-化学.md#44-石灰的循环-建筑的基础)。

### 豆类

```
1. 豆荚变黄、摇动有响声时连秧割下,晒干
2. 在场院上用连枷拍打、石磙碾压,或少量时装进麻袋用棍子敲,豆粒从荚里蹦出

```

## 榨油

油脂是能量最集中的食物(每 g 约9 kcal,是粮食的2倍多),还能点灯、做肥皂、保养工具。

### 原料

| 原料 | 籽(仁)含油量 | 传统土榨出油率(按原料重,约数) | 说明 |
|------|-------------|---------------------------|------|
| 花生仁 | 约40-50% | 约35-40% | 出油高、好榨;⚠️ 霉变的绝不能榨 |
| 芝麻 | 约45-55% | 约40-45% | 小磨香油用水代法,见下 |
| 油菜籽 | 约35-45% | 约30-35% | 北方南方都能种,产量稳 |
| 葵花籽 | 仁约40-50% | 带壳约25-30% | 先去壳出油更多 |
| 油茶籽(茶籽) | 仁约40-50% | 全籽约20-25% | 南方山区,耐储存 |
| 大豆 | 约17-20% | 约8-12% | 土榨出油低,豆饼是好饲料和肥料;更适合吃豆子本身 |
| 猪板油、肥膘 | — | 约70-80% | 熬炼,最容易 |

```
☠️ 霉变、发苦的花生、玉米胚、葵花籽不能榨油:
   黄曲霉毒素会溶进油里,油看起来清亮也照样有毒,高温炸也不分解
☠️ 棉籽: 含棉酚,长期吃土榨棉籽油会导致低血钾、全身无力、男女不育;
   只有经过碱炼精炼的棉籽油才能吃,小作坊做不到 → 不要食用土榨棉籽油
☠️ 桐油: 有毒,误食引起剧烈呕吐、腹泻;外观和气味都像食用油,历史上反复发生误食
   → 只作木器涂料、防水、灯油;用专门的容器,写明"桐油 不能吃",和食用油分开存放
☠️ 蓖麻籽: 含蓖麻毒素,种子不能吃;蓖麻油只作润滑油和泻药原料,不当食用油
```

### 基本工序

```
1. 清选: 筛去土石、挑出霉粒和瘪粒,晒干(油料水分约8-10%)
2. 去壳: 花生、葵花籽、茶籽先去壳(壳会吸油);油菜籽、芝麻不用去
3. 炒籽: 铁锅小火炒,不停翻动,到籽粒微黄、有香味(芝麻炒到发出噼啪声)
   → 加热让细胞破裂、油变稀,出油多;炒焦了油发苦发黑
4. 粉碎: 石碾碾碎或石磨磨成粗粉(不要太细,太细压榨时堵塞出油)
5. 蒸坯: 粉放在笼屉上用蒸汽蒸约10-20分钟,到用手一捏能成团、不散不出水
   → 让粉吸湿、受热,蛋白质凝固,油更容易流出
6. 包饼: 趁热把粉填进铁箍或竹箍里,外面用稻草或麻布包紧,踩实,做成圆饼
   ✓ 动作要快,凉了就压不出油
7. 压榨: 把一叠饼放进榨里,逐渐加压,油从饼缝里流出来,下面接住
8. 头道榨完后,饼可以再粉碎、再蒸、再榨一遍,能多出一些油
```

### 三种榨

```
楔式木榨(传统作坊):
- 一根挖空的大硬木(榨槽),饼饼相叠竖放在里面
- 饼和木块之间插入木楔,人拉吊起来的撞锤(撞杆)一下下撞击木楔,楔子越打越紧
- 原理: 楔子是斜面,小的进给距离换来很大的挤压力

杠杆榨(最容易自己做):
- 一根长而结实的木梁(约4-6 m),一端插进墙或木桩的孔里作支点
- 饼放在靠近支点的位置,木梁压在饼上
- 另一端挂石块或装重物的筐,逐渐加重
- 例: 饼距支点0.5 m,重物距支点5 m,挂200 kg重物 → 压在饼上的力相当于约2000 kg的重量
- 慢慢压,一榨压几个小时到一夜

螺旋榨:
- 一根粗木螺杆或铁螺杆穿过固定的横梁,下端压一块压板
- 用长杆转动螺杆,压板往下压饼
- 原理: 螺旋是绕在柱子上的斜面,转一圈只下降一个螺距,力放大很多倍
- 木螺杆用硬木刻制,铁螺杆需要车床或锉刀加工
```

杠杆、斜面和螺旋的原理见[物理-简单机械](../08-基础科学知识/02-物理.md#二简单机械)。

### 小磨香油(水代法)

```
芝麻不用压榨,用水把油"换"出来:
1. 芝麻炒熟,石磨磨成很细的芝麻酱
2. 酱里慢慢加入接近沸腾的热水,边加边用力搅
3. 水和芝麻渣结合沉下去,油被挤出来浮在上面
4. 不断晃动、撇出上层的油
→ 出油率接近压榨,不需要榨具
```

### 熬炼动物油

```
1. 猪板油、肥膘切小块,锅里加少量水,小火慢熬
2. 水分蒸干、油渣变成金黄色并缩小时离火(油渣焦黑会让油发苦)
3. 趁热用纱布过滤,装进干净干燥的陶罐
4. 凝固后表面平整洁白的为好油
✓ 油渣可以吃,也可以做馅
⚠️ 熬油时锅里绝不能突然进水(油会猛烈飞溅);油锅起火盖锅盖,绝不能用水浇
```

熬制更纯的脂肪见[照明与能源-熬炼动物脂肪](06-照明与能源.md#熬炼动物脂肪),废油做肥皂见[制皂-第二步: 准备油脂](04-制皂.md#第二步-准备油脂)。

## 油的澄清和储存

```
澄清:
1. 刚榨出的毛油浑浊,含渣和水,装进缸里静置几天到几周,渣和水沉底
2. 小心舀出或用细管虹吸出上层清油,底部的油脚另作他用(做肥皂、润滑)
3. 想存得更久: 把清油在锅里小火加热,直到不再冒细小水泡(水分蒸干),
   冷却后装罐;加热时锅里不能有水滴
   菜籽油加热到冒少量青烟、去掉生青味再用(熟油)

储存:
✓ 用深色玻璃瓶、陶罐、不锈钢桶,装满、盖严(少留空气)
✓ 避光、阴凉;光、热、空气和铜铁会加快酸败
✓ 少量多次取用,大罐不要天天打开
✓ 土榨油一般存几个月到半年,动物油冬天能存得久一些
✗ 不要用铜器、铁锈多的容器盛油

酸败的判断: 有"哈喇味"(刺鼻的陈油味),颜色变深变稠
→ 不要再吃,可以做肥皂或当灯油
```

## 作坊安全

### 粉尘爆炸

面粉、米糠、玉米粉、木屑都是可燃物。成堆时不容易烧,但**细粉飘散在空气中遇到火星,会在一瞬间全部烧起来**,形成爆炸,历史上的磨坊和粮仓爆炸屡见不鲜。

```
✓ 磨房、粮仓、筛面的地方禁止明火: 不点油灯、不抽烟、不在里面生火
✓ 照明用远离粉尘的灯,或把灯放在玻璃罩里,挂在门外照进来
✓ 筛面、倒粉时动作轻,少扬起粉尘;勤扫地面和梁上的积粉
✓ 石磨、轴承缺油发热也可能点燃积粉 → 定期上油、检查
✓ 门窗通风,让粉尘及时散出
```

原理见[化学进阶-反应速率和催化](../09-进阶科学与工程/05-化学进阶.md#四反应速率和催化),起火时的处置见[火灾](../02-灾难应对/04-火灾.md)。

### 机械卷入和畜力

```
⚠️ 脱粒机滚筒、风车摇柄、水磨齿轮、榨油螺杆都会卷住衣袖、头发、围巾
   → 扎紧袖口,长发盘起,不戴围巾和长挂件
⚠️ 清理缠绕、调整机器前,先让它完全停下来;水磨要先关闸断水
⚠️ 水轮和齿轮外面加木罩;水磨的水渠、水轮周围不让小孩靠近
⚠️ 牲畜拉磨: 人不进入牲畜绕行的圈内;给牲畜加料、调整套具时先让它停下并有人牵住
⚠️ 撞锤式油榨: 撞锤摆动范围内不能站人
⚠️ 搬抬石磨、石磙: 几个人一起,用撬棍、滚木,不要弯腰硬抬
```

## 📝 粮油加工要点

```
1. 收割宁早两三天不要晚;选连续晴天开镰,雨前收场
2. 晒到安全水分再入仓: 稻谷<13%、小麦<12%、玉米<14%;牙咬清脆,盐瓶法检查
3. 防虫: 低温冻、密闭缺氧、拌草木灰;不自己用磷化铝熏蒸
4. 霉变的粮食、花生、玉米整批丢弃: 不吃、不榨油、不喂牲畜
5. 米不要碾太白(脚气病);吃玉米为主先用石灰水煮(糙皮病)
6. 石磨磨齿变平就凿深;反复磨、反复筛,多出粉少丢麸
7. 榨油: 清选 → 去壳 → 炒 → 碎 → 蒸 → 包饼 → 压榨;杠杆榨最容易自己做
8. 不吃土榨棉籽油;桐油、蓖麻油有毒,专罐存放、写明标记
9. 油避光、装满、盖严;有哈喇味不再吃
10. 磨坊粮仓禁止明火(粉尘爆炸);机器先停稳再清理,袖口扎紧
```
