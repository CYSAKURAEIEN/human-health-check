## 为什么这一章很重要

一门手艺、一种知识,如果只在一两个人的脑子里,这个人一生病、一离开,它就消失了。历史上很多技术就是这样失传的。

```
知识要传下去,需要三样东西:
1. 会读、会写、会算的人(能自己从书本里学)
2. 写下来、保存好的资料(这本手册就是一份)
3. 有人愿意教、有人有时间学
```

灾后和长期困难时期,**孩子的学习不能停**: 规律的上课本身就能帮助孩子恢复安全感(见心理健康),而几年不上学,一代人的读写能力就会明显下降。

心理支持见[心理健康](../01-日常疾病和伤害/10-心理健康.md);技术重建中"人"的作用见[技术重建路线图-人](../09-进阶科学与工程/00-技术重建路线图.md#36-人)。

## 先教什么

时间和人手有限时,按对生存和健康的影响排序:

```
第一层(人人都要会):
- 洗手、饮水卫生、厕所的使用(见卫生设施、水源工程与供水)
- 基础急救: 止血、心肺复苏、烧伤处理、什么时候必须求助
- 安全: 火、水、电、有毒的植物和蘑菇、危险动物
- 本社区的应急计划: 集合点、报警方式

第二层(基础能力):
- 识字、写字
- 算术: 加减乘除、分数、比例、测量
- 本地的农时、种植和养殖的基本做法

第三层(按兴趣和需要分流):
- 手艺: 木工、铁匠、纺织、制陶、医护、建房……(学徒制)
- 科学: 物理、化学、生物(用本手册第八、九部分)
```

## 教孩子和成人识字

### 汉字的特点

```
- 认得常用的约2500个字,就能读懂日常文字的绝大部分(约98%)
  认得约3500个字,一般书报基本没有障碍
- 先学拼音,能帮助自学: 不认识的字查字典,或者看注音读物
- 字是一个一个记的,需要反复见、反复写,最好放在有意义的词句里学
```

### 方法

```
1. 先认后写: 认字比写字快得多,先大量认读,写字慢慢跟上
2. 从身边的字学起: 自己和家人的名字、"水""火""米""药""危险""出口"等
3. 在句子里学: 把字放进短句、儿歌、生活中的标签里
4. 多读: 认识了几百个字以后就开始读简单的读物,在读中认新字
5. 天天复习: 新学的字第二天、第三天、一周后、一个月后再复习,比一次学很多记得牢
6. 写字: 先描红,再临写,注意笔顺;每天写一点,不求多
7. 让学生大声读出来、讲给别人听

识字卡片: 一面写字,一面画图或写拼音;孩子之间可以互相考
在社区里贴标签: 水井、厕所、药箱、危险品上写字,随时看到随时认
```

```
教成人:
- 成人学得慢,但目的明确: 从他们需要的内容开始(记账、看说明、写信、读药品标签)
- 不要当众让人难堪;很多人不识字会感到羞愧
- 每次时间短一点(约半小时),坚持每天学
```

## 教算术

```
1. 实物开始: 用石子、豆子、小棍数数,理解"多少"
2. 位值: 十个一捆成一个"十",十个十成一个"百"(用小棍捆起来最直观)
3. 加减: 先用实物,再列竖式
4. 乘法: 背九九乘法表(可以编成歌)
5. 除法和分数: 分东西(分饼、分粮)最容易理解
6. 比例和百分数: 配消毒液、配料、按人分配
7. 测量: 量长度、称重量、算面积和体积(见度量衡与科学方法)
8. 算盘: 熟练后计算很快,不需要电

✓ 每道题都和实际生活联系: 一块地种多少种子、一袋粮食够几个人吃几天
✓ 先估算,再精确计算,检查结果是否合理
```

数学内容见[数学](../08-基础科学知识/01-数学.md);算盘见[计算与信息-算盘](../09-进阶科学与工程/08-计算与信息.md#11-算盘)。

## 怎样教手艺

### 学徒制

手艺(打铁、木工、制陶、接生、种地)的很多诀窍只能在做的过程中学会,书本只能辅助。

```
学徒的几个阶段:
1. 看: 先帮忙、打下手,看师傅怎么做,问为什么
2. 在指导下做: 做简单的部分,师傅在旁边纠正
3. 独立做简单的活,师傅检查
4. 独立做完整的活
5. 能教下一个学徒 → 这时才算真正掌握

✓ 每位掌握关键技能的人,至少带两个徒弟
✓ 关键技能(接生、伤口处理、冶铁、净水)要有好几个人会,不能只靠一个人
```

### 一个通用的教学步骤

```
1. 讲: 说清楚要做什么,为什么这样做,危险在哪里
2. 示范: 慢慢地完整做一遍,边做边说
3. 让学生做: 在旁边看着,出错马上纠正(涉及安全的错误必须马上停下)
4. 让学生讲: 让他一边做一边说出每一步和原因 → 能讲清楚才是真的懂
5. 反复练习,逐渐减少指导
6. 隔一段时间再检查一次
```

### 安全

```
- 危险的工作(火、刀、高处、化学品、电)先学安全规则,考过再上手
- 孩子参加劳动要按年龄分配: 不让孩子单独操作刀具、机器、明火和化学品
- 记录事故和差点出事的情况,大家一起讨论怎样避免
```

儿童安全见[儿童安全](../01-日常疾病和伤害/14-儿童安全.md)。

## 组织一所小学校

```
人数少时: 一个房间、一位老师,不同年龄的孩子一起上课
- 按程度分成几个小组,老师轮流教,其他组做练习
- 让大孩子教小孩子(大孩子讲一遍,自己也学得更牢)

一天的安排(例):
- 上午: 识字、读书、算术(注意力最好的时候)
- 下午: 实践课——种菜、手工、卫生、急救、认识动植物、做实验
- 每节课不要太长,小孩子约20-30分钟,中间活动一下

教具:
- 黑板: 木板刷上烟灰和胶调成的黑色涂料,用石灰块、白色的石膏块当粉笔
- 沙盘: 浅木盘装细沙,用木棍写字,抹平再写,不用纸
- 石板、木板、旧纸背面

✓ 记录每个孩子学到了哪里
✓ 定期让孩子在大家面前展示(朗读、讲解、做实验),给予鼓励
✓ 成人可以在晚上或农闲时上课
```

## 自己编写教材和操作手册

很多知识只存在于某个人的经验里。把它写下来,就是给后人留下的最宝贵的东西。

```
写操作手册(某件事怎么做):
1. 开头写清楚: 这是做什么的、需要什么材料和工具、有什么危险
2. 步骤编号,每一步只写一个动作
3. 写出数量和判断标准: 不写"加适量的碱",写"每升水加多少""煮到什么样子"
4. 写为什么: 知道原理,遇到情况变化时才能调整
5. 写常见的失败和原因
6. 画图: 工具的形状、操作的姿势,一张图胜过很多字
7. 找一个没做过的人照着做一遍,看哪里写得不清楚,再修改
8. 写上日期和作者;以后发现错误,修改时注明

记录经验:
- 每次试验、每次生产都记下来: 用了什么、怎么做的、结果怎样
- 失败的记录同样重要
```

记录方法见[度量衡与科学方法-记录](../08-基础科学知识/00-度量衡与科学方法.md#13-记录)。

## 抄写和保存资料

```
优先保存什么:
✓ 医学(急救、常见病、接生、药物用量)
✓ 农业(种植、养殖、种子保存)
✓ 净水、卫生
✓ 工程和手艺
✓ 数学和科学的基础
✓ 本社区的记录: 人口、出生和死亡、天气、收成、土地边界

保存:
✓ 多份抄本,放在不同的地点(一处失火或被淹,还有别处)
✓ 防潮: 用油纸、蜡封、密封的陶罐或金属盒;放在高处,远离地面
✓ 防虫: 樟木箱、花椒、艾草,定期晾晒
✓ 防火、防鼠
✓ 用碳黑墨书写,不用容易褪色的墨水
✓ 定期检查,发现损坏及时重抄

抄写:
✓ 字迹工整,数字尤其要清楚(药物剂量抄错一位就是十倍的差别)
✓ 抄完由另一个人对照原文校对一遍,特别是数字、单位、剂量
✓ 抄本上注明: 从哪里抄的、谁抄的、谁校对的、日期
```

纸和墨的制作见[陶瓷、玻璃与造纸-造纸](11-陶瓷玻璃与造纸.md#造纸);数字资料的寿命见[计算与信息-保存知识](../09-进阶科学与工程/08-计算与信息.md#八保存知识-数字资料不可靠)。

## 没有纸的时候

```
- 口诀和歌谣: 押韵、有节奏的内容最容易记住,也最容易口口相传
  例: 九九乘法表、二十四节气歌、急救口诀
- 讲故事: 把重要的教训编进故事里
- 刻写: 竹片、木片、陶片、石头上刻字(陶器和石头可以保存几千年)
- 沙盘、石板: 用来练习,反复擦写
- 定期复述: 让年轻人把学到的东西讲给大家听,发现记错的地方及时纠正
```

## 📝 教育与知识传承要点

```
1. 先教卫生、急救、安全,再教读写算,再按需要学手艺
2. 识字: 先认后写、在句子里学、天天复习;常用约2500字能读懂大部分文字
3. 算术从实物开始,每道题联系实际
4. 教手艺: 讲 → 示范 → 学生做 → 学生讲 → 反复练习
5. 关键技能至少要有好几个人会,每位师傅至少带两个徒弟
6. 写手册: 编号步骤、写清数量和判断标准、写为什么、画图、找新手试做
7. 资料多份抄写,分开保存;数字和剂量必须有人校对
```
