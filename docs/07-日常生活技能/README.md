# 日常生活技能

## 📋 目录概览

本部分涵盖长期生活中最基础、却最容易被忽视的技能: 怎么把食物存下来、怎么吃才不生病、怎么处理粪便和垃圾、怎么做肥皂、怎么盖一间安全过冬的房子、停电断供时怎么照明和取用能源、衣物破了怎么补、皮毛怎么鞣、怎样安全用电、桌椅农具坏了怎么修。

这些技能平时就用得上,在停水停电、物资短缺或长期自给自足的情况下更是关键——历史上灾后和饥荒中,大量死亡来自营养缺乏病和粪口传播的传染病,而不是灾害本身。

## ⚠️ 最重要的几条

### 食物安全

- ❌ **不要自制酵米面类食品**(酸汤子、臭碴子、吊浆粑等): 米酵菌酸中毒没有特效药,病死率很高,煮沸也破坏不了
- ❌ **没有压力锅时不要自制蔬菜、肉类罐头**: 沸水杀不死肉毒杆菌芽孢
- ❌ **霉变、发苦的粮食和坚果整批丢弃**: 黄曲霉毒素加热不能破坏
- ✓ 腌菜至少腌20天再吃

### 营养

- 储备粮只解决"饿",还需要豆类、蔬菜(包括豆芽、野菜)
- 冬季缺菜时发豆芽补维生素C
- 坚持吃碘盐

### 卫生

- 厕所距离水源至少30 m,在下坡方向
- 厕所旁必须能洗手
- 新鲜粪便绝不浇菜

### 住所

- 地震多发区的土坯房、夯土房必须做抗震措施(单层、轻屋顶、墙顶圈梁、墙角拉结),否则极易整体倒塌
- 火炕、炉灶、烟囱每年入冬前检查裂缝、清灰;烟囱闸板睡前不要关死;装一氧化碳报警器

### 能源

- 油灯绝不用汽油、酒精;停电照明优先用电池灯
- 木炭、发电机绝不在室内使用;发电机不能反送电接入家庭线路
- **沼气池绝不下池**;有人在池内昏倒,不要直接下去救

### 皮毛

- 剥皮鞣皮戴手套;**绝不处理病死、死因不明的动物的皮**(炭疽、布鲁氏菌病、兔热病)

### 用电

- 漏电保护器每月按一次试验按钮,不能拆除或短接
- 插线板不串插、不接大功率电器;电动自行车不进楼道、不进家充电
- 泡过水的电器和线路,电工检查前不通电

### 工具

- 斧头、锤头松动立即停用修理;刀具向外推,工件夹牢
