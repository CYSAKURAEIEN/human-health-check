## 为什么供水是第一位的

历史上和今天的灾后,霍乱、痢疾、伤寒、甲肝等通过脏水传播的疾病,夺走的生命往往比灾害本身还多。**一个社区有了干净、充足的水,大部分肠道传染病就能被挡在门外。**

```
供水的三个目标:
1. 够用: 不只是喝,还要能洗手、做饭、洗澡、洗衣
2. 干净: 不被粪便污染
3. 方便: 取水的路越远,人们用的水就越少,卫生就越差
```

病菌学说和肠道传染病见[生物与医学基础-病菌学说](../08-基础科学知识/04-生物与医学基础.md#二病菌学说-改变人类命运的认识)、[传染病家庭防控-腹泻类传染病](../01-日常疾病和伤害/15-传染病家庭防控.md#腹泻类传染病)。

## 需要多少水

```
每人每天:
- 饮用: 约2-3 L(炎热、劳动时更多)
- 做饭、洗手、个人卫生: 灾后应急时最少约15 L
- 正常生活(洗澡、洗衣、清洁): 几十升以上
另外: 牲畜和菜地需要更多

例: 一个50人的社区,按每人每天20 L计算,每天至少需要1000 L(1 m³)
```

## 保护水源

```
✓ 厕所、粪坑、畜圈、垃圾坑离水井、泉水、溪流至少30 m,并且在水源的下坡方向
✓ 井口高出地面,周围做一圈不渗水的井台(水泥、石板、夯实的黏土),
  向外倾斜,让洒出的水和雨水流走,不倒流回井里
✓ 井口加盖,不让人、牲畜、垃圾、雨水直接进入
✓ 用专用的桶和绳子取水,桶不放在地上
✓ 不在水源上游洗衣、洗澡、饮牲畜
✓ 泉水、溪流的取水点上游设围栏
```

厕所的选址见[卫生设施-旱厕](03-卫生设施.md#旱厕)。

## 泉水

泉水是从地下自然流出的地下水,通常比较干净,但出露的地方很容易被污染。

```
泉箱(保护泉眼):
1. 清理泉眼周围,挖到出水的地方
2. 用石块、砖或混凝土在泉眼周围砌一个有盖的小池(泉箱),
   泉水从池底或侧面流入
3. 池壁上方开一个出水管,接到取水点
4. 泉箱上方挖一条截水沟,把地面雨水引开
5. 上坡方向设围栏,防止人畜踩踏和粪便污染
```

找泉水和地下水见[地质、矿物与土壤-地下水](../08-基础科学知识/06-地质矿物与土壤.md#四地下水)。

## 挖井

### ⚠️ 挖井的危险

```
挖井每年都会造成伤亡,主要危险:
1. 塌方: 井壁倒塌把人埋在下面
2. 缺氧和有毒气体: 井底可能积聚二氧化碳(比空气重)、硫化氢,
   人下去几分钟就会昏迷死亡,下去救人的人也常常接连遇难
3. 落物: 上面掉下的石块、工具
4. 坠落

安全规则:
✓ 每次下井前,先用绳子吊一盏点燃的油灯或蜡烛放到井底:
  火焰变弱或熄灭 → 缺氧,绝不能下去
  (注意: 火焰正常也不能完全保证安全,有条件时用气体检测仪)
✓ 下井前用风扇、风箱或来回提放大块布料,向井里鼓风换气
✓ 下井的人系安全绳,井上至少两人看守,随时能拉上来
✓ 井下的人戴头盔;井口周围不放工具和松动的石块
✓ 绝不在井里或井边使用汽油机、发电机(一氧化碳)
✓ 有人在井下昏倒,不要直接下去救,先鼓风,系好安全绳再下,或用绳钩拉上来
```

有毒气体见[化学-化学安全](../08-基础科学知识/03-化学.md#九化学安全)。

### 手挖井

```
1. 选址: 地下水可能较浅的地方(见地质章),离污染源至少30 m,在其上坡方向
2. 直径约1-1.5 m(能容一人在下面操作)
3. 边挖边做井壁支护:
   - 每挖约1 m就砌一段井圈(砖、石块、预制的混凝土井圈)
   - 土质松软的地方,支护更要及时
4. 挖到地下水面以下:
   - 最好在旱季地下水位最低时挖,并再往下挖1-2 m,保证全年有水
   - 进入含水层后,井壁下部用不加砂浆的砖石或带孔的井圈,让水渗进来
5. 井底铺一层粗砂和砾石,减少取水时搅起泥沙
6. 井口上部1-2 m的井壁必须封严(用砂浆或黏土),防止地表脏水沿井壁渗入
7. 做井台、井盖,安装辘轳或手压泵
8. 新井投入使用前清洗并消毒(见下方"井水消毒")
```

### 井水消毒

```
新井、被洪水淹过的井、怀疑被污染的井:
1. 估算井中的水量: 圆井水量(L)≈ 3.14 × 半径²(m²)× 水深(m)× 1000
   例: 半径0.6 m、水深2 m → 约 3.14 × 0.36 × 2 × 1000 ≈ 2260 L
2. 按约每1000 L水加有效氯约50-100 g的量投加含氯消毒剂
   (如84消毒液有效氯约5%: 约1-2 L)
   先在桶里用水稀释,再倒入井中,搅动井水
3. 浸泡至少12小时,期间不要取水
4. 之后抽水或提水,直到闻不到明显的氯味,再使用
5. 之后的饮用水仍建议煮沸或按常规量消毒
```

84消毒液的浓度见[传染病家庭防控-家用消毒液的配制](../01-日常疾病和伤害/15-传染病家庭防控.md#家用消毒液的配制)。

## 收集雨水

```
雨水本身比较干净,收集和储存时要防止污染

收集量的估算:
  1 mm降水落在1 m²的屋顶上 = 1 L水
  可收集水量(L)≈ 屋顶面积(m²)× 降水量(mm)× 约0.8(损失)
例: 50 m²的屋顶,一场20 mm的雨 → 约 50 × 20 × 0.8 = 800 L

要点:
✓ 屋顶用瓦、铁皮等干净材料;茅草、沥青屋顶的水只用于浇灌和清洁
  (⚠️ 铅皮屋顶、含铅涂料的屋顶,雨水不能饮用)
✓ 屋檐装檐沟,引到水缸、水窖
✓ 弃流: 每场雨开始的前几分钟水最脏(冲刷屋顶的灰尘、鸟粪),
  在进水管上装一个能先装满再溢流的小桶,前面的脏水先流进去,满了以后干净的水才进入储水池
✓ 进水口装滤网,储水池加盖,防止蚊子产卵、树叶和小动物掉进去
✓ 雨水饮用前仍要煮沸或消毒
```

降水量的测量见[天气观测与预报-自己做观测](../08-基础科学知识/07-天气观测与预报.md#六自己做观测)。

## 净化: 从浑水到可以喝的水

### 多级处理

```
1. 沉淀: 浑水在桶、缸里静置几小时到一天,取上面较清的水
   → 加少量明矾可以加快沉淀(见化学-分离与提纯)
2. 过滤: 去掉剩下的悬浮物和一部分病菌(见下方慢砂过滤池)
3. 消毒: 煮沸或加氯,杀死病菌和病毒
→ 浑水直接消毒效果差,先沉淀、过滤再消毒
```

### 慢砂过滤池

慢砂过滤是最古老也最可靠的集中净水方法之一: 水缓慢通过细砂层,砂层表面会自然形成一层生物膜,能截留和分解大部分病菌。

```
构造(从上到下):
- 上部: 保持约5-10 cm深的水层(不能让砂层干掉)
- 细砂层: 厚约40-60 cm(洗净的细河沙)
- 粗砂层: 约5-10 cm
- 砾石层: 约5-10 cm,底部是出水管
容器: 大水缸、大桶、砖砌或混凝土池

使用:
1. 新的过滤池要连续使用约2-3周,表面的生物膜才会长好,
   这段时间出水必须消毒后才能喝
2. 进水要慢而持续,不要冲坏砂层表面
3. 砂层始终要被水淹着
4. 出水越来越慢时,刮掉表面1-2 cm的砂(生物膜和淤泥),洗净后可再用
   (刮过之后又要等一段时间才能恢复效果)

效果: 能去除大部分细菌和寄生虫卵,但不能保证完全去除病毒
→ 出水仍要煮沸或加氯消毒后再饮用
```

野外的简易过滤见[基础生存技能-水源获取与净化](../03-野外生存/00-基础生存技能.md#水源获取与净化)。

### 消毒

```
煮沸(最可靠): 沸腾至少1分钟,海拔2000 m以上至少3分钟

加氯(用84消毒液、漂白水等含氯消毒剂):
- 清水每升加2滴,浑水每升加4滴(按有效氯约5%的漂白水计算)
- 摇匀,静置30分钟
- 消毒后的水应该有一点淡淡的氯味;完全没有氯味,可以再加一次
- 大量储水: 每1000 L清水约加5% 漂白水40-50 mL,静置30分钟以上

阳光消毒: 清水装在透明塑料瓶里,在强烈阳光下晒6小时以上(多云天连续晒2天;一直下雨不能用)
```

### 不能用一般方法处理的水

```
❌ 被农药、化学品、工业废水、燃油污染的水: 煮沸和过滤都不能去除化学毒物
❌ 海水、苦咸水: 要蒸馏才能喝
❌ 含砷、氟过高的地下水: 普通方法去不掉
→ 这类水不要饮用,换水源
```

## 储存

```
✓ 用有盖、干净、专用的容器;容器口小一些更不容易被污染
✓ 用专用的长柄勺或水龙头取水,不要把手和碗伸进去舀
✓ 放在阴凉、避光处(光照会让藻类生长)
✓ 定期清洗容器,用稀释的含氯消毒液擦洗后冲净
✓ 存放较久的水,饮用前再消毒
✓ 储存饮用水的容器不装过农药、燃油、化学品
```

## 输水和提水

### 引水

```
- 利用自然落差: 水从高处的泉水、溪流沿水渠或管道流到低处的村子
- 水渠坡度: 不需要很大,千分之一左右的坡度水就能流动
  (需要水平测量来放线,见度量衡与科学方法-找水平)
- 管道: 竹管、陶管、回收的塑料管和金属管
- 虹吸: 越过小的高地(最高点不超过约10 m,见物理-大气压)
- 暗渠和有盖的管道比明渠干净
```

找水平的方法见[度量衡与科学方法-找水平](../08-基础科学知识/00-度量衡与科学方法.md#42-找水平)。

### 提水

```
- 辘轳、滑轮、杠杆(桔槔): 从井里提水(见物理-简单机械)
- 手压泵(吸水泵): 水面距泵不超过约7-8 m
- 更深的井: 用提桶,或把泵放到井下面
- 水车: 用流水的力量把水提到高处浇地
```

### 水锤泵: 不用燃料把水送上山

```
利用流水突然被截断时产生的压力(水锤),把一部分水推到比水源高得多的地方
- 需要: 有一定落差和稳定流量的溪流
- 不用电、不用燃料,昼夜工作
- 只能送上去一小部分水,其余的水流走
  送水量 ≈ 进水流量 × 落差 ÷ 送水高度 × 约0.6(效率)
例: 每分钟进水100 L,落差2 m,要送到20 m高处
  → 约 100 × 2 ÷ 20 × 0.6 = 6 L/min,一天约8600 L
```

水力和大气压的原理见[物理-压强与流体](../08-基础科学知识/02-物理.md#四压强与流体)。

## 废水

```
✓ 洗衣、洗澡、洗菜的灰水: 引到离水井至少30 m的渗水坑或菜地(不浇直接生吃的菜),
  不要随地泼在井边、房边
✓ 渗水坑: 挖坑填满碎石、砖块,上面盖土,让灰水慢慢渗入地下
✓ 粪便和尿液不进入灰水系统,按卫生设施的方法处理
✓ 积水坑及时填平(防蚊)
```

粪便处理见[卫生设施](03-卫生设施.md)。

## 📝 水源工程要点

```
1. 厕所、畜圈离水源至少30 m,在下坡方向
2. 井口高出地面、有井台和井盖,上部井壁封严
3. 下井前先放灯试火、鼓风换气;有人昏倒不要直接下去救
4. 1 mm雨 × 1 m²屋顶 = 1 L水;弃流先脏的雨水
5. 浑水先沉淀、过滤,再消毒
6. 慢砂过滤池要保持水层,出水仍要消毒
7. 煮沸最可靠;漂白水清水每升2滴、浑水4滴,等30分钟
8. 化学污染的水不能靠煮沸和过滤处理
```
