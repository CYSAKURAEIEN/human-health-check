## 先说清楚: 本章的定位

捆柴、拴牲口、搭棚子、吊井水、固定货物、拉木头,几乎每天都要用绳子。[基础生存技能](../03-野外生存/00-基础生存技能.md#绳结技能)里列了野外最常用的几个结,本章讲得更系统: 绳子从哪里来、能承受多大的力、十几个常用结怎么打、什么时候不能用。

```
⚠️ 安全:
- 绳子断裂时会猛烈回弹,能打伤眼睛和脸;不站在受力绳的延长线上,不站进绳圈里
- 自制的植物纤维绳强度差别极大,只用于捆扎、拖拉、晾晒等"断了也不伤人"的场合
- ☠️ 不用自制绳索攀爬、下降或做高处救援;没有合格的动力绳、安全带和训练,不做绳索救援
- 拉绳、放绳戴手套: 绳子在手里快速滑动会把手掌磨掉一层皮
- 儿童、牲畜周围的绳圈、活套有勒颈危险
```

野外救援和攀爬的原则见[山地求生-坠落](../03-野外生存/05-山地求生.md#坠落)和[涉水过河](../03-野外生存/08-涉水山洪与野外失温.md#涉水过河)(不要把绳子系在过河人身上)。

最现实的路线: **先回收**。废墟里的尼龙绳、涤纶绳、钢丝绳、电线、自行车内胎都比自己搓的绳子强得多。自制绳子用来补充日常消耗。

## 纤维从哪里来

| 材料 | 怎么取 | 强度 | 耐久 | 适合做什么 |
|------|--------|------|------|------------|
| 苎麻 | 剥茎皮,刮去外皮,晒干 | 很高 | 耐水,较耐腐 | 各种承力绳、渔网、缝线 |
| 大麻 | 沤麻后剥皮 | 很高 | 较耐腐 | 粗绳、缆绳(⚠️ 种植受管制) |
| 黄麻、剑麻 | 沤麻 / 刮叶肉取纤维 | 中等(剑麻较高) | 黄麻怕潮易烂;剑麻较耐 | 麻袋、捆扎绳 |
| 椴树、构树、榆树内皮 | 春夏剥树皮,取内层韧皮,浸泡沤软 | 中等 | 椴皮较耐水 | 捆扎绳、草鞋、编织 |
| 棕榈纤维(棕丝) | 剥下树干上的棕片,撕成丝 | 中等 | 很耐水、耐腐 | 井绳、船缆、扫帚、蓑衣 |
| 稻草、麦秸 | 选长而完整的秆,捶软 | 低 | 一季左右就烂 | 临时捆柴、捆稻、草绳护树 |
| 竹篾 | 劈成薄条 | 高(拉力) | 较耐水,但怕折 | 竹缆、编筐、绑扎 |
| 藤(白藤、葛藤等) | 直接用或劈开 | 中高 | 干后变脆 | 绑扎家具、篱笆、筐 |
| 生皮条 | 生皮切成螺旋长条 | 高 | 怕水泡软、易被鼠咬 | 湿绑后晾干收紧(绑工具柄) |
| 动物筋 | 牛、鹿背筋晒干后撕成丝 | 很高 | 怕潮 | 弓弦、缝线、细绑扎 |
| 回收尼龙、涤纶、丙纶绳 | 拆旧绳、旧网、编织袋 | 很高 | 不怕水不发霉,怕晒 | 一切重要用途 |
| 电线、网线、内胎 | 剥出导线 / 剪成橡胶条 | 中等 | 塑料外皮晒久变脆 | 绑扎、捆扎、临时固定 |

```
选料原则:
✓ 纤维越长越好: 长纤维接头少,绳子强度高
✓ 泡在水里的(井绳、船缆、渔网): 首选棕、苎麻、尼龙;不用稻草、黄麻
✓ 风吹日晒的: 天然纤维会霉烂,合成纤维会被晒脆,都要定期检查
✓ 竹篾、藤只能顺着拉,不能打紧结、不能急弯
✓ 生皮条湿着绑、晾干后收缩变紧,适合绑斧头柄、矛头;受潮会松
✗ 腐烂发黑、一扯就断的树皮,不要
```

麻和树皮的沤制、梳理见[纺织缝补与鞣皮-准备纤维](07-纺织缝补与鞣皮.md#准备纤维),皮条的处理见[鞣皮](07-纺织缝补与鞣皮.md#鞣皮),构树皮也是造纸原料,见[陶瓷玻璃与造纸-造纸](11-陶瓷玻璃与造纸.md#造纸)。⚠️ 大麻在我国种植受管制,可用苎麻、亚麻代替。

## 搓绳和制绳

### 原理: 反向捻,才不会散

```
一束纤维捻紧后,会想要"退捻"(松开)
把两股朝同一方向捻紧的纤维并在一起,再朝"相反"方向绞合:
  → 每一股想退捻的力,正好让两股互相咬紧
  → 绳子放开后不会散

规则: 股的捻向 与 绳的捻向 相反
  (纱线的捻向 与 股的捻向 也相反,一层一层交替)
```

纺锤纺线、合股的原理相同,见[纺织缝补与鞣皮-纺线](07-纺织缝补与鞣皮.md#纺线)。

### 手搓两股绳(不用任何工具)

```
1. 取一束纤维(或树皮条),在长度约1/3处(不要正好在中间)对折
   → 两股一长一短,以后的接头就会错开,不会在同一处
2. 左手捏住对折的弯头
3. 右手把离自己较远的那一股,朝离开自己的方向拧紧(拧到它想打卷)
4. 把拧紧的这一股朝自己的方向压过另一股,换到近的一侧
5. 现在另一股变成了远的一股: 再把它朝离开自己的方向拧紧,再压过来
6. 重复: 每一股都"向外拧,向内压",左手不断向前移,捏住刚搓好的部分
7. 搓好的绳子应该紧实均匀,没有松垮的地方

在大腿上搓(更快):
  两股平放在大腿上,手掌向前推,两股各自捻紧;
  然后手掌往回拉,让两股绞在一起;反复进行
```

### 接续纤维

```
1. 某一股只剩约5 cm长时,取一小束新纤维
2. 把新纤维的一端削薄(散开成锥形),和旧的一股重叠5-10 cm
3. 一起拧紧,继续搓,重叠部分会被捻在一起
4. 两股的接头至少错开几厘米,不要在同一位置接
5. 搓完后剪掉外面露出的毛头(不要剪到绳身)
✓ 新加的纤维量和原来的一样多,保持粗细均匀
```

### 三股绳和简易制绳器

三股绳比两股绳更圆、更结实、更耐磨,是井绳、缆绳的标准做法。

```
制绳器(一人摇,一人看):
- 摇柄端: 一块木板钻3个孔,每孔装一根带弯钩的曲柄
  (或用一根摇把同时带动3个钩子,也可以用3个手摇钻代替)
- 尾端: 一个能自由转动的单钩,装在一个可以移动的木桩或重物上
- 分股器: 一个木锥,侧面刻3道槽

步骤:
1. 把纱线在摇柄的3个钩子和尾端的单钩之间来回牵,分成3股,长度一样
2. 摇动摇柄,3股朝同一方向捻,直到松一下就会自己打卷
3. 把分股器塞在3股之间、靠近尾端,槽里各卡一股
4. 放开尾端的单钩,它会朝相反方向转,3股在分股器后面自动绞合成绳
5. 继续摇,同时慢慢把分股器向摇柄端推,尾端会被拉近
   → 绳子比原来的股缩短约1/4-1/3,备料时要留够长度
6. 绞到头后两端扎紧,挂起来拉直、晾几天定型
```

### 编辫

```
三股辫: 左股压到中间,右股压到中间,反复;适合草、竹叶、皮条、旧布条
四股圆编: 更圆、更结实,适合做鞭子、牲口缰绳
✓ 编辫不需要纤维有捻,短纤维、扁平材料也能用
✓ 回收的塑料袋、编织袋剪成条,编辫后是不错的捆扎绳
```

## 绳子能吊多重

### 粗细和强度

```
强度大致和截面积成正比,也就是和直径的平方成正比:
  直径加倍 → 强度约为4倍
  直径减半 → 强度只剩约1/4

1 kN 大约相当于静止吊起100 kg 重物的力
```

### 常见绳子的断裂强度(粗略量级)

以下是直径约10 mm的新绳的估计值,同类产品差别可达一倍以上,**以实际产品标注为准**,自制绳子必须自己试验。

| 绳子 | 断裂强度(约) | 特点 |
|------|---------------|------|
| 自制草绳、树皮绳 | 0.5-2 kN | 差别极大,只做捆扎 |
| 棉绳 | 3-5 kN | 柔软,易霉 |
| 麻绳(马尼拉麻、剑麻) | 6-9 kN | 伸长小,怕霉烂 |
| 丙纶绳(常见的彩色塑料绳) | 12-15 kN | 能浮在水上,最怕晒 |
| 涤纶绳 | 15-20 kN | 伸长小,耐晒较好 |
| 尼龙绳 | 18-25 kN | 弹性大,湿时强度降低约一成 |
| 钢丝绳 | 50-60 kN | 断丝、扭结、锈蚀就要报废 |
| 伞绳(直径约4 mm) | 约2 kN | 内芯可拆出做细线 |

### 安全系数: 只用断裂强度的一小部分

```
保守原则(宁可绳子用得粗):
- 载人、人在下方、断了会伤人的: 只按断裂强度的约1/10使用
- 吊装货物: 不超过约1/5
- 捆扎、晾晒、断了无所谓的: 可以用到1/3左右

再按下面的情况打折:
- 打结: 打结处强度大约只剩一半到七成,按一半估算
- 受潮: 天然纤维发霉后强度大降;尼龙湿时降约一成
- 日晒: 合成纤维晒几个月到一两年会变硬、发脆,丙纶最快
- 磨损: 外层起毛、有断股的,按新绳的一半以下估算
- 冲击: 东西掉落后猛然拉紧,力量可以是重量的好几倍

例: 一根新尼龙绳断裂强度约20 kN,打结后按10 kN,
    吊货按1/5 → 约2 kN,也就是最多吊约200 kg
```

安全系数的一般原则见[工程力学与材料-安全系数](../09-进阶科学与工程/01-工程力学与材料.md#34-安全系数)。

### 检查一根绳子能不能用

```
✓ 顺着整根绳子摸一遍: 有没有变细、变硬、变软、鼓包的地方
✓ 拧开几处看内部: 天然纤维里面发黑、有粉末、有霉味 → 报废
✓ 合成纤维表面发白、发粉、一刮就掉渣 → 被晒坏了
✓ 有熔化、烧焦、被化学品(酸、碱、汽油)泡过的地方 → 截掉或报废
✗ 来历不明、存放多年的旧绳,不用于任何承重
```

## 常用绳结

好的绳结: **打得快、受力时不松、用完好解**。每个结都要在家里反复练,直到闭着眼也能打出来。下面的"绳头"指活动的那一端,"主绳"指受力的那一段。

```
通用注意:
✓ 打完后整理平整、慢慢拉紧,检查形状对不对
✓ 绳头至少留出绳子直径的10倍长
✓ 滑的尼龙绳、新绳更容易松脱,重要的结在绳头再加一个半结或单结
✓ 不认得的结、打得不像的结,不要用于承重
```

### 平结: 只用来捆扎

```
用途: 包扎绷带、扎口袋、捆柴捆、系鞋带(加活扣)
打法:
1. 左绳头压在右绳头上,绕一圈(像系鞋带的第一步)
2. 右绳头压在左绳头上,再绕一圈
3. 拉紧: 两个绳头应该和各自的主绳并排,从同一侧出来
✗ 两次都是"左压右",打出来是歪的"祖母结",一拉就滑
⚠️ 不要用平结连接两根承重的绳子: 粗细不同、绳子很滑或抖动时会翻转松脱
```

[基础生存技能](../03-野外生存/00-基础生存技能.md#绳结技能)里说平结可连接同粗细的绳子,只限于不受力的场合;受力连接用下面的接绳结或渔人结。

### 接绳结: 连接粗细不同的两根绳

```
用途: 连接两根绳子(尤其是一粗一细)、把绳子系到布角上
打法:
1. 粗绳的一端折成U形
2. 细绳从下往上穿过U形
3. 细绳绕到U形的背后,把U形的两股一起绕住
4. 细绳从自己下面压过去(压在细绳和U形之间),不要穿进U形里
5. 拉紧: 两根绳头应该在同一侧
✓ 粗细差别很大或很滑时,第3步绕两圈(双接绳结)
⚠️ 不受力时容易松,抖动的地方要加固
```

### 单套结(称人结): 打一个不会收紧的绳圈

```
用途: 绳头固定圈,套在桩子、树上;拴牲口(圈不会勒紧);吊桶
打法(口诀: 兔子出洞,绕树一圈,回到洞里):
1. 在主绳上拧一个小圈,绳头一侧的绳子压在上面("洞")
2. 绳头从下往上穿出小圈("兔子出洞")
3. 绳头绕到主绳后面("绕树一圈")
4. 绳头从上往下穿回小圈("回到洞里")
5. 一手握主绳,一手握绳头和绳圈的一边,拉紧
✓ 受力后也容易解开
⚠️ 不受力、反复抖动时会慢慢松开: 绳头上加一个单结
⚠️ 套在人身上作救援只限于专业训练过的人,见本章开头的安全提示
```

### 八字结: 止索结和八字绳圈

```
止索结(防止绳头从孔、滑轮里滑出):
1. 绳头在主绳上绕出一个圈
2. 绳头绕到主绳后面
3. 绳头从前面穿进第一个圈,拉紧 → 形成一个"8"字

八字绳圈(比单套结更不容易松,但受力后难解):
1. 绳头一段对折成双股
2. 用双股打一个八字结,留出的弯头就是绳圈

穿绕八字(绳圈要套住树、环等封闭物体时):
1. 在离绳头一段距离处,用单股打一个松的八字结
2. 绳头绕过物体
3. 绳头顺着原来的八字结,沿原路反穿一遍,两股平行不交叉
```

### 双套结: 系在柱子上

```
用途: 绳子系在柱子、树、横杆上;绑扎的起头和收尾
打法:
1. 绳子绕柱子一圈
2. 交叉压过自己(主绳)
3. 再绕柱子一圈
4. 绳头从第二圈下面穿出,和主绳从中间相反方向出来
5. 拉紧
✓ 套在杆子顶端时: 做两个同方向的圈,后一个叠在前一个后面,套进去就成
⚠️ 柱子会转动、受力方向反复变化时会滑脱: 绳头再加两个半结
```

### 卷结: 顺着杆子方向拉也不滑

叫法各地不一,有的书把双套结也叫卷结。本章的卷结指在双套结基础上多绕一圈、能承受沿杆子方向拉力的结(也叫滚结)。

```
用途: 绳子沿着杆子、粗绳的方向拉(拉倒一根立柱、给一根受力的绳子"打个抓手")
打法:
1. 绳头绕杆子一圈,压过主绳
2. 再绕第二圈,压住第一圈,两圈都在主绳靠受力的那一侧
3. 绳头越过主绳到另一侧,绕第三圈
4. 绳头从第三圈下面穿出,拉紧
✓ 只朝"两圈"那一侧拉才不滑,打之前先想好拉力方向
```

### 拖木结: 拖拉、吊运木头

```
用途: 拖原木、吊一捆竹竿或柴、吊长条物体
打法:
1. 绳子绕木头一圈
2. 绳头绕主绳一下,然后顺着绳圈在自己身上缠3-5圈
3. 拉主绳,绳圈收紧咬住木头
4. 拖长木头时,在木头前端再加一个半结(绳子绕一圈压住),木头才不会横着走
✓ 不受力时一松就开,很好解
```

### 渔人结: 连接两根绳子

```
用途: 连接两根粗细相近的绳子,尤其是又细又滑的尼龙绳、钓线
打法:
1. 两根绳头相对重叠一段
2. 第一根绳头绕第二根绳打一个单结
3. 第二根绳头绕第一根绳打一个单结,方向相反
4. 两边拉主绳,两个单结滑到一起靠紧
✓ 每个单结多绕一圈(双渔人结)更牢,重要场合用双渔人结
⚠️ 受力后很难解开,做永久连接或绳圈用
```

### 营钉结: 可以调节松紧

```
用途: 帐篷、遮雨布的拉绳,晾衣绳,随时调松紧
打法:
1. 绳子绕过地钉(或树),绳头拉回来
2. 绳头在绳圈里面,绕主绳两圈,朝地钉的方向绕
3. 绳头越过刚才的两圈,在外侧再绕主绳一圈
4. 绳头从这一圈下面穿出,拉紧
5. 推动绳结即可调节松紧,受力时卡住不动
✓ 很滑的绳子,第2步多绕一圈
```

### 普鲁士结: 抓住另一根绳子

```
用途: 在一根绳子上做一个可以移动的抓手;拉紧绳子时防止倒退
需要: 一个细绳圈,直径约为主绳的一半到2/3
打法:
1. 细绳圈搭在主绳上
2. 把绳圈的一端从另一端中间穿过,绕主绳一圈
3. 重复,共绕3圈,圈与圈平整并排
4. 受力时咬紧不动,不受力时可以推着滑动
✓ 越滑的主绳绕越多圈
⚠️ 只用于拉货、收紧绳子;用于上升、下降、保护属于攀登技术,没有训练不要做
```

### 卡车司机结(货运结): 把绳子勒紧

```
用途: 捆车上、船上、背架上的货;拉紧晾衣绳、篱笆线、帐篷大梁绳
打法:
1. 绳子一端固定在一侧(双套结、单套结)
2. 在绳子中段做一个固定的小圈(八字绳圈最简单)
3. 绳头绕过另一侧的固定点(钩子、车帮、木桩),拉回来
4. 绳头穿过小圈,往回拉: 这里相当于一个滑轮,拉力约翻倍
5. 拉紧后,捏住交叉处,绳头在下方打两个半结固定
✓ 小圈处摩擦大,经常这样用的绳子要检查磨损
⚠️ 拉得过紧会勒坏货物或拉断老化的绳子
```

### 缩绳结: 临时缩短或绕过一段坏绳

```
用途: 绳子太长又不想剪;临时绕过中间磨损的一段
打法:
1. 把绳子折成"Z"形三股并排,磨损的部分放在中间那一股
2. 一端的弯头: 用旁边的主绳打一个半结(小圈)套住它
3. 另一端的弯头: 同样套住
4. 两端拉紧
⚠️ 只有一直受力时才稳,一松就散;只作临时应急,有条件就换绳
```

### 活结和活套

```
活结(滑结): 拉绳头就能一下解开
1. 打单结的最后一步,不把绳头整个拉出,而是对折成一个小弯拉出
2. 拉这个弯的绳头,结就散开
✓ 用于需要快速解开的地方: 拴船、拴牲口、扎口袋

活套(可收紧的绳圈,如套马的套索):
1. 在绳头打一个小的固定圈(单套结或八字绳圈)
2. 把主绳从小圈中穿过,形成一个大圈
3. 拉主绳,大圈就收紧
☠️ 绝不套在人或牲畜的脖子上;牵牲口用笼头或拴在角、腿上的固定圈
☠️ 活套、绳圈要远离儿童,不挂在孩子能够到的地方
```

## 绳头处理和插接

### 绳头防散

```
扎线(最通用):
1. 用细线在离绳头约1 cm处做一个"U"形,平放在绳上,弯头朝绳头
2. 从绳头一侧开始,用细线把绳子和U形一起紧紧缠住,缠的长度约为绳子直径的1-1.5倍
3. 细线末端穿进"U"形的弯头里
4. 拉U形的另一端,把末端拽进缠线下面,剪掉两头

烧熔(只限尼龙、涤纶、丙纶):
1. 用刀切断,在火上烤绳头,直到熔化
2. 趁软用湿布或沾湿的手指迅速捏圆
⚠️ 熔滴会粘在皮肤上造成烫伤,不要直接用手捏;在通风处做

应急: 绳头打一个八字结;或缠几圈胶布
```

### 插接: 比打结更结实

插接是把绳股拆开、再编回绳身里。三股绳插接后强度大约保留八到九成,比打结(约一半)强得多,适合永久用的绳圈、井绳、缆绳。

```
眼环插接(在绳头做一个永久绳圈):
1. 把绳头的3股拆开,长度约为绳子直径的15-20倍,每股用线扎住防散
2. 绳头弯回来,做出需要大小的绳圈
3. 中间一股: 塞进主绳的一股下面(逆着主绳的捻向穿)
4. 左边一股: 塞进上一步那股左边的一股下面
5. 翻过来,第三股: 塞进剩下的那一股下面
   → 此时3股从主绳的3个缝里各穿出一股,检查是否各占一个缝
6. 以后每股都"压一股、穿一股",轮流各穿一次为一轮
7. 天然纤维至少穿3轮,滑的合成纤维至少5轮
8. 在地上滚一滚、捶一捶让它平整,剪掉多余的毛头(留一点)

两根绳的插接(短插): 两根绳头都拆股,交叉对插,原理同上;
  插接处会变粗,穿不过滑轮;能过滑轮的"长插"更复杂,需要有人示范
```

## 绳子的用途: 捆扎、搭建、吊装、取水

### 捆扎货物

```
✓ 先把货物码稳、重的放下面,再上绳
✓ 绳子从固定点开始,用卡车司机结拉紧,收尾打两个半结
✓ 横向、纵向都要捆,长条货物至少两道
✓ 车辆、牲口驮运,走一段路后停下来复紧一次(货物会沉降,绳子会松)
✓ 绳子经过锐利的棱角处垫布、垫皮,否则会被割断
```

### 绑扎: 搭架子、搭棚子

**方回绑扎**(两根杆子十字交叉):

```
1. 在竖杆上、横杆的下方,打一个双套结起头
2. 绳子绕过横杆的前面,再绕到竖杆的后面,再绕过横杆前面……
   像"井"字一样绕3-4圈,每圈都拉紧,并排不交叉
3. 收紧圈: 在两根杆子之间,绕已经绑好的绳子缠2-3圈,用力拉紧
   → 这一步让绑扎变得非常紧
4. 在横杆上打一个双套结收尾
```

**三脚架绑扎**:

```
1. 三根杆子并排放在地上,一头对齐
2. 在外侧一根杆子上打双套结起头
3. 绳子在三根杆子之间以"8"字形穿绕(上、下交替)5-6圈,不要拉得太紧
4. 在杆子之间的缝隙里各缠2圈收紧圈
5. 打双套结收尾
6. 竖起来,把两侧的杆子交叉旋转、张开成三脚架
✓ 张开后用绳子把三条腿底部连起来,或把腿埋进土里,防止滑开
```

搭建的木料连接见[木工与工具维护](09-木工与工具维护.md#连接方法),住所的整体结构见[长期住所](05-长期住所.md)。

### 吊装

```
✓ 吊之前估算重量,对照前面的强度表,按安全系数选绳子
✓ 两根绳子吊一个重物时,两绳的夹角不要超过约90°;夹角越大,每根绳子受力越大
✓ 用滑轮组省力: 拉力约等于重量 ÷ 承重的绳段数
✓ 绳子绕过的东西(滑轮、横梁)越粗越好,急弯处绳子强度会下降
✓ 先吊离地面一点点,停住检查绳结、支点,再继续
✗ 吊起的东西下方不站人;不把手伸到绳子和滑轮之间
```

绳子夹角与拉力的计算见[工程力学与材料-绳子的夹角越大拉力越大](../09-进阶科学与工程/01-工程力学与材料.md#11-绳子的夹角越大拉力越大),悬索的拉力见[悬索和绳索](../09-进阶科学与工程/01-工程力学与材料.md#八悬索和绳索),滑轮原理见[物理-滑轮](../08-基础科学知识/02-物理.md#22-滑轮)。

### 井绳和取水

```
✓ 井绳首选: 棕绳、苎麻绳、尼龙绳;不用稻草绳、黄麻绳(泡水很快烂)
✓ 绳子和桶用单套结或插接的眼环连接,加一个金属钩或卸扣更耐用
✓ 井绳长期一干一湿,每月检查一次,发现发黑、变细就换
✓ 绳子绕在辘轳上要排整齐,不要乱缠压伤
✓ 取水用的绳和桶专用,不放在地上,以免把脏东西带进井里
```

井的修建和提水工具见[水源工程与供水-提水](10-水源工程与供水.md#提水)。

### 救援

```
☠️ 自制的绳子不用于攀爬、下降、悬挂人员和高处救援
✓ 落水救援: 把绳子扔过去让人抓住,救援者站稳、身体放低,不要被拖下水
✓ 不把绳子系在过河的人身上(人被冲倒时会被绳子按在水里)
✓ 有人掉进井里、坑里: 先求援,不要盲目下去;井下可能缺氧
```

落水救援见[救落水的同伴](../03-野外生存/08-涉水山洪与野外失温.md#救落水的同伴),井下作业的危险见[水源工程与供水-挖井](10-水源工程与供水.md#挖井),伤员搬运见[野外伤病处置与转运-搬运伤员](../03-野外生存/11-野外伤病处置与转运.md#搬运伤员)。

## 保养和储存

```
盘绳:
1. 短绳: 绕在手掌和肘之间盘成圈,最后用绳头在圈的一端缠几圈扎住
2. 长绳: 在地上盘成"8"字或顺着捻向一圈圈盘好,挂起来
✗ 不要乱塞成一团: 下次用时会打成死结、扭成麻花

晾干:
✓ 用过的湿绳展开挂在通风的阴凉处晾干,再收起来
✗ 湿绳子盘着收起来,几天就会发霉

避光:
✓ 合成纤维绳不用时放在室内或盖住,阳光(紫外线)会让它变脆
✓ 长期挂在室外的晾衣绳、帐篷绳,每年检查,发硬发脆就换

防鼠、防虫:
✓ 天然纤维绳和皮条挂在梁上,远离墙角和粮食
✓ 被老鼠啃过的地方剪掉,不要接着用

清洁:
✓ 沾了泥沙的绳子用清水冲洗(泥沙进入纤维会从里面磨损绳子)
✓ 沾了油、酸碱、汽油的绳子降级使用或报废

✓ 重要的绳子挂个标签: 什么材料、哪年开始用、用来干什么
```

## 安全

```
⚠️ 断绳回弹:
- 受力的绳子断开时会像鞭子一样抽回来,尼龙绳弹性大,回弹最猛
- 不站在受力绳的延长线上(两端和后方),不跨在绳子上
- 不站在绳圈里、不把脚放在盘着的绳子里: 绳子突然被拉走时会缠住脚
- 拉紧大力的绳子(拖树、拉车、绞盘)时,在绳子中间搭一件衣服或麻袋,
  断开时能减少回弹

⚠️ 手:
- 戴手套;放绳时不让绳子在手掌里快速滑过
- 不把绳子缠在手腕、手上用力拉: 被突然拉走时会勒伤、拖倒
- 手指不放在绳子和滑轮、木桩、绞盘之间

☠️ 勒颈:
- 窗帘绳、晾衣绳、活套离儿童远一些,不在婴儿床附近挂绳子
- 孩子玩绳子时有大人在旁边,不玩"套脖子"的游戏
- 拴牲口的绳子长度合适,周围没有能绕住的东西,防止牲口自己勒住
```

## 📝 绳索与结绳要点

```
1. 先回收合成纤维绳和钢丝绳;自制绳子只用于捆扎、拖拉等断了不伤人的场合
2. 搓绳的关键: 股的捻向与绳的捻向相反;接头错开
3. 绳子强度大致和直径的平方成正比;泡水用棕、苎麻、尼龙
4. 安全系数: 载人约1/10,吊货约1/5;打结后按强度减半算
5. 天然纤维怕霉,合成纤维怕晒;用后晾干、避光、防鼠
6. 平结只用于捆扎,连接绳子用接绳结或渔人结
7. 固定绳圈用单套结或八字绳圈,系柱子用双套结,收紧货物用卡车司机结
8. 永久绳圈用插接,强度远高于打结
9. ☠️ 不用自制绳索攀爬和高处救援
10. 不站在受力绳的延长线和绳圈里;绳圈、活套远离儿童
```
