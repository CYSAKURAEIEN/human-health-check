## 为什么要会做肥皂

手册里反复强调"勤洗手是预防感染最重要的措施"(见[卫生设施](03-卫生设施.md)、[抗生素制备-感染的预防](../06-制药技术/02-抗生素制备.md#五感染的预防))。储备的肥皂总会用完,而制皂的原料——草木灰和油脂——在农村和长期生存环境中都容易获得。

**原理**: 油脂 + 碱 → 肥皂 + 甘油(皂化反应)。肥皂一端亲水、一端亲油,能把油污和附着在皮肤上的细菌、病毒一起包裹起来冲走。

## 最简单: 天然皂荚和无患子

不需要碱,也没有烧伤风险,适合洗手、洗衣、洗碗。

### 皂荚(皂角)

```
来源: 皂荚树的果荚,秋季成熟变黑褐色时采收,晒干保存

用法:
1. 取2-3个皂荚掰碎(去掉种子)
2. 加水浸泡或煮10-15分钟
3. 用煮出的水搓洗,会起泡沫

⚠️ 皂荚和种子有一定毒性,只外用,不可食用;煮皂荚的锅不要再煮饭
⚠️ 泡沫入眼有刺激,用清水冲洗
```

### 无患子

```
来源: 无患子树的果实(南方常见),秋季采收,去核晒干
用法: 果皮加水揉搓或煮水,同皂荚
⚠️ 同样只外用,不可食用
```

**局限**: 去油污能力不如肥皂,但用于日常洗手已足够。

## 草木灰碱水制皂

传统制皂方法。原料易得,但**碱水是强腐蚀性液体**,必须做好防护。

### ⚠️ 安全须知(先读)

```
防护:
✓ 戴护目镜(碱水溅入眼睛可致失明)
✓ 戴手套、穿长袖
✓ 在室外或通风处操作
✓ 儿童、宠物远离操作区域
✓ 旁边准备一大桶清水

容器:
✓ 用不锈钢、搪瓷、陶瓷、木质或耐热塑料容器
❌ 不要用铝锅(会与碱反应产生氢气并腐蚀穿孔)

万一沾到:
- 皮肤: 立即用大量流水冲洗至少15分钟,不要用醋中和
- 眼睛: 立即翻开眼皮,用流水持续冲洗15-20分钟,然后就医
- 误饮: 不要催吐,立即拨打120
```

化学品入眼的完整处理见[异物处理-化学品入眼](../01-日常疾病和伤害/04-异物处理.md#化学品入眼紧急)。

### 第一步: 制碱水

```
原料: 硬木燃烧后的白色或浅灰色细灰
  ✓ 硬木(果木、橡木、槐木等)的灰效果好
  ❌ 不要用烧过油漆木料、塑料、垃圾、煤的灰(含有害物质)

做法:
1. 取一个底部有小孔的木桶或塑料桶,下面放接水的容器
2. 桶底铺一层碎石,再铺一层稻草(过滤用)
3. 装入草木灰,轻轻压实
4. 慢慢浇入雨水或煮沸后放凉的软水
5. 下方滴出的褐色液体就是碱水
6. 把滴出的碱水再浇回灰上反复几次,浓度会提高

浓度检验(传统方法):
- 放入一个新鲜鸡蛋或一块土豆
- 能浮起来、露出一小块(约硬币大小) → 浓度合适
- 沉底 → 太稀,小火熬浓一些
- 浮得太高 → 太浓,加一点水
```

### 第二步: 准备油脂

```
可用: 猪油、牛羊油、鸡油、菜籽油、花生油、用过的炸油
  - 动物油做出的皂更硬,植物油做出的皂更软
  - 用过的油要先过滤掉残渣

净化油脂:
1. 油脂加等量的水一起煮
2. 冷却后,干净的油脂浮在上层凝固,杂质沉入水中
3. 取出上层油脂备用
```

### 第三步: 熬制

```
1. 油脂在锅中小火化开
2. 慢慢加入碱水,边加边搅拌(先加约与油等量的碱水)
3. 小火保持微微冒泡,持续搅拌,需要几个小时
4. 混合物逐渐变稠,像稀粥或蜂蜜
5. 判断是否熬好:
   - 用勺子滴一滴在冷盘子上,能凝成软块
   - 取少许放入清水搅动,能溶开且水面没有浮油
   - 有浮油 → 碱不够,再加碱水继续熬
6. 得到的是棕色软膏状的"软皂"

草木灰碱水主要成分是碳酸钾和氢氧化钾,做出的是软皂(膏状),
不像商店里的肥皂那样硬,用法完全一样。
```

### 可选: 加盐变硬

```
1. 软皂熬好后,趁热加入一大把食盐,搅拌
2. 肥皂会凝成块浮到上面,下面是含杂质和甘油的盐水
3. 舀出上层皂块,倒入木盒或模具
4. 冷却后切块
```

### 第四步: 熟化与检验

```
熟化:
- 放在通风干燥处2-6周
- 这期间残余的碱会继续反应,肥皂变得更温和

检验(必须做):
- 有pH试纸时: 肥皂溶液pH在9-10之间为合适;高于11说明碱过量
- 皮肤测试: 用少量在手背洗一次,观察
  - 无刺痛、无发红 → 可以用于洗手
  - 刺痛、发红、发滑发涩 → 碱过量,只用于洗衣服、擦地,不要接触皮肤

❌ 不要用舌头去"尝"碱味(传统做法,有烧伤风险)
```

## 没有肥皂时

```
洗手:
✓ 草木灰搓洗20秒,再用流水冲净
✓ 只用流水认真搓洗20秒,也能去掉大部分病原体
❌ 不要用泥土(可能被粪便污染)

洗衣:
✓ 草木灰水: 草木灰加水浸泡,取上层澄清的水洗衣(传统做法)
✓ 皂荚水、无患子水

洗碗:
✓ 淘米水、面汤(去油)
✓ 热水 + 丝瓜络
✓ 洗后在阳光下晾干
```

---

## 📝 制皂要点

```
1. 最简单安全: 皂荚、无患子,直接煮水用
2. 草木灰碱水 + 油脂 → 软皂
3. 碱水是强腐蚀性的: 护目镜、手套、不用铝锅
4. 熟化2-6周,先在手背测试再用于洗手
5. 没有肥皂: 草木灰或流水搓洗20秒
```
