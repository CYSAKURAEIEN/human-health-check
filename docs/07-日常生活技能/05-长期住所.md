## 先说清楚: 本章的定位

[野外生存](../03-野外生存/00-基础生存技能.md#庇护所建造)讲的是几天到几周的临时庇护所。本章讲的是**要住上几年**的房子: 用泥土、木材、石头等就地取材的材料建造,能挡风雨、能过冬、不会在下一场雨或地震中塌掉。

```
⚠️ 房屋倒塌是地震中最主要的致死原因
⚠️ 取暖设施是冬季一氧化碳中毒和火灾的主要来源

所以本章的重点不是"怎么盖得快",而是"怎么盖得不害人":
1. 选址避开灾害
2. 地震区必须做抗震措施
3. 火炕、炉灶、烟囱不漏烟、不起火
```

**有条件时,请当地有经验的建筑工匠指导,并参照当地的农房建设技术规定。** 本章提供的是基本原理和通用做法,具体尺寸要结合当地的土质、气候和地震烈度调整。

## 选址

```
✓ 地势较高、排水好
✓ 地基土层结实(不要建在回填土、淤泥、沼泽上)
✓ 背风向阳(北方)或通风遮阴(南方)
✓ 靠近水源,但在洪水水位以上
✓ 离开林地边缘一段距离(防山火)

❌ 避开:
- 河滩、干河床、沟口(洪水、泥石流)
- 陡坡下方、坡脚(滑坡、滚石)
- 悬崖边、陡坡上方边缘
- 低洼易积水处
- 已有裂缝、树木歪斜的山坡(滑坡前兆)
```

各类地质灾害的识别见[地质灾害](../02-灾难应对/01-地质灾害.md)。

⚠️ 生活用水的水井、泉水要和厕所保持至少30米距离,见[卫生设施-旱厕](03-卫生设施.md#旱厕)。

## 防潮: 好靴子、好帽子

土墙最怕水。传统民居的经验是: **"好靴子、好帽子"**——墙脚有防水的基础,头上有出挑足够的屋檐。

### 好靴子: 墙基

```
1. 挖基槽,深至结实的原土层(北方要深于冻土层)
2. 用石块、砖或混凝土砌基础
3. 基础要高出室外地面至少30-50厘米
   - 防止雨水溅湿墙脚、地面积水泡墙
4. 基础顶部铺一层防潮层: 油毡、塑料布,或一层致密的石板
5. 室外地面向外做坡,四周挖排水沟
```

### 好帽子: 屋顶和屋檐

```
✓ 屋檐向外伸出至少50厘米,多雨地区更宽
✓ 屋面坡度足够,让雨水快速流走
✓ 屋顶不要过重(见下方抗震部分)
✓ 墙顶用石板、瓦或木板压顶,防雨水从墙顶渗入
```

### 外墙抹面

- 土墙外表面可用草泥或石灰砂浆抹面,保护墙体不被雨水冲刷
- 抹面开裂、脱落要及时修补

## 土坯墙

土坯是晒干的泥砖,做法简单,适合人力。

### 选土

```
理想的土: 有一定黏性,但不全是黏土(纯黏土干后开裂严重,纯沙土不成型)

简易检测(瓶子沉淀法):
1. 一个透明瓶子,装入1/3土、2/3水,加一小撮盐
2. 用力摇匀,静置一天
3. 土会分层: 下层沙、中层粉土、上层黏土
4. 黏土层约占土的1/4到1/3比较合适
   - 黏土太多: 掺沙
   - 黏土太少: 换土或掺黏土

去除: 表层腐殖土(含草根、有机物,会腐烂)、石块
```

### 制作

```
1. 土加水和成泥,掺入切碎的麦秸、稻草(约5-10厘米长,防开裂、增强拉结)
2. 反复踩踏和匀,闷一两天
3. 准备木模(常见尺寸约 长30 × 宽15 × 高10厘米,可按需要调整)
4. 模子沾水或撒沙防粘,填满泥,压实,刮平
5. 脱模,放在平整的地面上
6. 阴干2-3天后侧立,再晒2-4周,直到完全干透
   - 避免暴晒和淋雨,天气不好时遮盖

质量检查:
- 干透的土坯从约1米高处落到地上,只掉角、不碎成几块 → 合格
- 表面裂纹多、一碰就掉渣 → 土料不合适,调整配方
```

### 砌墙

```
1. 在防潮墙基上砌筑
2. 用和土坯同样的泥(不掺草或掺细草)作砌筑泥浆
3. 上下层错缝(像砌砖一样),不要通缝
4. 墙角和内外墙交接处要咬槎(相互交错咬合)
5. 每天砌筑高度不要太高(约1米),等下面干一些再往上砌
6. 墙要有足够厚度(一般不少于约35-40厘米)
```

## 夯土墙

在两块木板之间分层填土、夯实而成。比土坯墙整体性好,但需要模板和较多人力。

### 土料和含水量

```
土: 同土坯选土,可掺少量碎石、粗沙

含水量判断(传统方法"手握成团,落地开花"):
- 抓一把土用力攥紧 → 能攥成团,手上不沾泥水
- 从约1米高处落到地上 → 摔散开
- 攥不成团: 太干,洒水
- 落地不散、粘成一坨: 太湿,摊开晾一晾
```

### 夯筑

```
1. 在防潮墙基上立两侧模板(木板),用木杆和绳索或螺栓夹紧
2. 每层铺松土约15-20厘米厚
3. 用木夯或石夯均匀夯打,直到夯实到约原厚度的一半到三分之二,
   夯锤落下声音由闷变脆
4. 一层夯完再铺下一层
5. 一段夯满后拆模,向前或向上移动模板继续
6. 上下段之间的接缝要错开
7. 墙角、丁字墙处整体夯筑或加拉结材(见抗震部分)
8. 夯完的墙要防雨,慢慢干透(数周到数月)
```

## 简易木结构

木材资源丰富的地区,木结构房屋质量轻、韧性好,**在地震中比土墙房屋安全得多**。

```
基本形式: 木柱 + 木梁构成框架,墙体只起围护作用(可用木板、竹编抹泥、土坯填充)

要点:
✓ 木柱立在石柱础上,不要直接埋入土中(会腐烂)
✓ 柱、梁之间连接牢固(榫卯、木销、铁件)
✓ 加斜撑,防止框架左右晃动变形
✓ 木材要干燥后使用,防腐处理(刷桐油、熏烤表面)
✓ 屋架和柱子连接牢固,防止大风掀顶
⚠️ 木结构怕火: 炉灶、烟囱周围用砖石、泥土隔开
⚠️ 防白蚁: 木材离地,定期检查
```

## 抗震: 生土房屋的生死线

⚠️ **不加任何抗震措施的土坯房、夯土房,在地震中极易整体倒塌,历次地震中造成了大量伤亡。** 在地震多发区建造生土房屋,以下措施不是"加分项",而是必须做的。

```
1. 只建单层,墙不要太高
2. 屋顶要轻
   - 避免厚重的泥土屋面、厚重的瓦
   - 可用轻质的瓦、木板、草顶(草顶注意防火)
3. 墙顶设圈梁
   - 沿所有墙顶连续设一圈木圈梁(或配筋混凝土圈梁),四角连接牢固
   - 把各面墙箍成一个整体,地震时不会各自向外倒
4. 墙角和内外墙交接处加拉结
   - 每隔约50厘米高,在墙内水平铺设木条、竹条或荆条,伸入两侧墙内
5. 门窗洞口
   - 洞口不要太大,数量不要太多
   - 洞口离墙角至少约1米
   - 洞口上方设木过梁,两端伸入墙内足够长度
6. 平面规则
   - 房屋平面方正、对称,避免L形、凹凸复杂的形状
   - 隔墙间距不要太大(长墙中间加横墙或扶壁)
7. 屋架和墙体可靠连接,防止地震时屋顶滑落
```

**高地震风险地区优先选择木结构,或在专业指导下建造。** 已有的老土房,可通过加木圈梁、墙角加固、减轻屋顶等方法加固。

地震时的应对见[地质灾害-地震](../02-灾难应对/01-地质灾害.md#地震)。

## 保温

### 北方寒冷地区

```
✓ 墙要厚: 厚土墙蓄热好,白天吸热、夜间放热
✓ 北墙少开窗或开小窗;南墙多开窗采光取暖
✓ 门口设门斗或挂厚门帘(减少开门时的冷风)
✓ 窗户: 双层窗,或冬季在窗外钉塑料布
✓ 屋顶保温: 吊顶上方铺干草、稻壳、锯末等(注意防火)
✓ 堵住墙和门窗缝隙的冷风

⚠️ 封闭门窗保温的同时,有炉火的房间必须保持通风(见下方火炕与烟囱部分)
```

一氧化碳中毒的识别与救助见[一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

### 南方炎热地区

```
✓ 屋檐出挑大,遮挡阳光直射墙面
✓ 前后开窗,形成穿堂风
✓ 屋顶隔热: 双层屋面或吊顶,中间通风
✓ 浅色外墙反射阳光
✓ 房前屋后种树遮阴
```

## 火炕与炉灶

火炕是北方传统的取暖方式: 灶膛的烟火先经过炕下的烟道,把炕面烧热,再从烟囱排出。

### 结构要点

```
1. 灶膛(做饭的灶) → 炕洞(炕下的烟道) → 烟囱
2. 炕洞: 用土坯或砖砌出迂回的烟道,让热烟在炕下多停留
3. 炕面: 铺土坯板或石板,上面抹泥,干后铺席
4. 烟囱根部设闸板(可关小、不可完全关死,见下方)
```

### ⚠️ 一氧化碳中毒的风险

火炕和炉灶是北方冬季一氧化碳中毒的主要来源之一。

```
漏烟的原因:
- 炕面开裂、塌陷,烟从缝里冒进屋内
- 烟道被灰堵塞,烟排不出去,倒灌进屋
- 烟囱太矮、被积雪或杂物堵住
- 刮大风、气压低时烟气倒灌
- 睡前为了"保温"把烟囱闸板完全关死

预防:
✓ 每年入冬前检查炕面、灶台、烟道、烟囱,开裂处用泥抹严
✓ 定期掏炕洞、烟囱里的积灰
✓ 烟囱闸板睡前不要完全关闭
✓ 刮风天、阴雨天、气压低的天气特别注意
✓ 室内留一个通风口
✓ 安装一氧化碳报警器(燃气报警器检测不到一氧化碳)
✓ 炕上睡觉的人出现头痛、头晕、恶心 → 立即开窗、离开房间
```

### 炉灶

```
✓ 省柴灶: 灶膛小而深,锅底离火焰近,加挡火圈,烟道有拐弯,比敞口灶省柴、烟少
✓ 炉灶周围1米内不放柴草等易燃物
✓ 炉灶和木墙、木柱之间用砖石或厚泥层隔开
✓ 不在室内烧没有烟囱的炭盆、煤炉
✓ 炉灰倒在铁桶里,确认完全熄灭再倒到外面(余烬可复燃)
```

## 烟囱: 防火与防一氧化碳

### 高度和位置

```
✓ 烟囱要高出屋面,一般参考做法:
  - 高出它穿过屋面的位置约1米
  - 并且比周围3米范围内的屋脊、墙等最高处再高出约0.6米
  (太矮会因风压导致倒烟,火星也容易落到屋顶上)
✓ 烟囱顶部加防雨帽和防火星网(尤其是草顶、木屋顶)
✓ 烟囱穿过木屋顶、木楼板处,四周用砖石、泥土隔开,不能直接接触木料
```

### 防止烟囱起火

木柴不完全燃烧产生的焦油会附着在烟囱内壁,积多了会被点燃,引起烟囱火,进而引燃屋顶。

```
✓ 烧干透的木柴(湿柴焦油多、烟大)
✓ 不要长时间闷火慢烧
✓ 每年至少清扫一次烟囱(使用频繁时每个取暖季中途再清扫一次)
✓ 定期检查烟囱有没有裂缝

烟囱起火的迹象: 烟囱里发出轰隆声、烟囱口冒出大量火星或火焰、烟囱外壁发烫
处理: 关闭炉门和进风口,撤离房屋,拨打119,
     注意屋顶和周围有没有被火星引燃
```

## 维护

```
每年雨季前:
- [ ] 检查屋顶有没有漏雨,修补
- [ ] 清理排水沟
- [ ] 检查墙脚有没有被雨水冲刷、泡软

每年入冬前:
- [ ] 检查火炕、灶台、烟道、烟囱,修补裂缝
- [ ] 清扫烟囱和炕洞积灰
- [ ] 测试一氧化碳报警器
- [ ] 准备干柴(提前一年备好,充分晾干)

随时:
- [ ] 墙体出现明显裂缝、倾斜 → 及时加固,裂缝加宽时不要继续居住
- [ ] 木构件腐烂、虫蛀 → 及时更换
- [ ] 外墙抹面脱落 → 修补
```

## 📝 长期住所要点

```
1. 选址: 避开河滩、沟口、陡坡下;高于洪水位
2. 防潮: 好靴子(高出地面的石砖墙基)、好帽子(宽屋檐)
3. 地震区: 单层、轻屋顶、墙顶圈梁、墙角拉结、门窗离墙角远;
   优先木结构
4. 保温要和通风兼顾,有炉火的房间必须留通风口
5. 火炕炉灶: 每年检查裂缝、清灰,闸板不要关死,装一氧化碳报警器
6. 烟囱: 足够高,烧干柴,每年清扫
```
