## 先说清楚: 哪些事自己不能做

电气事故有两种后果: **触电**和**电气火灾**。多数电气火灾来自线路老化、插座过载、私拉乱接,这些都可以预防。

```
可以自己做:
✓ 定期按漏电保护器的试验按钮
✓ 检查插线板、电线、插头有没有发热、变色、破损
✓ 更换灯泡、插头(断电后)
✓ 合理安排大功率电器,不同时用太多

❌ 不要自己做(找有资质的电工):
- 改动、新增家里的线路和插座
- 更换配电箱里的开关
- 接入发电机、太阳能系统到家庭线路
- 处理任何带电操作
```

触电后的急救见[急性症状-电击伤](../01-日常疾病和伤害/05-急性症状.md#电击伤)。

## 漏电保护器和空气开关

家里配电箱里通常有两种开关,作用不同:

| 开关 | 作用 | 怎么认 |
|------|------|--------|
| 空气开关(断路器) | 电流过大(过载、短路)时跳闸,**防电气火灾** | 普通的开关 |
| 漏电保护器 | 有电流漏到人体或地面时迅速跳闸,**防触电** | 带一个"T"或"试验"按钮 |

```
✓ 插座回路、卫生间、厨房必须有漏电保护器
  (家用一般选额定漏电动作电流30 mA的)
✓ 每月按一次"试验"按钮: 按下后应该立即跳闸,然后重新合上
  按了不跳 → 漏电保护器已经失效,请电工更换
✓ 老房子没有漏电保护器的,请电工加装(这是家里最重要的电气安全装置)

跳闸后:
✓ 先拔掉刚才在用的电器,再合闸
✓ 合闸后又跳 → 线路或某个电器有问题,不要反复强行合闸,请电工检查
❌ 绝不能因为"老跳闸"就把漏电保护器拆掉、短接,或换成更大的开关
```

## 插座、插线板和电线

### 插线板

```
✓ 买有3C认证标志的插线板,带总开关和过载保护
✓ 看清插线板上标的最大功率(常见的约2500 W),所接电器加起来不要超过
❌ 不要插线板串插线板("串联插")
❌ 不要用插线板接空调、电热水器、电暖器等大功率电器
❌ 插线板不要放在地上有水的地方、不要被家具压住、不要盖在被子地毯下面
✓ 不用时关掉开关或拔掉;外出、睡前拔掉不用的充电器
```

### 插头和插座

```
✓ 插头插紧: 插头松动、接触不良会发热,时间长了会烧焦起火
✓ 拔插头时手握插头拔,不要拽电线
❌ 不要用湿手插拔插头、开关电器
✓ 有儿童的家庭使用带保护门的插座
```

### 电线

```
需要停用并更换的信号:
- 电线外皮破损、开裂、变硬、发黄
- 插头、插座、电线摸起来发烫,或有焦味、变色
- 插座有打火、噼啪声

❌ 不要用胶布缠裹破损的电线继续用
❌ 不要把电线钉在墙上、压在门缝或家具下、绕在铁钉铁丝上
❌ 不要私拉乱接电线(尤其是从窗户拉线到楼下)
⚠️ 住了二三十年的老房子,线路可能已经老化,请电工整体检查
```

## 大功率电器

```
空调、电热水器、电暖器、电磁炉、电烤箱、电饭锅等:
✓ 使用专用的墙上插座,不用插线板
✓ 不要几个大功率电器同时用在同一个回路上
✓ 电暖器离窗帘、床单、衣物至少1 m,不要在上面烘衣服
✓ 电热毯不要折叠使用;不要长时间通电整夜开着;老化的及时更换
✓ 电器用完关电源,长期不用拔掉插头
```

电气火灾的扑救(先断电,不能用水)见[火灾-电气火灾](../02-灾难应对/04-火灾.md#电气火灾)。

## 电动自行车充电

电动自行车电池起火燃烧非常猛烈,还会产生大量有毒浓烟。**多数电动自行车火灾伤亡发生在门厅、楼道、楼梯间等室内场所。**

```
❌ 不要在楼道、楼梯间、门厅、安全出口停放和充电
   (这些是逃生通道,起火后浓烟会封住全楼人的出路)
❌ 不要把电池带回家里充电,不要在室内、阳台充电
❌ 不要从窗户拉"飞线"下楼充电
✓ 在小区集中充电点充电
✓ 使用原装或匹配的充电器
✓ 充满后及时断电,不要整夜充电
✓ 电池鼓包、漏液、发热异常、摔过撞过 → 停止使用,到正规店检查更换
❌ 不要私自改装电池、加装大容量电池

起火时: 立即撤离,关上门,拨打119,不要试图扑救
```

## 潮湿环境用电

```
卫生间:
✓ 电热水器必须可靠接地,并有漏电保护
✓ 洗澡时尽量不用电吹风、手机充电
❌ 不要把插线板放在浴室里

厨房:
✓ 插座远离水槽
✓ 湿手不碰开关和插头

户外:
❌ 雷雨天不要在户外使用电器,拔掉不用的电器插头
❌ 不要在电线下钓鱼、放风筝
❌ 看到断落在地上的电线,不要靠近,至少远离8-10 m,拨打供电服务电话95598
```

## 灾后恢复用电

洪水、台风、地震后,电气线路可能已经泡水或受损,**来电后再出事的情况并不少见**。

```
灾前或灾中:
✓ 预计会被水淹时,提前关掉总闸
✓ 不要涉水进入有电器的房间
✓ 房间进水时,不要站在水里去拉闸

灾后:
❌ 泡过水的电器、插座、配电箱,没经过电工检查不要通电
   (即使看起来已经干了)
✓ 请电工检查线路后再合总闸
✓ 墙体开裂、房屋受损的,电线可能被拉断或挤破,也要先检查
✓ 闻到焦味、看到冒烟、听到打火声 → 立即拉总闸

用发电机时:
❌ 绝不在室内、车库、窗户附近使用(一氧化碳中毒)
❌ 不要把发电机接到家里的插座或配电箱上"反送电"(会电死抢修工人)
```

发电机的详细安全规则见[照明与能源-发电机](06-照明与能源.md#发电机)。

## 日常检查清单

```
每月:
- [ ] 按一次漏电保护器的试验按钮
- [ ] 摸一摸常用的插线板、插头有没有发烫

每年(或入冬前、梅雨季前):
- [ ] 检查电线、插线板外皮有没有破损老化
- [ ] 检查电热毯、电暖器
- [ ] 检查电动自行车电池

家里常备:
- [ ] 手电筒(知道配电箱在哪里,停电时能找到)
- [ ] 带漏电保护的插线板
- [ ] 适合电气火灾的灭火器(干粉灭火器)
```

---

## 📝 家庭用电安全要点

```
1. 漏电保护器防触电,每月按一次试验按钮,不能拆、不能短接
2. 跳闸后先拔电器再合闸;反复跳闸请电工检查
3. 插线板不串插、不接大功率电器、不超功率
4. 电线破损、插头发烫有焦味 → 停用更换
5. 电动自行车不进楼道、不进家、不整夜充电
6. 改线路、加插座、接发电机找电工
7. 泡过水的电器和线路,检查前不通电
8. 电器着火先断电,不能用水泼
```
