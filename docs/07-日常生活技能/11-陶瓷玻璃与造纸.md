## 先说清楚: 本章的定位

陶器能存粮、存水、做饭、发酵;砖瓦能盖房;玻璃能做瓶子、透镜和化学器皿;纸能把知识记下来、传下去。这几样在[技术重建路线图](../09-进阶科学与工程/00-技术重建路线图.md#三关键瓶颈)里都是瓶颈,本章讲小规模、手工的做法。

```
⚠️ 安全:
- 窑和熔炉温度极高: 烧伤、引燃周围的草木和房屋,窑要离房子远一些,周围清出防火带
- 烧窑、熔玻璃会产生一氧化碳,绝不在室内或密闭的棚子里烧
- 干燥的黏土粉、石英砂、釉料粉尘长期吸入会得矽肺: 打湿了再处理,戴口罩
- ☠️ 不用含铅的釉做盛食物的器皿(铅会慢慢溶进食物,特别是酸的食物)
- 熔融的玻璃看起来不红也可能有几百摄氏度;碎玻璃锋利,戴手套和护目镜
- 造纸用的碱水(石灰水、草木灰水)会烧伤皮肤和眼睛
```

最现实的路线: **先回收**。废墟里的陶瓷碗、玻璃瓶、纸张比自己做容易得多,自己做是为了长期补充。

## 陶器: 选土和练泥

### 什么样的土能做陶

```
找土: 河边、湖边、低洼地的细腻土层,挖开表土以下颜色均匀的一层(见地质矿物与土壤)
试土:
1. 取一把土加水揉成泥,搓成铅笔粗的泥条
2. 绕在手指上弯成圈: 不开裂或只有细纹 → 可塑性好,能做陶
   一弯就断 → 砂太多,不适合
3. 捏一个小碗或泥饼,晾干后放进火堆里烧
   - 烧后不碎、敲起来声音清脆 → 可用
   - 炸裂 → 可能是没干透,或者需要掺砂
   - 冒泡、熔化变形 → 含杂质太多,只能低温烧

颜色:
- 红色、褐色的土: 含铁多,烧成红陶,烧成温度较低
- 白色、灰白色的土(高岭土、瓷土): 能耐更高温度,是做瓷器和耐火材料的原料
```

黏土的识别见[地质、矿物与土壤-到哪里找有用的东西](../08-基础科学知识/06-地质矿物与土壤.md#三到哪里找有用的东西)。

### 练泥

```
1. 晒干后敲碎,泡在水里化开
2. 淘洗: 搅成稀泥浆,静置几分钟让砂石沉底,把上面的泥浆倒进另一个容器
   (这一步能去掉砂石和草根)
3. 泥浆静置沉淀,倒掉上面的清水,摊在布上或吸水的地面上,晾到能揉不粘手
4. 掺料(羼和料):
   - 加入细砂、粉碎的碎陶片(熟料),约占10-25%
   - 作用: 减少干燥和烧制时的收缩、开裂;做炊具时尤其需要
5. 揉泥: 像揉面一样反复揉压,挤出里面的气泡
   → 泥里的气泡在烧制时会膨胀,让陶器炸裂
6. 揉好的泥用湿布包好或放进缸里,"陈腐"几天到几周,可塑性会更好
```

## 成型

```
捏塑: 用手指从泥团中间按出凹坑,一边转一边捏薄 → 小碗、小杯、坩埚

泥条盘筑(最实用,能做大缸):
1. 做一个圆泥饼作底
2. 把泥搓成粗细均匀的泥条,一圈一圈盘在底的边缘上
3. 每盘一圈,用手指把上下两圈的接缝抹平、抹实(里外都要抹)
4. 盘到一定高度,等下面稍微变硬能支撑了,再继续往上盘
5. 用木板拍打外壁、里面用卵石垫着,让壁更薄更结实

泥板成型: 把泥擀成均匀的泥板,切开拼接 → 方形容器、瓦片、砖
  接缝处先划毛、刷泥浆再粘

轮制: 有转盘(陶轮)时,快速旋转中拉坯,做出的器物圆而薄
  → 需要大量练习,可以用回收的轴承和飞轮自制陶轮

✓ 器壁厚薄要均匀(约5-10 mm),厚薄不均容易在干燥和烧制时开裂
✓ 把手、壶嘴等附件在泥坯半干时接上,接口划毛、刷泥浆
```

## 干燥

**大多数失败都出在干燥上。** 泥坯含水,太快干燥会因为外干内湿、收缩不均而开裂。

```
1. 放在阴凉、不通风、不被太阳直晒的地方,慢慢阴干
2. 刚成型的头几天可以盖一层塑料布或湿布,让它均匀变干
3. 大件要一两周甚至更久
4. 判断干透: 摸起来不凉、颜色变浅均匀、贴在脸上不觉得凉
   → 没干透的坯放进窑里,里面的水变成蒸汽会让它炸裂
5. 烧之前最好再在火边或太阳下烘一两天
```

## 烧制

### 温度

```
约600°C以上: 黏土变成陶,不再遇水化开(这是陶和晒干的泥坯的本质区别)
约800-1000°C: 普通陶器
约1200-1300°C以上: 炻器、瓷器,致密不渗水,需要好的窑和耐火材料

看火色判断温度:
暗红色 → 约600-700°C
樱桃红 → 约800-900°C
橙色 → 约1000-1100°C
黄白色 → 约1200°C以上
```

看火色判断温度见[基础冶金知识-判断温度](../05-冶金技术/00-基础冶金知识.md#41-判断温度)。

### 露天堆烧(最简单)

```
1. 地上挖一个浅坑,铺一层干柴
2. 把干透的陶坯口朝下放好,先在周围烧小火烘烤一两个小时
   (让最后的水分慢慢出来)
3. 逐渐加柴,把坯子整个埋在柴堆里,外面盖树皮、碎陶片或湿泥保温
4. 大火烧几个小时,然后让它在灰里自然冷却,第二天再取出
→ 温度约600-900°C,不均匀,破损率高,适合小件
```

### 简易升焰窑

```
结构:
- 下面是燃烧室(火膛),上面是放坯子的窑室,中间隔一层有孔的窑箅(炉栅)
- 窑壁用土坯或砖砌,内外抹泥,上面留烟口
- 火从下往上穿过陶坯,从顶部烟口排出

烧窑:
1. 坯子码放在窑箅上,之间留缝让火通过
2. 小火慢烘几个小时: 先让残余的水分和黏土里的结合水慢慢出来
   ⚠️ 这一阶段升温太快最容易炸坯,烟口看到"白烟"(水汽)时保持小火
3. 白烟消失后逐渐加大火力,烧到需要的火色,保持一两个小时
4. 封住火口和烟口,让窑慢慢冷却一两天,绝不提前打开
   → 冷却太快会让陶器开裂(冷裂)

✓ 有鼓风设备时可以达到更高的温度
✓ 每窑记录: 用了多少柴、烧了多久、成品率多少,逐步改进
```

窑砖、炉衬的耐火材料见[工程力学与材料-陶瓷和耐火材料](../09-进阶科学与工程/01-工程力学与材料.md#105-陶瓷和耐火材料);鼓风见[鼓风设备与锻炉](../05-冶金技术/08-鼓风设备与锻炉.md)。

### 坩埚和耐火砖

```
冶炼、熔玻璃都需要能耐高温的容器:
- 用白色的耐火黏土(高岭土),掺入大量粉碎的熟料(碎耐火砖、碎瓷片),
  熟料可以占到三分之一甚至一半
- 壁要厚,彻底干燥后先低温素烧一次
- 使用前预热,不要把冷坩埚直接放进高温炉
```

## 釉和防渗

```
没有釉的陶器有孔隙,会渗水:
- 盛水的陶罐微微渗水,外壁蒸发能让水变凉,这反而是优点
- 储油、储酒、盛汤要防渗

不用釉的防渗方法:
- 打磨: 泥坯半干时用光滑的卵石反复磨光表面,烧后更致密
- 趁热浸渍: 陶器出窑还热时,浸入或泼上米汤、面糊、乳汁,封住孔隙
  (只能减少渗漏,不耐久)
- 涂一层蜡、松脂(只适合冷的东西)

釉(高温才能形成):
- 灰釉: 草木灰和细黏土按大约1:1混合,加水调成浆,涂在素烧过的坯上,
  需要约1200°C以上才能熔成光亮的釉面
- ☠️ 铅釉(含铅丹、密陀僧)在较低温度就能熔化,历史上很常用,
  但铅会溶进食物中,特别是酸的食物、酒、醋 → 盛食物的器皿绝不用铅釉
- 回收的旧瓷器、无铅玻璃磨成细粉,可以作为低温釉的原料(试验性)
```

## 砖瓦

```
砖: 黏土掺少量砂,倒进木模压实、脱模,阴干后烧制(约900-1000°C)
  - 烧透的砖: 敲起来声音清脆,断面颜色均匀
  - 欠火砖: 声音发闷、颜色发黄,遇水会变软,只能用在不受潮的地方
瓦: 泥板围在木筒上成型,干后切成几片,烧制
✓ 砖窑、瓦窑可以和陶窑共用,通常一窑烧几千块,需要大量柴

不烧的土坯也能盖房: 见长期住所
```

## 玻璃

### 最现实的做法: 回收和重熔

```
废墟里的玻璃瓶、窗玻璃数量很多:
✓ 完整的瓶罐洗净保存,是最好的储存容器和化学器皿
✓ 碎玻璃按颜色分类收集(无色、绿色、棕色分开)
✓ 重熔碎玻璃: 普通玻璃约700°C以上开始软化,约1000°C以上
  才能流动、吹制,比从原料熔制容易得多
⚠️ 不同来源的玻璃热胀冷缩不同,混在一起熔化后冷却时容易开裂
  → 尽量只用同一种来源的玻璃(如同一批瓶子)
⚠️ 耐热玻璃(实验器皿、烤箱玻璃)和普通玻璃不要混用;荧光灯管、显像管玻璃含有害物质,不要用
```

### 从原料熔制(原理)

```
普通钠钙玻璃的大致配方(按质量):
- 石英砂(SiO₂): 约70%,越白越纯越好,含铁多玻璃就发绿
- 纯碱(Na₂CO₃)或草木灰中的钾碱: 约15-20%,作用是降低熔化温度
- 石灰(CaO): 约10%,让玻璃不溶于水、更稳定
- 加入碎玻璃(10-30%)能帮助熔化

熔制温度约1400-1500°C,古代的窑温达不到时,
常先在较低温度下烧成"熔块",粉碎后再熔,并且烧很长时间

⚠️ 需要: 好的耐火坩埚、能长时间保持高温的窑、大量燃料
→ 对小社区来说非常困难,先回收,再考虑自己熔制
```

纯碱和石灰的化学见[化学进阶](../09-进阶科学与工程/05-化学进阶.md)、[化学-改变人类社会的重要反应](../08-基础科学知识/03-化学.md#四改变人类社会的重要反应)。

### 吹制和成型(了解)

```
- 吹管: 一根约1.2-1.5 m长的铁管
- 用吹管的一端从坩埚中蘸取一团熔融的玻璃,边转边吹气,
  玻璃就鼓成泡,再用工具、模具塑形
- 也可以把熔融的玻璃倒入预热的模具中压制
```

### 退火: 不能省的一步

```
成型后的玻璃如果直接放在空气中冷却,表面和内部冷却速度不同,
会留下很大的内应力 → 过几小时或几天后自己炸裂

退火:
1. 成型后立即放进保温的退火炉(或窑中余热的部位),约500°C
2. 保持一段时间,让里外温度一致
3. 然后用几个小时到一两天慢慢冷却到室温
厚的器物要更长时间
```

### 玻璃能做什么

```
- 瓶罐: 储存药品、化学品、食物
- 透镜: 磨制凸透镜做放大镜、眼镜(远视、老花),进一步做显微镜、望远镜
  → 用越来越细的磨料在凹模上反复研磨,需要大量耐心
- 化学器皿、温度计
- 窗玻璃: 让屋里有光又挡风
```

透镜原理见[物理-波、声与光](../08-基础科学知识/02-物理.md#六波声与光)。

## 造纸

我国东汉的蔡伦改进了造纸术,原料是树皮、麻头、破布、旧渔网。今天的做法原理相同。

### 原料

```
✓ 构树皮(最好的原料之一,构树在我国很常见): 剥下内层的白色韧皮
✓ 桑树皮、青檀皮
✓ 麻、旧麻布、旧棉布(破布造纸,纤维已经处理过,最容易)
✓ 竹子(嫩竹)、稻草、麦秆(纤维短,纸较粗)
✓ 废纸回收(最简单): 泡软打成浆就能重新抄纸
```

### 步骤

```
1. 浸泡: 树皮、麻、稻草切成小段,在水里泡几天
2. 蒸煮: 加入石灰水或草木灰水(碱水)煮几个小时到一天,
   直到纤维变软、能用手指搓开
   → 碱能溶解植物中把纤维粘在一起的胶质和木质素
   ⚠️ 碱水烧皮肤和眼睛,戴手套和护目镜,见制皂-安全须知
3. 洗涤: 用清水反复冲洗,去掉碱和杂质(可以装在布袋里放在流水中漂洗)
4. 漂白(可选): 在阳光下摊晒、反复浇水,纤维会逐渐变白
5. 打浆: 用木槌在石板上反复捶打,或用石臼舂,直到纤维分散成一丝一丝的细绒
   → 打浆越充分,纸越细密结实
6. 配浆: 在大水槽里加水,放入纸浆搅匀成很稀的浆(像稀米汤)
   可以加入"纸药"(黄蜀葵根、杨桃藤等植物的黏液),让纤维在水中分散均匀
7. 抄纸: 用纸帘(细竹丝或纱网绷在木框上)从水槽中斜着插入、平着抬起,
   轻轻摇晃让纤维均匀分布,水从网眼中滤走,网上留下一层薄薄的湿纸
8. 压榨: 把湿纸一张张叠起来(中间可以垫布),上面压木板和重物,挤出水分
9. 干燥: 把半干的纸一张张揭下,刷在平整的墙面或木板上晒干
10. 施胶(可选): 刷一层稀淀粉浆或骨胶水,干后墨水不容易洇开
```

```
简易版(废纸回收):
1. 废纸撕碎,用热水泡一夜
2. 捣成纸浆(没有工具时可以用手揉搓)
3. 倒进一盆水里搅匀
4. 用纱窗网绷在木框上做纸帘,捞起一层纸浆
5. 翻扣在布上,压去水,晾干
```

碱水的制作见[制皂-制碱水](04-制皂.md#第一步-制碱水)。

### 让纸保存得更久

```
✓ 碱法造的纸比现代的酸性纸耐久,好的手工纸能保存几百年
✓ 防潮、防虫(放樟木、花椒、艾草,定期晾晒)、防火、防鼠
✓ 重要内容抄写多份,分开保存
```

保存资料见[教育与知识传承-抄写和保存资料](12-教育与知识传承.md#抄写和保存资料)。

## 墨和书写

```
墨(碳黑墨,最耐久):
1. 收集烟灰: 油灯(植物油、动物油)上方罩一个碗或瓦片,刮下里面的黑烟灰(油烟);
   烧松木的烟灰(松烟)也可以
2. 加入胶水(骨胶、皮胶,或桃胶等树胶)和少量水,反复研磨、调匀
3. 直接用,或者做成墨块晾干,用时加水研磨
→ 碳黑墨不会褪色,几千年的文书仍然清晰

笔:
- 毛笔: 动物毛扎成束,插进竹管
- 蘸水笔: 削尖的竹片、禽类羽毛管,斜削出笔尖,中间劈一道细缝
- 木炭条、铅笔(石墨)

其他书写材料: 竹片(竹简)、木片(木牍)、布帛、刻在陶器或石头上(最耐久)
```

```
胶(骨胶、皮胶): 碎皮边角、骨头洗净,加水小火长时间熬煮,
  滤去渣,继续熬浓,冷却后凝成胶冻,切块晾干;用时加水隔水加热化开
```

## 📝 陶瓷玻璃与造纸要点

```
1. 先回收: 陶瓷碗罐、玻璃瓶、纸张都比自己做容易
2. 做陶最关键的三步: 揉出气泡、慢慢阴干、烧窑开始时小火慢烘
3. 炊具和大件要掺砂或碎陶片(约10-25%)防开裂
4. 窑要慢慢冷却,不能提前打开
5. 盛食物的器皿绝不用铅釉
6. 玻璃成型后必须退火,否则会自己炸裂;不同来源的碎玻璃不混熔
7. 造纸: 浸泡 → 碱水蒸煮 → 洗净 → 打浆 → 抄纸 → 压榨 → 晒干
8. 碳黑墨(烟灰 + 胶)最耐久,重要资料抄写多份分开保存
```
