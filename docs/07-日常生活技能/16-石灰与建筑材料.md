## 先说清楚: 本章的定位

水泥要在约1450°C烧成,小社区很难自己做好;**石灰只要约900°C,一座土窑就能烧出来**。在水泥普及之前的几千年里,砌墙的灰浆、抹墙的白灰、铺地的三合土、刷畜圈的消毒水,靠的都是石灰。它还能改良酸性土、帮助造纸和鞣皮。

本章讲: 怎样找原料、烧石灰、熟化,以及怎样用石灰和其他就地材料造房子。墙体本身怎么盖(土坯、夯土、抗震)见[长期住所](05-长期住所.md),砖瓦的烧制见[陶瓷玻璃与造纸-砖瓦](11-陶瓷玻璃与造纸.md#砖瓦),受力计算见[工程力学与材料](../09-进阶科学与工程/01-工程力学与材料.md)。

```
⚠️ 安全
- 生石灰遇水剧烈放热,能把水烧开,溅出的灰浆会烫伤、烧伤皮肤
- 生石灰粉尘或灰浆溅入眼睛可以致盲
- 受潮的生石灰膨胀发热,堆在木头、干草旁可能引起火灾
- 石灰窑产生一氧化碳(无色无味,能致命),窑内料堆可能坍塌
✓ 处理生石灰、熟化、拌灰浆时戴护目镜、手套,穿长袖,身边备一桶清水
✓ 儿童远离石灰池、灰堆和石灰窑
```

生石灰溅到皮肤上: **先刷去(擦去)干粉,再用大量清水冲洗**,不要先泼少量水。溅入眼睛: 擦去眼周可见的颗粒,马上翻开眼皮用大量清水持续冲洗,尽快就医。化学烧伤的处理见[外伤处理-化学烧伤](../01-日常疾病和伤害/02-外伤处理.md#化学烧伤)。

## 石灰的循环

石灰的妙处在于它"绕了一圈又回到石头":

```
1. 煅烧(约900°C以上):    CaCO₃ → CaO + CO₂↑
   石灰石(碳酸钙)        →  生石灰(氧化钙)

2. 熟化(加水):          CaO + H₂O → Ca(OH)₂ + 大量热
   生石灰                 →  熟石灰(氢氧化钙),也叫消石灰

3. 硬化(在空气中):      Ca(OH)₂ + CO₂ → CaCO₃ + H₂O
   熟石灰吸收空气中的二氧化碳 → 又变回坚硬的碳酸钙
```

```
实用结论:
- 窑温不到约840°C,石灰石怎么烧都不分解,所以要到约900°C以上
- 纯石灰石烧透后理论上减重约44%(100 kg 只剩约56 kg)
- 石灰砂浆靠吸收空气中的 CO₂ 硬化: 很慢(外层几周,厚墙深处几年),
  长期泡水、埋在湿土里的部位不会硬化 → 要用水硬性灰浆(见下文)
```

反应原理见[化学-石灰的循环](../08-基础科学知识/03-化学.md#44-石灰的循环-建筑的基础),为什么必须达到约900°C见[化学进阶-熵和吉布斯自由能](../09-进阶科学与工程/05-化学进阶.md#22-熵和吉布斯自由能),减重的计算见[化学-用方程式计算](../08-基础科学知识/03-化学.md#32-用方程式计算)。

## 原料: 哪些石头能烧石灰

| 原料 | 在哪里 | 说明 |
|------|--------|------|
| 石灰岩 | 石灰岩山区,常有溶洞、石林、地下河 | 最常用;灰白、青灰色,较纯的烧出来白 |
| 大理岩 | 变质岩地区 | 纯度高,烧出的石灰好,但常比石灰岩难找 |
| 贝壳、螺壳 | 海边、湖边、河边的贝壳堆 | 沿海传统的"蛎灰",先用淡水洗去盐分 |
| 白云岩 | 与石灰岩伴生 | 烧出的是含镁的"镁质石灰",熟化慢,也能用 |
| 泥灰岩(含黏土的石灰岩) | 石灰岩地区 | 烧出的石灰带一定水硬性,适合潮湿处 |

```
判断方法: 滴醋
1. 在石头新鲜的断面上滴几滴醋(或稀盐酸)
2. 立即冒出很多小气泡 → 石灰岩、大理岩、贝壳(碳酸钙)
3. 不冒泡或很弱,但磨成粉后再滴才冒泡 → 可能是白云岩
4. 完全不冒泡 → 不是碳酸盐,不能烧石灰(花岗岩、砂岩、石英等)

选料:
✓ 颜色均匀、致密、没有明显的黄褐色铁锈斑和泥质夹层
✓ 敲成约拳头到10-20 cm大小,块头尽量一致(大块烧不透,碎屑堵风)
✗ 含大量黏土、砂的石头: 烧出来杂质多、熟化不好
```

岩石的识别见[地质矿物与土壤-岩石的三大类](../08-基础科学知识/06-地质矿物与土壤.md#一岩石的三大类)和[建筑和日用材料](../08-基础科学知识/06-地质矿物与土壤.md#31-建筑和日用材料)。

## 石灰窑

### 简易立窑(土窑)

最简单的石灰窑是一个竖立的"大炉膛",常常依山坡挖成,从坡上装料、从坡下出灰。

```
结构(间歇式小窑,一窑出几百 kg 到几 t 生石灰):
- 窑膛: 圆筒形或蛋形,内径约1.5-2.5 m,高约2-4 m;依山挖进土坡最省事,
  土坡就是保温层;内壁用耐火石块或砖砌一圈,缝用黏土泥抹严
- 火门/出灰口: 窑底一侧的开口,加燃料、通风,烧完从这里扒出石灰
- 窑顶开口: 装料、排烟;窑底用石块架空成炉箅,让空气从下面进入
```

### 两种装窑方式

```
1. 分烧(单独火膛,适合烧柴):
   窑底用大块石灰石干砌成拱,拱下是火膛,拱上装满石灰石(大块在下);
   在火门持续烧柴,火焰穿过石块向上走;石灰不混燃料灰,比较干净
2. 混烧(分层装料,适合煤、焦炭、木炭):
   底部铺引火柴,然后一层燃料、一层石灰石交替往上装,火从下往上烧;
   连续窑从底部扒出石灰、顶部再加料,可以长期不熄火;石灰混有燃料灰,砌墙改土无妨
```

### 烧制过程

```
1. 头一天小火慢烘: 赶走石块和窑壁里的水分,急火会把石头和窑壁崩裂
2. 逐渐加大火力,保持窑内亮橙色(约900-1000°C;暗红色说明温度不够)
   柴窑大火持续烧2-4天(看窑和石块大小),中间不能断火
3. 烧好后封住火门,慢慢冷却1-2天再出窑,不要往热窑里泼水
4. 用长柄耙子从出灰口扒灰,人不要进窑、不要站在窑顶

怎样判断烧透:
✓ 变轻: 烧前称过的样块,纯碳酸钙理论减重约44%,一般石灰石约35-43%;
  减重远小于这个数 → 没烧透
✓ 敲开: 断面白色或灰白、疏松;中心有石头颜色的硬芯 → 欠烧,挑出重烧
✓ 遇水: 洒一点水很快"嘶嘶"冒汽、发烫、裂成粉;
  很慢才发热、块面发亮呈玻璃状 → 过烧(温度太高或时间太长)

燃料用量(数量级): 每烧出1 kg 生石灰约需干柴1-2 kg,或煤约0.25-0.5 kg
→ 一窑几 t 石灰要好几 t 柴,提前一两个月备柴晾干;有煤优先用煤混烧
```

```
⚠️ 窑的危险:
- 一氧化碳: 窑顶和下风处、低洼地不要久留,不要在窑旁睡觉
- 坍塌: 料常会"悬空"(下面烧酥塌陷,上面结成拱),人站上去或钻进去
  捅料会掉入高温窑膛;只用长杆在外面捅;依山的窑雨后土坡可能塌方
- 出窑粉尘大: 戴护目镜和口罩(湿布也行),站在上风处
```

窑的通风和耐火材料见[陶瓷玻璃与造纸-简易升焰窑](11-陶瓷玻璃与造纸.md#简易升焰窑)和[坩埚和耐火砖](11-陶瓷玻璃与造纸.md#坩埚和耐火砖)。

**生石灰的保存**: 出窑后尽快熟化,或装进干燥、有盖的铁桶、陶缸放在高处;不要堆在木地板、草堆旁(受潮发热可能引燃),也不要长期敞放(会慢慢失效)。

## 熟化与陈伏

### 熟化成石灰膏(砌墙、抹灰用)

```
1. 熟化池: 挖坑用砖石砌壁,或用铁桶、旧铁锅
   ✗ 不要用塑料桶、塑料盆: 温度可接近100°C,塑料会变软、开裂
2. 先放水,再分批放入生石灰块,水量约为生石灰重量的3-4倍
   ✗ 不要往一大堆灰上浇少量水,会局部沸腾飞溅
3. 用长柄木耙搅动,人站远、偏开脸: 会冒热汽、沸腾、溅浆
4. 用筛子或竹帘滤去没化开的石渣,流进储灰池;浆面保持一层水隔绝空气
```

```
陈伏: 石灰膏在池里泡着放一段时间再用
- 砌筑用至少2周,抹灰、刷墙用至少1个月;越久越好
- 原因: 过烧的颗粒熟化很慢,没化开就上墙,会在墙里吸水膨胀,
  把灰面顶出小坑、鼓包和裂缝("爆灰");陈伏让它们在池里化完
```

### 消石灰粉(撒地、消毒、改土用)

```
1. 生石灰块摊成薄层,边翻边少量洒水(每100 kg 生石灰约用水40-60 L)
2. 灰块发热、开裂,化成干粉后过筛
⚠️ 粉尘很大,戴护目镜和口罩,在上风处操作
✓ 消石灰粉也会吸收 CO₂ 慢慢失效,用多少化多少,装袋防潮
```

## 石灰砂浆和三合土

### 石灰砂浆

```
配比(体积): 石灰膏 : 砂 ≈ 1 : 3
- 砂用干净的河沙,海沙要淡水洗去盐分;拌到铲起来能挂住不流淌
- 几天内用完,用前再翻拌;盖好别让它干

砌筑: 砖、石、土坯先浇水润湿;灰缝约1 cm,饱满不留空;上下错缝
抹灰: 底层 1 : 3 掺切碎的麻丝、稻草("麻刀灰")防裂;面层砂少些(约1 : 1-2),
  薄抹压光;每层不超过约1 cm,上一层半干再抹;头几天保持潮湿,避免暴晒

⚠️ 局限: 强度低、硬化慢,适合1-2层的小房子;
  长期泡水、埋在湿土里的部位(墙基、水池、井壁)会泡软
  → 用石块干砌、水泥砂浆,或下面的水硬性灰浆
```

### 水硬性灰浆: 让石灰在潮湿处也能硬化

古罗马人把石灰和意大利波佐利一带的火山灰混在一起,做出了能在海水中硬化、两千年不坏的灰浆。原理是: 火山灰中的活性二氧化硅、氧化铝能和熟石灰反应,生成类似水泥的水化产物,**不需要空气中的 CO₂ 也能硬化**。

```
能起火山灰作用的材料:
✓ 天然火山灰、浮石粉(火山地区)
✓ 烧黏土粉: 黏土在约600-900°C烧过后磨细(陶窑、砖窑可以顺便烧)
✓ 碎砖、碎瓦、碎陶片磨成的细粉(烧得不太过火的红砖效果较好)
✓ 稻壳、秸秆烧成的白灰(含二氧化硅,效果因来源而异)

粗略配比(体积): 石灰膏 : 火山灰或碎砖粉 : 砂 ≈ 1 : 1 : 2
- 先少量试做: 抹在砖上,养护一周后泡进水里,不软不掉 → 可以用
- 养护期间要保持潮湿(和水泥一样)
用途: 墙基、水池、水窖内壁、井台、浴室、靠地面的墙脚
```

传统上还有一种**糯米灰浆**: 把糯米煮成稀浆拌进石灰砂浆里,明代的城墙、陵墓、海塘都用过,结构致密、耐久。不过它要消耗粮食,食物紧张时不要用。

### 三合土和灰土

```
三合土(传统): 石灰 + 黏土(或黄土)+ 砂(或碎石、碎砖),体积比约1 : 2 : 3,
  具体按土质调整
灰土: 消石灰粉 : 黏性土 ≈ 3 : 7(俗称"三七灰土")或 2 : 8

做法:
1. 土过筛,去掉草根、大石块
2. 和石灰拌匀,洒水到"手握成团,落地开花"(同夯土墙)
3. 分层铺,每层松铺约15-20 cm,夯实
4. 夯完不要马上泡水,保持潮湿、慢慢硬化,一两周后再承重

用途: 室内地面、晒场、墙基下的垫层、道路、水窖的底
✓ 比纯夯土耐水得多,不易起尘、不易长草
```

含水量判断和夯筑方法见[长期住所-夯土墙](05-长期住所.md#夯土墙),地基和墙基见[工程力学-地基](../09-进阶科学与工程/01-工程力学与材料.md#九地基)和[长期住所-好靴子: 墙基](05-长期住所.md#好靴子-墙基),砌筑要点见[工程力学-砌体墙](../09-进阶科学与工程/01-工程力学与材料.md#72-砌体墙)。

## 刷墙与消毒

### 白灰水刷墙

```
1. 陈伏好的石灰膏加水调成牛奶状稀浆(可加少量盐或胶水,不易掉粉)
2. 墙面扫净、洒水润湿
3. 用刷子或稻草把薄刷一层,干后再刷,共2-3遍;刷厚了会起皮掉粉

✓ 碱性,能杀灭墙面部分病菌、霉菌,虫子不爱藏身
✓ 白色反光,屋里更亮,外墙夏天不那么热;便宜,每年可重刷
```

### 畜圈、厕所消毒

```
石灰乳: 熟石灰1 kg 加水4-9 L(约10-20%),搅匀,现配现用
✓ 刷畜圈、禽舍的墙面和地面,先清扫粪便垃圾再刷,效果才好
✓ 圈舍门口的消毒池、消毒垫
✓ 旱厕: 每次如厕后撒一把草木灰、干土或少量石灰粉,减少臭味和苍蝇
✓ 病死动物深埋时,尸体上撒生石灰再覆土

⚠️ 干石灰粉撒在干燥地面上消毒作用很弱,而且放久了会失效,
   潮湿的石灰乳刷上去才有用
⚠️ 人的遗体不需要撒石灰,见灾后遗体处理
```

旱厕见[卫生设施-旱厕](03-卫生设施.md#旱厕),病死动物见[卫生设施-病死动物处理](03-卫生设施.md#病死动物处理),人的遗体见[灾后遗体处理](../02-灾难应对/07-灾后遗体处理.md)。

## 农业和其他用途

### 改良酸性土

我国南方的红壤、黄壤多偏酸,很多作物长不好。石灰能中和酸性、补充钙,还能让黏重土壤变得松散一些。

```
1. 先测土: 加水搅拌,用紫甘蓝汁或试纸测酸碱性(见地质矿物与土壤-酸碱性)
   - 不酸的土不要撒石灰,碱性土撒了更糟
2. 用量(数量级): 熟石灰约750-1500 kg/ha,酸性重、黏土多的取高值
   - 宁少勿多,一次不要撒太多,隔2-3年再测再撒
   - 生石灰效果更猛,用量减少约四分之一,而且容易烧苗,一般用熟石灰
3. 时间: 在整地时撒开、和土翻匀,过1-2周后再播种、栽苗
4. 和肥料错开:
   ✗ 不要和铵态氮肥(碳铵、硫铵)、尿素、人粪尿、厩肥同时施,
     石灰会让其中的氮变成氨气跑掉,还会把肥"烧"掉
   → 先撒石灰,间隔约1-2周再施粪肥和氮肥
```

石灰硫磺合剂(石灰和硫磺加水熬煮)是传统的果树杀菌杀虫剂,熬制和使用浓度请按专业资料,本书不展开。

## 石膏

石膏是另一种"烧了能再凝固"的矿物。它比石灰硬化快得多,几分钟到半小时就凝固,但不耐水。

```
原料: 生石膏(二水硫酸钙 CaSO₄·2H₂O),白色或灰白,指甲能划出痕迹,
  滴醋不冒泡;常见于干旱地区、盐湖边、沉积岩层中

烧石膏:
1. 敲碎、磨成粉,在铁锅里小火炒,约150°C左右(远低于烧石灰)
2. 粉会"沸腾"般冒出水汽,冒汽基本停止就停火
   → 得到熟石膏(半水石膏),装罐密封防潮
   ⚠️ 温度过高(几百°C)或炒得太久会"死烧",加水后凝固很慢或不凝固

使用: 石膏粉 : 水 约 3 : 2(重量),调成糊几分钟内用完;
  凝固时发热、略微膨胀,能精确复制模子的细节;只能用在干燥处

用途:
✓ 模具: 铸造用的模型、陶器的注浆模(石膏吸水)
✓ 室内抹灰、做线脚和装饰,比石灰快得多
✓ 点豆腐(用食品级的熟石膏,少量)
✓ 黑板粉笔

⚠️ 固定骨折: 医院打石膏是专业操作,
  缠得太紧会压迫血管神经导致肢体坏死,而且大量石膏凝固发热可能烫伤;
  急救和没有医生时优先用夹板固定,并定时检查手指脚趾的血液循环
```

骨折固定见[骨骼损伤-固定](../01-日常疾病和伤害/03-骨骼损伤.md#4-固定),点豆腐见[食物加工与保存-豆腐](01-食物加工与保存.md#豆腐)。

## 水泥和混凝土: 先回收

自己烧水泥需要约1450°C和精确配料,小社区很难做好(原理见[化学-水泥和玻璃](../08-基础科学知识/03-化学.md#49-水泥和玻璃))。最现实的是**回收废墟、仓库、工地里现成的水泥**。

```
回收的袋装水泥:
✓ 能用: 粉末松散,或只有手捏得开的小团(过筛后使用)
✗ 不能用: 结成手捏不碎的硬块 → 已受潮水化,失去胶结能力,砸碎只能当骨料
- 受潮程度不明的,只用在地面、垫层,不做梁和楼板
- 放置越久强度越低;储存时离地、离墙,盖严防潮

水泥有限时优先保证: 井台井壁、水池水窖的防渗 → 墙基、防潮层
  → 厕所防渗地面 → 过梁、圈梁等关键受力部位
  普通墙体用石灰砂浆、土坯就够了

再生骨料(碎混凝土、碎砖):
1. 砸碎(当石子用约2-4 cm,更细的当砂),拣出钢筋、木头、塑料、石膏板
2. 冲洗掉泥土粉尘;碎砖吸水多,拌混凝土前先浇水润湿
✓ 适合地面垫层、基础、非承重墙、路面;重要受力结构尽量用天然碎石和砂

⚠️ 拆废墟要注意:
- 老房子的石棉瓦、管道保温层可能含石棉: 不要砸碎、不要干扫,
  洒水润湿后整块移走,戴口罩
- 敲碎混凝土和砖的粉尘伤肺: 洒水降尘,戴口罩和护目镜
- 危房先看结构,不要在随时可能再塌的建筑里拆料
```

混凝土配合比和养护见[工程力学与材料-混凝土](../09-进阶科学与工程/01-工程力学与材料.md#106-混凝土),拱和过梁见[工程力学与材料-拱](../09-进阶科学与工程/01-工程力学与材料.md#71-拱)。

## 📝 石灰与建筑材料要点

```
1. 石灰的循环: 石灰石约900°C烧成生石灰 → 加水熟化成熟石灰 → 吸收 CO₂ 又变回石头
2. 原料滴醋冒泡才能烧石灰;烧透的石灰变轻(纯的减重约44%)、没有硬芯、遇水剧烈发热
3. 生石灰溅到身上先刷去再冲水;处理时戴护目镜手套;不用塑料桶熟化
4. 石灰窑有一氧化碳和坍塌的危险,人不进窑、不上窑顶,只用长杆操作
5. 石灰膏要陈伏: 砌墙至少2周,抹灰至少1个月,否则墙面"爆灰"
6. 石灰砂浆约1 : 3;潮湿处加烧黏土粉、碎砖粉或火山灰做成水硬性灰浆
7. 三合土、灰土分层夯实,做地面和墙基垫层
8. 石灰乳刷畜圈、厕所、墙面;改良酸性土要先测、少量、和粪肥氮肥错开
9. 石膏约150°C炒成熟石膏,几分钟凝固,做模具和抹灰,不耐水
10. 回收的水泥结硬块就不能用;有限的水泥优先给井、水池、墙基和关键受力处
```
