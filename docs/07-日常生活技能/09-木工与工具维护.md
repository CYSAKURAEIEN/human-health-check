## 为什么要学

在物资短缺、长期自给自足的情况下,桌椅、门窗、农具柄、鸡舍、篱笆坏了都只能自己修。**会修比会造更有用**: 大多数木工活是修理,而不是从头做家具。

```
优先顺序:
1. 保养好现有的工具(生锈、钝了的工具效率低还危险)
2. 学会修: 换工具柄、加固松动的桌椅、修门窗
3. 学会做简单的东西: 木箱、板凳、架子、篱笆
4. 再学更复杂的榫卯结构
```

## 工具储备

```
基本工具(优先储备):
- [ ] 锯: 一把通用的木工锯(手板锯),一把细齿锯
- [ ] 锤子: 羊角锤(能拔钉子)
- [ ] 凿子: 宽窄各一两把
- [ ] 刨子: 一把中等长度的刨子
- [ ] 斧头
- [ ] 手钻或手摇钻,配不同粗细的钻头
- [ ] 卷尺、角尺、铅笔、墨斗或粉线
- [ ] 螺丝刀(一字、十字各几把)
- [ ] 钳子、老虎钳
- [ ] 磨刀石(粗、细各一块)
- [ ] 夹具(F夹或木工夹,两个以上)

耗材:
- [ ] 各种规格的钉子、螺丝
- [ ] 木工胶(白乳胶)
- [ ] 砂纸(粗细几种)
- [ ] 防锈油、机油

手动工具不依赖电力,能用几十年,是长期储备的好选择。
```

如果工具损坏又无法购买,打制工具的方法见[简易工具锻造](../05-冶金技术/03-简易工具锻造.md)。

## 安全

```
✓ 刀具、凿子永远向外推,手放在刀口的后方,不要放在前方
✓ 工件用夹具或台钳夹牢,不要一手拿工件一手用凿子
✓ 锯、刨、凿保持锋利: 钝的工具要用更大力气,更容易打滑伤人
✓ 劈柴、敲打时戴护目镜(木屑、铁屑飞溅)
✓ 打磨、锯木时戴口罩(木屑粉尘),有条件时开窗或在室外
✓ 用斧头时周围清场,斧头挥动的范围内不能有人
✓ 工具用完收好,刃口朝下或套上护套,不要乱放在地上

❌ 不要穿宽松的袖子、戴手套操作电钻、电锯等旋转工具(容易被卷进去)
❌ 不要用手接住滑落的刀具、凿子
⚠️ 用过防腐剂、油漆处理过的旧木料,不要当柴烧(会产生有毒烟气)
```

割伤的处理见[外伤处理-割伤与擦伤](../01-日常疾病和伤害/02-外伤处理.md#割伤与擦伤)。

## 木材

### 常见木材的特点

| 木材 | 特点 | 适合用途 |
|------|------|----------|
| 杉木、松木 | 轻、软、易加工、便宜 | 房屋结构、箱子、架子、篱笆 |
| 槐木、榆木、柞木 | 硬、韧、结实 | 工具柄、农具、桌椅腿 |
| 白蜡木、山核桃木 | 韧性非常好,不易断 | 斧柄、锤柄、锄柄 |
| 竹子 | 轻、韧、生长快 | 篱笆、架子、简易家具、编织 |

### 干燥

**刚砍下的湿木头不能直接用来做家具和工具柄**: 干燥过程中会收缩、开裂、变形。

```
自然干燥(晾干):
1. 去掉树皮(防虫)
2. 锯成板材或木段,两端涂上油漆、蜡或泥(防止端头开裂)
3. 放在通风、遮雨、不直晒的地方
4. 每层木料之间垫上小木条,让空气流通
5. 一般每2.5 cm(1英寸)厚度需要约一年

✓ 急用时,可以先用干透的旧木料(拆旧家具、旧门窗)
✓ 新砍的木头可以先劈成小块当柴火晾干
```

木材在房屋结构中的使用见[长期住所-简易木结构](05-长期住所.md#简易木结构)。

## 基本操作

### 量和画线

```
✓ "量两次,锯一次"
✓ 用角尺画直角线,用墨斗或粉线弹长直线
✓ 在线的废料一侧锯(锯缝本身有宽度)
```

### 锯

```
1. 用拇指靠住锯片,轻轻往回拉几下,锯出一条小口
2. 拉开锯口后,用较长的行程、均匀的力往复锯
3. 不要用力往下压,让锯齿自己切削
4. 快锯断时放慢,托住要断的一端,防止木料撕裂
```

### 钉钉子

```
✓ 钉子长度约为上面那块木板厚度的2.5-3倍
✓ 靠近木板端头钉时容易劈裂: 先用细钻头钻个小引孔
✓ 斜着交叉钉比直着钉更结实
✓ 拔钉子时在羊角锤下面垫一块木片,保护木料表面
```

### 螺丝

```
✓ 硬木上拧螺丝要先钻引孔(比螺丝细一点)
✓ 螺丝比钉子结实,能拆卸,适合需要承力或以后要拆的地方
```

## 连接方法

| 方法 | 难度 | 特点 |
|------|------|------|
| 钉子 | ⭐ | 最快;不太结实,木料干缩后容易松 |
| 螺丝 | ⭐ | 比钉子结实,可拆卸 |
| 螺栓 | ⭐ | 最结实,适合承重的地方(如棚子、门) |
| 胶 + 钉/螺丝 | ⭐⭐ | 胶粘的面要贴紧;夹紧干透后再用 |
| 绑扎 | ⭐ | 不需要钉子;适合竹子、圆木、临时结构 |
| 榫卯 | ⭐⭐⭐ | 不用钉子也很结实;需要练习 |

### 简单的榫卯: 直角榫

```
用于桌椅腿和横档的连接:
1. 在横档的一端画出榫头(厚度约为木料厚度的1/3)
2. 锯掉两侧多余的部分,做成榫头
3. 在腿上对应位置画出卯眼,用钻头先钻掉大部分,再用凿子修方
4. 先试插,紧了就修榫头,不要用锤子硬砸(会把卯眼撑裂)
5. 抹胶后敲入,用夹具夹紧,干透后再受力

✓ 先在废木料上练习几次
```

绑扎用的绳结见[基础生存技能-绳索](../03-野外生存/00-基础生存技能.md#绳索)。

## 常见的修理活

### 换工具柄(斧、锤、锄)

```
1. 拆掉旧柄: 把断柄锯掉,剩下的部分从楔子一侧钻孔、敲出
2. 选木料: 干透的硬木,木纹顺着柄的长度方向,不能有疤节、裂纹
3. 削柄: 先粗削,再一边试一边削,让柄头刚好能紧紧敲进工具的孔里
4. 安装:
   - 把柄头敲进孔,露出孔外一点
   - 在柄头顶端顺着锯一道口(深约孔深的2/3)
   - 往锯口里敲进一个硬木楔子(可以抹点胶),把柄头撑紧
   - 锯平露出的部分
5. 检查: 甩一甩、敲一敲,不能有任何松动

⚠️ 斧头、锤头松动时立即停用修理,飞出去会伤人
❌ 不要把干燥的工具柄泡在水里"让它胀紧": 干了以后会更松
```

### 桌椅摇晃

```
✓ 找到松动的接头,拆开后清掉旧胶,重新上胶夹紧
✓ 不能拆开的: 在接头处加三角形的木块或金属角码,用螺丝固定
✓ 四条腿不一样长: 在最长的腿下面垫,或把长腿锯短一点(一次只锯一点)
```

### 门窗

```
门关不严、下垂:
✓ 先拧紧合页上的螺丝
✓ 螺丝孔滑丝了: 往孔里塞几根抹了胶的牙签或小木条,干后重新拧螺丝

抽屉、门窗推拉发涩:
✓ 在滑动的地方抹蜡烛蜡或肥皂
✓ 仍然发涩时,刨掉一点摩擦的地方
```

## 磨刀

刀、斧、凿、刨刀都要定期磨。**钝了立即磨,越钝越难磨。**

```
磨刀石:
✓ 先用粗磨石磨出锋口,再用细磨石磨光
✓ 磨石使用前泡水(油石用油),磨的过程中保持湿润
✓ 磨石放稳,下面垫湿布防滑

磨法:
1. 找准刃口原来的角度,让刃口斜面平贴在磨石上
2. 保持这个角度不变,来回推磨(角度忽高忽低会把刃口磨圆)
3. 磨到刃口背面摸到一条细小的卷边(毛刺)
4. 翻过来,把背面平贴磨石轻磨几下,去掉卷边
5. 细磨石上重复,磨得更光

常见角度(参考):
- 菜刀、小刀: 刃口斜面与刀面约15-20°
- 凿子、刨刀: 斜面约25-30°
- 斧头: 劈柴的斧头角度大一些(更钝更厚),砍树的斧头角度小一些

✓ 磨石用久了中间会凹下去,在平整的水泥地上加水和沙子磨平
✓ 没有磨石时: 平整的细砂岩、粗陶缸的缸底沿也能凑合用
```

磨刀与锻造工具的保养见[简易工具锻造-工具保养](../05-冶金技术/03-简易工具锻造.md#十工具保养)。

## 工具保养

```
防锈:
✓ 用完擦掉木屑、泥土和水汽
✓ 金属部分抹一层薄油(机油、缝纫机油、植物油都可以)
✓ 放在干燥的地方,不要直接放在泥地、水泥地上
✓ 已经生锈的: 用钢丝刷或砂纸除锈后上油

木柄:
✓ 定期抹一层熟桐油或亚麻籽油,防止干裂
✓ 柄出现裂纹立即更换,不要用胶布缠着继续用

收纳:
✓ 挂在墙上或放在工具箱里,刃口有保护套
✓ 锯片涂油,挂起来防止弯曲

农具:
✓ 每季用完清洗、晾干、上油,入库保存
✓ 下一季开始前检查柄和刃口,提前修好
```

## 📝 木工与工具维护要点

```
1. 手动工具不依赖电力,能用几十年,值得储备
2. 刀具向外推,工件夹牢,保持锋利;锯木打磨戴口罩
3. 湿木头要晾干才能做家具和工具柄,每2.5 cm厚约一年
4. 钉子长度约为上层木板厚度的2.5-3倍;硬木先钻引孔
5. 换斧柄: 木纹顺直的干透硬木,敲紧后打木楔;松动立即停用
6. 磨刀保持角度不变,磨出毛刺再翻面去掉
7. 工具用完擦干上油,木柄定期上油
```
