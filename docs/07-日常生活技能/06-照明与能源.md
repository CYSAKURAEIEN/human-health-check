## 停电时的应急照明

### 优先用电池灯,而不是蜡烛

停电期间是蜡烛引发火灾的高发时段: 人在黑暗中走动、睡着、照顾孩子,很容易碰倒或忘记熄灭。

```
首选:
✓ LED手电筒、头灯(头灯可以腾出双手)
✓ LED营地灯(照亮整个房间)
✓ 手摇或太阳能充电的灯
✓ 备足电池,定期检查(电池长期放在设备里可能漏液腐蚀,储存时取出)

其次: 油灯、蜡烛(遵守下方安全规则)
```

### 使用明火照明的安全规则

```
✓ 放在稳固、不易燃的底座上(盘子、铁盒),四周留出空间
✓ 远离窗帘、被褥、纸张、衣物
✓ 远离儿童和宠物能碰到的地方
✓ 人离开房间、睡觉前必须熄灭
✓ 不要拿着蜡烛找东西(尤其是翻柜子、床底)
✓ 不要用明火检查燃气泄漏、查看油箱
✓ 房间里有燃气味时,绝不点火
```

## 自制油灯

最简单的照明方法,所需材料几乎家家都有。

### 碟子油灯

```
材料:
- 不易燃的浅容器: 瓷碟、小碗、罐头盒
- 灯油: 食用植物油(菜籽油、花生油、用过的炸油)、动物油(猪油、牛油,化开后用)
- 灯芯: 纯棉线、棉布条(搓成条)、棉绳

做法:
1. 容器中倒入约1-2厘米深的油
2. 灯芯一端浸在油中,另一端露出油面约0.5厘米
   - 可用一小片铁皮(罐头盖)卷一个小管或折一个支架,把灯芯立住
3. 点燃露出的一端
4. 火苗太大、冒黑烟 → 把灯芯往下拉短一点

一碟油可以点几个小时,亮度相当于一支小蜡烛
```

### ❌ 绝对不要用作灯油

```
❌ 汽油: 挥发出的油气遇火会爆燃,极易造成严重烧伤和火灾
❌ 酒精: 火焰在白天几乎看不见,易被误碰;容易泼洒蔓延
❌ 柴油、机油: 燃烧冒浓烟、有毒,不适合在室内照明
❌ 来历不明的工业用油、废油
```

**煤油**: 只能用于专门设计的煤油灯,并且只在通风处使用。

## 自制蜡烛

### 原料

```
✓ 蜂蜡: 燃烧干净、烟少、味道好(养蜂时可从蜂巢收集)
✓ 动物脂肪(牛油、羊油最好): 需要先熬炼提纯,燃烧时有一些气味
✓ 回收的蜡烛头、蜡块
✓ 灯芯: 纯棉线搓成或编成辫状;用前在融化的蜡里浸一下晾干
```

### 熬炼动物脂肪

```
1. 生脂肪切成小块,加少量水,小火慢熬
2. 油全部熬出后,用纱布过滤掉油渣
3. 加等量清水再煮一次,冷却
4. 上层凝固的就是较纯净的脂肪,刮下底部的杂质
```

### 浸蘸法(不需要模具)

```
1. 隔水加热融化蜡或脂肪(把装蜡的罐子放在热水锅里,不要直接放在火上)
2. 拿住灯芯一端,浸入融化的蜡中,提起,稍微冷却
3. 反复浸蘸,一层层加厚,直到需要的粗细
4. 挂起晾干,剪平底部
```

### 模具法

```
1. 用竹筒、纸筒、罐头盒等做模具
2. 灯芯固定在中央(上端绑在横放的筷子上,下端从底部小孔穿出或压住)
3. 倒入融化的蜡,冷却后脱模
```

### ⚠️ 安全

```
✓ 一定要隔水加热,蜡和油直接加热温度过高会自燃
✓ 旁边准备一个锅盖
❌ 蜡油或油锅起火时绝不能用水浇!(会爆溅,火势急剧扩大)
   → 关火,盖上锅盖隔绝空气;或用湿毛巾、沙土覆盖
✓ 儿童远离操作区域
```

## 燃料的安全储存

### 木柴

```
✓ 砍下后劈开,堆放晾干至少6个月到1年
  - 干柴: 两块相敲声音清脆,两端有放射状裂纹,重量明显变轻
  - 湿柴: 烟大、热量低、在烟囱里积焦油,容易引发烟囱火
✓ 堆放在通风、防雨处: 上方遮盖,下方垫离地面,四周通风
✓ 柴堆离房屋墙壁一段距离(防火、防白蚁和蛇鼠藏身)
✓ 室内只放当天要烧的量
```

烟囱和炉灶的安全见[长期住所-烟囱](05-长期住所.md#烟囱-防火与防一氧化碳)。

### 木炭

- 木炭燃烧会产生大量一氧化碳,**绝不能在门窗紧闭的室内使用**
- 制作方法见[冶金技术-木炭制作](../05-冶金技术/00-基础冶金知识.md#32-木炭制作闷烧法)
- 储存在干燥处,远离火源;新烧好的木炭要确认完全熄灭冷却再收起(可能复燃)

### 汽油

```
✓ 只用专门的汽油桶(金属或专用塑料桶)
✓ 存放在室外通风、阴凉、远离火源的地方(如单独的棚子)
✓ 存量越少越好
✓ 一般储存3-6个月,添加燃油稳定剂可延长
✓ 定期轮换使用(先进先出)

❌ 不要放在居室、卧室、地下室、车内
❌ 不要用饮料瓶、矿泉水瓶装汽油(会被误饮;普通塑料会被腐蚀渗漏)
❌ 加油、倒油时附近不能有明火、不要吸烟、不要打手机
❌ 不要在发动机运转或高温时加油
```

### 液化气钢瓶

```
✓ 直立放置,不要倒置、横放
✓ 放在通风良好的地方,远离热源和明火
✓ 不要暴晒,不要用热水烫、用火烤钢瓶(会使瓶内压力升高)
✓ 定期用肥皂水涂抹接口、减压阀、软管检查是否漏气(起泡就是漏)
✓ 软管老化、开裂及时更换
✓ 用完关紧钢瓶角阀

❌ 不要放在地下室、卧室、楼梯间、密闭柜子里
   (液化气比空气重,泄漏后会沉积在低处)
❌ 不要自行倒灌、倒残液
```

闻到燃气味时的处理见[燃气泄漏](../02-灾难应对/04-火灾.md#燃气泄漏)。

### 煤油、柴油、酒精

- 原装容器或专用容器,标签清楚
- 远离火源、远离儿童
- 酒精挥发快、易燃,用后盖紧

## 发电机

```
✓ 只在室外使用,远离门、窗、通风口(至少数米)
  - 发电机尾气含大量一氧化碳,在车库、地下室、阳台、门口使用都可能致命
✓ 加油前先关机,等发动机冷却
✓ 下雨时用遮棚保护,不要让发电机受潮(触电)
✓ 用合格的户外延长线,直接给电器供电

❌ 不要把发电机直接接到家里的电线插座或配电箱上"反送电"
   - 电会沿线路倒送到外部电网,可能电死正在抢修线路的电工
   - 如需接入家庭线路,必须由电工安装专用的切换开关
```

一氧化碳中毒的识别与救助见[一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

## 小型太阳能

长期停电时,一套小型太阳能系统足以保障照明、手机、收音机等基本用电。

### 组成

```
太阳能板 → 充电控制器 → 蓄电池 → (逆变器) → 用电器

- 太阳能板: 把阳光转成电
- 充电控制器: 防止电池过充过放(不可省略)
- 蓄电池: 储存电能,夜间使用
- 逆变器: 把直流电变成220V交流电(只用直流电器时可不用)

最简单的: 自带电池的太阳能灯、太阳能充电宝
```

### 安装和使用

```
✓ 朝向: 北半球朝正南
✓ 倾角: 大约等于当地纬度(冬季可再调陡一些)
✓ 避开树木、建筑的阴影(部分遮挡会使发电量大幅下降)
✓ 定期擦去板面灰尘、积雪、落叶
✓ 优先用于低耗电设备: LED灯、手机、收音机、小风扇
  ❌ 不适合电热水壶、电饭锅、电暖器等大功率电器
✓ 阴雨天发电很少,电池电量要省着用
```

### 蓄电池安全

```
铅酸电池:
✓ 放在通风处(充电时会产生氢气,积聚遇火花会爆炸)
✓ 电池液是硫酸,沾到皮肤眼睛立即用大量清水冲洗
✓ 不要让正负极短路(金属工具搭在两极会产生火花、烧伤)

锂电池(充电宝、新型储能电池):
✓ 用配套的充电器和控制器
✓ 鼓包、发热、变形、漏液 → 立即停用,放到室外远离可燃物的地方
✓ 不要挤压、刺穿,不要放在暴晒的车内
❌ 锂电池起火不要靠近,撤离并拨打119
```

## 沼气

沼气池把人畜粪便、秸秆在密闭池内发酵,产生可燃的沼气(主要是甲烷),可以做饭、照明,剩下的沼渣沼液是好肥料。

### ⚠️ 沼气池的危险: 每年都有人因此死亡

```
1. 窒息和中毒
   - 池内几乎没有氧气,还有剧毒的硫化氢
   - 人下到池内几分钟就会昏倒、死亡
   - 最惨痛的情况: 一人下池昏倒,家人接连下去救,接连遇难

2. 爆炸
   - 甲烷在空气中浓度达到约5%-15%时,遇明火会爆炸
   - 沼气池周围、出料口、密闭的厨房都可能达到这个浓度
```

### 安全规则

```
❌ 绝对不要下池!
   - 出料、清渣使用池外的抽渣器、长柄工具
   - 确需进池维修,必须由专业人员按规程操作:
     打开所有盖口长时间通风、用仪器检测气体、系安全绳、池外有人监护
❌ 不要在沼气池口、出料口、导气管附近点火、吸烟
   - 不要用明火去"试一试有没有气"(只在灶具处点火)
✓ 定期用肥皂水检查导气管、开关、接口是否漏气
✓ 沼气池的进料口、出料口、水压间要加盖盖严
   - 防止儿童、牲畜掉入
✓ 使用沼气灶、沼气灯的房间要通风
✓ 闻到沼气味(臭鸡蛋味)时: 关闭开关,开窗通风,不要开关电器、不要点火

有人在池内昏倒:
1. ❌ 不要直接下去救!
2. 立即拨打120、119
3. 打开所有盖口,用鼓风机、风扇往池内吹新鲜空气
4. 只有在系好安全绳、有专业防护(呼吸器)、有人在上面拉绳的情况下,才能下池救人
```

### 沼渣沼液的利用

- 发酵后的沼渣沼液是优质肥料,病原体和寄生虫卵明显减少
- 但人粪尿来源的沼渣,用于生吃的蔬菜前仍应谨慎,参照[卫生设施-粪便与尿液的利用](03-卫生设施.md#粪便与尿液的利用)

**沼气池的建造需要专业设计和施工**(池体密封、压力、防渗),建议请有资质的施工队按当地农村能源部门的标准建造,不要自行挖坑凑合。

## 节约能源

```
取暖:
✓ 全家集中在一个房间取暖(选朝南、小一些的房间)
✓ 白天开窗帘让阳光进来,晚上拉上厚窗帘保温
✓ 多穿衣、睡觉用厚被褥和暖水袋,比烧火取暖省得多
✓ 保暖的同时保持通风

做饭:
✓ 盖锅盖煮
✓ 先浸泡豆子、米,缩短煮的时间
✓ 焖烧: 煮沸后把锅放进厚被褥或稻草筐里保温,利用余热焖熟
✓ 省柴灶比敞口灶省柴、烟少

照明:
✓ 日出而作,充分利用白天
✓ 一盏灯集中照明,大家围在一起
```

保温与通风的平衡见[长期住所-保温](05-长期住所.md#保温),省柴灶见[长期住所-火炕与炉灶](05-长期住所.md#火炕与炉灶)。

## 📝 照明与能源要点

```
1. 停电照明优先用LED电池灯,明火照明要有人看着、睡前熄灭
2. 油灯用食用油或动物油,绝不用汽油、酒精
3. 熬蜡隔水加热,油锅起火盖锅盖,绝不浇水
4. 木柴晾干半年以上;木炭、发电机绝不在室内使用
5. 汽油不进屋、不用饮料瓶;液化气钢瓶直立、不放地下室
6. 发电机不能反送电接入家庭线路
7. 太阳能: 朝南、倾角约等于纬度,必须用充电控制器
8. 沼气池绝不下池;有人在池内昏倒不要直接下去救
```
