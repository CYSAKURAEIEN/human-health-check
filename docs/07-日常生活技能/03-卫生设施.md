## 为什么这一章很重要

灾后和长期断水断电时,大量病患和死亡并非来自灾害本身,而是来自**粪便污染饮水和食物**引起的传染病:

```
霍乱、痢疾、伤寒、甲型肝炎、各种腹泻、蛔虫等寄生虫

传播途径: 粪便 → 水 / 手 / 苍蝇 / 食物 → 口
```

阻断这条途径只需要三件事: **把粪便和水源、食物隔开;饭前便后洗手;消灭苍蝇**。

这是性价比最高的公共卫生措施,比任何药物储备都能挽救更多生命。

## 应急厕所

适用于停水后的室内,或刚开始避难的头几天。

### 双桶法

```
材料: 两个带盖的桶、垃圾袋、覆盖物

1. 桶内套双层垃圾袋
2. 一个桶接大便,一个桶接尿液(分开能大幅减少臭味和体积)
   - 尿液可定期倒入远离水源的土坑
3. 每次便后撒一把覆盖物盖住:
   - 草木灰(最好,碱性可抑菌除臭)
   - 干土、锯末、碎干草、生石灰(少量)
4. 盖紧桶盖
5. 装到约2/3时扎紧袋口,移到下方旱厕或深埋处

⚠️ 停水时不要继续用抽水马桶,堵塞和倒灌会更难处理
⚠️ 用后洗手(见下文洗手点)
```

### 浅坑(野外、短期)

```
1. 选址同下方旱厕(远离水源至少30 m)
2. 挖坑深15-20 cm
3. 便后回填土
4. 用完一个换一个地方
```

## 旱厕

长期使用时建造。

### 选址(最关键)

```
✓ 距离水井、泉水、溪流、池塘至少30 m
✓ 位于水源的下坡方向(地势较低处)
✓ 坑底至少高于地下水位1.5 m
  - 判断: 挖坑时坑底出现渗水 → 离地下水太近,换地方或改为浅坑加覆盖
✓ 距住所和厨房有一定距离,但不要远到夜间不敢去(儿童、老人)
✓ 避开会积水、被洪水淹没的低洼地

⚠️ 岩石裂隙多、砂砾土的地区,污染会走得更远,应加大距离
```

### 建造

```
1. 挖坑: 宽约1 m,深1.5-2 m(视地下水位)
2. 坑口加固: 木头、石块或砖围边,防止塌方
3. 蹲板: 结实的木板或水泥板,留蹲口
4. 加盖: 蹲口要有盖子(防蝇的关键)
5. 通风管(可选): 竖一根管子从坑内通出顶棚,管口罩纱网
   - 臭气从管子排出,苍蝇被管口亮光吸引后被纱网困住
6. 遮挡: 四周和顶棚遮挡,保证隐私和防雨
7. 旁边放一桶草木灰或干土和一把勺子
```

### 使用和维护

```
✓ 便后撒一勺草木灰或干土
✓ 盖好蹲口盖子
✓ 每天检查、清理蹲板
✓ 坑满到距地面约50 cm时: 用土填满压实,另挖新坑
✓ 填满的旧坑做好标记,至少1-2年内不要挖开
```

社区供水、挖井、净水见[水源工程与供水](10-水源工程与供水.md)。

## 洗手点

**厕所旁必须有洗手的地方。** 没有洗手条件,厕所的作用会大打折扣。

### 简易洗手器

```
做法: 塑料桶或大瓶子,底部侧面开小孔,插一根带开关的管子或用木塞堵住;
     或把瓶子挂起来,用脚踩绳子让瓶子倾斜出水(手不碰容器)

放置: 厕所出口、厨房门口
旁边: 肥皂,或一罐草木灰
```

### 怎么洗

```
1. 打湿双手
2. 抹肥皂(或草木灰),手心、手背、指缝、指尖、拇指、手腕都搓到
3. 至少搓20秒
4. 流水冲净
5. 甩干或晾干(不要用脏毛巾擦)
```

**没有肥皂时**: 用草木灰搓洗,或者只用流水认真搓洗20秒,都比不洗好得多。不要用泥土代替(泥土本身可能被粪便污染)。

自制肥皂见[制皂](04-制皂.md)。

### 必须洗手的时刻

- 便后、给婴儿换尿布后
- 做饭前、吃饭前、喂孩子前
- 照顾病人前后
- 处理生肉、垃圾、动物后

## 粪便与尿液的利用

人的粪尿是好肥料,但**处理不当就是在给自己种寄生虫和痢疾**。

### 尿液(相对安全)

```
✓ 健康人的新鲜尿液病原体很少
✓ 用前加水稀释5-10倍(原液会烧苗)
✓ 浇在土壤上,不要浇在叶子上
✓ 最好单独收集、密封储存1个月以上再用
✓ 用于粮食作物、果树最稳妥;叶菜收获前1个月停用
```

### 粪便(必须长时间储存)

```
根据世界卫生组织关于安全利用排泄物的指南:
- 气温在20°C以下的地区: 储存1.5-2年
- 气温更高的地区: 储存至少1年
- 储存后可杀灭大部分细菌,大幅减少病毒和寄生虫卵(蛔虫卵最顽强)

做法:
1. 旱厕坑填满后封存,或另设堆肥箱
2. 期间不要翻开、不要使用
3. 到期后外观应像深色泥土、无臭味
4. 优先用于果树、粮食作物,施于土中并覆盖

❌ 绝对不要把新鲜粪便直接浇菜
❌ 不要用于生吃的蔬菜(生菜、黄瓜等)
❌ 腹泻流行期间的粪便更要严格隔离
```

动物粪便的利用见[动植物培育-土壤改良](../04-动植物培育/README.md#土壤改良)。

## 垃圾处理

### 分类

| 类型 | 处理 |
|------|------|
| 厨余(菜叶、果皮、剩饭) | 喂鸡鸭猪(⚠️ 不要喂泔水给猪,见[家畜养殖](../04-动植物培育/06-家畜养殖.md));或堆肥 |
| 可燃物(纸、木、干草) | 引火、燃料 |
| 塑料 | 尽量清洗后回收再利用;❌ 不要在住处附近焚烧(烟有毒) |
| 金属、玻璃 | 收集再利用(金属可回炉,见[冶金技术](../05-冶金技术/README.md)) |
| 其他不可利用的 | 深埋 |

### 填埋坑

```
✓ 选址同旱厕: 远离水源至少30 m,在下坡方向
✓ 每次倒入后盖一层土(防蝇、防鼠、防野狗刨)
✓ 坑满后盖土至少30 cm压实
❌ 不要倒在溪流、河边、水井附近
```

### 消灭苍蝇和老鼠

```
✓ 厕所加盖,便后覆灰
✓ 垃圾及时掩埋,不要露天堆放
✓ 厨房食物加盖
✓ 积水容器倒空(同时防蚊)
✓ 粮食用缸、铁桶密封储存(防鼠)
```

## 病死动物处理

```
✓ 戴手套,不要徒手接触
✓ 深埋: 坑深至少1.5 m,远离水源,尸体上撒生石灰后再覆土
✓ 或焚烧(远离住房和林地)
❌ 不要食用病死的禽畜
❌ 不要抛入河流、水塘
⚠️ 短期内大量死亡(尤其是禽类、猪),上报当地畜牧兽医部门
   (可能是禽流感、非洲猪瘟等疫病)
```

人的遗体处理不同于病死动物,见[灾后遗体处理](../02-灾难应对/07-灾后遗体处理.md)。

## 📝 卫生要点

```
1. 厕所离水源至少30 m,在下坡方向
2. 便后撒草木灰、盖盖子
3. 厕所旁必须能洗手(没肥皂就用草木灰)
4. 尿液稀释可用;粪便至少储存1-2年再用,不浇生吃的菜
5. 垃圾分类,无用的远离水源深埋
6. 消灭苍蝇老鼠
```
