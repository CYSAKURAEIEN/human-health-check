## 先缝补,再谈纺织

现代衣物在长期断供时会逐渐磨损,但**从头纺线织布非常费工**: 传统上一个人纺够做一件衣服的线就要很多天。所以:

```
优先顺序:
1. 爱护现有衣物: 勤补、早补(小洞不补,大洞吃苦)
2. 旧衣改制: 大改小、长改短、破衣拆成补丁和布条
3. 回收: 旧毛衣拆线重织、旧布条编织
4. 最后才是从原料纺线织布
```

保暖穿衣的原则见[雪地极地求生-保暖](../03-野外生存/04-雪地极地求生.md#保暖-最关键)。

## 缝补

### 工具储备

```
- [ ] 各种粗细的手缝针(含粗针、弯针)
- [ ] 线: 涤纶线(结实)、棉线、粗的尼龙线(缝帆布、鞋)
- [ ] 顶针(保护手指,缝厚布时用来顶针)
- [ ] 剪刀
- [ ] 穿针器
- [ ] 锥子(给皮革、厚布打孔)
- [ ] 纽扣、拉链、松紧带
- [ ] 补丁布(收集旧衣服的完好部分)

这些东西便宜、轻、不过期,值得多备一些。
```

### 自制针线(没有储备时)

```
针:
- 骨针: 把动物骨头劈成细条,在石头上磨尖磨细,尾部用尖锐的石头或钉子钻孔
- 铁丝针: 一段细铁丝一端磨尖,另一端弯成小圈作针眼
- 不能钻孔时: 用锥子先扎孔,再把线穿过去

线:
- 植物纤维: 麻、棉,搓成线(见下方纺线)
- 动物筋腱: 晒干后撕成细丝,用前润湿,干后收紧,非常结实,适合缝皮革
- 拆旧衣物、旧编织袋获得的线
```

更多绳索制作方法见[基础生存技能-绳索](../03-野外生存/00-基础生存技能.md#绳索)。

### 基本针法

**穿针打结**: 线穿过针眼,单线或对折成双线,末端打结。

| 针法 | 怎么缝 | 用在哪里 |
|------|--------|----------|
| 平针(跑针) | 针一上一下,等距前进 | 临时固定、不受力的地方 |
| 回针 | 每缝一针,往回退半针或一针再前进 | 最结实,代替缝纫机线迹,裤裆、腋下等受力处 |
| 锁边针(包边) | 线绕过布边缠绕缝 | 防止布边脱线 |
| 藏针(暗针) | 针在两片布的折边内穿行,线迹不外露 | 缝合开线的缝、补丁边 |

```
回针缝法:
1. 从布背面向正面出针
2. 向后退一小段,入针
3. 在出针点前方同样距离处出针
4. 重复2-3,每一针都回到上一针的终点
```

### 常见缝补

**开线**: 把开线处翻到反面,用回针沿原来的线迹重新缝合。

**破洞打补丁**:
```
1. 剪一块比破洞每边大约2厘米的补丁布(尽量同样厚薄的布)
2. 补丁四边向内折边
3. 贴在破洞后面(里补)或前面(外补),用大头针或几针固定
4. 用藏针或锁边针沿补丁四周缝一圈
5. 把破洞的毛边修剪整齐、锁边,防止继续散开
```

**织补(袜子、毛衣上的小洞)**:
```
1. 在洞里面垫一个圆形物体(灯泡、鸡蛋、小碗)撑平
2. 先用线在洞上横向来回拉满平行线,两端缝进完好的部分
3. 再纵向用针一上一下穿过横线,像织布一样织满
4. 线尽量和原来的颜色、粗细接近
```

**钉扣子**:
```
1. 双线打结
2. 从布背面出针,穿过扣眼,再穿回布里,重复6-8次
3. 最后在扣子和布之间绕线几圈形成"线脚"(让扣子不贴死,好扣)
4. 背面打结
```

**鞋子开胶、磨破**:
- 鞋底开胶: 有胶水先粘,再用粗针粗线沿鞋边缝一圈加固
- 用锥子扎孔,尼龙线或筋线穿过,回针缝合
- 鞋底磨穿: 剪一块旧轮胎、厚橡胶或多层皮革垫在里面,或缝/钉在外面

## 纺线

### 原料

| 原料 | 获得方式 | 特点 |
|------|----------|------|
| 棉花 | 种植,采摘棉桃里的棉絮 | 柔软吸汗;需要去籽 |
| 羊毛 | 春季剪毛(见[家畜养殖](../04-动植物培育/06-家畜养殖.md)) | 保暖,湿了仍保暖;需要洗净 |
| 麻(苎麻、大麻、亚麻) | 种植,剥取茎皮 | 结实耐磨;需要沤制 |
| 兔毛 | 安哥拉兔梳毛或剪毛 | 极柔软保暖,纤维短,常与羊毛混纺 |

⚠️ 大麻在我国种植受管制,仅限依法批准的工业用途,不要私自种植。可用苎麻、亚麻代替。

### 准备纤维

**羊毛**:
```
1. 剪下的毛先挑去草屑、粪块
2. 温水(不要开水)泡洗,可加少量草木灰水或皂荚水去油
   - 不要搓揉、不要冷热水交替(会毡化结块)
3. 清水漂净,摊开晾干
4. 梳理: 用两把梳子(或钉板)来回梳,把纤维梳顺、梳蓬松
```

**棉花**:
```
1. 晒干的棉絮去籽(手剥,或用两根滚轴碾压)
2. 弹松: 用弓弦弹打棉絮,使纤维蓬松
3. 搓成松散的棉条
```

**麻**:
```
1. 收割麻秆,在水塘中浸泡(沤麻)1-3周,让茎皮和木质部分离
   - 沤麻有臭味,不要在饮用水源中沤
2. 剥下茎皮,晒干
3. 用木棒捶打、刮去杂质,留下纤维
4. 用梳子梳理成细长的纤维
```

### 纺锤纺线(最简单的工具)

```
制作纺锤:
- 一根约30厘米长、筷子粗的直木杆
- 在杆的下部套一个有重量的圆盘(陶片、木片、土豆、石片中间钻孔)
- 杆的顶端刻一个小槽或钉一个小钩

纺线:
1. 在纺锤杆上先系一段已有的线作引线,绕过顶端的钩
2. 从梳好的纤维中拉出一小撮,和引线搭在一起
3. 一手捏住纤维,一手让纺锤朝一个方向旋转,然后放手让它悬空转动
4. 纺锤的旋转把纤维捻成线
5. 捏纤维的手慢慢向上放出纤维,保持粗细均匀
6. 纺锤快停时再转一下;线够长了,绕到纺锤杆上
7. 重复

合股: 两根同方向捻好的单线,反方向再捻在一起,成为更结实的双股线
```

## 织布与编织

### 棒针编织(新手首选)

比织布简单,只需要两根针,适合羊毛线。旧毛衣拆下的线也可以重新编织。

```
工具: 两根粗细相同、光滑的竹签或木棒,一端削尖磨光

基本步骤:
1. 起针: 在一根针上绕出需要的针数
2. 下针: 右针从左针第一个线圈前面插入,绕线,拉出新线圈,
   让旧线圈从左针滑落
3. 一行织完,换手,继续织下一行
4. 收针: 最后一行时,每织两针就把前一针套过后一针

先织围巾练手(一直织下针即可),熟练后再织帽子、袜子、毛衣
```

### 简易织布

```
框架织机:
1. 做一个方木框
2. 在上下两边钉一排等距的钉子(或刻出槽口)
3. 经线: 在上下钉子之间来回绕线,拉紧,形成一排平行的经线
4. 纬线: 用梭子(一根绕着线的扁木片)带着纬线,
   在经线间一上一下穿过去
5. 下一行反过来: 刚才在上面的经线这次在下面
6. 每织一行,用梳子或木片把纬线向下压紧
7. 织满后剪断经线,两端打结防止脱散

这样织出的是平纹布,适合做小块布料、腰带、包袋;
要织大块布料,需要更大的织机,效率很低,所以优先考虑回收旧布料。
```

### 编织(无需纺线)

- 稻草、麦秸、蒲草、玉米皮: 编草席、草帽、草鞋、蓑衣
- 竹篾、柳条、荆条: 编筐、篮子、簸箕
- 旧布条: 搓成条后编织地垫、坐垫

## 鞣皮

生兽皮晾干后会变得像木板一样硬,受潮又会腐烂发臭。鞣制就是把生皮变成柔软、不腐烂的皮革或毛皮。

### ⚠️ 安全须知(先读)

```
动物皮毛可能传播人兽共患病:
- 炭疽: 病死的牛羊等牲畜,皮毛可带炭疽芽孢(历史上曾叫"皮毛工人病")
- 布鲁氏菌病: 牛、羊、猪等,接触皮毛、内脏、体液可感染
- 兔热病: 剥野兔、野生啮齿动物皮时易感染

必须做到:
✓ 只处理健康宰杀的家畜家禽、或确认来源的动物
❌ 绝不剥病死、死因不明的动物的皮(上报当地畜牧兽医部门)
✓ 戴橡胶手套,有条件时戴口罩、护目镜、围裙
✓ 手上有伤口时不要处理生皮
✓ 处理完彻底洗手,工具清洗消毒
✓ 处理过程中出现发热、皮肤溃疡、关节痛,就医时说明接触过动物皮毛

法律:
❌ 不要猎捕、收购、加工国家保护的野生动物及其皮毛
   (野生动物保护法);优先利用自养的牛、羊、兔、猪的皮

环境:
✓ 鞣制废液、刮下的肉和脂肪远离水源处理(深埋)
```

### 第一步: 剥皮和去肉

```
1. 剥皮时尽量少留肉和脂肪,避免割破
2. 去肉: 把皮毛面朝下铺在圆木或光滑的木板上,
   用钝刀刮去皮板(肉面)上残留的肉、脂肪和薄膜
   - 要刮干净,残留的油脂会导致发臭、腐烂、鞣不透
3. 及时处理,夏天放置半天以上就可能开始腐败
```

### 第二步: 临时保存(如果不能马上鞣制)

```
盐腌: 在皮板上均匀撒满粗盐,皮板对皮板折叠,放阴凉处
晾干: 撑开钉在木板上,放阴凉通风处晾干(不要暴晒)
需要鞣制时: 清水浸泡回软,洗去盐分
```

### 方法一: 硝面熟皮(适合带毛的毛皮)

我国北方的传统方法,用芒硝和面粉发酵的糊来鞣制,做羊皮袄、兔皮的常用方法。

```
1. 皮回软、去肉干净
2. 配鞣液: 用小米面或面粉加水调成稀糊,加入芒硝(硫酸钠)和盐,
   静置发酵1-2天(微酸、有酒糟味)
   - 各地配比不一,没有统一标准;先用一小块皮试验,
     或向当地有经验的皮匠请教
3. 把鞣液均匀涂满皮板(或把皮浸入鞣液中),毛面保持干净
4. 皮板对皮板折叠,放在缸中或盖好,在温暖处放置数天到一两周,
   期间每天翻动、补涂鞣液
5. 检验: 皮板颜色均匀变白,用手指甲用力划过留下白印、不再透明发黏
6. 刮去鞣液,半干时开始反复揉搓、拉伸、在钝木棱上来回拉磨,
   直到干透变软(这一步决定皮子是否柔软,要有耐心)
7. 用细砂或木屑搓皮板使其更柔软干净;梳理毛面

⚠️ 硝面熟皮的皮子怕水,长期受潮会回生变硬发臭
```

### 方法二: 植物鞣(适合去毛做皮革)

用树皮中的单宁鞣制,做出的皮革结实耐用,适合做鞋、皮带、背带。

```
1. 去毛: 生皮浸泡在草木灰水或石灰水中数天,至毛根松动,
   刮去毛和表皮(⚠️ 碱水有腐蚀性,戴手套和护目镜,防护要求同制皂一章)
2. 用清水反复浸洗,去除碱性
3. 鞣液: 富含单宁的树皮(橡树、栗树、柳树、落叶松等)捣碎,
   加水浸泡或熬煮,得到褐色的鞣液
4. 把皮浸入鞣液,开始用淡液,逐渐换成浓液
   - 厚皮需要数周到数月,薄皮也要数周
   - 切开边缘检查,断面颜色一致说明鞣透
5. 取出晾至半干,涂抹动物油或植物油,反复揉搓
6. 晾干后再上油保养

特点: 时间长,但皮革耐水性比硝面熟皮好
```

### 让皮子更柔软、防水

```
✓ 柔软: 鞣后半干时反复揉搓、拉伸是关键;
  涂抹蛋黄与油的混合物(蛋黄可帮助油脂渗入)后再揉搓
✓ 防水: 皮革定期涂抹动物油或蜂蜡;毛皮可用柴烟慢慢熏皮板,
  熏过的皮子受潮后不易变硬
```

### ❌ 不要用的方法

```
❌ 铬鞣: 工业方法,使用的铬盐有毒,废液严重污染环境
❌ 用砒霜、汞等防虫(过去曾用于标本制作,剧毒)
```

## 衣物和皮毛的保存

```
✓ 收藏前洗净、彻底晒干(带汗渍和污渍的衣物更招虫)
✓ 毛料、皮毛: 樟木箱,或放入樟木块、花椒、干艾草、干薰衣草驱虫
✓ 密封袋或箱子保存,防潮
✓ 每年晴天拿出来晾晒、拍打一两次(梅雨季后尤其重要)
✓ 皮革制品定期上油,防止干裂

❌ 不要把湿衣物、汗湿的皮毛直接收起来(发霉、生虫、皮子腐烂)
⚠️ 樟脑丸(萘或对二氯苯)有毒,远离儿童,不要和婴儿衣物放在一起
```

---

## 📝 要点

```
1. 先缝补和改制旧衣,从头纺织非常费工
2. 储备针线、顶针、锥子、纽扣,便宜轻巧不过期
3. 回针最结实;补丁比破洞每边大约2厘米;织补要先撑平
4. 纺锤是最简单的纺线工具;棒针编织比织布简单
5. 剥皮鞣皮戴手套,不碰病死、来源不明的动物,不碰保护动物
6. 去肉要刮干净;硝面熟皮做毛皮,树皮单宁鞣做皮革
7. 鞣后反复揉搓才能柔软;皮革定期上油
8. 衣物皮毛晒干、驱虫、防潮保存
```
