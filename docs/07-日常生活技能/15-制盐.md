## 先说清楚: 为什么要会制盐

盐(氯化钠)是少数**无法用别的东西代替**的必需品。古代盐是国家专卖的战略物资,内陆缺盐的地方,盐的价格可以和粮食、布匹相当。

```
盐的用途:
1. 人: 钠是维持体液、神经和肌肉功能必需的;大量出汗、腹泻时丢失最多
2. 牲畜: 牛、羊、马等食草动物从草料中得不到足够的钠,会舔土、舔墙、啃骨头
3. 腌制: 咸菜、腊肉、咸鱼、酱 —— 没有冰箱时保存食物的主要办法
4. 鞣皮: 鲜皮先用盐腌,防止腐烂
5. 制皂: 软皂中加盐,析出硬皂
6. 其他: 鱼种消毒、盐水选种、清洁
```

```
⚠️ 安全
1. 工业盐、亚硝酸钠、融雪剂外观都像食盐,误食可以致命 —— 来源不明的"盐"一律不吃
2. 煮盐的锅里是100°C以上的浓卤,溅出或打翻会造成严重烫伤
3. 盐田、海边劳动日晒强、反光强,防中暑、防晒伤
4. 卤水、苦卤不能喝,要标明并远离儿童
5. 自己晒、煮的盐几乎不含碘,内陆地区长期吃会缺碘(见后文)
```

**先回收,再自制**: 超市、仓库、餐馆、食品厂、养殖场(饲料盐、盐砖)里储存的盐往往比想象中多。普通食盐只要干燥密封,放多少年都不会坏。

## 需要多少盐

### 人

```
现代建议: 成年人每天食盐不超过5 g(约一平啤酒瓶盖)
  → 这是针对现代饮食"吃得太咸"定的上限,不是最低需要量
  → 吃盐太多会升高血压,增加中风、心脏病风险

身体真正的最低需要: 每天约1-2 g盐就能维持基本需要(不出汗时)

出汗时: 汗里有盐,每出1 L汗大约损失1-3 g盐
  - 炎热天气重体力劳动,一天可能出汗几升
  → 这时每天吃到5-10 g盐是合理的,但要随餐吃、随水喝,不要一次猛吃

劳动出汗后的补充:
✓ 饭菜正常放盐,菜汤、咸菜就够补
✓ 出汗特别多时,饮水中可以加一点盐(淡到几乎尝不出咸味)
✓ 腹泻、中暑时用口服补液盐,按配方来,盐不能多放
✗ 不要吞盐片、干嚼盐;不要喝浓盐水
✗ 高血压、心脏病、肾病患者、婴儿要少盐(1岁以内婴儿不另外加盐)
```

热痉挛、热衰竭时的补液见[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑);口服补液盐的配法见[常见疾病-腹泻](../01-日常疾病和伤害/01-常见疾病.md#腹泻)。

### 牲畜

| 牲畜 | 大致需要量 | 喂法 |
|------|-----------|------|
| 牛、马 | 每头每天约30-60 g | 盐砖或盐槽自由舔食 |
| 羊 | 每只每天约5-10 g | 盐砖或拌料 |
| 猪 | 饲料的约0.3-0.5% | 拌入饲料 |
| 鸡鸭 | 饲料的约0.3% | 拌入饲料,必须拌匀 |

```
⚠️ 猪和家禽对盐很敏感: 用剩菜、咸菜、咸鱼喂猪喂鸡,或者饮水不足时,容易盐中毒
   (口渴、抽搐、转圈、死亡)。喂盐时一定要保证充足饮水
```

养殖细节见[家畜养殖](../04-动植物培育/06-家畜养殖.md)、[家禽养殖](../04-动植物培育/05-家禽养殖.md)。

### 腌制和其他用途

```
腌咸菜: 盐约为菜重的10-15% → 腌100 kg菜要10-15 kg盐
腌腊肉、咸肉: 盐约为肉重的6-8%
泡菜: 盐水浓度约5-8%
腌鱼: 用盐量和腌肉相当或更多
鲜皮临时保存: 皮板撒满粗盐,用盐量大致是鲜皮重量的三分之一到一半
```

腌制方法见[食物加工与保存-盐腌](01-食物加工与保存.md#盐腌),鲜皮腌制见[纺织缝补与鞣皮-临时保存](07-纺织缝补与鞣皮.md#第二步-临时保存如果不能马上鞣制),制皂加盐见[制皂-加盐变硬](04-制皂.md#可选-加盐变硬)。

### 一个社区一年要多少盐(估算)

```
例: 50人的社区,养10头牛、30只羊、几头猪和一群鸡

人吃:   50人 × 每天约6 g × 365天 ≈ 110 kg
腌菜:   每人每年腌菜约50 kg,用盐约10% → 50人约250 kg
腌肉鱼: 约50 kg
牛:     10头 × 每天约40 g × 365天 ≈ 150 kg
羊:     30只 × 每天约8 g × 365天 ≈ 90 kg
猪、鸡、鞣皮、制皂、损耗: 约50-100 kg

合计: 约700-800 kg,也就是每人每年大约10-15 kg
→ 结论: 腌制和牲畜用的盐比人直接吃的多得多
→ 一个社区每年要准备几百千克到一吨盐,这值得专门安排人手
```

库存和配给的记账方法见[记账交易与社会分工-库存管理](13-记账交易与社会分工.md#库存管理)。

## 不能吃的"盐"

| 东西 | 样子 | 危险 |
|------|------|------|
| 亚硝酸钠(工业盐、"硝盐") | 白色或微黄的结晶粉末,很像食盐,略带咸味 | 零点几克就可中毒,几克可致死: 口唇、指甲青紫,头晕、心慌、呼吸困难 |
| 工业用盐(化工、印染、制革用) | 和食盐一样 | 可能混有亚硝酸盐、重金属等杂质 |
| 融雪剂 | 白色颗粒,有的带颜色 | 氯化钙、氯化镁、工业盐或其他化学品,不能食用 |
| 饲料盐、盐砖 | 块状或颗粒 | 可能加了其他矿物质、药物,只作牲畜用 |
| 软水盐、再生盐(净水器用) | 白色大颗粒或片状 | 不按食品标准生产 |
| 盐碱地刮的土盐 | 灰白、发黄、发苦 | 可能含大量硝酸盐、亚硝酸盐、硫酸盐(芒硝),必须提纯 |
| 来源不明的袋装或散装"盐" | — | 无法判断,一律不吃 |

```
✓ 只吃来源清楚的食用盐,或自己按本章方法从海水、盐泉、盐井提纯的盐
✓ 工业盐、融雪剂单独存放,醒目标明"不能吃",绝不放进厨房
✗ 不要靠尝味道分辨食盐和亚硝酸钠 —— 尝一口就可能中毒
✗ 不要用苦卤、卤水当盐水喝或做菜调味

误食后: 口唇青紫、头晕、呼吸困难,立即拨打120,尽快送医(医院有特效解毒药)
```

亚硝酸盐和其他食物中毒见[食物加工与保存-高风险食品与食物中毒](01-食物加工与保存.md#高风险食品与食物中毒)、[中毒-其他中毒](../01-日常疾病和伤害/12-中毒.md#其他中毒)。

**草木灰不能代替食盐。** 草木灰泡出的碱水主要是碳酸钾(钾碱),是强碱,用来做肥皂和处理玉米,吃了会腐蚀口腔和消化道,也补不了钠。有些海边、盐碱地的植物(如碱蓬)吃起来是咸的,可以当野菜少量吃,但它们烧成的灰同样是碱,不是盐。

## 海水取盐: 基本道理

```
海水含盐约3.5%: 1 L海水约有35 g盐类
  - 其中约四分之三多是氯化钠(约27 g),其余是镁、钙、钾的盐(苦卤的来源)
  - 河口附近、雨季时海水被淡水冲淡,含盐更低,应在远离河口、潮水清的地方取水

取盐就是把水赶走:
1. 晒: 靠太阳和风蒸发,不用燃料,但需要大面积、晴朗少雨
2. 煮: 靠火蒸发,不受天气限制,但非常费燃料
3. 实际上常常两者结合: 先晒浓(或淋卤),再煮

水分蒸发时,各种盐按溶解度从小到大依次析出:
  浓缩到约4倍(约13%) → 石膏(硫酸钙)、泥沙先沉淀
  浓缩到约10倍(约26%,饱和) → 氯化钠开始大量结晶 ← 收这一段
  继续浓缩 → 硫酸镁、氯化镁、氯化钾等析出,盐变苦 ← 这时停止,把剩下的苦卤放掉
```

溶解度和蒸发结晶的原理见[化学-溶解度](../08-基础科学知识/03-化学.md#53-溶解度)、[化学-分离与提纯](../08-基础科学知识/03-化学.md#八分离与提纯)。

**不要直接喝海水**,见[荒岛求生-海岛取水](../03-野外生存/01-荒岛求生.md#海岛取水)。

## 判断卤水浓度

卤水越浓,越重。晒盐、煮盐、淋卤的每一步,都要知道卤水"够不够浓"。

```
方法一: 称重(最准,有秤就用)
  量1 L卤水称重(减去容器重量):
  - 海水                     约1.02-1.03 kg
  - 约13%,石膏开始析出      约1.10 kg
  - 约26%,饱和,即将出盐    约1.20 kg
  → 1 L卤水重1.15 kg以上,值得下锅煮;到1.20 kg,晒池里就会出盐

方法二: 浮蛋法(最简单)
  - 新鲜生鸡蛋在海水中下沉
  - 卤水浓度到约10-15%(海水的3-4倍)时,鸡蛋开始浮起
  - 浓度越高,鸡蛋露出水面越多;接近饱和时露出约一枚硬币大小
  → 鸡蛋浮起,说明卤水已经浓缩得差不多,可以下锅煮了
  → 用同一个鸡蛋反复测,结果更好比较(不同的蛋密度略有差别)
  古代盐工用石莲子(老莲子)测卤,道理相同

方法三: 自制比重计
  细竹管下端塞小石子使它直立漂浮,在海水和饱和盐水中各漂一次,
  在水面位置刻线,中间等分刻度(传统波美比重计的原理)
```

浮力和密度的原理见[物理-浮力](../08-基础科学知识/02-物理.md#45-浮力-阿基米德原理)。

## 晒盐: 盐田

晒盐几乎不用燃料,是产量最大的办法,但对地点和天气要求高。

```
适合的地方:
✓ 平坦、低洼的海滩或滩涂,地面是不渗水的黏土或淤泥(沙滩渗水太快,不行)
✓ 蒸发量大、降雨少,晴天多、风多 —— 北方春季和秋季、南方旱季
✓ 涨潮时海水能引进来,远离河口
✗ 多雨地区、雨季: 一场大雨就把晒浓的卤水冲淡,前功尽弃
```

```
盐田的构成(从海边向内):
1. 纳潮: 涨潮时打开闸门(木板闸),把海水引进储水池;潮退前关闸
2. 蒸发池: 分成几级,卤水从一级流到下一级,越往后越浓
   - 每级池子浅(水深约5-15 cm),面积大,蒸发快
   - 前几级池底会沉积泥沙和石膏,定期清理
3. 结晶池: 卤水浓到约26%(1 L约重1.20 kg)才放进结晶池
   - 池底要平整、夯实压光,最好铺一层压实的黏土或碎陶片、砖块
   - 卤水深约3-5 cm,几天后池底出现白色结晶
4. 收盐: 用木耙把盐耙成堆,堆在高处沥干卤水,再挑到仓库
5. 放苦卤: 结晶池里剩下发黏、发苦的母液(苦卤)要及时放掉,
   不然它的盐也会析出,盐就变苦;苦卤另存(见后文)

下雨前: 把浓卤水放进有盖的卤池或深坑(上面盖草帘、木板),雨后再放回去
```

```
产量数量级(晴朗干燥地区):
  - 每平方米盐田(含蒸发池)一年可产几千克到十几千克盐
  - 一个社区一年要1 t盐 → 大约需要100-200 m²的盐田
  - 多雨地区产量会低得多,要靠煮盐补充
```

看天安排晒盐见[天气观测与预报](../08-基础科学知识/07-天气观测与预报.md)。

## 煮盐: 先浓缩再煮

### 为什么不直接煮海水

```
直接煮海水(3.5%): 得到1 kg盐要蒸发掉约28 L水
  → 开口锅烧柴效率很低,大约要几十千克干柴才得1 kg盐
  → 一个社区一年的盐 = 几十吨柴,几乎做不到

先浓缩到约20%以上再煮: 得到1 kg盐只要蒸发约3-4 L水
  → 燃料省到约十分之一,几千克干柴得1 kg盐

结论: 煮盐前一定要先浓缩卤水,能晒就晒,不能晒就淋卤
```

### 淋卤: 用海滩的咸沙(或草木灰)浓缩

这是没有大面积黏土滩涂时的传统办法(古代叫"刮土淋卤"、"摊灰淋卤"),比开盐田省地,比直接煮省柴。

```
1. 选一片平整的海滩,沙或泥土表面耙松
   (也可以在平地上铺一层约3-5 cm厚的干净草木灰或细沙)
2. 泼洒海水,让太阳晒、风吹;干了再泼,反复几天
   → 盐分留在沙粒表面,晴天能看到表面一层白霜
3. 刮起表层带盐的沙土(约2-3 cm厚),堆到淋卤坑
4. 淋卤坑: 挖一个坑或用木桶、陶缸,底部铺草、树枝,再铺一层干净沙作滤层,
   底部留出口,下面接卤缸
5. 把咸沙放进去,浇海水慢慢往下淋
   → 海水把沙上的盐溶下来,从底部流出的就是浓卤
6. 用浮蛋法或称重检查: 鸡蛋能浮起的卤水才进锅
   太淡的卤水再淋一遍咸沙
7. 淋过的沙摊回海滩,继续晒,循环使用
```

### 煮盐

```
锅:
✓ 铁锅,越宽越浅越好(蒸发面积大);大量生产时用铁板焊或铆成浅盘
✓ 陶锅、陶盘也能用(古代用过),但易裂,产量小
✗ 不用铅制、镀锌、铝制的锅或容器 —— 浓盐水会溶出有害金属,铝锅会被腐蚀
✗ 不用沾过油漆、化学品的旧桶

步骤:
1. 浓卤倒进锅里先澄清过滤(泥沙、石膏在锅里会结成硬垢)
2. 大火烧开,撇去浮沫
3. 保持沸腾,随着蒸发不断补加浓卤,保持锅里液面
4. 锅边和液面出现盐花、锅底有晶体沉积,改小火
   → 小火慢蒸,晶体更大、更纯
5. 用带孔的铁勺或竹勺捞出盐粒,放进架在锅上方的竹筐沥卤
6. 不要把锅烧干: 最后剩下约十分之一、发黏发苦的液体就是苦卤,倒出另存
7. 捞出的盐摊开晒干或烘干

锅底结的硬垢(主要是石膏)要定期铲掉,否则传热差、锅易烧坏
```

```
燃料估算(以浓卤约20%计):
  - 每得1 kg盐约需几千克干柴
  - 一个社区一年700-800 kg盐 → 几吨柴,外加相应的劳力
  - 省柴: 锅上加盖导烟的灶,砌好灶膛和烟道;用晒浓的卤;几口锅串联,
    前锅余热预热后锅的卤水
  - 四川自贡古代用地下冒出的天然气煮盐,这是特例
```

省柴灶和木柴储存见[照明与能源-燃料的安全储存](06-照明与能源.md#燃料的安全储存)。

## 内陆的盐: 盐湖、盐泉、井盐、土盐

### 盐湖

```
西北、内蒙古、青藏等干旱地区有许多盐湖
  - 有的湖边、湖底直接结着厚厚的盐层,挖出来就是"大青盐"、"湖盐"
  - 有的是浓卤水,在岸边挖浅池晒卤即可
⚠️ 盐湖里的东西不一定都是食盐: 有的是碱湖(碳酸钠,滑腻、发涩)、
   有的是芒硝湖(硫酸钠,凉、苦)。尝一下极少量: 纯咸的才是食盐,
   发苦、发涩、发凉的要提纯或放弃
⚠️ 盐湖湖岸可能有松软的泥沼和盐壳下的空洞,不要单独深入
```

### 盐泉

```
有些泉水、溪水是咸的(牲畜和野兽常去舔,是找盐泉的好线索)
1. 用浮蛋法或称重测浓度
2. 浓度高的直接晒或煮;太淡的先晒浓
3. 把泉眼围起来,防止淡水混入
```

### 井盐: 自贡的卓筒井

四川盆地地下有古代海水留下的卤水和岩盐层。四川人在两千多年前就开始打井取卤。北宋时期出现的**卓筒井**是世界钻井史上的大发明:

```
卓筒井的原理(了解即可,不要求在灾后打深井):
1. 冲击钻: 用碓杆(像舂米的杠杆)带动沉重的铁钻头,一起一落把岩石砸碎,
   竹篾绳吊着钻头,一边砸一边转动,井眼只有碗口粗
2. 竹筒套管: 把打通节的大竹筒连接起来下到井里,挡住上部的淡水和塌方
3. 汲卤筒: 一根长竹筒,底部装一个皮质单向阀 ——
   放下去时卤水顶开皮阀进入,提上来时皮阀被压住,卤水不漏
4. 天车和绞盘: 用高木架和牛拉的绞车把汲卤筒提上来
5. 清代(1835年)自贡的燊海井深约1001 m,当时世界最深
```

对灾后社区来说: 老盐区原有的盐井、卤水管道可能还能修复使用;浅层的咸水井、咸泉可以用同样的汲卤筒原理提卤;打深井需要大量人力、时间和经验,一般社区不必尝试。

### 土盐: 盐碱地刮土淋盐

北方平原、沿海的盐碱地,天旱时地面泛出一层白霜(盐霜)。历史上缺盐的农民常刮这层土熬"小盐"(土盐)。

```
1. 选泛白霜最明显的地块,天旱时刮起表层薄薄一层土(不到1 cm)
2. 按"淋卤"的方法: 土放进淋卤坑,浇清水淋出卤水
3. 卤水先静置澄清,再用于后面的提纯步骤

⚠️ 土盐杂质很多:
  - 常含大量硫酸钠(芒硝)、硫酸镁,吃了腹泻
  - 可能含硝酸盐、亚硝酸盐(尤其靠近村庄、畜圈、粪坑、厕所的土)
  - 可能含当地的氟、砷等(本地有地方病的地区更要小心)
✓ 只在离村庄、畜圈、厕所、坟地、垃圾坑远的地方刮土
✓ 土盐必须提纯(见下一节),发苦、发凉、发涩的不吃
✓ 有海盐、井盐、湖盐时,优先用那些;土盐用于腌菜、喂牲畜也要先提纯
```

盐碱地的形成和改良见[地质矿物与土壤-酸碱性](../08-基础科学知识/06-地质矿物与土壤.md#53-酸碱性)。

## 提纯和苦卤

### 提纯: 溶解 → 过滤 → 澄清 → 再蒸发

```
适用于: 发灰、发黄的粗盐,土盐,结块混有泥沙的盐

1. 溶解: 粗盐加清水(约每3份水溶1份盐),搅拌到不再溶解
2. 过滤: 用布、或底部铺草和细沙的筐子过滤,去掉泥沙
3. 澄清: 静置一夜,让细小的杂质沉淀,舀出上层清液
   (可以加少量石灰水,让镁沉淀出来,再澄清 —— 这是传统做法)
4. 再蒸发: 晒或小火煮
5. 不要蒸干: 大部分盐结晶出来后就停,倒掉剩下的母液(含大部分杂质)
6. 洗盐: 用少量饱和的干净盐水(不用清水)冲洗盐粒
   → 饱和盐水不再溶解氯化钠,但能把粘在晶体表面的苦卤洗掉
7. 晒干

需要更纯时重复一次(重结晶)
```

```
内陆土盐的"冬天析硝":
  芒硝(硫酸钠)和硝石在冷水中溶解度大大降低,而食盐几乎不变
  → 冬天把浓卤水放在室外冷一夜,缸底析出的大块透明结晶多是芒硝或硝,捞出不吃
  → 剩下的卤水再煮盐,苦味会少很多
  (芒硝可以用于硝面熟皮,见纺织缝补与鞣皮章)
```

重结晶的原理见[化学-溶解度](../08-基础科学知识/03-化学.md#53-溶解度)。

### 苦卤

```
煮盐、晒盐最后剩下的发黏、发苦的液体: 主要是氯化镁、硫酸镁、氯化钾

用途:
✓ 点豆腐的"卤水"就是它(北豆腐)
✓ 冬天析出的硫酸镁、苦卤中的成分在古代还用于其他手工业

⚠️ 不能大量食用: 喝几口就可能腹泻,大量误饮可致严重中毒甚至死亡
⚠️ 用专门的瓶罐装,写明"卤水 不能喝",放在儿童拿不到的地方
⚠️ 盐吃起来发苦,说明苦卤没有放干净 —— 重新洗盐或提纯
```

用卤水点豆腐见[食物加工与保存-豆腐](01-食物加工与保存.md#豆腐)。

## 碘: 自制盐最大的缺陷

```
内陆缺碘地区(远离海洋的山区、丘陵,历史上中国大部分内陆省份都有):
  - 成年人: 甲状腺肿(大脖子病)
  - 孕妇缺碘: 胎儿大脑发育受损,孩子可能智力低下、身材矮小、聋哑(克汀病)
    → 损害不可逆,所以孕妇和婴幼儿最要紧

为什么自制盐几乎不含碘:
  - 海水里的碘很少,晒盐、煮盐后留在盐里的更少
  - 井盐、湖盐、土盐一般也不含多少碘
  - 现在的碘盐是工厂在食盐里专门加了碘酸钾(约20-30 mg/kg)
```

```
对策:
1. 储备碘盐: 优先留给孕妇、哺乳期妇女、儿童
   - 成年人每天吃约5 g碘盐,就能满足一天的碘需要
2. 吃海产品: 海带、紫菜、海鱼、贝类都富含碘
   - 沿海社区基本不缺碘
   - 内陆社区可以用盐、粮食和沿海交换晒干的海带、紫菜,一周吃几次即可
   - 海带含碘很高,不需要天天大量吃(碘过多也会引起甲状腺问题)
3. 不要用碘酒、碘伏等外用碘制品代替碘盐
4. 甲状腺疾病患者遵医嘱
```

```
碘盐的保存(碘会损失):
✓ 密封、避光、阴凉干燥 —— 受潮、受热、见光,碘都会慢慢跑掉
✓ 用有盖的陶罐或深色瓶,不要敞口放在灶台边
✓ 做菜时出锅前再放盐,不要长时间爆炒、久煮
✓ 先进先出,储备的碘盐按时轮换吃掉
```

缺碘的症状和其他营养缺乏病见[营养与营养缺乏病-碘](02-营养与营养缺乏病.md#碘)。从海带中提取单质碘(用于消毒)见[消毒剂制备-碘的来源](../06-制药技术/01-消毒剂制备.md#22-碘的来源),那是外用消毒品,不是食用补碘的办法。

## 储存

```
盐会吸收空气中的水分(潮湿天气盐罐"返潮"),受潮后结块、化成卤水流失

✓ 陶缸、陶罐、大口玻璃瓶加盖密封;大量储存用缸,缸口用油布、蜡纸扎紧
✓ 放在干燥、通风、离地的地方,不靠墙根、不放地面
✓ 塑料桶、编织袋内衬塑料袋也可以,注意防鼠咬
✓ 结块的盐敲碎照样能吃,不算变质
✓ 罐里放一小包炒干的米或干燥的木炭,有助于防潮
✗ 不用铁器、铁皮罐长期装盐 —— 盐会让铁很快生锈,盐也被染黄
✗ 不和工业盐、化肥、农药、融雪剂放在一起

普通食盐(不加碘)只要不受潮,可以无限期保存
碘盐保存见上一节
```

盐也是重要的交易品,有海、有盐泉的社区可以用盐换粮食、铁器、皮毛,见[记账交易与社会分工-交易](13-记账交易与社会分工.md#交易)。盐水加速铁器生锈的原理见[化学-生锈](../08-基础科学知识/03-化学.md#43-生锈)。

## 安全

```
煮盐:
⚠️ 浓卤沸点比水高,溅到皮肤上烫得更深;锅大、卤水多,打翻后果严重
✓ 灶台砌稳,锅放平,四周留足走动空间
✓ 加卤水时沿锅边慢慢倒,不要从高处猛倒
✓ 捞盐用长柄工具,穿长袖、长裤、布鞋,不光脚
✓ 儿童不得靠近灶台和卤池
✓ 灶房通风,防一氧化碳;远离柴堆,防火
✓ 被烫伤: 立即用凉水冲至少15-20分钟,再按烫伤处理

海边、盐田劳动:
⚠️ 盐田像雪地一样强烈反光,日晒加反光,容易晒伤、中暑、雪盲样的眼睛刺痛
✓ 戴宽檐草帽,穿浅色长袖衣服,有墨镜就戴
✓ 避开正午最热的时候干重活,多喝水,饭菜正常放盐
✓ 光脚踩卤水,皮肤会干裂、溃烂: 穿草鞋或胶鞋,收工后用清水洗脚、抹油
✓ 手上有伤口时戴手套或包好(浓盐水进伤口刺痛,也影响愈合)

其他:
⚠️ 卤池、盐井、淋卤坑要加盖或围栏,防止儿童和牲畜跌落溺水
⚠️ 涨潮、风暴潮时离开低洼的滩涂和盐田
⚠️ 卤水、苦卤、工业盐都要标明,不和食物、饮水放在一起
```

烫伤处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤);中暑见[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑);风暴潮见[海洋灾害](../02-灾难应对/03-海洋灾害.md)。

## 📝 制盐要点

```
1. 先回收储存的盐;普通食盐防潮密封可以无限期保存
2. 成年人日常每天不超过5 g;大量出汗时随餐、随水适当多补,不吞盐、不喝浓盐水
3. 一个社区用盐的大头是腌制和牲畜: 每人每年约10-15 kg
4. 海水约3.5%,煮之前一定先晒浓或淋卤,能省约九成燃料
5. 用称重(1 L约1.20 kg即饱和)或浮蛋法判断卤水浓度
6. 不要蒸干: 最后发苦的苦卤倒出另存,只能少量用于点豆腐,不能喝
7. 土盐、粗盐要溶解、过滤、澄清、再结晶;发苦、发凉、发涩的不吃
8. 工业盐、亚硝酸钠、融雪剂、来源不明的盐一律不吃,也不要尝
9. 草木灰是碱,不能代替盐
10. 自制盐几乎不含碘: 碘盐留给孕妇和儿童,内陆社区用海带、紫菜补碘
```
