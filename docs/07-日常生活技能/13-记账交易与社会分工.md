## 先说清楚: 本章的定位

一家人过日子,记在脑子里就够了;几十个人、几百个人一起生活,粮食够吃多久、谁做了多少工、谁欠谁什么,不记下来就一定会算不清,算不清就会争吵,甚至分裂。

```
本章讲小社区在困难时期最基本的组织方法:
- 记账: 东西有多少、进了多少、出了多少
- 配给: 不够的时候怎样公平地分
- 交易: 和别人交换东西
- 分工: 谁做什么、怎样记工

原则:
✓ 公开: 账目、库存、规则让大家都能看到
✓ 简单: 越简单越不容易出错、越容易让人信服
✓ 有记录: 口头约定容易忘、容易起争执,重要的事写下来
```

社区重建的整体策略见[末日求生-社区重建](../03-野外生存/06-末日求生.md#社区重建)。

## 记账

### 流水账: 最基本的账

每发生一笔进出,就按时间顺序记一行:

| 日期 | 事项 | 收入 | 支出 | 结余 | 经手人 |
|------|------|------|------|------|--------|
| 3月1日 | 上月结余 | | | 520 kg | |
| 3月2日 | 收获红薯 | 80 kg | | 600 kg | 张 |
| 3月3日 | 发放口粮(40人) | | 20 kg | 580 kg | 李 |
| 3月5日 | 换盐(给邻村) | | 30 kg | 550 kg | 张、王 |

```
✓ 每一类东西(粮食、盐、燃料、药品)单独一本账或单独一页
✓ 单位写清楚(kg、L、个、捆)
✓ 每笔都写经手人
✓ 记错了不要涂掉,划一道线在旁边写正确的,并签名
```

### 定期盘点

```
每周或每月:
1. 实际清点、称量库存
2. 和账上的结余比较
3. 对不上时查清原因: 记漏了?损耗(霉变、鼠害)?算错了?
4. 把盘点结果写进账里,由两个人签名
```

### 欠账和借条

```
借出、借入、赊欠都要写借条:
- 谁向谁借、借了什么、多少、什么时候还、用什么还
- 双方签名(或按手印),最好有一个见证人
- 一式两份,双方各保存一份
- 还清后在借条上注明"已还清",双方签名
```

## 库存管理

```
✓ 先进先出: 先入库的先用,新入库的放在后面或下面
✓ 每个容器贴标签: 内容、数量、入库日期
✓ 种子粮单独保存,单独记账,**绝不当口粮吃**(吃掉种子就没有明年)
✓ 分散储存: 不要把所有粮食放在一个地方(防火、防水、防盗、防鼠)
✓ 定期检查霉变、虫蛀、鼠害,发现问题及时处理
✓ 药品记录有效期,快过期的先用
```

食物的储存见[食物加工与保存](01-食物加工与保存.md)。

### 算一算够用多久

```
可用天数 = 库存总量 ÷ 每天的消耗量

例: 粮仓有2000 kg粮食,40人,每人每天约0.5 kg
  每天消耗 = 40 × 0.5 = 20 kg
  可用天数 = 2000 ÷ 20 = 100天
  → 离下一次收获还有150天 → 缺口 = 50天 × 20 kg = 1000 kg
  → 现在就要想办法: 节约、补种快熟作物、采集、交换
```

```
大致的粮食需要:
- 以粮食为主食时,成年人每天约0.5 kg粮食(约2000 kcal以上)
- 重体力劳动、哺乳期妇女需要更多;儿童、老人少一些
- 一个100人的社区,一年约需要18 t粮食
- 留出损耗和来年的种子
```

## 配给

当东西不够分时,需要有规则地分配。

```
原则:
1. 按需要分,而不是平均分: 重体力劳动者、孕妇和哺乳期妇女、生长期的儿童、病人需要更多
2. 规则事先定好、公开,所有人都知道
3. 由两个人一起发放,当场登记
4. 定量要及早开始: 等到快吃完才定量就晚了

⚠️ 定量时注意营养: 只分粮食会导致营养缺乏病,要同时分配豆类、蔬菜、油
⚠️ 病人、老人、残疾人不能因为不能劳动就少分到食物
```

配给登记表(例):

| 日期 | 户主 | 人数 | 粮食 | 盐 | 领取人签名 |
|------|------|------|------|------|------|
| 3月3日 | 刘 | 4 | 2.0 kg | 50 g | 刘 |

营养需要见[营养与营养缺乏病](02-营养与营养缺乏病.md)。

## 交易

### 统一度量

```
交易最大的纠纷来自"量不准":
✓ 社区统一一套秤、量具(量桶、量杯、尺),做好标记
✓ 用已知标准定期校准: 1 L水的质量是1 kg(见度量衡与科学方法)
✓ 双方当面称量、当面点数
```

单位的重建见[度量衡与科学方法-重建长度、质量、体积、时间](../08-基础科学知识/00-度量衡与科学方法.md#二重建长度质量体积时间)。

### 以物易物

```
- 先商量好比例: 例如1 kg盐换多少粮食、修一把锄头换多少工
- 社区内部可以列一张"参考价格表": 以一种大家都需要的东西(常用的是粮食)作为
  计价单位,其他东西都折算成多少粮食,写下来公开
- 价格会变(收获后粮食多,价格就低),定期调整

和外人交易:
- 地点选在社区外的固定地方
- 几个人一起去,不要独自携带大量物资
- 不暴露社区储备的总量
- 当面验货: 粮食看有没有霉变、受潮,药品看有效期和包装
```

### 记工分和信用

```
社区内部不一定需要"钱",可以用记账代替:
- 工分: 每人每天做了什么工、多长时间,记一笔;分配时参考工分
  (同时保证老人、儿童、病人的基本需要)
- 欠条和信用: 张家帮李家盖房三天,记一笔,以后李家还三天工
- 记录公开,每月核对一次
```

## 分工与协作

### 技能登记

```
1. 列出社区里每个人会什么: 医护、电工、木工、厨师、农业、驾驶、教书、
   机械维修、会说外语……(很多技能平时不会被想起)
2. 列出社区需要做的事: 取水、做饭、种地、看护孩子和病人、守夜、
   打柴、修缮、卫生、记账、教学
3. 把人和事对应起来;发现缺口(例如没有人会接生),就安排人去学
```

### 安排工作

```
✓ 关键岗位要有替补: 每个重要的工作至少两个人会
✓ 辛苦、危险、不受欢迎的工作(清理厕所、守夜)轮流做
✓ 写一张排班表,公开张贴
✓ 每天(或每周)开一个短会: 昨天做了什么、今天做什么、遇到了什么问题
✓ 每件事有一个明确的负责人
✓ 注意休息: 长期过度劳累会生病、出事故、产生怨气
```

### 一个常见的分组(例)

| 组 | 负责 |
|----|------|
| 水和卫生 | 水源保护、净水、厕所、垃圾 |
| 食物 | 种植、养殖、采集、储存、做饭 |
| 医护 | 急救、照顾病人、药品管理、防疫 |
| 建设 | 住房、修缮、工具、燃料 |
| 安全 | 防火、守夜、应急预案 |
| 教育 | 孩子上课、技能培训、资料保存 |
| 记录 | 记账、库存、档案 |

## 规则和决策

```
✓ 重要的规则写下来,公开,让所有成年人都知道
  例: 水源周围不准洗衣、粮仓的钥匙由谁保管、怎样分配、怎样处理违规
✓ 重大决定(搬迁、接纳新成员、动用种子粮)由大家开会讨论决定,记录下来
✓ 日常事务交给各组负责人,不必事事开会
✓ 负责人定期向大家汇报
✓ 有分歧时: 先听双方说完,找没有利害关系的人调解,按事先定好的规则处理
✓ 规则不合理时,开会修改,而不是各自违反
```

## 防止错误和不公

```
钥匙和账本分开: 管仓库钥匙的人不记账,记账的人不管钥匙
两人在场: 开仓、发放、交易时至少两个人在场,一起签名
公开: 账目和库存定期张贴,任何人都可以查看
定期轮换: 管钱管物的岗位定期换人
定期盘点: 实物和账面核对

这些不是因为不信任某个人,而是保护经手人: 账目清楚,就不会被冤枉
```

## 社区档案

```
长期需要记录:
- 人口: 姓名、出生日期、家庭关系、技能
- 出生和死亡: 日期、原因(死亡记录也帮助发现传染病,见灾后遗体处理)
- 疾病: 什么时间、多少人得了什么病(发现传染病流行的苗头)
- 土地: 每块地的位置、面积、边界、谁在耕种(见测量与制图)
- 收成: 每块地种了什么、收了多少(逐年比较,改进种植)
- 天气和物候(见天气观测与预报)
- 重要的决定和规则

保存: 多份抄写,分开保存(见教育与知识传承)
```

## 📝 记账与分工要点

```
1. 每一笔进出都记: 日期、事项、数量、结余、经手人
2. 定期盘点,两人签名;记错划线更正,不涂改
3. 借、欠、交换都写借条,双方签名、有见证人
4. 先进先出;种子粮单独保存,绝不当口粮
5. 可用天数 = 库存 ÷ 每天消耗;定量要及早开始
6. 配给按需要分,规则事先公开,照顾老弱病残
7. 统一秤和量具,定期用1 L水 = 1 kg校准
8. 技能登记,关键工作至少两人会,脏活累活轮流做
9. 钥匙和账本分开、两人在场、账目公开
```
