## 地震

我国是地震多发国家。地震本身很少直接伤人,**绝大多数伤亡来自房屋倒塌和坠落物**: 倒下的柜子、飞出的玻璃、掉落的吊灯和外墙装饰。所以地震应对的核心是三件事:

```
1. 震前: 把家里会倒、会掉、会飞的东西固定好;准备应急包;全家约好怎么做、去哪里集合
2. 震时: 就近躲避,护住头颈,不乱跑、不跳楼、不乘电梯
3. 震后: 迅速有序撤到开阔地,防余震、防燃气和电、防二次伤害;被困时保存体力等待救援
```

本节按"前兆 → 震时 → 震后 → 准备"的顺序写。**时间紧的话,先读[地震安全准备](#地震安全准备)和[地震时应对](#地震时应对)两部分。** 以下做法依据应急管理部、中国地震局等发布的防震减灾科普的主流建议整理。

### 地震前兆(不一定准确)

- 动物异常(不安、逃离)
- 地下水异常(变色、变味、涌出)
- 地光、地声
- 小震频繁

⚠️ **不要依赖前兆!准备最重要!**

这些现象在大地震前确实有过记录,但它们也经常由天气、季节、污染等普通原因引起,目前科学上**还不能靠它们预报地震**。社会上流传的"某天某地要发生大地震"一类消息,凡不是政府发布的,都按谣言对待;我国只有国务院和省级人民政府有权发布地震预报。

### 地震预警: 抢出来的几秒到几十秒

地震预警**不是预报**: 它是地震已经发生后,利用电信号比地震波传得快的原理,在破坏性的地震波到达之前几秒到几十秒发出警报。离震中越近,时间越短;震中附近可能来不及预警。

```
收到预警的途径:
- 手机(部分手机系统内置地震预警,需要在设置里打开)
- 电视、广播、应急广播、学校和社区的警报器

收到预警后怎么用这几秒:
✓ 预警时间很短(十几秒以内): 不要往楼下跑,立即就近躲避(伏地、遮挡、手抓牢)
✓ 时间较长,且在平房或楼房一层、门就在旁边: 可以迅速跑到室外开阔地
✓ 正在开车: 减速,打开双闪,在安全处靠边停车
✓ 正在用火: 顺手关火(只是顺手,不要为此冒险)
✓ 正在高处、梯子上、手术台旁、机器旁: 先让自己脱离危险位置

❌ 不要因为预警跑向电梯、拥挤的楼梯和出口
```

### 地震时应对

主震强烈晃动一般只有几十秒到一两分钟。**在这几十秒里,楼房里的人基本跑不出去**,而跑动中最容易被甩倒、被坠物砸中。所以除平房和一楼门口等少数情况外,原则是"就近躲避、震后撤离"。

#### 室内

**"伏地、遮挡、手抓牢"(Drop, Cover, Hold on)**

这是应急管理部、中国地震局科普中推荐的标准避震动作(国际上也通用),英文直译常被写成"伏地、掩护、抓牢",意思相同。

```
1. 伏地(Drop):
   - 立即趴下,双手双膝着地
   - 降低重心,避免被晃倒摔伤;这个姿势还能随时爬动换位置

2. 遮挡(Cover):
   - 钻到坚固的桌子或家具下
   - 用手保护头颈
   - 没有桌子时: 一只手臂护住头颈,另一只手抓住身边牢固的东西;
     可以顺手拿枕头、坐垫、书包顶在头上
   - 脸朝下,不要仰头看,防止碎玻璃、掉落物伤眼

3. 抓牢(Hold on):
   - 抓牢家具
   - 随着震动移动(桌子被晃走时,跟着桌子挪)
   - 保持姿势直到震动停止

如果没有桌子:
- 靠内墙角蹲下
- 双手护头
- 远离窗户、镜子、吊灯
```

**怎样选避震位置**:

```
✓ 相对安全:
- 结实、不易倾倒的桌子、床、矮柜下或旁边
- 内墙墙根、墙角(内墙一般比外墙结实)
- 开间小、有支撑、离自己最近的地方

✗ 危险:
- 窗户、玻璃门、玻璃隔断、镜子旁
- 吊灯、吊扇、吊顶下
- 高大书柜、衣柜、冰箱、电视、热水器旁(会倒、会掉)
- 外墙边、阳台上(外墙和阳台最容易塌、掉)
- 楼梯间、门框下

关于门框: "站在门框下最安全"的说法来自老式土木房屋。现代楼房的门框并不比其他
地方结实,门还会来回摆动夹伤手,不要专门跑去门框下。
```

**不同地点**:

**在床上**:
- 留在床上
- 用枕头保护头部
- 床边没有窗户和高大家具时,可以翻身滚到床边地上、紧贴床侧,同样护住头颈
- 震后下床前**先穿鞋**,地上很可能是碎玻璃(所以床边平时就放一双鞋和一支手电)

**在厨房**:
- 远离炉灶
- 远离吊柜
- 蹲在坚固家具旁
- 正在开火、晃动还不剧烈时,顺手关火;晃动已经很大就不要伸手去够,震后再关燃气总阀

**在卫生间**:
- 不要专门跑进卫生间躲避("卫生间最安全"缺乏依据,瓷砖、镜子、玻璃易伤人)
- 如果正在卫生间:就地伏地,护住头颈
- 远离镜子、玻璃隔断

**在高楼**:
- 不要跳楼!
- 不要乘电梯!
- 就地躲避
- 震后走楼梯疏散

高楼的晃动比低层更大、持续更久,书柜、电视甚至冰箱都可能被甩出去,所以就近找内墙角、坚固家具躲好。不要在晃动时冲向楼梯,楼梯间往往是晃得最厉害、最拥挤的地方。震后下楼前先看楼梯有没有明显断裂;遇到烟雾按[火场逃生](04-火灾.md#火场逃生)处理。

**在电梯里**(地震时恰好在电梯内):

```
1. 把所有楼层的按钮都按下,电梯在最近的楼层一停就出去,改走楼梯
2. 被困在电梯里: 不要扒门、不要从顶部爬出
3. 用电梯内的对讲或报警按钮、手机求救;保持冷静,蹲下护头,等待救援
```

**在平房或楼房一层**:

```
✓ 门就在身边、几步能到室外开阔地: 可以迅速跑出去,跑到远离房屋、电线杆的空地
✓ 来不及跑出、或者门外就是窄巷和高墙: 就近躲到结实的桌子、床边或内墙角
❌ 不要跑到屋檐下、院墙下、门口台阶上停留(房檐、瓦片、墙头最容易砸人)
❌ 土坯房、老旧砖房晃动时最容易整体倒塌,能跑出就跑出;来不及就躲到炕沿、
   结实的床边或家具旁,护住头颈
```

**在学校**:

```
上课时:
1. 听从老师指挥,迅速躲到课桌下或课桌旁,用书包护住头颈
2. 靠窗的同学离开窗户
3. 不要乱跑、不要冲向门口和楼梯

震后:
1. 在老师组织下有序撤到操场等开阔地,不要推挤,不要回教室拿东西
2. 在操场上远离教学楼、围墙、旗杆
3. 在约定地点等家长,不要自行离开

在操场上: 原地蹲下护头,远离建筑物和篮球架等高大物体
```

家长要提前了解学校的应急安排和接孩子的地点,见[应急通信与寻亲-家庭通信计划](06-应急通信与寻亲.md#灾前-家庭通信计划)。**震后不要一窝蜂冲进学校**,会堵塞疏散和救援通道。

#### 室外

```
✓ 跑到开阔地
✓ 远离建筑物
✓ 远离电线杆、路灯
✓ 远离立交桥、高架桥
✓ 蹲下,保护头部

避开:
❌ 建筑物旁(坠物)
❌ 狭窄街道
❌ 围墙、栅栏旁
❌ 悬崖边、河岸边
```

补充说明:

- 在街上,最危险的是**楼房外墙的玻璃、广告牌、空调外机、阳台上的花盆**被甩下来。正在楼边走时,如果周围没有空地,就用包护头,尽量靠近结实的建筑大门内侧,而不是贴着外墙走
- 不要钻进建筑物里"躲避",也不要在震动中跑进楼里找家人
- 远离加油站、化工厂、变压器、高压线
- 在桥上: 抓牢栏杆,震后尽快离开桥面

**在山区**:

```
地震在山区最大的危险是滚石、山崩、滑坡,而不是房屋:
✓ 立即离开陡坡下、悬崖下、坡脚和沟底
✓ 看到滚石: 向与滚石前进方向垂直的两侧躲避,不要顺着坡往下跑
✓ 来不及躲开时: 躲在结实的大树、大石或沟坎的背面(背对来石方向),蹲下护头
✓ 震后不要沿着陡峭的山间公路赶路,沿途塌方和落石可能持续多天
✓ 在河谷下游: 留意山体滑坡堵断河道形成"堰塞湖",一旦溃决,下游会突发洪水;
  见到河水突然断流,往两侧高处撤离
```

震后山区滑坡和泥石流的风险会持续很多年,见下文[泥石流](#泥石流)和[山体滑坡](#山体滑坡)。

#### 特殊场所

**在车内**:
```
1. 减速,打开双闪,靠边停车(避开桥梁、立交桥、隧道口、电线、高大建筑和陡坡)
2. 留在车内
3. 系好安全带
4. 压低身体,护住头颈,等震动停止(不要下车跑到楼边或桥下)
5. 震后小心驾驶(检查路况)
   - 绕开裂缝、塌陷、桥梁接缝错位的路段;不确定的桥不要上
   - 道路被堵时把车停到路边,钥匙留在车上,方便救援车辆通行

乘坐公交、火车、地铁时:
- 抓牢扶手,降低重心,躲在座位附近,不要跳车
- 停车后听从司乘人员指挥,不要自行扒门、跳下轨道
```

**在剧场、商场等公共场所**:
```
1. 不要拥挤冲向出口
2. 蹲在座椅旁、柱子边
3. 保护头部
4. 听从指挥
5. 震后有序疏散

商场、超市里还要注意:
✓ 选择结实的柜台旁、柱子边、内墙角
✗ 远离玻璃橱窗、高大货架(货物会砸下来)、吊灯和吊挂的广告牌
✗ 不要冲向电梯
✓ 在自动扶梯上: 抓紧扶手,蹲低,扶梯停稳后再走
✓ 在剧场、体育馆: 蹲在座位之间,用包护头,等晃动停止后按疏散指示有序离开
```

人群踩踏的危险往往大于地震本身。被挤在人流中时,顺着人流走,不要逆行、不要弯腰捡东西;双臂在胸前交叉护住胸口,留出呼吸空间;一旦被挤倒,尽量侧身蜷缩、双手护住头颈。

**在海边**:
```
⚠️ 地震后可能引发海啸!
1. 震后立即向高处转移
2. 远离海岸至少3 km
3. 爬到高处(至少30 m)

在海边感到强烈或持续很久的晃动,不要等官方警报,自己就开始往高处跑。
看到海水突然大幅退去,同样立即撤离。
```

海啸的详细应对见[海洋灾害-海啸](03-海洋灾害.md#海啸)。

### ❌ 地震时不要做

```
- 不要跳楼
- 不要乘电梯
- 不要靠近窗户
- 不要拥挤推搡
- 不要在狭窄过道逗留
- 不要使用明火
- 不要在晃动时往楼下跑、往楼里跑
- 不要站到阳台上、外墙边
- 不要为了拿财物、找手机耽误躲避
```

历次地震中都有人因跳楼、在楼梯上挤倒踩踏而伤亡,而他们所在的楼并没有倒。

### 地震后应对

#### 立即行动

晃动停止后,**楼里的人要尽快、有序撤到室外开阔地**,因为几分钟到几小时内很可能发生较强的余震,受损的房子可能在余震中倒塌。

**1. 检查伤情**:
```
- 先自己,再他人
- 提供急救
- 不要移动重伤者(除非有危险)
```

大出血先压迫止血,见[基础急救-止血方法](../01-日常疾病和伤害/00-基础急救知识.md#止血方法);怀疑脊柱受伤(颈背痛、手脚麻木无力)的人不要随意搬动,见[骨骼损伤-脊柱骨折](../01-日常疾病和伤害/03-骨骼损伤.md#脊柱骨折极其危险)。

**2. 检查隐患**:
```
- 闻:燃气泄漏
  * 如闻到,开窗通风
  * 关闭总阀
  * 不要开关电器(防火花)
  * 撤离并报告

- 看:电线是否损坏
  * 关闭电源总闸
  * 远离垂落电线

- 查:水管破裂
  * 关闭进水阀

- 看: 有没有起火
  * 小火立即扑灭;火势扩大就撤离并拨打119
```

燃气泄漏的完整处理见[火灾-燃气泄漏](04-火灾.md#燃气泄漏);来电后怎样安全恢复用电见[家庭用电安全-灾后恢复用电](../07-日常生活技能/08-家庭用电安全.md#灾后恢复用电)。

**3. 准备余震**:
```
✓ 余震可能持续数天甚至数月
✓ 可能和主震一样强
✓ 持续警惕
✓ 保持"伏地、遮挡、手抓牢"姿势

✓ 大地震后最初几天内余震最多、最强,之后逐渐减少
✓ 余震来时在室外: 远离建筑、围墙、山坡;在室内: 按震时的做法就近躲避
✓ 晚上睡觉: 鞋、手电、外衣放在手边;不要睡在受损的房子里
```

**4. 疏散**:
```
- 走楼梯(不要乘电梯)
- 携带应急包
- 关闭水电气
- 锁门(防盗)
- 前往安全地点

- 用手、包、书本护住头部下楼,防止余震时坠物
- 下楼时靠墙一侧走,不推挤;带上老人、孩子和行动不便的邻居
- 前往附近的应急避难场所或开阔地(公园、广场、学校操场),
  远离高楼、围墙、电线、山坡和河岸
- 到达后按约定向家人报平安
```

家人怎样联系、怎样约定集合点和寻人,见[应急通信与寻亲](06-应急通信与寻亲.md)。

#### 什么时候可以回屋

震后很多人急着回去拿东西,结果在余震中被砸伤。**判断房子能不能住,原则上听当地政府和专业人员的房屋安全评估结果。** 不少地方会在房屋门口张贴标识,按标识执行。

在专业人员到达之前,先用下表自己做个初步判断:

| 观察到的情况 | 判断 | 怎么办 |
|------|------|------|
| 房屋明显倾斜、局部倒塌,承重墙、梁、柱断裂或贯通的斜裂缝(常呈"X"形),楼板塌落 | 危险 | 绝对不要进入,在外面也要远离可能倒塌的范围 |
| 墙体有较宽裂缝、墙角松动,砖块掉落,门窗严重变形打不开,屋顶瓦片大面积滑落 | 可能危险 | 不要进入,等专业人员鉴定 |
| 只有墙面抹灰、瓷砖开裂脱落,细小的发丝状裂缝,门窗开关正常 | 多为轻微损坏 | 余震平息、官方允许后可以短时进入,取物后尽快出来 |
| 闻到燃气味、看到电线打火、听到房子"咔咔"作响 | 危险 | 立即离开,报告 |

```
即使判断为轻微损坏,回去时也要:
✓ 白天进去,不用明火照明(用手电)
✓ 先在门口看一看,确认没有燃气味、电线垂落
✓ 两人一起,一人在外面接应
✓ 速去速回,只拿必需品(药品、证件、衣物、被褥)
✓ 余震频繁的头几天,尽量在室外或帐篷、车里过夜
❌ 不要进入已坍塌部分的废墟翻找财物
```

**土坯房、老旧砖房、山坡上的房子**震后损坏往往比外表看起来严重,宁可多等几天。自建房屋的抗震做法见[长期住所-抗震](../07-日常生活技能/05-长期住所.md#抗震-生土房屋的生死线)。

#### 被困时

```
如果被困在废墟下:

✓ 保持冷静
✓ 保存体力
✓ 寻找水和食物
✓ 创造生存空间
✓ 定期呼救:
  - 敲击管道、墙壁
  - 吹哨子
  - 不要大声喊叫(浪费体力、吸入粉尘)
✓ 用手机:
  - 发送短信(更省电)
  - 定时开机
✓ 掩住口鼻(防尘)
✓ 等待救援

避免:
❌ 不要点火(消耗氧气、可能引起爆炸)
❌ 不要乱动(防坍塌)
```

**更具体的做法**:

```
1. 先稳住、先护住
   - 先检查自己有没有出血,有出血用衣物压住止血
   - 清除口鼻周围的灰土;用湿毛巾、衣服捂住口鼻,减少粉尘吸入
   - 闻到燃气或刺鼻气味: 用湿布捂住口鼻,千万不要点火、不要开关电器

2. 保持呼吸空间
   - 用手边的砖块、木棍、家具把头顶和胸前可能塌下来的东西支撑住
   - 胸口不要被压住,给胸廓留出起伏的空间
   - 清理身边可以挪动的碎物,但不要去拉扯承重的大块(会引起再次坍塌)
   - 朝有光亮、有空气流动的方向慢慢挪动;挪不动就不要硬挪

3. 求救要讲方法
   - 平时安静休息、闭目养神,节省体力
   - 定时敲击: 用硬物敲水管、钢筋、墙壁,声音能沿着管道和废墟传得很远
   - 有哨子就吹;用"三短声、停顿、重复"的节奏(国际通用求救信号)
   - 听到外面有人走动、说话、机器声时,再集中敲击和呼喊
   - 手机: 先发短信报告自己的位置和情况,然后关机或开省电模式,
     每隔几小时开机看一下

4. 水和食物
   - 身边能找到的饮用水、食物要省着吃,先喝水后吃东西
   - 水比食物重要得多: 不吃东西一般能坚持较长时间,缺水几天就有生命危险
   - 不确定是否干净的水(如水管、暖气管里的水)在没有其他水时也可以喝,
     活下来更重要,获救后告诉医生
   - 少说话、少动、保持身体不过热,都能减少水分消耗

5. 保持信心
   - 我国的地震救援会持续搜索很多天,也有被埋压一周以上仍获救的例子
   - 给自己找事做: 数数、定时敲击、回想家人,帮助保持清醒和希望
```

⚠️ **手脚或身体被重物长时间压住时**: 不要拼命自己挣脱。获救时,长时间被压的肢体突然解除压迫可能引发**挤压综合征**,有心律失常、肾衰竭甚至猝死的危险,要让救援人员知道自己被压了多久。详见[骨骼损伤-挤压伤](../01-日常疾病和伤害/03-骨骼损伤.md#挤压伤)。

求救信号的更多方式见[灾难应对-求救信号](README.md#-求救信号);信号弱时的通信方法见[应急通信与寻亲-灾中](06-应急通信与寻亲.md#灾中-怎样让消息发出去)。

#### 救人原则

震后最初的几十个小时里,大量被埋压的人是被**身边的家人、邻居**救出来的,专业救援队往往要过一段时间才能到。但不讲方法地挖掘,会让废墟再次坍塌,伤到被困者和自己。

```
先后顺序(防震减灾科普中常说的原则):
1. 先救近处的,后救远处的(不要舍近求远)
2. 先救容易救的,后救难救的
3. 先救青壮年和医护人员(他们获救后能加入救援,救更多的人)
4. 先救"生",后救"人": 先让被埋的人能呼吸(暴露头部、清除口鼻灰土),
   再去挖出全身;不要为了挖出一个人耽误了让好几个人先喘上气

怎样找人:
- 先问幸存者和邻居: 家里有几个人、地震时在哪个房间
- 喊话后安静下来听,注意敲击声、呻吟声
- 重点找床边、墙角、桌下、楼梯间等可能形成空间的地方

怎样挖:
✓ 先确定被困者头部的位置,先挖出头部和胸部
✓ 用手、小工具一点一点清理,接近人体时只用手
❌ 不要用铁镐、利器猛刨
❌ 不要扯动、撬动支撑着废墟的大梁、楼板
   (一边挖一边用木头支撑,防止二次坍塌)
❌ 不要强拉硬拽被困者的手脚,卡住时先清理卡住的东西

挖出后:
✓ 被困时间长的人,用布蒙住眼睛,避免强光刺激
✓ 清醒、能吞咽的人可以小口喝水;不要一下子大量喝水、进食
✓ 保暖
✓ 怀疑颈椎、腰椎受伤的,用门板等硬板平稳抬运,不要背、不要抱
✓ 尽快交给医护人员,告诉他们被压了多长时间、压在哪个部位

⚠️ 自己的安全第一:
- 房屋倾斜、余震频繁、闻到燃气、有电线带电时,不要进入
- 戴手套、穿结实的鞋,有条件戴安全帽
- 有专业救援队到场时,服从他们的指挥
```

⚠️ **被重物长时间压住(一般超过1小时左右)的人,尽量等专业救援人员到场再搬开重物**: 他们会先给伤员补液再解除压迫,能大大降低挤压综合征的死亡风险。只有现场必须马上救出(如余震、起火)时才自行搬开,搬开后的处理见[骨骼损伤-挤压伤](../01-日常疾病和伤害/03-骨骼损伤.md#挤压伤)。

找不到亲人、需要登记寻人见[应急通信与寻亲-家人失散后怎样寻找](06-应急通信与寻亲.md#家人失散后怎样寻找);遇难者的处理见[灾后遗体处理](07-灾后遗体处理.md);震后受到惊吓的家人和孩子怎样照顾,见[心理健康-心理急救](../01-日常疾病和伤害/10-心理健康.md#心理急救-怎样帮助身边的人)。

### 地震安全准备

#### 家庭准备

**固定家具**:
```
✓ 书柜、衣柜固定在墙上
✓ 重物放低处
✓ 柜门安装插销
✓ 固定热水器、冰箱
✓ 床头不要挂重物

具体做法:
- 高大家具用L形金属角码或防倾倒带,固定在墙体(不是在石膏板隔墙)上
- 柜子里重的东西放下层,玻璃器皿、瓶罐不要放在高处的开放架子上
- 搁板前沿钉一根挡条,防止东西滑出
- 电视、电脑显示器用防倾倒带固定或放在低处
- 燃气热水器用金属支架固定,燃气灶具连接用合格的软管并定期更换
- 窗户玻璃、柜门玻璃可以贴防爆膜,减少碎玻璃飞溅
```

**卧室和通道**:
```
✓ 床不要放在窗户下、吊灯下、高大家具旁
✓ 床头不要挂镜框、不要放重物
✓ 床边放一双鞋、一支手电、一个哨子
✓ 门口、走廊、楼梯不堆杂物,保证能马上出去
✓ 知道燃气总阀、电闸、自来水总阀在哪里,怎样关
```

**家中避震点**: 全家人在每个房间一起找一找: 哪里可以躲(结实的桌子下、内墙角),哪里危险(窗边、柜子旁、吊灯下)。让孩子亲自钻进桌子底下试一试。

**应急物资**:
- 参见[家庭应急包](README.md#-家庭应急包)
- 准备在门口、车里、工作地点

地震多发区的应急包里可以再加: 哨子(每人一个)、手套、口罩、结实的鞋、安全帽或头盔、帐篷或防水布(震后可能在室外住一段时间)。慢性病患者要备足常用药,见[慢性病用药储备](../01-日常疾病和伤害/08-慢性病用药储备.md)。应急包放在门边能一把拎走的地方,每半年检查一次,替换过期的水、食物和电池。

**制定计划**:
- 避震位置
- 疏散路线
- 集合地点
- 外地联系人

```
地震家庭计划要说清楚:
1. 在家时: 每个房间躲在哪里;震后谁去关燃气、谁带孩子和老人、谁拿应急包
2. 疏散路线: 从家到楼下开阔地的路线,至少两条
3. 集合点:
   - 第一集合点: 楼下或家门外的开阔空地(远离楼房、电线)
   - 第二集合点: 社区附近的应急避难场所、学校操场或公园
4. 白天各自在单位、学校时: 谁去接孩子;联系不上时各自去哪里会合
5. 外地联系人: 全家都向他报平安
6. 行动不便的家人(老人、残疾人、孕妇、婴幼儿): 指定专人负责
```

家庭通信计划、集合点的写法和寻人方法见[应急通信与寻亲-家庭通信计划](06-应急通信与寻亲.md#灾前-家庭通信计划),完整的家庭应急计划见[灾难应对-家庭应急计划](README.md#-家庭应急计划)。平时查一下所在社区的应急避难场所在哪里(常有绿色标识牌)。

**定期演练**:
- 家庭地震演练
- 每年至少2次

演练时真正做一遍: 喊"地震了"→ 各自就近躲避 → 一分钟后起身 → 一人去关燃气总阀,一人拿应急包 → 按路线走楼梯下楼 → 到集合点清点人数。练过的人在真地震时反应快得多。

#### 建筑安全

**抗震加固**:
- 老旧房屋抗震鉴定
- 必要时加固
- 符合抗震标准

```
❌ 不要私自拆改承重墙、在承重墙上开大洞、把阳台改造后堆放重物
❌ 不要在原有房屋上随意加层
✓ 农村自建房按当地的抗震设防要求建造,请有经验的工匠
✓ 发现墙体裂缝、地基下沉,请专业人员评估
```

自己建造土木房屋时的抗震措施(圈梁、墙角拉结、轻屋顶等)见[长期住所-抗震](../07-日常生活技能/05-长期住所.md#抗震-生土房屋的生死线)。

**了解房屋结构**:
- 承重墙位置
- 相对安全区域

### 地震强度参考

> 震级表示地震释放能量的大小,一次地震只有一个震级;烈度表示某地受影响和破坏的程度,离震中越远烈度越低。下表烈度为震中附近的大致对应,仅供参考。

| 震级 | 震中附近烈度(约) | 感觉和破坏 |
|------|------|------------|
| <3级 | I-II | 基本无感 |
| 3-4级 | III-IV | 室内有感,悬挂物摇晃 |
| 5-6级 | VI-VIII | 破坏性地震,建筑受损 |
| 7-8级 | IX-XI | 大地震,严重破坏 |
| >8级 | XII | 特大地震,毁灭性 |

震级每增加1级,释放的能量约增加30倍。同样震级的地震,震源越浅、离城镇越近、房屋越不抗震,破坏就越大。

## 泥石流

泥石流是山区沟谷中,暴雨或冰雪融水把大量泥沙、石块裹挟在一起形成的洪流。它**比山洪更稠、更重、冲击力更大**,能冲毁房屋、掩埋村庄,而且来得极快。

### 特征

- 暴雨后或连续降雨
- 山谷或沟谷
- 水流浑浊、夹带泥沙
- 伴有轰鸣声
- 流速快(可达数十 km/h)

泥石流常常不是在雨最大的时候发生,而是在**连续几天降雨之后又遇上一场暴雨**时发生,也可能在雨停后不久发生。地震后几年内,山区沟谷里松散的土石大量增加,泥石流会明显变多。

### 前兆

- 河水突然断流或水位突降
- 听到轰鸣声(像火车)
- 地面震动
- 山体裂缝
- 动物异常惊恐

```
怎样理解这些前兆:
- 沟里的水突然断流、突然变小: 上游很可能被滑坡或泥沙堵住,
  堵住的水和泥石随时会一起冲下来 —— 这是最危险的信号之一,不是"雨停了"
- 沟水突然变得很浑、很稠,夹带大量草木、泡沫
- 上游传来像火车、打雷一样的持续轰鸣,脚下能感到震动
- 沟谷两侧山坡有滚石、坍塌

⚠️ 出现任何一个,立即离开沟谷,往两侧高处撤,不要等着看
```

### 应对措施

#### 提前预防

**了解风险**:
```
高风险区域:
- 山区沟谷
- 暴雨后
- 植被破坏区
- 地震灾区
```

怎样认出"泥石流沟": 沟口有扇形的泥石堆积(洪积扇),堆积物里大小石块杂乱混在一起,沟床里有巨大的漂石,两岸树干上有被泥石擦伤的疤痕。读地形的方法见[地质矿物与土壤-读懂地形和地层](../08-基础科学知识/06-地质矿物与土壤.md#六读懂地形和地层)。

**避免**:
- 暴雨时不要在沟谷逗留
- 不要在沟口扎营
- 注意天气预报

```
住房和营地选址:
❌ 不要在沟口、沟底、洪积扇上、河道弯道的外侧(凹岸)建房或扎营
❌ 不要在沟谷里堆放垃圾、弃土弃渣(会堵塞沟道,成为泥石流的物源)
✓ 选在沟谷两侧明显高出沟床的稳定台地上,并且背后不是陡坡
✓ 预先找好从住处往两侧山坡高处撤离的路线,夜里也能走

雨季:
✓ 关注暴雨预警、地质灾害气象风险预警,收到预警就提前撤离,不要等看到泥石流
✓ 夜间暴雨时安排人值守,留意水声、轰鸣声
✓ 村里的避险预警信号(锣、哨、广播)平时就约定好
```

露营选址的更多原则和山洪的应对见[涉水、山洪与野外失温](../03-野外生存/08-涉水山洪与野外失温.md#山洪-溪谷里最大的危险);长期住房选址见[长期住所-选址](../07-日常生活技能/05-长期住所.md#选址)。

#### 发生时

```
⚠️ 立即行动!

1. 向两侧山坡跑!
   ✓ 垂直于泥石流方向
   ✓ 往高处跑
   ✓ 向两侧跑

   ❌ 不要顺沟向下游跑
   ❌ 不要往沟里跑

2. 丢弃物品
   - 抛弃沉重物品
   - 保留必需品

3. 不要上树
   - 可能被冲倒

4. 不要躲在凹坡
   - 可能被掩埋

5. 不要躲在陡坡下、土坎下、大石头背后
   - 泥石流会把它们一起推走,陡坡还可能同时滑塌

6. 不要停在桥上、沟边、弯道外侧
   - 泥石流在弯道处会冲高、漫出
```

泥石流往往一阵一阵地来,第一波过后会有更大的一波。**撤到高处后不要下来看,不要回去抢东西**;雨停后也要等一段时间、等当地通知后再返回。

### 逃生原则

```
✓ 向高处跑
✓ 向两侧跑
✓ 跑得越快越好
✓ 跑得越高越好
✓ 跑得越远越好
```

方向是第一位的: **与沟谷走向垂直,往两侧山坡的高处**。顺沟往下游跑,人是跑不过泥石流的。

## 山体滑坡

山坡上的土体或岩体,在重力作用下沿着某个软弱面整体往下滑动,就是滑坡。滑坡常见于**连续降雨、暴雨之后,以及地震、开挖坡脚之后**。有的滑坡一下子就滑下来;更多的滑坡在滑下来之前会缓慢变形几天到几年,只要留心,往往能提前发现。

### 前兆

- 山体出现裂缝
- 泉水、井水突然干涸或浑浊
- 山坡渗水增加
- 听到异常声响
- 树木倾斜
- 动物异常
- 地面下沉

```
更具体地看:
- 坡顶或坡上出现弧形(像月牙)的裂缝,并且越来越宽、越来越长
- 坡脚的地面鼓起、隆起、被挤出,或者坡脚突然冒出浑水
- 山坡上的树木东倒西歪("醉汉林");树干下部弯曲、上部直立("马刀树")
  说明这片坡过去一直在慢慢滑动
- 房屋墙壁开裂、门窗变形打不开、地坪下沉,而且越来越严重
- 电线杆、围墙歪斜,道路、水渠出现错位
- 坡上传出土石摩擦、断裂的声音,有小块土石不断滚落

⚠️ 变化在加快(裂缝一天比一天宽、掉土石越来越多)时,滑坡可能很快发生,立即撤离
```

### 裂缝的简易监测

在许多山区村庄,地质灾害"群测群防"就是靠村民自己看、自己量。发现山坡或房屋有裂缝时:

```
1. 在裂缝两侧各钉一根木桩(或在墙缝两侧画标记),量出两桩之间的距离,写下日期
2. 每天(下雨时每天几次)量一次,记在本子上
3. 也可以在墙缝上横着抹一条水泥砂浆或贴一张纸条,它被拉断说明裂缝在变宽
4. 裂缝在变宽、变长,特别是下雨后明显加快 → 立即报告村委会和自然资源部门,
   不要住在可能被波及的房子里
```

### 应对措施

#### 预防

```
避免:
❌ 在滑坡体上建房
❌ 破坏山体植被
❌ 在坡脚挖土
❌ 暴雨时登山

识别危险山体:
- 坡度陡(>40°)
- 土质松散
- 裂缝明显
- 植被破坏
```

```
房屋和坡地使用:
❌ 不要在陡坡下切坡建房(切掉坡脚等于抽掉山坡的"脚")
❌ 不要在坡上挖塘蓄水、大水漫灌,不要让生活污水、雨水随意往坡里渗
❌ 不要在坡顶堆土、堆石、盖重房子
✓ 房屋离开坡脚和坡顶边缘一段距离
✓ 坡上开挖排水沟,把雨水引走,不让它渗进坡体
✓ 坡面种植根系深的树和草,不要乱砍乱挖
```

另外,注意**不是所有陡坡都危险,也不是所有缓坡都安全**: 土质松散、有水渗出、下面有软弱地层的缓坡也会滑。陡坡、土质的判断见[地质矿物与土壤-读懂地形和地层](../08-基础科学知识/06-地质矿物与土壤.md#六读懂地形和地层)。

#### 发生时

```
1. 向两侧撤离!
   ✓ 垂直于滑坡方向
   ✓ 往稳定区跑

   ❌ 不要顺滑坡往下跑
   ❌ 也不要逆着滑坡方向往坡上跑(上方土体也在动)

2. 跑不掉时:
   - 抱紧大树(根深的)
   - 但不是最佳选择
   - 或蹲在结实的障碍物后,抱头护住头颈

3. 在家中:
   - 听到异响立即撤离
   - 不要犹豫收拾财物

4. 在车里:
   - 看到前方路面有落石、塌方,立即停车或倒车离开,不要强行冲过去
   - 不要把车停在陡坡下等待
```

#### 撤离后

```
✓ 不要立即返回
✓ 注意次生滑坡
✓ 远离危险区
✓ 报告有关部门

✓ 滑坡后往往还有后续滑动,雨季期间可能反复发生
✓ 不要去滑坡体上和坡脚围观、挖取财物
✓ 救人时先观察滑坡体是否还在动,安排专人在上方观察,一有动静就喊撤
✓ 滑坡堵断河道时,下游要防堰塞湖溃决,往高处撤
✓ 等当地政府和专业人员确认安全后再回家
```

## 地面塌陷

地面塌陷是地面突然陷落形成坑洞。在我国常见于:

- **岩溶(喀斯特)地区**: 地下的石灰岩被水溶蚀形成空洞,上面的土层陷落,西南地区较多
- **采矿区**: 地下采空区上方地面下沉、开裂
- **城市**: 地下水管、下水道长期漏水,把路基下的土冲空;地下施工、抽取地下水过多

### 塌陷的征兆

```
- 地面出现环形或弧形裂缝,地面局部下沉
- 井水、泉水突然变浑、水位突然变化;水塘、水田的水突然漏干
- 地下传来响声,有冒气、冒水、冒泥现象
- 房屋、围墙开裂并且在加剧,门窗变形
- 城市路面: 路面鼓包、下沉、出现网状或环形裂缝,窨井盖周围下陷,
  路边有不明原因的积水或冒水
```

### 遇到塌陷

```
✓ 发现征兆: 立即离开,绕开下沉、开裂的区域,并提醒其他人和车辆
✓ 拨打110或报告当地政府、自然资源部门;城市路面问题也可报给市政
✓ 在周围设置警示(绳子、树枝、醒目的物品),不要让人靠近
❌ 不要靠近坑边围观: 塌陷坑的边缘常常是被掏空的,会继续扩大
❌ 不要开车从下沉、开裂的路面上冲过去
❌ 不要往坑里填土、倒水

有人掉进塌陷坑:
- 不要贸然下去救,先拨打119
- 在远离坑边的稳固处,用绳子、长杆从远处施救,施救者身上也系好绳子
```

住房和水井选址要避开已知的溶洞区、采空区,见[长期住所-选址](../07-日常生活技能/05-长期住所.md#选址)。

## 火山喷发

我国境内有长白山天池等活火山,但近几百年没有大规模喷发。对大多数读者来说,火山更可能在出国旅行时遇到。**在火山地区,一切行动以当地政府的警报和疏散命令为准。**

### 危害

- 熔岩流
- 火山灰
- 火山碎屑流(极度危险,速度可达数百 km/h)
- 有毒气体
- 泥流
- 地震

其中**火山碎屑流**(高温气体和碎屑贴着地面冲下来)人和车都跑不过,唯一的办法是在它到来之前撤离危险区;熔岩流一般走得比人慢,反而较少直接伤人。火山泥流可以沿河谷冲出几十 km 远,在远离火山的河谷下游也会造成伤亡。

### 预警信号

- 地震频繁
- 地热增加
- 水质改变
- 气体释放
- 动物异常
- 官方预警

### 应对措施

#### 喷发前

```
如果在火山区:

✓ 关注官方预警
✓ 准备疏散
✓ 准备应急包
✓ 计划撤离路线
✓ 准备防护用品:
  - 护目镜
  - 口罩/湿布
  - 长袖衣物
```

#### 喷发时

**疏散**:
```
1. 立即撤离火山区
2. 远离河谷(泥流风险)
3. 向上风方向撤离
4. 驾车撤离:
   - 关闭窗户
   - 打开空调循环模式
   - 缓慢行驶
```

**防护**:
```
✓ 戴护目镜(防火山灰)
✓ 用湿布捂住口鼻
✓ 穿长袖长裤
✓ 进入室内:
  - 关闭门窗
  - 密封通风口
  - 呆在室内

有N95等防颗粒物口罩时优先使用,比湿布效果好。
低洼处可能积聚二氧化碳等有毒气体,不要进入山谷低地和地下室。
```

#### 火山灰防护

```
火山灰危害:
- 呼吸系统
- 眼睛刺激
- 损坏机械
- 压塌建筑

防护:
✓ 不要外出
✓ 戴口罩/呼吸器
✓ 护目镜
✓ 清除屋顶积灰(防压塌)
✓ 不要驾车(损坏发动机)

说明:
- 火山灰是磨碎的岩石和玻璃颗粒,不是柴火灰,很硬、很锋利
- 被雨淋湿的火山灰非常重,积了几 cm 就可能压塌平屋顶,要及时清扫
- 上屋顶清灰要防滑、防坠落,不要一个人上去
- 哮喘、慢性肺病患者、老人和孩子尤其要待在室内
- 戴隐形眼镜的改戴框架眼镜
```

#### 喷发后

```
✓ 等待官方通知
✓ 不要立即返回
✓ 清理火山灰:
  - 戴防护装备
  - 避免扬尘
  - 用水冲洗(先喷少量水润湿再扫,不要用大水把灰冲进下水道堵塞管道)
✓ 检查饮用水(可能污染)
✓ 检查建筑结构
```

## 📝 总结要点

### 地质灾害共同特点

- 突发性强
- 破坏力大
- 难以准确预测
- 可能引发次生灾害

### 应对核心原则

```
1. 事前准备
   - 了解风险
   - 准备物资
   - 制定计划
   - 定期演练

2. 事中应对
   - 保持冷静
   - 快速反应
   - 正确躲避
   - 及时撤离

3. 事后处理
   - 检查伤情
   - 警惕余震/次生灾害
   - 等待救援
   - 有序恢复
```

### 记住

```
✓ 生命第一
✓ 掌握正确逃生方向
✓ 不要贪恋财物
✓ 服从专业指挥
✓ 互助合作

地震: 伏地、遮挡、手抓牢;不跳楼、不乘电梯;震后撤到开阔地,防余震
被困: 保存体力,敲击求救,保护呼吸空间;长时间被压的人等专业人员来解救
泥石流: 离开沟谷,往与沟谷垂直的两侧高处跑
滑坡: 往滑动方向的两侧跑,不顺着跑也不逆着跑
塌陷: 远离坑边,设警示,报告
```
