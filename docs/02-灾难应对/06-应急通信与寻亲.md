## 灾前: 家庭通信计划

灾难发生时,家人往往分散在单位、学校、路上。**提前约定好,比灾后再想办法有效得多。**

```
1. 抄写重要电话
   - 手机没电、丢失后,很多人发现一个电话号码都记不住
   - 把家人、亲友、单位、学校的电话写在纸上,放在钱包、应急包里
   - 孩子的书包里也放一份

2. 约定一位外地联系人
   - 选一位住在外地的亲友
   - 灾区本地电话打不通时,往外地打往往更容易接通
   - 全家人都向这位联系人报平安,由他转告其他人

3. 约定集合地点
   - 第一集合点: 家门外的安全空地
   - 第二集合点: 社区内(学校操场、公园)
   - 第三集合点: 社区外(亲友家、指定避难场所)
   - 写下来,确保孩子和老人也知道

4. 了解孩子学校的应急安排
   - 学校发生灾害时如何疏散、在哪里接孩子、谁可以接

5. 定期演练(每年至少一次)
```

详细的家庭应急计划见[灾难应对-家庭应急计划](README.md#-家庭应急计划)。

## 灾中: 怎样让消息发出去

灾后通信网络常常因为基站损坏、停电或大量用户同时拨打而拥堵。

```
✓ 发短信,少打电话
  - 短信占用的网络资源少,在网络拥堵时更容易发出去
  - 网络恢复时会自动补发
  - 一条短信说清: 我是谁、在哪里、是否安全、接下来去哪

✓ 打电话要简短
  - 说完关键信息就挂断,把线路留给其他人和求救电话

✓ 有网络时
  - 用社交软件发消息、发送实时位置
  - 在家庭群里报平安(一条消息全家都能看到)

✓ 被困时
  - 优先拨打110、119、120(紧急呼叫在信号弱时也会尝试接入任何可用网络)
  - 说话不方便时,可发短信到12110报警(号码后加省份代码)
  - 节省电量,定时开机查看

✓ 部分手机支持卫星通信或北斗卫星消息功能,在没有地面信号时也可发送求救信息
  - 平时了解自己的手机是否支持、如何使用
```

求救信号(声音、视觉)见[灾难应对-求救信号](README.md#-求救信号)。

## 获取官方信息

```
✓ 收音机: 停电断网时最可靠的信息来源
  - 应急包里准备手摇或太阳能充电的收音机
  - 灾害期间关注当地广播电台的应急广播

✓ 预警短信
  - 国家突发事件预警信息通过"12379"等渠道发布
  - 收到预警短信时认真阅读,按要求行动
  - 也可以安装国家预警信息发布的官方应用

✓ 当地政府、应急管理部门、气象部门的官方账号

✓ 社区、村委会的广播和通知

⚠️ 只信官方渠道发布的信息,不信谣、不传谣
   (不确定的消息先核实,不要随手转发)
```

## 手机省电

```
✓ 打开省电模式或低电量模式
✓ 调低屏幕亮度,缩短自动锁屏时间
✓ 关闭不需要的定位、蓝牙、无线网络、后台应用
✓ 信号很弱时手机会持续搜索信号,耗电很快
  → 没有信号时开飞行模式,定时(如每小时)关闭飞行模式查看一次消息
✓ 少看视频、少刷社交软件
✓ 寒冷会让电池电量快速下降: 把手机放在贴身的口袋里保暖

充电:
✓ 应急包里放充电宝(平时保持充满)和充电线
✓ 手摇充电器、太阳能充电板(见照明与能源-小型太阳能)
✓ 汽车点烟器充电(注意在室外通风处启动汽车,防一氧化碳中毒)
```

## 对讲机

手机网络中断时,对讲机可以在家人、邻居之间短距离通话。

```
✓ 公众对讲机: 使用409MHz频段,发射功率不超过0.5瓦,免执照使用
  - 通话距离一般为几百米到几公里(受地形、建筑物影响很大)
  - 适合同一小区、同一村子内的家人联络
✓ 提前约定好使用的频道和呼叫时间(如每个整点开机5分钟)
✓ 备足电池
✓ 平时试用,熟悉操作

❌ 业余无线电台需要考取执照才能使用,不要未经许可发射
❌ 不要在机场、飞机上使用对讲机
```

## 家人失散后怎样寻找

```
1. 先到约定的集合地点等候和查看
2. 联系外地联系人,问有没有其他家人的消息
3. 在家门口、集合点留下纸条:
   - 写清: 我是谁、什么时间、人是否安全、现在去了哪里、怎么联系
   - 用防水的方式(装进塑料袋)贴在显眼处
4. 到当地政府设置的避难场所、安置点登记和查询
   - 登记自己的信息,方便亲人查找
   - 查询失散家人是否已在其他安置点登记
5. 向公安机关报告,提供失散者的照片和特征
6. 联系红十字会等救援组织,了解寻人服务

孩子、老人走失时,立即拨打110报警,不需要等24小时
(见儿童安全-防走失)

⚠️ 网上发布寻人信息时:
- 提供必要的信息(姓名、照片、最后出现的地点、联系方式)
- 注意保护隐私,警惕借寻人诈骗的人(不要轻易转账)
```

## 📝 应急通信要点

```
1. 把重要电话写在纸上,放在钱包、应急包、孩子书包里
2. 约定外地联系人和三个集合地点
3. 灾后发短信比打电话容易接通;电话简短
4. 收音机是停电断网时最可靠的信息来源
5. 没信号时开飞行模式省电,定时查看
6. 公众对讲机免执照,适合小范围联络
7. 失散后: 集合点、留纸条、安置点登记、报警
```
