# 气象灾害应对指南

气象灾害大多**有预报、有预警**: 台风提前几天就能看到路径,暴雨、寒潮、高温提前一两天发布预警。和地震不同,绝大多数伤亡发生在"知道要来却没当回事"的人身上。本章按我国应急管理部、中国气象局等官方科普的主流建议整理,具体行动以当地政府和气象部门的通知为准。

## 预警信号: 看懂颜色和等级

我国的气象灾害预警信号分为台风、暴雨、暴雪、寒潮、大风、沙尘暴、高温、干旱、雷电、冰雹、霜冻、大雾、霾、道路结冰等种类,每种按严重程度用颜色分级。收到预警的渠道见[应急通信与寻亲-获取官方信息](06-应急通信与寻亲.md#获取官方信息)。

### 四种颜色代表什么

| 颜色 | 级别 | 含义 | 普通人应该做什么 |
|------|------|------|------------------|
| 🔵 蓝色 | Ⅳ级(一般) | 可能出现灾害性天气,影响一般 | 关注后续预报;检查应急包、手机充电;取消不必要的户外远行 |
| 🟡 黄色 | Ⅲ级(较重) | 影响较大 | 做好防御准备: 加固、收物、储水;户外作业和集体活动考虑停止;危险地带的人准备转移 |
| 🟠 橙色 | Ⅱ级(严重) | 影响严重 | 停止户外作业和露天集体活动,尽量留在安全的室内;危险地带的人**按通知立即转移**;学校可能停课 |
| 🔴 红色 | Ⅰ级(特别严重) | 灾害已经或即将造成严重破坏 | 待在坚固建筑的安全位置,非必要绝不外出;停工停课停业;听从政府统一指挥 |

```
⚠️ 几点容易误解的地方:
1. 不是每种预警都有四种颜色
   - 例如雷电、高温、沙尘暴只有黄、橙、红;干旱、冰雹只有橙、红
   - 所以"只是黄色"不代表"最低一级",要看具体是哪种灾害
2. 预警是"即将发生"的提醒,不是事后通报
   - 暴雨红色预警的标准是"3小时内降雨量将达100 mm以上",
     等看到雨这么大时,低洼处可能已经开始进水
3. 预警会升级,也会解除
   - 升级时行动要跟着升级;没有收到"解除"之前,不要以为已经结束
4. 各地的具体标准和应对要求略有差别,以当地发布为准
5. 当地政府发布的"转移通知""停课通知"比预警颜色更具体,优先执行
```

### 几种常见预警的标准(参考)

| 种类 | 蓝色 | 黄色 | 橙色 | 红色 |
|------|------|------|------|------|
| 暴雨 | 12 h内降雨量≥50 mm | 6 h内≥50 mm | 3 h内≥50 mm | 3 h内≥100 mm |
| 台风 | 24 h内平均风力≥6级或阵风≥8级 | 24 h内平均≥8级或阵风≥10级 | 12 h内平均≥10级或阵风≥12级 | 6 h内平均≥12级或阵风≥14级 |
| 寒潮 | 48 h内降温≥8°C,最低气温≤4°C | 24 h内降温≥10°C,最低气温≤4°C | 24 h内降温≥12°C,最低气温≤0°C | 24 h内降温≥16°C,最低气温≤0°C |
| 高温 | — | 连续3 d最高气温≥35°C | 24 h内最高气温≥37°C | 24 h内最高气温≥40°C |

风力"级"和风速(m/s)的对应见[天气观测与预报-风力等级](../08-基础科学知识/07-天气观测与预报.md#34-风力等级)。

## 台风/飓风

台风的危害来自三个方面: **大风**(吹倒树木、广告牌、简易房,高空坠物)、**暴雨**(内涝、山洪、滑坡)、**风暴潮**(沿海海水倒灌)。历史上台风造成的死亡,多数来自后两者,而不是风本身。

### 台风等级(中国标准)

| 级别 | 风速 | 影响 |
|------|------|------|
| 热带低压 | <17.2 m/s | 轻微 |
| 热带风暴 | 17.2-24.4 m/s | 中等 |
| 强热带风暴 | 24.5-32.6 m/s | 较大 |
| 台风 | 32.7-41.4 m/s | 严重 |
| 强台风 | 41.5-50.9 m/s | 极严重 |
| 超强台风 | ≥51.0 m/s | 毁灭性 |

```
看台风预报时注意:
- 路径预报是一个"扇形"范围,不是一条线;不在中心线上也可能受严重影响
- 登陆点右侧(按台风前进方向)通常风更大、风暴潮更高
- 台风登陆后风力减弱,但降雨可能持续几天,内陆山区的山洪、滑坡往往发生在登陆之后
- 移动慢、"停滞打转"的台风,累积雨量特别大
```

### 台风来临前

**24-48小时前**:
```
关注预报:
✓ 气象局预警
✓ 台风路径
✓ 预计登陆时间和地点
✓ 影响范围
✓ 当地政府的转移、停课、停工通知

准备物资:
✓ 食物和水(至少3天)
  - 饮用水每人每天约2-3 L;另外把浴缸、水桶装满,停水时冲厕所、洗漱用
  - 不需要煮的食物: 面包、饼干、罐头、方便食品
✓ 应急包
✓ 手电筒、电池
✓ 收音机(停电断网时最可靠的信息来源)
✓ 急救包
✓ 药品(慢性病患者备足一周以上的药)
✓ 重要文件防水保存(装进密封袋)
✓ 充满电(手机、充电宝)
✓ 少量现金(停电时无法电子支付)
✓ 车辆加满油,不要停在大树下、广告牌下、低洼处和容易进水的地下车库
```

应急包的内容见[灾难应对-家庭应急包](README.md#-家庭应急包)。

**12-24小时前**:
```
加固房屋:
✓ 关紧门窗,插好插销;窗户松动的用木条、钉子临时固定
✓ 玻璃窗: 拉上窗帘,人远离窗户
  - 贴胶带(米字形)作用有限: 不能防止玻璃被打碎,只能稍微减少碎片飞散,
    不要因为贴了胶带就待在窗边
  - 临街或迎风的大玻璃窗,有条件时用木板、防风板从外面封住
✓ 收起阳台、窗台、屋顶的花盆、杂物、晾衣杆(高空坠物会砸死人)
✓ 检查空调外机、太阳能热水器、广告牌、雨棚是否固定牢靠
✓ 清理排水沟、地漏、阳台排水口
✓ 固定室外易飞物品
✓ 农村:
  - 铁皮、石棉瓦、彩钢板屋顶用绳索拉紧,或压上沙袋
  - 加固或拆除不牢固的棚架、大棚薄膜
  - 牲畜转移到地势高、结实的圈舍
✓ 沿海: 渔船回港避风,船上和海上养殖排上的人员上岸

撤离准备:
✓ 如在危险区,听从指挥撤离
✓ 低洼地带
✓ 危房
✓ 沿海地区
✓ 携带应急包
```

### 什么时候必须撤离

```
以下地方的人,收到转移通知就走,不要等到风大雨大:
- 沿海低洼地、海堤附近(风暴潮可能让海水漫进来几公里)
- 江河、水库下游,以前被淹过的低洼村庄和小区
- 山区的沟谷口、陡坡下、河边(山洪、滑坡、泥石流)
- 危房、土坯房、活动板房、工棚、简易房、彩钢房
- 地下室、半地下室的住户
- 船上、海上养殖排、海边帐篷

为什么要早走:
- 风力达到8级以上时,人在户外行走困难,飞来的杂物能致命
- 路可能被淹、被倒树和滑坡堵住,救援车辆也进不来
- 夜里撤离比白天危险得多

撤离时:
✓ 带上应急包、药品、证件、手机和充电宝
✓ 关闭电源总闸、燃气阀门,锁好门
✓ 按指定路线去指定的安置点,告诉亲友你去了哪里
✓ 帮助老人、孩子、病人、孕妇和行动不便的邻居
❌ 预警解除前不要私自返回取东西
```

风暴潮见[海洋灾害-风暴潮](03-海洋灾害.md#风暴潮);山洪、滑坡见[泥石流](01-地质灾害.md#泥石流)、[山体滑坡](01-地质灾害.md#山体滑坡)。

### 台风期间

**在室内**:
```
✓ 远离门窗
✓ 躲在内墙角、卫生间(没有窗户、四面是墙的小房间最安全)
✓ 房屋进水或线路受损时,关闭电源总闸(不要站在水里拉闸)
✓ 雷雨大风时尽量不使用电器
✓ 储水(可能停水)
✓ 保持通讯畅通,手机省电,用收音机听消息
✓ 楼房住户: 高层风更大,可以待在较低楼层的内部房间
✓ 门窗被吹开: 不要去顶门、关窗(大风中门窗玻璃可能突然爆裂),躲到内部房间

❌ 不要:
- 外出(包括去看海、拍照、抢收东西、"看看车怎么样了")
- 靠近窗户
- 使用明火(停电时用手电筒,燃气可能泄漏)
- 乘电梯(停电会被困)
```

**台风眼**:
```
⚠️ 警惕台风眼!
- 台风眼经过时风平浪静,甚至能看到蓝天
- 但很快第二次风暴来袭
- 不要以为台风过去而外出
- 继续躲避

为什么特别危险:
- 台风中心的"眼"直径一般几十公里,经过一个地方要几十分钟到一两个小时,
  足够让人走出门、走到海边或爬上屋顶修东西
- 眼过去后,风会从**相反方向**突然刮来,风力和前半段一样强
- 前半段已经被吹松的屋顶、门窗、树木,这时从另一侧受力,最容易倒塌和飞走
- 风暴潮也可能在后半段才最高

怎样判断台风真的过去了:
✓ 以官方解除或降低预警为准
✓ 风雨停了不到一两个小时,又处在台风中心经过的路径上,很可能只是台风眼
```

**在室外**(被困):
```
1. 寻找坚固建筑躲避(钢筋混凝土楼房最好,不要进简易房、工棚)
2. 避开:
   ❌ 大树下
   ❌ 广告牌下
   ❌ 临时建筑、脚手架、塔吊
   ❌ 电线杆、变压器附近
   ❌ 楼房的阳台、窗户下方(高空坠物)
   ❌ 海边、河边、桥上
3. 趴在地势低的地方(但不要在会积水的沟里、河边)
4. 抓紧固定物
5. 保护头部
6. 弯腰、侧身、小步走,不要在大风中奔跑
```

**在车内**:
```
- 立即停车
- 避开树木、电线、广告牌
- 不要停在低洼处、桥下、地道里(可能被淹)
- 留在车内
- 系好安全带
- 趴下保护头部
- 风雨小一些时,开到附近坚固的建筑(加油站便利店、商场、停车楼)里躲避
```

### 台风后

```
检查:
✓ 房屋结构(墙体裂缝、屋顶塌陷、地基被淘空的,不要进去)
✓ 燃气泄漏(闻到气味: 不开关电器、不点火,开窗,到室外打电话)
✓ 电线损坏(泡过水的线路和电器,请电工检查后再通电)
✓ 水质安全

清理:
✓ 积水(防蚊虫)
✓ 倒塌物
✓ 清洁消毒

注意:
❌ 不要触碰垂落电线(距离至少保持几米,并报告电力部门)
❌ 不要饮用未经处理的水
❌ 不要急于返回危险区
❌ 不要用发电机、炭火在室内取暖做饭(一氧化碳中毒)
✓ 注意次生灾害(滑坡、洪水),台风过后几天内山区仍可能发生
✓ 清理倒树、修屋顶等高处作业要两人以上配合,防止摔伤和砸伤
```

房屋进水后的清理、消毒见下方[洪水后](#洪水后);来电前的检查见[家庭用电安全-灾后恢复用电](../07-日常生活技能/08-家庭用电安全.md#灾后恢复用电)。

## 洪水

洪水是我国伤亡最多的气象灾害之一。**淹死人的往往不是很深的水,而是流动的水**: 人在齐膝深的急流里就站不稳,车辆在浅浅的流水里就会被冲走。

### 洪水类型

**暴雨洪水**: 短时强降雨
**河流泛滥**: 持续降雨、上游水库泄洪
**山洪**: 山区突发洪水,极度危险
**城市内涝**: 排水系统超负荷

山区溪谷的山洪征兆和逃生见[涉水、山洪与野外失温](../03-野外生存/08-涉水山洪与野外失温.md#山洪-溪谷里最大的危险)。

### 洪水前

**关注预警**:
```
✓ 天气预报
✓ 河流水位
✓ 官方预警
✓ 上游降雨情况
✓ 水库泄洪通知(下游河道可能在几个小时内大幅涨水)
```

**准备**:
```
✓ 应急包放在易取处
✓ 规划撤离路线(至少两条,避开低洼路段、桥梁和地道)
✓ 了解高地位置(附近的高地、坚固的多层楼房、指定的避险安置点)
✓ 准备救生衣/漂浮物
  (没有救生衣时: 盖紧盖子的空塑料桶、泡沫板、轮胎内胎、木盆都能用)
✓ 重要物品移至高处
✓ 一楼、地下室住户: 准备沙袋或挡水板堵门口;家电、粮食搬上楼
✓ 有地下车库的: 暴雨预警发布时提前把车开到地势高的地面停车场
```

### 洪水时

**撤离**:
```
立即撤离如果:
- 收到撤离命令
- 水位快速上涨
- 房屋进水
- 周围已被淹

撤离要点:
✓ 往高处走
✓ 避开河道、山谷
✓ 携带应急包
✓ 关闭电源、燃气
✓ 不要单独行动
✓ 走熟悉的路;天黑后看不清水深和路面,能在天黑前走就不要拖
```

**涉水安全**:
```
⚠️ 涉水极度危险!

如必须涉水:
- 水深>膝盖,不要冒险
- 水流>站稳,不要涉水
- 使用棍子探路(积水下可能是被冲开的井盖、沟渠、塌陷的路面)
- 抓紧固定物
- 集体手拉手(增加稳定)
- 穿着鞋,不要赤脚(碎玻璃、铁钉)
- 远离电线杆、路灯杆、变压器(水可能带电)

记住:
- 约15 cm深的快速流水就能把人冲倒
- 约30 cm深的流水就能让小汽车漂起来、被冲走
- 约60 cm深的流水能冲走包括越野车在内的大多数车辆
```

野外过河的判断和方法见[判断能不能过](../03-野外生存/08-涉水山洪与野外失温.md#判断能不能过)。

**驾车遇洪水**:
```
❌ 绝对不要:
- 开车进入淹水区
- "我能开过去"的想法非常危险!
- 开进积水的立交桥下、隧道、下穿通道、漫水桥(最常见的致死地点)

如被困车内:
1. 立即弃车
2. 往高处走
3. 如车辆漂浮:
   - 打开车窗/打破车窗
   - 爬到车顶
   - 等待救援
```

涉水行车和车辆落水的具体做法见下方[城市内涝](#城市内涝-地下空间涉水行车和井盖)和[车辆落水自救](#车辆落水自救)。

**被困建筑**:
```
1. 往高处移动(楼顶)
   - 进阁楼时一定带上能破开屋顶的工具,防止水涨上来被困在阁楼里
2. 携带:
   - 手机
   - 哨子
   - 鲜艳衣物
   - 饮用水、食物、手电筒
3. 发出求救信号
   - 白天: 在楼顶挥动鲜艳的衣物、床单,铺开写上"SOS"
   - 夜里: 手电筒、手机闪光灯一明一暗
   - 哨子: 吹三短声,停一会儿再吹
   - 打110/119/120报告位置、人数、有没有伤病员和老人孩子
4. 不要进入电梯
5. 不要轻易游泳逃生(水流湍急)
6. 救援船来时听从指挥,一个一个上船,不要一拥而上
```

**急流自救**:
```
如被冲入急流:
1. 面朝上,脚朝下
2. 仰泳姿势
3. 脚在前防撞击
4. 顺流而下
5. 斜向岸边移动
6. 抓住漂浮物
7. 抓住岸边可及物

❌ 不要在急流里试图站起来(脚会卡进石缝或杂物,被水按倒)
❌ 不要抱住倒树、桥墩前的杂物堆(水会把人压进下面)
```

详细做法和怎样在岸上救人见[落入急流](../03-野外生存/08-涉水山洪与野外失温.md#落入急流);救上岸后的急救见[溺水](../01-日常疾病和伤害/05-急性症状.md#溺水)。

### 城市内涝: 地下空间、涉水行车和井盖

城市里短时暴雨,半小时就能让低洼路段、地下空间积水。2021年7月郑州特大暴雨中,地铁列车在隧道里被困、京广快速路隧道被淹,都造成了人员遇难。

**地下车库、地下室、地下商场**:
```
⚠️ 地下空间进水速度远比想象的快,而且只有几个出口

✓ 暴雨预警时: 提前把车开出低洼的地下车库;住地下室、半地下室的人转移到地面以上
❌ 车库已经开始进水: 不要再下去挪车、抢东西
   - 水从入口坡道灌进来,人往外走是逆着水流上坡
   - 停电后卷帘门、电动门、电梯都可能打不开
✓ 已经在地下时发现进水:
  1. 立即放弃车辆和物品
  2. 走人行楼梯往上,不要乘电梯
  3. 门被水压住推不开时,不要硬推,找其他出口或待在高处呼救
  4. 水深到膝盖以上时,扶着墙、栏杆走,防止滑倒
```

**地铁**:
```
✓ 暴雨天出门前查看地铁是否停运、限流;车站入口有积水倒灌时不要进站
✓ 在车站内: 听从工作人员指挥,往地面出口走;不要逗留在站台和通道低处
✓ 列车被困在隧道里:
  - 保持冷静,听车厢广播和工作人员指挥
  - 不要自己扒车门、砸窗跳到轨道上(有的线路轨道旁有带电的供电轨,
    隧道里可能有积水和来往的列车)
  - 需要疏散时,按指挥沿疏散平台或轨道走向最近的车站,互相照顾
  - 车厢进水时,站到座椅上,用手机向外报告车次、车厢号、位置和人数
  - 空气不好时尽量少说话、少走动,保存体力
```

**涉水行车**:
```
能不过就不过。官方的建议是: 水深超过轮胎一半,或者看不清水深,就不要过。

✗ 以下情况一律不过:
  - 水在流动(哪怕只有浅浅一层)
  - 立交桥下、隧道、下穿通道、漫水桥
  - 看不到路面和路沿,不知道下面有没有坑、井盖
  - 前车在水里熄火了

✓ 确实只是浅积水、必须通过时:
  1. 先停车观察,看别的车过的时候水到哪里
  2. 低速挡,匀速、一口气开过去;不要中途停车、换挡、猛踩油门(会激起浪,水从进气口进入发动机)
  3. 和前车保持距离,不要跟着前车的浪
  4. 过去后轻踩几下刹车,把刹车片上的水蒸干,确认刹车正常

⚠️ 车在水里熄火: 不要再打火启动(发动机进水后再启动会彻底损坏);
   水在上涨或流动时,立即下车往高处走,不要留在车里等
```

**行人和井盖**:
```
积水下面看不见被冲开的井盖、排水口、施工坑,掉进去几乎没有生还机会。

✓ 尽量不在积水中行走;必须走时:
  - 沿着建筑物一侧、地势高的人行道走,不要走路中间和路边低处
  - 用长棍、雨伞在前面探路,一步一探
  - 结伴走,互相拉着
✓ 看到水面有漩涡、往下"吸"、或者冒水翻花的地方,远远绕开
  (那里通常是打开的井盖或排水口)
✓ 远离电线杆、路灯、变压器、配电箱、广告牌(漏电)
  - 看到积水里有电线、冒火花,或者附近的人突然倒下,不要靠近,
    单脚或双脚并拢小跳离开,并报警
❌ 不要让孩子在积水里玩
```

### 车辆落水自救

车辆冲进河里、深水里后,通常会先漂浮一小会儿(几十秒到一两分钟),这是最好的逃生时间。

```
1. 立即解开安全带(先解自己的,再帮孩子)
2. 马上打开车窗
   - 电动车窗在电路进水失灵前通常还能用,不要犹豫
   - 先开窗,后打电话(报警留到出去以后)
3. 车窗打不开时,砸破侧窗
   - 用车上的安全锤,或拔下座椅头枕,用金属插杆
   - 砸侧窗玻璃的边角(四个角最容易破),不要砸中间,也不要砸前挡风玻璃(夹层玻璃砸不破)
   - 注意: 有的车侧窗也是夹层玻璃,很难砸破,这时按下一步
4. 从车窗爬出: 孩子先出(大孩子先出,再把小孩子递出去),大人随后
5. 出去后爬上车顶等待救援,或者游向岸边;不要回车里拿东西
6. 窗和门都打不开时:
   - 不要在车里乱撞消耗体力
   - 水进到快没过头部时,车内外水压接近相等,这时深吸一口气,用力推门或从破窗处出去

❌ 不要一开始就推车门: 车外水压很大,门推不开,反而浪费最宝贵的时间
✓ 平时在驾驶座旁放一把安全锤,确认手能够到
```

### 农村洪水: 转移和上高处

```
平时:
✓ 弄清楚村里的转移路线、安置点在哪里,以及谁负责通知(广播、锣、喇叭、电话)
✓ 家里谁负责背老人、抱孩子,事先分好工
✓ 河边、沟口的房子,汛期晚上睡觉前把应急包放在门口

收到转移通知或听到报警时:
1. 立即走,不要等水进屋再走,不要先去收粮食、赶牲畜
2. 先转移老人、孩子、病人、孕妇和残疾人
3. 按指定路线去安置点或附近的高地;没有指定路线时,往和河道垂直的方向的高处走
4. 牲畜: 来得及就赶到高处;来不及时解开缰绳、打开圈门,让它们自己逃
5. 到了安置点向村干部报到,让人知道你已安全转移
6. 水退之前不要私自回村(二次涨水、房屋倒塌时有人员死亡)

来不及转移、被困时:
✓ 上高处: 坚固的楼房二层以上、屋顶、高地、结实的大树
❌ 不要躲在土坯房、砖木平房里: 墙泡水后会突然整面倒塌
❌ 不要爬电线杆、铁塔,不要靠近变压器
✓ 把能漂的东西准备在身边: 门板、木盆、塑料桶、轮胎、泡沫板、木床板
✓ 水快淹到所在位置、没有更高的地方时,才抱着漂浮物离开
✓ 发出求救信号(见上方"被困建筑")

堤坝:
✓ 发现堤坝渗水、冒水(管涌)、裂缝、塌陷,立即报告村干部,并远离堤坝下方
❌ 不要在河堤上看水、拍照
```

### 洪水后

```
返回前:
✓ 等待官方通知
✓ 确认安全

检查房屋:
✓ 结构损坏
✓ 电气安全(请专业人员)
✓ 燃气泄漏

清理:
✓ 排水(慢慢排,防结构损坏)
✓ 清洁消毒
✓ 丢弃污染食物
✓ 不要饮用井水(污染)

健康:
✓ 预防疾病(霍乱、伤寒)
✓ 避免接触污水
✓ 清洁伤口
✓ 防蚊虫
```

#### 房屋的检查和清理

```
1. 进屋前先在外面看: 墙体倾斜、大裂缝、地基被冲空、屋顶下沉的,不要进去
2. 白天进去,带手电,不要点火;先开门窗通风
3. 先拉总闸(人不要站在水里),泡过水的线路和电器请电工检查后再通电
4. 清淤时穿胶鞋或雨靴、戴手套,尽量不让皮肤直接接触泥水;
   小心淤泥里的碎玻璃、铁钉和被冲进屋的蛇、老鼠
5. 地下室积水: 不要一次抽干。外面的土还泡着水,压力很大,
   一下抽空可能把墙压垮;每天抽掉大约三分之一
6. 防霉: 尽量在一两天内把房子晾干(开窗、风扇)
   - 泡水的床垫、沙发、地毯、纸质物品、石膏板墙面通常要丢掉
   - 硬表面(地面、墙面、家具、餐具)先用清水和洗涤剂洗净,再用含氯消毒液擦拭或浸泡
   ⚠️ 含氯消毒液(84、漂白水)不能和洁厕灵等酸性清洁剂混用,会产生有毒的氯气
7. 搞清洁时戴口罩,有哮喘、过敏的人不要参与清理发霉的房间
```

消毒液的配制和浓度见[84消毒液(含氯消毒剂)](../01-日常疾病和伤害/15-传染病家庭防控.md#84消毒液含氯消毒剂);来电前的检查见[灾后恢复用电](../07-日常生活技能/08-家庭用电安全.md#灾后恢复用电)。

#### 食物和饮水

```
✓ 被洪水泡过的食物全部丢掉,包括袋装、纸盒装、玻璃瓶装、旋盖瓶装的
  - 唯一例外: 没有破损、没有鼓胀的金属罐头,撕掉标签后洗净、用消毒液泡过,
    再用笔把内容写在罐上
✓ 冰箱停电超过半天以上、里面的肉、奶、剩菜已经不凉了的,丢掉
✓ 饮用水: 在供水部门通知恢复之前,喝瓶装水或煮沸的水
✓ 被淹过的水井: 先把井水抽干净、清掉淤泥,再消毒,化验或观察几天后再饮用
✓ 泡过的锅碗瓢盆、奶瓶: 洗净后煮沸或用消毒液浸泡
```

井的消毒方法见[水源工程与供水-井水消毒](../07-日常生活技能/10-水源工程与供水.md#井水消毒)。

#### 预防疾病

```
洪水后常见的健康问题:
- 腹泻、痢疾等肠道传染病 → 只喝开水,饭前便后洗手,不吃泡过水的食物
- 皮肤病: 长时间泡在水里的脚和腿出现发白起皱、红肿、瘙痒
  → 尽量减少泡水时间,每天洗净擦干,保持干燥
- 伤口感染、破伤风 → 再小的伤口也要冲洗干净;受伤后考虑补打破伤风疫苗
- 钩端螺旋体病: 接触过洪水、泥水几天到两周后,突然发高烧、全身肌肉酸痛
  (小腿肚痛得特别明显)、眼睛发红 → 立即就医,并告诉医生接触过洪水
- 蚊子增多(登革热、乙脑)→ 清除积水,挂蚊帐、用驱蚊剂
- 一氧化碳中毒: 停电时在室内用发电机、烧炭

⚠️ 发高烧、腹泻不止、尿少、伤口红肿流脓,及时就医或拨打120
```

相关章节: [腹泻类传染病](../01-日常疾病和伤害/15-传染病家庭防控.md#腹泻类传染病)、[破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防)、[一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。经历洪水后睡不着、反复想起当时的情景是常见反应,见[心理健康](../01-日常疾病和伤害/10-心理健康.md)。

## 暴风雪

### 危险

- 能见度低,迷路
- 失温
- 交通中断
- 停电断水
- 积雪压塌建筑
- 雪崩(山区)
- 冻雨、道路结冰导致的摔伤和车祸
- 取暖不当导致的一氧化碳中毒和火灾(冬季在家里出事的人往往比在外面多)
- 寒冷和铲雪诱发心梗、脑卒中

### 寒潮来临时

寒潮是冷空气大规模南下,一两天内气温骤降十几度,常伴随大风、雨雪和冰冻。南方很多房子没有暖气、保温差,寒潮时同样危险。

```
人:
✓ 老人、婴幼儿、心脑血管病和慢性肺病患者是重点
  - 降温会让血压升高,寒潮期间心梗、脑卒中明显增多
  - 慢性病患者按时服药,不要自行停药;早上起床、出门时特别注意保暖
  - 突然胸痛、一侧手脚无力、说话不清,立即拨打120
✓ 帽子、围巾、手套,保护头颈和手脚
✓ 每天看看独居老人,确认家里够暖、取暖方式安全

房屋和取暖:
✓ 门窗缝隙用胶条、布条封住,窗户挂厚窗帘
✓ 煤炉必须有烟囱、装风斗,烟囱接口严密;睡前封火时也要留通风
✓ 不在门窗紧闭的房间里烧炭火盆、用燃气热水器洗很久的澡
✓ 电暖器不要用插线板,远离床单、衣物;不要盖着被子用电热毯以外的取暖器

水管防冻:
✓ 室外和不保暖处的水管、水表用保温棉、旧衣物、稻草包好
✓ 特别冷的夜里,让水龙头细细地滴着水,或者睡前关掉总阀、放空管里的水
✓ 水管已经冻住: 用温水浇、热毛巾敷,慢慢化开;不要用明火烤、不要浇开水(会炸裂)

农业:
✓ 大棚加固、加盖草帘;畜禽圈舍挡风、垫干草,保证饮水不结冰
✓ 防霜冻措施见天气观测章的"霜冻"一节
```

相关章节: [一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)、[老人照护-极端天气](../01-日常疾病和伤害/13-老人照护.md#极端天气)、[霜冻](../08-基础科学知识/07-天气观测与预报.md#五霜冻)。

### 冻雨和道路结冰

```
冻雨: 雨滴落到地面和物体上立即冻成冰,电线、树枝挂满冰会被压断,路面像镜子一样滑。

步行:
✓ 尽量不出门,特别是老人
✓ 穿防滑鞋;没有时在鞋外绑草绳、旧袜子、防滑链
✓ 小步走,脚掌平踩,身体稍向前倾,手不要插兜(摔倒时能撑地)
✓ 避开台阶、斜坡、井盖、桥面和背阴处(结冰最厚)
✓ 远离挂冰的电线、树木和屋檐(冰凌、断枝会砸下来)

驾车:
✓ 能不开就不开;必须开时: 减速、加大车距,轻踩刹车、不急转方向
✓ 桥面、高架、隧道出入口最先结冰
✓ 打滑时: 松开油门,方向盘朝车尾甩的方向轻轻修正,不要猛踩刹车
```

### 暴风雪前

```
准备:
✓ 储备食物、水(至少1周)
✓ 备用取暖设备(安全的)
✓ 应急照明
✓ 电池、收音机
✓ 药品
✓ 充足燃料(汽车、发电机)
✓ 铲雪工具
✓ 车上放: 毯子、保暖衣物、铲子、手电、食物和水、防滑链、鲜艳布条

房屋:
✓ 检查供暖系统
✓ 保温材料
✓ 清理排水沟
✓ 修剪树枝(防压断电线)
✓ 检查屋顶和大棚的承重,年久失修的棚房、车棚提前加撑或拆除
```

### 暴风雪中

**在家中**:
```
✓ 留在室内
✓ 保暖:
  - 多层衣物
  - 密闭一个房间取暖
  - 用毛巾堵门缝
✓ 节省燃料
✓ 防一氧化碳中毒:
  - 不要在室内烧炭取暖
  - 使用燃料取暖时保持通风
  - 识别与救助见 01-日常疾病和伤害/07-居家与交通意外.md
✓ 储水(管道可能冻裂)
✓ 定期清理屋顶积雪(防压塌)
```

**在车内被困**:
```
1. 留在车内!
   - 车是庇护所
   - 外出易迷失

2. 发信号:
   - 鲜艳布条系在天线
   - 定时打开危险信号灯
   - 偶尔鸣笛

3. 保暖:
   - 发动机每小时运转10分钟取暖
   - 确保排气管未被雪堵塞(防一氧化碳中毒)
     每次开发动机前先下车清掉排气管周围的雪,开的时候把背风一侧的车窗开一条缝
   - 多活动身体
   - 和他人挤在一起

4. 保持清醒:
   - 轮流睡觉
   - 防止睡着冻伤

5. 节省:
   - 燃料
   - 食物
   - 电池
```

**在户外**:
```
⚠️ 暴风雪中外出极度危险!

如被困户外:
1. 寻找/建造庇护所:
   - 天然庇护(洞穴、岩石)
   - 雪洞
   - 挡风墙

2. 保持干燥:
   - 湿衣服致命
   - 脱掉湿衣
   - 用干雪擦干

3. 保暖:
   - 多层衣物
   - 保护头部(头颈暴露时散热明显)
   - 覆盖口鼻(温暖吸入空气)
   - 活动身体

4. 不要:
   ❌ 吃雪(降低体温)
   ❌ 饮酒(虽感觉温暖,实际降温)
   ❌ 睡觉(易失温)
```

雪洞、雪墙的做法见[雪地极地求生](../03-野外生存/04-雪地极地求生.md);失温和冻伤的处理见[失温症](../01-日常疾病和伤害/05-急性症状.md#失温症)、[冻伤](../01-日常疾病和伤害/02-外伤处理.md#冻伤)。

### 屋顶和大棚除雪

```
大雪压塌屋顶、彩钢棚、蔬菜大棚,以及上屋顶扫雪摔下来,是暴雪中常见的伤亡原因。

✓ 积雪厚、又是湿重的雪时尽早清理,不要等到越积越厚
✓ 优先在地面用长杆、推雪板把雪推下来,尽量不上屋顶
✓ 必须上屋顶时: 两人以上,系安全绳,穿防滑鞋,不要站到屋檐边
✓ 大棚: 雪大时整夜轮流扫雪;棚架已经变形、发出响声时,人立即离开,不要进去抢救
✓ 清雪时注意脚下的电线和屋檐下的人
❌ 不要在压满雪的简易房、车棚、大棚里躲雪
```

### 暴风雪后

```
✓ 小心外出(路滑、能见度低)
✓ 避免过度劳累(铲雪是重体力活)
  - 干一会儿歇一会儿,用推的代替抬起来扔;一次少铲一点
  - 心脏病、高血压患者和老人尽量不要铲雪
  - 铲雪时胸痛、胸闷、喘不上气,立即停下,拨打120
✓ 注意雪崩风险(山区)
✓ 检查冻伤
✓ 补充水分和能量
✓ 积雪融化时注意屋檐冰凌掉落和融雪引起的积水、内涝
```

## 龙卷风

### 我国的龙卷风

```
- 我国每年都有龙卷风,多发生在4-9月,
  江苏、安徽、广东、湖北、山东等平原、河网和三角洲地区较多
- 常出现在强雷暴里,也常出现在台风外围的雨带中
- 2016年江苏盐城阜宁的强龙卷风造成近百人遇难,主要伤亡来自房屋倒塌
- 龙卷风范围小(一般宽几十到几百米)、来得快、持续时间短,
  很难提前几小时准确预报到具体地点,所以要靠收到预警后马上行动
```

### 识别

**云层特征**:
- 乌云翻滚
- 漏斗云
- 低垂云层
- 云底下垂的旋转"墙云"

**其他征兆**:
- 天空呈绿色
- 雷电频繁
- 大冰雹
- 响亮持续的轰鸣声(像火车)
- 突然平静(龙卷风前)
- 地面上有旋转的尘土、杂物柱(漏斗还没完全落地时也已经很危险)
- 夜里看不见漏斗,只能靠预警和声音判断

### 龙卷风警报

**Watch(关注)**: 条件适合,可能形成
**Warning(警告)**: 已发现龙卷风,立即行动!

```
上面是美国的分级。我国:
- 气象部门发布雷雨大风、冰雹、强对流天气预警时,就要想到可能有龙卷风
- 广东、江苏等地会单独发布龙卷风预警;收到后立即按下面的要求躲避
- 看到漏斗云、听到火车一样的轰鸣,不要等预警,马上躲
```

### 应对措施

**在家中**:
```
立即行动!

最佳位置:
1. 地下室:
   - 最安全
   - 躲在坚固工作台下
   - 远离窗户

2. 无地下室:
   - 最低楼层
   - 内部房间(卫生间、壁橱)
   - 无窗户
   - 远离外墙

姿势:
✓ 蹲下或趴下
✓ 双手抱头
✓ 保护头颈
✓ 用厚垫子、床垫覆盖

❌ 不要:
- 待在移动房屋
- 待在活动板房、彩钢房、工棚、简易平房里
  (这些房子会被整个掀起;能在龙卷风到来前转移到附近坚固的楼房就立即转移)
- 开窗"平衡气压"(错误!)
- 躲在汽车里
- 跑到外面看、拍视频
```

**在学校/公共建筑**:
```
✓ 内部走廊(最低楼层)
✓ 小房间
✓ 远离窗户、大厅
✓ 蹲下,保护头部
✓ 听从指挥
❌ 不要待在体育馆、礼堂、大超市中央等大跨度屋顶的空间(屋顶容易整体塌落)
```

**在室外**:
```
1. 寻找坚固建筑

2. 无建筑:
   - 趴在低洼处
   - 沟渠、水坑
   - 双手抱头
   (注意: 暴雨中沟渠可能突然涨水)

3. 不要:
   ❌ 躲在桥下(狭管效应,风更大)
   ❌ 躲树下
   ❌ 试图跑过龙卷风

4. 远离:
   - 电线杆
   - 树木
   - 汽车
```

**在车内**:
```
⚠️ 汽车不安全!

龙卷风接近:
1. 弃车!
2. 趴在附近低洼处
3. 距离车远一些(防被砸)

如无处可去:
- 系好安全带
- 趴下低于窗户
- 用手、毯子保护头

✓ 龙卷风还很远、道路通畅时,可以朝和它移动方向垂直的方向开车离开,
  进入最近的坚固建筑
```

### 龙卷风后

```
✓ 检查伤情
✓ 远离倒塌建筑
✓ 远离垂落电线
✓ 使用手电筒(不要明火)
✓ 帮助他人
✓ 听从救援指挥
✓ 穿结实的鞋、长袖长裤,废墟里到处是钉子和碎玻璃
✓ 闻到燃气味立即离开,并报告
```

## 冰雹

冰雹常和雷电、大风一起出现,持续时间一般只有几分钟到十几分钟。鸡蛋大小的冰雹能砸伤人、砸碎车窗,对庄稼的破坏尤其严重。冰雹预警只有橙色(6小时内可能出现)和红色(2小时内可能性极大)两级。

```
在室内:
✓ 关好门窗,远离窗户和天窗(玻璃会被砸碎)
✓ 不要出门去收东西、盖车

在室外:
✓ 立即进入坚固的建筑
✓ 来不及时: 用背包、书包、衣服护住头和后颈,
  躲到结实的屋檐下、墙边(背向来雹方向)
❌ 不要躲在大树下(冰雹常伴雷电,大树下容易被雷击;断枝也会砸人)
❌ 不要躲进简易棚子、广告牌下

在车内:
✓ 找到能停车的地方停好(不要停在路中间),留在车里
✓ 远离车窗,背对车窗,用衣物、毯子护住头和脸
✓ 附近有加油站顶棚、停车楼时开进去躲
❌ 不要在冰雹中下车跑向远处的建筑

之后:
✓ 冰雹堆积的路面很滑,小心驾驶和行走
✓ 雹后可能紧接着有雷雨、大风,注意后续预警
```

**庄稼受灾后**:
```
✓ 及时扶起倒伏的植株,剪掉被砸烂的叶子和枝条,减少病菌侵染
✓ 追施速效肥,帮助恢复
✓ 损毁严重、季节还来得及时,补种或改种生长期短的作物
✓ 果园、菜地经常受雹灾的地方,可以架设防雹网
```

各类作物的田间管理见[粮食作物](../04-动植物培育/02-粮食作物.md)、[蔬菜种植](../04-动植物培育/01-蔬菜种植.md)。

## 高温热浪

连续几天最高气温在35°C以上(高温预警的起点),夜里也不降温,对老人、婴幼儿、慢性病患者和户外劳动者特别危险。每次大的热浪都会让死亡人数明显增加,其中很多是在家里独自中暑的老人。

```
收到高温预警时:
✓ 黄色(连续3天≥35°C): 减少中午户外活动,安排好饮水和防暑
✓ 橙色(≥37°C): 户外作业缩短时间、避开中午,轮换休息
✓ 红色(≥40°C): 除必要的工作外,停止户外露天作业

✓ 避开高温时段外出(10:00-16:00)
✓ 定时喝水,不要等口渴;大量出汗时同时补充盐分
✓ 白天关窗拉帘,晚上凉快时通风;有空调就开,不要为省电硬扛
✓ 每天看望或电话问候独居老人
❌ 绝对不要把孩子、老人、宠物单独留在车里,哪怕几分钟
✓ 户外劳动: 安排在早晚,干一段歇一段,结伴干活、互相观察

⚠️ 出现头晕、恶心、大量出汗后突然不出汗、体温很高、意识模糊、抽搐 →
   可能是热射病,立即拨打120,同时把人移到阴凉处、迅速降温
```

中暑的分级、降温方法、高风险人群和补水的量见[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑);老人的照顾见[老人照护-极端天气](../01-日常疾病和伤害/13-老人照护.md#极端天气)。

**停电时降温**:
```
✓ 待在家里最凉的房间(北面、楼下、背阴处),白天门窗关严挡住热气
✓ 用湿毛巾擦身、冲凉水澡、把脚泡在凉水里
✓ 在窗口挂湿床单,靠蒸发降温(空气干燥时效果明显,很潮湿时效果差)
✓ 气温很高时风扇只是在吹热风,要配合打湿皮肤才有用
✓ 去社区的避暑点、凉爽的公共场所
```

## 干旱

干旱来得慢、持续时间长,不像洪水那样一下子致命,但它会逐步造成饮水困难、粮食减产甚至绝收。旱情发展时,**越早开始节水,后面越主动**。

### 影响

- 缺水
- 农作物歉收
- 粮食短缺
- 火灾风险增加
- 健康问题

### 应对

**用水的优先次序**:
```
水不够时,按这个顺序保证:
1. 人的饮用水和做饭用水(每人每天约2-3 L饮用,炎热和劳动时更多)
2. 洗手和基本卫生(防传染病)
3. 牲畜饮水
4. 庄稼的关键期浇水(见下方)
5. 其他用途(洗衣、清洁、浇花、洗车)

✓ 社区缺水时统一定量分配,安排专人管理水源,优先照顾老人、孩子、病人
```

每人用水量的估算见[水源工程与供水-需要多少水](../07-日常生活技能/10-水源工程与供水.md#需要多少水)。

**节水措施**:
```
日常:
✓ 缩短洗浴时间(改用盆浴擦身)
✓ 修理漏水(一个滴水的龙头一天能漏掉几升到十几升)
✓ 重复用水(洗菜水浇花)
  - 洗菜水 → 冲厕所、浇地;洗衣最后一遍的清水 → 下一次洗衣第一遍
✓ 收集雨水
✓ 减少洗车
✓ 使用节水器具
✓ 洗碗先用纸或刮板去掉油污,再用一盆水洗

农业:
✓ 滴灌
✓ 选择耐旱作物
✓ 覆盖保湿
✓ 改进灌溉时间(早晚)
```

**寻找水源**:
```
✓ 深挖水井
✓ 雨水收集系统
✓ 水资源共享
✓ 远距离运水
✓ 泉水: 旱季有的泉流量变小但不会断,可以清理泉眼、修小池子蓄水
```

挖井、找泉、集雨的方法见[水源工程与供水](../07-日常生活技能/10-水源工程与供水.md)。

### 干旱时的饮水安全

```
⚠️ 干旱时水源里的污染物会被"浓缩",水质往往比平时差

✓ 所有水都要煮沸或消毒后再喝
✓ 运来的水用干净的、带盖的容器装,不要用装过农药、化肥、油的桶
❌ 不要喝发绿、表面漂着绿色浮沫或油漆状膜、有腥臭味的池塘和水库水
   (可能是蓝藻爆发,其毒素煮沸也去不掉)
✓ 水少时更要洗手: 一盆水加肥皂,多人轮流洗手后,用剩的水还可以冲厕所
```

不能用一般方法处理的水见[水源工程与供水-不能用一般方法处理的水](../07-日常生活技能/10-水源工程与供水.md#不能用一般方法处理的水)。

### 农田抗旱

```
保墒(减少土壤水分蒸发):
✓ 雨后或浇水后及时浅锄松土,切断地表的毛细管,减少蒸发
✓ 地面覆盖秸秆、杂草、地膜
✓ 及时除草(杂草和庄稼争水)

浇水:
✓ 水少时优先浇关键期: 播种出苗期、拔节孕穗期、抽穗开花期
  (这些时期缺水对产量影响最大)
✓ 早晚浇、浇在根部;沟灌、穴灌比大水漫灌省水
✓ 浇透一次比天天浇一点好(让根往下长)

调整:
✓ 播种期延误时,改种生长期短、耐旱的作物(谷子、高粱、红薯、绿豆等)
✓ 牲畜过多时提前出栏一部分,保住种畜
```

**健康防护**:
```
✓ 保证饮水
✓ 防中暑
✓ 注意卫生(水少易传染病)
✓ 营养补充
```

**火灾预防**:
```
✓ 清理可燃物
✓ 禁止野外用火
✓ 准备灭火工具
✓ 房屋周围清出一圈没有干草、柴堆的隔离带
```

野外火灾的预防和逃生见[森林火灾](04-火灾.md#森林火灾)。

## 沙尘暴

沙尘暴多发生在春季的西北、华北地区。大风卷起沙尘,能见度可以降到几百米甚至几十米以内,对呼吸道、眼睛和交通危害最大。沙尘暴预警有黄色(能见度小于1000 m)、橙色(强沙尘暴,小于500 m)、红色(特强沙尘暴,小于50 m)三级。

```
在室内:
✓ 关好门窗,门窗缝用胶条或湿毛巾堵住
✓ 有空气净化器就开着
✓ 儿童、老人、哮喘、慢性支气管炎和心脏病患者尽量不出门,备好常用药

必须外出时:
✓ 戴口罩(KN95、N95类防护效果明显好于普通口罩;没有时用湿的纱巾、毛巾捂住口鼻)
✓ 戴护目镜或眼镜,不要戴隐形眼镜
✓ 穿长袖,用纱巾包住头发
✓ 远离广告牌、临时搭建物、围挡、脚手架、大树和高压线(大风会吹倒)
✓ 骑自行车、电动车不安全,尽量改为步行或停下躲避
✓ 回家后洗脸、漱口、清洗鼻腔,换下外衣

驾车:
✓ 打开近光灯、雾灯和示廓灯,减速,加大车距
✓ 能见度很低时,在最近的服务区、出口或路边安全地方停车
✓ 高速公路上被迫停在应急车道时: 打开危险报警闪光灯,
  人从右侧下车,撤到护栏外面,不要留在车里或站在车后面

在野外:
✓ 背对风向,躲到大石头、土坎的背风一侧
✓ 用衣物包住头、口鼻,趴下或蹲下等沙尘过去
❌ 不要在沙尘中继续赶路(容易迷路、摔下沟坎)

沙尘进眼睛: 不要揉,用清水冲洗,冲不出来时就医
```

眼睛进沙的处理见[眼睛异物](../01-日常疾病和伤害/04-异物处理.md#眼睛异物);沙漠中遇到沙尘暴见[沙漠求生](../03-野外生存/03-沙漠求生.md)。

## 雷电

我国每年都有不少人被雷击伤亡,大多数发生在**农村的田间地头、山上和水边**,时间多在夏季午后到傍晚。雷暴形成的征兆见[天气观测与预报-雷暴的征兆](../08-基础科学知识/07-天气观测与预报.md#23-雷暴的征兆)。

### 雷电危险

- 直接雷击(致命)
- 侧面闪络
- 接触电压
- 跨步电压

```
解释:
- 直接雷击: 闪电直接打在人身上,多发生在空旷地带的人、高处的人
- 侧面闪络: 闪电打在大树、电线杆上,再从树干"跳"到旁边的人身上
  → 这是在大树下避雨被雷击的主要原因
- 接触电压: 手扶着被雷击中的物体(铁栏杆、铁丝网、金属门、电线杆)
- 跨步电压: 雷电流沿地面向四周扩散,人两脚分开站着时,两脚之间有电压差
  → 附近的牲畜、并排的人常因此成片伤亡;雷击伤亡中这种情况最多
```

### 室外避雷

**寻找安全处**:
```
✓ 坚固建筑内
✓ 封闭汽车内
✓ 远离高大物体

只有两种地方真正安全:
1. 有防雷装置或有完整电线、水管的坚固建筑物内部
2. 硬顶的金属车厢内(轿车、公交车,关好车窗)

以下地方看起来能避雨,其实不安全:
- 亭子、凉亭、公交站棚、雨棚、帐篷、草棚、孤立的看瓜棚
- 大树下、山洞口(洞内深处相对好一些,但不要靠近洞壁和洞口)
- 敞篷车、摩托车、电动车、自行车、拖拉机驾驶座
```

**最后手段姿势**(无处躲避):

⚠️ 户外没有真正安全的地方。此姿势只能略微降低风险,美国国家气象局已不再将其作为推荐做法。听到雷声就应尽早进入坚固建筑或封闭汽车内。

```
双脚并拢蹲姿:
1. 双脚完全并拢
2. 蹲下
3. 双手抱膝
4. 头低下
5. 尽量小的接触地面面积

作用:
- 减小被击中概率
- 减少跨步电压伤害

补充:
- 如果有干燥的绝缘物(干的背包、防潮垫、塑料雨衣),可以蹲在上面
- 不要躺下或趴下(身体和地面接触面积越大,跨步电压的伤害越大)
- 这是来不及躲避时的最后办法,不能代替提前撤离;
  能走时,应尽快离开山顶、开阔地,向低处的建筑物或车辆转移
```

**避开**:
```
❌ 开阔地、山顶、水面
❌ 大树下(至少远离5 m)
❌ 金属物附近
❌ 电线杆、旗杆
❌ 孤立棚屋、凉亭
❌ 水中(游泳、钓鱼)
❌ 铁丝网、铁栅栏、晾衣铁丝、铁轨
❌ 高举的东西: 带金属尖的雨伞、锄头、钓竿、登山杖(放下,离远一些)
❌ 骑自行车、摩托车、电动车(下车,离开车子)
```

**不同场所**:
```
田间干活、放牧:
✓ 看到积雨云越长越高、听到雷声,马上收工回村,不要等雨下来
✓ 农具放下,不要扛在肩上;不要躲进田头的棚子
✓ 牲畜不要拴在大树下、铁丝网上

在水上、水边:
✓ 游泳、钓鱼、划船的人立即上岸,远离水边
✓ 船上来不及靠岸时,降低身体,远离桅杆和金属部件

在山上:
✓ 尽快离开山顶、山脊,往下撤
✓ 不要在山顶的孤立建筑、凉亭、信号塔下躲避
✓ 爬山时早出发早下山,午后雷暴前离开山顶
```

山地中遇雷暴见[山地求生-雷电](../03-野外生存/05-山地求生.md#雷电)。

**集体避雷**:
```
- 分散开(相互间隔至少15 m)
- 不要手拉手
- 各自蹲姿
- 这样即使有人被击中,其他人也能马上施救
```

### 室内避雷

```
✓ 关闭门窗
✓ 拔掉电器插头
✓ 不要打电话(有线)
✓ 不要洗澡
✓ 远离水管、金属管道
✓ 远离窗户
✓ 不要靠墙

补充:
- 雷电可以沿电线、电话线、网线、水管、天线传进屋里
- 电视、电脑、路由器等拔掉电源线和网线、天线;不要在雷雨中去拔(有危险),提前拔
- 使用太阳能热水器的,雷雨时不要淋浴
- 手机本身不会"招雷",在室内用手机一般是安全的;户外的危险来自所处的位置
- 农村没有防雷装置的平房、砖木房: 比室外安全得多,但要更加远离门窗、墙壁和电器
```

### 车内避雷

```
✓ 相对安全(金属车厢形成法拉第笼)
✓ 关闭车窗
✓ 不要触摸金属部件
✓ 停车,不要下车
✓ 等雷暴过去

⚠️ 敞篷车、软顶车、玻璃钢车身的车,以及摩托车、电动车、拖拉机,不能提供这种保护
```

### 雷击急救

```
⚠️ 可以触摸被雷击者(不带电)!

1. 立即检查呼吸心跳
2. 如无,立即CPR
3. 雷击者有很高复苏率
4. 持续CPR直到急救到达
5. 治疗烧伤
6. 所有雷击者都应就医

补充:
- 第一时间拨打120
- 雷暴还没过去时,先把伤者移到相对安全的地方再抢救,防止施救者也被击中
- 多人被雷击时,先救没有呼吸、看起来"已经死了"的人
```

详细的处理见[急性症状-雷击](../01-日常疾病和伤害/05-急性症状.md#雷击)。

### 判断雷暴距离

```
闪电-雷声法:
1. 看到闪电开始计数
2. 听到雷声停止
3. 秒数÷3 ≈ 距离(km)

例:9秒 = 约3 km

如<30秒(10 km),立即躲避!
最后一声雷响后等待30分钟,再离开避险处
```

```
"30-30规则":
- 前一个30: 闪电到雷声的间隔不到30秒,说明雷暴在10 km以内,
  已经进入雷击范围,必须马上进入安全场所
- 后一个30: 最后一声雷响过后,再等30分钟才能离开安全场所
  (雷暴离开时,后部仍可能打雷)

⚠️ 更稳妥的做法是"听到雷声就躲": 雷声一般能传十几公里,能听到雷声,
   就说明已经在雷击可能到达的范围内。闪电可能打在离雨区十几公里的晴空下,
   "还没下雨"不等于安全。
```

## 📝 总结要点

### 气象灾害共同原则

```
1. 提前关注预警
2. 准备应急物资
3. 及时撤离
4. 听从官方指挥
5. 不要冒险
6. 看懂颜色: 蓝→关注,黄→准备,橙→停止户外活动、危险区转移,红→留在安全处
7. 收到转移通知就走,不要等到风大雨大、水进屋再走
```

### 各类灾害优先级

**台风**: 加固房屋,危险区撤离,台风眼的平静不是结束
**洪水**: 往高处走,不要涉水,不开车进积水的地道和桥下,不下地下车库挪车
**暴风雪**: 留在庇护所,保暖,防一氧化碳中毒
**龙卷风**: 地下室/内部房间,保护头部
**冰雹**: 进入建筑,远离窗户,护住头部
**高温热浪**: 避开中午,定时喝水,看望独居老人,不把孩子留在车里
**干旱**: 先保饮水,早节水,水要煮沸
**沙尘暴**: 关窗,戴口罩和护目镜,能见度低时停车撤到护栏外
**雷电**: 尽早进入室内或封闭车内

### 记住

```
✓ 生命>财产
✓ 预防>应对
✓ 准备充分
✓ 保持冷静
✓ 帮助他人
```
