## 先说清楚: 本章的定位

```
1. 救活人永远优先: 搜救、救治伤员、保障幸存者的水和食物
2. 遗体由政府、公安、民政和殡葬部门统一处理
   - 发现遗体: 报告110或当地政府、救援队,说明位置
   - 不要自行搬运、掩埋或焚烧
3. 本章适用于:
   - 救援队到达之前,需要临时看护和记录遗体
   - 协助救援人员、照顾遇难者家属
   - 长期与外界隔绝、没有任何机构可以联系的极端情况
```

## 一个常见的误解: 遗体会引起瘟疫

世界卫生组织和红十字国际委员会指出: **因外伤、溺水、火灾等原因死于自然灾害或冲突的人,遗体一般不会引起疫病流行。** 这些人死前通常没有携带引起传染病的病原体。

```
因此:
❌ 不要因为怕瘟疫而匆忙集体掩埋或焚烧遗体
   - 匆忙集体掩埋会让遗体无法辨认
   - 家属找不到亲人、无法确认死亡,会带来长期的痛苦,
     还会带来继承、婚姻等法律问题
❌ 不需要在遗体上撒石灰、喷洒消毒液(没有防疫作用,浪费人力物资)

真正需要注意的风险:
⚠️ 遗体在水源里或水源附近: 可能污染饮用水,引起腹泻类疾病
   → 尽快移出水源,受影响的水煮沸或消毒后才能喝
⚠️ 死于霍乱等传染病的人(见下方"传染病死者")
⚠️ 处理遗体的人受伤感染、搬运时受伤
```

饮用水的消毒见[基础生存技能-水源获取](../03-野外生存/00-基础生存技能.md#水源获取与净化)。

## 接触遗体时的防护

```
✓ 戴手套(橡胶手套、一次性手套),穿长袖衣服、靴子
✓ 手上有伤口时先包扎好,或避免接触
✓ 接触后用肥皂和流动水洗手
✓ 处理时不吃东西、不喝水、不抽烟,不要用手摸脸
✓ 衣物和手套用后清洗或丢弃
✓ 有条件时戴口罩(主要是减轻气味的不适,不是防疫)

搬运:
✓ 用担架、门板、裹尸袋或结实的布,多人一起抬
✓ 注意自身安全: 倒塌的建筑、泥石流现场先确认不会二次坍塌
```

受伤后的处理和破伤风预防见[外伤处理-破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防)。

## 辨认和记录

辨认身份是对遇难者和家属最重要的帮助。**随着时间推移,面部特征会很快改变,越早记录越好。**

```
每一具遗体:
1. 编一个唯一的编号(如"地点缩写-001")
   - 写在防水标签上,系在遗体上
   - 同样的编号写在包裹遗体的袋子或布外面
2. 拍照(如果有手机或相机):
   - 编号牌要出现在每张照片里
   - 面部正面、全身、衣服、鞋子
   - 文身、疤痕、胎记、首饰等特征
3. 记录:
   - 发现的时间、具体地点
   - 大概的性别、年龄、身高、体型
   - 衣物、随身物品、明显特征
4. 随身物品(证件、手机、首饰、钱包):
   - 不要和遗体分开,装进袋子,写上同一个编号
   - 交给公安或负责机构,不要私自处置

❌ 不要只凭家属看照片或看一眼就确定身份后匆忙下葬
   (认错的情况并不少见,最终身份由公安等部门确认)
```

## 临时存放

```
✓ 放在阴凉、遮阳的地方,远离居住区和水源
✓ 用裹尸袋、塑料布或布单包好,外面贴上编号
✓ 有条件时冷藏(冷藏车、冷库)
✓ 遗体并排放置,不要堆叠
✓ 安排人看守,防止动物接近和随意翻动
✓ 让家属在有人陪同的情况下辨认和告别

⚠️ 天气炎热时遗体变化很快,尽快报告,等待专业人员处理
```

## 无法联系任何机构时的临时埋葬

只适用于**长期与外界隔绝、确实没有任何机构可以联系**的情况。埋葬前必须完成上面的辨认和记录。

```
原则: 单独埋葬,每个墓都有标记和记录,将来可以找到、迁葬

选址:
✓ 远离饮用水源(水井、泉水、河流):
  - 4具以下: 至少200米
  - 5-60具: 至少250米
  - 60具以上: 至少350米
✓ 墓底要高于地下水位至少2米: 挖坑时渗水的地方不能埋
✓ 选地势较高、不会被洪水淹没的地方
✓ 远离住房

埋葬:
✓ 坑深约1.5米以上,能防止野兽刨开
✓ 每具遗体单独放置,包裹好,编号标签随遗体一起下葬
✓ 不得不多人同坑时,遗体并排放置、不堆叠,
  每具之间留出间隔,画出位置图,写明每个位置对应的编号
✓ 每个墓立一块标记(木牌、石块),写上编号
✓ 画一张简单的地图,记录每个墓的位置和编号
✓ 所有记录、照片、随身物品妥善保存,将来交给有关部门和家属

✓ 尽可能尊重死者的宗教信仰和当地习俗
```

## 传染病死者

死于霍乱、埃博拉等烈性传染病的人,遗体**有传染性**。

```
❌ 不要清洗、触摸、亲吻遗体,不要按传统方式守灵、办丧事聚餐
✓ 立即报告当地疾控部门和卫生院,按要求处理
✓ 接触过遗体或病人的人注意观察有无症状
✓ 遗体用过的物品、排泄物按高浓度消毒液处理
```

消毒液的配制见[传染病家庭防控-家用消毒液的配制](../01-日常疾病和伤害/15-传染病家庭防控.md#家用消毒液的配制)。

## 平时家中有人去世

```
1. 不确定是否已经死亡时: 立即拨打120,能抢救的先抢救
2. 在家中因病去世:
   - 联系医疗机构或社区卫生服务中心,开具死亡医学证明
3. 意外、原因不明或可能是非正常死亡:
   - 拨打110报警,保护现场,不要移动遗体
4. 联系殡仪馆接运遗体
5. 凭死亡证明办理户口注销等手续

⚠️ 各地的具体流程不同,可以向社区、村委会询问
```

## 照顾家属和自己

```
对遇难者家属:
✓ 尽早告诉家属遗体在哪里、如何辨认
✓ 尊重家属辨认和告别的愿望,有人陪同
✓ 不要隐瞒,也不要说"至少走得不痛苦"之类的安慰话
✓ 帮助联系心理援助、社会救助

对参与处理遗体的人:
✓ 轮换工作,不要一个人长时间处理
✓ 出现失眠、反复想起场景、情绪低落,是正常反应,
  和同伴聊一聊,必要时寻求专业帮助
```

## 📝 灾后遗体处理要点

```
1. 救活人优先;发现遗体报告110或当地政府,不要自行处理
2. 外伤、溺水等死于灾害的遗体一般不会引起瘟疫
3. 不要匆忙集体掩埋或焚烧,不要撒石灰喷消毒液
4. 遗体在水源中要尽快移出,受影响的水消毒后再喝
5. 戴手套,接触后洗手;手上有伤口先包好
6. 每具遗体编号、拍照、记录,随身物品不和遗体分开
7. 万不得已临时埋葬: 单独埋、做标记、画地图,远离水源至少200米
8. 死于传染病的人,不清洗不触摸,报告疾控
```
