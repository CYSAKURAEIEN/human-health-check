## 战乱与武装冲突

### 冲突前准备

**信息收集**:
```
✓ 关注时事新闻
  - 只信官方渠道和可靠媒体,社交媒体上的消息先核实再转发
✓ 注册使领馆
  - 在国外: 通过外交部领事服务渠道登记个人信息,
    记下所在国中国使领馆的地址和电话
✓ 了解撤离路线
  - 至少两条,方向不同;走一遍,记下沿途的桥梁、隧道等容易被封锁的地点
✓ 准备应急包
  - 按全家人至少3天准备水、食物、药品、照明、收音机、充电宝
✓ 备份重要文件
  - 身份证、护照、户口本、房产和存款凭证、病历、处方
  - 纸质原件装防水袋随身;另存一份电子版在云端或U盘
✓ 储备现金
  - 停电、断网时电子支付不能用;备一些小面额现金,分开放在不同地方
```

**应急计划**:
```
✓ 安全集合地点
  - 家附近一个、城外一个;全家人都知道,包括孩子
✓ 多条撤离路线
✓ 外地联系人
  - 选一位住在外地的亲友作为全家的"信息中转站",失散后都向他报平安
✓ 多种通讯方式
  - 手机、短信、收音机,约定好联络时间
✓ 安全屋(如可能)
  - 家中选定一处最安全的位置(见下方"两堵墙"原则),
    提前放好水、手电、急救包和坐垫
✓ 慢性病人提前多备药,见慢性病用药储备一章
```

家庭通信计划的详细做法见[应急通信与寻亲](06-应急通信与寻亲.md#灾前-家庭通信计划),药品储备见[慢性病用药储备](../01-日常疾病和伤害/08-慢性病用药储备.md)。

### 冲突期间

**保护自身**:
```
✓ 留在室内(安全时)
✓ 远离窗户
  - 爆炸冲击波最大的伤害之一是碎玻璃;拉上窗帘,床和沙发不要靠窗
✓ 地下室或内部房间
  - "两堵墙"原则: 你和外面之间至少隔两堵承重墙,
    例如楼道、内走廊、没有窗的卫生间
✓ 储备食物和水
✓ 减少外出
  - 必须外出时结伴,说好去哪里、几点回来
  - 宵禁时间内不要外出
✓ 保持低调
  - 不穿迷彩服等类似军装的衣服,不携带望远镜等容易被误会的物品
✓ 避开军事目标
  - 军营、检查站、军用车队、指挥所、通信设施、桥梁和油库附近都更危险
✓ 不要拍摄、上传军事设施、部队调动和被袭击地点的照片和定位
  - 这些信息可能被用来校正攻击,也会让你自己被当作嫌疑人
```

**遇到炮击/空袭**:
```
立即:
1. 寻找掩护:
   - 地下室
   - 坚固建筑底层
   - 远离窗户
   - 附近有人防工程、地铁站、地下通道,就近进入
2. 趴下
   - 来不及进入建筑时,就地趴在沟渠、低洼处或路边石后面
3. 保护头部
   - 双手护住头颈,双肘护住两侧;微微张嘴,减少冲击波对耳朵和肺的伤害
4. 远离外墙
5. 等待停止
   - 炮击常常一轮接一轮,停下来不等于结束;
     等到解除警报或官方通知再出来
   - 出来后不要围观弹坑和被炸的建筑(可能二次打击、坍塌、起火)
```

### 防空警报与人防工程

```
我国的防空警报信号(各地每年会试鸣,注意收听):
- 预先警报: 鸣36秒、停24秒,反复3遍,共3分钟
  → 做好准备,带上应急包,按指引前往人防工程
- 空袭警报: 鸣6秒、停6秒,反复15遍,共3分钟
  → 立即就近进入人防工程或地下空间
- 解除警报: 连续长鸣3分钟
  → 听从通知再离开掩蔽处

人防工程:
✓ 平时就查清楚家、单位、学校附近的人防工程(很多地下停车场、地下商场兼作人防工程,
  入口有统一标识);也可以向社区或当地人防部门询问
✓ 进入后听从管理人员安排,不要拥挤;老人、孩子、孕妇先进
✓ 带上水、食物、常用药、手电、保暖衣物
```

**遇到枪战**:
```
立即:
1. 卧倒!
   - 站着是最大的目标;听到枪声第一时间趴下,不要先找声音来源
2. 寻找掩体:
   - 墙壁、柱子
   - 汽车发动机舱侧面
     (车门、木门、普通隔墙、灌木只能遮挡视线,挡不住子弹)
   - 坚固家具
3. 爬行到安全处
   - 低姿匍匐,离开窗口和门口的直线方向
4. 不要站立或奔跑
   - 只有在确定有安全出口、而且留在原地更危险时才快速移动
5. 保护头部和胸腹要害
6. 枪声停止后仍多等一段时间,确认安全后再起身;
   不要拍照、不要靠近查看
```

**检查站**:
```
✓ 保持冷静
✓ 双手可见
  - 开车时提前减速,开内灯(夜间),双手放在方向盘上
✓ 服从指令
✓ 缓慢动作
  - 要拿证件时先说清楚"我要从口袋里拿证件",得到允许再拿
✓ 不要突然移动
✓ 携带身份证件
✓ 不要拍照、不要争辩;被拒绝通过就掉头,换路线或等待
```

### 未爆弹药

```
冲突地区和冲突结束后很长一段时间里,未爆炸的炮弹、炸弹、地雷都会造成伤亡,
受害者中儿童很多(会好奇地去捡)。

❌ 不要触碰、踢、移动任何看起来像弹药或不明金属物体的东西
❌ 不要捡拾"纪念品",不要去收废铁
✓ 发现后: 停下 → 沿原路慢慢退回 → 在附近做醒目标记(不要靠近放) → 报告当地警方或军方
✓ 只走有人走过的硬化道路;不进入废弃的田地、树林、房屋
✓ 看到警示牌、红色标记、拉线,不要进入
✓ 反复告诉孩子: 不认识的东西不要碰
```

### 撤离

**时机**:
```
考虑撤离当:
- 官方建议撤离
- 冲突升级
  - 交战线逼近、炮击越来越频繁
- 生活物资短缺
  - 断水、断电、断药已经持续,而且看不到恢复的迹象
- 有安全撤离通道
  - 人道走廊、官方组织的撤离车队

没有安全通道时,在坚固的掩蔽处坚守往往比冒险穿越交战区更安全。
```

**撤离准备**:
```
✓ 监听官方信息
✓ 联系使领馆
✓ 选择安全路线
✓ 避开交战区
✓ 携带应急包
  - 水、食物、药品(足够路上和到达后一段时间)、证件、现金、手机和充电宝、保暖衣物
✓ 轻装上阵
  - 每人一个背包,带不走的东西就放下;双手尽量空出来
✓ 可用白旗等表明平民身份(不要使用红十字标志:受法律保护,仅限医疗救护人员使用)
✓ 白天行动,避免夜间赶路(夜间更容易被误判为威胁)
✓ 给孩子身上放一张写有姓名、父母电话和血型的卡片,以防失散
```

**集体撤离**:
```
✓ 跟随人群
  - 但不要盲目跟随,注意官方指示和道路情况
✓ 互相帮助
✓ 保护弱者
  - 老人、孩子、孕妇、伤病员、残疾人放在队伍中间
✓ 保持联络
  - 约定掉队后的集合点;定时清点人数
```

失散后的寻找见[应急通信与寻亲](06-应急通信与寻亲.md#家人失散后怎样寻找)。

## 化学品泄漏

化工厂事故、危化品运输车翻车、管道泄漏、仓库火灾都可能释放有毒气体或液体。普通人最重要的只有三件事: **往上风或侧风方向离开、来不及走就关门窗就地避难、沾上了就脱衣冲洗**。

### 识别化学品泄漏

**征兆**:
- 异常气味
  - 刺鼻、臭鸡蛋味、大蒜味、漂白水味等;但很多有毒气体**无色无味**,闻不到不代表安全,有的气体浓度高时反而会使嗅觉麻痹
- 烟雾或蒸汽
  - 不明来源的有色烟雾、贴地飘的白雾
- 死亡的动植物
  - 鸟、鱼、虫子成片死亡,草木突然枯黄
- 刺激眼睛、喉咙
- 呼吸困难
- 头晕恶心
- 皮肤刺激
- 周围很多人同时出现流泪、咳嗽、倒地 —— 这是最明确的警报,**不要靠近去救人**,先撤离再报警

### 立即行动

**室外遇到**:
```
1. 判断风向:
   - 观察烟雾、旗帜
   - 感觉风向
   - 看树叶、晾晒的衣物、烟囱冒的烟往哪边飘
   - 弄湿手指举起,感觉凉的一侧是风吹来的方向

2. 往上风、侧风方向撤离:
   ✓ 垂直于风向
     - 正处在下风的烟雾带里时,先横着(与风向垂直)走出烟雾带,
       再转向上风方向远离
     ❌ 不要顺着风跑: 有毒气体跟着你一起走
   ✓ 远离泄漏区
     - 走得越远越好,不要停下来围观、拍照
   ✓ 往高处(有些气体比空气重)
     - 避开地下通道、地下室、沟渠、桥洞等低洼处

3. 如在泄漏区:
   - 用湿布捂住口鼻
     (只能减轻部分刺激性气体的伤害,不能当作防毒面具,不要因此停留)
   - 快速撤离
   - 避免接触液体或烟雾
     - 不要踩踏、触摸泄漏的液体、粉末和残留物
   - 尽量少暴露皮肤;能骑车或开车就快速离开,车窗关紧、空调内循环

4. 脱离后:
   - 脱掉污染衣物(不要从头部脱)
   - 冲洗身体(清水,至少15分钟)
   - 就医
   - 拨打119/120报告泄漏地点、颜色、气味和你看到的情况
```

**室内应对**:
```
如泄漏在室外,你在室内:

1. 判断:
   - 室内更安全?进入
   - 还是撤离更安全?
   (政府通知撤离就撤离;没有通知、烟雾已经到了门口,
    往外走反而要穿过毒气时,就地避难通常更安全)

2. 如留在室内:
   ✓ 关闭门窗
   ✓ 关闭通风系统、空调
     - 还有排风扇、抽油烟机、新风系统;关闭燃气炉具
   ✓ 用湿毛巾堵门缝
     - 窗缝、通风口可用胶带和塑料布封住
   ✓ 往上层移动(有些气体重)
     - 选窗户最少的房间;注意: 这一点和核辐射相反,见下方对比
   ✓ 备水(湿毛巾捂鼻)
   ✓ 听从官方指示
     - 带上手机、充电宝、收音机,随时收听
   ✓ 室内气味越来越重、开始出现症状时,打119/120说明情况,按指示行动

3. 如需撤离:
   - 往上风方向
   - 用湿布保护呼吸道

4. 解除后:
   - 收到官方解除通知后,打开所有门窗通风,再到室外空气新鲜处待一会儿
```

### 就地避难还是撤离

| 情况 | 化学品泄漏 | 核与辐射事故 |
|------|-----------|-------------|
| 室内选哪里 | **楼上**、窗户少的房间(多数有毒气体比空气重,会积在低处) | **地下室或楼房中部**,远离外墙和屋顶(墙体和楼板越厚,挡住的辐射越多) |
| 要不要密封 | 要: 关门窗、关空调、封门缝窗缝 | 要: 关门窗、关通风 |
| 一般要待多久 | 多为几小时,听解除通知 | 先做好至少待24小时的准备,听官方通知 |
| 共同点 | 关门窗、关空调,收听官方信息,不出门围观 | 同左 |

### 不同化学品

**氯气**(黄绿色、刺鼻):
```
- 比空气重,下沉
- 往上风、高处撤离
- 可用小苏打水浸湿毛巾捂住口鼻;皮肤接触只用清水冲洗
- 吸入后可能先只有咳嗽、胸闷,数小时后才出现严重的呼吸困难,
  吸入较多的人即使暂时好转也要就医观察
```

**氨气**(刺激性臭味):
```
- 气态氨比空气轻,但液氨泄漏时会形成又冷又重的白色气团,贴地扩散
- 往上风或侧风方向撤离,不要往低处躲
- 可用清水(或稀醋水)浸湿毛巾捂住口鼻;皮肤接触只用清水冲洗
- 液氨溅到皮肤上还会造成冻伤,同样先用大量清水冲洗,不要揉搓
```

**硫酸(雾或液体)**:
```
- 硫酸雾、稀硫酸沾到皮肤: 立即用大量流动清水冲洗至少15分钟
- 浓硫酸液体: 先用干布迅速吸去(不要擦抹),随即用大量流动清水冲洗
- 少量水接触浓硫酸会放热,所以冲洗水量一定要大
```

**未知化学品**:
```
- 不要接触
- 不要闻
- 远离
- 报警
- 记下(从远处看)运输车或储罐上的危险品标志、编号、颜色,告诉119
```

家里常见的清洁剂混用产生毒气(洁厕灵+84消毒液等)见[中毒-清洁剂中毒](../01-日常疾病和伤害/12-中毒.md#清洁剂中毒)。

### 除污

**救人前先保护自己**: 不要冲进烟雾或泄漏区救人,每年都有施救者和伤者一起中毒的事故。伤者能自己走的,让他按你的指引走出来;不能走的,交给有防护装备的消防人员。帮人除污时戴手套(没有就套塑料袋),不要直接接触污染的衣物和皮肤。

**皮肤接触**:
```
1. 脱去污染衣物
   - 越快越好: 脱掉外衣可以去掉身上大部分(可达约90%)的污染物
   - 套头衫不要从头上拉,用剪刀剪开,避免蹭到脸、眼、口鼻
   - 摘下首饰、手表;眼镜用肥皂水洗净后可以再戴,隐形眼镜丢弃
   - 脱下的衣物装进塑料袋扎紧,再套一层袋子,放到远离人的地方,
     交给救援人员处理,不要自己清洗
2. 大量清水冲洗15-20分钟
   - 用流动的清水从头往下冲,再用肥皂和水轻轻清洗,不要用力搓
   - 皮肤已经发红、起疱、烧痛的属于化学烧伤,要冲30分钟以上,碱类更久
3. 不要使用中和剂(除非明确)
   - 用醋、小苏打去"中和"会放热,加重伤害
4. 就医
5. 带上化学品信息
   - 包装、标签或拍下的照片
```

化学烧伤的处理见[外伤处理-化学烧伤](../01-日常疾病和伤害/02-外伤处理.md#化学烧伤)。

**眼睛接触**:
```
1. 立即冲洗(清水)
   - 先冲再找人、打电话;每耽误一分钟都可能影响视力
2. 翻开眼皮冲洗
   - 伤眼在下方,水从内眼角流向外眼角
3. 至少15-20分钟
   - 冲满时间仍疼痛就继续冲,送医路上也尽量冲
4. 不要揉眼
5. 就医
```

冲洗的具体手法见[异物处理-化学品入眼](../01-日常疾病和伤害/04-异物处理.md#化学品入眼紧急)。

**吸入**:
```
1. 转移到新鲜空气处
   - 施救者自己不要进入有毒气体区域
2. 保持呼吸道通畅
   - 让伤者坐起或半躺(呼吸会轻松些);意识不清但有呼吸的,放成侧卧的复苏体位
   - 松开衣领、腰带;保暖,让他安静休息,不要走动
3. 如呼吸停止,CPR
   - 只做胸外按压即可;不要做口对口人工呼吸(可能使施救者中毒)
4. 就医
```

| 表现 | 处理 |
|------|------|
| 流泪、眼痛、咽痛、轻微咳嗽,离开后很快减轻 | 脱离现场、冲洗、休息观察;接触的是氯气等刺激性气体的,告诉医生,当天留意有无加重 |
| 咳嗽不止、胸闷、气短、声音嘶哑、头晕呕吐 | 尽快就医 |
| 呼吸困难、嘴唇发紫、咳粉红色泡沫痰、抽搐、意识不清 | 立即拨打120 |

复苏体位和CPR见[基础急救知识](../01-日常疾病和伤害/00-基础急救知识.md#气道与复苏体位)。

## 核辐射

辐射看不见、闻不到。核与辐射事故时,公众面对的主要危险是**放射性灰尘(沉降物)**: 它落在皮肤、衣服、地面和食物上,吸入或吃进体内。我国核应急对公众的主要防护措施是: **隐蔽、撤离、服用碘片(按通知)、控制食物和饮水**。

### 辐射来源

- 核电站事故
- 核武器
- 放射性物质泄漏
  - 包括医疗、工业用的放射源丢失;看到带有三叶形辐射警示标志的金属罐、金属件,不要捡拾、不要带回家,远离并报警
- 脏弹
  - 用普通炸药散布放射性物质;爆炸本身的伤害通常比辐射大,先按爆炸袭击处理,再离开现场、除污

### 防护原则

**三要素**:
```
1. 时间:减少暴露时间
   - 待在污染区的时间越短,受到的照射越少
2. 距离:远离辐射源
   - 距离加倍,受到的照射大约降到四分之一
3. 屏蔽:利用材料阻挡
   - 混凝土、砖石、泥土越厚越好;楼房中部、地下室屏蔽效果最好
   - 木板房、汽车的屏蔽作用很弱
```

### 核事故应对

**官方警报**:
```
✓ 听从指示
  - 通过电视、广播、手机短信、社区通知收听;不信、不传谣言
✓ 撤离或就地掩蔽
  - 政府会根据风向和距离划定范围,不同区域的要求不同,按自己所在区域的通知做
✓ 准备撤离
  - 把应急包、证件、药品放在门口
```

**就地掩蔽**:
```
如官方建议留在室内:

1. 进入室内:
   - 最好是地下室
   - 中心房间
   - 远离外墙
   - 楼房的中间楼层比顶层和一楼好(顶层离屋顶落灰近,一楼离地面落灰近)
   - 在户外的人尽快进入最近的坚固建筑,不要在车里掩蔽
   - 宠物也带进屋

2. 关闭门窗:
   - 密封
   - 关闭通风系统
     (空调、排风扇、新风系统、抽油烟机都关掉)

3. 脱去外衣:
   - 可能沾染放射性微粒
   - 密封在塑料袋中
   - 远离生活区
   - 从外面回来的人在门口脱掉外衣和鞋,脱掉外衣可以去除大部分(可达约90%)的放射性污染

4. 淋浴:
   - 温和清洗
   - 不要擦伤皮肤
   - 用洗发水洗头,不要用护发素(会使放射性颗粒附着在头发上)
   - 没有条件淋浴: 用湿毛巾擦洗露在外面的皮肤和头发,
     擤鼻涕、擦眼皮和耳朵;用过的毛巾装袋密封
   - 伤口先冲洗干净再包扎

5. 储备:
   - 食物和水
   - 收音机
   - 保持通信

6. 等待:
   - 听从官方通知
   - 可能数天
   - 先做好至少待24小时的准备;没有通知不要出门察看
```

**撤离**:
```
1. 按指定路线撤离
   - 不要自行选择方向,不要往下风方向走
2. 携带:
   - 应急包
   - 药物
   - 身份文件
   - 手机、充电器、少量换洗衣物
3. 关闭门窗
   - 关闭水、电、燃气总阀
4. 开车时关闭车窗,空调内循环
   - 没有车的按通知到集合点乘车;顺路帮助独居老人和行动不便的邻居
5. 到达安置点后接受辐射检测和除污,听从工作人员安排
```

### 核爆炸时

```
1. 看到强烈闪光: 不要看,立即就地趴下,护住头部
   (冲击波会在闪光后数秒到几十秒才到,趴下可以避免被抛出和被碎片击中)
2. 冲击波过后: 尽快进入最近的坚固建筑,越深越好(地下室、建筑中部)
3. 放射性落灰在最初几个小时最危险,强度随时间下降很快;
   先在室内至少待24小时,除非官方通知撤离
4. 进屋后马上脱外衣、清洗(同上)
```

**碘片**:
```
⚠️ 仅在官方指示下服用!

作用:
- 保护甲状腺
- 阻止吸收放射性碘
  - 核电站事故会释放放射性碘,吸入或吃进去后会集中在甲状腺,增加甲状腺癌风险,
    儿童最敏感
  - 碘片(碘化钾)让甲状腺先"吃饱"稳定碘,不再吸收放射性碘
  - 收到通知后尽快服用;接触放射性碘之前或之后几小时内服用效果最好,太晚服用作用很小
  - 剂量按发放时的说明和官方要求,婴儿、儿童、孕妇的剂量不同;一般只需服用一次,
    是否需要再服听官方通知,不要自己加量

注意:
- 不防护其他辐射
- 不治疗辐射
- 有禁忌症
  - 对碘过敏、患有某些甲状腺疾病的人,先问医生或现场医护人员
- 听从专业指导
- 优先保护对象是婴幼儿、儿童、孕妇和哺乳期妇女

❌ 不要吃碘盐、喝碘酒或碘伏代替碘片:
   碘盐里的碘含量太低,吃到起保护作用的量之前就会盐中毒;
   碘酒、碘伏是外用消毒药,喝下去会中毒
❌ 没有事故通知时不要自行"预防性"服用
```

### 辐射防护

**减少暴露**:
```
✓ 远离辐射区
✓ 留在室内
✓ 地下室最佳
✓ 减少外出时间
  - 必须外出时戴口罩、穿长衣长裤,回来在门口脱掉外衣、洗手洗脸
```

**避免摄入**:
```
✓ 不要饮用未经处理的水
  - 自来水能不能喝听官方通知;事故前已经装在密闭容器里的水可以喝
  - 室外的雨水、露天水缸和池塘的水不要喝
  - 煮沸和普通净水器去不掉放射性物质
✓ 不要食用当地食物(可能污染)
  - 菜地里的蔬菜、果树上的水果、放养的家禽家畜和它们的奶、蛋,
    在官方检测并通知可以吃之前都不要吃
✓ 使用密封包装食品和瓶装水
  - 放在室内、柜子里、冰箱里的食物可以吃;罐头和包装袋打开前先擦净外表
✓ 清洗食物
  - 包装没有破损的食物,外面擦洗干净后可以食用
✓ 不要哄抢食盐、碘片和瓶装水;按官方安排领取物资
```

**长期防护**:
```
✓ 监测辐射水平
✓ 避免高污染区
✓ 定期健康检查
✓ 心理辅导
  - 对辐射的恐惧和不确定感带来的心理压力,往往比辐射本身影响更多的人;
    失眠、焦虑持续不缓解要寻求帮助
```

**什么情况要告诉医护人员**: 事故后几小时内出现恶心、呕吐、乏力、皮肤发红,可能是受到了较大剂量的照射,要立即告诉现场医护人员或拨打120,并说明自己当时所在的位置和停留时间。

社会长期失序时的核灾难生存要点见[末日求生-核灾难](../03-野外生存/06-末日求生.md#核灾难),辐射剂量的物理基础见[现代物理](../09-进阶科学与工程/06-现代物理.md)。

## 恐怖袭击

### 类型

- 爆炸
- 枪击
- 车辆冲撞
- 持刀等暴力袭击
- 化学/生物/核袭击
  - 化学袭击按[化学品泄漏](#化学品泄漏)处理,放射性袭击按[核辐射](#核辐射)处理

**平时的防范**: 在车站、商场、景区等人多的地方,进门先看一眼安全出口在哪里;留意形迹可疑、在炎热天气穿厚重衣服、反复察看安保情况的人,以及无人看管的包裹,发现了告诉保安或拨打110。

### 爆炸袭击

**现场应对**:
```
1. 卧倒:
   - 脸朝下
   - 双手护头
   - 张嘴(减少气压伤)

2. 寻找掩护:
   - 坚固物体后
   - 远离窗户、镜子
   - 远离玻璃幕墙、广告牌和可能倒塌的吊顶

3. 二次爆炸:
   - 可能有
   - 不要立即返回
   - 快速撤离
   - 不要聚集围观;袭击者有时专门针对聚集的人群和救援人员

4. 撤离:
   - 远离现场
   - 往上风方向
   - 帮助他人
   - 不要触碰可疑物品
   - 走楼梯不坐电梯;有烟时低姿前进
   - 离开后打110/120,说清地点;随后给家人报平安(发短信,少打电话占线)
```

**现场受伤**:
```
- 先处理大出血: 用手或厚布直接用力压住伤口,持续不松手
- 四肢大出血压不住时才考虑止血带
- 伤者不能动、颈背部疼痛的,不要随意搬动(除非现场还有危险)
- 爆炸后耳鸣、听不清很常见;但胸痛、气短、咳血可能是冲击波造成的肺损伤,
  外表没伤也要告诉医护人员
- 有大量伤员时,把能走的人带离,把力量留给有大出血和呼吸困难的人
```

止血方法见[基础急救知识-止血方法](../01-日常疾病和伤害/00-基础急救知识.md#止血方法),起火和浓烟中的逃生见[火灾-火场逃生](04-火灾.md#火场逃生)。

### 枪击袭击

**"跑、躲、报"原则**: 我国公安机关和多数国家的反恐科普都按这个顺序——**能跑先跑,跑不了就躲,安全了马上报警**;只有在生命受到直接威胁、无路可逃时,才考虑最后一步"反抗"。

**1. 跑(Run)**:
```
如有逃生路线:
✓ 立即跑
  - 往远离枪声、远离袭击者的方向跑;利用墙角、柱子等遮挡,不要在空旷处直线停留
✓ 丢下物品
✓ 帮助他人(如可能)
  - 但不要因为说服别人跟你走而耽误时间
✓ 阻止他人进入危险区
✓ 拨打报警
  - 到了安全的地方再打
✓ 跑出去以后继续远离,不要在出口处聚集
```

**2. 躲(Hide)**:
```
如无法逃跑:
1. 躲在坚固掩体后
   - 挡得住子弹的才是掩体(承重墙、混凝土柱、厚重的金属柜);
     普通门、隔板、玻璃只能挡住视线
2. 锁门
3. 堵门
   - 用桌子、柜子等重物顶住门
4. 关灯
5. 静音手机
   - 同时关闭振动
6. 趴下,远离门窗
7. 保持安静
8. 如可能,报警(文字信息)
   - 不少地区开通了短信报警(如12110),平时先查清本地是否可用;
     不能发短信时拨通110后小声说出位置,说不了话就保持通话
   - 说清: 地点(楼层、房间)、袭击者人数、外貌、方向、有无伤员
```

**3. 报(Tell)**:
```
到安全地点后立即报警(110),说清:
- 准确地点
- 袭击者人数、衣着、外貌、携带的东西、逃跑的方向和交通工具
- 伤亡情况
- 你现在在哪里、怎样能找到你

警察到达时:
✓ 双手空着、举起、张开手指,让警察看清你手里没有东西
✓ 服从指令,不要突然动作,不要冲向警察或抓住他们
✓ 警察首先要制止袭击者,不会先救伤员,这是正常的
```

**最后手段: 反抗**:
```
⚠️ 只有在无法逃跑、躲藏已经被发现、生命受到直接威胁时!

- 下定决心,全力以赴,能多人一起更好
- 利用身边能拿到的东西(椅子、灭火器喷向对方面部等)阻止对方
- 目标:制服或逃脱
  - 一旦有机会脱身,立即跑
```

### 车辆冲撞

```
警惕:
✓ 观察周围
  - 在步行街、广场等人多的地方,不要整个人沉浸在手机里
✓ 听到异常声音
  - 发动机轰鸣、急加速、尖叫声
✓ 看到车辆加速冲向人群

反应:
1. 往侧面跑
   - 不要顺着车辆开来的方向往前跑,向两侧、离开车道的方向跑
2. 躲到障碍物后:
   - 柱子、树木
   - 车辆、建筑
   - 进入商店、楼道等车辆开不进去的地方
3. 如无法躲避,尽量往旁边闪避,不要停在原地;
   车辆停下后司机可能下车继续行凶,不要靠近,继续远离并报警
```

### 持刀等暴力袭击

```
✓ 和枪击袭击一样按"跑、躲、报"
✓ 跑的时候往人多、有安保的地方跑,同时大声呼喊提醒他人
✓ 不要试图夺刀;拉开距离、用椅子、背包等物品隔开最重要
✓ 刀伤出血: 用力按压伤口;刀还插在身上的不要拔,固定好送医
```

刺入物的处理见[外伤处理](../01-日常疾病和伤害/02-外伤处理.md)。

### 人质劫持

```
如被劫持:

✓ 保持冷静
✓ 服从指令
✓ 不要反抗(初期)
  - 劫持初期劫持者最紧张,最容易伤人
✓ 观察周围(如可能)
  - 记住劫持者的人数、外貌、口音、携带的东西,获救后告诉警方
✓ 保持低调
✓ 不要与劫持者对视
✓ 不要激怒
  - 不争辩、不哭闹、不试图说服;需要喝水、上厕所、吃药时平静地提出
✓ 照顾好自己: 能吃就吃,能休息就休息,谈判可能持续很久
✓ 如救援到来:
  - 立即卧倒
  - 双手抱头
  - 等待指令
  - 不要突然起身或奔跑,不要捡拾任何东西(会被误认为劫持者)
```

### 可疑物品

```
识别:
- 无人看管包裹
- 形状异常
- 电线、天线外露
- 异常声音、气味
- 标签奇怪

应对:
✓ 不要触碰!
  - 不要打开、移动、摇晃,不要用水浇、用东西盖
✓ 远离
  - 至少离开到有坚固墙体遮挡的地方,远离玻璃
✓ 报警
  - 离开之后再打电话(不要在物品旁边使用手机、对讲机)
✓ 疏散周围人
✓ 等待专业人员
```

## 踩踏与人群拥挤

踩踏多数不是因为有人"被踩",而是人群密度太大时,四面八方的挤压让人**胸口无法扩张、窒息**。演唱会、体育赛事、节日庆典、景区、地铁和车站的楼梯与狭窄通道都是高风险地点。

### 预防踩踏

```
✓ 尽量避开人流高峰;带孩子、老人时尽量不去人特别多的地方
✓ 进场先看清安全出口和疏散通道,约好走散后的集合地点
✓ 穿合脚、防滑的平底鞋,不穿拖鞋、高跟鞋;衣服不要有长带子
✓ 走在人群边缘,不走中间
✓ 顺着人流走,不要逆流,不要突然停下、回头、蹲下系鞋带或捡东西
✓ 在楼梯、斜坡、桥上、通道口特别小心
✓ 不起哄、不推搡;看到有人推挤,大声提醒"不要挤"

⚠️ 出现以下情况,说明人群已经危险,尽快往边上撤:
- 身体被前后挤住,自己无法控制往哪走
- 人群像波浪一样一阵阵来回涌动
- 呼吸开始困难,听到有人呼救、尖叫
```

### 被挤在人群中

```
1. 保持站立,这是最重要的一条
   - 双脚分开与肩同宽,膝盖微屈,重心放低,站稳
2. 护住胸口,留出呼吸空间
   - 一只手握拳,另一只手握住这只手的手腕,双肘撑开平放在胸前,
     用手臂在胸前顶出一点空间
3. 顺着人流,向侧面斜着移动
   - 不要硬往回挤,也不要原地抵抗;每次人群松一下,就往边缘挪一点
4. 远离危险的边界
   - 墙角、栏杆、玻璃橱窗、柱子前面都可能被挤伤;不要试图抓住栏杆不放
5. 保存体力,少喊叫;需要呼救时集中几次大声喊
6. 鞋子掉了、东西掉了,都不要弯腰去捡
7. 带着孩子: 把孩子抱起来,护在胸前或让孩子骑在大人肩上
```

### 摔倒后

```
1. 尽快爬起来
   - 借助身边人的力量,先蹲起再站起
2. 起不来时,采用保护姿势:
   - 侧躺,身体蜷缩成球形
   - 双手十指交叉相扣,护住后脑和后颈
   - 两肘向前,护住两侧太阳穴
   - 双膝尽量弯曲收向胸前,护住胸部和腹部
   - 不要仰面朝天或趴着(胸腹会被直接压住)
3. 人群稍有松动就立即爬起来
```

### 发现有人摔倒

```
✓ 马上停下,大声呼喊"有人摔倒了!别挤了!",让后面的人知道
✓ 身边几个人手挽手、背靠背围成一圈,挡住后面的人流,把摔倒的人拉起来
✓ 你在人群外围或高处时: 向后面的人喊话、示意停止前进,通知保安和警察
```

### 踩踏后的救助

```
✓ 等人群疏散、自己安全后再救人;先拨打120和110
✓ 优先救没有反应、没有正常呼吸的人: 立即开始CPR
✓ 有反应的伤员: 让他侧躺或坐着休息,不要随意搬动可能骨折的人
✓ 被挤压后胸闷、呼吸困难、咳血、腹痛的,外表没伤也要送医
```

CPR见[基础急救知识-心肺复苏](../01-日常疾病和伤害/00-基础急救知识.md#心肺复苏cpr),骨折的固定见[骨骼损伤](../01-日常疾病和伤害/03-骨骼损伤.md)。

## 大面积停电停水

电网事故、极端天气、战乱等都可能造成大范围、长时间的停电停水。下面只列要点,具体做法见相关章节。

**停电时**:
```
✓ 照明首选LED手电、头灯、营地灯;点蜡烛时人不离开,睡前熄灭
✓ 用发电机、炭火、燃气取暖或做饭时,绝不能在室内、车库、阳台使用 ——
  停电期间一氧化碳中毒的人数会明显增加
✓ 冰箱、冰柜尽量少开门: 一般冷藏室能保持低温约4小时,装满的冷冻室约2天;
  超过时间、已经变温的肉类、熟食、奶制品不要再吃
✓ 胰岛素等需要冷藏的药品提前想办法降温保存
✓ 用制氧机、呼吸机等家用医疗设备的人,提前准备备用电源,
  停电时间可能较长时尽早联系医院或社区
✓ 拔掉电器插头,只留一盏灯的开关打开,来电时就能知道,
  也避免电压不稳损坏电器、引起火灾
✓ 手机省电: 调低亮度、关闭不用的功能,用短信代替通话
✓ 被困电梯: 按警铃、拨打电梯内的救援电话或119,
  不要扒门、不要试图从电梯里爬出去,保持冷静等待救援
```

**停水时**:
```
✓ 接到停水通知后,用干净的有盖容器多储一些水,浴缸也可以放满(用于冲厕所)
✓ 饮用水按每人每天约2-3 L准备,另外要有洗手、做饭用的水
✓ 来源不明的水煮沸后再喝
✓ 冲厕所用储存的非饮用水;缺水时洗手仍然不能省(饭前便后、做饭前)
✓ 恢复供水后,先放水几分钟,水变清了再用
```

应急照明、发电机和燃料安全见[照明与能源](../07-日常生活技能/06-照明与能源.md#停电时的应急照明),一氧化碳中毒见[居家与交通意外](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒),来电后的用电安全见[家庭用电安全-灾后恢复用电](../07-日常生活技能/08-家庭用电安全.md#灾后恢复用电),胰岛素的保存见[慢性病用药储备-停电时](../01-日常疾病和伤害/08-慢性病用药储备.md#停电时),用水量、储水和净水见[水源工程与供水](../07-日常生活技能/10-水源工程与供水.md#需要多少水),手机省电见[应急通信与寻亲-手机省电](06-应急通信与寻亲.md#手机省电)。

## 📝 总结要点

### 人为灾难共同原则

```
1. 保持警惕
2. 关注预警
3. 快速反应
4. 保护自己
5. 帮助他人
6. 听从专业指挥
```

### 各类灾难应对

**战乱**:
- 低调行事
- 远离冲突区
- 及时撤离
- 不碰未爆弹药

**化学品**:
- 判断风向
- 往上风撤离
- 密闭室内(楼上)
- 脱衣冲洗,眼睛冲15-20分钟

**核辐射**:
- 时间、距离、屏蔽
- 就地掩蔽或撤离
- 避免摄入
- 碘片只在官方通知时服用

**恐怖袭击**:
- 跑、躲、报
- 远离现场
- 快速撤离

**踩踏**:
- 护住胸口,保持站立
- 顺人流向侧面移动
- 倒地后侧身蜷缩,护头护颈

### 记住

```
✓ 提前准备
✓ 保持冷静
✓ 快速决策
✓ 不要恐慌
✓ 互相帮助
✓ 生命第一
```

### 心理准备

```
人为灾难的特点:
- 突发性
- 不确定性
- 恐惧性

应对:
✓ 心理准备
✓ 学习知识
✓ 模拟演练
✓ 保持希望
✓ 寻求支持
```

经历事件后出现失眠、闪回、过度警觉等反应很常见,怎样照顾自己和身边的人见[心理健康](../01-日常疾病和伤害/10-心理健康.md#经历危机后的正常反应)。
