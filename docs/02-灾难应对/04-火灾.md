# 火灾应对指南

火灾最大的杀手往往不是火,而是烟: 多数火灾遇难者是被浓烟和有毒气体夺去生命的,而且常常发生在睡梦中。本章按应急管理部消防救援局等官方消防科普的主流建议整理,核心只有三条: **装报警器、早发现; 小火会扑、扑不灭就走; 大火不恋财、低姿快逃,逃不了就关门固守。**

## 建筑火灾

### 火灾预防

**家庭防火检查**:
```
每月检查:
✓ 烟雾报警器: 按测试键,能响才算合格(怎么装、何时换见下文)
✓ 电线老化: 外皮发硬、开裂、发黄发黑,插头插座发烫、有焦味、有烧痕
✓ 插座过载: 一个插线板上不同时插多个大功率电器,插线板不串接
✓ 燃气管道: 软管有无老化龟裂、被压、被老鼠咬;接口抹肥皂水看有无气泡
✓ 灭火器: 压力表指针在绿区(红区欠压、黄区超压都要送检),
          没有过期、喷管没有老化开裂,放在显眼易取处
✓ 消防通道畅通: 楼道、楼梯间、安全出口不堆杂物、不停放电动自行车,
               防火门保持关闭(不要用东西顶住常开)
✓ 阳台杂物清理: 纸箱、旧家具、易燃物不要堆在阳台和窗边

每天睡前:
✓ 关燃气灶具阀门,检查炉火、烟头、蚊香、蜡烛已熄灭
✓ 不需要通电的电器断电,不给电动自行车电池在室内充电
✓ 卧室门关上睡觉(关着的门能挡住烟火一段时间,争取逃生时间)
```

#### 烟雾报警器和燃气报警器

```
烟雾报警器(独立式、带电池,一两百元以内即可买到):
✓ 装在哪里: 每间卧室、卧室外的走廊、客厅,多层住宅每层至少1个
✓ 装在天花板中间,离墙和梁至少0.5 m;不要装在空调出风口、门窗旁
❌ 不要装在厨房和浴室(油烟、水汽会频繁误报),厨房改装感温报警器或燃气报警器
✓ 每月按一次测试键
✓ 可换电池的,每年换一次电池;发出"嘀"的低电量提示时立即换
✓ 报警器本身一般用10年左右就要整体更换(看产品说明)
✓ 家里有听力障碍者: 选带闪光或振动枕垫的报警器
❌ 误报时不要拆掉电池了事,扇一扇或开窗,找出原因

燃气报警器:
✓ 天然气比空气轻,报警器装在离天花板0.3 m以内
✓ 液化石油气比空气重,报警器装在离地面0.3 m以内
✓ 最好选能联动自动关闭燃气阀门的
```

**消防设备**:
```
必备:
✓ 烟雾报警器(见上文)
✓ 灭火器: 家庭选1-2 kg的ABC干粉灭火器或水基型灭火器,厨房、客厅各一个
✓ 灭火毯: 挂在厨房门边、离灶台不远的墙上
✓ 逃生绳(高层,配合练习使用)
✓ 防烟面罩(消防自救呼吸器): 每个家庭成员一个,放在卧室;
  按产品标注的防护时间使用,一次性,要提前练习佩戴
✓ 应急手电: 床头一个(夜间停电、浓烟中找路)

位置:
- 易取处,不要锁在柜子里、压在杂物下
- 家人都知道在哪里,会用
- 定期检查(和每月防火检查一起做)
```

**逃生计划**:
```
制定:
✓ 画一张家里的平面图,标出每个房间的门窗、通往楼梯的路线
✓ 至少2条逃生路线: 正门之外,想好第二条(另一个楼梯、阳台、相邻单元)
✓ 集合地点(楼外): 固定一个地方,如小区门口的某棵树、路灯下,
  逃出后在这里清点人数,有人没到要立即告诉消防员
✓ 每个房间的逃生路线: 特别是卧室,夜里起火要知道从床边怎么出去
✓ 确认防盗窗有可以从里面打开的逃生口,钥匙放在固定位置
✓ 特殊人员帮助计划:
  - 婴幼儿: 指定谁负责抱哪个孩子
  - 老人、行动不便者: 卧室尽量靠近出口,指定专人帮助
  - 听力障碍者: 闪光/振动报警器,约定叫醒方式
  - 孩子: 教会"着火了不要躲",不要躲在床下、衣柜里

演练:
✓ 每半年一次
✓ 夜间演练(睡着时起火最危险)
✓ 摸黑演练(模拟浓烟): 关灯、闭眼,沿墙摸到门口
✓ 计时(2分钟内逃出)
✓ 练习: 摸门、低姿前进、关门、到集合点报到、打119的说法
✓ 每次演练后讨论: 哪里卡住了,哪条路不通,东西是否放在了该放的地方
```

### 发现火灾

**立即**:
```
1. 大喊"着火了!",叫醒、通知家人和邻居
2. 启动火警报警器(楼道里的手动报警按钮,红色,按下或击碎面板)
3. 拨打119(火很小、正在扑救时让别人去打;火大时先逃出再打)
4. 准确报告:
   - 地址
   - 着火物
   - 火势大小
   - 有无人员被困
   - 姓名电话
5. 派人在路口接消防车
```

#### 报119怎么说

```
接通后说清楚(接警员问什么答什么,不要自己先挂电话):
1. 地址: 区/县、街道、小区、楼号、单元、楼层、门牌号
   说不清时,说附近明显的标志(学校、商店、路口、公交站)
2. 什么着火: 住宅、厨房、电动自行车、仓库、车辆……
   有没有燃气罐、汽油、化学品等危险物品
3. 火势: 只冒烟还是有明火,烧到哪里,在第几层
4. 有没有人被困: 几个人,在哪个房间,有没有老人、孩子、行动不便的人
5. 报警人姓名和电话,之后保持手机畅通(消防员可能回拨问路)

示例:
"XX区XX路XX小区5号楼2单元,12楼1203室厨房着火,
 明火已经烧到客厅,卧室里还有一位老人没出来。我叫……电话……"

打完之后:
✓ 派人到小区门口、路口接消防车,带路
✓ 通知物业、保安: 打开门禁、移开挡住消防通道的车辆
✓ 119报警免费;手机锁屏状态下可以用"紧急呼叫"拨打
❌ 不要因为"火不大""怕麻烦""怕赔钱"而不报警或拖延报警
❌ 不要谎报火警(违法,而且占用救援力量)
```

**小火扑救**:
```
仅当:
✓ 火势很小(如垃圾桶、锅里、一小块地毯),火焰没有超过人的高度
✓ 有灭火器
✓ 有逃生退路(背对出口灭火,火在前、门在后)
✓ 已报警
✓ 烟不浓,自己能正常呼吸

方法:
1. 使用灭火器(用法见下文"灭火器使用")
2. 站在上风处
3. 对准火源根部
4. 左右扫射
5. 如无效,立即撤离

撤离的时机: 一具灭火器喷完火还没灭、烟越来越浓、火烧到了天花板或窗帘
→ 立即撤离,出去时随手关门(把火和烟关在里面),然后报警
❌ 不要一边灭火一边让火挡住自己的出口
```

不同东西着火,扑救方法不同:

| 着火物 | 可以用 | 绝对不要 |
|------|------|------|
| 纸张、木头、布料、垃圾 | 水、水基型或ABC干粉灭火器、湿布覆盖 | — |
| 油锅、炸锅(食用油) | 关火、盖锅盖、灭火毯 | 泼水、端锅走 |
| 电器、插座、电线 | **先断电**,再用干粉或CO₂灭火器、灭火毯 | 未断电时用水或泡沫 |
| 燃气灶、燃气管 | 先关阀门,再灭余火 | 阀门没关就把火扑灭 |
| 汽油、酒精、油漆 | 干粉、泡沫灭火器,沙土覆盖 | 用水冲(会带着火流淌扩散) |
| 电动自行车电池、锂电池 | 一般不要自己扑救,立即撤离并关门 | 靠近、搬动 |

#### 油锅起火

```
⚠️ 绝对不要泼水!
  油温远高于100°C,水一进去瞬间变成蒸汽,把燃烧的油炸得到处都是,
  形成一团火球,烧伤人、引燃整个厨房

正确做法:
1. 关火(关掉灶具开关或燃气阀门)
2. 盖上锅盖(或灭火毯、大小合适的湿毛巾、案板)
   - 从自己这一侧斜着往前推着盖上,手和脸不要在锅的正上方
   - 也可以把切好的大量青菜倒进锅里降温(只适用于刚起火、火不大时)
3. 盖住之后不要马上掀开看,等锅彻底凉下来再打开(太早掀开会复燃)
4. 不要端起锅往外跑(油会洒出来,烧伤自己、引燃地面)
5. 火已经蔓延到抽油烟机、橱柜 → 用灭火器,扑不灭立即撤离,关上厨房门

预防:
✓ 炒菜、油炸时人不离开灶台
✓ 灶台旁放一个合适的锅盖,厨房备灭火毯
✓ 定期清洗抽油烟机和烟道里的油垢(油垢是火顺着烟道蔓延的"引线")
```

#### 灭火毯

```
用途: 油锅起火、小面积火、裹住身上着火的人、逃生时披在身上
用法:
1. 双手握住灭火毯包装下面的两根拉带,用力往下拉出
2. 抓住毯子上方两角,把毯子挡在身前,护住手和脸
3. 走近火源,把毯子从自己这一侧向前盖住火,完全盖严,不要抛扔
4. 盖住后保持不动,同时关火、断电
5. 等完全冷却后再取下(一般用过就报废,不再重复使用)

✓ 挂在厨房门边、伸手就能拿到的地方,不要放在灶台正上方(起火时够不着)
```

**大火逃生**:
```
立即逃生!不要:
❌ 试图扑救
❌ 收拾财物
❌ 寻找宠物
❌ 贪恋财物

优先:
✓ 生命
✓ 逃生
✓ 逃生
```

为什么要这么快: 现代家具、床垫、沙发大多含泡沫塑料和化纤,一旦烧起来,几分钟内整个房间就会充满浓烟,温度高到人无法存活。**起火后能安全逃生的时间常常只有两三分钟。** 手机、钱包、证件都不值得用命换。

### 火场逃生

#### 逃生原则

**1. 判断逃生路线**:
```
开门前:
1. 用手背触摸门把手(手背对热更敏感,被烫伤也不影响手掌抓握)
   也摸一摸门板上方和门缝(热烟先积在上面)
   - 烫?不要开门!
   - 不烫?小心打开一条缝观察

2. 看门缝:
   - 有烟?不要开门
   - 无烟?可以开门

   开门的方法: 身体躲在门后侧,用脚抵住门,慢慢打开一条缝;
   一旦有热气、浓烟涌进来,马上用力关上

3. 选择:
   - 如能逃生,立即走
   - 如不能,固守待援
```

**2. 低姿前进**:
```
浓烟中:
✓ 弯腰或匍匐
✓ 用湿毛巾捂住口鼻
✓ 沿墙壁前进
✓ 关闭身后的门(防烟扩散)

为什么要低: 热烟往上走,离地面越近,空气越凉、烟越少、能见度越好
- 烟不太浓: 弯腰快步走
- 烟很浓、看不清: 手膝着地爬行,头不要抬高
✓ 一只手摸着墙走,不会迷失方向;沿着墙总能摸到门
✓ 走之前想好方向,数着门走(提前演练过就有数)
❌ 浓烟中不要大口喘气、不要大声喊叫(吸入更多烟)
```

**湿毛巾的作用和局限**:
```
能做到:
✓ 挡住一部分烟尘颗粒,减轻呛咳
✓ 对刺激性的烟有一定缓冲
✓ 折叠几层,捂住口鼻,湿而不滴水即可(太湿反而憋气)

做不到:
❌ 挡不住一氧化碳、氰化氢等有毒气体,也不能提供氧气
❌ 不能让你在浓烟里待更久——它只是让你逃的路上好受一点

所以:
✓ 手边有水、有毛巾就顺手弄湿;身边没有水时,干毛巾、衣服捂住也比不捂好
❌ 出口就在眼前时,不要为了找水打湿毛巾耽误时间
✓ 真正保命的是: 低姿 + 快速离开烟区
✓ 有防烟面罩(消防自救呼吸器)的,戴上再走,比湿毛巾可靠得多
```

**3. 逃生路径**:
```
✓ 首选楼梯
✓ 往下跑(除非下方是火源)
✓ 关闭经过的防火门
✓ 跟着绿色的"安全出口"和疏散指示标志走

❌ 绝不:
- 乘电梯(断电会困住,烟囱效应)
- 往上跑(除非顶楼有出口)
- 返回取物
```

```
为什么不能乘电梯:
- 火灾时可能断电,人被困在电梯里,烟从井道灌进来
- 电梯井像烟囱,烟气在竖井里上升极快,比人上楼还快
- 电梯可能在着火的楼层停下、开门
- "消防电梯"是给消防员用的,不是给居民逃生的

为什么不能返回:
- 已经逃出来的人,回去拿东西、找人,是火场伤亡的常见原因
- 火势和烟在几分钟内会大变,回去时的路可能已经不通
- 有人没出来 → 立即告诉消防员他可能在哪个房间,让专业人员去救
```

#### 被困时

**高层住宅: 能逃则逃,不能逃则守**:
```
能逃(马上走):
- 自己家里着火 → 立即逃出,随手关上家门,下楼后报警
- 楼道、楼梯里没有烟或烟很少 → 走楼梯往下

不能逃(关门固守):
- 门把手烫、门缝冒烟
- 打开门看到楼道已经充满浓烟、看不清楼梯
- 下面楼层起火,烟正在往上涌
→ 留在自己家里,关门固守,等待救援
   一扇关着的门后面,往往比满是浓烟的楼道安全得多
   每年都有人在楼道里被烟呛倒,而关门待在家里的人却安然无恙
```

**无法逃离房间**:
```
1. 关门(普通房门也能延缓烟火数分钟;正规防火门耐火0.5-1.5小时)
2. 用湿布条堵门缝
3. 泼水降温(门、墙)
4. 往窗户移动
5. 发出求救信号:
   - 挥舞鲜艳衣物
   - 打手电
   - 敲击金属
   - 大声呼救
6. 等待救援
7. 湿毛巾捂口鼻
8. 低姿减少吸入烟雾
```

```
固守的细节:
✓ 选一个有窗、最好有水的房间(卫生间、带窗的卧室),
  离着火点越远越好,进去后把所有门都关上
✓ 用湿毛巾、湿床单、湿衣服塞住门下缝、门边缝,通风口、空调口也堵上
✓ 不断往门上泼水,保持门和堵缝的布湿润
✓ 立即打119,告诉对方你在几楼几室、哪个房间、几个人
✓ 窗外没有烟时可以开窗透气、求救;窗外有烟、火往上窜时要关窗
✓ 白天在窗口挥舞颜色鲜艳的衣物、床单;夜里用手电、手机灯光朝外晃
✓ 往窗外扔枕头、软的东西引起注意(不要扔硬物砸到人)
❌ 不要躲在床下、衣柜里、角落里——消防员搜索时很难发现你
❌ 不要冒险打开门去看情况
```

**被困楼梯间**:
```
- 楼梯间相对安全
  (指带防火门的封闭楼梯间、防烟楼梯间;防火门一旦被顶开就失去作用)
- 如无法下楼:
  * 等待救援
  * 关闭楼梯门
  * 发信号
- 敞开式楼梯、没有门的楼梯会像烟囱一样灌烟,不能久留
- 楼梯被烟火堵死时,可以进入未着火楼层的走廊或住户家里,关门躲避
```

**高层被困**:
```
⚠️ 不要跳楼!(3层以上致命)

选择:
1. 固守房间(如上述)
2. 逃生绳(提前准备,练习使用)
3. 床单打结:
   - 固定牢靠
   - 只作为最后手段
   - 极度危险
4. 等待救援
```

```
⚠️ 楼层不高也不要轻易跳: 即使2层,跳下去也常造成骨折、脊柱和头部损伤
   只有火已经烧进房间、确实无路可走时,低楼层才考虑:
   先往楼下扔被褥、床垫等软物,双手抓住窗台把身体垂下去,
   缩短下落高度后再松手,落地时双脚并拢、屈膝
✓ 高层建筑可能有避难层或避难间(楼梯间里有标识),下不去时可以到那里等待
```

#### 用绳索、床单自救(最后手段)

```
☠️ 只有火已经逼近、关门固守也守不住、不下去必死时才用
   绝大多数情况下,关门固守等待消防员比沿绳下降安全得多

1. 材料: 逃生绳最好;没有就把床单、被罩、窗帘撕成或拧成宽条
   拧成绳状比平铺的布条更结实
2. 连接: 两段布条或绳子之间用接绳结或渔人结(双渔人结更牢)
   ❌ 不要用平结: 平结受力、抖动时会翻转松脱,
     尤其是两根粗细、材质不同时,很容易在半空中散开
   每个结打好后拉紧,留出一拳长的绳头,用全身重量试拉
3. 固定: 系在暖气管、结实的承重固定物上,不要系在可能被拉脱的
   床脚、铝合金窗框、晾衣杆上
4. 长度: 不需要到地面,能下到下一层或下两层的阳台、窗台即可
   (然后从那一户、那一层的楼梯撤离)
5. 下降: 戴手套或用布裹住手,双手交替抓绳,双脚夹住绳子,
   面朝墙慢慢往下,不要抱着绳子往下滑(会把手磨伤后松手)
6. 孩子、老人自己抓不住绳: 用单套结打一个不会收紧的绳圈套在腋下,
   上面的人把绳子在固定物上绕一圈,慢慢放下去,再自己下
```

各种结的打法见[绳索与结绳-接绳结](../07-日常生活技能/17-绳索与结绳.md#接绳结-连接粗细不同的两根绳)、[渔人结](../07-日常生活技能/17-绳索与结绳.md#渔人结-连接两根绳子)、[单套结](../07-日常生活技能/17-绳索与结绳.md#单套结称人结-打一个不会收紧的绳圈),平结为什么不能用于连接见[平结](../07-日常生活技能/17-绳索与结绳.md#平结-只用来捆扎)。

### 身上着火

```
⚠️ 不要跑!(氧气助燃)

停-躺-滚:
1. 停下
2. 躺倒
3. 双手护脸
4. 滚动灭火
5. 或用厚衣物、毯子裹住灭火
```

```
细节:
✓ 双手捂住脸(保护眼睛、口鼻和气道),来回翻滚,直到火完全熄灭
✓ 附近有水池、水缸、浴缸,可以跳进去或往身上浇水
✓ 别人身上着火: 把他按倒,用厚毯子、外套、灭火毯
  从头往脚方向盖住压灭(让火焰往脚的方向走,不往脸上窜);
  不要用化纤织物(会熔化粘在皮肤上)
❌ 不要用灭火器对着人的脸喷;没有别的办法时可以对着身体喷
✓ 火灭后: 立即用冷水冲洗烧伤处,按烧伤处理(见下一节)
✓ 教孩子练习"停-躺-滚",在家里演练几次,遇到时才做得出来
```

### 逃出来以后: 烧伤和吸入烟雾

```
1. 到集合点清点人数,有人没出来 → 告诉消防员他可能在哪个房间
   ❌ 自己不要回去找
2. 吸入了烟的人: 到空气新鲜处,坐着休息,保暖,不要走动
3. 出现下列任何一项,拨打120(或告诉现场消防员、急救人员):
   - 头痛、头晕、恶心、乏力、意识模糊(一氧化碳等有毒气体中毒)
   - 咳嗽不止、声音嘶哑、呼吸困难、呼吸有杂音
   - 口鼻周围烧伤、鼻毛烧焦、痰里有黑色炭末(可能有呼吸道烧伤)
   - 胸痛、心慌
   - 孕妇、婴幼儿、老人、有心肺疾病的人吸入了烟,即使症状轻也要就医
   ⚠️ 现在感觉还好也要去医院检查: 呼吸道肿胀可能在几小时后才出现
4. 无反应、无正常呼吸 → 立即心肺复苏
5. 烧伤: 立即用流动的凉水冲洗,按"冲、脱、泡、盖、送"处理
   ❌ 不要涂牙膏、酱油、草木灰
6. 火灭之后,经消防人员确认安全前不要回到屋里
```

烧伤的处理和就医标准见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤)和[呼吸道烧伤](../01-日常疾病和伤害/02-外伤处理.md#呼吸道烧伤比面积更危险),一氧化碳中毒见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒),心肺复苏见[基础急救知识-心肺复苏](../01-日常疾病和伤害/00-基础急救知识.md#心肺复苏cpr)。经历火灾后的失眠、噩梦、害怕,见[心理健康](../01-日常疾病和伤害/10-心理健康.md)。

### 特殊场所火灾

#### 高层建筑

```
特点:
- 疏散困难
- 烟雾扩散快
- 消防车高度有限

应对:
✓ 熟悉逃生路线
✓ 不要乘电梯
✓ 避难层(如有)
✓ 固守待援(无法下楼时)
```

```
✓ 入住后先走一遍消防楼梯,确认楼梯间的门没有上锁、通道没有被堵
✓ 着火层和上面一两层的人最危险,要立即逃;离着火点很远的楼层,
  楼道没烟时下楼,楼道有烟时关门固守
✓ 下楼时靠楼梯一侧走,给上楼的消防员让出通道
✓ 高层的火往往也伴随外墙保温层、阳台杂物"窜火",窗外有火时关窗
```

#### 地下空间

```
特点:
- 出口少
- 烟雾聚集
- 方向难辨

应对:
✓ 记住入口位置
✓ 沿墙壁前进
✓ 往上走
✓ 跟着疏散指示标志和应急照明走,不要盲目跟着人群挤向同一个出口
```

```
地铁:
✓ 车厢内起火: 按车厢里的紧急报警按钮或对讲,告诉司机;
  车厢里有灭火器(通常在座椅下方或车门旁),小火可以扑救
✓ 列车一般会继续开到前方车站再疏散,不要自己扒门、砸窗跳下轨道
✓ 在站台和隧道里,听从工作人员指挥,沿疏散通道走
地下车库、地下商场:
✓ 进去时留意最近的两个出口
✓ 烟会顺着坡道、楼梯往上涌,往外跑时要低姿
```

#### 公共场所

```
电影院、商场、KTV等:

✓ 进入时观察安全出口
✓ 不要慌乱拥挤
✓ 听从指挥
✓ 寻找多个出口
✓ 不要返回拿物品
```

```
✓ 离你最近的出口不一定是你进来的那个门,大部分人只往进来的门挤
✓ 人群拥挤时,双臂在胸前交叉护住胸口,保持站立,跟着人流走,
  不要逆行、不要弯腰捡东西;有人摔倒立即大声呼喊让后面停下
✓ 宾馆入住后: 看门后的疏散图,数一数从房门到安全出口要经过几扇门
  (浓烟里看不见,摸着墙数门)
```

### 灭火器使用

**类型**:
- **ABC干粉**: 通用(最常见)
- **CO₂**: 电气火灾
- **水基**: 固体火灾
- **泡沫**: 液体火灾

| 火灾类别 | 着火物 | 适用灭火器 |
|------|------|------|
| A类 | 木头、纸、布、塑料等固体 | 水基型、ABC干粉、泡沫 |
| B类 | 汽油、柴油、酒精、油漆等液体 | ABC干粉、BC干粉、泡沫、CO₂ |
| C类 | 天然气、液化气等气体 | 干粉(先关阀门) |
| D类 | 镁、钠、钾等活泼金属 | 专用的金属灭火剂或干沙,不能用水 |
| E类 | 带电的电器、电线 | 干粉、CO₂(先断电) |
| F类 | 锅里的食用油 | 锅盖、灭火毯、标明适用F类的水基型 |

```
家庭怎么选:
✓ 一般选ABC干粉灭火器(1-2 kg)或水基型灭火器,轻便、好用
✓ 灭火器上会标明适用的火灾类别(A、B、C、E……),买时看清楚
⚠️ 干粉灭完后满屋粉尘,会弄脏、损坏电器,但救火时不要顾虑这个
⚠️ CO₂灭火器喷出的是低温气体: 不要握喷筒(会冻伤),
   在密闭小房间里大量使用会让人缺氧,用完立即离开
✓ 灭火器有报废年限(一般水基型6年、干粉10年,以产品标注为准),
  到期或压力不足要送检或更换
```

**使用方法**:
```
提-拔-握-压:
1. 提起灭火器
2. 拔掉保险销
3. 握住喷管
4. 压下手柄
5. 对准火焰根部
6. 左右扫射
7. 距离3-5 m
```

```
细节:
- 干粉灭火器用之前上下颠倒摇几下,让结块的干粉松动
- 提着灭火器走到距火3-5 m处,站在上风处,先远后近
- 一手握喷管对准火焰根部(不是火苗顶部),一手用力压下手柄
- 由近及远左右扫射,把火逐渐推灭,直到火完全熄灭
- 灭火后不要马上离开,盯住几分钟防止复燃
- 一具手提式家用灭火器只能连续喷十几秒,所以要对准了再压

和国外常说的"PASS"是一回事:
  Pull(拔销)- Aim(对准根部)- Squeeze(压把)- Sweep(扫射)
```

**禁忌**:
```
❌ 不要用水扑救:
- 电气火灾(触电)
- 油类火灾(飞溅扩大)
- 金属火灾(爆炸)
```

## 森林火灾

### 预防

```
野外用火安全:
✓ 遵守禁火令
✓ 指定区域用火
✓ 挖防火坑
✓ 完全熄灭:
  - 用水浇透
  - 土埋严实
  - 检查无明火和暗火
✓ 不要:
  - 乱扔烟头
  - 焚烧垃圾
  - 燃放烟花
```

```
✓ 进山前看当地的森林火险等级和防火期规定;防火期内林区一般禁止野外用火,
  包括上坟烧纸、烧荒、烧田埂、野炊
✓ 用火的地方: 选空旷处,清出一圈直径约3 m的裸土,远离树木、干草和树根,
  大风天不生火
✓ 用火时有人一直看着,身边备水或沙土
✓ 熄灭后用手背靠近灰烬感觉,不烫手才算灭透
  (地下的腐殖层、树根可能闷燃很久,几小时后再从别处冒出火来)
✓ 祭扫改用鲜花、植树等方式
```

林区、村庄周围的防火带和防火措施见[薪柴与林地管理](../04-动植物培育/09-薪柴与林地管理.md),野外生火的方法见[基础生存技能-生火技术](../03-野外生存/00-基础生存技能.md#生火技术)。

### 发现森林火灾

```
立即:
✓ 拨打森林火警:12119
✓ 报告位置、火势
✓ 如火小,可扑救
✓ 如火大,立即撤离
```

```
报告时说清楚:
- 你在哪里: 山名、村名、路名、景区名,附近明显的地标;能看手机定位就报经纬度
- 火在你的哪个方向、大概多远,烟是什么颜色(浓黑烟往往烧得猛)
- 风往哪个方向吹,火往哪里蔓延
- 附近有没有村庄、房屋、人员
✓ 打12119或119都可以
✓ 报完马上考虑自己的撤离路线,不要停下来拍照、围观
```

### 逃生

**判断风向**:
```
⚠️ 关键!

逃生方向:
✓ 逆风方向
✓ 向河流、湖泊、空旷地
✓ 向植被稀疏处
✓ 向山下(火向上蔓延快)

❌ 避免:
- 顺风跑(追不上火)
- 往山上跑
- 往浓密植被区
```

```
为什么这样走:
- 火顺风蔓延最快,大风时火头的推进速度比人跑得快,而且风会把
  火星吹到前方很远处,点燃新的火点,人跑在火前面很容易被包围
- 上坡时,下面的火把上面的草木烤干、预热,火往山上烧得比平地快得多,
  人往山上跑越跑越累,火却越烧越快
- 已经烧过的地方("火烧迹地")没有可燃物了,火不会再烧回来

怎样判断风向:
- 看烟往哪边飘,烟飘去的方向就是火要去的方向
- 风向会突然改变(午后、山谷里、锋面过境时),走的时候不断回头看烟

特别危险的地形(不要往这些地方走、不要在这里停留):
- 山脊鞍部、狭窄的山谷、沟口(风会被加速,像烟囱一样把火抽进来)
- 草深、灌木密、松树多的地方(松脂、油性植物烧得特别猛)
- 陡坡的上方
```

**快速逃离**:
```
1. 丢弃易燃物品(背包等)
2. 用湿布捂口鼻
3. 低姿前进
4. 如被包围:
   - 寻找已经烧过的区域,从火势较弱处冲入
   - 等待火过去
   - ⚠️ "点火自救"(点燃身前草地制造隔离带)是专业扑火人员的技术,
     普通人极易烧伤自己,只在完全无路、火头尚远时作为最后手段
5. 如实在无路:
   - 卧倒在空地、沟渠(避开草木茂密处)
   - 脚朝火冲来的方向
   - 扒开浮土直到见湿土,脸贴近湿土
   - 用湿衣物包住头部,用土掩盖身体
```

```
补充:
- 第1条指扔掉打火机、燃料罐、气罐等易燃易爆物和拖累速度的重物;
  水和手机留着
- 穿棉、毛衣物,把袖口、领口扎紧,露在外面的皮肤尽量盖住;
  化纤衣服遇热会熔化粘在皮肤上
- 冲入火烧迹地时: 选火焰低、火线窄的地方,用湿衣服蒙住头,
  屏住呼吸、逆风一口气冲过去,不要犹豫停留
- 有河流、水塘时进入水中,但注意浓烟和热气,不要进很深很急的水
- 开车遇到林火: 路上有浓烟看不清时不要硬闯;被困在车里时,
  停在没有草木的空地,关好门窗、关闭空调外循环,趴低,用衣物盖住身体,
  等火锋过去再出来
```

### 扑救安全

```
⚠️ 仅专业人员!

普通人:
✓ 小火可扑救
✓ 拍打火焰(湿布、树枝)
✓ 扬土压火
✓ 组织隔离带
✓ 保持逃生路线
❌ 大火不要冒险
```

```
什么算"小火": 刚刚烧起来、只在地面烧草和落叶、火焰不超过膝盖、
范围只有几平方米到十几平方米、风不大
→ 超过这个程度,或火已经烧上树冠,立即撤离,交给专业扑火队伍

扑打的方法:
✓ 用带叶的树枝扎成一把,或湿麻袋、湿衣服,
  斜着扑打火焰的根部,打一下往回拖一下
❌ 不要从上往下猛拍(会把火星扇得四处飞溅,引出新的火点)
✓ 从火的侧面、已经烧过的一侧打,不要站在火头正前方(下风处)
✓ 两三个人一组,互相照应,时刻留意风向和退路
✓ 扑灭后至少留人看守,把余火、冒烟的树桩、树根彻底弄灭

谁不能参加扑火:
❌ 未成年人、孕妇、老人、残疾人和身体不适的人不要参加扑救林火
❌ 没有经过训练的人不要进入林区深处扑火,不要到火头前方去
```

## 电气火灾

### 原因

- 线路老化、短路
- 插座过载
- 电器故障
- 私拉乱接

此外还有: 插头插座接触不良、接线松动(接头处长期发热,把周围烤焦);电线被重物压坏、被老鼠咬破;电暖器、浴霸、灯具离可燃物太近;电热毯折叠使用;电动自行车电池在室内充电。

### 预防

```
✓ 定期检查线路
✓ 不超负荷用电
✓ 不私拉乱接
✓ 及时更换老化线路
✓ 使用合格电器
✓ 电器不用时断电
✓ 不要:
  - 电线压在重物下
  - 湿手触碰电器
  - 电器长期待机
```

漏电保护器和空气开关怎么选、插线板和电线怎么用、大功率电器的注意事项、每月检查清单,见[家庭用电安全](../07-日常生活技能/08-家庭用电安全.md),这里不再重复。

### 扑救

```
⚠️ 首先断电!

1. 切断电源:
   - 关闭总闸
   - 或拔掉插头

2. 未断电前:
   ❌ 不要用水
   ❌ 不要用泡沫灭火器
   ✓ 使用干粉或CO₂灭火器

3. 断电后:
   - 可用水扑救
   - 注意复燃
```

```
细节:
- 插头、插线板冒烟起火: 先关掉墙上的开关或电闸,再拔插头;
  插头已经烧着、发烫时不要直接用手去拔
- 电视、电脑等电器起火: 断电后用灭火毯、湿棉被盖住,
  人站在侧面,不要正对屏幕(可能爆裂)
- 电闸在着火点附近、够不到: 不要冒险去拉闸,用干粉或CO₂灭火器,
  扑不灭立即撤离
- 室外电线、变压器起火,电线断落在地上: 远离,不要靠近,
  拨打119并告诉供电部门,等专业人员断电
- 火灭后: 请电工检查线路后再恢复供电
```

### 电动自行车和锂电池起火

```
电动自行车电池一旦起火:
- 燃烧极快,温度很高,还会喷射火焰、产生大量有毒浓烟
- 一般的灭火器很难扑灭,扑灭后还会反复复燃

所以:
✓ 立即撤离,关上门,把火和烟挡在里面,然后拨打119
❌ 不要试图扑救,不要搬动正在冒烟、鼓胀的电池
❌ 楼道里的电动车起火,不要穿过浓烟往下跑,按"不能逃则守"关门固守

预防的关键: 电动自行车不进楼道、不进家门、不进电梯,
在集中充电点充电,不整夜充电
```

充电和停放的具体要求见[家庭用电安全-电动自行车充电](../07-日常生活技能/08-家庭用电安全.md#电动自行车充电),电动汽车起火见[居家与交通意外-车辆起火](../01-日常疾病和伤害/07-居家与交通意外.md#车辆起火)。

手机、充电宝等锂电池也会起火: 不要压、摔、扎;鼓包了就停用;不要放在枕头下、被子里边充边用;充电时不要放在床上、沙发上。

## 燃气火灾

### 预防

```
✓ 定期检查燃气管道
✓ 使用燃气时有人看管
✓ 保持通风
✓ 及时更换老化管道
✓ 使用合格燃气器具
```

```
具体:
✓ 灶具和热水器选带"熄火保护"的(火被风吹灭、汤溢出浇灭时会自动关气)
✓ 连接灶具的软管: 优先换成金属波纹管;用橡胶软管的,长度不超过2 m,
  不穿墙、不穿门窗,两端用卡箍卡紧,发现老化、龟裂立即更换
  (一般建议18个月左右换一次)
✓ 怎样查漏: 用肥皂水抹在接口、阀门、软管上,冒泡就是漏气
  ❌ 绝不能用打火机、火柴"点火查漏"
✓ 安装燃气报警器(装在哪里见上文"烟雾报警器和燃气报警器")
✓ 不在装有燃气管道的房间里睡人,不私自改装、移动燃气管道和表具
✓ 液化石油气钢瓶: 直立放置,不倒放、不横放,不用热水烫、不用火烤,
  不私自倒残液;到正规充装站充气,过了检验期的钢瓶不用
✓ 长时间外出: 关闭燃气总阀门
✓ 燃气热水器不要装在浴室里;燃气、炉火引起的一氧化碳中毒见下方链接
```

一氧化碳中毒的识别、救助和预防见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

### 燃气泄漏

**发现泄漏**:
```
闻到燃气味:

立即:
✓ 开窗通风
✓ 关闭燃气总阀门
✓ 疏散人员
✓ 到户外拨打报警

❌ 禁止:
- 开关任何电器(产生火花)
- 打电话(在室内)
- 使用明火
- 按门铃
- 开抽油烟机
```

```
为什么这样做:
- 燃气本身无色无味,闻到的"臭鸡蛋味"是特意加进去的,闻到就说明在漏
- 燃气和空气混合到一定比例,一个小火花就能引爆:
  开灯、关灯、拔插头、按门铃、手机来电和拨打、开抽油烟机或排气扇,
  都可能产生火花
- 已经开着的电器也不要去关(关的一瞬间同样有火花)

步骤细节:
1. 轻轻打开门窗,让空气对流(不要用电风扇、排气扇吹)
2. 关闭燃气表前的阀门(手柄转到和管道垂直就是关);
   液化气钢瓶顺时针拧紧角阀
3. 叫上家人离开,不要坐电梯;敲门(不按门铃)通知邻居
4. 到室外远离泄漏处的地方,再打燃气公司的抢修电话或119
5. 不要再回到屋里,等专业人员检查处理完毕、确认安全再进去

天然气和液化气的区别:
- 天然气比空气轻,往上飘,聚在天花板附近
- 液化石油气比空气重,往下沉,聚在地面、地下室、下水道、低洼处
  → 液化气泄漏时更要注意地面附近和楼下、地下室不能有火源

楼道里、别人家里闻到燃气味:
✓ 不要在楼道里按电梯、开灯、打电话,先离开到室外再打电话报警
✓ 有人中毒倒在屋里时,先开窗通风,再把人移到室外,
  不要在屋里开灯、打电话
```

**已起火**:
```
1. 关闭燃气阀门(如能接近)
2. 阀门关闭后,用湿布、灭火器扑灭余火
3. ⚠️ 阀门关不上时不要扑灭燃气火焰:
   火灭后燃气继续泄漏,遇火源可能爆炸。
   让其稳定燃烧,只扑灭、隔离周围被引燃的物品
4. 如无法靠近,立即撤离
5. 拨打119
6. 疏散周围人员
```

```
液化气钢瓶的瓶口、软管起火:
- 火不大时: 用湿毛巾、湿抹布裹住手,迅速关闭钢瓶角阀,火会自己熄灭
- 钢瓶已经被火烤、瓶身发烫、火很大: 不要靠近,立即撤离到远处,
  疏散周围的人,拨打119并说明有液化气钢瓶(受热的钢瓶可能爆炸)
❌ 不要把着火的钢瓶放倒、拖走或扔出去
```

## 📝 总结要点

### 火场逃生"七要诀"

```
1. 熟悉环境,牢记出口
2. 保持镇静,明辨方向
3. 扑灭小火,惠及他人
4. 不入险地,不贪财物
5. 简易防护,捂鼻匍匐
6. 善用通道,莫入电梯
7. 火已及身,切勿惊跑
```

### 火灾逃生禁忌

```
❌ 不要返回取物
❌ 不要乘电梯
❌ 不要盲目跳楼
❌ 不要拥挤推搡
❌ 不要深呼吸(吸入毒烟)
❌ 不要站立奔跑(浓烟中)
❌ 不要往油锅里泼水
❌ 不要躲在床下、衣柜里
❌ 闻到燃气味时不要开关电器、不要在室内打电话
```

### 记住

```
预防:
✓ 消除火灾隐患
✓ 准备消防器材
✓ 制定逃生计划
✓ 定期演练

逃生:
✓ 时间就是生命
✓ 往下跑(低层)
✓ 固守待援(高层无法下)
✓ 低姿前进
✓ 发出信号

一句话速记:
- 报警: 119(森林火警12119),说清地址、什么着火、有没有人被困
- 灭火器: 提、拔、握、压,对准火焰根部,扑不灭就走,出门关门
- 油锅: 关火、盖锅盖,绝不泼水
- 电器: 先断电,再灭火
- 门把手烫: 不开门,关门堵缝,窗口求救
- 高层: 能逃则逃,不能逃则守
- 身上着火: 停、躺、滚
- 燃气味: 不碰电器、不打电话,开窗、关阀、到室外报警
- 林火: 逆风、往已烧过的地方和空旷处走,不往山上跑
- 逃出后: 吸了烟、被烧伤都要就医

原则:
生命第一!
```
