## 海啸

### 什么是海啸

海啸是由海底地震、火山喷发、海底滑坡等引起的巨大海浪,具有极强的破坏力。

**特点**:
- 速度快(深海可达700-800 km/h,接近喷气式客机)
- 波长长(数百 km)
- 近岸突然增高(可达数十 m)
- 连续多波(第一波不一定最大)
- 破坏力巨大

**和普通海浪有什么不同**:

普通海浪是风吹起来的,只搅动海面一层,拍上岸就退回去。海啸是整片海水从海底到海面一起被抬起,上岸时更像一堵不断往前推的"水墙"或者一次快速上涨、不停往内陆灌的"涨潮",持续几分钟到十几分钟才退。水里裹着汽车、船、房屋碎片和泥沙,**几十 cm 深的海啸水流就能把成年人冲倒,1 m 左右就足以致命**。所以不能拿"浪不高"来判断危险。

**近海海啸和远洋海啸**:

| 类型 | 来源 | 到达时间 | 能不能等警报 |
|------|------|----------|--------------|
| 近海(近源)海啸 | 附近海域地震 | 几分钟到几十分钟 | **不能**,警报可能比海浪还晚 |
| 远洋海啸 | 几千 km 外的大地震 | 数小时 | 一般有官方预警,按预警撤离 |

我国大陆沿海大部分地区面向浅而宽的大陆架,海啸风险总体比日本、印尼低,但台湾、东南沿海和南海(马尼拉海沟方向)仍有发生海啸的可能;到海外海边旅行时更要掌握这一节。

### 海啸预警信号

#### 自然预警(极重要!)

```
⚠️ 看到以下任一现象,立即撤离!

1. 强烈地震(沿海地区):
   - 持续超过20秒
   - 剧烈摇晃
   - 难以站立
   以上任意一条就算:
   摇得很厉害,哪怕时间短 → 撤离
   摇得不厉害但持续很长、像慢慢晃 → 同样撤离
   (有一种"海啸地震"震感不强,却能引发大海啸)

2. 海水异常:
   - 突然大幅退潮(露出海床)
   - 海面快速上涨
   - 海水翻腾、旋转
   - 发出怪声

3. 其他征兆:
   - 远处轰鸣声(像火车、飞机或炮声一样从海上传来)
   - 海平面异常升降
   - 动物异常(鸟类惊飞)
```

**记住**:
- 近海地震引发的海啸,可能几分钟到几十分钟就到(离震中越近越快),**没有固定的"安全时间"**
- 海水退去是海啸来临最明显信号,但海啸**不一定先退潮**,也可能直接涨上来,不要等看到退潮才跑
- 不要去看"奇观",立即逃命!

```
退潮时最常见的致命错误:
❌ 走下去捡鱼、捡贝壳、拍照
   → 2004年印度洋海啸,不少人就是在露出的海床上被卷走的
❌ "等等看浪多高再说"
   → 能看清浪头时,通常已经跑不掉了
❌ 以为地震震感不强就没事
❌ 第一波很小,就以为海啸过去了
```

#### 官方预警

```
✓ 手机预警短信
✓ 电视、广播
✓ 警报系统
✓ 社区广播
```

**我国的海啸预警**:
- 由自然资源部(国家海洋预警机构)发布海啸信息和警报,预警按严重程度从高到低分为**红、橙、黄、蓝**四色,红色最严重;同时通过当地政府、应急管理部门的预警短信和广播发布
- 收到**任何颜色**的海啸预警且你在海边、港口、河口低地:先往高处走,再看后续消息
- 预警"解除"要等官方正式通知,不要根据"已经过了好一会儿"自己判断

**不要等警报,自己判断后立即跑**:

```
⚠️ 核心原则: 自然征兆 > 官方警报

- 近海地震时,警报系统可能来不及,也可能因停电、地震损坏而不响
- 只要在海边感到强烈或长时间的地震,或看到海水异常,
  不需要等任何人通知,也不需要先打电话确认,立即往高处跑
- 跑到安全的地方后,再看手机、听广播
- 跑了以后发现海啸没来,没有任何损失;等警报而晚了,可能丢命
```

### 海啸来临前

**立即撤离**(分秒必争!):

```
1. 往高处跑!
   目标:
   - 海拔至少30 m(约10层楼)
   - 或距海岸3 km以上
   - 越高越远越好

2. 往内陆跑!
   - 垂直于海岸线
   - 远离海滩、港口
   - 远离河流(海啸会沿河逆流)

3. 携带:
   - 仅必需品
   - 不要浪费时间收拾
   - 生命>一切财物

4. 路线:
   - 提前规划逃生路线
   - 熟悉高地位置
   - 知道最近的坚固高层建筑
```

**撤离时的具体做法**:

```
1. 原则上步行或跑步撤离
   - 地震后道路可能开裂、堵塞,开车容易困在车流里被海水追上
   - 只有离高地很远、带着行动不便的老人或病人、道路明显通畅时才考虑开车,
     而且一堵就弃车步行
2. 跟着"海啸撤离路线"标志走
   (常见标志: 一个人往山坡上跑、身后是波浪;
    到了海外,注意 TSUNAMI EVACUATION ROUTE 字样)
3. 沿着离开河道的方向跑,不要沿河岸、过河桥
4. 路上大声提醒别人"海啸,往高处跑",带上身边的孩子
5. 跑到目标后不要停在边缘看海,继续往更高处走
6. 不要回家拿东西、不要回去找已经在别处的家人
   (见下方"家人分散时")
```

**如无法到达高地**:
```
最后选择:
- 爬上坚固高层建筑(至少3层)
- 钢筋混凝土结构最佳
- 避免木结构、临时建筑
- 爬到最高层
```

#### 垂直疏散

在平坦的海岸平原上,几分钟内跑不到 30 m 高或 3 km 外,这时**往上**比**往远**更快,叫"垂直疏散"。

```
怎样选楼:
✓ 优先: 当地政府指定的海啸避难大楼、应急避难场所
✓ 其次: 钢筋混凝土的学校、医院、酒店、商场、停车楼
✓ 楼层越高越好,至少3层,能上楼顶就上楼顶
✓ 离海越远越好,背海一侧更安全
❌ 避开: 木结构、砖瓦平房、简易板房、老旧危房、地下室
❌ 不要躲进地下商场、地下车库、隧道

没有楼时(最后的选择):
- 爬上结实的大树(尽量高,绑住自己)
- 抓住能漂浮的大件物品
```

#### 家人分散时

海啸来得快,各自所在的地方各自往高处跑,是保全全家最有效的办法。日本三陆地区把这种经验总结为"海啸来时各自逃命"——前提是全家**事先约好**:

```
提前约定:
- 每个人都知道: 地震了在哪里就从哪里直接往高处跑,不等家人
- 约好事后在哪个高地会合、几点前联系不上找谁(外地联系人)
- 孩子在学校时,学校会组织撤离,家长不要往海边方向去接
- 家里有行动不便的人: 提前和邻居、社区约好谁来帮忙,
  提前确定离家最近的避难楼
```

家庭通信计划的做法见[应急通信与寻亲-灾前: 家庭通信计划](06-应急通信与寻亲.md#灾前-家庭通信计划)。

### 海啸期间

**在建筑内**:
```
✓ 最高楼层
✓ 远离窗户
✓ 抓牢固定物
✓ 保护头部
✓ 已经在楼顶时,不要因为水退了就下楼
```

**在船上**:
```
- 在港口里、靠岸的小船: 弃船,上岸往高处跑
  (港湾里水位暴涨暴落、船互相撞击,比海上更危险)
- 已经在海上,收到远洋海啸预警且有足够时间:
  按海事部门指示驶向远离港湾的深水区,在外海等待,
  预警解除前不要回港
- 不要为了保船而返回港口
```

**被海水卷走**:
```
极度危险!尽全力:

1. 抓住:
   - 漂浮物(木头、门板)
   - 固定物(树、柱子)

2. 保护:
   - 头部(防撞击)
   - 保持口鼻在水面上

3. 等待:
   - 水流减弱
   - 救援到来

4. 注意:
   - 回流危险
   - 漂浮碎片
```

```
补充:
- 不要试图逆着水流游,尽量爬到漂浮物上面,让身体少泡在水里
- 回流(退水)往往和来水一样猛,会把人往海里拖,
  这时更要抱紧固定物或漂浮物
- 被冲到海上后,抱住漂浮物等待救援,
  白天挥动颜色鲜艳的衣物,夜里听到船声就喊
```

### 海啸后

**不要立即返回!**

```
⚠️ 关键:海啸通常不是一波!

- 第一波后会有多波
- 间隔几分钟到几小时
- 后续波可能更大
- 至少等待8-12小时
- 听从官方通知
```

**为什么第一波往往不是最大的**:
- 海啸是一串波,前后波之间间隔常见十几分钟到一小时以上,中间海水会退得很远、海面平静,看起来像结束了
- 最大的一波常常是第二、第三波,甚至几小时后才到;海湾、港口里海水来回震荡,危险时间更长
- 2011年日本海啸,有人在第一波过后回家取东西而遇难

**何时可以返回**:

```
可以返回的条件(全部满足):
✓ 官方正式解除海啸警报
✓ 当地政府允许回到该区域
✓ 道路、桥梁经过检查可以通行

没有任何官方消息时(通信中断):
- 至少等待8-12小时,远洋大海啸可能持续一天以上
- 并且已经连续几个小时看不到海水异常涨落
- 宁可多等,不要"去看一眼"
```

**返回时**:
```
✓ 官方宣布安全
✓ 注意建筑结构
✓ 远离垂落电线
✓ 不要进入受损建筑
✓ 小心污染水源
✓ 检查燃气泄漏
✓ 拍照记录损失(保险)
```

```
补充:
- 积水里可能有断电线、尖锐碎片、被冲开的井盖,
  穿厚底鞋,用棍子探路
- 被海水泡过的房子: 先断电断气,确认结构没问题再进入,
  电器和线路经专业人员检查后才通电
- 小心蛇和其他被冲来的动物躲在废墟里
- 地震引发的海啸,还要注意余震
```

**健康安全**:
```
✓ 煮沸饮用水
✓ 避免接触污水
✓ 清洁伤口
✓ 预防传染病
✓ 心理创伤辅导
```

```
需要就医的情况:
- 在海啸水里泡过、呛过水的人,之后出现咳嗽、发热、呼吸急促、胸痛
  → 吸进去的是混着泥沙、油污、细菌的脏水,可能引起严重肺炎
    (所谓"海啸肺"),症状可能几天后才出现
- 伤口被废墟划伤、刺伤: 尽快用大量清水冲洗,
  伤口发红、肿胀、剧痛、流脓或发热时立即就医;按需要补打破伤风疫苗
- 慢性病患者的药物被冲走: 尽快到救援点或医疗点说明情况
```

伤口处理和破伤风见[外伤处理-破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防);饮用水处理见[气象灾害-洪水后](02-气象灾害.md#洪水后);灾后心理反应见[心理健康](../01-日常疾病和伤害/10-心理健康.md)。

### 海啸预防准备

**沿海居民**:
```
必备知识:
✓ 了解海啸风险
✓ 规划撤离路线(至少2条)
✓ 知道高地/避难所位置
✓ 家庭演练计划
✓ 外地联系人

必备物资:
✓ 应急包
✓ 重要文件防水保存
✓ 应急药物
```

```
具体做法:
- 查清楚自家、单位、孩子学校的海拔,以及是否在当地划定的海啸/风暴潮淹没区
- 实地走一遍撤离路线,记下从家里步行到高地要几分钟;
  夜里也走一遍(停电后路灯不亮)
- 应急包放在门口,能拿起就走;不要为了拿应急包耽误撤离
- 参加社区组织的海啸演练
```

应急包内容见[灾难应对总目录-家庭应急包](README.md#-家庭应急包)。

**游客**:
```
✓ 询问酒店海啸撤离路线
✓ 了解预警系统
✓ 认识撤离标志
✓ 感受到地震立即撤离
✓ 不要低估危险
```

```
补充:
- 入住海边酒店时看一眼: 酒店有几层、是不是钢筋混凝土、离最近的高地有多远
- 在海滩上感到地震,不要回酒店房间拿东西,直接往高处走
- 手机里装上当地的预警应用或开启紧急警报
```

### 特殊提醒

**儿童教育**:
```
教导儿童:
- 地震后立即往高处跑
- 不要等大人
- 跟随人群往高处
- 记住集合地点
```

**夜间海啸**:
```
更危险:
- 难以观察海水变化
- 听到异响立即撤离
- 不要迟疑
```

**老人、孕妇和行动不便的人**:
```
- 走不快的人,首选离家最近的避难楼(垂直疏散),而不是远处的高地
- 提前把轮椅、拐杖、常用药放在出门顺手的地方
- 背不动、推不动时,把人带到身边最近最高的坚固建筑楼上
```

## 风暴潮

### 什么是风暴潮

强烈大气扰动(台风、寒潮等)引起的海面异常升高。

台风或寒潮大风持续把海水往岸边推,加上台风中心气压很低、把海面"吸"高,海面会比正常潮位高出 1 m 到几 m,持续几小时到一两天。和海啸不同,风暴潮**可以提前预报**,有时间准备,所以它造成的伤亡主要是"不当回事、不肯撤"。

**危害**:
- 海水倒灌
- 淹没沿海地区
- 破坏海堤
- 加剧台风/洪水影响

```
风暴潮为什么危险:
- 涨水快: 风暴潮和大浪叠加,海水可能在很短时间内漫过或冲垮海堤
- 范围广: 低洼的沿海平原、河口城市、养殖区大片被淹
- 河水排不出去: 海水顶托,河口城市内涝更严重
- 海水是咸的: 淹过的农田、淡水井要很久才能恢复
```

我国渤海湾、莱州湾、长江口、杭州湾、浙闽沿海、珠江口和雷州半岛、海南沿海都是风暴潮多发区,历史上造成过大量死亡。

### 预警

```
关注:
✓ 台风预警(常伴随风暴潮)
✓ 天文大潮时间(一般在农历初三、十八前后)
✓ 海洋预报
✓ 当地预警信息
```

**我国的风暴潮预警**:
- 自然资源部和沿海各省海洋预报部门发布风暴潮预警,分**红、橙、黄、蓝**四色,红色最严重;同时会发布海浪预警
- 预警根据预计的潮位是否超过当地的"警戒潮位"来划分——超过警戒潮位,意味着海水可能漫过海堤或淹到低地
- 看到预警时,同时留意: 预计高潮的时间、受影响的岸段,以及当地政府的转移通知

| 收到预警 | 该做什么 |
|----------|----------|
| 蓝色、黄色 | 不去海边、滩涂、海堤;渔船回港;养殖户加固设施;低洼地区做好转移准备 |
| 橙色、红色 | 按政府通知转移;危险区内的人在高潮到来**之前**离开;不要留下"看守"房子、鱼塘 |

### 应对措施

**与台风应对类似**:

```
提前准备:
✓ 加固房屋
✓ 准备应急物资
✓ 规划撤离路线

危险区撤离:
✓ 低洼沿海地区
✓ 海堤外
✓ 听从指挥
✓ 往高处转移

期间:
✓ 远离海边
✓ 不要观潮
✓ 不要在海堤上
```

**具体做法**:

```
撤离:
- 在高潮到来前几小时完成转移;高潮时道路可能已被海水淹没
- 去政府指定的避难场所或地势高、结构坚固的亲友家
- 出门前关闭电闸、燃气阀;贵重物品和粮食搬到楼上
- 不要开车穿过被海水淹没的道路,30 cm 左右的流水就能让小汽车漂起来

留在家里时(不在危险区、但可能进水):
- 住在高层、结构坚固时才可留在家中
- 停电断电,准备饮用水和食物
- 水进屋时往楼上转移,不要待在一楼和地下室

期间:
❌ 不要到海堤、码头、礁石上拍照、观潮、钓鱼
   → 大浪越过海堤,会把人直接卷进海里
❌ 不要去滩涂赶海、收网
❌ 台风"减弱"或天转晴后,海面仍可能很高,高潮时段仍要远离
```

台风期间的防护见[气象灾害-台风/飓风](02-气象灾害.md#台风飓风);被水淹时的自救见[气象灾害-洪水时](02-气象灾害.md#洪水时)。

**风暴潮后**:
```
- 等政府通知后再返回
- 被海水淹过的电器、线路经检查后才通电
- 被海水泡过的水井要先抽干、清洗、消毒,检测合格前不要饮用
- 被海水淹过的食物一律丢弃
- 清理淤泥时戴手套、穿胶鞋,伤口不要接触海水和污水
```

### 特殊注意

**天文大潮 + 台风 + 暴雨 = 极度危险!**

```
三碰头时:
- 风暴潮最严重
- 提高警惕
- 提前防范
- 及时撤离
```

每个月农历初一到初三、十五到十八前后是天文大潮,潮位本来就高;如果台风恰好在这几天的高潮时段登陆或靠近,再加上暴雨让河水上涨,三者叠加,水位可能远超历史纪录。预报中出现"天文大潮期""与天文大潮叠加"字样时,要按更高一级的危险来准备。

**沿海养殖户**:
```
✓ 关注预警
✓ 提前转移物资
✓ 固定设施
✓ 生命>财产
```

```
补充:
- 海上的养殖看护房、渔排上的人,必须在预警发布后按要求全部撤离上岸
- 不要在风暴潮期间去加固网箱、抢收
- 渔船按要求回港避风,船上不留人
```

## 离岸流

### 什么是离岸流

离岸流是海浪冲上岸后,海水集中从一条狭窄的"通道"快速流回大海形成的水流,俗称"裂流""回头浪"。它是海滨浴场溺水的主要原因之一。

```
特点:
- 宽度: 一般十几 m 到几十 m,很窄
- 速度: 可达约 2 m/s,比游泳最快的运动员还快
- 方向: 从岸边垂直往外海流,流出碎浪区后逐渐变弱、散开
- 常见于: 沙滩上的沙坝缺口、防波堤和礁石旁边、码头附近
- 退潮时、浪大时更强
- 离岸流不会把人"拉到水底",它只会把人往外海带;
  人是因为拼命逆流游、体力耗尽才溺水的
```

### 怎样识别离岸流

站在高处(沙丘、堤坝上)观察几分钟:

```
可能有离岸流的地方:
- 两边都在起浪、翻白花,中间一段没有浪或浪很小
  (看起来最"平静"的地方反而危险)
- 一条颜色比两边深的水带(水更深)
- 一条浑浊、带沙的水带
- 泡沫、海草、漂浮物持续往外海方向移动
- 水面起伏杂乱、有细碎的波纹
```

不是每次都能看出来。最可靠的办法是**到有救生员的海滨浴场、在救生员看得到的区域游泳**,并留意海滩上的旗帜和告示。各地标识不完全一样,国际上常见的是:

| 旗帜 | 含义 |
|------|------|
| 红黄双色旗 | 救生员看护的游泳区,在两面旗之间游 |
| 黄旗 | 有一定风险,谨慎下水 |
| 红旗 | 危险,禁止游泳 |

### 被离岸流带走时

```
1. 不要慌,不要逆着水流往岸边游
   → 再好的游泳者也游不过离岸流,只会耗尽体力
2. 先浮起来: 仰面漂浮,保存体力,让水流带一会儿
3. 举手挥动、大声呼救
4. 平行于海岸线游出去(横着游),
   脱离这条窄窄的水流(通常游出几十 m 就够)
5. 出了离岸流后,再斜着往岸边游,或借着海浪回到岸边
6. 实在游不动,就一直浮着等待救援;
   离岸流流出碎浪区后会变弱,有时还会把人带回近岸
```

### 看到别人被离岸流带走

```
✓ 立即叫救生员,拨打110或120(海上拨打12395)
✓ 一直盯着落水者的位置,给救援人员指方向
✓ 抛给他能漂浮的东西: 救生圈、冲浪板、泡沫板、充了气的游泳圈
✓ 大声喊话: "别往回游,横着游""浮起来"
❌ 没有受过训练、没有漂浮物,不要下水去救
   → 海滨溺水事件中,下水施救的人常常也一起遇难
```

救上岸后的急救见[急性症状-溺水](../01-日常疾病和伤害/05-急性症状.md#溺水)。

## 海上落水与船只遇险

### 救生衣: 穿着才有用

海上落水死亡的人,很多是带了救生衣但没穿。落水往往是一瞬间的事,来不及再穿。

```
✓ 上了小船、快艇、渔船、皮划艇、桨板,一上船就穿好并扣紧所有扣带
✓ 大型客轮: 登船后看一下救生衣存放位置和集合点,听安全广播
✓ 选择有合格标志、大小合适的救生衣
✓ 检查是否穿对: 扣好后,别人抓住两肩往上提,
  救生衣不能滑到下巴或耳朵以上

儿童:
- 按体重选儿童救生衣,最好带裆带(防止从救生衣里滑出去)和头枕
- 儿童、不会游泳的人用固有浮力(泡沫)式救生衣
- 充气式救生衣要定期检查气瓶,不适合儿童和不会游泳的人
```

### 落水后的第1分钟: 冷水休克

水温低于约 15°C 时(我国北方海域春秋季、南方海域冬季都可能这样),突然落水后的第1分钟最危险——不是冻死,而是**呛水**。

```
冷水刺激皮肤 → 不由自主地大口喘气、呼吸急促 → 如果头在水下,就会吸进大量的水
同时心跳、血压骤升,有心脏病的人可能心律失常

怎么做:
1. 落水瞬间尽量闭嘴,双手捂住口鼻(如果来得及)
2. 头一冒出水面,先不要挣扎、不要急着游
3. 仰面漂浮,双臂双腿张开,尽量让口鼻高出水面
4. 控制呼吸,大约1分钟后急促喘气会慢慢平复
5. 平复以后再决定: 爬上漂浮物、游向近处的船或岸边、还是原地等待救援

穿着救生衣时,冷水休克的风险大大降低——这也是一定要穿救生衣的原因
```

接下来约10分钟和1小时内发生什么,见[涉水、山洪与野外失温-落入冷水](../03-野外生存/08-涉水山洪与野外失温.md#落入冷水)的"1-10-1"原则。

### 等待救援时保持体温

```
穿着救生衣、一个人时: HELP 姿势(减少热量散失)
- 双腿并拢,膝盖蜷到胸前
- 双臂抱在胸前,夹紧腋下
- 头和颈部尽量露出水面、不要泡进水里
→ 保护散热最多的腋下、胸部、腹股沟

几个人时: 抱团姿势
- 面对面围成一圈,胸贴胸,手臂互相搂住
- 把孩子、受伤的人、体弱的人围在中间
- 还能让救援人员更容易发现

没有救生衣时:
- HELP 姿势会让人下沉,改为仰面漂浮,抓住任何漂浮物
- 只在离岸边、船很近且能确定游得到时才游,
  在冷水里游泳会让体温下降得更快

通用:
✓ 不要脱掉衣服和鞋子(衣服里的水层能保温,有些衣服还能帮助漂浮)
✓ 尽量把身体爬到漂浮物上,少泡在水里
✓ 不要喝海水
```

被救上来后按失温处理,冷水中泡过较长时间的人尽量**平着抬**上岸、上船,见[急性症状-失温症](../01-日常疾病和伤害/05-急性症状.md#失温症)。

### 有人从船上落水

```
1. 大喊"有人落水!",告诉船长/驾驶员落水的是哪一侧
2. 安排一个人专门盯住落水者,一直用手指着,不要移开视线
   (海上一转眼就找不到了)
3. 立即抛救生圈或任何漂浮物,最好系着绳子
4. 驾驶员减速并把船转回去;船尾螺旋桨附近不要靠近落水者
5. 拨打12395或用船上的甚高频电台(VHF)16频道呼救,
   报告时间、位置(经纬度或明显的地标)
6. 夜间抛出带灯的救生圈,用手电照住落水者
❌ 不要跳下去救人,除非受过训练、穿着救生衣、系着安全绳
```

### 船只遇险与弃船

```
发现险情时:
1. 所有人立即穿好救生衣
2. 呼救: 拨打12395,或用VHF 16频道呼叫"MAYDAY"(最紧急遇险),
   报出船名、位置、人数、遇到了什么情况
3. 多穿衣服(尤其是保暖的),带上手机(装进防水袋)、哨子、手电、饮用水
4. 听从船长和船员的指挥,不要拥挤到一侧(会导致翻船)

弃船时:
- 只有船确实要沉、起火无法控制时才弃船;
  船还能浮着时,留在船上比在海里安全
- 优先直接登上救生筏,尽量不要先落水
- 必须跳水时:
  * 从尽可能低的位置跳,先看清下方没有人和漂浮物
  * 一手捂住口鼻,另一只手按住救生衣,双腿并拢伸直,
    眼睛看前方(不要低头),脚先入水
- 入水后游离正在下沉的船和起火的油面,然后向救生筏或其他人靠拢

小船翻了:
- 待在翻扣的船边,尽量爬到船底上面
- 翻扣的船比人显眼得多,更容易被找到
- 不要离开船去游向看起来不远的岸边(海上目测距离往往严重偏近)
```

### 等待救援

```
✓ 在一起: 人和人、人和船、人和漂浮物待在一起
✓ 让自己被看见: 挥动颜色鲜艳的衣物;白天用镜子、手机屏幕反光;
  夜里用手电、手机闪光灯;有信号弹时听到或看到船、飞机再放
✓ 吹哨子比喊叫省力,声音传得远
✓ 手机放防水袋里省着用电,有信号时拨打12395或110
❌ 不要喝海水,不要喝尿 —— 只会加速脱水
```

在海上或荒岛长时间等待时的取水、遮阳和求救信号见[荒岛求生-海岛取水](../03-野外生存/01-荒岛求生.md#海岛取水)、[荒岛求生-信号与救援](../03-野外生存/01-荒岛求生.md#信号与救援)。

## 赤潮与有毒海产品

### 什么是赤潮

海水中某些微小藻类在短时间内大量繁殖,使海水变成红色、褐色、绿色或黄色,叫赤潮(有时颜色并不明显)。其中一部分藻类会产生毒素,贝类(牡蛎、扇贝、贻贝、蛤、蚶等)吃了这些藻类后,毒素在体内积累,人吃了这些贝类就会中毒。

```
关键事实:
- 有毒的贝类外观、气味、味道都和正常贝类一样,看不出来
- 贝类毒素耐热,煮、蒸、炒、烤都不能破坏,冷冻、腌制也去不掉
- 赤潮消失后,贝类体内的毒素还可能保留几周甚至更久
- 我国东海、南海沿海春夏季较多,福建、浙江、广东等地都发生过群体中毒
```

### 贝类中毒的类型

| 类型 | 发病时间 | 主要症状 | 危险程度 |
|------|----------|----------|----------|
| 麻痹性贝类中毒 | 吃后几十分钟到几小时 | 嘴唇、舌头、面部发麻刺痛,蔓延到手脚;头晕、走路不稳、感觉"飘";说话、吞咽困难;严重时呼吸肌麻痹 | ☠️☠️☠️ 可在几小时内因呼吸停止死亡 |
| 腹泻性贝类中毒 | 吃后半小时到几小时 | 腹泻、恶心、呕吐、腹痛 | 一般几天内好转,注意补液 |
| 记忆缺失性贝类中毒 | 吃后一天内 | 呕吐腹泻,随后头痛、意识模糊、记忆力丧失,严重时抽搐、昏迷 | ☠️☠️ 老人尤其危险 |
| 神经性贝类中毒 | 吃后几小时内 | 口周和手脚发麻、冷热感觉颠倒、恶心腹泻 | 一般不致命 |

### 吃海鲜后中毒怎么办

```
出现以下情况,立即拨打120或去医院:
- 吃贝类、海鱼后嘴唇、舌头、手脚发麻
- 头晕、站不稳、说话含糊、吞咽困难、呼吸费力
- 同一餐吃了同样东西的人接连出现症状

处理:
1. 立即就医,告诉医生吃了什么海鲜、在哪买的、什么时间吃的
2. 同桌吃过的人即使暂时没症状,也要一起去医院或密切观察
3. 留下剩余的海鲜和包装,交给医生和市场监管部门
4. 不要自行催吐,不要灌偏方
5. 送医途中: 意识不清但有呼吸 → 侧卧位;无反应、无正常呼吸 → 立即CPR

麻痹性贝类中毒没有特效解毒药,但只要及时用呼吸机等支持治疗,
大多数人能在一两天内恢复——所以发麻就要马上去医院,不要等到喘不上气
```

中毒的通用处理原则见[中毒-中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则);一般细菌性食物中毒见[常见疾病-食物中毒](../01-日常疾病和伤害/01-常见疾病.md#食物中毒)。

### 怎样预防

```
✓ 留意当地政府发布的赤潮信息和"贝类禁止采捕、禁止销售"通告,
  通告期间不采、不买、不吃相关海域的贝类
✓ 不在变色、有异味、漂着死鱼的海域赶海、采贝
✓ 从正规市场购买贝类,不买来路不明的
✓ 吃贝类时去掉内脏(消化腺,毒素最集中的部分),少量食用——
  但这只能减少风险,不能消除风险
✓ 赤潮期间不在变色海水里游泳,不吃海边死掉、冲上岸的鱼和贝类
✓ 有些赤潮会让海边空气刺激眼睛和呼吸道,有哮喘的人远离
```

### 其他有毒海产品

| 海产品 | 风险 | 怎样预防 |
|--------|------|----------|
| 河豚 | 河豚毒素,煮熟也不能破坏;吃后很快出现口唇手脚发麻、无力,严重时呼吸麻痹 | 不要自己捕捞、购买、加工野生河豚;只在有资质的正规餐馆食用养殖河豚加工品 |
| 热带珊瑚礁大型鱼(大石斑、苏眉、鳝鱼、梭鱼等) | 雪卡毒素,煮熟也不能破坏;口周发麻、腹泻,特征是冷热感觉颠倒(摸冷水觉得烫),症状可持续数周 | 不吃来源不明的大型珊瑚礁鱼,尤其不吃鱼头、鱼皮、内脏和鱼卵 |
| 不新鲜的金枪鱼、鲭鱼、鲣鱼、秋刀鱼等 | 存放不当产生组胺;吃后很快脸红、头痛、心慌、起疹子,像过敏 | 海鱼买回后冷藏冷冻,不吃不新鲜的;组胺中毒同样煮不掉 |
| 生食海鲜 | 副溶血性弧菌等引起腹痛腹泻;有肝病的人可能发生严重感染 | 海鲜煮熟煮透;生熟分开;肝病、糖尿病、免疫力低的人不要生吃 |

## 海边游玩安全

### 了解潮汐

```
潮汐的基本规律:
- 我国大部分海岸一天有两次涨潮、两次落潮,
  相邻两次高潮相隔约12小时25分钟
- 每天的高潮时间比前一天推迟约50分钟,所以不能凭"昨天这个点"来判断
- 北部湾等少数海岸一天只有一次高潮
- 涨潮时,水位上涨最快的是中间那几个小时
- 潮差(高潮和低潮的水位差)在不同地方从不到 1 m 到好几 m 不等,
  潮差大的平坦滩涂,海水涨上来时可能比人走得还快

出发前:
✓ 查当天的潮汐表(海事、海洋预报部门网站或天气、潮汐类手机应用都能查)
✓ 记下当天的低潮和高潮时间,写在手机备忘录里
✓ 同时看海浪预报和天气预报
```

### 赶海与退潮被困

退潮后的滩涂、礁石、沙洲适合赶海,但每年都有人因为"再挖一会儿"被涨潮困住。

```
赶海的时间安排:
- 跟着退潮往外走,最晚在低潮时间到达时就开始往回走
- 海水开始回涨时,立即回到岸上,不要等水漫到脚边
- 身后的低洼处、潮沟(滩涂上的小水沟)会最先灌满水,
  把人和岸边隔开 —— 往外走时就要记住回程路线,不要走过潮沟太远

其他:
✓ 结伴去,告诉家人去哪片海滩、几点回来
✓ 手机充满电、装防水袋
✓ 穿防滑、防割的鞋,不要光脚(贝壳、碎玻璃、牡蛎壳很锋利)
✓ 雾天、傍晚不去远处的滩涂(容易迷失方向)
✓ 不去没去过、没有人的滩涂和沙洲
✓ 孩子一直在大人伸手可及的范围
```

**已经被潮水困住时**:

```
1. 立即拨打110或12395,说清楚位置(附近的地标、手机定位截图)
2. 往附近最高的地方转移(礁石高处、沙洲最高点、堤坝)
3. 不要试图涉水或游过正在上涨的潮沟 —— 涨潮的水流很急,
   水深比看起来的深,底下是软泥
4. 白天挥动颜色鲜艳的衣物,夜间用手机手电向岸边打信号
5. 陷入软泥时:
   - 不要拼命拔腿(越挣扎陷得越深)
   - 身体往后仰、张开双臂,增大接触面积,
     慢慢地一条腿一条腿地左右晃动、抽出来,然后趴着或仰着往硬地方挪
   - 已经陷到膝盖以上时不要硬拔,保持身体平躺,立即呼救
```

### 礁石和海岸边

```
⚠️ 礁石是海边最容易出事的地方之一

危险:
- 礁石上长着青苔、海藻,湿滑,摔倒容易骨折、头部受伤、滑落海中
- 平静的海面会突然打来一个比平时大得多的浪("疯狗浪"),
  把站在礁石、防波堤上的人卷进海里,浪退回时很难再爬上岸
- 礁石缝隙中水流复杂,落水后很难被救起

怎么做:
✓ 不在浪打得到的礁石、防波堤、消波块(水泥四脚块)上拍照、钓鱼、玩耍
✓ 先站在远处观察至少10-20分钟,看浪最远打到哪里,站在比这更高、更远的地方
✓ 永远不要背对大海
✓ 风浪预警期间、台风前后不去礁石区
✓ 矶钓(礁石钓鱼)时穿救生衣和防滑鞋,结伴,系安全绳
❌ 不要爬消波块: 块与块之间缝隙很深,掉进去几乎无法自己爬出来
```

### 观潮安全

钱塘江、杭州湾等地的涌潮来势猛、速度快,每年都有观潮者被卷走。

```
✓ 只在指定的观潮区观潮,站在护栏以内,听从现场管理人员指挥
✓ 不要下到江滩、丁坝、堤坝的斜坡上
✓ 涌潮过去后,还可能有"回头潮"(潮水撞上堤坝后反卷回来),
  潮头过去后不要马上靠近江边
✓ 看到潮水冲上岸,立即往远离江边的高处跑,不要停下来拍照
```

### 游泳和其他注意事项

```
✓ 在有救生员看护的正规海滨浴场、在规定区域内游泳
✓ 不单独游泳,不在饱餐后、饮酒后、疲劳时下水
✓ 不会游泳的人和儿童全程穿救生衣,大人伸手可及
✓ 充气游泳圈、充气床垫、充气玩具在离岸风下很快会被吹向外海,
  玩具漂走时不要去追
✓ 不要从礁石、码头往下跳水: 水深看不准,头先撞到海底可能造成颈椎骨折
✓ 不要在沙滩上挖很深的沙坑,沙壁会突然塌下来把人埋住(儿童尤其危险),
  挖过的坑离开前填平
✓ 雷雨天立即离开海水和沙滩
✓ 防晒: 海边紫外线强,上午10点到下午4点之间做好遮阳,多喝水
```

```
被海里的东西伤到时:
- 被礁石、贝壳划伤,被海鲜(虾、蟹、鱼刺)扎伤:
  用大量清水冲洗干净;
  伤口在几小时到一两天内出现剧烈疼痛、迅速红肿、起水疱、皮肤变紫,或发热
  → 立即去医院,说明是海水或海产品造成的伤口
  (海水中的创伤弧菌可在一两天内引起危及生命的感染;
   有肝病、糖尿病、免疫力低的人风险最高,这些人有伤口时不要下海)
- 被水母蜇伤、踩到海胆: 见下方链接
- 被海蛇咬伤: 按毒蛇咬伤处理,立即送医
```

水母、海胆等有毒海洋生物见[荒岛求生-危险](../03-野外生存/01-荒岛求生.md#危险);蛇咬伤见[外伤处理-蛇咬伤](../01-日常疾病和伤害/02-外伤处理.md#蛇咬伤);海边雷电见[气象灾害-室外避雷](02-气象灾害.md#室外避雷);中暑见[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑);儿童防溺水见[儿童安全-防溺水](../01-日常疾病和伤害/14-儿童安全.md#防溺水)。

## 📝 总结要点

### 海洋灾害核心原则

**海啸**:
```
1. 感觉地震,立即撤离
2. 海水异常,立即撤离
3. 往高处跑(30 m以上)
4. 往内陆跑(3 km以上)
5. 不要返回(多波海啸)
6. 生命>一切财物
```

```
补充:
7. 不要等警报,自然征兆就是警报
8. 来不及去高地时,就近爬上坚固的高楼(垂直疏散)
9. 第一波往往不是最大的,等官方解除后才返回
```

**风暴潮**:
```
1. 关注预警
2. 低洼区撤离
3. 远离海边
4. 加固防护
```

**离岸流**:
```
1. 在救生员看护的区域游泳
2. 被带走时不要逆流往回游
3. 先浮起来、呼救,再平行于岸边游出去
4. 不会救人就不下水,抛漂浮物、叫救生员
```

**海上落水**:
```
1. 上船就穿救生衣
2. 落水第1分钟: 不挣扎,仰浮,控制呼吸
3. HELP 姿势或抱团保温,不脱衣服
4. 和船、漂浮物、同伴待在一起
5. 呼救电话12395
```

**赤潮与海产品**:
```
1. 贝类毒素煮不熟、看不出
2. 遵守禁采禁售通告
3. 吃海鲜后嘴唇手脚发麻,立即就医
```

**海边游玩**:
```
1. 出发前查潮汐表
2. 低潮时就开始往回走
3. 不上浪打得到的礁石,不背对大海
4. 被困早报警,不要游过潮沟
```

### 记住

```
时间就是生命:
- 海啸逃生时间有限
- 不要犹豫
- 不要收拾东西
- 不要围观
- 立即逃命

准备:
- 沿海居民必须有撤离计划
- 定期演练
- 熟悉路线
- 教育家人
```

### 海啸生存链

```
1. 识别预警(自然/官方)
   ↓
2. 立即决定撤离
   ↓
3. 快速往高处/内陆跑
   ↓
4. 到达安全地点
   ↓
5. 等待多波过去
   ↓
6. 官方通知后才返回
```
