# 消毒剂制备

> **防感染第一防线 - 最实用最重要的末日技能**

## ⚠️ 使用前必读

```
1. 能买到成品(医用酒精、碘伏、84消毒液、漂白水)就用成品;
   本章的自制方法只用于买不到、也没有储备的极端情况
2. 自制酒精只能外用,绝不能喝,也不能兑成酒(可能含甲醇)
3. 不同消毒剂不要混在一起用,尤其是含氯消毒剂不能遇酸、遇酒精(见8.2节)
4. 消毒剂只能减少感染机会,不能治疗感染。伤口红肿热痛加重、
   流脓、发热 → 及时就医,能联系上就拨打120
5. 所有消毒剂都有毒:贴标签、不用饮料瓶装、放在儿童拿不到的地方
```

## ✅ 为什么消毒剂最重要?

**末日情况下,第一死因不是饥饿,而是感染!**

- 小伤口感染 → 败血症 → 死亡
- 饮水不洁 → 霍乱、伤寒 → 死亡
- 手术无消毒 → 感染 → 死亡

**有效消毒可以:**
- 阻断90%的感染途径
- 提高伤口愈合率
- 延长食物保存时间
- 净化饮用水

**成功率高、风险低、立即有用!优先掌握!**

## 一、酒精(乙醇)制备

### 1.1 酒精的重要性

**用途:**
- 皮肤消毒(75%最佳)
- 器械消毒
- 伤口消毒(轻度)
- 溶剂(制药)
- 燃料(酒精灯)

**有效浓度:**
- 75%酒精:最佳杀菌浓度
- 95%酒精:太高,反而效果差(蛋白质凝固阻碍渗透)
- <60%酒精:效果不足

### 1.2 发酵法制取酒精

#### 原理:
```
糖 + 酵母 → 酒精 + 二氧化碳
C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂↑
```

#### 材料:

**糖源(选一种):**
- 粮食(大米、小麦、玉米): 淀粉→糖→酒精
- 水果(葡萄、苹果): 直接含糖
- 蜂蜜: 高糖
- 甘蔗汁、甜菜: 高糖

**酵母:**
- 酒曲(传统)
- 面包酵母
- 野生酵母(水果皮上,葡萄皮最多)

#### 步骤(以大米为例):

**第1步: 糖化(淀粉→糖)**
```
1. 大米2 kg,洗净
2. 蒸煮至熟烂
3. 摊凉至30°C
4. 拌入酒曲100 g(或甜酒曲)
5. 保温发酵24-48小时
6. 出现甜味 → 糖化成功
```

**第2步: 发酵(糖→酒精)**
```
1. 糖化好的饭加水4-6 L
2. 混匀,倒入发酵桶
3. 加盖(不密封,留气孔)
4. 温度保持20-30°C
5. 发酵7-14天
   - 初期: 冒泡旺盛
   - 中期: 逐渐平息
   - 末期: 基本不冒泡
6. 有酒香味 → 发酵完成
```

**产物: 米酒(酒精度5-12%)**

#### 步骤(水果酒-更简单):

```
1. 葡萄/苹果10 kg,洗净晾干
2. 压碎(保留皮,皮上有野生酵母)
3. 加糖2 kg(提高酒精度)
4. 装入容器,70%满(留发酵空间)
5. 封口(不完全密封)
6. 室温发酵10-20天
7. 过滤得果酒(酒精度8-15%)
```

### 1.3 蒸馏提纯

**低度酒(5-15%) → 高度酒(75-95%)**

#### 简易蒸馏装置:

```
[示意图]

   木炭火
      ↓
  ╔═══════╗
  ║ 大锅  ║ ← 米酒/果酒
  ║(蒸馏瓶)║
  ╚═══╦═══╝
      ║
    蒸汽↑
      ║  ╱冷水进
  ╔═══╩═══════╗
  ║  冷凝管    ║ ← 铜管/竹筒盘绕在冷水中
  ╚═════╦═════╝
      水出╲
    液滴↓
  ╔═══════╗
  ║接收瓶 ║ ← 高度酒精
  ╚═══════╝
```

#### 操作步骤:

**1. 装填:**
- 大锅装入米酒/果酒(70%满)

**2. 加热:**
- 小火慢慢加热
- 控制温度78-85°C(酒精沸点78°C)

**3. 蒸馏:**
```
温度控制关键:
- 开始(酒头): 含甲醇、乙醛等,至少丢弃最初的馏出液(每10 L原料约100 mL以上)
  ⚠️ 甲醇剧毒,可致失明、死亡。自制酒精只可外用,绝不可饮用!
- 中段: 纯酒精(收集!)
- 末段: 水蒸出(>85°C,停止收集)

判断:
  - 滴在手上,很快挥发,凉爽感 → 高度酒✓
  - 不易挥发,黏手 → 低度酒或水✗
```

**4. 测浓度:**
```
方法1: 酒精计(理想)
  - 读刻度

方法2: 燃烧法(很粗略,不可靠)
  - 只能大致区分高低浓度,不能用来确认是否达到75%
  - 点燃一小杯酒精
  - 完全烧干无残留 → 约95%以上
  - 有少量残留 → 70-90%
  - 烧一半熄灭 → <60%

方法3: 重量法
  - 纯酒精比重: 0.79 g/ml
  - 水比重: 1.0 g/ml
  - 称量100 mL计算
```

**5. 多次蒸馏:**
- 第一次: 30% → 60%
- 第二次: 60% → 85%
- 第三次: 85% → 约90%

⚠️ 简易蒸馏器的实际上限约90%。酒精与水会形成共沸物,普通蒸馏理论最高也只能到约95.6%。

**产量:**
- 10 L米酒(10%) → 约0.8-0.9 L高度酒精(约90%)
- 损耗约10-20%

### 1.4 酒精使用

**75%酒精配制:**
```
公式: 95%酒精稀释成75%
取95%酒精: 79 mL
加蒸馏水(或凉开水): 21 mL
混匀 = 100 mL 75%酒精

或简化:
约4份酒精 : 1份水
```

配好后先确认浓度:有酒精计就测一次;没有酒精计、只能靠燃烧法或手感估计的,按"浓度不确定"对待,只用于擦拭物品,皮肤和器械优先用煮沸、碘酒等其他办法。

**使用方法:**
- 皮肤消毒: 擦拭2次,间隔1分钟
- 器械消毒: 浸泡30分钟
- 手消毒: 揉搓至干(20秒以上)

**怎样用才有效:**
```
✓ 先清洁,后消毒:手上、物品上有泥、血、油污时,先用肥皂和清水洗净,
  酒精遇到有机物效果明显下降
✓ 用量要够:擦拭时表面要湿透,让它自然晾干,不要马上擦干或吹干
✓ 打针、扎刺前的皮肤:从中心向外画圈擦,范围直径约5 cm,等干了再操作
✓ 剪刀、镊子、针:先刷洗干净,再完全浸没在酒精里30分钟;
  能煮沸的金属器械优先煮沸(见十一节)
✗ 酒精杀不死细菌芽孢(如破伤风梭菌),对诺如病毒等无包膜病毒效果也差;
  沾过泥土的深伤口、腹泻病人的呕吐物和粪便,不能只靠酒精
```

**适用对象一览:**

| 对象 | 能不能用 | 说明 |
|------|----------|------|
| 完整皮肤、手 | ✓ | 主要用途 |
| 伤口周围皮肤 | ✓ | 不要流进伤口 |
| 伤口本身 | ✗ | 疼痛剧烈、损伤组织,用清水冲洗后涂碘伏 |
| 小件器械、体温计 | ✓ | 浸泡或反复擦拭 |
| 桌面、门把手、手机 | ✓ | 擦拭,不要大面积喷洒 |
| 饮水、食物 | ✗ | 不能用来消毒饮水 |
| 呕吐物、粪便 | ✗ | 用含氯消毒剂(见六节) |

**禁忌:**
- ✗ 深度伤口(疼痛、组织损伤)
- ✗ 黏膜(眼睛、口腔内)
- ✗ 大面积烧伤(吸收中毒)
- ✗ 发热时用酒精擦身降温(会经皮肤吸收,婴幼儿尤其危险)
- ✗ 酒精过敏的人(擦后皮肤发红、起疹)

**防火:**
```
- 酒精蒸气比空气重,会沿地面飘到火源处,遇明火、火星即燃
- 用酒精消毒时周围不能有明火、烟头、炉火;手上擦了酒精,等干透再靠近火
- 不要对着空气或在密闭房间大面积喷洒
- 酒精着火时火焰在白天几乎看不见:小火用湿布或锅盖盖灭,
  不要用嘴吹、不要泼水到盛酒精的容器里
```
火灾的处理见[火灾](../02-灾难应对/04-火灾.md)。

## 二、碘酒制备

### 2.1 碘酒的优势

**vs酒精:**
- ✓ 杀菌谱更广
- ✓ 对细菌、病毒、真菌、芽孢都有效
- ✓ 用量少
- ✗ 有刺激性
- ✗ 染色(棕色)

### 2.2 碘的来源

**方法A: 海藻提碘(沿海地区)**

**材料:**
- 海带、紫菜等海藻: 10 kg
- 草木灰: 5 kg

**步骤:**
```
1. 海藻晒干
2. 低温焖烧成灰(火太旺会使碘以紫色蒸气挥发损失)
3. 灰烬加水煮沸
4. 过滤取清液
5. 蒸发浓缩
6. 加稀酸(如醋)调至酸性(灰液呈碱性,碱性条件下碘无法析出)
7. 加入双氧水(H₂O₂)
   反应: 2I⁻ + H₂O₂ + 2H⁺ → I₂ + 2H₂O
8. 析出褐黑色碘沉淀,过滤收集
   (不能用酒精萃取:酒精与水互溶,无法分层)
9. 低温加热升华提纯,碘蒸气遇冷凝结成紫黑色晶体

产量: 10 kg海带 → 3-5 g碘
```

**方法B: 地下卤水(内陆地区)**

- 某些盐湖、盐井含碘
- 提取方法类似海藻法

**方法C: 购买/回收(现实)**

- 药店碘酒
- 碘伏
- 碘盐(含量极低,不实用)

### 2.3 碘酒配制

**标准碘酒(2%碘酒):**

**配方:**
```
碘(I₂): 2 g
碘化钾(KI): 1.5 g
75%酒精: 加至100 mL
```

**步骤:**
```
1. 碘化钾1.5 g溶于5 mL水
2. 加入碘2 g,搅拌溶解
   (碘化钾帮助碘溶解)
3. 加75%酒精至总体积100 mL
4. 充分混匀
5. 深色瓶保存(碘见光分解)
```

**简化版(无碘化钾):**
```
碘2 g + 95%酒精100 mL
  - 溶解度低,部分不溶
  - 效果略差,但能用
```

### 2.4 碘酒使用

**消毒:**
- 涂抹患处
- 等待2-3分钟
- 用75%酒精脱碘(去色)

**碘过敏测试:**
- 小范围涂抹
- 观察15分钟
- 如红肿、瘙痒 → 过敏,不用

**适用对象:**

| 对象 | 能不能用 | 说明 |
|------|----------|------|
| 完整皮肤(打针、切开前) | ✓ | 涂后等2-3分钟,再用75%酒精脱碘 |
| 小擦伤、小切口 | △ | 刺激大、疼痛明显;有碘伏就用碘伏,只能用碘酒时涂伤口周围 |
| 深伤口、大面积伤口、烧伤 | ✗ | 损伤组织,大面积还会吸收过多碘 |
| 黏膜(口腔、眼、会阴) | ✗ | 刺激性强 |
| 器械、物品 | △ | 会染色、腐蚀部分金属,一般用酒精或煮沸代替 |
| 饮水 | ✗ | 本书不推荐用碘酒消毒饮水,改用煮沸或含氯消毒(见6.2节) |

**哪些人不要用或少用:**
```
✗ 对碘过敏的人
✗ 新生儿和早产儿(皮肤吸收碘,可能影响甲状腺)
⚠️ 孕妇、哺乳期妇女、甲状腺疾病患者:只小面积、短期使用
⚠️ 2岁以下幼儿:优先用碘伏
```

**常见错误:**
- ✗ 涂后不脱碘,或用碘酒包扎、湿敷:皮肤会起泡、灼伤
- ✗ 和红药水(汞溴红)同时用:会生成刺激性很强的碘化汞,损伤皮肤
- ✗ 喝碘酒"补碘"或防辐射:会中毒(见[人为灾难](../02-灾难应对/05-人为灾难.md))

**储存和失效:**
- 深色玻璃瓶、拧紧瓶盖,放阴凉处
- 瓶盖没拧紧,酒精挥发后碘浓度变高,刺激性增大;瓶底出现析出的黑色颗粒说明已变浓,不要再直接涂皮肤
- 颜色明显变浅(从深棕变成淡黄)说明碘已损失,杀菌力不足,要重新配制

## 三、碘伏(聚维酮碘)

### 3.1 碘伏vs碘酒

| 特性 | 碘伏 | 碘酒 |
|------|------|------|
| 刺激性 | 小 | 大 |
| 疼痛感 | 无 | 明显 |
| 染色 | 轻 | 重 |
| 稳定性 | 好 | 较差(见光分解) |
| 制备难度 | 复杂 | 简单 |

### 3.2 不建议自制

用洗洁精等表面活性剂溶解碘得到的溶液,不等同于聚维酮碘(碘伏):杀菌效果、刺激性和稳定性都没有经过验证。

**替代方案:**
- 需要碘类消毒剂时,用2%碘酒(见上节)代替
- 末日前储备成品碘伏(避光、密封保存)

### 3.3 成品碘伏的用法

家用碘伏一般含有效碘约0.5%(5 g/L),不同产品浓度不同,**按瓶上说明书使用**。

```
皮肤、伤口:
1. 先用清水把伤口冲洗干净(见外伤处理)
2. 棉签蘸原液,从伤口中心向外画圈涂,涂到伤口外约2-3 cm
3. 不用脱碘,让它自然干;涂一次即可,不必反复涂厚
4. 换药时再涂,不需要每隔几小时涂一次

黏膜(口腔、会阴等):只能用说明书写明可用于黏膜的产品,按说明书稀释
```

| 对象 | 能不能用 | 说明 |
|------|----------|------|
| 伤口、擦伤、动物咬伤 | ✓ | 冲洗后首选 |
| 完整皮肤 | ✓ | 擦2遍,作用2-3分钟 |
| 眼睛 | ✗ | 用清水或生理盐水冲洗 |
| 大面积烧伤 | ✗ | 大面积使用会吸收过多碘,烧伤按外伤处理章处理 |
| 饮水 | ✗ | 不能用碘伏消毒饮水 |

**储存和失效:** 避光、密封、阴凉处保存;开封后尽量在说明书规定的时间内用完。颜色从红棕色变成淡黄或无色,说明有效碘已经分解,不能再用。

**哪些人慎用:** 与碘酒相同(碘过敏、新生儿、孕妇和哺乳期、甲状腺疾病),碘伏刺激小,但同样不要大面积长期使用。

伤口的完整处理步骤见[外伤处理-消毒](../01-日常疾病和伤害/02-外伤处理.md#3-消毒)。

## 四、双氧水(过氧化氢H₂O₂)

### 4.1 双氧水的用途

**优点:**
- 杀菌广谱
- 分解成水和氧(无残留毒性)
- 清洁伤口(冒泡带出脏物)

**缺点:**
- 不稳定,易分解
- 对组织有轻微损伤

### 4.2 双氧水制备(难度高)

**⚠️ 警告: 制备危险,仅作了解!**

**方法A: 电解法**
```
电解稀硫酸:
  - 阳极: 生成过硫酸
  - 水解: 得过氧化氢
  - 蒸馏纯化

危险: 需要电力、硫酸,爆炸风险
```

**方法B: 过氧化钡法**
```
BaO₂ + H₂SO₄ → H₂O₂ + BaSO₄↓
  - 过氧化钡加稀硫酸
  - 生成双氧水和硫酸钡沉淀
  - 过滤分离

危险: 钡化合物剧毒!
```

**结论: 末日情况下,双氧水极难制备。优先使用酒精、碘酒!**

### 4.3 双氧水使用

**医用浓度: 3%**

**使用:**
- 清洗污染伤口
- 冒泡带出脏物和坏死组织
- 冲洗后用生理盐水再次冲洗
- 不用于深度伤口(气泡阻碍愈合)

**使用原则:**
```
✓ 只在伤口很脏(泥土、血痂、异物多)时用一次,倒上后冒泡约1分钟,
  再用清水或生理盐水冲净
✗ 不要每天用来"消毒":它同样会杀死新生组织,让伤口长得更慢
✗ 不用于深而窄的刺伤、腔隙内(气体进入组织有危险)、眼睛、耳道内(鼓膜穿孔时)
✗ 不能用工业双氧水(常见为30%左右)直接接触皮肤:会立即发白、灼伤;
  只用标明"3%医用"的产品
```

**储存和失效:**
- 原装避光瓶,拧紧,阴凉处;开封后分解加快
- 瓶子鼓胀是分解产生的氧气,开盖时瓶口朝外
- 判断是否失效:倒一点在伤口血迹或切开的生土豆上,**几乎不冒泡**说明已经失效

**误入眼睛:** 立即用大量清水冲洗15分钟以上,然后就医。

## 五、高锰酸钾溶液

### 5.1 高锰酸钾的用途

**特点:**
- 强氧化剂
- 杀菌、消毒、除臭
- 深紫色,易识别

### 5.2 高锰酸钾来源

**工业级高锰酸钾:**
- 化工商店可能有售
- 深紫色晶体

**末日情况下难以自制,但可大量储备(稳定)**

### 5.3 高锰酸钾溶液配制

**不同用途不同浓度:**

| 用途 | 浓度 | 颜色 | 配法 |
|------|------|------|------|
| 伤口冲洗、湿敷、坐浴 | 0.02%(1:5000) | 淡紫红,透明,隔着水能看清杯底 | 0.2 g+1 L水 |
| 完整皮肤 | 0.05% | 紫红 | 0.5 g+1 L水 |
| 水果消毒 | 0.02% | 淡紫红 | 0.2 g+1 L水 |
| 饮水消毒 | 不推荐 | — | 用煮沸或含氯消毒(见6.2节) |

没有天平时按颜色判断:宁可淡,不要深。溶液呈深紫色、看不透,说明太浓,会灼伤皮肤和伤口。

**使用:**
- 浸泡10-15分钟
- 用清水冲洗

**使用要点:**
```
✓ 先把晶体在少量水里完全溶解,再加水到需要的量;
  未溶解的晶体粘在皮肤上会造成褐色的腐蚀性灼伤
✓ 现配现用:溶液由紫红变成棕褐色,说明已经失效
✓ 皮肤、指甲、衣物会被染成棕色,几天后自行褪去,不是灼伤
✗ 不要用于眼睛、口腔内
✗ 不能长期大量使用于大面积伤口
```

**禁忌:**
- ✗ 勿与甘油、酒精等还原性物质混合(爆炸!)
- ✗ 浓度过高伤皮肤
- ✗ 不能内服:误服晶体或浓溶液会腐蚀口腔、食道和胃,立即按[中毒](../01-日常疾病和伤害/12-中毒.md#误服清洁剂消毒液)处理并拨打120

## 六、漂白粉(含氯消毒剂)

### 6.1 漂白粉的用途

**优点:**
- 便宜、高效
- 适合大面积消毒
- 饮水消毒

**缺点:**
- 刺激性强
- 腐蚀性
- 不稳定(受潮失效)

### 6.2 漂白粉使用

**配制消毒液:**
```
漂白粉10 g + 水1 L = 1%消毒液

用途:
  - 地面、墙壁消毒
  - 厕所消毒
  - 疫区消毒
```

漂白粉含有效氯约25-30%(漂白精约60-70%,先看包装),所以上面的1%漂白粉液含有效氯约2500-3000 mg/L,浓度较高,只用于厕所、疫区和明显污染的地方。日常擦拭按下表再稀释,浓度与[84消毒液](../01-日常疾病和伤害/15-传染病家庭防控.md#84消毒液含氯消毒剂)的用法一致:

| 用途 | 目标有效氯 | 1%漂白粉液 : 水 | 作用时间 |
|------|-----------|-----------------|----------|
| 日常物体表面、餐具、衣物 | 约500 mg/L | 1 : 4 | 30分钟后清水冲净 |
| 病人用过的物品、马桶、污染地面 | 约1000 mg/L | 1 : 2 | 30分钟 |
| 厕所、疫区、粪坑周围 | 约2500 mg/L | 不稀释 | 30分钟以上 |

配制要点:漂白粉加少量水先调成糊,再加足水搅匀,静置后取上面的澄清液用(底部的石灰渣会堵塞喷壶、在物品上留白斑)。

**饮水消毒:**
```
1. 每升水加0.3-0.5 mL漂白粉1%溶液
2. 搅拌
3. 静置30分钟
4. 有氯味即可饮用(余氯保护)
```

```
- 浑水先静置、过滤,取上清再消毒;实在只能用浑水时,加氯量加倍
- 30分钟后闻不到一点氯味,说明氯已经被水里的脏物消耗,再加一次、再等30分钟
- 氯味很冲、难以入口,说明加多了,敞口放几小时或与未加氯的开水兑和后再喝
- 含氯消毒对隐孢子虫等少数寄生虫无效,婴儿冲奶、病人饮用的水最好煮沸
```
用家用漂白水(有效氯约5%)时:**每升清水2滴、浑水4滴,摇匀等30分钟**;井水、蓄水池和大量储水的加氯量见[水源工程与供水-消毒](../07-日常生活技能/10-水源工程与供水.md#消毒)。

### 6.3 84消毒液和家用漂白水

84消毒液和家用漂白水的有效成分都是次氯酸钠,常见有效氯约5%(不同品牌不同,看标签)。它们是成品,储备时比漂白粉更方便。

- **配制比例**: 日常1:100,有污染1:50,呕吐物粪便约1:10到1:5,详见[传染病家庭防控-家用消毒液的配制](../01-日常疾病和伤害/15-传染病家庭防控.md#家用消毒液的配制)
- **用凉水配,现配现用**,稀释液当天用完
- **作用时间**: 擦拭或浸泡后约30分钟,再用清水擦净或冲净
- **饮水**: 只用不含香精、不含洗涤剂的原味产品;带香味、"厨房去油"型的不能用于饮水

### 6.4 含氯消毒剂的适用对象

| 对象 | 能不能用 | 说明 |
|------|----------|------|
| 物体表面、地面、马桶 | ✓ | 主要用途 |
| 餐具、白色衣物 | ✓ | 500 mg/L浸泡30分钟,清水冲净 |
| 深色、羊毛、丝绸衣物 | ✗ | 会褪色、损坏 |
| 金属器械 | ✗ | 腐蚀生锈,用酒精或煮沸 |
| 呕吐物、粪便 | ✓ | 高浓度覆盖30分钟 |
| 饮水 | ✓ | 只用很小剂量(见6.2节) |
| 皮肤、伤口、黏膜 | ✗ | 刺激、灼伤;手上沾到用清水冲净 |

**储存和失效:**
```
- 漂白粉:密封、干燥、避光、阴凉;受潮会结块、氯味变淡,
  有效氯逐渐下降,开封后尽量在几个月内用完
- 84消毒液、漂白水:原装瓶避光、拧紧;一般保质期约1年,
  夏季高温存放会更快失效;过期或闻不到氯味的不要用于饮水
- 都要远离酸性物品(醋、洁厕灵)和易燃物,不和食物放在同一个柜子
```

## 七、生理盐水

### 7.1 用途

**不是消毒剂,但极重要:**
- 冲洗伤口(等渗,不损伤组织)
- 眼部冲洗
- 滴鼻、冲洗鼻腔

⚠️ **自制盐水绝不能静脉输注或注射**:不是无菌、没有热原检测,输进血管可能引起高热、休克、败血症。静脉补液只能由医务人员用合格的成品输液进行。

⚠️ **腹泻、呕吐补液不要喝生理盐水**:它不含糖和钾,补液效果不如口服补液盐,喝多了还会加重口渴。用口服补液盐(ORS),配法见[常见疾病-补液](../01-日常疾病和伤害/01-常见疾病.md#1-补液最重要)。

### 7.2 配制

**标准生理盐水(0.9%):**
```
食盐: 9 g(约2茶匙)
蒸馏水或凉开水: 1000 mL
混匀
```

**使用前煮沸消毒!**

```
- 先把水烧开,加盐溶解后再煮沸几分钟,盖上盖子放凉到接近体温再用
- 装在煮过的带盖容器里;放了超过24小时就倒掉重配
- 盐要用干净的食盐,碘盐、无碘盐都可以;不要用粗盐、腌菜盐(杂质多)
- 冲洗眼睛、伤口时,水温接近体温最舒适;太烫、太冷都不要用
- 盐不能多放:太咸会刺痛伤口、损伤组织,不能"越咸越消毒"
```

## 八、消毒剂对比

| 消毒剂 | 杀菌效果 | 刺激性 | 制备难度 | 稳定性 | 推荐度 |
|--------|----------|--------|----------|--------|--------|
| 75%酒精 | ★★★★ | ★ | ★★ | ★★★ | ★★★★★ |
| 2%碘酒 | ★★★★★ | ★★★ | ★★★ | ★★ | ★★★★ |
| 碘伏 | ★★★★★ | ★ | ★(买) | ★★★ | ★★★★ |
| 3%双氧水 | ★★★ | ★★ | ★★★★★ | ★ | ★★ |
| 高锰酸钾 | ★★★★ | ★★ | ★(买) | ★★★★ | ★★★ |
| 漂白粉 | ★★★★ | ★★★★ | ★(买) | ★★ | ★★★ |

**推荐组合:**
1. **75%酒精** - 首选,必备!
2. **碘酒** - 强力消毒
3. **生理盐水** - 冲洗用

### 8.1 按对象选用消毒方法

| 对象 | 首选 | 可以用 | 不要用 |
|------|------|--------|--------|
| 手 | 肥皂流水洗20秒以上 | 75%酒精揉搓至干 | 含氯消毒液 |
| 伤口 | 清水或生理盐水冲洗,再涂碘伏 | 很脏时3%双氧水一次;0.02%高锰酸钾 | 酒精、碘酒涂伤口内,含氯消毒液 |
| 完整皮肤(打针、切开前) | 碘伏或碘酒+酒精脱碘 | 75%酒精 | 含氯消毒液 |
| 金属器械 | 煮沸15分钟 | 75%酒精浸泡30分钟 | 含氯消毒液(腐蚀) |
| 餐具、毛巾 | 煮沸15分钟 | 含氯500 mg/L浸泡30分钟 | — |
| 桌面、门把手 | 含氯500 mg/L擦拭 | 75%酒精擦拭(小面积) | — |
| 呕吐物、粪便 | 含氯5000-10000 mg/L覆盖30分钟 | 生石灰覆盖 | 酒精 |
| 饮水 | 煮沸 | 含氯(2滴/4滴) | 酒精、碘伏、高锰酸钾 |

### 8.2 不能混用的组合

```
❌ 84消毒液/漂白水/漂白粉 + 洁厕灵、醋等酸性清洁剂 → 释放氯气,可致命
❌ 84消毒液 + 含氨清洁剂(部分玻璃清洁剂)、尿液大量积存处 → 产生有毒的氯胺
❌ 84消毒液 + 酒精 → 产生氯仿等有害物质,两者都失效
❌ 84消毒液 + 双氧水 → 相互分解,都失去消毒作用
❌ 84消毒液 + 洗衣粉、洗洁精 → 多数会降低消毒效果
❌ 高锰酸钾 + 甘油、酒精、糖等 → 可能起火、爆炸
❌ 碘酒 + 红药水(汞溴红) → 生成碘化汞,灼伤皮肤
❌ 碘伏 + 双氧水同时涂 → 相互消耗,效果下降(双氧水冲洗后先用清水冲净)

原则: 一次只用一种;换另一种之前,先用清水冲洗或擦净;
     不往同一个桶、同一块抹布里混倒
```

不小心混用、闻到刺鼻气味、咳嗽胸闷时,立即离开、开窗,见[中毒-清洁剂中毒](../01-日常疾病和伤害/12-中毒.md#清洁剂中毒)。

## 九、储备建议

### 9.1 消毒剂储备清单

**最小储备(4人家庭,3个月):**
- [ ] 95%酒精: 5 L(可稀释成6.7 L75%)
- [ ] 碘: 20 g(制2 L碘酒)
- [ ] 高锰酸钾: 500 g(制5000 L消毒液)
- [ ] 漂白粉: 5 kg
- [ ] 食盐: 10 kg(生理盐水)

**理想储备(1年):**
- [ ] 95%酒精: 20 L
- [ ] 碘: 100 g
- [ ] 高锰酸钾: 2 kg
- [ ] 漂白粉: 20 kg

### 9.2 储存要点

**酒精:**
- 密封(挥发!)
- 远离火源
- 阴凉处

**碘:**
- 深色瓶(避光)
- 密封(升华)
- 干燥

**高锰酸钾:**
- 干燥(受潮分解)
- 避光
- 远离有机物(防爆炸)

**共同要求:** 每瓶都贴标签,写名称、浓度和配制日期;不用饮料瓶、水杯装;锁在或放在儿童拿不到的高处;不和食物、药品放在一起。

### 9.3 有效期和失效判断

| 消毒剂 | 密封原装 | 开封或配好后 | 失效迹象 |
|--------|----------|--------------|----------|
| 95%/75%酒精 | 约2年 | 拧紧盖,浓度会因挥发下降;泡棉球的酒精缸每周更换 | 气味明显变淡、擦在手上不凉 |
| 2%碘酒 | 约2年 | 深色瓶拧紧,数月内用完 | 颜色变浅;或瓶底析出黑色颗粒(变浓) |
| 碘伏 | 按包装 | 按说明书 | 由红棕色变淡黄或无色 |
| 3%双氧水 | 按包装,通常1-2年 | 开封后分解加快 | 遇血迹、生土豆几乎不冒泡 |
| 高锰酸钾晶体 | 干燥避光可存多年 | 溶液现配现用 | 溶液变成棕褐色 |
| 漂白粉 | 约1年 | 稀释液当天用完 | 结块、氯味变淡 |
| 84消毒液、漂白水 | 约1年 | 稀释液当天用完 | 闻不到氯味 |
| 自制生理盐水 | — | 24小时内用完 | 浑浊、有沉淀或异味 |

酒精、碘酒的保存期与[基础制药知识-药物保存](./00-基础制药知识.md#五药物保存)一致。

### 9.4 毒性、误服和溅入眼睛

所有消毒剂都不能入口。以下情况先按下表初步处理,同时拨打120或尽快就医,带上瓶子或标签:

| 情况 | 立即做 | 不要做 |
|------|--------|--------|
| 误服84消毒液、漂白粉、高锰酸钾、双氧水 | 清水漱口吐掉,拨打120 | 不要催吐;不要喝醋、苏打水"中和" |
| 误服碘酒、碘伏 | 漱口,拨打120 | 不要催吐 |
| 误服酒精(尤其自制酒精) | 按酒精中毒处理,拨打120;可能含甲醇,即使当时没事也要就医 | 不要让人独自睡下 |
| 溅入眼睛 | 立即用大量清水冲洗15分钟以上,边冲边眨眼,然后就医 | 不要揉眼 |
| 溅到皮肤 | 脱掉沾湿的衣物,清水冲洗 | — |
| 吸入氯气(混用后) | 离开现场到通风处 | 咳嗽、胸闷、气短时不要以为"缓一缓就好" |

```
儿童误服的危险信号(立即送医):
- 流口水、吞咽困难、哭闹拒食(口腔食道可能被腐蚀)
- 呕吐、呕血、腹痛
- 呼吸急促、咳嗽不止
- 嗜睡、叫不醒
```

详细处理见[中毒-误服清洁剂、消毒液](../01-日常疾病和伤害/12-中毒.md#误服清洁剂消毒液)、[中毒-酒精中毒](../01-日常疾病和伤害/12-中毒.md#酒精中毒)和[中毒-儿童误服](../01-日常疾病和伤害/12-中毒.md#儿童误服)。

## 十、常见问题

### Q1: 白酒可以消毒吗?

**A: 视度数而定**
- 酒精度65%vol以上的白酒: 勉强可以应急
- 酒精度56%vol的白酒: 效果很差
- 低于50%vol: 基本无效

**最好重新蒸馏提纯到75%!**

### Q2: 没有酒曲怎么办?

**A: 野生发酵**
- 葡萄皮表面有天然酵母
- 直接压碎发酵即可
- 或从上一批酒糟中提取酵母

### Q3: 蒸馏装置里的管子用什么材料?

**A: 优先级排序**
1. 铜管(最好,导热好,无毒)
2. 不锈钢管
3. 竹筒(凿通竹节)
4. 陶管
5. ✗ 塑料管(有毒物溶出!)
6. ✗ 铅管(剧毒!)

### Q4: 酒精度数怎么看?

**A: 简易判断**
- 点燃,蓝色火焰持续燃烧 → 高度(>60%)
- 火焰跳跃,很快熄灭 → 低度(<40%)
- 滴在手上,快速挥发凉爽 → 高度
- 黏手 → 低度

## 十一、应急替代方案

**完全无消毒剂情况下:**

### 物理消毒:

**煮沸:**
- 器械: 煮沸15分钟
- 纱布: 煮沸30分钟
- 杀灭大部分病原体

**干烤:**
- 160°C,2小时
- 金属、玻璃器具

**日晒:**
- 紫外线杀菌
- 晒6-8小时
- 效果较弱

### 天然消毒:

**盐水(高浓度):**
- 20%盐水有抑菌作用
- 不要用来冲洗伤口:太咸会刺痛、损伤组织;冲洗伤口用干净的清水或0.9%生理盐水
- 可用于浸泡抹布、腌制食物防腐

**醋:**
- 稀释醋(5%)
- 有一定抑菌作用
- 不能替代正规消毒剂

**茶水:**
- 浓茶水
- 茶多酚有抑菌作用
- 效果很弱

**大蒜汁:**
- 压碎大蒜取汁
- ✗ 不建议涂抹伤口:刺激性强,敷在皮肤上较久会造成化学性灼伤、起水疱
- 有刺激性

**蜂蜜:**
- 涂抹伤口
- 抗菌、促愈合
- 不能用于深度伤口
- 只用于已经冲洗干净的浅表伤口:薄涂一层,盖干净纱布,每天换药时用清水冲掉旧蜂蜜再涂
- 伤口发红范围扩大、流脓、发热 → 停用,就医

```
判断标准:
以上天然方法都只能"聊胜于无",不能替代冲洗和正规消毒剂。
伤口处理最重要的始终是大量干净的水冲洗;
```
