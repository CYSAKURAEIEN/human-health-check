## 🚨 严重警告

**本章节内容极度危险!**

**风险清单:**
- ☠️ 过敏反应: 青霉素过敏可致死(过敏性休克)
- ☠️ 无法保证纯度: 杂质导致严重副作用
- ☠️ 剂量无法精确: 过量中毒,不足无效
- ☠️ 无菌条件极难达到: 污染导致感染加重
- ☠️ 耐药性: 滥用导致细菌耐药
- ☠️ 二重感染: 杀灭正常菌群,致病菌趁虚而入

**死亡风险: 真实且极高!**

**使用前提:**
- ✓ 细菌感染确诊(不是病毒!)
- ✓ 生命垂危,别无选择
- ✓ 具备医学知识
- ✓ 无青霉素过敏史
- ✓ 接受所有风险

**⚠️ 在有任何其他选择的情况下,绝不使用自制抗生素!**

## 一、青霉素: 为什么本手册不提供自制方法

### 1.1 青霉素简史

**发现:** 1928年,弗莱明发现青霉菌能抑制细菌
**意义:** 拯救了数亿生命
**问题:** 从发现到能用于治病,用了十几年;工业生产依赖特定高产菌株和专业发酵、提纯设备

### 1.2 自制青霉素不可行

- 野外采集的青霉菌大多不产或只产极少量青霉素,外观无法分辨
- 青霉素遇热、遇酸都会迅速分解,没有专业设备无法提纯
- 粗提物剂量未知、无法除菌,注射可致败血症,口服大多被胃酸破坏
- 没有可靠的野外自制成功案例

**结论: 末日前储备成品抗生素(见第六节),不要尝试自制。**
发霉的面包、水果同样不能用于治疗(见Q2)。

### 1.3 青霉素过敏抢救(使用储备青霉素时)

**症状:**
- 皮疹、瘙痒
- 胸闷、气短
- 血压下降
- 意识丧失

**抢救(争分夺秒!):**
```
1. 立即停药!

2. 肾上腺素:
   - 1:1000(1mg/ml)肾上腺素
   - 成人: 0.3-0.5ml(0.3-0.5mg),单次不超过0.5mg
   - 儿童: 0.01ml/kg(0.01mg/kg),单次不超过0.3mg
   - 肌肉注射(大腿外侧)
   - 无改善可重复,间隔5-15分钟

3. 体位:
   - 平卧
   - 抬高双腿

4. 保持气道通畅

5. 如呼吸心跳停止 → CPR

⚠️ 无肾上腺素 = 几乎必死!
   必须提前准备!
```

## 二、磺胺类药物

### 2.1 简介

**磺胺药:**
- 最早的人工合成抗菌药
- 二战期间广泛使用
- 现代已较少用(副作用大,有更好的药)

**优点:**
- 化学合成(不依赖发酵)
- 广谱抗菌

**缺点:**
- 副作用大(肾损害、血液系统)
- 容易耐药

### 2.2 合成(几乎不可能)

**⚠️ 需要专业化学实验室!**

**原料:**
- 苯胺
- 氯磺酸
- 氨水

**步骤:**
- 需要多步有机合成(包括氨基保护、氯磺化、氨解、脱保护等),每一步都需要专业设备和试剂控制,此处不展开

**现实:**
- 原料难获得
- 反应危险(强酸、有毒气体)
- 纯化困难
- **末日情况下几乎不可能制备!**

### 2.3 替代: 回收药品

**现实方案:**
- 末日前储备成品磺胺药
- 搜索废弃药房、医院
- 检查有效期
- 妥善保存

## 三、天然抗菌物质

### 3.1 大蒜素

**优点:**
- 天然、安全
- 广谱抗菌、抗病毒
- 容易制备

**制备:**

```
1. 新鲜大蒜: 500克
2. 去皮、洗净
3. 捣烂成泥
4. 加水500ml
5. 浸泡2小时
6. 过滤取汁

或:
1. 大蒜切片晒干
2. 研粉
3. 75%酒精浸泡7天
4. 过滤得大蒜酊
```

**使用:**
- 外用: 稀释2-5倍,清洗伤口
- 内服: 蒜汁10-20ml,一日3次
- 生吃: 3-5瓣/天

**适应症:**
- 轻度感染
- 肠道感染
- 呼吸道感染

**效果:** 弱于抗生素,但安全!

### 3.2 蜂胶

**成分:** 多种抗菌物质

**制备:**
```
1. 蜂胶: 100克(从蜂箱刮取)
2. 冷冻后粉碎
3. 加95%酒精500ml
4. 密封浸泡7天,每天摇晃
5. 过滤得蜂胶酊
```

**使用:**
- 外用: 涂抹感染创面
- 内服: 10-20滴,一日3次(稀释后)

### 3.3 金银花、连翘等(详见中药制剂章节)

**配方: 五味消毒饮**
- 金银花、野菊花、蒲公英、紫花地丁、紫背天葵
- 煎汤服用
- 清热解毒,治疗感染

**效果:**
- 对早期感染有效
- 安全性高
- **首选!**

### 3.4 茶树油(如有)

**来源:** 茶树叶蒸馏

**用途:**
- 外用抗菌
- 治疗皮肤感染、真菌感染

## 四、抗生素使用原则

### 4.1 何时使用

**明确细菌感染:**
- 伤口化脓
- 高热不退(>3天)
- 白细胞升高(如能检测)
- 局部红肿热痛

**不要用于:**
- ✗ 病毒感染(感冒、流感)
- ✗ 预防性使用(浪费且致耐药)
- ✗ 发热原因不明

### 4.2 用药原则

**1. 能口服不注射**
- 注射风险大

**2. 能窄谱不广谱**
- 减少耐药
- 保护正常菌群

**3. 足量足疗程**
- 不要一有好转就停药
- 至少用药5-7天
- 症状消失后再用2-3天

**4. 联合用药(重症)**
- 两种抗生素联用
- 增强效果
- 延缓耐药

### 4.3 副作用监测

**常见副作用:**

**消化道:**
- 恶心、呕吐、腹泻
- 停药或减量

**过敏:**
- 皮疹→停药
- 呼吸困难→抢救!

**肝肾损害:**
- 尿少、水肿
- 黄疸
- 立即停药

**二重感染:**
- 用药后出现新感染(如真菌)
- 停用抗生素
- 治疗新感染

## 五、感染的预防

**预防远胜于治疗!**

### 5.1 伤口处理

**正确步骤:**
```
1. 止血
2. 清洗:
   - 大量清水或生理盐水冲洗
   - 去除异物、泥土
   - 冲洗5-10分钟
3. 消毒:
   - 75%酒精或碘酒
   - 从里向外擦拭
4. 包扎:
   - 清洁纱布
   - 不要包太紧
5. 观察:
   - 每日换药
   - 注意红肿、化脓
```

**预防胜于抢救!**

### 5.2 个人卫生

- 勤洗手(最重要!)
- 饮水煮沸
- 食物煮熟
- 环境清洁
- 人群隔离(传染病)

### 5.3 营养与免疫

**增强抵抗力:**
- 充足睡眠
- 营养均衡(蛋白质、维生素)
- 适度运动
- 阳光照射

**免疫力 = 最好的抗生素!**

## 六、储备建议

### 6.1 商业抗生素储备(末日前)

**推荐储备(仅供参考,遵医嘱):**

**广谱类:**
- 阿莫西林: 首选,安全性好
- 头孢类: 广谱,效果好
- 左氧氟沙星: 广谱,但儿童禁用

**外用:**
- 红霉素软膏
- 莫匹罗星软膏

**储存:**
- 密封、避光、干燥
- 温度<25°C
- 定期检查有效期
- 轮换使用

### 6.2 天然抗菌物储备

**更推荐!**
- 大蒜: 易种植,长期保存
- 蜂蜜、蜂胶: 抗菌、储存久
- 中药材: 金银花、连翘、板蓝根等
- 茶树油: 外用抗菌

**优点:**
- 保质期长
- 副作用小
- 可持续获得

## 七、现实建议

### 7.1 不要幻想自制抗生素

**残酷现实:**
- 野外青霉菌粗提取: 没有可靠的成功案例
- 纯度无法保证: 可能致命
- 剂量无法控制: 无效或中毒
- 过敏风险: 无法预测
- 无菌条件: 几乎不可能

**结论: 自制抗生素 = 自杀!**

### 7.2 推荐策略

**优先级排序:**

**Tier 1: 预防**
- 清洁、消毒、卫生
- 减少感染机会

**Tier 2: 天然抗菌**
- 大蒜、蜂蜜、中药
- 安全、可持续

**Tier 3: 储备商业抗生素**
- 末日前大量储备
- 妥善保存
- 谨慎使用

**不推荐: 自制抗生素**
- 没有可靠方法,本手册不提供
- 风险远大于可能的收益

## 八、常见问题

### Q1: 青霉素过期还能用吗?

**A: 非常危险!**
- 青霉素分解产物致敏性更强
- 过敏风险大增
- 绝对不用过期青霉素!

### Q2: 发霉的面包可以治疗感染吗?

**A: 民间传说,极度危险!**
- 面包上的霉菌种类复杂
- 可能是有毒霉菌(如黄曲霉→剧毒!)
- 即使是青霉菌,含量极低
- **绝不可用!**

### Q3: 抗生素是万能药吗?

**A: 不是!**
- 只对细菌感染有效
- 对病毒、真菌、寄生虫无效
- 滥用导致耐药
- 破坏正常菌群

### Q4: 如何判断是细菌还是病毒感染?

**A: 粗略判断**

**细菌:**
- 局部化脓
- 高热持续
- 白细胞↑(如能化验)
- 抗生素有效

**病毒:**
- 全身症状(乏力、肌肉酸痛)
- 发热3天内多自愈
- 白细胞正常或↓
- 抗生素无效

**不确定 → 观察,支持治疗,不滥用抗生素**
