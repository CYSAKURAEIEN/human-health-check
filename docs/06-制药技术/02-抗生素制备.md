# 抗生素制备

> **⚠️ 极高风险 - 仅限绝境使用**

## 🚨 严重警告

**本章节内容极度危险!**

**风险清单:**
- ☠️ 过敏反应: 青霉素过敏可致死(过敏性休克)
- ☠️ 无法保证纯度: 杂质导致严重副作用
- ☠️ 剂量无法精确: 过量中毒,不足无效
- ☠️ 无菌条件极难达到: 污染导致感染加重
- ☠️ 耐药性: 滥用导致细菌耐药
- ☠️ 二重感染: 杀灭正常菌群,致病菌趁虚而入

**死亡风险: 真实且极高!**

**使用前提:**
- ✓ 细菌感染确诊(不是病毒!)
- ✓ 生命垂危,别无选择
- ✓ 具备医学知识
- ✓ 无青霉素过敏史
- ✓ 接受所有风险

**⚠️ 在有任何其他选择的情况下,绝不使用自制抗生素!**

## 一、青霉素: 为什么本手册不提供自制方法

### 1.1 青霉素简史

**发现:** 1928年,弗莱明发现青霉菌能抑制细菌
**意义:** 拯救了数亿生命
**问题:** 从发现到能用于治病,用了十几年;工业生产依赖特定高产菌株和专业发酵、提纯设备

### 1.2 自制青霉素不可行

- 野外采集的青霉菌大多不产或只产极少量青霉素,外观无法分辨
- 青霉素遇热、遇酸都会迅速分解,没有专业设备无法提纯
- 粗提物剂量未知、无法除菌,注射可致败血症,口服大多被胃酸破坏
- 没有可靠的野外自制成功案例

**结论: 末日前储备成品抗生素(见第六节),不要尝试自制。**
发霉的面包、水果同样不能用于治疗(见Q2)。

### 1.3 青霉素过敏抢救(使用储备青霉素时)

**症状:**
- 皮疹、瘙痒
- 胸闷、气短
- 血压下降
- 意识丧失

**抢救(争分夺秒!):**
```
1. 立即停药!

2. 肾上腺素:
   - 1:1000(1 mg/ml)肾上腺素
   - 成人: 0.3-0.5 mL(0.3-0.5 mg),单次不超过0.5 mg
   - 儿童: 0.01 mL/kg(0.01 mg/kg),单次不超过0.3 mg
   - 肌肉注射(大腿外侧)
   - 无改善可重复,间隔5-15分钟

3. 体位:
   - 平卧
   - 抬高双腿

4. 保持气道通畅

5. 如呼吸心跳停止 → CPR

⚠️ 无肾上腺素 = 几乎必死!
   必须提前准备!
```

**抢救时还要注意:**
```
- 同时拨打120,不要等"看看会不会好转"
- 呼吸困难明显、平躺更憋时,可以让患者坐起或半坐;
  但头晕、面色苍白、脉搏弱时必须平躺,不要让他站起来或走动
  (休克时突然站起可致心跳骤停)
- 抗组胺药(如氯雷他定)只能缓解皮疹瘙痒,不能代替肾上腺素,
  不要因为先吃抗组胺药而耽误注射
- 症状缓解后仍须送医观察: 一部分人会在数小时后再次发作(双相反应)
- 事后把"青霉素过敏"写进用药信息卡,终身不再使用青霉素类;
  头孢类是否可用必须由医生判断
```

用药信息卡的写法见[慢性病用药储备-用药信息卡](../01-日常疾病和伤害/08-慢性病用药储备.md#用药信息卡)。

## 二、磺胺类药物

### 2.1 简介

**磺胺药:**
- 最早的人工合成抗菌药
- 二战期间广泛使用
- 现代已较少用(副作用大,有更好的药)

**优点:**
- 化学合成(不依赖发酵)
- 广谱抗菌

**缺点:**
- 副作用大(肾损害、血液系统)
- 容易耐药

### 2.2 合成(几乎不可能)

**⚠️ 需要专业化学实验室!**

**原料:**
- 苯胺
- 氯磺酸
- 氨水

**步骤:**
- 需要多步有机合成(包括氨基保护、氯磺化、氨解、脱保护等),每一步都需要专业设备和试剂控制,此处不展开

**现实:**
- 原料难获得
- 反应危险(强酸、有毒气体)
- 纯化困难
- **末日情况下几乎不可能制备!**

### 2.3 替代: 回收药品

**现实方案:**
- 末日前储备成品磺胺药
- 搜索废弃药房、医院
- 检查有效期
- 妥善保存

**找到的药怎样判断能不能留:**
```
可以保留:
✓ 原包装完整,药名(通用名)、规格、批号、有效期清楚可辨
✓ 最好附有说明书;没有说明书的,用笔把药名和规格写在包装上
✓ 片剂、胶囊外观完好(判断标准见6.5)

不要保留或使用:
❌ 散装、无标签、说不清是什么药的药片
   (外观相似的药片可能是完全不同的药)
❌ 包装破损、受潮、被水泡过、被火烤过的
❌ 液体剂型、注射剂(无法判断是否污染,注射还需要专业操作)
```

⚠️ 磺胺类(复方新诺明)的禁忌比较多: 磺胺过敏、孕晚期、新生儿、严重肝肾功能不全、葡萄糖-6-磷酸脱氢酶缺乏症(蚕豆病)患者不能用;用药期间要多喝水,出现皮疹(尤其是起水疱、口腔溃烂)立即停药就医。是否适用必须看说明书并由医生判断。

## 三、天然抗菌物质

### 3.0 定位与证据强度

**它们能做什么:**
- 用于**浅表创面**的辅助处理
- 用于轻微感染的早期
- 在没有抗生素时,比什么都不做好

**它们不能做什么:**
- ✗ 替代抗生素
- ✗ 治疗深部感染、脓肿、骨感染
- ✗ 控制全身性感染(脓毒症)

⚠️ **出现以下情况,天然抗菌物无能为力,必须用抗生素:**
- 红肿沿肢体向上蔓延(淋巴管炎,常见为一条红线)
- 高热、寒战、心率快、意识改变
- 伤口有大量脓液、恶臭、组织发黑
- 咬伤、深刺伤、污染的深伤口

**按证据强度排序:**

| 物质 | 证据强度 | 主要用途 |
|------|----------|----------|
| 蜂蜜 | 较强(烧伤、术后感染创面) | 外用敷料 |
| 茶树油 | 中等(皮肤、真菌感染) | 外用,稀释后 |
| 蜂胶 | 较弱 | 外用 |
| 大蒜 | 体外实验强,人体创面证据弱 | 以食用为主 |
| 中药方剂 | 传统经验,现代证据有限 | 内服辅助 |

---

### 3.1 蜂蜜(外用首选)

**为什么有效:**
- 含水量极低,吸出创面水分,细菌难以存活
- 偏酸性(pH 3.2-4.5)
- 葡萄糖氧化酶缓慢释放微量过氧化氢
- 麦卢卡蜂蜜另含甲基乙二醛(MGO)

**证据:**
Cochrane 系统评价(26项研究,3011人)显示:
- **浅二度烧伤**: 高质量证据,比常规敷料愈合快约4-5天
- **术后感染创面**: 中等质量证据,优于消毒剂加纱布
- 其他创面(压力性损伤、静脉溃疡、糖尿病足等)证据质量低,不能确定优劣

**使用方法:**
```
1. 创面先按常规清洗(大量清水或生理盐水冲洗)
2. 蜂蜜直接涂于创面,或涂在纱布上再敷
   - 用量: 覆盖创面约1-3 mm厚
   - ⚠️ 不要加水稀释! 稀释后抗菌作用下降
3. 外层用吸收性敷料(渗液会稀释蜂蜜)
4. 换药: 渗液多时每天1-2次;渗液少时1-2天一次
5. 初敷时可有刺痛感(酸性和吸水作用),数分钟缓解
   如持续剧痛,停用
```

**选择:**
- 最好: 医用级蜂蜜(经伽马射线灭菌、抗菌活性标准化)
- 末日条件下: 纯生蜂蜜(不掺糖浆、未经高温加热)
- 结晶的蜂蜜可温水浴(<40°C)化开,不要煮沸(破坏酶活性)

**⚠️ 禁忌与注意:**
- **1岁以下婴儿绝对不能口服蜂蜜**(肉毒杆菌孢子→婴儿肉毒中毒)
- 生蜂蜜含少量孢子,用于大面积深创面前应权衡;有医用级时优先
- 糖尿病患者外用可以,大量内服需注意血糖
- 对蜂产品过敏者禁用

**内服用途:** 止咳(1岁以上),咽痛,轻度胃部不适

---

### 3.2 大蒜(以食用为主)

**有效成分:** 大蒜素(allicin)

大蒜完整时含有蒜氨酸(alliin)和蒜氨酸酶,**捣碎后**两者接触才生成大蒜素。

```
生成要点:
- 捣碎后静置约10分钟,大蒜素生成最多
- 加热会破坏蒜氨酸酶 → 先捣碎静置,再加热,才能保留部分活性
- 大蒜素本身不稳定,室温下数小时内逐渐分解
- 酒精长期浸泡得到的是其他含硫化合物,大蒜素含量不确定
```

**⚠️⚠️ 重要更正: 不要把生蒜泥敷在皮肤或伤口上!**

生蒜泥直接接触皮肤会造成**化学性烧伤**,这不是罕见意外:
- 一项系统评价收集到32篇文献、39例病例,多数为二度烧伤,部分出现组织坏死
- 包扎、覆盖(形成封闭环境)会显著加重损伤
- 儿童皮肤角质层薄,更易受伤
- 另有一部分人会出现IV型过敏反应(接触性皮炎)

**民间用蒜泥"消炎""治脚气""拔脓"是常见的致伤原因。**

**正确用法:**
```
✓ 食用(主要方式):
  - 生食: 1-3瓣/天,捣碎静置10分钟后拌入食物
  - 空腹大量生食会刺激胃,甚至引起胃黏膜损伤
  - 胃炎、胃溃疡患者减量或避免

✓ 煮食: 抗菌作用弱,但仍有营养价值

✗ 不要外敷生蒜泥
✗ 不要用蒜汁冲洗伤口
✗ 不要滴入耳道、鼻腔、眼睛
```

**其他注意:**
- 大蒜有抗血小板作用,大量食用会延长出血时间
  - 外伤出血、计划手术(含拔牙)前应减量
  - 正在服用抗凝药者慎用
- 与某些药物相互作用(如抗凝药)

---

### 3.3 蜂胶

**成分:** 树脂、黄酮类、酚酸类等混合物,成分随蜂种和植物来源差异很大

**制备:**
```
1. 蜂胶: 100 g(从蜂箱刮取)
2. 冷冻后粉碎(常温发黏难处理)
3. 加75-95%酒精500 mL
4. 密封避光浸泡7-14天,每天摇晃
5. 过滤,得蜂胶酊,避光保存
```

**使用:** 外用涂抹于浅表创面、口腔溃疡

**⚠️ 过敏较常见:**
蜂胶是公认的接触性过敏原,养蜂人和长期使用者中过敏性接触性皮炎并不少见。
```
首次使用前做皮肤测试:
1. 取少量涂在前臂内侧
2. 观察48小时
3. 出现红肿、瘙痒、小水疱 → 禁用
```

---

### 3.4 茶树油

**来源:** 互叶白千层(Melaleuca alternifolia)叶片蒸馏

**用途:** 外用抗菌、抗真菌(足癣、甲真菌、轻度皮肤感染)

**使用:**
```
✓ 必须稀释后使用:
  - 用植物油(椰子油、橄榄油)稀释至5-10%
  - 即1份茶树油加9-19份基础油
✓ 涂于患处,每天1-2次
✓ 首次使用做皮肤测试(同蜂胶)
```

**⚠️ 禁忌:**
- **绝对不可内服!** 口服有神经毒性,可致意识障碍、昏迷
- 不要用于眼周、黏膜
- 氧化变质的茶树油致敏性更强 → 避光密封保存,变色或气味刺鼻则弃用
- 宠物(尤其猫)对茶树油敏感,不要用于动物

---

### 3.5 中药方剂(详见中药制剂章节)

**五味消毒饮:**
- 金银花、野菊花、蒲公英、紫花地丁、紫背天葵
- 煎汤内服,传统用于热毒疮疡
- 原料可自种自采,安全性相对高

**定位:** 早期、轻度感染的内服辅助;不能替代抗生素处理进展性感染

---

### 3.6 不要依赖的方法

```
❌ 胶体银/银水内服
   - 无证据支持口服治疗感染
   - 长期服用可致银质沉着症(皮肤永久变灰蓝色),不可逆
   - 注: 磺胺嘧啶银软膏等外用含银制剂是正规药物,与此不同

❌ 发霉的面包、水果
   - 霉菌种类不可控,可能产生黄曲霉毒素等
   - 见Q2

❌ 尿液冲洗伤口
   - 并非无菌,无抗菌作用

❌ 牙膏、酱油、香灰敷伤口
   - 增加感染风险,影响后续判断
```

## 四、抗生素使用原则

### 4.1 何时使用

**明确细菌感染:**
- 伤口化脓
- 高热不退(>3天)
- 白细胞升高(如能检测)
- 局部红肿热痛

**不要用于:**
- ✗ 病毒感染(感冒、流感)
- ✗ 预防性使用(浪费且致耐药)
- ✗ 发热原因不明

**常见细菌感染的识别要点:**

| 部位 | 提示可能是细菌感染的表现 | 容易混淆的情况 |
|------|------|------|
| 伤口、皮肤 | 伤后1-3天红肿范围扩大、跳痛加重、发烫,有黄绿色脓液或臭味 | 伤口边缘一窄圈淡红、逐日消退是正常愈合 |
| 脓肿(疖、痈) | 局部隆起、发硬后变软、有波动感,中心可见脓头 | 脓肿主要靠切开排脓,单靠吃药常常不够 |
| 尿路 | 尿频、尿急、尿痛;发热、腰痛、寒战提示已上行到肾 | 单纯多喝水后好转的轻微不适 |
| 下呼吸道(肺炎) | 高热、咳嗽咳脓痰、呼吸急促、胸痛,老人可能只表现为没精神 | 普通感冒: 流涕、咽痛为主,一周左右自愈 |
| 咽喉 | 高热、咽痛明显、扁桃体有脓点、颈部淋巴结肿痛,无咳嗽流涕 | 病毒性咽炎多伴流涕、咳嗽 |
| 牙源性 | 牙痛伴面颊、牙龈肿胀,可有脓 | 肿胀扩散到眼周、颈部、张口困难是急症 |

⚠️ 这些只是帮助判断"是否需要尽快就医",**不是自行用药的依据**。伤口感染与正常愈合的详细区分见[外伤处理-感染迹象](../01-日常疾病和伤害/02-外伤处理.md#-感染迹象立即就医);牙脓肿见[口腔问题-牙脓肿与危险信号](../01-日常疾病和伤害/09-口腔问题.md#牙脓肿与危险信号)。

### 4.2 用药原则

**1. 能口服不注射**
- 注射风险大

**2. 能窄谱不广谱**
- 减少耐药
- 保护正常菌群

**3. 足量足疗程**
- 不要一有好转就停药
- 至少用药5-7天
- 症状消失后再用2-3天

**4. ⚠️ 不要自行联合用药**

**原文此处曾建议"重症时两种抗生素联用以增强效果、延缓耐药",这是错误的。**

联合用药在医院确实有明确指征(如结核病必须多药联用、脓毒症在培养结果出来前的
经验性覆盖、特定病原体感染),但这些都基于病原判断和药敏结果,由医生决定。
自行把两种药凑在一起有以下问题:

```
1. 可能相互拮抗,效果反而变差
   - 典型例子: 四环素类、大环内酯类抑制细菌分裂,
     而青霉素类需要细菌处于分裂状态才能起效
   - 协同还是拮抗取决于具体药物和病原体,不能靠猜

2. 毒性叠加
   - 肝、肾负担加倍
   - 不良反应更多且更难判断是哪种药引起的

3. 并不能可靠地延缓耐药
   - "多药联用防耐药"只在结核等特定情况下成立
   - 一般情况下反而增加选择压力,还会杀灭更多正常菌群
     (二重感染、严重腹泻风险上升)

4. 末日情境下尤其不划算
   - 储备有限,同时用两种药意味着能救治的感染次数减半
```

**正确做法:**
- 一次只用一种,按足量足疗程使用
- 用药2-3天完全无改善或加重 → 尽快就医重新判断(可能不是细菌感染、用错了药或需要引流),不要自己换药或加药
- 感染持续加重、出现脓毒症征象(见3.0) → 这是医疗急症,
  不是靠叠加药物能解决的问题

### 4.3 副作用监测

**常见副作用:**

**消化道:**
- 恶心、呕吐、腹泻
- 停药或减量

**过敏:**
- 皮疹→停药
- 呼吸困难→抢救!

**肝肾损害:**
- 尿少、水肿
- 黄疸
- 立即停药

**二重感染:**
- 用药后出现新感染(如真菌)
- 停用抗生素
- 治疗新感染

**按严重程度处理:**

| 表现 | 可能原因 | 怎么办 |
|------|------|------|
| 轻度恶心、胃部不适 | 胃肠刺激 | 按说明书随餐服用(说明书要求空腹的除外) |
| 稀便每天2-3次,无发热无血 | 肠道菌群被打乱 | 多喝水、补液,联系医生 |
| 腹泻频繁(每天多次)、带血或黏液、腹痛发热 | 严重的抗生素相关肠炎(艰难梭菌等) | 停药,立即就医,注意防脱水 |
| 口腔白膜、外阴瘙痒白带增多 | 真菌二重感染 | 就医 |
| 局部皮疹、瘙痒 | 过敏 | 停药,联系医生;记录药名 |
| 皮疹起水疱、皮肤剥脱、口眼黏膜溃烂 | 严重药物过敏(重症药疹) | 停药,立即拨打120 |
| 喉头发紧、呼吸困难、面唇肿、头晕虚脱 | 过敏性休克 | 按1.3抢救,拨打120 |
| 皮肤眼白发黄、尿色深如浓茶、尿量明显减少 | 肝、肾损害 | 停药,尽快就医 |

腹泻时的补液方法见[常见疾病-腹泻](../01-日常疾病和伤害/01-常见疾病.md#腹泻)。

```
用药期间记录(便于医生判断):
- 药名、开始日期和时间、每次服药时间
- 每天体温(早晚各一次)、伤口红肿范围(用笔画线)
- 出现的不适及时间
```

### 4.4 耐药: 为什么每一片都要用对

```
耐药的原理(自然选择):
- 用药时大部分细菌被杀死,少数天生不怕这种药的存活下来
- 存活的细菌繁殖,下一次同样的药就不管用了
- 耐药菌还会在家人、邻居之间传播

加快耐药的做法:
❌ 感冒、流感等病毒感染吃抗生素
❌ 好转就停药、吃吃停停、自己减量
❌ 把一个疗程的药分给几个人吃
❌ 吃别人剩下的、来源不明的药
❌ 没有指征地"预防性"服用

在末日情境下,耐药的代价更大:
- 没有医院做药敏试验,也没有新药可换
- 一个社区里出现耐药菌,储备的药就等于少了一类
```

耐药的生物学原理见[生物与医学基础-抗生素和耐药](../08-基础科学知识/04-生物与医学基础.md#四抗生素和耐药);剂量、半衰期和给药间隔为什么要严格遵守,见[生物医学进阶-药理学原理](../09-进阶科学与工程/07-生物医学进阶.md#四药理学原理)。

### 4.5 什么时候必须就医

**能找到医生、诊所或医院时,任何疑似细菌感染都应先就医,而不是先吃储备药。** 以下情况属于急症,立即拨打120或尽快送医:

```
全身感染(脓毒症)信号:
- 高热(≥39°C)或体温反而低于36°C,伴寒战
- 心跳快(成人静息时>100次/分)、呼吸急促
- 神志不清、反应迟钝、极度虚弱
- 尿量明显减少,皮肤发花、手脚冰凉

局部严重感染:
- 红肿几小时内明显扩大,或出现从伤口向心脏方向延伸的红线
- 疼痛剧烈,与伤口外观不相称;皮肤变紫黑、起血疱、按压有"咯吱"感
- 面部、眼周感染,或牙痛伴面颈部肿胀、张口或吞咽困难
- 关节红肿热痛、不能活动

其他:
- 发热伴颈部僵硬、剧烈头痛、按压不褪色的皮疹
- 咳嗽伴呼吸困难、胸痛、嘴唇发紫
- 动物咬伤、深刺伤、开放性骨折(还涉及狂犬病、破伤风)
- 用药2-3天完全无好转,或任何时候病情加重

特殊人群门槛更低:
- 3个月以下婴儿任何发热、老人"突然不对劲"、孕妇、糖尿病患者、
  长期用激素或化疗的人 → 尽早就医,不要观察等待
```

各人群的发热就医标准见[常见疾病-不同人群的发烧就医标准](../01-日常疾病和伤害/01-常见疾病.md#不同人群的发烧就医标准);全身感染的识别见[外伤处理-全身感染的危险信号](../01-日常疾病和伤害/02-外伤处理.md#全身感染的危险信号立即拨打120);破伤风见[外伤处理-破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防)。

⚠️ 在完全无法就医的极端情况下,也要先认真读储备药的说明书,核对禁忌和过敏史;本手册不提供自行用药方案(见6.1)。

## 五、感染的预防

**预防远胜于治疗!**

### 5.1 伤口处理

**正确步骤:**
```
1. 止血
2. 清洗:
   - 大量清水或生理盐水冲洗
   - 去除异物、泥土
   - 冲洗5-10分钟
3. 消毒:
   - 伤口上用碘伏(首选),从中心向外涂
   - 75%酒精或碘酒只擦伤口周围的皮肤,不要倒进伤口
4. 包扎:
   - 清洁纱布
   - 不要包太紧
5. 观察:
   - 每日换药
   - 注意红肿、化脓
```

**各步骤的要点:**
```
冲洗(最关键):
- 处理前先洗手,有手套戴手套
- 能直接喝的水、烧开放凉的水、生理盐水都可以
- 小伤口至少冲5分钟;脏的、大的伤口用数升水,冲到看不见泥沙
- 用不带针头的注射器或扎孔的瓶子挤出细水柱,冲力比浸泡有效得多
- 嵌入的沙粒用煮沸过的镊子夹出;夹不出、数量多 → 就医

消毒:
- 碘伏涂一次即可,不必天天厚涂
- 不要用紫药水、红药水、牙膏、草木灰、香灰、白糖敷伤口

包扎和换药:
- 敷料每边比伤口大约2 cm,湿了、脏了立即换
- 揭敷料前先用凉开水浸湿,不要硬撕

需要就医处理的伤口(不要自己包上了事):
- 深、长、裂开合不拢的伤口,可能需要缝合
- 动物咬伤、人咬伤、深刺伤(钉子、木刺)
- 被泥土、粪便、锈铁严重污染的伤口 → 同时考虑破伤风
```

完整的冲洗、消毒、包扎和换药方法见[外伤处理-割伤与擦伤](../01-日常疾病和伤害/02-外伤处理.md#割伤与擦伤),破伤风疫苗的判断见[外伤处理-破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防),消毒剂的选择见[消毒剂制备](./01-消毒剂制备.md)。

**预防胜于抢救!**

### 5.2 个人卫生

- 勤洗手(最重要!)
- 饮水煮沸
- 食物煮熟
- 环境清洁
- 人群隔离(传染病)

**洗手——最便宜的"抗生素":**
```
怎么洗:
1. 打湿双手,抹肥皂(没有肥皂可用草木灰)
2. 手心、手背、指缝、指尖、拇指、手腕都搓到,至少20秒
3. 流水冲净,甩干或晾干,不用脏毛巾擦

必须洗手的时刻:
- 便后、给婴儿换尿布后
- 做饭前、吃饭前、喂孩子前
- 处理伤口、照顾病人前后
- 处理生肉、垃圾、动物后
```

**饮水和食物:**
```
饮水:
- 煮沸是最可靠的方法: 烧开后持续沸腾1分钟(海拔2000 m以上3分钟)
- 没有燃料时可用家用漂白水: 每升清水2滴、浑水4滴,摇匀等30分钟
- 厕所、畜圈离水源至少30 m

食物:
- 肉、蛋、水产品彻底煮熟
- 生熟分开(刀、案板、容器)
- 剩饭菜及时冷却,吃前彻底加热;变味、发黏、长霉的不吃
```

**环境和隔离:**
- 粪便、垃圾妥善处理,灭蝇灭鼠
- 有人发热、腹泻、咳嗽时尽量单独居住,护理者戴口罩、勤洗手
- 脓液、带血的敷料装袋后烧掉或深埋

详见[卫生设施-洗手点](../07-日常生活技能/03-卫生设施.md#洗手点)、[水源工程与供水-消毒](../07-日常生活技能/10-水源工程与供水.md#消毒)、[传染病家庭防控](../01-日常疾病和伤害/15-传染病家庭防控.md)。

### 5.3 营养与免疫

**增强抵抗力:**
- 充足睡眠
- 营养均衡(蛋白质、维生素)
- 适度运动
- 阳光照射

**同样重要的预防措施:**
```
疫苗:
- 破伤风: 确认家人都完成了全程接种(≥3剂);受伤后是否加强按外伤处理章的间隔判断
  (干净小伤口距上次>10年、脏伤口距上次>5年)
- 其他按国家免疫规划和医生建议(如流感、肺炎球菌疫苗,
  老人和慢性病患者获益更大)

控制慢性病:
- 血糖控制差的糖尿病患者伤口难愈、容易感染,足部尤其要每天检查

口腔和皮肤:
- 每天刷牙,牙源性感染可以扩散到面颈部
- 皮肤保持清洁干燥,及时处理足癣、皲裂(细菌的入口)

营养:
- 蛋白质和维生素C、维生素A缺乏会让伤口愈合慢、更易感染
```

相关内容见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md)、[传染病家庭防控-疫苗](../01-日常疾病和伤害/15-传染病家庭防控.md#疫苗)、[口腔问题](../01-日常疾病和伤害/09-口腔问题.md)。

**免疫力 = 最好的抗生素!**

## 六、储备建议

**这是本章最重要的一节。** 既然自制不可行,末日前的储备就是唯一可靠的抗生素来源。

### 6.1 一个基本事实

抗生素是处方药,储备的前提是**合法获得**:
- 通过正规就诊获得处方,保留未用完的完整疗程
- 向医生说明长期外出、偏远地区居住等实际需求
- 不要通过非法渠道购买(来源不明、剂量不实、可能是假药)
- 大部分抗菌药物不能开长期处方,比慢性病药更难多备,更要靠平时有计划地积累
  (见[慢性病用药储备-怎样合法地多备一些药](../01-日常疾病和伤害/08-慢性病用药储备.md#怎样合法地多备一些药))

⚠️ **本手册不提供自行用药的剂量方案。** 抗生素的选择、剂量和疗程取决于
感染部位、病原体、患者体重、肝肾功能和过敏史,错误用药会导致治疗失败
和耐药。储备时请做两件事:
1. **保留原包装和说明书**(含剂量、禁忌、不良反应)
2. 就诊时请医生说明: 这些药分别适用于什么情况、你本人有无禁忌

### 6.2 储备哪些

**口服(核心):**

| 类别 | 常见药物 | 大致适用方向 |
|------|----------|--------------|
| 青霉素类 | 阿莫西林、阿莫西林克拉维酸钾 | 呼吸道、皮肤软组织、牙源性感染 |
| 头孢类 | 头孢呋辛、头孢克洛 | 范围较广,青霉素过敏者部分可用 |
| 大环内酯类 | 阿奇霉素 | 呼吸道,青霉素过敏替代 |
| 四环素类 | 多西环素 | 皮肤、呼吸道、立克次体;8岁以下和孕妇禁用 |
| 硝基咪唑类 | 甲硝唑 | 厌氧菌、肠道原虫 |
| 磺胺类 | 复方新诺明 | 尿路感染等 |

> 上表仅说明每类药的大致方向,**不是用药指导**。实际用哪一种必须由医生判断。

**外用:**
- 莫匹罗星软膏(皮肤细菌感染)
- 红霉素软膏(轻度,也用于眼部的专用剂型)
- 碘伏(消毒,见消毒剂章节)

**同等重要的非药品:**
```
伤口处理(很多感染本可避免):
- [ ] 生理盐水(或自配: 1 L凉开水+9 g盐,煮沸冷却)
- [ ] 大容量注射器/冲洗球(20-60 mL,用于加压冲洗)
- [ ] 无菌纱布、敷料(多种尺寸)
- [ ] 医用胶带、绷带
- [ ] 一次性手套(多副)
- [ ] 镊子、剪刀(可煮沸消毒)
- [ ] 体温计
- [ ] 蜂蜜(见3.1)

⚠️ 加压冲洗是预防伤口感染最有效的单项措施,
   比任何消毒剂都重要。
```

**过敏抢救(如有青霉素类储备):**
- [ ] 肾上腺素(自动注射笔或安瓿,需处方;中国大陆较难获得)
- [ ] 抗组胺药(氯雷他定、西替利嗪)
- [ ] 见1.3节抢救流程

### 6.3 剂型选择: 固体优于液体

**保存期从长到短:**
```
1. 片剂、胶囊(干燥固体) —— 最稳定,首选储备
2. 软膏
3. 干粉(需临用前加水的混悬剂) —— 加水前稳定,加水后仅数天-2周
4. 口服液、滴眼液 —— 最不稳定
```

**结论: 以片剂/胶囊为主。** 儿童用药若只有干混悬剂,注意加水后的使用期限
很短(看说明书,通常冰箱保存7-14天)。

### 6.4 储存条件

```
✓ 低温: 25°C以下,越低越好(但不要冷冻片剂)
✓ 避光: 原包装或不透光容器
✓ 干燥: 这是最容易被忽视的一条
  - 不要放在卫生间、厨房
  - 整瓶药不要取出分装
  - 保留瓶内的干燥剂
  - 潮湿地区可用密封盒加干燥剂
✓ 原包装: 铝塑板(泡罩)包装比散装瓶更防潮
✓ 分散存放: 家中主储备、应急包、随身包各一份(车上只放短期用的少量,定期更换)
✓ 记录: 在盒上写明获得日期和用途
✓ 过敏史: 家里每个人对哪些药过敏,写进用药信息卡,和药放在一起

❌ 避免:
- 车内长期存放(夏季车厢可达60°C以上)
- 反复冷热交替
- 撕掉说明书
```

### 6.5 关于有效期

这一点在末日情境下很关键,需要如实说明。

**有效期的含义:**
厂家保证在该日期前,药物含量不低于标示量的90%。**它不是"变毒"的日期。**

**实测数据:**
美国军方与FDA的货架期延长计划(SLEP)对122种药物、3005个批次做了检测:
- 88%的批次在标示有效期后至少仍可延长1年
- 平均延长超过5年
- 前提是**在良好条件下密封保存的固体剂型**

**唯一有记载的过期药中毒:**
曾有3例使用某种过期四环素制剂后出现可逆性范可尼综合征(肾小管损伤)。
该制剂配方早已停产。除此之外,文献中没有其他过期药物中毒的报告。

**因此,现实的判断原则:**
```
有正规在有效期内的药可用时:
→ 绝不使用过期药

完全没有替代、感染可能致命时:
✓ 妥善保存的过期片剂/胶囊,仍可能有效
⚠️ 风险是药效不足 → 治疗失败、诱导耐药,而不是中毒
⚠️ 剂量不能自行加大来"补偿"药效损失

无论如何都不要用:
❌ 变色、变味、结块、潮解、长霉的药
❌ 已加水的混悬剂超过说明书期限
❌ 任何浑浊、有沉淀或析出的注射剂和滴眼液
❌ 包装破损、密封失效的
```

**降解较快、过期后更不可靠的:**
- 所有液体剂型
- 硝酸甘油(极易失效)
- 需冷藏的药物(胰岛素、部分疫苗等)
- 青霉素类水溶液(配好后数小时内就显著降解)

### 6.6 天然抗菌物储备

**可长期自给的:**
```
✓ 蜂蜜: 密封避光可存数年甚至更久(结晶不影响使用)
✓ 大蒜: 阴凉干燥通风处可存数月;可自种,逐年留种
✓ 蜂胶酊: 避光密封,数年
✓ 茶树油: 避光密封,约1-2年(氧化后致敏性增强,勿用)
✓ 中药材: 金银花、连翘、蒲公英等,干燥密封1-2年,可自种自采
```

**优点:** 可持续获得、保质期长、不依赖工业供应
**局限:** 见3.0,不能替代抗生素

### 6.7 储备量的思路

```
以"疗程"为单位思考,不是以"片数":
- 一次细菌感染通常需要连续用药5-10天
- 半途停药会筛选出耐药菌,等于浪费

家庭参考(具体请与医生讨论):
- 2-3种不同类别的口服抗生素,各1-2个完整疗程
- 外用软膏1-2支
- 伤口冲洗和包扎物资: 按6.2清单,宁多勿少
  (这部分便宜、不过期、用量大)

轮换使用:
- 日常就诊用到同类药时,优先用掉旧的
- 补充新的
- 每6-12个月检查一次
```

## 七、现实建议

### 7.1 不要幻想自制抗生素

**残酷现实:**
- 野外青霉菌粗提取: 没有可靠的成功案例
- 纯度无法保证: 可能致命
- 剂量无法控制: 无效或中毒
- 过敏风险: 无法预测
- 无菌条件: 几乎不可能

**结论: 自制抗生素 = 自杀!**

### 7.2 推荐策略

**优先级排序:**

**Tier 1: 预防**
- 清洁、消毒、卫生
- 减少感染机会

**Tier 2: 天然抗菌**
- 大蒜、蜂蜜、中药
- 安全、可持续

**Tier 3: 储备商业抗生素**
- 末日前大量储备
- 妥善保存
- 谨慎使用

**不推荐: 自制抗生素**
- 没有可靠方法,本手册不提供
- 风险远大于可能的收益

## 八、常见问题

### Q1: 青霉素过期还能用吗?

**A: 有正规药时绝不用;完全没有替代时见6.5节。**

要分清两种风险:
- **药效不足**(主要风险): 过期后含量下降,可能治疗失败并诱导耐药
- **致敏性**: 青霉素的降解产物致敏性更强,过敏风险可能增加

实际判断:
- 妥善保存的片剂/胶囊 → 药效可能仍在(见6.5的SLEP数据),但不能确定
- 任何变色、结块、潮解、长霉的 → 丢弃
- 已配好的青霉素水溶液/混悬剂 → 过期即弃(降解很快)
- 有青霉素过敏史者 → 无论是否过期,一律禁用

### Q2: 发霉的面包可以治疗感染吗?

**A: 民间传说,极度危险!**
- 面包上的霉菌种类复杂
- 可能是有毒霉菌(如黄曲霉→剧毒!)
- 即使是青霉菌,含量极低
- **绝不可用!**

### Q3: 抗生素是万能药吗?

**A: 不是!**
- 只对细菌感染有效
- 对病毒、真菌、寄生虫无效
- 滥用导致耐药
- 破坏正常菌群

### Q4: 如何判断是细菌还是病毒感染?

**A: 粗略判断**

**细菌:**
- 局部化脓
- 高热持续
- 白细胞↑(如能化验)
- 抗生素有效

**病毒:**
- 全身症状(乏力、肌肉酸痛)
- 发热3天内多自愈
- 白细胞正常或↓
- 抗生素无效

**不确定 → 观察,支持治疗,不滥用抗生素**
