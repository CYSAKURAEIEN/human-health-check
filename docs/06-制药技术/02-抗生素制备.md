- ✓ 细菌感染确诊(不是病毒!)

- ✓ 具备医学知识
- ✓ 无青霉素过敏史

## 一、青霉素: 为什么本手册不提供自制方法

### 1.1 青霉素简史

**发现:** 1928年,弗莱明发现青霉菌能抑制细菌
**意义:** 拯救了数亿生命
**问题:** 从发现到能用于治病,用了十几年;工业生产依赖特定高产菌株和专业发酵、提纯设备

### 1.2 自制青霉素不可行

- 野外采集的青霉菌大多不产或只产极少量青霉素,外观无法分辨
- 青霉素遇热、遇酸都会迅速分解,没有专业设备无法提纯
- 粗提物剂量未知、无法除菌,注射可致败血症,口服大多被胃酸破坏
- 没有可靠的野外自制成功案例

**结论: 末日前储备成品抗生素(见第六节),不要尝试自制。**
发霉的面包、水果同样不能用于治疗(见Q2)。

### 1.3 青霉素过敏抢救(使用储备青霉素时)

**症状:**
- 皮疹、瘙痒
- 胸闷、气短
- 血压下降
- 意识丧失

**抢救(争分夺秒!):**
```
1. 立即停药!

2. 肾上腺素:
   - 1:1000(1mg/ml)肾上腺素
   - 成人: 0.3-0.5ml(0.3-0.5mg),单次不超过0.5mg
   - 儿童: 0.01ml/kg(0.01mg/kg),单次不超过0.3mg
   - 肌肉注射(大腿外侧)
   - 无改善可重复,间隔5-15分钟

3. 体位:
   - 平卧
   - 抬高双腿

4. 保持气道通畅

5. 如呼吸心跳停止 → CPR

⚠️ 无肾上腺素 = 几乎必死!
   必须提前准备!
```

## 二、磺胺类药物

### 2.1 简介

**磺胺药:**
- 最早的人工合成抗菌药
- 二战期间广泛使用
- 现代已较少用(副作用大,有更好的药)

**优点:**
- 化学合成(不依赖发酵)
- 广谱抗菌

**缺点:**
- 副作用大(肾损害、血液系统)
- 容易耐药

### 2.2 合成(几乎不可能)

**⚠️ 需要专业化学实验室!**

**原料:**
- 苯胺
- 氯磺酸
- 氨水

**步骤:**
- 需要多步有机合成(包括氨基保护、氯磺化、氨解、脱保护等),每一步都需要专业设备和试剂控制,此处不展开

**现实:**
- 原料难获得
- 反应危险(强酸、有毒气体)
- 纯化困难
- **末日情况下几乎不可能制备!**

### 2.3 替代: 回收药品

**现实方案:**
- 末日前储备成品磺胺药
- 搜索废弃药房、医院
- 检查有效期
- 妥善保存

## 三、天然抗菌物质

### 3.0 定位与证据强度

**它们能做什么:**
- 用于**浅表创面**的辅助处理
- 用于轻微感染的早期
- 在没有抗生素时,比什么都不做好

**它们不能做什么:**
- ✗ 替代抗生素
- ✗ 治疗深部感染、脓肿、骨感染
- ✗ 控制全身性感染(脓毒症)

⚠️ **出现以下情况,天然抗菌物无能为力,必须用抗生素:**
- 红肿沿肢体向上蔓延(淋巴管炎,常见为一条红线)
- 高热、寒战、心率快、意识改变
- 伤口有大量脓液、恶臭、组织发黑
- 咬伤、深刺伤、污染的深伤口

**按证据强度排序:**

| 物质 | 证据强度 | 主要用途 |
|------|----------|----------|
| 蜂蜜 | 较强(烧伤、术后感染创面) | 外用敷料 |
| 茶树油 | 中等(皮肤、真菌感染) | 外用,稀释后 |
| 蜂胶 | 较弱 | 外用 |
| 大蒜 | 体外实验强,人体创面证据弱 | 以食用为主 |
| 中药方剂 | 传统经验,现代证据有限 | 内服辅助 |

---

### 3.1 蜂蜜(外用首选)

**为什么有效:**
- 含水量极低,吸出创面水分,细菌难以存活
- 偏酸性(pH 3.2-4.5)
- 葡萄糖氧化酶缓慢释放微量过氧化氢
- 麦卢卡蜂蜜另含甲基乙二醛(MGO)

**证据:**
Cochrane 系统评价(26项研究,3011人)显示:
- **浅二度烧伤**: 高质量证据,比常规敷料愈合快约4-5天
- **术后感染创面**: 中等质量证据,优于消毒剂加纱布
- 其他创面(压力性损伤、静脉溃疡、糖尿病足等)证据质量低,不能确定优劣

**使用方法:**
```
1. 创面先按常规清洗(大量清水或生理盐水冲洗)
2. 蜂蜜直接涂于创面,或涂在纱布上再敷
   - 用量: 覆盖创面约1-3mm厚
   - ⚠️ 不要加水稀释! 稀释后抗菌作用下降
3. 外层用吸收性敷料(渗液会稀释蜂蜜)
4. 换药: 渗液多时每天1-2次;渗液少时1-2天一次
5. 初敷时可有刺痛感(酸性和吸水作用),数分钟缓解
   如持续剧痛,停用
```

**选择:**
- 最好: 医用级蜂蜜(经伽马射线灭菌、抗菌活性标准化)
- 末日条件下: 纯生蜂蜜(不掺糖浆、未经高温加热)
- 结晶的蜂蜜可温水浴(<40°C)化开,不要煮沸(破坏酶活性)

**⚠️ 禁忌与注意:**
- **1岁以下婴儿绝对不能口服蜂蜜**(肉毒杆菌孢子→婴儿肉毒中毒)
- 生蜂蜜含少量孢子,用于大面积深创面前应权衡;有医用级时优先
- 糖尿病患者外用可以,大量内服需注意血糖
- 对蜂产品过敏者禁用

**内服用途:** 止咳(1岁以上),咽痛,轻度胃部不适

### 3.2 大蒜(以食用为主)

**有效成分:** 大蒜素(allicin)

大蒜完整时含有蒜氨酸(alliin)和蒜氨酸酶,**捣碎后**两者接触才生成大蒜素。

```
生成要点:
- 捣碎后静置约10分钟,大蒜素生成最多
- 加热会破坏蒜氨酸酶 → 先捣碎静置,再加热,才能保留部分活性
- 大蒜素本身不稳定,室温下数小时内逐渐分解
- 酒精长期浸泡得到的是其他含硫化合物,大蒜素含量不确定
```

**⚠️⚠️ 重要更正: 不要把生蒜泥敷在皮肤或伤口上!**

生蒜泥直接接触皮肤会造成**化学性烧伤**,这不是罕见意外:
- 一项系统评价收集到32篇文献、39例病例,多数为二度烧伤,部分出现组织坏死
- 包扎、覆盖(形成封闭环境)会显著加重损伤
- 儿童皮肤角质层薄,更易受伤
- 另有一部分人会出现IV型过敏反应(接触性皮炎)

**民间用蒜泥"消炎""治脚气""拔脓"是常见的致伤原因。**

**正确用法:**
```
✓ 食用(主要方式):
  - 生食: 1-3瓣/天,捣碎静置10分钟后拌入食物
  - 空腹大量生食会刺激胃,甚至引起胃黏膜损伤
  - 胃炎、胃溃疡患者减量或避免

✓ 煮食: 抗菌作用弱,但仍有营养价值

✗ 不要外敷生蒜泥
✗ 不要用蒜汁冲洗伤口
✗ 不要滴入耳道、鼻腔、眼睛
```

**其他注意:**
- 大蒜有抗血小板作用,大量食用会延长出血时间
  - 外伤出血、计划手术(含拔牙)前应减量
  - 正在服用抗凝药者慎用
- 与某些药物相互作用(如抗凝药)

### 3.3 蜂胶

**成分:** 树脂、黄酮类、酚酸类等混合物,成分随蜂种和植物来源差异很大

**制备:**
```
1. 蜂胶: 100克(从蜂箱刮取)
2. 冷冻后粉碎(常温发黏难处理)
3. 加75-95%酒精500ml
4. 密封避光浸泡7-14天,每天摇晃
5. 过滤,得蜂胶酊,避光保存
```

**使用:** 外用涂抹于浅表创面、口腔溃疡

**⚠️ 过敏较常见:**
蜂胶是公认的接触性过敏原,养蜂人和长期使用者中过敏性接触性皮炎并不少见。
```
首次使用前做皮肤测试:
1. 取少量涂在前臂内侧
2. 观察48小时
3. 出现红肿、瘙痒、小水疱 → 禁用
```

---

### 3.4 茶树油

**来源:** 互叶白千层(Melaleuca alternifolia)叶片蒸馏

**用途:** 外用抗菌、抗真菌(足癣、甲真菌、轻度皮肤感染)

**使用:**
```
✓ 必须稀释后使用:
  - 用植物油(椰子油、橄榄油)稀释至5-10%
  - 即1份茶树油加9-19份基础油
✓ 涂于患处,每天1-2次
✓ 首次使用做皮肤测试(同蜂胶)
```

**⚠️ 禁忌:**
- **绝对不可内服!** 口服有神经毒性,可致意识障碍、昏迷
- 不要用于眼周、黏膜
- 氧化变质的茶树油致敏性更强 → 避光密封保存,变色或气味刺鼻则弃用
- 宠物(尤其猫)对茶树油敏感,不要用于动物

---

### 3.5 中药方剂(详见中药制剂章节)

**五味消毒饮:**
- 金银花、野菊花、蒲公英、紫花地丁、紫背天葵
- 煎汤内服,传统用于热毒疮疡
- 原料可自种自采,安全性相对高

**定位:** 早期、轻度感染的内服辅助;不能替代抗生素处理进展性感染

---

### 3.6 不要依赖的方法

```
❌ 胶体银/银水内服
   - 无证据支持口服治疗感染
   - 长期服用可致银质沉着症(皮肤永久变灰蓝色),不可逆
   - 注: 磺胺嘧啶银软膏等外用含银制剂是正规药物,与此不同

❌ 发霉的面包、水果
   - 霉菌种类不可控,可能产生黄曲霉毒素等
   - 见Q2

❌ 尿液冲洗伤口
   - 并非无菌,无抗菌作用

❌ 牙膏、酱油、香灰敷伤口
   - 增加感染风险,影响后续判断
```

## 四、抗生素使用原则

### 4.1 何时使用

**明确细菌感染:**
- 伤口化脓
- 高热不退(>3天)
- 白细胞升高(如能检测)
- 局部红肿热痛

**不要用于:**
- ✗ 病毒感染(感冒、流感)
- ✗ 预防性使用(浪费且致耐药)
- ✗ 发热原因不明

### 4.2 用药原则

**1. 能口服不注射**
- 注射风险大

**2. 能窄谱不广谱**
- 减少耐药
- 保护正常菌群

**3. 足量足疗程**
- 不要一有好转就停药
- 至少用药5-7天
- 症状消失后再用2-3天

**4. ⚠️ 不要自行联合用药**

**原文此处曾建议"重症时两种抗生素联用以增强效果、延缓耐药",这是错误的。**

联合用药在医院确实有明确指征(如结核病必须多药联用、脓毒症在培养结果出来前的
经验性覆盖、特定病原体感染),但这些都基于病原判断和药敏结果,由医生决定。
自行把两种药凑在一起有以下问题:

```
1. 可能相互拮抗,效果反而变差
   - 典型例子: 四环素类、大环内酯类抑制细菌分裂,
     而青霉素类需要细菌处于分裂状态才能起效
   - 协同还是拮抗取决于具体药物和病原体,不能靠猜

2. 毒性叠加
   - 肝、肾负担加倍
   - 不良反应更多且更难判断是哪种药引起的

3. 并不能可靠地延缓耐药
   - "多药联用防耐药"只在结核等特定情况下成立
   - 一般情况下反而增加选择压力,还会杀灭更多正常菌群
     (二重感染、严重腹泻风险上升)

4. 末日情境下尤其不划算
   - 储备有限,同时用两种药意味着能救治的感染次数减半
```

**正确做法:**
- 一次只用一种,按足量足疗程使用
- 用药2-3天完全无改善 → 考虑换用另一类(而不是加上另一类)
- 感染持续加重、出现脓毒症征象(见3.0) → 这是医疗急症,
  不是靠叠加药物能解决的问题

### 4.3 副作用监测

**常见副作用:**

**消化道:**
- 恶心、呕吐、腹泻
- 停药或减量

**过敏:**
- 皮疹→停药
- 呼吸困难→抢救!

**肝肾损害:**
- 尿少、水肿
- 黄疸
- 立即停药

**二重感染:**
- 用药后出现新感染(如真菌)
- 停用抗生素
- 治疗新感染

## 五、感染的预防

**预防远胜于治疗!**

### 5.1 伤口处理

**正确步骤:**
```
1. 止血
2. 清洗:
   - 大量清水或生理盐水冲洗
   - 去除异物、泥土
   - 冲洗5-10分钟
3. 消毒:
   - 75%酒精或碘酒
   - 从里向外擦拭
4. 包扎:
   - 清洁纱布
   - 不要包太紧
5. 观察:
   - 每日换药
   - 注意红肿、化脓
```

**预防胜于抢救!**

### 5.2 个人卫生

- 勤洗手(最重要!)
- 饮水煮沸
- 食物煮熟
- 环境清洁
- 人群隔离(传染病)

### 5.3 营养与免疫

**增强抵抗力:**
- 充足睡眠
- 营养均衡(蛋白质、维生素)
- 适度运动
- 阳光照射

**免疫力 = 最好的抗生素!**

## 六、储备建议

**这是本章最重要的一节。** 既然自制不可行,末日前的储备就是唯一可靠的抗生素来源。

### 6.1 一个基本事实

抗生素是处方药,储备的前提是**合法获得**:
- 通过正规就诊获得处方,保留未用完的完整疗程
- 向医生说明长期外出、偏远地区居住等实际需求
- 不要通过非法渠道购买(来源不明、剂量不实、可能是假药)

⚠️ **本手册不提供自行用药的剂量方案。** 抗生素的选择、剂量和疗程取决于
感染部位、病原体、患者体重、肝肾功能和过敏史,错误用药会导致治疗失败
和耐药。储备时请做两件事:
1. **保留原包装和说明书**(含剂量、禁忌、不良反应)
2. 就诊时请医生说明: 这些药分别适用于什么情况、你本人有无禁忌

### 6.2 储备哪些

**口服(核心):**

| 类别 | 常见药物 | 大致适用方向 |
|------|----------|--------------|
| 青霉素类 | 阿莫西林、阿莫西林克拉维酸钾 | 呼吸道、皮肤软组织、牙源性感染 |
| 头孢类 | 头孢呋辛、头孢克洛 | 范围较广,青霉素过敏者部分可用 |
| 大环内酯类 | 阿奇霉素 | 呼吸道,青霉素过敏替代 |
| 四环素类 | 多西环素 | 皮肤、呼吸道、立克次体;8岁以下和孕妇禁用 |
| 硝基咪唑类 | 甲硝唑 | 厌氧菌、肠道原虫 |
| 磺胺类 | 复方新诺明 | 尿路感染等 |

> 上表仅说明每类药的大致方向,**不是用药指导**。实际用哪一种必须由医生判断。

**外用:**
- 莫匹罗星软膏(皮肤细菌感染)
- 红霉素软膏(轻度,也用于眼部的专用剂型)
- 碘伏(消毒,见消毒剂章节)

**同等重要的非药品:**
```
伤口处理(很多感染本可避免):
- [ ] 生理盐水(或自配: 1升凉开水+9克盐,煮沸冷却)
- [ ] 大容量注射器/冲洗球(20-60ml,用于加压冲洗)
- [ ] 无菌纱布、敷料(多种尺寸)
- [ ] 医用胶带、绷带
- [ ] 一次性手套(多副)
- [ ] 镊子、剪刀(可煮沸消毒)
- [ ] 体温计
- [ ] 蜂蜜(见3.1)

⚠️ 加压冲洗是预防伤口感染最有效的单项措施,
   比任何消毒剂都重要。
```

**过敏抢救(如有青霉素类储备):**
- [ ] 肾上腺素(自动注射笔或安瓿,需处方;中国大陆较难获得)
- [ ] 抗组胺药(氯雷他定、西替利嗪)
- [ ] 见1.3节抢救流程

### 6.3 剂型选择: 固体优于液体

**保存期从长到短:**
```
1. 片剂、胶囊(干燥固体) —— 最稳定,首选储备
2. 软膏
3. 干粉(需临用前加水的混悬剂) —— 加水前稳定,加水后仅数天-2周
4. 口服液、滴眼液 —— 最不稳定
```

**结论: 以片剂/胶囊为主。** 儿童用药若只有干混悬剂,注意加水后的使用期限
很短(看说明书,通常冰箱保存7-14天)。

### 6.4 储存条件

```
✓ 低温: 25°C以下,越低越好(但不要冷冻片剂)
✓ 避光: 原包装或不透光容器
✓ 干燥: 这是最容易被忽视的一条
  - 不要放在卫生间、厨房
  - 整瓶药不要取出分装
  - 保留瓶内的干燥剂
  - 潮湿地区可用密封盒加干燥剂
✓ 原包装: 铝塑板(泡罩)包装比散装瓶更防潮
✓ 分散存放: 家里、车上、随身包各一份
✓ 记录: 在盒上写明获得日期和用途

❌ 避免:
- 车内长期存放(夏季车厢可达60°C以上)
- 反复冷热交替
- 撕掉说明书
```

### 6.5 关于有效期

这一点在末日情境下很关键,需要如实说明。

**有效期的含义:**
厂家保证在该日期前,药物含量不低于标示量的90%。**它不是"变毒"的日期。**

**实测数据:**
美国军方与FDA的货架期延长计划(SLEP)对122种药物、3005个批次做了检测:
- 88%的批次在标示有效期后至少仍可延长1年
- 平均延长超过5年
- 前提是**在良好条件下密封保存的固体剂型**

**唯一有记载的过期药中毒:**
曾有3例使用某种过期四环素制剂后出现可逆性范可尼综合征(肾小管损伤)。
该制剂配方早已停产。除此之外,文献中没有其他过期药物中毒的报告。

**因此,现实的判断原则:**
```
有正规在有效期内的药可用时:
→ 绝不使用过期药

完全没有替代、感染可能致命时:
✓ 妥善保存的过期片剂/胶囊,仍可能有效
⚠️ 风险是药效不足 → 治疗失败、诱导耐药,而不是中毒
⚠️ 剂量不能自行加大来"补偿"药效损失

无论如何都不要用:
❌ 变色、变味、结块、潮解、长霉的药
❌ 已加水的混悬剂超过说明书期限
❌ 任何浑浊、有沉淀或析出的注射剂和滴眼液
❌ 包装破损、密封失效的
```

**降解较快、过期后更不可靠的:**
- 所有液体剂型
- 硝酸甘油(极易失效)
- 需冷藏的药物(胰岛素、部分疫苗等)
- 青霉素类水溶液(配好后数小时内就显著降解)

### 6.6 天然抗菌物储备

**可长期自给的:**
```
✓ 蜂蜜: 密封避光可存数年甚至更久(结晶不影响使用)
✓ 大蒜: 阴凉干燥通风处可存数月;可自种,逐年留种
✓ 蜂胶酊: 避光密封,数年
✓ 茶树油: 避光密封,约1-2年(氧化后致敏性增强,勿用)
✓ 中药材: 金银花、连翘、蒲公英等,干燥密封1-2年,可自种自采
```

**优点:** 可持续获得、保质期长、不依赖工业供应
**局限:** 见3.0,不能替代抗生素

### 6.7 储备量的思路

```
以"疗程"为单位思考,不是以"片数":
- 一次细菌感染通常需要连续用药5-10天
- 半途停药会筛选出耐药菌,等于浪费

家庭参考(具体请与医生讨论):
- 2-3种不同类别的口服抗生素,各1-2个完整疗程
- 外用软膏1-2支
- 伤口冲洗和包扎物资: 按6.2清单,宁多勿少
  (这部分便宜、不过期、用量大)

轮换使用:
- 日常就诊用到同类药时,优先用掉旧的
- 补充新的
- 每6-12个月检查一次
```

## 七、现实建议

### 7.1 不要幻想自制抗生素

**残酷现实:**
- 野外青霉菌粗提取: 没有可靠的成功案例
- 纯度无法保证: 可能致命
- 剂量无法控制: 无效或中毒
- 过敏风险: 无法预测
- 无菌条件: 几乎不可能

**结论: 自制抗生素 = 自杀!**

### 7.2 推荐策略

**优先级排序:**

**Tier 1: 预防**
- 清洁、消毒、卫生
- 减少感染机会

**Tier 2: 天然抗菌**
- 大蒜、蜂蜜、中药
- 安全、可持续

**Tier 3: 储备商业抗生素**
- 末日前大量储备
- 妥善保存
- 谨慎使用

**不推荐: 自制抗生素**
- 没有可靠方法,本手册不提供
- 风险远大于可能的收益

## 八、常见问题

### Q1: 青霉素过期还能用吗?

**A: 有正规药时绝不用;完全没有替代时见6.5节。**

要分清两种风险:
- **药效不足**(主要风险): 过期后含量下降,可能治疗失败并诱导耐药
- **致敏性**: 青霉素的降解产物致敏性更强,过敏风险可能增加

实际判断:
- 妥善保存的片剂/胶囊 → 药效可能仍在(见6.5的SLEP数据),但不能确定
- 任何变色、结块、潮解、长霉的 → 丢弃
- 已配好的青霉素水溶液/混悬剂 → 过期即弃(降解很快)
- 有青霉素过敏史者 → 无论是否过期,一律禁用

### Q2: 发霉的面包可以治疗感染吗?

**A: 民间传说,极度危险!**
- 面包上的霉菌种类复杂
- 可能是有毒霉菌(如黄曲霉→剧毒!)
- 即使是青霉菌,含量极低
- **绝不可用!**

### Q3: 抗生素是万能药吗?

**A: 不是!**
- 只对细菌感染有效
- 对病毒、真菌、寄生虫无效
- 滥用导致耐药
- 破坏正常菌群

### Q4: 如何判断是细菌还是病毒感染?

**A: 粗略判断**

**细菌:**
- 局部化脓
- 高热持续
- 白细胞↑(如能化验)
- 抗生素有效

**病毒:**
- 全身症状(乏力、肌肉酸痛)
- 发热3天内多自愈
- 白细胞正常或↓
- 抗生素无效

**不确定 → 观察,支持治疗,不滥用抗生素**
