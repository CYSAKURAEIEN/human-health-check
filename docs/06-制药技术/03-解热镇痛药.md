# 解热镇痛药

> **退烧止痛 - 常用但难以自制的药物**

## ⚠️ 警告

**化学合成药物制备极度困难且危险!**

- 需要化学专业知识
- 需要专业设备和原料
- 反应条件苛刻
- 纯化困难
- 剂量难控制
- **末日情况下几乎不可能成功制备!**

**本章节主要作为知识储备,实际推荐使用天然替代品!**

**本章更实用的部分是: 现成退烧止痛药的使用原则和禁忌(1.5、2.3、2.4、5.4、5.5),以及疼痛的非药物处理和就医标准(6.5、6.6)。** 有储备的成品药时,按说明书使用;危险信号出现时,任何药都不能代替就医。

## 一、阿司匹林(乙酰水杨酸)

### 1.1 简介

**阿司匹林:**
- 最古老、最经典的解热镇痛药
- 1899年上市
- 至今仍广泛使用

**功效:**
- 解热(退烧)
- 镇痛(轻中度疼痛)
- 抗炎
- 抗血小板(预防心梗、脑梗)

**副作用:**
- 胃肠刺激(胃痛、出血)
- 过敏(阿司匹林哮喘)
- Reye综合征(儿童禁用!)

### 1.2 柳树皮中的有效成分

**原理:** 柳树皮含水杨苷,进入人体后在肠道和肝脏中代谢为水杨酸,起解热镇痛作用。

**为什么不能简单地提取水杨酸:**
- 水杨苷在酸或碱中水解,得到的是**水杨醇**和葡萄糖,不是水杨酸
- 水杨醇要再经过氧化才能变成水杨酸,需要化学试剂和控制条件
- 网上流传的"柳树皮加石灰水煮、再加酸析出水杨酸"在化学上不成立

**结论:** 末日条件下无法从柳树皮制得水杨酸,更无法进一步合成阿司匹林。
直接用柳树皮煎剂(见1.4),由人体自行把水杨苷转化为水杨酸,是唯一现实的方法。

### 1.3 乙酰化(水杨酸→阿司匹林)

**⚠️ 需要化学试剂,末日难以实现!以下以现成水杨酸为原料,仅作了解。**

**原理:**
```
水杨酸 + 乙酸酐 → 乙酰水杨酸(阿司匹林) + 乙酸
```

**材料:**
- 水杨酸: 10 g
- 乙酸酐: 20 mL(化学试剂,难获得)
- 浓硫酸: 数滴(催化剂,剧毒!)

**步骤:**
```
1. 混合:
   - 水杨酸 + 乙酸酐
   - 加数滴浓硫酸

2. 反应:
   - 50-60°C水浴加热
   - 15-20分钟
   - 搅拌

3. 水解过量乙酸酐:
   - 加水
   - 乙酸酐水解

4. 结晶:
   - 冷却
   - 阿司匹林析出

5. 过滤、洗涤、干燥

6. 重结晶纯化:
   - 热水溶解
   - 慢慢冷却结晶
   - 多次重复
```

**现实:**
- 乙酸酐: 管制化学品,难获得
- 浓硫酸: 剧毒、强腐蚀
- 纯化困难
- **不推荐尝试!**

### 1.4 柳树皮直接使用(推荐!)

**既然合成困难,不如直接用柳树皮!**

**方法:**
```
1. 柳树皮干品: 15-30 g
2. 加水500 mL
3. 煮沸后小火煎20分钟
4. 过滤取汁
5. 分2-3次服用

功效: 解热镇痛(效果弱于阿司匹林)
```

**注意:**
- 柳树皮含水杨酸类成分,禁忌与阿司匹林相同:
  - ❌ 18岁以下禁用(Reye综合征风险)
  - ❌ 孕妇、哺乳期禁用
  - ❌ 对阿司匹林过敏、哮喘、胃溃疡、出血倾向者禁用
- 空腹服用刺激胃,应饭后服用
- "天然"不等于安全,同样需要控制剂量

### 1.5 阿司匹林的使用原则与禁忌

**定位:** 有对乙酰氨基酚、布洛芬时,退烧止痛一般不首选阿司匹林。家里备的阿司匹林,最重要的用途是疑似心梗时嚼服(见下方链接)。

```
用法(成人,以说明书为准):
- 饭后服,用一整杯水送服
- 用于退烧不超过3天,用于止痛不超过5天;不见好转就停药、就医
- 不和布洛芬等其他止痛药同时吃

❌ 谁不能用:
- 18岁以下: 流感、水痘等病毒感染时服用,可能引起瑞氏综合征
  (急性脑病和肝损害,死亡率高)
- 孕妇(尤其孕晚期)
- 对阿司匹林或其他止痛药过敏,或吃后哮喘发作过
- 胃溃疡、胃出血、黑便史;血友病等出血性疾病
- 正在吃抗凝药(如华法林)或其他抗血小板药
- 拔牙、手术前后(先问医生)
⚠️ 慎用: 哺乳期、痛风、肝肾功能不全、长期饮酒

⚠️ 藏在别的药里的阿司匹林:
- 一些复方感冒药、止痛散里含阿司匹林,成分表写作"乙酰水杨酸"
- 给儿童用任何感冒药前先看成分表
- 柳树皮煎剂、含水杨酸的药也按阿司匹林对待

医生开的长期小剂量阿司匹林(预防心梗、脑梗):
- 不要自行停药,也不要为了"顺便止痛"加量
- 需要退烧止痛时另选对乙酰氨基酚;
  布洛芬可能削弱小剂量阿司匹林的保护作用,要用时先问医生

出现以下情况停药并就医:
- 黑便(柏油样)、呕吐咖啡色物或血 → 消化道出血,立即就医
- 皮肤大片瘀斑,鼻出血或牙龈出血不止
- 皮疹、喘憋、嘴唇眼睑肿胀 → 过敏,严重时拨打120
- 耳鸣、听力下降 → 水杨酸过量的早期表现
```

疑似心梗时怎样嚼服阿司匹林、哪些情况不能用,见[心脑血管与突发病症-阿司匹林: 何时可以用](../01-日常疾病和伤害/06-心脑血管与突发病症.md#阿司匹林-何时可以用)。

## 二、对乙酰氨基酚(扑热息痛)

### 2.1 简介

**对乙酰氨基酚(Paracetamol):**
- 商品名: 泰诺林、扑热息痛、百服宁
- 解热镇痛

**优点:**
- 副作用小(不伤胃)
- 儿童可用

**缺点:**
- 无抗炎作用
- 过量致肝损伤(严重可致死!)

### 2.2 合成(几乎不可能)

**⚠️ 复杂的化学合成,需专业实验室!**

**路线(仅作了解):**
```
苯酚 → 硝化 → 对硝基酚 → 还原 → 对氨基酚 → 乙酰化 → 对乙酰氨基酚
```

**每步都需要:**
- 危险化学试剂(浓硝酸、浓硫酸、乙酸酐等)
- 精确控制条件
- 专业设备

**结论: 末日情况下不可能制备!**

### 2.3 使用原则

```
剂量(与"常见疾病"一章一致,以所用药品说明书为准):
- 成人: 国内非处方说明书一般为每次500 mg,间隔≥4小时,24小时内≤4次
  (每天2000 mg);更高剂量(每次最多1000 mg、每天最多4000 mg)须遵医嘱
- 儿童: 按体重每次10-15 mg/kg,间隔≥4小时,24小时内≤4次;
  3个月以上可用,3-6个月最好先问医生,3个月以下发烧直接就医
- 长期饮酒、肝病、营养不良或体重<50 kg的成人: 每天总量要更低,先问医生

✓ 比较适合用对乙酰氨基酚的人:
- 儿童(包括出水痘的儿童)
- 孕妇(退烧首选,短期按说明书)、哺乳期
- 胃不好、有胃溃疡或胃出血史、正在吃抗凝药、哮喘、肾功能不好的人

使用要点:
1. 先看清正在吃的所有药的成分表:
   "对乙酰氨基酚""扑热息痛""APAP"出现在大量复方感冒药里
   (药名里常带"氨酚""酚麻""氨咖"等字样)
   → 已经在吃这类感冒药,就不要再另加退烧药
2. 每次用药记下时间和剂量;多人照顾病人时尤其要记,防止重复给药
3. 服药期间不喝酒
4. 吃药后约30-60分钟起效;体温降1-1.5°C、人舒服了就算有效,
   不要因为"没降到正常"提前加服
5. 用于退烧不超过3天、止痛不超过5天;仍不好就医
6. 它只能退烧止痛,对红肿发炎没有作用,也不治病因
```

儿童按体重的剂量表和毫克换算成毫升的方法见[常见疾病-退烧药剂量速查](../01-日常疾病和伤害/01-常见疾病.md#退烧药剂量速查)。

### 2.4 过量的危险: 肝损伤

**对乙酰氨基酚是家庭药物过量中最需要警惕的一种**: 常见、看起来温和,但过量后会造成严重肝损伤,甚至死亡。

```
为什么危险:
- 过量后最初1-2天可能毫无症状,或只有恶心、呕吐、出汗、乏力
- 2-4天后才出现右上腹痛、皮肤和眼白发黄、嗜睡或意识混乱
  → 到这时肝脏已经严重受损
- 医院有特效解毒药,但越早用越有效(最好在服药后8小时内)
  → 等到出现症状再去,往往已经晚了

以下情况都按"可能过量"处理,立即就医:
- 儿童误吞成人药片,或自己喝了一瓶甜味糖浆
- 一次吞服明显超过说明书的量
- 连续几天每次都超量,或同时吃了几种含对乙酰氨基酚的药
- 长期饮酒、肝病或营养不良的人,吃到了说明书上限还在加量

去医院时:
- 带上药盒,估计吃了多少片(数一数剩下的)
- 记下大概什么时间吃的

❌ 不要催吐
❌ 不要因为"现在没症状"就在家观察
❌ 不要用偏方"解毒"
```

误服和药物过量的处理见[中毒-药物过量与误服](../01-日常疾病和伤害/12-中毒.md#药物过量与误服)。如果过量可能是有意的,同时关注心理状况,见[心理健康-自杀风险](../01-日常疾病和伤害/10-心理健康.md#自杀风险-识别与应对)。

## 三、天然解热镇痛药(推荐!)

### 3.1 柳树皮(详见上文)

**最接近阿司匹林的天然药!**

### 3.2 白芷

**功效:** 祛风解表,止痛

**使用:**
```
白芷: 3-10 g
煎汤服用

适用:
- 头痛(特别是前额痛)
- 牙痛
- 风寒感冒
```

### 3.3 川芎

**功效:** 活血行气,祛风止痛

**使用:**
```
川芎: 6-10 g
煎汤服用

适用:
- 头痛(特别是偏头痛)
- 风湿痛
- 跌打损伤痛
```

### 3.4 菊花+薄荷

**功效:** 疏散风热,清肝明目

**使用:**
```
菊花: 10 g
薄荷: 6 g(后下)
泡茶或煎汤

适用:
- 风热头痛
- 发热
- 目赤肿痛
```

### 3.5 生姜+葱白

**功效:** 发汗解表,退烧

**使用:**
```
生姜: 5-8片
葱白: 3-5根
红糖: 适量
煎汤,趁热服,注意保暖
⚠️ 不要"捂汗": 婴幼儿被捂得太严可能体温急升、脱水

适用:
- 风寒感冒发烧
- 轻度发热
```

### 3.6 鱼腥草

**功效:** 清热解毒

**使用:**
```
鱼腥草干品: 15-25 g(鲜品加倍)
煎汤服用,不宜久煎

适用:
- 风热感冒
- 发热
- 咽喉肿痛
```

### 3.7 用中药退烧止痛的原则

```
- 这些药材作用比成品退烧药弱、起效慢,适合低热和轻中度疼痛;
  高热、婴幼儿发烧、出现危险信号(见5.3)时不要靠它们
- 1岁以下婴儿不要自行用中药煎剂退烧;
  薄荷、含薄荷脑的药油不要用在婴幼儿口鼻附近(可能引起呼吸暂停)
- 孕妇: 川芎活血,孕妇慎用;其他药材也先问医生
- 已经吃了退烧药,再喝"发汗"汤,要防出汗过多脱水
- 只用确认无误的药材;自己采挖时必须认准品种
- 服后出现皮疹、呕吐、腹泻,或病情加重 → 停用
```

药材辨认和易混淆的有毒植物见[药用植物-有毒植物(避免误用)](../04-动植物培育/04-药用植物.md#有毒植物避免误用)。

## 四、物理降温(辅助手段)

> 物理降温只能短时间、少量降低体温,不能代替退烧药,也不能预防热性惊厥;让病人舒服是主要目的。详见[常见疾病-发烧](../01-日常疾病和伤害/01-常见疾病.md#发烧)。

### 4.1 温水擦浴

**适用:** 作为辅助,让病人感觉舒服时使用;病人发抖、不舒服就停

**方法:**
```
1. 温水(32-34°C,手感微温)
2. 毛巾浸湿拧半干
3. 擦拭:
   - 颈部、腋下、腹股沟(大血管处)
   - 四肢
   - 背部
4. 每15-30分钟擦一次
5. 多喝水

禁忌:
  - 寒战时不用(会加重)
  - 新生儿谨慎
  - 不用冷水、冰水、酒精擦身(酒精可经皮肤吸收,儿童尤其危险)
```

### 4.2 冷敷

**方法:**
```
1. 凉毛巾(冰袋要用毛巾包好,不直接贴皮肤)
2. 敷额头,让病人舒服即可
3. 10-15分钟一换
⚠️ 婴幼儿不用冰袋;病人发抖时停止
```

### 4.3 多饮水

**重要!** 发烧时出汗、呼吸加快都会失水,脱水会让人更难受、体温更难降。

```
- 成人: 每小时约200-300 mL,少量多次;尿色淡黄说明喝够了
- 可以喝: 温开水、米汤、清汤、果汁兑水
- 婴儿: 继续母乳或配方奶,增加喂奶次数
- 出汗多,或同时腹泻、呕吐: 改喝口服补液盐
- 脱水信号: 尿少、尿色深、嘴唇干、哭时没眼泪、精神差 → 加紧补液,
  喝不进去或越来越蔫 → 就医
```

口服补液盐的配法见[常见疾病-腹泻](../01-日常疾病和伤害/01-常见疾病.md#腹泻)。

### 4.4 衣物与环境

```
- 室温保持在22-24°C左右,保持通风,风扇不要直吹病人
- 寒战(发冷发抖)时可盖一条薄毯;寒战停止、开始发热出汗后就减掉
- ❌ 不要"捂汗",尤其婴幼儿
- 出汗后及时擦干、换下湿衣服
```

## 五、发烧处理原则

### 5.1 何时需要退烧?

**体温(以腋温计,与[常见疾病-何时需要退烧](../01-日常疾病和伤害/01-常见疾病.md#何时需要退烧)一致):**
- 成人: ≥38.5°C且感到不适时可以用药;有基础疾病者≥38°C
- 儿童: 3个月以下任何发烧都应就医,不要自行用药;
  3-6个月≥38.5°C(只用对乙酰氨基酚,最好先问医生);6个月以上≥39°C或明显不适
- 体温≥40°C: 立即就医;等待时按说明书用退烧药,温水擦浴作辅助
- 未达到上面的标准、精神好、能吃能喝: 一般不必用药,多喝水、休息,让病人舒服即可

**特殊人群:**
- 孕妇: 任何≥38°C的发烧都联系产科医生;退烧首选对乙酰氨基酚
- 老人: 体温反应弱,比平时高1°C以上,或虽不高但突然没精神、不吃饭,就要重视
- 有热性惊厥史: 按常规处理发烧即可;退烧药和物理降温都不能预防惊厥,发作时的处理见常见疾病-发烧

### 5.2 发烧的意义

**发烧是症状,不是疾病!**

**发烧的作用:**
- 抑制病原体生长
- 增强免疫力
- 发出疾病信号

**盲目退烧的危害:**
- 掩盖病情
- 延误诊断
- 反而不利康复

**原则:**
1. 找出发烧原因!
2. 治疗原发病
3. 高烧才需退烧
4. 以让病人舒服为目的,不必追求把体温降到正常

### 5.3 危险信号

**立即就医(如有条件):**
- 持续高烧>3天
- 伴有意识改变
- 抽搐
- 呼吸困难
- 剧烈头痛、呕吐
- 皮肤出现瘀点、瘀斑
- 婴幼儿精神萎靡

各年龄段的就医标准见[常见疾病-不同人群的发烧就医标准](../01-日常疾病和伤害/01-常见疾病.md#不同人群的发烧就医标准)。

### 5.4 常用非处方退烧止痛药怎么选

| | 对乙酰氨基酚 | 布洛芬 | 阿司匹林 |
|------|------|------|------|
| 成人每次(非处方说明书常见) | 500 mg | 200-400 mg | 按说明书 |
| 间隔 | ≥4小时 | 4-6小时 | 按说明书 |
| 成人每天上限(非处方) | 2000 mg | 1200 mg | 按说明书 |
| 儿童 | 3个月以上 | 6个月以上 | ❌ 18岁以下不用 |
| 抗炎(消肿) | 无 | 有 | 有 |
| 主要风险 | 过量致肝损伤 | 胃出血、伤肾 | 胃出血、出血不止、瑞氏综合征 |
| 孕妇 | 首选(短期) | 避免,尤其孕20周以后 | 不用 |

```
怎么选:
- 儿童: 对乙酰氨基酚或布洛芬(布洛芬限6个月以上),不用阿司匹林
- 孕妇: 对乙酰氨基酚;哺乳期: 对乙酰氨基酚或布洛芬,短期按说明书
- 胃病、出血倾向、吃抗凝药、肾病、脱水、哮喘: 对乙酰氨基酚
- 肝病、长期饮酒: 两种都要先问医生
- 扭伤、牙痛、痛经等有红肿发炎的疼痛: 布洛芬通常效果更好

共同原则:
1. 一次只用一种,不叠加,也不"交替"(容易算错次数和总量)
2. 儿童按体重算剂量,用药品自带的量杯、量管
3. 等够间隔时间,不因为没降到正常就提前加服
4. 每次记下时间和剂量
5. 退烧不超过3天、止痛不超过5天,仍不好就医
6. 药只缓解症状,找到病因更重要
7. 所有药锁好,放在儿童拿不到的地方
```

### 5.5 布洛芬的使用与禁忌

```
剂量(与"常见疾病"一章一致,以说明书为准):
- 成人: 每次200-400 mg,间隔4-6小时,非处方每天≤1200 mg
- 儿童: 每次5-10 mg/kg,间隔6-8小时,24小时内≤4次;6个月以上可用

✓ 正确用法:
- 饭后或随餐服,减少胃部不适
- 同时喝够水
- 不和阿司匹林等其他止痛药同吃

❌ 以下情况不要自行使用:
- 胃溃疡、胃出血或黑便史
- 肾病;严重脱水(腹泻呕吐、几乎不排尿)时会伤肾 → 先补液,改用对乙酰氨基酚
- 对阿司匹林、布洛芬或其他止痛药过敏
- 正在吃抗凝药
- 孕妇(尤其孕20周以后)
- 6个月以下婴儿
- 出水痘的儿童(退烧用对乙酰氨基酚)
⚠️ 部分哮喘患者用后会诱发哮喘发作
⚠️ 心衰、血压控制不好的高血压、需要长期服用的老人: 先问医生

停药并就医:
- 胃痛加重、黑便、呕血
- 尿量明显减少、浮肿
- 皮疹、喘憋、面部肿胀
```

## 六、疼痛处理

### 6.1 头痛

**常见原因:**
- 感冒发烧
- 偏头痛
- 紧张性头痛
- 高血压

**处理:**
```
1. 休息,避免刺激(光、声)
2. 按摩太阳穴
3. 热敷或冷敷(视何者有效)
4. 中药:
   - 川芎茶调散
   - 白芷煎汤
5. 物理方法无效→用药
```

### 6.2 牙痛

**应急处理:**
```
1. 温盐水漱口: 一杯温开水加半茶匙盐,含漱30秒,每天数次
2. 口服止痛药: 布洛芬或对乙酰氨基酚,按说明书
3. 用牙线或牙签轻轻剔除嵌塞的食物
4. 有肿胀时,在脸颊外侧冷敷15-20分钟(隔着毛巾)
5. 丁香油(如有): 棉签蘸极少量,轻点在痛牙上,不要大面积涂牙龈
6. 避免过冷、过热、过甜的食物,用另一侧咀嚼;睡觉时头部垫高

❌ 不要把大蒜、花椒、烟丝或药片(包括阿司匹林)敷在牙龈上或塞进牙洞
   → 会造成牙龈和口腔黏膜化学性烧伤、溃烂
❌ 不要热敷肿起来的脸(可能促使感染扩散)

根本: 治疗牙病!
```

详见[口腔问题-牙痛](../01-日常疾病和伤害/09-口腔问题.md#牙痛);面部或颈部肿胀、吞咽或呼吸困难是急症,见[牙脓肿与危险信号](../01-日常疾病和伤害/09-口腔问题.md#牙脓肿与危险信号)。下牙、下颌痛伴胸闷出汗,要想到心梗。

### 6.3 腹痛

**⚠️ 原因复杂,需鉴别!**

**危险征兆(可能需手术):**
- 持续剧烈腹痛
- 腹部僵硬(板状腹)
- 伴呕吐、发烧
- 无法排气、排便

**→ 可能是阑尾炎、肠梗阻、穿孔等,需外科处理!**

**一般腹痛:**
- 热敷
- 按摩腹部
- 中药: 保和丸、藿香正气散等

```
⚠️ 注意:
- 热敷、按摩只用于轻微、原因明确的腹痛(如受凉、吃撑、痛经);
  原因不明、越来越重的腹痛不要按揉
- 原因不明的腹痛不要吃布洛芬、阿司匹林(可能加重胃出血),也不要用泻药或灌肠
- 育龄女性下腹痛伴停经或阴道出血 → 想到宫外孕,立即就医
- 吃了止痛药好转,不等于没事;危险征兆出现时仍要就医
```

### 6.4 关节痛、肌肉痛

**处理:**
```
急性期(受伤后48小时内):
  - 冰敷: 隔毛巾,每次15-20分钟,每2-3小时一次;发麻就停
  - 制动
  - 抬高患肢

48小时后,肿胀稳定:
  - 热敷
  - 按摩
  - 活动关节

外用:
  - 中药药酒擦拭
  - 红花油(如有)
  - ⚠️ 活血类外用药一般在受伤48小时、肿胀稳定后再用;不涂在破损皮肤上

口服: 布洛芬对扭伤、肌肉痛通常比对乙酰氨基酚更有效(注意5.5的禁忌)
```

扭伤的完整处理见[骨骼损伤-RICE处理](../01-日常疾病和伤害/03-骨骼损伤.md#rice处理i-ii度)。

### 6.5 疼痛的非药物处理

止痛药不是唯一的办法。下面这些方法本身就能减轻很多疼痛,和止痛药一起用效果更好,在药品耗尽时更重要。

```
1. 找到并去掉诱因
   - 松开过紧的绷带、鞋子、腰带、戒指(手指受伤肿胀前先摘)
   - 扶正被压住或别扭的肢体
   - 清除牙缝里的食物
2. 休息和合适的体位
   - 四肢伤痛: 垫高到心脏水平以上
   - 腰背痛: 侧卧屈膝,或仰卧在膝下垫枕;
     急性腰痛一般不需要绝对卧床,能忍受就适当走动
   - 腹痛: 屈膝侧卧常更舒服
3. 冷与热
   - 冷: 新伤、肿胀、发红发热的部位;隔毛巾,每次15-20分钟,发麻就停
   - 热: 48小时后的肌肉僵硬、慢性酸痛、痛经;温热不烫手,隔布,每次15-20分钟
   - ⚠️ 老人、糖尿病人、感觉迟钝者和婴幼儿容易被冻伤或低温烫伤,
     时间要缩短、多检查皮肤;不要抱着热水袋或冰袋睡觉
   - ⚠️ 感染化脓、出血、肿胀正在加重的部位不要热敷
4. 固定
   - 怀疑骨折、脱臼时用夹板固定,本身就能明显减轻疼痛
5. 放松和转移注意力
   - 缓慢腹式呼吸: 吸气约4秒,呼气约6秒,持续几分钟
   - 听音乐、聊天、做手上的小事
   - 儿童: 大人抱着、讲故事、玩玩具,比单纯哄"不疼"更有效
6. 睡好、吃饱、喝够水: 疲劳、饥饿、焦虑都会让疼痛更明显
7. 温和活动和按摩
   - 慢性肌肉酸痛可以轻柔按摩、拉伸
   - ❌ 新伤、疑似骨折、单侧小腿红肿疼痛(可能是血栓)不要按摩
```

固定的方法见[骨骼损伤-紧急处理原则](../01-日常疾病和伤害/03-骨骼损伤.md#紧急处理原则)。

### 6.6 什么样的疼痛必须就医

| 疼痛表现 | 可能原因 | 怎么做 |
|------|------|------|
| 胸口压榨样痛,向左臂、下颌、后背放射,伴出汗、气短 | 心梗 | 立即拨打120 |
| 突发撕裂样胸背痛 | 主动脉夹层 | 立即拨打120,不要给阿司匹林 |
| 一生中最剧烈的突发头痛;头痛伴口角歪斜、肢体无力、说话不清 | 脑出血、中风 | 立即拨打120 |
| 头痛伴发烧、颈部僵硬、皮疹或意识改变 | 脑膜炎 | 立即拨打120 |
| 剧烈腹痛、腹部发硬、伴呕吐发烧、不能排气排便 | 阑尾炎、肠梗阻、穿孔 | 立即就医,暂时不吃不喝 |
| 育龄女性下腹痛伴停经或阴道出血;孕妇腹痛 | 宫外孕、流产、胎盘问题 | 立即就医 |
| 外伤后疼痛伴肢体变形、不能负重、手脚发麻发凉 | 骨折、血管神经损伤 | 固定后就医 |
| 单侧小腿红肿痛 | 深静脉血栓 | 尽快就医,不要按摩 |
| 腰背痛伴大小便失禁、会阴部发麻、双腿无力 | 神经受压 | 立即就医 |
| 腰侧剧痛伴发烧或尿血 | 肾结石、肾盂肾炎 | 尽快就医 |
| 牙痛伴面颈部肿胀、吞咽或呼吸困难 | 牙源性感染扩散 | 立即拨打120或去急诊 |

```
另外,下面这些情况也要就医:
- 止痛药按说明书用了5天还不缓解,或需要越用越多
- 疼痛在夜里把人痛醒、一天比一天重
- 疼痛伴持续发烧、体重不明原因下降
- 婴幼儿、老人和说不清楚的人: 哭闹不止、不让碰某个部位、
  某条胳膊或腿突然不肯动,都可能是严重疼痛的表现
```

胸痛的现场处理见[心脑血管与突发病症-心梗与胸痛](../01-日常疾病和伤害/06-心脑血管与突发病症.md#心梗与胸痛)。

## 七、药物储备建议

### 7.1 商业药品储备(末日前)

**解热镇痛药:**
- 对乙酰氨基酚(泰诺林): 儿童首选
- 布洛芬: 成人常用,也可儿童用
- 阿司匹林: 成人用,儿童禁用

**储存:**
- 密封、避光、干燥
- <25°C
- 有效期内

**轮换使用,避免过期!**

```
储备要点:
- 成人片剂和儿童剂型(混悬液、滴剂)分开备,儿童药不要用成人片掰着吃
- 同一种药的滴剂和混悬液浓度可能相差一倍以上,在瓶上用记号笔写清浓度
- 保留原包装和说明书: 剂量、成分、批号、有效期都在上面
- 不放在浴室、灶台边、车里(湿热会加速变质)
- 锁好,放在儿童拿不到的地方

判断药品能不能用:
- 片剂变色、受潮发软、粘连、碎裂 → 不用
- 阿司匹林闻到明显的醋酸味 → 已经分解,不用
- 儿童混悬液开封后按说明书规定的期限用完;
  结块、摇不匀、变色、有异味 → 丢弃
- 有在有效期内的药时,绝不用过期药
```

过期药在极端情况下的取舍见[抗生素制备-关于有效期](./02-抗生素制备.md#65-关于有效期)。

### 7.2 天然药材储备

**更推荐,可持续!**

**干品:**
- 柳树皮: 500 g
- 白芷: 200 g
- 川芎: 200 g
- 菊花: 500 g
- 薄荷: 200 g

**鲜品(可种植):**
- 生姜
- 大葱
- 薄荷
- 鱼腥草

## 八、常见问题

### Q1: 阿司匹林和对乙酰氨基酚哪个好?

**A: 各有优劣**

| 特性 | 阿司匹林 | 对乙酰氨基酚 |
|------|----------|--------------|
| 解热 | 强 | 强 |
| 镇痛 | 强 | 中 |
| 抗炎 | 有 | 无 |
| 胃刺激 | 大 | 小 |
| 儿童 | 禁用 | 可用 |
| 肝损伤 | 小 | 过量严重 |

**选择:**
- 儿童: 对乙酰氨基酚或布洛芬
- 成人: 都可以
- 胃不好: 对乙酰氨基酚
- 炎症性疼痛: 阿司匹林或布洛芬

### Q2: 可以同时用几种退烧药吗?

**A: 不要!**
- 增加副作用风险
- 也不推荐两种药"交替"使用: 容易算错次数和总量
- 一种药按说明书用了效果不满意: 等够间隔再用同一种;
  体温仍很高或病人状态差 → 就医,而不是再加一种药
- 绝不超量!
- 注意复方感冒药里常含对乙酰氨基酚或阿司匹林,算在总量里

### Q3: 发烧一定要吃药吗?

**A: 不一定!**
- 是否用药看体温和人的状态,标准见5.1
- 未达到用药标准、精神好、能喝水: 多喝水、休息即可,物理降温只作辅助
- 退烧的目的是让人舒服、能喝水能睡觉,不是把体温压回正常
- 3个月以下婴儿发烧: 不要自己用药,直接就医

### Q4: 柳树皮真的有效吗?

**A: 有效,但弱于阿司匹林**
- 阿司匹林就是从柳树皮衍生
- 天然水杨酸含量低
- 但安全、可持续
- 轻中度疼痛可用

### Q5: 退烧药会上瘾吗?

**A: 不会**
- 解热镇痛药不会成瘾
- 但不要滥用
- 治疗原发病最重要

## 九、现实建议

### 9.1 不要幻想自制化学药

**结论明确:**
- 阿司匹林: 理论可行,实际极难
- 对乙酰氨基酚: 不可能

**推荐:**
1. 末日前储备成品药
2. 学习使用天然药
3. 掌握发烧护理和用药原则(物理降温只作辅助)

### 9.2 优先级策略

**始终要做: 护理**
- 多喝水、休息、合适的衣物和室温
- 温水擦浴、冷敷等物理方法只作辅助,让人舒服即可
- 观察危险信号,该就医时就医

**Tier 1: 储备成品药**
- 对乙酰氨基酚、布洛芬等
- 效果可靠,需要用药时首选
- 但不可持续,所以要节约、轮换、防过期

**Tier 2: 天然药物**
- 柳树皮、白芷、生姜等
- 作用弱,适合低热和轻中度疼痛
- 可持续,但同样有禁忌

**Tier 4: 自制化学药**
- 几乎不可能
- 不推荐

### 9.3 预防为主

**减少发烧、疼痛的发生:**
- 增强体质
- 避免感染
- 及时处理小病
- 注意安全防止受伤

**不生病 = 最好的药!**
