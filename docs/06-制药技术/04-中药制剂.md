# 中药制剂

> **传统智慧 - 最安全可行的末日制药方向**

## ✅ 为什么推荐中药?

**相比化学制药的巨大优势:**

| 对比项 | 中药 | 化学药 |
|--------|------|--------|
| 原料获取 | ⭐⭐⭐⭐⭐野生采集 | ⭐化工原料难得 |
| 制备难度 | ⭐⭐简单 | ⭐⭐⭐⭐⭐极难 |
| 安全性 | ⭐⭐⭐⭐较高 | ⭐⭐风险高 |
| 经验积累 | ⭐⭐⭐⭐⭐数千年 | ⭐⭐现代技术 |
| 副作用 | ⭐⭐⭐⭐较小 | ⭐⭐较大 |
| 成功率 | ⭐⭐⭐⭐60-80% | ⭐⭐<20% |

**推荐作为末日制药的主要方向!**

上表的"安全性较高"只是和自制化学药相比。**"天然"不等于"无毒"**: 认错植物、超量、长期服用、和西药同用,都可能出事(见[六、安全注意事项](#六安全注意事项))。

```
本章的读法:
- 能储备成品药、能看医生时,优先储备和就医;
  本章是买不到药、找不到医生时的参考
- 本章写的用量是成人每日干品的常规范围,
  按2020版《中华人民共和国药典》,与药用植物章一致;
  只用来提醒"不要超量",具体用不用、用多少按中医师指导
- 儿童、老人、孕妇、哺乳期妇女、肝肾病人、
  长期吃西药的人,用前先问医生(见6.2-6.5)
- 用2-3天没有好转,或出现6.7列出的情况 → 就医,不要换方再拖
```

药材的识别、种植和单味用量见[药用植物识别与种植指南](../04-动植物培育/04-药用植物.md)。

## 一、常见症状对应中药

### 1.1 感冒发烧

#### 感冒初期(风寒感冒)

**症状:** 怕冷、流清涕、打喷嚏、无汗

**方剂:** 葱姜红糖汤
```
材料:
  - 葱白: 3-5根(带须)
  - 生姜: 5-8片
  - 红糖: 30 g
  - 水: 500 mL

制法:
  1. 水煮沸
  2. 加入葱姜
  3. 小火煎10分钟
  4. 加红糖溶化
  5. 趁热喝下
  6. 注意保暖,微微出汗即可,不要捂汗

用法: 每日2-3次
```

```
注意:
- "发汗"指微微出汗即可,出汗后擦干、换干衣服,不要大汗淋漓
- 婴幼儿和高热的人不要"捂汗",可能体温急升、脱水、抽搐
- 糖尿病人不加红糖或少加
- 喝了1-2天仍怕冷发热,或体温升到39°C以上 → 按发烧处理
```

见[发烧护理的常见误区](../01-日常疾病和伤害/01-常见疾病.md#发烧护理的常见误区)、[不同人群的发烧就医标准](../01-日常疾病和伤害/01-常见疾病.md#不同人群的发烧就医标准)。

**方剂:** 麻黄汤(经典)
```
材料:
  - 麻黄: 9 g
  - 桂枝: 9 g
  - 杏仁: 9 g
  - 甘草: 3 g

功效: 发汗解表
```

```
⚠️ 麻黄的警示:
- 麻黄含麻黄碱,会使心跳加快、血压升高、失眠
- 高血压、心脏病、甲亢、青光眼、前列腺增生排尿困难的人,
  以及孕妇、体虚多汗的人不要用
- 不和含伪麻黄碱的西药感冒药同用(成分叠加)
- 服后心慌、胸闷、头痛加重 → 停用;胸痛、心跳极快 → 拨打120
- 杏仁指苦杏仁,有小毒,不能超量,不能生嚼大量
```

#### 感冒中期(风热感冒)

**症状:** 发热、口渴、咽痛、流黄涕

**方剂:** 银翘散
```
材料:
  - 金银花: 15 g
  - 连翘: 15 g
  - 薄荷: 6 g(后下)
  - 牛蒡子: 9 g
  - 桔梗: 6 g
  - 甘草: 3 g

制法:
  1. 除薄荷外,其余药加水煎煮20分钟
  2. 最后5分钟加入薄荷
  3. 过滤取汁

用法: 每日2次,温服
```

**简易版:**
```
金银花10-15 g + 菊花5-10 g + 薄荷3-6 g
开水冲泡,加盖焖10分钟,一天内分几次喝完
```

用量按药典常规范围(金银花6-15 g、菊花5-10 g、薄荷3-6 g);对菊科植物过敏的人不用菊花。咽痛加重、张口困难、流口水咽不下,或高热不退,要就医。

### 1.2 消化问题

#### 食积腹胀

**方剂:** 保和丸
```
材料:
  - 山楂: 12 g(消食)
  - 神曲: 15 g(助消化)
  - 陈皮: 9 g(理气)
  - 茯苓: 12 g
  - 莱菔子: 9 g

制法: 煎汤服用
功效: 消食化积
```

**简易版:**
- 干山楂9-12 g泡水或煎水喝(胃酸多、胃溃疡的人少用)
- 生萝卜榨汁饮用

#### 腹泻

**方剂:** 藿香正气散
```
材料:
  - 藿香: 9 g
  - 紫苏叶: 9 g
  - 白芷: 9 g
  - 陈皮: 9 g
  - 厚朴: 9 g
  - 茯苓: 12 g
  - 甘草: 3 g

功效: 解表化湿,理气和中
适用: 胃肠型感冒、水土不服
```

**简易方:**
```
大蒜: 3-5瓣,捣烂
加红糖水送服
杀菌止泻
```

```
腹泻时最要紧的是补液,不是止泻:
- 先喝口服补液盐,或自配淡盐糖水,少量多次
- 大蒜、藿香类只能辅助;生大蒜刺激胃,胃病的人少吃
- 婴幼儿、老人腹泻,尿少、精神差、嘴唇干 → 尽快就医
- 便血、高热、剧烈腹痛、喝什么吐什么、
  一天腹泻十几次 → 立即就医
```

补液方法和就医标准见[腹泻](../01-日常疾病和伤害/01-常见疾病.md#腹泻)、[脱水症状识别](../01-日常疾病和伤害/01-常见疾病.md#脱水症状识别)。

### 1.3 外伤

#### 止血

**方剂:** 云南白药替代方
```
材料:
  - 三七: 30 g(研粉)
  - 白及: 20 g(研粉)
  - 仙鹤草: 15 g(研粉)
  - 龙骨: 15 g(煅,研粉)

制法:
  1. 各药分别炮制
  2. 研成极细粉
  3. 混匀
  4. 密封保存

用法:
  - 外用: 直接撒敷伤口
  - 内服: 每次1-3 g,一日2次,温水送服(跌打后的瘀肿)
```

```
⚠️ 止血的先后:
1. 先用干净布直接用力压住伤口,持续压10分钟以上不松手——
   这是止血的主要办法,药粉只是辅助
2. 能冲洗时先用干净水把伤口冲干净,再撒药粉、包扎
3. 深、大、喷血、压不住的伤口: 继续按压,拨打120或送医;
   不要往深伤口里塞药粉、草叶
4. 内出血(呕血、咳血、黑便、腹部外伤后腹痛、头部外伤后呕吐嗜睡)
   不能靠吃药粉止住,必须立即送医
5. 孕妇不内服三七;服抗凝药的人内服前先问医生
6. 三七只用确认的五加科三七,不要用"土三七"(菊三七),
   见药用植物章的有毒植物表
```

见[外伤处理-止血](../01-日常疾病和伤害/02-外伤处理.md#1-止血)、[清洁伤口](../01-日常疾病和伤害/02-外伤处理.md#2-清洁伤口)、[有毒植物(避免误用)](../04-动植物培育/04-药用植物.md#有毒植物避免误用)。

**野外应急:**
- 艾叶: 揉碎敷伤口止血
- 蒲公英: 捣烂敷伤口消炎
- 侧柏叶: 止血(鼻出血塞鼻)

```
野外应急的注意:
- 先按压止血、清水冲洗;没有别的东西时才用草叶,
  只敷在浅表的小伤口上,叶子先用干净水洗过、捣烂
- 生草叶带泥土和细菌,深伤口、被锈物或动物弄伤的伤口不敷,
  这类伤口要考虑破伤风、狂犬病预防,尽快就医
- 敷后每天换,伤口红肿热痛加重、流脓、出现红线、发热 → 就医
- 鼻出血: 先坐下、头略前倾,捏紧鼻翼10分钟,不要仰头;
  塞鼻的叶子要洗净、卷紧,露一截在外便于取出;
  捏压20分钟以上仍不止 → 就医
```

见[鼻出血](../01-日常疾病和伤害/00-基础急救知识.md#鼻出血)、[破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防)、[感染迹象](../01-日常疾病和伤害/02-外伤处理.md#-感染迹象立即就医)。

#### 消炎

**方剂:** 五味消毒饮
```
材料:
  - 金银花: 15 g
  - 野菊花: 15 g
  - 蒲公英: 15 g
  - 紫花地丁: 15 g
  - 紫背天葵: 15 g

制法: 煎汤服用
功效: 清热解毒,消痈散结
适用: 疮疖、皮肤感染
```

**外用:**
- 煎汤洗患处
- 或捣烂敷患处

```
注意:
- 只适合小的、局限的疮疖;这五味药都偏寒凉,
  脾胃虚寒、容易腹泻的人少用,连服一般不超过一周
- 不要自己挤压疮疖,尤其是鼻子和上唇周围("危险三角区")
- 出现以下情况要就医,可能需要切开排脓或使用抗生素:
  · 红肿范围一两天内明显扩大,或出现向心延伸的红线
  · 发热、寒战、精神差
  · 疮疖长在面部危险三角区,或直径超过约2 cm、有波动感(内有脓)
  · 糖尿病人、免疫力低下的人、婴幼儿的皮肤感染
```

伤口感染的判断见[外伤处理-感染迹象](../01-日常疾病和伤害/02-外伤处理.md#-感染迹象立即就医)、[全身感染的危险信号](../01-日常疾病和伤害/02-外伤处理.md#全身感染的危险信号立即拨打120)。

## 二、中药炮制方法

### 2.1 净制

**目的:** 去除杂质、非药用部分

**方法:**

**拣选:**
- 挑出杂质、霉变、虫蛀部分

**筛选:**
- 用筛子去沙土、碎屑

**风选:**
- 扬去轻质杂物(毛、叶)

**水洗:**
- 快速漂洗,勿浸泡(损失成分)

### 2.2 切制

**目的:** 便于煎煮、服用、调剂

**方法:**

**切片:**
- 厚度: 2-3 mm
- 药材: 生姜、白术、当归等

**切段:**
- 长度: 2-3 cm
- 药材: 麻黄、桂枝等茎枝类

**切丝:**
- 药材: 陈皮等

**捣碎:**
- 药材: 种子类(莱菔子、杏仁等)

### 2.3 炮制(改变药性)

#### 炒制

**清炒(干炒):**
```
方法:
  1. 热锅
  2. 药材倒入
  3. 不断翻动
  4. 炒至微黄或焦黄
  5. 取出摊凉

目的:
  - 缓和药性、降低寒性(如炒山楂、炒白术)
  - 增强健脾和胃的作用
  - 便于粉碎(炒后酥脆)

药材: 白术、黄芪、山药等
```

**麸炒:**
```
方法:
  1. 热锅,撒麦麸
  2. 冒烟时加药材
  3. 翻炒至黄色
  4. 筛去麦麸

目的: 缓和药性,健脾
药材: 苍术、枳壳等
```

**土炒:**
```
方法:
  1. 灶心土(或黄土)研细
  2. 热锅中炒热
  3. 加药材拌炒
  4. 筛去土

目的: 止泻,止血
药材: 白术等
```

#### 炙制

**蜜炙:**
```
方法:
  1. 蜂蜜加水稀释(蜜:水=1:1)
  2. 药材拌匀
  3. 闷润吸尽
  4. 文火炒至不粘手
  5. 取出摊凉

目的: 增强补益,润肺止咳
药材: 甘草、麻黄、百部等
```

**姜炙:**
```
方法:
  1. 生姜榨汁
  2. 药材拌姜汁
  3. 闷润
  4. 炒干

目的: 增强止呕,温中
药材: 半夏、厚朴等
```

#### 蒸煮

**蒸:**
```
方法:
  1. 药材放蒸笼
  2. 大火蒸透(筷子能扎透)
  3. 取出切片晒干

目的: 改变药性,增强补益
药材:
  - 何首乌: 生用通便,蒸熟补肝肾
  - 地黄: 蒸熟成"熟地"补血
```

**煮:**
```
目的: 降低毒性
药材: 附子、川乌等(剧毒,需久煮)
```

⚠️ **附子、川乌、草乌不要自己炮制、自己煎服**: 去毒是否到位,家庭条件下无法判断;煮的时间、块的大小、品种和产地不同,毒性相差很大,中毒后可在几十分钟内出现口舌和四肢麻木、心律失常、心跳骤停。末日条件下也不值得冒这个险——本章的常见病用不到它们。见[有毒中药](#66-有毒中药)。

#### 煅制

**明煅:**
```
方法:
  1. 药材直接放火上
  2. 烧至红透
  3. 取出放凉

目的: 增强收敛、止血
药材: 龙骨、牡蛎、石膏等
```

**煅淬:**
```
方法:
  1. 药材烧红
  2. 立即投入液体(醋/酒/水)
  3. 取出干燥
  4. 重复7次(七煅七淬)

目的: 质地酥脆,易粉碎
药材: 自然铜等
```

煅制要几百摄氏度的高温,注意烫伤和炭火一氧化碳中毒,在通风处操作;烧红的药材投入液体时会剧烈溅射,人站在侧面、戴护目和手套。

## 三、中成药的简易制作

### 3.1 丸剂

**水丸:**
```
方法:
  1. 药材研成细粉
  2. 加水或药汁做黏合剂
  3. 制成小丸(绿豆大小)
  4. 阴干

优点: 简单
缺点: 易霉变,不易保存
```

**蜜丸:**
```
方法:
  1. 药粉过筛(极细)
  2. 蜂蜜加热炼制(去泡沫)
  3. 药粉:蜜 = 1:1-1.5(重量)
  4. 混合均匀
  5. 搓成条,切段
  6. 搓圆成丸

大小:
  - 大蜜丸: 9-15 g/丸
  - 小蜜丸: 绿豆大小

保存: 蜡纸包裹,防潮
保质期: 1-2年

优点: 保存久,补益药多用
```

### 3.2 散剂

```
方法:
  1. 药材分别炮制
  2. 干燥
  3. 分别研粉
  4. 过筛(100目以上)
  5. 按配方混合均匀

用法:
  - 内服: 温水送服,3-6 g/次
  - 外用: 撒敷患处

保存: 密封,防潮
保质期: 6个月-1年

优点: 简单,快速,吸收快
缺点: 不易保存
```

### 3.3 膏药(外用)

**黑膏药(传统):**
```
材料:
  - 药材: 500 g
  - 麻油/植物油: 1000 mL
  - 黄丹(四氧化三铅): 500 g
  - 松香: 100 g

方法:
  1. 药材浸油3-7天
  2. 熬煮至药枯(焦黑)
  3. 去渣,油温降至120°C
  4. 缓慢加入黄丹,不断搅拌
  5. 煎熬至"滴水成珠"(测试: 油滴入水中成珠,不散)
  6. 离火,加松香
  7. 倒入水中,反复揉搓去火毒
  8. 搓成条,备用

使用:
  1. 取一段加热软化
  2. 摊在布/纸上
  3. 贴患处

⚠️警告: 黄丹含铅,有毒!孕妇禁用!
```

⚠️ **不建议家庭制作黑膏药**: 熬油到几百摄氏度容易起火(油锅着火盖锅盖灭,不能泼水);加黄丹时产生含铅的烟雾,吸入和沾手都会造成铅中毒,儿童尤其敏感,铅中毒的损害(贫血、腹痛、神经和智力损伤)很难逆转。需要外用膏时,用下面不含铅的简易膏药。含黄丹的成品膏药也不要贴在破损皮肤上,儿童、孕妇不用。

**简易膏药:**
```
材料:
  - 药材粉: 100 g
  - 蜂蜜: 200 g
  - 凡士林/猪油: 100 g

方法:
  1. 蜂蜜加热
  2. 加入药粉搅匀
  3. 加入油脂
  4. 小火熬成膏状
  5. 冷却装瓶

用法: 涂抹患处
保存: 冷藏,3-6个月
```

### 3.4 酊剂(药酒)

```
方法:
  1. 药材粗碎
  2. 装入容器(70%满)
  3. 加入酒精度50-70%vol的白酒或酒精
  4. 密封
  5. 室温浸泡14-30天,每日摇晃
  6. 过滤装瓶

用法:
  - 内服: 10-30 mL/次,一日2-3次
  - 外用: 擦涂患处

常用配方:
  - 舒筋活血酒: 当归、川芎、红花、乳香等
  - 补肾酒: 枸杞、淫羊藿、肉苁蓉等
  - 跌打酒: 三七、骨碎补、土鳖虫等

保存: 密封,阴凉处,1-2年
```

```
⚠️ 药酒的安全:
- 外用的跌打酒、舒筋酒(含乳香、红花、土鳖虫等)只擦不喝,
  瓶上写明"外用",与内服的分开放
- 不要用乌头、附子、马钱子、雷公藤、曼陀罗泡酒,
  这类药酒中毒的报告很多,一口就可能致命
- 内服按上面的量,不要当酒喝;一天的酒精总量也要算进去
- 不能喝药酒的人: 孕妇、哺乳期妇女、儿童、肝病患者、
  要开车或操作机器的人、酒精过敏的人
- 正在服用头孢类抗生素、甲硝唑、替硝唑的人,
  用药期间和停药后约一周内不能喝含酒精的东西(包括药酒),
  可引起面红、心慌、呼吸困难、血压下降,严重的可致命
- 服镇静安眠药、抗过敏药、降糖药的人也不喝药酒
- 泡药的酒要用合格的粮食酒或医用乙醇;
  工业酒精、来路不明的散装酒可能含甲醇,会致盲致死
```

酒精和甲醇中毒见[中毒-酒精中毒](../01-日常疾病和伤害/12-中毒.md#酒精中毒)、[假酒(甲醇)中毒](../01-日常疾病和伤害/12-中毒.md#-假酒甲醇中毒)。

## 四、常用中药材识别与采集

这里只列简要特征。详细的识别对比、种植、采收加工,以及**容易和它们认错的有毒植物**,见[药用植物识别与种植指南](../04-动植物培育/04-药用植物.md)和其中的[有毒植物(避免误用)](../04-动植物培育/04-药用植物.md#有毒植物避免误用)。**不能100%确认的植物不采不用。**

### 4.1 全年可采

#### 蒲公英

**识别:**
- 叶: 羽状深裂,锯齿缘
- 花: 黄色,头状花序
- 果: 白色绒球(蒲公英降落伞)
- 根: 圆锥形,黄褐色

**采集:** 全草,春秋采挖

**功效:** 清热解毒,消痈散结
- 乳腺炎、扁桃体炎
- 尿路感染
- 外用治疮疖

**用法:**
- 鲜品: 捣烂敷患处
- 干品: 煎汤,10-15 g(按药典/中医师指导)

#### 艾叶

**识别:**
- 叶: 羽状深裂,背面灰白色绒毛
- 气味: 特异香气
- 高度: 50-120 cm

**采集:** 端午前后最佳

**功效:**
- 温经止血
- 散寒止痛
- 外用止血

**用法:**
- 煎汤: 3-9 g(按药典/中医师指导;艾叶有小毒,内服不超量、不长期服)
- 外用: 捣烂敷,或烟熏
- 艾灸: 制成艾条

#### 车前草

**识别:**
- 叶: 基生,卵形,有平行脉
- 花: 穗状花序
- 生境: 路边、田埂

**采集:** 全草

**功效:** 利尿通淋,清热解毒

**用法:** 煎汤,9-30 g(按药典/中医师指导);利尿,服锂盐、利尿药的人先问医生

### 4.2 春季采集

#### 金银花

**识别:**
- 藤本植物
- 花: 初开白色,后变黄(金银相映)
- 气味: 清香

**采集:** 花蕾,5-7月

**功效:** 清热解毒,疏散风热
- 感冒发热
- 咽喉肿痛
- 疮疖

**用法:** 煎汤或泡茶,6-15 g(按药典/中医师指导);注意与有毒的钩吻(断肠草)区分

#### 桑叶

**识别:**
- 叶: 卵形,边缘锯齿
- 来源: 桑树

**采集:** 初霜后(霜桑叶更佳)

**功效:** 疏散风热,清肝明目

**用法:** 煎汤,5-10 g(按药典/中医师指导)

### 4.3 秋季采集

#### 菊花

**识别:**
- 花: 头状花序,黄色或白色
- 气味: 清香

**采集:** 花盛开时

**功效:** 疏散风热,清肝明目

**用法:** 泡茶或煎汤,5-10 g(按药典/中医师指导);对菊科植物过敏的人不用

#### 山楂

**识别:**
- 果实: 红色,球形
- 树: 落叶乔木,有刺

**采集:** 秋季果熟

**功效:** 消食化积,活血化瘀

**用法:** 煎汤,9-12 g(按药典/中医师指导),或作为水果少量生食;胃酸多、胃溃疡的人少用

### 4.4 根茎类(秋冬采)

#### 生姜

**识别:** 根茎,黄褐色,断面淡黄

**功效:** 解表散寒,温中止呕

**用法:**
- 感冒: 3-10 g(约几片)煎汤(按药典/中医师指导)
- 止呕: 取下限,切几片煎汤或含服

#### 当归

**识别:**
- 根: 圆柱形,有浓郁香气
- 生境: 高山地区

**功效:** 补血活血,调经止痛

**用法:** 煎汤,6-12 g(按药典/中医师指导);孕妇、月经量多、腹泻的人慎用,服华法林等抗凝药的人不用

## 五、中药煎煮方法

### 5.1 器具选择

**最佳:**
- 砂锅、陶罐(不与药物反应)

**可用:**
- 不锈钢锅
- 搪瓷锅

**禁用:**
- 铁锅、铝锅(与药物反应)
- 铜锅

```
为什么不用铁锅、铝锅、铜锅:
- 很多药材含鞣质、有机酸,和铁反应后药液发黑、变涩,成分改变
- 酸性药液会溶出铝、铜,长期喝对身体不利
- 没有砂锅时: 不锈钢锅、搪瓷锅(瓷面无破损)都可以;
  自烧的陶罐要先装清水煮一次,确认不漏、不掉釉渣
- 新砂锅先用米汤或清水煮一次,减少开裂;
  热锅不要放在冷湿的地面上,不要空烧
- 煎药的锅最好专用,用后洗净晾干,
  不要和做饭的锅混用(尤其是煎过有毒药材的)
```

### 5.2 煎煮步骤

**标准煎法:**

```
1. 浸泡:
   - 药材放锅中
   - 加冷水没过药材3-5 cm
   - 浸泡30分钟(种子类1-2小时)

2. 煮沸:
   - 大火煮沸

3. 文火慢煎:
   - 沸后转小火
   - 解表药: 15-20分钟
   - 一般药: 25-30分钟
   - 滋补药: 40-60分钟

4. 二煎:
   - 药渣加水再煎20-30分钟

5. 合并药液:
   - 两次药液混合
   - 总量约400-600 mL
   - 分2-3次服用
```

**特殊煎法:**

**先煎:**
- 矿物、贝壳类(石膏、龙骨等)
- 提前30分钟下锅

**后下:**
- 芳香药(薄荷、藿香等)
- 最后5-10分钟下锅

**包煎:**
- 细小种子、花粉类
- 用纱布包裹煎煮

**另煎:**
- 贵重药(人参等)
- 单独煎2-3小时,取汁兑入

#### 加水量和煎出量

```
一剂药一般煎两次,一天喝完:
- 头煎: 加水没过药材3-5 cm;花叶类、质地松泡的药材吸水多,
  水面要高一些(约5 cm);一剂药一般加水约600-800 mL
- 二煎: 加水没过药渣2-3 cm
- 每次煎到约150-300 mL(大约一碗),两次合并
- 儿童的药煎得更浓、量更少,便于喂服;
  儿童剂量见6.3,不要自己估算
- 中途发现水快煎干: 可以补少量开水,不要补冷水
  (骤冷影响成分溶出,砂锅也容易炸裂)
```

#### 怎样判断煎对了

```
✓ 药液颜色均匀,有该药的气味,没有焦糊味
✓ 药渣煎透: 根茎类掰开中心没有干芯
✓ 煎出的量和上面的范围差不多;太少说明火太大或时间太长
❌ 煎焦、煎糊: 整锅倒掉,不要加水再煎——
   焦糊的药液可能有害,药性也变了
❌ 药液里有霉味、异味,药材本身有霉点: 不要喝
❌ 用开水直接浸泡后马上煎,或大火一直猛煮: 成分不易煎出
```

### 5.3 服用方法

**温服:**
- 一般药,温热服用

**热服:**
- 风寒感冒药
- 发汗解表

**冷服:**
- 清热药(夏季)
- 止吐药

**时间:**
- 饭前: 补益药
- 饭后: 消食药、刺激性药
- 睡前: 安神药

#### 药液的保存与服用期限

```
- 最好当天煎、当天喝完;一剂药不要分成几天喝
- 暂时不喝的药液放凉后加盖,有冰箱放冷藏,
  一般不超过1-2天;没有冰箱时当天喝完
- 再次服用前加热到温热(隔水加热或小火加热到微沸)
- 药液变酸、起泡、发霉、有异味 → 倒掉
- 一个方子一般先吃2-3剂看效果:
  好转可以按原方再吃几剂;没有好转或加重 → 停药就医
- 服药期间饮食清淡,少吃生冷油腻辛辣;
  服用解表发汗药后避免吹风受凉
- 服药后出现皮疹、瘙痒、腹痛腹泻、心慌、头晕、
  口舌或四肢麻木 → 停药,情况重的立即就医(见6.6)
```

- 藜芦 反 人参、沙参、丹参、玄参、细辛、芍药

**十九畏(避免同用):**
- 硫磺 畏 朴硝
- 水银 畏 砒霜
- 狼毒 畏 密陀僧
- 巴豆 畏 牵牛子
- 丁香 畏 郁金
- 川乌、草乌 畏 犀角
- 牙硝 畏 三棱
- 官桂 畏 石脂
- 人参 畏 五灵脂

**原则: 不清楚不要混用!**

### 6.2 孕妇禁忌

**绝对禁用(剧毒或堕胎):**
- 巴豆、牵牛子、大戟
- 斑蝥、商陆、麝香
- 水蛭、虻虫、三棱、莪术
- 乌头、附子

**慎用:**
- 活血类: 红花、桃仁、牛膝
- 通便类: 大黄、芒硝、番泻叶
- 理气类: 枳实、枳壳

**安全药:**
- 党参、黄芪、白术
- 当归、熟地(小量)
- 陈皮、砂仁

```
孕期用药的补充:
- "安全药"是相对的,孕期用任何中药都要有中医师或医生指导;
  怀孕头3个月尽量不用药
- 本章出现过、孕妇要避开的还有: 三七(内服)、麻黄、
  山楂(大量)、药酒、含黄丹的膏药
- 哺乳期妇女: 多数药物会进入乳汁,用药前问医生;
  大麦芽、炒麦芽可能减少乳汁
- 孕期出现阴道流血、腹痛、头痛眼花、浮肿加重、胎动减少 → 立即就医,
  不要靠"安胎"草药拖延
```

### 6.3 儿童用药

**剂量:** 见[基础制药知识-成人vs儿童剂量](./00-基础制药知识.md#23-成人vs儿童剂量);那里的公式只是粗略估算,儿童用中药最好由医生定量

**禁用:**
- 含重金属药(朱砂、雄黄)
- 有毒药(附子、半夏等)

**首选:**
- 温和药物
- 食疗为主

```
补充:
- 3岁以下不要自行用中药;婴儿不要用草药水代替喂奶和补液
- 儿童同样不用: 麻黄(心跳加快)、药酒、苦杏仁(易中毒)、
  含黄丹的膏药、来路不明的"小儿惊风散""保婴丹"类成药
  (有的含朱砂、铅等重金属)
- 中药苦,孩子吐出一部分不要立刻补喂一整份,以免过量
- 药材、药酒、药粉放在孩子拿不到的地方
- 儿童病情变化快: 高热、精神差、呼吸急促、
  尿少、抽搐 → 立即就医,不要等中药起效
```

儿童发热、腹泻、咳嗽的就医标准见[不同人群的发烧就医标准](../01-日常疾病和伤害/01-常见疾病.md#不同人群的发烧就医标准)、[婴幼儿、老人和孕妇腹泻](../01-日常疾病和伤害/01-常见疾病.md#婴幼儿老人和孕妇腹泻)、[儿童咳嗽和呼吸急促的判断](../01-日常疾病和伤害/01-常见疾病.md#儿童咳嗽和呼吸急促的判断)。

### 6.4 其他需要先问医生的人群

除孕妇和儿童外,下面这些人用任何中药(包括泡茶、药酒、药膳)之前都要先问医生:

| 人群 | 为什么 | 本章中要特别注意的药 |
|------|--------|-----------------|
| 老人 | 肝肾功能减退,常同时吃多种药,容易蓄积和相互作用 | 用量取下限;麻黄、药酒 |
| 肝病、肾病患者 | 多数药物经肝代谢、肾排出;部分草药本身伤肝肾 | 何首乌、含马兜铃酸的药、药酒 |
| 高血压、心脏病患者 | 有的药升高血压、加快心率 | 麻黄、甘草(长期大量) |
| 糖尿病人 | 方中常加红糖、蜂蜜,蜜丸含糖多 | 葱姜红糖汤、蜜丸、蜜炙药 |
| 过敏体质 | 尤其对菊科植物过敏的人 | 菊花、野菊花、蒲公英、艾叶 |
| 准备手术、拔牙的人 | 活血药增加出血 | 三七、当归、红花、桃仁、川芎;提前停用并告诉医生 |
| 长期服用西药的人 | 可能相互作用 | 见6.5 |

更详细的说明见[药用植物-用药安全](../04-动植物培育/04-药用植物.md#用药安全)。

### 6.5 与西药同用

```
要点:
- 长期服用降压药、降糖药、抗凝药(华法林)、抗血小板药(阿司匹林、
  氯吡格雷)、地高辛、利尿药、激素、抗癫痫药、免疫抑制剂的人,
  用中药前先问医生或药师
- 不要因为开始喝中药就自己减少或停掉西药
- 中药和西药一般间隔1-2小时服用,
  但这只能减少一部分相互影响,不能消除风险
- 很多中成药里加了西药成分: 例如一些感冒类中成药含
  对乙酰氨基酚、氯苯那敏,再和西药感冒药、退烧药一起吃
  会造成同一成分过量(对乙酰氨基酚过量可致肝衰竭);
  吃之前看说明书的"成分"一栏
- 服头孢类、甲硝唑期间不喝药酒(见3.4)
- 就医时把在吃的中药、药酒、保健品都告诉医生,
  写进用药信息卡
```

具体哪些草药和哪些西药相冲,见[药用植物-与西药同用的提醒](../04-动植物培育/04-药用植物.md#与西药同用的提醒);用药信息卡和不能突然停的药见[慢性病用药储备](../01-日常疾病和伤害/08-慢性病用药储备.md#突然停药最危险的几类药)。

### 6.6 有毒中药

本章和常见偏方里会遇到的有毒药材,**家庭条件下都不要自己炮制、自己配用**:

| 药材 | 主要风险 | 要点 |
|------|---------|------|
| 附子、川乌、草乌 | 乌头碱,心律失常、心跳骤停 | 炮制和煎煮是否去毒无法判断;不泡酒、不炖肉 |
| 马钱子 | 抽搐、呼吸麻痹 | 治疗量和中毒量非常接近 |
| 雷公藤 | 肝肾、血液、生殖毒性 | 只能在医生监测下用 |
| 生半夏、生天南星 | 口舌喉咙剧烈麻木灼痛,喉头水肿 | 只用药店的炮制品,按处方 |
| 苦杏仁、桃仁 | 含氰苷,过量可致呼吸困难、昏迷 | 不超量,不生嚼大量,儿童不用 |
| 朱砂、雄黄、黄丹(含汞、砷、铅) | 重金属中毒,损害难以逆转 | 不内服,不给儿童用;不自制含黄丹的膏药 |
| 关木通、广防己、青木香、马兜铃 | 马兜铃酸致肾衰竭和癌症 | 不自采名称里有"木通""防己"的植物 |
| 何首乌(尤其生首乌) | 肝损伤 | 不长期自服,肝病患者不用 |
| 细辛 | 毒性较大 | 用量很小,按处方 |
| 商陆、曼陀罗(洋金花)、甘遂、大戟、芫花、巴豆、斑蝥 | 剧毒或峻泻 | 不用 |

```
中毒的信号(服药后几分钟到几小时出现):
- 口舌、手脚发麻,心慌,心跳很慢或很乱 → 乌头类中毒的典型表现
- 剧烈呕吐、腹痛腹泻
- 头晕、视物模糊、说胡话、抽搐、昏迷
- 呼吸困难、喉咙发紧、嘴唇发紫

出现这些情况:
1. 立即停药,拨打120或尽快送医
2. 带上剩下的药材、药渣、药液或拍照,告诉医生吃了什么、多少、何时吃的
3. 没有反应、没有呼吸 → 心肺复苏
❌ 不要用绿豆汤、甘草水等偏方"解毒"后在家观察
```

常见有毒植物的辨认见[药用植物-有毒植物(避免误用)](../04-动植物培育/04-药用植物.md#有毒植物避免误用);处理见[误食有毒植物怎么办](../04-动植物培育/04-药用植物.md#误食有毒植物怎么办)、[中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则)。

### 6.7 什么时候必须就医

中药适合轻症和调理。下面这些情况**不要靠中药拖延**,尽快就医或拨打120:

| 情况 | 可能的原因 | 怎么做 |
|------|-----------|--------|
| 胸痛、呼吸困难、一侧肢体无力或口角歪斜、突然剧烈头痛 | 心梗、肺栓塞、中风 | 立即拨打120 |
| 高热不退,或伴颈部发硬、皮肤出血点、意识不清 | 严重感染、脑膜炎 | 立即就医 |
| 婴儿发热,或儿童精神差、呼吸急促 | 儿童病情进展快 | 立即就医 |
| 腹泻、呕吐伴尿少、精神差,或便血、黑便 | 脱水、消化道出血 | 尽快就医 |
| 剧烈腹痛,尤其右下腹痛、腹部发硬 | 阑尾炎等急腹症 | 立即就医,不要吃泻药 |
| 伤口深、出血压不住、动物咬伤、被锈物扎伤 | 大出血、狂犬病、破伤风 | 尽快就医打针 |
| 疮疖红肿扩大、出现红线、发热寒战 | 感染扩散 | 尽快就医 |
| 咳嗽、咳痰超过2周,或痰中带血,伴低热、夜间出汗、消瘦 | 肺结核等 | 就医检查 |
| 服药后皮疹、嘴唇舌头肿、喉咙发紧 | 过敏 | 停药;呼吸困难时拨打120 |
| 服药后口舌发麻、心慌、抽搐 | 中毒 | 立即拨打120(见6.6) |
| 用药2-3天没有好转,或越来越重 | 方不对证或病情较重 | 停药就医 |

各类急症的判断见[急性症状](../01-日常疾病和伤害/05-急性症状.md)、[心脑血管与突发病症](../01-日常疾病和伤害/06-心脑血管与突发病症.md)。

## 七、常见问题

### Q1: 中药一定要按方抓药吗?

**A: 不一定**
- 常见病: 单味药也很有效
  - 感冒: 生姜、葱白即可
  - 消化不良: 山楂、陈皮
  - 外伤: 三七、白及
- 复杂病: 需配伍增效

### Q2: 中药有副作用吗?

**A: 有,但相对较小**
- 毒性药: 家庭条件下不用(见6.6)
- 一般药: 按常规剂量、短期使用,多数较安全;
  认错药材、超量、长期服用、和西药同用时风险明显增加
- 药食同源: 按平常食用量一般安全,但长期大量也会出问题
  (例如甘草可致血压升高、低血钾)

**原则: 是药三分毒!**

### Q3: 煎煮时间越长越好?

**A: 不是**
- 解表药: 久煎损失挥发油
- 滋补药: 需久煎充分提取
- 一般: 25-30分钟
- 煎得太久: 药液少而浓、容易煎焦,焦了就倒掉(见5.2)

### Q4: 可以用电热杯煎药吗?

**A: 不理想,但应急可用**
- 最好用砂锅文火
- 电热杯温度难控制
- 容易煎焦

### Q5: 中药可以替代西药吗?

**A: 视情况而定**
- 轻症常见病(普通感冒、轻度消化不良): 多数可以先用中药和食疗
- 急危重症: 必须就医,西药和手术更快更可靠(见6.7)
- 慢性病: 高血压、糖尿病、心脏病、癫痫等长期用的西药不能用中药替代,
  也不要自行停药;中药只能作为调理和辅助
- 感染: 抗生素更可靠,中药辅助;细菌感染加重时不要只靠中药

**末日建议: 中西结合!**

- 补益: 人参、党参、枸杞、熟地、白术、茯苓

- 外用: 白及、乳香、没药

```
储备的提醒:
- 优先储备家人能用的成品药(退烧药、口服补液盐、
  慢性病长期用药),中药材是补充,不是替代
- 进阶清单里麻黄、杏仁、桃仁、红花等有明确禁忌,
  用前看6.2-6.6;麻黄在我国凭处方限量销售
- 有毒药材不列入家庭储备
```

### 8.3 药材的储存与有效期

药材储存不好,轻则失效,重则发霉产生毒素(如黄曲霉毒素,煮不掉)。

```
怎样存:
1. 入库前晒干或阴干: 干到折断时清脆、不发软
   (花叶类阴干,避免暴晒散失香气)
2. 分装: 每种药材单独装袋或装罐,
   用陶罐、玻璃罐、铁皮罐加盖,或厚塑料袋扎紧口
3. 贴标签: 名称、来源(自采/购买)、采收或购买日期
4. 放阴凉、干燥、避光处,离地离墙;
   相对湿度高的季节(梅雨季、南方回南天)每月检查一次
5. 防虫: 罐内可放少量花椒;发现虫蛀的单独处理
6. 有毒药材、药酒、药粉: 单独存放,明确标注,上锁或放高处,
   儿童拿不到
```

| 类别 | 一般保存期(干燥密封) | 容易出现的问题 |
|------|------------------|--------------|
| 花、叶类(金银花、菊花、薄荷、艾叶) | 约1年 | 变色、香气散失、受潮发霉 |
| 根、根茎类(当归、黄芪、甘草) | 约1-2年 | 虫蛀、"泛油"(表面发黏发暗) |
| 果实、种子类(山楂、枸杞、杏仁) | 约1年 | 泛油、发霉、虫蛀;种子类易哈喇 |
| 药粉(散剂) | 6个月-1年 | 吸潮结块、发霉 |
| 蜜丸 | 1-2年 | 发霉、变硬 |
| 水丸 | 较短,需充分干燥 | 发霉 |
| 药酒 | 1-2年 | 浑浊、沉淀异常、异味 |

```
有下列情况的药材不要用:
❌ 发霉: 有霉点、霉味、长白毛或绿毛——整袋丢掉,不要挑出来洗洗再用
❌ 严重虫蛀、成粉末
❌ 明显泛油、发黏、有哈喇味
❌ 颜色、气味和原来明显不同
❌ 标签丢失、认不出是什么药
放久了的药材有效成分会下降,但不能靠"加量"弥补——
超量带来的风险比失效更大。
```

食物干燥储存和黄曲霉毒素见[食物加工与保存-晒干与风干](../07-日常生活技能/01-食物加工与保存.md#晒干与风干)、[黄曲霉毒素](../07-日常生活技能/01-食物加工与保存.md#黄曲霉毒素)。
