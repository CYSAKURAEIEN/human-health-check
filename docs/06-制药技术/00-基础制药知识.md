# 基础制药知识

> **制药入门 - 安全第一,生命至上**

## ⚠️ 再次警告

**制药不是游戏!**

- 一个错误 = 中毒或死亡
- 无法保证纯度 = 严重副作用
- 剂量计算错误 = 无效或致死

**仅在文明崩溃、医疗体系瓦解、生死攸关时使用!**

## 一、基础化学概念

### 1.1 物质分类

**元素:**
- 氢(H)、氧(O)、碳(C)、氮(N)等
- 不能再分解的基本物质

**化合物:**
- 水(H₂O)、乙醇(C₂H₅OH)、食盐(NaCl)
- 由元素组成

**混合物:**
- 空气、溶液、药液
- 多种物质混合

### 1.2 酸碱盐

**酸(pH<7):**
- 例: 盐酸(HCl)、醋酸(CH₃COOH)
- 特征: 酸味,腐蚀性
- 用途: 溶解、中和

**碱(pH>7):**
- 例: 烧碱(NaOH)、石灰水(Ca(OH)₂)
- 特征: 苦涩,滑腻感,腐蚀性
- 用途: 中和、皂化

**盐:**
- 例: 食盐(NaCl)、苏打(Na₂CO₃)
- 酸+碱 → 盐+水

### 1.3 浓度计算

**质量百分比浓度:**
```
浓度(%) = (溶质质量/溶液总质量) × 100%

例: 10%盐水
  = 10 g盐 + 90 g水
  = 100 g溶液
```

**体积百分比浓度:**
```
浓度(%) = (溶质体积/溶液总体积) × 100%

例: 75%酒精(医用酒精按体积计,即75%vol)
  = 75 mL乙醇,加水至总体积100 mL
  (乙醇和水混合后体积会略缩小,所以不是简单的"75 mL + 25 mL")
```

**质量体积浓度(固体溶在液体里,药品标签最常见):**
```
浓度 = 溶质质量/溶液总体积

例: 0.9%生理盐水 = 每100 mL含0.9 g氯化钠(即9 g/L)
例: 2%碘酒 = 每100 mL含2 g碘(碘是固体,不能按"mL碘"计)
药品标签上的"100 mg/5 mL""0.5%"多属这一类
```

**稀释计算(重要!):**
```
公式: C₁V₁ = C₂V₂
C₁ = 原浓度
V₁ = 原体积
C₂ = 目标浓度
V₂ = 目标体积

例: 95%酒精稀释成75%
已知: C₁=95%, C₂=75%, V₂=100 mL
求V₁: V₁ = C₂V₂/C₁ = 75×100/95 ≈ 79 mL
即: 79 mL 95%酒精 + 21 mL水 = 100 mL 75%酒精
```

## 二、剂量与用量

### 2.1 剂量单位

| 单位 | 符号 | 换算 |
|------|------|------|
| 克 | g | 1 g |
| 毫克 | mg | 1 g = 1000 mg |
| 微克 | μg | 1 mg = 1000 μg |
| 毫升 | mL | 液体体积 |

**常用估算:**
- 1 g ≈ 一个回形针重量
- 1 mL ≈ 20滴液体
- 1茶匙 ≈ 5 mL
- 1汤匙 ≈ 15 mL

⚠️ 这些只是粗略估算,误差可达百分之几十,不能用来量取作用强的药。原因和更可靠的做法见下面的2.4。

### 2.2 治疗窗

```
[剂量-效果图]

致死量 --------☠️ (危险!)
         ↑
中毒量 --------⚠️
         ↑
有效量上限 ----✓ ← 治疗窗(安全范围)
         ↑
有效量下限 ----✓
         ↑
无效量 --------✗
```

**关键原则:**
- 剂量过小: 无效
- 剂量适中: 治疗
- 剂量过大: 中毒/死亡

**安全用药:**
- 从最小有效量开始
- 逐步增加
- 密切观察反应

```
补充:
- "逐步增加"只能在说明书或医嘱给出的范围内,绝不超过标明的
  单次最大量、每天最大量和最少间隔时间
- 效果不好时先想: 诊断对不对、药对不对症,而不是加量
- 治疗窗窄的药(如华法林、地高辛、某些抗癫痫药、降糖药),
  一点点偏差就可能出事,只能遵医嘱,不要自行调整
- 同一种成分可能藏在几种药里(如很多感冒药都含对乙酰氨基酚),
  几种药一起吃,加起来就可能超量 → 看清每种药的成分表
```

### 2.3 成人vs儿童剂量

**儿童剂量计算(粗略):**
```
方法1: 按体重
  儿童剂量 = 成人剂量 × (儿童体重kg/70)

方法2: 按年龄
  儿童剂量 = 成人剂量 × (年龄/(年龄+12))

例: 成人剂量100 mg,5岁儿童
  儿童剂量 = 100 × (5/(5+12)) ≈ 29 mg
```

⚠️ 上面两个公式是历史上的粗略换算,误差很大,只在完全没有儿童剂型和说明书时作为最后的参考:
- 优先用**儿童剂型**(滴剂、混悬液、颗粒),按说明书上的**体重**一栏给药;常用退烧药的剂量见[常见疾病-退烧药剂量速查](../01-日常疾病和伤害/01-常见疾病.md#退烧药剂量速查)
- 说明书写明"儿童禁用"或没有儿童用法的药,不能靠公式折算给孩子用(例如阿司匹林,儿童和青少年发热不用)
- 3个月以下婴儿发烧、生病,直接就医,不要自行用药;布洛芬用于6个月以上
- 体重比同龄孩子明显偏轻或偏重时,按体重算,不按年龄算

**特殊人群:**
- 老人: 剂量减少1/4-1/3
- 孕妇: 多数药物禁用!
- 肾/肝功能不全: 减量

```
补充:
老人
  - 肝肾功能随年龄下降,药在体内停留更久;"减量"指说明书或医生给出的
    老年用量,没有写明的从说明书的最低量开始
  - 同时吃的药多,相互作用和重复用药的风险大 → 每种药都记在用药信息卡上
  - 镇静、安眠、抗过敏(有嗜睡作用)的药容易引起头晕跌倒
孕妇和哺乳期
  - 任何药(包括中药、"天然"草药)用前先问医生
  - 发热、疼痛时,一般优先考虑对乙酰氨基酚;布洛芬、阿司匹林等
    在孕20周以后要避免,除非医生明确要求
  - 哺乳期用药同样会部分进入乳汁,看说明书的"哺乳期妇女用药"一栏
肝肾病人
  - 对乙酰氨基酚伤肝,布洛芬等伤肾,已有肝肾病的人用前要问医生
```

相关章节: [慢性病用药储备-用药信息卡](../01-日常疾病和伤害/08-慢性病用药储备.md#用药信息卡)。

### 2.4 剂量换算与称量误差

**最常见的错误是数量级错误,而不是小误差:**
```
mg 和 μg 看错 → 差1000倍
mg 和 g 看错   → 差1000倍
小数点错一位   → 差10倍(0.5 mg 写成 5 mg)
mg 和 mL 混为一谈 → 液体药一定要看浓度

防止办法:
✓ 写剂量时 μg 写成"微克",避免和 mg 混淆
✓ 小数前面一定写0: 写"0.5 mg",不写".5 mg"
✓ 整数后面不加小数: 写"5 mg",不写"5.0 mg"(容易被看成50)
✓ 算完让第二个人独立再算一遍,两人结果一致才用
✓ 结果和说明书常用量差了好几倍 → 一定是哪里算错了,停下来重算
```

**液体药: 从毫克换算成毫升**
```
要量取的体积(mL) = 需要的剂量(mg) ÷ 浓度(mg/mL)

例: 儿童混悬液标签写"100 mg/5 mL",即每mL含20 mg
    说明书按体重查得一次用150 mg
    → 150 ÷ 20 = 7.5 mL

步骤:
1. 确认浓度单位(同一种药的滴剂和混悬液浓度往往不同!)
2. 换算成每 mL 含多少 mg
3. 计算后和说明书上的毫升数对照
```

**量具的误差:**

| 量具 | 大致误差 | 能不能用来量药 |
|------|---------|---------------|
| 药盒附带的量杯、量勺、口服注射器 | 小 | ✓ 首选,按刻度用,不要换着用 |
| 带刻度的注射器(去掉针头,用作口服量具) | 小 | ✓ 量小体积液体最准 |
| 家用茶匙、汤匙 | 大小不一,可差20-50% | ✗ 不要用来量药 |
| 滴管数滴数 | 每 mL 15-25滴不等,因滴管和液体而异 | ⚠️ 只能用药品配套的滴管 |
| 用勺子量粉末 | 粉末轻重相差可达好几倍 | ✗ 不能代替称量 |
| 等臂天平 + 自制砝码 | 认真做可到千分之几,但只在克以上 | ⚠️ 毫克级做不到 |

**片剂能不能掰开、磨碎:**
```
✓ 有刻痕的普通片,说明书允许的,可以沿刻痕掰开
✗ 缓释片、控释片、肠溶片(名字或说明书里有"缓释""控释""肠溶")
  不能掰、不能嚼、不能磨碎 → 药一下子全部释放,可能中毒或伤胃
✗ 没有刻痕的小片掰开,两半的含量可能差别很大
```

**没有精确称量工具时:**
- 尽量用保存下来的成品药,按原包装上的规格(每片多少 mg)给药,这比任何自制称量都可靠
- 毫克级的药物不要尝试自己称量;自制天平和砝码的做法、能达到的精度和误差来源,见[计量基准的重建-影响精度的因素](../08-基础科学知识/09-计量基准的重建.md#41-影响精度的因素)和[能做到多准](../08-基础科学知识/09-计量基准的重建.md#43-能做到多准)
- 天平可以用未开封的包装食品、药品的净含量来核对,见[计量基准的重建-质量和容积](../08-基础科学知识/09-计量基准的重建.md#62-质量和容积)

## 三、提取与纯化技术

### 3.1 水提取法(煎煮法)

**原理:** 水溶性成分溶入水中

**步骤:**
```
1. 药材切碎
2. 加水(没过药材3-5 cm)
3. 浸泡30分钟
4. 煮沸后小火煎煮30-60分钟
5. 过滤取液
6. 药渣可再煎一次

用途: 中药煎剂
```

### 3.2 醇提取法

**原理:** 醇(乙醇)可溶解更多有机成分

**步骤:**
```
1. 药材粉碎
2. 浸入50-70%酒精
3. 密封
4. 室温浸泡7-14天,每天摇晃
5. 过滤取液

用途: 药酒、酊剂
```

### 3.3 蒸馏法

**原理:** 沸点不同,分离纯化

**简易蒸馏装置:**
```
[示意图]

加热 ↓
  ╔═══════╗
  ║ 蒸馏瓶 ║ ← 原料
  ╚═╦═══╦═╝
    ║ 蒸汽
    ║   ╔═════════╗
    ╚═══╣ 冷凝管  ║ ← 冷水流过
        ╚═════╦═══╝
              ↓液滴
        ╔═══════╗
        ║接收瓶 ║
        ╚═══════╝
```

**用途:**
- 提纯酒精
- 提取精油
- 制备蒸馏水

### 3.4 过滤与沉淀

**过滤:**
```
粗过滤: 纱布、棉布
中过滤: 滤纸、细布
精过滤: 多层滤纸
```

**沉淀法:**
```
1. 加入沉淀剂
2. 静置
3. 杂质沉底
4. 上清液倒出
```

### 3.5 结晶法

**原理:** 降温或蒸发,溶质析出晶体

**步骤:**
```
1. 热溶液饱和
2. 缓慢冷却
3. 晶体析出
4. 过滤收集
5. 洗涤、干燥

用途: 提纯药物(阿司匹林等)
```

## 四、无菌操作

### 4.1 为什么需要无菌?

**污染后果:**
- 口服药: 腹泻、食物中毒
- 外用药: 伤口感染
- 注射药: 败血症、死亡!

**无菌要求(从低到高):**
1. 口服药: 清洁即可
2. 外用药: 较高清洁度
3. 眼药、创面药: 无菌
4. 注射药: **绝对无菌!**

### 4.2 灭菌方法

**煮沸灭菌(最简单):**
```
步骤:
1. 器具浸入水中
2. 煮沸15-30分钟
3. 保持沸腾状态
4. 取出后不接触污染物

杀灭: 大部分细菌和病毒
不能杀灭: 芽孢(但已足够一般使用)
```

**高压蒸汽灭菌(最可靠):**
```
设备: 压力锅
条件: 121°C,15分钟,表压约100 kPa(约1个大气压)
杀灭: 所有微生物,包括芽孢

用于: 注射用器具、培养基

⚠️ 很多家用压力锅的工作压力只有50-80 kPa(锅内约112-117°C),
   达不到121°C,同样时间灭菌不彻底;压力锅也没有温度显示,
   无法确认是否达到条件 → 家用压力锅的结果只能当作"高度清洁",
   不能当作可靠的无菌
```

**干热灭菌:**
```
方法: 烤箱/炉子
温度: 160-170°C
时间: 2小时

用于: 玻璃器皿、金属器具
```

**化学灭菌:**
```
75%酒精浸泡: 30分钟
碘伏擦拭: 2次
高锰酸钾溶液: 浸泡

用于: 不耐热物品、皮肤消毒
```

高锰酸钾溶液按用途配成0.01%-0.1%,浓度表见[消毒剂制备-高锰酸钾溶液配制](./01-消毒剂制备.md#53-高锰酸钾溶液配制);含氯消毒液(84消毒液)用于物体表面和环境,不用于皮肤和伤口,配制比例见[传染病家庭防控-84消毒液](../01-日常疾病和伤害/15-传染病家庭防控.md#84消毒液含氯消毒剂)。化学消毒前先把物品洗净,血迹、脓液、油污会让消毒剂失效。

### 4.3 无菌操作要点

**操作前:**
- [ ] 手洗净,消毒
- [ ] 器具灭菌
- [ ] 工作台清洁、消毒
- [ ] 穿清洁衣物

**操作中:**
- [ ] 减少暴露时间
- [ ] 不说话、不咳嗽
- [ ] 器具口部不接触外物
- [ ] 盖子内面朝上放

**操作后:**
- [ ] 及时密封
- [ ] 标记日期、名称
- [ ] 低温避光保存

### 4.4 清洁、消毒和灭菌的区别

| 级别 | 做到什么程度 | 常用方法 | 够用于 |
|------|-------------|---------|--------|
| 清洁 | 去掉肉眼可见的污物和大部分微生物 | 肥皂、流水刷洗 | 口服用具、储药容器,也是消毒和灭菌的前提 |
| 消毒 | 杀死大部分致病微生物,但不一定杀死芽孢 | 煮沸、75%酒精、碘伏、含氯消毒液 | 皮肤、体温计、外用器具、换药用具 |
| 灭菌 | 杀死全部微生物,包括芽孢 | 可靠的高压蒸汽、干热 | 进入伤口深处或体内的器具 |

```
常见误区:
❌ 没洗干净就直接消毒 → 污物包住细菌,消毒剂渗不进去
❌ 酒精擦一下马上用 → 要等酒精自然干透(约30秒)才起作用
❌ 消毒后用普通毛巾擦干 → 又被污染,应自然晾干或用消毒过的布
❌ 以为"煮过了就无菌" → 煮沸只是消毒,杀不死芽孢
```

### 4.5 日常用药的卫生操作

**洗手(所有操作的第一步):**
```
1. 流水打湿双手
2. 擦肥皂,手心、手背、指缝、指尖、拇指、手腕都要搓到
3. 至少搓20秒
4. 流水冲净,用干净的布擦干或晾干

没有肥皂: 用草木灰搓洗,或只用流水认真搓洗20秒
手上没有明显脏污时,可用75%酒精搓手代替,搓到干为止
```

相关章节: [卫生设施-洗手点](../07-日常生活技能/03-卫生设施.md#洗手点)。

**取用和使用药品:**
```
✓ 药片倒在瓶盖里或干净的纸上再取,不要用手在瓶里翻找
✓ 多倒出来的药片不要放回原瓶
✓ 药膏用干净的棉签挑取,用过的棉签不再伸回药管或药瓶
✓ 滴眼液、滴鼻液的瓶口不要碰到眼睛、睫毛、鼻子或手指
✓ 滴眼液、滴鼻液、药膏一人一瓶,不要家人共用
✓ 每个用药的人用自己的杯子、量具;量具用后洗净晾干
✓ 换药前后都洗手,接触伤口时戴手套(没有手套套干净塑料袋)
✓ 用过的敷料、棉签装袋扎紧丢弃,沾血的东西不要让孩子接触
```

**怎样判断卫生做得不够:**
- 伤口换药后红肿、发热、疼痛反而加重,或流脓、有臭味 → 可能感染,见本章十一的就医标准
- 用滴眼液后眼睛更红、分泌物增多 → 停用这瓶药,换新的,仍不好就医
- 储药容器里出现水汽、霉点 → 容器不干燥或不密封,整瓶药按变质处理

## 五、药物保存

### 5.1 常见药物储存条件

| 药物类型 | 储存温度 | 其他要求 | 保质期 |
|----------|----------|----------|--------|
| 固体药片 | 阴凉(<25°C) | 干燥、避光 | 1-3年 |
| 液体药剂 | 冷藏(2-8°C) | 避光 | 1-6个月 |
| 酒精/碘酒 | 室温 | 密封 | 2年 |
| 中药饮片 | 阴凉干燥 | 通风、防虫蛀 | 1年 |
| 药膏 | 阴凉 | 密封 | 1-2年 |

⚠️ 上表是粗略参考。成品药一律以**包装上的储存条件和有效期**为准;表中"液体药剂 冷藏、1-6个月"指自制或已开封的液体,未开封的成品糖浆、口服液多数在室温保存,有效期看包装。

**常见储存条件用语的意思(《中国药典》):**

| 包装上写 | 意思 |
|---------|------|
| 常温 | 10-30°C |
| 阴凉处 | 不超过20°C |
| 凉暗处 | 避光并不超过20°C |
| 冷处 | 2-10°C |
| 遮光 | 用不透光的容器包装(如棕色瓶、黑纸包裹) |
| 密封 | 防止风化、吸潮、挥发或异物进入 |

```
储存要点:
✓ 放在干燥、阴凉、避光、孩子够不到的地方,最好上锁
✓ 保留原包装和说明书;铝塑板包装的药不要提前剥出来分装
✓ 不要放在卫生间、厨房灶台边、窗台上、夏天的车里
✓ 需要冷藏的药放冰箱冷藏室中间,不要贴着冰箱后壁,不要冷冻
✓ 外用药和内服药分开放,消毒液、农药绝不和药放在一起
✓ 定期(如每半年)检查一次,快过期的先用,过期变质的清理掉
```

储存条件的详细说明见[抗生素制备-储存条件](./02-抗生素制备.md#64-储存条件);胰岛素等冷藏药停电时怎么办,见[慢性病用药储备-胰岛素等需要冷藏的药](../01-日常疾病和伤害/08-慢性病用药储备.md#胰岛素等需要冷藏的药)。

### 5.2 变质判断

**外观变化:**
- ✗ 变色(褐色、黑色)
- ✗ 发霉(白毛、绿斑)
- ✗ 结块、潮解
- ✗ 液体浑浊、沉淀
- ✗ 异味

**任何变质,立即丢弃!**

### 5.3 容器选择

**玻璃瓶(最佳):**
- ✓ 不与药物反应
- ✓ 可高温消毒
- ✓ 密封性好
- 深色瓶更佳(避光)

**陶罐:**
- ✓ 存储干燥药材
- ✓ 透气性好

**塑料瓶(慎用):**
- ⚠️ 某些药物会溶解塑料
- ⚠️ 不耐高温
- 短期可用

```
不论用什么容器:
✓ 贴标签: 药名(通用名)、规格、有效期或开封日期、用法
✗ 不要用饮料瓶、食品罐装药或消毒液,孩子和老人容易误服
✗ 不要把几种药混装在一个瓶里,一旦混了就认不出来
```

### 5.4 有效期怎么看

```
包装上通常有三个日期:
- 生产日期
- 批号(出问题时用于追查,不是日期)
- 有效期: "有效期至2027年05月",一般指可用到该月最后一天;
  标到日的,用到该日为止
  旧包装上写"失效期"的,指在这个日期之前使用

开封后的有效期比包装上的短:
- 有效期是在原包装、未开封、按规定条件储存时测定的
- 开封后接触空气、水汽和手,降解和污染都会加快
```

**开封后的使用期限(说明书有写的以说明书为准;没写时的保守参考):**

| 剂型 | 开封后 | 说明 |
|------|--------|------|
| 滴眼液、滴鼻液、滴耳液 | 一般不超过4周 | 极易污染;单支装的打开后当次用完 |
| 糖浆、口服液、混悬液 | 按说明书;没有写的一般1-3个月 | 出现浑浊、异味、发霉立即丢弃 |
| 加水配好的干混悬剂(如儿童抗生素) | 按说明书,通常几天到2周 | 多需冷藏,到期即弃 |
| 乳膏、软膏 | 一般1-2个月 | 管装比罐装好,罐装用干净棉签挑取 |
| 散装瓶装药片 | 一般不超过6个月,且不超过原有效期 | 保留干燥剂,每次取完拧紧 |
| 铝塑板包装药片 | 未剥开的部分按原有效期 | 剥开的那一粒当次吃掉 |

开封时在瓶上写下开封日期,否则过一阵就记不清了。

### 5.5 过期药能不能用

**正常情况下: 不用过期药。** 有在有效期内的药、能去医院或药店时,过期药一律不用。

**在完全没有替代的极端情况下,判断原则:**
```
过期药的主要风险是"药效不足",而不是"变成毒药":
- 美国军方和FDA的货架期延长计划检测发现,在良好条件下密封保存的
  固体剂型(片剂、胶囊),多数过了标示有效期仍保持足够含量
- 但"多数"不是"全部",也不适用于储存条件差的药

所以:
✓ 原包装密封、储存条件好、外观正常的片剂和胶囊,过期不久的
  在没有任何替代时可以考虑使用
⚠️ 剂量不能自行加大来"补偿"药效损失
⚠️ 治疗致命疾病(如严重感染)时,药效不足 = 治疗失败,
  所以更要尽一切可能就医,不能因为"有药了"就耽误
```

**不能依赖过期药的情况:**

| 情况 | 原因 |
|------|------|
| 液体剂型(糖浆、口服液、滴眼液、注射液) | 降解快,还可能长菌 |
| 需要冷藏的药(胰岛素、部分疫苗等) | 储存条件一旦失守,效力不可预测 |
| 硝酸甘油 | 极易失效,心绞痛发作时不起作用会耽误抢救 |
| 治疗窗窄的药(华法林、地高辛、抗癫痫药等) | 含量变化后剂量就不对了 |
| 外观有任何变化(变色、结块、潮解、浑浊、异味、发霉) | 已经变质,不论有没有过期 |
| 包装破损、密封失效 | 无法判断受潮和污染程度 |

⚠️ 一个例外要知道: 严重过敏发作(过敏性休克)时,如果手边只有过期的肾上腺素笔、没有别的,多数专业意见认为仍然应该使用(药液明显变色或有沉淀的除外),同时立即拨打120。平时仍要按时更换,见[急性症状-过敏反应](../01-日常疾病和伤害/05-急性症状.md#过敏反应)。

过期药物的研究数据和抗生素的具体判断,见[抗生素制备-关于有效期](./02-抗生素制备.md#65-关于有效期)。

### 5.6 过期和变质药的处理

```
✓ 有药品回收点(药店、社区)时,交回收点
✗ 不要冲进马桶或倒进水源附近,会污染水
✗ 不要整瓶扔进垃圾桶,孩子或别人可能捡到误服
没有回收点时: 把药片从包装里取出,和泥土、用过的茶叶渣或
  猫砂混在一起,装进密封袋,扔进生活垃圾;撕掉或涂掉标签上的个人信息
```

### 6.1 个人防护装备

**基本防护:**
- [ ] 口罩(防吸入粉尘、蒸汽)
- [ ] 手套(防接触腐蚀物)

**高危操作(强酸、强碱):**
- [ ] 防化手套
- [ ] 面罩
- [ ] 长袖长裤

### 6.2 通风要求

**必须通风操作:**
- 蒸馏酒精(易燃蒸汽)
- 使用强酸强碱(腐蚀性蒸汽)
- 处理硫化物(有毒气体)
- 培养微生物(避免污染)

**通风措施:**
- 室外操作
- 开窗对流
- 简易通风罩

### 6.3 急救措施

**酸碱烧伤:**
```
1. 迅速脱去沾染的衣物、手套
2. 立即用大量流动清水冲洗,持续30分钟以上(碱烧伤冲得更久)
3. 不要用苏打水、醋等去"中和" → 中和反应放热,会加重烧伤,
   还耽误冲洗时间
4. 生石灰先刷去粉末再冲水;浓硫酸先用干布迅速沾去再大量冲水
5. 用干净的布松松盖住,带上化学品的容器或标签就医
6. 溅入眼睛: 立即用流动清水冲洗,边冲边就医
```

详见[外伤处理-化学烧伤](../01-日常疾病和伤害/02-外伤处理.md#化学烧伤)和[异物处理-化学品入眼](../01-日常疾病和伤害/04-异物处理.md#化学品入眼紧急)。

**吸入有毒气体:**
```
0. 先保护自己: 有异味、有人倒下时不要贸然进入,先通风或戴防护
1. 立即转移到新鲜空气处
2. 松开衣领
3. 保持呼吸道通畅
4. 无反应、无正常呼吸 → 拨打120,立即CPR
5. 就医(咳嗽、胸闷可能几小时后才加重)
```

**误食:**
```
1. 吐出嘴里剩余的东西,清水漱口(不要咽下)
2. 拨打120,说清楚吃了什么、大概多少、什么时间
3. 不要催吐,不要灌牛奶、蛋清、醋等偏方,除非医生或120明确让你这样做
   (催吐不能有效清除毒物;腐蚀性物质吐出来会再次烧伤食道;
    意识不清时呕吐容易吸进肺里)
4. 不要给意识不清的人喂任何东西;有呼吸但叫不醒 → 侧卧
5. 把原料、容器、剩余物带去医院
6. "现在看起来没事"也要就医,很多毒物几小时后才发作
```

详见[中毒-中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则)。

## 八、毒性物质识别

### 8.1 剧毒植物(绝对避免)

| 植物 | 毒性成分 | 致死量 | 症状 |
|------|----------|--------|------|
| 断肠草 | 钩吻碱 | 2-3 g | 呼吸麻痹 |
| 曼陀罗 | 莨菪碱 | 15-100 mg | 幻觉、昏迷 |
| 乌头 | 乌头碱 | 2-4 mg | 心脏骤停 |
| 夹竹桃 | 强心苷 | 少量 | 心律失常 |
| 毒芹 | 毒芹碱 | 少量 | 抽搐、呼吸衰竭 |

**原则: 不认识的植物绝对不用!**

### 8.2 重金属(禁用)

- ☠️ 汞(水银): 神经毒
- ☠️ 铅: 慢性中毒
- ☠️ 砷(砒霜): 剧毒
- ☠️ 镉: 肾损伤

**古代"仙丹"常含这些,导致很多人中毒!**

### 8.3 安全性测试(谨慎)

**如果必须测试未知植物:**
```
第1步: 皮肤测试
  - 挤汁液涂抹在手臂内侧
  - 等待4小时
  - 如红肿、灼痛 → 放弃

第2步: 唇部测试
  - 少量触碰嘴唇
  - 等待15分钟
  - 如麻木、灼痛 → 放弃

第3步: 舌尖测试
  - 微量放舌尖
  - 立即吐出
  - 等待15分钟
  - 如不适 → 放弃

第4步: 小量吞服
  - 极少量(米粒大小)
  - 等待8小时
  - 如无不良反应,逐渐增加

整个过程需2-3天!
```

**⚠️ 风险极高!除非绝境,否则不要尝试!**

## 九、常见问题

### Q1: 没有精确称量工具怎么办?

**A: 使用容积估算**
```
1茶匙(约5 mL) ≈ 5 g(粉末)
1汤匙(约15 mL) ≈ 15 g
1杯(约250 mL) ≈ 250 g

液体: 可用容量估算
固体: 用水测体积后估算重量
```

**原则: 宁少勿多!**

```
⚠️ "1茶匙 ≈ 5 g"只对水和密度接近水的东西成立:
- 干燥的药材粉末很轻,一茶匙可能只有2-3 g
- 盐、糖这类细密晶体,一茶匙约5-6 g
- 同一种粉末,压实和松散相差也很大
所以容积估算只能用于盐、糖这类本身安全范围很宽的东西,
不能用来量取作用强、有毒性的药
```

见上文[2.4 剂量换算与称量误差](#24-剂量换算与称量误差)。

### Q2: 如何判断提取是否完全?

**A: 多次提取对比**
- 第一次提取: 颜色深
- 第二次提取: 颜色浅
- 第三次提取: 几乎无色 → 完全

### Q3: 自制药物能保存多久?

**A: 保守估计**
- 液体药剂: 1-4周(冷藏)
- 干燥药粉: 3-6个月
- 药酒: 6-12个月
- 膏药: 1-3个月

**有任何可疑变质,立即丢弃!**

### Q4: 一定要无菌吗?

**A: 视用途而定**
- 口服: 清洁即可(非无菌)
- 外用创面: 尽可能无菌
- 注射: **绝对无菌!**(无条件不做!)

## 十一、药物不良反应与就医时机

> 任何药(包括中药、自制药和"天然"药)都可能有不良反应。会识别、会停药、知道什么时候必须送医,比会用药更重要。

### 11.1 不良反应分级

| 程度 | 常见表现 | 怎么办 |
|------|---------|--------|
| 轻 | 轻度恶心、胃不舒服、轻微头晕、口干、嗜睡、便秘或稀便 | 多数可继续观察;按说明书饭后服可减轻胃部不适;嗜睡时不开车、不登高、不操作危险器械 |
| 中 | 局部或全身皮疹、瘙痒、呕吐、腹泻次数多、明显心慌 | 停用可疑的药,记录,尽快咨询医生;观察是否加重 |
| 重(危及生命) | 呼吸困难、喉咙发紧、嘴唇和脸肿、头晕晕倒;大片皮肤起疱脱皮;呕血、黑便;抽搐、意识不清;呼吸变慢变浅 | **立即停药,拨打120** |

严重过敏(过敏性休克)可在用药后几分钟内发生,判断和处理见[急性症状-过敏反应](../01-日常疾病和伤害/05-急性症状.md#过敏反应)。

### 11.2 容易被忽视的危险信号

```
皮肤和黏膜
- 发热、全身不适几天后,出现大片红斑、水疱、皮肤脱落,
  并伴有口腔、眼睛、外阴的溃烂 → 严重药疹,立即就医
  (常在开始用药后几天到几周内出现,如某些抗癫痫药、
   磺胺类、别嘌醇、部分抗生素和解热镇痛药)

肝
- 皮肤或眼白发黄、尿色变深如浓茶、食欲差、右上腹痛
  → 可能是药物性肝损伤(对乙酰氨基酚过量、部分中药等)

胃肠道出血
- 呕吐咖啡渣样或鲜红色的东西、大便发黑发亮像柏油
  → 常见于布洛芬、阿司匹林等,老人和长期服用者风险更高

肾
- 尿量明显减少、全身浮肿
  → 布洛芬等在脱水、老人身上更容易伤肾

血液
- 用药期间出现发热、咽痛、口腔溃疡,或皮肤莫名出现瘀斑、
  牙龈出血 → 可能是白细胞或血小板减少,要查血

神经和呼吸
- 叫不醒、呼吸变慢变浅(安眠药、镇静药、某些止咳药过量)
- 抽搐、走路不稳、说话含糊
```

### 11.3 怎样判断是不是药引起的

```
支持是药引起的:
✓ 开始用药(或加量、换药)之后才出现
✓ 停药后逐渐好转
✓ 说明书"不良反应"一栏里写到过这种表现
✓ 以前用同一种或同类药时出现过类似情况

可能是别的原因:
- 疾病本身在加重(如感染引起的皮疹、发热)
- 同时吃的食物、酒、其他药

⚠️ 出现过严重反应(严重皮疹、喉头水肿、过敏性休克)的,
   不要为了"验证"再试一次,下一次可能更重
```

### 11.4 出现不良反应后怎么做

```
1. 重的(见11.1) → 立即拨打120,不要等
2. 中、轻的 → 停用最可疑的那种药
   (但抗癫痫药、激素、降压药、抗抑郁药等不能自行突然停,
    要先问医生,见慢性病用药储备)
3. 记录: 什么药、什么剂量、什么时间开始、什么表现、停药后怎样
4. 把药名写进用药信息卡和病历的"过敏史"一栏,告诉家人
5. 就医时带上药盒和说明书
```

### 11.5 常见的危险组合

| 组合 | 风险 |
|------|------|
| 几种感冒药、退烧药一起吃 | 对乙酰氨基酚等成分重复,不知不觉超量伤肝 |
| 对乙酰氨基酚 + 饮酒 | 加重肝损伤 |
| 安眠药、镇静药、有嗜睡作用的抗过敏药 + 酒 | 呼吸抑制,可致死 |
| 布洛芬 + 阿司匹林 / 抗凝药(如华法林) | 出血风险增加 |
| 头孢类、甲硝唑等 + 酒 | 双硫仑样反应: 脸红、心慌、血压下降,严重的可致死;用药期间和停药后约1周内不要喝酒 |
| 中药 + 西药"一起上" | 成分不明,相互作用难以预测;要同时用,先问医生或药师 |

### 11.6 什么时候必须就医

**立即拨打120:**
- [ ] 用药后呼吸困难、喉咙发紧、脸和嘴唇肿、头晕晕倒
- [ ] 意识不清、叫不醒、抽搐,或呼吸变慢变浅
- [ ] 呕血、黑便
- [ ] 大片皮肤起疱、脱皮,或口腔、眼睛溃烂
- [ ] 误服或过量服用了药物,哪怕现在没有症状(尤其是儿童)

**尽快(当天)就医:**
- [ ] 皮肤或眼白发黄、尿色像浓茶
- [ ] 尿量明显减少、全身浮肿
- [ ] 用药期间发热、咽痛、口腔溃疡,或莫名出现瘀斑
- [ ] 婴儿、孕妇、高龄老人用药后出现任何异常
- [ ] 按说明书用药2-3天症状没有好转,或反而加重

**不要自己用药,先就医的情况:**
- [ ] 3个月以下婴儿发烧或生病
- [ ] 孕妇和哺乳期需要用药
- [ ] 诊断不明的剧烈腹痛、胸痛、头痛
- [ ] 需要处方药、注射或输液才能治疗的病
- [ ] 怀疑是严重感染(高热不退、伤口红肿扩散、精神萎靡)

**在医疗体系瓦解、无法就医时:** 上面这些情况仍然意味着病情危重。尽一切可能寻找医生、护士、药师或有经验的人求助;同时按急救章节做力所能及的处理,详细记录病情变化。不要因为"有自制的药"就不去找人。

各种常见病的具体就医标准,见[常见疾病](../01-日常疾病和伤害/01-常见疾病.md)中每种病的"就医指征"一节,发烧见[不同人群的发烧就医标准](../01-日常疾病和伤害/01-常见疾病.md#不同人群的发烧就医标准)。
