# 菌藻树脂及其他

> **这一章的药材不长根、不开花,或者根本不是"一棵植物": 菌核、子实体、海藻、树脂、虫瘿、加工成的粉和膏——认它们靠的不是叶序和花,而是断面、气味、火烧和水试**

本章收录18味特殊来源的药材,分为菌类、藻类、树脂类和其他加工品四组: 菌类是真菌的菌核或子实体(茯苓、猪苓、灵芝、冬虫夏草、雷丸、马勃);藻类是海洋褐藻(海藻、昆布);树脂类是树木分泌或提取加工的产物(乳香、没药、血竭、琥珀、冰片);其他加工品包括虫瘿(五倍子)、植物加工粉末和浓缩物(青黛、芦荟、儿茶)以及发酵制品(神曲)。识别、采收、干燥、储存的通用方法见[总论](./00-总论.md),本章不再重复。

## ⚠️ 先读这几条


## 一、菌类

药用的"菌"大多不是普通人想象的蘑菇: 茯苓、猪苓、雷丸是埋在土里的**菌核**(一团菌丝结成的硬块),灵芝是木质的子实体,马勃是一包孢子粉,冬虫夏草是真菌和虫体的复合体。它们的共同点是: **市售品绝大多数来自栽培或专业收购,普通人不需要、也不应该到野外"找药用菌"**。

**⚠️ 野外采蘑菇有致命中毒的风险**: 我国每年都有人因误食鹅膏菌等毒蘑菇死亡,而且没有任何简单的鉴别方法(颜色、银针、虫咬、煮久都不可靠)。详见[毒蘑菇: 没有简单的鉴别方法](../03-野外生存/09-毒蘑菇与野菜误食.md#毒蘑菇-没有简单的鉴别方法);吃了野生菌后不舒服,按[吃了野生蘑菇后不舒服](../03-野外生存/09-毒蘑菇与野菜误食.md#吃了野生蘑菇后不舒服)处理,立即就医。本节的识别要点只用于**辨认买来的药材真假**,不是采食野生菌的依据。

### 1.1 茯苓

- **正名(别名)**: 茯苓(云苓、茯苓个、白茯苓);抱着松根的部分称"茯神",近外皮的淡红色部分称"赤茯苓",外皮称"茯苓皮"
- **来源**: 多孔菌科真菌茯苓 *Poria cocos* (Schw.) Wolf 的干燥菌核
- **分布与生境**: 寄生在马尾松、赤松等松树的根上,埋在土中;主产云南("云苓")、安徽、湖北等地,现在绝大多数是用松木段栽培的
- **识别要点**:
  - 药材(茯苓个): 类球形、椭圆形或不规则团块,大小不一;**外皮薄而粗糙,棕褐色至黑褐色,有明显的皱缩纹理**;体重,质坚实
  - 断面: **颗粒性**,外层淡棕色,内部白色,少数淡红色;有的中间抱有松根
  - 茯苓块、茯苓片: 白色或淡红色的方块或薄片,质地细腻
  - 气味: 气微,味淡,**嚼起来粘牙**
- **伪品**: 用**面粉、淀粉压制或掺入**的"茯苓块""茯苓片",外观更白、更整齐,嚼起来不粘牙、有面粉味;**滴一滴碘酒**: 真茯苓显红褐色,很快**变蓝黑色的掺了淀粉**(经验,药典鉴别用碘化钾碘试液,真品显深红色)
- **采收与加工**: 多在7-9月采挖;挖出后堆起来"发汗"(见[总论-发汗](./00-总论.md#54-发汗)),摊开晾到表面干燥,再发汗,反复几次到出现皱纹、内部水分大部分散失,**阴干**,称"茯苓个";也可趁鲜按部位切成块、片后阴干
- **储存**: 置干燥处,防潮;受潮易发霉,干燥过度易开裂
- **功效**: 利水渗湿,健脾,宁心
- **用量**: 10-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 药性平和;阴虚而没有水湿、尿多的人不宜多用(经验)。茯苓常被做成"茯苓饼"等食品,作为食物适量吃一般无妨,但不能代替治疗水肿——**水肿要先查心、肾、肝的原因**

### 1.2 猪苓

- **正名(别名)**: 猪苓(野猪粪、猪屎苓)
- **来源**: 多孔菌科真菌猪苓 *Polyporus umbellatus* (Pers.) Fries 的干燥菌核
- **分布与生境**: 生在桦、柞(栎)、槭等阔叶树的根旁土中;主产陕西、山西、河北、云南、四川等地。野生资源逐年减少,已有人工栽培
- **识别要点**:
  - 药材: 条形、类圆形或扁块状,有的有分枝,长5-25 cm,直径2-6 cm;**表面黑色、灰黑色或棕黑色,皱缩或有瘤状突起**(形似猪粪,因而得名)
  - 质地: **体轻,质硬**,能浮在水面上;断面**类白色或黄白色**,略呈颗粒状
  - 气味: 气微,味淡
- **伪品**: 表面过黑、发亮,断面颜色发暗,或放进水里**下沉**的,可能是染色或掺泥增重的(经验)
- **采收与加工**: 春、秋二季采挖,除去泥沙,干燥
- **储存**: 置通风干燥处
- **功效**: 利水渗湿
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 利水作用比茯苓强,没有水湿的人不宜用;长期大量用可能伤阴(经验)

### 1.3 灵芝

- **正名(别名)**: 灵芝(赤芝、紫芝、灵芝草)
- **来源**: 多孔菌科真菌赤芝 *Ganoderma lucidum* (Leyss. ex Fr.) Karst. 或紫芝 *G. sinense* Zhao, Xu et Zhang 的干燥子实体
- **分布与生境**: 野生的生在阔叶树(紫芝多在针叶树)的腐木、树桩上;**市售的绝大多数是段木或代料栽培品**,各地都有栽培
- **识别要点**:
  - 赤芝: 外形像一把伞;**菌盖肾形、半圆形或近圆形**,直径10-18 cm,厚1-2 cm;**皮壳坚硬,黄褐色至红褐色,有漆样光泽**,有环状棱纹和放射状皱纹,边缘薄而平截;菌肉白色至淡棕色;**菌柄侧生**(少数偏生),长7-15 cm,红褐色至紫褐色,光亮;菌盖下面是密集的小孔(不是菌褶),孢子细小、黄褐色
  - 紫芝: 皮壳**紫黑色**,有漆样光泽;菌肉锈褐色
  - 气味: 气微香,**味苦涩**
- **易混淆品("野生灵芝")**: 树桩上长的木质、半圆形的多孔菌很多——**树舌**(平盖灵芝,无柄,菌盖灰褐色、没有漆样光泽)、云芝、各种木蹄、栓菌等。它们多数质地像木头,有的成分和毒性还没研究清楚;市场上常把这些当"野生灵芝""百年灵芝"高价出售。**没有漆样光泽、没有侧生长柄的,不当灵芝用**;更不要把野外采的不认识的硬质菌拿来泡水、泡酒
- **采收与加工**: 栽培品全年可采;除去杂质,剪掉下端带朽木、泥沙或培养基质的菌柄,**阴干或在40-50°C烘干**
- **储存**: 密封,置干燥处,防霉、防蛀(灵芝很容易生虫)
- **功效**: 补气安神,止咳平喘
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 一般较安全;正在服抗凝药、降压药、降糖药或准备手术的人,长期服用前先问医生(经验)。**灵芝和灵芝孢子粉不能代替癌症的正规治疗**

### 1.4 冬虫夏草

> 🛡️ **法律提醒**: 冬虫夏草被列为**国家二级重点保护野生植物**(2021年《国家重点保护野生植物名录》)。采集、出售、收购须依法取得许可,并受《野生药材资源保护管理条例》等法规约束;无证采挖、收购是违法行为。产区的采挖由当地政府统一管理。本书**不写采挖方法**,只帮助读者识别真伪、避免上当。见[总论-国家重点保护野生植物名录](./00-总论.md#82-国家重点保护野生植物名录)。

- **正名(别名)**: 冬虫夏草(虫草、中华虫草)
- **来源**: 麦角菌科真菌冬虫夏草菌 *Cordyceps sinensis* (BerK.) Sacc. 寄生在蝙蝠蛾科昆虫幼虫上的子座和幼虫尸体的干燥复合体
- **分布与生境**: 只分布在青藏高原及周边海拔约3000-5000 m的高山草甸(青海、西藏、四川、云南、甘肃);目前还不能大规模人工栽培出完整的虫草
- **识别要点**(两部分: 下面的"虫"和上面的"草"):
  - 虫体: **像蚕**,长3-5 cm,直径0.3-0.8 cm;表面深黄色至黄棕色,有**环纹20-30个**,近头部的环纹较细;**头部红棕色**;**足8对,中部4对较明显**;质脆,易折断,断面略平坦,淡黄白色,**中间常可见黑色的"V"形或点状消化道**(经验)
  - 子座: 从虫头部长出,**细长圆柱形**,长4-7 cm,直径约0.3 cm;表面深棕色至棕褐色,有细纵皱纹,上部稍膨大;质柔韧,断面类白色
  - 气味: **气微腥**,味微苦
- **常见伪品和作假**:
  - **亚香棒虫草**等其他虫草: 虫体表面多有灰白色或类白色菌膜,环纹和足不如正品清楚,子座常有分枝或颜色不同
  - **地蚕**(唇形科植物地蚕、草石蚕的块茎): 纺锤形,有4-15个环节,**没有足、没有头、没有子座**,断面类白色,味甜
  - **面粉、豆粉、石膏用模具压制**: 每条形状、环纹、足都一模一样,过分整齐;断面均匀、没有消化道的黑点,泡水后变软、散开,滴碘酒变蓝(含淀粉)
  - **插铁丝、竹签、铅丝增重**,用胶水把断草粘起来: 用磁铁吸、对光看、掰开看接口;同等大小**明显偏重**的要怀疑
  - **用"虫草菌丝体""虫草花"冒充**: 虫草花是蛹虫草(北冬虫夏草)的子实体,橙黄色,和冬虫夏草不是一种东西
- **采收**: 不写。只需知道: 虫草在初夏子座出土、孢子未散发时由持证人员采集,产区实行管理
- **储存**: 密封,置阴凉干燥处,**防蛀**;可冷藏
- **功效**: 补肾益肺,止血化痰
- **用量**: 3-9 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 2016年原国家食品药品监管总局曾提示,冬虫夏草**砷含量较高,长期食用存在风险**;不建议当保健品长期大量吃。价格极高、功效被过度宣传,**不能代替任何正规治疗**

### 1.5 雷丸

- **正名(别名)**: 雷丸(雷实、竹苓)
- **来源**: 白蘑科真菌雷丸 *Omphalia lapidescens* Schroet. 的干燥菌核
- **分布与生境**: 多生在竹林中竹根附近的土里;主产四川、贵州、云南、湖北、广西等地
- **识别要点**:
  - 药材: 类球形或不规则团块,**直径1-3 cm**;表面黑褐色或棕褐色,**有略隆起的不规则网状细纹**;质坚实,不易破开
  - 断面: 不平坦,**白色或浅灰黄色**,常有黄白色的大理石样纹理
  - 气味: 气微,味微苦;嚼起来有颗粒感,微带黏性,久嚼无渣
  - **断面褐色、呈角质样(像牛角那样半透明)的已经变质,不能药用**
- **采收与加工**: 秋季采挖,洗净,晒干
- **储存**: 置阴凉干燥处;有效成分(一种蛋白酶)怕热,**不要高温烘烤**
- **功效**: 杀虫消积(传统用于绦虫、钩虫、蛔虫病)
- **用量**: 15-21 g,**不宜入煎剂**(加热失效),一般研粉服,一次5-7 g,饭后用温开水调服,一日3次,连服3天(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 传统认为有小毒,不宜长期服;孕妇、儿童不自用。**肠道寄生虫病现在有安全有效的驱虫药**,怀疑寄生虫(大便里见虫体或节片、肛门痒、贫血)应就医查明虫种再治

### 1.6 马勃

- **正名(别名)**: 马勃(马屁包、灰包、牛屎菇)
- **来源**: 灰包科真菌脱皮马勃 *Lasiosphaera fenzlii* Reich.、大马勃 *Calvatia gigantea* (Batsch ex Pers.) Lloyd 或紫色马勃 *C. lilacina* (Mont. et Berk.) Lloyd 的干燥子实体
- **分布与生境**: 夏秋雨后生在草地、山坡、林缘、牧场;全国大部分地区有分布,多为野生
- **识别要点**:
  - 鲜品: 圆球形或梨形,**没有菌盖、没有菌褶、没有菌柄**(或只有不孕的基部);幼嫩时**切开里面是均匀一致的白色**,成熟后内部变成褐色的孢子粉,一按就从顶部的破口"冒烟"
  - 药材(脱皮马勃): 扁球形或类球形,直径15-20 cm;包被灰棕色至黄褐色,纸质,常破碎成片或全部脱落;孢体灰褐色或浅褐色,紧密、有弹性,撕开内有棉絮状丝状物;**一碰孢子就像尘土一样飞扬**,手捻有细腻感
  - 气味: **气似尘土**,无味
- **易混淆品(有毒)**:
  - **鹅膏菌的"菌蕾"**: 鹅膏菌刚出土时包在白色的菌托里,像一个白色小球或鸡蛋,**外形和幼嫩马勃很像,而鹅膏菌是我国毒蘑菇致死的首要原因**。**从上到下纵切**: 马勃内部均匀无结构;菌蕾里能看到菌盖、菌褶、菌柄的轮廓——有任何"小蘑菇的轮廓",立即丢弃
  - **硬皮马勃**(*Scleroderma*): 外皮厚而硬、常有鳞片或裂纹,**内部很早就变成紫黑色**,有毒,可引起胃肠道中毒
- **采收与加工**: 夏、秋二季子实体**成熟时及时采收**,除去泥沙,干燥。采集和处理时**戴口罩,不要吸入孢子粉**(可刺激呼吸道,大量吸入可致肺部病变)
- **储存**: 置干燥处,防尘;孢子易飞散,用纸袋或布袋包好再装罐
- **功效**: 清肺利咽,止血
- **用量**: 2-6 g;外用适量,敷患处(《中国药典》2020年版,在中医师指导下使用)。粉末轻、易飞扬,煎煮时一般用纱布包煎(经验)
- **禁忌**: 风寒咳嗽、失音者不宜(经验)。民间用马勃粉撒伤口止血,只能用于小伤口渗血;**伤口要先清洗干净**,出血不止、伤口深或脏的按[外伤处理](../01-日常疾病和伤害/02-外伤处理.md)处理并就医

## 二、藻类

海藻和昆布都是生长在海里的大型褐藻,功效也相近(消痰软坚散结、利水消肿),药典用量都是6-12 g。两者有两个共同的安全问题:

```
1. 含碘很多: 海带等褐藻是含碘最高的食物之一
   - 缺碘地区适量吃海带,是补碘、预防"大脖子病"的传统办法
   - 但甲状腺功能亢进(甲亢)、桥本甲状腺炎、正在吃甲状腺药物
     或准备做放射性碘检查治疗的人,不要自行大量吃,也不要自行用作药材
   - "软坚散结"不等于能消甲状腺结节、肿块:
     脖子上长了包块,先去医院查清楚
2. 海藻"反甘草"(十八反): 海藻不和甘草同用,
   而甘草是方子里最常见的药之一,自己配药特别容易犯
```

补碘的道理见[营养与营养缺乏病-碘](../07-日常生活技能/02-营养与营养缺乏病.md#碘)和[制盐-碘](../07-日常生活技能/15-制盐.md#碘-自制盐最大的缺陷);十八反见[总论-十八反十九畏](./00-总论.md#73-十八反十九畏配伍禁忌)。

### 2.1 海藻

- **正名(别名)**: 海藻(大叶海藻、小叶海藻、海蒿子、羊栖菜)
- **来源**: 马尾藻科植物海蒿子 *Sargassum pallidum* (Turn.) C. Ag. 或羊栖菜 *S. fusiforme* (Harv.) Setch. 的干燥藻体;前者习称"大叶海藻",后者习称"小叶海藻"
- **分布与生境**: 海蒿子生在黄海、渤海沿岸低潮线下的岩石上;羊栖菜生在浙江、福建、广东等东南沿海潮间带的岩石上,浙江有大量养殖
- **识别要点**:
  - 大叶海藻: 皱缩卷曲,**黑褐色**,有的被白霜,长30-60 cm;主干圆柱状,有圆锥形突起,侧枝上有短小的刺状突起;叶披针形、倒卵形或条形;**有黑褐色的球形或卵圆形"气囊"**(海藻浮在水里靠它)
  - 小叶海藻: 较小,长15-40 cm;分枝互生,无刺状突起;叶条形或细匙形,先端稍膨大、中空;气囊纺锤形或球形,囊柄较长;质较硬
  - 质地: 干时质脆,**水浸后膨胀,肉质、黏滑**
  - 气味: **气腥,味微咸**
- **易混淆品**: 海边捡到的其他褐藻、绿藻很多,一般无毒,但不是药典海藻;**有气囊、有像叶子一样的分化**是马尾藻类的特点
- **采收与加工**: 夏、秋二季从海中捞取或割取,除去杂质,**用淡水洗净**,晒干。不要采排污口、港口、养殖污染区附近的海藻(易富集重金属)
- **储存**: 置干燥处,**防潮**(含盐易吸潮);表面的白霜是盐分和甘露醇析出,不是发霉;长了绿色、黑色绒毛状霉斑的不用
- **功效**: 消痰软坚散结,利水消肿
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **不宜与甘草同用**(十八反);甲状腺功能亢进等甲状腺病患者不自用;脾胃虚寒、常腹泻的人不宜(经验)。羊栖菜作为食物时,一些国家的食品安全机构提示其**无机砷含量较高**,不宜长期大量吃

### 2.2 昆布

- **正名(别名)**: 昆布(海带、鹅掌菜、黑昆布)
- **来源**: 海带科植物海带 *Laminaria japonica* Aresch. 或翅藻科植物昆布 *Ecklonia kurome* Okam. 的干燥叶状体
- **分布与生境**: 海带原产日本、朝鲜沿海和我国北方沿海,现在山东、辽宁、福建等地大量养殖;昆布(鹅掌菜)生在浙江、福建沿海低潮线下的岩石上
- **识别要点**:
  - 海带: 卷曲折叠成团或缠结成把;**黑褐色或绿褐色,表面附有白霜**;水浸软后膨胀成**扁平长带状**,长50-150 cm,宽10-40 cm,**中部较厚,边缘较薄而呈波状**;类革质,残留的柄部扁圆柱状;就是平常吃的干海带
  - 昆布(鹅掌菜): 卷曲皱缩成不规则团状,**黑色,较薄**;水浸软后成扁平的叶状,**两侧羽状深裂**,裂片长舌状(形似鹅掌);质柔滑
  - 气味: **气腥,味咸**
- **采收与加工**: 夏、秋二季采捞,晒干
- **储存**: 置干燥处,防潮;白霜(甘露醇)是正常现象,**不要洗掉再储存**
- **功效**: 消痰软坚散结,利水消肿
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **含碘极高**,甲状腺功能亢进、桥本甲状腺炎等甲状腺病患者不自用,作食物也要问医生;孕妇、哺乳期作为食物适量吃即可,不要大量"补碘";脾胃虚寒的人不宜(经验)。**颜色异常鲜绿、泡水掉色的海带**可能被染过色,不买

## 三、树脂类

乳香、没药、血竭原产热带(红海沿岸、东南亚),**全靠进口**;琥珀是埋在地下几千万年的树脂化石;冰片是提取或化学合成的结晶。这些药材**普通人采不到**,本节只写怎样分辨真假和怎样安全保存。树脂类的共同特点和检验方法:

```
1. 多数遇热软化、能燃烧,燃烧时的烟和气味是重要的鉴别依据
2. 不溶于水,但乳香、没药和水一起研磨能成乳状液
3. 常见的假货: 用松香(便宜的松树树脂)加染料、加砂土冒充,
   或用塑料、合成树脂冒充琥珀、用合成品冒充天然冰片
4. 多数内服量很小(冰片不到1 g),主要入丸散或外用;
   内服过量刺激胃肠,孕妇多需慎用
5. 怕热、易挥发(冰片)、易粘连: 密封,放阴凉处
```

另有一种有毒的树脂类药材**藤黄**,只能外用、不可内服,见[有毒中药-藤黄](./09-有毒中药与易混淆有毒植物.md#219-藤黄)。

### 3.1 乳香

- **正名(别名)**: 乳香(滴乳香、乳香珠、原乳香)
- **来源**: 橄榄科植物乳香树 *Boswellia carterii* Birdw. 及同属植物 *B. bhaw-dajiana* Birdw. 树皮渗出的树脂;按产地分索马里乳香、埃塞俄比亚乳香,按形状分乳香珠和原乳香
- **分布与生境**: 产红海沿岸的索马里、埃塞俄比亚和阿拉伯半岛干旱地区;我国全部进口
- **识别要点**:
  - 药材: **长卵形"滴乳"状**、类圆形颗粒,或粘合成不规则块,大的长约2 cm(乳香珠)或5 cm(原乳香);**表面黄白色,半透明,被有黄白色粉末**,久存颜色加深;质脆,遇热软化;破碎面有玻璃样或蜡样光泽
  - 气味: **有特异香气**,味微苦
  - 嚼试: 嚼时开始碎成小块,**很快软化成胶块,黏附牙齿**,唾液变成乳白色
  - 水试: 加水研磨成**白色或黄白色乳状液**
  - 火试: 燃烧时显油性,冒黑烟,有香气
- **伪品**: **松香**冒充或掺入: 松香透明度高、颜色偏黄,嚼起来不软化成胶团、不成乳状液,燃烧有明显的松节油气味;掺砂石的,捏碎后可见杂质(经验)
- **储存**: 密封,置阴凉干燥处;**夏季易软化粘连**
- **功效**: 活血定痛,消肿生肌
- **用量**: 煎汤或入丸散,3-5 g;外用适量,研末调敷(《中国药典》2020年版,在中医师指导下使用)。生品气味浓烈、刺激胃,多用醋炙等炮制品,见[中药制剂](../06-制药技术/04-中药制剂.md)
- **禁忌**: **孕妇及胃弱者慎用**;对乳香过敏的人外用也可出现皮疹

### 3.2 没药

- **正名(别名)**: 没药(末药、天然没药、胶质没药)
- **来源**: 橄榄科植物地丁树 *Commiphora myrrha* Engl. 或哈地丁树 *C. molmol* Engl. 的干燥树脂;分为天然没药和胶质没药
- **分布与生境**: 产索马里、埃塞俄比亚、阿拉伯半岛南部等干旱地区;全部进口
- **识别要点**:
  - 天然没药: 不规则颗粒状团块,大的直径6 cm以上;**表面黄棕色或红棕色**,近半透明部分棕黑色,被有黄色粉尘;质坚脆,破碎面不整齐,**无光泽**(乳香有光泽,没药无光泽,是两者的一个区别)
  - 胶质没药: 不规则块状和颗粒,多黏结成团块;表面棕黄色至棕褐色,**不透明**,质坚实或疏松
  - 气味: **有特异香气,味苦而微辛**(胶质没药味苦而有黏性)
  - 水试: 和水共研成**黄棕色乳状液**(乳香是白色乳状液)
- **伪品**: 掺入其他树胶、松香或泥沙(经验): 苦味淡、香气弱、有松节油味或杂质多的不用
- **储存**: 密封,置阴凉干燥处,防软化粘连
- **功效**: 散瘀定痛,消肿生肌
- **用量**: 3-5 g,炮制去油,多入丸散用(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇及胃弱者慎用**;常和乳香同用,两者都刺激胃,合用时更要注意

### 3.3 血竭

- **正名(别名)**: 血竭(麒麟竭、进口血竭)
- **来源**: 棕榈科植物麒麟竭 *Daemonorops draco* Bl. 果实渗出的树脂经加工制成
- **分布与生境**: 麒麟竭是一种藤本棕榈,产印度尼西亚、马来西亚等地;药典血竭全部进口
- **识别要点**:
  - 药材: 略呈**类圆四方形或方砖形**;**表面暗红色,有光泽**,附有摩擦产生的红粉;质硬而脆,破碎面红色,**研成粉是砖红色**
  - 气味: 气微,味淡;不溶于水,在热水中软化
  - **纸烤试验**(药典鉴别): 取粉末放在白纸上,隔着纸用火烘烤,**粉末熔化,但纸上没有向四周扩散的油迹**,对光看是**鲜艳的红色**
  - 火试: 用火点燃,产生**呛鼻的烟气**
- **"龙血竭"不是"血竭"**: 国产的**龙血竭**是天门冬科(旧归百合科、龙舌兰科)植物剑叶龙血树 *Dracaena cochinchinensis* 等的含脂木材提取出的树脂,产云南、广西,按部颁或地方标准使用,**不是药典"血竭"**;两者来源不同,功效相近但不能随意互相代替或混称
- **伪品**: 用**松香加红色染料**压成块冒充,或在真品中掺松香、泥土: 纸烤时**有油迹扩散**或**把纸染红一大片**、有松香气的是假货;用水或酒精擦拭**掉色**的可疑
- **储存**: 置阴凉干燥处,防热软化
- **功效**: 活血定痛,化瘀止血,生肌敛疮
- **用量**: 研末,1-2 g,或入丸剂;外用研末撒或入膏药用(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用,月经期不宜(经验);无瘀血的人不宜。外用止血只限小伤口,大出血按[外伤处理](../01-日常疾病和伤害/02-外伤处理.md)加压止血并就医

### 3.4 琥珀

- **正名(别名)**: 琥珀(血珀、煤珀)
- **来源**: 古代松科植物(多为松属)的树脂埋藏在地下,经过漫长地质年代形成的化石样物质;从泥土中挖出的称"琥珀",从煤层中挖出的称"煤珀"(黑色)。**《中国药典》2020年版一部未收载**,按部颁或地方标准使用
- **分布与生境**: 国内产广西、云南、河南、辽宁(抚顺煤珀)等地;另有缅甸、波罗的海沿岸等进口
- **识别要点**:
  - 药材: 不规则块状、颗粒状或多角形,大小不一;**血红色、黄棕色或暗棕色,近于透明**;质松脆,断面平滑,**有玻璃样光泽**;用手捻即成粉末
  - 气味: 无臭,味淡;**嚼之易碎,无沙砾感**
  - 摩擦起电: 在布或毛衣上用力摩擦后,**能吸起碎纸屑**
  - 盐水试: 琥珀很轻,在**饱和盐水中能浮起**;玻璃、多数矿石下沉(经验)
  - 热针试: 烧热的针尖轻触不显眼处,**有松香味**;塑料冒出刺鼻的塑料味(经验)
- **伪品**: **塑料、合成树脂**仿制品;用松香或年代很近的"柯巴树脂"(未完全石化的树脂)冒充: 柯巴树脂表面滴一滴酒精会**发黏**,真琥珀不受影响(经验)。工艺品琥珀常经过加热、压制、染色,**首饰琥珀不要当药材**
- **储存**: 置干燥处,避免高温和阳光长期直射
- **功效**: 镇惊安神,活血散瘀,利尿通淋(传统)
- **用量**: 研末冲服,一般1.5-3 g,**不入煎剂**(教材常用量;药典未收载,在中医师指导下使用)
- **禁忌**: 阴虚内热、无瘀血的人不宜(经验);小儿惊风、抽搐必须就医,不能靠琥珀"镇惊"

### 3.5 冰片

- **正名(别名)**: 冰片(龙脑、梅片、片脑)
- **来源**(药典按来源分为三种,用量不同):
  - **冰片(合成龙脑)**: 以松节油、樟脑等为原料**化学合成**,市面最常见、最便宜
  - **天然冰片(右旋龙脑)**: 樟科植物樟 *Cinnamomum camphora* (L.) Presl 的新鲜枝、叶经**提取加工**制成
  - **艾片(左旋龙脑)**: 菊科植物艾纳香 *Blumea balsamifera* (L.) DC. 的新鲜叶经提取加工制成的结晶
  - 古书的"龙脑香""梅片"是龙脑香科龙脑香树的树脂结晶,进口,现在很少见
- **分布与生境**: 天然冰片原料樟树(特定的"龙脑樟"化学型)主产江西、湖南等地;艾纳香产广东、广西、贵州、海南
- **识别要点**:
  - 合成冰片: **无色透明或白色半透明的片状松脆结晶**;**气清香,味辛、凉**;有挥发性,点燃产生浓烟,火焰明亮
  - 天然冰片: 白色结晶性粉末或片状结晶,气清香,味辛、凉,有挥发性
  - 天然品和合成品**外观几乎无法用肉眼区分**;合成冰片含相当比例的异龙脑,要靠实验室检测。价格相差很大,**标"天然冰片"但价格很低的要怀疑**
- **易混淆品**: **樟脑**(也是樟树提取的白色结晶,气味更冲、更像"樟木箱"味)**不是冰片**,口服可引起抽搐,**儿童误服几克就可能致命**;卫生球、樟脑丸(多为萘或对二氯苯)更不能入药
- **储存**: **密封**,置阴凉处;冰片极易挥发,开口放着会"越放越少"
- **功效**: 开窍醒神,清热止痛
- **用量**(《中国药典》2020年版,在中医师指导下使用):
  - 冰片(合成龙脑)、艾片: 0.15-0.3 g,入丸散用;外用研粉点敷患处
  - 天然冰片: 0.3-0.9 g,入丸散用;外用适量
  - **不入煎剂**(加热即挥发)
- **禁忌**: **孕妇慎用**;婴幼儿不要用(包括不要在婴幼儿口鼻附近涂含冰片的药膏);内服刺激胃肠,过量可引起恶心、呕吐、头晕;昏迷、中风、"闭证"必须立即就医,不能靠冰片"开窍"

## 四、其他加工品

这一组来源各不相同: 五倍子是蚜虫在树叶上刺激形成的"虫瘿";青黛、芦荟、儿茶是把植物的叶、汁或木材加工成粉末、浓缩物或煎膏;神曲是面粉和几种草药一起发酵的曲块。**除五倍子外,普通人很难自己采到合格的原料或加工出合格的成品**,本节重点仍是识别真伪和用药安全。

### 4.1 五倍子

- **正名(别名)**: 五倍子(百虫仓、肚倍、角倍)
- **来源**: 漆树科植物盐肤木 *Rhus chinensis* Mill.、青麸杨 *R. potaninii* Maxim. 或红麸杨 *R. punjabensis* Stew. var. *sinica* (Diels) Rehd. et Wils. 叶上的**虫瘿**,主要由五倍子蚜 *Melaphis chinensis* (Bell) Baker 寄生而形成;按外形分"肚倍"和"角倍"
- **分布与生境**: 盐肤木在长江流域及以南的山坡、林缘、荒地极常见;五倍子主产贵州、四川、湖北、湖南、云南、陕西等地
- **识别要点**:
  - 寄主盐肤木: 落叶小乔木或灌木;**奇数羽状复叶,叶轴上有明显的叶状"翅"**(这是认盐肤木最可靠的特征);小叶边缘有粗锯齿,背面有毛;秋天叶变红;果序上的小核果被白霜,舔一下**有咸酸味**(盐肤木因此得名)
  - 鲜虫瘿: 秋天挂在叶轴、叶柄上的绿色到红色的空心"果子",掰开里面是大量小蚜虫
  - 肚倍: 长圆形或纺锤形囊状,长2.5-9 cm,直径1.5-4 cm;**表面灰褐色或灰棕色,微有柔毛**;质硬而脆,断面角质样、有光泽,壁厚0.2-0.3 cm;**内壁平滑,有黑褐色死蚜虫和灰色粉状排泄物**
  - 角倍: 菱形,有不规则的钝角状分枝,柔毛较明显,壁较薄
  - 气味: 气特异,**味极涩**
- **⚠️ 不要和漆树、野漆混淆**: 漆树、野漆同属漆树科,也是羽状复叶、秋天变红,但**叶轴没有翅**;接触后可引起严重的过敏性皮炎("漆疮"),见[森林求生-有毒植物](../03-野外生存/02-森林求生.md#植物)。**叶轴无翅的树不碰**;对漆过敏的人采五倍子也要戴手套
- **采收与加工**: **秋季**虫瘿成熟、蚜虫还没有钻出来之前采摘(蚜虫飞出后虫瘿开裂,质量下降);采下后**放进沸水中略煮或蒸到表面呈灰色**,杀死里面的蚜虫,取出干燥
- **储存**: 置通风干燥处,防压碎
- **功效**: 敛肺降火,涩肠止泻,敛汗,止血,收湿敛疮
- **用量**: 3-6 g;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 外感咳嗽、湿热泻痢初起的人不宜(经验);含鞣质极多(可达50%以上),**大量内服可引起便秘、胃部不适**,并可能影响铁剂等药物吸收,与其他药同服间隔开(经验)。五倍子的鞣质也是传统鞣皮、制墨、染黑的原料,鞣皮方法见[植物鞣](../07-日常生活技能/07-纺织缝补与鞣皮.md#方法二-植物鞣适合去毛做皮革)

### 4.2 青黛

- **正名(别名)**: 青黛(靛花、蓝靛花)
- **来源**: 爵床科植物马蓝 *Baphicacanthus cusia* (Nees) Bremek.、蓼科植物蓼蓝 *Polygonum tinctorium* Ait. 或十字花科植物菘蓝 *Isatis indigotica* Fort. 的叶或茎叶**经加工制得的干燥粉末、团块或颗粒**
- **分布与生境**: 马蓝产福建、广东、四川、云南等南方地区(其根茎和根即"南板蓝根");菘蓝北方广泛栽培(其根即[板蓝根](./01-根及根茎类上.md#33-板蓝根),叶即大青叶);主产福建(建青黛)
- **识别要点**:
  - 药材: **深蓝色的粉末,体轻,易飞扬**;或为不规则多孔的团块、颗粒,用手一搓就成细末
  - 气味: 微有草腥气,味淡
  - 火试(药典鉴别): 取少量用微火灼烧,**有紫红色的烟雾产生**(靛蓝升华)
  - 水试: 撒在水面上**多数浮在水面**,水不明显变蓝(靛蓝不溶于水)(经验)
- **伪品**: **掺入过多石灰、滑石粉、泥土**增重: 手感沉,放在水里大量下沉,滴醋或稀盐酸冒大量气泡(石灰);**用化学染料染色**的粉末: 放在水里**水很快变蓝**,灼烧没有紫红色烟(经验)
- **产地加工**(了解即可): 传统做法是把鲜叶浸泡发酵,捞出枝叶后加石灰水反复搅打,**捞取浮在液面的蓝色泡沫**晒干即为青黛,沉在下面的是染布用的"蓝靛"。药用青黛要求杂质少,自制品难以达标
- **储存**: 置干燥处,**防潮**;粉末易飞扬,密封保存
- **功效**: 清热解毒,凉血消斑,泻火定惊
- **用量**: 1-3 g,宜入丸散用;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 胃寒、脾胃虚弱的人慎用;**不要长期内服**——有长期服用青黛后出现肺动脉高压、缺血性肠炎等的报道;孕妇不自用。外用治口疮、湿疹较常见,皮损范围大、渗液多的要就医

### 4.3 芦荟

- **正名(别名)**: 芦荟(老芦荟、新芦荟、象胆)
- **来源**: 百合科植物库拉索芦荟 *Aloe barbadensis* Miller、好望角芦荟 *A. ferox* Miller 或其他同属近缘植物**叶的汁液浓缩干燥物**;前者习称"老芦荟",后者习称"新芦荟"
- **分布与生境**: 原产非洲;我国南方(广东、广西、福建、海南、云南)有栽培,北方多作盆栽
- **识别要点**:
  - 植株: 多年生肉质草本;叶肥厚多汁,**披针形,边缘有刺状小齿**,簇生在短茎上;切开叶片,**中间是透明凝胶,紧贴叶皮的一层流出黄色苦汁**——药材芦荟就是这层黄汁浓缩干燥而成,不是透明凝胶
  - 老芦荟(库拉索芦荟): 不规则块状,常破裂为多角形;**表面暗红褐色或深褐色,无光泽**;体轻,质硬,不易破碎,断面粗糙或显麻纹;吸湿性强
  - 新芦荟(好望角芦荟): 表面暗褐色,略显绿色,**有光泽**;体轻,质松,易碎,**断面玻璃样**而有层纹
  - 气味: **有特殊臭气,味极苦**
- **易混淆品**: 家庭盆栽的"芦荟"品种很多,有些外形相似的观赏植物(如部分龙舌兰、虎尾兰)并不是芦荟;**不认识的品种不要吃**。市售"芦荟胶"是透明凝胶加工的外用品,与药材芦荟是两回事
- **储存**: 密封,置阴凉干燥处,**防潮**(吸湿后发黏结块)
- **功效**: 泻下通便,清肝泻火,杀虫疗疳
- **用量**: 2-5 g,宜入丸散;外用适量,研末敷患处(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**:
  - 药典标注"孕妇慎用";**本书建议孕妇不要内服芦荟**(刺激性泻药可刺激子宫收缩),哺乳期也不用
  - 是作用强烈的**刺激性泻药**,可引起腹部绞痛、腹泻;月经期、痔疮出血、**腹痛原因不明**(可能是阑尾炎、肠梗阻)的人不用;儿童不自用
  - 长期使用可致低血钾、肠道"懒惰"(依赖泻药)和结肠黑变病;**生吃大量芦荟叶**可引起腹泻、呕吐,甚至肾损害
  - 外用: 芦荟胶用于小面积轻度烫伤是可以的,见[烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤);对芦荟过敏的人可出现皮疹

### 4.4 儿茶

- **正名(别名)**: 儿茶(孩儿茶、黑儿茶)
- **来源**: 豆科植物儿茶 *Acacia catechu* (L. f.) Willd. 的**去皮枝、干的干燥煎膏**
- **分布与生境**: 儿茶是有刺的落叶小乔木,产云南南部(西双版纳等地)、广西、海南,也从印度、缅甸进口
- **识别要点**:
  - 药材: **方形或不规则块状**,大小不一;**表面棕褐色或黑褐色,光滑而稍有光泽**;质硬,易碎,断面不整齐,有光泽,**有细孔**,遇潮有黏性
  - 气味: 气微,**味涩、苦,略回甜**
- **易混淆品**: "方儿茶"(棕儿茶)是茜草科植物儿茶钩藤 *Uncaria gambier* 带叶嫩枝的煎膏,方块状、表面棕色、质较轻,历史上曾作儿茶用,但不是药典儿茶;掺淀粉、泥土的,断面颜色不匀、有沙粒感(经验)
- **采收与加工**: 冬季采收枝、干,除去外皮,砍成大块,加水煎煮,浓缩,干燥
- **储存**: 置干燥处,**防潮**(吸潮后发黏粘连)
- **功效**: 活血止痛,止血生肌,收湿敛疮,清肺化痰
- **用量**: 1-3 g,**包煎**;多入丸散服;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 含大量鞣质,内服可引起便秘;与铁剂、部分抗生素等同服可能影响吸收,间隔服用(经验)。外用治疮疡、湿疹,伤口化脓、范围扩大的要就医

### 4.5 神曲

- **正名(别名)**: 神曲(六神曲、六曲、建曲)
- **来源**: **不是《中国药典》(2020年版)一部收载的药材**,按各省市中药炮制规范等地方标准生产。传统上是用面粉(或麸皮)与苦杏仁、赤小豆和鲜青蒿、鲜苍耳、鲜辣蓼等几种草药混合后**发酵**制成的曲块,配方和工艺各地不一;"建曲"是福建的品种,加入的药物更多
- **识别要点**:
  - 药材: **方形或长方形块状**;表面**灰黄色,粗糙**;质脆易断,断面不平,类白色或黄白色,可见未粉碎的褐色草药残渣和**发酵产生的小孔洞**
  - 气味: **有陈腐的发酵气**,味苦
  - 炒神曲、焦神曲: 表面黄色或焦褐色,有焦香气
- **注意**: 本书**不提供神曲的发酵配方**: 原料中的苍耳有毒(见[苍耳幼苗和苍耳子](./09-有毒中药与易混淆有毒植物.md#410-苍耳幼苗和苍耳子)),发酵过程中杂菌污染可产生霉菌毒素,自制品质量无法保证。**酿酒、做酱用的酒曲、酱曲不是神曲**,不能代替
- **储存**: **极易生虫、发霉**: 密封,放阴凉干燥处,勤检查;**长了绿色、黑色霉斑或有霉臭、酸败味的不用**
- **功效**(传统): 健脾和胃,消食调中,用于饮食积滞、脘腹胀满
- **用量**: 一般6-15 g(教材常用量;药典未收载,在中医师指导下使用)。食积腹胀的常用配伍见[中药制剂-食积腹胀](../06-制药技术/04-中药制剂.md#食积腹胀)
- **禁忌**: 孕妇慎用(经验);脾阴虚、胃火盛的人不宜(经验)。**持续腹胀、食欲下降、消瘦、呕吐、黑便**的不是"积食",要就医查原因

## 五、易混淆汇总与自我检查

### 5.1 易混淆与风险汇总

| 本章品种 | 主要风险 | 怎样避免 |
|---------|---------|---------|
| 所有菌类 | 野外采蘑菇误食鹅膏菌等致命毒菌 | 不采野生菌入药、入食;只用正规药材 |

| 乳香、没药 | 松香冒充;刺激胃;孕妇用药风险 | 嚼试、水试;孕妇和胃弱者慎用 |
| 血竭 | 松香加染料的伪品;龙血竭混称 | 纸烤无油迹、对光鲜红;认准药典来源 |

| 冰片 | 合成品冒充天然品;樟脑误作冰片 | 看价格和检验报告;樟脑绝不内服,婴幼儿不用冰片 |

| 神曲 | 霉变;自制发酵污染;与酒曲混用 | 只用正规饮片;霉变的丢弃 |

### 5.2 自我检查

使用或购买本章药材之前,逐条确认:

- [ ] 我没有为了"找药用菌"去野外采不认识的蘑菇
- [ ] 冬虫夏草我只买、不采,而且会看足、环纹、子座和断面,掰开看有没有铁丝
- [ ] 茯苓片我嚼过、滴过碘酒,确认不是面粉压的
- [ ] 灵芝有漆样光泽和侧生长柄;没有的不当灵芝用
- [ ] 有甲状腺病的人不用海藻、昆布;方子里有甘草的不加海藻
- [ ] 树脂类(乳香、没药、血竭)做过嚼试、水试或纸烤试验,排除了松香
