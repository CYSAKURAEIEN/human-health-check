# 全草类

> **全草类是最常在野外采到的一类药材——它们长在路边、田埂、河滩,认得快,也认错得快;揉一片叶子闻一闻、掐一段茎看看有没有白汁,比记住名字更有用**

本章收录32味常用的全草类药材(药用部位是全株、地上部分、茎叶或带鳞叶的肉质茎;夏枯草用果穗、细辛只用根和根茎,按习惯也放在本章),按功效大致分为解表芳香、清热解毒、利湿退黄、活血止血、祛风补益及其他五组。识别、采收、干燥、储存的通用方法见[总论](./00-总论.md),本章不再重复。薄荷、蒲公英、鱼腥草、车前草、马齿苋、夏枯草、益母草的种植方法已写在[药用植物识别与种植指南](../04-动植物培育/04-药用植物.md),本章只写识别和采集。

## ⚠️ 先读这几条

```
1. 全草最常见的错误是"认错一棵草": 采之前至少核对3个特征
   (茎的形状、叶的排列、花、气味、断面有没有乳汁),
   有一项对不上就不采
2. 几个一定要记住的区分:
   - 薄荷: 揉碎有明确的清凉薄荷味;没有这股味的"野薄荷"不采
   - 马齿苋: 叶肉质、掐断是透明黏液;趴地生长、掐断流白色乳汁的
     是斑地锦、泽漆等大戟科植物,不采
   - 蒲公英: 一根花葶顶上只开一朵花;茎上分枝开多朵花的是苦苣菜、
     黄鹌菜等,多数无毒,但不是药典的蒲公英
3. 麻黄: 国家严格管制(麻黄碱是制毒原料),
   不要自行采集、收购、运输、使用;高血压、心脏病患者禁用
4. 细辛: 只用根和根茎(地上部分含马兜铃酸较多),
   有小毒、用量很小,不要自采自用
5. 青蒿不能代替抗疟药: 青蒿素是从黄花蒿中提取纯化的,
   煎煮青蒿的汤药里含量极低,疟疾必须就医
6. 石斛、肉苁蓉等的野生资源受国家保护,
   市售几乎都是栽培品,不要采挖野生
7. 益母草、泽兰等活血药孕妇不用;
   服华法林、阿司匹林等抗凝、抗血小板药的人用任何活血止血药前先问医生
8. 用量是《中国药典》(2020年版)成人每日的常规用量(饮片,水煎),
   只用来提醒"不要超量";用不用、用多少,在中医师指导下决定
9. 路边、农田边的全草容易沾农药、重金属和汽车尾气;
   远离公路、工厂、刚打过药的田地采集
```

## 一、解表芳香类

这一组多是唇形科、菊科的芳香草本,**揉碎叶子闻气味**是最快的认法。它们含挥发油,不耐久煎、不耐久放;麻黄是例外,它不是"香草",而是国家管制品种,列在这里只为让读者认得、避开。

### 1.1 薄荷

- **正名(别名)**: 薄荷(苏薄荷、南薄荷、野薄荷)
- **来源**: 唇形科植物薄荷 *Mentha haplocalyx* Briq. 的干燥地上部分
- **分布与生境**: 全国大部分地区有野生,溪边、沟旁、湿润草地;江苏、安徽、江西等地大量栽培
- **识别要点**:
  - 植株: 多年生草本,高30-60 cm;**茎四棱**;**叶对生**,长圆状披针形或卵形,边缘有锯齿;**轮伞花序生在叶腋**,一圈圈的淡紫色或白色小花;有匍匐的地下茎
  - 药材: 茎方柱形,紫棕色或淡绿色,棱角处有茸毛,断面白色,髓部中空;叶多皱缩,上表面深绿色,下表面灰绿色,对光可见凹点状腺鳞
  - 气味: **揉搓后有强烈的特殊清凉香气**,味辛凉——这是最重要的确认特征
- **易混淆品("假薄荷")**:
  - **留兰香**(绿薄荷、香花菜): 也是薄荷属,香气偏甜、**没有明显凉感**,花序集中在茎顶成长穗(薄荷的花在叶腋成轮);无毒,但不是药典薄荷
  - **唇萼薄荷**(欧薄荷、胡薄荷 *M. pulegium*): 有时作观赏或驱蚊植物栽培,香气刺鼻;含胡薄荷酮,**可伤肝,精油内服可致死**——不认识的"薄荷"不入药、不泡茶
  - 野外茎四棱、叶对生、有香气的唇形科植物很多(藿香、荆芥、紫苏、石荠苎等),彼此认错一般不致中毒;真正要防的是**把没有薄荷凉味的野草当成薄荷**
- **采收与加工**: 夏、秋二季茎叶茂盛或花开至三轮时,选晴天分次采割,晒干或阴干;阴干香气保留更好
- **储存**: 含挥发油,**香气越放越淡**;密封避光,放阴凉处,一般不超过1年
- **功效**: 疏散风热,清利头目,利咽,透疹,疏肝行气
- **用量**: 3-6 g,**后下**(其他药快煎好时再放,煮几分钟即可)(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 体虚多汗者不宜;**不要把薄荷油、清凉油涂在婴幼儿鼻孔附近**(可引起喉痉挛、呼吸困难);哺乳期大量服用可能减少乳汁(经验)
- 种植方法见[药用植物-薄荷](../04-动植物培育/04-药用植物.md#薄荷)

### 1.2 广藿香

- **正名(别名)**: 广藿香(藿香、枝香)
- **来源**: 唇形科植物广藿香 *Pogostemon cablin* (Blanco) Benth. 的干燥地上部分
- **分布与生境**: 原产东南亚,我国广东、海南、广西等地栽培;在国内很少开花,野外基本见不到野生的
- **识别要点**:
  - 植株: 多年生芳香草本或半灌木,高30-100 cm;茎直立、多分枝,**密被柔毛**;叶对生,卵圆形,边缘有粗钝齿,**两面都有灰白色绒毛**,摸起来柔软
  - 药材: 茎略呈方柱形,表面被柔毛,老茎近圆柱形、灰褐色;断面中部有髓;叶皱缩成团,展平后卵形,两面被灰白色绒毛
  - 气味: **香气特异而浓**,味微苦
- **易混淆品**: 北方常说的"藿香"多是**土藿香**(唇形科藿香 *Agastache rugosa*),野生或庭院常见,茎方而少毛,叶心状卵形,开紫色穗状花,**有茴香样甜香**;无毒,民间也作藿香用,但不是药典的广藿香
- **采收与加工**: 枝叶茂盛时采割,**日晒夜闷**(白天晒、晚上堆起来闷),反复至干
- **储存**: 含挥发油,密封,放阴凉干燥处,防香气散失
- **功效**: 芳香化浊,和中止呕,发表解暑
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺者不宜;夏天上吐下泻、发热口渴,先补液(见[腹泻类传染病](../01-日常疾病和伤害/15-传染病家庭防控.md#腹泻类传染病)),脱水、高热、精神差要就医

### 1.3 荆芥

- **正名(别名)**: 荆芥(香荆芥、假苏)
- **来源**: 唇形科植物荆芥 *Schizonepeta tenuisfolia* Briq. 的干燥地上部分;单用花穗的称"荆芥穗"
- **分布与生境**: 主产江苏、浙江、江西、河北等地,多为栽培;山坡路旁偶有野生
- **识别要点**:
  - 植株: 一年生草本,高60-100 cm;茎四棱,被短柔毛;**叶对生,羽状3-5深裂,裂片细条形**(这一点和薄荷、藿香明显不同);**穗状轮伞花序生于枝顶**,淡紫色小花
  - 药材: 茎方柱形,上部有分枝,表面淡黄绿色或淡紫红色,被短柔毛;断面类白色;叶多已脱落;花穗长2-9 cm
  - 气味: **气芳香**,味微涩而辛凉
- **易混淆品**: 同科的**猫薄荷**(荆芥属 *Nepeta cataria*)名字相近,叶为卵形、不深裂,不是药典荆芥;与其他唇形科香草混采一般不致中毒,但功效不同
- **采收与加工**: 夏、秋二季**花开到顶、穗绿时**采割,除去杂质,晒干
- **储存**: 含挥发油,密封,放阴凉干燥处
- **功效**: 解表散风,透疹,消疮
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 表虚自汗、阴虚头痛者不宜;皮疹伴发热、呼吸困难或面部肿胀要就医

### 1.4 香薷

- **正名(别名)**: 香薷(青香薷、江香薷)
- **来源**: 唇形科植物石香薷 *Mosla chinensis* Maxim. 或江香薷 *M. chinensis* 'Jiangxiangru' 的干燥地上部分。前者习称"青香薷",后者习称"江香薷"
- **分布与生境**: 石香薷野生于华东、华南、西南的山坡草地、石缝;江香薷主要在江西栽培
- **识别要点**:
  - 植株: 一年生直立草本,高10-40 cm(江香薷可达50 cm以上);茎方形,**被白色长柔毛**;**叶对生,条状披针形,边缘有疏浅锯齿,两面有腺点**;顶生总状花序,淡紫红色小花
  - 药材: 全体密被白色茸毛;茎方柱形,基部紫红色,上部黄绿色;叶多皱缩或脱落
  - 气味: **气清香而浓**,味微辛而凉
- **易混淆品**: 民间叫"香薷"的还有香薷属的海州香薷、香薷(*Elsholtzia ciliata*,又称土香薷),叶片宽卵形、花序偏向一侧;一般无毒,但不是药典品种
- **采收与加工**: 夏季茎叶茂盛、花盛时择晴天采割,除去杂质,**阴干**
- **储存**: 含挥发油,密封,放阴凉处
- **功效**: 发汗解表,化湿和中
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 发汗力较强,**表虚多汗、中暑大汗淋漓者不用**;中暑见头晕乏力、体温很高、意识不清的,先降温补液、就医,不要只靠香薷

### 1.5 佩兰

- **正名(别名)**: 佩兰(省头草、醒头草、兰草)
- **来源**: 菊科植物佩兰 *Eupatorium fortunei* Turcz. 的干燥地上部分
- **分布与生境**: 长江以南各地的路边、灌丛、溪边,也有栽培
- **识别要点**:
  - 植株: 多年生草本,高40-100 cm;**茎圆柱形**(不是方的),常带紫红色;叶对生,中部叶常**3全裂**,裂片长椭圆形,边缘有锯齿;**头状花序小,排成伞房状,花白色或带淡红色**
  - 药材: 茎圆柱形,表面黄棕色或黄绿色,有明显的节和纵棱线;断面髓部白色或中空;叶多皱缩破碎,绿褐色
  - 气味: **气芳香**,味微苦
- **易混淆品**: **泽兰**(见[4.2](#42-泽兰))名字相近,但泽兰是唇形科、**茎方形**、花在叶腋成轮,两者功效不同;同属(泽兰属)的不少野生种外形相似
- **采收与加工**: 夏、秋二季分两次采割,除去杂质,晒干
- **储存**: 密封,放阴凉干燥处,防香气散失
- **功效**: 芳香化湿,醒脾开胃,发表解暑
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 研究发现佩兰含**吡咯里西啶类生物碱**(可伤肝,和菊三七的有毒成分同属一类),**不长期、不大量服用**;泽兰属的其他野生种不要拿来代用;肝病患者、孕妇不用

### 1.6 麻黄

- **正名(别名)**: 麻黄(草麻黄、麻黄草)
- **来源**: 麻黄科植物草麻黄 *Ephedra sinica* Stapf、中麻黄 *E. intermedia* Schrenk et C. A. Mey. 或木贼麻黄 *E. equisetina* Bge. 的干燥草质茎
- **分布与生境**: 内蒙古、山西、河北、宁夏、甘肃、新疆等地的干旱草原、荒漠、沙丘
- **识别要点**(只为认得、避开):
  - 植株: 矮小灌木,高20-40 cm;**看上去几乎没有叶子**,只有一丛丛**绿色细长、有节的草质茎**,节上有膜质的鳞片状小叶;雌株结红色肉质"果"(苞片)
  - 药材: 细长圆柱形,有细纵棱线,触之微有粗糙感;节明显;**断面髓部红棕色**(习称"玫瑰心");气微香,味涩、微苦
  - 和木贼(问荆类)的区别: 木贼茎中空、节上的鞘齿一圈、可从节处拔开再插回;麻黄髓部红棕色、不能这样拔插
- **采收与加工**: 由取得许可的单位按计划采收;个人不采
- **功效**: 发汗散寒,宣肺平喘,利水消肿
- **用量**: **只能由医师处方、正规药房调配,不自行使用**(本书不列自用剂量)
- **禁忌**: 麻黄含**麻黄碱**,可升高血压、加快心率、引起心律失常和失眠。**高血压、冠心病和其他心脏病、甲亢、青光眼、前列腺增生排尿困难的人禁用**;体虚多汗者不用;正服降压药、抗抑郁药(尤其单胺氧化酶抑制剂)的人不用;运动员注意麻黄碱属兴奋剂
- ⚠️ **法律提醒**: 麻黄碱、麻黄浸膏等属于**第一类易制毒化学品**;国务院2000年专门发文制止滥挖甘草和麻黄草,各地对麻黄草的采集、收购、运输实行许可管理,无证收购、运输会被扣押查处。**不要自行采集、收购、运输、使用麻黄草**;另有"麻黄根"(止汗)是不同的药材,同样不要自采

## 二、清热解毒类

这一组是路边、田边最常见的野草,很多同时是野菜。它们大多性寒味苦,**脾胃虚寒、经常腹泻的人不宜多用久用**。"清热解毒"不等于消炎药: 伤口红肿扩散、出现红线、发热,化脓性感染、阑尾炎、肺炎,都必须就医。

### 2.1 蒲公英

- **正名(别名)**: 蒲公英(婆婆丁、黄花地丁、奶汁草)
- **来源**: 菊科植物蒲公英 *Taraxacum mongolicum* Hand.-Mazz.、碱地蒲公英 *T. borealisinense* Kitam. 或同属数种植物的干燥全草
- **分布与生境**: 全国各地的路边、田埂、草地、河滩、庭院,极常见
- **识别要点**:
  - 植株: 多年生草本,**没有地上茎**;叶全部从根头生出,平铺成莲座状,倒披针形,**羽状深裂,裂片常倒向叶基("倒向羽裂")**;全株**折断有白色乳汁**
  - 花: **花葶中空、不分枝,一根花葶顶上只开一朵黄色头状花**;花后结白色绒球("蒲公英伞")
  - 药材: 皱缩卷曲的团块;根圆锥状,多弯曲,棕褐色,根头部有棕褐色或黄白色茸毛;叶绿褐色,多皱缩破碎;花茎1至数条,头状花序黄褐色或淡黄白色;气微,味微苦
- **易混淆品**:
  - **苦苣菜**(苦菜 *Sonchus oleraceus*)、**苣荬菜**: 也开黄花、有白色乳汁,但**有明显的、会分枝的地上茎**,茎上的叶基部抱茎,一株开多朵花
  - **黄鹌菜** *Youngia japonica*: 也有莲座叶,但从中抽出**多分枝的花茎,顶上密生许多直径不到1 cm的小黄花**
  - 抱茎小苦荬、山莴苣等也类似。这些多数是传统野菜、一般无毒,但不是药典蒲公英;认准"无茎、单花、中空花葶"三条即可
  - 真正要防的是把**开黄花的毛茛**(叶掌状分裂、花瓣有蜡样光泽、没有乳汁,有毒)、**千里光**(有吡咯里西啶生物碱)当作蒲公英
- **采收与加工**: 春至秋季**花初开时**连根采挖,除去杂质,洗净,晒干;嫩叶当野菜时随时可采
- **储存**: 易受潮发霉;干透后放通风干燥处
- **功效**: 清热解毒,消肿散结,利尿通淋
- **用量**: 10-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 用量过大可引起腹泻;对菊科植物过敏者不用;乳房红肿热痛伴发热(乳腺炎)、硬块不消,要就医
- 种植方法见[药用植物-蒲公英](../04-动植物培育/04-药用植物.md#蒲公英)

### 2.2 紫花地丁

- **正名(别名)**: 紫花地丁(地丁、箭头草、犁头草)
- **来源**: 堇菜科植物紫花地丁 *Viola yedoensis* Makino 的干燥全草
- **分布与生境**: 全国大部分地区的田间、路边、荒地、草坡、林缘,早春开花
- **识别要点**:
  - 植株: 多年生矮小草本,高4-14 cm,**没有地上茎**;叶基生、莲座状,长圆形或舌状披针形,基部截形或稍心形,**叶柄上部有狭翅**;叶形像箭头或犁头
  - 花: 从叶丛中抽出细长花梗,**花紫堇色,左右对称,5个花瓣,下面一瓣向后延伸成细管状的"距"**;蒴果椭圆形,成熟后裂成3瓣
  - 药材: 多皱缩成团;主根长圆锥形,淡黄棕色;叶灰绿色;蒴果椭圆形或裂为三果瓣,种子多数;气微,味微苦而稍黏
- **易混淆品**: 叫"地丁"的植物有好几种: 同属的早开堇菜等常被混采(无毒,但不是药典品种);**苦地丁**(罂粟科地丁草)是另一味药,含生物碱,叶多回羽状细裂、花淡紫色呈细长筒状;豆科的**米口袋**(甜地丁)开紫色蝶形花、叶为羽状复叶。认准"叶不分裂、花有距、蒴果三裂"
- **采收与加工**: 春、秋二季采收全草,除去杂质,晒干
- **储存**: 放通风干燥处,防潮
- **功效**: 清热解毒,凉血消肿
- **用量**: 15-30 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 体质虚寒者慎用;疔疮痈肿红肿扩散、出现红线、发热,要就医(可能需要切开排脓和抗生素)

### 2.3 鱼腥草

- **正名(别名)**: 鱼腥草(蕺菜、折耳根、侧耳根)
- **来源**: 三白草科植物蕺菜 *Houttuynia cordata* Thunb. 的新鲜全草或干燥地上部分
- **分布与生境**: 长江流域及以南各地的阴湿沟边、田埂、林下、溪边;西南地区作蔬菜大量栽培
- **识别要点**:
  - 植株: 多年生草本,高15-50 cm;地下茎白色、有节,节上生根;**叶互生,心形**,下面常带紫红色,有细腺点;托叶膜质,与叶柄合生成鞘
  - 花: 穗状花序顶生,**基部有4片白色花瓣状苞片**,远看像一朵白色小花
  - 气味: **揉碎有浓烈的鱼腥气**——这是确认特征
  - 药材: 茎扁圆柱形,扭曲,表面黄棕色,有纵棱,节明显;叶卷折皱缩,展平后心形,上表面暗黄绿色至暗棕色,下表面灰绿色;搓碎有鱼腥气,味涩
- **易混淆品**: 同科的**三白草**也长在水边,但叶为长卵形,花序旁的叶片变白,**没有鱼腥气**;没有鱼腥味的"鱼腥草"不采
- **采收与加工**: 鲜品全年均可采割;干品夏季茎叶茂盛、花穗多时采割,除去杂质,晒干
- **储存**: 干品防潮,密封,鱼腥气会逐渐变淡
- **功效**: 清热解毒,消痈排脓,利尿通淋
- **用量**: 15-25 g,**不宜久煎**;鲜品用量加倍,水煎或捣汁服;外用适量,捣敷或煎汤熏洗(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 虚寒者不宜多服;**鱼腥草注射液曾有严重过敏反应的报道**,这和口服饮片不同,不要自己用任何注射剂;咳嗽伴高热、气促、咳脓痰或血痰,要就医
- 种植方法见[药用植物-鱼腥草](../04-动植物培育/04-药用植物.md#鱼腥草折耳根)

### 2.4 败酱草

- **正名(别名)**: 败酱草(败酱、黄花败酱、苦菜)
- **来源**: **2020年版《中国药典》一部未收载**,按地方标准和传统用药: 败酱科(新分类并入忍冬科)植物**黄花败酱** *Patrinia scabiosifolia* Fisch. ex Trev. 或**白花败酱** *P. villosa* (Thunb.) Juss. 的干燥全草。**北方许多地区习惯把菊科的苣荬菜当作"败酱草"(北败酱)**,两者是完全不同的植物
- **分布与生境**: 黄花败酱、白花败酱分布于全国大部分地区的山坡草地、林缘、路边、灌丛
- **识别要点**:
  - 植株(黄花败酱): 多年生草本,高可达1-2 m;基生叶丛生,茎生叶**对生,羽状深裂或全裂**;**顶生大型伞房状聚伞花序,密生许多黄色小花**(白花败酱开白花,叶多不裂或3裂)
  - 气味: **根和根茎有一股陈腐的酱臭味**(因此得名),干后更明显
  - 药材: 根茎有节,上生须根;茎圆柱形,黄绿色至黄棕色,节明显;叶多皱缩破碎;有特异陈腐酱臭气,味微苦
- **易混淆品**: 北败酱(苣荬菜)开黄色舌状花、有白色乳汁、叶互生,与有"酱臭"、叶对生、伞房状小黄花的黄花败酱容易区分。用哪一种,按当地中医师的习惯
- **采收与加工**: 夏、秋二季采挖全草,洗净,晒干
- **储存**: 放通风干燥处,防潮
- **功效**: 清热解毒,消痈排脓,祛瘀止痛(按传统用法)
- **用量**: 常用6-15 g(药典未收载,按教材和经验,在中医师指导下使用)
- **禁忌**: 脾胃虚弱、腹泻者慎用;**右下腹痛、发热(怀疑阑尾炎)必须就医**,不能靠败酱草

### 2.5 马齿苋

- **正名(别名)**: 马齿苋(马齿菜、长寿菜、瓜子菜)
- **来源**: 马齿苋科植物马齿苋 *Portulaca oleracea* L. 的干燥地上部分
- **分布与生境**: 全国各地的菜地、田边、路旁、墙脚,夏秋季极常见,也是传统野菜
- **识别要点**:
  - 植株: 一年生**肉质**草本,茎平卧或斜升,多分枝,**圆柱形,淡绿色或带紫红色,光滑无毛**;叶互生或近对生,**倒卵形、像马齿或小勺子,肥厚多汁**;黄色小花,早上开、中午后合
  - 断面: **掐断流出透明的黏液,没有白色乳汁**
  - 药材: 多皱缩卷曲成团;茎表面黄褐色,有明显纵沟纹;叶易破碎,完整叶片倒卵形,绿褐色;果实圆锥形,内含多数细小黑色种子;气微,味微酸
- **易混淆品(重要)**: **大戟科**的斑地锦、地锦草、泽漆、飞扬草等也常趴地生长、茎带红色,有的生在同一块地里——**它们折断有白色乳汁**,叶片薄而小、不肉质(泽漆是直立的,叶在茎顶轮生成"五朵云")。大戟科乳汁刺激皮肤和眼睛,误食引起口腔灼痛、剧烈呕吐腹泻。**有白色乳汁的一律不是马齿苋**
- **采收与加工**: 夏、秋二季采收,除去残根和杂质,洗净,**略蒸或用开水烫一下再晒干**(肉质多汁,直接晒很难干、易腐烂)
- **储存**: 干品易受潮发霉,干透后密封
- **功效**: 清热解毒,凉血止血,止痢
- **用量**: 9-15 g;外用适量,捣敷患处(《中国药典》2020年版,在中医师指导下使用);当野菜按日常食量吃是安全的
- **禁忌**: 性寒,脾胃虚寒、腹泻的人少吃;孕妇不宜大量食用或入药;含草酸较多,肾结石患者不要大量吃;腹泻伴高热、脓血便、严重脱水要就医
- 种植和食用见[药用植物-马齿苋](../04-动植物培育/04-药用植物.md#马齿苋)

### 2.6 穿心莲

- **正名(别名)**: 穿心莲(一见喜、榄核莲、苦胆草)
- **来源**: 爵床科植物穿心莲 *Andrographis paniculata* (Burm. f.) Nees 的干燥地上部分
- **分布与生境**: 原产南亚,我国广东、广西、福建、海南等地栽培,北方少见;野外遇到的多是逸生
- **识别要点**:
  - 植株: 一年生草本,高50-80 cm;**茎四棱,节稍膨大**;叶对生,卵状披针形或披针形,全缘或稍浅波状;花小,白色带紫色斑纹,二唇形;**蒴果长椭圆形,像橄榄核**
  - 药材: 茎方柱形,多分枝,节稍膨大,质脆易折断;叶多皱缩、易碎,上表面绿色,下表面灰绿色
  - 味道: **味极苦**(叶尤甚),只需舔一下叶片碎屑就能确认;气微
- **易混淆品**: 茎四棱、叶对生的植物很多;但没有任何一种像它这么苦。不苦的不是穿心莲
- **采收与加工**: 秋初茎叶茂盛时采割,晒干;叶的有效成分含量高于茎,采收时尽量保留叶片
- **储存**: 叶易碎,轻拿轻放;放干燥处
- **功效**: 清热解毒,凉血,消肿
- **用量**: 6-9 g;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 苦寒伤胃,**不宜多服久服**,脾胃虚寒者不宜;可引起皮疹等过敏反应,穿心莲类注射剂有严重过敏反应报道;孕妇慎用

### 2.7 白花蛇舌草

- **正名(别名)**: 白花蛇舌草(蛇舌草、二叶葎)
- **来源**: **2020年版《中国药典》一部未收载**,按地方标准: 茜草科植物白花蛇舌草 *Hedyotis diffusa* Willd. 的干燥全草(有的地方标准还收载纤花耳草)
- **分布与生境**: 长江以南各地的田埂、水田边、湿润旷地、路旁
- **识别要点**:
  - 植株: 一年生**纤细披散**草本,高20-50 cm,从基部分枝;**叶对生,无柄,线形**,长1-3 cm,宽仅1-3 mm,托叶基部合生
  - 花: **白色小花,单生或成对生在叶腋,花梗很短或几乎没有**;花冠4裂;蒴果扁球形,顶端有宿存的萼齿
  - 药材: 缠绕成团,灰绿色或灰棕色;茎细而卷曲,质脆易折断;气微,味淡
- **易混淆品**: **水线草**(伞房花耳草 *H. corymbosa*)外形极像,最常混用——它的花**2-5朵排成伞房状,有明显的总花梗**;其他耳草属植物也常混入。混用一般不会中毒,但不是同一种药
- **采收与加工**: 夏、秋二季采收全草,洗净,晒干
- **储存**: 放通风干燥处,防潮
- **功效**: 清热解毒,利湿通淋,消痈(按传统用法)
- **用量**: 常用15-30 g(药典未收载,按地方标准和经验,在中医师指导下使用)
- **禁忌**: 孕妇慎用;脾胃虚寒者不宜久服。**民间常把它当"抗癌草",但它不能代替手术、化疗、放疗等正规治疗**——不要因此延误就医

### 2.8 半枝莲

- **正名(别名)**: 半枝莲(狭叶韩信草、并头草)
- **来源**: 唇形科植物半枝莲 *Scutellaria barbata* D. Don 的干燥全草
- **分布与生境**: 华北以南各地的水田边、溪沟边、湿润草地
- **识别要点**:
  - 植株: 多年生草本,高12-35 cm;茎四棱,无毛或上部疏生短毛;叶对生,三角状卵形或卵状披针形,边缘有疏浅钝齿
  - 花: **花单生于茎上部叶腋,都偏向一侧**,像半边的花枝(因此叫"半枝莲");花冠蓝紫色,二唇形,长约1 cm;**花萼背面有一个小圆盾状突起**(黄芩属的特征)
  - 药材: 长15-35 cm,无毛或花轴上疏被毛;茎方柱形,丛生,表面暗紫色或棕绿色;叶多皱缩;果实扁球形,浅棕色;气微,味微苦
- **易混淆品**: 同属的**韩信草**等常被混采,叶较宽、心状卵形、两面有毛;**和"半边莲"(桔梗科,有小毒)只差一个字**,是两种不同的药,不要按名字互相替代
- **采收与加工**: 夏、秋二季茎叶茂盛时采挖,洗净,晒干
- **储存**: 放通风干燥处
- **功效**: 清热解毒,化瘀利尿
- **用量**: 15-30 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇不宜(化瘀);血虚者慎用。和白花蛇舌草一样,**不能代替正规抗癌治疗**

### 2.9 夏枯草

- **正名(别名)**: 夏枯草(夏枯球、棒槌草、铁色草)
- **来源**: 唇形科植物夏枯草 *Prunella vulgaris* L. 的干燥**果穗**(不是全草)
- **分布与生境**: 全国大部分地区的路边、荒坡、草地、林缘、田埂
- **识别要点**:
  - 植株: 多年生草本,高20-30 cm;**茎四棱,常带紫红色**;叶对生,卵形或卵状披针形;**顶生短而粗的穗状花序,像一个小棒槌**,花冠紫色或蓝紫色,一层层轮生;**夏至前后花穗变成棕褐色、像枯了一样**("夏枯")
  - 药材: 圆柱形果穗,略扁,长1.5-8 cm,直径0.8-1.5 cm,淡棕色至棕红色;由数轮至十几轮**宿萼与苞片**组成,每轮有2片对生的扇形苞片,先端尖尾状,脉纹明显,外表面有白毛;每片苞片内有花3朵,宿萼内有4枚小坚果;体轻,气微,味淡
- **易混淆品**: 其他唇形科的花穗(如野生的风轮菜、筋骨草的花序)形状不同;认准"短粗棒槌形、苞片扇形带尾尖、夏季变褐"
- **采收与加工**: 夏季果穗呈棕红色时采收,除去杂质,晒干
- **储存**: 放通风干燥处,防潮防虫
- **功效**: 清肝泻火,明目,散结消肿
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 性寒,脾胃虚弱者慎用;**脖子上、乳房里摸到肿块,不要自己用"散结"的草药,先去医院查清楚**;有降血压作用的报道,服降压药的人先问医生
- 种植和野外识别补充见[药用植物-夏枯草](../04-动植物培育/04-药用植物.md#夏枯草)

### 2.10 淡竹叶

- **正名(别名)**: 淡竹叶(竹叶麦冬、山鸡米)
- **来源**: 禾本科植物淡竹叶 *Lophatherum gracile* Brongn. 的干燥茎叶。**它是一种草,不是竹子的叶**;竹子(淡竹等)的叶另称"竹叶",是不同的药
- **分布与生境**: 长江流域以南各地的山坡林下、阴湿的路旁和沟边
- **识别要点**:
  - 植株: 多年生草本,高40-80 cm;须根中部常膨大成**纺锤形的小块根**(像小麦冬);叶片披针形,长6-20 cm,宽1.5-2.5 cm
  - 关键特征: **叶片的平行脉之间有横向的小脉,对着光看呈一个个长方形小格子**,叶背面更明显——这是区别其他禾草的最好方法
  - 药材: 茎圆柱形,有节,表面淡黄绿色,断面中空;叶鞘开裂;叶片浅绿色或黄绿色,有长方形网格状脉纹;体轻,质柔韧;气微,味淡
- **易混淆品**: 林下的其他禾草、莎草叶片没有"长方形格子";鸭跖草(俗称"竹叶菜")是另一种植物,不能代替
- **采收与加工**: 夏季**未抽花穗前**采割,晒干
- **储存**: 放通风干燥处
- **功效**: 清热泻火,除烦止渴,利尿通淋
- **用量**: 6-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 体虚有寒者不宜;孕妇慎用(经验);尿频尿痛伴发热、腰痛、尿血要就医

### 2.11 青蒿

- **正名(别名)**: 青蒿(黄花蒿、臭蒿、草蒿)
- **来源**: 菊科植物**黄花蒿** *Artemisia annua* L. 的干燥地上部分。注意: 药典"青蒿"的植物来源是黄花蒿;植物学上另有一种叫"青蒿"(香蒿 *A. carvifolia*)的植物,**几乎不含青蒿素**,不是药典青蒿
- **分布与生境**: 全国各地的路旁、荒地、山坡、河岸,极常见
- **识别要点**:
  - 植株: 一年生草本,高1-2 m;茎直立,多分枝;**叶3回羽状深裂,裂片细小,像胡萝卜叶**;**头状花序极多、很小(直径1.5-2.5 mm)、球形、黄色**,排成大型圆锥状花序;**揉碎有浓烈的特殊香气**
  - 香蒿的区别: 头状花序较大(直径3.5-4 mm)、半球形,叶的裂片较宽
  - 药材: 茎圆柱形,上部多分枝,表面黄绿色或棕黄色,有纵棱线;质略硬,断面中部有髓;叶暗绿色或棕绿色,卷缩易碎;气香特异,味微苦
- **易混淆品**: 蒿属植物极多(艾、茵陈、野艾蒿等),叶形和花序不同,多数无毒;但要避开**叶像胡萝卜、开白色伞形花的伞形科植物**(可能是毒芹类,见[毒芹 vs 水芹、野胡萝卜](./09-有毒中药与易混淆有毒植物.md#43-毒芹-vs-水芹野胡萝卜))——蒿属开的是黄绿色小球状花,不是白色伞
- **采收与加工**: 秋季**花盛开时**采割,除去老茎,**阴干**(青蒿素不耐高温,不要暴晒、烘烤)
- **储存**: 密封,放阴凉干燥处
- **功效**: 清虚热,除骨蒸,解暑热,截疟,退黄
- **用量**: 6-12 g,**后下**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚弱、腹泻者慎用
- ⚠️ **不能代替抗疟药**: 抗疟药青蒿素是从黄花蒿中**提取、纯化**得到的,再制成青蒿素类药物(青蒿琥酯、蒿甲醚等),并且要与其他抗疟药联合使用。**煎煮青蒿的汤药里青蒿素含量极低、不稳定,不能治疗疟疾**。到过疟疾流行区后出现发热、寒战,必须尽快就医查血

## 三、利湿退黄类

这一组用于黄疸、小便不利、尿路结石等。**黄疸、尿路结石、尿痛发热都是需要查明原因的病**: 皮肤和眼白发黄(可能是肝炎、胆道梗阻、溶血)、肾绞痛、尿血、发热腰痛,先就医,不要只靠草药"退黄""排石"。

### 3.1 茵陈

- **正名(别名)**: 茵陈(绵茵陈、花茵陈、茵陈蒿)
- **来源**: 菊科植物滨蒿 *Artemisia scoparia* Waldst. et Kit. 或茵陈蒿 *A. capillaris* Thunb. 的干燥地上部分。春季采收的习称"绵茵陈",秋季采割的称"花茵陈"
- **分布与生境**: 全国大部分地区的路边、河岸、沙地、山坡、荒地
- **识别要点**:
  - 春季幼苗: 高6-10 cm,**全体密被灰白色绢毛,摸起来绵软如绒**,叶片细裂;这时采的是"绵茵陈",也是早春野菜
  - 成株: 半灌木状或多年生草本,高40-100 cm;叶1-3回羽状全裂,**裂片细如丝状**;秋季开大量**很小的卵球形头状花序**,排成大型圆锥花序
  - 药材(绵茵陈): 多卷曲成团,灰白色或灰绿色,全体密被白色茸毛,绵软如绒;叶展平后1-3回羽状分裂,小裂片卵形或稍呈倒披针形、条形;**气清香**,味微苦
- **易混淆品**: 蒿属幼苗(艾、野艾蒿、黄花蒿等)常混采,多数无毒;茵陈幼苗的特点是**细裂的叶加上满身灰白绒毛**。民谚"三月茵陈四月蒿,五月六月当柴烧",说的是采收期
- **采收与加工**: 春季幼苗高6-10 cm时采收,或秋季花蕾长成至花初开时采割;除去杂质和老茎,晒干
- **储存**: 绵茵陈轻软,易受潮结块、发霉;放干燥处,防压
- **功效**: 清利湿热,利胆退黄
- **用量**: 6-15 g;外用适量,煎汤熏洗(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 血虚萎黄者慎用;**出现黄疸必须就医查明原因**;新生儿黄疸不要自行用茵陈煎水喂服

### 3.2 车前草

- **正名(别名)**: 车前草(车轱辘菜、蛤蟆草)
- **来源**: 车前科植物车前 *Plantago asiatica* L. 或平车前 *P. depressa* Willd. 的干燥全草。成熟种子另作"车前子",见[果实种子类-车前子](03-果实种子类.md#55-车前子)
- **分布与生境**: 全国各地的路边、田埂、草地、庭院、沟旁,极常见,耐踩踏
- **识别要点**:
  - 植株: 多年生(平车前为一年生或二年生)草本,**没有地上茎**;叶全部从根头生出,平铺成莲座状;叶片卵形或椭圆形,**有5-7条从叶基弧形伸到叶尖的粗脉**;**扯断叶柄能拉出白色细丝**
  - 花: 从叶丛中抽出数条直立的**细长穗状花序**,花很小,淡绿色;蒴果成熟时横向盖裂,种子细小、黑褐色
  - 两种的区别: 车前为须根;平车前有一条明显的圆柱状直根
  - 药材: 根丛生、须状(车前)或有直根(平车前);叶具长柄,皱缩,展平后卵状椭圆形或宽卵形,灰绿色或污绿色,有明显弧形脉5-7条;穗状花序数条;气微香,味微苦
- **易混淆品**: 一般不易认错。要注意叶脉同样是弧形平行脉的两种有毒植物: **藜芦**(有地上茎,叶片有明显纵向褶皱,茎基部有棕色网状毛,见[藜芦](./09-有毒中药与易混淆有毒植物.md#218-藜芦))和**铃兰**(北方林下,叶常2片、基部包成鞘,开一串白色铃铛花)——它们都不贴地长成莲座、也没有细长的绿色花穗
- **采收与加工**: 夏季采挖全草,除去泥沙,晒干
- **储存**: 放通风干燥处,防潮
- **功效**: 清热利尿通淋,祛痰,凉血,解毒
- **用量**: 9-30 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 有利尿作用,孕妇、肾功能不好的人、服利尿药的人先问医生;尿频尿痛伴发热、腰痛、尿血,要就医
- 种植和野外识别补充见[药用植物-车前草](../04-动植物培育/04-药用植物.md#车前草)

### 3.3 金钱草

- **正名(别名)**: 金钱草(过路黄、大金钱草、对座草)
- **来源**: 报春花科植物过路黄 *Lysimachia christinae* Hance 的干燥全草
- **分布与生境**: 长江流域及以南各地的山坡路旁、沟边、林缘湿地;四川为主产地
- **识别要点**:
  - 植株: 多年生**匍匐**草本,茎柔弱,平卧地面延伸,长20-60 cm,下部节上生根;**叶对生**,卵圆形、近圆形或肾圆形,全缘;**黄色小花成对生于叶腋,花梗长**
  - 关键特征: **叶片用水泡软后对着光看,能看到黑色或褐色的短条纹(腺条)**
  - 药材: 常缠结成团,无毛或被疏柔毛;茎扭曲,棕色或暗棕红色,断面实心;叶对生,展平后宽卵形或心形,叶柄长1-4 cm;有的带花,花黄色、单生叶腋、具长梗;蒴果球形;气微,味淡
- **易混淆品(同名异物很多)**:
  - **广金钱草**(豆科,药典另列一条): 直立或平卧的小灌木状草本,叶为圆形单叶或3小叶,**背面密生白色绒毛**
  - **连钱草**(唇形科活血丹,药典另列一条): **茎四棱,揉碎有香气**,开淡紫色唇形花
  - **江西金钱草**(马蹄金,旋花科)、**小金钱草**(天胡荽,伞形科)等: 叶互生、肾形或圆形,地方习用
  - 这些一般不致中毒,但功效不同,按处方用名取药
- **采收与加工**: 夏、秋二季采收,除去杂质,晒干
- **储存**: 放通风干燥处
- **功效**: 利湿退黄,利尿通淋,解毒消肿
- **用量**: 15-60 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾虚泄泻者慎用。**肾绞痛伴发热、尿少或无尿、结石较大、只有一个肾的人,必须就医**,不能靠喝金钱草"排石"——梗阻合并感染可迅速危及生命

## 四、活血止血类

这一组与月经、出血、瘀血有关。**活血药增加出血风险,止血药也不能掩盖出血的原因**: 孕妇、月经过多、有出血倾向、正在服用华法林、阿司匹林、氯吡格雷等抗凝或抗血小板药的人,用前先问医生;吐血、便血(黑便)、咯血、尿血、月经大出血,先就医。

### 4.1 益母草

- **正名(别名)**: 益母草(坤草、茺蔚、益母艾)
- **来源**: 唇形科植物益母草 *Leonurus japonicus* Houtt. 的新鲜或干燥地上部分。成熟果实另作"茺蔚子"
- **分布与生境**: 全国各地的田野、路边、荒地、山坡草地、河边
- **识别要点**:
  - 植株: 一年生或二年生草本,高0.5-1 m;**茎四棱**,叶对生;**叶形变化大**: 幼苗期基生叶近圆形、边缘浅裂,茎中下部叶**掌状3深裂**,越往上越细,顶部叶近条形
  - 花: **一圈圈轮生在上部叶腋**,花冠粉红色至淡紫色,二唇形;**花萼有5个刺尖,干后扎手**
  - 药材(干品): 茎表面灰绿色或黄绿色,体轻,质韧,断面中部有髓;叶片灰绿色,多皱缩、破碎、易脱落;轮伞花序腋生,小花淡紫色;气微,味微苦
- **易混淆品**: 同属的**细叶益母草**(叶裂片更细)常被混用;唇形科的**夏至草**、**錾菜**外形相近,花白色或叶不深裂。幼苗期叶近圆形,注意和有毒的**毛茛**幼苗区分——毛茛茎圆、叶互生、开有蜡样光泽的黄花
- **采收与加工**: 鲜品春季幼苗期至初夏花前期采割;干品夏季**茎叶茂盛、花未开或初开时**采割,晒干,或切段晒干
- **储存**: 放通风干燥处,防潮
- **功效**: 活血调经,利尿消肿,清热解毒
- **用量**: 9-30 g;鲜品12-40 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇不用**(药典标注"孕妇慎用";它能兴奋子宫,本书从严);月经量多、有出血倾向的人不用;**大量或长期服用有损伤肾脏的报道,肾功能不好的人不用**;服抗凝、抗血小板药的人不用;产后出血多、发热、腹痛要就医
- 种植和野外识别补充见[药用植物-益母草](../04-动植物培育/04-药用植物.md#益母草)

### 4.2 泽兰

- **正名(别名)**: 泽兰(地瓜儿苗、地笋)
- **来源**: 唇形科植物毛叶地瓜儿苗 *Lycopus lucidus* Turcz. var. *hirtus* Regel 的干燥地上部分
- **分布与生境**: 全国大部分地区的沼泽地、水边、沟边、潮湿草地
- **识别要点**:
  - 植株: 多年生草本,高0.6-1.7 m;**地下有白色肥厚、横走的根茎("地笋",可食)**;**茎方形**,通常不分枝,节上常有毛;叶对生,披针形,边缘有锐锯齿,几乎无柄
  - 花: **白色小花簇生在叶腋,成一轮轮**
  - 药材: 茎方柱形,少分枝,四面有浅纵沟,黄绿色或带紫色,节处紫色明显,有白色茸毛;断面黄白色,髓部中空;叶上表面黑绿色,下表面灰绿色,密具腺点,两面有短毛;花簇生叶腋成轮状,花冠多脱落;气微,味淡
- **易混淆品**: **佩兰**(菊科,茎圆,头状花序,见[1.5](#15-佩兰))名字相近,古籍中二者也常混称;认准"茎方、花在叶腋成轮、地下有白色地笋"
- **采收与加工**: 夏、秋二季茎叶茂盛时采割,晒干
- **储存**: 放通风干燥处
- **功效**: 活血调经,祛瘀消痈,利水消肿
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇不用**(活血);血虚无瘀者慎用;服抗凝药的人先问医生。地笋当蔬菜按日常食量吃是安全的

### 4.3 仙鹤草

- **正名(别名)**: 仙鹤草(龙芽草、脱力草、黄龙尾)
- **来源**: 蔷薇科植物龙芽草 *Agrimonia pilosa* Ledeb. 的干燥地上部分
- **分布与生境**: 全国各地的山坡、路旁、草地、林缘、溪边
- **识别要点**:
  - 植株: 多年生草本,高30-120 cm,全株被白色柔毛;**奇数羽状复叶,大小叶相间排列**(几对大的小叶之间夹着很小的小叶)——这是最好认的特征;托叶镰形
  - 花与果: **细长的总状花序,开黄色小花,5瓣**;果实倒圆锥形,**顶端有一圈钩刺**,常粘在衣服、裤腿上
  - 药材: 全体被白色柔毛;茎下部圆柱形、红棕色,上部方柱形、四面略凹陷、绿褐色,有纵沟和棱线,断面中空;羽状复叶暗绿色,皱缩卷曲,大小两种小叶相间生于叶轴上;气微,味微苦
- **易混淆品**: 蔷薇科的路边青(水杨梅)等也有羽状叶、黄花、带钩的果,但没有"大小叶相间"和细长花穗;一般无毒
- **采收与加工**: 夏、秋二季茎叶茂盛时采割,除去杂质,干燥
- **储存**: 放通风干燥处
- **功效**: 收敛止血,截疟,止痢,解毒,补虚
- **用量**: 6-12 g;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 出血量大、反复出血、原因不明的出血(如黑便、咯血、尿血)必须就医;"截疟"同样不能代替抗疟药。外伤止血见[外伤处理](../01-日常疾病和伤害/02-外伤处理.md)

### 4.4 小蓟

- **正名(别名)**: 小蓟(刺儿菜、刺菜、青青菜)
- **来源**: 菊科植物刺儿菜 *Cirsium setosum* (Willd.) MB. 的干燥地上部分
- **分布与生境**: 全国各地的田间、路边、荒地,是常见的农田杂草,嫩苗也是传统野菜
- **识别要点**:
  - 植株: 多年生草本,高30-80 cm;**有长长的横走根,常成片生长**;叶互生,椭圆形或长椭圆状披针形,**全缘或有浅齿,边缘有细密的针刺**,不深裂
  - 花: **头状花序单生或数个生于茎顶,紫红色,全为管状花**;总苞钟状,苞片多层;雌雄异株
  - 药材: 茎圆柱形,灰绿色或带紫色,有纵棱和白色柔毛,断面中空;叶皱缩或破碎,展平后长椭圆形或长圆状披针形,齿尖有针刺,两面有白色柔毛;总苞钟状,苞片5-8层,黄绿色;花紫红色;气微,味微苦
- **易混淆品**: 大蓟(见[4.5](#45-大蓟))。同样带刺的**苍耳**叶为宽三角状心形、果实为带钩刺的小枣核状,幼苗和果实有毒,见[苍耳幼苗和苍耳子](./09-有毒中药与易混淆有毒植物.md#410-苍耳幼苗和苍耳子)
- **采收与加工**: 夏、秋二季花开时采割,除去杂质,晒干
- **储存**: 放通风干燥处
- **功效**: 凉血止血,散瘀解毒消痈
- **用量**: 5-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒、无瘀滞者慎用;**尿血、便血、反复鼻出血要就医查原因**

### 4.5 大蓟

- **正名(别名)**: 大蓟(蓟、马蓟、虎蓟)
- **来源**: 菊科植物蓟 *Cirsium japonicum* Fisch. ex DC. 的干燥地上部分
- **分布与生境**: 全国大部分地区的山坡、草地、路旁、林缘
- **识别要点**:
  - 植株: 多年生草本,高0.5-1 m;根簇生,有纺锤状块根;茎直立,有纵棱和毛;**叶羽状深裂,裂片边缘有粗大、坚硬的刺**,基部叶较大
  - 花: **头状花序较大(直径约3-4 cm),紫红色**,单生或数个生于枝顶
  - 和小蓟的区别: 大蓟植株大、**叶羽状深裂、刺硬而粗**、有块根;小蓟叶多不裂、刺细密、有横走根、成片生长
  - 药材: 茎圆柱形,绿褐色或棕褐色,有数条纵棱,被丝状毛,断面灰白色,髓部疏松或中空;叶皱缩,多破碎,羽状深裂,边缘有不等长的针刺;头状花序球形或椭圆形,总苞黄褐色,苞片披针形,冠毛羽状,灰白色;气微,味淡
- **易混淆品**: 飞廉、其他蓟属植物常混入,一般无毒;与苍耳的区别同上
- **采收与加工**: 夏、秋二季花开时采割地上部分,除去杂质,晒干
- **储存**: 放通风干燥处
- **功效**: 凉血止血,散瘀解毒消痈
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 同小蓟

### 4.6 墨旱莲

- **正名(别名)**: 墨旱莲(旱莲草、鳢肠、墨汁草)
- **来源**: 菊科植物鳢肠 *Eclipta prostrata* L. 的干燥地上部分
- **分布与生境**: 全国大部分地区的田边、沟边、路旁、水田湿地
- **识别要点**:
  - 植株: 一年生草本,高15-60 cm,茎直立或斜升,**全株被白色粗毛**;叶对生,披针形,近无柄;**头状花序小(直径6-8 mm),白色**;瘦果扁,黑褐色
  - 关键特征: **折断茎叶,流出的汁液在几分钟内变成蓝黑色**(因此叫"墨汁草")
  - 药材: 全体被白色茸毛;茎圆柱形,有纵棱,绿褐色或墨绿色;叶对生,展平后长披针形,全缘或有浅齿,墨绿色;头状花序直径2-6 mm;瘦果椭圆形而扁,棕色或浅褐色;气微,味微咸
- **易混淆品**: 田边开白色小花的菊科植物很多(如鬼针草: 叶为羽状复叶、瘦果顶端有倒刺);**汁液不变黑的不是墨旱莲**
- **采收与加工**: 花开时采割,晒干
- **储存**: 放通风干燥处
- **功效**: 滋补肝肾,凉血止血
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒、大便溏泄者慎用;出血要先查原因

## 五、祛风、补益及其他

这一组来源杂: 伸筋草是蕨类,石斛是兰科附生植物,肉苁蓉、锁阳是荒漠里的寄生植物,细辛只用根。**石斛、肉苁蓉的野生资源受国家保护,补肾阳的几味常被当作"壮阳保健品"长期自服**——这两点是本组最需要注意的。

### 5.1 伸筋草

- **正名(别名)**: 伸筋草(石松、过山龙、宽筋藤)
- **来源**: 石松科植物石松 *Lycopodium japonicum* Thunb. 的干燥全草
- **分布与生境**: 长江以南各地及东北的山坡林下、灌丛、林缘,喜酸性土
- **识别要点**:
  - 植株: 多年生常绿的蕨类(石松类)植物,**没有花**;**匍匐茎细长,贴地横走,可达2 m**,向上生出直立的分枝;**叶很小,针形或钻形,螺旋状密生在茎上**,整株像一条条小松枝;直立枝顶端生2-8个**圆柱形的孢子囊穗**,成熟时散出大量黄色粉末(石松粉,极易燃)
  - 药材: 匍匐茎细圆柱形,略弯曲,下有黄白色细根;直立茎二叉状分枝;叶密生,螺旋状排列,皱缩弯曲,线形或针形,黄绿色至淡黄棕色,先端芒状;质柔软,断面皮部浅黄色,木部类白色;气微,味淡
- **易混淆品**: **蛇足石杉(千层塔)**也是石松类,但**直立丛生、没有长匍匐茎,叶较宽、披针形、边缘有锯齿**;它含石杉碱甲,误用过量可引起恶心、出汗、心跳变慢,不要混入。南方常用的垂穗石松(铺地蜈蚣)也常作伸筋草用
- **采收与加工**: 夏、秋二季茎叶茂盛时采收,除去杂质,晒干;只割取部分匍匐茎,不要连片扯光
- **储存**: 放通风干燥处
- **功效**: 祛风除湿,舒筋活络
- **用量**: 3-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用;关节红肿热痛、外伤后肿胀变形、腰腿痛伴下肢麻木无力,要就医

### 5.2 石斛

- **正名(别名)**: 石斛(金钗石斛、黄草、吊兰花)
- **来源**: 兰科植物金钗石斛 *Dendrobium nobile* Lindl.、霍山石斛 *D. huoshanense* C. Z. Tang et S. J. Cheng、鼓槌石斛 *D. chrysotoxum* Lindl. 或流苏石斛 *D. fimbriatum* Hook. 的**栽培品**及其同属植物近似种的新鲜或干燥茎。铁皮石斛(*D. officinale*,加工成螺旋状的"铁皮枫斗")在药典中另列一条
- **分布与生境**: 野生于云南、贵州、广西、四川、安徽等地,**附生在阴湿林中的树干上或岩石上**;现在药材主要来自大棚栽培和仿野生附树、附石栽培
- **识别要点**:
  - 植株: 多年生附生草本;**茎丛生,有明显的节**,像一节节的竹竿;叶革质,两列互生,常在第二年脱落;花大而美丽(金钗石斛白色带紫红色先端)
  - 药材(金钗石斛): **扁圆柱形**,长20-40 cm,节间长2.5-3 cm;表面金黄色或黄中带绿色,有深纵沟;质硬而脆,断面较疏松;气微,味苦
  - 药材(鼓槌石斛): **粗纺锤形**,中部直径1-3 cm,具3-7节;表面金黄色,有明显凸起的棱;质轻而松脆,断面海绵状;味淡,**嚼之有黏性**
  - 鲜石斛: 圆柱形或扁圆柱形,黄绿色,节上有膜质叶鞘;肉质多汁,易折断;味微苦而回甜,嚼之有黏性
- **易混淆品**: 市场上有用金石斛属、石仙桃等其他兰科植物的茎冒充,多数无毒但没有药效;价格高的"野生石斛""霍山石斛"冒充最多。到正规药店购买栽培品
- **采收与加工**: 全年均可采收(栽培品)。鲜用者除去根和泥沙;干用者除去杂质,用开水略烫或烘软,再边搓边烘晒,至叶鞘搓净,干燥
- **储存**: 干品防潮防虫;鲜石斛可栽在湿沙中保存
- **功效**: 益胃生津,滋阴清热
- **用量**: 6-12 g;鲜品15-30 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 舌苔厚腻、腹胀、大便溏泄者不宜;温热病初起、阴液未伤者不宜
- 🛡️ **保护提醒**: 2021年《国家重点保护野生植物名录》将**石斛属所有野生种**列为国家二级保护,其中曲茎石斛和霍山石斛为一级;所有兰科植物也列入CITES附录Ⅱ;石斛还在《国家重点保护野生药材物种名录》中(级别均以名录原文为准)。**不采挖、不买卖野生石斛**,包括从树上、岩壁上"顺手"摘下的

### 5.3 淫羊藿

- **正名(别名)**: 淫羊藿(仙灵脾、三枝九叶草)
- **来源**: 小檗科植物淫羊藿 *Epimedium brevicornu* Maxim.、箭叶淫羊藿 *E. sagittatum* (Sieb. et Zucc.) Maxim.、柔毛淫羊藿 *E. pubescens* Maxim. 或朝鲜淫羊藿 *E. koreanum* Nakai 的干燥叶(2020年版药典只用叶;巫山淫羊藿另列一条)
- **分布与生境**: 陕西、甘肃、山西、四川、湖北、东北等地的山坡林下、灌丛、阴湿处
- **识别要点**:
  - 植株: 多年生草本,高20-60 cm,根状茎坚硬;**茎生叶多为二回三出复叶,共9片小叶("三枝九叶")**,箭叶淫羊藿为一回三出复叶;**小叶卵圆形或箭形,基部心形,两侧小叶的基部明显不对称(外侧耳状)**,边缘有刺毛状细锯齿,近革质;花小,有距,白色或淡黄色
  - 药材: 小叶片卵圆形,长3-8 cm,先端微尖;顶生小叶基部心形,两侧小叶偏心形;边缘有黄色刺毛状细锯齿;上表面黄绿色,下表面灰绿色,主脉7-9条,网脉明显;近革质;气微,味微苦
- **易混淆品**: 同属其他种常混用;小檗科、毛茛科有些有毒植物也是三出复叶(如部分毛茛科植物),认准"革质小叶、基部不对称、边缘刺毛状锯齿"
- **采收与加工**: 夏、秋季茎叶茂盛时采收,晒干或阴干
- **储存**: 放干燥处,防潮防霉
- **功效**: 补肾阳,强筋骨,祛风湿
- **用量**: 6-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺者不宜;**有淫羊藿及含淫羊藿的中成药引起肝损伤的报道**,不长期大量服,肝病患者不用;不要当"壮阳保健品"长期自服;性功能问题可能是糖尿病、心血管病的信号,先就医

### 5.4 肉苁蓉

- **正名(别名)**: 肉苁蓉(大芸、苁蓉、沙漠人参)
- **来源**: 列当科植物肉苁蓉 *Cistanche deserticola* Y. C. Ma 或管花肉苁蓉 *C. tubulosa* (Schenk) Wight 的干燥带鳞叶的肉质茎
- **分布与生境**: 内蒙古、宁夏、甘肃、新疆的荒漠和沙地。**肉苁蓉寄生在梭梭的根上,管花肉苁蓉寄生在柽柳(红柳)的根上**;现在主要来自人工接种的栽培品
- **识别要点**:
  - 植株: **没有绿叶的寄生草本**;肉质茎粗壮,圆柱形,大部分埋在沙中,**被覆瓦状排列的鳞片叶**;春季露出地面,顶端是粗大的穗状花序,花冠管状钟形,淡黄白色带紫色或淡紫色
  - 药材(肉苁蓉): 扁圆柱形,稍弯曲,长3-15 cm,直径2-8 cm;表面棕褐色或灰棕色,密被覆瓦状排列的肉质鳞叶;体重,质硬,微有柔性;**断面棕褐色,有淡棕色点状维管束排列成波状环纹**;气微,味甜、微苦
  - 药材(管花肉苁蓉): 类纺锤形或扁纺锤形;断面颗粒状,灰棕色至灰褐色,**点状维管束散生**
- **易混淆品**: 锁阳(见[5.5](#55-锁阳))、同属的盐生肉苁蓉、沙苁蓉,以及列当科的草苁蓉、列当等常被冒充,断面维管束排列不同;到正规渠道购买
- **采收与加工**: 春季苗刚出土时或秋季冻土之前采挖,除去茎尖,切段,晒干
- **储存**: 含糖多,**易吸潮、发霉、虫蛀**;干透后密封
- **功效**: 补肾阳,益精血,润肠通便
- **用量**: 6-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺、大便泄泻者不宜;实热便秘不宜;不要当"壮阳保健品"长期自服
- 🛡️ **保护提醒**: 野生肉苁蓉列入2021年《国家重点保护野生植物名录》,也在《国家重点保护野生药材物种名录》中(级别以名录原文为准)。**挖野生肉苁蓉违法,还会破坏梭梭固沙林**;市售应选人工栽培品

### 5.5 锁阳

- **正名(别名)**: 锁阳(地毛球、锈铁棒)
- **来源**: 锁阳科植物锁阳 *Cynomorium songaricum* Rupr. 的干燥肉质茎
- **分布与生境**: 新疆、甘肃、青海、内蒙古、宁夏的荒漠、盐碱地;**寄生在白刺等植物的根上**
- **识别要点**:
  - 植株: **没有绿叶的寄生草本**;茎圆柱形,暗紫红色,大部分埋在沙中,有散生的鳞片叶;春季露出地面,**顶端是棒状的肉穗花序,密生暗紫红色小花**,像插在沙地上的一根紫红色棒槌
  - 药材: 扁圆柱形,微弯曲,长5-15 cm,直径1.5-5 cm;表面棕色或棕褐色,粗糙,有明显纵沟和不规则凹陷,有的残存三角形的黑棕色鳞片;体重,质硬,难折断;**断面浅棕色或棕褐色,有黄色三角状维管束**;气微,味甘而涩
- **易混淆品**: 与肉苁蓉的区别——肉苁蓉表面密被覆瓦状鳞叶、断面维管束呈波状环纹或点状散生;锁阳表面粗糙有纵沟、鳞片少、断面是三角状维管束
- **采收与加工**: 春季采挖,除去花序,切段,晒干
- **储存**: 防潮、防虫
- **功效**: 补肾阳,益精血,润肠通便
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺、脾虚泄泻、实热便秘者不宜;不长期自服"壮阳"
- 🛡️ **资源提醒**: 野生锁阳因过度采挖而减少,采挖还会破坏荒漠植被;部分地区有地方保护规定。不鼓励采挖野生,用栽培或正规渠道的药材

### 5.6 细辛

- **正名(别名)**: 细辛(辽细辛、北细辛、华细辛)
- **来源**: 马兜铃科植物北细辛 *Asarum heterotropoides* Fr. Schmidt var. *mandshuricum* (Maxim.) Kitag.、汉城细辛 *A. sieboldii* Miq. var. *seoulense* Nakai 或华细辛 *A. sieboldii* Miq. 的干燥**根和根茎**。前两种习称"辽细辛"
- **分布与生境**: 北细辛、汉城细辛分布于东北;华细辛分布于陕西、湖北、四川、浙江等地;生于林下阴湿处、山沟腐殖质厚的地方
- **识别要点**(只为认得,**不要自采自用**):
  - 植株: **矮小草本,贴地生长**;叶通常1-2片,**心形或肾形,有长柄**;**花单生在叶柄基部,紧贴地面,紫褐色,壶形或钟形**,常被落叶盖住;全株有辛辣气味
  - 药材: 常卷曲成团;根茎横生,呈不规则圆柱状,有环形的节,分枝顶端有碗状茎痕;根细长,密生节上,长10-20 cm,直径约0.1 cm,灰黄色;质脆,断面黄白色或白色;**气辛香,味辛辣、麻舌**
- **易混淆品**: 同属的杜衡、土细辛等常被混作细辛;马兜铃科的其他植物(马兜铃属的藤本)同样含马兜铃酸。**山里自采的"细辛"往往是带叶的全草,还可能是别的种**
- **为什么只用根**: 马兜铃酸主要集中在地上部分(叶),所以从2005年版药典起,细辛的药用部位改为只用根和根茎,2020年版沿用。马兜铃酸可造成不可逆的肾损害并致癌,详见[细辛: 只用根和根茎](./09-有毒中药与易混淆有毒植物.md#33-细辛-只用根和根茎)和[含马兜铃酸的药材](./09-有毒中药与易混淆有毒植物.md#三含马兜铃酸的药材)
- **采收与加工**: 夏季果熟期或初秋采挖,**除净地上部分**和泥沙,阴干
- **储存**: 含挥发油,密封,放阴凉干燥处
- **功效**: 解表散寒,祛风止痛,通窍,温肺化饮
- **用量**: 1-3 g;散剂每次服0.5-1 g;外用适量(《中国药典》2020年版)。**用量很小,只能由中医师处方,不自行使用**;古人早有细辛不可多用的告诫,超量可引起头痛、呕吐、烦躁、抽搐、呼吸抑制
- **禁忌**: **药典标注有小毒**;不宜与藜芦同用;孕妇、哺乳期妇女、儿童、肾病患者不用;气虚多汗、阴虚头痛、干咳无痰者不用;不要用带叶的细辛全草;出现上述中毒症状立即拨打120
- 🛡️ **保护提醒**: 细辛列入《国家重点保护野生药材物种名录》(级别以名录原文为准),不采挖野生

## 六、易混淆汇总与自我检查

### 6.1 易混淆与风险汇总

| 本章品种 | 主要风险 | 怎样避免 |
|---------|---------|---------|
| 薄荷 | 唇萼薄荷等"假薄荷"(伤肝)、无香味的野草 | 揉碎必须有清凉薄荷味;不认识的"薄荷"不入药、不泡茶 |
| 马齿苋 | 斑地锦、泽漆等大戟科植物(有白色乳汁) | 掐断看汁液: 透明黏液才是马齿苋 |
| 蒲公英 | 苦苣菜、黄鹌菜混采;毛茛、千里光误采 | 无地上茎、花葶中空、一葶一花、有白色乳汁 |
| 青蒿 | 当作抗疟药 | 疟疾必须就医;煎汤不能治疟 |
| 夏枯草 | 用来"散结"而延误肿块检查 | 摸到肿块先去医院 |
| 车前草 | 藜芦、铃兰(弧形平行脉) | 贴地莲座、长叶柄、细长绿色花穗 |
| 金钱草、败酱草、地丁 | 同名异物多 | 按处方用名和当地习惯取药 |
| 佩兰、淫羊藿 | 长期大量服可能伤肝 | 不长期自服;肝病不用 |
| 益母草、泽兰、半枝莲 | 孕妇用后可致流产;增加出血风险 | 孕妇不用;服抗凝药的人先问医生 |
| 伸筋草 | 千层塔(蛇足石杉)混入 | 认准长匍匐茎、针形叶 |
| 麻黄 | 升血压、心律失常;国家管制 | 不采、不收、不运、不自用 |
| 细辛 | 马兜铃酸肾损害;过量中毒 | 只用正规药房的根和根茎,遵医嘱 |
| 石斛、肉苁蓉、锁阳 | 野生资源受保护或稀少 | 只用栽培品 |
| 白花蛇舌草、半枝莲 | 被当作"抗癌草"延误治疗 | 不能代替手术、化疗、放疗 |

### 6.2 自我检查

采全草类药材之前,逐条确认:

- [ ] 我核对了至少3个特征: 茎圆还是方、叶对生还是互生、花的形状颜色、气味、有没有乳汁
- [ ] 这一类最容易混淆的有毒植物(大戟科、毛茛、伞形科、藜芦等)我已经排除
- [ ] 采集地远离公路、工厂、矿区和刚打过农药的田地
- [ ] 它不是麻黄、细辛、石斛、肉苁蓉等管制或受保护的品种
- [ ] 我只割取了一部分地上部分,留下了根和种株
- [ ] 采回后摊开晾晒,含挥发油的(薄荷、藿香、荆芥、香薷、青蒿)阴干、不暴晒
- [ ] 我知道药典用量和禁忌,孕妇、儿童、肝肾病人、服抗凝药的人先问医生

## 📝 本章要点

```
□ 全草采前核对3个特征: 茎形、叶序、花、气味、乳汁
□ 薄荷必须有清凉味;没有薄荷味的"野薄荷"不采
□ 马齿苋掐断是透明黏液;有白色乳汁的是大戟科,不采
□ 蒲公英一根中空花葶只开一朵花
□ 麻黄国家管制,不采不用;高血压、心脏病禁用
□ 细辛只用根和根茎,有小毒,地上部分含马兜铃酸,不自采自用
□ 青蒿汤不能治疟疾;疟疾必须就医
□ 石斛、肉苁蓉的野生资源受国家保护,只用栽培品
□ 益母草、泽兰孕妇不用;活血止血药服抗凝药的人先问医生
□ 黄疸、结石、肿块、出血,先查原因,不要只靠草药
```
