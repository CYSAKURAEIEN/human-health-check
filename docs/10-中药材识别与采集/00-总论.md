# 中药材识别与采集总论

> **先认准,再采收,后加工储存——认错一味药,比没有药更危险**

本章是第十部分《中药材识别与采集》的总论,不讲具体某一味药,而是讲所有药材共用的方法: 怎样分类、怎样识别、什么时候采、采后怎样加工和储存、药典用量怎样理解、哪些安全和法律底线不能碰。后面各章逐味介绍药材时,都默认读者已经读过本章。

## ⚠️ 先读这几条

```
1. 本部分是识别参考,不是用药指南:
   能看医生、能买到正规药材时,先就医、去药店买;
   自采药材只用于买不到药的情况,具体用不用、用多少,在中医师指导下决定
2. 认不准就不采、不用:
   "看起来像"不算认识;很多剧毒植物和常用药材长得很像
   (钩吻像金银花、毒芹像野芹菜、商陆根像人参、
   曼陀罗像茄科蔬菜、乌头的块根像芋头)
3. 有毒的植物绝不口尝:
   性状鉴定里的"尝",只适用于已经确认无毒的药材;
   不认识的植物、怀疑有毒的植物,一律不入口
4. "天然"不等于"无毒":
   超量、长期服用、认错品种、和西药同用都可能伤肝伤肾甚至致命
5. 孕妇、哺乳期妇女、儿童、老人、肝肾病人、长期服西药的人,
   用任何中药前先问医生
6. 不采挖国家重点保护的野生植物,不使用、不买卖保护动物制品;
   自然保护区内禁止采集
7. 出现口舌发麻、心慌、心跳乱、剧烈呕吐、抽搐、呼吸困难 →
   立即停用,拨打120,带上剩余药材和药渣去医院
```

## 二、中药材的分类

### 2.1 按药用部位分类

中药材的来源分植物、动物、矿物三大类,其中植物药占绝大多数。本部分按**药用部位**分类,因为同一部位的药材,采收时间、加工方法、储存要点大体相同,也最方便野外辨认。

| 类别 | 包括什么 | 常见例子 | 采收要点 |
|------|---------|---------|---------|
| 根及根茎类 | 根、根茎、块茎、球茎、鳞茎 | 黄芪、甘草、党参、当归、天麻、贝母 | 多在秋冬或早春 |
| 果实种子类 | 完整果实、果皮、种子、种仁 | 山楂、枸杞、五味子、陈皮、酸枣仁 | 成熟或近成熟 |
| 全草类 | 地上部分或带根全株 | 蒲公英、车前草、薄荷、益母草、鱼腥草 | 多在花期 |
| 花叶类 | 花蕾、花、柱头;叶 | 金银花、菊花、红花;艾叶、桑叶 | 花在含苞或初开;叶在花前或盛花期 |
| 皮类 | 树皮、根皮 | 杜仲、厚朴、黄柏、牡丹皮、肉桂 | 多在春夏之交 |
| 藤木类 | 藤茎、茎枝、心材 | 鸡血藤、桑枝、苏木、降香 | 多在秋冬 |
| 菌藻树脂类 | 真菌、藻类、地衣;树脂 | 茯苓、灵芝、猪苓;海藻、昆布;乳香、没药 | 各不相同 |
| 动物类 | 动物全体、部分组织、分泌物、加工品 | 地龙、蝉蜕、鸡内金、阿胶、蜂蜜 | 多涉及保护法规 |
| 矿物类 | 天然矿物、矿物加工品、化石 | 石膏、滑石、芒硝、龙骨 | 部分含汞砷铅,有毒 |

```
同一植物常有多个药用部位,名称和功效都不同,别混用:
- 桑: 桑叶(叶)、桑枝(嫩枝)、桑白皮(根皮)、桑椹(果穗)
- 枸杞: 枸杞子(果实)、地骨皮(根皮)
- 莲: 莲子、莲子心、莲房、莲须、荷叶、藕节
- 橘: 陈皮(成熟果皮)、青皮(幼果或未成熟果皮)、橘核、橘络
- 忍冬: 金银花(花蕾或初开的花)、忍冬藤(茎枝)
```

### 2.2 其他分类方法

| 分法 | 依据 | 用途 |
|------|------|------|
| 按自然属性 | 植物、动物、矿物 | 最粗的分法 |
| 按亲缘关系 | 植物的科、属(如伞形科、豆科、菊科) | 认植物、找替代品、判断毒性风险 |
| 按功效 | 解表药、清热药、补益药、活血药等 | 中医开方用,见[中药制剂](../06-制药技术/04-中药制剂.md) |
| 按药用部位 | 根、果、草、花叶、皮…… | 认药、采收、加工、储存——本部分采用 |

**了解科属的好处**: 同科植物常有相似的形态特征和化学成分。例如伞形科多有复伞形花序和芳香气味,其中既有当归、柴胡、防风,也有剧毒的毒芹;毛茛科有黄连、白芍,也有乌头、附子。认出科属,就知道该提防哪些有毒的"近亲"。

## 三、识别方法

中药鉴定传统上有四种方法: 基原鉴定、性状鉴定、显微鉴定、理化鉴定。后两种需要显微镜和实验室,家庭条件下主要靠前两种,加上一些简单的水试、火试。

### 3.1 基原鉴定: 看整株植物

基原鉴定就是确认药材来自哪种植物。野外采药时,**一定要在植株完整、最好带花或果的时候认**,只看一片叶子或一段根很容易认错。

**观察顺序**:

```
1. 生长习性: 草本还是木本?直立、匍匐还是缠绕(顺时针还是逆时针)?
             一年生还是多年生?
2. 茎:       圆柱形还是四棱形(唇形科多为四棱)?中空还是实心?
             有没有刺、毛、乳汁(折断后流白色乳汁的要特别小心)
3. 叶:       单叶还是复叶(羽状、掌状、三出)?
             叶序: 互生、对生、轮生、基生(莲座状)
             叶形、叶缘(全缘、锯齿、分裂)、叶脉(网状、平行)
             揉碎后有没有气味
4. 花:       花色、花瓣数、对称性;单生还是成花序
             (伞形、头状、穗状、总状、圆锥)
5. 果实:     浆果、核果、蒴果、荚果、瘦果、翅果……
6. 地下部分: 直根还是须根?有没有块根、根茎、鳞茎?断面颜色,有无乳汁
7. 生境:     山坡、林下、溪边、田埂、路旁;海拔、阴坡还是阳坡
```

**几个常用的科级特征**(用来缩小范围):

| 科 | 典型特征 | 药材例子 | 要提防的有毒成员 |
|----|---------|---------|----------------|
| 唇形科 | 茎四棱,叶对生,唇形花,多有香气 | 薄荷、益母草、夏枯草、丹参、黄芩 | 本科毒性植物少,但仍要认准 |
| 伞形科 | 复伞形花序,茎常中空有节,多有特殊气味 | 当归、柴胡、防风、川芎、白芷 | 毒芹、毒参 |
| 菊科 | 头状花序(像一朵花实为很多小花) | 菊花、蒲公英、艾叶、红花、苍术 | 千里光属部分种类、苍耳(果实有毒) |
| 豆科 | 蝶形花,荚果,常为羽状复叶 | 甘草、黄芪、葛根、决明子 | 相思子(种子剧毒) |
| 毛茛科 | 花部离生,雄蕊和心皮多数 | 黄连、白芍、牡丹皮、升麻 | 乌头、毛茛、铁线莲属部分种类 |
| 天南星科 | 佛焰苞包着肉穗花序 | 半夏、天南星、石菖蒲 | 天南星、半夏生品、滴水观音(海芋) |
| 茄科 | 花冠合瓣,浆果或蒴果 | 枸杞 | 曼陀罗、颠茄、天仙子、龙葵未熟果 |
| 百合科(广义) | 单子叶,叶脉平行,常有鳞茎或根茎 | 贝母、麦冬、玉竹、黄精 | 藜芦、重楼(有小毒) |

**用植物检索的思路**:

植物志和检索表采用"二歧检索": 每一步给出两个对立的特征,符合哪个就走哪条路,一步步缩小范围,直到科、属、种。

```
检索的示例(只示意思路,不是完整检索表):
1a. 叶脉平行,花部多为3或3的倍数 ........ 单子叶植物 → 转2
1b. 叶脉网状,花部多为4、5或其倍数 ........ 双子叶植物 → 转3
3a. 茎四棱,叶对生,有香气,唇形花 ........ 唇形科 → 再往下查属
3b. 不符合 → 继续下一组对立特征

用法要点:
- 先把植株的根、茎、叶、花、果都看全(或拍照记录)再检索
- 遇到不确定的特征,两条路都走一遍,看哪个结论站得住
- 检索出来后,再对照植物志的完整描述和图片逐项核对
- 检索结果和药材性状对不上,宁可放弃
```

现代条件下可以用中国植物志(iplant.cn)、各省植物志、《中国药典》、《中药鉴定学》《药用植物学》教材对照;没有网络时,平时就要准备好一本本地的植物图鉴和药材图谱。手机识图软件只能作为参考线索,**不能作为采食和用药的依据**。

### 3.2 性状鉴定: 看、摸、闻、尝

性状鉴定是对已经采收、加工好的药材(或从别人手里得到的药材)进行判断,是药工几百年积累的经验方法。观察内容有八项:

| 项目 | 看什么 | 例子 |
|------|------|------|
| 形状 | 圆柱形、纺锤形、块状、片状、卷筒状 | 天麻扁长椭圆,有"鹦哥嘴"(顶端残留的红棕色芽苞);厚朴树皮卷成筒状 |
| 大小 | 长度、直径、厚度(测量多个样品取范围) | 种子类常要量毫米级的大小 |
| 颜色 | 表面色和断面色;颜色变了常说明受潮、变质或加工不当 | 黄连断面鲜黄;丹参表面砖红;玄参断面乌黑 |
| 表面 | 光滑或粗糙、皱纹、皮孔、毛茸、环节、疤痕 | 黄芪表面有纵皱纹;党参根头有"狮子盘头"(许多疣状茎痕) |
| 质地 | 轻重、软硬、坚韧或松脆、粉性、油润、角质、黏性 | 粉性(山药、天花粉);角质(天麻);油润(当归) |
| 断面 | 折断难易、断面平坦或纤维性、颜色、纹理、有无油点 | 黄芪断面"金井玉栏"(皮部白、木部黄);茅苍术断面有"朱砂点" |
| 气 | 直接闻,或折断、揉搓后闻 | 当归浓香、薄荷清凉、鱼腥草有腥气、阿魏蒜臭 |
| 味 | 舌尖舔尝(只限确认无毒的) | 黄连极苦;甘草甜;五味子五味俱全;乌梅极酸 |

```
"看、摸、闻、尝"的要领:
看: 自然光下看,表面和断面都看;多看几个样品,不凭一个下结论
摸: 掂分量、试软硬、折一折听声音、捻一捻粉末
闻: 先直接闻,再折断或揉搓、或用热水浸泡后闻;
    有的药材气味很淡,闻不出不代表没有
尝: 只在确认无毒后进行;取极少量放舌尖,
    尝后吐掉并漱口,不要咽下
```

```
⚠️ 绝不能尝的情况:
- 来源不明、自己还没确认品种的任何植物
- 已知有毒或可能有毒的药材: 乌头、附子、半夏、天南星、马钱子、
  雷公藤、商陆、钩吻、曼陀罗、藜芦、巴豆、斑蝥、蟾酥等
- 有毒矿物: 朱砂、雄黄、砒石、铅丹等
- 折断后流白色乳汁、有强烈刺鼻气味、口尝后立即出现麻舌刺喉感的
  (出现后立即吐出、漱口,观察有没有其他症状)
- 发霉、虫蛀、来路不明的药材
很多剧毒植物少量入口就能致命,"尝一点点"不是安全的识别方法。
```

### 3.3 简单的水试与火试

有些药材放进水里或用火烧时会出现特殊现象,可以作为辅助鉴别。下面是教材中常举的例子:

| 方法 | 药材 | 现象 |
|------|------|------|
| 水试 | 西红花 | 浸水后柱头膨胀呈喇叭状,水被染成黄色并逐渐扩散(染料伪品常使水变红或柱头不膨胀) |
| 水试 | 秦皮 | 热水浸出液在日光下显碧蓝色荧光 |
| 水试 | 苏木 | 投入热水中,水显鲜艳的桃红色 |
| 水试 | 栀子 | 水浸液呈鲜黄色 |
| 水试 | 胖大海 | 浸水后迅速膨胀成海绵状 |
| 水试 | 车前子、葶苈子 | 加水后种子表面变黏滑 |
| 水试 | 菟丝子 | 加水煮至种皮破裂,露出黄白色卷旋状的胚,俗称"吐丝" |
| 火试 | 海金沙 | 撒在火上,发出轻微爆鸣声和闪光,几乎不留灰渣 |
| 火试 | 降香 | 点燃后香气浓烈,有油状物渗出,烧完留白色灰 |
| 火试 | 血竭 | 粉末放在白纸上,下面用火烘烤,熔化后对光透视呈鲜艳红色,纸上无扩散的油迹 |
| 火试 | 青黛 | 微火灼烧,产生紫红色烟雾 |

```
注意:
- 水试火试只是辅助,一项符合不能证明就是真品
- 火试在通风处做,只取少量;有毒药材和矿物药不要火烧闻烟
  (雄黄、朱砂加热会放出砷、汞的有毒气体)
- 判断药材真伪,最终还是要基原 + 性状 + 来源三者都对得上
```

### 3.4 识别的总原则

```
✓ 采集时认植株,储存后认性状,两步都要过
✓ 每味药至少核对3个以上特征,都符合才算认准
✓ 第一次采一种药,最好跟有经验的人(药农、中医师)一起
✓ 采回来的每一批单独装、立即贴标签: 名称、采集地、日期
✓ 采集时拍下整株照片(花、叶、根),留作日后核对
✗ 不凭单一特征(只看叶子、只闻气味)下结论
✗ 不凭"老人说""网上说"就采挖地下部分
✗ 认不出来的、和有毒植物难以区分的,宁可不采
```

易混淆的有毒植物见[有毒中药与易混淆有毒植物](09-有毒中药与易混淆有毒植物.md);野菜和毒蘑菇的误食见[毒蘑菇与野菜误食](../03-野外生存/09-毒蘑菇与野菜误食.md)。

## 四、采收原则

药材的有效成分含量随生长阶段和季节变化很大。采收时间不对,采回来的可能只是"草"。传统有"三月茵陈四月蒿,五月砍来当柴烧"的说法,说的就是采收时机。

### 4.1 各部位的最佳采收期

| 药用部位 | 最佳采收期 | 道理 | 例子 |
|---------|-----------|------|------|
| 根及根茎 | 秋冬地上部分枯萎后,或早春萌芽前 | 养分贮藏在地下,含量最高 | 黄芪、党参、葛根、天麻(冬季采"冬麻"质量较好) |
| 叶 | 植物生长旺盛、花将开或盛花期 | 叶片发育充分,光合产物多 | 艾叶、大青叶、紫苏叶;桑叶例外,经霜后采 |
| 花 | 含苞待放或刚开放时 | 盛开后香气散失、花瓣易脱落 | 金银花、槐米(花蕾);菊花、红花(初开或盛开) |
| 果实 | 成熟或近成熟时 | 有效成分积累最多 | 山楂、枸杞(成熟);枳实、青皮(未成熟幼果) |
| 种子 | 完全成熟时 | 种子饱满、含量最高 | 决明子、车前子、酸枣仁 |
| 全草 | 多在开花期或花前枝叶茂盛时 | 地上部分生长最旺 | 益母草、薄荷、车前草;茵陈在幼苗期 |
| 树皮 | 春夏之交(约清明到夏至) | 树液流动旺盛,皮容易剥离,伤口也易愈合 | 杜仲、厚朴、黄柏 |
| 根皮 | 多在秋季,随挖根时剥取 | 与根同期 | 牡丹皮、地骨皮、桑白皮 |
| 藤木 | 秋冬落叶后或全年 | 养分积累 | 鸡血藤、桑枝 |

```
例外很多,以后面各章写的为准:
- 茵陈: 春季幼苗(绵茵陈)或秋季花蕾期
- 桑叶: 初霜后采
- 夏枯草: 果穗呈棕红色时
- 槐米(花蕾)和槐花(开放的花)是同一植物不同采收时间的两种药材
```

### 4.2 采收方法

```
时间:
✓ 晴天,上午露水干后;雨后不要马上采,含水多,难干易霉
✓ 花类、芳香类在晴天上午采,香气足

工具:
- 剪刀或枝剪: 花、叶、果、嫩枝
- 小锄、铲、长柄镐: 挖根(根深的植物如甘草、黄芪要深挖,
  挖断的根容易发霉,也降低质量)
- 刀: 剥树皮
- 布袋、竹篮、纸袋分装;不用不透气的塑料袋长时间捂着(会发热变质)

方法:
- 根: 顺着根的走向挖,尽量完整;抖去泥土,不要在水里长时间泡
- 叶: 摘下或连枝割下;不要把一棵植物的叶子摘光
- 花: 用手摘或剪,轻拿轻放,不要挤压
- 果实: 成熟一批采一批;浆果连果柄摘下不易破
- 种子: 果实成熟、开始干裂前整穗割下,铺在布上晾干后拍打脱粒
- 树皮: 不要环剥(剥一整圈树会死);只剥树干一侧的条状或块状,
  或采用"环剥再生"等专门技术;能修枝取皮就不剥主干
- 全草: 从地面以上割取(需要带根的按品种要求)

每次只采一种,分开装、分开晾、分别贴标签。
```

```
不要在这些地方采:
✗ 公路边(汽车尾气中的铅等污染)
✗ 工厂、矿区、冶炼厂、垃圾场附近(重金属污染)
✗ 刚喷过农药、除草剂的田边地头
✗ 污水沟、化粪池旁
✗ 坟地、牲畜圈附近(卫生问题)
✗ 自然保护区、风景名胜区(法律禁止)
```

### 4.3 可持续采集

野生药材是有限资源。很多今天的保护物种(人参、甘草、天麻、石斛等),就是过度采挖造成的。在长期生存条件下,把一片药源挖光,等于断了以后的药。

```
可持续采集的原则:
1. 留种: 每片地只采一部分(一般不超过约三分之一),
         留下母株和正在开花结籽的植株;种子类药材先撒一部分种子再走
2. 留小采大: 挖根时只采成熟的大株,小株留着继续长
3. 不连根拔光: 用地上部分的(全草、叶、花),割取而不拔根;
              根茎类可以把带芽的根头部分重新埋回去
4. 回填: 挖根后把土回填、踩实,减少水土流失
5. 轮采: 把采集地分成几片,每年只采其中一片,
         让其他几片休养生息(根类药材往往要3-5年以上才能恢复)
6. 引种: 采一次野生的种子或根苗,带回来种植;
         能家种的尽量家种(见药用植物章)
7. 树皮类: 优先采修剪下来的枝条皮;剥主干只剥一侧,不环剥
```

## 五、产地加工

采回来的新鲜药材含水多,如果不及时处理,几天内就会发热、霉烂、变色。产地加工的目的是: 去掉杂质和非药用部分、迅速干燥、便于储存运输,有些还能保持或改善药效。

**注意区分**: 产地加工(本节)是采收后马上做的初步处理;炮制(炒、炙、煅、去毒等)是用药前的进一步加工,见[中药制剂-中药炮制方法](../06-制药技术/04-中药制剂.md#二中药炮制方法)。

### 5.1 净选

```
1. 挑拣: 去掉泥沙、杂草、枯叶、石块和混进来的其他植物
         (混入的其他植物可能有毒,这一步要认真)
2. 去除非药用部位: 按药材要求去芦头、须根、栓皮、果柄、种皮、木心等
3. 去掉虫蛀、霉烂、变色的部分
4. 清洗: 根及根茎类用清水快速洗净,不要长时间浸泡,
         以免有效成分溶出;花、叶、种子类一般不洗
5. 分级: 按大小分开,便于干燥均匀
```

### 5.2 切制

```
- 较粗大、不易干燥的根、根茎、果实,趁鲜切成片、段、块:
  如葛根、大黄切片,木瓜对半剖开
- 切片厚度一般约2-4 mm,越薄干得越快,但太薄容易碎和散失成分
- 含挥发油的药材(如当归、川芎)不宜切得太早,
  切开后挥发成分散失加快,一般整个干燥,用时再切
- 切后立即摊开干燥,不要堆着
```

### 5.3 蒸、煮、烫

有些药材在干燥前要先蒸、煮或用沸水烫,目的是: 杀死细胞和酶,防止有效成分分解;使淀粉糊化、质地变得角质透明,便于干燥和储存;便于去皮或去心;杀死虫卵。

| 方法 | 适用 | 例子 | 判断标准 |
|------|------|------|---------|
| 蒸 | 含淀粉、黏液多,不易干燥的根茎 | 天麻、黄精、红参 | 蒸至透心、断面无白心 |
| 煮 | 需要去皮或糊化的根 | 白芍(煮后去皮)、明党参 | 煮至透心 |
| 烫 | 肉质块根,防止干燥时变质 | 天冬、太子参(沸水略烫) | 表皮发软、断面半透明 |

```
蒸煮烫的分寸: 不足则不透心,干燥时容易变色发霉;
过度则有效成分流失。具体时间按后面各章的品种要求。
```

### 5.4 发汗

"发汗"是把药材堆积起来或用湿草、湿麻袋覆盖闷着,让内部水分渗出到表面,同时发生一定变化,使药材颜色变深、香气增加、质地变软、干燥更快。

```
适用: 厚朴、杜仲、玄参、续断、茯苓等
方法: 堆积或盖严,闷到内部颜色变化、表面"出汗"后,
      摊开晾晒,如此可反复几次
注意: 发汗是有意识的、控温控时的过程;
      和"药材堆着发热霉烂"不是一回事——
      发汗时出现霉味、白毛,就是失败了
```

### 5.5 干燥

干燥是产地加工最关键的一步。干得快、干得透,才不霉不坏。

| 方法 | 适用对象 | 要点 |
|------|---------|------|
| 晒干 | 大多数根及根茎、果实、种子、皮类、不含挥发油的全草 | 摊薄一层,勤翻动;傍晚收回,防止夜露回潮 |
| 阴干 | 花类、叶类、含挥发油的芳香类药材(薄荷、荆芥、紫苏、当归) | 放在通风的阴凉处或屋檐下,避免暴晒散失香气和褪色 |
| 烘干 | 阴雨天、量大、或需要快速干燥的药材 | 用烘房、火炕、低温炉,控制温度 |

**烘干温度**(参考《中药鉴定学》等教材的一般原则):

```
- 一般药材: 约50-60°C,短时间内不会破坏多数有效成分
- 含挥发油的芳香类药材: 不超过约35-40°C(教材多取35°C),
  否则香气和有效成分大量散失
- 含维生素C的多汁果实: 可用约70-90°C快速干燥
- 含苷类、含酶的药材: 宜尽快升温到能抑制酶活性的温度,
  避免慢慢晾干时被酶分解
- 不宜晒的: 颜色鲜艳的花(红花、金银花暴晒易变色)、
  芳香类、含挥发油的根(当归、川芎)
- 不宜高温的: 含油脂多的种子(杏仁、桃仁、柏子仁),高温会"走油"
```

```
没有烘房时的土办法:
- 火炕、灶台上方搭架子(注意烟熏和失火)
- 屋内通风处挂起来,下面放炭盆
- 太阳能干燥箱: 木箱加玻璃盖、下部进气上部出气
低温干燥的具体做法见食物加工章(链接在本节末尾)。
```

**怎样判断干透**:

```
- 根、根茎: 断面没有湿心,颜色一致;能折断的折断时声音清脆
- 叶、花: 用手一搓就碎,一捏就成粉
- 全草: 茎一折就断
- 果实、种子: 用手抓一把,摇动时声音清脆,咬(只限无毒的)或用指甲掐坚硬
- 皮类: 一折就断,不弯不软
- 重量: 同一批药材连续两天称重,重量不再明显减少

药典对大多数药材都规定了水分上限(多在百分之十几),
家庭条件下按上面的手感判断即可;
宁可多晒一天,不要没干透就装起来——几天之内就会发霉。
```

阴雨天的低温干燥方法见[食物加工与保存-晒干与风干](../07-日常生活技能/01-食物加工与保存.md#晒干与风干)。

## 六、储存

药材储存不好,轻则失效,重则发霉产生毒素(如黄曲霉毒素,煮不掉)。储存中的变质主要有四种: 霉变、虫蛀、走油(泛油)、变色和散气。

### 6.1 四种变质与防止办法

| 变质 | 表现 | 容易发生在 | 原因 | 防止办法 |
|------|------|----------|------|---------|
| 霉变 | 表面有白、绿、黑色毛状物或斑点,有霉味 | 含糖、淀粉、黏液多的(党参、天冬、枸杞、山药、当归) | 温度约20-35°C、空气潮湿、药材没干透 | 充分干燥,密封防潮,阴凉处储存,定期复晒 |
| 虫蛀 | 有蛀孔、虫粉、虫丝,甚至蛀空成粉末 | 含淀粉、糖、蛋白质多的(党参、白芷、山药、薏苡仁)和动物药 | 采收加工时带入虫卵,储存时受潮 | 干燥、密封;复晒或低温烘;对抗同贮(见下) |
| 走油(泛油) | 表面发黏、发暗、出油,有哈喇味 | 含油脂多的(杏仁、桃仁、柏子仁、当归)和含糖多的(枸杞、天冬、党参) | 温度高、久放、接触空气和光 | 低温、避光、密封,不要压挤;储存期不宜过长 |
| 变色、散气 | 颜色变暗变褐,香气变淡 | 花类、叶类、芳香类(金银花、菊花、红花、薄荷) | 光照、氧化、受潮、温度高 | 避光、密封、阴凉;花叶类一般1年左右更新 |

```
药材储存的环境:
- 阴凉: 温度尽量低,一般不超过约20-25°C最好
- 干燥: 相对湿度尽量控制在约75%以下;南方梅雨季、回南天要特别留意
- 避光: 放在暗处或不透光容器里
- 通风: 库房要能通风,但容器本身要密封
- 离地离墙: 架子或垫板上放,离地面和墙面都留出空隙,防潮
```

### 6.2 容器

| 容器 | 适合 | 备注 |
|------|------|------|
| 陶罐、瓷坛(带盖) | 大多数药材 | 传统首选,避光防潮;封口可用油纸加泥封 |
| 玻璃瓶、玻璃罐 | 少量药材、种子 | 透光,要放在暗处或用纸包住 |
| 铁皮罐、铁皮箱 | 花类、芳香类、易受潮药材 | 防潮防鼠好;不要装酸性强的药材 |
| 木箱、木柜(中药房的"百眼柜") | 大量药材分格储存 | 注意防潮防虫 |
| 布袋、纸袋 | 短期周转、透气要求高的 | 不防潮、不防虫,不适合长期储存 |
| 厚塑料袋 | 临时替代 | 药材必须先干透,扎紧后外面再套一层 |

```
防潮的传统做法——"石灰缸":
缸底放用布包好的生石灰吸潮,中间隔一层木板或竹篦,上面放药材,盖严。
生石灰遇水剧烈放热,包好放稳,不让孩子接触;
石灰溅入眼睛先刷去固体再用大量清水冲洗。
也可用木炭、干燥的稻壳吸潮,但效果差一些。
```

### 6.3 常见虫害与对策

药材仓库里常见的害虫有药材甲、烟草甲、谷蠹、锯谷盗、印度谷螟、粉螨等。它们多半是采收加工时虫卵带进来的,在温暖潮湿时大量繁殖。

```
发现:
- 药材上有小孔、粉末(虫粉)、细丝(蛾类幼虫吐的丝)
- 容器底部有虫尸、虫粉
- 粉螨: 药材表面一层会动的细粉

处理:
1. 立即把生虫的药材和其他药材分开
2. 虫蛀轻的: 筛去虫粉,摊开暴晒或低温烘烤
   (多数药材可在约50-60°C烘一段时间;
   芳香类、含油多的不能高温,只能阴凉通风处摊晾、挑拣)
3. 虫蛀严重、蛀成粉末的: 丢掉
4. 容器清洗、晒干后再用

传统的"对抗同贮"(经验做法,只作辅助):
- 牡丹皮与泽泻同贮,泽泻不易生虫,牡丹皮不易变色
- 花椒与动物类药材(如蛇类、鹿茸)同贮,防虫
- 容器里放少量花椒、细辛、大蒜,有一定驱虫作用
化学熏蒸剂(如磷化铝)剧毒,家庭不要使用。
```

### 6.4 储存期与定期检查

下表是干燥密封、阴凉避光条件下的经验储存期:

| 类别 | 储存期 | 容易出现的问题 |
|------|--------|-------------|
| 花、叶类 | 约1年 | 变色、香气散失、受潮发霉 |
| 根、根茎类 | 约1-2年 | 虫蛀、泛油 |
| 全草类 | 约1年 | 变色、发霉 |
| 皮类 | 约1-2年 | 虫蛀、受潮 |
| 果实、种子类 | 约1年;含油多的种子更短 | 泛油、发霉、虫蛀;种子类易哈喇 |
| 药粉(散剂) | 6个月-1年 | 吸潮结块、发霉 |

艾叶、陈皮等少数药材讲究"陈久者良",存放1-3年反而更好(以后面各章写的为准)。

```
检查:
- 平时每1-2个月打开检查一次;梅雨季、回南天、雨季前后每月一次
- 回潮的拿出来复晒或低温烘干
- 每年新药材入库时,把旧的先用掉("先进先出")

有下列情况的药材不要用:
❌ 发霉: 有霉点、霉味、长白毛或绿毛——整袋丢掉,
   不要洗一洗、晒一晒、炒一炒再用
❌ 严重虫蛀、成粉末
❌ 明显泛油、发黏、有哈喇味
❌ 颜色、气味和原来明显不同
❌ 标签丢失、认不出是什么药
放久了的药材有效成分会下降,但不能靠"加量"弥补——超量的风险比失效更大。

有毒药材: 单独存放,明确标注"有毒",上锁或放高处,儿童拿不到;
不和普通药材、食物放在一起。
```

更多储存细节见[中药制剂-药材的储存与有效期](../06-制药技术/04-中药制剂.md#83-药材的储存与有效期)。

## 七、用量与安全

### 7.1 药典用量是什么意思

```
《中国药典》每味药材条目中的"用法与用量":
- 一般指成人一日的常用剂量,多为水煎内服的饮片用量
- 是常规范围,不是"可以随便吃到上限"
- 有些写"外用适量",表示只外用或主要外用
- 药典在凡例中说明: 必要时可遵医嘱酌情增减——
  这里"增减"的决定权在医生,不在患者

读后面各章的用量时要注意:
1. 指的是单味药在一张方子里的量,不是单独大量服用的量
2. 儿童、老人、体弱者用量更小,由医生定
3. 有毒药材的用量,即使在药典范围内也可能中毒(个体差异大)——
   本部分对有毒中药不写用量
4. 鲜品和干品不同,药典用量一般指干品(另注明鲜品的除外)
5. "在中医师指导下使用"——这句话每一处都算数
```

### 7.2 "天然"不等于"无毒"

```
草药也会伤人,常见的情况:
1. 认错品种: 把钩吻当金银花、把商陆当人参、
   把含马兜铃酸的"木通""防己"混用
2. 本身有毒: 乌头类(附子、川乌、草乌)、马钱子、雷公藤、
   生半夏、生天南星、商陆、曼陀罗、苍耳子、细辛等
3. 超量或长期服: 甘草长期大量致高血压、低血钾、水肿;
   何首乌致肝损伤;苦杏仁、桃仁过量致氰化物中毒
4. 加工储存不当: 发霉产生黄曲霉毒素;
   污染地采的药材含重金属、农药
5. 个体差异: 过敏体质(尤其对菊科过敏)、孕妇、肝肾病人
6. 与西药相互作用(见7.5)
```

### 7.3 十八反、十九畏(配伍禁忌)

"十八反"和"十九畏"是中医传统的配伍禁忌,指某些药物同用会产生或增强毒性、降低疗效。具体名单见[中药制剂-十八反十九畏](../06-制药技术/04-中药制剂.md#61-十八反十九畏配伍禁忌),这里只列出总的意思:

```
十八反(同用可能产生或增强毒副作用):
- 甘草 反 甘遂、大戟、芫花、海藻
- 乌头 反 半夏、瓜蒌、贝母、白蔹、白及
- 藜芦 反 人参、沙参、丹参、玄参、细辛、芍药

十九畏(一般避免同用):
硫黄与朴硝、水银与砒霜、狼毒与密陀僧、巴豆与牵牛子、
丁香与郁金、川乌草乌与犀角、牙硝与三棱、官桂与石脂、人参与五灵脂

意义: 自采药材不要自行配伍;
     不清楚能不能一起用的,不要混在一起煎,问中医师
```

### 7.4 孕妇禁用、慎用

《中国药典》把对孕妇有影响的药材分为"孕妇禁用""孕妇忌用""孕妇慎用"几类,后面各章逐味注明。

```
大致分类:
- 禁用(多为毒性强或作用峻猛的): 如巴豆、牵牛子、大戟、甘遂、芫花、
  商陆、斑蝥、水蛭、三棱、莪术、马钱子、川乌、草乌、雄黄、朱砂、麝香等
- 慎用(活血、行气、攻下、辛热类): 如红花、桃仁、牛膝、益母草、
  大黄、芒硝、枳实、附子、肉桂等

原则:
- 孕期用任何中药都要有中医师或医生指导,怀孕头3个月尽量不用药
- 哺乳期: 多数药物会进入乳汁,用前问医生
- 孕期出现阴道流血、腹痛、头痛眼花、浮肿加重、胎动减少 →
  立即就医,不要靠"安胎"草药拖延
```

孕妇用药的更多说明见[中药制剂-孕妇禁忌](../06-制药技术/04-中药制剂.md#62-孕妇禁忌)。

### 7.5 与西药同用

```
- 长期服用降压药、降糖药、抗凝药(华法林)、抗血小板药、地高辛、
  利尿药、激素、抗癫痫药、免疫抑制剂的人,用中药前先问医生或药师
- 不要因为开始喝中药就自己减少或停掉西药
- 举例: 甘草长期大量服用可致低血钾,与利尿药、地高辛同用风险增加;
  当归、丹参、三七、银杏叶等可能增加抗凝药的出血风险
- 就医时把在吃的中药、药酒、保健品都告诉医生
```

详见[药用植物-与西药同用的提醒](../04-动植物培育/04-药用植物.md#与西药同用的提醒)和[中药制剂-与西药同用](../06-制药技术/04-中药制剂.md#65-与西药同用)。

### 7.6 肝肾损伤风险

```
已知可能伤肝的(举例): 何首乌(尤其生首乌)、雷公藤、千里光、土三七
  (菊三七,含吡咯里西啶生物碱,常被误当三七)、苍耳子、川楝子、黄药子等
已知可能伤肾的(举例): 含马兜铃酸的关木通、广防己、青木香、马兜铃、天仙藤;
  雷公藤;含汞、砷、铅的矿物药(朱砂、雄黄、铅丹)

预防:
- 不长期自服任何草药,"调理""保健"也一样
- 已有肝病、肾病的人,用药前先问医生
- 服药期间出现乏力、食欲差、恶心、皮肤或眼白发黄、尿色深如浓茶、
  尿量明显减少、浮肿 → 停药就医,检查肝肾功能
- 不自采名称里带"木通""防己"的植物;不把"土三七"当三七
```

### 7.7 中毒了怎么办

```
1. 立即停用,拨打120或尽快送医
2. 带上剩余的药材、药渣、药液,或拍照,告诉医生吃了什么、多少、何时吃的
3. 没有反应、没有呼吸 → 心肺复苏
❌ 不要用绿豆汤、甘草水等偏方"解毒"后在家观察
```

处理原则见[中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则)。

## 八、法律与资源保护

采药不只是技术问题,也是法律问题。很多常用中药材的野生资源已经很少,国家有专门的法规保护。

### 8.1 野生药材资源保护管理条例

《野生药材资源保护管理条例》由国务院于1987年发布,把国家重点保护的野生药材物种分为三级:

| 级别 | 含义 | 管理 |
|------|------|------|
| 一级 | 濒临灭绝状态的稀有珍贵野生药材物种 | **禁止采猎** |
| 二级 | 分布区域缩小、资源处于衰竭状态的重要野生药材物种 | 按国家批准的计划采猎、收购,需取得采药证 |
| 三级 | 资源严重减少的主要常用野生药材物种 | 同二级,按计划采猎、收购 |

```
条例还规定:
- 禁止在禁止采猎区、禁止采猎期采猎,禁止使用禁用工具
- 二、三级物种的采猎须持采药证,按批准的种类、数量、地点、期限进行
- 省级政府可以在国家名录之外增加本地区的保护物种
- 配套的《国家重点保护野生药材物种名录》中,
  包括野生的人参、甘草、黄连、杜仲、厚朴、黄柏,
  以及川贝母、黄芩、龙胆、防风、远志、肉苁蓉、细辛、
  五味子、石斛、连翘、羌活等常用药材(以名录原文为准)
```

### 8.2 国家重点保护野生植物名录

2021年9月,国家林业和草原局、农业农村部公布了新版《国家重点保护野生植物名录》,共列入455种和40类植物,分为一级和二级保护。其中有不少是常用药材的野生来源。

```
要点:
- 采集、出售、收购国家重点保护野生植物,须依法取得许可;
  无证采挖野生的保护植物是违法行为,数量大的可以构成犯罪
- 名录中有不少药用植物和药用真菌(冬虫夏草即为二级保护),
  许多人们熟悉的药材,其野生种也被列入
- 人工种植的同种植物不受此限,但要能说明来源
- 名录会更新,采挖野生植物前先查当地林草部门公布的最新名录
- 各省还有省级重点保护野生植物名录
```

### 8.3 野生动物保护法

```
- 《中华人民共和国野生动物保护法》(2022年修订)保护国家重点保护野生动物,
  禁止非法猎捕、杀害、出售、购买、利用
- 虎骨、犀角自1993年起禁止贸易和药用
- 穿山甲已列为国家一级保护野生动物,
  2020年版《中国药典》不再收载穿山甲
- 麝、熊、玳瑁、赛加羚羊等也是保护动物,
  其制品的使用受严格限制,只能是合法人工养殖或批准的来源
- 本部分对这些动物药只写法律提醒和替代品说明,不写获取方法
```

### 8.4 采药人的底线

```
✗ 不采挖国家和地方重点保护的野生植物
✗ 不猎捕、不买卖、不使用保护动物及其制品
✗ 不在自然保护区、风景名胜区、森林公园内采集
✗ 不在禁采期采集;不用毁灭性的方法(放火、连片挖光、环剥树皮)
✓ 优先购买正规药店的药材,优先使用人工种植的来源
✓ 能家种的自己种,采一次野生种子或根苗带回繁殖
✓ 不清楚是否受保护时,当作受保护对待
```

即使在社会秩序崩溃、无人执法的情况下,这些原则依然适用——过度采挖造成的资源枯竭,最终伤害的是采药人自己和后代。

## 十、自我检查清单

采一味药之前,逐条确认:

- [ ] 我能说出这种植物的正名、科属和药用部位
- [ ] 我核对了至少3个以上的识别特征(植株 + 性状),都符合
- [ ] 我知道它最容易和哪些有毒植物混淆,并能区分
- [ ] 现在是这个部位的适宜采收期
- [ ] 采集地远离公路、工厂、矿区、农药田,不在保护区内
- [ ] 它不是国家或本省重点保护的野生植物
- [ ] 我只采一部分,留下母株和种子
- [ ] 我知道怎样干燥、怎样判断干透、怎样储存
- [ ] 我知道它的药典常规用量和禁忌人群
- [ ] 用之前会请中医师或医生确认
