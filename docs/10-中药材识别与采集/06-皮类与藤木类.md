# 皮类与藤木类

> **树皮、根皮、藤茎和木材,是最"像"彼此的一类药材——干了都是一卷卷、一段段、一块块的棕色东西;认它们靠的是断面、气味和一点点小技巧(杜仲的白丝、秦皮的蓝光、苏木的红水、降香的油),而采它们最要紧的是: 不要剥死一棵树**

本章收录26味常用的皮类与藤木类药材,分为树皮类、根皮类、茎枝与藤茎类、茎髓与竹茹、心材与含树脂木材五组。药用部位包括树皮(干皮、枝皮)、根皮、嫩枝、藤茎、带钩茎枝、茎髓、茎秆中间层、心材和含树脂的木材。识别、采收、干燥、储存的通用方法见[总论](./00-总论.md),本章不再重复;地骨皮来自枸杞的根皮,枸杞的种植见[药用植物-枸杞](../04-动植物培育/04-药用植物.md#枸杞),忍冬藤来自金银花的植株,种植见[药用植物-金银花](../04-动植物培育/04-药用植物.md#金银花忍冬)。

## ⚠️ 先读这几条

```
1. 剥树皮不要环剥: 绕树干剥一整圈,树就会死。
   只剥树干一侧的条状或块状("条剥""半环剥"),
   优先用修剪、间伐下来的枝条和树干;杜仲、厚朴、黄柏的野生资源受国家保护
2. "木通"一定分清: 关木通(马兜铃科,含马兜铃酸)2003年起已被取消药用标准,
   可造成不可逆的肾衰竭和尿路癌症。本章的川木通是毛茛科铁线莲属植物,
   名字里带"木通"的草药不要自采,只从正规药房凭处方取
3. "五加皮"一定分清: 香加皮(北五加皮,杠柳的根皮)含强心苷,
   过量可致心律失常甚至心跳骤停;有浓烈特殊香气的"五加皮"不用、不泡酒
4. 采藤茎要认准整株: 钩吻(断肠草)、雷公藤("黄藤")都是藤本,
   和忍冬藤、鸡血藤等生长在同样的林缘灌丛里,剧毒;
   不认识整株植物的藤,一段都不采
5. 沉香、降香、檀香价格高、伪品多: 沉香属列入CITES附录II,
   土沉香、降香檀是国家二级保护野生植物;不采伐野生树,
   买到的"老沉香""海南黄花梨"多数靠不住
6. 用量是《中国药典》(2020年版)成人每日的常规用量(饮片,水煎;
   现行为2025年版,以现行版原文为准),
   只用来提醒"不要超量";用不用、用多少,在中医师指导下决定
7. 肉桂、苏木、牡丹皮、大血藤、通草等孕妇慎用;
   服华法林、阿司匹林等抗凝、抗血小板药的人,用活血药前先问医生
```

## 一、树皮类

树皮类药材来自乔木的树干、树枝。树皮内侧紧贴着的一层(韧皮部和形成层)是树输送养分、长出新组织的地方: **绕树干剥掉一整圈("环剥"),树根得不到叶子制造的养分,树就会在一两年内死去**。过去杜仲、厚朴、黄柏的野生资源大量减少,很大程度就是"剥皮砍树"造成的。

```
可持续剥皮的做法(以杜仲、厚朴、黄柏为例):

1. 先用修剪、间伐、采伐下来的枝条和树干剥皮——这是最好的来源
2. 剥活树只剥一侧: 纵向剥取一条或几块,宽度不超过树干周长的1/3-1/2
   ("条剥""半环剥"),留下的树皮能继续输送养分;
   伤口愈合、长出新皮后(通常隔2-3年),再剥另一侧
3. 时间选在春夏之交树液流动旺盛时(多在4-6月),皮容易剥离,伤口也易愈合;
   选阴天或晴天的傍晚,避开雨天
4. 刀口只切到木质部表面,不伤木质部;剥下后不要用手摸裸露的木质部
5. 剥后用塑料薄膜等包裹伤口一段时间,防止暴晒、失水和病虫侵入
6. 栽培园里专门的"环剥再生"技术要求很高(时间、天气、包扎都有讲究),
   失败树就会死;没有经验不要尝试,野生树一律不环剥
```

"发汗"是杜仲、厚朴产地加工的特有步骤: 把新剥的皮堆起来、盖严,让它自己发热回潮,内表面变色后再晒干,方法见[总论-发汗](./00-总论.md#54-发汗)。

### 1.1 杜仲

- **正名(别名)**: 杜仲(思仲、丝连皮、扯丝皮)
- **来源**: 杜仲科植物杜仲 *Eucommia ulmoides* Oliv. 的干燥树皮
- **分布与生境**: 中国特有的单种科植物;陕西、四川、贵州、湖南、湖北、河南等地,野生于山地林中,现在各地广泛栽培
- **识别要点**:
  - 植株: 落叶乔木,高可达20 m;叶互生,椭圆形或卵形,边缘有锯齿;**把叶子、树皮、果实轻轻折断再慢慢拉开,断口之间有许多银白色、富有弹性的细丝相连**(杜仲胶)——这是杜仲最独特的特征;果为扁平长椭圆形的翅果
  - 药材: 板片状或两边稍向内卷,厚3-7 mm;外表面淡棕色或灰褐色,有明显的皱纹或纵裂槽纹,有的已刮去粗皮;内表面暗紫色,光滑;质脆,易折断,**断面有细密、银白色、富弹性的橡胶丝相连**;气微,味稍苦
- **易混淆品/伪品**:
  - **丝棉木**(白杜 *Euonymus maackii*,卫矛科)等的树皮("土杜仲"): 折断也有少量白丝,但**丝稀疏、弹性差、一拉就断**
  - **杜仲藤**(夹竹桃科藤本,俗称"红杜仲")的皮: 断面的白丝稀少、弹性小;夹竹桃科植物多有毒性,不要混用
  - 认法: 真杜仲的白丝**密、多、拉长到1 cm以上仍不断**
- **采收与加工**: 4-6月剥取,刮去粗皮,堆置"发汗"至内皮呈紫褐色,晒干;剥皮方法见本节开头,**不环剥**
- **储存**: 不易变质;放通风干燥处防潮
- **功效**: 补肝肾,强筋骨,安胎
- **用量**: 6-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺者慎用(经验);怀孕期间出现腹痛、阴道出血,必须先去医院查明原因,不能只靠"安胎药";杜仲有一定降压作用,服降压药的人先问医生
- 🛡️ **保护提醒**: 野生杜仲列入《国家重点保护野生药材物种名录》(级别以名录原文为准);现在药材几乎都来自栽培,不采野生树

### 1.2 厚朴

- **正名(别名)**: 厚朴(川朴、紫油厚朴、温朴)
- **来源**: 木兰科植物厚朴 *Magnolia officinalis* Rehd. et Wils. 或凹叶厚朴 *M. officinalis* var. *biloba* Rehd. et Wils. 的干燥干皮、根皮及枝皮(新分类将厚朴归入厚朴属 *Houpoea*)
- **分布与生境**: 四川、湖北、湖南、贵州、浙江、江西、福建等地的山地林中;主要来自栽培
- **识别要点**:
  - 植株: 落叶乔木;**叶极大**,长20-45 cm,倒卵形,集生在枝顶像一把伞;初夏开**白色大花**,直径10-15 cm,有香气;凹叶厚朴的叶先端凹缺成两个钝圆浅裂片
  - 药材: 干皮卷成单筒或双卷筒状(习称"筒朴"),近根部的干皮一端展开像喇叭口("靴筒朴");外表面灰棕色或灰褐色,粗糙,有椭圆形皮孔;**内表面紫棕色或深紫褐色,较平滑,用指甲划之显油痕**;断面颗粒性,外层灰棕色,内层紫褐色或棕色,**有油性,有的可见多数小亮星**;**气香,味辛辣、微苦**
- **易混淆品/伪品**: 同科的武当玉兰、凹叶木兰、望春花等的树皮常被冒充("土厚朴"),多数内表面颜色浅、油性小、香气和辛辣味弱;认准"紫色、油润、香、辛辣"
- **采收与加工**: 4-6月剥取,根皮和枝皮直接阴干;干皮置沸水中微煮后,堆置阴湿处"发汗"至内表面变紫褐色或棕褐色时,蒸软,取出,卷成筒状,干燥;剥皮方法见本节开头
- **储存**: 含挥发油,放阴凉干燥处,防香气散失
- **功效**: 燥湿消痰,下气除满
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用;体虚、津液不足者不宜(经验);厚朴的花("厚朴花")是另一味药
- 🛡️ **保护提醒**: 厚朴(含凹叶厚朴)列入2021年《国家重点保护野生植物名录》二级,野生厚朴也列入《国家重点保护野生药材物种名录》;**不采剥野生树**,只用栽培品

### 1.3 黄柏

- **正名(别名)**: 黄柏(川黄柏、黄檗皮)
- **来源**: 芸香科植物黄皮树 *Phellodendron chinense* Schneid. 的干燥树皮,习称"川黄柏"。东北的黄檗 *P. amurense* Rupr. 的树皮在药典中另列为"关黄柏",性状和用法相近
- **分布与生境**: 川黄柏产于四川、贵州、湖北、云南等地;关黄柏产于东北和华北;生于山地杂木林中,现多栽培
- **识别要点**:
  - 植株: 落叶乔木;**奇数羽状复叶对生**,小叶7-15片,揉碎有特殊气味;雌雄异株;核果圆球形,熟时蓝黑色;黄檗的老树树皮有很厚的**软木栓层**,可用手指按出凹陷
  - 药材: 板片状或浅槽状,厚1-6 mm;外表面黄褐色或黄棕色,平坦或有纵沟纹,有的可见皮孔痕及残存的灰褐色粗皮;**内表面暗黄色或淡棕色**;体轻,质硬;**断面纤维性,呈裂片状分层,深黄色**;气微,**味极苦,嚼之有黏性,可使唾液染成黄色**
- **易混淆品**: 同属其他种和民间叫"黄柏"的十大功劳、小檗等的茎皮,也含小檗碱、断面也黄,但不是药典品;认准"片状、断面层层分开、味极苦、嚼之发黏"
- **采收与加工**: 剥取树皮后,除去粗皮,晒干;剥皮方法见本节开头,**不环剥**
- **储存**: 放通风干燥处,防潮防霉
- **功效**: 清热燥湿,泻火除蒸,解毒疗疮
- **用量**: 3-12 g;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 性寒味苦,**脾胃虚寒、食少腹泻者不宜**;含小檗碱,葡萄糖-6-磷酸脱氢酶缺乏症(蚕豆病)患者和新生儿慎用
- 🛡️ **保护提醒**: 黄檗和川黄檗都列入2021年《国家重点保护野生植物名录》二级,野生黄柏也列入《国家重点保护野生药材物种名录》;**不采剥野生树**,只用栽培品

### 1.4 肉桂

- **正名(别名)**: 肉桂(玉桂、牡桂、桂皮)
- **来源**: 樟科植物肉桂 *Cinnamomum cassia* Presl 的干燥树皮
- **分布与生境**: 广西、广东、云南、福建等地,栽培为主;喜温暖湿润的南亚热带
- **识别要点**:
  - 植株: 常绿乔木;叶互生或近对生,革质,长椭圆形,**有明显的离基三出脉**(从叶基稍上方分出三条主脉);全株有浓郁桂皮香气
  - 药材: 槽状或卷筒状,厚0.2-0.8 cm;外表面灰棕色,稍粗糙,有不规则的细皱纹和横向突起的皮孔;内表面红棕色,略平坦,**用指甲刻划可见油痕**;质硬而脆,易折断;**断面不平坦,外层棕色而较粗糙,内层红棕色而油润,两层间有1条黄棕色的线纹**;**气香浓烈,味甜、辣**
- **易混淆品**: 调味用的"桂皮"常是阴香、天竺桂、川桂等同属植物的树皮,香气较淡、味不甜或带苦、少油;锡兰肉桂(*C. verum*,西餐用)不是药典品种。药用认准"油润、甜辣、断面有一条黄棕色线纹"
- **采收与加工**: 多于秋季剥取,阴干;同样只从栽培园修剪、间伐的枝干剥取,**不环剥**
- **储存**: 含挥发油,**密封避光,放阴凉处**,香气越放越淡
- **功效**: 补火助阳,引火归元,散寒止痛,温通经脉
- **用量**: 1-5 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **有出血倾向者及孕妇慎用;不宜与赤石脂同用**(药典);阴虚火旺、发热者不用(经验);桂皮类含香豆素,长期大量吃(包括作香料或保健品)可能伤肝

### 1.5 秦皮

- **正名(别名)**: 秦皮(白蜡树皮、梣皮)
- **来源**: 木犀科植物苦枥白蜡树 *Fraxinus rhynchophylla* Hance、白蜡树 *F. chinensis* Roxb.、尖叶白蜡树 *F. szaboana* Lingelsh. 或宿柱白蜡树 *F. stylosa* Lingelsh. 的干燥枝皮或干皮
- **分布与生境**: 东北、华北、西北到长江流域的山地杂木林中;白蜡树也是常见的行道树和放养白蜡虫的树
- **识别要点**:
  - 植株: 落叶乔木;**奇数羽状复叶对生**,小叶5-7片;果为倒披针形的单翅果(像一根小桨)
  - 药材: 卷筒状或槽状,厚1.5-3 mm;外表面灰白色、灰棕色至黑棕色或相间成斑状,平坦或稍粗糙,有灰白色圆点状皮孔及细斜皱纹;内表面黄白色或棕色,平滑;质硬而脆,断面纤维性,黄白色;气微,味苦
  - **水试**: 取少量树皮浸入热水中,**浸出液在日光下可见碧蓝色荧光**——这是秦皮的经典鉴别特征
- **易混淆品**: 核桃楸(胡桃楸)的树皮常被混作秦皮,**浸出液没有蓝色荧光**
- **采收与加工**: 春、秋二季剥取,晒干;优先用修剪下来的枝条剥皮
- **储存**: 放通风干燥处
- **功效**: 清热燥湿,收涩止痢,止带,明目
- **用量**: 6-12 g;外用适量,煎洗患处(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒者不宜(经验);眼睛红肿疼痛、视力下降,要先就医,不要自己用药液洗眼

### 1.6 合欢皮

- **正名(别名)**: 合欢皮(夜合皮、绒花树皮)
- **来源**: 豆科植物合欢 *Albizia julibrissin* Durazz. 的干燥树皮
- **分布与生境**: 华北至华南广泛分布,野生于山坡,城市中常作行道树、庭院树
- **识别要点**:
  - 植株: 落叶乔木;**二回羽状复叶**,小叶细小、镰刀状,**夜间成对合拢**;夏季开**粉红色绒球状的花**(实际是长长的雄蕊);荚果扁平带状
  - 药材: 卷曲筒状或半筒状,厚0.1-0.3 cm;外表面灰棕色至灰褐色,稍有纵皱纹,有的成浅裂纹,**密生明显的椭圆形横向皮孔,棕色或棕红色**;内表面淡黄棕色或黄白色,平滑;质硬而脆,易折断,断面呈纤维性片状,淡黄棕色或黄白色;气微香,味淡、微涩、稍刺舌,而后喉头有不适感
- **易混淆品**: 同属的山合欢(山槐 *A. kalkora*,花白色或黄白色)树皮有时混入,不是药典品种
- **采收与加工**: 夏、秋二季剥取,晒干;城市行道树受园林部门管理,不要随意剥皮
- **储存**: 放通风干燥处
- **功效**: 解郁安神,活血消肿
- **用量**: 6-12 g;外用适量,研末调敷(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用(经验);失眠、情绪低落持续两周以上的,应当就医,"安神药"不能代替抑郁症、焦虑症的治疗;合欢花是另一味药

## 二、根皮类

根皮类是挖出根后剥下的根皮,去掉中间的木心。挖根会伤及整株,**只挖栽培株,或在移栽、间苗、更新时顺便取皮**;野生灌木挖一株少一株。根皮类之间最危险的混淆是**香加皮**: 它常冒充五加皮,也混作地骨皮,而它含强心苷。

### 2.1 牡丹皮

- **正名(别名)**: 牡丹皮(丹皮、粉丹皮、凤丹皮)
- **来源**: 毛茛科植物牡丹 *Paeonia suffruticosa* Andr. 的干燥根皮
- **分布与生境**: 药用牡丹主要栽培于安徽(铜陵、亳州)、山东、河南、四川等地;观赏牡丹各地都有
- **识别要点**:
  - 植株: 落叶小灌木,高1-2 m,**茎木质**(和草本的芍药相区别);二回三出复叶;春季开大花
  - 药材: 筒状或半筒状,有纵剖开的裂缝,略向内卷曲,厚0.1-0.4 cm;外表面灰褐色或黄褐色,有多数横长皮孔样突起和细根痕,栓皮脱落处粉红色;**内表面淡灰黄色或浅棕色,有明显的细纵纹,常见发亮的结晶**(丹皮酚析出,习称"亮银星");质硬而脆,易折断,断面较平坦,**粉性**,淡粉红色;**气芳香,味微苦而涩**
- **易混淆品**: 芍药(白芍、赤芍的原植物)的根皮、同属野生牡丹的根皮偶有混入;白芍、赤芍是整根入药,见[根及根茎类上-白芍](./01-根及根茎类上.md#22-白芍)
- **采收与加工**: 秋季采挖根部,除去细根和泥沙,剥取根皮,晒干("连丹皮");或刮去粗皮,除去木心,晒干("刮丹皮")
- **储存**: 含丹皮酚,易挥散,**密封,放阴凉干燥处**
- **功效**: 清热凉血,活血化瘀
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**(药典);月经过多者不宜(经验);服抗凝药的人先问医生
- 🛡️ **保护提醒**: 紫斑牡丹、杨山牡丹、卵叶牡丹、大花黄牡丹等野生牡丹属植物列入2021年《国家重点保护野生植物名录》(级别以名录原文为准);药材只用栽培的牡丹,**不挖山里的野牡丹**

### 2.2 地骨皮

- **正名(别名)**: 地骨皮(枸杞根皮)
- **来源**: 茄科植物枸杞 *Lycium chinense* Mill. 或宁夏枸杞 *L. barbarum* L. 的干燥根皮
- **分布与生境**: 枸杞全国大部分地区有野生,生于山坡、田埂、路旁、村边;宁夏枸杞主要栽培于宁夏、甘肃、青海、新疆等地
- **识别要点**:
  - 植株: 多分枝灌木,枝条细长弯曲,**有棘刺**;叶互生或簇生,卵形或披针形;花淡紫色;浆果红色(即枸杞子,见[果实种子类-枸杞子](./03-果实种子类.md#11-枸杞子))
  - 药材: 筒状或槽状,长3-10 cm,厚0.1-0.3 cm;**外表面灰黄色至棕黄色,粗糙,有不规则纵裂纹,易成鳞片状剥落**;内表面黄白色至灰黄色,较平坦,有细纵纹;体轻,质脆,易折断;断面不平坦,外层黄棕色,内层灰白色;气微,味微甘而后苦。经验鉴别概括为"糟皮白里"
- **易混淆品**: **香加皮**(杠柳根皮,有毒)外表也是栓皮松软、鳞片状剥落,有时混作地骨皮;区别是**香加皮有浓烈的特殊香气**,地骨皮气微。详见[香加皮 vs 五加皮](./09-有毒中药与易混淆有毒植物.md#46-香加皮-vs-五加皮)
- **采收与加工**: 春初或秋后采挖根部,洗净,剥取根皮,晒干;只挖栽培株或更新淘汰的老株
- **储存**: 放通风干燥处,防潮
- **功效**: 凉血除蒸,清肺降火
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 外感风寒发热、脾胃虚寒便溏者不宜(经验);长期低热、夜间盗汗、消瘦,要先查结核病等病因

### 2.3 桑白皮

- **正名(别名)**: 桑白皮(桑根白皮、桑皮)
- **来源**: 桑科植物桑 *Morus alba* L. 的干燥根皮
- **分布与生境**: 全国各地,野生或栽培(蚕桑地区大量种植)
- **识别要点**:
  - 植株: 落叶乔木或灌木,**折断枝叶有白色乳汁**;叶卵形,边缘有粗锯齿,有时分裂;桑葚由绿变红再变紫黑
  - 药材: 扭曲的卷筒状、槽状或板片状,厚1-4 mm;**外表面白色或淡黄白色**,较平坦,有的残留橙黄色或棕黄色鳞片状粗皮;内表面黄白色或灰黄色,有细纵纹;体轻,质韧,**纤维性强,难折断,易纵向撕裂,撕裂时有粉尘飞扬**;气微,味微甘
- **易混淆品**: 同属鸡桑、华桑、构树(楮树)等的根皮偶有混入,不是药典品种
- **采收与加工**: 秋末叶落时至次春发芽前采挖根部,**刮去黄棕色粗皮**,纵向剖开,剥取根皮,晒干;只取栽培桑园更新、挖除的老桑树
- **储存**: 易受潮发霉、虫蛀;放通风干燥处
- **功效**: 泻肺平喘,利水消肿
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 肺虚无火、风寒咳嗽者不宜(经验);喘憋、口唇发紫、水肿加重,必须就医;桑叶、桑枝、桑葚各是另外的药材

### 2.4 白鲜皮

- **正名(别名)**: 白鲜皮(白藓皮、八股牛、北鲜皮)
- **来源**: 芸香科植物白鲜 *Dictamnus dasycarpus* Turcz. 的干燥根皮
- **分布与生境**: 东北、华北、华东、西北;生于山坡草地、林缘、疏林下
- **识别要点**:
  - 植株: 多年生草本,高40-100 cm,**全株有强烈的特殊气味**(像羊膻);奇数羽状复叶,叶片上有透明油点;总状花序,花大,淡紫红色或白色,**花瓣上有紫红色的线条**;蒴果5裂
  - 药材: 卷筒状,长5-15 cm,直径1-2 cm,厚0.2-0.5 cm;外表面灰白色或淡灰黄色,有细纵皱纹和细根痕,常有突起的颗粒状小点;内表面类白色,有细纵纹;质脆,折断时有粉尘飞扬;断面不平坦,略呈层片状,剥去外层,迎光可见闪烁的小亮点;**有羊膻气,味微苦**
- **注意**: 白鲜的植株(尤其花和果)接触皮肤后再晒太阳,可引起**光敏性皮炎**(起红斑、水疱),采挖时戴手套、穿长袖
- **采收与加工**: 春、秋二季采挖根部,除去泥沙和粗皮,剥取根皮,干燥
- **储存**: 放通风干燥处,防潮
- **功效**: 清热燥湿,祛风解毒
- **用量**: 5-10 g;外用适量,煎汤洗或研粉敷(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **国内外有多例口服白鲜皮(及含白鲜皮的中成药)引起肝损伤的报道**;肝病患者不用,不长期、大量自服;服用期间出现乏力、食欲差、尿色变深、皮肤眼睛发黄,立即停药就医;脾胃虚寒者不宜

### 2.5 五加皮

- **正名(别名)**: 五加皮(南五加皮、细柱五加皮)
- **来源**: 五加科植物细柱五加 *Acanthopanax gracilistylus* W. W. Smith 的干燥根皮(新分类名 *Eleutherococcus nodiflorus*)
- **分布与生境**: 华中、华东、华南、西南;生于林缘、灌丛、山坡、路边
- **识别要点**:
  - 植株: 灌木,高2-3 m;**枝上有疏生的扁钩刺**;**掌状复叶,小叶5片**(偶3-4片),在长枝上互生、在短枝上簇生;伞形花序,花黄绿色;果熟时黑色
  - 药材: 不规则卷筒状,长5-15 cm,直径0.4-1.4 cm,厚约0.2 cm;外表面灰褐色,有稍扭曲的纵皱纹和横长皮孔样斑痕;内表面淡黄色或灰黄色,有细纵纹;体轻,质脆,易折断;断面不整齐,灰白色;**气微香,味微辣而苦**
- **易混淆品(重点)**: **香加皮**(北五加皮)是萝藦科(新分类归夹竹桃科)藤本杠柳 *Periploca sepium* 的根皮,**含杠柳毒苷等强心苷,有毒**,药典单列为另一味药并标注"有毒"。只说识别:
  - 植株: **缠绕藤本,折断有白色乳汁**,叶对生、披针形、光滑无刺;五加是**带刺的直立灌木,掌状复叶**
  - 药材: 香加皮**栓皮松软、常呈鳞片状剥落**,**有浓烈的特异香气**(有人形容像冬青油);五加皮只是气微香
  - 中毒表现: 恶心呕吐、视物发黄发绿、**心跳过慢或心律失常**,严重时心跳骤停;服地高辛等强心药的人风险更大
  - 对照表见[香加皮 vs 五加皮](./09-有毒中药与易混淆有毒植物.md#46-香加皮-vs-五加皮)。**不要自己买"五加皮"泡药酒**,北方市场上的"五加皮"不少就是香加皮
- **采收与加工**: 夏、秋二季采挖根部,洗净,剥取根皮,晒干
- **储存**: 放通风干燥处,防潮防蛀
- **功效**: 祛风除湿,补益肝肾,强筋壮骨,利水消肿
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺者慎用(经验);刺五加(*Eleutherococcus senticosus*)是另一味药,用根和根茎或茎

## 三、茎枝与藤茎类

这一组是带皮的嫩枝和木质藤茎,多在秋冬落叶后采收、趁鲜切片。干燥后的藤茎切片彼此很像,**认藤要在采的时候看整株: 叶、花、果、乳汁、气味**。林缘灌丛里同时长着剧毒的**钩吻(断肠草)**和**雷公藤**("黄藤"),都是藤本或攀援灌木,见[钩吻 vs 金银花](./09-有毒中药与易混淆有毒植物.md#42-钩吻-vs-金银花)和[雷公藤](./09-有毒中药与易混淆有毒植物.md#214-雷公藤)。不认识整株植物的藤,一段都不采。

### 3.1 桂枝

- **正名(别名)**: 桂枝(柳桂、嫩桂枝)
- **来源**: 樟科植物肉桂 *Cinnamomum cassia* Presl 的干燥嫩枝
- **分布与生境**: 同[肉桂](#14-肉桂),广西、广东等地栽培
- **识别要点**:
  - 药材: 长圆柱形,多分枝,长30-75 cm,粗端直径0.3-1 cm;表面红棕色至棕色,有纵棱线、细皱纹及小疙瘩状的叶痕、枝痕和芽痕,皮孔点状;质硬而脆,易折断;切片厚2-4 mm,**切面皮部红棕色,木部黄白色至浅黄棕色,髓部略呈方形**;**有特异香气,味甜、微辛,皮部味较浓**
- **易混淆品**: 同属其他樟科植物的嫩枝香气淡、无甜味;认准"皮红、髓方、甜辛"
- **采收与加工**: 春、夏二季采收,除去叶,晒干,或切片晒干;来自栽培肉桂的修剪枝,不伤主干
- **储存**: 含挥发油,密封,放阴凉干燥处
- **功效**: 发汗解肌,温通经脉,助阳化气,平冲降逆
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**(药典);发热口渴、咽喉肿痛、有出血倾向者不宜(经验)

### 3.2 桑枝

- **正名(别名)**: 桑枝(嫩桑枝)
- **来源**: 桑科植物桑 *Morus alba* L. 的干燥嫩枝
- **分布与生境**: 同[桑白皮](#23-桑白皮),全国各地
- **识别要点**:
  - 药材: 长圆柱形,少有分枝,长短不一,直径0.5-1.5 cm;表面灰黄色或黄褐色,有多数黄褐色点状皮孔及细纵纹,并有灰白色略呈半圆形的叶痕和黄棕色的腋芽;质坚韧,不易折断;**切面皮部较薄,木部黄白色,射线放射状,髓部白色或黄白色**;气微,味淡
- **采收与加工**: 春末夏初采收,去叶,晒干,或趁鲜切片,晒干;桑园冬季修剪的枝条也可利用
- **储存**: 放通风干燥处,防霉防蛀
- **功效**: 祛风湿,利关节
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 关节红肿热痛突然发作(痛风、化脓性关节炎)、关节变形,要先就医查明病因

### 3.3 鸡血藤

- **正名(别名)**: 鸡血藤(血风藤、密花豆藤)
- **来源**: 豆科植物密花豆 *Spatholobus suberectus* Dunn 的干燥藤茎
- **分布与生境**: 广西、广东、云南、福建等地的山地疏林、沟谷灌丛
- **识别要点**:
  - 植株: 大型木质攀援藤本;**三出复叶**,小叶宽椭圆形;圆锥花序,花白色;**砍断藤茎有红色汁液流出**(像鸡血)
  - 药材: 椭圆形、长矩圆形或不规则的斜切片,厚0.3-1 cm;栓皮灰棕色,有的可见灰白色斑,栓皮脱落处显红棕色;质坚硬;**切面木部红棕色或棕色,导管孔多数;韧皮部有树脂状分泌物,呈红棕色至黑棕色,与木部相间排列,形成3-8个偏心性半圆形环;髓部偏向一侧**;气微,味涩
- **易混淆品**:
  - **大血藤**: 名字相近、常被混用,但切面是"皮部红棕色嵌入木部、木部黄白色",**没有多层偏心环**,见[3.4](#34-大血藤)
  - **山鸡血藤**(香花崖豆藤等崖豆藤属)、**滇鸡血藤**(五味子科,药典另列)等各地叫"鸡血藤"的藤茎不少;认准"多层红黑色偏心环"
  - 雷公藤也被叫作"黄藤",老藤断面不呈红色同心环;不认识的藤不采
- **采收与加工**: 秋、冬二季采收,除去枝叶,切片,晒干
- **储存**: 放通风干燥处
- **功效**: 活血补血,调经止痛,舒筋活络
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用;月经过多、有出血倾向者不宜;服抗凝药的人先问医生(经验);"补血"不能代替贫血的病因检查和治疗

### 3.4 大血藤

- **正名(别名)**: 大血藤(红藤、血藤)
- **来源**: 木通科植物大血藤 *Sargentodoxa cuneata* (Oliv.) Rehd. et Wils. 的干燥藤茎
- **分布与生境**: 长江流域及以南各省的山坡灌丛、疏林、林缘
- **识别要点**:
  - 植株: 落叶木质藤本;**三出复叶**,中间小叶菱状卵形,两侧小叶斜卵形、两边不对称;总状花序下垂,花黄绿色,有香气;聚合浆果,熟时蓝黑色、被白粉,生在膨大的红色肉质花托上
  - 药材: 圆柱形,略弯曲,直径1-3 cm;表面灰棕色,粗糙,**外皮常呈鳞片状剥落**,剥落处显暗红棕色;质硬;**断面皮部红棕色,有数处向内嵌入木部;木部黄白色,有多数细孔状导管,射线呈放射状排列**;气微,味微涩
- **易混淆品**: 与鸡血藤互相混淆,区别见[鸡血藤](#33-鸡血藤);两者功效不同,不能互代
- **采收与加工**: 秋、冬二季采收,除去侧枝,截段,干燥
- **储存**: 放通风干燥处
- **功效**: 清热解毒,活血,祛风止痛
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**(药典);中医用于"肠痈",但**右下腹持续疼痛、发热(可能是阑尾炎)必须就医**,不能只靠草药

### 3.5 忍冬藤

- **正名(别名)**: 忍冬藤(金银藤、银花藤)
- **来源**: 忍冬科植物忍冬 *Lonicera japonica* Thunb. 的干燥茎枝(花蕾即金银花)
- **分布与生境**: 全国大部分地区,野生于山坡灌丛、林缘、路旁;山东、河南等地大量栽培
- **识别要点**:
  - 植株: 半常绿缠绕藤本;**叶对生**,卵形至长圆状卵形,全缘,幼时两面有毛;**花成对生于叶腋,初开白色、后变黄色**("金银"),有清香,花冠二唇形;浆果球形,熟时黑色
  - 药材: 长圆柱形,多分枝,常缠绕成束,直径1.5-6 mm;表面棕红色至暗棕色,有的灰绿色,光滑或被茸毛;**外皮易剥落**;枝上多节,节间长6-9 cm,有残叶和叶痕;质脆,易折断;**断面黄白色,中空**;气微,老枝味微苦,嫩枝味淡
- **易混淆品(致命)**: **钩吻**(断肠草 *Gelsemium elegans*,剧毒)也是缠绕藤本、叶对生,常和忍冬长在同一片山坡,两广、福建、云贵多见,**误采钩吻的藤叶、花煎服可在短时间内致死**:
  - 钩吻的花是**黄色漏斗状,五裂、整齐**,多朵聚成顶生或腋生的聚伞花序;忍冬的花白黄两色、二唇形、成对生在叶腋
  - 钩吻叶片光滑无毛;忍冬嫩叶和嫩枝多有毛
  - 不开花时极难区分——**没见到花的藤,不采**。详见[钩吻 vs 金银花](./09-有毒中药与易混淆有毒植物.md#42-钩吻-vs-金银花)
- **采收与加工**: 秋、冬二季采割,晒干;栽培金银花修剪下来的枝条是好来源
- **储存**: 放通风干燥处
- **功效**: 清热解毒,疏风通络
- **用量**: 9-30 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒、经常腹泻者不宜(经验)

### 3.6 首乌藤

- **正名(别名)**: 首乌藤(夜交藤)
- **来源**: 蓼科植物何首乌 *Polygonum multiflorum* Thunb. 的干燥藤茎(块根即何首乌,见[根及根茎类上-何首乌](./01-根及根茎类上.md#26-何首乌))
- **分布与生境**: 华东、华中、华南、西南及陕西、甘肃南部;生于山坡灌丛、沟边石隙、村边
- **识别要点**:
  - 植株: 多年生缠绕藤本;茎多分枝,下部木质化;**叶互生,卵状心形,有长柄**;**托叶鞘膜质、抱茎**(蓼科特征);圆锥花序,花小,白色或淡绿色;地下有肥厚的块根
  - 药材: 长圆柱形,稍扭曲,具分枝,长短不一,直径4-7 mm;**表面紫红色至紫褐色**,粗糙,有扭曲的纵皱纹,节部略膨大,有侧枝痕,外皮菲薄,可剥离;质脆,易折断;**断面皮部紫红色,木部黄白色或淡棕色,导管孔明显,髓部疏松,类白色**;气微,味微苦涩
- **易混淆品**: 同科的虎杖、杠板归等的茎有时混入;山里同为心形叶的缠绕藤本很多(包括马兜铃属,叶也心形,但花为烟斗形,见[怎样认出马兜铃科植物](./09-有毒中药与易混淆有毒植物.md#34-怎样认出马兜铃科植物)),采前看整株
- **采收与加工**: 秋、冬二季采割,除去残叶,捆成把或趁鲜切段,干燥
- **储存**: 放通风干燥处
- **功效**: 养血安神,祛风通络
- **用量**: 9-15 g;外用适量,煎水洗患处(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 何首乌有引起**肝损伤**的大量报道,首乌藤与之同株,风险虽较低,也**不要长期大量自服**;肝病患者不用;用药期间出现乏力、尿黄、眼黄立即停药就医;长期失眠应就医查找原因

### 3.7 钩藤

- **正名(别名)**: 钩藤(双钩藤、钩丁)
- **来源**: 茜草科植物钩藤 *Uncaria rhynchophylla* (Miq.) Miq. ex Havil.、大叶钩藤 *U. macrophylla* Wall.、毛钩藤 *U. hirsuta* Havil.、华钩藤 *U. sinensis* (Oliv.) Havil. 或无柄果钩藤 *U. sessilifructus* Roxb. 的干燥带钩茎枝
- **分布与生境**: 长江以南各省的山谷溪边疏林、灌丛
- **识别要点**:
  - 植株: 常绿木质藤本;**叶对生**;**叶腋处生有成对或单个的弯钩**(由不育的花序梗变成),像鱼钩一样向下弯;头状花序球形,黄色
  - 药材: 茎枝圆柱形或类方柱形,长2-3 cm,直径0.2-0.5 cm;表面红棕色至紫红色(钩藤),或棕褐色、带白色点状皮孔(其他种);**多数枝节上对生两个向下弯曲的钩,或仅一侧有钩**,钩略扁或稍圆,先端细尖,基部较阔;钩基部的枝上可见叶柄脱落后的窝点状痕迹和环状的托叶痕;质坚韧,断面黄棕色,皮部纤维性,髓部黄白色或中空;气微,味淡
- **采收与加工**: 秋、冬二季采收,**去叶,切段**(每段带钩),晒干;只剪带钩的枝段,不连根拔藤
- **储存**: 放通风干燥处
- **功效**: 息风定惊,清热平肝
- **用量**: 3-12 g,**后下**(久煎有效成分会被破坏)(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒者慎用(经验);钩藤有一定降压作用,服降压药的人先问医生;**小儿高热抽搐、成人突发头痛眩晕、口眼歪斜、肢体无力(可能是中风),立即拨打120**

### 3.8 络石藤

- **正名(别名)**: 络石藤(络石、白花藤、石龙藤)
- **来源**: 夹竹桃科植物络石 *Trachelospermum jasminoides* (Lindl.) Lem. 的干燥带叶藤茎
- **分布与生境**: 华东、华中、华南、西南及河北、陕西;攀附在树干、岩石、墙上,也常作绿化栽培
- **识别要点**:
  - 植株: 常绿木质藤本,**茎上生气生根,攀附他物**;**全株折断有白色乳汁**;**叶对生**,革质,椭圆形,光亮;春末开**白色、有浓香的花,花冠5裂、裂片向一侧旋转,像小风车**;蓇葖果双生,细长如筷
  - 药材: 茎圆柱形,弯曲,多分枝,直径1-5 mm;表面红褐色,有点状皮孔和不定根;质硬,断面淡黄白色,常中空;叶对生,有短柄,展平后椭圆形或卵状披针形,全缘,略反卷,上表面暗绿色或棕绿色,下表面色较淡,革质;气微,味微苦
- **易混淆品**: **薜荔**(桑科 *Ficus pumila*,"凉粉果")也爬墙、有白色乳汁,但**叶互生**,结的是倒卵形的大"果"(隐头花序);地锦(葡萄科"爬山虎")叶有长柄、三裂,用卷须吸盘攀爬,无乳汁。"爬墙虎"这类俗名各地所指不同,按植物认
- **采收与加工**: 冬季至次春采割,除去杂质,晒干
- **储存**: 放通风干燥处
- **功效**: 祛风通络,凉血消肿
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 夹竹桃科植物多含有毒成分,**不超量、不长期服用**(经验);孕妇不宜;夹竹桃本身剧毒,见[夹竹桃](./09-有毒中药与易混淆有毒植物.md#415-夹竹桃)

### 3.9 川木通

- **正名(别名)**: 川木通(淮木通、油木通)
- **来源**: 毛茛科植物小木通 *Clematis armandii* Franch. 或绣球藤 *C. montana* Buch.-Ham. 的干燥藤茎
- **分布与生境**: 四川、贵州、湖南、湖北、陕西、甘肃等地的山坡林缘、灌丛
- **识别要点**:
  - 植株: 木质藤本(铁线莲属);**叶对生**,三出复叶;小木通为常绿藤本、小叶革质,花白色;绣球藤为落叶藤本,花白色或带粉红色;**瘦果顶端有羽毛状的长尾**,一团团像白色绒球
  - 药材: 长圆柱形,略扭曲,直径2-3.5 cm;表面黄棕色或黄褐色,有纵向凹沟及棱线;节处多膨大,有叶痕及侧枝痕;残存皮部易撕裂;质坚硬,不易折断;切片厚2-4 mm,**边缘不整齐,残存皮部黄棕色,木部浅黄棕色或浅黄色,有黄白色放射状纹理及裂隙,其间布满导管孔,髓部较小**,类白色或黄棕色,偶有空腔;气微,味淡
- **易混淆品(致命)**: **关木通**——马兜铃科东北马兜铃 *Aristolochia manshuriensis* 的藤茎,**含马兜铃酸**。2003年以前曾大量作"木通"使用,引起了一批马兜铃酸肾病(肾衰竭)病例,**2003年起国家取消其药用标准**。马兜铃酸的肾损害不可逆,还会导致尿路上皮癌:
  - 关木通断面**黄色,导管孔多、排列成多层整齐的环,射线放射状,像蜘蛛网**;摩擦残余粗皮有**樟脑样气味**,味苦
  - 川木通断面浅黄棕色,纹理不整齐、有裂隙,气微、味淡
  - 药典另有"木通"(木通科木通、三叶木通或白木通的藤茎),也不是关木通
  - 对照表见[关木通 vs 川木通、广防己 vs 粉防己](./09-有毒中药与易混淆有毒植物.md#47-关木通-vs-川木通广防己-vs-粉防己),马兜铃酸的危害见[含马兜铃酸的药材](./09-有毒中药与易混淆有毒植物.md#三含马兜铃酸的药材)。**名字里带"木通"的草药一律不自采、不在市场散买**
- **采收与加工**: 春、秋二季采收,除去粗皮,晒干,或趁鲜切薄片,晒干
- **储存**: 放通风干燥处
- **功效**: 利尿通淋,清心除烦,通经下乳
- **用量**: 3-6 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用;精亏、无湿热、小便过多者不宜(经验);尿频尿痛伴发热、腰痛、血尿,要就医

## 四、茎髓与竹茹

这两味药都不是"皮"也不是"木": 通草是茎中心的髓,竹茹是竹秆外皮下面的中间层。它们都轻、软、白,容易吸潮发霉,要单独存放。

### 4.1 通草

- **正名(别名)**: 通草(通脱木、大通草、白通草)
- **来源**: 五加科植物通脱木 *Tetrapanax papyrifer* (Hook.) K. Koch 的干燥茎髓
- **分布与生境**: 长江以南各省及陕西南部;生于向阳山坡、林缘、杂木林中,也有栽培
- **识别要点**:
  - 植株: 常绿灌木或小乔木,高1-3.5 m;**叶极大,集生茎顶,掌状5-11裂**,叶背密生白色或淡棕色的星状绒毛;茎粗壮,**中央有很粗的白色髓**(旧时用来做"通草纸"和通草花)
  - 药材: 圆柱形,长20-40 cm,直径1-2.5 cm;表面白色或淡黄色,有浅纵沟纹;**体轻,质松软,稍有弹性**,易折断;**断面平坦,显银白色光泽,中部有直径0.3-1.5 cm的空心或半透明的薄膜,纵剖面呈梯状排列**,实心者少见;气微,味淡
- **易混淆品**:
  - **小通草**: 旌节花科喜马山旌节花、中国旌节花或山茱萸科青荚叶的茎髓,较细(直径0.5-1 cm),药典另列
  - 古代医书里的"通草"多指今天的**木通**,读古方时不要把两者对换;更不能拿关木通(马兜铃科)代替,见[川木通](#39-川木通)
- **采收与加工**: 秋季割取茎,截成段,**趁鲜取出髓部**,理直,晒干
- **储存**: 体轻易碎、易吸潮,**装箱或布袋,放干燥处,防压防潮**
- **功效**: 清热利尿,通气下乳
- **用量**: 3-5 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**(药典);乳房红肿热痛、有硬块、发热(乳腺炎),要就医

### 4.2 竹茹

- **正名(别名)**: 竹茹(竹二青、淡竹茹、青竹茹)
- **来源**: 禾本科植物青秆竹 *Bambusa tuldoides* Munro、大头典竹 *Sinocalamus beecheyanus* (Munro) McClure var. *pubescens* P. F. Li 或淡竹 *Phyllostachys nigra* (Lodd.) Munro var. *henonis* (Mitf.) Stapf ex Rendle 的茎秆的干燥中间层
- **分布与生境**: 青秆竹、大头典竹产于华南;淡竹产于长江流域;多为栽培
- **识别要点**:
  - 药材: 卷曲成团的不规则丝条,或呈长条形薄片;宽窄厚薄不等,**浅绿色、黄绿色或黄白色**;纤维性,体轻松,质柔韧,有弹性;气微,味淡
  - 来源: 新鲜竹秆刮去最外一层青绿色的表皮后,再刮下来的那层带淡绿色的丝条
- **易混淆品**: 其他竹种的刮丝常混用;陈旧发黄发黑、有霉斑的不用
- **采收与加工**: 全年均可采制,取新鲜茎,除去外皮,将**稍带绿色的中间层刮成丝条**("散竹茹"),或削成薄片,捆扎成束("齐竹茹"),阴干;砍竹时选3年以上的老竹,不砍新竹
- **储存**: 易吸潮发霉,**放干燥处,防潮防蛀**
- **功效**: 清热化痰,除烦,止呕
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 胃寒呕吐者不宜(经验);**孕早期频繁剧烈呕吐、喝水也吐、尿少、体重下降(妊娠剧吐)必须就医输液**;呕吐伴剧烈腹痛、头痛、发热,也要先查原因

## 五、心材与含树脂木材

心材是树干中心颜色深的部分(外面浅色的叫边材,要去掉)。苏木、降香、檀香、沉香都来自生长很慢的热带、亚热带树木,**一棵树要几十年才能形成有价值的心材或香脂**,所以价格高、野生资源被大量盗伐,市面上伪品、染色品、注油品极多。

```
这一组的底线:
- 不采伐、不收购野生的降香檀、土沉香(都是国家二级保护野生植物);
  沉香属所有种列入CITES附录II,进出口需要许可证明
- 药用只从正规药房购买,不从古玩、"收藏"市场买"药材"
- 野外认得这些树,是为了知道"不能砍",不是为了去找
- 火试(点燃闻香、看油)只用很小的碎屑,在空旷处、远离易燃物进行
```

### 5.1 苏木

- **正名(别名)**: 苏木(苏方木、红苏木)
- **来源**: 豆科植物苏木 *Caesalpinia sappan* L. 的干燥心材
- **分布与生境**: 广西、广东、云南、台湾等地,栽培或野生于山谷、丛林
- **识别要点**:
  - 植株: 灌木或小乔木;**枝上有疏刺**;二回羽状复叶;圆锥花序,花黄色;荚果木质,扁平
  - 药材: 长圆柱形或对剖半圆柱形,直径3-12 cm;**表面黄红色至棕红色**,有刀削痕,常见纵向裂缝;质坚硬;断面略具光泽,年轮明显,有的可见暗棕色、质松、带亮星的髓部;气微,味微涩
  - **水试**: 取碎片投入热水中,**水被染成鲜艳的桃红色**;苏木自古就是红色染料(经验)
- **易混淆品**: 用染料染红的普通木材: 水泡后颜色发浑、掉色快,碎片内外颜色不一致
- **采收与加工**: 多于秋季采伐,除去白色边材,干燥;用栽培树
- **储存**: 不易变质;放干燥处
- **功效**: 活血祛瘀,消肿止痛
- **用量**: 3-9 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**(药典);月经过多、有出血倾向者不宜;服抗凝药的人先问医生(经验);外伤肿痛先按[急救与家庭健康](../01-日常疾病和伤害/README.md)处理,骨折要就医

### 5.2 降香

- **正名(别名)**: 降香(降真香、紫降香、花梨母)
- **来源**: 豆科植物降香檀 *Dalbergia odorifera* T. Chen 树干和根的干燥心材
- **分布与生境**: 海南特产,野生于中海拔以下的山坡疏林、林缘;广东、广西、福建等地有栽培。降香檀的木材就是名贵红木"海南黄花梨"
- **识别要点**:
  - 植株: 半落叶乔木;奇数羽状复叶,小叶9-13片,卵形或椭圆形;圆锥花序,花小,淡黄色或乳白色;荚果舌状长圆形,种子处明显隆起
  - 药材: 类圆柱形或不规则块状;**表面紫红色或红褐色**,切面有致密的纹理;质硬,**有油性**;气微香,味微苦
  - **火试**: 点燃后**香气浓烈,有油状物流出,烧完留有白灰**
- **易混淆品/伪品**: 进口的其他黄檀属(如印度、东南亚的"降香""黄花梨")和其他红色硬木常被冒充;染色、浸油的普通木材火试香气弱、无油或冒黑烟。正规药房的降香来自合法栽培
- **采收与加工**: 全年均可采收,除去边材,阴干;**只用合法栽培、有来源证明的木材**
- **储存**: 放阴凉干燥处,防香气散失
- **功效**: 化瘀止血,理气止痛
- **用量**: 9-15 g,**后下**;外用适量,研细末敷患处(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用;阴虚火旺、有出血倾向者不宜(经验);胸痛、胸闷持续不缓解(可能是心肌梗死),**立即拨打120**,不要靠"理气止痛"的药拖延
- 🛡️ **保护提醒**: 降香檀列入2021年《国家重点保护野生植物名录》二级;野生树因"黄花梨"热被盗伐殆尽,**不砍伐、不收购野生降香檀**,不从红木、收藏市场买"药材"

### 5.3 檀香

- **正名(别名)**: 檀香(白檀、白檀香、真檀)
- **来源**: 檀香科植物檀香 *Santalum album* L. 树干的干燥心材
- **分布与生境**: 原产印度、印度尼西亚等热带地区;我国广东、海南、云南、台湾等地引种栽培。檀香是**半寄生植物**,幼苗需要和其他植物(寄主)种在一起,靠根吸取寄主的养分
- **识别要点**:
  - 植株: 常绿小乔木;叶对生,椭圆状卵形,膜质;花初为淡黄色,后变深紫红色;核果球形,熟时深紫红色至紫黑色
  - 药材: 长短不一的圆柱形木段,有的略弯曲,直径10-30 cm;**外表面灰黄色或黄褐色,光滑细腻**,有的有疤节或纵裂;横截面呈棕黄色,**显油迹**;棕色年轮明显或不明显;纵向劈开纹理顺直;质坚实,不易折断;**气清香,燃烧时香气更浓;味淡,嚼之微有辛辣感**
- **易混淆品/伪品**: 用檀香精油或香精浸泡的普通木材(香气浮而冲鼻、放久就散、断面没有油迹);澳洲檀香等同属其他种不是药典品种;"紫檀""黑檀""绿檀"等是完全不同的木材,不是檀香
- **采收与加工**: 采伐木材后,切成段,除去树皮和边材即得;来自栽培树
- **储存**: 密封,放阴凉干燥处,防香气散失
- **功效**: 行气温中,开胃止痛
- **用量**: 2-5 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺、有出血倾向者不宜(经验);檀香精油不要内服,也不要直接大量涂在皮肤上
- 🛡️ **资源提醒**: 檀香在原产地因过度采伐资源锐减,印度等国对其采伐和出口实行严格管制;国内药用依靠栽培

### 5.4 沉香

- **正名(别名)**: 沉香(白木香、土沉香、莞香、国产沉香)
- **来源**: 瑞香科植物白木香 *Aquilaria sinensis* (Lour.) Gilg 含有树脂的木材
- **分布与生境**: 海南、广东、广西、云南、福建、台湾;野生于低海拔的山地、丘陵疏林;广东、海南等地大量人工种植
- **识别要点**:
  - 植株: 常绿乔木;叶互生,革质,卵形或椭圆形,有光泽;伞形花序,花黄绿色,有香气;蒴果卵球形,被灰黄色短柔毛,成熟后2瓣裂,种子基部有一条长尾
  - **怎样"结香"**: 健康的白木香木材是白色、无香的;**只有在树干受伤(雷击、虫蛀、刀砍、真菌侵染)后,伤口周围的木材分泌树脂,经过多年积累,才形成黑褐色、有香气的"沉香"**。所以药材是"含树脂的木材",不是整块木头
  - 药材: 不规则块、片状或盔帽状,有的为小碎块;表面凹凸不平,有刀痕,偶有孔洞;**可见黑褐色树脂与黄白色木部相间的斑纹**,孔洞及凹窝表面多呈朽木状;质较坚实,断面刺状;**气芳香,味苦**
  - **火试**: 点燃后**冒浓烟、香气浓烈,有黑色油状物渗出**
- **人工结香**: 现在药用沉香主要来自人工种植的白木香,用打洞、接种菌剂、输液等方法促进结香(《中国药典》2020年版要求醇溶性浸出物不少于10%,人工结香品只要质量达标即可药用)。这是保护野生资源的正确方向
- **伪品(很多)**:
  - 注胶、注油: 用沉香油、松香、色素等注入或浸泡普通木材或含脂量低的白木香,加重、加黑;切开内外颜色不一,火试冒黑烟、有刺鼻的胶臭
  - 用其他木材雕刻、染黑后冒充;"沉水"并不能证明是沉香(注入重物也能沉水)
  - 进口沉香(其他沉香属植物)不是药典品种
- **采收与加工**: 全年均可采收,割取含树脂的木材,除去不含树脂的部分,阴干
- **储存**: 密封,放阴凉干燥处,防香气散失
- **功效**: 行气止痛,温中止呕,纳气平喘
- **用量**: 1-5 g,**后下**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺、气虚下陷者慎用(经验);**价格昂贵,不要花高价买"老沉香"当保健品**;喘憋加重、胸痛要就医
- 🛡️ **保护提醒**: **沉香属所有种自2004年起列入CITES(《濒危野生动植物种国际贸易公约》)附录II**,国际贸易需要许可证明;土沉香(白木香)列入2021年《国家重点保护野生植物名录》二级。野生白木香因为"割香""砍树找香"已非常稀少,**不砍伐、不割取、不收购野生白木香**

## 六、易混淆汇总与自我检查

### 6.1 易混淆与风险汇总

| 本章品种 | 主要风险 | 怎样避免 |
|---------|---------|---------|
| 杜仲、厚朴、黄柏、肉桂 | 环剥致树死亡;剥野生保护树 | 只剥栽培树的一侧或修剪枝;不剥野生树 |
| 杜仲 | 丝棉木、杜仲藤等"土杜仲" | 白丝密、多、拉长1 cm以上不断 |
| 厚朴 | 木兰科其他植物的树皮 | 内表面紫褐、油润,气香、味辛辣 |
| 秦皮 | 核桃楸皮冒充 | 热水浸出液在日光下有碧蓝色荧光 |
| 五加皮、地骨皮 | **香加皮**(强心苷,可致心律失常) | 有浓烈特殊香气的不用;不自买泡酒 |
| 白鲜皮、首乌藤 | 肝损伤 | 不长期大量自服;肝病不用 |
| 川木通 | **关木通**(马兜铃酸,肾衰竭、致癌) | 名字带"木通"的不自采、不散买 |
| 忍冬藤 | **钩吻**(断肠草,可迅速致死) | 没见到花的藤不采 |
| 鸡血藤 | 大血藤、山鸡血藤、雷公藤("黄藤") | 断面有多层红黑色偏心环;不认识的藤不采 |
| 络石藤 | 薜荔、地锦混用 | 叶对生、白色风车状花、细长双生果 |
| 肉桂、桂枝、苏木、牡丹皮、大血藤、通草 | 孕妇用后可能不安全;增加出血 | 孕妇慎用;服抗凝药的人先问医生 |
| 降香、沉香、檀香 | 保护物种、伪品、注油染色 | 只从正规药房买;不砍野生树 |

### 6.2 自我检查

采皮类、藤木类药材之前,逐条确认:

- [ ] 我采的是栽培树、修剪下来的枝条或间伐的树干,不是野生的杜仲、厚朴、黄柏、降香檀、白木香
- [ ] 剥皮只剥一侧(条剥或半环剥),没有绕树一圈;伤口已包扎
- [ ] 采藤茎前我看清了整株的叶、花、果,排除了钩吻、雷公藤和马兜铃科植物
- [ ] 名字里带"木通"的,我只从正规药房凭处方取
- [ ] "五加皮""地骨皮"闻过了: 没有浓烈的特殊香气
- [ ] 采根皮只挖栽培株或更新淘汰的老株
- [ ] 加工后摊开晒干,含挥发油的(厚朴、肉桂、桂枝、牡丹皮、檀香、沉香、降香)密封存放
- [ ] 我知道药典用量和禁忌,孕妇、儿童、肝肾病人、服抗凝药或强心药的人先问医生

| 环节 | 难度 | 出错的风险 |
|------|------|----------|
| 认杜仲、秦皮、苏木(有简单的试验) | ⭐⭐ | ☠️(混入伪品) |
| 认厚朴、黄柏、肉桂、牡丹皮药材 | ⭐⭐⭐ | ☠️(用错药) |
| 不伤树地剥取树皮 | ⭐⭐⭐ | 剥死树木;违法剥取保护植物 |
| 区分五加皮与香加皮 | ⭐⭐⭐ | ☠️☠️☠️☠️(强心苷中毒) |
| 野外认藤茎(忍冬藤、鸡血藤、络石藤) | ⭐⭐⭐⭐ | ☠️☠️☠️☠️☠️(误采钩吻、雷公藤) |
| 区分川木通与关木通 | ⭐⭐⭐⭐ | ☠️☠️☠️☠️(不可逆肾衰竭、致癌) |
| 辨别沉香、降香、檀香真伪 | ⭐⭐⭐⭐⭐ | 上当受骗;购买盗伐的保护植物 |

## 📝 本章要点

```
□ 剥树皮不环剥: 只剥一侧,优先用修剪、间伐下来的枝干
□ 野生杜仲、厚朴、黄柏受国家保护,只用栽培品
□ 杜仲断面拉出密集的银白色胶丝;秦皮水浸液有蓝色荧光;苏木泡水变桃红
□ 五加皮、地骨皮有浓烈特殊香气的,可能是香加皮(强心苷),不用
□ 关木通含马兜铃酸,已取消药用标准;名字带"木通"的不自采
□ 采藤先看整株;没见到花的藤不采,防钩吻(断肠草)和雷公藤
□ 白鲜皮、首乌藤有肝损伤可能,不长期大量自服
□ 钩藤、降香、沉香入汤剂后下
□ 沉香属列入CITES附录II,土沉香、降香檀国家二级保护;不砍野生树
□ 肉桂、桂枝、苏木、牡丹皮、大血藤、通草孕妇慎用
```
