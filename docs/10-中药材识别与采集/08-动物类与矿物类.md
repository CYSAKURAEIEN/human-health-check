# 动物类与矿物类

> **动物药和矿物药是中药里最容易"出事"的两类: 一类牵涉保护动物和违法交易,一类牵涉汞、砷、铅等重金属——认它们,先认清哪些能用、哪些根本不该碰**

本章收录常用的动物药18味、保护动物药材7种和矿物药9味: 动物药按来源分为胶、角、甲壳类(鹿茸、阿胶、龟甲、鳖甲、牡蛎、珍珠、石决明、海螵蛸)和昆虫、蠕虫及其他(蝉蜕、僵蚕、地龙、全蝎、蜈蚣、土鳖虫、水蛭、蜂蜜、蜂房、鸡内金);保护动物(穿山甲、犀角、虎骨、天然麝香、熊胆、羚羊角、玳瑁)**只写法律禁令和合法替代品**;矿物药包括石膏、滑石、芒硝、龙骨、磁石、赭石、炉甘石、白矾、硼砂;朱砂、雄黄等有毒矿物药只列名,详见[有毒中药与易混淆有毒植物](./09-有毒中药与易混淆有毒植物.md)。识别、采收、干燥、储存的通用方法见[总论](./00-总论.md),本章不再重复。

```

## 一、胶、角、甲壳类

这一组药材来自鹿角、驴皮、龟鳖的甲和海里的贝壳。它们的共同点: **原料来自养殖或水产捕捞,普通人不需要、也不应该去野外"找"**;要学的是辨认买来的药材真假,和知道哪些动物受保护。

贝壳和甲类质地坚硬,入汤剂多要"先煎"(先煮半小时左右再下其他药),煅制方法见[中药制剂-煅制](../06-制药技术/04-中药制剂.md#煅制)。它们主要成分是碳酸钙、角蛋白和胶质,药性平和,但**不能代替补钙药或治疗骨质疏松**。

### 1.1 鹿茸

- **正名(别名)**: 鹿茸;梅花鹿的称"花鹿茸",马鹿的称"马鹿茸"
- **来源**: 鹿科动物梅花鹿 *Cervus nippon* Temminck 或马鹿 *Cervus elaphus* Linnaeus 的雄鹿未骨化、密生茸毛的幼角
- 🛡️ **合法来源只有人工养殖**: 野生梅花鹿是国家一级保护野生动物,野生马鹿是国家二级保护野生动物(2021年《国家重点保护野生动物名录》,均"仅限野外种群");梅花鹿、马鹿已列入《国家畜禽遗传资源目录》,养殖场的鹿可以合法生产鹿茸。**不猎捕野鹿,不买来路不明的"野生鹿茸"**
- **分布与生境**: 养殖场主要在吉林、辽宁、黑龙江(梅花鹿)和新疆、内蒙古、东北(马鹿)
- **识别要点**:
  - 花鹿茸(二杠): 圆柱状分枝,主枝习称"大挺",长17-20 cm,侧枝一个;**外皮红棕色或棕色,多光润,表面密生红黄色或棕黄色细茸毛**;锯口黄白色,外围无骨质,中部密布细孔(蜂窝状);体轻;气微腥,味微咸
  - 马鹿茸: 较花鹿茸粗大,分枝较多;外皮灰黑色,茸毛灰褐色或灰黄色;锯口外皮较厚,外围多已骨化
  - 鹿茸片: 顶端切下的"蜡片"黄白色、半透明、像蜡,中段"粉片""血片"有细密小孔,近基部的"骨片"孔大、质硬——**越靠下越接近骨头,价值越低**
- **伪品**: 用其他鹿类的茸冒充;用**动物皮包裹骨胶、面粉压成的假鹿茸片**(泡水后散开、没有蜂窝状小孔,经验);用骨化的鹿角片染色冒充茸片。鹿角、鹿角霜、鹿角胶是另外的药材,药性和价格都不同
- **采收与加工**: 养殖场在夏、秋二季由专业人员锯取,经加工后阴干或烘干;锯茸需要麻醉保定,有出血和伤人的风险,只能由养殖专业人员操作
- **储存**: 密封,置阴凉干燥处,**防蛀**(总论提到可与花椒同贮,见[常见虫害与对策](./00-总论.md#63-常见虫害与对策))
- **功效**: 壮肾阳,益精血,强筋骨,调冲任,托疮毒
- **用量**: 1-2 g,研末冲服(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 药性温热: 发热、阴虚火旺(手足心热、口干、盗汗)、高血压、出血的人不宜用(经验);**宜从小量开始**,骤然大量可致头晕、鼻出血等(经验)。不要用"鹿茸泡酒"大量长期喝

### 1.2 阿胶

- **正名(别名)**: 阿胶(驴皮胶、傅致胶)
- **来源**: 马科动物驴 *Equus asinus* L. 的干燥皮或鲜皮经煎煮、浓缩制成的固体胶
- **分布与生境**: 传统产地山东东阿;驴是家畜,养驴见[家畜养殖-驴、马、骡的饲养要点](../04-动植物培育/06-家畜养殖.md#驴马骡的饲养要点)
- **识别要点**:
  - 药材: **长方形块、方形块或丁状**;棕色至黑褐色,有光泽
  - 质地: **质硬而脆**,断面光亮;**碎片对光照视呈棕色半透明状**
  - 气味: 气微,味微甘
- **伪品(杂皮胶)**: 用猪皮、牛皮、马皮或杂皮熬的胶冒充或掺入,是最常见的造假。经验上: 杂皮胶断面光泽差、有气泡或杂质,**夏天容易发软、粘手**,化开后有明显的腥臭或焦糊味,对光看浑浊不透明。**但这些都不可靠**——药典要靠检测驴源特征多肽(质谱)区分,家里分不出来,**只买有批准文号的正规产品**
- **采收与加工**: 工厂熬制,不能自制成合格的药用阿胶;本书不写熬胶工艺
- **储存**: 密闭,置阴凉干燥处;**怕潮、怕热**,受潮发软发霉,太干燥会碎裂
- **功效**: 补血滋阴,润燥,止血
- **用量**: 3-9 g,**烊化兑服**(用开水或黄酒化开后冲入汤药,不和其他药同煎)(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 质地滋腻,**消化不良、腹胀、大便溏泄、舌苔厚腻**的人不宜用(经验);**贫血要先查原因**——缺铁性贫血补铁、失血要止血,阿胶不能代替检查和治疗,见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md)

### 1.3 龟甲

- **正名(别名)**: 龟甲(龟板、龟壳)
- **来源**: 龟科动物乌龟 *Chinemys reevesii* (Gray) 的背甲及腹甲
- 🛡️ **野生乌龟是国家二级保护野生动物**(2021年名录,"仅限野外种群");药材应来自人工养殖。**不捕捉野生乌龟,不买野生龟**;其他龟类(尤其是金钱龟、鹰嘴龟等)多数也是保护动物,壳不能当龟甲用
- **分布与生境**: 养殖遍及长江流域及以南各地
- **识别要点**:
  - 背甲和腹甲由甲桥相连;**背甲长椭圆形拱状**,长7.5-22 cm,外表面棕褐色或黑褐色,中间有纵棱
  - **腹甲板片状**,近长方椭圆形,长6.4-21 cm;外表面淡黄棕色至棕黑色,盾片12块,每块常有紫褐色放射状纹理;内表面黄白色至灰白色
  - 质坚硬;气微腥,味微咸
- **易混淆品**: 其他龟类的甲(多为保护动物);用**鳖甲冒充或混入**——鳖甲只有背甲、没有角质盾片,两侧肋骨伸出边缘(见下一节)
- **采收与加工**: 养殖龟宰杀后剥取甲,除去残肉,晒干(药典另有沸水烫后去皮肉的加工法,这里不展开)
- **储存**: 置干燥处,防蛀
- **功效**: 滋阴潜阳,益肾强骨,养血补心,固经止崩
- **用量**: 9-24 g,**先煎**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 药性偏寒: 脾胃虚寒、腹泻的人不宜用;孕妇慎用(经验)

### 1.4 鳖甲

- **正名(别名)**: 鳖甲(甲鱼壳、团鱼甲)
- **来源**: 鳖科动物鳖 *Trionyx sinensis* Wiegmann 的背甲
- **分布与生境**: 甲鱼在各地广泛养殖,药材主要来自养殖甲鱼
- **识别要点**:
  - **椭圆形或卵圆形,背面隆起**,长10-15 cm,宽9-14 cm
  - 外表面黑褐色或墨绿色,略有光泽,有细网状皱纹和灰黄色或灰白色斑点,中间有一条纵棱,两侧各有对称的横凹纹8条;外皮脱落后可见锯齿状嵌接缝
  - 内表面类白色,**中部有突起的脊椎骨,颈骨向内卷曲,两侧各有肋骨8条,伸出边缘**
  - 质坚硬;气微腥,味淡
- **易混淆品**: 和龟甲的区别——鳖甲只用背甲、**没有角质盾片、肋骨伸出边缘**;龟甲背腹两甲、有盾片纹
- **采收与加工**: 全年均可;宰杀后取背甲,除去残肉,晒干(药典另有沸水烫后去皮肉的加工法)
- **储存**: 置干燥处,防蛀
- **功效**: 滋阴潜阳,退热除蒸,软坚散结
- **用量**: 9-24 g,**先煎**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒、食少便溏的人不宜用;孕妇慎用(经验)

### 1.5 牡蛎

- **正名(别名)**: 牡蛎(蚝壳、海蛎子壳)
- **来源**: 牡蛎科动物长牡蛎 *Ostrea gigas* Thunberg、大连湾牡蛎 *O. talienwhanensis* Crosse 或近江牡蛎 *O. rivularis* Gould 的贝壳
- **分布与生境**: 沿海潮间带和浅海;现在大量养殖,吃剩的蚝壳就是原料
- **识别要点**:
  - 长牡蛎: **长片状**,背腹缘几乎平行,长10-50 cm;右壳较小,鳞片坚厚,层状或层纹状排列,壳外面平坦或有数个凹陷,淡紫色、灰白色或黄褐色;**内面瓷白色**,壳顶二侧无小齿;左壳凹陷深,鳞片较右壳粗大
  - 大连湾牡蛎: 类三角形,右壳外面淡黄色,有疏松的同心鳞片,鳞片起伏成波浪状
  - 近江牡蛎: 圆形、卵圆形或三角形;右壳外面稍不平,有灰、紫、棕、黄等色,环生同心鳞片
  - 质硬,断面层状,洁白;气微,味微咸
- **易混淆品**: 其他贝壳混入,一般无毒;**外面附着泥沙、海藻、残肉的要洗净**
- **采收与加工**: 全年均可;**去肉,洗净,晒干**。自家吃剩的牡蛎壳刷净晒干即可作原料,煅制见[中药制剂-煅制](../06-制药技术/04-中药制剂.md#煅制)
- **储存**: 置干燥处
- **功效**: 重镇安神,潜阳补阴,软坚散结;煅牡蛎收敛固涩,制酸止痛
- **用量**: 9-30 g,**先煎**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 药性偏寒、收涩,体虚有寒、便秘的人不宜多用(经验)。胃痛反酸长期不好,要查胃溃疡、幽门螺杆菌,不只靠煅牡蛎"制酸"

### 1.6 珍珠

- **正名(别名)**: 珍珠(真珠)
- **来源**: 珍珠贝科动物马氏珍珠贝 *Pteria martensii* (Dunker)、蚌科动物三角帆蚌 *Hyriopsis cumingii* (Lea) 或褶纹冠蚌 *Cristaria plicata* (Leach) 等双壳类动物受刺激形成的珍珠
- **分布与生境**: 海水珍珠产广东、广西、海南;淡水珍珠产浙江、江苏、湖南等地,**几乎都是养殖珍珠**
- **识别要点**:
  - **类球形、长圆形、卵圆形或棒形**,直径1.5-8 mm
  - 表面类白色、浅粉红色、浅黄绿色或浅蓝色,半透明,光滑或微有凹凸,**有特有的彩色光泽**
  - 质坚硬;破碎面显层纹;气微,味淡
- **伪品**: 玻璃珠、塑料珠涂"珍珠漆"冒充: **真珠两颗互相轻轻摩擦有细微的涩感,仿珠光滑打滑**;仿珠的涂层用指甲刮会掉(经验)。**珍珠粉造假更多**: 用贝壳粉、珍珠母粉冒充或掺入,家里分不出;珍珠母是另一味药(贝壳的珍珠层),功效相近但不同
- **采收与加工**: 自动物体内取出,洗净,干燥;药用时**水飞或研成极细粉**(粉末不细的刺激胃肠)
- **储存**: 密闭保存
- **功效**: 安神定惊,明目消翳,解毒生肌,润肤祛斑
- **用量**: 0.1-0.3 g,**多入丸散用**;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 一般不入煎剂;"珍珠粉美白""珍珠粉补钙"的说法夸大——补钙不需要这么贵的东西

### 1.7 石决明

- **正名(别名)**: 石决明(鲍鱼壳、九孔螺、千里光——注意不要和菊科草药千里光混淆)
- **来源**: 鲍科动物杂色鲍 *Haliotis diversicolor* Reeve、皱纹盘鲍 *H. discus hannai* Ino、羊鲍 *H. ovina* Gmelin、澳洲鲍 *H. ruber* (Leach)、耳鲍 *H. asinina* Linnaeus 或白鲍 *H. laevigata* (Donovan) 的贝壳
- **分布与生境**: 沿海岩礁;现多为养殖鲍的壳
- **识别要点**:
  - 杂色鲍: **长卵圆形,内面观略呈耳形**,长7-9 cm;表面暗红色,有多数不规则的螺肋和细密生长线;**从螺旋部顶处开始向右排列有20余个疣状突起,末端6-9个开孔**,孔口与壳面平
  - 皱纹盘鲍: 长椭圆形,长8-12 cm;表面灰棕色,有多数粗糙而不规则的皱纹;末端4-5个开孔,孔口突出壳面
  - **内面光滑,有珍珠样彩色光泽**;质坚硬,不易破碎;气微,味微咸
- **易混淆品**: 其他螺壳没有这一排开孔,容易区分
- **采收与加工**: 夏、秋二季捕捞;**去肉,洗净,干燥**。吃鲍鱼剩下的壳刷净晒干即可
- **储存**: 置干燥处
- **功效**: 平肝潜阳,清肝明目
- **用量**: 6-20 g,**先煎**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 药性偏寒,脾胃虚寒、食少便溏的人慎用(经验)。**头晕、头痛、视物模糊要先量血压、查眼睛**——高血压、青光眼要按病治疗

### 1.8 海螵蛸

- **正名(别名)**: 海螵蛸(乌贼骨、墨鱼骨)
- **来源**: 乌贼科动物无针乌贼 *Sepiella maindroni* de Rochebrune 或金乌贼 *Sepia esculenta* Hoyle 的干燥内壳
- **分布与生境**: 沿海;墨鱼是常见海产,杀墨鱼时取出的"墨鱼骨"就是原料
- **识别要点**:
  - 无针乌贼: **扁长椭圆形,中间厚,边缘薄**,长9-14 cm,宽2.5-3.5 cm;背面有瓷白色脊状隆起,两侧略显微红色;腹面白色,自尾端到中部有细密波状横层纹;**尾部较宽平,无骨针**
  - 金乌贼: 长13-23 cm,背面疣点明显;**尾部有1根骨针**,多已断落
  - **体轻,质松,易折断,断面粉质**,显疏松层纹;气微腥,味微咸
- **易混淆品**: 其他乌贼的内壳,一般无毒
- **采收与加工**: 收集乌贼的骨状内壳,**洗净,干燥**
- **储存**: 置干燥处,防潮
- **功效**: 收敛止血,涩精止带,制酸止痛,收湿敛疮
- **用量**: 5-10 g;外用适量,研末敷患处(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 性收涩,便秘的人不宜多用(经验)。**外用止血只适合小伤口渗血**;伤口大、出血多先按[外伤处理](../01-日常疾病和伤害/02-外伤处理.md)直接压迫止血,不往深伤口里撒药粉

## 二、昆虫、蠕虫及其他

虫类药里有一半是能自己收集的: 蝉蜕在树干上捡,鸡内金在杀鸡时剥,地龙就是蚯蚓。另一半——全蝎、蜈蚣、土鳖虫、水蛭——是药典标注"有毒"或"有小毒"的破血、息风药,**孕妇禁用**,商品主要来自人工养殖和专业收购,本书**不写捕捉和去毒炮制**,只写怎样认、为什么危险。

斑蝥、蟾酥是剧毒的动物药,在国家管制的28种毒性中药之列,见[有毒中药-斑蝥](./09-有毒中药与易混淆有毒植物.md#220-斑蝥)和[有毒中药-蟾酥](./09-有毒中药与易混淆有毒植物.md#221-蟾酥)。

```
虫类药的共同提醒:
- 动物蛋白可引起过敏: 用后出现皮疹、瘙痒、喘憋、面部肿胀,立即停药就医
- 增重造假普遍: 盐、明矾、泥沙、石灰粉,买来先看、先称、先闻
- 易生虫、易霉变: 密封、干燥、低温保存,可与花椒同贮
```

### 2.1 蝉蜕

- **正名(别名)**: 蝉蜕(蝉衣、知了壳、蝉退)
- **来源**: 蝉科昆虫黑蚱 *Cryptotympana pustulata* Fabricius 的若虫羽化时脱落的皮壳
- **分布与生境**: 全国大部分地区都有;夏季若虫夜间从土里爬出,在**树干、灌木枝、墙根**上羽化,留下空壳
- **识别要点**:
  - **略呈椭圆形而弯曲**,长约3.5 cm,宽约2 cm;**表面黄棕色,半透明,有光泽**
  - 头部有丝状触角1对(多已断落),复眼突出;口吻发达,下唇伸长成管状
  - **胸部背面呈十字形裂开**(成虫从这里钻出),裂口向内卷曲;脊背两旁有小翅2对;腹面有足3对,被黄棕色细毛
  - 腹部钝圆,共9节;**体轻,中空,易碎**;气微,味淡
- **伪品**: 壳内**塞泥沙增重**(摇一摇有沙声、掰开有土,经验);混入其他蝉类的蜕壳,一般无毒
- **采收与加工**: 夏、秋二季收集;**除去泥沙,晒干**。这是少数可以安全自己收集的动物药: 在树干上捡拾即可,不需要伤害任何动物;不要在打过农药的树、马路边灰尘重的地方收集
- **储存**: 置干燥处,**防压**(很容易压碎)
- **功效**: 疏散风热,利咽,透疹,明目退翳,解痉
- **用量**: 3-6 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用(传统经验)。**小儿发热、出疹、抽搐要先就医**——可能是麻疹、脑膜炎等,见[常见疾病](../01-日常疾病和伤害/01-常见疾病.md)

### 2.2 僵蚕

- **正名(别名)**: 僵蚕(白僵蚕、天虫)
- **来源**: 蚕蛾科昆虫家蚕 *Bombyx mori* Linnaeus 4-5龄的幼虫感染(或人工接种)白僵菌 *Beauveria bassiana* (Bals.) Vuillant 而致死的干燥体
- **分布与生境**: 养蚕地区(江苏、浙江、四川、广东等)的副产品
- **识别要点**:
  - **略呈圆柱形,多弯曲皱缩**,长2-5 cm,直径0.5-0.7 cm
  - **表面灰黄色,被有白色粉霜状的气生菌丝和分生孢子**;头部较圆,足8对,体节明显,尾部略呈二分歧状
  - 质硬而脆,易折断;**断面平坦,外层白色,中间有亮棕色或亮黑色的丝腺环4个**
  - 气微腥,味微咸
- **伪品**: 用**石灰粉、滑石粉、明矾**裹在病死蚕外面冒充白色菌丝并增重(经验: 粉霜一擦就掉、有石灰味,断面无亮丝腺环);**其他病害(如软化病、腐败)死亡的蚕**发黑发臭,不能用
- **采收与加工**: 多于春、秋季生产,将感染白僵菌病死的蚕干燥。白僵病会在蚕室里传染,**不要为了"做僵蚕"故意让家蚕感染**——会毁掉整批蚕
- **储存**: 置干燥处,**防蛀**
- **功效**: 息风止痉,祛风止痛,化痰散结
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 有报道少数人服用后过敏;**对蚕蛹过敏的人不用**(经验)

### 2.3 地龙

- **正名(别名)**: 地龙(蚯蚓、曲蟮)
- **来源**: 钜蚓科动物参环毛蚓 *Pheretima aspergillum* (E. Perrier)、通俗环毛蚓 *P. vulgaris* Chen、威廉环毛蚓 *P. guillelmi* (Michaelsen) 或栉盲环毛蚓 *P. pectinifera* Michaelsen 的干燥体;前一种习称"广地龙",后三种习称"沪地龙"
- **分布与生境**: 广地龙产广东、广西、福建;沪地龙产上海、江苏、浙江等地;生活在潮湿、肥沃的土壤中
- **识别要点**:
  - 广地龙: **长条状薄片(已剖开)**,弯曲,边缘略卷,长15-20 cm,宽1-2 cm;全体有环节;**背部棕褐色至紫灰色,腹部浅黄棕色**;第14-16环节为生殖带,习称"白颈",较光亮
  - 沪地龙: 长8-15 cm,宽0.5-1.5 cm;背部棕褐色至黄褐色,腹部浅黄棕色
  - 体轻,略呈革质,不易折断;**气腥,味微咸**
- **伪品**: 未剖开、腹内**泥沙多**的(药典对杂质有限量);一般无毒
- **采收与加工**: 广地龙春季至秋季捕捉,沪地龙夏季捕捉;**及时剖开腹部,除去内脏和泥沙,洗净,晒干或低温干燥**。**不要在污染土壤(工厂、矿区、垃圾场、公路旁)挖蚯蚓**——蚯蚓会富集重金属
- **储存**: 置通风干燥处,**防霉,防蛀**
- **功效**: 清热定惊,通络,平喘,利尿
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 药性寒,脾胃虚寒的人慎用;少数人过敏;孕妇慎用(经验)。**高热抽搐、哮喘发作是急症**,先送医

### 2.4 全蝎

- **正名(别名)**: 全蝎(全虫、蝎子)
- **来源**: 钳蝎科动物东亚钳蝎 *Buthus martensii* Karsch 的干燥体
- **分布与生境**: 主产河南、山东、河北等地;**商品多来自人工养殖**,本书不写野外捕捉
- **识别要点**:
  - 头胸部与前腹部呈**扁平长椭圆形**,后腹部呈尾状,皱缩弯曲;完整的体长约6 cm
  - 头胸部绿褐色,前面有1对短小的螯肢和**1对较长大的钳状脚须,形似蟹螯**;背面覆有梯形背甲;腹面有足4对
  - 前腹部由7节组成;**后腹部棕黄色,6节,末节有锐钩状毒刺**,毒刺下方无距
  - 气微腥,**味咸**
- **伪品**: **"盐蝎"加盐过多增重**——表面有明显盐霜、捏之潮软、尝之极咸(经验);腹内塞泥沙;用其他蝎种冒充
- **采收与加工**: 由养殖场和专业收购单位加工(药典规定沸水或沸盐水煮后阴干);活蝎蜇人,**不自行捕捉、不徒手处理**
- **储存**: 置干燥处,**防蛀**;盐蝎易返潮
- **毒性**: 药典标注"**有毒**"。蝎毒主要是神经毒素;用量过大可出现头痛、头昏、血压升高、心慌、烦躁,严重时呼吸困难;也可引起过敏性皮疹(经验)
- **功效**: 息风镇痉,通络止痛,攻毒散结
- **用量**: 3-6 g(《中国药典》2020年版);**只在中医师指导下使用**,不自行加量,不做"油炸蝎子""蝎子酒"大量食用
- **禁忌**: **孕妇禁用**;儿童、体弱、血虚的人慎用(经验)。被活蝎蜇伤的处理见[外伤处理-昆虫叮咬](../01-日常疾病和伤害/02-外伤处理.md#昆虫叮咬)

### 2.5 蜈蚣

- **正名(别名)**: 蜈蚣(百足虫、天龙)
- **来源**: 蜈蚣科动物少棘巨蜈蚣 *Scolopendra subspinipes mutilans* L. Koch 的干燥体
- **分布与生境**: 主产湖北、浙江、江苏、安徽等地;商品来自专业收购和人工养殖,本书不写野外捕捉
- **识别要点**:
  - **扁平长条形**,长9-15 cm,宽0.5-1 cm;由头部和躯干部组成,**全体共22个环节**
  - **头部暗红色或红褐色**,略有光泽,有头板覆盖;前端两侧有触角1对,颚肢1对
  - **躯干部背板棕绿色或墨绿色**,有光泽;腹部淡黄色或棕黄色,皱缩;自第二节起每节两侧有步足1对,**步足黄色或红褐色,弯钩形**;最末一对步足尾状(尾足),易脱落
  - 质脆,断面有裂隙;**气微腥,有特殊刺鼻的臭气**,味辛、微咸
- **伪品**: 用其他种类的蜈蚣冒充;**腹内填塞泥土、面粉增重**;断头、断足拼接(经验)。商品常用竹片撑直,买时看头尾是否完整
- **采收与加工**: 由专业人员捕捉加工(药典规定用竹片插入头尾、绷直、干燥);活蜈蚣咬人很痛,可致局部红肿,少数人过敏
- **储存**: 置干燥处,**防霉,防蛀**
- **毒性**: 药典标注"**有毒**"。过量可出现恶心、呕吐、腹痛、心慌、心率变慢,严重时呼吸困难;**也有引起溶血、过敏性休克和肝损害的报道**
- **功效**: 息风镇痉,通络止痛,攻毒散结
- **用量**: 3-5 g(《中国药典》2020年版);**只在中医师指导下使用**,不做"蜈蚣酒"自饮
- **禁忌**: **孕妇禁用**;儿童、体弱、肝病患者慎用(经验)

### 2.6 土鳖虫

- **正名(别名)**: 土鳖虫(䗪虫、地鳖虫、土元)
- **来源**: 鳖蠊科昆虫地鳖 *Eupolyphaga sinensis* Walker 或冀地鳖 *Steleophaga plancyi* (Boleny) 的雌虫干燥体
- **分布与生境**: 野生的生活在老房子墙根、灶台下、粮仓等阴暗潮湿的松土里;**商品绝大多数是人工养殖**
- **识别要点**:
  - 地鳖: **扁平卵形**,长1.3-3 cm,宽1.2-2.4 cm;前端较窄,后端较宽;**背部紫褐色,有光泽,无翅**
  - 前胸背板较发达,盖住头部;腹背板9节,**呈覆瓦状排列**;腹面红棕色,有足3对
  - 冀地鳖: 长2.2-3.7 cm,宽1.4-2.5 cm;背部黑棕色,通常在边缘带有淡黄褐色斑块及黑色小点
  - 质松脆,易碎;**气腥臭**,味微咸
- **伪品**: **金边土鳖**(赤边水䗪,边缘有金黄色边)等其他种冒充;掺泥沙、盐增重(经验);雄虫有翅,不作药用
- **采收与加工**: 养殖场捕捉后烫死,晒干或烘干
- **储存**: 置通风干燥处,**防蛀**(易生虫、易走油)
- **毒性**: 药典标注"**有小毒**"
- **功效**: 破血逐瘀,续筋接骨
- **用量**: 3-10 g(《中国药典》2020年版,只在中医师指导下使用)
- **禁忌**: **孕妇禁用**;月经过多、有出血倾向、正在服抗凝药或抗血小板药的人不用(经验)。**骨折要先固定、就医**,见[外伤处理](../01-日常疾病和伤害/02-外伤处理.md),不能只靠"接骨药"

### 2.7 水蛭

- **正名(别名)**: 水蛭(蚂蟥)
- **来源**: 水蛭科动物蚂蟥 *Whitmania pigra* Whitman、水蛭 *Hirudo nipponica* Whitman 或柳叶蚂蟥 *Whitmania acranulata* Whitman 的干燥全体
- **分布与生境**: 稻田、池塘、沟渠;**商品多来自人工养殖**
- **识别要点**:
  - 蚂蟥: **扁平纺锤形,有多数环节**,长4-10 cm,宽0.5-2 cm;背部黑褐色或黑棕色,稍隆起,**用水浸后可见黑色斑点排成5条纵纹**;腹面平坦,棕黄色
  - **两端各有1个吸盘**,前吸盘不显著,后吸盘较大
  - 水蛭: 扁长圆柱形,体多弯曲扭转,长2-5 cm,宽0.2-0.3 cm
  - 柳叶蚂蟥: 狭长而扁,长5-12 cm,宽0.1-0.5 cm
  - 质脆,易折断,**断面胶质状**;气微腥
- **伪品**: **用明矾、盐、硫酸镁、泥浆、胶等灌注或浸泡增重**,是水蛭最常见的造假(经验: 断面有白色结晶或泥沙、尝之涩咸、手感异常沉重);药典对水蛭有灰分和"抗凝血酶活性"的要求,家里查不了
- **采收与加工**: 由养殖场和专业收购单位加工(药典规定用沸水烫死,晒干或低温干燥)
- **储存**: 置干燥处,**防蛀**
- **毒性**: 药典标注"**有小毒**"。水蛭素有很强的**抗凝血作用**,过量可致出血(牙龈、皮下、消化道出血)
- **功效**: 破血通经,逐瘀消癥
- **用量**: 1-3 g(《中国药典》2020年版,只在中医师指导下使用)
- **禁忌**: **孕妇禁用**;月经期、有出血性疾病、近期手术或外伤的人不用;**正在服华法林、阿司匹林、氯吡格雷等抗凝或抗血小板药的人不能同用**(出血风险叠加,见[总论-与西药同用](./00-总论.md#75-与西药同用))。野外被活蚂蟥叮咬的处理见[马蜂、蜱虫与危险动物-旱蚂蟥](../03-野外生存/10-马蜂蜱虫与危险动物.md#旱蚂蟥)

### 2.8 蜂蜜

- **正名(别名)**: 蜂蜜(蜜、白蜜、石蜜)
- **来源**: 蜜蜂科昆虫中华蜜蜂 *Apis cerana* Fabricius 或意大利蜂 *Apis mellifera* Linnaeus 所酿的蜜
- **分布与生境**: 全国各地养蜂;中华蜜蜂(中蜂)和意大利蜂都可以家养
- **识别要点**:
  - **半透明、带光泽、浓稠的液体**,白色至淡黄色或橘黄色至黄褐色
  - **放久或遇冷渐有白色颗粒状结晶析出**——结晶是正常现象,不是掺糖的证据
  - 气芳香,味极甜;不同蜜源(槐花、荆条、枣花、油菜)颜色和香气不同
- **伪品**: **掺糖浆(果葡糖浆、大米糖浆)**是最常见的造假。民间的"拉丝""滴纸""点火"等方法都不可靠,只有实验室能检测;买**来源清楚的蜂农或有标准的产品**
- **⚠️ 有毒蜂蜜**: 蜜蜂采了有毒植物的花蜜,酿出的蜜可以使人中毒。已知的有毒蜜源包括**雷公藤、昆明山海棠、钩吻(断肠草)、博落回、闹羊花(羊踯躅)等杜鹃花属植物、藜芦、乌头**等。
  - 风险最高的是**山区野生蜂巢、来源不明的"土蜂蜜"、开花季节附近有大片有毒植物的蜂场**
  - 中毒表现: 食后数十分钟到数小时出现口舌麻木、头晕、恶心呕吐、腹痛腹泻、心慌,严重者血压下降、心律失常、休克,甚至死亡(雷公藤蜜可致肾衰竭)
  - **味道发苦、发涩、发麻的蜂蜜不吃**;吃后出现上述症状立即就医,带上剩余的蜂蜜。这些有毒植物的识别见[有毒中药与易混淆有毒植物](./09-有毒中药与易混淆有毒植物.md)
- **⚠️ 一岁以下婴儿禁止吃蜂蜜**: 蜂蜜可能含肉毒杆菌芽孢,婴儿肠道菌群尚未建立,芽孢可在肠内繁殖产毒,引起**婴儿肉毒中毒**(便秘、吃奶无力、哭声微弱、全身松软、呼吸困难)。煮沸不能可靠地杀死芽孢。见[新生儿最初几天-喂养](../01-日常疾病和伤害/11-紧急分娩与新生儿护理.md#喂养)和[肉毒中毒](../07-日常生活技能/01-食物加工与保存.md#肉毒中毒)
- **采收与加工**: 春至秋季由养蜂人从蜂箱摇取,**滤过**;不要为了取蜜去捅野生蜂巢——除了蜇伤危险,野生蜂巢的蜜源无法控制
- **储存**: **密封**,置阴凉处;蜂蜜吸湿,开口久放会吸水发酵变酸、冒泡,发酵的不吃;不用金属容器长期存放
- **功效**: 补中,润燥,止痛,解毒;外用生肌敛疮
- **用量**: 15-30 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 糖尿病人要算进糖的摄入量,不当"降糖食品";湿阻中满、腹泻的人不宜多吃(经验)

### 2.9 蜂房

- **正名(别名)**: 蜂房(露蜂房、马蜂窝)
- **来源**: 胡蜂科昆虫果马蜂 *Polistes olivaceous* (DeGeer)、日本长脚胡蜂 *P. japonicus* Saussure 或异腹胡蜂 *Parapolybia varia* Fabricius 的巢
- **分布与生境**: 全国各地;马蜂窝挂在屋檐下、树枝上、灌木丛中
- **识别要点**:
  - **圆盘状或不规则的扁块状**,有的似莲房状,大小不一;表面灰白色或灰褐色
  - **腹面有多数整齐的六角形房孔**,孔径3-4 mm或6-8 mm;**背面有1个或数个黑色短柄**(挂在树枝上的地方)
  - 体轻,**质韧,略有弹性**;气微,味辛淡
  - 药典规定: **质酥脆或坚硬的不可供药用**
- **易混淆品**: 蜜蜂的蜂巢(蜂蜡做的,能燃烧、有蜡香),不是蜂房
- **⚠️ 采收**: 药典规定秋、冬二季采收,晒干,或略蒸,除去死蜂死蛹,晒干。**胡蜂(马蜂)蜇伤可以致命**: 被群蜂攻击可因过敏性休克或毒素引起溶血、急性肾衰竭死亡。只能在**深冬、蜂群已经离巢、确认巢内没有活蜂**时收取废弃的蜂巢;**不要去捅有蜂的巢**。被蜇后的处理见[马蜂、蜱虫与危险动物-马蜂(胡蜂)](../03-野外生存/10-马蜂蜱虫与危险动物.md#马蜂胡蜂)
- **储存**: 置通风干燥处,**防压,防蛀**
- **功效**: 攻毒杀虫,祛风止痛
- **用量**: 3-5 g;外用适量,研末油调敷患处,或煎水漱口,或洗患处(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 气血虚弱的人慎用;对蜂毒过敏的人不用(经验)

### 2.10 鸡内金

- **正名(别名)**: 鸡内金(鸡肫皮、鸡黄皮)
- **来源**: 雉科动物家鸡 *Gallus gallus domesticus* Brisson 的干燥沙囊内壁
- **分布与生境**: 家家养鸡都能取得,养鸡见[家禽养殖-鸡的养殖](../04-动植物培育/05-家禽养殖.md#鸡的养殖)
- **识别要点**:
  - **不规则卷片**,厚约2 mm
  - **表面黄色、黄绿色或黄褐色,薄而半透明,有明显的条状皱纹**
  - 质脆,易碎;断面角质样,有光泽;气微腥,味微苦
- **伪品**: **鸭内金**冒充——颜色紫黑色或黑绿色,较厚,皱纹少(经验);鸭内金也作药用,但不是药典的鸡内金
- **采收与加工**: **杀鸡后,取出鸡肫(沙囊),立即剥下内壁**,洗净,干燥。要趁新鲜剥,放久了不好剥;剥时不要用水泡太久,以免有效成分流失(经验)。只用健康鸡,病死鸡不用
- **储存**: 置干燥处,**防蛀**
- **功效**: 健胃消食,涩精止遗,通淋化石
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 药性平和;研末吞服效果较好(经验)。**小儿长期厌食、消瘦、腹痛要查原因**(寄生虫、营养不良等),不只靠消食药;"化石"不能代替结石的检查和治疗

## 三、保护动物药材: 禁令与替代

这一节**只写法律和替代品**。本书不写这些动物药的识别、获取、加工和用法——不是因为它们"没用",而是因为**任何获取都意味着猎杀濒危动物或参与非法交易**,而且现在都有合法的替代品或人工品。法律总览见[总论-野生动物保护法](./00-总论.md#83-野生动物保护法)。

### 3.1 法律总览

```
1. 《中华人民共和国野生动物保护法》(2022年修订):
   禁止猎捕、杀害国家重点保护野生动物;
   禁止出售、购买、利用国家重点保护野生动物及其制品(法律另有规定的除外);
   禁止为食用非法购买国家重点保护野生动物及其制品
2. 刑法: 危害珍贵、濒危野生动物的(猎捕、杀害、收购、运输、出售),
   情节严重的可判处有期徒刑
3. 国务院《关于禁止犀牛角和虎骨贸易的通知》(1993年):
   禁止犀牛角和虎骨的一切贸易活动;取消犀牛角和虎骨的药用标准,
   今后不得再用犀牛角和虎骨制药
4. 犀牛、虎、穿山甲、玳瑁等同时受《濒危野生动植物种国际贸易公约》(CITES)管制,
   国际贸易同样禁止
5. 少数药材(麝香、熊胆粉、羚羊角)仍有合法来源,
   但只限于经批准的人工养殖或库存,用于指定的中成药,个人不能买卖
```

| 药材 | 来源动物 | 保护级别 | 现状 | 合法替代 |
|------|---------|---------|------|---------|
| 穿山甲 | 穿山甲属 | 国家一级(2020年升级) | 药典2020年版不再收载 | 由中医师改用其他药物 |
| 犀角 | 犀牛 | CITES附录I | 1993年起禁止贸易和药用 | 水牛角(药典收载) |
| 虎骨 | 虎 | 国家一级 | 1993年起禁止贸易和药用 | 人工虎骨粉等 |
| 天然麝香 | 林麝、马麝、原麝 | 国家一级 | 限养殖活体取香,用于指定中成药 | 人工麝香 |
| 熊胆 | 黑熊、棕熊 | 国家二级 | 限经批准的养殖来源 | 熊去氧胆酸(西药) |
| 羚羊角 | 赛加羚羊 | 国家一级 | 限库存,用于指定中成药 | 由中医师改用其他药物 |
| 玳瑁 | 玳瑁(海龟) | 国家一级 | 禁止交易和使用 | 无需替代 |

保护级别以2021年《国家重点保护野生动物名录》原文为准。

### 3.2 穿山甲

- 🚫 **法律**: 2020年6月,穿山甲属所有种由国家二级调整为**国家一级保护野生动物**;**2020年版《中国药典》不再收载穿山甲**,也不再收载含穿山甲的部分中成药
- 穿山甲是全世界非法贸易最严重的哺乳动物之一;市面上的"穿山甲片""山甲珠"**都是违法来源**,买卖就是犯罪
- **替代**: 过去穿山甲用于"通经下乳""消肿排脓",现在中医师会改用其他药物(如王不留行、路路通、皂角刺等,**由医师根据病情决定**)。**产后缺乳**首先要保证母亲营养、频繁哺乳和正确含接,乳房红肿热痛、发热可能是乳腺炎,要就医

### 3.3 犀角

- 🚫 **法律**: 1993年国务院通知**禁止犀牛角一切贸易**,取消药用标准;犀牛在国际上受CITES附录I保护
- **替代**: **水牛角**,牛科动物水牛的角,《中国药典》收载,功效清热凉血、解毒、定惊,用量大、须先煎;另有水牛角浓缩粉。原来含犀角的古方,现在都以水牛角代替,**由中医师决定用法**
- 市面上的"犀角杯""犀角片"要么是违法品,要么是用牛角、树脂做的假货——两种都不买

### 3.4 虎骨

- 🚫 **法律**: 1993年国务院通知**禁止虎骨一切贸易**,取消药用标准,不得再用虎骨制药;虎是国家一级保护野生动物
- **替代**: 已有经批准的**人工虎骨粉**制成的中成药;中医治疗风湿骨痛也有许多其他药物。**"虎骨酒"都是违法品或假货**,不买、不喝
- **关节、骨头长期疼痛要查原因**: 骨关节炎、类风湿、痛风、骨质疏松、肿瘤骨转移的治疗完全不同

### 3.5 麝香

- 🚫 **法律**: 林麝、马麝、原麝等麝类都是**国家一级保护野生动物**;**猎麝取香是违法的**。天然麝香目前只来自经批准的人工养殖场(活体取香),只用于国家指定的少数中成药,个人不能买卖
- 《中国药典》2020年版仍收载麝香,但**市售"天然麝香"绝大多数是假货或违法品**
- **替代**: **人工麝香**,20世纪90年代起已批准用于中成药,现在大部分含麝香的中成药使用人工麝香
- 提醒: 麝香有很强的活血作用,**孕妇禁用**;含麝香或人工麝香的中成药(包括外贴的膏药),孕妇都要先问医生

### 3.6 熊胆

- 🚫 **法律**: 黑熊、棕熊是**国家二级保护野生动物**(马来熊为一级);**猎熊取胆是违法的**。现在的熊胆粉只来自经批准的养熊场,个人不能买卖野生熊胆
- 市售"野生熊胆"多为猪胆、牛胆、羊胆冒充,或违法品
- **替代**: 熊胆的主要成分之一**熊去氧胆酸**早已能人工合成,是治疗某些胆结石和胆汁淤积性肝病的**西药**(需医生处方)。黄疸、右上腹痛、发热要就医,不要找"熊胆偏方"

### 3.7 羚羊角

- 🚫 **法律**: 赛加羚羊是**国家一级保护野生动物**,在我国野外已经绝迹;国际贸易受CITES管制。《中国药典》2020年版仍收载羚羊角,但来源只限于国家库存和合法进口,**只用于指定的中成药**
- 市售"羚羊角"多为山羊角、黄羊角等冒充;藏羚羊、黄羊、鹅喉羚等也都是保护动物,**任何羚羊的角都不买**
- **替代**: 中医有用山羊角等代替的做法,作用较弱,**由中医师决定**。高热抽搐是急症,先送医

### 3.8 玳瑁

- 🚫 **法律**: 玳瑁和所有海龟一样是**国家一级保护野生动物**,受CITES附录I保护;**玳瑁甲片、玳瑁饰品的收购、出售、运输都是违法的**
- 玳瑁在现代中医中已基本不用,无需替代。旅游地出售的"玳瑁手镯""玳瑁梳子"不买——要么违法,要么是塑料仿制品

## 四、矿物药

矿物药是天然矿石或矿物加工品。认矿物主要看**颜色、条痕(在没上釉的白瓷片背面划出的粉末颜色)、光泽、硬度(指甲能否划动)、比重(掂分量)、磁性和气味**,见[总论-简单的水试与火试](./00-总论.md#33-简单的水试与火试)。

```
矿物药的共同提醒:
- 只用药店的合格饮片: 天然矿石常伴生砷、铅、汞、氟等有害杂质,
  自己捡的石头成分不明,不内服
- 本书不写矿物的煅烧、提纯、精制方法
- 质重的矿物药入汤剂要先煎,多数不宜久服(难消化、伤胃)
- 外观相似的白色粉末和结晶(芒硝、硝石、亚硝酸盐、硼砂、白矾、食盐)
  一定要贴标签分开放,来路不明的不入口
```

### 4.1 石膏

- **正名(别名)**: 石膏(生石膏、细石、白虎)
- **来源**: 硫酸盐类矿物石膏族石膏,主含含水硫酸钙(CaSO₄·2H₂O)
- **分布与生境**: 产湖北应城、安徽、河南、山东等地,沉积岩中的矿层
- **识别要点**:
  - **纤维状的集合体**,呈长块状、板块状或不规则块状
  - **白色、灰白色或淡黄色**,有的半透明
  - 体重,**质软(指甲能划出痕迹)**;**纵断面有绢丝样光泽**
  - 气微,味淡
- **易混淆品**:
  - **方解石**(碳酸钙): 菱形解理,较硬,指甲划不动,滴醋或稀盐酸冒气泡;石膏不冒泡
  - **硬石膏**(无水硫酸钙): 较硬,无纤维状绢丝光泽
  - **建筑用熟石膏粉、模型石膏**: 已经煅烧过,常加有添加剂,不能代替药用生石膏或煅石膏;石膏在建筑上的用法见[石灰与建筑材料-石膏](../07-日常生活技能/16-石灰与建筑材料.md#石膏)
- **采收与加工**: 采挖后除去杂石及泥沙
- **储存**: 置干燥处
- **功效**: 生石膏清热泻火,除烦止渴;煅石膏外用收湿,生肌,敛疮,止血
- **用量**: 生石膏15-60 g,**先煎**;煅石膏外用适量,研末撒敷患处(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 大寒之药: **脾胃虚寒、食少便溏、没有实热**的人不宜用(经验)。高热不退要先就医查原因,见[常见疾病](../01-日常疾病和伤害/01-常见疾病.md)

### 4.2 滑石

- **正名(别名)**: 滑石(硬滑石、画石)
- **来源**: 硅酸盐类矿物滑石族滑石,主含含水硅酸镁[Mg₃(Si₄O₁₀)(OH)₂]
- **分布与生境**: 产山东、江西、辽宁、广西等地
- **识别要点**:
  - 多为块状集合体,呈不规则的块状
  - **白色、黄白色或淡蓝灰色,有蜡样光泽**
  - **质软,细腻,手摸有滑润感**;**无吸湿性,置水中不崩散**
  - 气微,味淡
- **易混淆品**: 高岭土、白陶土类的"软滑石"(吸湿、粘舌、入水崩散)不是药典的滑石;**部分滑石矿伴生石棉**,工业滑石粉不能药用
- **采收与加工**: 采挖后除去泥沙和杂石;药用的滑石粉要求极细,由药厂加工
- **储存**: 置干燥处
- **功效**: 利尿通淋,清热解暑;外用祛湿敛疮
- **用量**: 10-20 g,**先煎**(滑石粉入汤剂要包煎);外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 性寒滑利: **孕妇慎用**,脾虚、遗精、尿多的人不宜用(经验)。**不要吸入滑石粉**,不往婴儿口鼻附近大量扑粉;不用于女性外阴长期扑粉(经验提醒)。尿频尿痛、血尿要就医查尿路感染和结石

### 4.3 芒硝

- **正名(别名)**: 芒硝(朴硝精制品、皮硝);芒硝风化失水后的白色粉末是**玄明粉**(另一味药)
- **来源**: 硫酸盐类矿物芒硝族芒硝,经加工精制而成的结晶体,主含含水硫酸钠(Na₂SO₄·10H₂O)
- **分布与生境**: 产于盐湖、盐碱地、含硫酸钠的卤水中
- **识别要点**:
  - **棱柱状、长方形或不规则块状及粒状**
  - **无色透明或类白色半透明**
  - 质脆,易碎;断面呈**玻璃样光泽**
  - 气微,**味咸**(带苦)
  - **放在干燥空气中会风化**,表面变成白色粉末
- **⚠️ 易混淆品**:
  - **亚硝酸钠(工业盐)**: 白色或微黄色结晶,外观像盐和芒硝,**误食0.2-0.5 g即可中毒,3 g左右可致死**(嘴唇、指甲发紫,头晕、呼吸困难)
  - **硝石**(硝酸钾): 无色或白色结晶,投入火中剧烈燃烧、爆响,与芒硝完全不同
  - **食盐、白矾、硼砂**: 都是白色结晶
  - **来路不明、没有标签的白色结晶一律不入口**;家里存放的芒硝贴好标签
- **采收与加工**: 由药厂精制;本书不写精制方法
- **储存**: **密闭,在30°C以下保存**,防风化(风化失水后药量就不准了)
- **功效**: 泻下通便,润燥软坚,清火消肿
- **用量**: 6-12 g,**一般不入煎剂**,待汤剂煎得后溶入汤液中服用;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**;**不宜与硫黄、三棱同用**(药典);体弱、老人、脾胃虚寒的人慎用(经验)。**腹痛原因不明时不要用泻药**——阑尾炎、肠梗阻用泻药可致穿孔,见[急性症状](../01-日常疾病和伤害/05-急性症状.md)

### 4.4 龙骨

- **正名(别名)**: 龙骨(白龙骨、花龙骨);古代哺乳动物的牙齿化石另称"龙齿"
- **来源**: 古代哺乳动物如三趾马、犀类、鹿类、牛类、象类等的骨骼化石,或象类门齿的化石
- ⚠️ **药典**: **《中国药典》(2020年版)一部未收载龙骨**,质量标准见部分省级地方标准,各地不一
- 🛡️ **法律**: 古脊椎动物化石受《古生物化石保护条例》保护,**有重要科学价值的化石不准私自采挖、买卖**;发现化石层应报告当地主管部门。历史上大量珍贵的古生物、甲骨文都曾被当成"龙骨"磨成药粉
- **识别要点**:
  - 骨骼状或已破碎成不规则块状,大小不一
  - 表面**白色、灰白色或浅棕色**,多较平滑,有的有纹理与裂隙,或有棕色条纹和斑点(花龙骨)
  - 质硬,**断面不平坦,关节处有多数蜂窝状小孔**
  - **吸湿性强,舔之吸舌**(传统经验鉴别);气微,味淡
- **伪品**: 用**现代动物骨头煅烧、做旧**冒充(不吸舌或吸舌弱,有焦臭味,经验);用石灰岩块冒充
- **储存**: 置干燥处
- **功效(传统)**: 镇惊安神,平肝潜阳;煅龙骨收敛固涩
- **用量**: 药典未收载;传统常用15-30 g,先煎(经验,以中医师为准)
- **禁忌**: 性收涩,有湿热、实邪的人不宜用(经验)

### 4.5 磁石

- **正名(别名)**: 磁石(灵磁石、吸铁石)
- **来源**: 氧化物类矿物尖晶石族磁铁矿,主含四氧化三铁(Fe₃O₄)
- **分布与生境**: 产河北、山东、辽宁、江苏等地的铁矿中
- **识别要点**:
  - 块状集合体,不规则块状或略带方形,**多有棱角**
  - **灰黑色或棕褐色,条痕黑色,有金属光泽**
  - **体重,质坚硬**;断面不整齐
  - **有磁性,能吸铁**(放久了磁性会减弱);有土腥气,味淡
- **易混淆品**: 赭石(条痕樱红色、无磁性);其他黑色铁矿石(磁性弱或无)
- **采收与加工**: 采挖后除去杂石
- **储存**: 置干燥处
- **功效**: 镇惊安神,平肝潜阳,聪耳明目,纳气平喘
- **用量**: 9-30 g,**先煎**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 质重难消化,**不宜多服久服**;脾胃虚弱的人慎用(经验)。失眠、耳鸣、头晕长期不好要查原因

### 4.6 赭石

- **正名(别名)**: 赭石(代赭石、钉头赭石、土朱)
- **来源**: 氧化物类矿物刚玉族赤铁矿,主含三氧化二铁(Fe₂O₃)
- **分布与生境**: 产山西、河北、河南、山东等地
- **识别要点**:
  - 鲕状、豆状、肾状集合体,多呈不规则的扁平块状
  - **暗棕红色或灰黑色,条痕樱红色或红棕色**,有的有金属光泽
  - **一面多有圆形的突起,习称"钉头";另一面与突起相对应处有同样大小的凹窝**
  - 体重,质硬;砸碎后**断面显层叠状**;气微,味淡
- **易混淆品**: **朱砂**(鲜红、条痕红色、更重、含汞——剧毒)、**铅丹**(橙红色粉末、很重、含铅)——红色的矿物药不要凭颜色认,见[第五节](#五有毒矿物药只列名)
- **采收与加工**: 采挖后除去杂石
- **储存**: 置干燥处
- **功效**: 平肝潜阳,重镇降逆,凉血止血
- **用量**: 9-30 g,**先煎**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**(药典);部分产地的赭石含砷等杂质,**不宜长期服用**(经验)。吐血、呕血是急症,要立即就医

### 4.7 炉甘石

- **正名(别名)**: 炉甘石(甘石、卢甘石)
- **来源**: 碳酸盐类矿物方解石族菱锌矿,主含碳酸锌(ZnCO₃)
- **分布与生境**: 产广西、四川、云南、湖南等地的锌矿
- **识别要点**:
  - 块状集合体,呈不规则的块状
  - **灰白色或淡红色,表面粉性,无光泽,凹凸不平,多孔,似蜂窝状**
  - **体轻,易碎**;气微,味微涩
- **易混淆品**: 其他多孔的白色石块;**滴醋或稀盐酸会冒气泡**(碳酸盐)
- **采收与加工**: 采挖后洗净,晒干,除去杂石;药用的是水飞或煅后水飞的极细粉
- **储存**: 置干燥处
- **功效**: 解毒明目退翳,收湿止痒敛疮
- **用量**: **只外用**,适量(《中国药典》2020年版);不内服
- **禁忌**: 不用于大面积破损、流水的创面;**不入眼**(眼病用药由医生处理)。常用的**炉甘石洗剂**是西药外用止痒药,蚊虫叮咬、湿疹瘙痒时可用,见[外伤处理-昆虫叮咬](../01-日常疾病和伤害/02-外伤处理.md#昆虫叮咬)

### 4.8 白矾

- **正名(别名)**: 白矾(明矾、矾石);煅制失去结晶水后称**枯矾**
- **来源**: 硫酸盐类矿物明矾石经加工提炼制成,主含含水硫酸铝钾[KAl(SO₄)₂·12H₂O]
- **分布与生境**: 产安徽、浙江、山西、湖北等地
- **识别要点**:
  - **不规则块状或粒状**
  - **无色或淡黄白色,透明或半透明**;表面略平滑或凹凸不平,有细密纵棱,**有玻璃样光泽**
  - 质硬而脆
  - 气微,**味酸、微甘而极涩**(舔一下舌头发紧)
- **易混淆品**: 芒硝(味咸)、硼砂(味甜后略咸、碱性)、食盐;都要贴标签分开放
- **采收与加工**: 由工厂加工;本书不写提炼方法。明矾净水的用法见[水源工程与供水-多级处理](../07-日常生活技能/10-水源工程与供水.md#多级处理)
- **储存**: 置干燥处
- **功效**: 外用解毒杀虫,燥湿止痒;内服止血止泻,祛除风痰;枯矾收湿敛疮,止血化腐
- **用量**: 0.6-1.5 g;外用适量,研末敷或化水洗患处(《中国药典》2020年版,在中医师指导下使用)
- **⚠️ 禁忌**: **含铝**,铝在体内蓄积可能损害神经系统和骨骼,**不宜久服、多服**;肾功能不全的人、儿童、孕妇不内服(经验)。大量内服可引起口腔、咽喉灼痛,呕吐、腹泻,甚至虚脱。**用明矾做的油条、粉丝等食品也不要长期大量吃**

### 4.9 硼砂

- **正名(别名)**: 硼砂(月石、蓬砂)
- **来源**: 硼砂矿经精制而成的结晶,主含四硼酸钠(Na₂B₄O₇·10H₂O)
- ⚠️ **药典**: 据编者所知,**《中国药典》(2020年版)一部没有单列硼砂这味药材**,但收载了含硼砂的外用成方(如冰硼散);质量标准见部颁或地方标准(以药典原文为准)
- **识别要点**:
  - 不规则块状,大小不一;**无色透明或白色半透明**,有玻璃样光泽;久置空气中易风化成白色粉末
  - 体轻,质脆,易碎;气无,味甜而后略咸,水溶液呈碱性
- **⚠️ 毒性**: 硼砂**有毒**: 内服过量引起恶心呕吐、腹泻、皮肤红斑脱屑,严重时肾损害、抽搐、休克;**儿童对硼更敏感**;长期少量摄入在体内蓄积,影响生殖和发育
- **⚠️ 食品禁用**: 硼砂是**国家明令禁止加入食品的非食用物质**——过去有人加进面条、粽子、凉粉、肉丸里"增筋""防腐",是违法的,也是慢性中毒的来源
- **用途(传统)**: 外用清热解毒、消肿防腐,多用于口腔、咽喉的外用散剂;**本书不写内服用量**
- **禁忌**: 不内服;不用于大面积破损皮肤;**不给婴幼儿用**(包括涂抹口腔);孕妇不用。口腔溃疡反复不好、超过两周不愈,要就医排除其他疾病

✓ 长期吃过来路不明的"秘方""药丸"的,告诉医生,查血铅、尿汞、尿砷
```

此外,**硫黄**(药典标注"有毒",主要外用)、**胆矾**(硫酸铜,内服可致严重中毒)等也是有毒的矿物药,同样不自行内服。

## 六、易混淆汇总与自我检查

### 6.1 易混淆与风险汇总

| 正品 | 易混淆品/伪品 | 怎样区分 | 混错的后果 |
|------|-------------|---------|----------|
| 阿胶 | 杂皮胶(猪皮、牛皮、马皮) | 对光透明度、夏季是否发软、气味(都不可靠) | 无效;只买正规产品 |
| 鹿茸片 | 骨胶面粉压制片、染色鹿角片 | 泡水是否散开,有无蜂窝状小孔 | 无效、受骗 |
| 龟甲 | 鳖甲、其他龟类的甲 | 龟甲背腹两甲、有盾片;鳖甲只有背甲、肋骨伸出边缘 | 用错药;涉及保护动物 |
| 全蝎、水蛭、蜈蚣 | 加盐、明矾、泥沙增重的 | 盐霜、断面结晶、尝之极咸或涩、手感过重 | 剂量不准;杂质有害 |
| 僵蚕 | 石灰粉裹的病死蚕 | 粉霜一擦就掉,断面无亮丝腺环 | 无效;石灰刺激 |
| 鸡内金 | 鸭内金 | 鸭内金紫黑色、较厚、皱纹少 | 用错药 |
| 蜂蜜 | 糖浆掺假;有毒蜜源的蜂蜜 | 家里分不出;发苦发麻的不吃 | ☠️ 有毒蜜可致死 |
| 石膏 | 方解石、建筑熟石膏 | 石膏指甲能划、有绢丝光泽、遇酸不冒泡 | 用错药 |
| 芒硝 | 亚硝酸钠、硝石、硼砂 | **来路不明的白色结晶不入口** | ☠️ 亚硝酸盐中毒 |
| 赭石 | 朱砂、铅丹 | 赭石条痕樱红、有"钉头";朱砂更红更重 | ☠️ 汞、铅中毒 |
| 龙骨 | 煅烧做旧的现代骨头 | 吸舌程度、焦臭味(经验) | 无效 |
| 犀角、虎骨、麝香、熊胆、羚羊角 | 违法品或牛角、猪胆等假货 | **不需要区分——一律不买** | 违法;受骗 |

### 6.2 自我检查

- [ ] 我知道穿山甲、虎骨、犀角、天然麝香、熊胆、羚羊角、玳瑁不能买卖和使用,也知道它们的合法替代品
- [ ] 鹿茸、龟甲来自人工养殖,有正规来源
- [ ] 全蝎、蜈蚣、土鳖虫、水蛭只在中医师指导下用;家里有孕妇的不用
- [ ] 服抗凝药、抗血小板药的人不用水蛭、土鳖虫等破血药
- [ ] 不给1岁以下婴儿吃蜂蜜;不吃发苦发麻、来源不明的野蜂蜜
- [ ] 收蜂房只收深冬无蜂的废巢
- [ ] 白色结晶(芒硝、白矾、硼砂、食盐)都贴了标签,来路不明的不入口
- [ ] 白矾、硼砂不长期内服;硼砂不加入食品
- [ ] 朱砂、雄黄等含汞砷铅的矿物药不内服、不加热
- [ ] 我知道药典用量和禁忌,孕妇、儿童、肝肾病人先问医生

## 📝 本章要点

```
□ 保护动物药一律不买不用: 穿山甲、虎骨、犀角、天然麝香、熊胆、羚羊角、玳瑁;
  替代品: 水牛角代犀角,人工麝香代麝香,人工虎骨粉代虎骨
□ 鹿茸、龟甲只用人工养殖来源;阿胶杂皮胶多,只买正规产品
□ 贝壳甲类(牡蛎、石决明、龟甲、鳖甲、磁石、赭石、石膏)入汤剂先煎
□ 全蝎、蜈蚣有毒,土鳖虫、水蛭有小毒,孕妇禁用,只在中医师指导下用;
  水蛭不与抗凝药同用
□ 1岁以下婴儿禁止吃蜂蜜;有毒蜜源的蜂蜜可致死
□ 蝉蜕、鸡内金、牡蛎壳、墨鱼骨可以自己收集;蜂房只收深冬无蜂的废巢
□ 芒硝孕妇慎用,不与硫黄、三棱同用;来路不明的白色结晶不入口
□ 白矾含铝、硼砂有毒,都不长期内服;硼砂禁止加入食品
□ 龙骨药典未收载,化石受法律保护
□ 朱砂、雄黄、轻粉、红粉、铅丹、砒石: 不内服、不加热
```
