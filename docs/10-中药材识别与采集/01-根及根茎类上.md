# 根及根茎类(上)

> **挖根之前先认全株——地下部分最难辨认,商陆冒充人参、菊三七冒充三七,都是从"只看根"开始的**

本章收录30味最常用的根及根茎类药材,按功效大致分为补益、补血活血、清热、解表祛风、化湿息风化痰养阴五组。每味药写怎样认、在哪里找、何时采、怎样加工储存、药典用量和禁忌。识别、采收、干燥、储存的通用方法见[总论](./00-总论.md),本章不再重复;其余根及根茎类药材(知母、麦冬、大黄、贝母等)见[根及根茎类(下)](02-根及根茎类下.md)。

## ⚠️ 先读这几条

```
1. 只看根认不准药: 根类药材一定要在植株带花或带果时认准地上部分,
   再挖地下部分;只拿到一段根的,按"来路不明"处理
2. 两组最危险的混淆:
   - 商陆根冒充人参(路边、荒地挖到的"野人参"几乎都不是人参)
   - 菊三七(土三七)冒充三七(长期服用可致严重肝损伤)
   见第09章《有毒中药与易混淆有毒植物》
3. 何首乌可致肝损伤: 不长期服、不大量服,不用生首乌"乌发""保健",
   肝病患者不用
4. 本章很多品种的野生资源受国家保护:
   人参、三七(野生)、甘草、黄连、天麻、羌活、川党参、珊瑚菜(北沙参)等,
   以及黄芩、防风等列入《国家重点保护野生药材物种名录》的品种。
   市售几乎都是栽培品,不要采挖野生
5. 用量是《中国药典》(2020年版)成人每日的常规用量(饮片,水煎),
   只用来提醒"不要超量";用不用、用多少,在中医师指导下决定
6. 人参、党参、丹参、白芍、赤芍、南沙参、北沙参、西洋参不宜与藜芦同用;
   甘草不宜与甘遂、京大戟、红大戟、芫花、海藻同用
7. 孕妇、儿童、肝肾病人、长期服降压药、降糖药、抗凝药的人,
   用任何一味之前先问医生
```

## 一、补益类

这一组是最常用的补气药。它们本身毒性很低,但"补药"最容易被长期、大量自服,而且最贵的几味(人参、西洋参)也最常被冒充。

### 1.1 人参

- **正名(别名)**: 人参(园参、林下山参、棒槌)
- **来源**: 五加科植物人参 *Panax ginseng* C. A. Mey. 的干燥根和根茎。栽培的习称"园参";播种在山林中自然生长的习称"林下山参"
- **分布与生境**: 野生于东北长白山、小兴安岭一带海拔数百 m至千余米的针阔混交林下,阴湿、腐殖质厚的地方;现在药材几乎全部来自吉林、辽宁、黑龙江的人工栽培
- **识别要点**:
  - 植株: 多年生草本,高约30-60 cm;**掌状复叶轮生于茎顶**(年限越长复叶越多,通常3-6片),每片复叶多为5片小叶;顶生伞形花序,夏季结一簇**鲜红色**扁球形小浆果
  - 药材: 主根纺锤形或圆柱形,表面灰黄色,上部有断续的粗横纹,下部有2-3条支根;顶端有**"芦头"**(根茎),上面有碗状茎痕(芦碗);须根上有细小疣状突起("珍珠点")
  - 断面: 淡黄白色,有粉性,**一圈棕黄色的形成层环**,皮部散有黄棕色小点和放射状裂隙;香气特异,味微苦、甘
- **易混淆品**: **商陆根**最危险——路边、荒地、村旁挖到的分叉粗根常被当作"野山参"泡酒炖汤。商陆是高大草本、单叶、紫黑色葡萄状果穗,根的横切面有多层同心环纹,没有芦头。对比见[商陆 vs 人参](./09-有毒中药与易混淆有毒植物.md#44-商陆-vs-人参)。另有用桔梗、华山参(有毒)、栌兰(土人参)等加工冒充的
- **采收与加工**: 栽培园参一般生长5-6年后于秋季采挖,洗净后晒干或烘干为"生晒参";蒸制后干燥为"红参"(另有药典条目)
- **储存**: 含糖和淀粉多,易受潮发霉、虫蛀;密封,放阴凉干燥处;量少时可放冰箱冷藏
- **功效**: 大补元气,复脉固脱,补脾益肺,生津养血,安神益智
- **用量**: 3-9 g,另煎兑服;也可研粉吞服,一次2 g,一日2次(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与藜芦、五灵脂同用;发热、实证、阴虚火旺者不宜;高血压、失眠、正服降糖药或华法林等抗凝药的人用前先问医生;儿童不自行进补
- 🛡️ **保护提醒**: 野生人参是《国家重点保护野生药材物种名录》的二级物种,人参属野生种也列入2021年《国家重点保护野生植物名录》(级别以名录原文为准)。**野生人参不能采挖、买卖**;正规药店卖的都是园参或林下山参,够用

### 1.2 西洋参

- **正名(别名)**: 西洋参(花旗参、洋参)
- **来源**: 五加科植物西洋参 *Panax quinquefolium* L. 的干燥根。药典注明均系栽培品
- **分布与生境**: 原产北美洲(加拿大、美国东部)落叶林下;我国吉林、山东、北京、陕西等地引种栽培
- **识别要点**:
  - 植株: 与人参非常相似,掌状复叶轮生茎顶,结红色浆果;只靠植株不易区分,但野外不会遇到野生西洋参
  - 药材: 纺锤形、圆柱形或圆锥形,长3-12 cm;表面浅黄褐色或黄白色,有**细密的横向环纹**和线状皮孔样突起
  - 断面: 质坚实,断面平坦,浅黄白色,略显粉性,有棕黄色形成层环,皮部有黄棕色小点;气微而特异,味微苦、甘
- **易混淆品**: 常用较小的园参(生晒参)加工冒充。经验上,西洋参质地更重实、横纹更细密、断面更平坦;人参常有芦头较长、支根较多。冒充品不伤人,但价格悬殊;拿不准时到正规药店购买
- **采收与加工**: 栽培3-4年后,秋季采挖,洗净,晒干或低温干燥
- **储存**: 同人参,易虫蛀、受潮;密封避光
- **功效**: 补气养阴,清热生津
- **用量**: 3-6 g,另煎兑服(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与藜芦同用;性偏凉,脾胃虚寒、腹泻的人不宜;与降糖药、抗凝药同用前问医生
- 🛡️ **保护提醒**: 野生西洋参只分布在北美,列入《濒危野生动植物种国际贸易公约》(CITES)附录Ⅱ;国内只有栽培品

### 1.3 党参

- **正名(别名)**: 党参(潞党参、纹党、台党)
- **来源**: 桔梗科植物党参 *Codonopsis pilosula* (Franch.) Nannf.、素花党参 *C. pilosula* var. *modesta* (Nannf.) L. T. Shen 或川党参 *C. tangshen* Oliv. 的干燥根
- **分布与生境**: 山西、甘肃、陕西、四川、东北等地的山地林缘、灌丛、沟边;药材主要来自栽培
- **识别要点**:
  - 植株: 多年生**缠绕草质藤本**,全株折断有**白色乳汁**,揉碎有特殊气味;叶卵形,对生或互生;花单生,**钟状,黄绿色带紫色斑点**;根肉质
  - 药材: 长圆柱形,稍弯,长10-35 cm;表面灰黄色至灰棕色,根头部有许多疣状突起的茎痕和芽,习称**"狮子盘头"**;根头下有致密的环状横纹
  - 断面: 稍平坦,有裂隙或放射状纹理,皮部淡棕黄色,木部淡黄色;有特殊香气,味微甜
- **易混淆品**: 同科的羊乳(四叶参)、管花党参等的根曾被混用。野外缠绕藤本很多,一定要见到钟状花、乳汁和"狮子盘头"再确认
- **采收与加工**: 栽培2-3年后秋季采挖,洗净晒干;传统做法在晒到半干时反复搓揉几次,使皮肉紧贴、不空泡,再晒干
- **储存**: 含糖多,**易受潮发霉、虫蛀、走油(变软发黏)**;干透后密封,放阴凉处,勤检查
- **功效**: 健脾益肺,养血生津
- **用量**: 9-30 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与藜芦同用;实证、热证不宜单用
- 🛡️ **保护提醒**: 野生川党参已列入2021年《国家重点保护野生植物名录》(以名录原文为准);不采挖野生党参,种植方法见[药用植物](../04-动植物培育/04-药用植物.md)

### 1.4 黄芪

- **正名(别名)**: 黄芪(黄耆、绵芪、北芪)
- **来源**: 豆科植物蒙古黄芪 *Astragalus membranaceus* (Fisch.) Bge. var. *mongholicus* (Bge.) Hsiao 或膜荚黄芪 *A. membranaceus* (Fisch.) Bge. 的干燥根
- **分布与生境**: 山西、内蒙古、甘肃、黑龙江、河北等地向阳的山坡、草地、林缘;商品主要为栽培或仿野生栽培
- **识别要点**:
  - 植株: 多年生草本,高50-100 cm;**奇数羽状复叶**,小叶多对、椭圆形;总状花序,蝶形花,**淡黄色**;荚果膜质、**膨胀如小气囊**
  - 药材: 长圆柱形,有的有分枝,长30-90 cm;表面淡棕黄色或淡棕褐色,有不整齐的纵皱纹
  - 断面: 质硬而韧,不易折断,**断面纤维性强(折断后像棉絮)**,皮部黄白色,木部淡黄色,有放射状纹理和裂隙(习称"菊花心");气微,味微甜,**嚼之有豆腥味**
- **易混淆品**: 历史上曾有锦鸡儿根、紫苜蓿根、圆叶锦葵根等冒充,断面和味道不同(没有豆腥味和"菊花心")。黄芪属和近缘的棘豆属有一些"疯草"类植物,牲畜误食会中毒——**不要随便挖不认识的野生黄芪属植物代用**
- **采收与加工**: 春、秋二季采挖,除去须根和根头,晒干;栽培的一般生长2-3年以上
- **储存**: 易受潮发霉、虫蛀;捆扎后放通风干燥处
- **功效**: 补气升阳,固表止汗,利水消肿,生津养血,行滞通痹,托毒排脓,敛疮生肌
- **用量**: 9-30 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 外感发热、热毒疮疡初起、阴虚火旺者不宜;自身免疫病、器官移植后服免疫抑制剂的人用前问医生

### 1.5 甘草

- **正名(别名)**: 甘草(国老、甜草、甜根子)
- **来源**: 豆科植物甘草 *Glycyrrhiza uralensis* Fisch.、胀果甘草 *G. inflata* Bat. 或光果甘草 *G. glabra* L. 的干燥根和根茎
- **分布与生境**: 内蒙古、新疆、甘肃、宁夏等西北、华北的干旱草原、沙地、河岸;耐旱、固沙
- **识别要点**:
  - 植株: 多年生草本,高30-120 cm,全株有短毛和腺点,手摸有黏感;奇数羽状复叶;蝶形花**紫色或淡紫色**,密集成总状花序;**荚果弯曲成镰刀状或环状,密生刺毛**
  - 药材: 根圆柱形,长25-100 cm;外皮红棕色或灰棕色,有明显纵皱纹和皮孔;根茎表面有芽痕,断面中央有髓
  - 断面: 黄白色,粉性,形成层环明显,有放射状纹理;**味甜而特殊**,是最容易靠味道确认的药材之一
- **易混淆品**: 一般不易混淆;注意市售"甘草片"有切制的甘草饮片,也有含甘草流浸膏的西药止咳片,两者不同
- **采收与加工**: 春、秋二季采挖,除去须根,晒干;栽培的一般生长3-4年
- **储存**: 易虫蛀、受潮;放干燥处
- **功效**: 补脾益气,清热解毒,祛痰止咳,缓急止痛,调和诸药
- **用量**: 2-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与海藻、京大戟、红大戟、甘遂、芫花同用。**长期或大量服用可引起水肿、血压升高、低血钾**(严重时肌无力、心律失常);高血压、心脏病、肾病、低血钾的人慎用;与利尿药、地高辛、激素同用前问医生。孕妇不宜长期大量服用
- 🛡️ **保护提醒**: 甘草是《国家重点保护野生药材物种名录》的二级物种,野生甘草(甘草、胀果甘草、光果甘草)也列入2021年《国家重点保护野生植物名录》;国务院2000年专门发文制止滥挖甘草(滥挖造成草原沙化)。**不挖野生甘草**,市售多为栽培品

### 1.6 白术

- **正名(别名)**: 白术(於术、冬术)
- **来源**: 菊科植物白术 *Atractylodes macrocephala* Koidz. 的干燥根茎
- **分布与生境**: 主产浙江、安徽、湖南、湖北等地,商品基本为栽培;野生的(浙江於潜一带的"於术")已极少
- **识别要点**:
  - 植株: 多年生草本,高30-80 cm;叶有长柄,常3裂,边缘有刺状细齿;**头状花序单生枝顶,紫红色,外有一圈羽状深裂的叶状苞片**
  - 药材: **不规则的肥厚团块**,长3-13 cm;表面灰黄色或灰棕色,有瘤状突起和断续的纵皱,顶端有残留茎基和芽痕
  - 断面: 质坚硬,断面黄白色至淡棕色,**散有棕黄色点状油室**;烘干的断面角质样;**气清香,味甘、微辛,嚼之略带黏性**
- **易混淆品**: 同属的苍术(见[5.1](#51-苍术))。白术块大、肥厚,断面油点较少,香气清淡;苍术呈结节状长条,断面"朱砂点"多,香气浓烈
- **采收与加工**: 冬季下部叶枯黄、上部叶变脆时采挖,除去泥沙,烘干或晒干,再除去须根
- **储存**: **易走油、虫蛀**;放阴凉干燥处,避免高温
- **功效**: 健脾益气,燥湿利水,止汗,安胎
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚燥渴、津液亏少者慎用;"安胎"也要由医生判断,孕期出血、腹痛先就医

### 1.7 山药

- **正名(别名)**: 山药(淮山、怀山药、薯蓣)
- **来源**: 薯蓣科植物薯蓣 *Dioscorea opposita* Thunb. 的干燥根茎
- **分布与生境**: 全国大部分地区有野生,山坡、林缘、灌丛;河南焦作(古怀庆府,"怀山药")等地大量栽培,也是常见蔬菜
- **识别要点**:
  - 植株: **缠绕草质藤本**,茎常带紫红色;叶**对生或三叶轮生**(下部偶互生),三角状卵形至戟形,基部心形;**叶腋常生珠芽("山药豆""零余子")**
  - 药材: "毛山药"略呈圆柱形,弯曲稍扁,表面黄白色或淡黄色,有纵沟和须根痕;"光山药"呈匀整的圆柱形,表面光滑白色;"山药片"为趁鲜切的类圆形或不规则厚片
  - 断面: 白色,**粉性强**;气微,味淡、微酸,**嚼之发黏**
- **易混淆品**: 同属的**黄独**(块茎即"黄药子",有肝毒性)——叶**互生**、宽心形,珠芽大而呈球形,地下块茎近球形、断面黄色,与山药的长柱形白色根茎不同。还有用木薯片、参薯片冒充山药片的。挖野生薯蓣属植物必须认清叶序和根茎形状
- **采收与加工**: 冬季茎叶枯萎后采挖,切去根头,洗净,去外皮和须根后干燥(毛山药);或趁鲜切厚片干燥(山药片)。鲜山药的黏液可引起手部瘙痒,削皮时戴手套
- **储存**: 富含淀粉,**极易虫蛀、发霉**;干透后密封
- **功效**: 补脾养胃,生津益肺,补肾涩精
- **用量**: 15-30 g(《中国药典》2020年版,在中医师指导下使用);作为食物按日常食用量吃是安全的
- **禁忌**: 湿盛中满、积滞者不宜多用;对山药过敏者避免

## 二、补血活血类

这一组多与月经、出血、瘀血有关。**活血药会增加出血风险**: 孕妇、月经过多、有出血倾向、正在服用华法林、阿司匹林、氯吡格雷等抗凝或抗血小板药的人,一律先问医生。本组的何首乌和三七(及其冒充品菊三七)涉及肝损伤,要特别注意。

### 2.1 当归

- **正名(别名)**: 当归(秦归、岷归、西当归)
- **来源**: 伞形科植物当归 *Angelica sinensis* (Oliv.) Diels 的干燥根
- **分布与生境**: 主产甘肃岷县、渭源一带,以及云南、四川、湖北等地海拔约2000-3000 m 的高寒阴湿山区;商品几乎全部为栽培
- **识别要点**:
  - 植株: 多年生草本,高40-100 cm,茎带紫色;叶为二至三回羽状复叶,叶柄基部膨大成鞘;**复伞形花序,花白色**;全株有浓郁的特殊香气
  - 药材: 略呈圆柱形,下部有3-5条或更多支根,长15-25 cm;根头(归头)有环纹和紫色或黄绿色的叶鞘残基,主根(归身)凹凸不平,支根(归尾)上粗下细
  - 断面: 质柔韧,断面黄白色或淡黄棕色,皮部厚,有许多棕色点状分泌腔,形成层环黄棕色;**香气浓郁,味甘、辛、微苦**。药典规定: 柴性大、干枯无油或断面呈绿褐色的不可供药用
- **易混淆品**: 曾有欧当归(引种的西方香料植物)、东当归、独活等混充,香气和味道不同。**当归属于伞形科,野外不要挖不认识的伞形科植物**——毒芹等剧毒植物外形相似,见[毒芹 vs 水芹、野胡萝卜](./09-有毒中药与易混淆有毒植物.md#43-毒芹-vs-水芹野胡萝卜)
- **采收与加工**: 秋末采挖,除去须根和泥沙,待水分稍蒸发后捆成小把,上棚用烟火慢慢熏干
- **储存**: **易走油、虫蛀、发霉**;密封,放阴凉干燥处,夏季要勤查
- **功效**: 补血活血,调经止痛,润肠通便
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 腹泻、湿盛中满者不宜;月经过多、有出血倾向者慎用;孕妇在医生指导下使用;与华法林等抗凝药同用可能增加出血风险

### 2.2 白芍

- **正名(别名)**: 白芍(杭白芍、亳白芍、川白芍)
- **来源**: 毛茛科植物芍药 *Paeonia lactiflora* Pall. 的干燥根
- **分布与生境**: 野生于东北、华北、西北的山坡草地、林缘;药材主要为浙江、安徽亳州、四川等地的栽培品(观赏芍药也是同一种)
- **识别要点**:
  - 植株: 多年生草本,高40-70 cm;叶为二回三出复叶,小叶狭卵形;**花大而美,单生茎顶,白色、粉红色或红色**,与牡丹相似,但芍药是草本、冬季地上部分枯死
  - 药材: 圆柱形,平直或稍弯,**两端平截**,长5-18 cm,直径1-2.5 cm;表面**类白色或淡棕红色,光洁**(已去皮),偶有残存的棕褐色外皮
  - 断面: 质坚实,断面较平坦,类白色或微带棕红色,形成层环明显,射线放射状;气微,味微苦、酸
- **易混淆品**: 与赤芍来自同一种植物,区别在于加工: 白芍**去皮、水煮**,表面光洁类白色;赤芍不去皮、不煮,表面棕褐色、粗糙
- **采收与加工**: 夏、秋二季采挖栽培3-4年的根,洗净,除去头尾和细根,置沸水中煮后去外皮(或去皮后再煮),晒干
- **储存**: 防潮、防虫蛀;放干燥处
- **功效**: 养血调经,敛阴止汗,柔肝止痛,平抑肝阳
- **用量**: 6-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与藜芦同用;虚寒腹痛、腹泻者慎用

### 2.3 赤芍

- **正名(别名)**: 赤芍(赤芍药、草芍药)
- **来源**: 毛茛科植物芍药 *Paeonia lactiflora* Pall. 或川赤芍 *Paeonia veitchii* Lynch 的干燥根
- **分布与生境**: 芍药野生于内蒙古、东北、河北等地的山坡草地;川赤芍分布于四川、甘肃、青海、西藏等地的山坡林下、灌丛。赤芍商品以野生为主
- **识别要点**:
  - 植株: 芍药见[2.2](#22-白芍);川赤芍叶的小叶羽状深裂,花紫红色或粉红色,常数朵生于茎顶和叶腋
  - 药材: 圆柱形,稍弯,长5-40 cm;表面**棕褐色,粗糙**,有纵沟、皱纹和横长皮孔样突起,外皮有的易脱落
  - 断面: 质硬而脆,易折断,断面**粉白色或粉红色**,皮部窄,木部放射状纹理明显;气微香,味微苦、酸涩。经验上以外皮易脱落、断面粉性足("糟皮粉渣")者为佳
- **易混淆品**: 毛茛科有不少有毒植物(乌头、毛茛等),**不认识的毛茛科植物的根一律不挖**,见[有毒中药-乌头类](./09-有毒中药与易混淆有毒植物.md#21-川乌草乌附子乌头类)
- **采收与加工**: 春、秋二季采挖,除去根茎、须根和泥沙,晒干(不去皮、不水煮)
- **储存**: 防潮、防虫蛀
- **功效**: 清热凉血,散瘀止痛
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与藜芦同用;血寒经闭者不宜;孕妇、月经过多及有出血倾向者在医生指导下使用
- 🛡️ **保护提醒**: 赤芍商品多来自野生,内蒙古等产区野生资源已明显减少;不连片挖光,采挖遵守当地规定

### 2.4 川芎

- **正名(别名)**: 川芎(芎䓖、抚芎)
- **来源**: 伞形科植物川芎 *Ligusticum chuanxiong* Hort. 的干燥根茎
- **分布与生境**: 只有栽培,没有野生;主产四川都江堰、彭州一带,用茎节("苓子")繁殖
- **识别要点**:
  - 植株: 多年生草本,高40-60 cm;茎丛生,**茎节膨大成盘状**;叶为二至三回羽状复叶;复伞形花序,花白色;全株有浓香
  - 药材: **不规则的结节状拳形团块**,直径2-7 cm;表面灰褐色或褐色,粗糙皱缩,有许多平行隆起的轮节,顶端有凹陷的类圆形茎痕
  - 断面: 质坚实,断面黄白色或灰黄色,散有黄棕色油室,**形成层呈波状环纹**;**香气浓郁**,味苦、辛,稍有麻舌感,微回甜
- **易混淆品**: 同属的藁本、抚芎(茶芎)等有时混用,形态和香气相近,由正规渠道购买即可。川芎不能野外采集,野外见到的类似伞形科植物不要当川芎挖
- **采收与加工**: 夏季当茎上的节盘明显突出、略带紫色时采挖,除去泥沙,晒后烘干,再去须根
- **储存**: 含挥发油,**易走油、虫蛀**,香气会散失;密封,放阴凉处
- **功效**: 活血行气,祛风止痛
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺、月经过多、有出血倾向者慎用;孕妇慎用,须由医生决定;头痛反复发作或突然剧烈头痛应先就医查明原因,不要只靠川芎止痛

### 2.5 地黄

- **正名(别名)**: 地黄(怀地黄);按加工分为鲜地黄、生地黄(生地)、熟地黄(熟地)
- **来源**: 玄参科植物地黄 *Rehmannia glutinosa* Libosch. 的新鲜或干燥块根。熟地黄是生地黄经酒炖或蒸制后的炮制品(药典另立条目)
- **分布与生境**: 野生于华北、西北、华东的山坡、路旁、荒地、田埂、墙根,北方很常见;药材主要为河南温县、武陟一带(古怀庆府)的栽培品
- **识别要点**:
  - 植株: 多年生矮小草本,高10-30 cm,**全株密生灰白色长柔毛和腺毛,手摸发黏**;叶多基生成莲座状,倒卵形,边缘有齿,叶面皱;**花冠筒状、略呈唇形,外面紫红色,里面黄色带紫纹**(北方儿童叫它"蜜罐罐",吸花蜜)
  - 鲜地黄: 纺锤形或条状,外皮薄,浅红黄色;断面皮部淡黄白色,可见橘红色油点
  - 生地黄: 不规则团块或长圆形,表面**棕黑色或棕灰色,极皱缩**;体重,质较软而韧,断面**棕黑色或乌黑色,有光泽,有黏性**;气微,味微甜
  - 熟地黄: 不规则块片,**乌黑发亮,黏性大**,质柔软带韧性,味甜
- **易混淆品**: 一般不易混淆;注意"生地"指干燥的生地黄,不是新鲜的鲜地黄,两者用量不同
- **采收与加工**: 秋季采挖,除去芦头、须根和泥沙,鲜用(鲜地黄);或缓缓烘焙至约八成干(生地黄)。熟地黄的蒸制属于炮制,见[中药制剂](../06-制药技术/04-中药制剂.md)
- **储存**: 鲜地黄埋在沙土中保存;生地黄、熟地黄含糖多,**易受潮发霉、发黏**,密封放阴凉干燥处
- **功效**: 鲜地黄清热生津、凉血止血;生地黄清热凉血、养阴生津;熟地黄补血滋阴、益精填髓
- **用量**: 鲜地黄12-30 g;生地黄10-15 g;熟地黄9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾虚湿滞、腹满便溏者不宜;熟地黄滋腻,影响消化,食少腹胀者慎用

### 2.6 何首乌

- **正名(别名)**: 何首乌(首乌、赤首乌、夜交藤根);炮制后为制何首乌
- **来源**: 蓼科植物何首乌 *Polygonum multiflorum* Thunb. 的干燥块根。茎藤为"首乌藤"(见第06章),制何首乌为炮制品(药典另立条目)
- **分布与生境**: 华东、华中、华南、西南广布,山坡、灌丛、石缝、沟边、村旁都很常见;也有栽培
- **识别要点**:
  - 植株: 多年生**缠绕藤本**,茎红褐色,中空;叶互生,**卵状心形**,全缘;叶柄基部有**膜质托叶鞘**(蓼科特征);秋季开白色小花,成大型圆锥花序;瘦果有三棱
  - 药材: 团块状或不规则纺锤形,长6-15 cm;表面**红棕色或红褐色**,皱缩不平,有浅沟和横长皮孔样突起
  - 断面: 体重,质坚实,断面浅黄棕色或浅红棕色,粉性,**皮部有4-11个类圆形的异型维管束环列,形成"云锦花纹"**;气微,味微苦而甘涩
- **易混淆品**: 市场上"人形何首乌"多是用模具种植或用其他块根雕刻的,不要迷信、不要高价购买;"白首乌"是萝藦科植物(牛皮消等)的块根,是另一种药材,不能互相代替
- **采收与加工**: 秋、冬二季叶枯萎时采挖,削去两端,洗净,个大的切成块,干燥
- **储存**: 防潮、防虫蛀;放干燥处
- **功效**: 生首乌解毒、消痈、截疟、润肠通便;制首乌补肝肾、益精血、乌须发、强筋骨、化浊降脂
- **用量**: 何首乌3-6 g;制何首乌6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**:

```
⚠️ 何首乌(包括制何首乌)可引起肝损伤:
- 国家药品监管部门曾多次就口服何首乌及其制剂的肝损伤风险发布提醒
- 生首乌风险更高;有人用生首乌泡水、打粉、泡酒"乌发""养生",正是常见的出事方式
- 不长期服用、不超量服用,不与其他可能伤肝的药物同用
- 已有肝病、肝功能异常的人不用;老人、儿童、孕妇、哺乳期妇女不自行服用
- 服用期间出现乏力、食欲差、恶心、厌油、尿色变深(浓茶色)、
  皮肤或眼白发黄 → 立即停用,就医查肝功能
- 生首乌有通便作用,大便溏泄者不宜
```

### 2.7 丹参

- **正名(别名)**: 丹参(紫丹参、红根、血参)
- **来源**: 唇形科植物丹参 *Salvia miltiorrhiza* Bge. 的干燥根和根茎
- **分布与生境**: 全国大部分地区有分布,山坡、林下草丛、溪谷旁;四川、山东、河南、陕西等地大量栽培
- **识别要点**:
  - 植株: 多年生草本,高30-80 cm;**茎四棱**,全株密生柔毛;**奇数羽状复叶,小叶3-7片**,卵形,边缘有齿;轮伞花序组成总状,**唇形花蓝紫色**
  - 药材: 根茎短粗,下生数条长圆柱形的根,长10-20 cm,直径0.3-1 cm;表面**棕红色或暗棕红色**,粗糙,有纵皱纹;老根外皮疏松,紫棕色,常呈鳞片状剥落。栽培品较粗壮,外皮紧贴
  - 断面: 质硬而脆,断面疏松有裂隙,皮部棕红色,木部灰黄色或紫褐色,有黄白色导管束放射状排列;气微,味微苦涩
- **易混淆品**: 同属的甘西鼠尾草、南丹参等曾作地方习用品;都是根红色的唇形科植物,毒性不大,但不能代替正品。辨认时抓住"茎四棱、羽状复叶、蓝紫色唇形花、根外皮红"
- **采收与加工**: 春、秋二季采挖,除去泥沙,干燥
- **储存**: 防潮、防霉;放干燥处
- **功效**: 活血祛瘀,通经止痛,清心除烦,凉血消痈
- **用量**: 10-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与藜芦同用;孕妇、月经过多、有出血倾向者慎用;**与华法林、阿司匹林等抗凝、抗血小板药同用可能增加出血风险**;冠心病、胸痛患者不能用丹参代替医院治疗,胸痛发作立即拨打120

### 2.8 三七

- **正名(别名)**: 三七(田七、参三七、金不换)
- **来源**: 五加科植物三七 *Panax notoginseng* (Burk.) F. H. Chen 的干燥根和根茎。支根习称"筋条",根茎习称"剪口"
- **分布与生境**: 主产云南文山、广西百色一带,在荫棚下人工栽培;野生三七已极难见到
- **识别要点**:
  - 植株: 多年生草本,高30-60 cm;**掌状复叶3-4片轮生于茎顶**,每片有小叶5-7片,边缘有细锯齿;顶生伞形花序,花小,淡黄绿色;**浆果鲜红色**——与人参是同属近亲,样子很像
  - 药材: 主根类圆锥形或圆柱形,长1-6 cm,直径1-4 cm;表面灰褐色或灰黄色,有断续的纵皱纹和支根痕,顶端周围有瘤状突起(俗称"猴头""狮子头")
  - 断面: **体重,质坚实**,敲打不易碎;断面**灰绿色、黄绿色或灰白色**,木部略呈放射状;气微,**味苦回甜**
- **易混淆品**:

```
⚠️ 菊三七(土三七)最危险:
- 菊科植物菊三七,很多人家院子、花盆里种的"三七""土三七""血三七"就是它
- 叶互生、羽状深裂、常带紫色;开黄色或橙黄色小绒球状的花
  (真三七是掌状复叶轮生、结红色浆果)
- 含吡咯里西啶类生物碱,长期或大量泡酒、炖汤、打粉服用,
  可在数周至数月后引起肝窦阻塞综合征: 腹胀、腹水、黄疸,严重时肝衰竭
- 不要用自家种的"三七"泡酒、炖汤、打粉吃
此外,景天科的"景天三七"(费菜)也叫"土三七",与菊三七不是同一种;
市场上还有用莪术、姜黄等块根加工冒充三七的——三七粉最好在正规药店买
```

详细对比见[菊三七(土三七) vs 三七](./09-有毒中药与易混淆有毒植物.md#45-菊三七土三七-vs-三七)。

- **采收与加工**: 栽培3年以上,秋季开花前采挖,洗净,分开主根、支根和根茎,干燥
- **储存**: 质坚,较耐储存;防潮、防虫蛀。三七粉密封保存,不要长期敞口
- **功效**: 散瘀止血,消肿定痛
- **用量**: 3-9 g;研粉吞服,一次1-3 g;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**;与华法林等抗凝、抗血小板药同用可能影响凝血;大出血(呕血、便血、外伤大出血)要立即就医,不能只靠三七止血
- 🛡️ **保护提醒**: 人参属野生种已列入2021年《国家重点保护野生植物名录》(级别以名录原文为准);市售三七都是栽培品

## 三、清热类

这一组都很苦,性寒。共同的提醒是: **脾胃虚寒、平时怕冷、容易腹泻的人不宜多用,也不宜长期服用**;发热、咽痛、感染不是靠"清热药"能解决的,高热不退、呼吸困难、精神差要就医。

### 3.1 黄连

- **正名(别名)**: 黄连(味连、雅连、云连、川连)
- **来源**: 毛茛科植物黄连 *Coptis chinensis* Franch.、三角叶黄连 *C. deltoidea* C. Y. Cheng et Hsiao 或云连 *C. teeta* Wall. 的干燥根茎,分别习称"味连""雅连""云连"
- **分布与生境**: 重庆石柱、湖北利川、四川峨眉、云南西北部等地海拔约1000-2000 m 以上的山地林下阴湿处;商品主要为在遮荫棚或林下栽培的味连
- **识别要点**:
  - 植株: 多年生常绿小草本,高约20-30 cm,无地上茎;**叶基生,三全裂**,中央裂片有柄,再羽状深裂,边缘有锐锯齿,叶面光亮;花小,黄绿色;根茎和须根**断面鲜黄色**
  - 药材(味连): **多分枝聚成簇,常弯曲,形如鸡爪**;单枝长3-6 cm,表面灰黄色或黄褐色,有结节状隆起和须根残基,有的节间光滑如茎秆,习称"过桥"
  - 断面: 质硬,断面不整齐,**皮部橙红色或暗棕色,木部鲜黄色或橙黄色**,呈放射状;**味极苦**,久久不散
- **易混淆品**: 同科有毒植物多,野外不要凭"根是黄的"就挖;有的地方把唐松草属、十大功劳等根茎黄色、味苦的植物叫"土黄连",它们不是黄连
- **采收与加工**: 栽培4-6年后,秋季采挖,除去须根和泥沙,干燥,撞去残留须根
- **储存**: 较耐储存;防潮
- **功效**: 清热燥湿,泻火解毒
- **用量**: 2-5 g;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 大苦大寒,脾胃虚寒者忌用;不长期服用;**新生儿、葡萄糖-6-磷酸脱氢酶缺乏症(蚕豆病)患儿不用**黄连及含黄连、小檗碱的药物(有引起溶血的报道);孕妇在医生指导下使用
- 🛡️ **保护提醒**: 黄连是《国家重点保护野生药材物种名录》的二级物种,黄连属所有野生种都已列入2021年《国家重点保护野生植物名录》。**不挖野生黄连**,市售为栽培品

### 3.2 黄芩

- **正名(别名)**: 黄芩(条芩、枯芩、山茶根)
- **来源**: 唇形科植物黄芩 *Scutellaria baicalensis* Georgi 的干燥根
- **分布与生境**: 河北、山西、内蒙古、山东、东北等地向阳干燥的山坡、草地、路边;现在商品以栽培为主
- **识别要点**:
  - 植株: 多年生草本,高30-60 cm;**茎四棱**,基部多分枝;**叶对生,披针形,全缘,几乎无柄**,背面有黑色腺点;总状花序偏向一侧,**唇形花蓝紫色**
  - 药材: 圆锥形,扭曲,长8-25 cm,直径1-3 cm;表面棕黄色或深黄色,上部粗糙有扭曲的纵皱,下部有顺纹;栽培品较细长,多有分枝,外皮紧贴
  - 断面: 质硬而脆,易折断,**断面黄色,中心红棕色**;老根中心常枯朽或中空,呈暗棕色或棕黑色(习称"枯芩");气微,味苦
- **易混淆品**: 同属的滇黄芩、粘毛黄芩、甘肃黄芩等在产地作地方习用品;毒性小,但不能当正品。经验上,黄芩**遇冷水易变绿**,说明有效成分分解,药材不要长时间泡冷水
- **采收与加工**: 春、秋二季采挖(栽培2-3年),除去须根和泥沙,晒后撞去粗皮,再晒干。避免淋雨受潮
- **储存**: 防潮;受潮后易变绿、发霉
- **功效**: 清热燥湿,泻火解毒,止血,安胎
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒、食少便溏者不宜;"安胎"须由医生判断,孕期出血、腹痛先就医;偶有肝损伤和过敏的报道,用药期间不适即停
- 🛡️ **保护提醒**: 黄芩是《国家重点保护野生药材物种名录》的三级物种,采挖野生的须按规定持证;优先用栽培品,种植方法见[药用植物](../04-动植物培育/04-药用植物.md)

### 3.3 板蓝根

- **正名(别名)**: 板蓝根(北板蓝根、菘蓝根、靛青根)
- **来源**: 十字花科植物菘蓝 *Isatis indigotica* Fort. 的干燥根。同一植物的叶是大青叶(见第05章)
- **分布与生境**: 原产我国北方,河北安国、安徽、江苏、甘肃、黑龙江等地大量栽培;偶见逸为野生
- **识别要点**:
  - 植株: 二年生草本,高40-100 cm,全株**粉绿色、光滑**;基生叶莲座状,长圆形;**茎生叶基部箭形、抱茎**;**十字形小黄花**,成圆锥状花序;短角果扁平,长圆形,边缘有翅,成熟时紫褐色,下垂
  - 药材: 圆柱形,稍扭曲,长10-20 cm,直径0.5-1 cm;表面淡灰黄色或淡棕黄色,有纵皱纹和横长皮孔样突起;**根头略膨大,可见暗绿色或暗棕色轮状排列的叶柄残基和密集的疣状突起**
  - 断面: 质略软,断面皮部黄白色,木部黄色;气微,味微甜后苦涩
- **易混淆品**: "南板蓝根"是爵床科植物马蓝的根茎和根,药典另立条目,不能简单互换。十字花科一般没有剧毒种,但仍要见到箭形抱茎叶和黄花再确认
- **采收与加工**: 秋季采挖,除去泥沙,晒干
- **储存**: 易虫蛀、受潮;放干燥处
- **功效**: 清热解毒,凉血利咽
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒者慎用;**不要长期当"预防感冒"的饮料喝**;偶有过敏反应。板蓝根不能代替疫苗和抗病毒治疗,流感高危人群(老人、孕妇、慢性病人)发热要及时就医

## 四、解表祛风类

这一组用于感冒发热、头痛身痛、风湿痹痛等。**除葛根(豆科)和升麻(毛茛科)外,都是伞形科植物**——伞形科里有剧毒的毒芹、毒参,野外挖这几味药之前,必须先读[毒芹 vs 水芹、野胡萝卜](./09-有毒中药与易混淆有毒植物.md#43-毒芹-vs-水芹野胡萝卜)。

### 4.1 葛根

- **正名(别名)**: 葛根(野葛、柴葛、葛藤根)
- **来源**: 豆科植物野葛 *Pueraria lobata* (Willd.) Ohwi 的干燥根,习称"野葛"。淀粉含量高的甘葛藤的根是"粉葛",药典另立条目
- **分布与生境**: 除新疆、西藏外全国广布,山坡、路边、林缘、灌丛,常成片覆盖;非常容易找到
- **识别要点**:
  - 植株: **粗壮的缠绕藤本**,可长达10 m 以上,**全株密生黄褐色长硬毛**;**三出复叶**,顶生小叶宽卵形或菱状卵形,有时3浅裂;总状花序,蝶形花**紫红色**,有香气;荚果扁平,密生黄色长硬毛
  - 药材: 纵切的长方形厚片或小方块,外皮淡棕色至棕色,粗糙,有纵皱纹
  - 断面: 切面黄白色至淡黄棕色,有的可见同心环纹;**质韧,纤维性强**;气微,味微甜
- **易混淆品**: 葛的植株好认,注意别和其他有毒的豆科藤本混淆,例如种子剧毒的相思子(偶数羽状复叶,种子红黑两色,见[相思子](./09-有毒中药与易混淆有毒植物.md#414-相思子));抓住"三出复叶 + 全株黄毛 + 紫红花"
- **采收与加工**: 秋、冬二季采挖,趁鲜切成厚片或小块,干燥(大块根干后极难切开)
- **储存**: 含淀粉,**易虫蛀、发霉**;干透后密封
- **功效**: 解肌退热,生津止渴,透疹,升阳止泻,通经活络,解酒毒
- **用量**: 10-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 胃寒、脾虚泄泻者慎用;正服降压药、降糖药的人用前问医生。葛根粉作为食物按日常食用量吃是安全的

### 4.2 柴胡

- **正名(别名)**: 柴胡;按性状分为北柴胡(硬柴胡)、南柴胡(软柴胡、红柴胡)
- **来源**: 伞形科植物柴胡 *Bupleurum chinense* DC. 或狭叶柴胡 *B. scorzonerifolium* Willd. 的干燥根,分别习称"北柴胡"和"南柴胡"
- **分布与生境**: 北柴胡分布于东北、华北、西北、华东的向阳山坡、路边、草丛;南柴胡分布于东北、华北及西北、华东部分地区的干燥草原、向阳山坡;现多有栽培
- **识别要点**:
  - 植株: 多年生草本,高40-80 cm;**和多数伞形科不同,柴胡的叶是单叶、全缘、有平行的纵脉,像禾草叶**;茎上部多分枝,略呈"之"字形;复伞形花序小,**花黄色**
  - 北柴胡: 根圆柱形或长圆锥形,长6-15 cm,根头膨大,顶端残留3-15个茎基或短纤维状叶基;表面黑褐色或浅棕色;**质硬而韧,断面纤维性**;气微香,味微苦
  - 南柴胡: 根较细,圆锥形,顶端有许多细毛状枯叶纤维;表面红棕色或黑棕色,近根头处有紧密环纹;质稍软,易折断,断面略平坦;**有"败油气"**
- **易混淆品**: **大叶柴胡** *Bupleurum longiradiatum* 的根茎**有毒**,药典明确规定不可当柴胡用——它的根茎表面**密生环节**,叶较宽大、基部抱茎。同属其他种(如竹叶柴胡、锥叶柴胡)在一些地方混用。最危险的仍是误挖其他伞形科有毒植物——柴胡的"禾草状全缘单叶 + 黄色小花"是关键
- **采收与加工**: 春、秋二季采挖,除去茎叶和泥沙,干燥
- **储存**: 防潮、防虫蛀
- **功效**: 疏散退热,疏肝解郁,升举阳气
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚阳亢、肝风内动、阴虚火旺及气机上逆者忌用或慎用;不宜长期大量服用;柴胡注射液等制剂有过敏反应报道,不能自行使用

### 4.3 防风

- **正名(别名)**: 防风(关防风、东防风、屏风)
- **来源**: 伞形科植物防风 *Saposhnikovia divaricata* (Turcz.) Schischk. 的干燥根
- **分布与生境**: 黑龙江、吉林、内蒙古、河北、山西等地的草原、丘陵和干旱山坡;东北所产习称"关防风",质量最好;现多为栽培
- **识别要点**:
  - 植株: 多年生草本,高30-80 cm;**茎单生,自基部起作二歧分枝**,分枝多而斜展,整株像一团扫帚;基生叶丛生,二回或近三回羽状深裂,裂片狭窄;**复伞形花序,花白色**
  - 药材: 长圆锥形或长圆柱形,长15-30 cm;表面灰棕色或棕褐色,粗糙,有纵皱纹和许多横长皮孔样突起;**根头部有明显密集的环纹,有的残存棕褐色毛状叶基**(习称"蚯蚓头")
  - 断面: **体轻,质松,易折断**;断面不平坦,皮部棕黄色至棕色,有裂隙("菊花心"),木部黄色;气特异,味微甘
- **易混淆品**: 历史上曾有水防风、川防风、云防风等多种伞形科植物的根混用;更要防的是野外误挖毒芹等。开花结果后的植株根会木质化、中空,不堪药用
- **采收与加工**: 春、秋二季采挖**未抽花茎**植株的根,除去须根和泥沙,晒干
- **储存**: 易虫蛀;放干燥处
- **功效**: 祛风解表,胜湿止痛,止痉
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴血亏虚、热病动风者不宜;破伤风等抽搐必须立即就医,不能靠防风"止痉"
- 🛡️ **保护提醒**: 防风是《国家重点保护野生药材物种名录》的三级物种,野生资源因过度采挖已明显减少;采挖野生的须按规定持证,优先用栽培品

### 4.4 羌活

- **正名(别名)**: 羌活(蚕羌、竹节羌、大头羌)
- **来源**: 伞形科植物羌活 *Notopterygium incisum* Ting ex H. T. Chang 或宽叶羌活 *N. franchetii* H. de Boiss. 的干燥根茎和根
- **分布与生境**: 四川西部、青海、甘肃、西藏东部等地海拔约2000-4000 m 的高山林缘、灌丛、沟谷;商品长期依赖野生,现已开始栽培
- **识别要点**:
  - 植株: 多年生草本,高60-120 cm,有浓烈的特殊香气;茎带紫色;叶为三出式二至三回羽状复叶;复伞形花序,花白色
  - 药材(羌活): 圆柱状略弯曲的根茎,表面棕褐色至黑褐色,外皮脱落处呈黄色;**节间缩短、紧密隆起成环,形似蚕的,习称"蚕羌"**;节间延长、形如竹节的,习称"竹节羌";节上有许多点状或瘤状根痕
  - 断面: **体轻,质脆**,断面有许多裂隙,皮部黄棕色至暗棕色,**油润,有棕色油点**,木部黄白色,髓部黄色至黄棕色;**气香**,味微苦而辛
- **易混淆品**: 产区有用其他伞形科植物的根茎混充;高山伞形科植物种类繁多,外行几乎无法在野外分辨,**不要自行采挖**
- **采收与加工**: 春、秋二季采挖,除去须根和泥沙,晒干
- **储存**: 含挥发油,**易走油、虫蛀**,香气会散失;密封放阴凉处
- **功效**: 解表散寒,祛风除湿,止痛
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴血亏虚、阴虚头痛者慎用;用量过大易引起呕吐,脾胃虚弱者不宜多用
- 🛡️ **保护提醒**: 羌活是《国家重点保护野生药材物种名录》的三级物种,野生羌活和宽叶羌活也已列入2021年《国家重点保护野生植物名录》(以名录原文为准)。资源恢复很慢,**不采挖野生羌活**

### 4.5 独活

- **正名(别名)**: 独活(川独活、香独活、资丘独活)
- **来源**: 伞形科植物重齿毛当归 *Angelica pubescens* Maxim. f. *biserrata* Shan et Yuan 的干燥根
- **分布与生境**: 四川、湖北、重庆、陕西等地的山地林下、林缘、草丛;湖北资丘、重庆巫溪等地有栽培
- **识别要点**:
  - 植株: 多年生高大草本,高1-2 m;茎中空,常带紫色;叶为二至三回三出式羽状复叶,小叶边缘有重锯齿,叶柄基部成宽鞘;复伞形花序大,花白色
  - 药材: 根略呈圆柱形,下部2-3分枝或更多,长10-30 cm;**根头部膨大,圆锥状,多横皱纹**;表面灰褐色或棕褐色,有纵皱纹和横长皮孔样突起
  - 断面: 质较硬,**受潮则变软**;断面皮部灰白色,**散有许多棕色油室**,木部灰黄色至黄棕色,形成层环棕色;**有特异香气,味苦、辛,微麻舌**
- **易混淆品**: 各地叫"独活"的植物很多(如牛尾独活等独活属、当归属植物),有的地方以九眼独活(五加科)作独活用;外形相近的伞形科有毒植物同样要提防
- **采收与加工**: 春初苗刚发芽或秋末茎叶枯萎时采挖,除去须根和泥沙,烘至半干,堆置2-3天发软后,再烘至全干
- **储存**: **易走油、虫蛀、受潮发软**;密封放阴凉干燥处
- **功效**: 祛风除湿,通痹止痛
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚血燥者慎用;含呋喃香豆素类成分,用药期间注意避免强烈日晒(有光敏反应的可能);关节红肿热痛、发热或长期关节痛应先就医查明原因

### 4.6 白芷

- **正名(别名)**: 白芷(川白芷、杭白芷、禹白芷、祁白芷)
- **来源**: 伞形科植物白芷 *Angelica dahurica* (Fisch. ex Hoffm.) Benth. et Hook. f. 或杭白芷 *A. dahurica* var. *formosana* (Boiss.) Shan et Yuan 的干燥根
- **分布与生境**: 白芷野生于东北、华北的林下、林缘、溪边;药材基本为四川遂宁、浙江、河南禹州、河北安国等地的栽培品
- **识别要点**:
  - 植株: 多年生高大草本,高1-2.5 m;茎粗壮中空,常带紫色;叶为二至三回羽状分裂,**叶柄基部膨大成囊状的鞘**;复伞形花序大,花白色;有特殊香气
  - 药材: 长圆锥形,长10-25 cm,直径1.5-2.5 cm;表面灰棕色或黄棕色,有许多**皮孔样横向突起,有的排成四纵行**(习称"疙瘩丁");根头部钝四棱形或近圆形
  - 断面: 质坚实,断面**白色或灰白色,粉性**,形成层环棕色,**近方形或近圆形**,皮部散有许多棕色油点;**气芳香**,味辛、微苦
- **易混淆品**: 野生的白芷与独活、当归属其他植物及毒芹等伞形科有毒植物外形接近,**不要野外采挖**,用栽培品
- **采收与加工**: 夏、秋间叶黄时采挖,除去须根和泥沙,晒干或低温干燥
- **储存**: 粉性大,**极易虫蛀、发霉**;是传统上最难保存的药材之一,干透密封,勤检查
- **功效**: 解表散寒,祛风止痛,宣通鼻窍,燥湿止带,消肿排脓
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚血热者忌用;**含呋喃香豆素类光敏成分,服用或外用后避免强烈日晒**,以防光敏性皮炎;头痛、鼻窦炎反复发作应就医查原因

### 4.7 升麻

- **正名(别名)**: 升麻(绿升麻、关升麻、川升麻)
- **来源**: 毛茛科植物大三叶升麻 *Cimicifuga heracleifolia* Kom.、兴安升麻 *C. dahurica* (Turcz.) Maxim. 或升麻 *C. foetida* L. 的干燥根茎
- **分布与生境**: 大三叶升麻、兴安升麻产东北、华北;升麻产西南、西北;多生于山地林下、林缘、灌丛、草甸
- **识别要点**:
  - 植株: 多年生高大草本,高1-2 m;叶为二至三回三出复叶,小叶有粗齿;**大型圆锥状或总状花序,密生许多白色小花**,像一支支白色的穗;兴安升麻有特殊臭气
  - 药材: **不规则的长形块状,多分枝,呈结节状**,长10-20 cm;表面黑褐色或棕褐色,粗糙不平,有坚硬的须根残留;**上面有数个圆形空洞状的茎基痕,洞内壁有网状沟纹**
  - 断面: **体轻,质坚硬**,不易折断;断面不平坦,有裂隙,纤维性,**黄绿色或淡黄白色**;气微,味微苦而涩
- **易混淆品**: 有地方用菊科、虎耳草科等植物的根茎作"升麻";毛茛科多有毒植物,野外**不要把不认识的毛茛科根茎当升麻**
- **采收与加工**: 秋季采挖,除去泥沙,晒至须根干时,燎去或除去须根,再晒干
- **储存**: 防潮、防虫蛀
- **功效**: 发表透疹,清热解毒,升举阳气
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 麻疹已透、阴虚火旺、肝阳上亢者忌用;**过量可引起头痛、恶心呕吐、眩晕等不良反应**,不要超量;孕妇在医生指导下使用

## 五、化湿、息风、化痰与养阴类

### 5.1 苍术

- **正名(别名)**: 苍术;按产地和来源分为茅苍术(南苍术)、北苍术
- **来源**: 菊科植物茅苍术 *Atractylodes lancea* (Thunb.) DC. 或北苍术 *A. chinensis* (DC.) Koidz. 的干燥根茎
- **分布与生境**: 茅苍术产江苏(以句容茅山一带最有名)、湖北、河南、安徽等地;北苍术产华北、东北、西北;都生于山坡草丛、林下、灌丛
- **识别要点**:
  - 植株: 多年生草本,高30-80 cm;**叶较硬,近革质,边缘有刺状细齿**;头状花序单生枝顶,外有一圈羽状深裂、带刺的叶状苞片,**花白色**(白术为紫红色)
  - 茅苍术: **不规则连珠状或结节状圆柱形**,长3-10 cm;表面灰棕色,有皱纹、横曲纹和残留须根;质坚实,断面黄白色或灰白色,**散有许多橙黄色或棕红色油室(习称"朱砂点")**,断面暴露稍久可析出白色细针状结晶(习称"起霜");**香气特异浓烈**,味微甘、辛、苦
  - 北苍术: 疙瘩块状或结节状圆柱形,表面黑棕色;质较疏松,断面油室黄棕色;香气较淡,味辛、苦
- **易混淆品**: 与白术同属,区别见[1.6](#16-白术)。野外与其他带刺的菊科植物(蓟类)相似,要看根茎的香气和"朱砂点"
- **采收与加工**: 春、秋二季采挖,除去泥沙,晒干,撞去须根
- **储存**: 含挥发油,**易走油**,香气会散失;密封放阴凉处
- **功效**: 燥湿健脾,祛风散寒,明目
- **用量**: 3-9 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 性温燥,阴虚内热、出汗多、口干舌燥者忌用

### 5.2 天麻

- **正名(别名)**: 天麻(赤箭、明天麻、定风草);冬季采挖的称"冬麻",春季采挖的称"春麻"
- **来源**: 兰科植物天麻 *Gastrodia elata* Bl. 的干燥块茎
- **分布与生境**: 野生于全国多数山区海拔约400-3200 m 的阴湿林下、林缘腐殖质厚的地方;它没有叶绿素,**依靠蜜环菌生活**。商品基本为陕西汉中、云南昭通、湖北、贵州、安徽等地的栽培品
- **识别要点**:
  - 植株: 一年中大部分时间只有地下块茎;夏季抽出**一根黄褐色或橙红色的直立花茎,高30-100 cm,没有绿叶**(只有膜质鞘),像一支插在地上的箭,所以古称"赤箭";顶端总状花序,花黄褐色
  - 药材: 椭圆形或长条形,略扁,皱缩稍弯,长3-15 cm;表面黄白色至黄棕色,有**由潜伏芽排成的多轮横环纹**(习称"点状环纹"),有时可见棕褐色菌索;**顶端有红棕色至深棕色的鹦嘴状芽(冬麻)或残留茎基(春麻),另一端有圆脐形疤痕**(习称"鹦哥嘴、肚脐眼")
  - 断面: 质坚硬,不易折断;断面较平坦,黄白色至淡棕色,**角质样、半透明**;气微,味甘。冬麻质地饱满坚实,质量较好
- **易混淆品**: 天麻价格较高,市场上曾有**紫茉莉根**、大丽菊块根、芭蕉芋、马铃薯、羽裂蟹甲草块茎等加工冒充。冒充品没有"多轮点状环纹 + 鹦哥嘴 + 肚脐眼"这组特征;**紫茉莉根有毒性**,误服可引起腹痛腹泻。不在路边摊、不明来源处买天麻
- **采收与加工**: 立冬后至次年清明前采挖,立即洗净,**蒸透**,敞开低温干燥(不蒸透容易霉变、空心)
- **储存**: 防潮、防虫蛀;放干燥处
- **功效**: 息风止痉,平抑肝阳,祛风通络
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜长期大量当保健食品吃;**头晕、头痛、肢体麻木、抽搐可能是高血压、脑卒中、癫痫等急重症的表现**,先就医,不能只靠天麻;突发口角歪斜、一侧肢体无力、言语不清立即拨打120
- 🛡️ **保护提醒**: 野生天麻已列入2021年《国家重点保护野生植物名录》(二级,以名录原文为准)。**不采挖野生天麻**,市售都是栽培品

### 5.3 桔梗

- **正名(别名)**: 桔梗(苦桔梗、铃铛花、包袱花)
- **来源**: 桔梗科植物桔梗 *Platycodon grandiflorum* (Jacq.) A. DC. 的干燥根
- **分布与生境**: 全国南北均有分布,向阳山坡、草地、灌丛、林缘;安徽、山东、河北、内蒙古、东北等地大量栽培,东北和朝鲜族地区也作蔬菜(腌咸菜)
- **识别要点**:
  - 植株: 多年生草本,高20-120 cm,**全株有白色乳汁**;叶多轮生或对生,卵形,边缘有锯齿;**花蕾膨大像一个小气球,开放后为大型钟状花,蓝紫色(也有白色),5裂**,非常好认
  - 药材: 圆柱形或略呈纺锤形,下部渐细,长7-20 cm;**已去外皮的表面淡黄白色**,未去外皮的黄棕色至灰棕色;有纵扭皱沟和横长皮孔样斑痕,上部有横纹,顶端有半月形茎痕(芦头)
  - 断面: **质脆**,断面不平坦,**形成层环棕色,皮部黄白色、有裂隙,木部淡黄色**(习称"金井玉栏");气微,**味微甜后苦**
- **易混淆品**: 同科的沙参、党参等根相似,都有乳汁;历史上曾有人用桔梗冒充人参(桔梗没有芦碗、珍珠点,断面没有棕黄色树脂道小点)。桔梗本身无剧毒,但同生境的有毒植物多,挖根前认清花
- **采收与加工**: 春、秋二季采挖,洗净,除去须根,趁鲜剥去外皮或不去外皮,干燥
- **储存**: 易虫蛀、受潮;放干燥处
- **功效**: 宣肺,利咽,祛痰,排脓
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **用量过大可引起恶心、呕吐**;阴虚久咳、咳血者不宜;胃溃疡患者慎用。咳嗽超过3周、咳血、胸痛、气促要就医

### 5.4 南沙参

- **正名(别名)**: 南沙参(沙参、泡参、空沙参)
- **来源**: 桔梗科植物轮叶沙参 *Adenophora tetraphylla* (Thunb.) Fisch. 或沙参 *A. stricta* Miq. 的干燥根
- **分布与生境**: 轮叶沙参广布于东北、华北、华东、华南、西南的山坡草地、林缘、灌丛;沙参主要分布于华东、华中;商品多为野生,部分栽培
- **识别要点**:
  - 植株: 多年生草本,高50-150 cm,**有白色乳汁**;轮叶沙参的**茎生叶3-6片轮生**,沙参的叶互生;**花蓝紫色,钟状,下垂,花柱伸出花冠外**,排成狭长的圆锥花序
  - 药材: 圆锥形或圆柱形,略弯,长7-27 cm,直径0.8-3 cm;表面黄白色或淡棕黄色,凹陷处常残留粗皮,**上部有深陷的断续环状横纹**,下部有纵纹和纵沟;顶端有1-2个根茎
  - 断面: **体轻,质松泡,易折断**;断面不平坦,黄白色,**多裂隙**;气微,味微甘
- **易混淆品**: 与北沙参名字相近,但**南沙参是桔梗科、北沙参是伞形科**,两者不能互换;沙参属有很多种,各地习用不一
- **采收与加工**: 春、秋二季采挖,除去须根,洗后趁鲜刮去粗皮,洗净,干燥
- **储存**: 质地疏松,**易虫蛀、受潮**;放干燥处
- **功效**: 养阴清肺,益胃生津,化痰,益气
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与藜芦同用;风寒咳嗽、痰多清稀、脾胃虚寒者不宜

### 5.5 北沙参

- **正名(别名)**: 北沙参(莱阳参、海沙参、辽沙参)
- **来源**: 伞形科植物珊瑚菜 *Glehnia littoralis* Fr. Schmidt ex Miq. 的干燥根
- **分布与生境**: 野生于辽宁、河北、山东、江苏、浙江、福建、台湾、广东沿海的**海边沙滩**;药材主要为山东莱阳、河北、内蒙古等地的栽培品
- **识别要点**:
  - 植株: 多年生矮小草本,高5-20 cm,**全株有白色柔毛**,根细长、深入沙中;叶多基生,**质厚**,三出式分裂,裂片边缘有锯齿;复伞形花序,花白色;果实近球形,**密生棕色长柔毛,有木栓质翅状棱**
  - 药材: **细长圆柱形**,偶有分枝,长15-45 cm,直径0.4-1.2 cm;表面淡黄白色,略粗糙(已去外皮),全体有细纵皱纹和纵沟,并有棕黄色点状细根痕;上端稍细,中部略粗,下部渐细
  - 断面: **质脆,易折断**;断面皮部浅黄白色,木部黄色;气特异,味微甘
- **易混淆品**: 与南沙参不同科(见[5.4](#54-南沙参));野外只在海边沙滩出现,内陆见到的"北沙参"不要采
- **采收与加工**: 夏、秋二季采挖,除去须根,洗净,稍晾,置沸水中烫后除去外皮,干燥;或洗净直接干燥
- **储存**: 易虫蛀、受潮;放干燥处
- **功效**: 养阴清肺,益胃生津
- **用量**: 5-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 不宜与藜芦同用;风寒咳嗽、脾胃虚寒、痰湿重者不宜
- 🛡️ **保护提醒**: 野生珊瑚菜是国家重点保护野生植物(以2021年名录原文为准),海滩生境破坏使野生种群很少。**不采挖野生珊瑚菜**,市售为栽培品

## 六、本章小结

### 6.1 易混淆与风险汇总

| 本章品种 | 主要风险 | 怎样避免 |
|---------|---------|---------|
| 人参 | 商陆根冒充(有毒) | 看掌状复叶、红果、芦头;路边"野人参"不挖不买 |
| 三七 | 菊三七(土三七)冒充(伤肝) | 看掌状复叶、红果;家种的"土三七"不泡酒、不打粉 |
| 何首乌 | 本身可致肝损伤 | 不长期服,不用生首乌保健,肝病不用 |
| 甘草 | 长期大量致低血钾、高血压 | 不长期单味泡水喝 |
| 柴胡 | 大叶柴胡(有毒)混入 | 看根茎有无密集环节,正规渠道购买 |
| 天麻 | 紫茉莉根等冒充 | 认准环纹、鹦哥嘴、肚脐眼 |
| 山药 | 黄独(黄药子,伤肝)混淆 | 看叶序(山药对生)和根茎形状 |
| 当归、柴胡、防风、羌活、独活、白芷、北沙参 | 伞形科,野外可能误挖毒芹等 | 不挖不认识的伞形科植物 |
| 白芍、赤芍、黄连、升麻 | 毛茛科,有毒近亲多 | 不挖不认识的毛茛科植物 |
| 丹参、三七、当归、川芎、赤芍 | 增加出血风险 | 服抗凝药、孕妇、月经过多者先问医生 |

### 6.2 自我检查

挖根类药材之前,逐条确认:

- [ ] 我在植株带花或带果时认准了地上部分,不是只看根
- [ ] 我知道它最容易和哪种有毒植物混淆,并核对了区别
- [ ] 它不是人参、三七、甘草、黄连、天麻、羌活、珊瑚菜等受保护的野生种
- [ ] 采挖地不在自然保护区内,远离公路、工厂和农药田
- [ ] 我只挖了一部分,回填了土坑,留下了母株和种子
- [ ] 我知道这味药怎样干燥、是否容易走油或虫蛀
- [ ] 我知道药典用量和禁忌,使用前会问中医师

| 环节 | 难度 | 出错的风险 |
|------|------|----------|
| 认栽培品药材(人参、黄芪、甘草、当归饮片) | ⭐⭐ | ☠️(买到冒充品) |
| 野外认常见品种(葛根、桔梗、丹参、地黄、山药) | ⭐⭐⭐ | ☠️☠️(黄独等混淆) |
| 野外认伞形科根药(柴胡、防风、白芷等) | ⭐⭐⭐⭐⭐ | ☠️☠️☠️☠️(毒芹等) |
| 分辨人参与商陆、三七与菊三七 | ⭐⭐⭐ | ☠️☠️☠️☠️(中毒、肝损伤) |
| 长期自服何首乌、甘草 | 不建议 | ☠️☠️☠️(肝损伤、低血钾) |

## 📝 本章要点

```
□ 根类药材先认地上部分,只拿到一段根的不用
□ 路边"野人参"多是商陆;院子里的"土三七"多是菊三七——都不吃
□ 何首乌伤肝,不长期吃、不用生首乌保健
□ 甘草长期大量可致水肿、高血压、低血钾
□ 伞形科(当归、柴胡、防风、羌活、独活、白芷)野外极易误挖毒芹
□ 人参、三七、甘草、黄连、天麻、羌活、珊瑚菜等野生种受保护,用栽培品
□ 人参、党参、丹参、芍药、沙参类不与藜芦同用
□ 活血药增加出血风险,服抗凝药的人先问医生
```
