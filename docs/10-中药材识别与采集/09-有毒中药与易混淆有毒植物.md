# 有毒中药与易混淆有毒植物

> **这一章不是教你用有毒中药,而是教你认出它们、躲开它们。** 每年的中药中毒,大多来自自采自制、药酒偏方和认错植物——乌头炖肉、断肠草当金银花、商陆根当人参、土三七泡酒。认出来,不去碰,就是最好的解毒法。

---

## ⚠️ 先读这几条

```
1. 本章只写识别、毒性和中毒表现,不写任何炮制去毒方法和用法用量。
   这是有意的: 家庭条件下无法可靠控制炮制质量和剂量,
   "照着书炮制一下"正是很多中毒事件的起点。

2. 本章列出的品种,一律不要自行采集、自行炮制、自行服用或外敷,
   也不要用来泡药酒、炖汤、做"偏方"。
   需要时只能由医院或正规药房按医师处方调配炮制好的饮片。

3. 很多剧毒植物没有"难吃的味道",也不会立刻发作;
   有的(乌头、钩吻、毒芹)几十分钟内就能导致呼吸、心跳停止。

4. "断肠草""土三七""木通""防己""五加皮""白附子"这些名字
   各自对应好几种不同的植物,有的有毒、有的无毒。
   名字对上了,不代表东西对了。

5. 拍照识别软件、"老人说能吃"、"以前吃过没事"都不能作为确认依据。

6. 误食、误用后: 立即拨打120,带上剩余的植物、药材、药渣或药酒,
   不要催吐,不要用绿豆汤、甘草水等偏方"解毒"。
   见本章第五节和中毒章。

7. 本章是教育参考,不能替代医生和药师。
```

## 一、国家管制的毒性中药品种

### 1.1 28种毒性中药名单

国务院1988年发布的《医疗用毒性药品管理办法》把下列中药列为"毒性中药品种"。它们和西药中的毒性药品一样受国家专门管理:

```
砒石(红砒、白砒)   砒霜           水银           生马钱子
生川乌             生草乌         生白附子       生附子
生半夏             生南星         生巴豆         斑蝥
青娘虫             红娘虫         生甘遂         生狼毒
生藤黄             生千金子       生天仙子       闹阳花(即闹羊花)
雪上一枝蒿         红升丹         白降丹         蟾酥
洋金花             红粉           轻粉           雄黄
```

- 名单里很多品种写着"生"字: 指的是未经炮制的原药材,毒性最强
- 红升丹和红粉是同一类东西的不同名称;红升丹、白降丹是传统外用丹药(加工品),不是天然药材
- 青娘虫、红娘虫和斑蝥同属芫青科昆虫,含斑蝥素
- 不同资料对这份名单的统计口径略有差别(有的说27种、有的按药材算24种),以《办法》原文附录为准

### 1.2 这份名单意味着什么

```
- 这些品种的收购、经营、加工、调配都由指定单位负责,
  医疗机构凭医师处方调配,有严格的剂量和处方管理规定
- 个人私自收购、加工、销售这些品种是违法的
- 药店买不到"生川乌""生半夏"不是缺货,是按规定不能随意出售
- 网上、集市上卖的"野生生附子""祖传马钱子"来路不明、质量不明,
  不要买,更不要自己炮制
```

### 1.3 名单之外同样危险的品种

名单是1988年定的,**不在名单上不等于安全**。下列品种不在28种名单内,但毒性同样很强或经常出事:

- **雷公藤**、**藜芦**、**钩吻(断肠草)**: 毒性极强,野外常见
- **商陆**、**京大戟**、**芫花**、**香加皮**、**苍耳子**、**白果**、**苦杏仁**、**蓖麻子**: 药典标注"有毒"或"有小毒"
- **含马兜铃酸的药材**: 急性中毒不明显,但会造成不可逆的肾损害并致癌(见第三节)
- **朱砂**、**铅丹**: 重金属,长期少量服用就会慢性中毒
- **菊三七(土三七)**: 不是药典品种,但常被家庭种植、泡酒,引起严重肝损伤

## 二、常见剧毒中药材

每个品种只写: 来源、识别要点、常被误认成什么、有毒部位和成分、中毒表现。**一律不要自行采集或使用。**

### 2.1 川乌、草乌、附子(乌头类)

**来源**:
- 川乌: 毛茛科植物乌头 *Aconitum carmichaelii* 的干燥母根(主根)
- 附子: 同一种乌头的子根(旁生的小块根)的加工品
- 草乌: 毛茛科植物北乌头 *Aconitum kusnezoffii* 的干燥块根
- 乌头属植物我国有一百多种,很多地方品种(如雪上一枝蒿、关白附)同样剧毒

**识别要点**:
- 植株: 多年生草本,高约0.6-1.5 m;叶互生,掌状3深裂或全裂,裂片再分裂;秋季开蓝紫色花,花的上萼片像一顶头盔(所以英文叫"僧帽草");长在山坡草丛、林缘
- 块根: 形状像小芋头或倒圆锥形,母根旁边常连着1-数个子根;表面棕褐色,有瘤状突起(侧根痕)
- 药材川乌: 不规则圆锥形,稍弯曲,顶端常有残茎,中部多向一侧膨大;断面类白色或浅灰黄色,有多角形环纹

**常被误认成**:
- 自己挖来"炖汤""泡酒"的"附子""草乌",实为未炮制的生品或别的乌头属植物
- 春季幼苗被当成野芹菜、山芹等野菜(见[4.9](#49-乌头-vs-野芹类野菜))
- 块根被当成芋头、野山药等

**有毒部位和成分**: 全株有毒,块根毒性最强。主要毒性成分是乌头碱、新乌头碱、次乌头碱等双酯型生物碱,**极少量即可致死**。

**中毒表现**(常在服后10分钟至2小时内出现):
- 口唇、舌头、咽喉发麻,很快蔓延到手指、脚趾和全身,有蚁走感
- 流涎、恶心、呕吐、腹痛
- 心慌、胸闷,心跳过慢或过快、严重心律失常(可发展为心室颤动)、血压下降
- 头晕、视物模糊、抽搐、呼吸困难,最终可呼吸、心跳骤停

```
❌ 不要自制乌头、草乌、附子药酒——乌头碱溶在酒里,喝一口就可能致命
❌ 不要自己"附子炖肉""草乌炖鸡"——"煮久一点就没事"的说法不可靠,
   煮的时间、火候、药材本身的毒性差别都无法控制
❌ 不要外敷生乌头——破损皮肤同样会吸收中毒
⚠️ 喝了含乌头类的药酒、汤后出现口唇发麻,立即拨打120
```

### 2.2 雪上一枝蒿

**来源**: 毛茛科乌头属植物短柄乌头 *Aconitum brachypodum* 等数种的块根,主产云南、四川西南部高山地区,当地民间多用作治跌打损伤和风湿的"草药"。

**识别要点**: 植株较矮,茎多不分枝;叶掌状细裂,裂片窄线形;花蓝紫色,头盔状;块根细长纺锤形,常成对。外观与其他乌头属植物相似,非专业人员无法可靠区分。

**常被误认成**: 当地草药摊上以"止痛药""跌打药"出售,被买来泡酒、研粉吞服。

**有毒部位和成分**: 块根,含乌头碱类生物碱,毒性比川乌、草乌更强。

**中毒表现**: 同乌头类——口唇和四肢发麻、恶心呕吐、严重心律失常、呼吸麻痹,进展很快。

```
❌ 旅游时不要购买、不要试用当地的"雪上一枝蒿""三分三""草乌"等止痛草药
```

### 2.3 马钱子

**来源**: 马钱科植物马钱 *Strychnos nux-vomica* 的干燥成熟种子。原产印度、东南亚,我国云南、广东等地有栽培。

**识别要点**:
- 种子: 扁圆形纽扣状,直径约1.5-3 cm,一面稍凹、一面稍隆起;表面灰棕色至灰绿色,**密被灰棕色或灰绿色绢状茸毛,从中央向四周呈辐射状排列,有丝样光泽**;边缘稍隆起,有一个小突起(珠孔);质地极坚硬
- 气微,味极苦(**不要尝**)

**常被误认成**: 少见误认为食物;中毒多因自制"治风湿""治瘫痪"的偏方药酒、药丸,或自行炮制不当、过量。同属的云南马钱等也可能混入。

**有毒部位和成分**: 种子,主要毒性成分为士的宁(番木鳖碱)和马钱子碱。士的宁是强烈的中枢神经兴奋剂,治疗量与中毒量非常接近。

**中毒表现**:
- 早期: 头痛、头晕、烦躁不安、嚼肌和颈部肌肉发紧、吞咽困难
- 进展: 声、光、触碰都能诱发全身强直性抽搐,牙关紧闭、面肌痉挛呈"苦笑"状,身体向后弯成弓形(角弓反张)
- 抽搐时人往往是清醒的,极其痛苦;反复抽搐可因呼吸肌痉挛窒息死亡

```
⚠️ 中毒者周围保持安静、避光,不要反复摇晃、拍打他,立即拨打120
❌ 不要服用来路不明的"祖传风湿药""马钱子药酒""壮骨丸"
```

### 2.4 生半夏

**来源**: 天南星科植物半夏 *Pinellia ternata* 的干燥块茎。全国大部分地区的田边、荒地、林下都有野生。

**识别要点**:
- 植株: 矮小草本,高约15-30 cm;幼苗叶为单叶卵形,长大后叶为3全裂(三片小叶);叶柄下部和叶片基部常有一个小珠芽;初夏抽出绿色佛焰苞,中间的肉穗花序顶端有一根细长的鞭状附属物伸出
- 块茎: 类球形,直径约1-1.5 cm;表面白色或浅黄色,顶端有凹陷的茎痕,周围密布麻点状根痕;质坚实,断面洁白,富粉性

**常被误认成**:
- 小芋头、野生小土豆、野荸荠
- 药材中的伪品"水半夏"(鞭檐犁头尖的块茎)、虎掌(掌叶半夏)等,同样有毒

**有毒部位和成分**: 全株有毒,块茎毒性最大。主要是草酸钙针晶和一种刺激性毒蛋白,针晶刺入口腔、咽喉黏膜引起强烈刺激。

**中毒表现**:
- 生嚼少量: 口舌、咽喉剧烈麻木、灼痛、肿胀,流涎、说不出话(失音)
- 严重时: 喉头水肿导致呼吸困难、窒息
- 也可出现恶心、呕吐、腹泻;皮肤接触汁液可引起瘙痒、皮炎

```
❌ 不要生嚼尝试,不要把野生块茎当小芋头煮着吃
⚠️ 出现喉咙发紧、呼吸困难、声音嘶哑 → 立即拨打120,这是气道危险
```

### 2.5 生天南星

**来源**: 天南星科植物天南星 *Arisaema erubescens*、异叶天南星 *A. heterophyllum* 或东北天南星 *A. amurense* 的干燥块茎。各地山林阴湿处常见。

**识别要点**:
- 植株: 叶片放射状或鸟足状分裂成多片小叶,像一把撑开的伞;花为佛焰苞包着的肉穗花序,佛焰苞绿色或带紫褐色条纹;秋季结一串红色浆果(像一根红色玉米棒),非常醒目
- 块茎: 扁球形,直径约1.5-6.5 cm;顶端中央有凹陷的茎痕,周围有麻点状根痕,有的块茎周边有小扁球状侧芽;断面白色、粉性

**常被误认成**: 芋头、魔芋;红色果串被儿童当野果采食。

**有毒部位和成分**: 全株有毒,块茎和果实毒性大。与半夏类似,主要是草酸钙针晶和刺激性成分。

**中毒表现**: 口舌麻木、灼痛,口腔和咽喉黏膜肿胀糜烂,流涎、吞咽困难、声音嘶哑,严重时喉头水肿窒息;皮肤接触引起瘙痒红肿。

```
❌ 教育孩子不要采食林下的"红玉米串"状野果
```

### 2.6 白附子

**来源**: 药典的白附子是天南星科植物独角莲 *Typhonium giganteum* 的干燥块茎(习称"禹白附")。

**识别要点**:
- 植株: 叶从地下块茎生出,叶片大、戟状箭形或卵状宽三角形;佛焰苞紫色
- 块茎: 椭圆形或卵圆形,长约2-5 cm;表面白色至黄白色,略粗糙,有环纹和须根痕,顶端有茎痕或芽痕;断面白色,粉性

**常被误认成**:
- **"关白附"**: 毛茛科植物黄花乌头 *Aconitum coreanum* 的块根,名字相近但属于乌头类,含乌头碱,毒性更大。"白附子"这个名字在不同地区可能指不同的东西
- 与芋头、半夏、天南星的块茎外形相近

**有毒部位和成分**: 块茎,刺激性成分同天南星类;若是关白附,则为乌头碱类。

**中毒表现**: 口舌、咽喉麻木灼痛,流涎,喉头水肿;若误用关白附,出现口唇四肢发麻、心律失常等乌头碱中毒表现。

### 2.7 巴豆

**来源**: 大戟科植物巴豆 *Croton tiglium* 的干燥成熟果实,有毒部分主要是其中的种子。产四川、云南、广西、广东等地。

**识别要点**:
- 植株: 灌木或小乔木;叶卵形,边缘有细锯齿,叶基部有2个腺体
- 果实: 卵圆形,有3条钝棱,内分3室,每室1粒种子
- 种子: 略扁的椭圆形,长约1-1.5 cm,表面棕色或灰棕色;种仁黄白色,富含油质

**常被误认成**: 种子外形像小坚果、蓖麻子或某些豆类,儿童可能误食。

**有毒部位和成分**: 种子,尤其是种子中的**巴豆油**(含巴豆醇酯类,是强烈的刺激物和泻剂,动物实验有促癌作用)和巴豆毒蛋白。

**中毒表现**:
- 口腔、咽喉、食道烧灼感,剧烈腹痛,频繁水样或血样腹泻
- 严重脱水、休克;毒蛋白可引起溶血、肾损害
- 皮肤接触巴豆油引起红肿、起疱,入眼可严重灼伤

### 2.8 甘遂

**来源**: 大戟科植物甘遂 *Euphorbia kansui* 的干燥块根。产陕西、山西、河南、甘肃等地。

**识别要点**:
- 植株: 多年生草本,折断有白色乳汁(大戟属的共同特征);叶互生,线状披针形;顶端伞状分枝,杯状聚伞花序
- 块根: 椭圆形、长圆柱形或连珠状(像一串念珠);表面类白色或黄白色,凹陷处有残留的棕色外皮;断面粉性,白色

**常被误认成**: 连珠状块根有时被当作其他"根类补药"或野生山药类。

**有毒部位和成分**: 块根,含甘遂萜酯类等二萜酯和三萜类,对胃肠道黏膜有强烈刺激。

**中毒表现**: 剧烈腹痛、频繁腹泻(可呈水样)、恶心呕吐,严重脱水、电解质紊乱、血压下降;乳汁接触皮肤引起红肿、起疱。

### 2.9 京大戟与红大戟

**来源**:
- 京大戟: 大戟科植物大戟 *Euphorbia pekinensis* 的干燥根
- 红大戟: 茜草科植物红大戟 *Knoxia valerianoides* 的干燥块根
- 两者名字相同、科属不同,是两种药材

**识别要点**:
- 京大戟植株: 草本,高30-80 cm,**折断有白色乳汁**;叶互生,长圆状披针形;顶生伞状聚伞花序。根呈不规则长圆锥形,表面灰棕色或棕褐色,有纵皱纹;质坚硬,断面类白色或淡黄色,纤维性
- 红大戟: 块根略呈纺锤形,表面红褐色或红棕色,质坚实,断面皮部红褐色,木部棕黄色

**常被误认成**: 大戟属植物种类很多(如泽漆、乳浆大戟、猫眼草),在路边、田野极为常见,外形近似,都有乳汁、都有毒,不要采来做野菜。

**有毒部位和成分**: 京大戟全株有毒,根和乳汁毒性大,含二萜酯类等刺激性成分;红大戟毒性较弱。

**中毒表现**: 咽喉肿痛、剧烈腹痛、呕吐、腹泻,脱水,严重时血压下降;乳汁入眼可致严重结膜炎甚至失明,接触皮肤引起红肿起疱。

```
✓ 野外遇到折断有白色乳汁的草本,一般不要采食,也别让乳汁沾到眼睛
  (注意: 蒲公英、苦荬菜等可食野菜也有白色乳汁,
   所以"有乳汁"只是提醒你小心,不是判断可食与否的依据)
```

### 2.10 芫花

**来源**: 瑞香科植物芫花 *Daphne genkwa* 的干燥花蕾。分布于长江流域及以南各省和山东、河南、陕西等地的路旁、山坡。

**识别要点**:
- 植株: 落叶灌木,高约0.3-1 m;**早春先开花后长叶**,淡紫色或淡紫红色的小花簇生在去年生枝条上
- 花蕾: 常3-7朵簇生于短花轴上;单个花蕾呈棒槌状,稍弯曲,长约1-1.7 cm;花被筒表面淡紫色或灰绿色,密被短柔毛;质软,气微,味甘、微辛

**常被误认成**: 早春开紫花的灌木,外形和丁香、紫荆的花接近,有人误采当花茶或野菜。

**有毒部位和成分**: 全株有毒,花蕾和根皮毒性较大,主要是芫花酯类二萜原酸酯,刺激性强,可兴奋子宫(孕妇禁用)。

**中毒表现**: 恶心、剧烈呕吐、腹痛腹泻,头晕、头痛,严重时脱水、抽搐;孕妇可致流产。

### 2.11 狼毒

**来源**: 药典的狼毒是大戟科植物月腺大戟 *Euphorbia ebracteolata* 或狼毒大戟 *Euphorbia fischeriana* 的干燥根。

**识别要点**:
- 月腺大戟、狼毒大戟: 多年生草本,有白色乳汁;根粗大肥厚,圆锥形或纺锤形;横切面有黄褐色同心环纹(大戟属特征)
- **瑞香狼毒**(瑞香科 *Stellera chamaejasme*): 北方草原和高原极常见,也俗称"狼毒""断肠草",顶端开一团团红白色小花的球状花序;根粗大,同样有毒,但不是药典的狼毒

**常被误认成**: 根粗大肉质,易被当成野生"人参""萝卜"类;草原上的瑞香狼毒偶有被牲畜和儿童误食。

**有毒部位和成分**: 根(全株有毒),含二萜类等刺激性成分。

**中毒表现**: 口腔咽喉灼痛、剧烈呕吐、腹痛腹泻,头晕、乏力,严重时抽搐、昏迷;乳汁或汁液接触皮肤引起红肿起疱。

### 2.12 千金子

**来源**: 大戟科植物续随子 *Euphorbia lathyris* 的干燥成熟种子。各地有栽培,也逸为野生;有人把植株当作"驱鼠草"种在院子里。

**识别要点**:
- 植株: 二年生草本,茎直立粗壮,有白色乳汁;**叶交互对生,线状披针形,排成整齐的"十"字形四列**,很有特点
- 种子: 椭圆形或倒卵形,长约5 mm;表面灰棕色或灰褐色,有不规则网状皱纹,一侧有纵沟状种脊;种仁白色或黄白色,富油质

**常被误认成**: 种子像芝麻、紫苏子或小粒豆类,儿童可能误食。

**有毒部位和成分**: 全株有毒,种子毒性最大,含千金子甾醇和大戟二萜醇酯类,刺激胃肠。

**中毒表现**: 头晕、恶心、剧烈呕吐、腹痛腹泻,心慌、出冷汗、血压下降,严重时脱水、休克。

### 2.13 商陆

**来源**: 商陆科植物商陆 *Phytolacca acinosa* 或垂序商陆(美洲商陆) *Phytolacca americana* 的干燥根。商陆分布广;垂序商陆原产北美,现在已在城乡荒地、路边、林缘大量蔓延,极为常见。

**识别要点**:
- 植株: 高大草本,高约1-2 m,茎粗壮、多分枝,**茎常带紫红色**;叶大,椭圆形,全缘
- 花果: 总状花序;果实为扁球形浆果,成熟时紫黑色,一串串很像葡萄;**垂序商陆的果穗下垂**,商陆的果穗直立
- 根: 粗壮肉质,圆锥形,常有分叉,外皮淡黄色或灰褐色;**横切面有多层同心环纹(俗称"罗盘纹")**,这是很重要的识别点
- 药材: 横切或纵切的片,切面浅黄棕色或黄白色,横切片可见多个凹凸不平的同心环,纵切片可见凹凸的纵条纹

**常被误认成**:
- **人参**、"土人参"、野萝卜: 根粗大分叉、有人形,被当作野生人参泡酒、炖汤(对比见[4.4](#44-商陆-vs-人参))
- 果实被儿童当野葡萄采食;嫩叶被当野菜

**有毒部位和成分**: 全株有毒,根和未熟果实毒性最大,主要是商陆皂苷类和商陆毒素。

**中毒表现**(常在食后半小时至3小时内出现): 恶心、剧烈呕吐、腹痛腹泻,头晕、头痛、言语不清、站立不稳,严重时抽搐、昏迷、血压下降、呼吸抑制。

### 2.14 雷公藤

**来源**: 卫矛科植物雷公藤 *Tripterygium wilfordii* 的根(全株有毒)。分布于长江以南各省的山地林缘、灌丛。在部分地区也被叫作"黄藤""断肠草""菜虫药"。

**识别要点**:
- 植株: 落叶藤本灌木,长可达数 m;小枝棕红色,有4-6条细棱,密生瘤状皮孔和锈色短毛
- 叶: 互生,椭圆形或宽卵形,边缘有细锯齿
- 花果: 圆锥花序,花小,黄白色;**果实有3片膜质翅,像一个小螺旋桨**,成熟时红褐色
- 根: 外皮橙黄色至橙红色,木部淡黄白色

**常被误认成**: 民间自采泡"风湿药酒";嫩芽被误当野菜;以雷公藤为主要蜜源的蜂蜜(所谓"醉蜜")也曾引起中毒。

**有毒部位和成分**: 全株有毒,根皮、嫩芽、花毒性大。主要毒性成分为雷公藤甲素等二萜类和雷公藤碱等生物碱。**治疗剂量和中毒剂量非常接近**,临床使用的雷公藤制剂也要在医生监测下用。

**中毒表现**:
- 急性: 剧烈呕吐、腹痛、腹泻(可带血),头晕、乏力,心律失常、血压下降,少尿、无尿(急性肾衰竭),可致死
- 长期用: 肝损伤、白细胞和血小板减少、月经紊乱和闭经、男性精子减少(生殖毒性)

```
❌ 不要自采雷公藤泡酒治风湿
❌ 来路不明的野生蜂蜜,吃后口麻、恶心、心慌 → 立即就医
```

### 2.15 闹羊花

**来源**: 杜鹃花科植物羊踯躅 *Rhododendron molle* 的干燥花。分布于长江流域及华南的山坡、灌丛。名字的来历是"羊吃了会踯躅(走路蹒跚)而死"。

**识别要点**:
- 植株: 落叶灌木,高约0.5-2 m;叶长椭圆形,背面有灰白色柔毛
- 花: 春季开花,**金黄色的大漏斗形花**,常多朵集生在枝顶,花冠5裂,上方一片裂片内侧有绿色斑点;雄蕊5枚,与花冠近等长
- 药材: 花多脱落皱缩,灰黄色至黄褐色;花冠漏斗状,雄蕊5,花丝卷曲

**常被误认成**: 野生杜鹃花有的地方会采来焯水当菜(映山红),黄色的闹羊花被一并采食;花还会被误当黄花菜。

**有毒部位和成分**: 全株有毒,花和果实毒性最大,含木藜芦毒素类(梫木毒素)。

**中毒表现**: 恶心、呕吐、流涎,口唇和四肢发麻,头晕、视物模糊、乏力,**心跳明显变慢、血压下降**,严重时休克、呼吸抑制。

```
❌ 不要采食黄色杜鹃花;不确定的野生杜鹃花一律不吃
```

### 2.16 洋金花(曼陀罗)

**来源**: 药典的洋金花是茄科植物白花曼陀罗 *Datura metel* 的干燥花。同属的曼陀罗 *Datura stramonium* 全国各地的荒地、路边、村旁极其常见,毒性相同。

**识别要点**:
- 植株: 一年生粗壮草本,高约0.5-1.5 m;叶大,宽卵形,边缘有不规则波状浅裂;**叶揉碎有难闻的气味**
- 花: 单生,**大型喇叭状(长约10-20 cm),白色或淡紫色**,花冠顶端有5个尖角
- 果实: 卵圆形或球形蒴果,**表面密生硬刺**(像一个小刺球,俗称"狗核桃"),成熟后4瓣裂开,里面有许多黑褐色或淡褐色、扁肾形的种子
- 药材洋金花: 多皱缩成条状,完整的花冠喇叭状,表面微有茸毛,烘干品质柔韧,气特异

**常被误认成**: 种子混入芝麻、豆类等粮食中;根被误当牛蒡等根菜;叶被误当野菜;花被当成观赏植物摆在家中被儿童误食;也有人用来自制"止咳平喘"烟卷(见[4.8](#48-曼陀罗-vs-茄科野菜和根菜))。

**有毒部位和成分**: 全株有毒,种子毒性最大,花次之。主要是东莨菪碱和莨菪碱(阿托品类)等托烷类生物碱。

**中毒表现**(俗称"抗胆碱能综合征",常在食后半小时至数小时内出现):
- 口干舌燥、声音嘶哑、吞咽困难,皮肤干燥潮红、无汗、发烫
- **瞳孔明显散大、怕光、看东西模糊**
- 心跳加快、体温升高、排尿困难
- 烦躁、胡言乱语、幻觉、狂躁,随后转入嗜睡、昏迷,严重时呼吸衰竭

```
医学生记忆口诀(帮助识别,不用于自行诊断):
  "干如骨、红如甜菜、热如野兔、盲如蝙蝠、疯如帽匠"
   = 皮肤口干、皮肤潮红、体温升高、瞳孔散大视物模糊、精神错乱
```

### 2.17 天仙子

**来源**: 茄科植物莨菪 *Hyoscyamus niger* 的干燥成熟种子。分布于华北、东北、西北等地的村边、田野、路旁。

**识别要点**:
- 植株: 一年或二年生草本,**全株被黏性腺毛,有特殊臭气**;叶大,边缘有不规则羽状浅裂或深裂,基部半抱茎
- 花: 花冠钟状,**淡黄色,带有明显的紫色网状脉纹**,喉部暗紫色
- 果实: 藏在宿存的瓶状花萼内的小蒴果,顶端盖裂
- 种子: 很小,类扁肾形或扁卵形,直径约1 mm;表面棕黄色或灰黄色,有细密的网纹

**常被误认成**: 种子极小,可混入其他种子类药材或粮食;根曾被误当野菜根。

**有毒部位和成分**: 全株有毒,种子毒性最大,主要成分为莨菪碱、东莨菪碱。

**中毒表现**: 同曼陀罗——口干、皮肤潮红无汗、瞳孔散大、心跳快、体温高、谵妄幻觉、昏迷。

### 2.18 藜芦

**来源**: 藜芦科(旧分类为百合科)植物藜芦 *Veratrum nigrum* 及同属多种植物的根及根茎。分布于东北、华北、西北和西南的山坡林下、草甸。

**识别要点**:
- 植株: 高大草本,高可达1 m;**茎基部被残存叶鞘撕裂成的黑褐色网状纤维**(像一圈棕毛),这是很重要的特征
- 叶: 宽大,椭圆形,**叶脉平行、叶面有明显的纵向褶皱**,像折扇
- 花: 顶生大型圆锥花序,花小,黑紫色(藜芦)或黄绿、白色(同属其他种)
- 根: 根茎短粗,下面簇生许多细长的须根

**常被误认成**: 春季嫩苗被当成**茖葱(山葱、寒葱)**、**玉簪**、**黄精、玉竹**的嫩苗采食;根被当作其他草药。

**有毒部位和成分**: 全株有毒,根和根茎毒性最大,含藜芦碱类、原藜芦碱等甾体生物碱。

**中毒表现**(食后数十分钟内出现): 口舌、咽喉灼热刺痛,流涎、剧烈恶心呕吐、腹痛,出汗、头晕,**心跳明显变慢、血压下降**,严重时心律失常、意识障碍。

```
✓ 区分茖葱: 茖葱的叶片揉碎有浓烈的葱蒜味,藜芦没有葱蒜味
✓ 不确定是不是茖葱的,一律不采
```

### 2.19 藤黄

**来源**: 藤黄科植物藤黄 *Garcinia hanburyi* 树干被割伤后流出的胶质树脂,干燥后使用。原产柬埔寨、泰国等地,也是传统绘画颜料("藤黄"色)。

**识别要点**: 呈管状或不规则块状,红黄色或橙棕色,表面有纵条纹;质脆,断面平滑、有光泽;遇水研磨成黄色乳液。

**常被误认成**: 作为国画颜料和其他用途流通,可能被儿童误食,或被当成"外用偏方"误服。

**有毒部位和成分**: 树脂,含藤黄酸等,对胃肠道刺激极强。

**中毒表现**: 剧烈腹痛、呕吐、频繁腹泻(可带血),头晕,严重脱水、休克。

```
✓ 家中有藤黄颜料的,收好,远离儿童
```

### 2.20 斑蝥

**来源**: 芫青科昆虫南方大斑蝥 *Mylabris phalerata* 或黄黑小斑蝥 *Mylabris cichorii* 的干燥虫体。夏秋季常在豆类、瓜类作物的花和叶上群集。

**识别要点**:
- 南方大斑蝥: 长圆形甲虫,体长约1.5-3 cm;头和足黑色;**鞘翅黑色,上有3条黄色或棕黄色的宽横纹**
- 黄黑小斑蝥: 外形类似,体型较小,长约1-1.5 cm
- 有特殊的臭气

**常被误认成**: 小孩当玩具抓;民间用来"拔毒"、外敷"治癣",或研粉服用"治癌"。同科的青娘虫、红娘虫也含相同毒素。

**有毒部位和成分**: 整个虫体,含斑蝥素,是强烈的发疱剂。**徒手捏碎或拍死在皮肤上,接触部位就会起水疱**。

**中毒表现**:
- 皮肤: 接触部位烧灼感、红肿,数小时后起大水疱
- 口服: 口腔、咽喉、食道烧灼起疱,剧烈呕吐(可带血)、腹痛、便血
- 尿频、尿痛、**血尿,严重时急性肾衰竭**;可出现心律失常、抽搐、昏迷

```
✓ 野外不要徒手抓黑黄相间的甲虫;落在皮肤上时轻轻吹走或抖落,不要拍
✓ 皮肤沾上了: 立即用大量清水和肥皂冲洗
```

### 2.21 蟾酥

**来源**: 蟾蜍科动物中华大蟾蜍 *Bufo bufo gargarizans* 或黑眶蟾蜍 *Bufo melanostictus* 的耳后腺和皮肤腺分泌物,经加工干燥而成。

**识别要点**:
- 蟾蜍(癞蛤蟆): 皮肤粗糙,满布大小不等的疣状突起;眼睛后方有一对明显隆起的椭圆形大腺体(耳后腺),受刺激会分泌白色浆液
- 蟾酥药材: 扁圆形团块或片状,棕褐色至红棕色;断面棕褐色,角质状,微有光泽;气微腥,**味初甜而后有持久的麻辣感(不要尝)**

**常被误认成**:
- 民间"吃癞蛤蟆治病"、把蟾蜍当牛蛙或青蛙误食
- 儿童过量服用含蟾酥的中成药(如某些咽喉用药丸)
- 浆液溅入眼睛

**有毒部位和成分**: 蟾蜍的耳后腺、皮肤、卵和内脏都有毒,主要是蟾蜍二烯羟酸内酯类(作用类似洋地黄类强心苷)和蟾蜍色胺类。

**中毒表现**(食后半小时至1小时左右出现): 恶心、呕吐、腹痛、腹泻,口唇和四肢发麻,头晕、出汗,**心跳过慢、严重心律失常(各种传导阻滞)、血压下降**,可致心跳骤停;浆液入眼引起剧痛、红肿,甚至视力损害。

```
❌ 不要吃蟾蜍和蟾蜍卵,不要用它"偏方治病"
✓ 含蟾酥的中成药要放在儿童够不着的地方,严格按说明书或医嘱用
✓ 浆液溅入眼睛: 立即用流动清水冲洗至少15分钟,然后就医
```

### 2.22 砒石与砒霜

**来源**: 砒石是天然含砷矿物(如砷华)或由毒砂、雄黄等含砷矿石加工制成,主要成分为三氧化二砷;分红砒、白砒。砒霜是砒石升华精制后的产物,白色粉末,成分为三氧化二砷。

**识别要点**: 白砒呈白色、无色或略带浅灰色的块状或粉末,红砒略带红色或黄色;砒霜为白色细粉,**无臭无味**,外观与面粉、小苏打、白糖等相似。

**常被误认成**: 与白色食品原料、药粉混淆;民间"以毒攻毒"的偏方。

**有毒部位和成分**: 三氧化二砷,剧毒,极少量可致死。加热会升华产生含砷烟雾,同样危险。

**中毒表现**:
- 急性(口服后数十分钟至数小时): 口中金属味、咽喉食道烧灼感,剧烈呕吐、腹痛,**大量水样腹泻(可呈米泔样)**,严重脱水、休克;随后可出现心律失常、肝肾损害、抽搐、昏迷
- 慢性(长期少量): 乏力、皮肤色素沉着和掌跖角化、手脚麻木刺痛(周围神经病)、贫血,长期可致皮肤癌、肺癌等

### 2.23 雄黄

**来源**: 硫化物类矿物雄黄族雄黄,主含二硫化二砷(As₂S₂)。

**识别要点**: 块状或粒状集合体,**深红色或橙红色**,条痕淡橘红色;晶面有金刚石样光泽;质脆,易碎,断面有树脂样光泽;微有特异的臭气。

**常被误认成**: 和朱砂(颜色更红、更重)外观相近;端午节民间有喝"雄黄酒"、在小孩额头涂雄黄的习俗。

**有毒部位和成分**: 硫化砷本身溶解度低,但**受热(包括火烧、加热饮用)或长时间接触空气会生成三氧化二砷(即砒霜)**,毒性大增;所含杂质中也常有可溶性砷。

**中毒表现**: 急性同砒霜中毒(呕吐、腹痛、腹泻、休克);长期少量使用可致慢性砷中毒(皮肤色素沉着、角化、神经损害)。

```
❌ 不要喝雄黄酒,尤其不要加热饮用;不要给儿童涂抹、口服雄黄
❌ 不要用雄黄驱虫、熏蒸室内
```

### 2.24 朱砂

**来源**: 硫化物类矿物辰砂族辰砂,主含硫化汞(HgS)。

**识别要点**: 粒状或块状集合体,**鲜红色或暗红色**,条痕红色至褐红色;有光泽;**体重(拿在手里比同样大小的石头沉得多)**,质脆;气微,味淡。

**常被误认成**: 被当成"安神"保健品长期服用,或做成饰品、"开光"挂件给婴幼儿佩戴、含在口中;有的劣质产品用红色染料或铅丹冒充。

**有毒部位和成分**: 硫化汞;**加热时分解释放汞蒸气,毒性剧增**(药典规定朱砂忌火煅)。长期服用,汞在体内蓄积。

**中毒表现**:
- 急性: 口腔金属味、牙龈肿痛出血、恶心呕吐、腹痛腹泻
- 慢性汞中毒: 口腔炎、牙龈出现蓝黑色线、手指和舌头震颤、易激动、失眠、记忆力下降,**肾损害(蛋白尿、肾功能下降)**
- 儿童和孕妇更敏感

```
❌ 不要长期服用含朱砂的"安神"偏方,不要给婴幼儿佩戴可接触口腔的朱砂饰品
❌ 不要加热、焚烧朱砂
```

### 2.25 轻粉、红粉与水银

**来源**:
- 轻粉: 以汞、明矾、食盐等为原料经升华制成的氯化亚汞(Hg₂Cl₂),白色有光泽的鳞片状结晶或粉末
- 红粉(红升丹): 由水银、硝石、白矾等炼制而成,主含氧化汞(HgO),橙红色片状或粉状
- 白降丹: 主含氯化汞类,传统外用丹药,腐蚀性强
- 水银: 液态金属汞

**识别要点**: 轻粉白色、遇光颜色渐变暗;红粉橙红色、体重;水银为银白色可流动的液态金属,常温下就会缓慢挥发。

**常被误认成**: 民间外用"拔毒""去腐"的药粉、治皮肤病的偏方;传统外用,但被误服或大面积外用于破损皮肤。

**有毒部位和成分**: 汞化合物和金属汞。可溶性汞盐有强烈腐蚀性;汞蒸气经呼吸道吸收。

**中毒表现**:
- 口服: 口腔、咽喉烧灼痛,剧烈呕吐、腹痛、血性腹泻,急性肾衰竭(少尿、无尿)
- 外用于大面积破损皮肤: 吸收后同样可出现汞中毒
- 吸入汞蒸气: 咳嗽、胸痛、呼吸困难,发热;长期吸入出现震颤、情绪和记忆改变

```
⚠️ 体温计等打碎后: 开窗通风,人离开房间;不要用吸尘器吸、不要用扫帚扫散,
   用硬纸片把汞珠收集到能密封的瓶子里;不要倒进下水道
```

### 2.26 铅丹

**来源**: 用金属铅加工制成的四氧化三铅(Pb₃O₄),又名黄丹、广丹、章丹;过去用来熬制传统外用黑膏药。同类的还有密陀僧(氧化铅)。

**识别要点**: 橙红色或橙黄色粉末,**体很重**,不溶于水;质地细腻,手捻有滑腻感。

**常被误认成**: 掺入劣质朱砂、"红丹"偏方;个别民间偏方口服治癫痫、"安神"。

**有毒部位和成分**: 铅化合物,在体内蓄积。

**中毒表现**:
- 腹部阵发性剧烈绞痛("铅绞痛")、便秘、食欲差
- 贫血、面色苍白,牙龈边缘出现蓝灰色"铅线"
- 头痛、乏力、手腕下垂(周围神经损害)
- **儿童对铅极敏感,可造成智力和行为的长期损害**

```
❌ 不要口服任何含铅、含汞、含砷的"偏方"
✓ 来路不明的"秘方""祖传药丸""排毒药粉"可能含重金属;
  长期吃过的,告诉医生,查血铅、尿汞、尿砷
```

## 三、含马兜铃酸的药材

### 3.1 马兜铃酸为什么危险

马兜铃酸主要存在于马兜铃科马兜铃属植物中。它的危害和前面那些"吃了马上出事"的毒物不一样:

```
- 急性中毒表现常不明显,很多人"吃了一段时间也没什么感觉"
- 但会造成肾小管和肾间质的损害(称为"马兜铃酸肾病"),
  可在用药后数月至数年发展为慢性肾衰竭,需要透析或换肾,且损害不可逆
- 已被确认是人类致癌物,与上尿路(肾盂、输尿管)癌和膀胱癌相关,
  也有研究提示与肝癌有关
- 剂量越大、用得越久,风险越高;但没有公认的"安全剂量"
- 损害可以在停药后继续发展
```

### 3.2 品种与现状

| 药材 | 来源 | 现状 | 常与之同名或混用的品种 |
|------|------|------|----------------------|
| 关木通 | 马兜铃科东北马兜铃 *Aristolochia manshuriensis* 的藤茎 | 2003年起国家取消其药用标准 | 木通(木通科)、川木通(毛茛科) |

| 马兜铃 | 马兜铃或北马兜铃 *A. contorta* 的果实 | 2020年版药典已不再收载 | — |

```
✓ 正规药房现在用的"木通"是木通科的木通,"防己"是防己科的粉防己,
  "木香"是菊科的木香——自己在市场、网上买的不能保证
✓ 长期服用过含这些药材的"偏方""减肥茶""排石茶"的,告诉医生,定期查肾功能和尿常规
```

### 3.3 细辛: 只用根和根茎

细辛是马兜铃科植物北细辛 *Asarum heterotropoides* var. *mandshuricum*、汉城细辛 *A. sieboldii* var. *seoulense* 或华细辛 *A. sieboldii* 的干燥根和根茎。

- 过去细辛常常全草入药。研究发现**马兜铃酸主要集中在地上部分(叶)**,根和根茎含量很低,所以从2005年版药典起,细辛的药用部位改为**只用根和根茎**,2020年版沿用
- 细辛本身药典标注"有小毒",含挥发油(黄樟醚等),过量可引起头痛、呕吐、烦躁、抽搐、呼吸抑制
- 自己在山里采的"细辛"往往是带叶的全草,还可能是同属其他种(杜衡、土细辛等)——**不要自采自用**

### 3.4 怎样认出马兜铃科植物

不要求你据此辨认药材,只是为了野外遇到时知道"这是一类要避开的植物":

- **马兜铃属**: 多为缠绕藤本;叶互生,心形或三角状心形;**花形非常特别——花被管弯曲成烟斗形或喇叭形,基部膨大成球状**;果实为下垂的蒴果,成熟后像倒挂的小铃铛或降落伞
- **细辛属**: 矮小草本,贴地生长;叶1-2片,心形或肾形,有长柄;花单生在叶柄基部,贴近地面,紫褐色,壶形或钟形,常被落叶盖住;全株有辛辣气味

### 4.1 对照总表

这是本章的重点。**下面的区分要点用来帮助你"排除",不能用来"确认能吃能用"**——只要有一点不确定,就不采、不吃、不用。

| 见 | 有毒植物 | 常被误认成 | 一眼能看的区别 | 中毒后果 |
|---|---------|-----------|---------------|---------|
| [4.2](#42-钩吻-vs-金银花) | 钩吻(断肠草) | 金银花、五指毛桃、鸡血藤等 | 钩吻花为整齐5裂的黄色小漏斗、多朵聚生;金银花花冠唇形、成对生、初白后黄 | 数十分钟至数小时内呼吸麻痹死亡 |

| [4.4](#44-商陆-vs-人参) | 商陆 | 人参 | 商陆根横切有同心环纹,植株高大、紫黑色浆果串 | 呕吐、抽搐、昏迷 |

| [4.6](#46-香加皮-vs-五加皮) | 香加皮 | 五加皮 | 香加皮有浓烈特异香气;五加皮气微香 | 强心苷中毒、心律失常 |
| [4.7](#47-关木通-vs-川木通广防己-vs-粉防己) | 关木通 | 川木通、木通 | 关木通断面黄色,导管孔排成多层整齐环 | 马兜铃酸肾病、致癌 |

### 4.2 钩吻 vs 金银花

**钩吻**(断肠草、大茶药、胡蔓藤): 钩吻科(旧归马钱科)植物 *Gelsemium elegans*,分布于浙江、福建、江西、湖南、广东、广西、贵州、云南等南方各省的山坡、灌丛、林缘。**我国毒性最强的植物之一,吃几片嫩叶就可能致死。**

| 特征 | 钩吻(有毒) | 金银花(忍冬) |
|------|-----------|-------------|
| 茎 | 光滑无毛 | 幼枝常有柔毛 |
| 叶 | 对生,卵状披针形,**光滑无毛**,较薄 | 对生,卵形或长圆形,**两面常有柔毛** |
| 花序 | 多朵花聚成顶生或腋生的聚伞花序 | **两朵花并生在一个花梗上**(所以叫"金银花"、"鸳鸯藤") |
| 花形 | **漏斗状,花冠顶端整齐5裂**,像小喇叭 | **唇形**: 花冠上方4裂成一片、下方1裂成一片,像张开的嘴 |
| 花色 | **只有黄色** | 初开白色,后变黄色,同一株上常黄白并存 |
| 雄蕊 | 藏在花冠内 | 明显伸出花冠外 |
| 花期 | 约5-11月,南方有的冬季仍开花 | 约4-6月,有的地方秋季再开一茬 |

**两者花期重叠,不能靠花期区分**,要同时看花形、花序和叶片有没有毛。

**其他误认**:
- 南方煲汤用的**五指毛桃**(粗叶榕的根)、**鸡血藤**等根或藤茎,和钩吻的根或藤茎同生一处,采挖时混入,已多次造成全家中毒。五指毛桃的根有奶香气,切开有白色乳汁;但**根和藤一旦切片晒干,普通人就几乎无法区分**
- "断肠草"是一个俗名,不同地方还指雷公藤、瑞香狼毒、紫堇等多种有毒植物

**有毒成分**: 全株有毒,嫩叶和根毒性最大,含钩吻素子、钩吻碱等多种吲哚类生物碱。

**中毒表现**(食后数十分钟内出现): 头晕、眼花、视物重影、**眼睑下垂、瞳孔散大**,言语不清、吞咽困难、四肢无力、站立不稳,随后呼吸困难,可在数小时内因呼吸肌麻痹死亡。

```
✓ 南方山区: 不要自挖五指毛桃、鸡血藤及各种"煲汤草根",从正规渠道购买
✓ 不确定是不是金银花的藤,不采花、不采叶
✓ 喝了自采草药汤、药酒后出现视物重影、眼皮抬不起来、说话不清 → 立即拨打120
```

正品金银花和忍冬藤的识别见[花叶类-金银花](05-花叶类.md#11-金银花)、[皮类与藤木类-忍冬藤](06-皮类与藤木类.md#35-忍冬藤)。

### 4.3 毒芹 vs 水芹、野胡萝卜

**毒芹**: 伞形科植物 *Cicuta virosa*,分布于东北、华北、西北等地的沼泽、水边、湿草地。**伞形科里有毒的不止毒芹**,还有毒参(*Conium maculatum*,茎上有紫红色斑点,揉碎有鼠尿样臭味)、水毒芹等。

| 特征 | 毒芹(有毒) | 水芹(可食) | 野胡萝卜(南鹤虱) |
|------|-----------|-----------|----------------|
| 植株 | 高大,可达1 m以上,直立 | 矮小,茎匍匐或斜升,高约20-60 cm | 高约0.5-1 m,茎有粗硬毛 |
| 根 | **根状茎粗短,纵切开可见多个横隔空腔(一格一格的),切口流出淡黄色汁液** | 须根,节上生根 | 细长的肉质直根,像小胡萝卜,有胡萝卜气味 |
| 叶 | 2-3回羽状复叶,小叶狭长披针形,边缘有锯齿 | 1-2回羽状复叶,小叶卵形 | 2-3回羽状深裂,裂片细 |
| 气味 | 无芹菜清香,有的有不愉快气味 | **有芹菜清香** | 胡萝卜味 |
| 茎 | 中空,有时基部带紫色 | 中空 | 有毛 |

**有毒成分**: 全株有毒,根状茎毒性最强,含毒芹素(一种多炔醇类),作用于中枢神经。

**中毒表现**(食后数十分钟至2小时内出现): 口腔咽喉烧灼感、流涎、恶心呕吐、腹痛,头晕,随后**剧烈的全身抽搐**,呼吸困难,可因呼吸衰竭死亡。

```
✓ 区分要点只能帮你排除,不能保证可食
✓ 不要采食任何野生的、开白色伞状小花、叶子像芹菜或胡萝卜的植物
✓ 想吃水芹: 自己种,或买市场上的栽培水芹
```

### 4.4 商陆 vs 人参

| 特征 | 商陆(有毒) | 人参 |
|------|-----------|------|
| 植株 | 高大草本,高1-2 m,茎粗壮、常紫红色 | 矮小草本,高约30-60 cm |
| 叶 | 单叶,大,椭圆形,互生 | **掌状复叶**,通常3-6片轮生于茎顶,每片复叶有5片小叶 |
| 果实 | 一串串紫黑色浆果,像葡萄 | 顶生伞形花序,结一簇**鲜红色**小浆果 |
| 根的外形 | 粗大肉质,圆锥形,多分叉,外皮淡黄或灰褐色,无芦头 | 主根纺锤形或圆柱形,**上端有"芦头"(根茎)和茎痕**,表面有细密横纹,须根上有小疣状突起("珍珠点") |
| 根的横切面 | **有多层同心环纹** | 有一圈棕黄色的形成层环,皮部有棕黄色小点 |
| 分布 | 城乡荒地、路边极常见 | 野生人参极稀少(东北深山老林),是国家重点保护野生植物 |

```
✓ 在路边、荒地、村旁挖到的"人参",几乎可以肯定不是人参
✓ 野生人参受国家保护,即使见到也不能采挖
✓ 市场上的"土人参"可能是栌兰(马齿苋科的土人参,可食),
  也可能是商陆根——不要买来泡酒
```

### 4.5 菊三七(土三七) vs 三七

| 特征 | 菊三七(有毒) | 三七 |
|------|-------------|------|
| 科 | 菊科 *Gynura japonica* | 五加科 *Panax notoginseng* |
| 叶 | 互生,**羽状深裂**,叶面常带紫色,略肉质 | **掌状复叶**,3-4片轮生于茎顶,每片5-7片小叶 |
| 花 | **黄色或橙黄色的头状花序**(像小绒球) | 顶生伞形花序,花小,淡黄绿色 |
| 果实 | 带白色冠毛的瘦果 | **鲜红色**浆果 |
| 根 | 拳头状块根,表面灰棕色或棕黄色,有瘤状突起;断面淡黄色 | 主根类圆锥形,表面灰褐色或灰黄色,有支根痕和瘤状突起;**体重质坚,断面灰绿、黄绿或灰白色**,味苦回甜 |
| 来源 | 很多人家院子、花盆里种的"三七""土三七""血三七" | 主要为云南、广西人工栽培,野生极少 |

**有毒成分**: 菊三七含吡咯里西啶类生物碱,损伤肝脏的小血管,引起**肝窦阻塞综合征**。

**中毒表现**: 多见于长期或大量用"土三七"泡酒、炖汤、打粉服用的人,数周至数月后出现腹胀、腹水、肝区疼痛、肝脏肿大、黄疸,严重时肝衰竭。

```
❌ 不要用自家种的"三七""土三七"泡酒、炖汤、打粉吃
✓ 院子、花盆里那种叶子羽状裂、开黄色或橙色小绒球花的"三七",就是菊三七
✓ 另有景天科的"景天三七"(费菜,开黄色星形小花,叶肉质),也常被叫"土三七",
  它与菊三七不是一种植物——这正说明俗名靠不住
```

正品三七的识别见[根及根茎类(上)-三七](01-根及根茎类上.md#28-三七)。

### 4.6 香加皮 vs 五加皮

| 特征 | 香加皮(北五加皮,有毒) | 五加皮(南五加皮) |
|------|---------------------|-----------------|
| 来源 | 萝藦科(新分类归夹竹桃科)植物杠柳 *Periploca sepium* 的根皮 | 五加科植物细柱五加 *Eleutherococcus nodiflorus* 的根皮 |
| 形状 | 卷筒状或槽状,少数呈不规则块片;**外表面灰棕色或黄棕色,栓皮松软,常呈鳞片状、易剥落** | 不规则卷筒状;外表面灰褐色,有稍扭曲的纵皱纹和横长皮孔样斑痕 |
| 内表面 | 淡黄色或淡黄棕色,较平滑,有细纵纹 | 淡黄色或灰黄色,有细纵纹 |
| 断面 | 不整齐,黄白色 | 不整齐,灰白色 |
| **气味** | **有浓烈的特异香气**,味苦 | 气微香,味微辣而苦 |
| 植株 | 落叶缠绕藤本,折断有白色乳汁;叶对生、披针形、光滑;花紫红色 | 灌木,枝上有刺,掌状复叶 |

**有毒成分**: 香加皮含杠柳毒苷等**强心苷**,作用类似洋地黄。

**中毒表现**: 恶心、呕吐、腹泻,头晕、视物模糊(看东西发黄或发绿),**心跳过慢或心律失常**,严重时心跳骤停。正在服用地高辛等强心药的人风险更大。

```
❌ 不要自己买"五加皮"泡药酒;香加皮是常见的冒充或混用品
✓ 闻到一股浓烈的特殊香味(有人形容像冬青油)的"五加皮",很可能是香加皮
```

### 4.7 关木通 vs 川木通、广防己 vs 粉防己

**木通类**:

| 特征 | 关木通(含马兜铃酸,已禁用) | 川木通 | 木通 |
|------|-------------------------|--------|------|
| 来源 | 马兜铃科东北马兜铃的藤茎 | 毛茛科小木通 *Clematis armandii* 或绣球藤 *C. montana* 的藤茎 | 木通科木通、三叶木通或白木通的藤茎 |
| 外表 | 灰黄色或棕黄色,有浅纵沟和棕褐色残留粗皮斑点;节部稍膨大 | 黄棕色或黄褐色,有纵向凹沟和棱线;节处多膨大 | 灰棕色至灰褐色,有不规则裂纹或纵沟纹,有突起的皮孔 |
| 断面 | **黄色或淡黄色,木部宽广,导管孔多数、排列成多层整齐的环**,射线放射状(像蜘蛛网) | 边缘不整齐,木部浅黄棕色,有黄白色放射状纹理和裂隙,导管孔密布,中央有髓 | 木部黄白色,射线呈放射状排列,髓小或有时中空 |
| 气味 | 摩擦残余粗皮有樟脑样气味,味苦 | 气微,味淡 | 气微,味微苦而涩 |

**防己类**: 广防己(马兜铃科,含马兜铃酸)和粉防己(防己科,药典的"防己")都是圆柱形或块状的根,断面都有粉性和放射状纹理,**肉眼很难区分**。粉防己断面灰白色、射线稀疏("车轮纹");广防己断面灰白色、灰棕色与类白色相间排列成放射状。这类区分属于专业鉴定内容,普通人只要记住: **名字里有"防己"的药材,只从正规药房、凭处方用。**

### 4.8 曼陀罗 vs 茄科野菜和根菜

曼陀罗和茄子、辣椒、番茄、龙葵、枸杞同属茄科,幼苗和叶片有相似之处。

| 误认情形 | 区别 |
|---------|------|
| 幼苗、嫩叶当野菜(像茄子苗、龙葵苗) | 曼陀罗叶大、边缘有不规则的大波状浅裂,**揉碎有浓烈难闻气味**;龙葵叶较小、近全缘或有浅波状齿,无难闻气味——龙葵本身未熟果也有毒,同样不建议采食 |
| 根被误当牛蒡根、山药 | 牛蒡根外皮褐色、断面白色、有牛蒡特有的泥土清香,地上部分叶极大、心形、背面有白色绵毛;曼陀罗根木质化,地上部分有喇叭花和刺球果。挖根时一定要看清地上部分 |
| 种子混入芝麻、豆类等粮食 | 曼陀罗种子扁肾形,约3-4 mm,黑褐色或淡褐色,表面有细小的凹凸或网纹;芝麻种子扁卵形、光滑。收获粮食时注意田间是否有曼陀罗 |
| 花当成"金针花""百合"或观赏花 | 曼陀罗花单生,长约10-20 cm的大喇叭,顶端有5个尖角 |

### 4.9 乌头 vs 野芹类野菜

乌头属植物春天刚长出的幼苗和嫩叶,和山芹、野芹菜以及银莲花属的一些野菜(如二轮草)在不开花时比较像,国外有采野菜误采乌头导致死亡的事例。

| 特征 | 乌头(有毒) | 山芹、野芹类 |
|------|-----------|------------|
| 叶形 | **掌状**3深裂或全裂(从叶柄一个点向外分出),裂片再分裂 | **羽状**复叶(小叶沿叶轴两侧排列) |
| 气味 | 揉碎**没有芹菜香** | 有芹菜清香 |
| 地下部分 | **块根**,形如小芋头或倒圆锥形,常两个相连(母根和子根) | 直根或须根 |
| 花 | 蓝紫色(少数黄色、白色),**像头盔或僧帽** | 白色小花,排成伞形花序 |

```
✓ 乌头幼苗和野菜混生在一起时,一棵误混进去就足以致命——
  采野菜时一棵一棵确认,不要成把割
```

### 4.10 苍耳幼苗和苍耳子

**苍耳**: 菊科植物 *Xanthium strumarium*(药典名为 *X. sibiricum*),全国各地的荒地、路边、田野极常见。苍耳子(带总苞的果实)药典标注"有毒"。

**识别要点**:
- 成株: 一年生草本,高约0.2-1 m;叶互生,三角状卵形或心形,边缘有不规则粗锯齿,两面粗糙
- 果实: **椭圆形或纺锤形,表面密生带钩的硬刺,常粘在衣服、动物毛上**,长约1-1.5 cm,内有2粒瘦果
- 幼苗: 刚出土时只有两片肥厚的长椭圆形子叶,像大号豆芽

**常被误认成**: 幼苗被当成野菜或豆芽;苍耳子被儿童当零食嚼食;自己炒苍耳子泡水"治鼻炎"。

**有毒成分**: 全株有毒,**果实(种子)和两片子叶期的幼苗毒性最大**,含苍术苷、羧基苍术苷等,主要损害肝脏。

**中毒表现**(食后数小时至2-3天出现): 恶心、呕吐、腹痛、乏力、嗜睡,**低血糖**,黄疸、肝脏肿大(急性肝衰竭),严重时抽搐、昏迷、死亡。

### 4.11 白果(银杏种子)生食或多食

**来源**: 银杏科植物银杏 *Ginkgo biloba* 的成熟种子。药典标注"有毒"。

**识别要点**: 外层是有臭味的黄色肉质种皮(外种皮,接触可引起皮炎);里面是白色坚硬、两侧有棱的"白果"(中种皮);再里面是淡黄绿色的种仁。

**常被误认成**: 当作零食炒着吃、烤着吃,或炖汤、煮粥时一次放很多;儿童更易中毒。

**有毒成分**: 种仁(尤其是生的和胚芽)含银杏毒素(4'-O-甲基吡哆醇)等,干扰维生素B6的作用,引起神经兴奋;外种皮含银杏酸,刺激皮肤。

**中毒表现**(食后1-12小时出现): 呕吐、腹痛、腹泻,烦躁不安、惊厥、抽搐,严重时昏迷、呼吸衰竭。**熟的白果吃多了同样会中毒**,儿童吃几粒到十几粒就可能出现症状。

```
❌ 不要生吃白果;儿童不要把白果当零食
✓ 捡拾银杏果时戴手套,外种皮的汁液会引起皮肤红肿瘙痒
```

银杏叶的识别和注意事项见[花叶类-银杏叶](05-花叶类.md#62-银杏叶)。

### 4.12 苦杏仁

**来源**: 蔷薇科植物山杏、西伯利亚杏、东北杏或杏的干燥成熟种子。药典标注"有小毒"。

**识别要点**: 扁心形,长约1-1.9 cm,一端尖、一端钝圆而厚、左右不对称;种皮黄棕色至深棕色;**味苦**。超市卖的零食杏仁大多是"甜杏仁"(或美国大杏仁,实为扁桃仁),较大而扁、味不苦。

**常被误认成**: 当甜杏仁、零食吃,或自己砸开杏核吃里面的仁;桃仁、枇杷仁、生木薯、李子仁也有类似毒性。

**有毒成分**: 苦杏仁苷,在体内分解释放**氢氰酸(氰化物)**。

**中毒表现**(食后半小时至数小时出现): 口中苦涩、流涎、恶心、呕吐、头晕、头痛、心慌,呼吸急促,严重时意识丧失、抽搐、呼吸停止。儿童吃十几粒苦杏仁就可能严重中毒。

```
❌ 不要生吃苦杏仁、桃仁、杏核仁、枇杷核仁
✓ 尝到明显苦味的"杏仁",吐出来,不要再吃
```

### 4.13 蓖麻子

**来源**: 大戟科植物蓖麻 *Ricinus communis* 的干燥成熟种子。药典标注"有毒"。蓖麻在各地广泛栽培和逸生。

**识别要点**:
- 植株: 高大草本或小乔木状;**叶极大、掌状5-11深裂**,叶柄盾状着生;茎常带紫红色、有白粉
- 果实: 卵球形蒴果,外面有软刺
- 种子: **椭圆形,略扁,长约1 cm;表面光滑,有灰白色与黑褐色或红棕色相间的花斑纹,像小豆子或蜱虫;一端有白色海绵状的突起(种阜)**

**常被误认成**: 好看的花斑被儿童当豆子、坚果吃,或做成手工饰品。

**有毒成分**: 种子含**蓖麻毒蛋白**,毒性极强;咬碎、嚼烂后吃下最危险。

**中毒表现**(潜伏期数小时,也可长达1-3天): 口咽烧灼感、恶心、剧烈呕吐、腹痛、严重腹泻(可带血),脱水、休克,随后可出现肝、肾等多器官衰竭。

```
⚠️ 嚼碎吃了蓖麻子,哪怕只有一两粒、暂时没症状,也要立即就医
```

### 4.14 相思子

**来源**: 豆科植物相思子 *Abrus precatorius* 的种子。分布于广东、广西、云南、台湾等地,种子常被做成手串、项链出售。

**识别要点**:
- 植株: 缠绕藤本;偶数羽状复叶,小叶很多、小而长圆形
- 种子: **椭圆形,长约5-7 mm,大部分鲜红色、有光泽,一端(种脐周围)为黑色**
- 区别"红豆": **海红豆**(孔雀豆)种子全红无黑斑、心形扁圆;**红豆树**的种子全红、较大;**赤小豆**暗红色、长圆形、种脐为白色线状

**常被误认成**: 当"红豆""相思豆"送人、穿饰品;儿童放进嘴里咬。

**有毒成分**: 种子含**相思子毒蛋白**,毒性与蓖麻毒蛋白相当或更强。种皮坚硬完整时吞下多可原样排出,**咬碎或钻孔后就很危险**(手工钻孔时也要防止粉末接触伤口和眼睛)。

**中毒表现**: 同蓖麻子——数小时至数天后出现剧烈呕吐、腹泻(可带血)、脱水、休克,肝肾损害、抽搐。

```
✓ 带红黑两色种子的手串、饰品,不要给儿童玩
```

### 4.15 夹竹桃

**来源**: 夹竹桃科植物夹竹桃 *Nerium oleander*。南北各地作为绿化植物广泛种植在道路、公园、学校。

**识别要点**:
- 常绿大灌木;**叶3片轮生(少数对生),狭长披针形,厚革质,中脉明显,侧脉细密、平行、几乎与中脉垂直**
- 花: 顶生聚伞花序,粉红色、红色、白色或黄色,花冠5裂,有的重瓣
- 果实: 细长的蓇葖果,种子有毛
- 折断有白色乳汁

**常被误认成**: 叶被当成柳叶、竹叶泡茶;枝条被当成烧烤签子、筷子;花被儿童采摘吸吮。

**有毒成分**: 全株有毒(叶、花、种子、枝干、乳汁),含夹竹桃苷等**强心苷**。**焚烧枝叶产生的烟也有毒**。

**中毒表现**: 恶心、呕吐、腹痛、腹泻,头晕、视物模糊,**心跳过慢、严重心律失常**,可致心跳骤停。

```
❌ 不要用夹竹桃枝条串烤肉、当筷子,不要焚烧夹竹桃枝叶取暖做饭
✓ 修剪夹竹桃时戴手套,手洗干净再吃东西
```

### 4.16 海芋 vs 芋头

**海芋**: 天南星科植物海芋 *Alocasia odora*(常被称为"滴水观音",与同属的观赏种常混称),南方山谷、林下、村边野生,北方常作盆栽。

| 特征 | 海芋(有毒) | 芋头(可食) |
|------|-----------|-----------|
| 叶柄着生位置 | 叶柄连在**叶片基部的缺口处**(叶片呈箭头形,基部两片裂开) | **盾状着生**: 叶柄连在叶片背面靠近中部的位置,叶片基部只有浅缺口 |
| 叶面 | 有光泽,绿色发亮 | 叶面有一层细绒,**水滴在上面会滚成水珠**,不沾湿 |
| 地上茎 | **茎粗壮直立,露出地面,像一截树干**,可高达1 m以上 | 没有露出地面的粗茎,叶从地下块茎直接长出 |
| 地下部分 | 粗大的根状茎,无可食的球茎簇 | 地下有一个母芋,周围簇生多个小芋头 |
| 叶尖滴水 | 湿度大时叶尖常滴水("滴水观音") | 一般不明显 |

**有毒成分**: 全株有毒,茎和汁液毒性大,含草酸钙针晶和刺激性成分。

**中毒表现**: 口舌、咽喉剧烈麻痛、肿胀,流涎、吞咽困难、声音嘶哑,严重时喉头水肿窒息;汁液入眼可引起剧痛、角膜损伤;皮肤接触引起瘙痒、红肿。

```
✓ 吃芋头只吃自己种的或市场上买的芋头
✓ 家里养"滴水观音"的,放在儿童、宠物够不着的地方;修剪时戴手套,汁液不要碰眼睛
✓ 生芋头本身也会刺激口舌,一定要煮熟
```

### 4.17 采野菜、挖草根的通用提醒

把上面各组的教训归纳成几条"一看就不采"的原则:

```
✓ 叶子掌状深裂、开蓝紫色头盔状花的(乌头) → 不采
✓ 开白色伞形小花、叶像芹菜或胡萝卜的(伞形科) → 野生的不采
✓ 叶片平行脉、有纵向褶皱、基部有棕毛的(藜芦) → 不采
✓ 喇叭状大花、刺球果的(曼陀罗) → 不采
✓ 天南星科(佛焰苞花序、块茎) → 野生的一律不采
```

## 五、中毒的通用处理

完整的中毒处理原则见[中毒-中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则)。下面只列植物、中药中毒的要点:

```
立即做:
1. 拨打120,不要等症状出现或加重
   - 乌头、钩吻、毒芹、马钱子可在几十分钟内致命
   - 蓖麻子、相思子、苍耳子、毒蘑菇等可能要几小时到几天后才发作,
     "现在没事"不代表没中毒
2. 一起吃过、喝过的人都要去医院,即使没有症状
3. 带上样本: 剩下的植物、药材、药渣、药酒、药丸包装,
   或者拍下植物整株(包括叶、花、果、根)的照片
4. 告诉医生: 吃(喝、敷)了什么、多少、什么时间、什么时候开始不舒服
5. 皮肤、眼睛沾染: 脱去污染衣物,用大量流动清水冲洗;眼睛冲洗15-20分钟
6. 病人意识不清但有呼吸 → 侧卧(复苏体位),防止呕吐物堵塞气道
   没有反应、没有正常呼吸 → 立即开始心肺复苏

不要做:
❌ 不要催吐(抠喉咙、灌盐水都不推荐;意识不清或抽搐时更危险)
❌ 不要用绿豆汤、甘草水、醋、牛奶、生鸡蛋等偏方"解毒"
❌ 不要给意识不清的人喂任何东西
❌ 马钱子中毒抽搐时,不要反复摇晃、拍打、强光照射病人
```

心肺复苏和复苏体位见[基础急救知识-心肺复苏](../01-日常疾病和伤害/00-基础急救知识.md#心肺复苏cpr)、[复苏体位](../01-日常疾病和伤害/00-基础急救知识.md#复苏体位侧卧位)。
