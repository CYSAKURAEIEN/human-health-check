# 果实种子类

> **果实和种子最容易"当零食吃"——苦杏仁、桃仁、白扁豆、川楝子、槟榔,毒性都藏在看起来很普通的一粒里**

本章收录43味常用的果实种子类药材,按功效大致分为补益、收涩安神、理气消食、清热解表利咽、化湿利水、温里、止咳润肠、驱虫八组。每味药写怎样认、在哪里找、何时采、怎样加工储存、药典用量和禁忌。识别、采收、干燥、储存的通用方法见[总论](00-总论.md),本章不再重复。

## ⚠️ 先读这几条

```
1. 果实种子类的药材很多同时是食物(枸杞、山楂、大枣、莲子、薏米、花椒),
   "药食同源"不等于可以随便大量吃;作为药用时按药典用量,在中医师指导下使用
2. 生吃会中毒的几味:
   - 苦杏仁、桃仁(含苦杏仁苷,生食过量释放氰化物,儿童十几粒即可严重中毒)
   - 白扁豆(生的或没煮透的扁豆含凝集素,引起呕吐腹泻)
   - 梅、桃、杏、李、枇杷的核仁都不要砸开生吃
3. 本身有毒、不要自行使用的:
   川楝子(及更毒的苦楝子)、吴茱萸;
   外形相近的苍耳子(有毒,伤肝)不要和牛蒡子混采
4. 槟榔: 嚼食槟榔是口腔癌的明确病因,槟榔果被国际癌症研究机构列为一类致癌物;
   药用驱虫是另一回事,也只在医生指导下短期用
5. 补骨脂可致肝损伤,并引起光敏性皮炎(用后晒太阳起红斑、水疱);
   决明子不要长期当茶喝(长期缓泻)
6. 种子富含油脂,储存中最容易"走油"(发黏、哈喇味)和虫蛀;
   发霉、有哈喇味的不再用——霉变种子可能产生黄曲霉毒素
7. 孕妇慎用: 枳实、枳壳、青皮、桃仁、薏苡仁、槟榔等;
   孕妇、儿童、肝肾病人、长期服抗凝药和其他西药的人,用任何一味前先问医生
```

## 一、补益类

这一组多是"药食两用"的品种,最容易被长期、大量当保健品吃。补骨脂有肝毒性和光敏性,白扁豆生吃会中毒,不能和枸杞、大枣一样看待。

### 1.1 枸杞子

- **正名(别名)**: 枸杞子(枸杞、宁夏枸杞、西枸杞)
- **来源**: 茄科植物宁夏枸杞 *Lycium barbarum* L. 的干燥成熟果实
- **分布与生境**: 主产宁夏、甘肃、青海、新疆、内蒙古;大量栽培。同属的枸杞 *L. chinense* 全国各地田埂、路边、村旁常见,果实俗称"土枸杞",不是药典正品
- **识别要点**:
  - 植株: 灌木,枝条细长下垂,**有棘刺**;叶互生或簇生,披针形;花淡紫色,花冠5裂;浆果**红色**,卵形
  - 药材: 类纺锤形或椭圆形,长6-20 mm,直径3-10 mm;表面**红色或暗红色**,顶端有小突起状的花柱痕,基部有白色果梗痕;果皮柔韧、皱缩,果肉柔润;种子20-50粒,肾形;**味甜**
- **易混淆品/伪品**: 土枸杞果实较小、肉薄,味甜而后微苦;另有**染色、硫磺熏**的枸杞——颜色过分鲜艳均一、手搓掉色、泡水后水立即变红,或闻有刺鼻酸味的,不要买
- **采收与加工**: 夏、秋二季果实呈红色时采收,热风烘干后除去果梗;或晾至皮皱后再晒干,除去果梗
- **储存**: 含糖多,**极易走油(发黏变黑)、虫蛀、发霉**;密封,放阴凉处,量少时冷藏
- **功效**: 滋补肝肾,益精明目
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用);日常作食物少量食用一般是安全的
- **禁忌**: 外感发热、脾虚腹泻的人不宜多吃;**正在服华法林的人**有枸杞引起出血风险升高(INR升高)的报道,用前问医生;糖尿病人注意含糖量

### 1.2 女贞子

- **正名(别名)**: 女贞子(女贞实、冬青子)
- **来源**: 木犀科植物女贞 *Ligustrum lucidum* Ait. 的干燥成熟果实
- **分布与生境**: 长江流域及以南各地,多栽培作行道树、绿篱,城市中极常见
- **识别要点**:
  - 植株: 常绿乔木;叶**对生**,革质,卵形,光亮;夏季开白色小花,圆锥花序,有浓香;核果肾形或长椭圆形,冬季熟时**蓝黑色,被白粉**
  - 药材: 卵形、椭圆形或肾形,长6-8.5 mm,直径3.5-5.5 mm;表面黑紫色或灰黑色,皱缩不平;体轻;外果皮薄,中果皮较松软、易剥离,内果皮木质、黄棕色、有纵棱;种子通常1粒,肾形,紫黑色,油性;味甘、微苦涩
- **易混淆品**: 同属的小蜡、日本女贞等果实相似;城市里其他树木(如樟树)也结黑色小果。认准"叶对生、革质、果肾形被白粉"。**行道树果实可能受汽车尾气和喷洒农药污染,不宜采**
- **采收与加工**: 冬季果实成熟时采收,除去枝叶,稍蒸或置沸水中略烫后干燥;或直接干燥
- **储存**: 放干燥处,防霉、防虫蛀
- **功效**: 滋补肝肾,明目乌发
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 性凉,脾胃虚寒、腹泻的人不宜

### 1.3 菟丝子

- **正名(别名)**: 菟丝子(吐丝子、黄丝子)
- **来源**: 旋花科植物南方菟丝子 *Cuscuta australis* R. Br. 或菟丝子 *C. chinensis* Lam. 的干燥成熟种子
- **分布与生境**: 全国各地;**寄生**在大豆、苜蓿、菊科植物和灌木上,是农田里常见的寄生杂草
- **识别要点**:
  - 植株: 一年生寄生草本,**没有叶、没有绿色**,茎**黄色、细丝状**,缠绕在寄主上,用吸器吸取养分;花小,白色,簇生;蒴果球形
  - 药材: 类球形,直径1-2 mm;表面灰棕色至棕褐色,粗糙;质坚实,不易用指甲压碎;气微,味淡
  - 水试: 用沸水浸泡后表面有黏性;煮到种皮破裂时露出**黄白色、卷旋状的胚,像吐出的丝**(习称"吐丝"),是最简单的真伪鉴别方法
- **易混淆品/伪品**: 有用泥沙团、黏土加工成颗粒冒充的(水中散开、浑浊,不"吐丝");也有其他小种子混入。同属的金灯藤(大菟丝子)种子较大,是地方习用品
- **采收与加工**: 秋季果实成熟时采收植株,晒干,打下种子,除去杂质。寄主喷过农药或本身有毒的,不采
- **储存**: 放干燥处;种子细小,注意防潮
- **功效**: 补益肝肾,固精缩尿,安胎,明目,止泻;外用消风祛斑
- **用量**: 6-12 g;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺、大便燥结的人慎用;"安胎"必须由医生判断,孕期出血、腹痛先就医

### 1.4 补骨脂

- **正名(别名)**: 补骨脂(破故纸、黑故子)
- **来源**: 豆科植物补骨脂 *Psoralea corylifolia* L. 的干燥成熟果实
- **分布与生境**: 河南、四川、安徽、陕西等地栽培;野生少见
- **识别要点**:
  - 植株: 一年生草本,高0.5-1.5 m,全株有白色柔毛和**黑褐色腺点**;单叶互生,宽卵形,边缘有粗齿;花淡紫色或白色,密集成近头状的总状花序;荚果卵形,不开裂
  - 药材: **肾形**,略扁,长3-5 mm,宽2-4 mm;表面**黑色、黑褐色或灰褐色**,有细微网状皱纹;质硬;果皮薄,与种子不易分离;种子1枚,子叶黄白色,有油性;**气香**,味辛、微苦
- **易混淆品**: 曾有用其他豆科小种子混入的;认准肾形、黑色、网状皱纹和香气
- **采收与加工**: 秋季果实成熟时采收果序,晒干,搓出果实,除去杂质
- **储存**: 放干燥处,防走油、虫蛀
- **功效**: 温肾助阳,纳气平喘,温脾止泻;外用消风祛斑
- **用量**: 6-10 g;外用20%-30%酊剂涂患处(《中国药典》2020年版,在中医师指导下使用)
- **风险**(重点):
  - **肝损伤**: 补骨脂和含补骨脂的中成药(用于骨质疏松、白癜风、脱发等的制剂)有引起肝损伤的报道,国家药品监督管理部门曾发布相关风险提示。不长期服,肝病患者不用;服用期间出现乏力、食欲差、尿黄、皮肤眼白发黄,立即停药就医
  - **光敏性**: 含补骨脂素等呋喃香豆素,内服或外涂后晒太阳,可引起**日光性皮炎**: 红斑、灼痛、水疱、色素沉着。外用、内服期间避免日晒
- **禁忌**: 阴虚火旺、大便秘结的人忌用;孕妇、儿童不自行使用

### 1.5 大枣

- **正名(别名)**: 大枣(红枣、干枣)
- **来源**: 鼠李科植物枣 *Ziziphus jujuba* Mill. 的干燥成熟果实
- **分布与生境**: 全国大部分地区栽培,新疆、河北、山东、山西、河南、陕西为主产区
- **识别要点**:
  - 植株: 落叶小乔木,枝上有托叶刺;叶互生,卵形,**基出三脉**;花小,黄绿色;核果长圆形,熟时红色
  - 药材: 椭圆形或球形,长2-3.5 cm,直径1.5-2.5 cm;表面**暗红色**,略带光泽,有不规则皱纹;果肉棕黄色或淡褐色,柔软,**富糖性而油润**;果核纺锤形,两端锐尖,质坚硬;味甜
- **易混淆品**: 一般不易混淆;注意霉变、虫蛀和用糖水泡过、染色的
- **采收与加工**: 秋季果实成熟时采收,晒干
- **储存**: 含糖多,**易发霉、虫蛀、走油**;干透后密封,放阴凉干燥处
- **功效**: 补中益气,养血安神
- **用量**: 6-15 g(《中国药典》2020年版,在中医师指导下使用);作食物日常食用是安全的
- **禁忌**: 湿盛、腹胀、痰多的人不宜多吃;糖尿病人注意含糖量。**枣核尖硬,幼儿吃枣要去核**,防止卡喉、刺伤消化道

### 1.6 白扁豆

- **正名(别名)**: 白扁豆(扁豆、白眉豆)
- **来源**: 豆科植物扁豆 *Dolichos lablab* L. 的干燥成熟种子
- **分布与生境**: 全国各地栽培,作蔬菜和药用;药用取开白花、结白色种子的品种
- **识别要点**:
  - 植株: 一年生缠绕藤本;**三出复叶**,小叶宽三角状卵形;总状花序,蝶形花白色(也有紫色品种);荚果扁平,镰刀形或半月形
  - 药材: 扁椭圆形或扁卵圆形,长8-13 mm,宽6-9 mm,厚约7 mm;表面淡黄白色或淡黄色,平滑,略有光泽;**一侧边缘有隆起的白色眉状种阜**(这是最显眼的特征);质坚硬;嚼之有豆腥气
- **易混淆品**: 紫花扁豆的种子为黑色或紫黑色,不作白扁豆用;其他白色豆类没有"白眉"
- **⚠️ 生食中毒**: 扁豆(包括扁豆角、四季豆等菜豆类)的豆粒和豆荚含**植物凝集素**和皂苷,**生的或没有煮透的**会引起中毒: 吃后数十分钟到数小时内出现恶心、呕吐、腹痛、腹泻、头晕,集体食堂常见。预防办法是**彻底煮沸、煮到完全熟透**(豆荚失去生绿色、没有豆腥味),不要凉拌生吃、不要只焯一下。症状重、持续呕吐腹泻或儿童中毒,就医
- **采收与加工**: 秋、冬二季采收成熟果实,晒干,取出种子,再晒干
- **储存**: 易虫蛀(豆象);密封,放干燥处
- **功效**: 健脾化湿,和中消暑
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用);入药煎煮时间要足,做食物必须煮熟
- **禁忌**: 对豆类过敏的人避免

## 二、收涩安神类

收涩药用于出汗过多、久泻、遗尿、遗精等"滑脱不禁"的情况;**有发热、感冒、腹泻初起(可能是感染)时一般不用**,以免"闭门留寇"。久泻、遗尿、夜间盗汗本身可能是疾病信号,先就医查明原因。

### 2.1 山茱萸

- **正名(别名)**: 山茱萸(山萸肉、枣皮、萸肉)
- **来源**: 山茱萸科植物山茱萸 *Cornus officinalis* Sieb. et Zucc. 的干燥成熟**果肉**
- **分布与生境**: 浙江、河南、安徽、陕西等地的山坡、林缘;主要为栽培
- **识别要点**:
  - 植株: 落叶小乔木;叶对生,卵形,侧脉**弧形**向叶尖弯曲;**早春先开花后长叶**,伞形花序,小花黄色;核果长椭圆形,秋季熟时**鲜红色**
  - 药材: 不规则的片状或囊状,长1-1.5 cm,宽0.5-1 cm;表面**紫红色至紫黑色**,皱缩,有光泽;顶端有的有圆形宿萼痕,基部有果梗痕;质柔软;味酸、涩、微苦
- **易混淆品/伪品**: 掺入果核(药典限量)、用葡萄皮、山楂皮、酸枣皮染色冒充;冒充品没有山茱萸特有的光泽和酸涩味。**和吴茱萸只差一字,是完全不同的药**(吴茱萸有毒,见[6.1](#61-吴茱萸)),抓药时核对
- **采收与加工**: 秋末冬初果皮变红时采收果实,用文火烘或置沸水中略烫后,**及时除去果核**,干燥
- **储存**: 含糖多,易发霉、虫蛀、粘结成团;密封,放阴凉干燥处
- **功效**: 补益肝肾,收涩固脱
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 湿热、小便淋涩的人不宜

### 2.2 五味子

- **正名(别名)**: 五味子(北五味子、辽五味子)
- **来源**: 木兰科植物五味子 *Schisandra chinensis* (Turcz.) Baill. 的干燥成熟果实,习称"北五味子"。同属华中五味子的果实是"南五味子",药典另列一条
- **分布与生境**: 东北、华北的山地林缘、灌丛、沟谷;东北有栽培
- **识别要点**:
  - 植株: 落叶**木质藤本**;叶互生,宽椭圆形;花单性,乳白色或粉红色;花后花托伸长,结成**下垂的穗状聚合果**,小浆果球形,熟时**红色**
  - 药材: 不规则球形或扁球形,直径5-8 mm;表面**红色、紫红色或暗红色**,皱缩,显油润,有的表面黑红色或出现"白霜";果肉柔软;种子1-2粒,肾形,表面棕黄色、有光泽
  - 气味: 果肉味酸;种子破碎后有香气,味辛、微苦——"五味俱全"由此得名
- **易混淆品**: 南五味子个小、表面棕红色至暗棕色、干瘪,肉薄;两者功效相近但不能互相冒充
- **采收与加工**: 秋季果实成熟时采摘,晒干或蒸后晒干,除去果梗和杂质
- **储存**: 易走油、发霉;密封,放阴凉处
- **功效**: 收敛固涩,益气生津,补肾宁心
- **用量**: 2-6 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 外感发热、咳嗽初起、内有实热的人不宜。**五味子会影响他克莫司等药物在体内的代谢**(升高血药浓度),器官移植后服免疫抑制剂、以及长期服其他处方药的人,用前问医生
- 🛡️ **保护提醒**: 五味子列入《国家重点保护野生药材物种名录》(三级,以名录原文为准)。野生资源要留种、留藤,不要连藤拔起;优先用栽培品

### 2.3 乌梅

- **正名(别名)**: 乌梅(酸梅、熏梅)
- **来源**: 蔷薇科植物梅 *Prunus mume* (Sieb.) Sieb. et Zucc. 的干燥近成熟果实
- **分布与生境**: 四川、浙江、福建、湖南、云南等地栽培
- **识别要点**:
  - 植株: 落叶小乔木;早春先叶开花,白色或粉红色,有香气;叶卵形,先端尾尖;核果近球形,有纵沟,熟时黄色,**果肉与核黏着**
  - 药材: 类球形或扁球形,直径1.5-3 cm;表面**乌黑色或棕黑色**,皱缩不平;果核坚硬,椭圆形,棕黄色,**表面有凹点**;种子扁卵形,淡黄色;**味极酸**
- **易混淆品/伪品**: 用杏、李等果实熏黑冒充;冒充品的果核表面没有梅核那样的密集凹点,酸味也不同
- **采收与加工**: 夏季果实近成熟时采收,低温烘干后**闷至色变黑**
- **储存**: 放干燥处,防霉
- **功效**: 敛肺,涩肠,生津,安蛔
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 外有表邪(感冒发热)或内有实热积滞的人不宜;胃酸过多的人少用。**梅核里的仁含苦杏仁苷,不要砸开生吃**

### 2.4 金樱子

- **正名(别名)**: 金樱子(糖罐子、刺梨子、山石榴)
- **来源**: 蔷薇科植物金樱子 *Rosa laevigata* Michx. 的干燥成熟果实
- **分布与生境**: 华东、华南、西南的向阳山坡、田边、灌丛
- **识别要点**:
  - 植株: 常绿攀援灌木,枝上有**钩状皮刺**;复叶通常**3片小叶**,革质,有光泽;花大,单生,**白色**,5瓣;果实梨形或倒卵形,**外面密生刺毛**,熟时红黄色
  - 药材: 倒卵形,长2-3.5 cm,直径1-2 cm;表面红黄色或红棕色,有突起的棕色小点(毛刺脱落后的残基);顶端有盘状花萼残基;质硬;切开后壁厚1-2 mm,**内有多数坚硬的小瘦果,内壁和瘦果上都有淡黄色绒毛**;味甘、微涩
- **易混淆品**: 同属野蔷薇、缫丝花(刺梨)等的果实;刺梨果实扁球形、密生刺,另作食用
- **采收与加工**: 10-11月果实成熟变红时采收,干燥,除去毛刺。入药前纵切去净瘦果和绒毛(称"金樱子肉")——**绒毛刺激咽喉,不去净会引起咳嗽、咽痒**
- **储存**: 放干燥处,防霉、虫蛀
- **功效**: 固精缩尿,固崩止带,涩肠止泻
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 有实火、湿热的人不宜;采摘时戴手套,防皮刺和刺毛

### 2.5 覆盆子

- **正名(别名)**: 覆盆子(华东覆盆子、掌叶覆盆子)
- **来源**: 蔷薇科植物华东覆盆子 *Rubus chingii* Hu 的干燥果实
- **分布与生境**: 浙江、福建、江西、安徽等地的山坡、林缘、路旁灌丛
- **识别要点**:
  - 植株: 落叶灌木,枝上有皮刺;单叶,**掌状5深裂**;花白色,单生;聚合果近球形,熟时红色,可食
  - 药材: 聚合果,由多数小核果聚成**圆锥形或扁圆锥形**,高0.6-1.3 cm,直径0.5-1.2 cm;表面黄绿色或淡棕色,顶端钝圆,基部中心凹入;小果易剥落,每个呈半月形,**背面密被灰白色茸毛**,两侧有明显网纹;体轻,质硬;味微酸涩
- **易混淆品**: 悬钩子属种类很多,野外的"野莓"大多可食,但不是药典品种;超市卖的"树莓/覆盆子"水果是欧洲红树莓,与药材覆盆子不是同一种。药材是**未成熟**时采的,不是熟透的红果
- **采收与加工**: 夏初果实由绿变绿黄时采收,除去梗、叶,置沸水中略烫或略蒸,取出,干燥
- **储存**: 放干燥处,防霉、虫蛀
- **功效**: 益肾固精缩尿,养肝明目
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 小便短赤、有湿热的人不宜

### 2.6 莲子

- **正名(别名)**: 莲子(莲肉、莲米)
- **来源**: 睡莲科植物莲 *Nelumbo nucifera* Gaertn. 的干燥成熟种子
- **分布与生境**: 全国各地池塘、湖泊;湖南(湘莲)、福建(建莲)、江西、湖北等地大量栽培
- **识别要点**:
  - 植株: 多年生水生草本;叶圆盾形,伸出水面;花大,粉红或白色;花托膨大成**莲蓬**(莲房),每孔一粒莲子
  - 药材: 略呈椭圆形或类球形,长1.2-1.8 cm,直径0.8-1.4 cm;表面**红棕色**,有细纵纹和较宽的脉纹;一端中心呈乳头状突起,多有裂口;质硬,种皮薄,不易剥离;子叶2,黄白色,肥厚,中间有绿色的**莲子心**(或已去心,底部有小孔);味甘、微涩,莲子心味苦
- **易混淆品**: 一般不易混淆。莲的各部分是不同的药: 莲子心、莲房、莲须、荷叶(见第05章花叶类)、藕节;带黑色硬壳的老熟果实称"石莲子"
- **采收与加工**: 秋季果实成熟时采割莲房,取出果实,除去果皮,干燥;或除去莲子心后干燥
- **储存**: 易虫蛀、发霉;密封,放干燥处
- **功效**: 补脾止泻,止带,益肾涩精,养心安神
- **用量**: 6-15 g(《中国药典》2020年版,在中医师指导下使用);作食物日常食用是安全的
- **禁忌**: 大便干结、腹胀的人不宜多吃

### 2.7 芡实

- **正名(别名)**: 芡实(鸡头米、鸡头实)
- **来源**: 睡莲科植物芡 *Euryale ferox* Salisb. 的干燥成熟种仁
- **分布与生境**: 江苏、山东、湖南、湖北、安徽等地的池塘、湖沼;苏州一带栽培作食物
- **识别要点**:
  - 植株: 一年生大型水生草本;叶浮于水面,**圆形巨大,直径可达1 m以上,两面有刺,叶背紫色、叶脉隆起**;花紫色;果实球形,**密生硬刺,顶端有宿萼,形如鸡头**
  - 药材: 类球形,多为破粒,完整的直径5-8 mm;表面有**棕红色或红褐色内种皮**,一端黄白色(约占1/3),有凹点状种脐痕;除去内种皮显白色;质较硬,断面白色,**粉性**;味淡
- **易混淆品**: 一般不易混淆;注意霉变和用其他淀粉颗粒加工的
- **采收与加工**: 秋末冬初采收成熟果实,除去果皮,取出种子,洗净,再除去硬壳(外种皮),晒干。果实和叶都有硬刺,戴手套;**采收在水中进行,注意溺水风险,不要独自下水**
- **储存**: 富含淀粉,易虫蛀、发霉
- **功效**: 益肾固精,补脾止泻,除湿止带
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 大小便不利、食积腹胀、便秘的人不宜

### 2.8 酸枣仁

- **正名(别名)**: 酸枣仁(枣仁、山枣仁)
- **来源**: 鼠李科植物酸枣 *Ziziphus jujuba* Mill. var. *spinosa* (Bunge) Hu ex H. F. Chou 的干燥成熟种子
- **分布与生境**: 河北、陕西、辽宁、河南、山西、山东等地向阳干燥的山坡、丘陵、路旁
- **识别要点**:
  - 植株: 灌木或小乔木,枝上有**托叶刺,一枚长直、一枚短而弯钩**;叶小,基出三脉;核果小,近球形,熟时红褐色,**果肉薄,味酸**
  - 药材: 扁圆形或扁椭圆形,长5-9 mm,宽5-7 mm,厚约3 mm;表面**紫红色或紫褐色,平滑有光泽**;**一面较平坦,中间有1条隆起的纵线纹**,另一面稍凸起;一端凹陷有线形种脐;种皮较脆,子叶浅黄色,富油性;气微,味淡
- **易混淆品/伪品**: 最常见的是**理枣仁**(滇刺枣的种子): 个较大,表面黄棕色,平坦一面**没有**隆起的纵线纹;还有用枳椇子、兵豆(小扁豆)染色冒充的
- **采收与加工**: 秋末冬初采收成熟果实,除去果肉和核壳,收集种子,晒干
- **储存**: 富含油脂,**易走油、虫蛀**;密封,放阴凉处,不宜久存
- **功效**: 养心补肝,宁心安神,敛汗,生津
- **用量**: 10-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 有实邪郁火的人慎用;**与安眠药、镇静药同用可加重嗜睡**,先问医生。长期失眠应就医查找原因

## 三、理气消食类

理气药多辛香、行散,用于腹胀、嗳气、食积。**"破气"作用强的(枳实、青皮)孕妇慎用**,体虚乏力的人不宜久用。川楝子本身有毒,放在本组末尾单独提醒。

### 3.1 陈皮

- **正名(别名)**: 陈皮(橘皮、广陈皮、新会皮)
- **来源**: 芸香科植物橘 *Citrus reticulata* Blanco 及其栽培变种的干燥成熟果皮。药材分为"陈皮"和"广陈皮"(广东新会一带茶枝柑的果皮)
- **分布与生境**: 长江以南各地广泛栽培
- **识别要点**:
  - 陈皮: 常剥成数瓣,基部相连,或为不规则片状,厚1-4 mm;**外表面橙红色或红棕色,有细皱纹和凹下的点状油室**;内表面浅黄白色,粗糙,附黄白色或黄棕色筋络状维管束;质稍硬而脆;**气香,味辛、苦**
  - 广陈皮: 常3瓣相连,形状整齐,厚度均匀,约1 mm;点状油室较大,**对光照视透明清晰**;质较柔软
- **易混淆品/伪品**: 用柚皮、橙皮冒充(皮厚、油室小、香气不同);高价的"新会陈皮"有染色、做旧冒充的
- **采收与加工**: 采摘成熟果实,剥取果皮,晒干或低温干燥。"陈"的意思是存放年久者为佳
- **自制提醒**: 吃剩的橘子皮可以自制,但市售水果果皮可能有**农药残留和打蜡**;选自家种或确认未打蜡的,洗净后再晒;已经发霉的不要用
- **储存**: 易受潮发霉、虫蛀;晒透后密封,放通风干燥处,定期翻晒
- **功效**: 理气健脾,燥湿化痰
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 气虚、阴虚燥咳、吐血的人慎用

### 3.2 青皮

- **正名(别名)**: 青皮(个青皮、四花青皮)
- **来源**: 芸香科植物橘 *Citrus reticulata* Blanco 及其栽培变种的干燥幼果或未成熟果实的果皮
- **分布与生境**: 同陈皮
- **识别要点**:
  - 个青皮(自落的幼果): 类球形,直径0.5-2 cm;表面**灰绿色或黑绿色**,有细密凹下的油室;质硬;断面果皮黄白色,厚0.1-0.2 cm,瓤囊8-10瓣;气清香,味酸、苦、辛
  - 四花青皮(未成熟果实的果皮): 果皮剖成**4裂片**,基部相连,裂片长椭圆形,长4-6 cm;外表面灰绿色或黑绿色,密生油室;内表面类白色或黄白色,附小筋络
- **易混淆品**: 与枳实外形相近(都是芸香科幼果),枳实个大、果皮厚、切面中果皮宽(见[3.3](#33-枳实))
- **采收与加工**: 5-6月收集自落的幼果,晒干(个青皮);7-8月采收未成熟果实,在果皮上纵剖成四瓣至基部,除尽瓤瓣,晒干(四花青皮)
- **储存**: 放干燥处,防霉
- **功效**: 疏肝破气,消积化滞
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 破气作用强,气虚、多汗的人慎用;**孕妇慎用**

### 3.3 枳实

- **正名(别名)**: 枳实(江枳实、鹅眼枳实)
- **来源**: 芸香科植物酸橙 *Citrus aurantium* L. 及其栽培变种或甜橙 *C. sinensis* Osbeck 的干燥**幼果**
- **分布与生境**: 江西、四川、湖南、湖北、浙江等地栽培
- **识别要点**:
  - 植株: 常绿小乔木,枝有刺;叶柄有**翼叶**;花白色芳香;果实球形,熟时橙黄色,味酸苦
  - 药材: **半球形**,少数为球形,直径0.5-2.5 cm;外果皮黑绿色或棕褐色,有颗粒状突起和皱纹;**切面中果皮略隆起,黄白色或黄褐色,厚0.3-1.2 cm**,边缘有1-2列油室,瓤囊棕褐色;质坚硬;气清香,味苦、微酸
- **易混淆品**: 枸橘(枳 *Poncirus trifoliata*)的幼果曾被称为"绿衣枳实",表面有细柔毛,不是药典正品
- **采收与加工**: 5-6月收集自落的果实,除去杂质,自中部横切为两半,晒干或低温干燥;较小的直接干燥
- **储存**: 放干燥处,防霉、虫蛀
- **功效**: 破气消积,化痰散痞
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**;脾胃虚弱的人慎用。枳实含辛弗林等成分,可升高血压、加快心率;**高血压、心脏病患者用前问医生**,不要服用含"苦橙提取物"的减肥产品

### 3.4 枳壳

- **正名(别名)**: 枳壳(江枳壳、川枳壳)
- **来源**: 芸香科植物酸橙 *Citrus aurantium* L. 及其栽培变种的干燥**未成熟果实**
- **分布与生境**: 同枳实
- **识别要点**:
  - 药材: 半球形,直径3-5 cm(**比枳实大**);外果皮棕褐色至褐色,有颗粒状突起,突起顶端有凹点状油室;切面中果皮黄白色,光滑稍隆起,厚0.4-1.3 cm,边缘散有1-2列油室;瓤囊7-12瓣,汁囊干缩成棕褐色;质坚硬;气清香,味苦、微酸
- **与枳实的区别**: 同一种植物,**采收时间不同**: 5-6月自落的幼果是枳实(小、力强),7月尚绿的未成熟果实是枳壳(大、力缓)
- **采收与加工**: 7月果皮尚绿时采收,自中部横切为两半,晒干或低温干燥
- **储存**: 放干燥处,防霉、虫蛀
- **功效**: 理气宽中,行滞消胀
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**;脾胃虚弱的人慎用;高血压、心脏病同枳实

### 3.5 山楂

- **正名(别名)**: 山楂(北山楂、山里红、红果)
- **来源**: 蔷薇科植物山里红 *Crataegus pinnatifida* Bge. var. *major* N. E. Br. 或山楂 *C. pinnatifida* Bge. 的干燥成熟果实
- **分布与生境**: 山东、河北、河南、辽宁、山西等地;多栽培,野生于山坡、林缘
- **识别要点**:
  - 植株: 落叶乔木,枝有刺(山里红刺少或无);叶宽卵形,**羽状深裂**;伞房花序,花白色;梨果近球形,深红色,**表面有浅色斑点**
  - 药材: 圆形片,皱缩不平,直径1-2.5 cm,厚0.2-0.4 cm;外皮**红色**,有灰白色小斑点;果肉深黄色至浅棕色;中部横切片有5粒浅黄色果核(多已脱落);气微清香,**味酸、微甜**
- **易混淆品**: 野山楂的果实较小,习称"南山楂",是部分地区习用品;另有用苹果片、海棠果片冒充的(没有灰白色斑点和硬核)
- **采收与加工**: 秋季果实成熟时采收,切片,干燥
- **储存**: 易虫蛀、发霉
- **功效**: 消食健胃,行气散瘀,化浊降脂
- **用量**: 9-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **胃酸过多、胃溃疡的人不宜多吃**,也不宜空腹大量吃;孕妇不宜大量食用;**山楂和柿子大量同时空腹食用,有形成胃结石的报道**。正在服他汀类降脂药的人,不要自行用山楂代替或叠加

### 3.6 莱菔子

- **正名(别名)**: 莱菔子(萝卜子、萝卜籽)
- **来源**: 十字花科植物萝卜 *Raphanus sativus* L. 的干燥成熟种子
- **分布与生境**: 全国各地栽培
- **识别要点**:
  - 植株: 萝卜,开淡紫色或白色的十字形花;长角果圆柱形,种子间缢缩成**念珠状**,不开裂
  - 药材: 类卵圆形或椭圆形,稍扁,长2.5-4 mm,宽2-3 mm;表面黄棕色、红棕色或灰棕色;一端有深棕色圆形种脐,一侧有数条纵沟;子叶黄白色,有油性;味淡、微苦辛
- **易混淆品**: 其他十字花科种子(芥菜籽、油菜籽)多为球形、更小;购买菜种时注意**种子包衣**(染成红、蓝、绿色的种子拌过农药或杀菌剂,不能入药、不能吃)
- **采收与加工**: 夏季果实成熟时采割植株,晒干,搓出种子,除去杂质,再晒干
- **储存**: 易走油、虫蛀
- **功效**: 消食除胀,降气化痰
- **用量**: 5-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 气虚、无食积痰滞的人慎用;传统经验认为不宜与人参同用

### 3.7 川楝子

- **正名(别名)**: 川楝子(金铃子、川楝实)
- **来源**: 楝科植物川楝 *Melia toosendan* Sieb. et Zucc. 的干燥成熟果实
- **分布与生境**: 四川、云南、贵州、湖北、湖南等地;平原、丘陵、村旁
- **识别要点**:
  - 植株: 落叶乔木;**二至三回奇数羽状复叶**;花淡紫色,圆锥花序;核果近球形,熟时黄色,冬季挂在树上
  - 药材: 类球形,**直径2-3.2 cm**;表面金黄色至棕黄色,微有光泽,有深棕色小点;外果皮革质,与果肉间常有空隙,果肉松软,淡黄色;果核球形或卵圆形,质坚硬,有6-8条纵棱,内分6-8室;气特异,味酸、苦
- **易混淆品**: 同属的**苦楝** *Melia azedarach* 全国各地城乡极常见,果实"苦楝子"**较小(长约1.5 cm)、椭圆形,毒性更大**,不能代替川楝子,更不能食用
- **毒性**(重点):
  - 药典标注"**有小毒**"。主要毒性成分是川楝素(苦楝素)等
  - 中毒表现: 恶心、呕吐、腹痛、腹泻,头晕、嗜睡,视物模糊,**肝损伤**;严重时心律失常、呼吸麻痹。有儿童误食苦楝果、成人自服过量致死的报道
- **采收与加工**: 冬季果实成熟时采收,除去杂质,干燥
- **储存**: 单独存放,贴"有毒"标签,放在儿童拿不到的地方
- **功效**: 疏肝泄热,行气止痛,杀虫
- **用量**: 药典规定5-10 g;外用适量。**有毒,不要自行使用**——只能由中医师开方、从正规药房取药
- **禁忌**: 不长期服、不加量;孕妇、儿童、肝病患者不用;脾胃虚寒的人慎用。**教育儿童不要采食楝树果实**。出现中毒表现立即拨打120,见[中毒的通用处理](09-有毒中药与易混淆有毒植物.md#五中毒的通用处理)

## 四、清热解表利咽类

这一组多性凉,用于发热、咽痛、目赤、疮肿。**性寒的药久服伤脾胃**,脾胃虚寒、容易腹泻的人不宜久用;发热超过三天、咽痛伴吞咽困难或高热,先就医。

### 4.1 栀子

- **正名(别名)**: 栀子(山栀、黄栀子、山栀子)
- **来源**: 茜草科植物栀子 *Gardenia jasminoides* Ellis 的干燥成熟果实
- **分布与生境**: 江西、湖南、湖北、浙江、福建、四川等地的山坡灌丛、林缘;广泛栽培(栀子花即此)
- **识别要点**:
  - 植株: 常绿灌木;叶**对生**,革质,有光泽;花大,**白色,浓香**;果实卵形,**有5-9条翅状纵棱,顶端有宿存的长条形萼片**,熟时橙红色
  - 药材: 长卵圆形或椭圆形,长1.5-3.5 cm,直径1-1.5 cm;表面**红黄色或棕红色**,有6条翅状纵棱;顶端残存萼片;果皮薄而脆;内有多数扁卵圆形种子,集结成团,深红色或红黄色;味微酸而苦
  - 水试: 少量泡水,水被染成**鲜黄色**(栀子是传统黄色染料)
- **易混淆品**: "水栀子"(大果栀子)果实大而长,棱高,主要作染料,不作药用
- **采收与加工**: 9-11月果实成熟呈红黄色时采收,除去果梗和杂质,蒸至上气或置沸水中略烫,取出,干燥
- **储存**: 放干燥处,防霉
- **功效**: 泻火除烦,清热利湿,凉血解毒;外用消肿止痛
- **用量**: 6-10 g;外用生品适量,研末调敷(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 性寒,脾虚便溏的人不宜。**不宜长期服用**: 有长期(数年)服用含栀子的制剂后发生肠系膜静脉硬化性结肠炎的报道

### 4.2 连翘

- **正名(别名)**: 连翘(青翘、老翘、黄翘)
- **来源**: 木犀科植物连翘 *Forsythia suspensa* (Thunb.) Vahl 的干燥果实
- **分布与生境**: 山西、河南、陕西、河北、山东等地的山坡灌丛、林缘;城市常栽培作早春观赏花木
- **识别要点**:
  - 植株: 落叶灌木,枝条拱形下垂,**枝中空**;早春先叶开花,**黄色,花冠4深裂**;叶对生,单叶或三出复叶;蒴果卵球形,表面散生瘤点
  - 药材: 长卵形至卵形,稍扁,长1.5-2.5 cm,直径0.5-1.3 cm;表面有不规则纵皱纹和多数凸起的小斑点,**两面各有1条明显的纵沟**;顶端锐尖
    - **青翘**: 多不开裂,表面绿褐色;种子多数,黄绿色,细长,一侧有翅
    - **老翘**: 自顶端开裂或裂成两瓣,表面黄棕色或红棕色,内表面平滑,有一纵隔;种子多已脱落
  - 气微香,味苦
- **易混淆品**: 早春开黄花的还有**迎春花**(枝绿色、四棱形,花冠5-6裂,一般不结果)和金钟花(枝有片状髓,不中空)。认准"枝中空、花冠4裂"
- **采收与加工**: 秋季果实初熟尚带绿色时采收,除去杂质,**蒸熟,晒干**(青翘);果实熟透时采收,晒干(老翘)
- **储存**: 放干燥处
- **功效**: 清热解毒,消肿散结,疏散风热
- **用量**: 6-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒、气虚发热的人慎用
- 🛡️ **保护提醒**: 连翘列入《国家重点保护野生药材物种名录》(三级,以名录原文为准)。青翘价高,过早"抢青"采摘破坏资源;采收不早于成熟季节,只采部分果实

### 4.3 决明子

- **正名(别名)**: 决明子(草决明、马蹄决明)
- **来源**: 豆科植物钝叶决明 *Cassia obtusifolia* L. 或决明(小决明) *C. tora* L. 的干燥成熟种子
- **分布与生境**: 长江以南各地野生或栽培,北方也有栽培
- **识别要点**:
  - 植株: 一年生半灌木状草本,高1-2 m;**偶数羽状复叶,小叶3对**,倒卵形;花黄色;**荚果细长,近四棱形,长达15 cm**
  - 药材(决明): **略呈菱方形或短圆柱形,两端平行倾斜**,长3-7 mm,宽2-4 mm;表面**绿棕色或暗棕色,平滑有光泽**;背腹面各有1条突起的棱线,棱线两侧各有1条斜向对称、色较浅的线形凹纹;质坚硬;味微苦
  - 小决明: 短圆柱形,较小;棱线两侧各有1片宽广的浅黄棕色带
- **易混淆品**: **望江南子**(望江南 *Cassia occidentalis* 的种子,**有毒**)常被混入或误采: 扁卵形,灰绿色或灰棕色,**两面中央各有一个椭圆形凹陷**,形状和决明子的"菱方柱形"明显不同。两种植物常长在一起,采收时认准植株(望江南小叶4-5对,荚果扁平带状)
- **采收与加工**: 秋季采收成熟果实,晒干,打下种子,除去杂质
- **储存**: 放干燥处,防霉、虫蛀
- **功效**: 清热明目,润肠通便
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **⚠️ 不要长期当茶喝**: 决明子含蒽醌类成分,有缓泻作用。长期大量泡水喝可引起**腹泻、腹痛、电解质紊乱**;长期服用蒽醌类泻药与结肠黑变病有关;也有肝损伤的个案报道。"降压、减肥、明目"的说法不能代替正规治疗
- **禁忌**: 脾虚便溏、低血压的人不宜;孕妇不要长期饮用

### 4.4 牛蒡子

- **正名(别名)**: 牛蒡子(大力子、鼠粘子、恶实)
- **来源**: 菊科植物牛蒡 *Arctium lappa* L. 的干燥成熟果实
- **分布与生境**: 全国各地的山坡、路旁、村旁、林缘;东北、浙江等地栽培(根作蔬菜"牛蒡")
- **识别要点**:
  - 植株: 二年生大型草本,高1-2 m;**基生叶极大,宽卵形或心形,背面有灰白色绒毛**;头状花序球形,**总苞片顶端钩状**,花紫红色;果序成熟后整个球形总苞像带钩的刺球,能粘在衣服上
  - 药材: 从刺球里打出的瘦果,**长倒卵形**,略扁,微弯曲,长5-7 mm,宽2-3 mm;表面**灰褐色,带紫黑色斑点**,有数条纵棱;顶端钝圆,有圆环;子叶淡黄白色,富油性;味苦后微辛而稍麻舌
- **易混淆品**: ⚠️ **苍耳子**(有毒,伤肝)——同为菊科、同样带钩刺、同样粘衣服,野外常一起出现。区别: 牛蒡是高大的、叶极大的植物,刺球是**球形**、花紫红色;苍耳的刺果是**纺锤形或椭圆形**、长约1-1.5 cm、整个带刺果实就是药材,叶三角状卵形、粗糙。见[苍耳幼苗和苍耳子](09-有毒中药与易混淆有毒植物.md#410-苍耳幼苗和苍耳子)
- **采收与加工**: 秋季果实成熟时采收果序,晒干,打下果实,除去杂质,再晒干。总苞钩刺和细毛刺激皮肤,戴手套
- **储存**: 易走油、虫蛀
- **功效**: 疏散风热,宣肺透疹,解毒利咽
- **用量**: 6-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 性寒滑肠,脾虚便溏的人慎用

### 4.5 蔓荆子

- **正名(别名)**: 蔓荆子(荆子、万荆子)
- **来源**: 马鞭草科植物单叶蔓荆 *Vitex trifolia* L. var. *simplicifolia* Cham. 或蔓荆 *V. trifolia* L. 的干燥成熟果实
- **分布与生境**: 单叶蔓荆生于山东、江苏、浙江、福建、广东等地**海边沙滩**;蔓荆分布于华南
- **识别要点**:
  - 植株: 单叶蔓荆为**匍匐**灌木,茎在沙上蔓延生根;单叶对生,倒卵形,**背面密生灰白色茸毛**;圆锥花序,花**淡紫色**;全株有香气
  - 药材: 球形,直径4-6 mm;表面灰黑色或黑褐色,被灰白色粉霜状茸毛,有纵向浅沟4条;**基部有灰白色宿萼**,萼长为果实的1/3-2/3,密被茸毛;体轻,质坚韧;横切面4室;**气特异而芳香**,味淡、微辛
- **易混淆品**: 同属的黄荆子、牡荆子(山坡常见灌木的果实)较小,是地方习用品,不能代替
- **采收与加工**: 秋季果实成熟时采收,除去杂质,晒干
- **储存**: 放干燥处,防霉
- **功效**: 疏散风热,清利头目
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 血虚引起的头痛、目眩慎用;反复剧烈头痛先就医排查原因

### 4.6 罗汉果

- **正名(别名)**: 罗汉果(拉汗果、假苦瓜)
- **来源**: 葫芦科植物罗汉果 *Siraitia grosvenorii* (Swingle) C. Jeffrey ex A. M. Lu et Z. Y. Zhang 的干燥果实
- **分布与生境**: 广西桂林(永福、临桂)一带为主产区,基本为栽培;野生于华南山区林中
- **识别要点**:
  - 植株: 多年生攀援草质藤本,有卷须;叶心状卵形;雌雄异株;果实球形或椭圆形,有黄色柔毛
  - 药材: 卵形、椭圆形或球形,长4.5-8.5 cm,直径3.5-6 cm;表面**褐色、黄褐色或绿褐色**,有深色斑块和黄色柔毛;**体轻,质脆,果皮薄,易破**;果瓤海绵状,浅棕色;种子扁圆形,多数,浅红色至棕红色,边缘有槽;**味甜**
- **易混淆品**: 一般不易混淆;选果大、完整、摇之不响、无破损发霉的
- **采收与加工**: 秋季果实由嫩绿变深绿色时采收,晾数天后,低温干燥
- **储存**: 果皮脆薄,轻拿轻放;受潮易霉,密封放干燥处
- **功效**: 清热润肺,利咽开音,滑肠通便
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒、腹泻的人慎用

### 4.7 胖大海

- **正名(别名)**: 胖大海(安南子、大海子、通大海)
- **来源**: 梧桐科植物胖大海 *Sterculia lychnophora* Hance 的干燥成熟种子
- **分布与生境**: 主产越南、泰国、柬埔寨、印度尼西亚等东南亚国家,商品多为进口;国内海南、广西有少量引种
- **识别要点**:
  - 药材: **纺锤形或椭圆形**,长2-3 cm,直径1-1.5 cm;先端钝圆,基部略尖而歪;表面**棕色或暗棕色**,微有光泽,有不规则干缩皱纹;外层种皮极薄,易脱落;中层种皮较厚,黑褐色,质松易碎,**遇水膨胀成海绵状**;味淡,嚼之有黏性
  - 水试: 放入热水中很快膨胀,体积增大数倍,呈棕色半透明的海绵状团块——不膨胀的是伪品或陈旧品
- **易混淆品**: 曾有用同属其他植物的种子冒充(膨胀性差)
- **采收与加工**: 果实成熟开裂时采收种子,晒干
- **储存**: 放干燥处,防霉、虫蛀
- **功效**: 清热润肺,利咽开音,润肠通便
- **用量**: 2-3枚,沸水泡服或煎服(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **不宜长期当茶喝**: 性寒滑肠,久服可致腹泻、食欲减退,脾胃虚寒的人尤其不宜;有过敏反应的报道。风寒感冒引起的咽痛、声哑不宜。**声音嘶哑超过2周不好转,要去医院检查喉部**,不要一直靠泡胖大海

## 五、化湿利水类

砂仁、豆蔻、草果是姜科的芳香果实,**气味是识别和判断质量的关键**——香气淡了说明久放走气。薏苡仁、车前子利水渗湿,木瓜舒筋化湿,放在本组。

### 5.1 砂仁

- **正名(别名)**: 砂仁(阳春砂、春砂仁、缩砂仁)
- **来源**: 姜科植物阳春砂 *Amomum villosum* Lour.、绿壳砂 *A. villosum* Lour. var. *xanthioides* T. L. Wu et Senjen 或海南砂 *A. longiligulare* T. L. Wu 的干燥成熟果实
- **分布与生境**: 广东阳春、广西、云南、海南等地;山谷林下阴湿处,多栽培
- **识别要点**:
  - 植株: 多年生草本,高1.5-3 m,有匍匐根茎;叶二列,披针形,像姜叶;**花序从根茎上抽出,贴近地面**;蒴果椭圆形,有软刺
  - 药材(阳春砂、绿壳砂): 椭圆形或卵圆形,有不明显的三棱,长1.5-2 cm,直径1-1.5 cm;表面棕褐色,**密生刺状突起**;果皮薄而软;种子集结成团,中有白色隔膜将种子团分成3瓣,每瓣种子5-26粒;种子为不规则多面体,直径2-3 mm,棕红色或暗褐色,外被淡棕色膜质假种皮;**气芳香而浓烈,味辛凉、微苦**
  - 海南砂: 长椭圆形,**三棱明显**,表面有片状、分枝的软刺;果皮厚而硬;气味稍淡
- **易混淆品/伪品**: 山姜属植物的果实("土砂仁")、红壳砂仁等冒充,香气淡或气味不同。买药时剥开闻香、看种子团是否分3瓣
- **采收与加工**: 夏、秋二季果实成熟时采收,晒干或低温干燥
- **储存**: 含挥发油,**密封保存,防止香气散失**;不宜久存
- **功效**: 化湿开胃,温脾止泻,理气安胎
- **用量**: 3-6 g,**后下**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚血燥、火热内盛的人慎用;"安胎"由医生判断

### 5.2 豆蔻

- **正名(别名)**: 豆蔻(白豆蔻、白蔻、紫蔻)
- **来源**: 姜科植物白豆蔻 *Amomum kravanh* Pierre ex Gagnep. 或爪哇白豆蔻 *A. compactum* Soland ex Maton 的干燥成熟果实。按产地分为"原豆蔻"和"印尼白蔻"
- **分布与生境**: 主产泰国、柬埔寨、印度尼西亚,商品多进口;云南、海南有引种
- **识别要点**:
  - 原豆蔻: **类球形**,直径1.2-1.8 cm;表面**黄白色至淡黄棕色**,有3条较深的纵向槽纹,两端有浅棕色绒毛;果皮体轻,质脆,易纵向裂开,内分3室,每室约10粒种子;种子不规则多面体,直径3-4 mm,暗棕色;**气芳香,味辛凉,略似樟脑**
  - 印尼白蔻: 个略小,表面黄白色,有的微显紫棕色;果皮较薄,种子瘦瘪;气味较弱
- **易混淆品**: 名字带"蔻"的有好几味,不能互相代替:
  - **肉豆蔻**(肉豆蔻科,种仁,卵圆形,表面有网状沟纹): 另一味药,**大量服用有毒**(可致幻觉、心慌),不要当调料大量用
  - 草豆蔻(姜科山姜属的种子团)、红豆蔻: 都是另一味药
- **采收与加工**: 果实成熟时采收,晒干
- **储存**: 同砂仁,密封防走气
- **功效**: 化湿行气,温中止呕,开胃消食
- **用量**: 3-6 g,**后下**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚血燥的人慎用

### 5.3 草果

- **正名(别名)**: 草果(草果仁、老蔻)
- **来源**: 姜科植物草果 *Amomum tsao-ko* Crevost et Lemaire 的干燥成熟果实
- **分布与生境**: 云南、广西、贵州的山谷林下阴湿处,多栽培;也是常见调料
- **识别要点**:
  - 植株: 多年生丛生草本,高2-3 m;叶二列,长椭圆形;花序从根茎抽出;蒴果密集成穗,熟时红色
  - 药材: **长椭圆形,具三钝棱**,长2-4 cm,直径1-2.5 cm;表面**灰棕色至红棕色**,有纵沟和棱线,顶端有圆形突起的柱基;果皮坚韧,易纵向撕裂;剥开后中间有黄棕色隔膜将种子团分成3瓣,每瓣多为8-11粒;种子圆锥状多面体,直径约5 mm,红棕色,外被灰白色膜质假种皮;**有特异香气**,味辛、微苦
- **易混淆品**: 比砂仁、豆蔻大得多,一般不易混淆;注意霉变
- **采收与加工**: 秋季果实成熟时采收,除去杂质,晒干或低温干燥
- **储存**: 密封防潮、防走气
- **功效**: 燥湿温中,截疟除痰
- **用量**: 3-6 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚血少、无寒湿的人慎用。"截疟"是古代用法,**疟疾必须就医用抗疟药**,不能靠草果

### 5.4 薏苡仁

- **正名(别名)**: 薏苡仁(薏米、苡仁、六谷米)
- **来源**: 禾本科植物薏米 *Coix lacryma-jobi* L. var. *ma-yuen* (Roman.) Stapf 的干燥成熟种仁
- **分布与生境**: 贵州、广西、福建、浙江、云南等地栽培;野生近缘种(川谷、"草珠子")生于溪边、湿地
- **识别要点**:
  - 植株: 一年生粗壮草本,高1-2 m,像玉米苗;叶片宽线形;果实包在**骨质、有光泽的总苞**里(野生川谷的总苞很硬,白色、灰色或黑色,小孩常用来串珠子;栽培薏米的总苞较薄、易破)
  - 药材: 宽卵形或长椭圆形,长4-8 mm,宽3-6 mm;表面**乳白色**,光滑,偶有残存的黄褐色种皮;一端钝圆,另端较宽而微凹,有淡棕色点状种脐;**腹面有1条较宽而深的纵沟**;质坚实,断面白色,粉性;味微甜
- **易混淆品/伪品**: 用大麦仁、高粱米加工冒充(没有那条又宽又深的纵沟);川谷的种仁较小,不作薏苡仁用
- **采收与加工**: 秋季果实成熟时采割植株,晒干,打下果实,再晒干,除去外壳、黄褐色种皮和杂质,收集种仁
- **储存**: 富含淀粉,**极易虫蛀、发霉**;**发霉、变黄、有霉味的不要再吃**(可能产生黄曲霉毒素,伤肝致癌)
- **功效**: 利水渗湿,健脾止泻,除痹,排脓,解毒散结
- **用量**: 9-30 g(《中国药典》2020年版,在中医师指导下使用);作杂粮少量食用一般是安全的
- **禁忌**: **孕妇慎用**;津液不足、大便干结的人不宜多用

### 5.5 车前子

- **正名(别名)**: 车前子(车前实、凤眼前仁)
- **来源**: 车前科植物车前 *Plantago asiatica* L. 或平车前 *P. depressa* Willd. 的干燥成熟种子
- **分布与生境**: 全国各地的路边、田埂、草地、宅旁,极常见
- **识别要点**:
  - 植株: 草本,**叶全部基生,排成莲座状**,卵形或椭圆形,有**5-7条弧形脉**(撕断叶柄可见筋丝);穗状花序细长直立;蒴果成熟时**横裂,上半部像盖子一样脱落**。车前须根多;平车前有直主根,叶较窄
  - 药材: 椭圆形、不规则长圆形或三角状长圆形,略扁,长约2 mm,宽约1 mm;表面**黄棕色至黑褐色**,有细皱纹,一面有灰白色凹点状种脐;质硬;味淡
  - 水试: 放入水中,表面很快产生**黏液**,种子周围出现透明的黏液层
- **易混淆品**: 葶苈子、荆芥子等其他小种子;水试有黏液、有灰白色种脐的是车前子
- **采收与加工**: 夏、秋二季种子成熟时采收果穗,晒干,搓出种子,除去杂质。路边的车前可能受尾气、粉尘、除草剂污染,选干净的地方采
- **储存**: 种子细小,易混入泥沙;放干燥处
- **功效**: 清热利尿通淋,渗湿止泻,明目,祛痰
- **用量**: 9-15 g,**包煎**(用纱布袋装好再煎,否则黏液使药汁黏稠、容易糊锅)(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 肾虚滑精、无湿热的人慎用;正在服利尿药的人先问医生。尿频尿痛、血尿要先就医。车前的全草(车前草)见第04章全草类

### 5.6 木瓜

- **正名(别名)**: 木瓜(皱皮木瓜、宣木瓜、贴梗海棠)
- **来源**: 蔷薇科植物贴梗海棠 *Chaenomeles speciosa* (Sweet) Nakai 的干燥近成熟果实
- **分布与生境**: 安徽(宣城,"宣木瓜")、湖北、四川、浙江等地栽培;也常作庭院观赏花木
- **识别要点**:
  - 植株: 落叶灌木,枝有刺;早春开花,**花猩红色或淡红色,紧贴在枝上**(故称"贴梗");梨果球形或卵形,黄色或带红色,有香气
  - 药材: 长圆形,**多纵剖成两半**,长4-9 cm,宽2-5 cm;外表面**紫红色或红棕色,有不规则的深皱纹**;剖面边缘向内卷曲,果肉红棕色,中心部分凹陷,棕黄色;质坚硬;气微清香,**味酸**
- **易混淆品**: "光皮木瓜"(木瓜海棠/榠楂的果实)表面平滑不皱,是另一种;超市卖的水果"木瓜"是**番木瓜**(番木瓜科),和药材木瓜毫无关系
- **采收与加工**: 夏、秋二季果实绿黄时采收,置沸水中烫至外皮灰白色,对半纵剖,晒干(晒后果皮皱缩)
- **储存**: 放干燥处,防霉、虫蛀
- **功效**: 舒筋活络,和胃化湿
- **用量**: 6-9 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 内有郁热、小便短赤的人不宜;胃酸过多的人慎用

## 六、温里类

温里药性温热、辛辣,用于腹部冷痛、呕吐。**阴虚火旺(口干、手足心热、易上火)的人、孕妇不宜多用**。吴茱萸有小毒,不要自行使用;小茴香和花椒是日常调料,作调料用的量一般是安全的。

### 6.1 吴茱萸

- **正名(别名)**: 吴茱萸(吴萸、茶辣、辣子)
- **来源**: 芸香科植物吴茱萸 *Euodia rutaecarpa* (Juss.) Benth.、石虎 *E. rutaecarpa* (Juss.) Benth. var. *officinalis* (Dode) Huang 或疏毛吴茱萸 *E. rutaecarpa* (Juss.) Benth. var. *bodinieri* (Dode) Huang 的干燥近成熟果实
- **分布与生境**: 贵州、广西、湖南、浙江、江西、四川等地的山地疏林、林缘,多栽培
- **识别要点**:
  - 植株: 灌木或小乔木;**奇数羽状复叶对生**,小叶对光可见**透明油点**,揉碎有强烈气味;聚伞圆锥花序顶生;果实紫红色,有粗大腺点
  - 药材: **球形或略呈五角状扁球形**,直径2-5 mm;表面暗黄绿色至褐色,粗糙,有多数点状突起或凹下的油点;**顶端有五角星状的裂隙**,基部残留被有黄色茸毛的果梗;质硬而脆;**气芳香浓郁,味辛辣而苦**
- **易混淆品**: **与山茱萸只差一字**,一个有毒、一个是补益药(见[2.1](#21-山茱萸)),抓药、写方时一定核对。同属其他植物的果实也有混入
- **毒性**(重点):
  - 药典标注"**有小毒**"。现代研究证实有**肝毒性**,主要与吴茱萸碱等生物碱和挥发油有关
  - 过量的表现: 剧烈腹痛、腹泻、呕吐,头痛、眩晕、胸闷,视力障碍、错觉,皮疹;严重的肝功能损害
- **采收与加工**: 8-11月果实尚未开裂时,剪下果枝,晒干或低温干燥,除去枝、叶、果梗等杂质
- **储存**: 单独存放,标明"有毒",放在儿童拿不到的地方;密封防走气
- **功效**: 散寒止痛,降逆止呕,助阳止泻
- **用量**: 药典规定2-5 g;外用适量。**有毒,不要自行使用**——只能由中医师开方、从正规药房取药
- **禁忌**: 不长期服、不加量;阴虚有热的人忌用;孕妇、儿童、肝病患者不用。出现中毒表现立即就医,见[中毒的通用处理](09-有毒中药与易混淆有毒植物.md#五中毒的通用处理)

### 6.2 小茴香

- **正名(别名)**: 小茴香(茴香、谷茴香、小茴)
- **来源**: 伞形科植物茴香 *Foeniculum vulgare* Mill. 的干燥成熟果实
- **分布与生境**: 全国各地栽培,嫩茎叶是蔬菜"茴香菜"
- **识别要点**:
  - 植株: 草本,高0.4-2 m,全株有强烈茴香气味;**叶多回羽状细裂成丝状**;复伞形花序,花黄色
  - 药材: 双悬果,**圆柱形**,有的稍弯曲,长4-8 mm,直径1.5-2.5 mm;表面黄绿色或淡黄色,两端略尖,顶端有黄棕色突起的柱基;分果长椭圆形,**背面有纵棱5条**,接合面平坦而较宽;**有特异香气,味微甜、辛**
- **易混淆品**:
  - 莳萝子(扁平,边缘有翅)、孜然等调料种子,气味不同
  - **"大茴香"(八角茴香)是另一味药**。要警惕**莽草、红茴香**等有毒的八角属果实混入八角: 有毒品蓇葖多于8个、顶端尖而**弯成鸟喙状**、气味弱或不正;误食可致呕吐、抽搐
  - 伞形科有毒植物(毒芹等)的果实外形也相近——**只用栽培的、气味确认的茴香**,不在野外采伞形科果实
- **采收与加工**: 秋季果实初熟时采割植株,晒干,打下果实,除去杂质
- **储存**: 密封,防走气、虫蛀
- **功效**: 散寒止痛,理气和胃
- **用量**: 3-6 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺的人慎用。疝气、睾丸疼痛肿胀要先就医排除急症(如睾丸扭转、嵌顿疝)

### 6.3 花椒

- **正名(别名)**: 花椒(川椒、蜀椒、青花椒)
- **来源**: 芸香科植物青椒 *Zanthoxylum schinifolium* Sieb. et Zucc. 或花椒 *Z. bungeanum* Maxim. 的干燥成熟**果皮**
- **分布与生境**: 四川、陕西、甘肃、河北、山东、山西等地,多栽培
- **识别要点**:
  - 植株: 灌木或小乔木,**枝干和叶轴上有皮刺**;奇数羽状复叶,小叶边缘有细齿,齿缝处有透明油点;果实球形,熟时红色(花椒)或绿色(青椒),表面有疣状油点
  - 花椒药材: 蓇葖果多单生,直径4-5 mm;外表面**紫红色或棕红色**,散有多数**疣状突起的油点**,对光观察半透明;内表面淡黄色;**香气浓,味麻辣而持久**
  - 青椒药材: 多为2-3个上部离生的小蓇葖果,直径3-4 mm;外表面**灰绿色或暗绿色**,有网状隆起皱纹;残存种子卵形,黑色,有光泽;气香,味微甜而辛
- **易混淆品**: 野花椒、竹叶花椒等同属植物的果皮,麻味较弱或气味不同,多为地方习用。黑色的种子叫"椒目",是另一味药,入药时要除去
- **采收与加工**: 秋季采收成熟果实,晒干,除去种子和杂质。采摘时戴手套,防皮刺
- **储存**: 密封,防走气、受潮
- **功效**: 温中止痛,杀虫止痒
- **用量**: 3-6 g;外用适量,煎汤熏洗(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺的人慎用;孕妇不宜多用。外用熏洗注意不要烫伤,皮肤破损处不用

## 七、止咳润肠类

这一组都是富含油脂的种子,能润肠通便,苦杏仁、桃仁、紫苏子还能止咳平喘。**苦杏仁和桃仁含苦杏仁苷,生食过量会氰化物中毒**;种子富含油脂,储存时都要防走油。

### 7.1 苦杏仁

- **正名(别名)**: 苦杏仁(北杏仁、杏仁)
- **来源**: 蔷薇科植物山杏 *Prunus armeniaca* L. var. *ansu* Maxim.、西伯利亚杏 *P. sibirica* L.、东北杏 *P. mandshurica* (Maxim.) Koehne 或杏 *P. armeniaca* L. 的干燥成熟种子
- **分布与生境**: 华北、西北、东北的山坡、丘陵,野生或栽培
- **识别要点**:
  - 药材: **扁心形**,长1-1.9 cm,宽0.8-1.5 cm,厚0.5-0.8 cm;表面黄棕色至深棕色;一端尖,另端钝圆、肥厚,**左右不对称**;尖端一侧有短线形种脐,圆端合点处向上有多数深棕色脉纹;种皮薄,子叶2,乳白色,富油性;**味苦**
- **易混淆品**: 零食"甜杏仁"(南杏)较大而扁、味不苦;"美国大杏仁"实为扁桃仁。**桃仁**外形相近,较扁长、表面有颗粒状突起(见[7.2](#72-桃仁))
- **毒性**(重点):
  - 药典标注"**有小毒**"。含**苦杏仁苷**,在体内分解释放**氢氰酸(氰化物)**
  - 中毒表现(食后半小时至数小时): 口中苦涩、流涎、恶心、呕吐、头晕、头痛、心慌,呼吸急促,严重时意识丧失、抽搐、呼吸停止。**儿童吃十几粒生苦杏仁就可能严重中毒**
  - 详见[苦杏仁](09-有毒中药与易混淆有毒植物.md#412-苦杏仁)
- **采收与加工**: 夏季采收成熟果实,除去果肉和核壳,取出种子,晒干
- **储存**: 富含油脂,**极易走油、虫蛀**;低温、避光、密封,不宜久存;单独存放,放在儿童拿不到的地方
- **功效**: 降气止咳平喘,润肠通便
- **用量**: 5-10 g,生品入煎剂**后下**(《中国药典》2020年版,在中医师指导下使用)。**内服不宜过量**
- **禁忌**: **不要生吃**,不要自己砸杏核吃仁;婴儿、儿童不自行使用;孕妇、大便溏泻的人慎用。误食后出现上述症状,立即拨打120

### 7.2 桃仁

- **正名(别名)**: 桃仁(毛桃仁、山桃仁)
- **来源**: 蔷薇科植物桃 *Prunus persica* (L.) Batsch 或山桃 *P. davidiana* (Carr.) Franch. 的干燥成熟种子
- **分布与生境**: 桃全国各地栽培;山桃野生于华北、西北的山坡、沟谷
- **识别要点**:
  - 桃仁: **扁长卵形**,长1.2-1.8 cm,宽0.8-1.2 cm,厚0.2-0.4 cm;表面黄棕色至红棕色,**密布颗粒状突起**;一端尖,中部膨大,另端钝圆稍偏斜,边缘较薄;子叶2,类白色,富油性;味微苦
  - 山桃仁: 类卵圆形,较小而肥厚,长约0.9 cm,宽约0.7 cm,厚约0.5 cm
- **与苦杏仁的区别**: 杏仁**心形、较厚、表面较光**;桃仁**扁长、较薄、表面有颗粒状突起**。两者都含苦杏仁苷,都不能生吃过量
- **⚠️ 氰苷中毒风险**: 桃仁同样含苦杏仁苷,**生食过量可引起氰化物中毒**,表现同苦杏仁(见[7.1](#71-苦杏仁)和[苦杏仁](09-有毒中药与易混淆有毒植物.md#412-苦杏仁));儿童不要砸桃核吃仁
- **采收与加工**: 果实成熟后采收,除去果肉和核壳,取出种子,晒干
- **储存**: 同苦杏仁,极易走油;低温、避光、密封
- **功效**: 活血祛瘀,润肠通便,止咳平喘
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**(活血);月经过多、有出血倾向、正在服抗凝药或抗血小板药的人先问医生;大便溏泻的人不宜

### 7.3 紫苏子

- **正名(别名)**: 紫苏子(苏子、黑苏子)
- **来源**: 唇形科植物紫苏 *Perilla frutescens* (L.) Britt. 的干燥成熟果实
- **分布与生境**: 全国各地栽培,也有逸为野生的;叶是常见调味蔬菜
- **识别要点**:
  - 植株: 一年生草本,**茎四棱形**,叶对生,**叶两面或背面紫色**,有特殊香气;轮伞花序组成总状,花淡紫色(唇形科特征)
  - 药材: **卵圆形或类球形**,直径约1.5 mm;表面灰棕色或灰褐色,有微隆起的**暗紫色网纹**;基部稍尖,有灰白色点状果梗痕;果皮薄而脆,易压碎;种子黄白色,子叶类白色,有油性;**压碎有香气**,味微辛
- **易混淆品**: 白苏(叶绿色的变种)的种子较大、灰白色,习称"白苏子",不作紫苏子用;其他唇形科小坚果气味不同
- **采收与加工**: 秋季果实成熟时采收,除去杂质,晒干
- **储存**: 富含油脂,**易走油**、产生哈喇味;密封,低温避光
- **功效**: 降气化痰,止咳平喘,润肠通便
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾虚便溏的人慎用。气喘、呼吸困难先就医;紫苏叶见第05章花叶类

### 7.4 火麻仁

- **正名(别名)**: 火麻仁(麻子仁、大麻仁、火麻子)
- **来源**: 桑科植物大麻 *Cannabis sativa* L. 的干燥成熟果实
- **分布与生境**: 历史上各地栽培取纤维和籽;现在**大麻植株的种植受国家严格管制**
- **识别要点**:
  - 药材: **卵圆形**,长4-5.5 mm,直径2.5-4 mm;表面**灰绿色或灰黄色**,有微细的白色或棕色网纹,两边有棱,顶端略尖,基部有圆形果梗痕;果皮薄而脆,易破碎;种皮绿色,子叶2,乳白色,富油性;味淡
- **易混淆品**: 一般不易混淆;注意霉变和哈喇味
- **法律提醒**: 大麻是毒品原植物。根据《禁毒法》等规定,**未经许可种植大麻属植物是违法的**(工业大麻需取得许可);药用火麻仁从正规药店购买,**不要自行种植大麻**
- **采收与加工**: 秋季果实成熟时采收,除去杂质,晒干
- **储存**: 富含油脂,**极易走油**;密封,低温避光
- **功效**: 润肠通便
- **用量**: 10-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **不要大量食用**: 一次大量吃火麻仁(尤其连壳炒食)有引起中毒的报道,表现为恶心、呕吐、腹泻、四肢发麻、烦躁或嗜睡,严重时昏迷。脾虚腹泻的人不宜。长期便秘要就医查原因

## 八、驱虫类

**怀疑有寄生虫,先就医做粪便检查,确认是哪种虫**。现代驱虫药(如阿苯达唑、吡喹酮)效果确切、用法简单,能买到时优先用。传统驱虫药用量与中毒剂量接近,儿童尤其要在医生指导下用。

### 8.1 使君子

- **正名(别名)**: 使君子(留求子、史君子)
- **来源**: 使君子科植物使君子 *Quisqualis indica* L. 的干燥成熟果实
- **分布与生境**: 四川、福建、广东、广西、云南等地;山坡、路旁灌丛,也栽培作观赏藤本
- **识别要点**:
  - 植株: 攀援状灌木;叶对生,卵形;**花筒细长,花瓣初开白色,后变淡红至红色**,一串花上颜色深浅不同,有香气;果实有5棱
  - 药材: **椭圆形或卵圆形,具5条纵棱**,长2.5-4 cm,直径约2 cm;表面**黑褐色至紫黑色**,平滑,微有光泽;顶端狭尖,基部钝圆;质坚硬,**横切面多呈五角星形**,中间为类圆形空腔;种子长椭圆形或纺锤形,长约2 cm,表面棕褐色,有纵皱纹;子叶黄白色,有油性;气微香,味微甜
- **易混淆品**: 外形特殊(五棱、紫黑色),一般不易混淆
- **采收与加工**: 秋季果皮变紫黑色时采收,除去杂质,干燥
- **储存**: 易走油、虫蛀;单独存放,放在儿童拿不到的地方(种仁味甜,儿童容易多吃)
- **功效**: 杀虫消积
- **用量**: 使君子9-12 g,捣碎入煎剂;使君子仁6-9 g,多入丸散或单用,分1-2次服。小儿每岁1-1.5粒,炒香嚼服,**一日总量不超过20粒**(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **服药时忌饮浓茶**(同服易引起呃逆)。**过量**可引起呃逆(打嗝不止)、眩晕、恶心、呕吐、腹泻,严重时抽搐;不要多吃、不要生吃大量种仁。儿童驱虫先就医确诊

### 8.2 槟榔

- **正名(别名)**: 槟榔(大腹子、槟榔子、海南子)
- **来源**: 棕榈科植物槟榔 *Areca catechu* L. 的干燥成熟种子
- **分布与生境**: 海南、云南、台湾栽培;东南亚、南亚广泛种植
- **识别要点**:
  - 植株: 常绿乔木,茎直立不分枝,**有明显的环状叶痕**,树形像椰子树但更细高;羽状复叶聚生茎顶;果实卵球形,熟时橙黄色
  - 药材: **扁球形或圆锥形**,高1.5-3.5 cm,底部直径1.5-3 cm;表面淡黄棕色或淡红棕色,有稍凹下的网状沟纹,底部中心有圆形凹陷的珠孔;质坚硬,不易破碎;**断面可见棕色种皮与白色胚乳相间的大理石样花纹**;味涩、微苦
- **相关品**: 果皮是另一味药"大腹皮";嚼食用的"槟榔"多是未成熟果实加工的,和药材不是同一个东西
- **⚠️ 一类致癌物**: 国际癌症研究机构(IARC)把**槟榔果**列为**一类致癌物**(对人类有明确致癌性)。**长期嚼食槟榔(无论是否加烟草)会引起口腔黏膜下纤维化(张口困难)、口腔白斑和口腔癌**;槟榔碱还可引起心跳加快、血压升高、成瘾。**不要嚼食槟榔**;已经在嚼的,口腔里出现白斑、溃疡两周不愈、张口受限,尽快去口腔科检查
- **采收与加工**: 春末至秋初采收成熟果实,用水煮后干燥,除去果皮,取出种子,干燥
- **储存**: 易虫蛀、发霉;放干燥处
- **功效**: 杀虫,消积,行气,利水,截疟
- **用量**: 3-10 g;驱绦虫、姜片虫30-60 g(《中国药典》2020年版,**必须在医生指导下使用**)。驱虫的大剂量只能短期用,不能长期服
- **禁忌**: 过量可引起流涎、呕吐、腹泻、心跳变慢、抽搐;**孕妇、儿童不自行使用**;脾虚便溏、气虚下陷的人不宜;心脏病、哮喘患者慎用

## 九、本章小结

### 9.1 易混淆与风险汇总

| 本章品种 | 主要风险 | 怎样避免 |
|---------|---------|---------|
| 苦杏仁、桃仁、梅杏桃李核仁 | 生食过量氰化物中毒 | 不生吃,不砸核吃仁;儿童尤其注意 |
| 白扁豆(及扁豆、四季豆) | 生食、没煮透中毒 | 彻底煮熟,不凉拌、不只焯一下 |

| 牛蒡子 | 混采苍耳子(伤肝) | 认准球形刺果和大叶;苍耳刺果纺锤形 |
| 决明子 | 长期当茶致腹泻;望江南子(有毒)混入 | 不长期喝;看种子形状 |
| 补骨脂 | 肝损伤、光敏性皮炎 | 不长期服,服用期间避免日晒 |
| 槟榔 | 嚼食致口腔癌 | 不嚼食;药用只在医生指导下短期用 |
| 枳实、枳壳、青皮、桃仁、薏苡仁、槟榔 | 孕妇慎用 | 孕期一律先问医生 |
| 小茴香、八角 | 有毒八角属果实(莽草)混入 | 只用栽培、气味确认的;不采野外伞形科果实 |
| 枸杞、山茱萸、五味子、火麻仁、苦杏仁等含糖含油的 | 走油、虫蛀、发霉 | 低温、避光、密封;霉变、哈喇味的不用 |
| 火麻仁 | 大量食用中毒;大麻种植违法 | 正规药店购买,不自种 |

### 9.2 自我检查

采收或使用果实种子类药材之前,逐条确认:

- [ ] 我认准了整株植物(叶、花、果),不是只凭一把种子判断
- [ ] 我知道它最容易和哪种有毒植物混淆(苍耳子、苦楝子、望江南子、莽草等),并核对了区别
- [ ] 需要煮熟的(白扁豆)我会彻底煮熟;苦杏仁、桃仁不生吃
- [ ] 川楝子、吴茱萸这类有毒的,我不自行使用
- [ ] 果实采自干净的地方,不是行道树、公路边、喷过农药的田
- [ ] 我知道它是否容易走油、虫蛀,用什么方法储存;霉变的会扔掉
- [ ] 它不是连翘、五味子等野生资源受保护的品种,或我只采了一部分、留下了母株
- [ ] 我知道药典用量和禁忌,使用前会问中医师;孕妇、儿童、肝肾病人和长期服药的人先问医生

| 环节 | 难度 | 出错的风险 |
|------|------|----------|
| 认栽培品和食用品(枸杞、大枣、山楂、莲子、薏米、花椒) | ⭐ | ☠️(买到染色、硫熏、霉变品) |
| 认常见野生品(车前子、女贞子、金樱子、酸枣仁) | ⭐⭐ | ☠️☠️(污染、混入杂草种子) |
| 野外区分牛蒡子与苍耳子、决明子与望江南子 | ⭐⭐⭐ | ☠️☠️☠️(肝损伤、中毒) |
| 苦杏仁、桃仁、白扁豆的安全处理 | ⭐⭐ | ☠️☠️☠️☠️(氰化物中毒、凝集素中毒) |
| 川楝子、吴茱萸、槟榔大剂量驱虫 | 不适合自行使用 | ☠️☠️☠️☠️ |

## 📝 本章要点

```
□ 苦杏仁、桃仁不生吃,梅、杏、桃、李、枇杷的核仁不砸开吃
□ 白扁豆、四季豆一定要煮透
□ 川楝子、吴茱萸有毒,不要自行使用;苦楝子更毒
□ 牛蒡子和苍耳子都带钩刺,苍耳子有毒伤肝,不要混采
□ 槟榔是一类致癌物,不要嚼食
□ 补骨脂伤肝、致光敏;决明子、胖大海不长期当茶喝
□ 山茱萸(补)和吴茱萸(毒)只差一字,抓药核对
□ 种子类最易走油、虫蛀、发霉,霉变的一律不吃
□ 孕妇慎用枳实、枳壳、青皮、桃仁、薏苡仁、槟榔
```
