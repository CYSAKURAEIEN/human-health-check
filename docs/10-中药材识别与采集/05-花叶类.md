# 花叶类

> **花和叶是最"好看"的一类药材——也正因为好看、好卖,伪品和染色品最多;花要看形状、闻香气、泡在水里看颜色,叶要看叶脉、摸绒毛、揉碎闻味,光凭颜色鲜艳不能断定是好药**

本章收录23味常用的花类和叶类药材(药用部位是花蕾、开放的花、头状花序、柱头、花粉、叶或带叶的枝梢),按功效大致分为清热解毒的花、活血理气的花、化痰通窍安神温里的花、疏散清热的叶、止咳止血温经的叶,以及需要特别小心的叶六组。识别、采收、干燥、储存的通用方法见[总论](./00-总论.md),本章不再重复。金银花、菊花、艾草的种植方法已写在[药用植物识别与种植指南](../04-动植物培育/04-药用植物.md),本章只写识别和采集。

## ⚠️ 先读这几条

```
1. 花类药材贵、轻、颜色好看,是染色和增重造假的重灾区:
   - 西红花、红花: 常见染色的玉米须、纸浆丝、莲须冒充,
     或者掺糖、盐、明矾、油增重
   - 用"水试"先筛一遍: 放进清水里看掉不掉色、怎么掉色(见2.2)
2. 金银花 vs 钩吻(断肠草): 两者都是缠绕藤本、叶对生、开黄花,
   钩吻吃几片叶子就能致死;花不是"两朵并生、唇形、黄白相间"的,
   不采花、不采叶、不碰藤
3. 观赏花卉、花店切花、公园行道树的花和叶多打过农药,
   不入药、不泡茶;"玫瑰"切花绝大多数其实是月季
4. 番泻叶是刺激性泻药: 只能短期偶尔用,
   长期用会成依赖、低血钾、结肠黑变;不能用来减肥;
   孕妇、哺乳期、月经期禁用
5. 银杏叶生叶含银杏酸(致敏、有毒性),
   正规制剂要专门除去;不要自己采叶泡茶
6. 红花、西红花、蒲黄、月季花等活血药孕妇不用;
   服华法林、阿司匹林等抗凝、抗血小板药的人用前先问医生
   (银杏叶、丹参类同理)
7. 艾叶药典标注"有小毒": 不要大量内服;艾灸注意烫伤和烟雾
8. 款冬花含吡咯里西啶生物碱(伤肝),不长期大量服,
   孕妇、哺乳期、儿童不用
9. 用量是《中国药典》(2020年版)成人每日的常规用量(饮片,水煎),
   只用来提醒"不要超量";用不用、用多少,在中医师指导下决定
```

## 一、清热解毒的花

这一组的花多在夏秋采收,讲究"采花蕾、不采盛开的花",采后要快干、防变色。金银花和槐花都是野外、村旁能见到的,但各有一个危险或常见的混淆对象: 金银花防钩吻,槐花防洋槐。

### 1.1 金银花

- **正名(别名)**: 金银花(忍冬花、双花、二宝花)
- **来源**: 忍冬科植物忍冬 *Lonicera japonica* Thunb. 的干燥花蕾或带初开的花
- **分布与生境**: 全国大部分地区有野生,山坡灌丛、林缘、路旁、村边篱笆;山东、河南、河北等地大量栽培
- **识别要点**:
  - 植株: 半常绿缠绕藤本,幼枝有柔毛;**叶对生**,卵形至长圆形,两面常有柔毛;**两朵花并生在一个花梗上**,生于叶腋;花冠**唇形**(上唇4浅裂、下唇1片),雄蕊伸出花冠外;**初开白色、后变黄色**,同一株上常黄白并存;浆果球形,熟时黑色
  - 药材: 花蕾**棒状,上粗下细**,略弯曲,长2-3 cm;表面黄白色或绿白色,**密被短柔毛**;偶见开放的花,花冠筒状,先端二唇形
  - 气味: 气清香,味淡、微苦
- **易混淆品**:
  - **钩吻(断肠草)**: 也是缠绕藤本、叶对生、开黄花,**剧毒**;它的叶光滑无毛,花多朵聚成花序、**漏斗状整齐5裂、只有黄色**。详细对照见[钩吻 vs 金银花](./09-有毒中药与易混淆有毒植物.md#42-钩吻-vs-金银花)
  - **山银花**: 灰毡毛忍冬、红腺忍冬、华南忍冬、黄褐毛忍冬的花蕾,药典另列"山银花",功效相近但不能当金银花;多数花蕾较长、毛较少或有腺毛
  - 商品中偶见用硫磺熏、用糖或明矾水增重的: 颜色过于鲜亮、有酸味或摸着发黏的不要
- **采收与加工**: 夏初**花开放前**(花蕾由绿变白、上部膨大时)清晨采摘;摊薄晾干或低温烘干,**干燥前不要翻动、不要用手揉**,否则变黑
- **储存**: 易吸潮变色、生虫;密封,放阴凉干燥处
- **功效**: 清热解毒,疏散风热
- **用量**: 6-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒、大便稀溏者慎用(经验)
- 种植方法见[药用植物-金银花](../04-动植物培育/04-药用植物.md#金银花忍冬);藤茎"忍冬藤"见第06章

### 1.2 菊花

- **正名(别名)**: 菊花(按产地和加工分亳菊、滁菊、贡菊、杭菊、怀菊)
- **来源**: 菊科植物菊 *Chrysanthemum morifolium* Ramat. 的干燥头状花序
- **分布与生境**: 栽培品,安徽(亳州、滁州、歙县)、浙江(桐乡)、河南(焦作)等地为主产区;没有真正的野生"药菊"
- **识别要点**:
  - 植株: 多年生草本,茎基部木质化;叶互生,卵形,羽状浅裂或半裂,下面有白色短柔毛;秋季开花
  - 药材: 头状花序,外层是多层**舌状花**(白色、类白色或黄色),中央是**管状花**(黄色,多隐藏);总苞碟状,苞片3-4层,有柔毛。亳菊、滁菊花朵较松散,贡菊、杭菊花朵较紧、扁平
  - 气味: **气清香**,味甘、微苦
- **易混淆品**:
  - **观赏菊、盆栽菊**: 品种不同,且多打过农药,不入药、不泡茶
  - **野菊花**(见1.3): 头状花序小得多,黄色,味苦得多
  - **硫磺熏过的菊花**: 颜色异常洁白鲜亮、闻着有刺鼻酸味,少买
- **采收与加工**: 9-11月花盛开时分批采收;阴干或焙干,或熏、蒸后晒干(各产区工艺不同)
- **储存**: 易受潮、变色、生虫;密封,阴凉避光
- **功效**: 散风清热,平肝明目,清热解毒
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒者少用(经验);对菊科植物过敏者(如对艾草、豚草过敏)可能过敏
- 种植方法见[药用植物-菊花](../04-动植物培育/04-药用植物.md#菊花)

### 1.3 野菊花

- **正名(别名)**: 野菊花(苦薏、野黄菊)
- **来源**: 菊科植物野菊 *Chrysanthemum indicum* L. 的干燥头状花序
- **分布与生境**: 全国广布,山坡草地、灌丛、河边、田边、路旁
- **识别要点**:
  - 植株: 多年生草本,高25-100 cm;叶互生,卵形或长卵形,**羽状半裂至浅裂**,有柄;秋季顶端开多个**小黄菊**,直径约1.5-2.5 cm,**舌状花黄色、只有1层**
  - 药材: 头状花序类球形,直径约0.3-1 cm,棕黄色;总苞片4-5层,外层卵形,边缘膜质;舌状花1轮,黄色至棕黄色,皱缩卷曲;管状花多数
  - 气味: 气芳香,**味苦**(比菊花苦得多)
- **易混淆品**: **甘菊**(岩香菊、野甘菊 *C. lavandulifolium*)、**旋覆花**(见3.3)、各种黄色小花的菊科野草。甘菊叶二回羽状深裂、花更小;旋覆花的舌状花细长、苞片条形。多数无毒,但不是药典野菊花
- **采收与加工**: 秋、冬二季**花初开放时**采摘;晒干,或蒸后晒干
- **储存**: 防潮、防虫,密封
- **功效**: 清热解毒,泻火平肝
- **用量**: 9-15 g;外用适量,煎汤外洗或制膏外涂(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 苦寒,脾胃虚寒者慎用,不宜长期当茶喝(经验);菊科过敏者慎用

### 1.4 槐花

- **正名(别名)**: 槐花(开放的花);槐米(花蕾)
- **来源**: 豆科植物槐 *Sophora japonica* L. 的干燥花及花蕾,前者习称"槐花",后者习称"槐米"
- **分布与生境**: 全国各地普遍栽培,北方村旁、路旁、庭院最常见(俗称"国槐")
- **识别要点**:
  - 植株: 落叶乔木,**枝上没有刺**,小枝绿色;奇数羽状复叶,小叶7-15片,卵状长圆形;**盛夏(7-8月)开花**,圆锥花序顶生,花淡黄白色、蝶形;荚果肉质,**串珠状**(这就是"槐角")
  - 药材: **槐米**卵形或椭圆形,长2-6 mm,黄绿色,下部花萼有数条纵纹;**槐花**皱缩卷曲,花瓣多散落,完整者花萼钟状、黄绿色,花瓣5片,黄色或黄白色,其中1片较大(旗瓣)
  - 气味: 气微,味微苦
- **易混淆品**:
  - **刺槐(洋槐)** *Robinia pseudoacacia*: 很多地方做"槐花饭"、蒸槐花吃的其实是它。区别: 刺槐**枝上有成对的托叶刺**,**春季(4-5月)开花**,花白色、有浓香、成串下垂,荚果扁平。花作野菜可吃,但**树皮、叶、种子有毒**;它不是药典的槐花
  - 槐花常被染色或掺杂花梗、沙土增重,黄绿色异常鲜艳的少买
- **采收与加工**: 夏季**花蕾形成时**采槐米,**花开放时**采槐花;及时干燥,除去枝梗和杂质。药用以槐米为佳(芦丁含量高)
- **储存**: 防潮、防霉,密封
- **功效**: 凉血止血,清肝泻火
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 脾胃虚寒者慎用(经验);便血、痔疮出血必须先查清原因,不要只靠槐花止血

## 二、活血理气的花

这一组多数**孕妇不用或慎用**,有出血倾向、月经量多、服抗凝药的人也要先问医生。红花和西红花价格高,伪品最多,是练习"水试"的好例子;水试的通用方法见[总论-简单的水试与火试](./00-总论.md#33-简单的水试与火试)。

### 2.1 红花

- **正名(别名)**: 红花(草红花、红蓝花)
- **来源**: 菊科植物红花 *Carthamus tinctorius* L. 的干燥花
- **分布与生境**: 栽培品,新疆、河南、四川、云南、甘肃等地种植;野外没有野生的
- **识别要点**:
  - 植株: 一年生草本,高30-100 cm;叶互生,长椭圆形,**边缘有刺齿**,总苞片也带刺;头状花序全是管状花,开花时由黄变橙红
  - 药材: 为不带子房的管状花,长1-2 cm;**红黄色或红色**,花冠筒细长,先端5裂,裂片狭条形;雄蕊5枚,花药聚合成筒状,黄白色;质柔软
  - 气味: 气微香,味微苦
  - 水试: 浸入水中,**水被染成金黄色**(溶出的是红花黄色素;红色素不溶于水,花本身仍保留红色)
- **易混淆品/伪品**:
  - **染色品**: 用色素染红的劣质红花或其他花丝,泡水后水变成**红色**或很快大量掉色,手捏染色
  - **增重品**: 掺糖、盐、明矾、沙土、植物油,手捏发黏、发沉,有咸味、甜味或油迹
  - 红花也常被染色后冒充西红花(见2.2)
- **采收与加工**: 夏季**花由黄变红时**清晨采摘(带露水时总苞刺软,不扎手);阴干或晒干,不宜暴晒过久
- **储存**: 避光、防潮、防虫,密封;受潮后易霉变、颜色发暗
- **功效**: 活血通经,散瘀止痛
- **用量**: 3-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **药典标注"孕妇慎用"**,本书建议孕妇不用;月经过多、有出血倾向者不用;服抗凝、抗血小板药的人先问医生

### 2.2 西红花

- **正名(别名)**: 西红花(番红花、藏红花)
- **来源**: 鸢尾科植物番红花 *Crocus sativus* L. 的干燥柱头
- **分布与生境**: 原产地中海沿岸和伊朗(伊朗是最大产地),经西藏转运入内地故俗称"藏红花"——**西藏并不出产**;国内上海崇明、浙江建德等地有栽培(球茎多在室内开花采收)
- **识别要点**:
  - 植株: 多年生球茎草本,叶细线形,秋季开淡紫色花,花中央的花柱顶端分成**3条深红色的柱头**,这就是药材;每朵花只有3条,约15万朵花才能得到1 kg,所以极贵
  - 药材: **线形,三分枝**,长约3 cm,**暗红色**;上部较宽而略扁平,**顶端边缘有不整齐的齿状、内侧有一短裂隙**(展开呈喇叭状),下端有时残留一小段黄色花柱;体轻,质松软,无油润光泽,干后质脆易断
  - 气味: 气特异,微有刺激性,味微苦
  - **水试**(最有用的现场方法): 取少量放入清水中,可见**橙黄色像一条直线向下扩散**,水逐渐被染成**黄色**,无沉淀;柱头吸水膨胀后呈**长喇叭状、一侧有短缝**,用针拨动不易碎
- **伪品**(市场上最常见):
  - **染色的玉米须、莲须(莲花雄蕊)、纸浆丝或合成纤维**: 没有"三叉喇叭口"的结构,泡水后形状仍是单根细丝或散成纸浆
  - **染色的红花、菊花舌状花**: 泡水后可见花冠筒、花瓣等结构
  - 伪品和染色品泡水后通常**迅速掉出红色**(而非黄色),或有沉淀、水面浮油
  - **加油、加甘油增重**: 表面油亮,压在白纸上留下油迹
  - 一句话: **"便宜的藏红花"基本都是假的**
- **采收与加工**: 秋季开花期每天清晨采花,摘下柱头,低温烘干或阴干
- **储存**: **避光**(见光颜色和有效成分都会分解)、密封、阴凉干燥
- **功效**: 活血化瘀,凉血解毒,解郁安神
- **用量**: 1-3 g,煎服或沸水泡服(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **药典标注"孕妇慎用"**;它有明显的收缩子宫作用,本书建议孕妇不用;有出血倾向、服抗凝药者先问医生;一次大量服用(数克以上)可致中毒(经验)
- **另一个危险**: 园艺上的"秋水仙"(*Colchicum*,英文也叫 autumn crocus)外形和番红花相似,**全株剧毒**;不要把花园里任何像番红花的花拿来泡水喝

### 2.3 月季花

- **正名(别名)**: 月季花(月月红、四季花)
- **来源**: 蔷薇科植物月季 *Rosa chinensis* Jacq. 的干燥花
- **分布与生境**: 全国普遍栽培,庭院、公园、路边绿化
- **识别要点**:
  - 植株: 常绿或半常绿灌木;**皮刺较稀,钩状**;羽状复叶,小叶**3-5片**,**叶面平滑有光泽**;**一年多次开花**("月月红")
  - 药材: 类球形,直径1.5-2.5 cm;**花托长圆形**,萼片5,暗绿色,先端尾尖;花瓣覆瓦状排列,紫红色或淡紫红色,脉纹明显
  - 气味: 气清香,味淡、微苦
- **易混淆品**: **玫瑰花**(见2.4),两者常被混用,但药典分列,功效不同;区别看花托: 月季长圆形,玫瑰半球形
- **采收与加工**: 全年均可采收,**花微开时**采摘;阴干或低温干燥
- **储存**: 防潮、防虫、避光
- **功效**: 活血调经,疏肝解郁
- **用量**: 3-6 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用;用量不宜大,多服可致便溏腹泻(经验);**公园、花店的月季多打过农药,不采**

### 2.4 玫瑰花

- **正名(别名)**: 玫瑰花(徘徊花、刺玫花)
- **来源**: 蔷薇科植物玫瑰 *Rosa rugosa* Thunb. 的干燥花蕾
- **分布与生境**: 山东(平阴)、甘肃(苦水)、北京等地栽培;东北、山东沿海有少量野生
- **识别要点**:
  - 植株: 落叶灌木;**茎密生皮刺和刺毛**;小叶**5-9片**,**叶面明显皱褶**(种名 *rugosa* 就是"有皱纹"),下面有柔毛;**一年只开一季**(春末夏初),花紫红色,芳香浓郁
  - 药材: 略呈半球形或不规则团状,直径0.7-1.5 cm;**花托半球形**,与花萼基部合生;萼片5,披针形,黄绿色或棕绿色,被有细柔毛;花瓣多皱缩,紫红色,有的黄棕色
  - 气味: **气芳香浓郁**,味微苦涩
- **易混淆品**: 花店卖的"玫瑰"切花**几乎都是月季的杂交品种**,且农药残留高,不入药;**月季花**区别见2.3
- **采收与加工**: 春末夏初**花将开放时**分批采摘;及时**低温干燥**(高温烘烤香气会散失、颜色变暗)
- **储存**: 密封避光,防潮;香气逐渐散失,一般不超过1年
- **功效**: 行气解郁,和血,止痛
- **用量**: 3-6 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用(经验);阴虚火旺者不宜多用

### 2.5 蒲黄

- **正名(别名)**: 蒲黄(蒲棒花粉、蒲花)
- **来源**: 香蒲科植物水烛香蒲 *Typha angustifolia* L.、东方香蒲 *Typha orientalis* Presl 或同属植物的干燥花粉
- **分布与生境**: 全国各地的池塘、湖边、沼泽、沟渠浅水中
- **识别要点**:
  - 植株: 水生草本,高1-3 m;叶条形,像宽韭菜叶;夏季茎顶长出圆柱形的"**蒲棒**",上部是雄花序(黄色,散出花粉),下部是雌花序(以后变成褐色的"蒲棒");**水烛香蒲的雌雄花序之间有一段间隔,东方香蒲的则相连**
  - 药材: **黄色粉末**,体轻,**放入水中则漂浮在水面**;手捻有滑腻感,易附着在手指上
  - 气味: 气微,味淡
- **伪品**: 掺黄土、玉米粉、淀粉、其他花粉或染色的增重粉末——**放入水中下沉的部分就是掺杂物**;加碘液变蓝的掺有淀粉
- **采收与加工**: 夏季剪取蒲棒上部的**黄色雄花序**,晒干后碾轧,筛取花粉;带雄花的粗粉习称"草蒲黄"
- **储存**: 极易吸潮结块、生虫,密封,放干燥处
- **功效**: 止血,化瘀,通淋
- **用量**: 5-10 g,**包煎**(花粉会浮在汤面、难以过滤);外用适量,敷患处(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **孕妇慎用**;污染水域(工厂排水口、养殖污水塘)的蒲黄不要采;外伤大出血先压迫止血、送医,不要只撒蒲黄

## 三、化痰、通窍、安神、温里的花

辛夷和旋覆花**带绒毛**,煎煮时要用纱布包起来(包煎),否则绒毛刺激咽喉引起咳嗽;款冬花要注意吡咯里西啶生物碱;丁香要和园林里的"丁香花"分清。

### 3.1 辛夷

- **正名(别名)**: 辛夷(木笔花、望春花、毛笔头)
- **来源**: 木兰科植物望春花 *Magnolia biondii* Pamp.、玉兰 *Magnolia denudata* Desr. 或武当玉兰 *Magnolia sprengeri* Pamp. 的干燥花蕾
- **分布与生境**: 河南(南召)、湖北、陕西、安徽、四川等地;玉兰各地广泛栽培作绿化树
- **识别要点**:
  - 植株: 落叶乔木;**早春先开花后长叶**,花大,白色或外面带紫红色;冬季枝顶的花芽**像一支毛笔头**,外面裹着毛茸茸的苞片
  - 药材: 呈**长卵形,似毛笔头**,长1.2-2.5 cm,基部常有短梗;苞片2-3层,**外表面密被灰白色或灰绿色有光泽的长茸毛**,内表面无毛;剥开可见多层花被片和多数雄蕊、雌蕊
  - 气味: **气芳香**,味辛凉而稍苦
- **易混淆品**: 紫玉兰、二乔玉兰、广玉兰(荷花玉兰,常绿)等同属植物的花蕾外形相近;广玉兰花蕾大、苞片毛为锈褐色。多数无明显毒性,但不是药典品种
- **采收与加工**: **冬末春初花未开放时**采收,除去枝梗,阴干
- **储存**: 含挥发油,密封阴凉,防潮防虫
- **功效**: 散风寒,通鼻窍
- **用量**: 3-10 g,**包煎**;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚火旺者慎用(经验);长期鼻塞、流脓涕、反复鼻出血要到耳鼻喉科检查,不要只靠辛夷

### 3.2 款冬花

- **正名(别名)**: 款冬花(冬花、款冬)
- **来源**: 菊科植物款冬 *Tussilago farfara* L. 的干燥花蕾
- **分布与生境**: 华北、西北、西南,河南、甘肃、山西、陕西、内蒙古等地;生于山谷溪边、河岸沙地、湿润的林缘
- **识别要点**:
  - 植株: 多年生草本,**早春先开花、后长叶**: 花葶从地下抽出,被白色绵毛,有鳞片状苞叶,顶生一个**黄色头状花序**;花谢后才长出基生叶,叶**心形或宽心形**,边缘有波状疏齿,**背面密生白色绵毛**
  - 药材: **长圆棒状**,单生或2-3个基部连生,长1-2.5 cm,直径0.5-1 cm;上端较粗,下端渐细或带短梗;外面被**多数鱼鳞状苞片**,外表面**紫红色或淡红色**,内表面密被白色絮状茸毛;体轻,撕开后可见白色茸毛
  - 气味: 气香,味微苦而辛
- **易混淆品**: **蜂斗菜**(*Petasites*)的花蕾和叶与款冬相似,也含吡咯里西啶生物碱,不能代用
- **采收与加工**: **12月或地冻前、花尚未出土时**采挖花蕾,除去花梗和泥沙,**阴干**;不要水洗、不要日晒,否则变色、开花
- **储存**: 易生虫、发霉、变色,密封阴凉
- **功效**: 润肺下气,止咳化痰
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 含克氏千里光碱等**吡咯里西啶生物碱**,长期或大量服用可能损伤肝脏(肝小静脉闭塞病);**不长期服用;孕妇、哺乳期、儿童、肝病患者不用**(经验,一些国家已限制款冬内服);咳嗽超过3周、咳血、发热要就医

### 3.3 旋覆花

- **正名(别名)**: 旋覆花(金沸花、六月菊、金钱花)
- **来源**: 菊科植物旋覆花 *Inula japonica* Thunb. 或欧亚旋覆花 *Inula britannica* L. 的干燥头状花序
- **分布与生境**: 东北、华北、华东、华中等地,河滩、田埂、路旁、湿润草地
- **识别要点**:
  - 植株: 多年生草本,高30-70 cm;叶互生,长圆形或披针形,**基部稍抱茎**,下面有疏毛;夏秋顶端开**金黄色头状花序**,直径2.5-4 cm,**舌状花一圈、细长**
  - 药材: 头状花序**扁球形或类球形**,直径1-2 cm;**总苞片多层、覆瓦状排列**,披针形或条形,灰黄色;舌状花1列,黄色,多卷曲;管状花多数,棕黄色;有的可见带白色冠毛的小瘦果;体轻,易散碎
  - 气味: 气微,味微苦
- **易混淆品**: **野菊花**(1.3)、**蒲公英**的头状花序、其他黄花菊科植物;旋覆花的舌状花细长且只有1轮、苞片条形。它的地上部分叫"金沸草",是另一味药
- **采收与加工**: 夏、秋二季**花开放时**采收,除去杂质,阴干或晒干
- **储存**: 易散碎,防潮、防虫
- **功效**: 降气,消痰,行水,止呕
- **用量**: 3-9 g,**包煎**(冠毛和绒毛刺激咽喉)(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 阴虚劳嗽、津伤燥咳者慎用(经验)

### 3.4 合欢花

- **正名(别名)**: 合欢花(夜合花、绒花);花蕾习称"合欢米"
- **来源**: 豆科植物合欢 *Albizia julibrissin* Durazz. 的干燥花序或花蕾,前者习称"合欢花",后者习称"合欢米"
- **分布与生境**: 华北至华南广布,常见行道树、庭院树,山坡也有野生
- **识别要点**:
  - 植株: 落叶乔木;**二回羽状复叶**,小叶细小、镰刀状,**夜间成对闭合**(所以叫"夜合");夏季开**粉红色绒球状花**,看到的"绒毛"其实是细长的雄蕊
  - 药材: 合欢花为头状花序,皱缩成团;总花梗长3-4 cm;花细长而弯曲,长0.7-1 cm,淡黄色或黄褐色,花冠筒状,先端5裂;**雄蕊多数,花丝细长**,黄棕色至黄褐色。合欢米呈棒槌状,淡黄色至黄褐色
  - 气味: 气微香,味淡
- **易混淆品**: 同科的**南洋楹、山合欢**(花白色、小叶较大)等;**树皮"合欢皮"是另一味药**,见第06章
- **采收与加工**: 夏季**花开放时**择晴天采收,或花蕾形成时采收合欢米;及时晒干
- **储存**: 防潮、防虫
- **功效**: 解郁安神
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 孕妇慎用(经验);长期失眠、情绪低落超过两周的,要找医生评估是否有抑郁症,不要只靠安神药;行道树的花可能沾尾气和农药,不采

### 3.5 丁香

- **正名(别名)**: 丁香(公丁香、丁子香)
- **来源**: 桃金娘科植物丁香 *Eugenia caryophyllata* Thunb. 的干燥花蕾
- **分布与生境**: 原产印度尼西亚马鲁古群岛,东非(桑给巴尔)、马达加斯加等地大量栽培;国内海南、广东有少量栽培
- **识别要点**:
  - 植株: 常绿乔木,叶对生,革质,有油腺点;热带才能生长,国内野外见不到
  - 药材: 略呈**研棒状(小钉子状)**,长1-2 cm;上端是圆球形的花冠,直径0.3-0.5 cm,花瓣4片覆瓦状抱合,棕褐色;下部是圆柱状的**萼筒**,红棕色或棕褐色,上部有**4枚三角形萼片呈十字形张开**;质坚实,**富油性**,用指甲划萼筒会渗出油
  - 气味: **气芳香浓烈,味辛辣,有麻舌感**
  - 水试: 好丁香含油多,**放入水中萼筒朝下、垂直下沉**;漂浮或横浮的多是已经提过油的劣品
- **易混淆品**:
  - **园林里的"丁香花"**(紫丁香、白丁香,木犀科丁香属 *Syringa*): 北方常见的春季开紫色或白色小花的灌木,**和药材丁香完全不是一种植物**,不入药
  - **母丁香**: 同一植物的近成熟果实,药典另列,椭圆形、较大
  - **提过油的丁香**: 颜色发暗、香气淡、入水不沉
- **采收与加工**: 当花蕾**由绿色转红色时**采摘,晒干
- **储存**: 密封,阴凉避光;香气越放越淡
- **功效**: 温中降逆,补肾助阳
- **用量**: 1-3 g,内服或研末外敷(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **不宜与郁金同用**(十九畏,见[总论-十八反、十九畏](./00-总论.md#73-十八反十九畏配伍禁忌);郁金见[第02章](./02-根及根茎类下.md#32-郁金));热病及阴虚内热者不用;**丁香油刺激性强,不要给儿童内服**,牙痛外用丁香油只能短期应急,随后看牙医

## 四、疏散清热的叶

叶类药材干燥后皱缩破碎,认的时候**泡软展平**再看: 叶形、叶缘、叶脉、两面的毛和颜色、叶柄,再揉碎闻一闻。

### 4.1 桑叶

- **正名(别名)**: 桑叶(霜桑叶、冬桑叶)
- **来源**: 桑科植物桑 *Morus alba* L. 的干燥叶
- **分布与生境**: 全国各地,村旁、田边、山坡;江浙、广东、四川等蚕区大量栽培
- **识别要点**:
  - 植株: 落叶乔木或灌木;**折断叶柄或嫩枝有白色乳汁**;叶互生,卵形或宽卵形,边缘有锯齿,有的不规则分裂;果实是聚花果,熟时紫黑色或白色(桑椹)
  - 药材: 多皱缩、破碎,完整者有柄,展平后卵形或宽卵形,长8-15 cm,宽7-13 cm;先端渐尖,基部截形、圆形或心形,边缘有锯齿;上表面黄绿色或浅黄棕色,有的有小疣状突起;下表面颜色稍浅,**叶脉突出、小脉网状**,脉上有疏毛,**脉腋有簇毛**;质脆
  - 气味: 气微,味淡、微苦涩
- **易混淆品**: **构树叶**(同科,也有白色乳汁,叶两面粗糙、密生毛,常3-5深裂)、鸡桑、华桑的叶;多数无毒,但不是药典桑叶
- **采收与加工**: **初霜后**采收(所以叫"霜桑叶"),除去杂质,晒干
- **储存**: 防潮、防霉,易碎,轻压保存
- **功效**: 疏散风热,清肺润燥,清肝明目
- **用量**: 5-10 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 风寒感冒(怕冷、流清涕)不宜用(经验);糖尿病患者不能用桑叶代替降糖药
- 根皮"桑白皮"、嫩枝"桑枝"见第06章

### 4.2 紫苏叶

- **正名(别名)**: 紫苏叶(苏叶、赤苏)
- **来源**: 唇形科植物紫苏 *Perilla frutescens* (L.) Britt. 的干燥叶(或带嫩枝)
- **分布与生境**: 全国各地广泛栽培,村旁、园边也常有逸为野生的
- **识别要点**:
  - 植株: 一年生草本,高0.3-2 m;**茎四棱**,有长柔毛;**叶对生**,宽卵形,边缘有粗锯齿,**两面紫色或上面绿、下面紫**;轮伞花序组成偏向一侧的总状花序,花白色至紫红色
  - 药材: 叶多皱缩卷曲、破碎,完整者展平后卵圆形,长4-11 cm,宽2.5-9 cm,先端长尖或急尖,边缘有圆锯齿;两面紫色或上表面绿色、下表面紫色,疏生灰白色毛,**下表面有多数凹点状腺鳞**;叶柄长2-7 cm,紫色或紫绿色;质脆
  - 气味: **气清香**(特有的紫苏香),味微辛
- **易混淆品**:
  - **白苏**: 同一种的绿叶类型,香气较淡;部分地区混用
  - **彩叶草**(*Coleus*): 也是唇形科、叶紫色或花叶,常作盆栽,但**没有紫苏的香气**
  - **石荠苎、野生香薷**等: 叶小得多;多数无毒
  - 记住: 揉碎**没有紫苏香味的紫叶子不采**
- **采收与加工**: 夏季**枝叶茂盛时**采收,除去杂质,阴干或低温干燥(暴晒香气损失)
- **储存**: 含挥发油,密封阴凉,一般不超过1年
- **功效**: 解表散寒,行气和胃
- **用量**: 5-10 g,不宜久煎(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 表虚多汗者慎用(经验)。民间用紫苏"解鱼蟹毒"是指吃鱼蟹后轻微的胃肠不适;**吃海鲜后出现皮疹、喉咙发紧、呼吸困难(过敏)或剧烈呕吐腹泻,要立即就医**
- 种子"紫苏子"见[第03章-紫苏子](./03-果实种子类.md#73-紫苏子)

### 4.3 大青叶

- **正名(别名)**: 大青叶(菘蓝叶、蓝叶)
- **来源**: 十字花科植物菘蓝 *Isatis indigotica* Fort. 的干燥叶
- **分布与生境**: 栽培品,河北、江苏、安徽、甘肃、黑龙江等地种植;它的根就是板蓝根
- **识别要点**:
  - 植株: 二年生草本,高40-100 cm,全株光滑、带白粉;基生叶长圆形,有柄;**茎生叶长圆状披针形,基部箭形、半抱茎**;春季开**黄色十字形小花**;角果扁平,长圆形,边缘有翅,下垂
  - 药材: 多皱缩卷曲,有的破碎;完整叶片展平后**长椭圆形至长圆状倒披针形**,长5-20 cm,宽2-6 cm;上表面暗灰绿色,有的可见色较深、稍突起的小点;先端钝,全缘或微波状,**基部狭窄下延至叶柄呈翼状**;叶柄长4-10 cm,淡棕黄色;质脆
  - 气味: 气微,味微酸、苦、涩
- **易混淆品(同名异物多)**:
  - **蓼大青叶**: 蓼科植物蓼蓝的叶,药典另列;叶卵形,蓝绿色
  - **马蓝叶**: 爵床科植物马蓝的叶(马蓝的根是"南板蓝根"),叶对生
  - **路边青**: 马鞭草科(今归唇形科)植物大青的叶,南方部分地区称"大青叶"
  - 这几种功效相近,但成分不同,药典大青叶专指菘蓝叶
- **采收与加工**: 夏、秋二季分2-3次采收,除去杂质,晒干
- **储存**: 防潮、防霉
- **功效**: 清热解毒,凉血消斑
- **用量**: 9-15 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 苦寒,脾胃虚寒者慎用(经验);不能代替疫苗和抗病毒药
- 根"板蓝根"见[第01章-板蓝根](./01-根及根茎类上.md#33-板蓝根)

### 4.4 荷叶

- **正名(别名)**: 荷叶(莲叶)
- **来源**: 睡莲科植物莲 *Nelumbo nucifera* Gaertn. 的干燥叶
- **分布与生境**: 全国各地的池塘、湖泊、水田栽培或野生
- **识别要点**:
  - 植株: 多年生水生草本;叶**圆形、盾状**(叶柄连在叶片中央),直径可达70 cm,**表面有蜡质、水滴成珠滚动**;叶柄有小刺
  - 药材: 半圆形或折扇形,展开后类圆形,直径20-50 cm,全缘或稍呈波状;上表面深绿色或黄绿色,较粗糙;下表面淡灰棕色,较光滑,有**粗脉21-22条,从中心向四周放射**;中心有突起的叶柄残基;质脆,易破碎
  - 气味: 稍有清香气,味微苦
- **易混淆品**: **睡莲叶**(叶浮在水面、有一道深缺口、不是盾状)、**芡实叶**(叶面多皱、有刺),很容易区分
- **采收与加工**: 夏、秋二季采收,晒至七八成干时,除去叶柄,折成半圆形或折扇形,干燥
- **储存**: 易碎、易霉,干燥通风处保存
- **功效**: 清暑化湿,升发清阳,凉血止血
- **用量**: 3-10 g;荷叶炭3-6 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **不要把"荷叶减肥茶"当减肥药长期喝**: 市售的减肥茶常混有番泻叶(见6.1),也查出过非法添加的西药;体虚、消瘦者不宜(经验);重金属污染的河塘(工厂下游、城市排污口附近)的荷叶不采

## 五、止咳、止血、温经的叶

枇杷叶、侧柏叶、艾叶都是常绿树或常见野草,全年或夏季随手可采;要防的是侧柏和有毒柏类混采、艾叶和其他蒿类混采,以及艾叶大量内服。

### 5.1 枇杷叶

- **正名(别名)**: 枇杷叶(杷叶)
- **来源**: 蔷薇科植物枇杷 *Eriobotrya japonica* (Thunb.) Lindl. 的干燥叶
- **分布与生境**: 长江流域及以南各地广泛栽培,庭院、果园、村旁
- **识别要点**:
  - 植株: 常绿小乔木;小枝、叶背、花序都密被**锈色或灰棕色绒毛**;叶大,革质,长圆形;**秋冬开白花**,初夏结黄色果实
  - 药材: 长圆形或倒卵形,长12-30 cm,宽4-9 cm;先端尖,基部楔形,**边缘有疏锯齿,近基部全缘**;上表面灰绿色、黄棕色或红棕色,较光滑;**下表面密被黄色绒毛**,主脉在下表面显著突起,侧脉羽状;叶柄极短,被棕黄色绒毛;**革质而脆**,易折断
  - 气味: 气微,味微苦
- **易混淆品**: 广玉兰叶(背面锈色毛、但叶全缘、更厚)、石楠叶(背面无毛)等常绿革质叶;多数无毒
- **采收与加工**: 全年均可采收,晒至七八成干时,扎成小把,再晒干;用前**刷去背面绒毛**
- **储存**: 防潮,通风干燥处
- **功效**: 清肺止咳,降逆止呕
- **用量**: 6-10 g(《中国药典》2020年版,在中医师指导下使用);绒毛没刷净的要包煎,否则刺激咽喉反而加重咳嗽
- **禁忌**: 风寒咳嗽(痰白清稀、怕冷)不宜用(经验);**枇杷的种子(果核)含苦杏仁苷,不要吃**,参见[苦杏仁](./09-有毒中药与易混淆有毒植物.md#412-苦杏仁)

### 5.2 侧柏叶

- **正名(别名)**: 侧柏叶(柏叶、扁柏叶)
- **来源**: 柏科植物侧柏 *Platycladus orientalis* (L.) Franco 的干燥枝梢和叶
- **分布与生境**: 全国大部分地区,山地阳坡、石灰岩山地;陵园、寺庙、公园大量栽植
- **识别要点**:
  - 植株: 常绿乔木;**小枝扁平,排成一个平面,而且这个平面是竖着的**(像侧立的手掌,所以叫"侧"柏);叶全部为**细小鳞片状,交互对生、紧贴小枝**;球果卵形,种鳞4对,**背部顶端有一个反曲的尖头**,熟时开裂
  - 药材: 多分枝,小枝扁平;叶细小鳞片状,交互对生,贴伏于枝上,深绿色或黄绿色;质脆,易折断
  - 气味: **气清香**,味苦涩、微辛
- **易混淆品**:
  - **圆柏(桧柏)**: 同一株上常有**刺状叶和鳞叶两种叶**,小枝不排成平面;球果肉质、不开裂。不是药典品种
  - **叉子圆柏(沙地柏)** *Juniperus sabina*: 匍匐灌木,多见于西北沙地和园林绿化,**全株有毒**(含桧油),可引起呕吐、肝肾损害和流产;**匍匐生长、枝不成竖直平面的"柏"不要采**
  - 侧柏的种仁"柏子仁"是另一味药
- **采收与加工**: 多在夏、秋二季采收,**阴干**
- **储存**: 含挥发油,防潮,阴凉保存
- **功效**: 凉血止血,化痰止咳,生发乌发
- **用量**: 6-12 g;外用适量(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: 长期大量服用可引起胃部不适、食欲减退(经验);咯血、便血、尿血都必须先查原因

### 5.3 艾叶

- **正名(别名)**: 艾叶(艾、家艾、蕲艾)
- **来源**: 菊科植物艾 *Artemisia argyi* Lévl. et Vant. 的干燥叶
- **分布与生境**: 全国大部分地区,荒地、路旁、河边、山坡;湖北蕲春的"蕲艾"最有名,各地多有栽培
- **识别要点**:
  - 植株: 多年生草本,高0.5-1.5 m,全株**密被灰白色绒毛**;叶互生,**羽状深裂**,裂片椭圆状披针形,边缘有粗锯齿;**叶上面灰绿色、有腺点,下面密生灰白色绒毛**(翻过来是白的);揉搓有**浓烈的艾香**
  - 药材: 多皱缩、破碎,有短柄;完整叶片展平后卵状椭圆形,羽状深裂,裂片边缘有不规则粗锯齿;上表面灰绿色或深黄绿色,有稀疏柔毛和腺点;**下表面密生灰白色绒毛**;质柔软
  - 气味: **气清香**,味苦
- **易混淆品**: **野艾蒿、五月艾、蒙古蒿、魁蒿**等蒿属植物外形相近,叶背也有白毛,各地常混作"艾";其中多数可作灸用,但**不是药典艾叶**。**青蒿、茵陈**等也是蒿属(见[全草类](./04-全草类.md)),叶裂得更细、背面不白。注意别和**豚草**(外来入侵杂草,花粉强致敏,叶背不白、无艾香)混淆
- **采收与加工**: **夏季花未开时**采摘(端午前后),除去杂质,晒干;做艾绒用陈艾叶(存放1年以上)
- **储存**: 防潮、防霉,通风干燥处
- **功效**: 温经止血,散寒止痛;外用祛湿止痒
- **用量**: 3-9 g;外用适量,供灸治或熏洗用(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**: **药典标注"有小毒"**: 艾叶挥发油大量内服可引起恶心呕吐、肝损害、神经兴奋甚至抽搐,**不要大量内服、不要喝艾叶精油**;孕妇用艾必须在医生指导下;**艾灸**要防烫伤和起泡(糖尿病、感觉迟钝的人尤其),室内**开窗通风**,哮喘、慢阻肺患者远离艾烟
- 种植方法见[药用植物-艾草](../04-动植物培育/04-药用植物.md#艾草艾蒿)

## 六、需要特别小心的叶

番泻叶和银杏叶都能在市场上随手买到,常被当成"通便茶""保健茶"自己泡着喝——这正是它们出问题的地方。

### 6.1 番泻叶

- **正名(别名)**: 番泻叶(泻叶、泡竹叶)
- **来源**: 豆科植物狭叶番泻 *Cassia angustifolia* Vahl 或尖叶番泻 *Cassia acutifolia* Delile 的干燥小叶
- **分布与生境**: 原产热带非洲和印度;狭叶番泻主产印度,尖叶番泻主产埃及;国内海南、云南有少量栽培,野外见不到
- **识别要点**:
  - 植株: 灌木,偶数羽状复叶,小叶4-8对;总状花序,花黄色;荚果扁平
  - 药材: **狭叶番泻**小叶长卵形或卵状披针形,长1.5-5 cm,宽0.4-2 cm,全缘,**叶端急尖,叶基稍不对称**;上表面黄绿色,下表面浅黄绿色,无毛或近无毛,叶脉稍隆起;革质。**尖叶番泻**呈披针形或长卵形,略卷曲,叶端短尖或微突,叶基不对称,两面均有细短毛茸
  - 气味: 气微弱而特异,味微苦,稍有黏性
- **易混淆品**: **耳叶番泻叶**(*Cassia auriculata*)常混入: 小叶卵圆形,**先端钝圆或微凹、有短刺尖**,两面密被长茸毛,几乎没有泻下作用
- **采收与加工**: 开花前或果实成熟期采叶,晒干(进口商品为主)
- **储存**: 防潮、防霉,避光
- **功效**: 泻热行滞,通便,利水
- **用量**: 2-6 g,**后下**,或开水泡服(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**:
  - 药典标注"孕妇慎用";本书按常规禁忌: **孕妇、哺乳期、月经期禁用**(可致盆腔充血、子宫出血,哺乳期成分可进入乳汁)
  - 它是**刺激性泻药**(含番泻苷,刺激结肠蠕动),**只能短期、偶尔用**(一般不超过1周);长期服用会**依赖成瘾、越用越便秘**,并引起**低血钾、脱水**和结肠黑变病
  - 剂量过大可致剧烈腹痛、呕吐、腹泻,甚至消化道出血
  - **不能用来减肥**;儿童、老年体弱者、肠梗阻、不明原因腹痛者禁用;服地高辛、利尿剂的人更易因低血钾出危险
  - 便秘伴**便血、体重下降、大便习惯突然改变**(尤其40岁以上),要就医排查肠道肿瘤

### 6.2 银杏叶

- **正名(别名)**: 银杏叶(白果叶)
- **来源**: 银杏科植物银杏 *Ginkgo biloba* L. 的干燥叶
- **分布与生境**: 全国各地广泛栽培,行道树、庭院、寺庙;江苏邳州、山东郯城等地有大面积叶用和果用银杏园
- **识别要点**:
  - 植株: 落叶大乔木;叶**扇形**,有长柄,在短枝上簇生、长枝上互生;**叶脉是二叉分枝的平行脉**(全世界只此一种);秋季叶变金黄
  - 药材: 多皱折或破碎,完整者扇形,长3-12 cm,宽5-15 cm;黄绿色或浅棕黄色,上缘呈不规则波状弯曲,有的中间凹入,深者可达叶长的4/5;**二叉状平行叶脉细而密**,光滑无毛,**易纵向撕裂**;叶基楔形,叶柄长2-8 cm;体轻
  - 气味: 气微,味微苦
- **易混淆品**: 叶形独特,几乎不会认错;要防的是**行道树叶沾染尾气、农药**,以及用黄落叶充数
- **采收与加工**: **秋季叶尚绿时**采收,及时干燥
- **储存**: 防潮、防霉
- **功效**: 活血化瘀,通络止痛,敛肺平喘,化浊降脂
- **用量**: 9-12 g(《中国药典》2020年版,在中医师指导下使用)
- **禁忌**:
  - 药典标注"有实邪者忌用"
  - **生叶含银杏酸**,可引起过敏性皮炎、胃肠反应,有一定细胞毒性;正规银杏叶提取物和制剂要专门除去银杏酸并严格限量,**自己采叶泡"银杏叶茶"不推荐**
  - 银杏叶有抗血小板作用,与**华法林、阿司匹林、氯吡格雷**等同用可增加出血风险;**手术、拔牙前要告诉医生**;孕妇、有出血倾向者不用(经验)
  - 银杏的种子白果药典标注"有毒",见[白果(银杏种子)生食或多食](./09-有毒中药与易混淆有毒植物.md#411-白果银杏种子生食或多食)

### 7.2 自我检查

采花叶类药材之前,逐条确认:

- [ ] 花: 我看了花的结构(唇形还是漏斗形、几朵并生、有没有刺),不只看颜色
- [ ] 叶: 我泡软展平看了叶形、叶脉、两面的毛,揉碎闻了气味
- [ ] 缠绕藤本开黄花的,我已经排除了钩吻
- [ ] 采集地远离公路、工厂和污染水体;不采公园、花店、绿化带打过药的花叶
- [ ] 买西红花、红花、蒲黄时做了水试,便宜得离谱的不买
- [ ] 采回后及时摊开干燥,花蕾类不揉不翻,含挥发油的(紫苏叶、辛夷、玫瑰花)阴干或低温干燥
- [ ] 番泻叶只短期用;银杏叶不自采泡茶;艾叶不大量内服
- [ ] 我知道药典用量和禁忌,孕妇、儿童、肝肾病人、服抗凝药的人先问医生

| 环节 | 难度 | 出错的风险 |
|------|------|----------|
| 认常见花叶(金银花、菊花、桑叶、荷叶、艾叶) | ⭐⭐ | ☠️(功效不同,极少中毒) |
| 区分金银花和钩吻 | ⭐⭐⭐ | ☠️☠️☠️☠️☠️(误采钩吻可致死) |
| 鉴别西红花、红花真伪 | ⭐⭐⭐ | ☠️(花冤枉钱、吃进染料) |
| 区分同名异物(大青叶、丁香、玫瑰与月季) | ⭐⭐⭐⭐ | ☠️(用错药) |

## 📝 本章要点

```
□ 花类看结构、叶类泡软展平看叶脉和毛,不只看颜色
□ 金银花: 两朵并生、唇形、黄白相间;钩吻漏斗状、只有黄色,剧毒
□ 西红花: 水试橙黄色直线下降、柱头三叉喇叭口;便宜的基本是假的
□ 红花泡水变金黄,变红的多是染色品
□ 槐花是国槐(无刺、夏花),不是洋槐(有刺、春花)
□ 药材丁香是热带花蕾,不是北方园林的丁香花;不宜与郁金同用
□ 辛夷、旋覆花有绒毛,包煎;枇杷叶刷去绒毛
□ 款冬花含吡咯里西啶生物碱,不长期服
□ 番泻叶只短期用;孕妇、哺乳期、月经期禁用;不能减肥
□ 银杏叶生叶含银杏酸,不自采泡茶;服抗凝药的人不用
□ 艾叶有小毒,不大量内服;艾灸防烫伤、通风
□ 红花、西红花、蒲黄、月季花等活血药孕妇不用
```
