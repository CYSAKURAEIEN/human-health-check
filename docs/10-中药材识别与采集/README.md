# 中药材识别与采集

## 📋 目录概览

本部分是全书中药内容的"识别手册": 常用中药材怎样认、在哪里找、什么时候采、采哪个部位、怎样加工和储存,以及药典常规用量、禁忌和容易混淆的有毒植物。

和其他章节的分工:
- 种植方法见[药用植物](../04-动植物培育/04-药用植物.md)
- 炮制、煎煮和常用方剂见[中药制剂](../06-制药技术/04-中药制剂.md)
- 野外误食有毒植物和蘑菇见[毒蘑菇与野菜误食](../03-野外生存/09-毒蘑菇与野菜误食.md)
