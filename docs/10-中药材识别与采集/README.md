# 中药材识别与采集

## 📋 目录概览

本部分是全书中药内容的"识别手册": 常用中药材怎样认、在哪里找、什么时候采、采哪个部位、怎样加工和储存,以及药典常规用量、禁忌和容易混淆的有毒植物。

和其他章节的分工:
- 种植方法见[药用植物](../04-动植物培育/04-药用植物.md)
- 炮制、煎煮和常用方剂见[中药制剂](../06-制药技术/04-中药制剂.md)
- 野外误食有毒植物和蘑菇见[毒蘑菇与野菜误食](../03-野外生存/09-毒蘑菇与野菜误食.md)

### 内容章节

其余各章(按药用部位分: 根及根茎、果实种子、全草、花叶、皮类与藤木、菌藻树脂、动物与矿物,以及有毒中药与易混淆有毒植物)正在编写中。

## ⚠️ 说明

- 本部分是教育参考,不能替代就医;用量为《中国药典》(2020年版)的成人常规范围,具体用药请在中医师指导下进行
- **认不准的植物一律不采、不用、不尝**;有毒中药只写识别和毒性,不写用法
- 不采挖、不购买野生保护物种,不使用保护动物制成的药材
