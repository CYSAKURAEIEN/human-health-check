# 热力学与动力机械

> **工业革命的本质,是人类学会了把燃料里的热变成源源不断的机械动力**

## ⚠️ 安全第一

**锅炉爆炸是历史上最致命的工业事故之一。** 19世纪蒸汽机普及时,锅炉爆炸每年造成大量伤亡。

- 💥 锅炉里的高压热水一旦破裂,会瞬间大量变成蒸汽,威力如同炸弹
- ☠️ 内燃机、木煤气发生炉排出的一氧化碳无色无味,在室内使用会致命
- 🔥 蒸汽烫伤比沸水烫伤更严重
- ⚙️ 飞轮、皮带、齿轮会卷入衣服、头发和手指

**本章介绍原理和估算方法,帮助理解动力机械。** 制造和使用压力容器(锅炉)必须遵守专业的设计和检验规范;没有这样的条件时,只使用常压或很低压力的装置。

基础的热学知识见[物理-热学](../08-基础科学知识/02-物理.md#五热学)。

## 一、热力学定律

### 1.1 第一定律: 能量守恒

```
系统内能的增加 = 吸收的热量 - 对外做的功
  ΔU = Q - W

→ 热机从燃料获得热量,一部分变成功,其余的热量排到环境中
→ 不存在不消耗能量就能做功的"永动机"
```

### 1.2 第二定律: 热不能全部变成功

```
热量自发地从高温传向低温
任何热机都必须向低温环境排出一部分热量,不可能把热全部变成功

卡诺效率(理论最高效率):
  η = 1 - T冷 ÷ T热(温度用开尔文 = °C + 273)

例: 蒸汽温度180°C(453开),冷凝温度40°C(313开)
  最高效率 = 1 - 313 ÷ 453 ≈ 31%
  实际的蒸汽机远低于这个数(早期只有几个百分点)

→ 提高效率: 提高热源温度(更高的蒸汽压力),降低冷源温度(冷凝器)
```

### 1.3 熵

```
熵是衡量"混乱程度"的量
孤立系统的熵只会增加或不变 → 热量会自发散开、混合,不会自发集中
→ 这就是为什么能量守恒,但"可用的能量"会越用越少
```

## 二、水和蒸汽的性质

### 2.1 饱和温度和压力

| 绝对压力(兆帕) | 约合大气压 | 水的沸点(°C) |
|---------------|-----------|-------------|
| 0.1 | 1 | 100 |
| 0.2 | 2 | 约120 |
| 0.5 | 5 | 约152 |
| 1.0 | 10 | 约180 |
| 2.0 | 20 | 约212 |

```
✓ 压力越高,水的沸点越高
✓ 压力表上的读数通常是"表压"(比大气压高出多少),
  绝对压力 = 表压 + 约0.1兆帕
```

### 2.2 为什么锅炉这么危险

```
1千克水变成100°C、1个大气压的蒸汽,体积膨胀约1700倍

锅炉里储存着大量超过100°C的高压热水:
  锅炉一旦破裂,压力骤降,这些热水瞬间沸腾成蒸汽,
  释放的能量远远超过锅炉里原有的蒸汽
→ 锅炉越大、压力越高,破裂时的威力越大
```

## 三、锅炉

### 3.1 必须有的安全装置

```
✓ 安全阀: 压力超过设定值时自动打开排汽(必须定期检查,绝不能堵死、压死)
✓ 压力表: 随时看到压力
✓ 水位计: 随时看到水位
✓ 进水装置: 能在运行中补水

⚠️ 缺水是最危险的情况之一:
   水位过低,炉膛上方的金属被干烧过热、强度下降,
   此时突然补进冷水,可能立即引发爆炸
   → 发现严重缺水时,先停火,让锅炉慢慢冷却,不要立即补水
```

### 3.2 压力容器的强度(原理)

```
圆筒形容器壁上的环向应力:
  σ = p × D ÷ (2 × t)
  p: 内部压力;D: 直径;t: 壁厚

→ 直径越大、压力越高,壁就要越厚
→ 同样的壁厚,小直径的管子比大直径的筒能承受更高的压力
   (所以后来的水管锅炉比火管锅炉安全)
→ 实际设计还要考虑焊缝或铆缝的强度、腐蚀、高温下强度降低、
   反复加热冷却造成的疲劳,安全系数要取得很大
```

### 3.3 检验和维护

```
✓ 新造或修理后做水压试验: 灌满水,加压到工作压力的约1.5倍,检查有无渗漏变形
  (用水而不用空气: 水几乎不可压缩,万一破裂不会爆炸)
✓ 定期清除水垢: 水垢传热差,会让炉壁局部过热
✓ 使用软水或经过处理的水
✓ 检查腐蚀、裂纹、变形
✓ 操作人员经过培训,运行时有人看守
```

## 四、蒸汽机

### 4.1 发展历程

```
1712年 纽科门蒸汽机: 蒸汽进入气缸后喷冷水凝结,形成真空,
  大气压推动活塞——用于矿井抽水,效率极低
1769年 瓦特: 增加单独的冷凝器,气缸始终保持热的,燃料消耗大幅降低;
  后来又发明双作用、离心调速器、曲柄齿轮传动
约1800年 高压蒸汽机: 不再依赖真空,结构紧凑,可以装在车船上

→ 重建时可以直接从"带分离冷凝器的双作用蒸汽机"开始
```

### 4.2 主要部件

```
锅炉 → 产生蒸汽
气缸和活塞 → 蒸汽推动活塞往复运动
配汽阀(滑阀)→ 交替把蒸汽送到活塞两侧
曲柄连杆 → 把往复运动变成旋转运动
飞轮 → 使旋转平稳
调速器 → 转速太快时自动关小进汽(离心飞球)
冷凝器(可选)→ 把排汽冷凝成水,降低背压,提高效率,回收水
```

### 4.3 功率估算

```
功率 ≈ 平均有效压力 × 活塞面积 × 行程 × 每秒做功次数

例: 平均有效压力0.2兆帕,活塞直径10厘米,行程15厘米,
    每分钟120转,双作用(每转做功2次)
  活塞面积 = π × 0.05² ≈ 0.00785平方米
  每次做功 = 0.2 × 10⁶ × 0.00785 × 0.15 ≈ 236焦
  每秒做功次数 = 120 ÷ 60 × 2 = 4
  功率 ≈ 236 × 4 ≈ 940瓦,约1.3马力
```

### 4.4 提高效率的方法

```
✓ 膨胀做功: 只在行程的前一部分进汽,剩下的行程让蒸汽自己膨胀
✓ 保温: 气缸、管道包上保温材料
✓ 冷凝器: 降低排汽压力
✓ 提高蒸汽压力和温度(受锅炉安全限制)
```

### 4.5 斯特林发动机

```
外燃机: 用任何热源(木柴、太阳聚光、余热)从外部加热一个密闭气缸,
  另一端冷却,内部的气体反复受热膨胀、冷却收缩,推动活塞

优点: 可以在低压下工作,没有锅炉爆炸的风险,安静,燃料随意
缺点: 功率小,体积大
→ 适合小规模、低功率的场合(抽水、小型发电)
```

## 五、内燃机

### 5.1 四冲程循环

```
1. 吸气: 活塞下行,吸入空气(和燃料)
2. 压缩: 活塞上行,压缩混合气
3. 做功: 点燃(或压燃),燃气膨胀推动活塞下行
4. 排气: 活塞上行,排出废气

汽油机: 火花塞点火,压缩比约8-12,效率约25-30%
柴油机: 把空气压缩到很高温度,喷入柴油自燃,压缩比约15-22,
  效率约35-40%以上,结构坚固,对燃料要求较宽
```

### 5.2 替代燃料

```
乙醇: 可以作为汽油机的燃料(需要调整供油,冷启动较难)
  → 由粮食、甘蔗、薯类发酵后蒸馏得到(见化学-发酵)

植物油: 柴油机可以掺用,但黏度大,长期使用会积碳;
  通常要加热降低黏度,或加工成"生物柴油"

木煤气(发生炉煤气):
  木炭或木块在缺氧条件下不完全燃烧,产生一氧化碳和氢气等可燃气体,
  冷却过滤后送入发动机燃烧
  二战期间燃料短缺时,很多汽车、拖拉机用它行驶
  ⚠️ 一氧化碳剧毒: 发生炉和发动机只能在室外使用,
     停车后不要在密闭车库里继续产气

沼气: 主要成分是甲烷,可以作为发动机燃料
```

沼气的安全见[照明与能源-沼气](../07-日常生活技能/06-照明与能源.md#沼气);一氧化碳中毒见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

## 六、传热计算

### 6.1 热传导

```
通过一面墙传出去的热量(每秒,瓦):
  q = k × A × ΔT ÷ d
  k: 导热系数;A: 面积;ΔT: 两侧温差;d: 厚度

热阻 R = d ÷ k(多层叠加时,热阻相加)
  q = A × ΔT ÷ (R₁ + R₂ + …)
```

### 6.2 常见材料的导热系数(瓦/(米·°C),约数)

| 材料 | 导热系数 | 说明 |
|------|---------|------|
| 铜 | 约400 | 导热最好的常用金属 |
| 铝 | 约200 | |
| 钢铁 | 约50 | |
| 混凝土 | 约1-1.7 | |
| 玻璃 | 约1 | |
| 砖墙 | 约0.6-0.8 | |
| 土坯、夯土 | 约0.5-1 | 随含水量变化 |
| 木材 | 约0.1-0.2 | |
| 干稻草、草捆 | 约0.05-0.08 | 很好的保温材料 |
| 羊毛、棉絮、羽绒 | 约0.04 | |
| 静止的空气 | 约0.026 | 所有保温材料都是靠"困住空气" |

### 6.3 计算: 保温层有多大用

```
例: 一面50平方米的砖墙,厚30厘米,室内外温差20°C
  只有砖墙: 热阻 = 0.3 ÷ 0.7 ≈ 0.43
    散热 = 50 × 20 ÷ 0.43 ≈ 2300瓦
  加上10厘米厚的草捆保温层: 热阻 = 0.43 + 0.1 ÷ 0.06 ≈ 2.1
    散热 = 50 × 20 ÷ 2.1 ≈ 480瓦
  → 散热减少约80%,冬天烧的柴可以少很多

✓ 屋顶散热往往最多(热空气上升),优先保温屋顶
✓ 门窗缝隙漏风造成的热量损失也很大,先堵缝
```

保温的实际做法见[长期住所-保温](../07-日常生活技能/05-长期住所.md#保温)。

### 6.4 对流和辐射

```
对流: 风越大,散热越快 → 挡风、减少缝隙
辐射: 物体辐射的热量和绝对温度的四次方成正比
  → 温度高的炉子主要靠辐射散热;火墙、火炕的热辐射让人感觉温暖
  → 光亮的金属表面辐射少(保温瓶内胆镀银)

换热器: 两种流体隔着薄壁换热
  逆流(两种流体方向相反)比顺流效率高
  → 回收排出的热水、热烟气中的热量
```

## 七、制冷

### 7.1 蒸发冷却(不需要电)

```
水蒸发吸收大量热量(见物理-潜热)

陶罐冰箱(双罐冷藏):
1. 一个大的无釉陶罐里套一个小陶罐
2. 两个罐之间填满湿沙子
3. 小罐里放蔬菜、食物,上面盖湿布
4. 放在通风、阴凉的地方,每天给沙子加水
→ 在炎热干燥的地区,可以让内部温度明显降低,延长蔬菜保存时间
  (空气潮湿时效果差)

其他: 湿布包住水罐、挂在通风处;泥地洒水
```

### 7.2 储冰

```
冬天把河湖里的冰切成块,存进地下的冰窖,用厚厚的稻草、锯末隔热
→ 可以保存到夏天(我国古代称为"凌阴")
冰熔化时吸收大量热量,温度保持在0°C
```

### 7.3 压缩式制冷和热泵

```
冰箱、空调的原理:
1. 压缩机压缩制冷剂气体,温度升高
2. 在冷凝器中放热,变成液体(冰箱背后发热的地方)
3. 经过节流阀,压力骤降
4. 在蒸发器中蒸发吸热(冰箱内部变冷)
5. 回到压缩机,循环

热泵: 同样的原理反过来用,从室外空气、地下吸热送进室内
  每消耗1份电能,能搬运3-4份热量,比直接用电取暖省得多

吸收式制冷: 用热源(煤油、燃气、太阳能)代替压缩机驱动
  → 历史上有烧煤油的冰箱;常用氨作工质,⚠️ 氨有毒
```

## 八、水力、风力和畜力

### 8.1 水力

```
水力功率 ≈ 9.8 × 流量(立方米/秒)× 落差(米)× 效率(千瓦)

水轮的种类和效率(大致):
- 下射式(水从下面冲过): 约20-30%,适合流速快、落差小的地方
- 上射式(水从上方落进水斗): 约60%以上,需要一定落差
- 冲击式水轮机(水从喷嘴高速喷到叶片上): 可达80%以上,适合高落差小流量
```

估算例子见[物理-水力: 水车和水磨](../08-基础科学知识/02-物理.md#33-水力-水车和水磨)。

### 8.2 风力

```
风的功率 = ½ × 空气密度 × 扫风面积 × 风速³
  空气密度约1.2千克/立方米

✓ 风速加倍,功率变成8倍 → 选址最重要: 开阔、高处、风稳定的地方
✓ 理论上最多只能获得风能的约59%(贝茨极限),
  实际风车大约20-40%

例: 叶轮直径2米(扫风面积约3.14平方米),风速6米/秒
  风的功率 = 0.5 × 1.2 × 3.14 × 216 ≈ 407瓦
  按30%效率 → 约120瓦
```

### 8.3 畜力和人力

```
一个成年人长时间持续劳动: 约75-100瓦
一匹马长时间持续工作: 约0.5-1马力(约370-750瓦)
牛: 力气大但速度慢,适合犁地、拉磨

✓ 畜力磨、畜力水车: 牲畜绕圈行走,通过齿轮带动机器
```

### 8.4 储能

```
能量储存从易到难:
- 储存燃料(木柴、木炭、粮食、油)——最简单、能量密度最高
- 抬高的水(水塔、水库): 1吨水抬高10米,只储存约0.03千瓦时
  → 储能很少,但简单可靠
- 蓄电池
- 飞轮(短时间)
```

## 九、能源的比较

| 能源 | 可得性 | 功率规模 | 主要限制 |
|------|-------|---------|---------|
| 人力 | 随时 | 约100瓦/人 | 人要吃饭,时间宝贵 |
| 畜力 | 需要饲养 | 数百瓦/头 | 饲料、草场 |
| 水力 | 有河流落差的地方 | 几百瓦到很大 | 地点固定;枯水期、冰冻 |
| 风力 | 开阔多风的地方 | 几十瓦到数千瓦 | 不稳定,需要储能 |
| 木柴木炭 | 有森林的地方 | 取决于燃烧量 | 森林再生速度 |
| 太阳能板 | 回收的太阳能板 | 每平方米约100-200瓦(晴天) | 夜间、阴天;无法自制 |
| 煤 | 有煤矿的地方 | 大 | 开采、运输、污染 |
