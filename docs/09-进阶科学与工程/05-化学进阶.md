# 化学进阶

> **基础化学告诉我们"会发生什么反应",进阶化学回答"为什么发生、能进行到什么程度、有多快、怎样控制"——这是从手工作坊走向化学工业的关键**

## ⚠️ 安全第一

**本章讲原理,不是实验或生产指导。**

- ☠️ 化工生产涉及强酸、强碱、有毒气体、高温高压,事故往往是群死群伤
- 💥 放热反应如果散热不及时,温度越高反应越快,会"失控"(冲料、爆炸)
- 💥 面粉、煤粉、木屑、金属粉末等可燃粉尘飘散在空气中遇到明火,会发生粉尘爆炸
- ☠️ 氧化剂(硝酸盐、氯酸盐、高锰酸钾、浓硝酸等)不要和可燃物(油、纸、木屑、硫、碳粉)放在一起
- ✓ 任何不熟悉的反应,先查资料、小量试验、做好防护、在室外进行

基础知识见[基础科学知识-化学](../08-基础科学知识/03-化学.md)。

## 一、原子结构和周期律

### 1.1 电子排布

```
电子在原子核外分层排布,每层能容纳的电子数有限(第1层2个,第2层8个,第3层先排8个……)
最外层的电子数(价电子)决定了元素的化学性质

最外层8个电子(第1层为2个)最稳定 → 惰性气体(氦、氖、氩)几乎不反应
其他原子通过得失电子或共用电子,达到稳定结构
```

### 1.2 元素周期表的规律

```
同一列(族)的元素最外层电子数相同,性质相似:
  第1族 碱金属(锂、钠、钾): 最外层1个电子,极易失去,非常活泼,遇水剧烈反应
  第2族 碱土金属(镁、钙): 容易失去2个电子
  第17族 卤素(氟、氯、溴、碘): 最外层7个电子,极易得到1个电子,有毒、有强氧化性
  第18族 惰性气体: 几乎不反应

周期表左边是金属(容易失去电子),右边是非金属(容易得到电子)
同一族从上到下,金属性增强(钾比钠更活泼)
```

### 1.3 化学键

```
离子键: 一方失去电子、一方得到电子,正负离子相互吸引
  例: 食盐 NaCl;离子化合物熔点高,溶于水后能导电
共价键: 两个原子共用电子
  例: 水 H₂O、甲烷 CH₄、所有有机物
金属键: 金属原子的外层电子在整块金属中自由流动
  → 金属导电、导热、有光泽、能锻打

极性: 共用电子偏向吸引力强的一方(如水中的氧),分子一端带部分负电,一端带部分正电
  → 水分子之间有"氢键",所以水的沸点比同样大小的分子高得多,
    而且能溶解很多物质("相似相溶": 极性物质溶于水,油脂溶于汽油、酒精等)
```

## 二、化学热力学: 反应能不能发生

### 2.1 反应热(焓变)

```
放热反应(ΔH < 0): 燃烧、中和、生石灰遇水
  例: 甲烷完全燃烧 CH₄ + 2O₂ → CO₂ + 2H₂O,每摩尔放出约890千焦
吸热反应(ΔH > 0): 烧石灰、电解水、光合作用

盖斯定律: 反应热只和起点、终点有关,和经过几步无关
  → 可以把已知的几个反应的热相加减,算出未知反应的热
```

### 2.2 熵和吉布斯自由能

```
熵(S): 混乱程度;气体比液体、液体比固体的熵大

反应能否自发进行,看吉布斯自由能的变化:
  ΔG = ΔH - T × ΔS
  ΔG < 0: 能自发进行;ΔG > 0: 不能自发进行

例: 烧石灰 CaCO₃ → CaO + CO₂
  ΔH ≈ +178千焦/摩尔(吸热,不利)
  ΔS ≈ +0.16千焦/(摩尔·开)(产生气体,混乱度增加,有利)
  ΔG = 178 - T × 0.16
  T 高于约 1110开(约840°C)时 ΔG < 0
  → 这就是为什么烧石灰必须达到约900°C,温度不够怎么烧都不分解
```

### 2.3 冶炼的热力学

```
金属氧化物越稳定,越难被碳还原

把各种金属氧化物与碳的稳定性随温度的变化画在一张图上(埃林汉姆图),
可以看出:
- 铜、铅、锡的氧化物: 较低温度下就能被木炭还原
- 铁的氧化物: 需要更高的温度
- 铝、镁、钙的氧化物: 极其稳定,碳在一般炉温下无法还原,要用电解
→ 这从热力学上解释了金属活动性顺序和人类使用金属的先后顺序
```

金属活动性顺序见[化学-金属活动性顺序](../08-基础科学知识/03-化学.md#22-金属活动性顺序)。

## 三、化学平衡: 反应能进行到什么程度

### 3.1 可逆反应和平衡常数

```
很多反应不会进行到底,而是正反应和逆反应速度相等时停下来(平衡)

  aA + bB ⇌ cC + dD
  平衡常数 K = [C]ᶜ × [D]ᵈ ÷ ([A]ᵃ × [B]ᵇ)  ([X] 表示浓度)
  K 很大: 几乎完全反应;K 很小: 几乎不反应
  K 随温度变化
```

### 3.2 勒夏特列原理

```
改变平衡的条件,平衡会向"减弱这种改变"的方向移动:
- 增加反应物浓度,或移走产物 → 向生成产物的方向移动
- 增大压强 → 向气体分子数减少的方向移动
- 升高温度 → 向吸热的方向移动

例: 合成氨 N₂ + 3H₂ ⇌ 2NH₃,ΔH ≈ -92千焦(放热)
  - 4个气体分子变成2个 → 高压有利于生成氨
  - 放热反应 → 低温有利于产率,但低温时反应太慢
  - 折中: 约400-500°C、数百个大气压、铁催化剂,并不断把氨冷凝分离出去
→ 这就是哈伯法需要大型高压设备的原因
```

### 3.3 酸碱平衡

```
pH = -lg[H⁺],即氢离子浓度的负对数
  水在25°C时 [H⁺] × [OH⁻] = 10⁻¹⁴,中性时两者都是 10⁻⁷,pH = 7

强酸(盐酸、硫酸)在水中完全电离;弱酸(醋酸、碳酸)只部分电离
缓冲溶液: 弱酸和它的盐混合,加入少量酸或碱时pH变化很小
  → 人体血液就是缓冲体系,pH 稳定在约7.4
```

### 3.4 溶解平衡

```
难溶物质在水中也会溶解极少一点,达到平衡
  → 加入相同的离子会让它更难溶(同离子效应)
  → 利用生成沉淀来分离、检验离子(见第七节)
```

## 四、反应速率和催化

```
影响反应速率的因素:
1. 浓度: 浓度越大越快
2. 温度: 温度每升高10°C,很多反应的速度大约增加到2-4倍
   → 食物冷藏能延缓变质;放热反应失控的原因
3. 接触面积: 颗粒越细越快
   → 粉尘爆炸: 可燃物磨成细粉飘在空气中,燃烧速度极快
4. 催化剂: 降低反应需要的"门槛"(活化能),本身不被消耗
   → 合成氨用铁,制硫酸用五氧化二钒

酶: 生物体内的催化剂,本质是蛋白质
  - 效率极高,专一性强(一种酶只催化一种或一类反应)
  - 怕高温、强酸强碱(蛋白质变性后失活)
  - 酿酒、发面、做酱、消化食物都靠酶
```

## 五、电化学

### 5.1 氧化还原

```
氧化: 失去电子(化合价升高)
还原: 得到电子(化合价降低)
氧化和还原总是同时发生
  例: Zn + Cu²⁺ → Zn²⁺ + Cu  锌被氧化,铜离子被还原
```

### 5.2 原电池和电极电势

| 电极 | 标准电极电势(伏) |
|------|-----------------|
| 锂 Li⁺/Li | -3.04 |
| 钾 K⁺/K | -2.93 |
| 钠 Na⁺/Na | -2.71 |
| 镁 Mg²⁺/Mg | -2.37 |
| 铝 Al³⁺/Al | -1.66 |
| 锌 Zn²⁺/Zn | -0.76 |
| 铁 Fe²⁺/Fe | -0.44 |
| 锡 Sn²⁺/Sn | -0.14 |
| 铅 Pb²⁺/Pb | -0.13 |
| 氢 H⁺/H₂ | 0 |
| 铜 Cu²⁺/Cu | +0.34 |
| 银 Ag⁺/Ag | +0.80 |
| 金 Au³⁺/Au | +1.50 |

```
电池电压 ≈ 正极电势 - 负极电势
  例: 锌-铜电池(丹尼尔电池)= 0.34 - (-0.76) = 1.10伏
  → 两种金属在表中相距越远,组成的电池电压越高

铅酸蓄电池放电反应:
  Pb + PbO₂ + 2H₂SO₄ → 2PbSO₄ + 2H₂O
  充电时反应逆向进行
```

### 5.3 电解和法拉第定律

```
电解: 用外加电流驱动不能自发进行的反应

析出物质的质量 = (电量 ÷ F) × (摩尔质量 ÷ 离子的价数)
  F(法拉第常数)≈ 96485 库仑/摩尔
  电量 = 电流 × 时间(库仑 = 安 × 秒)

例: 用1安电流镀铜1小时
  电量 = 3600库仑 → 3600 ÷ 96485 ≈ 0.0373摩尔电子
  铜为2价 → 0.0187摩尔铜 × 64 ≈ 1.2克铜

用途:
- 电镀: 在铁件表面镀铜、镀锌、镀镍,防锈美观
- 精炼铜: 粗铜作阳极,纯铜作阴极,得到高纯度的铜(导线需要)
- 制铝、制烧碱和氯气(需要大量电力)
```

### 5.4 腐蚀和防护

```
钢铁生锈是电化学腐蚀: 铁表面不同部位形成许多微小的原电池
  有盐水、两种金属接触时腐蚀更快

牺牲阳极保护: 在钢铁(船体、水管、锅炉)上连接一块更活泼的锌或镁,
  让锌、镁先被腐蚀,保护钢铁(定期更换)
```

## 六、有机化学

### 6.1 官能团

| 类别 | 官能团 | 例子 | 性质 |
|------|--------|------|------|
| 烷烃 | 只有碳碳单键 | 甲烷(沼气)、汽油、石蜡 | 稳定,可燃 |
| 烯烃 | 碳碳双键 | 乙烯(催熟水果) | 能发生加成、聚合 |
| 芳香烃 | 苯环 | 苯、甲苯 | ⚠️ 苯有毒致癌 |
| 醇 | -OH | 乙醇(酒精)、甲醇(⚠️剧毒)、甘油 | 溶于水 |
| 醛 | -CHO | 甲醛(⚠️有毒)、乙醛 | 易被氧化 |
| 羧酸 | -COOH | 醋酸、脂肪酸 | 酸性 |
| 酯 | -COO- | 乙酸乙酯、油脂 | 有香味;能水解 |
| 胺 | -NH₂ | 氨基酸的一部分 | 碱性 |

### 6.2 主要反应类型

```
燃烧: 有机物 + 氧气 → 二氧化碳 + 水
取代: 一个原子(团)替换另一个
加成: 双键打开,接上新的原子
酯化和水解:
  酸 + 醇 ⇌ 酯 + 水
  油脂在碱中水解 → 肥皂 + 甘油(皂化)
氧化: 醇 → 醛 → 酸
  乙醇 → 乙醛 → 乙酸(酒变醋)
  甲醇 → 甲醛 → 甲酸 → 这是甲醇中毒致盲致死的原因
聚合: 许多小分子连成长链高分子
  加聚: 乙烯 → 聚乙烯(塑料袋)
  缩聚: 尼龙、涤纶
```

### 6.3 天然高分子和材料

```
纤维素: 棉花、木材、纸;人不能消化
淀粉: 粮食;能被酶分解成葡萄糖(制糖、酿酒的原理)
蛋白质: 羊毛、蚕丝、皮革、肉
天然橡胶: 橡胶树的乳汁
  硫化: 加入少量硫磺加热,橡胶分子之间形成交联,
  从发黏怕热变得有弹性、耐用(轮胎、密封圈)
```

### 6.4 从木材和松脂中获得化学品

```
木材干馏(隔绝空气加热):
  → 木炭(固体)
  → 木醋液(含醋酸、⚠️甲醇、丙酮等)
  → 木焦油(防腐、防水)
  → 可燃气体
  历史上醋酸、甲醇、丙酮都来自木材干馏
  ⚠️ 产物中的甲醇有剧毒,木醋液不能饮用

松脂蒸馏:
  松树割开树皮流出的松脂 → 加热蒸馏
  → 松节油(溶剂、稀释油漆)
  → 松香(残留的固体;焊接助焊剂、肥皂、胶、防滑)
```

## 七、分析化学: 这是什么、有多少

### 7.1 焰色反应

```
用干净的铁丝(先在火中烧到无色)蘸取样品,放在无色火焰中:
  钠: 黄色(很强,会掩盖其他颜色)
  钾: 浅紫色(透过蓝色玻璃观察)
  钙: 砖红色
  铜: 绿色或蓝绿色
  锂: 深红色
  钡: 黄绿色
用途: 粗略判断矿石、盐类中含有哪种金属
```

### 7.2 常用检验方法

| 要检验的物质 | 方法 | 现象 |
|-------------|------|------|
| 二氧化碳 | 通入澄清石灰水 | 变浑浊 |
| 氧气 | 带火星的木条 | 复燃 |
| 氢气 | 点燃收集的少量气体(远离大量气体) | 轻微爆鸣 |
| 淀粉 | 滴碘酒 | 变蓝 |
| 氯离子 | 加硝酸银溶液 | 白色沉淀 |
| 硫酸根 | 加氯化钡溶液 | 白色沉淀 |
| 铁离子 | 加浓茶或单宁(鞣质) | 变黑(铁胆墨水的原理) |
| 酸碱性 | 紫甘蓝汁、石蕊 | 变色(见化学-pH) |
| 水的硬度 | 加肥皂水摇晃 | 泡沫少、有浮渣 → 硬水 |

### 7.3 滴定: 精确测量浓度

```
用已知浓度的溶液,一滴一滴地加入待测溶液,直到恰好完全反应(用指示剂变色判断)

例: 测醋的酸度
  取10毫升醋,加几滴指示剂(酚酞,或者紫甘蓝汁)
  用0.5摩尔/升的氢氧化钠溶液滴定,到颜色刚好改变时,用去16毫升
  氢氧化钠的摩尔数 = 0.5 × 0.016 = 0.008摩尔
  醋酸和氢氧化钠1:1反应 → 10毫升醋中有0.008摩尔醋酸
  浓度 = 0.8摩尔/升 ≈ 每升48克(约4.8%)

需要: 准确的量筒或滴定管、天平、已知浓度的标准溶液
```

### 7.4 称量分析

```
把要测的成分变成纯净的沉淀,过滤、烘干、称重,按化学式算出含量
  例: 测矿石中某种金属的含量
```

## 八、重要的化工过程(原理)

```
纯碱(索尔维法):
  NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl
  2NaHCO₃ → Na₂CO₃ + H₂O + CO₂↑(加热)
  氨用石灰回收循环使用
  原料: 食盐、石灰石;产品用于玻璃、肥皂、造纸

硫酸(接触法):
  S + O₂ → SO₂
  2SO₂ + O₂ ⇌ 2SO₃(约400-450°C,五氧化二钒催化)
  三氧化硫用浓硫酸吸收(直接用水吸收会形成难以收集的酸雾),再稀释
  ⚠️ 二氧化硫、三氧化硫、浓硫酸都极具危险性

氯碱工业: 电解饱和食盐水 → 氢氧化钠 + 氯气 + 氢气(见化学章)

合成氨: 见本章第三节

造纸: 用碱液蒸煮木材、稻草,溶解木质素,留下纤维素纤维
制糖: 甘蔗、甜菜榨汁 → 用石灰澄清 → 浓缩结晶
石油炼制: 按沸点不同分馏出汽油、煤油、柴油、润滑油、沥青
```
