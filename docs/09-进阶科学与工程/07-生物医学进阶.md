# 生物医学进阶

> **现代医学的力量来自三样东西: 理解身体怎样工作(生理),知道药物在体内怎样起作用(药理),以及用严格的试验区分真正有效的疗法和安慰(循证)**

## ⚠️ 本章的定位

本章讲医学背后的科学原理,帮助理解医生为什么这样诊断和用药、药物为什么要按剂量和疗程使用、医学知识是怎样被验证的。

```
⚠️ 重要:
- 本章不是诊疗指南,不能代替医生。具体疾病和急救的处理见急救与家庭健康部分
- 药物剂量必须遵医嘱或说明书,本章的公式和例子只用于理解原理
- 微生物培养只用于诊断和教学,所有培养物都要按有致病性对待,用后彻底灭菌
- 本手册不提供自制抗生素、疫苗、注射剂的方法(原因见制药技术部分)
```

基础知识见[生物与医学基础](../08-基础科学知识/04-生物与医学基础.md)。

## 一、分子生物学

### 1.1 中心法则

```
DNA → (转录) → RNA → (翻译) → 蛋白质

DNA: 遗传信息的载体,由四种"碱基"(A、T、G、C)排列而成,双螺旋结构
  A 和 T 配对,G 和 C 配对 → 一条链可以作为模板复制出另一条
RNA: 把 DNA 上一段信息(基因)抄写下来,带到细胞质中
蛋白质: 按 RNA 上的信息,每3个碱基决定一个氨基酸,连成长链折叠而成
  → 酶、抗体、肌肉、激素、血红蛋白……生命活动几乎都由蛋白质执行
```

### 1.2 突变

```
DNA 复制出错或被破坏(紫外线、辐射、某些化学物质),碱基序列改变
- 大多数突变无害或有害,极少数有益
- 生殖细胞中的突变能遗传给后代 → 进化的原材料
- 体细胞突变积累可能导致癌症
→ 这就是辐射、吸烟、某些化学品致癌的原因
```

### 1.3 病毒为什么难治

```
病毒没有自己的细胞,只是一段 DNA 或 RNA 包在蛋白质外壳里
它钻进人的细胞,利用人体细胞的"机器"复制自己
→ 很难在杀死病毒的同时不伤害人体细胞
→ 抗生素对病毒无效;抗病毒药物种类少、针对性强
→ 预防(疫苗、隔离、洗手)比治疗更重要
```

## 二、免疫学进阶

### 2.1 免疫系统的分工

```
先天免疫(天生的,反应快,不针对特定病原):
  皮肤黏膜屏障、吞噬细胞(吞掉入侵者)、炎症反应(红肿热痛)、发热

适应性免疫(后天获得的,反应慢,针对特定病原,有记忆):
  B 细胞 → 产生抗体,抗体和病原体特异结合,使其失效或被清除
  T 细胞 → 杀死被感染的细胞,协调整个免疫反应
  记忆细胞 → 再次遇到同一病原体时,迅速大量反应
```

### 2.2 疫苗的种类

| 类型 | 原理 | 例子 |
|------|------|------|
| 减毒活疫苗 | 毒力减弱的活病原体 | 麻疹、卡介苗(结核) |
| 灭活疫苗 | 杀死的病原体 | 狂犬病、甲肝 |
| 类毒素 | 去除毒性的细菌毒素 | 破伤风、白喉 |
| 亚单位/重组 | 病原体的一部分蛋白 | 乙肝 |
| 核酸疫苗 | 让人体细胞自己制造病原体的一种蛋白 | 部分新冠疫苗 |

```
⚠️ 疫苗的生产需要严格控制病原体的毒力、纯度、无菌和剂量,
   必须由专业机构完成;冷链运输保存
```

### 2.3 免疫异常

```
过敏: 免疫系统对无害物质(花粉、食物、药物)过度反应
  最严重的是过敏性休克,数分钟内危及生命
自身免疫病: 免疫系统攻击自身组织(类风湿关节炎、1型糖尿病等)
免疫缺陷: 免疫力低下,容易反复感染
```

过敏性休克的处理见[急性症状-过敏反应](../01-日常疾病和伤害/05-急性症状.md#过敏反应)。

## 三、生理学要点

### 3.1 循环

```
心脏: 右心把静脉血泵到肺里换气,左心把含氧的血泵到全身
血压: 收缩压(心脏收缩时)/ 舒张压(心脏舒张时),单位毫米汞柱
  我国标准: 达到或超过 140/90 为高血压
脉搏: 成人安静时约60-100次/分钟

休克: 全身组织得不到足够的血液供应
  原因: 大出血、严重脱水、严重感染、过敏、心脏衰竭
  表现: 皮肤苍白湿冷、脉搏快而弱、烦躁或淡漠、尿少
```

### 3.2 呼吸

```
肺泡中,氧气进入血液,二氧化碳排出
呼吸频率: 成人安静时约12-20次/分钟
血氧饱和度(指夹式血氧仪测量): 正常一般在95%以上
  明显偏低 → 缺氧,需要就医
调节呼吸的主要信号是血液中的二氧化碳浓度
  → 过度换气(呼吸太快太深)会让二氧化碳过低,出现手脚麻木、抽筋
```

### 3.3 肾脏和体液

```
肾脏过滤血液,排出废物和多余的水、盐,维持体内水和电解质的平衡
成人每天需要的水约2-2.5升(包括食物中的水),炎热、劳动、发热、腹泻时需要更多
尿量和颜色是判断是否缺水的简单指标: 尿少、颜色深 → 缺水

腹泻、呕吐的主要危险是失水和失盐
口服补液盐: 按一定比例含有葡萄糖和盐,葡萄糖能帮助肠道吸收钠和水
  → 比单纯喝白开水补液效果好得多,是20世纪最重要的医学进展之一
```

口服补液盐的使用见[常见疾病-腹泻](../01-日常疾病和伤害/01-常见疾病.md#腹泻)。

### 3.4 体温调节

```
下丘脑像"恒温器",把体温维持在37°C左右
发热: 感染时"恒温器"的设定点调高,是免疫反应的一部分
  → 一般发热不必急于降到正常;过高的体温才需要积极处理
中暑: 产热和吸热超过散热能力,体温失控上升(和发热的机制不同)
```

发热的分级见[常见疾病-发烧](../01-日常疾病和伤害/01-常见疾病.md#发烧)。

### 3.5 血糖

```
胰岛素降低血糖,胰高血糖素升高血糖
糖尿病: 胰岛素不足(1型)或作用减弱(2型),血糖长期过高
低血糖: 最常见于用降糖药或胰岛素的糖尿病人,严重时昏迷,
  清醒时立即吃糖
```

低血糖的处理见[心脑血管与突发病症-低血糖](../01-日常疾病和伤害/06-心脑血管与突发病症.md#低血糖)。

## 四、药理学原理

### 4.1 药物在体内的过程

```
吸收 → 分布 → 代谢(主要在肝脏)→ 排泄(主要经肾脏)
→ 肝病、肾病、老人、婴幼儿、孕妇的用药剂量和种类往往需要调整
```

### 4.2 剂量与效应

```
剂量太小 → 无效
剂量合适 → 有效
剂量太大 → 中毒

治疗指数 = 引起中毒的剂量 ÷ 有效剂量
  治疗指数大 → 比较安全(有效量和中毒量相差很远)
  治疗指数小 → 危险(有效量和中毒量很接近,如地高辛、某些抗癫痫药)

"剂量决定毒性": 任何物质(包括水和盐)过量都有害
  对乙酰氨基酚(扑热息痛)过量会导致严重的肝损伤,
  多种感冒药里都含有它,同时吃几种容易超量
```

### 4.3 半衰期和给药间隔

```
半衰期: 体内药物浓度降低一半所需的时间
  - 经过约5个半衰期,药物基本从体内清除
  - 按固定间隔反复给药,约4-5个半衰期后体内浓度达到稳定("稳态")

→ 给药间隔通常和半衰期相关: 半衰期短的药一天要吃好几次
→ 漏服、随意加量都会让浓度忽高忽低
→ 有些药为了尽快起效,第一次给较大的"负荷剂量"
```

半衰期的计算见[数学-指数衰减和半衰期](../08-基础科学知识/01-数学.md#72-指数衰减和半衰期)。

### 4.4 按体重计算剂量

```
儿童用药常按体重计算: 每次剂量 = 每千克体重的剂量 × 体重
  例: 某药每次每千克10毫克,孩子体重15千克 → 每次150毫克
  ⚠️ 同时要核对"每次最大剂量"和"每天最多几次",不能超过成人剂量
  ⚠️ 注意药液的浓度: 每5毫升含多少毫克
```

### 4.5 药物相互作用和不良反应

```
- 一种药可以增强或减弱另一种药的作用(如抗凝药和某些止痛药合用增加出血风险)
- 酒精和很多药物(镇静药、某些抗生素、对乙酰氨基酚)一起用有危险
- 过敏: 与剂量无关,一点点就可能严重过敏;用过敏过的药前一定要告知医生

✓ 每次看病带上正在吃的所有药物清单
```

用药信息卡见[慢性病用药储备](../01-日常疾病和伤害/08-慢性病用药储备.md)。

## 五、微生物学实验技术(诊断和教学)

### 5.1 显微镜

```
自制简易显微镜(列文虎克式):
  用一颗很小的玻璃珠(细玻璃棒在火焰中熔化成小球)作透镜,
  固定在金属片的小孔上,样品贴近另一侧观察
  → 能放大一两百倍,足以看到较大的细菌、酵母、血细胞、寄生虫卵

复式显微镜(物镜 + 目镜)放大倍数 = 物镜倍数 × 目镜倍数
  看细菌通常需要约1000倍(油镜)
```

### 5.2 无菌操作

```
✓ 所有器材、培养基事先高压蒸汽灭菌(约121°C,15分钟以上)
✓ 在酒精灯火焰附近操作(火焰上方的上升气流减少落入的杂菌)
✓ 接种环每次使用前后在火焰中烧红
✓ 打开容器的时间尽量短,开口过火
✓ 工作台面用75%酒精擦拭
```

### 5.3 培养和染色

```
培养基: 细菌需要营养(肉汤、蛋白胨)和合适的温度(人体致病菌约37°C)
  加入琼脂凝固成固体培养基,单个细菌会长成肉眼可见的"菌落"

革兰染色(区分两大类细菌,指导抗生素的选择):
  结晶紫染色 → 碘液固定 → 酒精脱色 → 番红复染
  革兰阳性菌: 紫色;革兰阴性菌: 红色

⚠️ 生物安全:
- 来自病人的样本、长出的菌落都要按可能致病对待
- 不要用嘴吸液体,不要在工作区吃喝
- 用过的培养物、器材必须高压灭菌后再丢弃或清洗
- 不要培养来源不明、可能高度危险的病原体
```

### 5.4 简单的检验

```
- 血涂片: 看红细胞、白细胞;疟疾流行区可查疟原虫
- 粪便镜检: 寄生虫卵(蛔虫、钩虫等)
- 尿液: 颜色、浑浊度;试纸可测尿糖、尿蛋白、白细胞
- 痰涂片抗酸染色: 结核杆菌
这些检验需要训练才能判读,结果要结合症状由医生综合判断
```

## 六、诊断的思路

```
1. 问诊: 什么时候开始、哪里不舒服、怎样变化、有什么诱因、既往病史、用药、过敏
2. 体格检查: 生命体征(体温、脉搏、呼吸、血压、意识)、看、摸、叩、听
3. 列出几种可能(鉴别诊断),先考虑常见的和危险的
4. 必要的检验
5. 处理后观察效果,不符合预期时重新考虑

"红旗"信号: 提示严重疾病、需要尽快就医的症状
  (如剧烈头痛伴发热和颈部僵硬、胸痛、意识改变、呼吸困难、便血)
```

各种危险信号见[急救与家庭健康](../01-日常疾病和伤害/README.md)部分的"何时必须立即就医"。

## 七、循证医学: 怎样知道一种疗法真的有效

### 7.1 证据的等级(从弱到强)

```
1. 个人经验、"某某说有效"、个案
2. 病例系列(一组病人用了某疗法,结果如何,没有对照)
3. 观察性研究(比较用了和没用的人,但不是随机分组)
4. 随机对照试验(随机分组、有对照、最好双盲)
5. 多个随机对照试验的综合分析
```

### 7.2 为什么必须有对照

```
- 很多病会自己好(感冒、大部分腹泻、轻度扭伤)
- 安慰剂效应: 相信自己在接受治疗,症状就可能减轻
- 回归平均: 人往往在最难受时去求医,之后自然会好转一些
→ 没有对照组,这些都会被当成"疗效"
```

### 7.3 随机对照试验的要点

```
✓ 事先写好: 研究什么问题、怎样算有效、需要多少人
✓ 随机分组(抽签)
✓ 盲法: 病人不知道自己用的是哪种;评估效果的人最好也不知道
✓ 对照组用目前最好的已知疗法或安慰剂(在伦理允许的前提下)
✓ 统计分析(见高等数学-统计推断)
✓ 伦理: 参与者知情同意;不能让对照组得不到已知有效的治疗
```

统计方法见[高等数学-统计推断](04-高等数学.md#八统计推断-判断结果是不是巧合)。

### 7.4 评价一个疗效说法

```
问自己:
- 有没有对照?是否随机?
- 多少人参加?
- "有效"是怎么衡量的?
- 有没有说清楚副作用?
- 是否只报告了好的结果?
```

## 八、炎症和伤口愈合

```
炎症: 组织受伤或感染后的防御反应
  红(血管扩张)、肿(液体渗出)、热、痛,以及功能障碍
  → 是愈合的必要过程,但范围过大或持续不退提示感染或其他问题

伤口愈合的阶段:
  止血(数分钟)→ 炎症(约数天)→ 增生、长出新组织(约数天到数周)
  → 重塑(数周到数月,瘢痕慢慢变软变淡)

影响愈合的因素: 感染、异物、血液供应差、营养不良(蛋白质、维生素C)、
  糖尿病、吸烟、反复摩擦
```

伤口处理见[外伤处理](../01-日常疾病和伤害/02-外伤处理.md)。
