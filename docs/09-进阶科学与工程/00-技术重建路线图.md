# 技术重建路线图

> **技术不是一项一项孤立的发明,而是一棵树: 每一项都站在别的技术上面。知道树的形状,才知道先种哪一棵**

## ⚠️ 本章的定位

本章是全书的"地图": 把粮食、冶金、制药、能源、科学知识等各部分串成一条路线,说明**每一项技术需要哪些前提、卡在哪里、可以走哪些捷径**。

```
要现实地看待:
- 现代工业依赖全球分工: 一部手机需要几十个国家、上百万人的协作,
  一个小社区不可能重建
- 现实的目标是: 先保证生存,再逐步恢复到大约19世纪后期的技术水平
  (农业、冶铁炼钢、蒸汽动力、基本的电力和化工、病菌学说指导下的医疗卫生)
- 每一步都需要足够的人口和分工: 几十个人只能维持简单的农业和手工业,
  冶金、化工、机械制造需要更大的社会

最重要的三条:
1. 生存优先: 水、食物、住所、卫生、医疗,这些不稳定时,其他都谈不上
2. 先保存和利用,再制造: 废墟里的钢材、铜线、书籍比自己造的好得多
3. 知识是最大的捷径: 我们知道答案,不需要重走前人几千年的弯路
```

## 一、技术树总览

```
阶段0  生存
       水 · 食物 · 住所 · 卫生 · 急救 · 火
          │
阶段1  农业与基础手工
       种植养殖 · 留种 · 食物保存 · 陶器 · 纺织 · 木工 · 石灰 · 制皂 · 木炭
          │
阶段2  冶金与机械
       铜和青铜 → 铁 → 钢
       水车 · 风车 · 齿轮 · 车床 · 标准量具
          │
阶段3  基础化工与材料
       碱 · 硫酸 · 玻璃 · 水泥 · 纸和印刷 · 耐火材料
          │
阶段4  动力
       锅炉 · 蒸汽机 · (斯特林发动机)
          │
阶段5  电力
       电池 · 发电机 · 电动机 · 电报 · 电灯
          │
阶段6  化工与医药进阶
       电解(氯碱) · 化肥 · 药物提纯 · 显微镜与微生物学
          │
阶段7  电子
       真空管 · 半导体 · 无线电 · 计算机
       (从零制造极其困难,现实做法是利用保存下来的器件)
```

阶段之间不是严格的先后关系: 电磁感应的知识可以让人在没有蒸汽机的时候就用水力发电,病菌学说的知识在阶段0就能救人。

## 三、关键瓶颈

### 3.1 燃料和能源

```
一切技术都需要能量:
- 冶铁: 炼1 kg铁需要的木炭往往是铁的好几倍,一座炼铁炉一年要烧掉大片森林
- 历史上很多地区因为烧炭炼铁把森林砍光了

对策:
✓ 森林轮伐: 把林地分成多块,每年只砍一块,砍后让树桩重新发芽(很多阔叶树可以),
  十几年轮一圈
✓ 找煤: 煤的热值高,但含硫,直接用来炼铁会让铁变脆(历史上要先炼成焦炭)
✓ 水力和风力: 用来鼓风、锻打、研磨,节省人力和燃料
✓ 节能: 好的炉子、保温、余热利用
```

燃料热值见[物理-热学](../08-基础科学知识/02-物理.md#五热学);森林和木炭见[照明与能源-燃料的安全储存](../07-日常生活技能/06-照明与能源.md#燃料的安全储存)。

### 3.2 精密加工: 机器的"母机"

```
蒸汽机的气缸要和活塞紧密配合,发电机的转子不能碰到定子,
螺丝和螺母要能互换——这些都需要精度。而精度是"自举"出来的:

1. 平面: 三平板互研法
   - 准备三块铸铁板(或硬石板),A和B对研、B和C对研、C和A对研,轮流进行
   - 两块板对研只能保证它们互相吻合(可能一凹一凸)
   - 三块轮流对研,唯一能让三对都吻合的形状就是平面
   - 不需要任何现成的精密工具,就能从零得到非常平的平面

2. 直线和直角: 有了平面,就能做出直尺、角尺

3. 车床: 被称为"机床之母"
   - 能车出圆柱、圆孔,配上丝杠就能车出螺纹
   - 有了一台精度一般的车床,就能做出精度更高的零件,
     再用这些零件做更好的车床

4. 标准量具: 全社区统一的标准尺、标准螺纹、量规
   → 零件可以互换,机器坏了能换零件而不是整台重做
```

度量标准的建立见[度量衡与科学方法](../08-基础科学知识/00-度量衡与科学方法.md);机械元件见[工程力学与材料-机械元件](01-工程力学与材料.md#十一机械元件)。

### 3.3 硫酸

```
被称为"化工之母": 处理矿石、制化肥、蓄电池、制其他酸和很多化学品都需要它
古代用加热绿矾(硫酸亚铁)的方法少量制取;
近代用硫磺燃烧再氧化吸收的方法大量生产(见化学章)
⚠️ 浓硫酸腐蚀性极强,生产过程产生有毒气体,需要耐酸的设备(铅、玻璃、陶瓷)
```

### 3.4 玻璃

```
没有玻璃,就没有: 透镜(眼镜、显微镜、望远镜)、化学实验器皿、温度计、
真空管、密封保存的药瓶
需要: 石英砂、纯碱(或草木灰)、石灰,约1400-1500°C的窑炉
```

### 3.5 纸和印刷: 知识的传播

```
知识只存在几个人的脑子里是很脆弱的
✓ 造纸: 植物纤维(树皮、麻、竹、稻草)捣烂成浆 → 用帘子抄成薄层 → 压干晒干
✓ 印刷: 雕版、活字
✓ 教育: 让更多的人识字、会算术、懂科学原理
```

### 3.6 人

```
技术最终由人掌握。比任何一台机器都重要的是:
- 识字和算术
- 记录和传承的习惯
- 分工和协作的组织
- 学徒制: 有经验的人带年轻人,手艺才能传下去
```

## 四、废墟里的资源: 先利用,再制造

文明崩溃后的很长一段时间里,**废墟中保存下来的现代材料,比任何能自己制造的东西都好**。

| 资源 | 来源 | 用途 |
|------|------|------|
| 钢材 | 钢筋、型钢、汽车车架、弹簧 | 锻造工具和刀具(汽车板簧是很好的工具钢) |
| 铜线 | 电线电缆、电动机、变压器的线圈 | 发电机、电动机、电报 |
| 磁铁 | 扬声器、电动机、硬盘 | 发电机、指南针 |
| 发电机 | 汽车的交流发电机 | 用水力、风力带动,给12 V蓄电池充电 |
| 电动机 | 各种电器、电动车、跑步机 | 永磁直流电动机反向转动就是发电机 |
| 蓄电池 | 汽车、电动车、不间断电源 | 储存电能;铅可以回收 |
| 太阳能板 | 屋顶、路灯 | 发电(寿命可达几十年) |
| 轴承、齿轮、链条 | 汽车、自行车、机械 | 水车、风车、机械 |
| 玻璃 | 窗户、瓶子 | 容器、温室;重熔需要高温 |
| 书籍 | 图书馆、学校、书店 | **最有价值**: 中学和大学的理工科教材、农业、医学、工程手册 |
| 手动工具 | 五金店、家庭 | 锯、锤、凿、锉、钳、扳手、手钻 |
| 种子 | 种子店、农户 | 优先传统品种(能留种) |

```
⚠️ 拆解时的安全:
- 坍塌: 不要进入受损严重的建筑
- 石棉: 旧建筑的保温材料、石棉瓦,不要打碎、不要吸入粉尘
- 化学品: 不认识的不要打开、不要混合
- 电池: 铅酸电池的酸会腐蚀,锂电池破损会起火
- 电容器: 大电容(如微波炉内)断电后仍可能储存致命的电量
- 冷媒、制冷剂: 拆空调冰箱时会泄漏
```

## 五、可以走的捷径

我们知道历史的"答案",很多弯路不必再走:

```
✓ 病菌学说: 直接洗手、煮沸、消毒、隔离,不必经历"瘴气论"
✓ 营养: 直接知道豆芽防坏血病、糙米防脚气病、碘盐防大脖子病
✓ 成熟的设计: 直接做上射式水轮、改良的犁、带分离冷凝器的蒸汽机,
  不必从最原始的版本开始
✓ 电磁感应: 知道原理,只要有铜线和磁铁(可以从废墟中获得),
  就能在蒸汽机之前用水力、风力发电
✓ 科学方法: 对照实验、记录,让每一次尝试都积累知识
✓ 统一的度量衡和标准: 从一开始就统一,不必经历各地标准混乱的阶段

不能跳过的:
✗ 材料: 没有足够好的钢、铜、玻璃,知道原理也造不出机器
✗ 精度: 必须一步步自举
✗ 规模: 很多技术只有在足够大的规模上才划算
✗ 技能: 锻造、烧窑、木工这些手艺,只能通过反复练习掌握
```

## 六、小社区能做到什么

| 社区规模 | 现实可以维持的技术 |
|---------|-------------------|
| 几户到几十人 | 农业、养殖、留种、食物保存、木工、纺织、制皂、简单陶器、急救和卫生;利用废墟中的材料和工具 |
| 几百人 | 加上: 小规模冶铁锻造、水车风车、烧石灰、烧砖、简单的机械加工、小型发电、学校 |
| 几千人以上 | 加上: 炼钢、玻璃、造纸印刷、基础化工、蒸汽机、电报、较完整的医疗 |
| 更大的区域协作 | 化肥工业、钢铁工业、电网、药品工业、电子工业 |
