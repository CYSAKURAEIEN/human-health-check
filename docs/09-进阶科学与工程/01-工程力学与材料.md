# 工程力学与材料

> **房子会不会塌、桥能承受多重、轴会不会断——工程力学让这些问题可以事先算出来,而不是等它塌了才知道**

## ⚠️ 本章的定位

本章讲结构和机械设计背后的原理和基本计算方法,帮助理解"为什么这样做更结实"。

```
⚠️ 重要:
- 本章的计算是简化的,用于理解和粗略估算
- 住人的房屋、桥梁、起重设备、压力容器,一旦失效会造成伤亡:
  有条件时请专业人员设计,没有条件时取更大的安全系数,并先做试验
- 材料强度的数值是典型值,实际材料(尤其是自制的铁、回收的旧料、
  有疤节的木材)可能低得多
```

需要的数学和物理基础见[数学](../08-基础科学知识/01-数学.md)、[物理-运动与力](../08-基础科学知识/02-物理.md#一运动与力)。

## 一、力的合成和分解

```
力有大小和方向,可以像箭头一样相加(平行四边形法则)

一个斜向的力可以分解成水平和竖直两个分力:
  水平分力 = F × cos θ
  竖直分力 = F × sin θ

例: 用绳子以30°角斜向上拉一个箱子,拉力100 N
  水平方向拉动箱子的力 = 100 × cos30° ≈ 87 N
  向上提起的力 = 100 × sin30° = 50 N
```

### 1.1 绳子的夹角越大,拉力越大

```
用两根绳子吊起一个重物,两根绳子之间的夹角为 α:
  每根绳子的拉力 = 重量 ÷ (2 × cos(α/2))

  夹角 0°(两根都竖直): 每根承担一半重量
  夹角 120°: 每根绳子的拉力 = 整个重量
  夹角接近 180°(绳子几乎拉平): 拉力趋向无穷大

⚠️ 起吊时绳子的夹角不要超过约90°;晾衣绳、索桥不能拉得太平,
   拉得越平,绳子受的力越大,越容易断
```

## 二、静力平衡和力矩

```
物体静止不动(平衡)的条件:
1. 所有力的合力为零(不会移动)
2. 所有力矩的合计为零(不会转动)

力矩 = 力 × 力臂(力的作用线到转动点的垂直距离)

例: 一根4 m长的梁,两端支撑,在离左端1 m处挂400 kg的重物
  对左端取力矩: 右端支座的力 × 4 = 400 × 1 → 右端承担100 kg
  左端承担 400 - 100 = 300 kg
  → 重物靠近哪一端,哪一端的支座受力就大
```

## 三、应力和应变

### 3.1 应力

```
应力 = 力 ÷ 横截面积(σ = F ÷ A),单位帕(Pa)
  1 MPa(兆帕)= 1 N/mm² ≈ 每 cm² 承受约10 kg

材料是否会坏,取决于应力,而不是力的大小:
  同样的拉力,粗绳子比细绳子安全
```

### 3.2 应变和弹性

```
应变 = 伸长量 ÷ 原长(ε = ΔL ÷ L),没有单位

胡克定律: 在弹性范围内,应力 = 弹性模量 × 应变(σ = E × ε)
  弹性模量 E 越大,材料越"硬",受力后变形越小

超过弹性极限后: 卸载后不能恢复原状(塑性变形),再大就会断裂
  - 韧性材料(钢、铜、熟铁): 断之前会明显弯曲变形,有预警
  - 脆性材料(铸铁、石头、玻璃、混凝土): 几乎没有变形就突然断裂
```

### 3.3 常用材料的性能(典型值)

| 材料 | 弹性模量 E(GPa) | 抗拉强度(MPa) | 抗压强度(MPa) | 特点 |
|------|-----------------|---------------|---------------|------|
| 低碳钢 | 约200 | 约370-500(屈服约235) | 与抗拉相近 | 韧性好,结构钢 |
| 灰铸铁 | 约100 | 约150-250 | 约600-1000 | 抗压好,抗拉差,脆 |
| 铜(退火) | 约110-120 | 约200-250 | | 韧性极好,导电 |
| 铝合金 | 约70 | 约150-300 | | 轻 |
| 松木、杉木(顺纹,无疵) | 约10 | 约60-100 | 约30-50 | 有疤节、横纹时强度大大降低 |
| 竹 | 约10-20 | 常超过100 | 约40-80 | 轻而韧,抗拉好 |
| 混凝土 | 约25-30 | 约2-4 | 约20-40 | 抗压好,几乎不能受拉 |
| 砖砌体 | | 很低 | 约2-10 | 只能受压 |
| 花岗岩 | 约50 | 约5-15 | 约100-250 | 只能受压 |

```
⚠️ 以上是"能承受的极限",设计时还要除以安全系数(见下)
⚠️ 木材的设计强度通常只取无疵小试样的几分之一(疤节、裂纹、含水率、长期荷载)
```

### 3.4 安全系数

```
允许使用的应力 = 材料的极限强度 ÷ 安全系数

安全系数的选择(经验范围):
- 材料质量稳定、荷载清楚(如合格的钢结构): 约1.5-2
- 木结构、自制或回收的材料: 3以上
- 起吊用的绳索、链条: 5以上
- 有人员在下面、失效后果严重的: 取更大
- 冲击荷载(落下、撞击): 实际力可能是静止重量的好几倍

✓ 新做的承重构件,先用比实际更重的荷载试验,人员远离
```

## 四、受压构件和屈曲

```
短而粗的柱子: 受压时被压坏(取决于抗压强度)
细而长的柱子: 远没有达到抗压强度,就会突然向一侧弯曲失稳("屈曲")

欧拉公式(两端铰接的细长杆):
  临界压力 P = π² × E × I ÷ L²
  I: 截面惯性矩(矩形 I = 宽 × 高³ ÷ 12;圆形 I = π × 直径⁴ ÷ 64)
  L: 长度

→ 长度加倍,能承受的压力只剩1/4
→ 防止屈曲: 加粗、在中间加横撑或斜撑(把长柱分成几段短柱)
→ 竹竿、细木杆做支柱时,中间要加横向拉结
```

## 五、梁的弯曲

### 5.1 弯矩

```
梁在荷载作用下会弯曲: 下边被拉长,上边被压短(简支梁)

简支梁(两端搁在支座上)的最大弯矩:
  跨中一个集中荷载 P:  M = P × L ÷ 4
  均匀分布的荷载 q(N/m): M = q × L² ÷ 8

→ 跨度加倍,弯矩变成4倍(均布荷载时)
```

### 5.2 截面: 为什么木板要"立着放"

```
梁的最大弯曲应力 σ = M ÷ W
  W: 截面模量,矩形截面 W = 宽 × 高² ÷ 6

强度和高度的平方成正比,和宽度只成正比:
  一根 10 cm × 20 cm 的木梁
  - 立着放(高20 cm): W = 0.1 × 0.2² ÷ 6 ≈ 6.7 × 10⁻⁴ m³
  - 平着放(高10 cm): W = 0.2 × 0.1² ÷ 6 ≈ 3.3 × 10⁻⁴ m³
  → 立着放的强度是平着放的2倍,刚度(不容易弯)是4倍

工字钢、槽钢做成这种形状,也是把材料放在离中心最远的上下边缘,
用最少的材料得到最大的强度
```

### 5.3 估算一根木梁能承受多少

```
例: 跨度4 m的松木梁,截面10 cm宽、20 cm高(立放),
    设计时取允许应力10 MPa(已考虑安全系数)
  允许弯矩 M = 10 × 10⁶ × 6.7 × 10⁻⁴ ≈ 6700 N·m
  均布荷载 q = 8M ÷ L² = 8 × 6700 ÷ 16 ≈ 3350 N/m
  → 约340 kg/m(还要扣除梁和楼板的自重)

挠度(弯下去多少)也要控制,楼板梁一般不超过跨度的1/250左右,
否则走上去会晃,抹灰会裂
```

### 5.4 悬臂梁

```
一端固定、一端悬空(阳台、挑檐、吊杆):
  端部集中荷载 P 时,固定端弯矩 M = P × L
  → 同样的荷载和长度,悬臂梁的弯矩是简支梁的4倍,
    固定端必须非常牢固
```

## 六、三角形和桁架

```
三角形是唯一一种只要边长不变、形状就不会改变的多边形
  - 四边形的框架一推就会变成平行四边形
  - 加一根斜撑,分成两个三角形,就稳定了

桁架: 由许多三角形组成的结构(屋架、桥架、塔架)
  - 杆件只受拉或只受压,不受弯,能用细杆件跨越很大的跨度
  - 节点要连接牢固

✓ 木结构房屋的墙架、屋架都要加斜撑
✓ 门框、木箱的角上加三角形木块
```

木结构的做法见[长期住所-简易木结构](../07-日常生活技能/05-长期住所.md#简易木结构)。

## 七、拱、穹顶和墙

### 7.1 拱

```
石头、砖、混凝土抗压很强、抗拉很弱
拱的形状让荷载沿着拱身变成压力传到两端,材料只受压
  → 用不能受拉的石头,也能跨越很大的跨度

理想的拱形: 把一根链条两端挂起,让它自然下垂形成的曲线(悬链线),
  上下翻转过来,就是只受压、不受弯的最理想拱形

⚠️ 拱会向两侧推: 两端的桥台、墙必须足够厚重,
   或者用拉杆把两端拉住,否则拱脚会向外滑开而坍塌

赵州桥(隋代,约1400年前): 单孔石拱,两肩开小拱,
  既减轻自重又能让洪水通过,至今仍在
```

### 7.2 砌体墙

```
✓ 只受压,不能受拉: 墙要竖直,荷载要压在墙的中间
✓ 砖石要错缝砌筑(上下层的竖缝错开),不能通缝
✓ 墙高和墙厚要成比例: 又高又薄的墙容易倒
✓ 门窗洞口上方要有过梁或拱
✓ 地震区: 圈梁、构造柱把墙"箍"起来(见长期住所-抗震)
```

抗震措施见[长期住所-抗震: 生土房屋的生死线](../07-日常生活技能/05-长期住所.md#抗震-生土房屋的生死线)。

## 八、悬索和绳索

```
绳索只能受拉
悬索桥、索道: 两端锚固,中间下垂

均匀荷载下,悬索的水平拉力 ≈ q × L² ÷ (8 × f)
  q: 每 m 的荷载(N/m);L: 跨度;f: 中间下垂的深度(垂度)
→ 垂度越小(拉得越平),拉力越大
→ 垂度通常取跨度的1/10左右
→ 两端的锚固点要承受全部拉力,必须非常牢固

绳结会降低绳子的强度(打结处可能只剩一半左右的强度)
```

## 九、地基

```
建筑物的重量最终要由地基下面的土来承担

不同土的大致承载力(单位面积能承受的压力,粗略范围):
- 淤泥、软土、回填土: 很低,不宜直接建房
- 一般黏土、粉土: 约100-200 kPa(约10-20 t/m²)
- 密实的砂、砾石: 约200-400 kPa
- 岩石: 更高

基础底面积 = 建筑物传下来的总重量 ÷ 地基承载力
  → 地基土越软,基础就要做得越宽

✓ 挖到原状土(没有被扰动过的老土),不要建在回填土上
✓ 基础底面要在冻土层以下(北方),否则冬天冻胀会把墙顶裂
✓ 做好排水,地基被水泡软后承载力大幅下降
```

选址和墙基见[长期住所](../07-日常生活技能/05-长期住所.md)。

## 十、材料科学

### 10.1 金属为什么能锻打

```
金属由大量小晶粒组成,晶体内部的原子可以成排滑移
  → 金属能弯曲、锻打、拉丝而不断裂(塑性)

加工硬化: 金属反复弯折、锤打后会变硬变脆
  (铁丝反复弯折会断)
退火: 加热后缓慢冷却,消除硬化,恢复塑性
  → 锻打中途要回炉加热,冷锻的铜要退火才能继续加工
```

### 10.2 铁和钢: 碳决定一切

```
按含碳量(本手册冶金部分采用的划分):
  熟铁: 含碳 < 0.2%  软、韧,好锻打,不能淬硬
  钢:   含碳约 0.2-2%  可以淬火变硬,强度和韧性兼备
  生铁: 含碳约 2-4%  熔点低,可以浇铸,但很脆,不能锻打

  含碳越多,越硬越脆;含碳越少,越软越韧
```

### 10.3 钢的热处理原理

```
钢在约727°C以上会转变成另一种晶体结构(奥氏体),碳能溶解在其中

淬火: 加热到约780-850°C(碳钢),迅速放入水或油中冷却
  → 碳原子来不及跑出来,被"冻结"在晶格中,形成很硬很脆的组织(马氏体)

回火: 淬火后再加热到较低的温度(约200-350°C),保持一段时间
  → 降低脆性,恢复一部分韧性;回火温度越高越韧、越不硬

退火: 加热后在炉中缓慢冷却 → 最软,便于加工
正火: 加热后在空气中冷却 → 组织均匀

判断淬火温度的小技巧:
  钢在约770°C以上会失去磁性
  → 加热时用磁铁靠近,刚好吸不住时,温度就接近淬火温度了
```

具体操作和回火颜色见[金属加工技术](../05-冶金技术/04-金属加工技术.md)。

### 10.4 常用合金

| 合金 | 成分 | 特点和用途 |
|------|------|-----------|
| 青铜 | 铜 + 锡(约10%) | 比铜硬,耐腐蚀,铸造性好;钟、轴承 |
| 黄铜 | 铜 + 锌 | 易加工,耐腐蚀;阀门、零件 |
| 焊锡 | 锡 + 铅(或锡 + 铜等无铅焊料) | 熔点低,焊接导线和铁皮;⚠️ 含铅焊料有毒 |
| 不锈钢 | 铁 + 铬(10.5%以上)+ 镍等 | 不易生锈 |
| 铸铁 | 铁 + 碳(2-4%)+ 硅 | 浇铸锅、炉、机床床身 |

### 10.5 陶瓷和耐火材料

```
陶器: 普通黏土,约800-1000°C烧成,有孔隙,渗水
瓷器: 高岭土(瓷土)+ 长石 + 石英,约1200-1300°C以上烧成,致密不渗水
砖: 黏土成型晒干后烧成;烧不透的砖强度低、怕水

耐火材料: 冶炼炉、窑炉、锅炉的内衬必须能耐高温
  - 耐火黏土(含铝量高的黏土)、高岭土
  - 掺入烧过的熟料(粉碎的旧耐火砖、瓷片)减少收缩开裂
  - 炉衬是冶金的瓶颈之一: 普通黏土在高温下会熔化软化
```

### 10.6 混凝土

```
水泥 + 砂 + 石子 + 水 → 水泥水化后把砂石粘结成整体

常用的粗略配比(体积比): 水泥 : 砂 : 石子 ≈ 1 : 2 : 3
  水越多越好浇筑,但强度越低;够用就好,不要随意加水

养护: 浇筑后要保持湿润至少7天(盖草帘洒水),不能让它很快干掉
  冬天低于5°C时强度增长很慢,结冰会冻坏

钢筋混凝土: 混凝土抗压,钢筋抗拉
  梁的钢筋放在受拉的一侧(简支梁在下部),两者结合
```

回收水泥和再生骨料见[石灰与建筑材料-水泥和混凝土](../07-日常生活技能/16-石灰与建筑材料.md#水泥和混凝土-先回收)。

### 10.7 木材

```
✓ 顺着木纹方向强度高,垂直木纹方向强度低、容易劈裂
✓ 含水率影响强度和变形: 干燥后再用(见木工与工具维护)
✓ 疤节、斜纹、裂纹会大大降低强度,承重构件要挑直纹无大疤节的
✓ 防腐: 保持干燥、通风,离开地面(木柱下垫石础)
```

木材干燥见[木工与工具维护-木材](../07-日常生活技能/09-木工与工具维护.md#木材)。

## 十一、机械元件

### 11.1 轴和轴承

```
滑动轴承: 轴在孔中转动,中间要有润滑油
  - 材料: 青铜、铸铁、硬木(用油浸过的硬木可以做低速轴承)
  - 必须保持润滑和清洁,干摩擦会很快磨损发热
滚动轴承: 滚珠或滚柱,摩擦很小(从废旧机械中回收)
```

### 11.2 齿轮

```
两个咬合的齿轮,齿的大小(模数)必须相同
  分度圆直径 = 模数 × 齿数
  转速比 = 齿数的反比
  传递的扭矩 = 转速的反比(忽略摩擦)

木齿轮: 传统水车、风车、磨坊都用硬木齿轮,磨损后可以更换单个木齿
```

### 11.3 皮带和链条

```
皮带传动: 简单、能缓冲、过载时打滑保护机器;两个皮带轮的转速比 = 直径的反比
链传动: 不打滑,传力大(自行车链条可以回收利用)
```

### 11.4 曲柄连杆

```
把往复直线运动变成旋转运动(蒸汽机、脚踏缝纫机),
或者反过来(往复泵、锯木机)
```

### 11.5 飞轮

```
沉重的轮子,转动时储存能量(动能 = ½ × 转动惯量 × 角速度²)
→ 让断断续续的动力(活塞每次推一下)变成平稳的转动
```
