# 电气工程与电子学

> **电让能量可以远距离传送、随时分配,也让信息能以光速传播。从一根铜线和一块磁铁开始,就能走进电的时代**

## ⚠️ 安全第一

- ⚡ 220 V交流电足以致命;高压电即使不接触,靠近也可能放电伤人
- ⚡ 大电容在断电后仍可能储存致命的电量,拆修前必须放电
- 🔥 蓄电池短路会产生极大电流,导线瞬间烧红起火;锂电池破损会起火爆炸
- 🔥 导线过细、接头松动会发热引起火灾
- ✓ 改装或连接家庭线路、接入发电机,一定要断开与外部电网的连接(防止反送电伤及他人)

日常用电安全见[家庭用电安全](../07-日常生活技能/08-家庭用电安全.md);电压、电流、欧姆定律等基础见[物理-电与磁](../08-基础科学知识/02-物理.md#七电与磁)。

## 一、直流电路进阶

### 1.1 基尔霍夫定律

```
电流定律: 流进一个节点的电流之和 = 流出的电流之和(电荷不会堆积)
电压定律: 沿着任何一个闭合回路走一圈,电压升高之和 = 电压降低之和

用这两条加上欧姆定律,可以算出任何复杂电路中每处的电流和电压
```

### 1.2 电源内阻

```
实际的电池、发电机都有内阻 r:
  端电压 = 电动势 - 电流 × r
→ 输出电流越大,端电压下降越多
→ 电池快没电时内阻变大,一接负载电压就掉下去
```

### 1.3 电容和电感

```
电容器: 两块导体中间隔着绝缘层,能储存电荷
  电量 Q = C × U;储存的能量 = ½ × C × U²
  充放电的快慢: 时间常数 τ = R × C(约5τ后基本充满或放完)
  → 隔直流、通交流;滤波;储能

电感器(线圈): 阻碍电流的变化
  储存的能量 = ½ × L × I²
  → 突然断开有电感的电路(电动机、继电器线圈),会产生很高的反向电压,
    开关处出现电火花
```

## 二、交流电

### 2.1 基本概念

```
交流电的电压和电流按正弦规律周期性变化:
  u = Um × sin(2π × f × t)

我国电网: 频率50 Hz(每秒变化50个周期)
有效值: 和同样发热效果的直流电相等的数值
  有效值 = 峰值 ÷ √2
  家用220 V是有效值,峰值约311 V

为什么用交流电: 可以用变压器方便地升压、降压(见下),适合远距离输电
```

### 2.2 电感和电容在交流电路中

```
感抗 XL = 2π × f × L(频率越高,线圈越"挡"电流)
容抗 XC = 1 ÷ (2π × f × C)(频率越高,电容越容易通过)

电流和电压不同步(有相位差)时:
  有功功率 P = U × I × cos φ(真正做功的部分)
  cos φ 叫功率因数
  → 电动机等感性负载功率因数较低,线路要输送更多电流
```

### 2.3 三相电

```
三根火线,电压依次相差1/3周期
  相电压(火线对零线)220 V,线电压(火线之间)380 V
  线电压 = √3 × 相电压

为什么工业用三相电:
- 三相电动机结构简单、能自己启动、运转平稳
- 输送同样的功率,用的导线更省
```

## 三、发电机

### 3.1 原理

```
电磁感应: 线圈中的磁通量发生变化,线圈两端就产生电压
  感应电压 ∝ 线圈匝数 × 磁通量变化的快慢

交流发电机: 磁铁(或电磁铁)和线圈相对转动,输出交流电
直流发电机: 用换向器(电刷 + 分段的铜环)把交流变成方向不变的电流
  也可以用交流发电机 + 整流二极管(见第十节)

输出电压的大小取决于: 转速、线圈匝数、磁场强弱
```

### 3.2 转速和频率

```
交流发电机输出的频率: f = 磁极对数 × 每分钟转数 ÷ 60
  一对磁极(2极)要输出50 Hz,需要每分钟3000转
  磁极越多,需要的转速越低
→ 水车、风车转得很慢,要么用齿轮、皮带增速,要么做成多磁极的发电机
```

### 3.3 现实可行的小型发电

```
方案一: 汽车交流发电机(从废旧汽车中回收)
- 内置整流和稳压,输出约14 V直流,正好给12 V蓄电池充电
- 需要较高的转速才能发电,通常要用皮带轮增速
- 励磁需要蓄电池先提供一点电流(接线按原车方式)

方案二: 永磁直流电动机反转发电
- 跑步机、电动工具、电动车的永磁电动机,外力带动它转动就能发电
- 转得越快电压越高
- 通常要加一个二极管,防止蓄电池电流倒流让电动机转起来

方案三: 自制
- 用回收的强磁铁(钕磁铁)和漆包线绕制线圈,做成转盘式发电机
- 需要耐心调整磁铁和线圈的间隙

动力: 水车、风车、自行车(人力约75-100 W,只够少量照明和充电)
```

水力和风力的功率估算见[热力学与动力机械-其他动力](03-热力学与动力机械.md#八水力风力和畜力)。

## 四、电动机

```
原理: 通电导线在磁场中受力 → 线圈转动
直流电动机: 用换向器让线圈中的电流方向不断切换,保持朝一个方向转
三相异步电动机(最常用的工业电动机):
  三相电流产生旋转的磁场,带动转子跟着转,转速略低于磁场的转速
  磁场转速(同步转速)= 60 × f ÷ 磁极对数(50 Hz、2极时为3000转/分)
  → 结构简单、坚固耐用、几乎不用维护

电动机和发电机是同一种机器: 输入电能就转动,用外力转动就发电
```

## 五、变压器

```
两个线圈绕在同一个铁芯上:
  U₁ ÷ U₂ = N₁ ÷ N₂(电压之比 = 匝数之比)
  I₁ ÷ I₂ = N₂ ÷ N₁(电流之比 = 匝数的反比)
  → 功率基本不变(效率通常在95%以上)

✓ 只能用于交流电(直流电的磁场不变化,不能感应)
✓ 铁芯用一片片绝缘的薄硅钢片叠成,减少铁芯里的涡流发热
⚠️ 变压器可以把低压变成高压,同样可以致命
```

## 六、输电和配电

### 6.1 为什么要高压输电

```
线路损失的功率 = I² × R
输送功率一定时,电压越高,电流越小,损失越小

例: 用两根各1 km长、10 mm²的铜线,输送10 kW
  铜线电阻 = 1.7 × 10⁻⁸ × 1000 ÷ (10 × 10⁻⁶) ≈ 1.7 Ω,来回两根约3.4 Ω

  用220 V: 电流约45 A,线路损失 = 45² × 3.4 ≈ 6900 W,
    线路上的电压降约150 V → 根本送不过去
  用2200 V: 电流约4.5 A,线路损失 = 4.5² × 3.4 ≈ 69 W → 只损失不到1%
```

### 6.2 导线和保护

```
✓ 导线粗细按电流选: 家庭插座回路一般用2.5 mm²铜线(配16 A开关)
  线路越长,导线要越粗(电压降)
✓ 每个回路都要有熔断器或空气开关,防止短路、过载起火
✓ 接头要拧紧、包好,铜和铝直接连接会腐蚀发热
✓ 接地: 电器的金属外壳接地,漏电时电流流入大地而不是人体
✓ 漏电保护器(30 mA)防触电
```

家庭用电的具体做法见[家庭用电安全](../07-日常生活技能/08-家庭用电安全.md)。

### 6.3 小型离网电力系统

```
发电(太阳能板 / 风力 / 水力)
  → 充电控制器(防止过充过放)
  → 蓄电池组(储能)
  → 直流用电器(12 V或24 V灯、充电)
  → 或经逆变器变成220 V交流电

能量估算: 每天用电量(Wh)= Σ(每个电器的功率 × 每天使用小时数)
  蓄电池容量要能满足阴天无风时几天的用电
```

太阳能系统的安装见[照明与能源-小型太阳能](../07-日常生活技能/06-照明与能源.md#小型太阳能)。

## 七、电池和储能

| 类型 | 每格电压 | 特点 | 注意 |
|------|---------|------|------|
| 铅酸蓄电池 | 约2.0 V(6格 = 12 V) | 便宜、可回收、技术简单 | 充电时产生氢气要通风;不要深度放电(放电到一半左右就充,寿命长得多) |
| 锂离子电池 | 约3.6-3.7 V(满电4.2 V) | 轻、储能多 | 过充、过放、破损、高温会起火,必须有保护电路 |
| 镍铁电池 | 约1.2 V | 极其耐用,可用几十年,耐过充过放 | 效率较低、自放电大 |
| 干电池(锌锰) | 约1.5 V | 不能充电 | |

```
容量: Ah(安时);储存的能量(Wh)= 电压(V)× 容量(Ah)
  12 V、100 Ah的蓄电池 ≈ 1200 Wh(实际可用约一半,以保护电池)

铅酸蓄电池充电电压: 约13.8-14.4 V(12 V电池)
⚠️ 铅酸电池中的硫酸有腐蚀性,铅有毒;拆装时戴手套护目镜
```

蓄电池的安全见[照明与能源-蓄电池安全](../07-日常生活技能/06-照明与能源.md#蓄电池安全)。

## 八、电报和通信

### 8.1 电报

```
最简单的远距离通信: 一根导线(以大地作回路)、电池、电键、接收器
  - 接收器可以是电磁铁带动的蜂鸣器,或者让指南针偏转的线圈
  - 用长短信号组合表示字母和数字(莫尔斯电码)
  → 19世纪中期就把各大洲连在了一起
```

### 8.3 电话的原理

```
话筒: 声音引起振动 → 改变电阻(碳粒话筒)或在线圈中感应电流 → 电流随声音变化
听筒: 变化的电流通过电磁铁 → 吸引薄铁片振动 → 发出声音
```

### 8.4 无线电

```
电流快速变化时会向空间辐射电磁波,以光速传播
  波长 = 光速 ÷ 频率(λ = c ÷ f)
  天线长度通常取波长的1/4或1/2

LC振荡电路: 线圈和电容组成,会以固有频率振荡
  f = 1 ÷ (2π × √(L × C))
  → 发射机用它产生特定频率的电磁波,收音机用它选台(调谐)

调制: 把声音"加"到高频电磁波上
  调幅(AM): 改变电磁波的强弱;调频(FM): 改变频率

矿石收音机(不需要电源):
  长天线 + 地线 + 线圈和可变电容(调谐) + 二极管(检波) + 高阻抗耳机
  → 能收听附近较强的中波广播

⚠️ 接收无线电不需要许可;发射无线电需要依法取得执照,
   未经许可发射会干扰航空、应急等重要通信
```

应急通信见[应急通信与寻亲](../02-灾难应对/06-应急通信与寻亲.md)。

## 九、电气测量

```
检流计: 线圈放在磁铁(或指南针)旁边,有电流通过时指针偏转
  简易版: 导线绕在指南针外面几十圈,通电时指南针偏转
电流表: 检流计 + 并联一个很小的电阻(分流)
电压表: 检流计 + 串联一个很大的电阻

万用表: 能测电压、电流、电阻(从废旧物资中找一台,非常有用)
  ⚠️ 测电流时万用表要串联在电路中,测电压时要并联;
     用电流挡去测电压会直接短路
```

没有可信的电表时,用电解铜标定电流、用丹尼尔电池或电热法标定电压,见[计量基准的重建-电学](../08-基础科学知识/09-计量基准的重建.md#72-电学)。

## 十、半导体和电子学

### 10.1 半导体

```
导体(铜、铝): 导电好
绝缘体(橡胶、玻璃、陶瓷、干木头): 几乎不导电
半导体(硅、锗): 介于两者之间,导电性可以被控制

掺杂: 在纯净的硅中掺入极少量其他元素
  N型: 多出自由电子;P型: 多出"空穴"

⚠️ 制造半导体器件需要极高纯度的硅(杂质要少到十亿分之一以下)、
   洁净的环境和精密的设备,从零开始几乎不可能
   → 现实做法: 保存和回收现有的电子元件
```

### 10.2 二极管

```
P型和N型半导体结合在一起(PN结): 电流只能朝一个方向通过
  导通时硅二极管两端约有0.7 V的压降

用途:
- 整流: 把交流电变成直流电(桥式整流用4个二极管,再加电容滤波)
- 防止电流倒流(发电机给蓄电池充电)
- 检波(收音机)
- 发光二极管(LED): 通电发光,效率高,寿命长
- 太阳能电池: 本质上是一个大面积的PN结,受光照产生电压
```

### 10.3 晶体管

```
用一个小电流(或电压)控制一个大电流:
- 作为放大器: 把微弱的信号放大(收音机、扩音器)
- 作为开关: 导通或截止 → 数字电路的基础
```

### 10.4 从开关到计算机

```
逻辑门: 用晶体管(或继电器、真空管)组成
  与门(AND): 两个输入都为1,输出才为1
  或门(OR): 任一输入为1,输出就为1
  非门(NOT): 输出和输入相反
  与非门(NAND): 只用这一种门就能组合出所有其他逻辑电路

用逻辑门可以做出: 加法器(二进制加法)、存储器(触发器)
→ 再组合起来就是计算机的处理器

历史顺序: 继电器计算机 → 真空管计算机 → 晶体管 → 集成电路
继电器(电磁铁控制的开关)虽然慢,但结构简单,
  是没有半导体时可以用来做逻辑电路的选择
```

二进制见[数学-实用算法](../08-基础科学知识/01-数学.md#十实用算法)。

### 10.5 真空管

```
历史上最早的电子放大器件: 抽成真空的玻璃管中,加热的阴极发射电子,
  由栅极控制流向阳极的电流
需要: 玻璃加工、真空泵、金属丝、密封技术
→ 比半导体容易,但仍然需要相当高的工业水平
```
