# 天文导航进阶

> **没有卫星和地图的时候,天空就是钟表、日历和地图: 太阳和星星的位置能告诉我们现在几点、今天是哪天、我们在哪里**

```
本章的内容:

2. 定方向: 更精确的方法

- 精确的航海定位需要精密的仪器、准确的钟表和天文历表,需要大量练习
```

## 一、天球和坐标

### 1.1 天球

```
想象地球外面有一个巨大的球,所有星星都贴在球面上
- 地球自西向东自转 → 看起来天球自东向西转,每天一圈
- 天球旋转的轴穿过南北天极;北天极附近是北极星
- 天赤道: 地球赤道向外延伸到天球上的大圆
- 黄道: 一年中太阳在天球上走过的路线,与天赤道成约23.4°夹角
```

### 1.2 两种坐标

```
地平坐标(随观测地点和时间而变):
  高度角: 天体离地平线的角度(0°在地平线,90°在头顶)
  方位角: 从正北开始顺时针量的角度(正东90°,正南180°,正西270°)

赤道坐标(星星的"地址",基本不变):
  赤纬: 天体离天赤道的角度,相当于天上的纬度
  赤经: 相当于天上的经度,用小时表示(0-24小时)
  → 星表上记录的就是恒星的赤经和赤纬
```

### 1.3 恒星日和太阳日

```
恒星日(星星回到同一位置): 约23小时56分4秒
太阳日(太阳回到同一位置): 24小时
→ 每天同一时刻,星星的位置比前一天提前约4分钟
→ 所以不同季节,夜晚看到的星座不同

月亮每天比前一天晚升起约50分钟
```

## 二、精确定方向

### 2.1 北极星

```
找北极星:
  北斗七星勺口的两颗星(天枢、天璇)连线,向勺口方向延长约5倍距离
  或者: 仙后座(W形)在北极星另一侧,和北斗七星隔着北极星相对
北极星距离真正的北天极不到1°,是最方便的正北标志

北斗七星绕北极星逆时针旋转,每小时约15°
  → 熟悉之后可以用来大致估计夜里的时间
```

### 2.2 南半球: 南十字座

```
南十字座长轴向下方(十字的长边)延长约4.5倍,大致是南天极
(我国南方低纬度地区在春季的夜晚能看到南十字座贴近南方地平线)
```

### 2.3 立杆测影定正南北(精确方法)

```
1. 在平地上竖一根垂直的杆子(用铅垂线校直)
2. 上午某时刻,标出杆影顶端的位置,以杆底为圆心,经过这一点画一个圆
3. 下午杆影顶端再次落在圆上时,标出这一点
4. 两个点的连线就是正东西方向,连线的中点与杆底的连线就是正南北
→ 我国古代用这种方法确定建筑的方向
```

### 2.4 磁偏角

```
指南针指向的是"磁北",不是地理上的正北
两者之间的夹角叫磁偏角,因地而异,而且会缓慢变化
  我国大部分地区为西偏,大约2°到11°(南方较小,东北较大)
→ 需要精确方向时,先用北极星或立杆测影测出正北,
  再看指南针指向和正北差多少,记下来作为当地的修正值
```

## 三、测纬度

### 3.1 北极星法

```
北半球: 北极星的高度角 ≈ 当地纬度(误差不到1°)
  例: 北极星离地平线40° → 约北纬40°(北京附近)
```

### 3.2 正午太阳法(任何一天都能用)

```
步骤:
1. 测出当天正午(太阳最高时)太阳的高度角 h
2. 查出(或算出)当天太阳的赤纬 δ
3. 北半球、太阳在南方时: 纬度 = 90° - h + δ

太阳赤纬的近似计算:
  δ ≈ 23.44° × sin[360° × (N - 81) ÷ 365]
  N: 当天是一年中的第几天(1月1日为1)
  - 春分(约3月21日): δ ≈ 0°
  - 夏至(约6月21日): δ ≈ +23.44°
  - 秋分(约9月23日): δ ≈ 0°
  - 冬至(约12月22日): δ ≈ -23.44°

例: 6月21日正午,太阳高度80°
  纬度 = 90 - 80 + 23.44 ≈ 33.4° → 约北纬33°
```

### 3.3 测量的修正(精确测量时)

```
- 测太阳时测的是太阳的下边缘,要加上太阳的半径约0.27°(16′)
- 在海上以海平线为基准,眼睛越高,海平线越"低",
  要减去"眼高差": 约 1.76′ × √眼睛高度(m)
- 天体接近地平线时,大气折射让它看起来偏高:
  在地平线上约偏高0.5°,10°高度约偏高0.1°,20°以上可以忽略
→ 尽量测高度在20°以上的天体
```

## 四、测经度

### 4.1 原理: 经度就是时间差

```
地球每小时自转15°(每4分钟1°)
当地正午时刻,与已知经度的参照地点的正午时刻相差多少,就能算出经度差

例: 用一只准确的钟,按北京时间(以东经120°为准)走时
  测得当地太阳最高的时刻是北京时间12:40
  → 比东经120°的正午晚40分钟 → 经度差 = 40 ÷ 4 = 10°
  → 当地约在东经110°
```

### 4.2 时差修正

```
真正的太阳正午,每天并不正好在钟表的12:00
一年中最多相差约16分钟(11月初太阳正午偏早,2月中旬偏晚)
→ 精确测经度时要查"时差表"修正,否则误差可达4°

另外,太阳在正午前后高度变化很慢,很难精确判断"最高时刻":
→ 可以记下上午和下午太阳在同一高度的两个时刻,取平均值作为正午
```

### 4.3 钟表是关键

```
钟表每慢1分钟,经度就差1/4°(在赤道约28 km)
→ 18世纪航海钟(能在船上保持准确的钟)的发明,才让远洋航海能精确测经度
→ 在此之前,用"月距法"(测月亮和恒星的角距离,查表推算时间),计算非常复杂

没有准确的钟时: 长期在一个地方,可以每天中午校准钟表;
  外出时记录走过的方向和距离(航位推算)
```

## 五、测角仪器

### 5.1 象限仪(陆地上使用)

```
制作:
1. 一块四分之一圆形的木板,弧边刻上0°-90°的刻度
2. 一条直边上装两个小孔或一根细管,作为瞄准器
3. 圆心处挂一根细线,下面拴一个小重物(铅垂线)

使用:
- 沿瞄准器对准星星(⚠️ 不要直视太阳),铅垂线在弧上指示的读数就是高度角
- 测太阳时: 让阳光穿过前面的小孔,光点落在后面小孔上,不要用眼睛看
- 精度大约0.5-1°,刻度越大越准
```

### 5.2 六分仪(海上使用)的原理

```
两面镜子: 一面固定的半透明地平镜,一面随指标臂转动的指标镜
- 透过地平镜看海平线,同时从指标镜反射过来的天体像出现在同一视野中
- 转动指标臂,让天体的像"落"在海平线上
- 反射定律: 镜子转过的角度是光线转过角度的一半
  → 刻度弧只有60°(六分之一圆),却能测量120°的角度,所以叫"六分仪"
- 优点: 船摇晃时,天体和海平线一起晃动,仍然能对准;精度可达1′(角分)

⚠️ 观测太阳必须使用滤光镜,直视太阳会造成永久的眼睛损伤
```

## 六、航位推算

```
没有天体可看时,根据出发点、方向、速度和时间推算当前位置:
  走过的距离 = 速度 × 时间
  在地图(或方格纸)上从出发点沿方向画出这段距离

单位:
  1 nmi(海里)= 1852 m = 纬度1′(角分,即1/60°)的长度
  1 kn(节)= 1 nmi/h
  纬度1° ≈ 111 km

陆地上: 步测距离(见度量衡章),指南针定方向,每走一段记录一次
海上: 把打了等距绳结的绳子拴在木板上扔进海里,数一定时间内放出几个结,
  得到航速("节"这个单位就是这么来的)

⚠️ 误差会累积: 水流、风、方向偏差,每走一段都要尽量用地标或天体校正
```

步测见[度量衡与科学方法-估算距离](../08-基础科学知识/00-度量衡与科学方法.md#44-估算距离)。

## 七、编制历法

### 7.1 圭表定冬至和回归年

```
圭表: 一根垂直的表杆(越高越精确),地上一条正南北方向、刻有刻度的"圭"
- 每天正午测量杆影的长度
- 影子最长的那天是冬至,最短的那天是夏至
- 测量许多年,两次冬至之间的平均天数就是回归年: 约365.2422天
```

### 7.2 阳历的闰年

```
每4年一闰(2月29天),逢100年不闰,逢400年又闰
  → 400年中有97个闰年,平均每年365.2425天,与回归年非常接近
```

### 7.3 农历: 阴阳合历

```
农历的月以月相为准: 朔(看不到月亮)为初一,一个朔望月约29.53天
  → 大月30天,小月29天
12个朔望月约354天,比一年少约11天
→ 加闰月: 19个回归年 ≈ 235个朔望月,在这19年里加入7个闰月
   (19 × 12 = 228,235 - 228 = 7)
→ 二十四节气按太阳的位置定(见物理-历法),
  规定没有"中气"的月份作为闰月,让月份和季节保持一致
```

## 八、天体运行规律

### 8.1 开普勒三定律

```
1. 行星绕太阳的轨道是椭圆,太阳在椭圆的一个焦点上
2. 行星离太阳近时走得快,远时走得慢
   (行星和太阳的连线在相等时间内扫过相等的面积)
3. 行星公转周期的平方与轨道半长轴的立方成正比
   T² ∝ a³
   例: 火星轨道半长轴约1.52倍地球的 → 周期约 √(1.52³) ≈ 1.88年

牛顿用万有引力定律推导出了这三条定律
```

### 8.2 人造卫星

```
在离地面不高的轨道上绕地球做圆周运动需要约7.9 km/s(第一宇宙速度)
脱离地球引力需要约11.2 km/s(第二宇宙速度)
地球同步轨道: 高度约35786 km,周期与地球自转相同,
  从地面看卫星停在天上不动(通信、气象卫星)

圆轨道速度: v = √(G × M ÷ r);离地心越远,速度越慢、周期越长
```

### 8.3 肉眼可见的行星

```
水星、金星、火星、木星、土星
- 行星不像恒星那样闪烁,光比较稳定
- 在星座之间缓慢移动
- 都在黄道附近
- 金星最亮,只在黄昏后的西方("长庚")或黎明前的东方("启明")出现
```

### 8.4 日食和月食

```
日食: 月亮挡住太阳,只发生在朔日(初一)
月食: 地球的影子落在月亮上,只发生在望日(十五前后)
不是每个月都有,因为月亮轨道和黄道有约5°的夹角

沙罗周期: 约18年11天,日食月食大致按这个周期重复出现
  → 古人用它来预报日月食

⚠️ 观看日食绝不能直视太阳(即使只剩一小部分),
   用针孔投影(纸上扎个小孔,把太阳的像投到另一张纸上)最安全
```

## 九、观测记录

```
✓ 每次观测记录: 日期、时刻(以及钟表的误差)、地点、测量的天体、读数、天气
✓ 长期坚持: 很多规律(回归年长度、星星的岁差、彗星的周期)
  只有积累几十年、几百年的记录才能发现
✓ 我国古代保存了世界上最连续的天象记录(日食、彗星、新星、太阳黑子),
  至今仍被天文学家使用
```
