# 进阶科学与工程

## 📋 目录概览

[基础科学知识](../08-基础科学知识/README.md)讲的是人人都该懂的原理;本部分面向想要深入的人,讲**怎样把技术一层层重建起来**: 先看整体路线,再看结构与材料、电力、动力这几个支撑工业的支柱。

内容大致相当于大学理工科和工程入门的程度,重点放在原理、估算方法和现实可行的做法上。

### 内容章节

1. [技术重建路线图](00-技术重建路线图.md) - 技术树与阶段划分、燃料/精密加工/硫酸/玻璃/纸等关键瓶颈、三平板互研与车床自举、废墟中可回收的资源、可以走的捷径、不同规模社区能维持的技术、优先保存的书籍和物品
2. [工程力学与材料](01-工程力学与材料.md) - 力的分解与吊绳夹角、力矩平衡、应力应变与材料强度表、安全系数、屈曲、梁的弯曲与估算、桁架、拱、悬索、地基、铁碳与热处理原理、合金、陶瓷耐火材料、混凝土、机械元件
3. [电气工程与电子学](02-电气工程与电子学.md) - 基尔霍夫定律、电容电感、交流电与三相电、发电机与小型发电方案、电动机、变压器、高压输电的道理、离网电力系统、蓄电池、电报与莫尔斯电码、无线电原理、半导体与逻辑门
4. [热力学与动力机械](03-热力学与动力机械.md) - 热力学定律与卡诺效率、蒸汽性质、锅炉安全、蒸汽机与斯特林发动机、内燃机与替代燃料、传热计算与保温、蒸发冷却与储冰、热泵、水力风力畜力、能源比较
5. [高等数学](04-高等数学.md) - 极限、导数与最值、牛顿法、积分与数值积分、泰勒级数、微分方程(冷却、增长、振动、传染病SIR模型)、复数、线性方程组与最小二乘、置信区间与假设检验(卡方检验、t检验)
6. [化学进阶](05-化学进阶.md) - 电子排布与化学键、焓与吉布斯自由能(为什么烧石灰要900°C)、化学平衡与勒夏特列原理、反应速率与催化、电极电势与电解、有机官能团与反应、木材干馏与松脂、焰色反应与滴定、纯碱硫酸等化工原理
7. [现代物理](06-现代物理.md) - 光的波粒二象性、原子能级与光谱、量子力学要点、能带与半导体、激光、相对论与卫星定位、放射性衰变与半衰期测年、辐射剂量、核裂变与聚变原理、四种相互作用与宇宙

## ⚠️ 说明

- 本部分的计算是简化的,用于理解和估算。住人的房屋、桥梁、起重设备、锅炉等压力容器一旦失效会造成伤亡,有条件时请专业人员设计,没有条件时取更大的安全系数并先做试验
- 涉及高压电、锅炉、有毒气体的内容,只在理解原理和遵守安全规则的前提下使用

## 📖 学习建议

```
1. 先读技术重建路线图,了解全局和优先顺序
2. 先打好基础科学知识的底子(尤其是数学、物理)
3. 再按需要阅读: 盖房架桥看工程力学,发电看电气工程,
   蒸汽机、水车风车、保温看热力学与动力机械
4. 理论工具: 高等数学(工程计算和试验统计)、化学进阶(化工)、
   现代物理(半导体、辐射)
```
