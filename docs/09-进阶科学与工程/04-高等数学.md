# 高等数学

> **微积分描述变化,线性代数处理多个未知数,统计推断判断结果是不是巧合——近代科学和工程几乎都建立在这三样工具上**


## 一、极限

```
极限描述"无限接近": 当 x 越来越接近某个值时,函数值越来越接近什么

两个重要的极限:
  当 x → 0 时,sin x ÷ x → 1(x 用弧度)
  当 n → ∞ 时,(1 + 1/n)ⁿ → e ≈ 2.71828

e 的来历: 本金1元,年利率100%,
  一年结算1次得2元,每月结算得约2.613元,每天结算得约2.715元,
  结算次数无限多时趋向 e 元

弧度: 360° = 2π 弧度,1弧度 ≈ 57.3°
  微积分中的三角函数一律用弧度
```

## 二、导数和微分

### 2.1 求导法则

```
和:     (u + v)' = u' + v'
积:     (u × v)' = u' × v + u × v'
商:     (u ÷ v)' = (u' × v - u × v') ÷ v²
链式法则(复合函数): 若 y = f(g(x)),则 y' = f'(g(x)) × g'(x)
  例: (sin 3x)' = cos 3x × 3
```

### 2.2 常用导数表

| 函数 | 导数 |
|------|------|
| 常数 C | 0 |
| xⁿ | n × xⁿ⁻¹ |
| eˣ | eˣ |
| aˣ | aˣ × ln a |
| ln x | 1/x |
| sin x | cos x |
| cos x | -sin x |
| tan x | 1/cos²x |

### 2.3 求最大值和最小值

```
函数在最大值、最小值处,导数等于0(切线是水平的)

例: 用一块边长 a 的正方形铁皮,四角各剪去边长 x 的小正方形,
    折成无盖的盒子,x 取多少时容积最大?
  容积 V = x × (a - 2x)²
  V' = (a - 2x)² - 4x(a - 2x) = (a - 2x)(a - 6x)
  令 V' = 0,x = a/6(x = a/2 时盒子没有底,舍去)
  → 剪去边长的1/6时容积最大

例: 用同样多的材料做圆柱形的罐子,容积最大时,高度等于直径
```

### 2.4 牛顿法: 解任何方程

```
求 f(x) = 0 的根:
  先猜一个 x₀,然后反复计算
  x_新 = x - f(x) ÷ f'(x)

例: 求 x³ - 2x - 5 = 0 的根,猜 x₀ = 2
  f(2) = -1,f'(x) = 3x² - 2,f'(2) = 10
  x₁ = 2 - (-1) ÷ 10 = 2.1
  x₂ = 2.1 - 0.061 ÷ 11.23 ≈ 2.0946
  (真实值约2.09455,两步就很准了)

求平方根的巴比伦法(见基础数学)就是牛顿法用在 x² - a = 0 上
```

### 2.5 线性近似

```
在 x₀ 附近: f(x) ≈ f(x₀) + f'(x₀) × (x - x₀)

例: √4.1 ≈ 2 + (1/4) × 0.1 = 2.025(真实值2.0248)
例: 角度很小时,sin x ≈ x,tan x ≈ x(x 用弧度)
  → 单摆在摆角小时周期和摆角无关,就是用了这个近似
```

## 三、积分

### 3.1 常用积分表

| 函数 | 不定积分(加常数 C) |
|------|-------------------|
| xⁿ(n ≠ -1) | xⁿ⁺¹ ÷ (n+1) |
| 1/x | ln \|x\| |
| eˣ | eˣ |
| sin x | -cos x |
| cos x | sin x |

```
定积分: 从 a 到 b 的积分 = F(b) - F(a),F 是不定积分
  几何意义: 曲线下方、a 到 b 之间的面积

换元法: 把复杂的部分设成新变量
  例: ∫ 2x × cos(x²) dx,设 u = x²,du = 2x dx → ∫ cos u du = sin(x²) + C

分部积分: ∫ u dv = u × v - ∫ v du
  例: ∫ x × eˣ dx = x × eˣ - ∫ eˣ dx = (x - 1) × eˣ + C
```

### 3.2 积分的用途

```
面积: 曲线 y = f(x) 和 x 轴之间,从 a 到 b 的面积 = ∫ f(x) dx

旋转体体积: 曲线绕 x 轴旋转一周
  V = π × ∫ y² dx
  例: 验证球的体积,x² + y² = r²
  V = π × ∫(从-r到r)(r² - x²) dx = 4πr³ ÷ 3

变力做功: W = ∫ F dx
  例: 把一个深 h m、底面积 A m²、装满水的池子里的水全部抽到池口
  W = ∫(从0到h)ρ × g × A × y dy = ρ × g × A × h² ÷ 2
  → 1 m深、10 m²的池子: 1000 × 9.8 × 10 × 1 ÷ 2 ≈ 49000 J

平均值: 函数在 a 到 b 上的平均值 = ∫ f(x) dx ÷ (b - a)
```

### 3.3 数值积分: 没有公式时怎么算

```
把区间分成 n 等份(n 为偶数),每份宽 h,各点函数值 f₀, f₁, …, fₙ

梯形法: 面积 ≈ h × [f₀/2 + f₁ + f₂ + … + fₙ₋₁ + fₙ/2]

辛普森法(更准):
  面积 ≈ h ÷ 3 × [f₀ + 4f₁ + 2f₂ + 4f₃ + … + 4fₙ₋₁ + fₙ]

用途: 测量不规则田地(每隔一段距离量一次宽度)、河流断面面积、
  根据每小时记录的流量算一天的总水量
```

## 四、级数

### 4.1 等比级数

```
1 + r + r² + r³ + … = 1 ÷ (1 - r)(|r| < 1 时)
前 n 项和 = (1 - rⁿ) ÷ (1 - r)
```

### 4.2 泰勒级数: 用加减乘除算出任何函数

```
eˣ = 1 + x + x²/2! + x³/3! + x⁴/4! + …
sin x = x - x³/3! + x⁵/5! - x⁷/7! + …
cos x = 1 - x²/2! + x⁴/4! - x⁶/6! + …
ln(1 + x) = x - x²/2 + x³/3 - x⁴/4 + …(-1 < x ≤ 1)
(1 + x)ⁿ ≈ 1 + n × x(x 很小时)

(n! = 1 × 2 × 3 × … × n,如 4! = 24)

例: 算 e ≈ 1 + 1 + 0.5 + 0.1667 + 0.0417 + 0.0083 + 0.0014 ≈ 2.718
例: 算 sin 0.5 ≈ 0.5 - 0.02083 + 0.00026 ≈ 0.47943

用途: 在没有计算器的时候编制三角函数表、对数表
⚠️ x 越大,需要的项越多;要在收敛范围内使用
```

## 五、微分方程

描述"变化率和当前状态的关系",是物理、工程、生物、医学中最常用的数学模型。

### 5.1 指数增长和衰减

```
dy/dt = k × y   →   y = y₀ × e^(kt)
  k > 0: 指数增长(细菌繁殖、早期的传染病、复利)
  k < 0: 指数衰减(放射性衰变、药物在体内的代谢)

药物半衰期 T 与 k 的关系: k = -ln 2 ÷ T ≈ -0.693 ÷ T
```

### 5.2 牛顿冷却定律

```
物体温度的变化速度,和它与环境的温差成正比:
  dT/dt = -k × (T - T环境)
  → T = T环境 + (T₀ - T环境) × e^(-kt)

例: 一锅100°C的粥放在20°C的房间里,10分钟后降到80°C
  60 = 80 × e^(-10k) → k ≈ 0.0288/分钟
  降到40°C(和环境温差20°C)需要: 20 = 80 × e^(-kt) → t ≈ 48分钟

用途: 估算食物多久能凉到可以放进冷藏的温度、
  估算保温措施的效果
```

### 5.3 有限增长(逻辑斯谛模型)

```
dP/dt = r × P × (1 - P/K)
  K: 环境能容纳的最大数量
  开始时近似指数增长,接近 K 时增长变慢,最后稳定在 K

用途: 鱼塘、牧场、野生动物的数量;
  在 P = K/2 时增长最快 → 收获时把数量保持在一半左右,
  能持续获得最多的产量
```

### 5.4 振动

```
d²x/dt² = -ω² × x   →   x = A × sin(ωt + φ)
  弹簧上的重物、小角度的单摆、LC电路中的电流

有阻尼时(摩擦、空气阻力): 振幅逐渐减小
受到周期性外力时: 外力频率接近固有频率会发生共振,振幅变得非常大
  → 队伍过桥不能齐步走;机器转速要避开结构的共振频率
```

### 5.5 传染病模型(SIR)

```
把人群分成: 易感者 S、感染者 I、康复者 R,总人数 N
  dS/dt = -β × S × I ÷ N
  dI/dt = β × S × I ÷ N - γ × I
  dR/dt = γ × I

  β: 传染率;γ: 康复率(1/γ 约等于平均患病天数)
  基本传染数 R₀ = β ÷ γ(一个病人平均传染几个人)

结论:
- R₀ > 1 时疫情扩散,R₀ < 1 时疫情消退
- 免疫的人比例超过 1 - 1/R₀ 时,疫情无法扩散(群体免疫阈值)
  例: R₀ = 4 时,需要约75%的人有免疫力
```

相关概念见[生物与医学基础-流行病学基础](../08-基础科学知识/04-生物与医学基础.md#九流行病学基础)。

### 5.6 欧拉法: 一步一步数值求解

```
已知 dy/dt = f(t, y) 和起点 y₀,取很小的时间步长 h:
  y_下一步 = y + h × f(t, y)

步长越小越准,但要算的步数越多
没有解析解的方程(大多数实际问题)都可以这样一步步算
```

## 六、复数

```
虚数单位 i,i² = -1
复数 z = a + b × i(a 实部,b 虚部)

运算: 和普通代数一样,遇到 i² 就换成 -1
  (2 + 3i)(1 - i) = 2 - 2i + 3i - 3i² = 5 + i

几何表示: 平面上的点 (a, b)
  模(长度)r = √(a² + b²);辐角 θ:tan θ = b ÷ a
  z = r × (cos θ + i × sin θ)

欧拉公式: e^(iθ) = cos θ + i × sin θ
  → 复数相乘 = 模相乘、角度相加

用途:
- 交流电路: 用复数表示阻抗(工程上虚数单位常写作 j)
  电阻 R、感抗 jωL、容抗 1/(jωC),像直流电路中的电阻一样串并联计算
- 解二次方程时 b² - 4ac < 0 的情况
- 振动和波动的计算
```

交流电路见[电气工程与电子学-交流电](02-电气工程与电子学.md#二交流电)。

## 七、线性代数

### 7.1 线性方程组和高斯消元法

```
例: 用三种饲料配一份混合饲料,要求恰好含蛋白质 22、脂肪 5、纤维 6.5 个单位
  每 kg 饲料的成分:      蛋白质  脂肪  纤维
    饲料甲 x kg           10      2      2
    饲料乙 y kg           20      5      3
    饲料丙 z kg            4      1      6

  10x + 20y + 4z = 22
   2x +  5y +  z =  5
   2x +  3y + 6z = 6.5

消元步骤:
1. 用第2式乘以5,和第1式相减,消去 x: (10x+25y+5z) - (10x+20y+4z) = 25 - 22
   → 5y + z = 3 …… (A)
2. 第2式减去第3式,消去 x: 2y - 5z = -1.5 …… (B)
3. 由 (A) 得 z = 3 - 5y,代入 (B): 2y - 15 + 25y = -1.5 → y = 0.5
4. 回代: z = 3 - 2.5 = 0.5,x = (5 - 5 × 0.5 - 0.5) ÷ 2 = 1
   → 甲1 kg、乙0.5 kg、丙0.5 kg
5. 代回三个原方程检查一遍

⚠️ 如果解出负数,说明用这几种饲料无法恰好满足要求,需要调整要求或换饲料

方法要点: 每一步用一个方程消去其他方程中的一个未知数,
  直到只剩一个未知数,再逐步回代
```

### 7.2 矩阵

```
把方程组的系数排成表格就是矩阵,方程组可以写成 A × x = b

矩阵乘法: 结果第 i 行第 j 列 = A 的第 i 行与 B 的第 j 列对应相乘再相加

二阶行列式: | a b ; c d | = a × d - b × c
  行列式为0时,方程组没有唯一解

用途: 桁架中每根杆件的受力、复杂电路中每条支路的电流、
  配料、坐标变换,都是解线性方程组
```

### 7.3 最小二乘法: 用数据拟合直线

```
有一组测量数据 (x, y),找一条最贴近的直线 y = a + b × x:
  b = Σ(x - x̄)(y - ȳ) ÷ Σ(x - x̄)²
  a = ȳ - b × x̄
  (x̄、ȳ 是平均值)

例: 施肥量与产量的关系、用几次测量校准一个仪器的刻度
相关系数 r(-1 到 1): 越接近 ±1,两者的直线关系越强
⚠️ 相关不等于因果
```

## 八、统计推断: 判断结果是不是巧合

### 8.1 标准误和置信区间

```
样本平均数本身也有误差,大小用"标准误"衡量:
  标准误 = 标准差 ÷ √样本数
  → 样本数增加到4倍,误差才减小一半

95%置信区间 ≈ 平均数 ± t × 标准误
  t 的取值(双侧95%):
    样本数 6(自由度5): 2.57
    样本数 10(自由度9): 2.26
    样本数 11(自由度10): 2.23
    样本数 21(自由度20): 2.09
    样本数 31(自由度30): 2.04
    样本很大: 1.96(约等于2)

例: 测了16块地的单产,平均3750 kg/ha,标准差300 kg/ha
  标准误 = 300 ÷ 4 = 75 kg/ha,95%置信区间约 3750 ± 2.13 × 75 ≈ 3590 到 3910 kg/ha
```

### 8.2 假设检验的思路

```
1. 先假设"没有效果"(零假设): 新药和对照组的效果一样
2. 计算: 如果真的没有效果,纯靠运气出现现在这样大的差别,概率有多大(p值)
3. p < 0.05(不到5%): 认为差别不太可能是巧合,结果"显著"
   p ≥ 0.05: 不能排除巧合(不等于证明"没有效果")
```

### 8.3 比较两组的比例: 卡方检验

```
例: 50个病人用新疗法,20人好转;50个病人用对照方法,10人好转

            好转   未好转   合计
  新疗法     20      30      50
  对照       10      40      50
  合计       30      70     100

期望值(如果两组没有差别): 每组好转应为 50 × 30/100 = 15,未好转35
卡方 = Σ(实际 - 期望)² ÷ 期望
     = 25/15 + 25/35 + 25/15 + 25/35 ≈ 4.76

临界值(自由度1,p = 0.05): 3.84
4.76 > 3.84 → 差别显著,不太可能是巧合
⚠️ 每个格子的期望值最好不少于5,否则这个方法不准
```

### 8.4 比较两组的平均数: t检验

```
t = (平均数₁ - 平均数₂) ÷ √(标准差₁²/n₁ + 标准差₂²/n₂)
|t| 大于上面表中对应的值(自由度大约取较小的那组样本数减1),差别显著

例: 两种种子各种10块地,平均单产3900 kg/ha和3600 kg/ha,标准差都是300 kg/ha
  t = 300 ÷ √(9000 + 9000) ≈ 2.24
  自由度约为9,临界值2.26;2.24 略小于 2.26 → 还不能确定是不是巧合
  → 多种几块地再比较
```

### 8.5 设计试验时要注意

```
✓ 随机分组(抽签决定谁用新方法),避免把好的地、轻的病人都分到一组
✓ 有条件时"盲法": 病人(甚至评估的人)不知道谁用了哪种方法
✓ 事先定好要比较什么、怎样算"有效",不要事后挑好看的结果
❌ 同时比较很多指标,总会有一两个碰巧"显著"
❌ 样本太少: 真正有效的方法也可能看不出差别
```
