# 现代物理

> **半导体、激光、X光、核能、卫星定位——20世纪改变世界的技术,都来自对原子和光的新认识**

## ⚠️ 本章的定位

19世纪末,人们以为物理学已经差不多完成了。随后几十年里,量子力学和相对论彻底改变了对世界的理解,也带来了电子工业、核能、医学影像等技术。

```
本章的目的:
- 理解现代技术为什么能工作(半导体为什么能控制电流、太阳能板为什么能发电)
- 理解辐射的危害和防护
- 知道这些知识存在,让后人有方向可以重新研究

需要说明:
- 这些技术大多需要很高的工业基础,短期内无法重建
- 核能部分只讲原理,不涉及任何武器相关的内容
```

基础知识见[基础科学知识-物理](../08-基础科学知识/02-物理.md)。

## 一、光: 波还是粒子

### 1.1 光是波

```
干涉: 光通过两条很窄的平行狭缝,在后面的屏上形成明暗相间的条纹
  → 只有波才会这样相互叠加、相互抵消
衍射: 光绕过很小的障碍物或小孔会散开

光谱: 白光经过三棱镜或衍射光栅,分成连续的彩色光带
电磁波谱(波长从长到短):
  无线电波 → 微波 → 红外线 → 可见光(红到紫,约0.4-0.7微米)→ 紫外线 → X射线 → γ射线
```

### 1.2 光也是粒子

```
光电效应: 光照到金属上会打出电子,但是:
  - 能不能打出电子,只取决于光的颜色(频率),不取决于光的强弱
  - 红光再强也打不出电子,紫外线很弱也能打出
  → 爱因斯坦解释: 光由一份一份的"光子"组成

光子的能量: E = h × f
  h(普朗克常数)≈ 6.63 × 10⁻³⁴ 焦·秒
  频率越高(紫外线、X射线),每个光子的能量越大
  → 所以紫外线会晒伤皮肤、X射线和γ射线能破坏细胞,而可见光、无线电波不会

太阳能电池、数码相机的感光元件,都基于光电效应
```

### 1.3 波粒二象性

```
不只是光,电子等粒子也有波的性质:
  波长 λ = h ÷ (质量 × 速度)(德布罗意关系)
→ 电子的波长比可见光短得多 → 电子显微镜能看到比光学显微镜小得多的东西(如病毒)
```

## 二、原子结构

### 2.1 原子核的发现

```
卢瑟福(1911年)用α粒子轰击金箔:
  绝大多数穿了过去,极少数被大角度弹回
  → 原子的质量几乎全部集中在中心一个极小的核里,其余几乎是空的
  (原子核的直径大约只有原子的十万分之一)
```

### 2.2 能级和光谱

```
电子只能处在某些特定的能量状态(能级),不能处在两个能级之间
  氢原子的能级: Eₙ = -13.6 电子伏 ÷ n²(n = 1, 2, 3, …)

电子从高能级跳到低能级时,放出一个光子,能量等于两个能级之差
  → 每种元素都有自己特有的一组谱线,像"指纹"一样
  → 光谱分析: 看物体发出或吸收的光谱,就知道它含有哪些元素
    (人类就是这样知道太阳和遥远恒星由什么组成的)
  → 焰色反应、霓虹灯、钠灯的颜色都来自特定的谱线

1电子伏(eV)≈ 1.6 × 10⁻¹⁹ 焦,是原子尺度常用的能量单位
```

焰色反应见[化学进阶-焰色反应](05-化学进阶.md#71-焰色反应)。

### 2.3 电子排布和元素周期表

```
量子力学算出了每一层能容纳多少电子,
解释了为什么元素周期表是现在这个样子、为什么同一族元素性质相似
(泡利不相容原理: 两个电子不能处在完全相同的状态)
```

## 三、量子力学的要点

```
1. 量子化: 能量、角动量等只能取某些分立的值,不是连续的
2. 概率: 不能精确预言单个粒子在哪里,只能算出在各处出现的概率
3. 不确定性原理: 位置和动量不能同时精确确定
   Δx × Δp ≥ h ÷ (4π)
4. 隧道效应: 粒子有一定概率穿过按经典物理"翻不过去"的势垒
   → 太阳内部的核聚变、某些电子元件、扫描隧道显微镜都依赖它

这些规律只在原子和更小的尺度上明显,日常生活中感觉不到,
但所有化学键、半导体、激光、核反应都要用它来解释
```

## 四、固体物理和半导体

### 4.1 能带

```
固体中大量原子的能级合并成"能带":
  导体: 电子可以自由移动 → 导电
  绝缘体: 电子被束缚,要跨过很大的能量间隙(禁带)才能导电 → 不导电
  半导体: 禁带比较窄(硅约1.1电子伏,锗约0.7电子伏)
    → 温度、光照、掺入杂质都能显著改变导电性
```

### 4.2 半导体器件的原理

```
掺杂形成 N 型、P 型半导体,两者相接形成 PN 结:
- 二极管: 单向导电
- 发光二极管(LED): 电子跨过禁带时放出光子,禁带宽度决定光的颜色
- 太阳能电池: 光子把电子激发过禁带,在 PN 结两侧形成电压
  单层硅太阳能电池的理论效率上限约33%,实际产品约20%
- 晶体管: 用小信号控制大电流
```

具体器件见[电气工程与电子学-半导体和电子学](02-电气工程与电子学.md#十半导体和电子学)。

### 4.3 激光

```
受激辐射: 一个光子经过一个处于高能级的原子时,可以"复制"出一个
  频率、方向、相位完全相同的光子
在两面镜子之间反复放大 → 方向极准、颜色单一、能量集中的激光
用途: 测距、切割焊接、光纤通信、医疗手术、条码扫描
⚠️ 激光直射眼睛会造成永久损伤
```

### 4.4 超导

```
某些材料冷却到极低温度时,电阻完全消失
用途: 医院的核磁共振成像(MRI)设备中的强磁体
```

## 五、相对论

### 5.1 狭义相对论

```
两条基本假设:
1. 物理规律在所有匀速运动的参考系中都一样
2. 真空中的光速对所有观察者都相同(约 3 × 10⁸ 米/秒)

推论:
- 运动的钟走得慢(时间膨胀): 时间变慢的倍数 γ = 1 ÷ √(1 - v²/c²)
  速度接近光速时才明显;日常速度下几乎察觉不到
- 运动的物体在运动方向上变短
- 任何有质量的物体都不能达到光速
- 质能关系: E = m × c²
```

### 5.2 广义相对论

```
引力不是一种普通的"力",而是质量使时空发生弯曲
推论:
- 引力越强的地方,时间走得越慢
- 光经过大质量天体附近会弯曲
- 预言了黑洞、引力波(都已被观测证实)
```

### 5.3 卫星定位为什么需要相对论

```
卫星定位(北斗、GPS)靠精确测量信号从多颗卫星传到接收机的时间来算出位置
- 卫星高速运动 → 卫星上的钟每天慢约7微秒(狭义相对论)
- 卫星处在引力较弱的高空 → 卫星上的钟每天快约45微秒(广义相对论)
- 合计每天快约38微秒
- 不修正的话,定位误差每天会累积到大约十公里
```

## 六、原子核物理

### 6.1 原子核

```
原子核由质子和中子组成,靠"强相互作用"(核力)紧紧结合
同位素: 质子数相同、中子数不同(如碳-12和碳-14)

结合能: 把原子核拆散需要的能量
  中等质量的原子核(铁附近)最稳定
  → 很重的原子核分裂成中等的(裂变),或很轻的原子核合并成较重的(聚变),
    都会放出巨大的能量
```

### 6.2 放射性衰变

| 衰变 | 放出 | 穿透力 | 防护 |
|------|------|--------|------|
| α衰变 | 氦原子核(2个质子 + 2个中子) | 很弱,一张纸、皮肤表层就能挡住 | 主要危险是吸入、吃进体内 |
| β衰变 | 电子(中子变成质子) | 中等,几毫米铝板能挡住 | 防止皮肤沾染和体内摄入 |
| γ射线 | 高能光子 | 很强 | 厚铅板、厚混凝土、厚土层,加上距离 |

### 6.3 半衰期和放射性测年

| 同位素 | 半衰期 | 说明 |
|--------|--------|------|
| 碘-131 | 约8天 | 核事故早期的主要威胁,集中在甲状腺 |
| 铯-137 | 约30年 | 核事故后长期污染土壤 |
| 碳-14 | 约5730年 | 用于考古测年 |
| 钾-40 | 约12.5亿年 | 天然存在于人体和食物中 |
| 铀-238 | 约45亿年 | 用于测定岩石和地球的年龄 |

```
碳-14测年:
  活着的生物不断从环境中吸收碳,体内碳-14的比例和大气中相同
  死后不再吸收,碳-14按半衰期减少
  测出剩下的比例,就能算出死了多久
  例: 剩下1/4 → 经过两个半衰期 → 约11500年前
  适用于约5万年以内的有机物(木头、骨头、种子)
```

计算方法见[数学-指数衰减和半衰期](../08-基础科学知识/01-数学.md#72-指数衰减和半衰期)。

### 6.4 辐射剂量

```
活度: 每秒衰变多少次,单位贝可勒尔(Bq)
有效剂量: 衡量对人体的危害,单位希沃特(Sv),常用毫希沃特(mSv)

参考:
- 天然本底辐射: 全球平均每人每年约2-3毫希沃特(来自岩石、空气中的氡、宇宙射线、食物)
- 一次胸部X光片: 约0.02-0.1毫希沃特
- 短时间受到约1希沃特(1000毫希沃特)以上: 出现急性放射病(恶心、呕吐、白细胞下降)
- 短时间受到约4-5希沃特: 不经治疗,约半数人死亡

防护三原则: 时间(少待)、距离(远离)、屏蔽(躲在厚墙后、地下)
```

核事故的应对见[人为灾难](../02-灾难应对/05-人为灾难.md)。

### 6.5 核裂变和核电(原理)

```
铀-235等很重的原子核吸收一个中子后分裂成两个中等的原子核,
放出能量和2-3个新的中子,新的中子又引起其他原子核裂变 → 链式反应

核电站: 用控制棒吸收多余的中子,让链式反应稳定地、可控地进行,
  放出的热量烧水产生蒸汽,推动汽轮机发电
  - 1千克铀-235完全裂变放出的能量,相当于燃烧约2700吨标准煤
  - 必须持续冷却: 停堆后燃料仍会放出大量"余热",失去冷却会熔毁
  - 乏燃料具有强放射性,需要长期隔离保存
```

### 6.6 核聚变

```
很轻的原子核(如氢的同位素)在极高温度下合并成氦,放出能量
  → 太阳和所有恒星发光发热的来源
  → 人类正在研究可控核聚变发电,尚未实现商业应用
```

### 6.7 辐射的有益用途

```
✓ X光检查(1895年伦琴发现X射线)、CT
✓ 放射治疗癌症
✓ 辐照消毒医疗器械、保存食品
✓ 放射性测年
✓ 烟雾报警器(含少量放射源,⚠️不要拆开)
```

## 七、粒子和宇宙

### 7.1 四种基本相互作用

| 相互作用 | 作用 | 作用范围 |
|---------|------|---------|
| 引力 | 天体运行、物体下落 | 无限远,但非常弱 |
| 电磁力 | 化学键、摩擦、光、电和磁 | 无限远 |
| 强相互作用 | 把质子、中子结合成原子核 | 原子核内 |
| 弱相互作用 | β衰变 | 原子核内 |

```
质子和中子由更小的"夸克"组成;电子目前认为没有更小的结构
```

### 7.2 宇宙

```
- 太阳到地球的平均距离约1.5亿千米,阳光约8分钟传到地球
- 太阳是银河系中几千亿颗恒星中普通的一颗
- 宇宙在膨胀: 越远的星系退行得越快
- 宇宙大约起源于138亿年前的"大爆炸"
- 恒星由氢聚变成氦,较重的元素(碳、氧、铁)在恒星内部和超新星爆发中形成
  → 构成我们身体的原子,大多来自很久以前的恒星
```

## 八、常用物理常数(补充)

| 常数 | 数值 |
|------|------|
| 普朗克常数 h | 约 6.63 × 10⁻³⁴ 焦·秒 |
| 电子电荷 e | 约 1.60 × 10⁻¹⁹ 库仑 |
| 电子质量 | 约 9.11 × 10⁻³¹ 千克 |
| 质子质量 | 约 1.67 × 10⁻²⁷ 千克 |
| 1电子伏 | 约 1.60 × 10⁻¹⁹ 焦 |
| 玻尔兹曼常数 k | 约 1.38 × 10⁻²³ 焦/开 |
| 斯特藩-玻尔兹曼常数 σ | 约 5.67 × 10⁻⁸ 瓦/(平方米·开⁴) |
| 维恩位移常数 | 约 2.90 × 10⁻³ 米·开 |

```
维恩位移定律: 物体辐射最强的波长 × 绝对温度 ≈ 2.9 × 10⁻³ 米·开
  → 温度越高,发出的光越偏向蓝白色
  → 这就是可以凭炉火、烧红的铁的颜色判断温度的物理原理
```

用颜色判断温度见[金属加工技术](../05-冶金技术/04-金属加工技术.md)。
