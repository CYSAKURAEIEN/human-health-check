# 森林求生指南

森林里最常见的危险不是野兽,而是**迷路、天黑、淋雨失温和摔伤**。林子里视线只有几十 m,树木看起来都一样,太阳常被树冠挡住,人很容易不知不觉地绕圈子。本章讲在森林中迷路、被困时怎样保住自己,直到获救或走出去。

⚠️ 原则: 优先求救、等待救援;不冒险赶路;不吃不认识的东西。出发前的准备和报警方法见[户外出行准备与求救](07-户外出行准备与求救.md)。

## 方向辨别

### 不要迷路

```
✓ 沿已有小路/河流
  - 林中不要为了"抄近路"离开道路;小路在落叶多的地方会变模糊,
    看不清路时停下,找到下一个路标(路条、油漆标记、踩踏痕迹)再走
✓ 做标记(布条、刻痕、石堆)
  - 离开主路去取水、上厕所、捡柴时也要做,林中走出几十 m就可能找不回来
✓ 记住地标
  - 特别的大树、岩石、溪流交汇处、山脊的缺口;每经过一个就记一下时间
✓ 定期回头看
  - 回程看到的景象和去程完全不同,每走几分钟回头看一眼,记住"回来时的样子"
✓ 河流一般通向人烟(但沿溪谷走有危险,见下文"沿河下行")

补充:
✓ 出发前下载离线地图,手机开着定位轨迹记录;带充电宝
✓ 每隔一段时间(例如每30分钟或每到一个岔路口)在地图上确认一次位置,
  不要等到完全不认识了才看
✓ 下午三四点以后林中光线暗得很快,天黑前1-2小时就要开始考虑回撤或过夜
```

行程单、掉头时间和装备见[户外出行准备与求救](07-户外出行准备与求救.md#出发前)。

### 已迷路

```
STOP:
S - Stop:停下
T - Think:思考
O - Observe:观察
P - Plan:计划

原则:
- 有人知道你的行程、会来搜救: 留在原地,发出信号(最优先)
- 确认无人搜救、必须自行脱困时:
  * 先往高处观察地形,确认道路、村庄方向
  * 优先沿山脊、已有小路走
  * ⚠️ 不要盲目沿溪谷下行: 溪谷常通向峡谷、瀑布、陡崖,雨后还有山洪
```

**具体怎么做**:
```
1. 停下,坐下来,喝口水、吃点东西,让自己冷静
   (慌乱时人会加快脚步乱走,往往越走越远、越走越累)
2. 先看手机:
   - 有信号: 立即拨打110或119报警,发送定位;然后留在原地
   - 打不通电话时发短信,短信更容易发出去
   - 没有信号: 打开离线地图看定位(GPS不需要手机信号);
     开飞行模式省电,每隔一段时间关闭飞行模式试一下信号;
     往高处、开阔处走几十 m,信号可能就有了
3. 回想: 最后一次确定位置是在哪里,之后走了多久、大概往哪个方向
4. 在当前位置做一个明显的标记(见"留记号"),作为"原点"
5. 以原点为中心,短距离试探(每次不超过几十 m、始终能看到原点的标记),
   寻找来时的路;找不到就回到原点
6. 天黑前2小时还没找到路: 停止行动,准备过夜(庇护所、保暖、火)
   ❌ 不要摸黑在林中赶路: 夜间摔伤、坠崖、落水的风险远大于在原地过一夜
```

怎样报警、怎样说清位置见[户外出行准备与求救-报警求救](07-户外出行准备与求救.md#报警求救-说清楚你在哪里);求救信号见[基础生存技能-求救信号](00-基础生存技能.md#求救信号)。

### 留在原地还是移动

| 情况 | 建议 |
|------|------|
| 有人知道你的行程、约定了报警时间 | **留在原地**,搜救从你的计划路线开始找 |
| 已经报警、救援已知道你的位置 | **留在原地**,不要换地方(除非有山洪、林火、落石等直接危险) |
| 有人受伤、天快黑、天气恶劣、体力透支 | **留在原地**,先保暖 |
| 原地是密林、谷底,从空中和远处都看不见 | 可以移动到**附近**的开阔处、林间空地、林缘(几百 m内),并在原处留下指向新位置的记号 |
| 确定没有人知道你进了山,等待了1-2天也没有搜救迹象,而且身体还能走 | 可以考虑自行脱困: 先登高看路,沿山脊或小路走,见下文"导航" |

```
为什么"留在原地"通常更好:
- 搜救队按你的计划路线和最后已知位置搜索,移动的目标很难找
- 静止的人能省下体力和体温;迷路的人走得越多,失温、摔伤的风险越大
- 搜救直升机和无人机在林冠上方很难看到树下移动的人,
  在开阔处摊开鲜艳物品、生烟更容易被发现

等待时:
✓ 每隔一段时间吹哨子,三声一组(比喊叫省力,传得远)
✓ 听到人声、狗叫、发动机、直升机时,立即吹哨、挥动鲜艳衣物、点燃信号烟
✓ 白天在开阔处生烟(火上加青枝绿叶产生白烟),夜间保留火光
```

等待救援时的保暖和自我照顾见[户外出行准备与求救-等待救援](07-户外出行准备与求救.md#等待救援)。

**带孩子进山**:
```
出发前告诉孩子: "如果找不到大人,就抱住一棵树,不要再走了。"
✓ 让孩子随身带一个哨子,教他听到喊名字就吹哨
✓ 告诉孩子: 搜救的叔叔阿姨是来找你的,听到有人喊你要答应,不要躲
  (走失的孩子常因为害怕"陌生人"或怕挨骂而躲起来)
✓ 给孩子穿鲜艳的衣服
```

### 可靠的定向方法

迷路时最需要的往往不是"哪边是北",而是"道路、村庄在哪个方向"。知道方向只有在你大致知道自己在哪里、要去的地方在哪个方向时才有用。

| 方法 | 可靠程度 | 说明 |
|------|---------|------|
| 手机地图定位 | 高(有电时) | 不需要手机信号;进山前下载离线地图 |
| 指南针 | 高 | 远离铁器、电子设备;红针指磁北,和真北有几度的偏差(磁偏角),徒步时一般可以忽略 |
| 太阳 | 中-高 | 北半球中纬度地区: 早上大致在东方,正午在南方,傍晚在西方;立杆测影可以更准确 |
| 北极星 | 高(晴夜) | 指向正北,偏差不到1° |
| 树冠、年轮、苔藓、蚂蚁窝 | **低** | 见下一节,不要依靠 |

```
在林中使用方向时:
1. 用指南针或太阳确定要走的方向
2. 沿这个方向看出去,选一个远处容易认的目标(一棵特别的树、一块大石头)
3. 走到目标处,再选下一个目标
   (不选目标、凭感觉走,在林中几乎一定会绕圈子)
4. 遇到障碍需要绕行时,绕过后回到原来的方向线上
5. 太阳会移动(每小时约15°),用太阳定向时每隔半小时重新确认一次
```

指南针、手表法、立杆测影和北极星的具体方法见[基础生存技能-导航与定向](00-基础生存技能.md#导航与定向);地图和指南针配合使用见[户外出行准备与求救-用地图和指南针](07-户外出行准备与求救.md#用地图和指南针);更精确的天文定向和磁偏角见[天文导航进阶](../09-进阶科学与工程/09-天文导航进阶.md#二精确定方向)。

### 树冠、年轮、苔藓为什么靠不住

民间流传"树冠南侧茂密、年轮南宽北窄、苔藓长在北面"。这些说法有一点道理(北半球南侧光照多),但**在森林里几乎没有用**:

```
❌ 树冠: 林中树木互相遮挡,树冠朝空隙、朝坡下、朝光多的地方长,
   和南北关系不大;山坡上的树普遍偏向坡外
❌ 年轮: 年轮宽窄主要由坡度、风向、树干倾斜、相邻树木竞争决定;
   很多树的年轮南北两侧几乎一样宽,有的反而北侧宽
❌ 苔藓: 苔藓长在潮湿、背阴的地方。林中到处阴湿,四面都可能长满;
   靠近溪流的一侧、迎雨的一侧、树干倾斜的下侧苔藓更多
❌ 蚂蚁窝在树的南侧、积雪北侧化得慢: 在空旷处有时成立,林中不可靠

结论:
- 只有在找不到太阳、星星,也没有指南针时,把多棵树的情况放在一起看,
  作为非常粗略的参考
- 不要根据一棵树、一块苔藓决定前进方向
```

## 水源

### 寻找

```
线索:
✓ 植被茂盛
  - 林中出现一片特别绿、特别茂密的植物(芦苇、蕨类、柳树、竹丛),下面往往有水
✓ 动物踪迹汇集
  - 多条兽径汇合、往低处去,常通向水边
✓ 昆虫多
  - 蚊子、蜻蜓多说明附近有静水;蜜蜂常在水源和蜂巢之间来回
✓ 鸟类飞向(傍晚)
  - 斑鸠、鸽子、麻雀等吃种子的鸟,清晨和傍晚会飞去喝水;
    鹰等猛禽的飞行方向说明不了什么
✓ 山谷低洼处
  - 沿着地形往下找;静下来听流水声
  - 干涸的溪沟: 在拐弯处外侧、大石下方往下挖几十 cm,可能渗出水
✓ 跟随动物踪迹

其他取水方法:
✓ 竹子: 老的青竹有时竹节里存水,摇晃能听到水声,在节的下方开孔取水
✓ 藤本植物: 雨林中砍断某些粗藤,会流出清水;只喝无色、无味、不黏的,
  流出乳白色、有颜色、发苦、发黏的液体不要喝
✓ 雨水: 用防水布、大树叶接(见下一节)
```

### 水源

**优先级**:
```
1. 流动溪流(上游)
2. 泉水
3. 雨水
4. 露水
5. 植物蒸腾水
6. 池塘/湖水(必须净化)

注意: 排在前面的只是"相对干净",并不是可以直接喝
```

```
取水时:
✓ 从水流湍急、清澈处取水,不要取岸边浅处、有泡沫、有死动物的水
✓ 先看上游: 有没有村庄、牧场、牛羊粪便、矿区、农田(农药)
✓ 浑水先静置沉淀,再用布、衣服过滤,然后消毒
❌ 不要在山洪征兆出现时到溪边取水
```

山洪征兆见[涉水、山洪与野外失温-山洪来临的征兆](08-涉水山洪与野外失温.md#山洪来临的征兆)。

**净化**:
```
⚠️ 所有野外水源都应净化!
- 煮沸(最佳)
  * 烧到沸腾后保持至少1分钟;海拔2000 m以上保持3分钟
- 过滤+煮沸
  * 浑水先过滤再煮;自制的沙石木炭过滤器只能去除泥沙,不能杀灭病菌
- 化学消毒
  * 净水片按说明书用量,等30分钟(水冷、水浑时等更久)
  * 家用漂白水(含次氯酸钠,无香味): 每升清水2滴、浑水4滴,摇匀等30分钟

为什么林中清澈的溪水也要净化:
- 野生动物和放牧的牛羊会把贾第鞭毛虫、隐孢子虫、致病细菌带进溪水,
  "看起来清澈""山泉水"都不能保证安全
- 野外腹泻会造成脱水、虚弱,让本来能走出去的人走不出去
```

各种净化方法的细节见[基础生存技能-水质净化](00-基础生存技能.md#水质净化)。出现腹泻时的补液见[野外伤病处置与转运-腹泻、呕吐](11-野外伤病处置与转运.md#腹泻呕吐)。

## 庇护所

森林里材料多,但**地面潮湿、夜间降温、下雨后湿冷**是主要问题。林中夜晚即使在夏天也可能降到十几°C,湿衣服加上风,足以造成失温。

### 林中扎营选址

```
✓ 稍高、平坦、排水好的地面: 林中的缓坡台地、小土包
✓ 抬头看: 头顶没有枯死的树、断了挂在半空的树枝("寡妇枝")
  - 枯树、半倒的树、树根被冲空的树,大风或雨后随时会倒
  - 扎营处与枯树的距离至少大于这棵树的高度
✓ 背风: 依托土坎、大石、密灌丛挡风
✓ 靠近能看见天空的空地或林缘(方便被发现、发信号),但不要在空地中央

❌ 避免:
- 溪边、河滩、干沟、沟口(山洪)
- 低洼积水处、苔藓特别厚的湿地(潮湿、冷空气在夜间沉积)
- 兽径上、蚂蚁窝和蜂窝附近、果树下(会招来动物)
- 陡坡下方(落石、滑坡)、孤立的大树下(雷击)
```

**雷雨时**:
```
⚠️ 野外没有真正安全的避雷处,听到雷声就要提前准备,
   能撤到建筑物或车里就撤
✓ 在森林中: 离开林中最高的树和孤立的大树,
  到一片高度差不多的较矮树林中,离树干至少几 m
✓ 离开山脊、山顶、林中空地的中央、水边
✓ 帐篷和简易棚不能防雷;雷暴到头顶时,离开金属物,
  双脚并拢蹲在防潮垫或干背包上
✓ 多人时分散开,相互间隔至少15 m
❌ 不要躲在大树下、岩石突出部下方、浅洞口
```

雷电的详细应对见[气象灾害-室外避雷](../02-灾难应对/02-气象灾害.md#室外避雷)和[山地求生-雷电](05-山地求生.md#雷电);露营选址的通用原则见[涉水、山洪与野外失温-露营选址](08-涉水山洪与野外失温.md#露营选址)。

### 自然庇护所

```
利用:
✓ 洞穴(检查无动物)
  - 先在洞口观察: 有没有粪便、骨头、毛发、强烈的动物气味,有就不要进
  - 不要深入狭窄、潮湿、有水流的洞(可能被困、被淹)
  - 洞里有大量老鼠粪便时: 先洒水打湿再清理,不要干扫
    (干的鼠粪被扬起吸入,可能传播出血热)
✓ 大树下(临时)
  - 只用于短时间避雨;雷雨天不要躲在大树下
✓ 倒下的树干旁
  - 选已经稳稳躺在地上、不在坡上、不会滚动的倒木
  - 先用棍子拍打、拨开周围,倒木下面常有蛇、马蜂、蚂蚁、蝎子、蜈蚣
  - 不要靠在斜靠着别的树、悬在半空的倒木下(会突然滑落)
✓ 岩石突出部
  - 先看上方有没有松动的石头、新鲜的落石痕迹
```

### 建造庇护所

**A字棚**:
```
1. 找主梁(粗长木棍)
   - 约比身高长1 m,手腕粗以上,选结实、没有腐朽的
2. 一端架高(叉树枝)
   - 架在树杈或两根交叉绑好的木棍上,离地约1 m(坐起来头碰不到即可)
3. 另一端触地
4. 两侧斜靠木棍
   - 间距一拳左右,下端插稳
5. 密铺树枝、树叶(瓦片状)
   - 从下往上铺,上一层压住下一层
6. 越厚越好(30 cm+)
   - 冷天越厚越好,标准是从里面看不到外面的光
7. 内铺干树叶
   - 压实后至少10-15 cm厚
```

**树叶小屋**:
```
- 框架:A字
- 厚覆盖树叶
- 入口小
- 保暖效果好
- 内部空间只比身体稍大(空间越大越难保暖)
- 入口背风,可以用一堆树叶或背包堵住
```

**防雨技巧**:
```
✓ 瓦片状铺设(下层在外)
✓ 树皮作顶层
✓ 坡度足够(水流走)
  - 顶面和地面夹角至少约45°,太平了雨水会渗进来
✓ 周围挖排水沟
  - 在上坡一侧挖一道浅沟,把雨水引向两侧
✓ 有防水布、雨衣、大塑料袋时,铺在树枝层上面,效果远好于纯树叶
```

庇护所的其他类型见[基础生存技能-庇护所建造](00-基础生存技能.md#庇护所建造)。

### 防潮与保暖

```
⚠️ 林中过夜最容易被忽视的是"地面": 潮湿的地面带走体温的速度比空气快得多

✓ 不要直接躺、坐在地上: 铺干树叶、松针、蕨类、树枝,压实后至少10 cm厚,
  或者坐在背包、防潮垫上
✓ 湿衣服尽量拧干,能换就换;袜子单独烘干(湿脚会起泡、浸渍)
✓ 睡前吃点东西、喝点热水;身体冷时动一动(做几十次深蹲)再躺下
✓ 几个人时挤在一起;把应急保温毯裹在身上
✓ 夜里冷得发抖、手脚不灵活、说话含糊,是失温的信号,要立即处理
```

失温的识别和处理见[涉水、山洪与野外失温-不只是冬天: 野外失温](08-涉水山洪与野外失温.md#不只是冬天-野外失温)。

## 火

森林里柴多,但**林火是森林里最大的人为灾害**。生火前先想清楚: 是否真的需要(取暖防失温、烧水、发信号),当地是否在森林防火期。

### 选址

```
✓ 平坦地面
✓ 避风但通风
✓ 近庇护所(但安全距离)
  - 至少离庇护所几 m,火星不能飘到树叶棚顶上
✓ 近木材来源
✓ 清除周围可燃物
  - 清出一圈直径约3 m的裸土,扫开落叶、枯草、松针
✓ 挖坑或围石
  - 不要用河里湿的石头围火(受热可能炸裂)

❌ 不要在以下地方生火:
- 树下(头顶的枝叶会被烤着)、树根上、倒木旁
- 厚厚的腐殖层、泥炭地上(地下会闷燃很久,几小时后从别处冒出火来)
- 大风天、干草丛中
```

### 湿木生火

**找干材料**:
```
✓ 枯死树上的小树枝(未落地)
  - 掰的时候"啪"一声脆断的是干的;弯而不断的是湿的或活的
✓ 树皮下干燥层
✓ 松树脂(易燃)
  - 松树伤口处流出、凝固的松脂,或富含松脂的松明子,下雨也能点着
✓ 桦树皮(防水易燃)
  - 从倒木、枯树上剥,不要剥活树的树皮(会让树死亡)
✓ 劈开湿木(内部干燥)
  - 选手腕粗的枯枝,劈开后芯部常是干的
```

**方法**:
```
1. 准备大量火绒
   - 准备的量是你认为需要的2-3倍;湿天火最容易在这一步失败
2. 劈开湿木露出干芯
3. 削薄片(feather stick)
   - 在干芯木棍上削出一圈卷曲不掉的薄片,越薄越容易点着
4. 生小火
   - 下面垫一层树皮或木棍,不要让火直接在湿地上
5. 烤干湿木
   - 把要用的柴围在火堆旁边烤
6. 逐渐添加
   - 由细到粗: 火柴棍粗 → 铅笔粗 → 拇指粗 → 手腕粗,
     前一种烧旺了再加下一种
```

生火方法和火堆结构见[基础生存技能-生火技术](00-基础生存技能.md#生火技术)。

### 防止引发林火

```
✓ 进山前查看当地森林火险等级和防火期规定
  - 我国北方春秋两季、南方冬春季节是主要防火期;
    防火期内林区一般禁止一切野外用火,违者会被处罚,引起森林火灾要承担刑事责任
  - 真正危及生命(迷路过夜、失温)时用火取暖、发信号,也要格外小心
✓ 火堆一直有人看着,身边备好水或沙土
✓ 火堆不要大,够取暖、烧水即可
✓ 离开或睡觉前彻底熄灭:
  1. 浇水
  2. 用棍子搅拌灰烬,翻出底下的余火
  3. 再浇水,直到没有烟、没有嘶嘶声
  4. 用手背靠近灰烬,感觉不到热才算灭透
  没有水时用湿土反复覆盖、搅拌
```

### 遇到林火

```
✓ 发现林火: 拨打森林火警12119或119,说清位置、火的方向和风向
✓ 立即撤离,往逆风、山下、河流、开阔地、已烧过的地方走
❌ 不要往山上跑,不要顺风跑,不要进入狭窄的山谷、沟口
❌ 不要停下拍照、围观、为了拿东西回去
```

逃生和被火包围时的自救方法见[火灾-森林火灾](../02-灾难应对/04-火灾.md#森林火灾)。

## 食物

人不吃东西也能活几周,**在等待救援的几天里,食物远不如水和保暖重要**。在林中翻找食物消耗的体力和带来的风险(中毒、受伤、迷路更远),往往大于得到的能量。短期被困时,应急食品省着吃,不要冒险采食。

只有在长时间无法获救的情况下,才需要从森林中获取食物,原则是: **不认识的不吃,不确定的不吃。**

### 可食植物

**常见可食** (确认后):
```
✓ 橡子(去涩,煮熟)
  - 含大量单宁,生吃发苦、伤胃
  - 去壳捣碎,用清水浸泡或反复煮,每次换水,直到不再苦涩(可能需要几天)
✓ 蒲公英(全株)
  - 叶子越老越苦,嫩叶焯水后吃;根可以煮
✓ 车前草
  - 嫩叶焯水后吃
✓ 野蒜野葱
  - 一定要揉碎闻: 有明显的葱蒜味才是;没有葱蒜味的"葱蒜"可能是石蒜、水仙等有毒植物
✓ 某些野果(确认)
  - 只吃自己从小认识、当地常吃的(如野草莓、野生猕猴桃、板栗、松子)
✓ 蕨菜嫩芽
  - 只吃未展开的嫩芽,必须焯水浸泡后煮熟,不要长期大量吃(含致癌物)
✓ 竹笋
  - 生笋含有可产生氰化物的成分,必须去壳煮熟,最好焯水后再烹饪
✓ 木耳、蘑菇(⚠️专业识别!)
  - 新鲜木耳泡发过久会变质产生毒素;野生蘑菇不认识的一律不吃
```

**避免**:
```
❌ 白色浆果(大多毒)
❌ 聚合浆果的白色、黄色种类
❌ 乳白汁液(大多有毒,蒲公英等可确认的种类例外)
❌ 苦杏仁味
  - 苦杏仁味说明含氰化物
❌ 伞形花序(很多毒)
  - 伞形科里有毒芹、毒参等剧毒植物,长得像野胡萝卜、水芹、野芹菜
❌ 三片叶(很多毒)
❌ 嚼起来嘴麻、舌麻、灼烧、极苦的,立即吐掉并漱口

⚠️ 蘑菇:不确定绝不吃!(致命,见毒蘑菇与野菜误食)
```

相关章节: [毒蘑菇与野菜误食](09-毒蘑菇与野菜误食.md)。

```
⚠️ 关于"可食性测试":
- 有些资料介绍逐步试吃的"通用可食性测试"
- 它发现不了几小时到几天后才发作的毒素,对蘑菇完全无效,对剧毒植物也不安全
- 只能作为长期无法获救、确实快要饿垮时的最后手段;短期被困不要用
```

民间蘑菇鉴别法为何不可靠、容易认错的有毒植物见[毒蘑菇与野菜误食](09-毒蘑菇与野菜误食.md#毒蘑菇-没有简单的鉴别方法);可食性测试的局限见[毒蘑菇与野菜误食-关于"可食性测试"](09-毒蘑菇与野菜误食.md#关于可食性测试)。

### 动物蛋白

**昆虫**:
```
可食(煮熟):
✓ 蚱蜢、蟋蟀
  - 去掉翅膀和后腿(腿上的倒刺会卡喉咙)
✓ 白蚁
✓ 甲虫幼虫(朽木中)
  - 劈开朽木、翻开树皮常能找到白色的幼虫
✓ 蚯蚓(挤出内容物,冲洗)
  - 可以先放在清水里泡一段时间让它吐出泥土,必须煮熟
✓ 蚂蚁(去头)

避免:
❌ 鲜艳颜色
❌ 有毛
❌ 臭味强烈
❌ 蜘蛛、蜱虫、蜈蚣、蝎子、苍蝇、蚊子
❌ 死了一段时间的昆虫、从粪便、腐肉上捡的

注意:
- 一律煮熟或烤熟再吃(昆虫和蚯蚓可能带寄生虫)
- 对虾蟹过敏的人吃昆虫可能过敏,先少量尝试
```

**小动物**:
```
陷阱捕猎:
- 简易绳索陷阱
- 挖陷坑
- 落石陷阱

⚠️ 需技能和时间
- 能量消耗可能>获得
- 优先昆虫和植物
- 陷阱不分对象: 可能夹住保护动物、别人的狗、甚至路过的人(包括孩子)
- 抓到的野生动物可能携带寄生虫和病原体,处理时戴手套或包住手,肉必须彻底煮熟
- 不吃病死、死因不明的动物
```

**钓鱼**:
```
溪流中:
✓ 制作鱼钩(弯针、骨头)
  - 别针、缝衣针掰弯最简单
✓ 鱼线(伞绳内芯)
✓ 诱饵(虫子)
  - 蚯蚓、甲虫幼虫;鱼多躲在水潭、岸边树根下、大石头背水的一侧
✓ 或徒手(石头下)
  - 小心湿滑的石头,不要为了抓鱼下到急流和深水里
✓ 鱼叉

⚠️ 淡水鱼必须彻底煮熟(生吃或半生吃可能感染肝吸虫等寄生虫)
```

### 关于狩猎和捕鱼的法律

```
⚠️ 平时在我国:
- 《野生动物保护法》禁止猎捕、杀害国家和地方重点保护野生动物,
  其他野生动物也要有狩猎证、在规定的时间地点才能猎捕
- 禁止使用猎套、猎夹、地枪、毒药、爆炸物、电击、捕鸟网等工具
- 禁止食用陆生野生动物(人工饲养的家禽家畜等除外)
- 《渔业法》禁止电鱼、毒鱼、炸鱼;禁渔期、禁渔区(包括长江流域重点水域的长期禁捕)不得捕鱼
- 违反者会被罚款,情节严重的构成犯罪

本节内容只用于了解野外生存的基本知识,或文明崩溃、长期无法获救的极端情况。
迷路几天等待救援,用不着打猎。
```

昆虫和捕鱼的通用方法见[基础生存技能-食物获取](00-基础生存技能.md#食物获取);长期生存时的养殖和渔业见[水产养殖](../04-动植物培育/07-水产养殖.md)。

## 危险

### 动物

**大型动物**:
```
遇到熊:
- 保持冷静
- 缓慢后退
- 不要奔跑
- 不要直视
- 发出声音示警
- 使自己显大(举高手臂)
- 如攻击:
  * 棕熊防御性攻击(护崽、近距离受惊):趴下装死,双手护住颈部
  * 黑熊攻击,或任何熊持续攻击、把人当猎物(尾随、夜间闯入帐篷):全力反击
  * 有防熊喷雾时优先使用

遇到野猪:
- 不要靠近
- 爬树
- 背对大树

遇到蛇:
- 远离
- 不要惊动
- 检查睡袋、鞋子
- 用棍子探路
```

**熊: 预防比应对重要**:
```
我国的熊主要是亚洲黑熊(俗称狗熊、黑瞎子,东北、西南、秦岭等林区)
和棕熊(东北、西北、青藏高原)。大多数熊遇到人会主动避开,
伤人多发生在突然近距离相遇、母熊护崽、熊在争夺食物时。

✓ 在熊出没的林区走路时说话、拍手、挂铃铛,让熊提前知道有人来
✓ 结伴走,不要单独行动;不要在黄昏、清晨钻密灌丛
✓ 看到新鲜的熊粪、脚印、被翻开的树桩和蚁穴、被扒开的蜂巢,换路线离开
✓ 食物、垃圾、牙膏等有气味的东西不放在帐篷里:
  - 做饭、存放食物的地方离睡觉处约100 m,最好在下风处
  - 有条件时把食物袋挂在树枝上,离地约4 m、离树干1-2 m
❌ 不要投喂、靠近、拍照小熊(母熊一般就在附近)

遇到熊时补充:
- 熊站起来多半是在看、在闻,不一定是要进攻
- 熊冲过来常是"假冲锋",冲到几 m外就停下;不要跑,站住
- 防熊喷雾在熊进入约10 m内时对着熊脸喷
- 爬树不能躲开黑熊(黑熊会爬树)
- 被熊抓咬伤后必须尽快就医: 伤口深、污染重,要清创、打破伤风和狂犬病疫苗
```

野猪、狗、猴子和蛇的预防与应对见[马蜂、蜱虫与危险动物](10-马蜂蜱虫与危险动物.md);被蛇咬伤的处理见[外伤处理-蛇咬伤](../01-日常疾病和伤害/02-外伤处理.md#蛇咬伤);动物咬伤和狂犬病预防见[外伤处理-咬伤](../01-日常疾病和伤害/02-外伤处理.md#咬伤)。

**昆虫**:
```
✓ 检查身体(蜱虫)
  - 每天至少检查一次全身,特别是头皮、耳后、腋下、腰部、腹股沟、膝盖后面
  - 发现叮着的蜱虫用细镊子贴近皮肤夹住,垂直慢慢拔出,不要用火烧、涂油
✓ 烟熏驱蚊
✓ 泥巴涂皮肤(防虫咬)
  - 只在没有驱虫剂时使用,不要涂在伤口上
✓ 检查衣物、睡袋
✓ 马蜂: 林中最常伤人的动物之一。看到蜂窝、听到嗡嗡声变大就绕开;
  被蜂群攻击时护住头颈,往远离蜂窝的方向快跑
  ⚠️ 被蜇10处以上,或出现呼吸困难、全身起疹、脸肿,立即求救就医
✓ 有驱虫剂(含避蚊胺)时按说明书涂在裸露皮肤上;裤腿扎进袜子里
```

马蜂、蜱虫、旱蚂蟥的预防和处理见[马蜂、蜱虫与危险动物](10-马蜂蜱虫与危险动物.md)。

### 植物

**有毒植物**:
```
❌ 毒藤、毒橡树(三片叶,触碰过敏)
  - 主要分布在北美;我国林区更常见的是漆树、野漆,
    接触或靠近后皮肤红肿、起水疱、剧痒("漆疮")
❌ 毒芹(致命)
  - 生在水边湿地,像水芹、野芹菜;根切开有黄色汁液
❌ 夹竹桃(全株有毒)
  - 不要用夹竹桃枝条当烤肉签、筷子,不要用它烧火烤食物
❌ 钩吻(断肠草): 南方山林常见的藤本,开黄色小花,少量即可致死
❌ 荨麻: 叶和茎上的刺毛碰到后皮肤刺痛、起疹,一般几小时后消退

原则:
- 不认识不吃
- 不确定不碰
```

```
接触有毒植物后:
✓ 尽快用肥皂和大量清水冲洗皮肤(最好在接触后几十分钟内)
✓ 接触过的衣服、手套、工具也要洗(汁液可以沾在上面继续致敏)
✓ 不要抓挠;痒得厉害可以冷敷
⚠️ 脸部、眼睛、大面积起水疱,或吸入了焚烧有毒植物的烟后咳嗽、气喘,要就医
⚠️ 误吃了不认识的植物后出现呕吐、嘴麻、抽搐、心慌,立即求救,
   保留吃剩的植物给医生看
```

容易认错的有毒植物和误食后的处理见[毒蘑菇与野菜误食-容易认错的有毒植物](09-毒蘑菇与野菜误食.md#容易认错的有毒植物);中毒的一般处理见[中毒](../01-日常疾病和伤害/12-中毒.md)。

### 疾病

**预防**:
```
✓ 净化水
  - 防止腹泻类疾病(细菌性痢疾、贾第鞭毛虫等)
✓ 煮熟食物
✓ 个人卫生
  - 饭前便后洗手(没有水时用免洗洗手液);粪便挖坑掩埋,离水源至少30 m
✓ 避免积水(疟疾)
  - 不在积水旁扎营;用蚊帐、驱蚊剂;黄昏和夜里穿长袖
✓ 伤口清洁
  - 林中湿热,小伤口也容易感染,及时用干净的水冲洗、包扎
```

```
森林中需要注意的几种病:
- 蜱传疾病: 森林脑炎(东北、西北林区)、发热伴血小板减少综合征、莱姆病;
  被叮后约2周内发热要就医并告诉医生
- 疟疾: 主要在国外的热带地区和我国边境部分地区;去这些地方前咨询医生是否需要预防用药
- 恙虫病: 南方草丛、灌木丛中的恙螨叮咬引起,叮咬处有黑色焦痂,伴发热
- 钩端螺旋体病: 接触被鼠类、家畜尿液污染的水和泥土(雨季、洪水后),
  皮肤有伤口时不要在这样的水里涉水、洗澡
- 出血热: 吸入鼠类排泄物的灰尘;不要干扫鼠粪,不要睡在鼠洞旁

⚠️ 从林区回来后几周内出现发热、头痛、皮疹、乏力,就医时主动说明去过哪里
```

传染病的家庭防控见[传染病家庭防控](../01-日常疾病和伤害/15-传染病家庭防控.md);蜱虫的详细内容见[马蜂、蜱虫与危险动物-蜱虫](10-马蜂蜱虫与危险动物.md#蜱虫)。

## 导航

### 沿河下行(谨慎)

```
优点:
✓ 河流最终通向人烟
✓ 水源保证
✓ 食物(鱼)

⚠️ 风险:
- 溪谷可能变成峡谷、瀑布、陡崖,进退两难
- 河边湿滑,易落水
- 降雨后山洪暴发

做法:
- 只在河谷开阔、两岸可行走时沿河走
- 遇到峡谷、瀑布不要硬闯,退回改走山脊
- 不在河边扎营
```

| | 适合沿河走 | 不要沿河走 |
|---|---|---|
| 地形 | 平缓的丘陵、平原林区,河谷宽、两岸有路或可以走 | 山区溪谷,两侧是陡坡、悬崖 |
| 河流 | 较大的河,沿岸常有村庄、道路、渔民 | 小溪沟,常在下游变成峡谷、跌水 |
| 天气 | 晴天、水位稳定 | 下雨、上游有雨、水变浑 |
| 身体 | 能稳当行走 | 疲劳、受伤、天快黑 |

```
沿河走时:
✓ 走在高于河床的岸坡上,不要走在河道里、石头上
✓ 看到前面河谷收窄、两侧变陡、听到瀑布的轰鸣,提前退出,不要等进去了才回头
✓ 需要过河时,能不过就不过
✓ 出现山洪征兆(水变浑、涨水、上游轰鸣),立即往两侧高处走
```

涉水和山洪见[涉水、山洪与野外失温](08-涉水山洪与野外失温.md)。

### 找高处观察

```
✓ 爬到高处/树上
  - 登高时选有路、坡度缓的地方;不要爬湿滑的岩壁
  - 爬树只爬自己有把握的高度,枯枝不要踩;受伤摔下的代价比迷路大得多
✓ 观察:
  - 烟(人烟)
  - 灯光(夜晚)
  - 道路、建筑
  - 开阔地
  - 河流方向
  - 电线、输电塔、梯田、茶园、人工林(整齐的一排排树)都说明附近有人
✓ 也要用耳朵: 安静时听汽车声、狗叫、鸡鸣、伐木和机器声,判断方向
✓ 看到目标后,用指南针或太阳记下它的方向,选好沿途的中间目标再出发
  (下到林中就看不见目标了)
```

### 留记号

```
✓ 布条(鲜艳)
  - 挂在齐眼高、从两个方向都能看见的地方
✓ 树干刻记号
  - 只在紧急情况下使用;平时会伤害树木,保护区和景区禁止刻画
✓ 石堆
  - 叠三块以上,自然界很少有这样的石堆,一看就知道是人做的
✓ 折断树枝指向
  - 折断但不折下,断口朝前进方向;新鲜断口颜色浅,容易认出

作用:
- 搜救队找到
- 自己不走回头路

做法:
✓ 每隔一段距离做一个,站在一个记号处应该能看到上一个
✓ 在离开原处时,用石头、树枝摆一个大箭头指向你去的方向,
  能写字时留下日期、时间、人数、去向
✓ 前进方向改变的地方一定要做记号
✓ 用同一种做法,不要一会儿布条一会儿石堆,搜救队容易混淆
✓ 获救或走出后,把能找到的布条收回
```

## 热带雨林与温带森林

我国的热带雨林主要在云南南部(西双版纳等)、海南和西藏东南部;大部分人去的是南方的亚热带常绿林,和北方、东北的温带落叶林、针叶林。不同森林的主要危险不一样。

| | 热带雨林、南方湿热山林 | 温带森林(北方、东北) |
|---|---|---|
| 气候 | 常年湿热,几乎天天下雨;衣物很难晾干 | 四季分明,冬季严寒;春秋昼夜温差大 |
| 林下 | 光线昏暗,藤蔓、灌木密,视线只有几 m,一天可能只走几 km | 林下较开阔,视线相对好;落叶季节容易辨认地形 |
| 水 | 水多,但几乎都被污染,必须净化 | 溪流多;冬季结冰,需要融冰 |
| 主要危险 | 旱蚂蟥、蚊虫与疟疾等虫媒病、毒蛇、马蜂、湿热中暑、皮肤溃烂和真菌感染、雨季山洪 | 失温、冻伤、蜱虫(森林脑炎)、熊、林火 |
| 过夜 | 尽量不睡在地上: 吊床或用树枝搭离地的床;上面一定要有防雨层 | 地面隔热最重要,铺厚厚的落叶、松针 |
| 生火 | 木头湿透,生火困难,需要找竹子、树脂、枯死未落地的枝条 | 春秋干燥季节林火风险高,防火期禁火 |

```
在湿热山林:
✓ 雨林里一样会失温: 整夜淋雨、穿湿衣服,夜间二十几°C也可能发冷发抖
✓ 每天晚上把脚擦干、晾干,换干袜子;脚长期泡在湿鞋里会浸渍、溃烂
✓ 不要随手抓藤蔓、树干借力(可能有刺、蚂蚁、毒虫、蛇)
✓ 穿长袖长裤,扎紧裤腿防旱蚂蟥和蜱虫
✓ 大量出汗,注意补水和补盐

在温带、寒温带森林:
✓ 秋冬季节天黑早、夜里冷,迷路时最大的威胁是失温
```

雪地中的行动和保暖见[雪地极地求生](04-雪地极地求生.md);浸渍足的处理见[外伤处理-冻疮与浸渍足(不是冻伤)](../01-日常疾病和伤害/02-外伤处理.md#冻疮与浸渍足不是冻伤);中暑见[野外伤病处置与转运-高原反应、中暑、失温](11-野外伤病处置与转运.md#高原反应中暑失温)。

## 📝 森林求生要点

```
优先级:
1. 水(溪流、雨水、植物)
2. 庇护所(防雨保暖)
3. 火(驱兽、取暖、信号)
4. 食物(昆虫、植物、鱼)
5. 导航/信号

技巧:
✓ 有人搜救时留在原地
✓ 做标记
✓ 自行脱困时先登高看路,谨慎沿河
✓ 利用天然庇护所
✓ 木材充足(火)
✓ 天黑前停下准备过夜,不摸黑赶路
✓ 定方向靠指南针、手机、太阳、星星,不靠苔藓和年轮
✓ 溪水再清也要煮沸

危险:
⚠️ 迷路
⚠️ 野兽
⚠️ 有毒动植物
⚠️ 失温(夜晚)
⚠️ 枯树倒伏、雷击、山洪、林火
```

```
注: 上面的优先级适用于一般情况。夜里冷、下雨、衣服湿时,
保暖(庇护所和火)比找水更急;短期被困时,食物可以放在最后。
```
