## 野外急救和城市急救有什么不同

在城市里,拨打120后十几分钟救护车就能到。**在野外,救援可能要几个小时甚至一两天才能到达**,在这之前,同伴就是伤员唯一的照顾者。

```
野外急救要多考虑的事:
- 伤员要在野外坚持很长时间: 保暖、喝水、防休克变得和处理伤口一样重要
- 要做决定: 原地等待救援,还是自己走出去
- 小伤也会变成大问题: 脚上的水泡、扭伤的脚踝,可能让人走不出山
- 搬运非常困难: 山路上抬一个人,几个人轮换也走不了多远

本章把第一部分的急救方法放到野外情境里串起来。
具体的急救操作,先学习第一部分的相关章节。
```

相关章节: [基础急救知识](../01-日常疾病和伤害/00-基础急救知识.md)。

## 第一步: 安全、评估、求救

```
1. 确保安全
   - 先看周围: 还有没有落石、塌方、水流、蜂群等危险
   - 不要让救人的人也受伤(救援者受伤,情况会加倍糟糕)
   - 必要时先把伤员移到安全的地方(移动时尽量保持头颈和身体成一条直线)

2. 检查危及生命的情况
   - 有没有反应、有没有正常呼吸 → 没有就立即CPR
   - 有没有大出血 → 立即压迫止血
   - 有没有休克的迹象(面色苍白、皮肤湿冷、脉搏快弱、烦躁)

3. 求救
   - 有信号就尽早报警,说清位置和伤情
   - 不要等到天黑、手机没电才打

4. 全身检查
   - 从头到脚检查一遍,找出所有伤处
   - 问伤员: 哪里痛、怎么受的伤、有没有麻木
   - 问清楚伤员有没有慢性病、过敏、在吃什么药
```

相关章节: [基础急救知识-生命体征评估](../01-日常疾病和伤害/00-基础急救知识.md#生命体征评估)、[心肺复苏](../01-日常疾病和伤害/00-基础急救知识.md#心肺复苏cpr)、[止血方法](../01-日常疾病和伤害/00-基础急救知识.md#止血方法)、[报警时说清位置](07-户外出行准备与求救.md#报警求救-说清楚你在哪里)。

## 原地等待还是自行撤出

这是野外受伤后最重要的决定。

### 应该原地等待救援

```
⚠️ 以下情况不要自行搬运或强行走出:
- 怀疑脊柱、颈部损伤(从高处摔下、头部受到撞击、背部剧痛、手脚麻木)
- 大腿骨折、骨盆骨折
- 意识不清、头部受伤后反复呕吐、越来越嗜睡
- 大出血、出现休克
- 胸部、腹部受了重伤,呼吸困难
- 严重失温
- 天黑、天气恶劣、路况危险,或者人手不够
```

### 可以考虑慢慢走出去

```
✓ 伤员能自己走路(扭伤较轻、手臂受伤固定好后、手部小伤口)
✓ 路线明确、距离不远、天气允许、天黑前能到
✓ 有人陪着,同伴分担伤员的背包
✓ 途中情况变坏,随时停下来,改为原地等待

⚠️ 不确定时,原地等待救援通常更安全
```

### 需要有人去求援时

```
✓ 至少留一个人陪着伤员,不要把伤员单独留下
✓ 去求援的人最好两个人一起走(防止求援的人也出事)
✓ 带上写好的位置和伤情记录(见下节)
✓ 留下的人和去的人约好: 什么时间、在哪里、怎样联系
✓ 求援的人沿着确定的路走,标记路线,方便带救援队回来
```

## 写一份伤情记录

把情况写在纸上(或手机备忘录里),交给救援人员或去求援的同伴。**医生和救援队拿到这份记录,能更快做出判断。**

```
伤情记录:
1. 时间、地点(经纬度或详细描述)
2. 伤员: 性别、大概年龄、慢性病、过敏、正在吃的药
3. 怎么受的伤: 从多高摔下、被什么砸到、什么时间
4. 发现的伤: 哪个部位、什么样子
5. 做了什么处理: 包扎、固定、吃了什么药(药名、剂量、时间)
6. ⚠️ 用了止血带的,写清楚开始的时间
7. 每隔30分钟到1小时记录一次:
   - 意识: 清醒 / 迷糊 / 叫得醒 / 叫不醒
   - 每分钟呼吸次数、脉搏次数
   - 皮肤颜色和温度
   - 有没有排尿
8. 现场的人数、装备、食物和水、手机电量
```

## 等待救援时照顾伤员

```
保暖(最常被忽略):
✓ 即使是夏天,躺在地上不动的伤员也会很快变冷
✓ 身体下面垫防潮垫、背包、树枝、干草,隔开地面
  (地面带走的热量比空气多)
✓ 盖上衣服、睡袋、应急保温毯,戴上帽子
✓ 湿衣服换掉
✓ 用雨布、树枝搭个遮挡,挡风挡雨挡太阳

防休克:
✓ 让伤员平躺,不要随意移动
✓ 安慰伤员,陪伴说话

喝水和吃东西:
✓ 伤员清醒、能自己吞咽、没有腹部重伤时,小口喝水,吃点东西
❌ 意识不清的不能喂水喂食
❌ 不要给伤员喝酒

体位:
✓ 意识不清但有呼吸的,侧卧位(防止呕吐物堵住气道)
  怀疑脊柱损伤时,翻身要几个人一起保持头颈身体成一条直线
✓ 呼吸困难的(没有脊柱损伤时),可以让他半坐着

定时检查:
✓ 固定过的手脚,检查手指脚趾的颜色、温度、感觉,太紧了放松
✓ 包扎过的伤口有没有继续渗血
✓ 按伤情记录定时记下意识、呼吸、脉搏
```

失温的处理见[涉水、山洪与野外失温-不只是冬天: 野外失温](08-涉水山洪与野外失温.md#不只是冬天-野外失温);休克处理见[基础急救知识-休克处理](../01-日常疾病和伤害/00-基础急救知识.md#休克处理)。

## 就地取材固定

骨折、脱臼、严重扭伤都要先固定再移动。固定的原则: **固定伤处上下两个关节**,固定前后都检查手指脚趾的血液循环。

```
可以当夹板的东西:
- 登山杖、树枝、木板
- 防潮垫(卷起来或折起来,包住受伤的手脚,非常好用)
- 背包的支撑条、硬纸板、卷起来的杂志
- 绑带: 三角巾、绷带、撕成条的衣服、背包带、头巾
  ❌ 不要用细绳、铁丝直接勒在皮肤上

手臂:
✓ 夹板固定后,用三角巾或外套把手臂吊在胸前
✓ 没有三角巾时: 把衣服下摆往上翻,包住手臂,用别针别在胸前

腿:
✓ 夹板放在腿的两侧
✓ 没有夹板时,把伤腿和健康的腿绑在一起,中间垫上衣服

手指、脚趾:
✓ 和旁边的手指(脚趾)用胶布绑在一起,中间垫一点纱布

✓ 夹板和皮肤之间垫上柔软的东西
✓ 绑带避开伤处,绑在伤处的上下方
✓ 固定后检查: 手指脚趾发白、发紫、发凉、麻木 → 太紧了,放松重绑
```

各部位的固定方法见[骨骼损伤-各部位固定方法](../01-日常疾病和伤害/03-骨骼损伤.md#各部位固定方法)。

⚠️ 脱臼、骨折都不要试图自己复位(见[骨骼损伤-复位](../01-日常疾病和伤害/03-骨骼损伤.md#复位))。

## 野外常见小伤病

### 崴脚: 还能不能走

```
以下情况按可能骨折处理(固定,不要自己走):
- 受伤后完全不能用这只脚着地,走不了4步
- 按压脚踝两侧突出的骨头的后缘和尖端,剧烈疼痛
- 脚明显变形

较轻的扭伤,需要走出去时:
1. 先冷敷(冷水、溪水浸湿的毛巾)
2. 用弹力绷带"8"字形包扎脚踝
3. 穿着鞋,鞋带系紧(高帮鞋可以起固定作用)
   - 不要脱鞋: 脚肿起来后可能穿不上
4. 用登山杖或木棍分担重量
5. 同伴分担背包,放慢速度,多休息
```

扭伤的分级和处理见[骨骼损伤-扭伤](../01-日常疾病和伤害/03-骨骼损伤.md#扭伤)。

### 脚上的水泡

```
预防(比处理重要得多):
✓ 穿合脚、已经穿过一段时间的鞋,不要穿新鞋走长路
✓ 穿合适的袜子,保持干燥;袜子湿了换干的
✓ 一感到某处发热、摩擦痛("热点"),马上停下来
  → 贴上胶布或水泡贴,不要等磨出水泡

已经起了水泡:
✓ 小水泡不要刺破,用中间剪个洞的纱布垫或胶布圈围住,减少摩擦
✓ 大而胀痛、影响走路的:
  1. 清洗、消毒
  2. 用消毒过的针从水泡边缘刺破,轻压排出液体
  3. 保留水泡皮(保护下面的嫩肉)
  4. 覆盖敷料,贴胶布固定
✓ 每天检查,出现红肿热痛、流脓 → 感染,尽快就医
```

### 伤口

```
野外伤口最重要的是冲洗:
✓ 用大量干净的水(饮用水、煮过的水)冲洗伤口,冲掉泥沙
  (冲洗比抹药更能预防感染)
✓ 清除看得见的异物
✓ 覆盖干净的敷料,每天检查和更换

❌ 不要自己缝合脏的伤口(会把细菌封在里面)
❌ 不要在伤口上涂泥土、草木灰、牙膏等"偏方"
⚠️ 伤口深、被动物咬伤、被生锈或脏的东西扎伤 → 尽快就医,注意破伤风和狂犬病
⚠️ 红肿扩大、出现红线、发热 → 感染,尽快就医
```

相关章节: [外伤处理-割伤与擦伤](../01-日常疾病和伤害/02-外伤处理.md#割伤与擦伤)、[外伤处理-破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防)。

### 腹泻、呕吐

```
✓ 野外最大的危险是脱水: 小口多次补充口服补液盐
✓ 只喝煮沸或净化过的水
✓ 严重腹泻、呕吐不止、发热、便血时,停止行程,尽快就医
```

相关章节: [常见疾病-腹泻](../01-日常疾病和伤害/01-常见疾病.md#腹泻)、[基础生存技能-水源获取与净化](00-基础生存技能.md#水源获取与净化)。

### 高原反应、中暑、失温

这三种在野外都可能危及生命,最重要的处理都是**及时停止、及时撤离**: 高原反应加重时下撤,中暑时降温,失温时保暖。

相关章节: [山地求生-高原反应](05-山地求生.md#高原反应)、[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑)、[急性症状-失温症](../01-日常疾病和伤害/05-急性症状.md#失温症)。

## 搬运伤员

**在山路上搬运伤员极其费力**: 用担架抬一个人通常需要6个人以上轮换,速度很慢,还可能摔倒造成二次伤害。所以除非必须离开危险的地方,或者救援确实无法到达,**一般原地等待专业救援**。

```
能走但需要帮助:
✓ 一人或两人在两侧扶着走
✓ 同伴背走伤员的背包

不能走、伤势不重(没有脊柱、大腿骨折):
✓ 背负: 一人背,其他人轮换
✓ 双人座椅式: 两人双手交叉握成"座椅",伤员坐在上面搂住两人肩膀
✓ 背包背负: 把空背包的两条肩带套在伤员的两条大腿上,
  救援者背上背包,伤员像坐在背包上一样被背着

需要担架:
✓ 两根结实的木棍或登山杖 + 毯子、睡袋或几件拉好拉链的外套
✓ 伤员绑好固定在担架上,防止滑落
✓ 上坡时头在前,下坡时脚在前(保持头部比脚高)
✓ 抬的人步调一致,轮流替换,不要累到摔倒

⚠️ 怀疑脊柱损伤: 除非现场有生命危险(落石、火、水),绝对不要移动,等待专业救援
```

搬运方法和简易担架的做法见[基础急救知识-搬运伤员](../01-日常疾病和伤害/00-基础急救知识.md#搬运伤员)。

## 直升机救援

```
✓ 救援人员会告诉你需要做什么,听从指挥
✓ 找一块尽量平坦开阔的地方,清除周围的帐篷、雨布、衣物等轻的东西
  (旋翼的大风会把它们卷起来)
✓ 用鲜艳的衣物或者人站在开阔地挥手示意;夜间用手电
✓ 直升机靠近时,背对风向,蹲下,保护眼睛
❌ 没有救援人员示意时,不要靠近直升机
❌ 绝不要走到直升机尾部(尾桨非常危险)
❌ 不要从高处一侧靠近(山坡上方离旋翼更近)
```

## 户外急救包

```
伤口:
- [ ] 创可贴、纱布块、医用胶布
- [ ] 弹力绷带(扭伤包扎)、三角巾
- [ ] 碘伏棉签或小瓶碘伏
- [ ] 水泡贴

固定:
- [ ] 卷式夹板(没有时用防潮垫代替)
- [ ] 别针几个

药品(按个人情况,注意有效期):
- [ ] 止痛退烧药
- [ ] 口服补液盐
- [ ] 抗过敏药
- [ ] 个人常用药(降压药、哮喘喷雾、过敏严重者的肾上腺素笔),多带几天的量

其他:
- [ ] 应急保温毯
- [ ] 一次性手套
- [ ] 小剪刀、镊子(也用来取蜱虫)
- [ ] 笔和小本子(写伤情记录)
- [ ] 头灯

✓ 出发前检查一遍,用过的及时补充
✓ 学会用里面的每一样东西
```

---

## 📝 要点

```
1. 野外救援要几个小时到几天,同伴就是伤员唯一的照顾者
2. 先保证自身安全,再处理危及生命的问题,尽早求救
3. 怀疑脊柱损伤、大腿骨折、意识不清、休克 → 原地等待救援
4. 去求援的人最好两人同行,留一人陪伤员,带上伤情记录
5. 伤员身下要隔开地面,保暖和处理伤口一样重要
6. 防潮垫、登山杖都能当夹板,固定伤处上下两个关节
7. 崴脚后走不了4步、按压踝骨剧痛 → 按骨折处理
8. 水泡重在预防: 一感到"热点"就停下贴胶布
9. 伤口用大量干净的水冲洗,不要缝合脏伤口
10. 山路搬运极其困难,一般等待专业救援
```
