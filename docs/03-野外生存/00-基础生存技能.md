## 生存优先级

普通人在野外遇险,绝大多数是迷路、天黑、受伤、天气变坏,通常在一两天内就能获救。本章的技能首先是为了**撑到救援到来**,其次才是长期在野外生活。出发前的准备、迷路后怎样报警,见[户外出行准备与求救](07-户外出行准备与求救.md)。

### 3-3-3法则

```
3分钟 - 没有空气
3小时 - 极端环境无庇护所
3天   - 没有水
3周   - 没有食物
```

这是一个帮助记忆**先做什么**的数量级规则,不是精确的生存时间:

| 威胁 | 大致时间 | 实际含义 |
|------|---------|---------|
| 呼吸、大出血 | 几分钟 | 气道堵塞、溺水、喷射性大出血要立即处理,其他事都往后放 |
| 寒冷或酷热 | 几小时 | 风雨中湿透、夜间低温、烈日暴晒,几小时内就可能失温或中暑 |
| 缺水 | 约3天 | 气温适中、休息时;炎热环境、大量出汗时可能只有1-2天 |
| 缺食物 | 约3周以上 | 有水时健康成人能撑数周,但几天后体力、判断力就会明显下降 |

### 3-3-3法则的局限

```
⚠️ 不要把这些数字当成"还有多少时间":
- 大出血、严重过敏、冷水落水可以在几分钟内致命
  (冷水落水的"1-10-1"原则见涉水山洪与野外失温)
- "3小时"在气温10°C左右、下雨刮风、衣服湿透时同样成立,不只是冬天
- 沙漠里40°C以上又在走路时,没有水可能不到一天就出现严重脱水
- 儿童、老人、孕妇、慢性病人(尤其糖尿病)对寒冷、炎热、缺水、
  缺食物都更敏感,时间要打折扣
- 这些时间是"活下来"的极限,不是"还能正常行动"的时间:
  脱水、寒冷和饥饿会先让人判断失误、摔倒受伤,这才是更常见的死因
```

失温的识别和处理见[涉水、山洪与野外失温-不只是冬天: 野外失温](08-涉水山洪与野外失温.md#不只是冬天-野外失温),中暑见[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑)。

### 生存任务优先顺序

```
0. 确保安全、求救
   - 先离开眼前的危险(落石、涨水、火、急流)
   - 有手机信号就立即报警(110/119),说清位置,然后留在原地
1. 急救(处理伤病)
   - 先止血、保持呼吸道通畅,再处理骨折、伤口
2. 庇护所(体温调节)
   - 寒冷、下雨时: 穿上所有衣服、离开湿冷地面、挡风
   - 炎热时: 进阴凉处,白天少活动
3. 水(生存必需)
4. 火(取暖、煮食、信号)
   - 有庇护所和足够衣物时,火不是必需;生火消耗体力也有引发林火的危险
5. 食物(能量补充)
   - 等待救援的几天里,食物几乎不影响生死
6. 信号/导航(获救/回家)
   - 准备好随时能发出的信号;没有把握时不要自己乱走
```

**记住**:人可以数周不吃饭,但只能数天不喝水!

实际顺序要看情况调整: 天黑前一两小时,优先准备过夜(保暖、隔地);天气晴好、体力充足时,先布置好求救信号。野外受伤后原地等待还是自行撤出,见[野外伤病处置与转运-原地等待还是自行撤出](11-野外伤病处置与转运.md#原地等待还是自行撤出)。

### 稳住情绪和节省体力

```
慌乱是野外最常见的"第二个错误": 迷路后加速乱走、天黑后摸黑赶路、
为抄近道下陡坡、冒险涉水,往往比最初的处境更危险。

✓ 停下来,坐下,喝几口水,吃点东西,做几次缓慢的深呼吸
✓ 把要做的事列出来(写在纸上或说出来),一件一件做
✓ 同伴之间分工,不要所有人都去干同一件事
✓ 量力而行: 出汗湿透衣服在寒冷天气里非常危险,干活时脱掉一层,休息时再穿上
✓ 天黑前停止移动,把剩下的光用来准备过夜
✓ 照顾好队伍中最弱的人(孩子、老人、受伤者),整队的速度由他们决定
```

长期压力下的心理调适见[心理健康-长期压力下照顾好自己](../01-日常疾病和伤害/10-心理健康.md#长期压力下照顾好自己)。

## 导航与定向

知道"哪边是北"只有在你大致知道自己在哪里、要去的地方在哪个方向时才有用。能找到原路、有手机定位、或者确定附近有公路时才考虑自己走;否则先报警、原地等待(见下方[如果迷路](#如果迷路))。

各种方法的可靠程度:

| 方法 | 可靠程度 | 主要误差来源 |
|------|---------|------------|
| 手机地图定位 | 高(有电时) | 没电;定位不需要信号,但要提前下载离线地图 |
| 指南针 | 高 | 靠近铁器、手机;磁偏角(我国约2°-11°) |
| 北极星 | 高(晴夜) | 偏离正北不到1° |
| 立杆测影 | 中-高 | 等待时间太短、地面不平 |
| 手表法 | 中 | 用北京时间而不是当地太阳时;低纬度夏季正午附近误差很大 |
| 太阳大致方位 | 低-中 | 日出日落的方向随季节变化很大 |
| 树冠、年轮、苔藓 | **低** | 林中几乎无用,不要依靠 |

### 使用指南针

```
基础使用:
1. 水平放置
   - 托在胸前,保持表盘水平,否则磁针会卡住
2. 让磁针自由转动
   - 远离手机、刀具、铁栏杆、汽车、高压线至少约1 m,否则会指错
3. 红针指向北(通常)
   - 有的指南针用白色、夜光或标"N"的一端指北,用之前先对照太阳确认
   - 指的是"磁北",和真北差几度(磁偏角),徒步时一般可以忽略
4. 转动表盘对准方向
   - 把表盘的"N"转到和红针重合,读出要走的方向的度数(方位角),记下来
5. 沿方向前进
   - 沿这个方向看出去,选一个远处容易认的目标(一棵特别的树、一块大石),
     走到那里再选下一个目标,不要边走边低头看指南针

检查:
✓ 走一段后回头看,来路上的目标应该在正后方(方位角相差180°)
✗ 凭感觉走: 在林中、雾中、雪地里几乎一定会绕圈子
```

地图和指南针配合使用见[户外出行准备与求救-用地图和指南针](07-户外出行准备与求救.md#用地图和指南针);磁偏角的测定和修正见[天文导航进阶-磁偏角](../09-进阶科学与工程/09-天文导航进阶.md#24-磁偏角)。

**简易指南针**: 缝衣针在丝绸或头发上沿同一方向摩擦几十次(或用磁铁沿同一方向擦),放在漂在水面的树叶或软木片上,静止后两端指南北。哪一端是北要用太阳确认。

### 无指南针辨方向

#### 太阳法

**太阳的大致方位**(我国大部分地区):
```
- 当地正午(不一定是北京时间12点): 太阳在正南,影子指向正北
- 早上在东边、傍晚在西边,但只有春分、秋分前后才是正东、正西
  - 夏季: 日出在东北、日落在西北
  - 冬季: 日出在东南、日落在西南
- 太阳每小时移动约15°,用太阳定向时每隔半小时重新确认一次
⚠️ 北回归线(约北纬23.5°,广州、南宁附近)以南,夏季正午太阳可能在头顶或偏北
```

**手表法**(北半球):
```
1. 手表平放
2. 时针指向太阳
3. 时针与12点刻度夹角平分线指向南
4. 取时针与12点之间较小的那个夹角
   (适用于早上6点到傍晚6点之间)

⚠️ 要用当地太阳时,不能直接用北京时间:
- 北京时间按东经120°计算,往西每15°,当地正午就比北京时间12点晚约1小时
  - 成都、昆明一带: 当地正午约在北京时间13点
  - 乌鲁木齐一带: 约在北京时间14点
- 做法: 先把北京时间减去这个差值,再用手表法
- 在纬度低的地方、夏季正午前后,这个方法误差可达几十度,只作粗略参考
数字表: 在地上画一个表盘,按当前时间画出时针再用

南半球: 把12点刻度对准太阳,12点与时针夹角的平分线指向北
```

**影子法**:
```
1. 直立木棍
   - 约1 m长,插在平地上,尽量垂直
2. 标记影子顶端(A点)
3. 等待15-20分钟
4. 再次标记影子顶端(B点)
5. 连线A-B,指向东
   (先标的A点在西,后标的B点在东)
6. 垂直线指向北
   (站在A点和B点之间,左脚踩A、右脚踩B,面对的就是北)

原理:太阳东升西落,影子朝相反方向移动

✓ 在上午或下午用比正午附近更好(正午前后影子移动慢,看不清)
✓ 等得越久越准;要精确定正南北,用天文导航进阶里的"立杆测影"
✗ 阴天影子模糊时不能用
```

精确的立杆测影见[天文导航进阶-立杆测影定正南北](../09-进阶科学与工程/09-天文导航进阶.md#23-立杆测影定正南北精确方法)。

#### 星星法(夜晚)

**北极星**(北半球):
```
找法:
1. 找到北斗七星(勺子形)
2. 勺口两颗星连线
3. 延长约5倍
4. 就是北极星
5. 北极星方向=正北

补充:
- 北斗七星被山或地平线挡住时: 找仙后座(W形),它和北斗七星
  隔着北极星相对,W开口一侧大致朝向北极星
- 北极星不是很亮的星,但它周围没有更亮的星,容易认
- 北极星离地平线的高度角 ≈ 当地纬度(我国约20°-50°)
- 北斗七星整夜绕北极星转动,勺口的两颗星始终指向北极星
```

**猎户座**(冬季和春季夜晚):
```
猎户座腰带上排成一条直线的三颗亮星,最右边(西边)那颗从正东升起、
在正西落下 → 刚升起或快落下时,可以用来确定东、西
```

**南十字星**(南半球):
```
1. 找到南十字星
2. 十字长轴延长约4.5倍
3. 垂直到地平线
4. 就是正南方向

注意: 南十字星旁边有一个更大、更暗的"假十字",假十字没有两颗明亮的指极星
```

更多天文定向、测纬度的方法见[天文导航进阶](../09-进阶科学与工程/09-天文导航进阶.md#二精确定方向)。

#### 自然标志

**树木**:
```
北半球:
- 树冠: 南侧茂密
- 树桩年轮: 南侧宽
- 苔藓: 北侧多
```

⚠️ 这些方法**不可靠**: 树冠朝空隙和坡外长,年轮宽窄主要由坡度、风向和相邻树木决定,苔藓长在任何潮湿背阴的地方。在林中几乎没有用,不要根据一棵树、一块苔藓决定前进方向。原因见[森林求生-树冠、年轮、苔藓为什么靠不住](02-森林求生.md#树冠年轮苔藓为什么靠不住)。

比较可靠的自然线索:
```
✓ 河流、溪沟: 水往低处流,大河两岸常有道路和村庄
  (但不要沿陡峭的溪谷往下走,见下方"如果迷路")
✓ 电线、通信塔、梯田、砍伐痕迹、垃圾、牲畜粪便: 说明附近有人活动
✓ 狗叫、鸡鸣、汽车声、伐木声: 在安静的清晨和傍晚传得很远
✓ 从高处观察: 爬到附近视野开阔的山脊或山顶(不要冒险攀爬),看清地形和人烟
```

### 估计距离和时间

```
步测(提前在平路上测好自己的步长):
- 一个"复步"(同一只脚落地两次)成人一般约1.3-1.6 m
- 平路上100 m大约65-75个复步;上坡、林地、雪地步子变短
- 每走100 m在绳上打一个结或捡一颗石子,记录走了多远

时间:
- 好走的山路约4 km/h,每爬升约500-600 m多算1小时左右
- 没有路的林地、灌丛、乱石坡可能只有1 km/h甚至更慢
- 下坡省力但更容易摔伤,速度不要比上坡快太多
- 算一下离天黑还有多久: 手臂伸直,手掌横放,一个手掌(四指并拢)
  从太阳下沿到地平线约相当于1小时(只是粗略估计)
```

### 避免迷路

```
✓ 经常回头看(记住来时的样子)
  - 回程时看到的景色和去程完全不同,每到岔路口转身看一眼、拍张照
✓ 做标记(布条、石堆)
  - 在岔路口和转弯处做,标记要能从两个方向看到
  - 用后尽量拆除,不要刻划树皮
✓ 保持直线(选定远处目标前进)
✓ 记录路线(地标、方向、时间)
  - 手机开启轨迹记录,迷路时可以沿轨迹原路返回
✓ 不要离开水源太远
✓ 定好掉头时间: 到点没到目的地也要往回走
```

行程单、掉头时间和装备见[户外出行准备与求救](07-户外出行准备与求救.md#出发前)。

### 如果迷路

```
STOP原则:
S - Stop:停下,不要慌
T - Think:思考你的位置
O - Observe:观察周围环境
P - Plan:制定计划

原则:
✓ 留在原地(更易被找到)
✓ 发出信号
✓ 找水源
✓ 建庇护所
✓ 等待救援

具体:
1. 停下: 越走越远、越走越累是迷路后最常见的错误
2. 想: 最后一次确定位置是什么时候、之后大约走了多久、往哪个方向
3. 看: 手机有没有信号、能不能定位;附近有没有路、人工痕迹、高处
4. 计划:
   - 能确定原路且安全 → 沿原路返回
   - 不能确定 → 报警,原地等待,准备过夜
   - 天快黑 → 不再移动,用剩下的光准备庇护所和保暖

❌ 不要沿着溪沟、峡谷往下走: 山里的溪谷常有瀑布、悬崖,还可能遇到山洪,
   往往越走越陡,最后上下不得
❌ 不要摸黑走路: 夜间跌落是迷路者最常见的伤亡原因之一
✓ 如果决定移动,在原地留下标记和字条(写明时间、去向),沿途做标记
```

怎样报警、怎样说清自己的位置见[户外出行准备与求救](07-户外出行准备与求救.md#报警求救-说清楚你在哪里)。

## 水源获取与净化

### 每天需要多少水

```
每人每天饮水(只算喝的):
- 气温适中、休息: 约2 L
- 炎热或徒步、干活: 4-6 L,甚至更多
- 寒冷天气也会因呼吸、出汗失水,只是不容易感到渴

判断是否缺水(看尿):
✓ 淡黄色、量正常 → 基本够
⚠️ 深黄色、量少 → 缺水,要多喝
☠️ 半天以上没有尿、头晕、意识模糊 → 严重脱水,尽快求救
   婴幼儿6小时以上没有尿要立即就医

原则:
✓ 有水时不要刻意"省着喝": 水存在身体里比存在瓶子里有用,
  该喝就喝;要省的是出汗(白天躲阴凉、少活动)
✓ 水很少时少吃东西,尤其少吃肉和盐(消化要消耗水)
❌ 不喝海水、尿、酒
```

脱水的分级和口服补液见[常见疾病-腹泻](../01-日常疾病和伤害/01-常见疾病.md#腹泻);沙漠中保存体液见[沙漠求生-配给水](03-沙漠求生.md#配给水)。

### 寻找水源

**地形线索**:
```
✓ 山谷、低洼处
  - 地图上等高线V字尖端指向高处的地方是沟谷,常有水
✓ 植被茂盛区
  - 芦苇、香蒲、柳树、竹林、蕨类成片生长的地方,地下常有水
✓ 动物踪迹汇聚处
  - 多条兽径往低处汇合
✓ 昆虫飞行方向(傍晚)
✓ 鸟类飞行(早晚飞向水源)
✓ 山脚、岩壁底部的渗水和泉眼
✓ 干河床: 在河道外弯处、最低处往下挖,湿沙下可能渗出水

优先级(从好到差):
1. 泉眼、山上流下的清澈溪流(上游没有村庄、牧场、矿山)
2. 雨水
3. 流动的河水
4. 湖泊、池塘的水
5. 积水坑、死水(最后手段)
→ 任何地表水都要净化后再喝,看起来清澈不等于干净
```

**冰雪**:
```
✓ 化了再喝: 直接吃雪消耗大量体热,还会冻伤口腔
✓ 用冰比用雪省燃料(同样体积出水多)
✓ 化雪时锅底先放一点水,否则锅会烧干烧糊
✓ 冰雪化的水同样要煮沸或消毒
```

融雪的具体方法见[雪地极地求生-融雪](04-雪地极地求生.md#融雪)。

### 收集雨水

```
方法:
✓ 干净容器接水
✓ 塑料布收集(中间低洼)
  - 四角系在树上,一角略低,下面放容器;1 m²的塑料布下1 mm雨就能接约1 L
✓ 大叶子引流
✓ 挖坑铺塑料布
✓ 在树干上绑一圈布条,下端垂进容器,能引下顺树干流的雨水

最安全的水源!

注意:
- 刚下雨的头几分钟冲下来的是灰尘、鸟粪,先不要接
- 从屋顶、岩石上引下的雨水最好也消毒后再喝
- 准备好容器,雨来了再找就晚了
```

### 露水收集

```
清晨:
1. 用吸水布料擦草
   - 把布绑在小腿上,在草地里来回走,效果更好
2. 拧到容器里
3. 重复

露水很重时每小时可能收集数百 mL,多数情况更少
要在日出前尽快收集(露水很快蒸发)
避开喷过农药的田地、路边的草
```

### 植物取水

**蒸腾水收集**:
```
1. 选择绿叶茂盛植物
2. 套透明塑料袋在枝叶上
3. 袋口扎紧
4. 袋内角落放小石子(让水聚集)
5. 数小时后收集

注意:
- 选择无毒植物
  - 不认识的、汁液是白色乳汁的、夹竹桃等有毒植物不要用
- 不要选枯叶
- 产量: 晴天一个袋子一天约几十到几百 mL,多套几个袋子
- 袋子放在向阳处,每隔几小时换一枝,同一枝会被"抽干"
- 水可能有一点植物味,一般可以直接喝;不放心时煮沸
```

**竹子取水**:
```
1. 绿竹节间有水
2. 摇晃听水声
3. 顶部开口
4. 倒出饮用

- 水应该清澈、无异味;发黄、浑浊、发臭的不要喝
- 也可以把竹梢弯下来绑住,割掉顶端,下面放容器,一夜能接一些水
```

**藤本植物**:
```
- 粗的藤先在高处砍一刀,再在低处砍断,水会从下端流出
- 清澈、没有味道的可以喝;乳白色、有颜色、苦涩、黏稠的不要喝
- 不认识的藤不要冒险
```

### 太阳能蒸馏器(最后手段)

⚠️ 实测效果很差: 野外实测通常每天只有几十到几百 mL,挖坑时出的汗往往比收集到的水还多。只在有现成塑料布、不需大量挖掘、其他水源都不可得时考虑。

优先选择几乎不耗体力的方法: 收集雨水、塑料布集水、植物蒸腾袋。

```
制作:
1. 挖坑(直径约1 m,深50 cm)
2. 坑底中央放容器
3. 坑内可放植物(增加水分)
4. 坑上铺塑料布
5. 边缘用土压实
6. 中央放小石子(使塑料布下凹)
7. 凝结水滴入容器

产水: 实测通常每天几十到几百 mL(取决于土壤湿度和日照)
✓ 可以往坑里倒尿、脏水、海水来增加水分(收集到的是蒸馏水)
✓ 不要在白天最热时挖,在清晨或傍晚动手
```

### 水质净化

不干净的水可能带有细菌、病毒、寄生虫(如贾第鞭毛虫、隐孢子虫),喝了以后腹泻会让脱水更严重。**浑水要先沉淀、过滤,再消毒**: 泥沙会挡住紫外线、消耗消毒剂。

```
先处理浑水:
1. 沉淀: 在容器里静置几小时,取上面较清的水
2. 粗滤: 用布(衣服、头巾、袜子)折几层,把水倒过去
3. 再用下面任一种方法消毒
```

#### 煮沸(最可靠)

```
方法:
- 沸腾至少1分钟
- 高海拔(>2000 m):3分钟
- 杀死所有病原体
  (细菌、病毒、寄生虫都能杀死;但去不掉农药、重金属、燃油等化学物质)

要点:
✓ 要看到持续翻滚的大气泡,锅底冒小泡还不算沸腾
✓ 盖上锅盖,省燃料也防止落入灰土
✓ 煮好后放凉,装进干净容器;不要用脏手、脏杯子再碰
✓ 没有锅: 用金属罐头盒、竹筒,或用烧热的石头放进水里(见下方容器)
✓ 喝起来"没味道"可以在两个容器之间来回倒几次,让水溶进空气
```

#### 过滤

```
自制过滤器:
材料:瓶子/竹筒

层次(从下到上):
1. 小石子
2. 粗沙
3. 细沙
4. 木炭(烧过的,碾碎)
5. 布料

使用:
- 水从上倒入
- 下方收集
- 去除颗粒和部分杂质
- 仍需煮沸!

做法:
1. 塑料瓶剪掉瓶底,倒过来挂起,瓶口塞一团布或草防止沙子漏出
2. 沙子、木炭先用清水冲洗,冲到流出的水比较清
3. 每层厚约5-10 cm,细沙层越厚效果越好
4. 刚做好时流出的水先倒掉一些
5. 木炭能去掉一部分异味和颜色,不能杀菌

市售户外滤水器:
- 孔径0.1-0.2 μm的中空纤维滤水器能滤掉细菌和寄生虫,但滤不掉病毒
  → 在有人畜粪便污染的地方(村庄下游、牧场),滤过后仍要消毒
- 中空纤维滤芯冻过以后可能损坏而看不出来,冬天贴身放
```

长期使用的慢砂过滤池见[水源工程与供水-净化](../07-日常生活技能/10-水源工程与供水.md#净化-从浑水到可以喝的水)。

#### 化学消毒

```
碘片/氯片:
- 按说明使用
- 等待30分钟
- 杀死大部分病原体

漂白剂(次氯酸钠):
- 2滴/升清水
- 4滴/升浑水
- 摇匀,等30分钟

要点:
✓ 漂白剂用不加香味、不加洗涤剂的,按有效氯约5%计算;
  浓度不同的产品按说明书换算
✓ 消毒后应有淡淡的氯味;完全没有氯味,再加同样的量,再等30分钟
✓ 水温低于约5°C时,等待时间加倍
✓ 把瓶口螺纹、瓶盖也用消毒过的水冲一下
✗ 氯和碘对隐孢子虫几乎无效;二氧化氯片可以杀灭,但要按说明书等更长时间
  (通常约4小时)
✗ 碘消毒的水: 孕妇、甲状腺病人、对碘过敏的人不要喝,其他人也只宜短期使用
  (几周以内)
✗ 化学消毒去不掉农药、重金属、燃油
```

#### 紫外线消毒

```
条件:
- 清澈的水
- 透明塑料瓶
- 强烈阳光

方法:
1. 装入透明瓶
2. 阳光直射6小时
3. 或2天阴天
4. 杀死部分病原体

要点(太阳能消毒法):
✓ 用2 L以下、无色透明、没有划花的塑料瓶(PET瓶,即一般饮料瓶)
✓ 判断够不够清: 隔着装满水的瓶子,能看清下面报纸上的大字标题
  不够清就先沉淀、过滤
✓ 装满3/4后盖上摇30秒,再装满
✓ 平放在铁皮屋顶、石板或深色地面上,不要被遮挡
✓ "2天阴天"指一半以上天空有云时连续晒2天;一直下雨的天气不能用,
  改用煮沸或化学消毒
✓ 晒好的水直接从瓶里喝,不要倒进不干净的容器
✗ 玻璃瓶会挡掉大部分紫外线,效果差
✗ 不能去除化学物质
```

#### 蒸馏

蒸馏是野外唯一能把**海水、苦咸水**变成淡水的办法,也能去掉泥沙、病原体和大部分盐类、重金属,但非常费燃料。

```
简易做法:
1. 锅里装海水(或脏水),架在火上
2. 锅盖倒扣(盖顶朝下),让凝结的水顺着盖子流到中间滴下
3. 锅里水面上方吊一个小杯子接水滴
   - 或者在锅盖上放雪、冷水,让蒸汽更快凝结
另一种: 壶嘴接一根管子(金属管、竹管),管子用湿布包住降温,
        另一端放容器接水
最简单: 在锅口上方蒙一块干净布,吸满蒸汽后拧出来

产量: 烧一锅水往往只能得到几百 mL,要准备大量燃料
⚠️ 汽油、柴油、部分农药等挥发性的物质会和水一起蒸出来,
   被燃油、化学品污染的水蒸馏也不安全
```

海岛上取淡水的其他方法见[荒岛求生-海岛取水](01-荒岛求生.md#海岛取水)。

#### 各种方法比较

| 方法 | 细菌 | 病毒 | 寄生虫(含隐孢子虫) | 化学物质、盐 | 主要限制 |
|------|------|------|-----------------|------------|---------|
| 煮沸 | ✓ | ✓ | ✓ | ✗ | 需要燃料和锅 |
| 户外滤水器 | ✓ | ✗ | ✓ | ✗ | 怕冻、会堵 |
| 自制沙炭过滤 | 部分 | ✗ | 部分 | ✗ | 只能做预处理 |
| 氯、碘 | ✓ | ✓ | 部分(对隐孢子虫几乎无效) | ✗ | 浑水、低温效果差 |
| 二氧化氯 | ✓ | ✓ | ✓(要等较久) | ✗ | 等待时间长 |
| 太阳能消毒 | ✓ | 大部分 | 大部分 | ✗ | 要清水和强烈阳光 |
| 蒸馏 | ✓ | ✓ | ✓ | 大部分(挥发性除外) | 极费燃料、产量小 |

### 不能喝的水

```
❌ 避免:
- 死水、臭水
- 颜色异常(黄、红、黑)
- 有泡沫
- 有毒植物附近
- 海水(高盐)
- 尿液(浓缩毒素)
- 血液
- 水边有死鱼、死动物,或周围寸草不生
- 矿山、工厂、农田排水沟下游(农药、重金属,煮沸也去不掉)
- 表面有油膜、彩色反光
- 酒(加速脱水和失温)
```

被化学品污染的水的处理原则见[水源工程与供水-不能用一般方法处理的水](../07-日常生活技能/10-水源工程与供水.md#不能用一般方法处理的水)。喝了不干净的水后腹泻,见[野外伤病处置与转运-腹泻、呕吐](11-野外伤病处置与转运.md#腹泻呕吐)。

## 生火技术

火能取暖、烘干衣物、煮水消毒、做信号,还能让人安心。但在野外,火也是**引发森林火灾的首要原因之一**。

```
⚠️ 用火的法律和安全底线:
- 我国林区、草原在防火期内严禁野外用火,很多景区、保护区全年禁火
  平时只在允许的地方用火;只有真正危及生命时才在禁火区生火
- 大风天(树梢明显摇动)、天气长期干旱时,不要生明火
- 火堆旁始终有人看守,离开或睡觉前彻底熄灭
- 不要在帐篷、雪洞、密闭的庇护所里生火或烧炭: 会一氧化碳中毒
```

一氧化碳中毒的识别和处理见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒);发现林火、被林火围困见[火灾-森林火灾](../02-灾难应对/04-火灾.md#森林火灾)。

### 火的三要素

```
燃料 + 氧气 + 热量 = 火

缺一不可!

生火时: 三样都要给足
- 燃料: 从细到粗,够干
- 氧气: 柴之间留空隙,不要压实;火小时轻轻吹,对着火的根部吹
- 热量: 小火先把细柴烤热烤干,粗柴才能点着;一下子加太多柴会把火"压死"

灭火时: 去掉其中一样
- 浇水(去掉热量)、盖土(去掉氧气)、把柴拨开(去掉燃料)
```

### 选火堆位置与安全

```
✓ 平坦、避风、地面是泥土、沙子或石头的地方
✓ 清出直径约3 m的空地,扫开枯叶、干草,露出泥土
✓ 离庇护所、帐篷、树木至少约3 m;头顶不能有低垂的树枝
✓ 火堆周围可以用石头围一圈(只用干燥的石头)
✓ 手边准备一桶水或一堆土

❌ 不要在:
- 枯草、落叶厚的地方,泥炭地、腐殖层厚的林地(火会在地下阴燃,几天后复燃)
- 树根上、大树干旁、倒木旁
- 从河里、水边捡的石头围火(内部含水,受热可能炸裂飞溅)
```

### 熄火

```
1. 提前停止加柴,让火烧成灰
2. 浇水,浇到没有嘶嘶声
3. 用棍子搅拌灰和炭,把底下的翻上来
4. 再浇水,再搅拌
5. 手背靠近灰堆(不要直接碰)感觉不到热,才算熄灭
没有水时: 用沙土覆盖、搅拌,反复几次,同样要确认完全冷却
❌ 只盖一层土就走: 下面的炭可以闷烧很久,然后复燃
```

### 准备材料

**生火前把三种材料都准备好,数量是你以为够的两倍。** 火苗起来后再去找柴,火往往已经灭了。

**火绒**(最易燃):
```
- 干燥细纤维
- 蒲公英绒、芦苇绒
- 干草、树叶
- 桦树皮
- 棉絮、纸张
- 钢丝绒

要点:
- 要能被火花或很小的火焰点着,拿起来一大把(约一个拳头大),
  揉松成鸟窝状,中间留个凹
- 桦树皮含油,湿了也能点燃,剥树表面已经翘起的外皮,不要剥活树的整圈树皮
- 干的蒿草、艾叶搓碎(艾绒)是传统火绒
- 自带: 凡士林棉球(棉球蘸凡士林,一个能烧1-2分钟)、炭布(见下方保存火种)
- 钢丝绒用电池两极一碰就能点着
```

**引火材**(细燃料):
```
- 细树枝(铅笔粗细)
- 松针
- 干树枝
- 木片

要点:
- 由细到粗准备: 火柴粗 → 铅笔粗 → 拇指粗,每种一大把
- 折的时候"啪"一声清脆断开的才够干;弯而不断、断面发绿的太湿
- 从站着的枯树、挂在树上的枯枝上取,比地上捡的干得多
- 羽毛棒: 用刀把干木棍表面削成一圈卷曲的薄片,不削断,
  潮湿天气里比细枝更容易点着
```

**燃料**(主燃料):
```
- 手指粗-手腕粗树枝
- 木柴
- 粗树枝

一夜取暖需要的柴比想象的多得多: 天黑前准备一大堆(至少齐腰高的一堆)
粗木头不用砍断,可以一头放进火里,烧短了再往里推
```

**选择木材**:
```
✓ 干燥木材
✓ 硬木烧得久
✓ 软木易点燃
✓ 松树含树脂(助燃)

❌ 避免:
- 湿木(冒烟不燃烧)
- 绿木(难燃)
- 腐烂木(不好)
- 夹竹桃、漆树等有毒植物(烟会刺激眼睛、皮肤和肺)
- 塑料、橡胶(有毒烟雾,只在需要黑烟做信号时用)
```

木柴的热值和干燥见[薪柴与林地管理-柴要干](../04-动植物培育/09-薪柴与林地管理.md#柴要干)。

### 生火方法

#### 现代方法

**打火机/火柴**:
- 最简单
- 保持干燥
- 防风
- 打火机在低温下打不着: 冬天贴身放,用前握在手里捂热
- 火柴放在密封袋或小瓶里;可以用蜡浸过火柴头防水
- 点火时背对风,用身体和手挡风,火柴头朝下倾斜让火焰往上烧火柴杆
- 一根火柴只点一次: 先把火绒和引火材全部摆好再划

**打火石**(镁棒):
```
1. 刮镁棒屑到火绒上
2. 用刮铁快速刮打火石
3. 产生火花
4. 点燃镁屑和火绒
5. 添加引火材

技巧:
- 刮片紧贴火绒不动,把镁棒往后拉,而不是用刮片往前推
  (往前推容易把火绒堆打散)
- 火花要落在最细、最干的火绒上;粗火绒要先揉碎揉松
- 湿手、寒冷时也能用,是最可靠的备用火源
```

**火镰**(传统方法):
```
用高碳钢片(旧锉刀、钢制刀背)斜擦燧石、石英等硬石的锐边,
打出的火星落在炭布、艾绒或干燥的木蹄层孔菌(火绒菌)上,
先变成一个暗红的火点,再包进干草里吹成火
普通火绒接不住火星,一定要用炭布这类能"接住火星"的材料
```

#### 原始方法

摩擦生火在干燥气候、有合适木材、事先练习过的情况下才有把握。**潮湿天气、没有练习过,成功率很低,还很消耗体力**。出门带打火机和镁棒,比学会钻木取火重要得多。

**弓钻法**:
```
工具:
- 弓(弯曲树枝+绳)
- 钻轴(硬木,筷子粗细,削尖一头)
- 钻板(软木,平板)
- 手座(木块,手握)
- 火绒

步骤:
1. 钻板上刻V型缺口
2. 缺口下放火绒
3. 钻轴绕弓弦一圈
4. 钻轴尖端放钻板凹槽
5. 手座压住钻轴顶部
6. 快速拉弓(钻轴旋转)
7. 摩擦生热
8. 产生烟和炭粉
9. 炭粉掉入火绒
10. 轻轻吹,产生火苗

要点:
- 木材: 钻轴和钻板都用干燥、不太硬、不含油的木头效果最好,
  常用椴、杨、柳、杉等;钻轴约20-30 cm长、拇指粗
- 先在钻板上钻出一个浅坑,再在坑边刻V形缺口,缺口约占圆坑的1/8,
  一直刻到圆坑中心
- 缺口下面垫一片树皮或木片接住炭粉,而不是直接放火绒
- 手座的凹坑里放一点树叶、油脂润滑,让上端不发热
- 钻出黑色炭粉、不拉弓也持续冒烟时,才算有了"火种",
  小心连木片一起移到火绒窝里,包起来轻轻吹
```

**手钻法**:
```
类似弓钻,但用手搓:
- 更费力
- 需要练习
- 钻杆要长而直(约60 cm),常用干燥的植物茎秆
- 双手合掌从上往下搓,搓到底时快速回到顶部继续,不能停顿太久
```

**火犁法**:
```
1. 一块木板刻槽
2. 另一根木棍
3. 快速在槽里推拉摩擦
4. 产生炭粉
5. 引燃火绒

- 在热带比较常用,干燥的软木效果好
- 炭粉会堆积在槽的前端,在那里放好接炭粉的木片
```

**透镜聚焦法**:
```
条件:
- 强烈阳光
- 透镜(眼镜、放大镜、冰透镜、水瓶)

方法:
1. 聚焦阳光到火绒上
2. 形成最小亮点
3. 保持不动
4. 开始冒烟
5. 轻吹成火

- 近视眼镜(凹透镜)不行,要老花镜、远视眼镜或放大镜
- 装满清水的透明塑料瓶、透明塑料袋也能聚光,但要反复调整距离
- 火绒用颜色深的(炭布、烧过的木头末)更容易点着
- 只能在晴天中午前后用
```

### 火堆结构

**锥形**(快速生火):
```
- 火绒中央
- 引火材围成锥形
- 顶部留通气口
- 点燃火绒
- 逐渐添加粗燃料

- 在迎风一侧留一个小口,从这里点火,风会把火吹进去
- 适合烧水、快速取暖;烧得快,费柴
```

**木屋式**(持久燃烧):
```
- 井字交叉堆叠
- 中心放火绒和引火材
- 通风好,燃烧旺
- 会塌成一层均匀的炭火,适合做饭、烤东西
```

**星形火**(省柴):
```
- 几根粗木头像车轮辐条一样,一头朝向中心摆放
- 在中心生火,烧短了就把木头往中心推
- 火小而持久,适合一个人整夜维持,省柴
```

**平台式**(湿地/雪地):
```
- 底部铺平台(粗木头)
- 隔离湿气
- 上面正常生火
- 雪地上平台要用一层手腕粗以上的木头紧密排列,否则会陷进雪里熄灭
```

**反射墙**(取暖):
```
- 火后方堆石头或木头墙
- 反射热量
- 增强取暖效果

- 木头墙: 两根木桩打进地里,中间横着叠放粗木头,约1 m高
- 人坐在火和庇护所之间,前面烤火、背后的庇护所挡风
- 反射墙离火约0.5-1 m,太近会被点着
```

### 潮湿天气生火

```
1. 找干材料:
   - 站立的枯树、挂在树上的枯枝(比地上的干)
   - 大树、岩石下面背雨一侧的枯枝和干草
   - 把手腕粗的湿木头劈开,里面的木芯常常是干的
   - 松明: 老松树桩、树脂多的松木心,油亮发黄、有松香味,湿了也能点
   - 桦树皮、松脂
2. 削羽毛棒、劈细柴: 表面积越大越容易烧
3. 在地面上先搭平台或铺一层树皮,不要在湿地上直接生火
4. 用身体、雨衣、防水布在上方和迎风面挡雨挡风(留出烟的出口)
5. 火绒、引火材准备平时的两倍以上,火着起来后先烧一阵细柴再加粗柴
6. 把下一批湿柴放在火堆旁烤着(不要太近),烘干后再加进去
7. 平时就在背包里带一小袋干火绒(凡士林棉球、桦树皮)和一截蜡烛
```

森林中湿木生火的更多经验见[森林求生-湿木生火](02-森林求生.md#湿木生火)。

### 生火技巧

```
✓ 准备足够材料(湿了不能停下找材料)
✓ 从小到大逐渐添加
✓ 保持氧气供应(不要压实)
✓ 防风(但不能完全挡风)
✓ 耐心(不要急于添粗燃料)
✓ 火绒点着后,捧在手里或放在地上,从下面轻轻吹,吹到起明火再放进柴堆
✓ 每次加柴不超过当前火焰能"抱住"的量;火苗刚起时只加火柴粗细的
✓ 冒浓烟、火苗变小 → 柴太湿或太密,拨开一点,少加柴、多吹气
```

### 保存火种

```
方法:
- 用灰覆盖炭火(减少氧气)
- 可保持一夜
- 早上拨开灰,添引火材

或:
- 制作火绳(绳子浸树脂)
- 阴燃携带

要点:
- 睡前在火堆里放几根粗硬木(栎、槐等),烧出一层红炭后用灰盖住,
  灰厚约3-5 cm;早上拨开,放上火绒、细柴,吹几下就着
- 携带火种: 在铁罐里放几块红炭,罐壁打几个小孔通气,裹上干苔藓或艾绒,
  用铁丝提着走;每隔一段时间打开看看,快灭时加一点
- 干燥的木蹄层孔菌(火绒菌)、晒干的牛粪点着后能阴燃很久
- 炭布: 纯棉布剪成小块,装进有个小孔的铁罐里,放在火上烧到小孔不再冒烟,
  离火冷却后再打开;得到的黑色布片一个火星就能点着,装在密封罐里保存
```

## 庇护所建造

庇护所的作用是**保住体温**: 挡风、挡雨、隔开冰冷潮湿的地面,炎热时遮阳。身体通过四种途径失去热量,在野外最常被忽视的是**传导**——直接坐卧在冷地面、岩石、雪上,热量流失比在空气中快得多。

```
优先顺序:
1. 穿上所有衣服,换掉湿衣服(棉衣湿了几乎不保暖)
2. 隔地: 坐、躺在厚厚的干材料上
3. 挡风、挡雨
4. 缩小空间、几个人挤在一起
5. 火(有条件时)
```

### 先利用现成的

```
✓ 车辆: 困在车里时一般留在车旁,车比人好找得多
  - 车内取暖开发动机时,每小时开约10分钟,先确认排气管没有被雪堵住,
    车窗留一条缝,防一氧化碳中毒
✓ 岩石凹处、岩檐: 先看上方有没有松动的石头、顶上有没有裂缝,
  里面有没有动物住过的痕迹(粪便、骨头、毛)
✓ 倒木、大石的背风面: 靠着它们搭单坡棚,省一半材料
✓ 茂密的常绿树(松、杉)下: 低垂的树枝能挡风雪
❌ 雷雨时不要躲在孤立的大树下、山顶的岩石下
❌ 不要进废弃矿洞、深洞(塌方、缺氧、有害气体)
```

### 选址

```
✓ 地势较高(防洪水)
✓ 排水良好
✓ 靠近水源(但不太近,防蚊虫)
✓ 靠近材料来源
✓ 避风处
✓ 阳光充足(寒冷环境)
✓ 阴凉处(炎热环境)
✓ 附近有开阔地,便于布置求救信号、让救援人员看到

❌ 避免:
- 山谷底(冷空气下沉)
- 干河床(山洪)
- 孤立高地(雷电)
- 悬崖下(滚石)
- 枯树下(倒塌)
- 动物巢穴附近
- 蚂蚁窝、马蜂窝附近(先抬头看看树上)
- 河滩、沟口、两条溪流交汇处的低地

检查:
- 躺下试一试: 地面平整、没有石头树根顶着、头略高于脚
- 抬头看: 头顶有没有枯枝("寡妇枝",风一吹就会砸下来)
- 低头看: 有没有被水冲过的痕迹(泥沙、倒伏的草、挂在树枝上的杂物)
```

河边扎营和山洪征兆见[涉水、山洪与野外失温-露营选址](08-涉水山洪与野外失温.md#露营选址)。

### 隔地保温最重要

```
做法:
1. 收集大量干燥的松散材料: 枯叶、干草、松针、蕨类、细树枝
2. 铺到松散时厚30 cm以上,躺上去压实后仍有约10 cm
   (手压下去感觉不到地面的凉意)
3. 地面很湿、积雪时,先铺一层树枝或粗木头,再铺软材料
4. 背包、绳子、地图袋、空塑料瓶都可以垫在身下
5. 坐着等待时也要坐在背包或树枝上,不要直接坐在地上、石头上

判断够不够:
✓ 躺一会儿后背不觉得凉
⚠️ 后背、臀部发冷 → 再加厚
⚠️ 材料潮湿 → 换干的,或在上面铺一层塑料布再加干材料
```

### 简易庇护所类型

#### A字庇护所

```
结构:
1. 主梁:长木杆,一端架在树叉或支撑物上
2. 肋骨:斜靠在主梁两侧
3. 覆盖:树枝、树叶、草
4. 底部:铺草、树叶(隔离地面湿气)

优点:
- 简单快速
- 防雨
- 两侧挡风

尺寸:
- 主梁比身高长约1 m,高的一端架在齐腰高(约1 m)的树叉、树桩或
  两根交叉绑住的木桩上,低的一端着地
- 里面只要能躺下、翻身就够,不要做大: 空间越小越暖和
- 肋骨间距约一拃(20 cm左右),上面先横着编一些细枝,
  覆盖物才不会漏下来
- 入口开在背风的一侧,睡觉时用一堆树叶或背包堵住
```

#### 单坡庇护所

```
结构:
1. 两根支柱
2. 横梁连接
3. 一侧斜靠木杆
4. 覆盖防雨材料

优点:
- 简单
- 可加反射墙(火堆前取暖)

要点:
- 横梁高约1-1.5 m,斜面约45°-60°,背对风向
- 覆盖物从下往上像瓦片一样一层压一层
- 开口前约1 m处生火,火的另一侧垒反射墙
- 只挡一面,风向改变时不保暖;没有火时不如A字庇护所
```

#### 防水布、雨衣搭建

```
有防水布(或雨衣、大塑料布、垃圾袋)时,几分钟就能搭好:
- A字帐: 两棵树之间拉一根绳(高约1 m),布搭在绳上,
  两边用石头压住或用树枝做的木钉钉住
- 单坡: 布的一边系在高处的绳上,另一边斜拉到地面固定,背对风
- 绳子要拉紧,布面要有坡度,不能有积水的凹陷
- 布的边缘向下折进去,雨水不会顺着流进里面
- 应急保温毯(铝箔毯): 银色面朝着身体裹住,能反射体温;
  很轻,但容易撕破,也可以铺在庇护所顶的里面
```

拉绳用的营钉结、单套结见[绳索与结绳-常用绳结](../07-日常生活技能/17-绳索与结绳.md#常用绳结)。

#### 树叶小屋

```
结构:
1. A字框架
2. 厚厚覆盖树叶(30 cm以上)
3. 从下往上铺(瓦片状)
4. 内部铺干树叶

优点:
- 保暖
- 防水
- 隐蔽

要点:
- 寒冷的夜晚,覆盖物要厚到60 cm以上(大约一臂长),
  不靠火也能过夜;30 cm只能挡雨挡风
- 覆盖物上面压一些树枝,防止被风吹走
- 里面塞满干树叶,人钻进去像钻进睡袋
- 收集材料要花一两个小时,天黑前2-3小时就要开始
```

#### 雪洞(雪地)

```
步骤:
1. 找雪堆或积雪
2. 挖入口(小,保温)
3. 向上挖(冷空气下沉,热空气上升)
4. 内部:睡眠平台高于入口
5. 顶部戳气孔(通风)
6. 用雪块或背包堵部分入口

注意:
✓ 保持通风!
✓ 入口低于睡眠平台
✓ 内部不要太湿(体温融化)
✓ 顶部内壁修成圆弧形,水会沿壁流下而不是滴在身上
✓ 顶和四壁保留约30 cm厚,太薄会塌;挖洞时出汗弄湿衣服要避免,
  动作放慢,脱掉一层外衣
✓ 洞口外插一根树枝或放鲜艳物品做标记,夜里下雪可能埋住洞口
✓ 带一把能挖雪的工具(铲子、锅)放在洞里,万一塌了能自救
❌ 雪洞里不要生火、不要用炉子烧炭(一氧化碳中毒);
  点蜡烛照明时更要保持气孔通畅
```

雪洞、雪沟和雪屋的更多做法见[雪地极地求生-雪洞](04-雪地极地求生.md#雪洞)。

#### 炎热环境的遮阳棚

```
- 白天的庇护所是为了遮阳,不是为了挡风
- 用两层布、隔开约30 cm搭顶棚: 两层之间的空气能隔热,
  比一层布凉快得多
- 四周留空让风通过;浅色的布在上面
- 地面以下约30 cm的沙土比表面凉得多,可以挖浅坑躺在里面(只在清晨或傍晚挖)
- 夜里沙漠、戈壁可能很冷,要准备保暖
```

沙漠中的防晒庇护所见[沙漠求生-防晒(白天)](03-沙漠求生.md#防晒白天)。

### 改进庇护所

```
✓ 防水:
  - 塑料布、雨衣
  - 厚层树叶(瓦片状)
  - 树皮
  - 屋顶坡度要陡(45°以上),平缓的顶会漏

✓ 保温:
  - 厚覆盖物
  - 减小空间(保存体温)
  - 反射层(在热带用树叶反射热,寒带用应急保温毯反射体温)
  - 底部隔离层(厚树叶、草)
  - 几个人挤在一起,孩子放在中间
  - 睡前吃点东西、喝热水;把第二天要穿的衣服、鞋垫放在睡袋里或身下

✓ 防虫:
  - 烟熏
  - 网状遮挡
  - 选址(通风处)

✓ 舒适:
  - 平整地面
  - 软垫
  - 排水沟(周围挖沟防雨水倒灌)

✓ 防一氧化碳:
  - 封闭空间里不烧炭、不用炉子;必须用时开门开窗,有人醒着看守
```

几天到几周以上的住所,见[长期住所](../07-日常生活技能/05-长期住所.md)。

## 求救信号

**最有效的求救是在出事之前**: 出发前留下行程单,约好"过了某个时间联系不上就报警"。出事后,有手机信号就先报警。下面的信号是在没有信号、等待搜救时让人找到你。

### 国际求救信号

```
SOS: ... --- ... (短短短-长长长-短短短)

"三"规则(间隔相等,重复发出):
- 三声哨声
- 三堆火
- 三次反光

用法:
- 哨子、手电、敲击都可以发SOS: 短约1秒,长约3秒
- 每组三声发完,停约1分钟再发,让人有时间判断方向
- 三堆火排成三角形或一条直线,相距约20-30 m
- 听到回应(也是三声)后,继续发信号,引导对方找到你
```

### 信号方法

```
视觉信号:
- 镜子或反光物(白天,晴天从空中可见十几 km 以上)
- 挥舞鲜艳衣物
- 火堆(夜晚)
- 烟雾(白天): 湿草、绿叶产生白烟
- 地面标记:
  * SOS、HELP
  * 尽可能大(至少3 m),与周围颜色对比明显

声音信号:
- 哨子(比喊叫省力,传得更远)
- 敲击金属

电子信号:
- 手机(尽量到高处、开阔处,节省电量)
- 卫星通信设备、个人定位信标
```

**镜子怎样瞄准**:
```
1. 一只手伸直,食指和中指比成V字,把飞机或远处目标"夹"在两指之间
2. 另一只手拿镜子贴近眼睛下方,把阳光反射到伸出的手上
3. 慢慢移动镜子,让光斑落在两指之间,再左右微微晃动,光就扫过目标
4. 飞机明显转向你时,不要一直照向驾驶舱,以免晃得飞行员看不清
- 手机屏幕、光盘、铝箔、擦亮的锅盖、刀面都能代替镜子
- 没有飞机时,也要每隔一段时间朝可能有人的方向(山脊、公路)扫几下
```

**火和烟**:
```
✓ 提前把信号火堆搭好(火绒、细柴、粗柴都摆好),上面用树皮盖住防雨,
  听到飞机声时能立即点燃
✓ 准备一大堆青绿树枝、湿草放在旁边,点着后压上去产生浓烟
✓ 白烟(青枝、湿草)在深色背景(森林、岩石)前明显;
  黑烟(橡胶、油布、塑料)在雪地、沙地等浅色背景前明显
  (烧塑料、橡胶有毒,只在信号火堆短时间使用,站在上风)
✓ 信号火堆搭在开阔地或高处,注意防止引发林火
```

### 提高可见性

```
✓ 到开阔地、高处
✓ 穿鲜艳衣物
✓ 制造对比(雪地用深色,草地用浅色)
✓ 看到飞机或听到人声时,挥舞衣物、用镜子反光、吹哨子
✓ 在林中: 救援人员和飞机很难看到林下的人,要到林间空地、河滩边缘、
  山脊上布置信号(注意河滩涨水危险)
✓ 夜间: 头灯、手电、手机闪光灯朝天空和有动静的方向照,
  手电也可以发SOS;节省电池,听到动静再用
✓ 人走开时留下标记和字条(时间、人数、去向)
```

### 地面对空信号

```
在地面上摆出大字母,让飞机上的人看到:
✓ V - 需要援助
✓ X - 需要医疗援助
✓ ↑ - 正朝这个方向前进
✓ Y - 是/同意
✓ N - 否/拒绝

做法:
- 用石头、树枝、鲜艳衣物、挖出的沟(露出不同颜色的土)、
  在雪地上踩出的深沟摆出
- 每个符号尽量大,线条宽约0.5-1 m
- 摆在开阔、从空中看没有遮挡的地方
- 直线和直角在自然界里很少见,比曲线更容易被认出是人为的

身体信号(对着飞机或直升机):
- 双臂斜向上高举成Y形 → 需要帮助
- 一只手臂斜向上、一只斜向下 → 不需要帮助
- 飞机摇摆机翼、或低空绕圈,通常表示已经看到你
```

直升机接近时怎样做见[野外伤病处置与转运-直升机救援](11-野外伤病处置与转运.md#直升机救援)。

怎样报警、怎样说清自己的位置,见[户外出行准备与求救](07-户外出行准备与求救.md#报警求救-说清楚你在哪里)。

## 食物获取

详见各环境特定章节。基础原则:

### 野外食物的优先级

```
1. 等待救援的几天里不用找食物: 有水时健康成人可以几周不进食,
   饿的感觉一两天后会减弱;把力气留给保暖、喝水、发信号
2. 随身的食物按天分配,但每天都吃一点,保持体力和判断力
3. 必须找食物时,按"花的力气少、风险低、能确认"的顺序:
   ① 能100%确认的植物和果实(当地人普遍吃的)
   ② 昆虫、蚯蚓(必须煮熟)
   ③ 鱼、螺、贝类(必须煮熟)
   ④ 小动物(平时违法,且耗费时间体力,收获往往不如付出)
4. 获取食物消耗的能量不能比得到的还多: 跑半天追一只鸟不值得

⚠️ 不吃: 不认识的蘑菇和植物、死因不明或病死的动物、腐败变质的东西
⚠️ 水很少时少吃,尤其少吃高蛋白食物
```

不认识的蘑菇和野菜为什么不能吃,见[毒蘑菇与野菜误食](09-毒蘑菇与野菜误食.md);我国关于狩猎和捕鱼的法律,见[森林求生-关于狩猎和捕鱼的法律](02-森林求生.md#关于狩猎和捕鱼的法律)。

### 可食植物测试

⚠️ 仅紧急情况使用!很多植物有毒!

⚠️ 此测试不能发现延迟发作的毒素(毒蘑菇、某些生物碱可在数小时到数天后才发作),
   也不适用于蘑菇。许多野外医学专家已不建议普通人使用。
   优先只吃能100%确认的植物;不认识的宁可不吃(人可数周不进食)。

这个测试只适合**长期无法获救、确实没有其他食物来源**的极端情况。等待救援的几天里绝不要用。

```
不要测试,直接放弃的:
❌ 所有蘑菇、菌类
❌ 有乳白色或有颜色汁液的
❌ 有苦杏仁味、桃叶味的
❌ 伞状花序的(胡萝卜、芹菜一类,其中的毒芹等能致死)
❌ 豆荚里的种子、颜色鲜艳的浆果、白色浆果
❌ 叶子有细毛、细刺,或长得像栽培植物但长在野外的
❌ 已经发霉、变质的
⚠️ 就算避开了这些,也不能保证安全: 有些剧毒植物没有任何特征
```

```
通用可食性测试:
1. 确认只有一个人测试一种植物
2. 分离植物部分(叶、茎、根、果)
3. 闻:刺鼻气味?避免
4. 皮肤测试:内手腕,等15分钟,红肿?
5. 唇部:放嘴唇,等3分钟,刺激?
6. 舌部:舌尖,等15分钟,刺激?
7. 咀嚼:不吞,等15分钟,不适?
8. 吞咽:小量,等8小时,观察反应
9. 如无不适,可少量食用
10. 等24小时确认安全

每次只测一种!

补充:
- 测试前约8小时不吃别的东西,只喝净化过的水,以免分不清是什么引起的反应
- 每一步出现苦、辣、麻、灼热、刺痛 → 立即吐出、漱口,放弃这种植物
- 第9步"少量"指约小半碗(60 mL左右的量),再等8小时
- 煮过的和生的要分开测,同一种植物不同部位要分开测
- 孕妇、儿童、有病的人不做测试
- 整个测试至少需要一天,而且只对这一种植物、这一个部位有效

中毒症状(恶心、呕吐、腹痛、腹泻、嘴麻、头晕、心慌、视物模糊、抽搐):
→ 立即停止进食,不要催吐(催吐清除不了多少毒物,还可能呛入气道),
  保留剩下的植物,尽快求救就医
```

中毒的通用处理见[中毒-中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则);容易认错的有毒植物见[毒蘑菇与野菜误食-容易认错的有毒植物](09-毒蘑菇与野菜误食.md#容易认错的有毒植物)。

### 昆虫

```
可食(煮熟):
✓ 蚱蜢、蟋蟀
✓ 蚂蚁(去头)
✓ 白蚁
✓ 甲虫幼虫
✓ 蠕虫

避免:
❌ 鲜艳颜色
❌ 有毛
❌ 散发臭味
❌ 蜘蛛、蜱虫
❌ 苍蝇、蚊子、蟑螂(传播疾病)、蜈蚣、蝎子
❌ 已经死了的、在粪便或腐肉上的

准备:
- 去头、翅、腿
- 煮熟或烤熟
- 高蛋白!

要点:
- 一律煮熟或烤熟(可能带寄生虫)
- 蚱蜢的后腿有倒刺,会卡喉咙,一定去掉
- 朽木、树皮下、石头下最容易找到幼虫和白蚁;清晨天凉时蚱蜢不太跳,容易抓
- 对虾蟹过敏的人吃昆虫也可能过敏,先吃一点试试
```

### 捕鱼

```
方法:
- 钩和线(制作鱼钩:弯针、骨头、木头削尖)
- 鱼叉(快速刺)
- 陷阱(在浅水处围困)
- 手抓(在石头下)

优点:
- 容易获取
- 营养丰富
- 相对安全

具体:
- 鱼钩: 别针、缝衣针掰弯最简单;或用一小段两头削尖的骨头、硬木
  (中间系线,鱼吞下后一拉就横着卡住)
- 鱼线: 伞绳的内芯、缝衣线、细的植物纤维绳
- 饵: 蚯蚓、昆虫、幼虫;钓到第一条鱼后,用鱼内脏作饵
- 地点: 水潭、岸边树根下、大石头背水的一侧、两股水流汇合处;
  清晨和傍晚鱼最活跃
- 夜钓: 傍晚放下几根带饵的钓线,系牢在岸边,第二天早上收,不费体力
- 塑料瓶鱼笼: 剪下瓶口倒插进瓶身,放饵,沉在浅水里,小鱼进去出不来
- 在浅溪里用石头垒成V形,开口朝上游,把鱼赶到窄口处捉

安全:
⚠️ 淡水鱼、螺类必须彻底煮熟: 生吃或半生吃可感染肝吸虫,
   生吃螺(尤其福寿螺)可感染广州管圆线虫(可引起脑膜炎)
⚠️ 不吃河豚;不认识的海鱼、贝类要谨慎(有的季节、有的海域有毒)
⚠️ 不要为了抓鱼下到急流、深水里,不要踩湿滑的石头
⚠️ 平时: 禁止电鱼、毒鱼、炸鱼;禁渔期、禁渔区不得捕鱼
```

海边的贝类、海鱼见[荒岛求生](01-荒岛求生.md);长期生存时的养鱼见[水产养殖](../04-动植物培育/07-水产养殖.md)。

### 其他动物性食物

```
- 螺、蚌、蛙: 必须彻底煮熟(寄生虫);蟾蜍皮肤有毒,不要吃
- 鸟蛋: 只取一部分,煮熟吃
- 小动物、鸟: 平时受《野生动物保护法》保护,禁止猎捕和食用;
  只在文明崩溃、长期无法获救的情况下考虑
  - 布陷阱需要知识、时间,收获很不稳定,还可能误伤他人、宠物
  - 处理野生动物时戴手套或包住手,肉要彻底煮熟,不吃病死、死因不明的
```

长期野外生活中获取蛋白质的更多方法见[森林求生-动物蛋白](02-森林求生.md#动物蛋白)。

## 基础工具制作

一把好刀比任何自制工具都有用。出门随身带一把多功能刀,自制工具只在没有刀或刀不够用时才需要。

### 刀具

```
石刀:
1. 找坚硬石头(燧石、黑曜石)
2. 用另一石头敲击边缘
3. 形成锋利边
4. 绑在木棍上

竹刀:
1. 斜切竹子
2. 边缘锋利

石器要点:
- 质地细、断口像玻璃一样光滑的石头(燧石、黑曜石、石英岩)才能打出锋利的刃
- 用一块圆的硬石头(锤石)斜着敲击石块边缘,打下来的薄石片本身就是刀,
  往往比被打的石核更好用
- 石片刃口非常锋利,也非常脆,切割时不要撬、不要扭
⚠️ 敲石头时: 碎片会飞溅,保护眼睛(侧过脸、戴眼镜),
   石块垫在包着衣物的大腿上或放在地上,不要用手掌托着敲

竹刀要点:
- 用干竹比青竹硬;沿纤维劈出竹片,刃口在竹子坚硬的外皮一侧
- 能切肉、剖鱼,但很快变钝,随时再劈新的

用刀安全:
✓ 削的方向始终朝外、离开身体
✓ 不在大腿上方削东西(大腿内侧有大血管,割伤会大出血)
✓ 刀不用时收起或插在固定的地方,不要随手放在地上
```

大出血的处理见[外伤处理](../01-日常疾病和伤害/02-外伤处理.md)。工具的磨利和保养见[木工与工具维护](../07-日常生活技能/09-木工与工具维护.md);金属刀具的锻造见[简易工具锻造](../05-冶金技术/03-简易工具锻造.md)。

### 容器

```
竹筒:
- 节间作容器
- 煮水(不要太靠近火)

树皮:
- 桦树皮做容器
- 缝合边缘

叶子:
- 大叶子包裹
- 煮食(石头煮:烧热石头放水里)

要点:
- 竹筒: 选粗的青竹,在竹节下方锯断,保留一个节做底;
  一定要开口煮,两头都是竹节的密封竹筒受热会爆裂
  斜靠在火边,竹筒里有水的部分不会烧穿,水能烧开
- 树皮容器: 剥一大片树皮,四角折起,用细枝或竹签夹住,
  可以装水;桦树皮容器放在炭火上可以烧开水(水面以上的部分不要碰到明火)
- 石头煮: 在树皮、木头挖的容器或兽皮里装水,把在火里烧热的石头用木棍夹进去,
  反复换几块,水能烧开
  ⚠️ 只用干燥的石头: 从河里、水边捡的石头、页岩、砂岩受热可能炸裂
- 塑料瓶装满水也可以直接放在火边加热(火焰不碰到水面以上的部分),
  但会变形,只作应急
```

### 绳索

```
材料:
- 植物纤维
- 动物筋腱
- 藤蔓

制作:
1. 取长纤维
2. 搓成小股
3. 两股交叉拧
4. 形成绳

要点:
- 好用的植物纤维: 椴树、榆树、柳树的内树皮,葛藤、芦苇叶、香蒲叶、
  荨麻、苎麻的茎皮
- 每一股朝一个方向拧,两股合在一起时反方向拧,绳子才不会散开
- 伞绳拆开后,里面的细芯可以作缝线、鱼线、鞋带
- 自制绳子强度难以估计,绝不能用来吊人、攀爬
```

搓绳、制绳的详细方法见[绳索与结绳](../07-日常生活技能/17-绳索与结绳.md)。

### 其他简易工具

```
- 挖掘棍: 一根手腕粗的硬木,一头削成扁平的斜尖,在火上烤硬(不要烤焦),
  可以挖根茎、挖坑、挖排水沟
- 木钉(营钉): 拇指粗的硬木削尖,上端刻一个缺口挂绳,固定防水布
- 火钳: 一根青树枝在中间削薄,弯过来,能夹炭、夹石头
- 扫把、垫子: 用细枝、草捆起来,整理庇护所
- 针: 骨头、硬刺磨尖,用来缝补衣物、树皮容器
- 手杖: 一根齐胸高的直木棍,过陡坡、探路时用
```

## 绳结技能

野外最常用的几个结,先学会这四个:

### 基础绳结

**平结**(捆扎):
```
用途:捆扎包裹、系绷带(只用于捆扎)
方法:左搭右,右搭左
⚠️ 受力时容易散开,不要用来连接两根承重的绳子
   → 连接用接绳结或渔人结
```

**双套结**(固定):
```
用途:绑在柱子、树上
可承重
- 两端都受力时最牢;只有一端受力、被来回拉扯时可能慢慢松开,
  末端再打两个半结加固
```

**称人结**(救援):
```
用途:腰间绳圈,不会收紧
救援使用
- 也叫单套结;受力后不会勒紧,用完容易解开
- 绳头至少留出约绳子粗细的10倍长,或再打一个止索结
```

**营钉结**(张紧):
```
用途:帐篷、遮蔽布
可调节松紧
```

```
用绳安全:
✓ 用之前检查绳子有没有磨损、割伤、霉烂
✓ 打完结拉紧,检查形状对不对,不确定就重打
✗ 不认识的绳子、自制绳子,不要用来吊人、攀爬、横渡急流
```

更多绳结的打法步骤、绳子的强度和安全用法见[绳索与结绳](../07-日常生活技能/17-绳索与结绳.md)。

## 📝 总结要点

### 生存五大支柱

```
1. 庇护所 - 保护身体
2. 水 - 维持生命
3. 火 - 取暖煮食
```
