## 马蜂(胡蜂)

在国内野外,**马蜂比蛇、熊更常伤人**。秋季(大约8-10月)马蜂窝最大、最有攻击性,陕西、云南、湖北等地每年都有被群蜂蜇伤致死的事件。

马蜂和蜜蜂不同: 蜜蜂蜇一次后蜇针留在皮肤里,自己会死;**马蜂可以反复蜇人,毒性更强,常常成群攻击**。

### 预防

```
✓ 留意树上、灌木丛、岩缝、屋檐下、地洞里的蜂窝,远远绕开
✓ 听到嗡嗡声变大、看到很多蜂在一个地方进出 → 停下,换路线
✓ 穿浅色、素色衣服,不用香水、发胶等有香味的东西
✓ 戴帽子
❌ 不要捅、扔石头打、用火烧蜂窝
❌ 不要在蜂窝附近大声喧哗、快速挥舞手臂
✓ 发现居住地附近有马蜂窝,打119或请专业人员摘除,不要自己处理
```

### 被蜂群攻击时

```
✓ 立即用衣服、外套护住头部和脖子
✓ 尽快离开,往远离蜂窝的方向快跑,跑出几十米以外
✓ 能躲进屋里、车里的,躲进去关好门窗
✓ 来不及逃跑时,蹲下或趴下,用衣服包住头颈
❌ 不要原地挥打(会招来更多的蜂)
❌ 不要跳进水里(蜂会在水面上等着)
```

### 被蜇后

```
1. 离开蜂窝附近
2. 如果是蜜蜂,留有蜇针: 用卡片边缘刮掉,不要用手捏
3. 用肥皂和清水冲洗伤处
4. 冷敷,减轻肿痛
5. 取下戒指、手镯(手指手腕可能会肿)

⚠️ 以下情况立即就医(最好在被蜇后6小时内):
- 出现任何过敏症状: 全身起疹子、嘴唇或脸肿、呼吸困难、
  喉咙发紧、头晕、心慌 → 可能是过敏性休克,立即拨打120
- 被蜇的地方多: 10处以上,即使暂时没有不适也要去医院
- 蜇在口腔里、喉咙、眼睛附近
- 儿童、老人,或者有心脏病、过敏体质的人

⚠️ 被蜇多处后的几天里,出现以下情况要立即就医:
- 尿的颜色变深,像浓茶、酱油
- 尿量明显减少
- 全身肌肉酸痛无力、恶心、呕吐
  (马蜂毒素会破坏肌肉和红细胞,导致急性肾衰竭,这是群蜂蜇伤的主要死因)
```

昆虫叮咬的一般处理见[外伤处理-昆虫叮咬](../01-日常疾病和伤害/02-外伤处理.md#昆虫叮咬),过敏性休克的处理见[急性症状-过敏反应](../01-日常疾病和伤害/05-急性症状.md#过敏反应)。

## 蜱虫

蜱虫(俗称草爬子、狗鳖)生活在草丛、灌木丛和树林里,爬到人身上后叮在皮肤上吸血,可以连续吸好几天。**被叮时通常不痛不痒,很多人是洗澡时才发现。**

蜱虫能传播多种疾病,国内常见的有:
- **发热伴血小板减少综合征**: 主要在中部、东部的丘陵山区,病死率较高;病人的血液和体液也有传染性
- **森林脑炎**: 主要在东北、西北的林区
- **莱姆病**: 被叮的地方周围出现慢慢扩大的环形红斑

### 预防

```
✓ 进入草丛、树林前:
  - 穿长袖长裤,裤腿扎进袜子里,衣服下摆扎进裤子里
  - 穿浅色衣服(容易发现爬在身上的蜱虫)
  - 皮肤裸露的地方涂含避蚊胺(DEET)的驱虫剂,按说明书使用
✓ 尽量走在路中间,不要在草地上坐卧,不要把衣服铺在草地上
✓ 离开后仔细检查全身,特别是:
  头皮、耳后、脖子、腋下、腰部、肚脐、腹股沟、膝盖后面
✓ 衣服抖一抖,检查背包;带回家的衣服热水洗、高温烘干
✓ 宠物狗进过草丛,也要检查
```

### 发现蜱虫叮在身上

```
✓ 用细尖头的镊子,尽量贴近皮肤,夹住蜱虫的头部(口器)
✓ 垂直于皮肤,稳稳地慢慢往外拔
✓ 拔出后用碘伏或酒精消毒伤口,洗手
✓ 把蜱虫装进密封袋或拍照,记下被叮的日期(万一生病给医生看)

❌ 不要用手指直接捏、挤蜱虫的身体
❌ 不要用火烧、烟头烫、涂油、涂指甲油让它"自己退出来"
❌ 不要猛拽、左右扭转
⚠️ 拔不出来,或口器断在皮肤里,到医院处理
```

### 被叮以后

```
⚠️ 在被叮后的大约2周内,出现以下情况尽快就医,并主动告诉医生被蜱虫叮过:
- 发热、乏力、头痛、肌肉酸痛
- 恶心、呕吐、腹泻、不想吃饭
- 被叮的地方周围出现扩大的红斑
- 牙龈出血、皮肤出血点
- 精神变差、嗜睡、抽搐

✓ 照顾发热伴血小板减少综合征病人时,接触血液、体液要戴手套,接触后洗手
✓ 东北、西北林区的长期工作者,可以咨询接种森林脑炎疫苗
```

## 旱蚂蟥

南方山林、雨林的雨季,地上、草叶上常有旱蚂蟥(山蚂蟥),会钻进鞋袜、裤腿里吸血。

```
预防:
✓ 穿防蚂蟥袜,或者把裤腿扎进袜子里、绑紧
✓ 鞋袜、裤腿上涂驱虫剂,也可以抹肥皂、盐水
✓ 每走一段路停下来检查脚踝、小腿、腰部

被叮后:
✓ 用手指甲沿着皮肤把蚂蟥的吸盘慢慢推开,或者等它吸饱后自己脱落
✓ 也可以在它身上撒盐、滴酒精或风油精,让它自己松开
✓ 伤口会流血较长时间(蚂蟥的唾液让血不容易凝固),压住止血,消毒,包扎
❌ 不要硬拽(口器留在皮肤里容易感染)
```

## 蛇

国内大多数蛇没有毒,毒蛇也很少主动攻击人。被咬大多是因为踩到、伸手去抓、或者惹它。

```
预防:
✓ 穿长裤、高帮鞋,走路时用登山杖或木棍拍打前方的草丛("打草惊蛇")
✓ 夜里走路一定要用头灯或手电照路(很多毒蛇晚上活动)
✓ 不把手伸进看不见的石缝、树洞、草堆里;不随手翻石头
✓ 搭帐篷前清理地面,睡前、穿鞋前检查睡袋和鞋子
❌ 不要抓蛇、玩蛇、打蛇
❌ 刚打死的蛇、砍下来的蛇头,仍然可能咬人

遇到蛇:
✓ 停下,慢慢后退,给它留出逃走的路
✓ 大多数蛇会自己离开
```

被蛇咬后的处理(不要切开、不要用嘴吸、立即就医)见[外伤处理-蛇咬伤](../01-日常疾病和伤害/02-外伤处理.md#蛇咬伤)。

## 野猪、狗、猴子等

### 野猪

近年来很多地方野猪数量增加,山区村庄、城郊也能见到。

```
✓ 远远看到就绕开,不要靠近,尤其是带着小猪的母猪
✓ 不要追赶、投喂、拍照逗弄
✓ 野猪冲过来时: 躲到大树后面,或者爬上树、大石头等高处
✓ 带着小孩时,把孩子抱起来
⚠️ 被野猪咬伤、撞伤要就医(伤口深,容易感染)
```

### 狗

```
农村和山区常有看家狗、流浪狗:
✓ 不要跑(跑会引起追咬)
✓ 面向狗,慢慢后退,不要直视它的眼睛
✓ 用登山杖、背包挡在身前
✓ 被扑倒时,蜷成一团,双手护住头颈
⚠️ 被狗咬伤、抓伤,按狂犬病暴露处理,尽快就医
```

### 猴子

```
峨眉山、黄山等景区的猴子会抢食物、抓人:
✓ 不要喂食,把食物、塑料袋收进背包
✓ 不要盯着猴子看、不要对它龇牙(在猴子看来是挑衅)
✓ 猴子靠近时,把手里的东西放下,慢慢走开
⚠️ 被猴子咬伤、抓伤,按狂犬病暴露处理,尽快就医
```

动物咬伤的处理和狂犬病预防见[外伤处理-咬伤](../01-日常疾病和伤害/02-外伤处理.md#咬伤);熊等大型动物见[森林求生-动物](02-森林求生.md#动物)。

## 📝 要点

```
1. 秋天的马蜂最危险: 远离蜂窝,被追时护住头颈快跑,不要跳进水里
2. 被蜇10处以上,或有过敏症状,立即就医;几天内尿色变深要警惕肾衰竭
3. 进草丛前扎紧裤腿,出来后检查全身的蜱虫
4. 用镊子贴近皮肤夹住蜱虫头部垂直拔出,不要用火烧、涂油
5. 被蜱虫叮后2周内发热,就医时告诉医生被叮过
6. 蛇: 打草惊蛇,夜里照路,不伸手进石缝,不抓蛇
7. 野猪绕开,遇狗不跑,猴子不喂
8. 被狗、猴子咬伤抓伤,按狂犬病暴露处理
```
