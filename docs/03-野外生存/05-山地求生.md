# 山地求生指南

## 核心挑战

- 高原反应
- 气温低、风大
- 地形险峻
- 易迷路、坠落
- 天气多变
- 紫外线强

```
这几条为什么在山里特别要命:
- 高原反应: 海拔2500 m以上就可能发生,重症(肺水肿、脑水肿)一两天内可以致死
- 气温低、风大: 海拔每升高100 m,气温平均下降约0.6°C;
  山下30°C,海拔3000 m的山顶可能只有10°C左右,再加上大风和雨,夏天也会失温
- 地形险峻: 陡坡、碎石、湿滑的岩石和草坡;大多数山地伤亡来自滑倒、坠落和落石
- 易迷路: 山里的路岔多、雾多,手机信号常常时有时无
- 天气多变: 夏季午后常有雷暴,一两个小时内从晴天变成冰雹、大雨
- 紫外线强: 海拔越高紫外线越强,大约每升高1000 m增加10%左右;雪面还会反射
```

山地事故大多不是"运气不好",而是出发准备不足、不肯掉头。出发前的行程单、装备和掉头时间见[户外出行准备与求救](07-户外出行准备与求救.md)。

## 高原反应

高原反应(急性高山病)是因为海拔升高后空气稀薄、身体缺氧引起的。**它和年龄、体能关系不大**,身体强壮、经常运动的人照样会得,而且往往因为"自己身体好"而硬撑,反而更危险。

### 海拔越高风险越大

| 海拔 | 情况 |
|---|---|
| 1500 m以下 | 一般不会发生高原反应 |
| 1500-2500 m | 少数人(尤其是快速到达、剧烈运动时)有轻微症状;运动时气喘明显 |
| 2500-3500 m | 高原反应常见;直接乘飞机、汽车到达的人,相当一部分会有症状 |
| 3500-5500 m | 高原反应很常见,肺水肿、脑水肿的风险明显增加 |
| 5500 m以上 | 人无法长期适应,只能短时间停留 |

```
决定风险的主要不是"白天到了多高",而是:
- 睡觉的海拔(夜里呼吸变浅,缺氧最重)
- 上升速度(乘飞机直接到拉萨约3650 m,比几天内逐步走上去风险大得多)
- 以前得过高原反应、尤其是得过肺水肿或脑水肿的人,再上高原更容易复发
```

### 症状

**轻度**:
- 头痛、头晕
- 乏力
- 失眠
- 食欲差

**中度**:
- 剧烈头痛
- 恶心呕吐
- 呼吸困难

**重度**(危险):
- 肺水肿:咳嗽、粉红痰、呼吸极度困难
- 脑水肿:意识障碍、共济失调、昏迷

```
症状出现的时间:
- 高原反应一般在到达新高度后6-12小时出现,第1-2天最重
- 肺水肿多在到达后第2-4天夜里出现
- 在高海拔出现的头痛、乏力、恶心,先当成高原反应处理,
  不要当成"感冒""累了""晒的",除非确实有别的明确原因

失眠、夜里憋醒、呼吸时快时慢(停几秒又大口喘):
- 在高海拔很常见,单独出现不一定是高原反应
- 但不要吃安眠药(会抑制呼吸,加重缺氧)
```

### 自我评分

国际上常用"路易斯湖评分"来判断高原反应的轻重。思路很简单: 在海拔上升后出现**头痛**,再加上其他症状,按轻重打分。

| 症状 | 0分 | 1分 | 2分 | 3分 |
|---|---|---|---|---|
| 头痛 | 没有 | 轻微 | 中等 | 剧烈、难以忍受 |
| 胃肠症状 | 胃口正常 | 胃口差或恶心 | 明显恶心或呕吐 | 严重恶心、呕吐,无法进食 |
| 疲乏、无力 | 没有 | 轻微 | 中等 | 严重,难以行动 |
| 头晕 | 没有 | 轻微 | 中等 | 严重,难以行动 |

```
怎样用:
- 海拔上升后有头痛,并且四项加起来≥3分 → 按高原反应处理
- 3-5分: 轻度;6-9分: 中度;10-12分: 重度
- 每天早晚各评一次,同伴之间互相评,记在本子上,看是变好还是变坏
- 评分只是帮助判断的工具: 不管总分多少,只要出现下面"肺水肿、脑水肿"的表现,
  就按重症处理,立即下撤

儿童(尤其是不会说话的幼儿)不会说头痛: 观察有没有
  烦躁哭闹、不爱玩、吃得少、睡得不好、呕吐 —— 在高海拔出现这些,按高原反应对待
```

### 怎样识别肺水肿和脑水肿

| | 高原肺水肿 | 高原脑水肿 |
|---|---|---|
| 早期 | 比同伴明显更容易累、上坡跟不上;休息时也气短;干咳 | 高原反应加重,头痛剧烈、呕吐;异常嗜睡、萎靡 |
| 加重 | 安静躺着也喘不上气、平躺更难受;咳嗽加重;嘴唇、指甲发紫 | 走路不稳、像喝醉了;说话含糊、答非所问、性格反常 |
| 晚期 | 咳粉红色泡沫痰,胸口有"咕噜"声 | 意识模糊、叫不醒、昏迷 |
| 是否先有高原反应 | 不一定,可以没有明显头痛 | 一般先有高原反应,逐渐加重 |

```
脚跟对脚尖走直线测试(检查共济失调):
1. 让病人在平地上沿一条直线走,每一步脚跟紧贴前一只脚的脚尖,走5-6步
2. 正常人(即使累)也能基本走直
3. 摇晃、需要扶、走不了直线 → 怀疑脑水肿(排除醉酒、严重疲劳、低血糖等)

⚠️ 危险的错误:
- "睡一觉就好了": 脑水肿的人越来越嗜睡,夜里可能就昏迷
- "等天亮再说": 肺水肿夜里加重最快;能安全行动时,天黑也要组织下撤
- 让病人单独留在营地或单独下山: 病人的判断力已经受损,必须有人陪同
```

### 预防和处理

```
预防:
✓ 海拔3000 m以上: 每天睡眠海拔上升<500 m
✓ 每上升约1000 m(或每3-4天)休息1天适应
✓ 保持水分
✓ 避免剧烈运动
✓ 高碳水饮食

预防的具体做法:
- 能慢就慢: 先在2000-3000 m的地方住1-2晚,再往上走
- "爬高睡低": 白天可以走得比睡觉的地方高一些,晚上回到较低处睡觉
- 睡眠海拔每天上升不超过约500 m 指的是今晚和昨晚睡觉处的高差,
  不是白天走了多少;地形限制一天必须升得更多时,之后要多休息一天
- 休息日不是躺一天: 可以在附近轻松走走,但不要上升睡眠高度
- 水: 喝到尿色淡黄、尿量正常即可;高原空气干,呼吸丢水多,
  一般每天要比平时多喝一些,但喝得过多并不能预防高原反应
- 前两天动作放慢,不要跑跳、背重物快速爬坡;到达后当天不要洗澡受凉
- 不喝酒,不吃安眠药
- 以前得过高原肺水肿、脑水肿的人,以及心脏病、肺病、严重贫血、
  孕妇、带婴幼儿的人,出发前先咨询医生

轻中度:
✓ 休息、不再上升
✓ 补水
✓ 止痛药(头痛)
✓ 如恶化,下降!

轻中度的具体做法:
1. 原地休息,停止上升,直到症状完全消失(通常要1-3天)
2. 头痛可以用对乙酰氨基酚或布洛芬,按说明书剂量服用,不要超量
3. 保暖,少量多次进食易消化的碳水(粥、面条、饼干、糖)
4. 每隔几个小时重新评分;24小时内没有好转,或者变重 → 下撤
5. 症状完全消失后,可以按原来的速度继续上升;不消失就不能再往上走
✗ 不要带着症状继续往上走 —— 这是重症最常见的来源
✗ 不要用止痛药压住头痛后继续上升

重度:
⚠️ 立即下降!(生死攸关)
- 下降500-1000 m
- 吸氧(如有)
- 就医
```

### 下撤

```
1. 立即拨打120或报警,说明是高原肺水肿/脑水肿,请求救援
2. 下撤不能等救援到了再开始: 能走就有人陪着走,不能走就抬、背、用牲畜或车辆送
3. 下降到症状明显好转为止;通常500-1000 m 就有明显改善,但重症仍要送医院
4. 下撤途中:
   - 肺水肿病人尽量少用力(用力会加重),保暖,半坐位
   - 脑水肿病人有人搀扶,注意呕吐时侧头,防止窒息
5. 有氧气就吸氧,有便携式加压袋(高压舱袋)也可以用,
   但这些只是为下撤争取时间,不能代替下撤
6. 天气、夜晚、地形实在不能移动时: 吸氧、保暖、半坐位,
   一有条件马上下撤或等待直升机
```

### 关于药物

```
- 乙酰唑胺可以用于预防和治疗高原反应,但它是处方药,
  有过敏(尤其是磺胺类药物过敏)和其他禁忌,必须由医生评估后开具,按医嘱服用
- 治疗肺水肿、脑水肿还有其他处方药,只能在医生指导下使用
- 非处方药中只有止痛药(对乙酰氨基酚、布洛芬)可用于缓解头痛,不能治疗重症
- 网上流传的"红景天""葡萄糖口服液""提前吃抗生素"等,没有可靠证据能预防高原反应,
  不能因为吃了这些就加快上升速度
- 任何药物都不能代替"慢慢上升、症状加重就下撤"
```

慢性病人出门前的用药准备见[慢性病用药储备](../01-日常疾病和伤害/08-慢性病用药储备.md)。

## 水源

```
山地水源丰富:
✓ 溪流
✓ 泉水
✓ 融雪
✓ 雨水
✓ 露水

优先:
- 高海拔源头
- 流动水

净化:
- 煮沸(高海拔需更久)
- 过滤+消毒
```

```
补充:
- "高山上的水很干净"不可靠: 上游常有放牧的牛羊、牦牛和野生动物,
  一条清澈的溪水也可能含有引起腹泻的病原体
- 泉水从岩缝、地下直接流出的相对干净;流出后经过草地、牧场的就要净化
- 冰川融水常是灰白色(含细岩粉),先在容器里静置沉淀,再取上层清水净化
- 雪和冰要融化后再喝,直接吃雪会降低体温;融雪的方法见雪地章节
- 海拔高,水在不到100°C就沸腾(海拔3000 m约90°C),但沸腾仍能杀灭病原体;
  海拔2000 m以上煮沸3分钟
- 高原上呼吸快、空气干,丢水比平原多,不渴也要定时喝几口;
  尿色深黄、尿少说明喝得不够
- 雨季的山区溪流可能突然涨水,取水时站在岸边稳固处,不要走进急流
```

相关章节: [基础生存技能-水质净化](00-基础生存技能.md#水质净化)、[雪地极地求生-融雪](04-雪地极地求生.md#融雪)。

## 庇护所

### 选址

```
✓ 避风(山坳、岩石后)
✓ 避开山顶(风大、雷击)
✓ 避开谷底(冷空气聚集)
✓ 避开滑坡、滚石区
✓ 靠近水源(但不在河边-山洪)
✓ 平坦处

❌ 避免:
- 孤立高处(雷电)
- 悬崖边
- 干河床(山洪)
- 雪檐下(雪崩)
```

```
怎样看出危险:
- 滚石区: 坡下散落着棱角新鲜、颜色较浅的石块,树干上有撞痕,
  坡面上有一道道往下的沟槽 —— 不要在它的下方和延长线上扎营
- 冷空气: 夜里冷空气顺坡往下流,积在谷底和洼地,比半山腰的台地冷好几度
- 山洪: 选明显高出河床的台地,地面没有泥沙、倒伏的草、树上挂着的杂物
- 雪崩: 不要扎在陡坡下方、雪崩槽(坡上一条没有树的通道)的出口
- 枯树和大枝: 大风时会断落砸人

✓ 比较好的位置: 山腰背风一侧的平缓台地、林线下方的树林边缘
✓ 天黑前1-2小时就开始找营地,不要摸黑找
```

露营选址的更多原则见[涉水、山洪与野外失温-露营选址](08-涉水山洪与野外失温.md#露营选址)。

### 利用地形

```
天然庇护:
✓ 洞穴(检查是否安全)
✓ 岩石突出部
✓ 大石块后(挡风)
✓ 茂密树丛

改进:
- 石墙挡风
- 覆盖遮雨
- 底部隔离
```

```
具体做法:
- 洞穴、岩檐: 先看顶部有没有裂缝、松石,地面上有没有新掉下来的碎石;
  看有没有动物粪便、毛发(可能是野兽的窝);雷暴时不要待在浅洞和洞口
- 小洞里不要烧大火: 烟和一氧化碳排不出去会中毒;火堆放在洞口外侧下风处
- 石墙: 在迎风一侧用石块垒一道矮墙,大石在下、小石在上,高度够挡住躺下的身体即可;
  不要从陡坡上撬石头(会引发落石)
- 底部隔离最重要: 身体从地面和岩石上丢失的热量比从空气中多,
  垫上背包、绳子、干草、树枝、防潮垫,厚度至少一拳
- 穿上所有干衣服,把湿衣服换下;几个人挤在一起
```

搭建庇护所的方法见[基础生存技能-简易庇护所类型](00-基础生存技能.md#简易庇护所类型)。

## 导航

### 地形辨识

```
✓ 地图+指南针
✓ 明显地标(山峰、河流)
✓ 观察地形
✓ 结合河流判断下山方向(不要盲目沿溪谷走)
```

```
补充:
- 出发前下载离线地图,看懂等高线: 线密的地方陡,线疏的地方缓;
  V字形尖端指向高处的是山谷,指向低处的是山脊
- 走路时不断对照: 现在在山脊上还是沟里?左手边是哪座山?
- 每到岔路口、垭口、地形转折处,停下来确认,回头看一眼来路
- 起雾时山脊和山谷都看不清,能见度低于几十米时,停在安全处等雾散
```

看懂地图和等高线见[户外出行准备与求救-看懂地图和等高线](07-户外出行准备与求救.md#看懂地图和等高线)。

### 下山原则

```
通常:
✓ 优先沿山脊或已有小路下山(视野好,不易迷路)
✓ 河流往下最终通向人烟,但溪谷常有峡谷、瀑布、陡崖
✓ 遇到峡谷、陡崖立即回头,不要冒险攀爬
```

```
补充:
- 下山比上山更容易出事: 腿累、注意力下降、重心靠前容易滑倒
- 下陡坡时膝盖微弯、小步走,用登山杖或树枝辅助,不要跑
- 山脊也可能突然变成悬崖,发现越走越陡、下不去时就原路退回
- 不要钻进看不到底的陡沟"抄近路": 很多被困者是下到一半上不去也下不来
- 留出时间: 天黑前到达安全处;来不及就提前准备过夜,不要摸黑下山
```

### 迷路

```
✓ 有人搜救时: 留在原地,发信号(最优先)
✓ 必须自行脱困时: 往高处观察,沿山脊或小路下山
✓ 不要盲目沿溪谷走
```

```
迷路时的步骤:
1. 停下来,坐下喝口水,吃点东西,不要慌着乱走
2. 回想最后一次确定位置的地方,能确定安全地沿原路返回就原路返回
3. 看手机有没有信号: 先打电话报警,开启位置共享,然后关闭不需要的功能省电
   (没有信号的地方,往开阔、稍高处走几十米可能就有信号,但不要冒险)
4. 已经有人知道你的行程(留了行程单): 原地等待,让搜救的人找得到你
5. 天快黑、天气变坏: 先找避风处准备过夜,保暖比找路重要

为什么不要沿陡谷往下走:
- 山地溪谷越往下越窄越陡,常有瀑布、跌水、光滑的岩壁
- 两侧是陡崖,下去就很难再爬上来
- 一下雨,溪谷是山洪最先经过的地方
- 树林和谷底信号差,也最难被搜救的人和直升机看到

掉头时间:
- 出发前定好掉头时间(如下午2点),到点不管到没到都往回走
- 在山上迷路的人,很多是因为"再往前一点就到了"
```

迷路后的详细处理见[户外出行准备与求救-发现自己迷路了](07-户外出行准备与求救.md#发现自己迷路了)和[掉头时间](07-户外出行准备与求救.md#掉头时间);报警时怎样说清位置见[报警求救: 说清楚你在哪里](07-户外出行准备与求救.md#报警求救-说清楚你在哪里)。

## 危险

### 坠落

```
预防:
✓ 小心行走
✓ 试探石头(可能松动)
✓ 三点支撑(始终保持3点接触)
✓ 避开悬崖边
✓ 雨雾天减少移动
```

```
具体怎么做:
- 小心行走: 眼睛先看脚下再迈步,走路时不看手机、不边走边拍照;
  要看风景、拍照时先停下来站稳
- 试探石头: 用手推、用脚轻踩,确认不晃再把重心放上去;
  抓植物时抓根部,枯枝、小灌木不能承重
- 三点支撑: 在需要手脚并用的地方,四肢中一次只移动一个,另外三个牢牢固定;
  身体贴近岩壁但不要趴死在上面(重心外移反而稳)
- 最容易滑倒的地面: 湿岩石、长青苔的石头、落叶覆盖的陡坡、碎石坡、
  雨后的草坡、背阴处的薄冰 —— 走这些地方放慢,降低重心
- 累了就休息: 很多坠落发生在一天的后半段、下山路上
- 背包收紧,不要挂着晃来晃去的东西;双手尽量空出来
- 带孩子时,孩子走在靠山壁一侧,大人在外侧
- 爬不上去或下不来的地方不要尝试;攀爬、绳索下降需要专业训练和装备,
  不懂的人不要用一根绳子临时吊人
```

绳子能用来做什么、不能做什么见[绳索与结绳](../07-日常生活技能/17-绳索与结绳.md)。

### 跌倒和滑坠时

```
在陡坡上开始往下滑:
1. 第一时间翻身成面朝坡面、脚朝下
2. 手肘、手、膝盖、脚尖用力压进地面减速,手里有登山杖就横过来往坡里插
3. 不要头朝下滑,不要仰面滑(无法刹车)

在平地或缓坡上摔倒:
- 尽量侧身倒,用小臂和肩背着地分散冲击,不要用手腕硬撑
- 收下巴,不让后脑着地

开始翻滚时:
- 双臂抱头,护住头和后颈,身体蜷起来
- 能抓住树、灌木、大石头就抓住

在雪坡上: 用冰镐制动需要专门训练;没有训练和装备的人不要走陡雪坡
```

### 受伤以后

```
1. 先保证不再受伤: 伤员停在原地,其他人从安全的路线靠近,注意上方落石
2. 评估: 有没有意识、呼吸;有没有大出血;能不能动手脚
3. 从高处坠落、头部着地、背部摔伤的人,按可能有脊柱损伤对待,
   不要扶起来、不要让他自己走,除非原地有落石、山洪等危险
4. 立即报警求救,说清位置和伤情
5. 保暖: 伤员躺在地上失温很快,即使是夏天也要垫和盖
6. 扭伤、小伤能走的,有人陪同慢慢下撤;不要让伤员独自下山
```

相关章节: [野外伤病处置与转运-第一步: 安全、评估、求救](11-野外伤病处置与转运.md#第一步-安全评估求救)、[原地等待还是自行撤出](11-野外伤病处置与转运.md#原地等待还是自行撤出)、[基础急救知识-何时不能搬运](../01-日常疾病和伤害/00-基础急救知识.md#何时不能搬运)、[骨骼损伤-骨折](../01-日常疾病和伤害/03-骨骼损伤.md#骨折)。

### 滚石/山体滑坡

```
识别:
- 松动岩石
- 裂缝
- 新落石痕迹

避免:
✓ 不在陡坡下
✓ 快速通过危险区
✓ 雨后格外小心
```

```
补充:
- 落石最多的时候: 大雨中和雨后、冻融交替的早晨(冰把石头撑松)、
  午后冰雪融化时、有人或动物在上方活动时
- 通过落石区: 一次一个人快速通过,不在下方停留、休息、拍照;
  其他人在安全处看着上方,看到落石大声喊
- 队伍在碎石坡上: 不要上下排成一列(上面的人踢落的石头会砸到下面的人),
  要么靠近走、要么横向错开
- 自己踢落了石头,马上大喊"落石!"
- 听到"落石"或上方有响声: 不要抬头看,立即贴近岩壁、躲到大石后,
  用背包护住头;来不及就就地蹲下,背包顶在头上
- 戴头盔能大幅减少落石致命伤,走落石多的路线要戴
- 路面出现新裂缝、坡上树木歪斜、泉水突然变浑或断流、听到山体有响声
  → 可能要滑坡,立即往与滑动方向垂直的两侧高处撤
```

滑坡、泥石流的应对见[地质灾害-山体滑坡](../02-灾难应对/01-地质灾害.md#山体滑坡)和[泥石流](../02-灾难应对/01-地质灾害.md#泥石流)。

### 雷电

```
山地雷电危险!

如遇雷暴:
1. 下到低处
2. 远离山顶、山脊
3. 不在孤立树下
4. 无处躲避时双脚并拢蹲下(只能略微降低风险)
5. 远离金属物
6. 进入低洼处(但避开水流处)
```

```
补充:
- 听到雷声就要行动: 能听到雷声,就已经在雷击可能到达的范围内,不要等下雨
- 最好的办法是避开: 早出发,中午前登顶,午后雷暴来临前离开山顶和山脊
- 山上的亭子、山顶小庙、信号塔、孤立棚屋都不能当避雷处
- 抓着铁链、铁索、铁栏杆的路段(很多景区山路都有): 雷暴时立即离开这些路段
- 登山杖、金属框架的背包放下,离开几 m;不要举在头上
- 浅洞、岩檐下、洞口不安全(电流可能从洞口跳过人体);
  较深的洞内相对好一些,但不要靠着洞壁,不要站在洞口
- 树林中: 往成片的较矮树木中间躲,远离最高的那棵树
- 多人时分散开,相互间隔至少15 m,这样一个人被击中,其他人还能施救
- 双脚并拢蹲姿是来不及躲避时的最后手段: 蹲在干燥的背包、防潮垫上,
  双手抱膝,头低下;不要躺下、不要趴下
- 最后一声雷响后再等30分钟,才回到山脊、山顶
- 被雷击的人身上不带电,可以立即触摸;没有呼吸就立即做心肺复苏
```

雷电的原理、避雷的完整做法和雷击急救见[气象灾害-雷电](../02-灾难应对/02-气象灾害.md#雷电);判断雷暴距离见[判断雷暴距离](../02-灾难应对/02-气象灾害.md#判断雷暴距离)。

### 天气骤变

```
山地天气多变:
✓ 关注天气
✓ 早出发(午后易有雷暴)
✓ 准备防雨防寒
✓ 天气差时不冒险
```

```
具体怎么做:
- 出发前查天气预报和预警,看山顶(不是山下县城)的气温和风力
- 夏季山区多"午后雷暴": 上午晴朗,中午前后积云越长越高、顶部像花椰菜,
  午后就可能雷雨、冰雹 —— 所以要早出发,中午前后就开始下撤
- 变天的征兆: 远处山头被云罩住、风突然变凉变大、云层越来越低越来越厚、
  远处有雷声 → 停止上升,准备下撤
- 无论季节,背包里都要有保暖层和防雨层;夏天的高山遇到冷雨大风也会失温
- 能见度突然变差(起雾、下雪): 停在安全处,不要在悬崖边、山脊上摸索前进
- 天气不好时"今天不上了"永远是对的选择,山不会跑
```

看云识天气和雷暴的征兆见[天气观测与预报-看云识天气](../08-基础科学知识/07-天气观测与预报.md#二看云识天气)和[雷暴的征兆](../08-基础科学知识/07-天气观测与预报.md#23-雷暴的征兆)。

### 山洪

山区溪谷汇水快,上游下暴雨,下游可能还是晴天,洪水几分钟内就冲下来。

```
✓ 不在河滩、干河床、沟口、峡谷底部扎营、休息
✓ 溪水突然变浑、上涨或反常地断流,水里出现大量树枝杂草,
  听到上游有轰鸣 → 立即向河道两侧高处跑
❌ 不要顺着河谷往下游跑,不要涉水过急流
```

山洪征兆和涉水过河的详细方法见[涉水、山洪与野外失温](08-涉水山洪与野外失温.md#山洪-溪谷里最大的危险)。

### 失温和冻伤

```
山地失温的典型情况: 夏天或春秋,穿着单衣登山,突遇冷雨、冰雹、大风,
衣服湿透,在山脊上越走越冷 —— 2021年甘肃白银的山地越野赛就因此造成多人遇难

早期表现: 发抖、手脚不灵活、说话含糊、走路跌跌撞撞、反应迟钝、情绪反常
处理: 停止前进,离开风口,换下湿衣服,穿上所有干衣服、裹上保温毯,
      吃喝含糖的东西,下撤到低处;发抖停止而人越来越迷糊是加重的信号
预防: 不穿棉质衣物;保暖层和防雨层随身带;湿冷天气提前下撤
```

相关章节: [涉水、山洪与野外失温-不只是冬天: 野外失温](08-涉水山洪与野外失温.md#不只是冬天-野外失温)、[急性症状-失温症](../01-日常疾病和伤害/05-急性症状.md#失温症)、[外伤处理-冻伤](../01-日常疾病和伤害/02-外伤处理.md#冻伤)。

### 紫外线和雪盲

```
- 高海拔晒伤很快,阴天、凉爽时也一样
- 戴宽边帽、墨镜,露出的皮肤涂防晒霜,隔几个小时补涂;嘴唇也要防晒
- 在雪地、冰川上必须戴能挡紫外线的墨镜,否则几个小时后就可能雪盲
  (眼睛剧痛、流泪、怕光,往往在当晚才发作)
- 没有墨镜时,用布条、树皮、硬纸片开一道细缝,蒙在眼睛前
```

雪盲的处理见[雪地极地求生-雪盲](04-雪地极地求生.md#雪盲);在雪坡上行走还要注意[雪崩](04-雪地极地求生.md#雪崩)。

## 食物

```
高山:
- 植被稀少
- 动物少

可能:
✓ 鱼(溪流)
✓ 昆虫
✓ 小型动物
✓ 某些高山植物(需识别)
✓ 浆果(确认可食)
```

```
补充:
- 短期被困时,食物远没有保暖、水和求救重要;一个健康成年人几天不吃饭不会有生命危险,
  不要为了找吃的冒险攀爬、离开避险处
- 野外取食的原则: 不认识的不吃;野生蘑菇一律不吃
- "可食性测试"只能作为长期被困、没有其他办法时的最后手段,
  对蘑菇无效,对剧毒植物也不安全
- 高原上食欲差,但身体消耗大: 少量多次吃碳水为主的食物(饼干、面食、糖、巧克力)
- 平时捕猎、捕捉野生动物违反我国野生动物保护法律,很多高山动物是保护动物;
  只有在真正的生存危机中才考虑,并且以鱼、昆虫等为主
- 高原上水沸点低,米饭、豆类、肉煮不熟,用高压锅,或把食物切小、煮更久
```

相关章节: [毒蘑菇与野菜误食](09-毒蘑菇与野菜误食.md)、[基础生存技能-食物获取](00-基础生存技能.md#食物获取)。

## 信号

```
山地:
✓ 镜子反光(远距可见)
✓ 烟雾(峡谷中上升明显)
✓ 哨声(山谷回声)
✓ 鲜艳衣物(对比背景)
✓ 往开阔高地(更易被发现)
```

```
补充:
- 首选手机: 有信号就报警,发送定位截图;没有信号时也可以试着拨打紧急电话
- 国际求救信号是"三": 哨子吹三声一组,停一下再吹;火堆摆成三角形;
  长时间没有回应也要定时重复
- 镜子(或手机屏幕、金属片)反光: 对着飞机、远处的人或村庄晃动,晴天几 km 外都能看到
- 白天生烟、夜里点火,但要在没有枯草、远离树林的空地上,防止引起山火
- 把鲜艳的衣服、睡袋摊开在开阔处;在雪地、草坡上用石块、树枝摆出大字(SOS)
- 往开阔处移动只限于安全、不需要攀爬的情况;受伤、天黑、天气差时留在原地
- 听到直升机时,站在开阔处挥动鲜艳衣物;不要在山脊顶上、悬崖边招呼直升机
```

## 📝 山地求生要点

```
优先级:
1. 高原适应(防高反)
2. 避免坠落(小心行走)
3. 庇护所(防风寒)
4. 水(相对容易)
5. 火、食物

关键:
✓ 逐渐上升
✓ 小心行走
✓ 避雷电
✓ 迷路先停下,有人搜救就原地等待
✓ 注意天气

危险:
⚠️ 高原反应(下降!)
⚠️ 坠落
⚠️ 失温
⚠️ 雷电
⚠️ 滑坡

记住:
1. 海拔3000 m以上,睡眠海拔每天上升不超过约500 m,有症状就不再上升
2. 呼吸困难、咳粉红痰、走路不稳、意识改变 → 立即下撤,同时求救
3. 早出发、定好掉头时间,午后雷暴前离开山顶和山脊
4. 听到雷声就下撤;双脚并拢蹲姿只是最后手段
5. 迷路不沿陡谷往下走;有人知道你的行程,就原地等待
6. 夏天的高山也要带保暖层和防雨层
```
