## 大多数野外事故是怎么发生的

荒岛、沙漠求生是少数情况。现实中更常见的是: 周末徒步走了"野线"、天黑前没下山、手机没电、天气突变、走散。

```
常见原因:
- 擅自进入未开发、未开放区域,走没人维护的"驴友线路"
- 不告诉任何人自己去了哪里
- 低估路程,出发晚,天黑还在山里
- 只带了一件T恤,没有保暖和防雨的衣物
- 只靠手机导航,手机没电或没信号
- 不看天气预报,或看到变天还坚持往前走
- 队伍走散,有人掉队
```

⚠️ 黄山等多个景区已实行有偿救援: 擅自进入未开发、未开放区域遇险的,救援费用由组织者和被救者承担。**更重要的是,这类区域的救援往往要很长时间,有时来不及。**

## 出发前

### 留下行程单

**出发前把行程告诉一个不同行的人**,这是最简单、也最常被忽略的一步。

```
行程单写清:
- 去哪里: 起点、路线、终点(最好发一张路线截图)
- 什么时间出发、预计什么时间回来
- 同行的人和他们的电话
- 车停在哪里、车牌号
- 约定: "过了某个时间还联系不上我,就报警"

✓ 临时改变路线时,有信号的地方及时告诉对方
✓ 回来后告诉对方已经平安
```

### 查清楚

```
✓ 天气预报: 有暴雨、雷电、大风、降温预警的,改期
  (山区暴雨后几小时内可能爆发山洪,见涉水、山洪与野外失温)
✓ 路线: 是否是开放的正规路线,长度、爬升、需要几个小时
✓ 日落时间: 按日落前1-2小时下山来安排
✓ 沿途有没有补水点、手机信号、撤退路线
✓ 自己和同伴的体力,带老人孩子时缩短路线
```

相关章节: [涉水、山洪与野外失温](08-涉水山洪与野外失温.md)。

### 掉头时间

```
出发前定一个"掉头时间"(如下午2点):
- 到了这个时间,无论有没有到目的地,都往回走
- 大多数被困的人,都是因为"再往前走一点就到了"
```

## 装备

即使是计划几个小时的一日徒步,也要按"可能要在野外过一夜"来准备。

```
必带:
- [ ] 手机 + 充满的充电宝
- [ ] 头灯或手电,加备用电池(最常见的被困原因之一就是天黑)
- [ ] 保暖层: 抓绒衣或轻薄羽绒服(夏天的山上也要带)
- [ ] 防雨: 雨衣或冲锋衣
- [ ] 足够的水(一般每人至少1.5-2 L,天热或路线长时更多)
- [ ] 高能量食物,比计划多带一些
- [ ] 哨子(喊叫很快会让嗓子哑,哨声传得更远)
- [ ] 急救包: 创可贴、纱布、绷带、弹力绷带、个人常用药
- [ ] 应急保温毯(铝箔毯,很轻)
- [ ] 打火机

建议带:
- [ ] 登山杖(过河、下坡时很有用)
- [ ] 离线地图(出发前下载好)、指南针
- [ ] 帽子、墨镜、防晒霜
- [ ] 驱虫剂(防蜱虫、蚊子)

穿着:
✓ 合脚的登山鞋或运动鞋,不要穿新鞋
✓ 速干衣物,不穿棉质衣服(棉衣湿了不保暖,失温的重要原因)
✓ 长裤,裤腿扎进袜子(防蜱虫、防划伤)
```

更多装备见[野外生存指南-野外生存装备](README.md#-野外生存装备)。

## 途中

```
✓ 跟着路标和明显的路走,不抄"近道"
✓ 每隔一段时间回头看看来路(回程时认得)
✓ 在岔路口、地形变化处记住特征,或拍照
✓ 手机开省电模式,只在需要时看地图;有信号时打开位置共享
✓ 队伍: 最慢的人走在前面,有经验的人走在最后,不让任何人掉队
✓ 天气变坏、有人体力不支、时间来不及 → 果断下撤
❌ 不要单独离开队伍去拍照、方便,离开要告诉同伴
```

## 发现自己迷路了

```
1. 停下来,不要慌,不要继续乱走
   (越走越远、越走越累,是迷路后最常见的错误)
2. 想一想: 最后一次确定自己在哪里是什么时候,之后大概走了多久、往哪个方向
3. 看手机: 有没有信号?地图上能不能看到自己的位置?
4. 能找到原路且确定安全,就沿原路返回
5. 不能确定时:
   - 原地等待,打电话报警
   - 天快黑了,先在原地准备过夜(保暖、找避风处)
6. 不要沿着溪沟、峡谷往下走
   - 很多人以为"沿着水往下走就能出去"
   - 但山里的溪谷常常有瀑布、悬崖,还可能遇到山洪
   - 往往越走越陡,最后困在中间上下不得
```

更多迷路后的处理(STOP原则)见[基础生存技能-如果迷路](00-基础生存技能.md#如果迷路)。

## 报警求救: 说清楚你在哪里

### 打什么电话

```
✓ 110或119(都可以,会联动救援)
✓ 有信号就打,不要等到天黑、手机快没电才打
✓ 打不通电话时发短信,短信更容易发出去
  - 可以发短信到12110报警(号码后加省份代码)
✓ 部分手机支持卫星通信,没有地面信号时也能求救
```

相关章节: [应急通信与寻亲-灾中: 怎样让消息发出去](../02-灾难应对/06-应急通信与寻亲.md#灾中-怎样让消息发出去)。

### 怎样说清楚位置

**救援最难的一步是找到你。** 只说"我在某某山上"几乎没有用。

```
1. 经纬度(最准确):
   - 打开手机地图,长按自己所在的蓝点,通常会显示经纬度
   - 也可以在指南针等应用里看到
   - 把数字一个一个念给接警员,或用短信发过去

2. 发送位置:
   - 用聊天软件把实时位置发给家人或朋友,由他们转告救援人员

3. 描述:
   - 从哪里出发、走了多长时间、大概往哪个方向
   - 周围能看到什么: 山顶、河流、电线塔、房子、公路
   - 海拔(手机或手表上可能有)

4. 其他要说的:
   - 几个人,有没有人受伤、伤得多重
   - 有什么装备: 有没有头灯、保暖衣物、食物和水
   - 手机还剩多少电

✓ 打完电话后,保持手机开机待接救援人员的电话,其他时间省电
✓ 不要换位置: 一旦报了位置,就留在原地
```

## 等待救援

```
✓ 留在原地(或者最近的开阔、避风、安全的地方),不要乱走
✓ 保暖第一: 穿上所有衣服,坐在背包或树枝上,不要直接坐在地上
  - 用应急保温毯裹住身体
  - 几个人靠在一起
✓ 让自己容易被看见:
  - 鲜艳的衣服、物品摊在开阔处
  - 夜间用头灯、手机闪光灯
  - 听到人声或看到灯光时吹哨子(三声一组)
✓ 节省体力和手机电量
✓ 有水的话小口喝,食物分着吃
```

求救信号见[基础生存技能-求救信号](00-基础生存技能.md#求救信号),庇护所搭建见[基础生存技能-庇护所建造](00-基础生存技能.md#庇护所建造)。

## 看懂地图和等高线

手机没电时,纸质地图和指南针是最可靠的导航工具。出发前打印或买一份路线地区的地图。

### 等高线

```
等高线是把同一海拔高度的点连起来的线:
- 线越密 → 坡越陡;线越稀 → 坡越缓
- 线挤在一起几乎重合 → 悬崖、陡壁,不能走
- 一圈一圈闭合的小圈 → 山顶
- 等高线向高处弯曲凸出(V字尖端指向高处) → 山谷、沟,可能有水
- 等高线向低处弯曲凸出 → 山脊
- 两座山顶之间较低的地方 → 鞍部(垭口),常常是翻山的路线
```

### 用地图和指南针

```
1. 把地图摆平,转动地图,让地图上的北和指南针指的北一致
2. 对照地图找周围明显的地形: 山顶、河流、湖泊、公路
3. 确定自己在地图上的位置
4. 在地图上找出要去的方向,按指南针的方向走

⚠️ 指南针要远离手机、刀具、汽车等铁器和磁性物品,否则会指错
```

指南针的基本用法见[基础生存技能-导航与定向](00-基础生存技能.md#导航与定向)。

### 手机导航

```
✓ 出发前下载离线地图和路线轨迹
✓ 开启轨迹记录: 迷路时可以按轨迹原路返回
✓ 打开飞行模式也能用GPS定位(定位不需要手机信号),还更省电
✓ 手机是工具之一,不能是唯一的工具: 准备充电宝,或者纸质地图
```

## 📝 户外出行要点

```
1. 出发前把行程留给一个不同行的人,约好联系不上就报警
2. 只走开放的正规路线,不进未开发区域
3. 查天气、定掉头时间,天黑前下山
4. 一日徒步也要带头灯、保暖层、雨衣、充电宝、哨子
5. 迷路了先停下,不要沿着溪谷往下走
6. 有信号就报警,报经纬度或发送位置,然后留在原地
7. 等待时保暖第一,让自己容易被看见
```
