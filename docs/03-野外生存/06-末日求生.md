# 末日求生指南

⚠️ **本章节提供长期生存策略,适用于社会秩序严重崩溃的极端情况**

```
⚠️ 先说清楚: 本章的定位
- 这一章是全书"长期生存"的总纲: 讲原则、优先顺序、大致数量和常见错误,
  具体做法放在各个专门章节里,每一节末尾都给出链接
- 绝大多数灾难是暂时的: 停电、停水、地震、洪水、疫情,几天到几周内救援和秩序就会恢复。
  只要政府、救援队、医院还在运转,一切以官方通知和专业人员的指令为准,
  有人受伤先拨打120,不要因为"末日"的想象做出过激的事
- 本章不涉及武器。安全靠低调、组织、邻里互助和避免冲突,而不是对抗
```

一般灾害的家庭准备先看[灾难应对-家庭应急包](../02-灾难应对/README.md#-家庭应急包);野外迷路、受伤等短期求生见[基础生存技能](00-基础生存技能.md)。

## 核心原则

```
1. 安全第一
   - 人比东西重要: 任何物资都不值得拿命去换
2. 水、食物、庇护
   - 先后顺序: 保暖/防暑 → 水 → 卫生 → 食物;
     一个人几天不喝水就有生命危险,几周不吃饭还能活下来
3. 社区合作
   - 一家人守不住、也种不出一年的全部所需;几十人的社区才有分工的可能
4. 技能>物资
   - 物资总会用完,会种地、会净水、会急救的人才是长期的保障
5. 适应和灵活
   - 计划要有,但情况变了就改;不要为了"按原计划"冒险
6. 保持希望
   - 有目标、有日常、有人互相支持的群体,存活率明显更高
```

### 优先顺序一览

| 阶段 | 最要紧的事 | 最常见的致命错误 |
|------|-----------|-----------------|
| 第一天 | 人员安全、伤员处置、储水、收听官方信息 | 盲目出门察看、冒险抢物资 |
| 第一周 | 卫生(厕所、洗手)、定量、决定撤离还是固守、联络邻居 | 不定量、随地便溺、喝未处理的水 |
| 第一个月 | 稳定水源、组织值守和分工、开始种快熟蔬菜 | 囤积不分、与人结仇、明火和炉具引起火灾或一氧化碳中毒 |
| 1-6个月 | 粮食生产、燃料、记账配给、防传染病 | 吃掉种子粮、只种一种作物、砍光附近树木 |
| 6个月以后 | 社区制度、留种、教育、技术积累 | 没有规则、知识只在一两个人脑子里 |

## 初期(0-30天)

### 时间表: 第一天到第一个月

**第一小时**:
```
1. 确认所有家人安全;有人受伤先止血、保持呼吸道通畅,能打通120就打
2. 有燃气泄漏味道、建筑开裂、起火: 先关燃气总阀,离开危险建筑
3. 打开收音机、手机,收听官方信息(电视、广播、短信、社区通知)
4. 停水前尽快储水: 浴缸、水桶、锅、瓶子全部装满(浴缸水用于冲厕所和洗涤)
```

**第一天**:
```
1. 盘点: 有多少水、食物、药品、燃料、现金、电池,写下来
2. 先吃冰箱里的: 停电后冷藏室一般能保持低温约4小时,装满的冷冻室约2天;
   之后才动用罐头、干粮
3. 按家庭通信计划联系家人,约定集合点
4. 检查慢性病患者的药还剩多少天;胰岛素等需要冷藏的药想办法降温保存
5. 把应急包放在门口,随时准备撤离
```

**第一周**:
```
1. 定量: 不确定什么时候恢复供应时,从第二天起就按计划吃,不要等快吃完才省
2. 下水道不通时立即改用应急厕所(双桶法),不要往堵塞的马桶里继续排便
3. 设洗手点: 便后、做饭前、吃饭前必须洗手(这是防腹泻最有效的一条)
4. 和邻居见面: 谁家有老人、婴儿、病人,谁有医疗、电工、种地的技能
5. 决定撤离还是固守(见下)
6. 开始轮流值守和夜间防火检查
```

**第一个月**:
```
1. 找到并保护一个长期水源(井、泉、可收集雨水的屋顶)
2. 组织起来: 选出负责人,记账、分组(见"社区重建")
3. 种快熟蔬菜和芽菜(豆芽几天就能吃,补维生素C)
4. 准备燃料: 收集干柴,至少储够一个月做饭的量
5. 记录: 每天的消耗、发生的事、新加入的人
```

### 立即行动

**撤离 vs 固守**:
```
撤离,如果:
- 当前位置不安全
  (建筑受损、洪水或火灾威胁、化学品或辐射污染、持续的暴力冲突)
- 有安全目的地
  (亲友家、安置点,并且确认那里能接纳你)
- 有交通工具和燃料
  (或者全家都能步行到达,包括老人和孩子)
- 有足够物资
  (至少够路上和到达后头几天用)

固守,如果:
- 相对安全
- 有储备
- 有防御
  (门窗结实、邻里能互相照应)
- 熟悉环境
  (知道水源、邻居、医院、可以撤离的路线)

⚠️ 官方要求撤离时,按官方路线和时间撤离,不要固守
⚠️ 没有明确目的地的"出逃"最危险: 路上没有水、没有住处、容易遇到冲突
⚠️ 家里有卧床病人、婴儿、孕晚期妇女时,撤离的风险要算进去
```

**撤离时**:
```
✓ 提前定好两条路线和一个备用集合点
✓ 带: 应急包、证件、药品、水、现金、手机和充电宝、换洗衣物
✓ 关闭水、电、燃气总阀,锁门
✓ 在门上或约定地点留下去向(写给家人,不要写给陌生人看的细节)
✓ 结伴行动,不分散;白天走,不走夜路
```

撤离路线和集合点见[人为灾难-撤离](../02-灾难应对/05-人为灾难.md#撤离);应急包内容见[灾难应对-家庭应急包](../02-灾难应对/README.md#-家庭应急包)。

### 基本需求

**水**:
```
✓ 储备(每人每天4 L)
  - 其中饮用约2-3 L(炎热、劳动、哺乳时更多),其余做饭
  - 洗手、洗漱、冲厕所的水另外算,可以用雨水、河水等未经净化的水
    (洗手、洗碗的水最好也消毒)
  - 2周储备 = 每人约56 L饮用和做饭用水;一家3口约170 L
✓ 净化方法(煮沸、过滤、化学)
  - 煮沸: 烧到大开后再煮1分钟(海拔2000 m以上3分钟),最可靠
  - 含氯消毒: 每升清水2滴家用漂白水、浑水4滴,等30分钟
  - 浑水先沉淀、过滤,再消毒
✓ 备用水源(雨水收集、附近水源)
✓ 至少2周储备
  - 储水容器: 干净、有盖、不透光、食品级,标上日期
  - 自来水装满密封的容器约6个月更换一次

判断喝够了没有: 尿是淡黄色、量正常;深黄、尿少、口干、头晕说明缺水
❌ 不要喝: 汽车水箱水、游泳池水、来源不明的工业用水、海水、尿
```

需要多少水见[水源工程与供水-需要多少水](../07-日常生活技能/10-水源工程与供水.md#需要多少水);净水见[水源工程与供水-净化](../07-日常生活技能/10-水源工程与供水.md#净化-从浑水到可以喝的水)、[基础生存技能-水质净化](00-基础生存技能.md#水质净化)。

**食物**:
```
✓ 长期储备:
  - 罐头(数年)
  - 干粮(大米、面、豆类)
  - 能量棒
  - 盐、糖、油
✓ 至少1个月储备
  - 以粮食为主食时,成年人每天约0.5 kg粮食(约2000 kcal以上);
    一个月约15 kg
✓ 轮换使用(先进先出)
  - 平时就吃储备的东西,买新的补到后面,不要存了不吃、到期全扔

先后顺序: 冰箱里的生鲜 → 新鲜蔬果 → 面包、鸡蛋等短期食物 → 罐头和干粮
✓ 一开始就定量,不是等快吃完才省
✓ 保证每天有豆类、一点油和蔬菜(或豆芽),只吃米面几个月会得营养缺乏病
❌ 不要吃: 鼓胀、漏气、生锈严重的罐头;发霉的粮食、花生;
   泡发时间过长的木耳、发酸的米面制品(米酵菌酸中毒,极难救治)
```

储备粮引起的营养缺乏病见[营养与营养缺乏病](../07-日常生活技能/02-营养与营养缺乏病.md#为什么储备粮会让人生病);食物中毒见[食物加工与保存-高风险食品与食物中毒](../07-日常生活技能/01-食物加工与保存.md#高风险食品与食物中毒)。

**庇护所**:
```
✓ 加固住所
  - 检查房屋是否受损;有明显裂缝、倾斜的房子不要住
✓ 备用避难所
  - 亲友家或邻居家,事先约定
✓ 防御准备
  - 门锁、门窗加固、照明(见"安全")
✓ 保持低调
  - 夜里遮光,不让人看出你家有电、有暖气、有储备

保暖: 寒冷季节集中住进一个房间,封好漏风的窗缝,多层衣物、被褥,
      睡觉隔开地面;老人和婴儿最怕冷
防暑: 白天关窗遮阳,早晚通风;多喝水,避开最热的时段劳动
```

长期住所见[长期住所](../07-日常生活技能/05-长期住所.md);野外临时庇护所见[基础生存技能-庇护所建造](00-基础生存技能.md#庇护所建造)。

### 安全

秩序混乱时,人们受到的伤害大多不是来自坏人,而是来自**火灾、一氧化碳、摔伤、冻伤、腹泻和与熟人的冲突**。安全措施按这个顺序考虑。

**防御**:
```
✓ 加固门窗
  - 门要能从里面可靠地锁住;一楼窗户加固
  - 不要把所有出口都封死: 火灾时必须能逃出去
✓ 应急逃生路线
  - 每个房间至少两条出路,全家知道在哪集合
✓ 观察哨(了解周围)
  - 白天留意周围有什么人来往、发生了什么变化
✓ 警报系统(自制)
  - 门口挂铃铛、串起来的空罐头;晚上门窗附近放容易碰响的东西
✓ 保持警惕
  - 夜间轮流值守: 2人一组,每班2-4小时,有事先叫醒其他人,不单独处理
```

**防火和一氧化碳**(秩序混乱时最常见的死因之一):
```
✓ 明火照明、蜡烛不离人,远离窗帘、被褥;睡前全部熄灭
✓ 不在室内、帐篷里、车库里用炭火盆、发电机、燃气烤炉取暖或做饭
✓ 室内生火必须有烟囱或良好通风
✓ 屋里放几桶水、沙子,有灭火器更好
✓ 燃料(汽油、液化气、柴油)放在通风的屋外,远离住处和火源
⚠️ 头痛、头晕、恶心,同屋几个人一起出现 → 先怀疑一氧化碳中毒,
   立即开窗、把人移到外面
```

**人员**:
```
✓ 建立信任的小组
  - 从家人、邻居、同事开始;同一栋楼、同一个村最自然
✓ 分工合作
✓ 守望相助
  - 帮助老人、残疾人、带孩子的邻居,他们最先陷入困境,
    也会成为你的盟友
✓ 谨慎对待陌生人
  - 隔着门或在院外交谈;几个人一起出面,不单独接触
  - 不透露家里有多少人、多少储备
  - 有能力时给一点水或食物,并告诉对方安置点、救济点在哪里
  - 想加入的人: 先了解他会什么、从哪里来,经大家商量后再决定

化解冲突:
✓ 对方情绪激动时,语气平和,给对方台阶下
✓ 退一步、给一些物资,换取平安,往往是最好的结果
✓ 遇到暴力威胁,优先躲避、离开,能报警就报警(110)
❌ 不要为了保住物资和人动手、追赶
```

一氧化碳中毒见[居家与交通意外-一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒);火灾预防见[火灾-火灾预防](../02-灾难应对/04-火灾.md#火灾预防);明火照明见[照明与能源-使用明火照明的安全规则](../07-日常生活技能/06-照明与能源.md#使用明火照明的安全规则);战乱时的避险见[人为灾难-战乱与武装冲突](../02-灾难应对/05-人为灾难.md#战乱与武装冲突)。

## 中期(1-6个月)

如果一个月后供应仍未恢复,就要从"消耗储备"转向"自己生产"。储备是给你争取时间的,目标是在储备吃完之前收获第一批粮食。

### 自给自足

**优先顺序**:
```
1. 稳定、干净的水源 —— 没有水,一切都谈不上
2. 卫生: 厕所、洗手、垃圾处理 —— 腹泻是灾后最大的杀手之一
3. 快熟蔬菜和芽菜 —— 1-2个月内有收获,防营养缺乏病
4. 主粮和薯类 —— 决定能不能活过第一个冬天
5. 燃料 —— 做饭、烧水、取暖都靠它,柴要提前晒干
6. 盐 —— 人和牲畜都离不开,也用来腌制保存食物
7. 养殖 —— 鸡最容易,先从几只开始
```

**水源**:
```
✓ 雨水收集系统
  - 屋顶接水,弃掉每场雨最先流下的脏水;储水桶加盖防蚊
✓ 水井(如可能)
  - 挖井有塌方、缺氧的危险,必须有人在上面守着,不要独自下井
✓ 附近溪流
  - 取水点在村子和厕所的上游
✓ 净化设备
  - 慢砂过滤 + 煮沸或消毒,能长期供应一个社区
✓ 循环利用(灰水)
  - 洗菜、洗衣的水可以浇地(不浇直接生吃的蔬菜)、冲厕所

⚠️ 厕所、畜圈、垃圾坑离水源至少30 m,并在水源的下坡方向
```

具体做法见[水源工程与供水](../07-日常生活技能/10-水源工程与供水.md)(收集雨水、挖井、慢砂过滤、储存)。

**食物生产**:
```
✓ 种植:
  - 快速作物(萝卜、生菜、小白菜、菠菜: 30-60天)
  - 高产作物(土豆、玉米)
  - 储藏作物(南瓜、红薯)
  - 豆类(大豆、豇豆、豌豆: 蛋白质,还能改良土壤)

✓ 养殖:
  - 鸡(蛋、肉)
  - 兔(繁殖快)
  - 鱼(如有水源)

✓ 觅食:
  - 野生植物
  - 狩猎、捕鱼
  - 昆虫

大致需要: 每人一年约180 kg粮食(每天约0.5 kg),薯类按鲜重计要多几倍
种植顺序建议: 土豆、红薯 → 玉米 → 大豆 → 有水的地方种水稻 → 小麦

常见错误:
❌ 吃掉种子粮 —— 吃掉种子就没有明年
❌ 只种一种作物 —— 一场病虫害或天灾就全军覆没
❌ 用杂交种(F1)的种子留种 —— 第二代性状分离,产量大降
❌ 采不认识的野菜、野蘑菇 —— 毒蘑菇没有简单的鉴别方法,
   "可食性测试"只是极端情况下的最后手段,对蘑菇无效
⚠️ 平时野生动物受法律保护,禁止捕猎;只有在无法获得其他食物、
   秩序完全崩溃时才考虑,优先捕鱼和昆虫
```

相关章节: [蔬菜种植-快速生长蔬菜](../04-动植物培育/01-蔬菜种植.md#快速生长蔬菜30-60天)、[粮食作物-新手推荐种植顺序](../04-动植物培育/02-粮食作物.md#新手推荐种植顺序)、[家禽养殖](../04-动植物培育/05-家禽养殖.md)、[水产养殖](../04-动植物培育/07-水产养殖.md)、[留种与育种-杂交种为什么不能留种](../04-动植物培育/08-留种与育种.md#杂交种f1为什么不能留种)、[毒蘑菇与野菜误食](09-毒蘑菇与野菜误食.md#采食野菜野果的原则)、[基础生存技能-可食植物测试](00-基础生存技能.md#可食植物测试)。

**能源**:
```
✓ 柴火(烹饪、取暖)
  - 只做饭: 每人每天约1.5-3 kg风干柴;取暖的用柴往往比做饭多得多
  - 湿柴烟大、热量低,砍下的柴要晾干后再烧,所以要提前一季准备
  - 先用枯枝、倒木、废木料,不要砍光房前屋后的树
✓ 太阳能(如有设备)
  - 优先给收音机、手机、照明充电,不要用来取暖做饭
✓ 人力(自行车发电机等)
✓ 保存热量
  - 一锅多用: 烧饭的同时烧水;用保温桶、草窝焖煮省柴
  - 有火炕的地区,做饭的火同时烧炕
```

### 物资管理

```
✓ 清单记录
  - 每样东西: 名称、数量、存放地点、入库日期、有效期
  - 进出都记流水账,定期盘点核对
✓ 配给分配
  - 按需要分,不是平均分: 重体力劳动者、孕妇和哺乳期妇女、生长期的儿童、病人多分
  - 规则事先定好、公开;两人一起发放,当场登记
✓ 循环利用
✓ 物物交换
  - 社区统一秤和量具;以粮食作为计价单位,列参考价格表
  - 和外人交易在社区外的固定地点,几个人一起去,不暴露储备总量
✓ 节约使用

算一算够用多久:
  可用天数 = 库存总量 ÷ 每天的消耗量
  例: 300 kg粮食,10人,每人每天0.5 kg → 300 ÷ 5 = 60天
  离下次收获还有90天 → 现在就要节约、补种快熟作物、采集、交换

常见错误:
❌ 只记脑子里,不写下来
❌ 一个人既管钥匙又记账(容易出错,出了错说不清)
❌ 所有粮食存在一个地方(一场火、一次鼠害就全没了)
❌ 种子粮和口粮混放
```

记账、库存、配给、交易的具体做法见[记账交易与社会分工](../07-日常生活技能/13-记账交易与社会分工.md)(特别是[库存管理](../07-日常生活技能/13-记账交易与社会分工.md#库存管理)、[配给](../07-日常生活技能/13-记账交易与社会分工.md#配给)、[交易](../07-日常生活技能/13-记账交易与社会分工.md#交易))。

## 长期(6个月+)

### 社区重建

一个人或一家人可以撑过几个月,但要长期活下去、生活越来越好,需要一个有分工的社区。历史上和各地灾后的经验都说明: **组织起来的群体比各自为战的个人活得好得多**。

**组织**:
```
✓ 建立/加入社区
  - 几户到几十人: 能维持农业、养殖、留种、木工、纺织、急救卫生
  - 几百人: 才有条件冶铁锻造、烧砖、办学校
✓ 分工专业化
  - 先做技能登记: 每个人会什么、愿意学什么
  - 常见分组: 农业、水和卫生、燃料和建造、医护、后勤记账、教育
✓ 资源共享
✓ 集体防御
  - 共同值守、共同防火,比各家各管一摊省力得多
✓ 技能互补
```

**规则**:
```
✓ 基本法纪和秩序
  - 重要规则写下来、公开,所有成年人都知道
  - 例: 水源周围不准洗衣、粮仓钥匙谁保管、怎样处理违规
✓ 公平分配
  - 管钥匙的人不记账,记账的人不管钥匙;账目定期公开
  - 老人、病人、残疾人不能因为不能劳动就少分到食物
✓ 冲突解决机制
  - 先听双方说完,找没有利害关系的人调解,按事先定好的规则处理
✓ 共同目标
  - 重大决定(搬迁、接纳新成员、动用种子粮)开会讨论,记录下来

常见错误:
❌ 由一个人说了算,没有监督
❌ 规则只在口头,出了事各说各的
❌ 排斥外来者 —— 新来的人往往带来社区缺的技能;
   按规则审核、观察,而不是一概拒绝
```

### 健康

没有医院时,**预防比治疗重要得多**: 历史上饥荒和战乱中死去的人,多数死于腹泻、呼吸道感染、营养不良和伤口感染,而这些大多可以靠卫生和营养预防。

**预防**:
```
✓ 卫生(洗手、清洁)
  - 便后、做饭前、吃饭前、照顾病人后用肥皂洗手;没有肥皂用草木灰
✓ 食物安全
  - 生熟分开,剩饭菜彻底加热;不吃发霉、变质的食物
✓ 水质净化
✓ 垃圾处理
  - 厨余堆肥,其他垃圾挖坑填埋,远离水源和住处
✓ 防虫防鼠
  - 清除积水防蚊;粮食密封防鼠
✓ 营养
  - 碘盐、豆类、蔬菜或豆芽缺一不可;孕妇、婴幼儿、老人特别注意
✓ 安全劳动
  - 伐木、挖井、上房最容易受伤,做之前想好安全措施,不要单独干
```

**医疗**:
```
✓ 急救技能
  - 至少一半成年人会止血、心肺复苏、处理烧烫伤、固定骨折
✓ 药品储备
  - 常用非处方药按说明书使用;慢性病处方药按医嘱逐步积累
✓ 草药知识
  - 只用认得准、有可靠资料的药用植物;用法和用量查清楚再用
✓ 隔离病患
✓ 基础护理
  - 退热、补液、翻身防压疮、喂食、清洁,能救回很多人

⚠️ 只要还能联系到医院、医生、卫生院,就要送医,不要自己硬扛
⚠️ 婴儿、孕妇、老人病情变化快,标准要放宽: 早发现、早处理
```

**心理**:
```
✓ 保持规律作息
✓ 娱乐活动
✓ 互相支持
✓ 保持希望
✓ 设定目标
```

## 特殊情境

### 核灾难

核与辐射事故时,公众面对的主要危险是**放射性灰尘(沉降物)**。核心是**时间、距离、屏蔽**: 待得越短、离得越远、隔着的墙和土越厚,受到的照射越少。

```
初期:
✓ 躲避(地下室、内部房间)
  - 立即进入室内: 最好是地下室,或楼房中部、远离外墙和屋顶的房间
    (顶层离屋顶落灰近,一楼离地面落灰近)
  - 在户外的人尽快进入最近的坚固建筑;木板房、汽车的屏蔽作用很弱
✓ 密封门窗
  - 关闭空调、排风扇、新风系统、抽油烟机
✓ 收听信息
✓ 储备的食物和水
  - 事故前已经密封保存的水和食物可以吃;室外的雨水、露天的水不要喝
✓ 不外出
  - 先做好至少待24小时的准备;落灰在最初几个小时最危险,强度随时间下降很快,
    没有通知不要出门察看
  - 粗略规律: 核爆落灰的辐射强度,约7小时后降到约1/10,约2天后降到约1/100

中期:
✓ 听从官方指导
  - 撤离还是继续就地掩蔽,按自己所在区域的通知做;撤离不要往下风方向走
✓ 避免污染食物和水
  - 菜地里的菜、树上的果子、放养的家禽家畜和奶、蛋,检测之前不要吃
  - 煮沸和普通净水器去不掉放射性物质
✓ 除污(脱衣、淋浴)
  - 进门前脱掉外衣和鞋,装袋密封放远处(可去除大部分污染)
  - 温和淋浴,用洗发水不用护发素;没有条件时用湿毛巾擦洗露在外面的皮肤和头发
✓ 碘片(官方指导下)
  - 只在官方通知时服用;没有通知不要自行"预防性"服用
  - 只保护甲状腺不吸收放射性碘,不防其他辐射
  - ❌ 不要吃碘盐、喝碘酒或碘伏代替碘片(会盐中毒或中毒)

长期:
✓ 监测辐射
✓ 远离高污染区
✓ 定期健康检查
  - 事故后几小时内出现恶心、呕吐、乏力、皮肤发红,要立即告诉医护人员
✓ 心理疏导
  - 对辐射的恐惧和不确定,往往比辐射本身影响更多的人
```

详细做法(就地掩蔽的步骤、撤离、核爆炸时、碘片的作用和禁忌)以[人为灾难-核辐射](../02-灾难应对/05-人为灾难.md#核辐射)为准;辐射剂量的物理基础见[现代物理-辐射剂量](../09-进阶科学与工程/06-现代物理.md#64-辐射剂量)。

### 瘟疫

```
✓ 隔离病人
  - 病人住单独的房间;没有单独房间时保持1 m以上距离,用帘子隔开
  - 固定一个人照顾(最好不是老人、孕妇、慢性病患者)
✓ 个人防护(口罩、手套)
  - 接触病人的分泌物、呕吐物、粪便时戴手套,摘手套后立即洗手
✓ 消毒
  - 常摸的地方每天消毒;病人的衣物床单单独洗,能用热水就用热水
✓ 避免接触
  - 疫情期间减少聚集;外来人员先在单独住处观察约2周再进入社区
✓ 增强免疫(营养、休息)
✓ 照顾病患(做好防护措施)
  - 腹泻病人最要紧的是及时补液(口服补液盐),很多人死于脱水而不是病本身

社区层面:
✓ 记录: 每天谁发热、腹泻、出疹,及早发现流行的苗头
✓ 水源和厕所是防肠道传染病的关键,霍乱、伤寒、痢疾都是"吃进去的"
✓ 死者遗体按防护要求处理;但普通灾难中的遗体一般不会引起瘟疫,不要因恐慌乱埋乱烧
⚠️ 能联系到医疗机构和疾控部门时,按他们的要求隔离和治疗
```

具体做法见[传染病家庭防控](../01-日常疾病和伤害/15-传染病家庭防控.md)(特别是[居家隔离](../01-日常疾病和伤害/15-传染病家庭防控.md#居家隔离)、[家用消毒液的配制](../01-日常疾病和伤害/15-传染病家庭防控.md#家用消毒液的配制)、[腹泻类传染病](../01-日常疾病和伤害/15-传染病家庭防控.md#腹泻类传染病));遗体处理见[灾后遗体处理-传染病死者](../02-灾难应对/07-灾后遗体处理.md#传染病死者)。

### 社会崩溃

```
✓ 低调(不显富)
  - 不在外面吃东西、不展示储备;做饭的烟和香味也会引人注意
✓ 守望相助
✓ 避免冲突
  - 能谈就谈,能让就让;冲突中受了伤,在没有医院的时候可能就是致命的
✓ 保持移动性(能快速撤离)
  - 应急包随时放在门口,车里保持有油(如有车)
✓ 多个藏身处
  - 物资分散存放: 一处被发现或毁坏,还有别处
✓ 建立信任网络
  - 和附近几个社区保持联系,互通消息、交换物资、互相救援
```

## 储备清单

先按顺序准备: **3天 → 2周 → 3个月**。3天的应急包大多数家庭都应该有;更多的储备在有余力时逐步增加,平时轮换着吃,不要一次性大量囤积,也不要在灾难来临时哄抢。

### 基础储备(3-6个月)

**按人估算的数量**(成年人,3个月;儿童、老人少一些,重体力劳动、哺乳期多一些):

| 物资 | 每人每天约 | 每人3个月约 | 说明 |
|------|-----------|------------|------|
| 饮用和做饭用水 | 4 L(饮用约2-3 L) | 储备2周约56 L | 更长时间靠水源和净化,不靠储备 |
| 粮食(米、面、杂粮) | 0.5 kg | 45 kg | 不要只存精白米,存一些糙米、杂粮 |
| 豆类 | 50 g | 4.5 kg | 黄豆、绿豆;能发豆芽补维生素C |
| 食用油 | 25 g | 2.5 L | 避光、阴凉;过期会变哈喇味 |
| 碘盐 | 5 g | 0.5 kg | 腌制食物另外准备 |
| 糖 | 少量 | 1 kg | 也可用于口服补液 |

**食物**:
```
- 大米、面粉、豆类
- 罐头食品
- 食用油、盐、糖
- 奶粉
- 能量棒、干果
- 调味料
- 维生素
```

## 心理准备

```
末日情境的心理挑战:
- 恐惧、不确定
- 失去、哀伤
- 压力、焦虑
- 孤独

正常的反应: 灾后最初几周失眠、做噩梦、容易受惊、麻木、易怒,
大多数人会随时间慢慢缓解;这不是软弱

应对:
✓ 保持规律作息
  - 固定的起床、吃饭、劳动、休息时间,让人有"日子还在过"的感觉
✓ 互相支持
  - 每天有一段时间大家坐下来说说话;不逼人讲经历,愿意讲时认真听
✓ 设定目标
  - 小而具体: "这周修好水桶""月底前种完这块地"
✓ 庆祝小胜利
✓ 保持人性
  - 守住底线: 照顾弱者、信守承诺、尊重死者
✓ 保持希望
✓ 记录历史
✓ 保护儿童
  - 孩子的安全感来自大人: 尽量和家人在一起,维持游戏、上课和日常
✓ 文化传承
  - 节日、讲故事、唱歌、教孩子认字,这些都是让人撑下去的东西

需要特别留意的人:
⚠️ 长时间不吃不睡、不说话、对什么都不感兴趣
⚠️ 说"活着没意思""大家没有我会更好",或者开始交代后事、送掉心爱的东西
→ 不要回避,直接、温和地问;陪着他,不让他独处,收走危险物品,
  能联系到专业人员时尽快联系

照顾别人的人也要照顾自己: 轮流休息,累了说出来

记住:
人类坚韧不拔!
历史上无数次重建
保持信念和行动
```
