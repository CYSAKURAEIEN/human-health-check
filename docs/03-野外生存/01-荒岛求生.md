# 荒岛求生指南

> 现实中"流落荒岛"多发生在船只遇险、小船漂流、赶海被困沙洲之后。大多数海岛离航线、渔场或有人居住的岛屿并不远,**活下来的关键是保住体温和水分、让自己被看见,等待救援**,而不是长期定居。
>
> 有手机信号时先求救: 海上遇险拨打12395,也可拨打110、120。报警时怎样说清位置见[户外出行准备与求救-报警求救](07-户外出行准备与求救.md#报警求救-说清楚你在哪里)。

## 优先任务

### 第一24小时

```
1. 急救处理伤病
2. 寻找/建造临时庇护所
3. 寻找淡水
4. 发出求救信号
5. 探索环境
```

上面是大致顺序,实际上很多事要同时做。热带海岛上最先要命的通常是**海浪、暴晒和脱水**,而不是饥饿。

```
第1小时: 先保命
1. 离开海浪和潮水能到的地方,到最高漂流物线以上(见"庇护所-选址")
2. 清点人数;处理危及生命的情况: 大出血先压迫止血,
   溺水者检查呼吸,无反应、无正常呼吸立即CPR
3. 检查每个人的伤: 划伤、骨折、晒伤、受凉;泡过冷水的人脱下湿衣服保暖
4. 打捞冲上岸的物品,但不要为了漂在海里的东西再下水
   (离岸流、碎浪、礁石区最容易出事)
5. 试一下手机: 有信号立即求救;没有信号就关机或开飞行模式省电

第1-6小时: 遮阳和水
6. 在阴凉处休息,白天最热的时候不要干重活
7. 清点所有能装水、接水的东西: 瓶子、塑料袋、塑料布、雨衣、罐头盒、椰子壳
8. 把接雨水的东西提前铺好(热带的阵雨常常来得快、停得也快)
9. 有剩余的淡水,按需要喝,不要硬省着不喝(见"水源")

天黑以前: 过夜准备
10. 在高潮线以上搭一个能遮阳挡雨的简易棚,地面垫高、垫干
11. 收集足够烧一夜的干柴,生火(取暖、驱蚊、夜间信号)
12. 在海滩显眼处准备好信号火堆,随时可以点着
13. 在凉快的清晨或傍晚,沿海岸线走一段,看有没有人、房屋、
    道路、码头、淡水,不要独自深入丛林;走之前告诉同伴方向和回来的时间

第一夜:
14. 有人轮流值班照看火和信号,留意潮水和天气
15. 记下日期和发生过的事(见"长期生存")
```

```
有孩子、老人或伤员时:
- 孩子和老人比成年人更快脱水、更容易晒伤和中暑,
  让他们一直待在阴凉处,水优先给他们
- 每隔一两个小时看一次: 有没有尿、尿是什么颜色、精神好不好
- 伤员的情况写下来(什么时间、什么伤、做了什么处理),等救援时交给医生
```

现场评估和止血、CPR见[基础急救知识](../01-日常疾病和伤害/00-基础急救知识.md),野外伤员的照顾和伤情记录见[野外伤病处置与转运-写一份伤情记录](11-野外伤病处置与转运.md#写一份伤情记录),溺水者救上岸后的处理见[急性症状-溺水](../01-日常疾病和伤害/05-急性症状.md#溺水)。

## 水源

### 为什么不能喝海水

```
海水含盐约3.5%: 1 L海水里约有35 g盐
人的肾脏能排出的尿,最咸也比海水淡
→ 喝进1 L海水,要排出比1 L更多的尿才能把这些盐排掉
→ 越喝越渴,身体里的水反而更少
另外海水里的镁盐会引起腹泻,进一步丢水

❌ 不要喝海水,也不要把海水掺进淡水里"省水"
❌ 不要喝尿: 尿里是身体要排出去的盐和废物,喝回去同样加速脱水
✓ 海水可以用来洗东西、打湿衣服给身体降温,
  但皮肤上的盐要尽量用少量淡水或雨水擦掉,否则容易起疹、生疮
```

### 海岛取水

**雨水**(最佳):
```
✓ 收集雨水(容器、塑料布)
✓ 树叶引流
✓ 挖坑收集
✓ 最安全的水源
```

```
能收多少: 1 mm 雨落在 1 m² 上就是 1 L
例: 一块 2 m × 3 m 的塑料布(6 m²),一场 10 mm 的阵雨,
    理论上能接约 60 L,实际有损耗,能接到一半左右也很可观

怎么接:
1. 塑料布四角绑在树或木桩上,一角放低,下面放容器
   (或者中间压一块石头让它凹下去,在凹处底下扎小孔引流)
2. 大片的棕榈叶、芭蕉叶、香蕉叶斜着摆放,叶尖对着容器
3. 树干上缠一圈布条,把布条的一头引到容器里,可以接到顺树干流下来的雨水
4. 沙地上挖坑,铺塑料布或几层大叶子,做成"蓄水池"
5. 椰子壳、竹筒、贝壳都能当容器;提前摆好,天一下雨就能接

要点:
- 刚下雨的头几分钟先冲洗塑料布和叶子(上面有海盐、鸟粪、灰尘),
  这部分水不要,之后再接
- 接好的水加盖或用叶子盖住,放在阴凉处,防止蚊子产卵、落入杂物
- 有条件就煮沸再喝;实在没法煮,直接从干净塑料布上接的雨水风险最低
- 能装多少就装多少: 下一场雨可能要等很多天
```

**露水**:
```
- 清晨用布擦草
- 拧到容器
```

```
补充:
- 日出前就要收(太阳一出来很快蒸发)
- 塑料布、船体、金属片表面清晨也会凝结露水,用布擦下拧干
- 露水很重时每小时可能收到几百 mL,多数时候更少,只能当补充
- 擦有盐分的海边草叶、礁石得到的水会发咸,尝一下再决定喝不喝
```

**太阳能蒸馏器**(最后手段,产水很少):
```
1. 挖坑,中央放容器
2. 可放海水或湿沙(不直接接触容器)
3. 铺塑料布,边缘压实
4. 中央放石子
5. 蒸发凝结成淡水
6. 产量: 实测通常每天几十到几百 mL,挖坑出汗可能比产水还多
   (海岛优先收集雨水,其次蒸腾袋)
```

```
现实估计:
- 一个人在炎热的海岛上每天至少需要约2-3 L饮水,干活、出汗多时更多
- 一个蒸馏器一天几十到几百 mL,也就是说要做十个以上才够一个人喝,
  而挖十个坑本身就要流掉大量的汗
- 所以它只适合: 有现成透明塑料布、不用大量挖掘、雨水和其他水源都没有时

做的话:
- 在清晨或傍晚动手,不要在正午挖坑
- 海边用海水效果比湿沙好: 把海水倒进深色的盘子、罐头盒里放在坑底,
  集水的容器放在正中央,不能被海水溅到
- 塑料布不能碰到集水容器以外的地方,否则水珠会顺着流回坑里
- 每天尝一下收到的水: 发咸说明海水溅进去了
```

太阳能蒸馏器的通用做法见[基础生存技能-太阳能蒸馏器](00-基础生存技能.md#太阳能蒸馏器最后手段)。

**用火蒸馏海水**:
```
海岛上漂流木多时,用火煮海水、收集蒸汽,比太阳能蒸馏器产水多得多,但很费柴:
1. 在锅、罐头盒里煮海水
2. 收集蒸汽:
   - 锅口上方盖一块布,布吸满水汽后拧到另一个容器里;或
   - 在锅盖内侧凝结的水珠顺着倾斜的盖子流下来,用容器接住;或
   - 有管子(竹管、金属管)时,一头接在密闭的锅口,
     另一头穿过浸湿的布或海水降温,冷凝的水从末端滴出
3. 冷凝下来的水就是淡水;锅里剩下的浓盐水可以继续加海水煮,
   最后得到的盐可以留着用

现实估计: 敞口的火效率很低,每得到1 L淡水往往要烧掉好几 kg 干柴
不要让锅里的海水煮干,也不要让沸腾溅起的海水混进收集的水里
```

**植物取水**:
```
- 绿椰子(大量淡水)
- 竹子节间
- 藤蔓(切断,水滴出)
- 蒸腾水(塑料袋套枝叶)
```

```
椰子水: 好东西,但有限度
- 嫩的青椰子(摇起来水声闷、壳绿)水多,一个通常有几百 mL;
  刚打开的椰子水是无菌的,可以直接喝
- 成熟的褐色椰子水少,椰肉和椰浆油脂多,吃多了容易腹泻
- 一般建议每天喝几个就够,不要大量地只靠椰子水:
  喝太多会腹泻,反而丢水;椰子水含钾多、含钠少,不能完全代替口服补液盐
- 不建议爬高大的椰子树(摔伤在荒岛上可能致命),
  先捡地上的、用长杆钩够得着的

藤蔓水:
- 只取流出来清澈、无色、不苦、不黏的;乳白色汁液、苦、黏的一律不喝
- 先在藤上高处砍一刀,再在低处砍断,水才会流出来

蒸腾袋: 透明塑料袋套在向阳的绿叶枝条上,袋口扎紧,
        袋子最低处放一块小石子,几小时后取水;每个袋子一天几十到几百 mL,
        套在有毒植物上收到的水不能喝
```

**地下水**:
```
在沙滩:
1. 高潮线以上挖坑
2. 深1-2 m
3. 可能渗出淡水(比海水轻,浮在上层)
4. 必须净化!
```

```
原理: 雨水渗进沙子里,因为比海水轻,会在海水之上形成一层"淡水透镜",
      离海越远、岛越大、下雨越多,这层淡水越厚;很小、很低的岛,旱季时可能没有

怎么挖:
1. 位置: 在第一道沙丘的后面(靠陆地一侧)、低洼处,
   或岸边有绿色植物生长的地方;离海越远越好
2. 挖到沙子变湿、开始渗水就停下,不要一直往深处挖
   (实际深度要看地形,有时不到 1 m 就见水;挖得越深,越可能挖到下面的咸水)
3. 等水慢慢渗满,用容器轻轻从表层舀,不要搅动、不要一次舀干
4. 舀出来先尝一小口: 明显发咸就不要喝,换个更靠陆地的地方再挖
5. 用布过滤后,能煮沸就煮沸再喝
6. 坑壁容易塌,不要挖成人能站进去的深坑;用完后盖上,防止东西掉进去

其他线索:
- 退潮时,沙滩上、悬崖脚下有时能看到淡水从沙里或岩缝里渗出(水流方向朝海)
- 有溪流入海的地方,往上游走一段,在潮水影响不到的位置取水
```

水的净化方法见[基础生存技能-水质净化](00-基础生存技能.md#水质净化);长期住下时的雨水收集设施见[水源工程与供水-收集雨水](../07-日常生活技能/10-水源工程与供水.md#收集雨水)。

**⚠️ 绝不**:
```
❌ 喝海水!(脱水更快)
❌ 喝尿液!(浓缩毒素)
```

### 怎样喝水和省水

```
✓ 有水时按需要喝,不要硬省着不喝 —— 把水留在瓶子里,不如留在身体里
  真正能省水的办法是"少出汗":
  - 白天最热的时候(约10-16点)待在阴凉处休息,干活放到清晨和傍晚
  - 穿着衣服、戴帽子,不要光着身子晒太阳(出汗更多)
  - 少说话,用鼻子呼吸
  - 可以把衣服在海水里浸湿再穿上降温,但要注意皮肤别起疹
✓ 水少的时候少吃东西,尤其少吃肉、鱼和咸的食物(消化它们需要更多的水)
✓ 每天看尿: 淡黄色、一天几次 → 大致够;
  深黄、很少、一整天没有尿 → 脱水了,要优先补水
❌ 不喝酒、不吸烟
```

脱水的判断见[常见疾病-脱水症状识别](../01-日常疾病和伤害/01-常见疾病.md#脱水症状识别)。

## 庇护所

热带海岛上,庇护所首先是**遮阳和挡雨**,其次是防风、防虫。在烈日下暴露一天,足以造成严重晒伤和中暑。

### 选址

```
✓ 靠近水源
✓ 高于高潮线!
✓ 避风
✓ 接近信号区(海滩可见)
✓ 靠近资源(木材、食物)

❌ 避免:
- 潮水可达处
- 椰子树正下方(掉落椰子危险)
- 岩石下(涨潮淹没)
```

```
怎样判断高潮线:
- 沙滩上一条条由海草、木头、垃圾组成的"漂流物线",是不同时间的潮水留下的
- 最靠陆地的那一条,往往是大潮或风暴时海水到过的地方
- 庇护所要在最高那条线以上,再留出几 m 的余量,
  最好是高出海面几 m 的沙丘后面或林地边缘

其他要避开的地方:
- 干涸的小溪沟、低洼处(下大雨时会变成水道)
- 悬崖、陡坡下(落石)、枯死或歪斜的大树下(断枝)
- 蚂蚁窝、螃蟹洞密集的地方
- 茂密丛林深处: 闷热、蚊子多,也不容易被看到

折中: 在海滩和林地交界处,既有海风吹散蚊子,又有树荫,离信号区也近
```

### 简易庇护所

**单坡棚**:
```
1. 找两棵树或竖柱子
2. 架横梁
3. 斜靠木棍
4. 覆盖:
   - 棕榈叶(瓦片状,从下往上)
   - 草
   - 树皮
5. 地面铺干草、树叶
```

```
要点:
- 棚子的开口背对主要的风向;雨季在开口方向挖一条浅沟排水
- 椰子叶、棕榈叶要铺得厚,至少几层,像瓦片一样从下往上层层压住,
  缝隙越少越不漏雨
- 有塑料布、帆布时铺在叶子下面,防雨效果好得多;但不要用透明塑料布遮阳
- 斜面要够陡,雨水才会流下去,不会积在顶上漏下来
- 横梁和立柱用藤、布条、树皮绑紧(打结方法见绳索与结绳一章)

最快的遮阳: 在两棵树之间拉一块布或塑料布,离头顶留出空隙,
            双层更好(两层之间留一点空隙,隔热效果明显)
```

**改进**:
```
✓ 高离地面(防虫、潮湿、涨潮)
✓ 厚覆盖(防雨)
✓ 烟熏防蚊虫
```

```
睡觉的地方:
- 用木头、竹子搭一个离地约几十 cm 的床铺,上面铺干叶子和干草,
  能避开沙蚤、螃蟹、蚂蚁和地面的潮气
- 晚上海边风大会冷,尤其是被雨淋湿后,准备干的覆盖物
- 有蚊帐、纱布时罩住床铺;热带地区蚊子可能传播疟疾、登革热
```

搭建方法和绳结见[基础生存技能-庇护所建造](00-基础生存技能.md#庇护所建造)、[绳索与结绳](../07-日常生活技能/17-绳索与结绳.md)。

### 防风暴和大浪

```
热带海岛常有台风(夏秋季),简易棚子挡不住台风

征兆:
- 海上的涌浪越来越大、越来越长,但当地风还不大
- 天空出现从一个方向辐射开来的高空卷云,随后云越来越厚低
- 风向持续改变、风力逐渐增强,海鸟往陆地飞

怎么做:
✓ 提前把水、火种、工具、食物转移到岛上较高、有遮挡的地方
  (大石头、山坡、坚固的树林后面,不在空旷的海滩和孤立大树下)
✓ 风雨最大时趴低、躲在岩石或土坎的背风面,远离会被吹断的树
✓ 风突然停下、天空放晴,可能是台风眼经过,很快会从反方向再刮起来,不要出去
✓ 雷雨时离开海滩和水边

⚠️ 感觉到地震、或者看到海水突然大幅后退、露出平时看不到的海底:
   可能是海啸,立即往岛上最高处跑,不要去海滩看
```

台风的更多应对见[气象灾害-台风/飓风](../02-灾难应对/02-气象灾害.md#台风飓风),风暴潮和海啸见[海洋灾害-风暴潮](../02-灾难应对/03-海洋灾害.md#风暴潮)、[海洋灾害-海啸](../02-灾难应对/03-海洋灾害.md#海啸),雷电见[气象灾害-室外避雷](../02-灾难应对/02-气象灾害.md#室外避雷)。

## 火

### 生火

**火绒**:
```
- 干椰子壳纤维(极佳)
- 干树皮
- 干草
```

```
补充:
- 椰子壳外层的棕色纤维撕成细丝、搓松,是很好的火绒;
  干的椰子壳本身耐烧,适合作为引火后的中等燃料
- 干枯的棕榈叶、棕榈树干上的网状纤维也很好用
- 晴天时把火绒和细柴提前摊开晒干,再收进庇护所里保存
- 有眼镜、放大镜、手电的凸面反光碗、装满清水的透明瓶子,晴天可以聚光点火
```

**燃料**:
```
✓ 漂流木(充足)
✓ 先晒干
✓ 硬木烧得久
```

```
注意:
- 泡过海水的木头含盐,晒干后也能烧,但火小、爱爆裂,先放在火边烤干
- 刷过油漆、做过防腐处理的木板、塑料和橡胶,烧的烟有毒,
  只用作信号火,不要用来做饭,也不要在庇护所里烧
- 粗的漂流木放在火堆旁边,一边烤干一边用
```

**保护**:
```
✓ 防风
✓ 防雨(遮蔽)
✓ 保持火种(灰覆盖)
```

```
⚠️ 沙滩上的火: 熄火后,埋在沙子下面的炭和热沙可以烫好几个小时
   → 用水浇透再离开;不要只用沙子盖住,别人(尤其是孩子)光脚踩上去会严重烫伤
⚠️ 火堆离庇护所的叶子屋顶要有足够距离,防止火星引燃
```

生火方法见[基础生存技能-生火方法](00-基础生存技能.md#生火方法),保存火种见[基础生存技能-保存火种](00-基础生存技能.md#保存火种)。

## 食物

人不吃东西可以活几周,所以**不要为了找食物冒险**,也不要在缺水时多吃。海边最容易得到、最安全的食物是贝类、螺、螃蟹和鱼,但每一种都有中毒的风险。

### 海洋食物

**贝类**(最容易):
```
✓ 岩石上的牡蛎、藤壶
✓ 沙滩上的蛤蜊(看气孔挖)
✓ 低潮时收集

安全:
- 煮熟!
- 避免赤潮季节(赤潮毒素煮熟也无法去除!)
- 新鲜食用
```

```
怎样挑:
✓ 只要活的: 双壳贝壳闭紧,或者张开的壳一碰就合上;螺缩在壳里,
  碰它的口盖会动
✓ 在水流通畅、清澈的海域采,不在河口、排污口附近,
  不在漂着死鱼、海水变色或有异味的地方采
❌ 壳破了、张开不合、发臭、轻飘飘的不要
❌ 冲上岸的死贝、死鱼一律不吃
❌ 有些热带地区夏季贻贝(海虹)容易带毒,一些生存手册建议热带夏季不吃贻贝

怎样吃:
- 煮开后再煮几分钟,直到壳全部张开;煮了还不开的扔掉
- 去掉内脏(颜色深的消化腺,毒素最集中),少量吃
- 第一次在一个地方采的贝,先少吃一点,观察几个小时

⚠️ 吃贝类后几十分钟到几小时内嘴唇、舌头、手指发麻、刺痛,头晕站不稳:
   可能是麻痹性贝类中毒(毒素煮不坏)
   → 所有人立即停吃同一批贝类,尽一切办法求救
   → 中毒者侧卧,有人一直守着;如果呼吸越来越弱或停止,
     立即开始人工呼吸和CPR —— 这种中毒的危险在于呼吸肌麻痹,
     只要坚持帮他呼吸,毒素在一两天内会逐渐代谢掉
```

**芋螺**(鸡心螺): 热带礁石区常见的圆锥形漂亮螺壳,里面的活螺能射出毒刺,可以致命。**不要用手捡任何圆锥形的活螺**。

赤潮、贝类中毒和其他有毒海产品见[海洋灾害-赤潮与有毒海产品](../02-灾难应对/03-海洋灾害.md#赤潮与有毒海产品)。

**鱼**:
```
方法:
- 鱼叉(削尖木棍,多叉)
- 鱼钩(骨头、木头弯曲)
- 潮汐池(退潮后困住)
- 简易鱼网(衣服)

技巧:
- 夜晚用火把吸引
- 涨潮时鱼进浅滩
```

```
更省力的办法:
- 在潮间带用石头垒一道半圆形的矮墙,开口朝向陆地,
  涨潮时鱼游进来,退潮时被困在里面
- 钓鱼用贝肉、螃蟹肉、虫子做饵;线可以从衣服、背包带上拆
- 下水捕鱼穿鞋,不要在礁石边缘、浪大的地方下水,不要在黄昏和夜里下海

哪些鱼不要吃:
❌ 河豚类: 身体能鼓成球、皮上有刺或没有鳞、牙齿像鸟喙
   (河豚毒素煮不坏,很少量就能致命)
❌ 箱鲀: 身体像个硬盒子
❌ 热带珊瑚礁的大型掠食鱼(大的石斑、梭鱼、海鳝等): 可能有雪卡毒素
   → 优先吃小鱼;任何鱼都不吃内脏、肝、鱼卵
❌ 冲上岸的死鱼、不新鲜的鱼(鳃发暗、眼睛浑浊、按下去不回弹、有臭味)

处理:
- 热带高温下鱼几个小时就会变质,捕到后立即去内脏,尽快煮熟或烤熟
- 吃不完的切薄片晒干或烟熏(见"长期生存")
```

河豚、雪卡毒素等见[海洋灾害-其他有毒海产品](../02-灾难应对/03-海洋灾害.md#其他有毒海产品);被鱼鳍、鱼刺扎伤见本章"危险"。

**螃蟹**:
```
- 夜晚活跃
- 用灯/火把引诱
- 小心钳子
- 煮熟
```

```
- 不吃颜色鲜艳、甲壳上有花纹的礁石小蟹,有些种类(如花纹爱洁蟹)
  带有和麻痹性贝类毒素相似的毒素,煮不坏
- 一定要煮熟煮透: 螃蟹(尤其是陆地和淡水中的蟹)可能带有寄生虫
- 死了的螃蟹不吃
- 抓的时候从背后按住甲壳,手指避开钳子
```

**海藻**:
```
- 很多绿藻(像薄薄的绿色生菜叶的石莼、浒苔)、褐藻(海带、裙带菜)
  和紫菜可以吃
- 只采附着在礁石上、新鲜有弹性的,不采冲上岸腐烂的
- 用淡水或雨水冲洗,能煮就煮软了吃
- 少吃: 海藻很咸,吃多了更渴,缺水时不要吃
❌ 不吃: 一团团黏糊糊、像毛发或胶冻的蓝绿色"藻"(可能是有毒的蓝藻);
   有酸味、刺激味的海藻
❌ 不认识的不吃
```

### 陆地食物

**椰子**:
```
获取:
- 地上捡(检查是否新鲜)
- 爬树摘(危险)
- 用长棍钩

开椰子:
1. 找椰子的"眼睛"(三个点)
2. 用尖石/棍戳破
3. 倒出椰汁
4. 砸开取椰肉
```

```
补充:
- 外面厚厚的纤维壳要先剥掉: 把一根削尖的硬木棍或尖石头牢牢插在地上,
  尖朝上,把椰子用力往尖上砸、撬,一块一块剥下来;剥下的纤维留着当火绒
- 三个"眼睛"里有一个比较软,用尖物就能戳开
- 喝完椰汁后,沿着椰子的"腰线"用石头一圈圈敲,会裂成两半
- 椰肉: 嫩椰子的椰肉软,可以用勺子刮;老椰子的椰肉硬、油脂多,少量吃
- 发了芽的椰子里面有海绵状的"椰子苹果",可以吃
- 挑椰子时摇一摇: 没有水声、发出臭味、有裂缝流汁的不要
```

**可食植物**:
```
常见:
- 棕榈心(嫩芽)
- 香蕉、芭蕉
- 木瓜
- 海草(某些种类)

⚠️ 不确定不要吃!
```

```
- 只吃有百分之百把握认得出来的植物
- 取棕榈心要砍掉整棵树的顶芽,这棵树就死了;偶尔为之
- 海岛上有些常见植物有剧毒(比如海檬果、海芒果的果实,
  外形像小芒果,吃了会危及生命),像水果但不认识的,一定不要试
- 可食性测试只能作为极端情况下的最后手段,对剧毒植物不安全,对蘑菇无效
```

可食性测试的局限见[基础生存技能-可食植物测试](00-基础生存技能.md#可食植物测试),野菜和蘑菇见[毒蘑菇与野菜误食](09-毒蘑菇与野菜误食.md)。

**昆虫**:
```
✓ 甲虫幼虫(腐木中)
✓ 白蚁
✓ 蚱蜢
- 煮熟食用
```

```
⚖️ 法律: 平时海龟、砗磲、珊瑚、椰子蟹等都是受保护的物种,不能采捕;
   各地还有休渔期和禁止的捕捞方法。本章的取食方法只用于真正的遇险求生
```

## 信号与救援

在海岛上,**被看见**是获救最重要的一步。白天用反光、烟和地面大字,夜里用火光和手电,而且要一直准备着,救援船、飞机可能只在视野里出现一两分钟。

### 信号方法

**烟雾**:
```
白天最有效:
- 三堆火(三角形)
- 添湿草、树叶产生浓烟
- 白烟(湿草)或黑烟(橡胶、油)
- 保持燃烧
```

```
- 三堆火摆成三角形,彼此相距约 20-30 m,在开阔的海滩上
  (三堆火、三声哨、三次闪光是国际通用的求救信号)
- 每堆火提前搭好: 底下干的火绒和细柴,上面架粗柴,最上面盖一堆绿叶、
  湿海藻(产生浓烟,同时帮下面的干柴挡雨)
- 看到船、听到飞机发动机的声音时,马上点着;火点着后再加绿叶加大烟
- 背景是浅色天空时用黑烟(橡胶、油、塑料),背景是深色树林时用白烟(绿叶、湿草)
- 一直保持一小堆火燃着,需要时可以迅速引燃信号火
```

**火光**:
```
夜晚:
- 三堆火
- 火焰高
- 可见数 km
```

**反光**:
```
材料:
- 镜子、金属片
- CD、手机屏幕
- 磨光的罐头

使用:
- 向天空、地平线扫射
- 看到飞机/船立即信号
- V字手势瞄准
```

```
V字手势瞄准:
1. 一只手拿镜子贴近眼睛下方
2. 另一只手伸直,食指和中指分开成V字,让目标(船、飞机)落在V字中间
3. 转动镜子,让反光的亮斑照在V字的两根手指上
4. 亮斑照到手指上时,反光就正对着目标;轻轻上下晃动,形成闪光
- 有中间带孔的信号镜时,从孔里看着目标,调整到镜子上的"光点"对准目标
- 晴天反光远处数 km 外都能看到,是白天最好的信号之一
- 没看到目标时,每隔一段时间朝地平线来回扫一扫,远处的人可能看得到你
- 飞机已经朝你飞来、确认看见你后,不要一直照驾驶舱(会晃到飞行员)
```

**地面标记**:
```
沙滩/空地:
- SOS(大字,至少3 m高)
- HELP
- V(需要援助)、X(需要医疗援助)
- 用石头、木头、海草摆放
- 与周围对比明显(深色/浅色)
```

```
怎样让大字从空中看得见:
- 越大越好: 每个字母至少3 m高,能做到 10 m 更好;笔画宽约 1 m
- 摆在高潮线以上、平坦开阔的沙滩上,不要被树挡住
- 白沙滩上用深色的海藻、木头、深色石头;或者挖沟,沟里的阴影从空中能看到
- 线条要直、角要分明,自然界很少有直线和直角
- 涨潮、大风、下雨后去检查、修补
```

地面对空信号的含义见[基础生存技能-地面对空信号](00-基础生存技能.md#地面对空信号)。

**声音**:
```
- 哨子(三声短)
- 敲击金属
- 呼喊
```

**旗帜**:
```
- 鲜艳衣物
- 绑在高处
- 挥舞
```

**电子设备**:
```
- 手机: 到岛上高处、开阔处试信号;打不通电话时试着发短信(短信需要的信号更弱)
- 平时关机或开飞行模式,每天固定时间开机试一次,节省电量
- 有个人定位信标、卫星通信设备、船上的甚高频电台时,按说明使用
- 夜里用手电、手机闪光灯朝着看到的船灯打信号: 三短、三长、三短(SOS)
```

### 保持可见

```
✓ 保持海滩信号火准备好
✓ 定期到海滩观察
✓ 制作高处观察台
✓ 保持信号标记清晰
```

```
✓ 每天固定时间(早、中、晚)有人到海滩或高处看海面和天空
✓ 在岛上最显眼的高处(海岬、山顶、最高的树)挂一面鲜艳的布旗
✓ 留在一个地方: 救援人员找到一个固定的营地,比找一个到处走动的人容易得多
✓ 离开营地时,在营地留下标记(箭头、写着去向和日期的字条)
❌ 不要轻易扎筏或游泳离开海岛: 海上目测距离往往严重偏近,
   洋流、风浪、暴晒、缺水会让离开比留下危险得多;
   除非确定救援不会来、对岸很近而且看得清、有可靠的漂浮工具
```

海上等待救援的注意事项见[海洋灾害-等待救援](../02-灾难应对/03-海洋灾害.md#等待救援)。

## 危险

### 动物

**鲨鱼**:
```
避免:
- 黄昏/夜晚游泳
- 出血时下水
- 浑水
- 单独游泳

如遇到:
- 保持冷静
- 面对它
- 缓慢移动
- 如攻击:打鼻子、眼睛、鳃
```

```
补充:
- 不要在清洗鱼、扔鱼内脏的地方附近下水
- 不穿戴反光的首饰下水
- 看到鲨鱼时慢慢退回岸上或礁石上,不要拍水、乱扑腾
- 被咬伤后的最大危险是大出血: 上岸后立即用力直接压迫伤口止血,
  四肢大出血压不住时考虑止血带
```

止血方法见[基础急救知识-止血方法](../01-日常疾病和伤害/00-基础急救知识.md#止血方法)。

**有毒生物**:
```
- 水母:远离;蜇伤后用海水(不要用淡水)冲洗,小心去除触须;醋仅对部分种类(如箱水母)有效,对僧帽水母可能加重
- 海蛇:剧毒,不要触碰
- 石鱼:伪装,看清再踩
- 海胆:刺入皮肤,用镊子取出可见的刺;患处浸泡热水(约45°C,不烫手)30-90分钟缓解疼痛;不要用尿液
```

| 生物 | 怎样受伤 | 处理 | 什么时候必须尽快送医 |
|------|----------|------|----------------------|
| 水母 | 碰到触须,立即火辣辣地疼,皮肤出现条状红痕 | 离开水;用海水冲洗(淡水会让残留的刺细胞继续放毒);用镊子、戴手套或用卡片边缘刮掉残留触须,不要用手、不要用沙子搓;去掉触须后用能耐受的热水(约45°C)泡约20分钟止痛,没有热水时冷敷 | 呼吸困难、胸痛、意识改变、全身起疹(过敏);被大面积蜇伤;儿童;在热带印度洋-太平洋海域被半透明的方形水母(箱水母)蜇伤——可在几分钟内危及生命 |
| 海胆 | 踩到或手按到,刺扎进皮肤断在里面 | 取出露在外面的刺;热水浸泡(约45°C)30-90分钟;皮肤上留下的黑色斑点可能只是染色,不要用针深挖 | 刺扎进关节、手掌深处;几天后红肿化脓加重 |
| 石鱼、蓑鲉(狮子鱼)等毒鱼 | 踩到礁石上伪装得像石头的鱼,或碰到鱼鳍上的毒刺;剧痛 | 冲洗伤口,热水浸泡(约45°C)30-90分钟止痛;伤肢放低、少动 | 石鱼蜇伤疼痛剧烈,可出现虚脱、呼吸困难,需要尽快送医 |
| 魟(魟鱼、刺鳐) | 踩到埋在沙里的魟,尾巴上的锯齿刺扎进腿脚,出血、剧痛 | 压迫止血,冲洗,热水浸泡止痛;伤口里可能残留刺的碎片 | 刺扎进胸部、腹部、颈部时不要拔出,固定后立即送医;伤口一般都需要医生清创 |
| 芋螺、蓝环章鱼 | 用手捡起时被蜇或咬,一开始可能不太疼 | 让伤者保持安静不动 | 都可能引起全身麻痹、呼吸停止 → 立即求救;呼吸减弱或停止时持续人工呼吸、CPR |
| 海蛇 | 在海里或礁石缝里被咬,局部不怎么疼 | 按毒蛇咬伤处理,伤肢制动 | 一律尽快送医;几小时内可出现眼睑下垂、吞咽和呼吸困难 |

```
热水浸泡的要点:
- 温度约45°C,以不烫手为准;先用施救者自己没受伤的手试水温
  (伤者的伤处很疼,感觉不准,容易被烫伤)
- 水凉了就续热水,疼痛复发就再泡
- 不要用尿、酒精、生肉敷;不要切开、吸吮伤口

预防:
✓ 下水、在礁石和浅滩走路时穿鞋(即使是破鞋、用布和树皮绑的"鞋"也比光脚好)
✓ 在浅水沙地上拖着脚走、用棍子在前面戳一戳,能把魟吓跑
✓ 不把手伸进看不见的礁石缝和洞里
✓ 不用手捡活的螺、不碰海里颜色鲜艳的、不认识的东西
✓ 被冲上岸的水母,即使已经死了,触须仍然能蜇人
```

蛇咬伤的处理见[外伤处理-蛇咬伤](../01-日常疾病和伤害/02-外伤处理.md#蛇咬伤),过敏反应见[急性症状-过敏反应](../01-日常疾病和伤害/05-急性症状.md#过敏反应),扎进身体的异物见[外伤处理-刺伤](../01-日常疾病和伤害/02-外伤处理.md#刺伤)。

**陆地危险**:
```
- 蛇:小心行走
- 蝎子:检查鞋子、衣物
- 蜘蛛:检查庇护所
```

```
补充:
- 早上穿鞋、穿衣前抖一抖
- 晚上走路带火把或手电,用棍子在前面拨草
- 蜈蚣、蝎子、毒蜘蛛咬伤后冲洗、冷敷;出现全身症状、儿童被咬,尽快求医
- 蚊子: 用烟熏、穿长袖、睡觉罩住,热带地区蚊子会传播疟疾、登革热
```

野外蛇和其他危险动物见[马蜂蜱虫与危险动物](10-马蜂蜱虫与危险动物.md)。

### 环境

**太阳**:
```
✓ 遮阳(帽子、庇护所)
✓ 避免10-16点户外
✓ 保持水分
```

```
海边的阳光比内陆更厉害: 水面和白沙会反射紫外线,阴天也能晒伤

防晒:
- 尽量穿长袖、长裤;没有帽子时用布做一个盖住后颈和耳朵的头巾
- 皮肤上有一层盐、身体湿着时更容易晒伤
- 眼睛: 长时间看着反光的海面和沙滩,眼睛会刺痛、流泪、像进了沙子;
  用树皮、布条或椰子壳做一个只留一道细缝的"眼罩"能减轻

晒伤后:
- 立即到阴凉处,用凉的湿布冷敷,多喝水
- 起水疱不要弄破,保持干净
- 大面积起水疱、发热发冷、头痛恶心 → 当作烧伤和热病对待,尽快求医

中暑的警告信号:
- 大量出汗、头晕、恶心、乏力、口渴 → 热衰竭: 立即到阴凉处、喝水、
  用湿布扇风降温
- 体温很高、意识不清、说胡话、抽搐 → 热射病,危及生命:
  立即用一切办法降温(浸到凉水里、浇水、扇风),同时求救
```

晒伤的处理见[外伤处理-烫伤与烧伤](../01-日常疾病和伤害/02-外伤处理.md#烫伤与烧伤),中暑的分级和降温见[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑)。

**珊瑚割伤和海水伤口**:
```
珊瑚、牡蛎壳、藤壶非常锋利,划出的伤口看起来不大,却很容易感染、
愈合很慢;海水里的细菌(如创伤弧菌)还可能在一两天内引起严重感染

处理:
1. 用大量干净的淡水(最好是煮过放凉的水)冲洗,
   有肥皂就用肥皂水刷洗,把伤口里的珊瑚碎屑、沙子全部冲干净
2. 看得见的碎屑用消过毒的镊子夹出来
3. 有碘伏就消毒,然后用干净的布覆盖,每天检查、换药
4. 受伤后尽量不要再泡海水
5. 每天看伤口: 红肿范围越来越大、越来越疼、流脓、出现红线、发热
   → 感染,在荒岛上这是严重的情况,尽一切办法求救
   伤口在几小时到一两天内剧烈疼痛、迅速肿胀、起血疱、皮肤发紫
   → 可能是危及生命的感染,立即求救

✓ 预防比处理重要: 穿鞋、戴手套(或用布缠手),不要在礁石上光脚走、
  不要被浪推着撞向礁石
```

伤口处理和感染迹象见[外伤处理-割伤与擦伤](../01-日常疾病和伤害/02-外伤处理.md#割伤与擦伤)、[野外伤病处置与转运-伤口](11-野外伤病处置与转运.md#伤口),破伤风见[外伤处理-破伤风预防](../01-日常疾病和伤害/02-外伤处理.md#破伤风预防),海水伤口的危险见[海洋灾害-游泳和其他注意事项](../02-灾难应对/03-海洋灾害.md#游泳和其他注意事项)。

**潮汐**:
```
✓ 观察高潮线
✓ 不要在潮汐区建庇护所
✓ 了解潮汐时间(约每12小时一次)
```

```
潮汐的规律:
- 大部分海岸一天两次高潮、两次低潮,相邻两次高潮相隔约12小时25分钟,
  所以每天的高潮时间比前一天推迟约50分钟
- 新月和满月前后潮水涨得最高、退得最低(大潮)
- 头几天在固定的地方插一根木杆,记下高潮、低潮到达的时间和位置,
  以后就能推算

和潮汐有关的危险:
❌ 退潮时走到远处的沙洲、礁盘上觅食,涨潮时被困、被淹
   → 最晚在低潮时就开始往回走;记住身后的低洼处和潮沟会先灌满水
❌ 在浪打得到的礁石上站着、背对大海(突然的大浪能把人卷下去)
❌ 在两边起浪、中间一段水面平静颜色深的地方下水: 可能是离岸流
   → 被带走时不要逆流往岸边游,先浮起来,再平行于海岸横着游出去
```

离岸流的识别和自救见[海洋灾害-离岸流](../02-灾难应对/03-海洋灾害.md#离岸流),潮汐和退潮被困见[海洋灾害-赶海与退潮被困](../02-灾难应对/03-海洋灾害.md#赶海与退潮被困),礁石上的危险见[海洋灾害-礁石和海岸边](../02-灾难应对/03-海洋灾害.md#礁石和海岸边)。

## 长期生存

如果几天之后仍未获救,要把临时营地改造成能长期住下去的地方,同时**一刻也不放弃发信号**。

### 资源管理

```
✓ 不过度捕捞一处
✓ 轮流利用资源点
✓ 保存食物(烟熏、晒干)
✓ 储备淡水(容器)
✓ 保持火种
```

```
水:
- 每次下雨都尽量把所有容器装满;用椰子壳、竹筒、挖空的木头、
  沙地里铺塑料布的坑做储水池,上面盖好
- 记录每天用了多少水、还剩多少、多久下一次雨,心里有数

食物:
- 鱼肉切成薄片,抹盐(或在浓海水里浸过)后放在架子上晒干,或者用烟熏
- 晒的时候防苍蝇、防雨,晒到干硬再存放;发霉、发黏、有臭味的扔掉

盐:
- 煮海水或在礁石的小坑里让海水晒干,都能得到盐;
  晒干后最后析出的发苦的部分(苦卤)不要
- 盐用来腌鱼、补充出汗丢掉的盐分;但不要因为有盐就多吃,缺水时尤其要少吃
```

晒干和烟熏的方法见[食物加工与保存-晒干与风干](../07-日常生活技能/01-食物加工与保存.md#晒干与风干)、[食物加工与保存-烟熏](../07-日常生活技能/01-食物加工与保存.md#烟熏);从海水制盐见[制盐-海水取盐](../07-日常生活技能/15-制盐.md#海水取盐-基本道理)、[制盐-煮盐](../07-日常生活技能/15-制盐.md#煮盐-先浓缩再煮)。

### 保持健康

```
✓ 个人卫生(防感染)
✓ 营养均衡
✓ 充足饮水
✓ 伤口护理
✓ 避免过度劳累
✓ 保持希望和积极
```

```
具体做法:
- 在离营地和取水点至少30 m、在下风处、高潮线附近挖坑做厕所,
  每次用完盖土(或在退潮时到远离营地的水边)
- 饭前、处理伤口前尽量用干净的水洗手;没有足够淡水时用海水洗,再用少量淡水冲
- 每天检查脚和皮肤: 小划伤也要清洗、盖住;长期湿着的脚容易烂,晚上要晾干
- 只靠鱼和贝类时,尽量也吃一些认得出来的水果(椰子、木瓜、香蕉)和海藻,
  补充维生素
- 腹泻是荒岛上最常见的病之一,多半是喝了不干净的水、吃了不新鲜的海鲜:
  水尽量煮沸,海鲜煮熟,出现腹泻时多补水,可以用一点盐和糖兑进干净的水里补液
```

腹泻和补液见[常见疾病-腹泻](../01-日常疾病和伤害/01-常见疾病.md#腹泻),厕所的位置和做法见[卫生设施](../07-日常生活技能/03-卫生设施.md)。

```
心理:
- 孤独、焦虑、绝望在漂流和被困时很常见,也会让人做出危险的决定
  (比如冒险扎筏离开、喝海水)
- 给每天定小目标: 今天修好屋顶、今天做好两个接水的容器
- 有同伴时分工、每天一起商量;一个人时可以自己说话、写日记
- 刻日子: 在木头上或石头上每天刻一道,不会搞不清过了多久
```

心理调适见[心理健康](../01-日常疾病和伤害/10-心理健康.md)。

### 日常作息

```
建立规律:
- 早:检查信号、收集露水
- 日间:改进庇护所、觅食、制作工具
- 傍晚:准备食物、水、燃料
- 夜间:保持火、休息
```

```
按热带的天气调整:
- 清晨(日出前后): 收露水;趁凉快干重活(砍柴、搬木头、修庇护所);退潮时觅食
- 正午前后(约10-16点): 在阴凉处休息,做手工活(编绳、做容器、修工具),
  同时有人看海面
- 傍晚: 觅食、捕鱼、准备第二天的柴和火绒
- 夜里: 轮流照看火;晴朗的夜里留意海上的灯光,随时准备打信号
- 每天: 检查信号火和地面大字、检查储水、记日子
- 觅食的时间要跟着潮水走,按前面记录的潮汐时间安排
```

## 📝 荒岛求生要点

```
优先级:
1. 淡水(生存3天)
2. 庇护所(防晒、防雨、防风)
3. 火(煮食、信号、驱虫)
4. 食物(海洋资源丰富)
5. 信号(持续努力)

心态:
✓ 保持希望
✓ 保持忙碌
✓ 设定目标
✓ 记录日期
✓ 相信会获救
```

```
最重要的几条:
❌ 不喝海水、不喝尿
✓ 雨水是最好的水源,提前铺好接水的东西;太阳能蒸馏器产水很少
✓ 庇护所建在最高的漂流物线以上,先遮阳
✓ 白天最热的时候休息,少出汗比硬省水重要
✓ 信号火随时准备好,看到船和飞机立即点燃、用镜子反光
✓ 不认识的鱼、贝、植物不吃;吃海鲜后嘴唇发麻立即停吃、求救
✓ 下水和走礁石穿鞋;珊瑚划伤要彻底冲洗
✓ 留在岛上等待救援,不要轻易扎筏离开
```
