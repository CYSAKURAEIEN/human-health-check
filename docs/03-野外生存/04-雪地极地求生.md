# 雪地/极地求生指南

## 核心挑战

```
- 极寒: 身体不断向空气、地面、雪散失热量,只靠吃进去的食物产热补回来
- 失温风险: 被汗或雪水打湿、大风、疲劳饥饿时最快
- 冻伤: 手指、脚趾、耳朵、鼻尖、脸颊最先受害
- 暴风雪: 能见度降到几 m,几小时到几天无法行动
- 白茫茫易迷路: 雪覆盖了路和地标,"白化天气"时连地面起伏都看不清
- 食物水源困难: 到处是雪却缺水(化雪要燃料),寒冷让人消耗的热量成倍增加
- 雪崩、冰面破裂: 看不见的地形危险,发生后几分钟内决定生死
```

```
最重要的原则:
1. 不在暴风雪预警、雪崩风险高时进山;冬季出行比夏季更需要留下行程单
2. 被困时优先求救、原地等待救援,而不是冒险自己走出去
3. 天黑前至少1-2小时停下来做庇护所 —— 冬季白天短,天黑后什么都难做
```

出发前的准备、行程单、迷路和报警见[户外出行准备与求救](07-户外出行准备与求救.md);城市和农村的暴风雪、寒潮应对见[暴风雪](../02-灾难应对/02-气象灾害.md#暴风雪)。

## 保暖 (最关键!)

身体散热有四条路: **传导**(坐在雪上、穿湿衣服)、**对流**(风吹)、**辐射**(暴露的头颈、手)、**蒸发**(出汗、呼吸)。保暖就是把这四条路一条条堵住:

| 散热途径 | 典型情况 | 怎样堵住 |
|------|------|------|
| 传导 | 直接坐、躺在雪地或冰冷的石头上;湿衣服贴身 | 身下垫背包、防潮垫、树枝;保持衣服干燥 |
| 对流 | 大风吹透衣服 | 防风外层;躲到背风处;雪墙挡风 |
| 辐射 | 不戴帽子、手套,脖子敞开 | 戴帽子、围脖、手套 |
| 蒸发 | 走路出汗、呼吸带走水汽 | 少出汗;用围巾挡住口鼻温暖吸入的空气 |

### 穿着系统

**多层穿衣法**:
```
1. 内层(排汗):
   - 合成纤维或羊毛
   - 不要穿棉!(湿后失温)
   - 贴身但不勒;作用是把汗从皮肤上导走,让皮肤保持干

2. 中层(保暖):
   - 羊毛、抓绒
   - 多层薄胜于一层厚
   - 羽绒最暖最轻,但湿了几乎不保暖;潮湿天气、容易出汗时用抓绒或化纤棉

3. 外层(防风防水):
   - 防水外套
   - 防风
   - 最好透气,有腋下拉链方便散热

原则:
✓ 可调节(热了脱,冷了穿)
✓ 保持干燥!(湿=致命)
```

为什么不能穿棉: 棉吸水后纤维塌下来,里面的空气被水取代,水导热比空气快约20倍,湿棉衣贴在身上就像披着一层冷水,而且很难干。羊毛湿了还能保留部分保暖性,化纤干得最快。

**COLD 原则**(国外冬季户外常用的口诀,便于记忆):
```
C - 保持清洁(Clean):   衣服沾了油污、汗渍后保暖性下降
O - 避免过热(Overheating): 出汗就是在打湿自己,热了马上减衣服
L - 宽松分层(Loose, Layered): 太紧会压扁保暖层、阻碍血液循环
D - 保持干燥(Dry):     内湿(汗)和外湿(雪水、雨)都要防
```

**没有专业装备时的替代办法**:
```
- 报纸、干草、干树叶塞在两层衣服之间(作用是留住空气),湿了就换
- 塑料袋、垃圾袋可以当防风层: 套在保暖层外面;
  也可以作"隔汽袜": 穿上一层薄袜 → 套塑料袋 → 再穿厚袜,让厚袜不被脚汗湿透
  (塑料袋不透气,里面的薄袜会湿,每天要晾干)
- 毛毯、被子剪洞套头当斗篷
- 多穿几层旧衣服,比一件厚棉袄更好调节
```

**重点部位**:
```
✓ 头部(暴露时散热明显):
  - 帽子、头巾
  - 盖住耳朵;睡觉时也戴帽子

✓ 手脚:
  - 手套(连指更暖)
  - 厚袜
  - 靴子(防水保暖)
  - 鞋要留出能活动脚趾的空间,穿两层厚袜时鞋要大半码到一码
    (挤在鞋里的脚最容易冻伤)
  - 带一双备用干袜子和手套,装在防水袋里贴身放
  - 手套用绳子连起来或挂在手腕上,大风中脱下一下就可能被吹走

✓ 面部:
  - 围巾、面罩
  - 防冻伤
  - 同伴之间每隔一阵互相看脸,发现鼻尖、脸颊有白斑马上处理

✓ 眼睛:
  - 雪盲防护
  - 太阳镜/护目镜
```

**小孩、老人和体弱者**:
```
- 小孩体表面积相对大,散热快,自己又不会说冷;
  背在背上或坐在雪橇上的孩子不活动,比走路的大人冷得多,要多穿一层,勤摸手脚和后颈
- 婴儿用背带贴身背在大人外套里面最暖和,注意露出口鼻
- 老人、糖尿病人感觉迟钝,冻伤了也可能不觉得痛,要主动检查手脚
- 疲劳、饥饿、饮酒的人散热快、发抖产热能力差,最先出现失温
```

### 风寒效应: 风让冷加倍

风把皮肤表面那层暖空气不断吹走,人感到的冷远远超过温度计的读数:

| 气温 | 风速约10 km/h | 风速约30 km/h | 风速约50 km/h |
|------|------|------|------|
| 0°C | 体感约-3°C | 体感约-6°C | 体感约-8°C |
| -10°C | 体感约-15°C | 体感约-20°C | 体感约-22°C |
| -20°C | 体感约-27°C | 体感约-33°C | 体感约-35°C |
| -30°C | 体感约-39°C | 体感约-46°C | 体感约-49°C |

```
- 体感低于约-28°C: 暴露的皮肤约30分钟内可能冻伤
- 体感低于约-40°C: 约10分钟内就可能冻伤
- 应对: 尽量不露皮肤;躲到背风处;风大时宁可停下等待
- 估计风速: 树枝摇动、雪被吹起约20-30 km/h;人顶风走路吃力约50 km/h以上
```

### 保持干燥

```
⚠️ 湿冷=致命组合!

✓ 脱掉湿衣服
✓ 拧干
✓ 体温烘干
✓ 不出大汗(及时脱层)
✓ 刷掉雪(不要让化)
✓ 防水层
```

**出汗管理**(冬季最容易被忽视的一条):
```
- 出发前先脱掉一层: 刚开始觉得"有点冷"正合适,走10分钟就暖和了
- 上坡、开路、挖雪洞时提前减衣服、拉开拉链,放慢速度,
  "宁可慢一点也不要出大汗";感到背上开始潮了就该减了
- 一停下来(休息、看地图、等人)马上加上保暖层,不要等冷了再穿
- 挖雪洞、劈柴等重活时只穿内层 + 防风层,保暖层收在背包里保持干燥,干完活穿上
```

**弄干衣物**:
```
- 小件(袜子、手套内衬)睡觉时放在睡袋里或贴身口袋,用体温烘干
- 有火时把衣服挂在火边,但离远一点、有人看着: 化纤遇火就熔,羽绒、鞋子烤焦常见
- 零下很冷时,湿衣服可以先挂在外面冻硬,把冰拍掉,能去掉一部分水
- 进帐篷、雪洞前把身上的雪彻底拍干净(雪在里面一化就湿了)
```

**怎样判断开始变危险**: 一直发抖、手指不灵活(拉不开拉链、划不着火柴)、说话含糊、走路踉跄 —— 这是早期失温,马上停下来加衣、吃东西、找避风处,见下方[失温症](#失温症)。

## 庇护所

```
冬季庇护所的原则:
✓ 越小越暖 —— 只做刚好够躺下的空间,人的体温能把它烘暖
✓ 先挡风 —— 风是最大的热量小偷
✓ 身下隔地 —— 见下方"睡觉"一节
✓ 通风 —— 雪洞墙壁不透气,见下方"庇护所里的空气"
✓ 天黑前完成 —— 挖一个雪洞要2-3小时,一定要提前开始
✓ 挖之前先看上方: 不要在可能发生雪崩的坡下、雪檐下、积雪很重的树下搭建
✓ 带一把铲子(雪铲、锅、平板)进庇护所,万一坍塌能自己挖出来
```

被困在车里时,车本身就是最好的庇护所,见[暴风雪-在车内被困](../02-灾难应对/02-气象灾害.md#暴风雪中)。

### 雪洞

**最佳选择** (保暖,隐蔽风):

```
步骤:
1. 找深雪堆或积雪坡
   - 雪要至少约2 m深,背风坡的积雪堆最好
   - 用棍子或探杆插下去试深度,确认下面不是岩石或空洞
2. 挖入口(小,保温)
   - 刚好能爬进去,约60 cm宽
3. 向上挖:
   - 入口低于睡眠平台
   - 冷空气下沉,暖空气上升
4. 内部:
   - 圆顶状(结构稳定)
   - 睡眠平台高于入口
   - 足够空间(但越小越暖)
   - 顶部至少30 cm厚;顶面抹光滑,融水会顺着弧顶流下,不会滴在身上
   - 洞内做一个低于平台的"冷槽",冷空气流到那里
5. 通气孔!(戳洞,防CO2)
   - 在平台上方的顶部斜着捅一个约拳头粗的孔
   - 留一根棍子插在孔里,每隔一两个小时转动一下,防止被雪或结冰堵住
6. 标记入口(防埋)
   - 在入口外插树枝、滑雪杖或鲜艳物品,下大雪时也能被找到
7. 铺垫隔离雪地

注意:
✓ 必须通气!
✓ 入口可用雪块或背包部分堵
✓ 内温可达0°C(外零下,相对温暖!)
✓ 挖洞时只穿内层+防风层,不要把衣服弄湿,挖得慢一点
✓ 两个人轮流: 一人在里面挖,一人在外面清运雪并照看
```

### 庇护所里的空气: 防窒息和一氧化碳

雪洞、雪屋、帐篷里有两种看不见的危险:

```
1. 缺氧、二氧化碳积聚
   - 雪洞内壁被体温和炉子烘化后再结冰,形成一层冰壳,雪就不透气了
   - 外面下大雪时通气孔和入口可能被埋住
   → 通气孔要一直保持通畅;入口不要完全封死;夜里下雪时起来检查一次

2. 一氧化碳(无色无味,致命)
   - 炉子、蜡烛、炭火在通风不良的地方燃烧会产生
   - 雪洞、帐篷空间小,几分钟到几十分钟就能达到危险浓度
   → 尽量在外面或入口处做饭;必须在里面用炉子时,打开入口和通气孔,用完马上熄灭
   → 绝不在封闭的雪洞、帐篷里烧炭取暖,也不要点着炉子睡觉

危险信号: 头痛、头晕、恶心、犯困,几个人同时出现,或蜡烛火焰变小变暗
→ 立即把所有人带到外面新鲜空气中,意识不清的人按一氧化碳中毒处理
```

一氧化碳中毒的识别与救助见[一氧化碳中毒](../01-日常疾病和伤害/07-居家与交通意外.md#一氧化碳中毒)。

### 雪墙

```
挡风:
- 堆雪墙
- 围成半圆或U形
- 背风侧开口
- 配合火堆

做法:
- 用铲子、锅或木板从踩实的雪里切出雪砖(约50 cm长、30 cm宽、20 cm厚)
- 墙高约1-1.5 m,能挡住坐着或躺着的人就够了
- 雪砖错缝垒,缝隙用雪填实
- 墙内再搭雨布、树枝或帐篷,保暖效果大增
- 火堆放在开口处,墙会把热量反射回来;火离墙太近会把墙烤化
```

### 雪沟

```
紧急:
- 挖雪沟
- 铺松枝、草
- 覆盖树枝、雪块
- 简易快速

做法:
- 沟比身体长一点,宽约1 m,深约1 m,与风向垂直
- 沟底铺至少20-30 cm厚的松枝、干草或背包
- 顶上横搭树枝、雪板、滑雪板,再盖雨布或雪块,只留一个小入口
- 1小时左右可以完成,适合天快黑、没力气挖雪洞时
- 雪浅时可以利用倒树下、大石旁的凹处,或先把雪堆高再挖
```

### Quinzhee雪屋

```
方法:
1. 堆大雪堆
   - 直径约3 m、高约2 m(两个人用)
   - 一边堆一边把不同层的雪搅匀,结实得更快
2. 等1-2小时(雪固化)
   - 粉状干雪需要更久,气温很低时等3小时左右
3. 从一侧挖空
4. 向上挖出睡眠平台
5. 壁厚20-30 cm
   - 挖之前从外面往雪堆里插一圈约30 cm长的小棍,
     从里面挖到棍子的末端就停,这样墙厚均匀
6. 通气孔!
   - 要求和雪洞一样: 保持通畅,不在里面烧炭

适合: 雪不够深、挖不了雪洞,但雪量还够堆起来的地方
```

### 睡觉: 身下隔地比身上盖被更重要

躺在雪上时,身体被压住的那一侧睡袋保暖层被压扁,热量主要通过身下流失。很多人盖得很厚还冻醒,原因就在身下。

```
隔地:
✓ 防潮垫(泡沫垫、充气垫);冬季最好两张叠着用
✓ 没有垫子时: 松枝、干草、树叶铺至少20-30 cm厚(压实后还有约10 cm)
✓ 背包、绳子、空的背包也能垫在脚下
✓ 坐着休息时也要垫东西,不要直接坐在雪上

睡觉前:
✓ 吃一点含脂肪的食物、喝热水 —— 身体要靠"燃料"产热过夜
✓ 先上厕所(憋尿时身体要额外耗热保持尿液温度)
✓ 原地做几下运动让身体暖起来再钻进睡袋,但不要出汗
✓ 换上干的袜子和内层;湿衣服不要穿着睡
✓ 一壶热水用袜子包好放进睡袋(检查盖子拧紧)

睡袋里:
✓ 帽子戴着,头和口鼻之外都包住
✓ 不要把头埋进睡袋呼吸 —— 呼出的水汽会让睡袋越来越潮
✓ 第二天要用的手套内衬、袜子、水壶(倒放,防止壶口先冻住)、电池、手机放进睡袋
✓ 几个人时挤在一起睡,互相取暖

夜里冻醒: 吃点东西、做几下仰卧起坐类的小运动,再睡
```

## 水源

寒冷环境同样会脱水: 冷空气很干,呼吸带走大量水汽;冷让人不想喝水,还会多尿。脱水后血液变稠,手脚更容易冻伤、更容易失温。

```
- 每天至少喝约3-4 L,干重活时更多
- 判断: 尿液淡黄色说明够了;深黄、量少说明缺水
- 水壶装在背包里、贴身放,或用袜子、衣服包住;倒着放,壶口不容易冻住
- 晚上烧好第二天的水,装进保温壶
```

### 融雪

**⚠️ 不要直接吃雪!**
```
原因:
- 降低体温(危险)
- 消耗能量
  1 kg雪从0°C融化再升到体温,要消耗约490 kJ(约120 kcal),
  相当于吃一小块饼干的热量全被用来"暖雪"了;雪越冷消耗越多
- 雪很蓬松,吃一大把雪只得到一小口水,却冻伤口腔、让人更想喝
- 只有在体温正常、正在活动发热,且只吃一点点润润嘴时,才可以接受

正确方法:
✓ 融化后饮用
✓ 煮沸(更暖和)
✓ 或体温融化(放水壶贴身,慢)
  - 水壶里留一点水,加雪,摇晃,放在外套里面贴近身体(不要直接贴皮肤)
  - 只适合补充少量,不能满足一天的需要
```

**融雪技巧**:
```
✓ 先放少量水,再加雪(防烧焦容器)
  - 锅底干烧雪会烧坏锅,而且水有焦味;没有水时先放一小把雪慢慢化出底水
✓ 选干净白雪
✓ 压实雪(比蓬松雪水多)
  - 新下的粉雪约10 L雪才出1 L水;压实的旧雪、冰粒雪约2-3 L出1 L
✓ 不要用黄、粉、脏雪
  - 黄雪可能有尿,粉红雪是藻类(可能引起腹泻),灰黑雪有灰尘、烟尘
  - 不要用营地、厕所、动物活动区、公路边的雪
✓ 盖上锅盖,边化边加雪,不用每次都等全化完
✓ 也可以把雪装进深色布袋挂在火边或太阳下,下面放容器接水
```

**燃料够不够**:
```
化雪很耗燃料: 先要把雪升到0°C,再化开(这一步最耗热),再加热
→ 同样得到1 L热水,化雪比烧现成的水多用两到三倍燃料

粗略估计:
- 气罐炉: 只靠化雪供水时,每人每天约需100-200 g气
- 木柴: 一个人一天的饮用水,也要一大抱柴火
- 冷天气罐火力会变弱: 用前把气罐揣在怀里暖一暖;
  液化气在约0°C以下汽化困难,冬季要选低温气罐

节省燃料:
✓ 锅盖盖好,炉子挡风,锅底贴近火焰
✓ 有流动的溪水、湖面冰洞的水时优先取液态水(只需消毒)
✓ 晴天用深色塑料布、黑色锅放在太阳下化雪
✓ 一次烧够,装进保温壶,不要反复烧
```

雪水大体干净,但融化后和其他野外水一样可能带病菌: 雪不干净、在有人和动物活动的地方取雪时,化开后煮沸1分钟(海拔2000 m以上煮3分钟)。湖水、溪水更要消毒,方法见[基础生存技能-水质净化](00-基础生存技能.md#水质净化)。

### 冰

```
✓ 冰比雪更好(水多)
  - 同样一锅,冰出的水是雪的几倍,用的燃料少
✓ 选干净冰
  - 河流、湖泊冰下的水同样可能有病菌,化开后要消毒
✓ 融化饮用

海冰(极地海边):
- 新结的海冰是咸的(灰白色、不透明、边缘尖锐),不能喝
- 隔年的老海冰盐分已经析出(浅蓝色、透明、边角圆滑),化开后基本可以喝
- 尝一下: 咸的就不要用
```

## 火

### 生火挑战

```
困难:
- 湿木
- 大雪覆盖
- 风大
- 火绒难找

解决:
✓ 找枯死树上枝条(干燥)
  - 挂在树上、没有接触地面的枯枝最干;能"啪"地折断的是干的,弯而不断的是湿的
✓ 劈开湿木用内芯
✓ 松树脂(极好的引火物)
✓ 桦树皮(防水易燃)
✓ 挡风
✓ 雪地:先铺木头平台(防雪融化灭火)
  - 用一排手腕粗的湿木或生木铺底,火在上面燃烧;雪深时一定要有平台
✓ 火柴、打火机放在贴身口袋(打火机冷了打不着,捂热再用)
✓ 带上引火物: 蘸凡士林的棉球、蜡烛头、固体燃料
```

生火的基本方法、火堆结构见[基础生存技能-生火技术](00-基础生存技能.md#生火技术)。

```
注意:
- 不要在积雪很重的树下生火: 热气上升会把树枝上的雪震落,把火砸灭
- 不要在雪洞、雪屋里生火(化塌、一氧化碳)
- 火堆后面立一排木头或一块岩石作反射墙,把热量反射到人这边
- 生火要先收集够柴火: 引火物一把、细枝(火柴粗到手指粗)一大抱、粗柴是细枝的几倍
```

### 保持火

```
✓ 准备足够燃料
  - 冬夜很长,过夜要准备的柴比想象的多得多,天黑前收集好
✓ 防风雪遮蔽
✓ 持续维护
✓ 夜间:灰覆盖保留火种
✓ 几个人轮流守火,同时互相照看(睡着的人有没有冻着)
```

## 食物

```
寒冷时身体需要更多热量:
- 平时成年人每天约2000 kcal,冬季野外活动常需要3000-4500 kcal
- 脂肪每克的热量是糖和淀粉的两倍多,而且消化慢、产热持久:
  坚果、肥肉、黄油、巧克力、芝麻糊都是好选择
- 少量多次: 每1-2小时吃一点,不要等饿了才吃
- 睡前吃一些含脂肪的食物,夜里不容易冻醒
- 被困时先盘点所有食物,定量分配
```

### 动物

```
⚠️ 我国《野生动物保护法》禁止平时猎捕野生动物,
   设置陷阱、套索在正常情况下属违法行为。
   下面只适用于真正的求生绝境;能求救时优先求救、等待救援。
   人不吃东西也能活几周,冬季被困首先要解决的是保暖,不是打猎。
```

**可猎**:
```
- 兔、松鼠
- 鸟类
- 鱼(冰钓)
- 大型动物(需技能)

方法:
- 陷阱、绳套
- 冰钓(凿冰洞)
  - 只在足够厚的冰面上凿洞(见下方"冰面"一节),洞口不要太大
- 追踪雪上足迹
```

**所有肉煮熟!**(防寄生虫)

```
- 野生动物可能携带寄生虫(如旋毛虫)和传染病,不要吃生肉、生血
- 不碰病死、来历不明的动物尸体
- 只吃很瘦的兔肉等瘦肉而没有脂肪时,会出现恶心、腹泻、虚弱("兔肉饥饿"),
  要同时吃脂肪和植物性食物
- 极地: 北极熊、海豹等的肝脏维生素A含量极高,吃了会中毒,不要吃
```

### 注意

```
⚠️ 食物需水消化
- 吃太多脱水
- 平衡水和食
- 尤其是高蛋白的肉类,消化和排出时需要大量水;水少时少吃肉,多吃淀粉和糖
```

## 导航

### 白茫茫易迷路

```
预防:
✓ 指南针/GPS
✓ 地图
✓ 做标记(旗帜、堆雪)
✓ 视线差时不乱走
✓ 暴风雪时停下
✓ 留在原地(如迷路)
```

**白化天气**(白茫茫一片):
```
阴天下雪或起雾时,天空、雪地、远处的山都是同一种白色,
看不到地平线,看不出地面起伏,也分不清远近 ——
人会走下悬崖、掉进沟里,或者以为自己在走直线其实在绕圈。

应对:
1. 最好的办法: 停下来,原地挡风等待,白化天气常常几小时就会过去
2. 必须移动时:
   - 按指南针方位走,不要凭感觉
   - 队伍用绳子连起来,间隔几 m,前面的人走,后面的人看指南针纠正方向
   - 往前方丢雪球、深色物品(如手套)看它落在哪里,判断前面是平地、下坡还是悬崖
   - 用登山杖或长棍在前面探路
   - 每隔一段插标记,迷路时能退回来
3. 远离山脊边缘: 山脊上的雪檐悬空伸出,看起来像实地,踩上去会塌落
```

迷路后怎么办、怎样向救援人员说清位置,见[发现自己迷路了](07-户外出行准备与求救.md#发现自己迷路了)和[报警求救: 说清楚你在哪里](07-户外出行准备与求救.md#报警求救-说清楚你在哪里)。

### 雪地行进

```
速度和体力:
- 在深雪里不穿雪鞋走路,每一步陷到膝盖甚至大腿,非常消耗体力,
  一天可能只走几 km
- 有雪鞋、滑雪板时速度和体力消耗大为改善;
  没有时可以用树枝、木板绑在鞋底做简易雪鞋(增大面积,不让脚陷下去)
- 多人行进时排成一列,踩着前面人的脚印走;
  开路的人最累,每隔10-15分钟轮换一次

时间:
- 冬季白天短,下午三四点就要开始准备过夜
- 出发前定好"掉头时间": 到点没到目的地就原路返回

路线:
✓ 选林间、缓坡、山脊较宽处
✗ 避开陡坡、雪檐下方、沟槽(雪崩通道)
✗ 避开冰封的河流、湖面(除非确认冰足够厚)
✗ 不要独自上冰川: 冰川上的裂缝被雪桥盖住,掉进去非常危险,
  需要结组绳和专业训练

树坑(树井): 大树周围的雪是松的,下面是空的,
人掉进去头朝下被卡住会窒息 —— 深雪中不要贴着大树走
```

"掉头时间"的定法见[户外出行准备与求救-掉头时间](07-户外出行准备与求救.md#掉头时间)。

### 暴风雪

```
如遇:
1. 立即寻找/建造庇护所
   - 不要等风雪大到看不见了才开始,有暴风雪迹象(天色转暗、风突然变大、
     云层压低)时就动手
2. 雪洞、雪墙
3. 等待过去
   - 暴风雪可能持续一两天,定量分配食物和燃料
4. 不要继续前进(迷路风险)
5. 保持温暖
6. 定时清理入口和通气孔的积雪
7. 有手机时先报告位置,然后省电,定时开机
```

天气变化的征兆见[天气观测与预报](../08-基础科学知识/07-天气观测与预报.md)。

## 危险

### 失温症

**最大杀手!**

见[急性症状-失温](../01-日常疾病和伤害/05-急性症状.md#失温症)

野外失温的识别、处理要点见[涉水山洪与野外失温-野外失温](08-涉水山洪与野外失温.md#不只是冬天-野外失温);落入冷水见[落入冷水](08-涉水山洪与野外失温.md#落入冷水)。

```
识别要点:
- 早期: 一直发抖、手指不灵活、走路踉跄、说话含糊、情绪低落或烦躁
- 危险: 发抖停止但人更迷糊、叫不醒、反常地脱衣服
- 失温的人自己往往意识不到,同伴要互相观察

雪地处理要点:
1. 停下,进庇护所或挡风处
2. 湿衣服换成干的;身下隔地;用睡袋、毯子、保温毯从头到脚包起来
3. 清醒能吞咽时喝温热的甜饮料、吃东西
4. 热水壶用衣服包好放在胸口、腋下、腹股沟
5. 严重时(不发抖、意识模糊): 立即求救;平放,动作要轻,
   不要搓手脚、不要让他走路、不要火烤或泡热水
❌ 不要喝酒
```

**预防**:
```
✓ 保暖多层
✓ 保持干燥
✓ 避免出汗
✓ 充足食物(燃料)
✓ 庇护所
✓ 保持活动(但不过度)
✓ 喝够水
✓ 互相观察,有人掉队、话变少就停下检查
```

### 冻伤

冻伤和失温同时存在时,**先处理失温(保命),再处理冻伤**。冻伤分度、复温和复温后护理的详细做法见[外伤处理-冻伤](../01-日常疾病和伤害/02-外伤处理.md#冻伤)。

**症状**:
```
浅表:
- 皮肤发白、麻木
- 刺痛

深度:
- 皮肤发黑
- 无感觉
- 组织坏死

补充:
- 刚冻上时各度看起来都差不多: 苍白、蜡样、摸着发硬、没有感觉
- 冻伤到底有多深,要复温后1-2天(起清亮水疱还是血疱、发紫发黑)才看得清
- 最常见的是"冻伤前兆": 鼻尖、耳朵、脸颊、手指出现白斑,摸着凉、麻木,
  此时还没有冻结,温暖即可完全恢复
```

**预防**:
```
✓ 覆盖暴露部位
✓ 保持循环(活动手指脚趾)
✓ 不要太紧(手套、鞋)
✓ 保持干燥
✓ 感觉麻木立即处理
✓ 不要徒手接触零下的金属、汽油(汽油挥发快速带走热量,瞬间冻伤)
✓ 吃饱、喝够水,不喝酒、不吸烟
✓ 脚冷了不能缓解时,停下来脱鞋检查,换干袜子
```

**处理**:
```
冻伤前兆(白斑、麻木,还能活动):
- 把冻手放进对侧腋下或肚皮上,冻脚放在同伴腋下或肚皮上
- 用手捂住脸颊、耳朵、鼻子;不要搓
- 几分钟后颜色恢复、有刺痛感,说明处理对了

已经冻硬的冻伤:
✓ 转移温暖处
✓ 温水复温(37-39°C)
  - 救助者用手肘或手腕内侧试水温,"温热、能一直放在里面"即可;
    伤者的冻伤部位没有感觉,不能自己试
  - 浸泡到皮肤变软、恢复颜色,通常30分钟左右;中途不断加热水保持温度
    (加热水时先把伤肢拿出来)
  - 复温过程很痛,可按说明书服用布洛芬等止痛药
✓ 复温后用干燥纱布宽松包扎,手指脚趾之间垫纱布;抬高;不要刺破水疱
✓ 不要:
  ❌ 揉搓
  ❌ 用热水、火烤
  ❌ 复温后再冻(更危险)
  ❌ 用雪搓(错误的老方法)
✓ 就医

⚠️ 什么时候复温: 只有确定复温后不会再冻上,才复温
- 还在雪地里、还要继续走路撤出时,冻住的脚宁可先不复温:
  冻着的脚还能勉强走,复温后的脚肿痛、不能走路,而且再冻一次损伤更重
- 到达能一直保暖的地方(营地、车里、屋里、医院)再复温
- 能在短时间内送医的,包裹保暖,由医院复温
```

```
必须尽快送医:
- 起水疱(尤其是血疱)、皮肤发紫发黑、复温后仍然没有感觉
- 大面积冻伤,或手、脚、脸的冻伤
- 同时有失温
- 冻伤伤口有破伤风风险,需要就医评估
```

不冻结的冷损伤(冻疮、长时间穿湿鞋袜引起的浸渍足)见[冻疮与浸渍足](../01-日常疾病和伤害/02-外伤处理.md#冻疮与浸渍足不是冻伤)。

### 雪盲

**原因**:雪反射UV

```
新雪能把80%以上的紫外线反射回来,加上高海拔紫外线本来就强,
眼睛从上下两个方向同时被晒 —— 相当于角膜被"晒伤"。
晒的时候不痛,通常几个小时后(常是晚上)才发作。
```

**症状**:
```
- 眼痛
- 流泪
- 视力模糊
- 怕光
- 眼睛里像有沙子,眼睑红肿,睁不开眼
```

**预防**:
```
✓ 太阳镜/护目镜
  - 要能挡紫外线的(标有UV400或防紫外线),两侧最好有遮挡
  - 普通的有色眼镜挡不住紫外线,反而让瞳孔放大,更伤眼
✓ 或自制:
  - 布条留缝
  - 木片刻细缝
  - 硬纸板、树皮也行: 宽度盖住双眼,开两道1-2 mm的细缝,用绳子系在脑后
  - 眼睛下方和颧骨涂黑(炭灰)能减少反光
✓ 阴天也需要!
  - 云层挡不住大部分紫外线,阴天、雾天照样会雪盲
✓ 眼镜丢了的人走在队伍里,低头看前面人的背影,不要看雪面
```

**治疗**:
```
- 避光休息
- 冷敷
- 通常24-48小时恢复

具体做法:
- 闭眼,用干净湿布盖住双眼,或待在暗处;能戴眼镜就继续戴
- 摘掉隐形眼镜
- 不要揉眼睛
- 疼痛明显时可按说明书服用布洛芬或对乙酰氨基酚
- 恢复之前尽量不要继续在雪地里行走;必须走时戴好护目镜,由同伴带路

⚠️ 就医: 超过2天不见好转、视力明显下降、眼睛有脓性分泌物、或只有一只眼剧痛
```

### 雪崩

```
绝大多数雪崩是被困者自己或同伴的体重触发的。
最有效的保命办法是不进入雪崩地形 —— 被埋之后能活下来靠的是运气和同伴。
```

**识别危险**:
```
- 坡度30-45°
  - 最常发生在约35-45°的坡;更陡的坡雪存不住,常常小规模不断滑落
  - 估计坡度: 把两根等长的登山杖一根竖直、一根平放组成直角,
    或者看坡面: 平地上站立觉得"需要用手扶"的坡已经超过30°
  - 坡下的人也危险: 雪崩会从上方的陡坡冲下来,冲出很远
- 新降雪后
  - 一天内降雪20-30 cm以上,之后一两天最危险
- 气温骤升
  - 春季中午、下雨后、太阳暴晒的坡面
- 坡面无植被
  - 树木稀少、有被冲断的树、坡下有成堆的碎雪和树枝 → 以前发生过雪崩
- "嗡嗡"声
  - 踩在雪上听到"嘭"的闷响、雪面出现裂纹 → 雪层不稳,马上离开
- 背风坡: 大风把雪吹积成厚厚的雪板,特别容易断裂
- 近期附近发生过雪崩
```

**避免**:
```
✓ 避开危险坡
✓ 了解路线
  - 出发前查当地雪崩预报、问当地人和管理部门
✓ 早晨(雪冻结)更安全
  - 春季尤其明显,中午以后湿雪雪崩风险大增
✓ 逐一通过(团队)
  - 一个人通过时其他人在安全处观察,一旦被埋能马上记住位置
✓ 走山脊、缓坡、茂密树林里;沿谷底走时远离两侧陡坡
✓ 不在沟槽、陡坡下方休息和扎营
✓ 解开背包腰带、胸带,拿登山杖时不套腕带,万一被卷入方便甩掉
```

**装备**(进入有雪崩风险的地方,每人必带,并且练习过):
```
- 雪崩信标(收发器): 出发时打开发射,检查每个人的都在工作
- 探杆: 能折叠的长杆,用来插进雪里找人
- 雪铲: 被埋的雪很快会变得像混凝土,用手几乎挖不动
只带一样等于没带: 信标找到大致位置,探杆确定位置和深度,铲子才能挖出来
```

**如被埋**:
```
1. 全力游向上
   - 雪崩刚开始时,大喊让同伴注意,尽量往侧面跑、冲出雪崩的边缘
   - 被卷入时甩掉滑雪杖、背包,抓住树木岩石,手脚做游泳动作尽量留在表面
2. 雪崩停前:
   - 一手护脸(造空气空间)
   - 一手向上(标记位置)
   - 雪一停就会凝固,要在停下前的最后一刻做这两件事
3. 停止后:
   - 扩大空间
   - 向上挖
     - 能动就挖;分不清上下时,吐一口唾沫,看它往哪边流,反方向就是上
     - 被埋较深时雪会凝固得挖不动,不要白费力气
   - 节省氧气
     - 保持冷静,慢慢呼吸;听到上方有人时再喊
   - 等待救援
```

**同伴被埋时(搜救)**:
```
时间就是生命:
- 15分钟内挖出,大多数人能活;超过约35分钟,生还率急剧下降
- 等外部救援队到达往往要一小时以上 —— 现场的同伴是被埋者最大的希望
→ 先自救互救,同时派一人(或用电话)报警,不要所有人都离开去求援

步骤:
1. 先确认安全: 上方还有没有可能二次雪崩;所有人信标转为搜索模式
2. 记住被埋者最后被看到的位置,搜索从那里往下方雪崩流动的方向进行
3. 先目视: 雪面上露出的手、脚、衣物、装备
4. 用信标搜索,接近后用探杆以约25 cm的间隔螺旋式往外插,
   探到人后探杆留在原地标记
5. 从探杆下方(坡下一侧)约1-1.5倍埋深处开始挖,不要从正上方往下挖
   (从正上方挖会踩塌被埋者的空气空间);几个人时排成一队轮流挖、往后传雪
6. 先挖出头部,清理口鼻;不呼吸时开始心肺复苏
7. 救出后防止失温,按失温处理,送医

没有信标时: 排成一排,每人间隔约50 cm,用探杆或长棍在雪里一步一插地向前推进
```

心肺复苏方法见[心肺复苏](../01-日常疾病和伤害/00-基础急救知识.md#心肺复苏cpr);伤员的搬运见[野外伤病处置与转运-搬运伤员](11-野外伤病处置与转运.md#搬运伤员)。

### 冰面与落入冰窟

冬季每年都有人在河面、湖面、水库上落水身亡。冰面看起来结实,但厚度很不均匀。

**冰的厚度参考**(指新结的、透明发青的坚冰):

| 冰厚 | 能承受 |
|------|------|
| 不到15 cm | 不要上去 |
| 约15 cm | 一个人或几个人分散步行 |
| 约20 cm | 一群人(如滑冰的人群) |
| 约25 cm | 雪地摩托、全地形车;普通汽车不要开上冰面 |

```
⚠️ 上表只是参考,不能保证安全:
- 白色、不透明、有气泡的冰,强度只有透明冰的一半左右,厚度要加倍
- 下面这些地方的冰更薄: 河流(水在冰下流动)、入水口出水口、桥墩附近、
  芦苇和树枝周围、有温泉或排污口的地方、雪覆盖的冰面(雪像被子一样让冰长不厚)
- 化冰季节(初春)、气温连续在0°C以上、冰面发灰发黑有积水 → 不要上冰
- 冰面有裂缝、发出"咔咔"声 → 马上趴下,沿原路返回

上冰时:
✓ 先用斧头、冰锥在岸边凿开测量厚度,往前走时每隔一段再测
✓ 几个人时分散开,间隔至少几 m,不要聚在一起
✓ 带一根长杆横抱在胸前(落水时横在冰洞上能撑住),带绳子
✓ 冰锥一对挂在胸前: 两个带尖钉的木柄,用绳子连起来,落水时扎进冰面往外拉
  (没有时用两根削尖的木棍、两把螺丝刀代替)
✓ 解开背包腰带
✓ 宁可绕远路走岸边
```

**落入冰窟的自救**:
```
1. 前1分钟: 冷水会让人不由自主地大口喘气("冷休克")
   → 不要慌乱挣扎,把头保持在水面以上,控制呼吸,等这一阵过去
2. 转身朝向掉下来的方向 —— 刚才走过的冰承受住了你,那里最结实
3. 双臂伸到冰面上,用冰锥扎进冰里(或用手肘、手掌压住冰面)
4. 双腿在身后用力踢水,让身体尽量变成水平,像海豹爬上岸一样
   一边踢腿一边用手往前拉,慢慢把身体推到冰面上
5. 上了冰面不要站起来: 滚离冰洞,或趴着往回爬,
   让体重分散在大面积上,直到回到厚冰或岸上
6. 有大约10分钟手脚还能用力,抓紧时间;爬不出去时,
   双臂搭在冰面上不要动,让衣服冻在冰上,能撑得更久,等待救援
7. 上岸后立即到避风处脱掉湿衣服,换干衣服,按失温处理
```

**救落入冰窟的人**:
```
❌ 不要直接走过去拉人 —— 冰洞周围的冰已经裂了,施救者会一起落水
1. 大声告诉他: "转身朝我这边、踢腿、慢慢爬"
2. 先报警(110、119)
3. 递: 趴在冰上(或在岸上),递长杆、树枝、围巾、皮带
4. 抛: 绳子(一端打一个绳圈)、救生圈、能漂浮的东西
5. 必须靠近时: 趴着、分散体重,推着梯子、木板、长杆前进,后面有人拉着你的脚或绳子
6. 拉出来后趴着拖离冰洞,上岸后防失温;呛过水、意识不清的人送医
```

冷水落水的"1-10-1"原则见[落入冷水](08-涉水山洪与野外失温.md#落入冷水);溺水的急救见[溺水](../01-日常疾病和伤害/05-急性症状.md#溺水)。

## 信号

```
白色背景:
✓ 深色标记(SOS、X)
✓ 烟雾(日)
✓ 火光(夜)
✓ 镜子反光
✓ 鲜艳衣物
✓ 踩出大字

做法:
- 在开阔雪地上踩出或挖出大字,每个字母长至少3-5 m,沟要踩深,
  让阴影显出来;沟里填树枝、深色衣物更显眼
- 风雪后字会被填平,要定时重新踩
- 白天的烟: 火上加松枝、绿叶,冒出浓白烟;
  雪地背景下白烟不显眼,加橡胶、塑料、油可以产生黑烟
- 准备三堆柴火排成三角形,听到飞机声时点燃
- 手机: 冷天电池耗电很快,贴身保暖,关机省电,定时开机看信号
```

地面对空信号的含义见[基础生存技能-地面对空信号](00-基础生存技能.md#地面对空信号);等待直升机救援见[野外伤病处置与转运-直升机救援](11-野外伤病处置与转运.md#直升机救援)。

## 📝 雪地求生要点

```
优先级:
1. 保暖(失温致命)
2. 庇护所(雪洞)
3. 水(融雪)
4. 火(保暖、融雪、信号)
5. 食物

关键:
✓ 保持干燥!
✓ 多层穿衣
✓ 少出汗: 热了先减衣,停下马上加衣
✓ 雪洞庇护所
✓ 通气孔保持通畅,不在雪洞、帐篷里烧炭
✓ 睡觉时身下隔地
✓ 不吃雪(融化后喝)
✓ 防冻伤: 复温水温37-39°C;可能再冻时不要复温
✓ 防雪盲: 阴天也戴护目镜

危险:
⚠️ 失温(#1杀手)
⚠️ 冻伤
⚠️ 雪崩: 避开30-45°的坡;带信标、探杆、铲子
⚠️ 雪盲
⚠️ 迷路: 白化天气停下等待
⚠️ 冰面: 不到15 cm不要上;落水后转身、踢腿、爬出、滚离
⚠️ 一氧化碳和窒息
```
