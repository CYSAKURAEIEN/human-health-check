# 沙漠求生指南

## 核心挑战

```
- 极度缺水
- 高温(日)
- 低温(夜)
- 暴晒
- 迷失方向
- 食物匮乏
```

沙漠里致命的通常不是饥饿,而是**脱水和中暑**,其次是迷路和夜间寒冷。我国的沙漠、戈壁主要在西北(塔克拉玛干、库姆塔格、巴丹吉林、腾格里、罗布泊一带和大片戈壁),每年都有自驾、徒步穿越的人遇险。回顾这些事故,常见的经过几乎一样:

```
出事的典型经过:
1. 水带得不够,或者以为"够了"
2. 车坏了、陷沙了、迷路了
3. 离开车辆,白天顶着太阳步行去找人、找水
4. 一两天内脱水、中暑,倒在离车几 km 到十几 km 的地方
   (而搜救队往往先找到的是那辆车)

能活下来的关键也几乎一样:
✓ 出发前留下行程单,告诉别人路线和最晚返回时间
✓ 带足水
✓ 出事后留在车旁,白天躲阴,减少出汗,发信号,等待救援
```

出发前的准备(行程单、装备、掉头时间、迷路后怎么办)见[户外出行准备与求救](07-户外出行准备与求救.md)。进沙漠、戈壁时额外注意:

```
✓ 不要单车进入: 至少两辆车结伴,一辆坏了还有另一辆
✓ 每人每天按至少4-6 L水准备,再多带几天的备用水
  (车上的备用水比"计划刚好够"重要得多)
✓ 带卫星通信设备(卫星电话或能发短信、定位的卫星信标):
  沙漠腹地大多没有手机信号
✓ 带遮阳布、铁锹、拖车绳、打气泵、备用胎、镜子、哨子
✓ 避开最热的季节(盛夏)和沙尘暴多发的季节(春季)
✓ 走成熟的路线,跟有经验的向导或车队
```

## 水源 (最关键!)

### 保存体液

```
⚠️ 水比食物重要100倍!

减少水分流失:
✓ 避免日间活动(阴凉处休息)
✓ 夜间/清晨/傍晚行动
✓ 保持衣物(防晒保湿)
✓ 用鼻呼吸,少张嘴(减少呼吸失水)
✓ 小口喝水(不要牛饮)
✓ 不要进食(消化消耗水)
✓ 保持冷静(焦虑增加失水)

❌ 不要:
- 白天行走
- 脱光衣服(增加蒸发)
- 饮酒
- 吸烟
- 过度劳动
- 说话过多
```

**核心思路: 省的是汗,不是水。** 身体每出一滴汗,都要用喝下去的水来补。所以能做的是**减少出汗**,而不是少喝水(见下面[配给水](#配给水))。

#### 出汗有多快

```
高温下大致的失水量(个人差异很大,仅作估计):
- 在阴凉处静坐休息: 每天也会失去好几 L 水,气温越高越多
- 在烈日下走路、干活: 每小时出汗可达约1 L,甚至更多
- 同样走一段路,白天顶着太阳走要比夜里走多出好几倍的汗

所以:
- 白天在阴凉处一动不动,是最"省水"的做法
- 在烈日下走一个下午,可能就把一整天的水用光
```

#### 怎样减少出汗

```
1. 白天躲阴: 大约10点以后到傍晚,待在阴凉处不动
   - 车底、车旁的阴影、岩石背阴面、自己搭的遮阳棚
   - 不要躺在晒过的沙地、石头上: 先垫衣物、垫子或树枝,
     或者把表层热沙扒开,下面几十 cm 的沙子明显凉一些
   - 阴影会随太阳移动,隔一段时间挪一下位置
2. 夜间行动: 必须走的路,放在傍晚、夜里和清晨
3. 穿长袖长裤,不脱衣服:
   - 衣服挡住阳光直射,汗留在衣服里慢慢蒸发,起到降温作用
   - 脱光后,阳光直接晒到皮肤上,汗水刚出来就被干燥的热风吹干,
     身体只能出更多的汗来降温,失水更快,还会严重晒伤
   - 浅色、宽松、透气的最好;头和颈后一定要遮住
4. 少说话、少张嘴: 用鼻子呼吸,干燥空气每次呼气都会带走水分
5. 不要做多余的事: 挖坑、搬东西、找食物都放在凉快的时候,而且量力
6. 不喝酒: 酒精利尿,会加快脱水,还会让人判断失误
```

#### 不能喝的"水"

```
❌ 尿液: 越脱水尿越浓,里面是身体要排出的盐和废物,喝了只会更渴
   (可以倒进蒸馏器坑里,或用来打湿衣服帮助降温)
❌ 汽车水箱里的冷却液、防冻液: 有毒,喝少量就可能致命
❌ 玻璃水(雨刷液): 常含甲醇,有毒
❌ 海水、盐湖水、明显发咸发苦的苦咸水: 越喝越渴,加重脱水
❌ 酒

不确定能不能喝的水,宁可不喝。
```

### 寻找水源

先要有一个现实的认识: **在真正的沙漠腹地,靠自己找到足够的水,可能性很小。** 最可靠的"水源"是出发时带的水和尽快到来的救援。下面这些线索只在有条件、不耗费太多体力时尝试,不要为了追一个线索在白天远走。

**地形线索**:
```
✓ 干河床(挖底部,可能有地下水)
✓ 岩石裂缝(清晨有露水)
✓ 植被聚集处
✓ 动物踪迹汇聚
✓ 鸟类飞行方向(傍晚)
✓ 蜜蜂活动(距水<5 km)
✓ 苍蝇(距水<100 m)
```

```
补充说明:
- 绿色、茂密的植物(芦苇、胡杨、红柳成片生长)说明地下水位较浅,
  在这些地方的低处挖掘,成功的机会比在光秃秃的沙丘上大得多
- 我国的戈壁、荒漠里,牧民的井和泉眼往往是附近唯一的水源;
  牲畜(羊、骆驼)踩出的多条小路汇聚的方向,常常通向水井
- 动物、鸟、蜜蜂、苍蝇这几条是传统经验,只能作参考,
  不能保证一定有水,更不能据此判断水能喝
- 远处"一片湖水"多半是海市蜃楼(见下面导航部分)
- 盐碱地上的水、湖边有白色盐霜的水,往往是苦咸水,不能喝
```

**挖掘取水**:
```
干河床:
1. 选择外弯、低处
2. 挖坑至湿沙
3. 继续挖
4. 等待渗水
5. 必须净化!

特点:
- 费力
- 可能无水
- 最后手段
```

```
具体做法:
- 选河道转弯处外侧的最低点、或者有绿色植物生长的地方
- 在清晨或傍晚挖,不要在中午挖(出的汗可能比挖到的水还多)
- 挖到三四十 cm 还完全是干沙,换个地方或者放弃;
  挖到湿沙再往下挖一些,然后等待,水会慢慢渗进坑底
- 舀水时舀上层的清水,用布过滤后再消毒
- 干河床也是山洪的通道: 可以在河床里挖水,但不要在河床里过夜
```

净化方法见[基础生存技能-水质净化](00-基础生存技能.md#水质净化);干河床扎营的危险见[涉水山洪与野外失温-露营选址](08-涉水山洪与野外失温.md#露营选址)。

**露水收集**:
```
清晨:
- 用布擦岩石、植物
- 拧到容器
- 可收集少量
```

```
补充说明:
- 要赶在日出前、露水蒸发前收集
- 金属车身、塑料布在夜里降温快,清晨表面上常常结露,
  也可以用布擦下来
- 沙漠空气干燥,很多夜晚根本没有露水;即使有,量也很少,
  只能润润嘴,不能当作主要水源
```

**植物取水**:
```
仙人掌:
⚠️ 谨慎!很多有毒!
- 桶状仙人掌(某些种类)
- 切开,捣碎,挤汁
- 多数仙人掌汁会引起呕吐、腹泻,反而加重脱水
- 不能靠"苦不苦"判断能否饮用,只作最后手段
```

```
补充说明:
- 我国的沙漠里基本没有野生仙人掌;梭梭、红柳、沙拐枣等沙漠灌木
  也不是能挤出水的植物,不要指望从中得到水
- 植物蒸腾袋: 把透明塑料袋套在一根有叶子的灌木枝上,扎紧袋口,
  放在阳光下,叶子蒸腾出的水会凝结在袋里;不耗体力,
  但沙漠灌木叶子小,产水量很少(实测常常只有几十 mL),
  而且只能用确认无毒的植物
```

植物蒸腾袋的做法见[基础生存技能-植物取水](00-基础生存技能.md#植物取水)。

**太阳能蒸馏器**(最后手段):
```
⚠️ 实测产水很少,挖坑出汗可能比产水还多
   不要在白天挖,只在清晨或傍晚、有现成塑料布时考虑

1. 挖坑(1 m直径,50 cm深)
2. 底部中央放容器
3. 坑内放植物、湿沙(增加水分)
4. 铺透明塑料布
5. 边缘压实密封
6. 中央放小石子(向下凹)
7. 蒸发→凝结→滴入容器

产量: 实测通常每天几十到几百 mL
不要指望靠它维持生命!
```

```
怎样让它"划算"一点:
- 只在土壤本来就潮湿的地方挖(干河床低处、植物根部附近),
  在干燥的沙子里几乎收不到水
- 可以把尿、苦咸水倒在坑里(不要倒进收水的容器里),
  蒸发出来再凝结的水可以喝
- 如果有软管,一头放进容器,另一头引到外面,
  可以直接吸水,不用每次掀开塑料布(一掀开热气就跑了)
- 一个人一天要几 L 水,一个蒸馏器只能补一点零头
```

### 配给水

```
原则:
✓ 不要配给!该喝就喝!
✓ 脱水比缺水更危险
✓ 小口慢饮
✓ 湿润嘴巴

注意:
- 不喝水不会"适应"
- 只会脱水更严重
```

**为什么不要省着喝**: 水存在水壶里不能帮你降温,存在身体里才能。省着不喝的人,脱水后头晕、乏力、判断力下降,更容易做出错误决定(比如白天出去乱走),也更早中暑。沙漠搜救中曾多次发现遇难者的水壶里还有水。**要省的是身体里的水(少出汗),不是水壶里的水。**

```
具体做法:
- 渴了就喝,不要等到很渴;最好在口渴之前就喝
- 小口慢饮: 每次喝几口,隔一会儿再喝,
  比一口气灌下一大瓶更容易吸收,也不容易恶心呕吐
  (湿润嘴巴只能缓解口干,不能代替真正喝下去)
- 每小时喝水一般不要超过约1-1.5 L
- 长时间大量出汗时,只喝白开水会丢失盐分,
  出现头痛、恶心、乏力、抽筋甚至意识模糊(低钠血症);
  有条件时喝口服补液盐、运动饮料或淡盐水,或配着吃点咸的东西
- 看尿: 淡黄色说明水够;深黄、尿量很少说明已经缺水,
  大半天不排尿是危险信号

水确实不多、救援还要很久时:
- 仍然按需要喝,不要硬撑;把力气用在减少出汗上
  (白天完全不动、躲阴,只在夜里做必须的事)
- 把水留给最需要的时候,不如现在就喝下去保持清醒
- 多人时平均分配,儿童、老人、病人和中暑的人优先
```

补液盐的配制见[常见疾病-补液](../01-日常疾病和伤害/01-常见疾病.md#1-补液最重要),补水的量和低钠血症见[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑)。

## 庇护所

### 防晒(白天)

**优先级最高!**

```
选址:
✓ 阴凉处(岩石、峡谷)
✓ 避免沙地(反射、辐射热)
✓ 通风

建造:
1. 利用自然阴影
2. 或搭建遮阳:
   - 任何布料、塑料
   - 离地面30-45 cm(空气流通)
   - 不要触碰地面(热传导)
3. 两层更好(隔热)
```

```
补充说明:
- 夏季正午沙地、石头表面的温度可以比气温高出二三十度,
  直接坐、躺在上面等于被"烙"着;而表层以下几十 cm 的沙子凉得多
- 车旁的遮阳棚: 把遮阳布、帆布、车罩一边固定在车顶或车身上,
  另一边用石头、木棍、备用胎撑起来,形成一面斜坡阴影;
  布要绷紧,高度留出空隙通风
- 地坑式遮阳(更凉快,但要挖,只在清晨或傍晚做):
  1. 挖一条能躺下一个人的浅沟,深约40-60 cm,沟的长边东西走向
     (这样一天大部分时间都能遮住)
  2. 挖出的沙堆在沟的两侧,用来压住布边
  3. 盖上一块布,上面隔约20-30 cm再盖一层
     (两层之间的空气能隔热,比一层凉很多)
  4. 浅色、反光的一面朝上(应急保温毯银色面朝上)
- 峡谷、岩洞的阴影最好,但注意落石、蛇蝎,也不要选在可能走山洪的沟底
- 阴影会移动: 提前想好太阳转过去后挪到哪里
```

**白天活动**:
```
❌ 不要在10:00-18:00暴晒下行动
✓ 待在阴凉处
✓ 节省体力和水分
```

```
补充说明:
- ⚠️ 白天不要关着门窗待在停着的车里: 阳光下的车内温度可以
  在短时间内升到五六十度以上,比车外的阴影处热得多;
  打开车门车窗通风,人在车旁的阴影里休息
- 不要长时间开着发动机吹空调: 很快会耗光燃油;
  车被沙埋住排气管时,发动机废气中的一氧化碳会进入车内,可能中毒
- 阴凉处也要遮住头、颈,坐在垫子上,不要贴着晒热的地面
```

### 保暖(夜晚)

**沙漠夜晚寒冷!**

```
方法:
✓ 挖浅坑(沙堆保温)
✓ 堆沙围挡风
✓ 火堆(如有燃料)
✓ 多层衣物
✓ 保温毯
✓ 活动身体
```

沙漠空气干燥、云少,太阳一落,地面的热量很快散到天上,一天里的温差常常有二三十度。白天热到中暑、夜里冷到发抖,在沙漠里是常事。**我国的沙漠戈壁冬季夜间可降到零下二三十度,这时失温比中暑更危险**,按[雪地极地求生](04-雪地极地求生.md)和[野外失温](08-涉水山洪与野外失温.md#不只是冬天-野外失温)的原则准备。

```
具体做法:
- 天黑前就把衣服穿上,不要等冷得发抖才加
  (白天出过汗的衣服如果还是湿的,夜里会更冷)
- 不要直接睡在地上: 夜里的地面会持续吸走身体的热,
  垫上垫子、衣物、干草、灌木枝,隔开地面
- 睡在车里比睡在外面暖和(关好门窗,但不要开着发动机取暖睡觉)
- 风大时睡在沙丘、岩石或车的背风一侧
- 燃料: 枯死的灌木(梭梭、红柳的枯枝)、骆驼粪、牛羊粪都能烧;
  在车上可以少量用机油、汽油引火,远离车辆和油箱
- 应急保温毯裹在身上时,把身体整个包住,尤其是头颈
- 几个人靠在一起取暖
- 出现剧烈发抖、动作笨拙、说话含糊,是失温的信号,见失温章节
```

生火的方法见[基础生存技能-生火技术](00-基础生存技能.md#生火技术)。

## 导航

### 白天

**避免迷失**:
```
✓ 沿车辙、小路
✓ 做标记
✓ 记住来时路
✓ 观察地标
✓ 使用指南针/GPS

⚠️ 极易迷失方向!
- 地形单一
- 缺乏地标
- 海市蜃楼
```

#### 沙丘地形

```
- 沙丘会移动、变形: 风一吹,脚印、车辙几小时内就可能被抹平,
  不要把某个沙丘当作长期地标,也不要指望顺着脚印原路返回
- 沙丘一面缓、一面陡: 缓坡是迎风面,陡坡(落沙坡)是背风面;
  在同一片沙丘区里,陡坡大多朝向同一个方向,可以帮助大致判断方位,
  但只能作参考,要配合太阳、星星、指南针
- 在沙丘之间的低地(丘间地)顺着沙丘延伸的方向走,
  比翻越一道道沙丘省力得多
- 陡的落沙坡上沙子松软,往上爬极费力;从顶上往下走可能滑塌,
  不要靠近陡坡边缘
- 戈壁(砾石荒漠)地面平坦坚硬,好走,但更缺少地标,
  远处看着很近的山可能要走一两天
```

#### 海市蜃楼和看错距离

```
- 炎热的平地上,远处常出现一片"湖水"、"水面"的影子,
  走近却什么都没有: 这是地面被晒热后空气折射形成的,是天空的倒影
- 中午地面热气蒸腾,远处的东西会抖动、变形、看起来浮在空中,
  很难认准地标;尽量在早晨、傍晚看地形、定方向
- 沙漠空气干燥透明,远处的山、建筑看起来比实际近得多,
  "看着只有几 km"往往是十几甚至几十 km
- 不要追着"水面"或"看起来很近"的目标在白天出发
```

#### 用指南针、手机和标记

```
- 离开车辆前,在手机或GPS上记下车的位置(标记航点),
  并确认自己会用"导航回到这个点"
- 用指南针时离开车辆和大块金属几 m 以上,否则读数会偏
- 沿途用石头摆箭头、插树枝、系布条做记号,方向指向来路
- 手机没有信号时,GPS定位通常仍然可以用(提前下载离线地图),
  但要省电: 定一次位就关屏幕或开飞行模式
- 走一段就回头看一眼来路的样子,回来时才认得出
```

辨方向的方法见[基础生存技能-导航与定向](00-基础生存技能.md#导航与定向),迷路后怎么办见[户外出行准备与求救-发现自己迷路了](07-户外出行准备与求救.md#发现自己迷路了)。

**沙尘暴**:
```
如遇到:
1. 立即寻找遮蔽
2. 背风方向
3. 用布遮住口鼻
4. 躺下(避免吸入沙尘)
5. 保护眼睛
6. 等待过去
```

```
具体做法:
- 征兆: 远处地平线上出现一道黄褐色或暗红色的"墙",风突然变大,
  天色发暗;看到后立即准备,不要试图赶在它到来前走完路程
- 躲在大石头、土坎、车的背风一侧;在车里就关好门窗留在车里
- 趴下或蹲下、侧身背对风,用衣服包住头,用湿布或口罩捂住口鼻,
  有护目镜、眼镜就戴上,没有时闭眼、用布遮住
- 在开阔地上把背包、物品压在身边或身下,防止被风吹走
- 沙尘中能见度可以降到几 m,绝对不要继续走路或开车赶路
  (容易迷路、走散、摔下沟坎);同伴之间互相拉住或用绳子连在一起
- 记住沙尘暴来之前自己面对的方向和要走的方向,
  过去之后周围的地形和痕迹可能全变了
- 沙子进眼睛不要揉,用清水冲洗
```

更多沙尘暴的应对见[气象灾害-沙尘暴](../02-灾难应对/02-气象灾害.md#沙尘暴),眼睛进沙的处理见[眼睛异物](../01-日常疾病和伤害/04-异物处理.md#眼睛异物)。

### 夜间

```
✓ 星星导航(参见基础技能)
✓ 温度较低
✓ 可行动(如必须)
✓ 小心视线
```

```
补充说明:
- 夜里出的汗少得多,必须移动时尽量在夜里、清晨走
- 出发前在白天看清要走的方向,选一颗星或远处的山影作为目标,
  每隔一段时间重新对准(星星会随时间移动)
- 有月光的夜晚好走得多;没有照明时步子放小、放慢
- 夜里蛇、蝎子出来活动,要用头灯或手电照路,不要伸手乱摸
- 注意沙丘的陡坎、冲沟和坑洞;看不清前方时停下来,等天亮
- 多人走夜路不要拉开距离,定时清点人数
```

星星辨方向见[基础生存技能-星星法](00-基础生存技能.md#星星法夜晚),更精确的方法见[天文导航进阶](../09-进阶科学与工程/09-天文导航进阶.md#二精确定方向)。

### 是否留在原地?

**留在车旁**(如有):
```
✓ 更易被发现(大目标)
✓ 有遮蔽
✓ 可能有水、食物
✓ 镜子、轮胎(信号)

除非:
- 确知方向和距离
- 有足够水
- 否则留下!
```

#### 为什么留在车旁

```
1. 好找: 从飞机、无人机上看,一辆车比一个人大得多,
   一个走在沙漠里的人几乎不可能被看到
2. 搜救从你的路线和最后位置开始: 有人知道你的行程时,
   搜救队首先沿路线找车;人走开了,搜索范围就变成一大片
3. 车本身就是物资:
   - 车身和车里的布、座套、车罩能搭遮阳棚
   - 后视镜可以当信号镜,车灯、喇叭能发信号
   - 备用胎、机油可以烧出黑烟(见下面信号部分)
   - 夜里车内可以挡风保暖
4. 省水: 在阴影里不动,每天失去的水比白天走路少得多;
   在高温下步行几十 km 去求救,往往在中途就脱水、中暑
5. 人走开以后,可能连车也找不回来了
```

#### 车陷在沙里

```
- 一陷住就停,不要猛踩油门: 车轮空转只会越陷越深
- 在清晨或傍晚凉快时处理,中午先躲阴
- 挖开车轮前方(以及底盘下)的沙子,
  在轮胎前面垫脱困板、地垫、木板、灌木枝、石块
- 适当给轮胎放气,让轮胎和沙子的接触面变大,更容易出来;
  出来后低速开到坚硬路面,尽快补气
- 低挡、缓慢给油,向来时的方向(车辙压实的地方)倒出来
- 结伴的车用拖车绳拖出,拖车时人远离绳子(绳子断了会弹伤人)
- 不要为了脱困干到筋疲力尽、大汗淋漓;弄不出来就留在车旁求救
```

#### 实在要离开时

只有以下情况才考虑离开车辆: 确切知道有人、有水的地方在哪个方向、有多远;带的水足够走完全程;身体状况允许;并且明知不会有人来找(没有留行程单、联系不上任何人)。

```
如果决定走:
- 只在傍晚、夜里和清晨走,白天找阴凉躲着
- 尽量沿着道路、车辙、电线杆、管线走,不要抄近路穿沙丘
- 在车上留下纸条(写在显眼处或车窗上): 几个人、什么时候离开、
  往哪个方向走、带了多少水、要去哪里
- 沿途留下记号,方向指向你前进的方向
- 带上全部的水、遮阳布、镜子、哨子、手电、指南针或手机
- 多人时不要分散;有伤病员时,伤员和至少一个人留在车旁,
  其余身体好的人结伴去求援
```

原地等待还是自行撤出的更多判断见[野外伤病处置与转运-原地等待还是自行撤出](11-野外伤病处置与转运.md#原地等待还是自行撤出)。

## 行动

### 何时行动

```
✓ 夜间、清晨、傍晚
✓ 温度较低
✓ 保存体力
✓ 减少水分流失
```

一般安排: 天亮前后走几个小时 → 上午太阳变烈前找好或搭好阴凉,躲到傍晚 → 傍晚太阳下山后再走,夜里视情况继续或休息。冬季白天不热,可以白天走,夜里重点是保暖。

### 如何行走

```
✓ 稳定步速
✓ 不要赶路
✓ 定期休息
✓ 阴凉处休息
✓ 少量喝水(频繁)
✓ 避免出汗过多
```

```
补充说明:
- 速度以"能边走边说话、不喘"为准,走一个小时左右歇一会儿
- 多人时按最慢的人的速度走,最慢的人走在前面,不要拉开距离
- 沙地上走: 尽量踩在沙子较硬的地方(迎风坡、沙丘之间的低地、有植物的地方),
  避开松软的落沙坡;步子小一点
- 鞋子进沙会磨出水泡: 扎紧裤脚或用布条包住鞋口,定时倒沙
- 出现头晕、头痛、恶心、乏力、停止出汗或反常地烦躁 → 立即停下,
  到阴凉处休息降温(见下面中暑部分)
```

脚上水泡的处理见[野外伤病处置与转运-脚上的水泡](11-野外伤病处置与转运.md#脚上的水泡)。

### 穿着

```
✓ 保持衣物穿着:
  - 防晒
  - 减少蒸发
  - 防风沙
✓ 浅色宽松
✓ 长袖长裤
✓ 头部遮盖(自制头巾)
✓ 太阳镜/眼部保护
✓ 坚固鞋子(沙地烫)
```

```
补充说明:
- 头巾: 用一块大布或T恤包住头顶、颈后和两侧,前面可以遮住口鼻
  (挡风沙,也减少呼吸失水);布打湿后戴上更凉快(有多余的水时)
- 没有太阳镜: 用布、纸板剪一条窄缝挡在眼前,
  沙漠的强光和沙面反光会灼伤眼睛,和雪盲类似
- 皮肤暴露处涂防晒霜,嘴唇涂润唇膏;严重晒伤会起水疱、发热,
  本身就会加重失水
- 夜里加衣服,白天不要因为热而脱光
- 不要光脚在沙地上走: 夏天中午沙面可以烫伤脚底
```

## 食物

### 原则

```
⚠️ 不吃比乱吃好!

- 食物需水消化
- 缺水时少吃或不吃
- 水优先!
```

```
补充说明:
- 一个人有水、没有食物,通常能坚持几周;沙漠求生一般在几天内
  就能得救或走出,食物不是这几天的问题
- 水够喝时可以正常吃;水不够时少吃,
  尤其少吃肉、蛋、干肉这类高蛋白的食物和很咸的食物(消化、排出时需要更多的水);
  含水多的水果、含糖的食物相对好一些
- 不吃不认识的植物、蘑菇、果子
- 不要为了找食物在白天出去活动,出的汗得不偿失
```

### 可能食源

**植物**(极少):
```
- 仙人掌果(某些可食)
- 沙漠植物种子
- ⚠️ 需确认,大多有毒或不可食
```

**动物**:
```
- 蜥蜴、蛇(煮熟)
- 昆虫(蚂蚁、甲虫)
- 鸟蛋
- 小型哺乳动物

获取:
- 夜间活动多
- 岩石下
- 简易陷阱
```

```
⚠️ 补充说明:
- 只有在真正长期困在沙漠、生命受到威胁时才考虑捕食野生动物;
  我国很多荒漠动物(野骆驼、鹅喉羚、各种沙蜥等)是保护动物,
  平时猎捕、食用野生动物是违法的
- 抓蛇、翻石头抓蜥蜴容易被蛇蝎咬伤蜇伤,收益很小
- 野生动物一定要彻底煮熟,野生动物可能携带寄生虫和疾病
```

昆虫和可食植物测试见[基础生存技能-食物获取](00-基础生存技能.md#食物获取),野菜误食见[毒蘑菇与野菜误食](09-毒蘑菇与野菜误食.md)。

## 信号

```
信号要提前准备好,发现飞机、车辆时立刻能用:
- 白天: 镜子放在手边,烟堆准备好
- 夜里: 手电、车灯、火堆准备好
- 地面标记在凉快时摆好,一直留着
发信号时按"三"规则: 三次一组,重复发出
```

### 视觉

**镜子反光**:
```
⚠️ 沙漠最有效信号!
- 晴天从空中可见十几 km 以上
- 向天空、地平线扫射
- 看到飞机/车立即信号
```

```
怎样对准:
1. 一只手伸直,食指和中指比一个"V"字,把目标(飞机、车)卡在两指之间
2. 另一只手拿镜子放在眼睛下方,把反射的光斑先打在自己的手指上
3. 慢慢把光斑移到两指之间,再左右轻轻晃动,光就扫过了目标
- 没有镜子: 汽车后视镜、手机屏幕、光盘、擦亮的金属片、
  应急保温毯的银色面都可以
- 看到飞机时连续闪;没有目标时也隔一会儿向地平线各个方向扫一遍
- 不要一直用强光直射驾驶员的眼睛,飞机已经朝你飞来、摇晃机翼回应后,
  改成间断闪光
```

**烟雾**:
```
- 白天有效
- 轮胎、油(黑烟)
- 保持准备好
```

```
补充说明:
- 沙漠背景是浅色的,黑烟比白烟显眼;
  可以在火堆上加橡胶、机油、塑料,或者烧一个备用胎(放在离车较远处)
- ⚠️ 烧轮胎、机油的烟有毒,人站在上风处;烧之前先把车开远或远离火堆,
  轮胎周围清空可燃物
- 预先搭好火堆、准备好引火物,听到飞机声再点,
  不要整天烧着浪费燃料
```

**地面标记**:
```
- SOS(大石头、深色材料)
- 至少3 m高字母
- 与沙漠对比
```

```
补充说明:
- 在浅色沙地上用深色的石头、灌木枝、衣物、座椅垫摆
- 也可以在沙地上挖沟摆字: 沟的阴影从空中能看到
  (在清晨或傍晚挖,中午不要干)
- 地面对空信号: V 表示需要援助,X 表示需要医疗援助
- 字越大越好,摆在车旁的开阔平地上
```

**火光**:
```
- 夜晚
- 三堆火
```

```
补充说明:
- 三堆火摆成三角形或一条直线,间隔大致相等
- 夜里车灯、手电闪光也能传很远: 按三下一组闪
```

### 声音

```
- 哨子
- 喊叫(省点体力)
```

```
补充说明:
- 哨子比喊叫传得远,也不费力、不费水: 三声一组,停一下再吹
- 汽车喇叭: 三声一组,但别耗光电瓶(电瓶还要发动车、开灯)
- 只在听到人声、车声、看到灯光时用声音信号
```

### 求救电话

```
- 有信号时立即拨打110或120(也可以拨112),说清楚位置
  (坐标、走的路线、车的颜色和型号、几个人、伤病情况)
- 信号很弱时,发短信往往比打电话容易发出去;
  到附近高处、开阔处试一试
- 手机省电: 不用时关机或开飞行模式,约定好时间再开机
- 有卫星通信设备时,一出事就发送求救和位置,不要等到情况恶化
```

求救信号的详细方法见[基础生存技能-求救信号](00-基础生存技能.md#求救信号),怎样说清位置见[户外出行准备与求救-报警求救](07-户外出行准备与求救.md#报警求救-说清楚你在哪里)。

## 危险

### 中暑

**症状**:
```
- 体温高
- 皮肤干热
- 意识模糊
- 停止出汗(劳动中发生的热射病常常仍在出汗,不能因为有汗就排除)

⚠️ 致命!
```

```
先看意识:
- 在高温中出现任何意识异常(说话含糊、答非所问、走路不稳、
  反常地烦躁或犯困、抽搐、昏迷)→ 按热射病处理,这是急症
- 意识清楚,只是大量出汗、头晕、恶心、乏力、脸色苍白、皮肤湿冷
  → 多是热衰竭,及时休息降温补液能恢复,不处理会发展成热射病
- 没有体温计或量不准时,不要等量体温,看意识就够了
```

**热射病怎么办**(能多快就多快,边降温边求救):
```
1. 立即求救(110/120,或者用卫星设备),同时开始降温
2. 移到阴凉处,脱去多余衣物
3. 降温(有什么用什么):
   - 水够时: 用防水布、塑料布兜住患者四边,倒进水,
     让身体泡在水里,只露头颈
   - 水不多时: 用水把全身皮肤打湿,不停地扇风、吹风
     (沙漠空气干燥,蒸发降温的效果很好),干了再打湿
   - 湿布敷在颈部两侧、腋下、腹股沟
   ⚠️ 这时把水用来救命是值得的,不要舍不得
4. 意识不清、抽搐的人不要喂水,放成侧卧位,防止呕吐物呛入气管
5. 一直降温到意识明显好转、开始发抖;之后继续观察,
   体温或意识又变差时再降温
6. 即使醒过来了,也必须尽快送医(可能已经有肾、肝、肌肉损伤)

❌ 不要给退烧药(中暑不是发烧,退烧药无效且伤肝肾)
❌ 不要用酒精擦身
```

**热衰竭**: 在阴凉处平躺,抬高双腿,脱掉多余衣物,打湿皮肤扇风;清醒、不呕吐时小口喝补液盐或淡盐水。处理约半小时仍不好转,或出现意识改变、抽搐,按热射病处理。好转后当天不要再在高温下活动。

分级表、冷水浸泡的具体做法和注意事项见[急性症状-中暑](../01-日常疾病和伤害/05-急性症状.md#中暑);野外等待救援时的处置见[野外伤病处置与转运](11-野外伤病处置与转运.md#高原反应中暑失温)。

**预防**:
```
✓ 遮阳
✓ 补水
✓ 避免日间活动
✓ 保持通风
```

```
补充说明:
- 刚到炎热地区的头几天身体还没有适应(适应高温需要约1-2周),
  这时最容易中暑,活动量减半
- 老人、儿童、肥胖、有心脏病等慢性病、正在腹泻或发烧、
  服用利尿剂等药物的人风险更高
- 结伴的人互相观察: 中暑的人自己常常意识不到,
  同伴发现他反应变慢、说话奇怪,要立即让他停下降温
- 喝酒、睡眠不足、前一天已经脱水,都会增加中暑的风险
```

### 脱水

**征兆**:
```
轻度:
- 口渴
- 尿色深

中度:
- 极度口渴
- 乏力
- 头晕
- 少尿

重度:
- 不再口渴(危险!)
- 无尿
- 意识模糊
- 皮肤干燥失弹性
```

```
处理:
- 轻、中度: 到阴凉处休息,小口频繁地喝水,
  最好喝口服补液盐或淡盐水(大量出汗丢失的不只是水,还有盐)
- 站起来时头晕眼黑、心跳快,说明已经明显脱水,不要再走路
- 重度(意识模糊、无尿、喝不进去): 需要静脉补液,立即求救;
  意识不清的人不要硬灌水
- 儿童和老人脱水更快,而且老人口渴感迟钝,要主动让他们喝
```

脱水的判断(包括儿童)见[常见疾病-脱水症状识别](../01-日常疾病和伤害/01-常见疾病.md#脱水症状识别)。

### 动物

沙漠里的蛇、蝎子、蜘蛛大多在夜里出来活动,白天躲在石头下、灌木根部、洞里和阴凉处——正好是人白天躲阴、夜里走路的地方。被咬、被蜇大多是因为把手脚伸进了看不见的地方。

**蝎子**:
```
- 岩石下、鞋子里
- 检查睡袋、衣物
- 晚上活动
- 蜇伤:冰敷,就医
```

```
补充说明:
- 早上穿鞋、穿衣服前,先倒过来抖一抖、拍一拍
- 不要光脚走路,夜里用手电照路;蝎子在紫外线手电下会发出荧光
- 不要随手翻石头、捡柴;要翻时用棍子撬开,站在石头的另一侧
- 睡觉时把睡袋拉链拉好,鞋子、衣服装进袋子里或倒挂起来
- 被蜇后: 用清水和肥皂冲洗,冷敷止痛;多数只是局部剧痛、麻木
- 儿童被蜇,或出现流口水、肌肉抽动、眼球乱转、呼吸困难、
  大量出汗、呕吐 → 立即求救送医
```

**蛇**:
```
- 日间藏身阴凉处
- 晚上活动
- 用棍子探路
- 检查岩石缝隙
```

```
补充说明:
- 遇到蛇: 停下,慢慢后退,给它让出路,不要抓、不要打
- 坐下、躺下前看清楚周围,不要坐在石头堆、灌木丛旁边
- 被咬后: 保持安静、少动,取下伤肢的戒指、手表,
  伤肢制动,保持与心脏大致同一水平,立即求救;
  不要切开伤口、不要用嘴吸、不要用冰敷或烧烫
```

被蛇咬后的处理见[外伤处理-蛇咬伤](../01-日常疾病和伤害/02-外伤处理.md#蛇咬伤),预防见[马蜂蜱虫与危险动物-蛇](10-马蜂蜱虫与危险动物.md#蛇)。

**蜘蛛**:
```
- 检查鞋子、衣物
- 小心岩石下
```

```
补充说明:
- 多数蜘蛛咬伤只是局部红肿,冲洗、冷敷即可
- 伤口中心变紫变黑、范围扩大,或出现肌肉痉挛、腹痛 → 就医
```

蝎子、蜘蛛、蜈蚣等叮咬的处理见[外伤处理-其他常见叮咬和接触](../01-日常疾病和伤害/02-外伤处理.md#其他常见叮咬和接触)。

## 📝 沙漠求生要点

```
记住:
1. 水是生命!(找水、省水、存水)
2. 遮阳防晒(白天不活动)
3. 保暖(夜晚温差大)
4. 不要迷路(标记、地标)
5. 留在车旁(如可能)
6. 信号(镜子反光最有效)

优先级:
水 >> 庇护所 >>> 其他

有水但不吃饭:
- 可活约3周
不喝水(沙漠高温下):
- 可能只能坚持1-2天

⚠️ 水是一切!
```

```
最容易犯的错误:
❌ 水带得不够,单车进沙漠,不告诉别人路线
❌ 车坏了就弃车,白天顶着太阳走路求救
❌ 舍不得喝水,脱水后判断失误
❌ 热了就脱衣服
❌ 追着"湖水"(海市蜃楼)或"看起来很近"的山走
❌ 中午挖坑、找水、找食物,出的汗比得到的多
❌ 白天关着车窗待在车里,或开着发动机在车里睡觉
❌ 只防热不防冷,夜里冻得发抖
```
