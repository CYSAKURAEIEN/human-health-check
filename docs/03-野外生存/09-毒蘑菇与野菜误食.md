## 为什么要专门讲

**采食毒蘑菇是我国家庭食物中毒的首要原因,也是食物中毒死亡的主要原因。** 每年雨季(南方春夏、北方夏秋),云南、贵州、湖南、四川、广西等地都有全家中毒、多人死亡的事件,城市公园、小区草坪里长出的蘑菇也一样有毒。

野菜野果误食的情况少一些,但有几种植物毒性极强,误食一点就可能致命。

```
最重要的一条:
✓ 不采、不买、不卖、不吃不认识的野生蘑菇
✓ "认识"必须是100%确定,"看起来像""以前吃过类似的"都不算
✓ 野外求生时,蘑菇的热量很低,完全不值得冒这个险
```

## 毒蘑菇: 没有简单的鉴别方法

很多剧毒蘑菇和可食用的蘑菇长得非常像,连有经验的采菌人每年都有中毒的。**目前没有任何简单的方法能分辨蘑菇有没有毒,鉴别要靠专业人员和设备。**

```
以下"经验"全部不可靠:
❌ "颜色鲜艳的有毒,颜色朴素的没毒"
   → 最致命的鹅膏菌,很多是白色、灰色、灰褐色的,外表很朴素
❌ "用银针、银器、大蒜一起煮,变黑就有毒"
   → 蘑菇的毒素不会让银器、大蒜变色
❌ "煮熟、煮久、加辣椒就能去毒"
   → 致命的毒素(鹅膏毒肽)非常稳定,高温煮不坏
❌ "有虫咬过、动物吃过的没毒"
   → 动物和人对毒素的反应不一样
❌ "长在松树下、草地上的没毒"
❌ "撕开后有乳汁、变色的才有毒"
❌ "用手机拍照识别"
   → 识别准确率不高,不能用来判断能不能吃
❌ "村里老人一直这么吃"
   → 每年中毒的人里,有很多是常年采菌的人
```

### 特别危险的几类

```
鹅膏菌(俗称"白毒伞""致命白毒伞""灰花纹鹅膏"等):
- 我国毒蘑菇中毒死亡的主要原因
- 很多是白色或灰色,外表朴素,常被误认为可食用的菌子
- 中毒后要经过一段"假愈期",然后肝脏衰竭(见下节)

肉褐鳞环柄菇: 北方城市公园、绿地常见,剧毒,也会损害肝脏

亚稀褶红菇: 南方常见,外形像可食用的菌子,
  可引起横纹肌溶解(肌肉坏死),病死率很高

见手青等牛肝菌: 市场上有卖,但没有彻底炒熟时会引起幻觉
  (看到"小人"等),要彻底加热熟透
```

⚠️ 不要根据上面的描述去"辨认"蘑菇。这里只是说明: 致命的蘑菇往往不像人们想象的那样"看起来就有毒"。

## 毒蘑菇中毒的类型

| 类型 | 一般多长时间出现症状 | 表现 | 危险程度 |
|------|---------------------|------|----------|
| 胃肠炎型 | 较快,常在几个小时内 | 恶心、呕吐、腹痛、腹泻 | 多数较轻,但严重腹泻可致脱水 |
| 神经精神型 | 较快 | 幻觉、兴奋、流口水、大量出汗、瞳孔变化 | 多数可恢复,严重时危及生命 |
| 急性肝损害型 | **较慢,常在6-30小时后** | 先呕吐腹泻,好转后1-2天出现黄疸、出血、昏迷 | **最致命** |
| 横纹肌溶解型 | 数小时到一天 | 肌肉酸痛无力、尿呈酱油色 | 很危险,可致肾衰竭、心脏骤停 |
| 溶血型、急性肾衰竭型等 | 不一 | 尿色变深、尿少 | 危险 |

### ⚠️ 假愈期

```
急性肝损害型中毒(主要由鹅膏菌引起)的典型经过:
1. 吃完后6-30小时,开始恶心、呕吐、腹痛、腹泻
2. 治疗后症状消失,病人觉得"好了"——这就是"假愈期"
3. 1-2天后,肝脏、肾脏衰竭的症状出现: 黄疸、出血、昏迷,
   此时往往已经错过最佳治疗时机

所以:
⚠️ 吃完蘑菇6小时以后才出现症状的,反而更危险
⚠️ 不能因为"吐完、拉完就好了"而不去医院或提前离开医院
```

## 吃了野生蘑菇后不舒服

```
1. 立即拨打120或尽快去医院,不要等症状加重
2. 一起吃过这些蘑菇的人,即使没有症状,也都要去医院
3. 带上剩下的蘑菇(生的、熟的都可以),或者拍下照片
   - 没有剩下的,把吃过的菜、呕吐物带上
   - 帮助医生判断是哪种蘑菇
4. 告诉医生: 什么时间吃的、吃了多少、什么时候开始不舒服
5. 症状好转了也要听医生的,不要自行出院

❌ 不要自己用偏方解毒(喝绿豆汤、灌醋等)
❌ 不要自行催吐;是否需要催吐按120或医生的指导
```

中毒的通用处理见[中毒-中毒的通用处理原则](../01-日常疾病和伤害/12-中毒.md#中毒的通用处理原则)。

## 容易认错的有毒植物

| 有毒植物 | 常被误认为 | 危险 |
|----------|-----------|------|
| 钩吻(断肠草) | 金银花、其他草药 | 毒性极强,少量即可致死,呼吸麻痹 |
| 毒芹 | 野芹菜、水芹 | 全株有毒,抽搐、呼吸麻痹 |
| 商陆的根 | 人参 | 呕吐、腹泻、抽搐,严重时呼吸麻痹 |
| 曼陀罗的种子、果实、花 | 误入食物、误当草药 | 口干、皮肤发红、瞳孔放大、幻觉、狂躁 |
| 马桑的果实 | 野果(儿童常误食) | 抽搐、昏迷 |
| 蓖麻籽 | 坚果 | 严重呕吐腹泻、脱水,可致死 |
| 乌头、草乌、附子 | 自采自制的药酒、炖品 | 心律失常、心脏骤停,极其危险 |
| 苦杏仁、桃仁、生木薯 | 坚果、食物 | 含氰化物,生吃或吃多了中毒 |

```
✓ 以上只是常见的例子,有毒植物远不止这些
✓ 不要自己上山采草药、泡药酒;中药材从正规药店购买,按医生的用法用量
✓ 教育孩子不要吃路边、野外的果子、种子
```

误认的有毒植物还有夹竹桃、毒藤等,见[森林求生-植物](02-森林求生.md#植物)。

## 采食野菜野果的原则

```
只吃:
✓ 自己100%确定认识的(最好是从小就吃、当地普遍食用的)
✓ 按当地传统方法处理过的(很多野菜要焯水、浸泡去除苦味和有害物质)

不采:
❌ 不认识或不确定的
❌ 路边、工厂附近、垃圾堆旁、喷过农药的地方的

吃的时候:
✓ 第一次吃某种野菜,只吃少量
✓ 野菜、野果吃了以后觉得嘴麻、舌头麻、恶心、头晕 → 立即停止,就医
✓ 留一点没吃的,万一中毒可以给医生看
```

### 关于"可食性测试"

一些野外求生资料介绍一种逐步试吃的"通用可食性测试"。**这种测试不能发现慢慢发作的毒素**(毒蘑菇、一些植物的毒素要几个小时到几天后才发作),**也完全不适用于蘑菇**。人可以几个星期不吃东西,但误食一次剧毒植物就可能致命。见[基础生存技能-可食植物测试](00-基础生存技能.md#可食植物测试)中的警告。

野外更可靠的食物来源是昆虫、鱼和能确认的植物,见[基础生存技能-食物获取](00-基础生存技能.md#食物获取)。

## 📝 要点

```
1. 不采、不买、不吃不认识的野生蘑菇
2. 颜色、银针、大蒜、虫咬、煮熟——这些鉴别方法全部不可靠
3. 最致命的鹅膏菌外表朴素,中毒后有"假愈期"
4. 吃完6小时以后才出现症状的更危险
5. 中毒后所有吃过的人都去医院,带上剩下的蘑菇或照片
6. 钩吻像金银花、毒芹像水芹、商陆根像人参
7. 不自己采草药泡药酒(乌头、草乌极危险)
8. 野菜只吃100%认识、按传统方法处理过的
```
