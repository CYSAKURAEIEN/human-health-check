## 山洪: 溪谷里最大的危险

山区溪谷汇水快,**上游下暴雨,下游可能晴空万里**,洪水却在几分钟内冲下来。每年都有在河谷里玩水、扎营的人被山洪卷走。

### 山洪来临的征兆

```
⚠️ 出现以下任何一个,立即离开河道,往高处走:
- 溪水突然变浑浊、变黄
- 水位突然上涨,或者反常地突然下降(上游可能被堵塞,随后会溃决)
- 水里突然出现大量树枝、杂草、泡沫
- 听到上游传来轰隆隆的声音
- 上游方向乌云密布、有雷声,或者已经下了一段时间大雨
- 收到暴雨、山洪预警
```

### 遇到山洪

```
✓ 立即往河道两侧的高处跑(和水流方向垂直)
❌ 不要顺着河谷往下游跑(跑不过洪水)
❌ 不要为了拿东西回去
❌ 不要涉水过河、不要开车过漫水的路和桥
✓ 被困时,爬到高处或者结实的大树上,等待救援
✓ 山洪往往很快就退,但雨没停之前不要回到河道里
```

洪水的更多应对见[气象灾害-洪水](../02-灾难应对/02-气象灾害.md#洪水)。

## 露营选址

```
❌ 不要在以下地方扎营:
- 河滩、河道里、干涸的河床(看起来没水的河床,雨后也可能变成河道)
- 沟口、峡谷底部
- 两条溪流交汇处的低地
- 悬崖、陡坡下(落石)
- 孤立的大树下(雷击、断枝)

✓ 选择:
- 明显高于河床的台地,地面上没有被水冲过的痕迹(泥沙、倒伏的草、挂在树上的杂物)
- 离水边有一定距离,并且有往高处撤离的路线
✓ 夜里下雨时有人留意水声和水位,准备随时撤离
```

庇护所选址的更多原则见[基础生存技能-选址](00-基础生存技能.md#选址)。

## 涉水过河

**能不过河就不过河。** 涉水是野外最容易低估的危险之一: 齐膝深的急流就能把人冲倒,冲倒后背包会把人往水里拖。

### 判断能不能过

```
❌ 以下情况不要过:
- 水流湍急,扔一根树枝下去,漂得比快步走还快
- 急流处水深超过膝盖
- 水浑浊,看不到底
- 下游不远处有瀑布、急流、深潭、倒木
- 刚下过大雨、水位正在上涨
- 自己很累、很冷

✓ 不确定时: 等一等
  - 山溪雨后涨水往往几个小时后就会回落
  - 冰雪融水形成的河流,早上的水量通常比下午小
✓ 沿河岸找更好的地方,或者绕路
```

### 选择过河的地方

```
✓ 河面宽的地方(通常更浅、水流更慢)
✓ 水面平稳、底部是小石子的地方
❌ 不要选窄处(水深流急)、河弯的外侧(冲刷深)
❌ 不要踩着湿滑的石头跳过去、不要走湿的倒木
```

### 怎样过

```
1. 解开背包的腰带和胸带
   (一旦被冲倒,可以迅速甩掉背包,不会被背包拖进水里)
2. 穿着鞋过河(防止脚被石头割伤、卡住),可以脱掉袜子
3. 面向上游,侧着身子一小步一小步横着走
4. 用登山杖或结实的木棍撑在上游一侧,形成"三点支撑"
   - 每次只移动一个支撑点,站稳了再移动下一个
5. 斜着向下游方向走(顺着水流的力量,比逆着走省力)

多人过河:
✓ 两三个人互相挽住胳膊或抓住背包,一起横排过河
✓ 最强壮的人站在上游一侧
✓ 下游方向安排人准备接应

❌ 不要把绳子系在过河人的身上
   - 人被冲倒后,绳子会把人按在水下,非常危险
❌ 不要在水里乱跑、跳
```

## 落入急流

```
1. 甩掉背包
2. 仰面朝上,脚朝下游,脚抬到水面附近
   - 用脚蹬开前方的石头
   - 双臂在两侧划水控制方向
3. 寻找机会,斜着向岸边游(和水流成一定角度,不要直接逆流)
4. 到了水缓、水浅的地方再站起来

❌ 在急流中不要试图站起来走
   - 脚可能卡进石缝,水流会把人推倒按在水里,很难脱身
❌ 不要抱住水里的倒木、树枝(水会把人冲进树枝下面)
```

### 救落水的同伴

```
✓ 先保护好自己: 在岸上救,不要下水
✓ 大声呼喊,让对方往岸边漂
✓ 扔: 绳子、救生圈、空水壶、背包(能漂浮的东西)
✓ 递: 树枝、登山杖、衣服结成的长条(趴在岸上,降低重心,防止被拽下去)
❌ 没有受过专业救援训练,不要下水救人
```

溺水者救上岸后的急救见[急性症状-溺水](../01-日常疾病和伤害/05-急性症状.md#溺水)。

## 落入冷水

即使是夏天,高山溪流和水库的水也可能很冷。冷水首先会让人呛水,而不是直接冻死。

```
"1-10-1"原则:
- 前1分钟: 落入冷水会不由自主地大口喘气("冷休克")
  → 不要挣扎,尽量把头保持在水面以上,控制呼吸,等这一阵过去
- 接下来约10分钟: 手脚还能活动
  → 抓紧这段时间自救,游到岸边或爬上漂浮物
- 大约1小时内: 体温下降,逐渐失去意识
  → 无法离开水面时,抱住漂浮物,双腿蜷起抱在胸前,减少热量散失
     几个人在水里时抱在一起

上岸后: 立即脱掉湿衣服,换上干衣服,按下方失温处理
```

## 不只是冬天: 野外失温

**失温不只发生在雪地里。** 气温十几度,只要同时有**雨淋湿衣服 + 大风 + 体力透支**,一样会发生致命的失温。2021年5月甘肃白银的山地越野赛,遇到冰雹、冻雨和大风,21名参赛者遇难,很多人只穿着短袖短裤。

### 容易发生失温的情况

```
- 春秋季节、夏季的高山上,天气突然变化(降温、下雨、刮风)
- 穿着棉质衣服被雨淋湿、被汗湿透
- 没带保暖层和防雨层
- 长时间运动后体力耗尽、没有吃东西
- 落水、涉水后
- 在野外意外过夜
```

### 识别: 早发现最重要

```
早期:
- 一直发抖
- 手指不灵活,拉不上拉链、系不了鞋带
- 走路踉跄、跟不上队伍
- 说话含糊、反应变慢、情绪低落或烦躁
- 判断力变差(比如该穿衣服了却不穿)

⚠️ 危险信号:
- 发抖停止了,但人更加迷糊(不是好转,而是更严重了)
- 意识模糊、叫不醒
- 有的人会出现"反常脱衣": 觉得热,把衣服脱掉

⚠️ 失温的人自己往往意识不到,同伴要互相观察
```

### 野外处理

```
1. 停下来,不要继续往前走或往上爬
2. 找避风、避雨的地方(大石头后面、树林里、搭起雨布)
3. 脱掉湿衣服,换上干衣服;没有干衣服时,在湿衣服外面套上防风防雨的衣物
4. 隔绝地面: 坐在背包、防潮垫、树枝上,不要直接坐在地上
5. 包裹: 用睡袋、应急保温毯从头到脚包起来(头部散热很多,要戴帽子)
6. 人清醒、能自己吞咽时,喝温热的甜饮料,吃高热量的食物
7. 把热水袋或装热水的水壶用衣服包好,放在胸口、腋下、腹股沟(不要直接贴皮肤)

⚠️ 严重失温(停止发抖、意识模糊):
- 立即求救
- 搬动时动作要轻,保持平躺
- 不要搓揉手脚,不要让他走路或活动
- 不要用火直接烤,不要泡热水
- 继续保暖,等待救援

❌ 不要喝酒(会加快散热)
```

失温的分级和更多处理见[急性症状-失温症](../01-日常疾病和伤害/05-急性症状.md#失温症);寒冷环境的穿衣见[雪地极地求生-保暖](04-雪地极地求生.md#保暖-最关键)。

### 预防

```
✓ 不穿棉质的内层衣服,穿速干或羊毛的
✓ 洋葱式穿衣: 贴身排汗层 + 保暖层 + 防风防雨外层
✓ 无论天气预报多好,上山都带保暖层和雨衣
✓ 热了提前减衣服(少出汗),停下休息时马上加衣服
✓ 按时吃东西、喝水,不要等到饿了累了
✓ 天气突变时,及时下撤或就地避险,不要硬撑
```

---

## 📝 要点

```
1. 溪水变浑、突然涨水、水里有杂物、上游有轰鸣 → 立即往两侧高处跑
2. 不在河滩、干河床、沟口扎营
3. 能不过河就不过;过河解开背包腰带,面向上游,三点支撑
4. 不把绳子系在过河人身上
5. 落入急流: 仰面、脚朝下游,不要在急流中站起来
6. 落入冷水: 先控制呼吸,抓紧前10分钟自救
7. 雨 + 风 + 疲劳,十几度也会失温;不穿棉,带保暖层和雨衣
8. 发抖停止、意识模糊是严重失温,轻柔搬动、保暖、求救
```
