## 🔑 生存优先级

```
3分钟 - 没有空气
3小时 - 恶劣环境下没有庇护所(失温或中暑)
3天   - 没有水
3周   - 没有食物
```

所以在野外,**保暖(或防暑)比找水急,找水比找食物急**。生存任务的优先顺序和生存心态见[基础生存技能-生存优先级](00-基础生存技能.md#生存优先级)。

## ⚠️ 最重要的几条

### 出发前

- 把行程告诉一个不同行的人,约好"过了某个时间联系不上就报警"
- 只走开放的正规路线;查天气,定好掉头时间,天黑前下山
- 一日徒步也要带头灯、保暖层、雨衣、充电宝、哨子

### 迷路、受伤时

- 迷路了先停下;不要沿着溪谷往下走
- 有信号就报警,报经纬度或发送位置,然后留在原地
- 怀疑脊柱损伤、大腿骨折、意识不清、休克 → 原地等待救援,不要强行搬运

### 水和天气

- 溪水突然变浑、涨水、有杂物、上游有轰鸣 → 立即往两侧高处跑
- 不在河滩、干河床、沟口扎营;能不过河就不过
- 雨 + 风 + 疲劳,十几度也会失温;不穿棉质衣服

### 吃的和咬人的

- 不采、不吃不认识的野生蘑菇;颜色、银针、大蒜等鉴别方法全部不可靠
- 远离马蜂窝;被蜇10处以上或有过敏症状,立即就医
- 进草丛扎紧裤腿,出来后检查全身的蜱虫

## 🎒 野外生存装备

### 十大必备物品

1. **刀具**: 多功能刀
2. **火种**: 打火机、防水火柴、镁棒
3. **容器**: 能烧水的金属水壶
4. **庇护**: 防水布、应急保温毯
5. **绳索**: 伞绳
6. **导航**: 指南针、地图(手机离线地图之外)
7. **急救包**: 清单见[野外伤病处置与转运-户外急救包](11-野外伤病处置与转运.md#户外急救包)
8. **信号**: 哨子、反光镜、头灯
9. **食物**: 高能量应急食品
10. **净水**: 净水片或滤水器

一日徒步的装备和穿着见[户外出行准备与求救-装备](07-户外出行准备与求救.md#装备)。
